# 战略 — 战略框架与合规

> **作为**高管，**我想要**浏览战略目录，**以便**快速找到当前战略问题所需的正确框架或旅程。
>
> **目录定位**：战略框架是分析工具，不是答案本身。它们帮助提出正确的问题、组织思考、以及向团队和投资人沟通战略逻辑。

### 框架选择决策树

```
我需要了解...
├── 当前内外部状况？ → SWOT 分析（快速，适合入门）
│   └── 内部优势是否可持续？ → VRIO 框架
├── 行业结构是否有利？ → 波特五力模型
├── 客户真正需要什么？ → 价值主张画布
├── 商业模式是否成立？ → 商业模式画布
├── 如何找到无竞争空间？ → 蓝海战略
├── 何时启动下一增长曲线？ → 第二曲线
├── 如何制定产品路线图？ → Now/Next/Later 路线图
└── 如何把以上合并为一套战略？ → 产品战略框架（元框架）
```

## 常见导航路径

常见战略任务的典型目录路径：

### 路径 A：年度战略刷新

```
10-战略-SWOT分析.md → 12-战略-VRIO框架.md → 07-战略-波特五力模型.md
    → 01-战略-蓝海战略.md → 02-战略-商业模式画布.md
    → 08-战略-产品战略框架.md → 06-战略-Now-Next-Later路线图.md
```

逻辑：先知己（SWOT + VRIO），再知彼（P5F），再找机会（蓝海），再验证模型（BMC），最后合成战略和路线图。

### 路径 B：新产品/市场进入

```
01-战略-蓝海战略.md → 11-战略-价值主张画布.md
    → 02-战略-商业模式画布.md → 08-战略-产品战略框架.md
    → 06-战略-Now-Next-Later路线图.md
```

逻辑：先找无竞争空间，再验证客户需求，再设计商业模式，最后形成战略和路线图。

### 路径 C：合规驱动的战略评审

```
04-战略-处理监管变更.md → 05-战略-数据合规处理.md
    → 02-战略-商业模式画布.md → 08-战略-产品战略框架.md
    → 06-战略-Now-Next-Later路线图.md
```

逻辑：监管变化可能影响商业模式的核心假设，需要重新验证并调整战略。

### 路径 D：组合重新平衡

```
09-战略-第二曲线.md → 07-战略-波特五力模型.md
    → 02-战略-商业模式画布.md → 08-战略-产品战略框架.md
```

逻辑：评估各业务线所处 S 曲线位置，结合行业结构，决定资源重新分配策略。
