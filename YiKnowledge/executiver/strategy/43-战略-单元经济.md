# 单元经济与商业指标

> **作为**高管，**我想要**用核心商业指标和单元经济分析判断商业模式是否成立，**以便**在战略讨论中不被财务数据吓倒——也不被虚荣指标误导。
>
> **核心洞见**：你不需要成为 CFO，但必须能用 5 个数字讲清楚你的商业模式为什么成立。如果"用户增长很好"但不知道获客成本和客户终身价值——你不知道你的增长是在创造价值还是在烧钱。

## 五个必须知道的指标

### 1. 客户获取成本 (CAC)

**定义**：获取一个新客户的平均成本。

```
CAC = 总销售和营销费用 / 新客户数
```

| 类型 | 包含什么 | 适用阶段 |
|---|---|---|
| **全成本 CAC** | 销售+市场人员薪资、广告费、工具费、渠道分成 | 成长期和成熟期 |
| **付费 CAC** | 仅广告费/市场活动费 | 早期——此时销售团队很小 |

**CAC 的常见误解**：只看广告费不看人员成本——"我们 CAC 很低，才 $50"。但支撑这 $50 CAC 的团队成本是 $50K/月。算全成本 CAC 才接近真相。

### 2. 客户终身价值 (LTV)

**定义**：一个客户在与你关系的整个周期中产生的总收入。

```
LTV = 平均月收入 × 毛利率 × 平均客户生命周期（月）
```

| 场景 | 计算方式 |
|---|---|
| 刚起步，不知道客户生命周期 | 用月流失率估算：LTV = 月收入 / 月流失率 |
| 有不同客户群 | 按群分别算 LTV——高价值客户的 LTV 可能是普通客户的 5x |
| 免费增值模式 | 只算付费用户。免费用户的价值 = 传播价值 + 转化潜力 |

### 3. LTV/CAC 比率

**定义**：商业模式的核心健康指标——每 $1 的获客投入产生了多少终身价值。

```
LTV/CAC = 客户终身价值 / 客户获取成本
```

| 比率 | 含义 | 行动 |
|---|---|---|
| < 1:1 | 商业模式不成立——每获取一个客户都在亏钱 | 要么降 CAC，要么提 LTV，重新定义客户群 |
| 1:1 ~ 3:1 | 勉强可持续 | 优化 CAC（找更便宜的渠道）或提 LTV（提价/降低流失） |
| 3:1 ~ 5:1 | **健康区间**——投入产出比合理 | 保持在健康区间 |
| > 5:1 | 可能投入不足——有机会通过更多投入加速增长 | 增加获客投入——你在用 20% 的效率烧钱 |

### 4. CAC 回收期

**定义**：花多少钱在多长时间内能赚回来。

```
CAC 回收期（月）= CAC / (月收入 × 毛利率)
```

| 回收期 | 含义 |
|---|---|
| < 6 个月 | 健康——现金流压力小 |
| 6-12 个月 | 可接受——需要确保有足够现金支撑 |
| 12-18 个月 | 需要关注——现金消耗快，需要融资或更长跑道 |
| > 18 个月 | 危险——除非有强大的现金储备或高续约保证 |

### 5. 客户流失率 (Churn)

**定义**：在给定周期内停止使用/付费的客户比例。

```
月流失率 = 当月流失客户 / 月初客户总数
年流失率 = 1 - (1 - 月流失率)^12
```

| 月流失率 | 年流失率 | 含义 |
|---|---|---|
| 1% | 11% | 优秀——SaaS 行业标杆 |
| 2% | 22% | 一般——有优化空间 |
| 3% | 31% | 糟糕——任何增长努力都会被流失吞噬 |
| 5% | 46% | 危险——半年流失近一半客户。先解决流失再谈增长 |

**流失率为什么重要**：月流失 5% 意味着每年损失 46% 的客户——你的 CAC 减半了。在解决流失之前，任何增长投入都是在用桶往漏水的缸里倒水。

## 不只是 SaaS 指标

### 内部工具/平台的"单元经济"（YrY 当前适用）

YrY 当前不是对外销售的产品——但同样需要单元经济思维：

| 概念 | SaaS 定义 | YrY 内部平台定义 |
|---|---|---|
| **客户** | 付费的外部用户 | 使用产品的内部团队成员 |
| **CAC** | 市场+销售成本 | 搭建+维护+培训成本 |
| **LTV** | 客户产生的收入 | 提高的团队效率 × 替代方案的成本 |
| **流失** | 客户停止使用 | 功能不再被使用 |

**对于 YrY 来说的核心问题**：YiKnowledge RAG 的维护成本（人月）vs. 它节省的团队查找信息的时间（人月 × 时薪）。如果维护成本 > 节省的时间价值——即使是内部工具，单元经济也是负的。

### AI 产品的特殊考量

| 考量 | 说明 |
|---|---|
| **推理成本的边际性** | 每次 AI 调用的成本是真实的可变成本——与传统软件零边际成本不同 |
| **免费层的成本** | AI 产品免费用户的每次调用都产生成本——免费层必须设硬性用量上限 |
| **模型切换对毛利率的影响** | 切换到更便宜的开源模型可以显著提升毛利率 |
| **算力作为 COGS** | AI 推理成本是营业成本 (COGS)，不是研发费用 |

## 虚荣指标 vs. 可行动指标

| 虚荣指标（看起来好，不能指导决策） | 可行动指标（能指导决策） |
|---|---|
| 注册用户总数 | 周活跃用户 (WAU) |
| 下载量 | 激活率（下载后 7 天内完成核心操作的%） |
| 页面浏览量 | 核心功能使用频次 |
| 社交媒体粉丝 | 从社区转化到产品的比例 |
| "我们增长很快" | 增长率是加速还是减速？ |

**识别虚荣指标的法则**：如果这个数字明天翻倍了，你知道该做什么不同的事吗？如果不知道——这是虚荣指标。

## 如何不适应财务的人也能用的财务检查

每次做重大商业决策前，回答三个数字：

1. **这个决定的回收期多长？** 花的钱/时间什么时候能赚回来（或节省回来）？
2. **如果这个决定的假设错了一半——我们还能承受吗？** 
3. **如果不做这个决定——最大的代价是什么？**

不需要精确的财务模型——需要的是方向性的数字思维。

## 核心产出

- 核心业务指标的月度追踪表（CAC/LTV/Churn/CAC 回收期）
- 单元经济健康检查（每季度）
- 虚荣指标清理清单

## 反模式

| 反模式 | 为何失败 | 正确做法 |
|---|---|---|
| 只看总数不看比率 | "月收入在涨"——但如果 CAC 涨得更快，你是花钱买收入 | 追踪比率：LTV/CAC、CAC 回收期 |
| 不计全成本 | "我们的单元经济很好"——但没有计入团队成本 | 全成本 CAC：人员 + 工具 + 广告 |
| 用虚荣指标自我安慰 | 注册数在涨但没人用核心功能 | 追踪激活→留存→付费的转化漏斗 |
| 忽视流失谈增长 | 月增长 10% 但月流失 5% → 净增长 5% 但趋势在恶化 | 先修复漏水的缸，再往里面倒水 |
| 只在融资时才看指标 | 平常不看，临时拼凑——董事会前发现数字不成立 | 每月追踪核心指标 |
