# VRIO Framework

> **As a** strategist, **I want to** assess whether our resources and capabilities provide sustainable competitive advantage, **so that** we invest in the right things and don't overestimate our position.

## Definition

VRIO evaluates resources and capabilities against four criteria:

| Criterion | Question |
|---|---|
| **V**aluable | Does it enable us to exploit an opportunity or neutralize a threat? |
| **R**are | Is it controlled by few, if any, competitors? |
| **I**nimitable | Is it costly or difficult for competitors to copy? |
| **O**rganized | Is the organization structured to capture value from it? |

The outcome depends on how many criteria are met:

| V | R | I | O | Competitive implication |
|---|---|---|---|---|
| ❌ | — | — | — | Competitive **disadvantage** |
| ✅ | ❌ | — | — | Competitive **parity** |
| ✅ | ✅ | ❌ | — | Temporary competitive **advantage** |
| ✅ | ✅ | ✅ | ❌ | Unexploited competitive **advantage** |
| ✅ | ✅ | ✅ | ✅ | **Sustained** competitive advantage |

## Applicable scenarios

- Build-vs-buy decisions: is this capability worth developing internally?
- Investment prioritization: which resources should we double down on?
- Acquisition due diligence: what unique resources does the target have?
- Competitive response: can competitors easily copy what we're doing?
- Identifying "unexploited" advantages that need organizational fixes

## Design steps

### Step 1: Inventory resources

List all potentially strategic resources. Consider:

| Category | Examples |
|---|---|
| **Physical** | Data centers, proprietary hardware, geographic location |
| **Human** | Talent density, specialized expertise, founder knowledge |
| **Organizational** | Processes, culture, brand, patents, exclusive partnerships |
| **Data & IP** | Training data, proprietary models, customer data, algorithms |
| **Network effects** | User base, marketplace liquidity, developer ecosystem |

### Step 2: Score each resource

For each resource, answer the four VRIO questions with evidence:

- **Valuable**: Link to revenue, cost savings, or threat mitigation
- **Rare**: How many competitors have this? Name them specifically
- **Inimitable**: What makes it hard to copy? (path dependency, causal ambiguity, social complexity, legal protection)
- **Organized**: Do we have the reporting structure, incentives, and processes to use it?

### Step 3: Map to strategic actions

| Implication | Action |
|---|---|
| Sustained advantage | **Protect and invest** — these are your moats |
| Temporary advantage | **Exploit now** — window is closing; move fast |
| Unexploited advantage | **Fix the organization** — the resource is there but you're not using it |
| Competitive parity | **Maintain** — don't overspend; it's table stakes |
| Competitive disadvantage | **Fix or exit** — either acquire the capability or compete on other dimensions |

### Step 4: Cross-reference with SWOT

Feed VRIO results into [SWOT](./swot-analysis.md):
- Sustained advantages → **Strengths** (with evidence)
- Disadvantages → **Weaknesses** (with action plan)

## Key outputs

- Resource inventory with VRIO scores (spreadsheet)
- Sustained advantage list (top 3–5) with evidence
- Unexploited advantage list with organizational fix recommendations
- Build-vs-buy recommendation for any resource gaps

## Anti-patterns

| Anti-pattern | Why it fails | Fix |
|---|---|---|
| Everything is VRIO | Overconfidence bias | Require specific competitor evidence for "Rare" and "Inimitable" |
| Only listing technical resources | Ignores brand, culture, network effects | Use the category checklist in Step 1 |
| "Organized" always checked | Most companies have org gaps | Be specific: name the team, process, and incentive that captures value |
| Static assessment | Resources decay over time | Re-assess bi-annually; any key hire/departure triggers a re-check |
| Confusing size with advantage | Big ≠ valuable or rare | Market share alone is not a VRIO resource unless it creates network effects |
