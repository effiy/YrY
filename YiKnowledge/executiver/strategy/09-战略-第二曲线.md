# 第二曲线

> **作为**高管，**我想要**合理安排当前业务向下一增长引擎的转型时机，**以便**不会等到衰退才被迫做绝望的转向。
>
> **核心洞见**：最危险的时刻不是第一曲线在衰退，而是第一曲线仍在增长——人们会问"为什么要改变正在奏效的事？"。但历史反复证明：柯达在胶片巅峰时发明了数码相机，却等到衰退才被迫转型。时机是一切。

## 定义

第二曲线模型描述任何业务、产品或技术作为 S 曲线的生命周期：

```
业绩
    ▲
    │                                    ● 第二曲线
    │                                 ╱
    │                              ╱
    │         ● 第一曲线        ╱
    │       ╱               ╱
    │     ╱               ╱
    │   ╱     ← 间隙 →  ╱
    │ ╱               ╱
    └──────────────────────────────► 时间
        增长     成熟     衰退
```

核心见解：**你必须在第一曲线仍在增长时启动第二曲线**，因为转型需要时间和资源。如果等到第一曲线见顶，你已经太晚了。

## 适用场景

- 核心业务收入增长放缓
- 颠覆性技术威胁当前模式
- 年度组合评审：每条产品线在曲线的什么位置？
- 资源配置：当前 vs 未来业务该投入多少？
- 并购战略：买来第二曲线还是自己开发？
- 识别"成熟的幻觉"——增长仍在但底层指标已恶化

## 设计步骤

### 步骤 1：绘制当前曲线

对每条产品/业务线，标绘：

| 属性 | 如何评估 | 信号 |
|---|---|---|
| **当前位置** | 增长率、市场份额趋势、获客成本趋势 | 加速（早期）、线性（中期）、减速（晚期） |
| **曲线形状** | 增长是加速（早期）、线性（中期）还是减速（晚期）？ | 二阶导数为正/零/负 |
| **剩余跑道** | TAM 渗透率、使用场景饱和度、竞争强度 | 渗透 < 20%：大空间；> 60%：有限空间 |
| **峰值指标** | 增长率下降、流失增加、价格受压、商品化 | 越多信号出现，越接近峰值 |

### 步骤 2：识别第二曲线候选

潜在第二曲线的来源：

| 来源 | 示例 | 工具 |
|---|---|---|
| **相邻市场** | 地域扩展、新垂直行业 | [蓝海战略](./01-战略-蓝海战略.md) |
| **新技术** | 现有产品的 AI 原生版本 | [VRIO](./12-战略-VRIO框架.md) |
| **商业模式创新** | 订阅制 → 市场平台 | [BMC](./02-战略-商业模式画布.md) |
| **客户细分扩展** | 企业 → 中小企业，或反过来 | [价值主张画布](./11-战略-价值主张画布.md) |
| **价值链移动** | 前向/后向整合 | [波特五力](./07-战略-波特五力模型.md) |

### 步骤 3：评估第二曲线候选

为每个候选打分：

| 标准 | 权重 | 候选 A | 候选 B |
|---|---|---|---|
| 市场规模 (TAM) | 25% | | |
| 竞争优势 (VRIO) | 25% | | |
| 与当前业务的协同 | 15% | | |
| 团队和能力匹配 | 15% | | |
| 到有意义收入的时间 | 10% | | |
| 所需资本 | 10% | | |

### 步骤 4：安排转型时机

启动第二曲线的最佳窗口：

```
太早 ──────► 最佳窗口 ──────► 太晚
   │              │                │
第一曲线        第一曲线         第一曲线
仍在加速        增长强劲         增长持平
但显示           但减速          或衰退
最终平台期迹象
```

在最佳窗口内：
- 将 10–20% 资源配置给第二曲线探索
- 保护第二曲线团队免受第一曲线运营需求的干扰
- 用第一曲线利润资助第二曲线投资

### 步骤 5：管理组合

按曲线位置分类所有产品/业务：

| 阶段 | 资源配置 | 管理方式 | KPI 重点 |
|---|---|---|---|
| **第一曲线 — 增长中** | 70–80% | 优化、规模化、防守 | 增长、效率 |
| **第一曲线 — 成熟中** | 50–60% | 收割、降成本、维持 | 利润率、现金流 |
| **第二曲线 — 探索中** | 10–20% | 保护、实验、别过早优化 | 学习速度、验证数量 |
| **第二曲线 — 规模化中** | 30–40% | 从衰退第一曲线转移资源 | 增长、单位经济 |
| **衰退中** | 0–5% | 退出或挤奶，不再投入 | 剩余价值最大化 |

### 第二曲线候选

| 候选 | 来源 | 市场潜力 | 与当前协同 |
|---|---|---|---|
| YiPet 作为 C 端 AI 助手 | 新入口形态 | 浏览器用户 × AI 助手需求 | YiAi 后端 + YiKnowledge RAG 已有基础 |
| YiKnowledge 作为独立产品 | 知识库 SaaS | 企业知识管理 × RAG | 已有结构化知识和 RAG 流水线 |
| YiAi API 外部化 | 商业模式创新 | 开发者工具 × AI API | 已有 RPC 协议和 Agent 循环 |

### 推荐优先级
1. **优先**：YiPet → YiVad 跨项目桥接验证（低投入，高学习价值）
2. **探索**：YiKnowledge 作为独立 RAG 知识库产品（中投入，差异化强）
3. **观察**：YiAi API 外部化（需等内需充分验证后再外推）

## 核心产出

- S 曲线地图，含所有产品/业务定位
- 按评估标准排序的第二曲线候选
- 资源配置建议（各曲线间百分比划分）
- 转型时机建议含触发信号
- 第一曲线峰值预警仪表盘

## 反模式

| 反模式 | 为何失败 | 正确做法 |
|---|---|---|
| 启动太晚 | 第一曲线见顶时已无资源和信誉 | 监控成熟度领先指标；在估算跑道 60–70% 时开始探索 |
| 启动太多第二曲线 | 资源摊太薄，没有获得足够投资 | 选 1–2 个第二曲线候选；其余砍掉 |
| 用管理第一曲线的方式管理第二曲线 | 第二曲线需要探索，不是优化 | 不同的 KPI、不同的团队、不同的治理 |
| 过早放弃第一曲线 | 你需要它的现金流资助转型 | 继续收获第一曲线；不要让它断粮 |
| 假设第二曲线就是"第一曲线 + AI" | 仅靠技术很少能创造新 S 曲线 | 用 [BMC](./02-战略-商业模式画布.md) 将技术与商业模式创新结合 |
