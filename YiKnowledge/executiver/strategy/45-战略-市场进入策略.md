# 市场进入策略

> **作为**高管，**我想要**在新市场机会出现时基于战略而非诱惑做出进入决策，**以便**不在"看起来大"但不适合我们的市场上浪费核心资源。
>
> **核心洞见**：进入新市场是创业公司死亡的第三大原因——前两个是"产品没需求"和"钱花完了"。新市场进入的吸引力往往来自"那边草地更绿"的错觉，而非对自身优势在新市场中能否移植的诚实评估。

## 进入决策的三层过滤

### 过滤器 1：市场吸引力

| 标准 | 评估 | 数据来源 |
|---|---|---|
| 市场规模（TAM/SAM/SOM） | 足够大吗？增长中还是萎缩中？ | 行业报告、分析师预测 |
| 竞争强度 | 是红海、蓝海还是空白？ | [波特五力分析](./07-战略-波特五力模型.md) |
| 利润结构 | 行业的平均利润率和成本结构？ | 上市公司财报、行业分析 |
| 监管风险 | 进入是否有监管壁垒？ | 监管法规、政策趋势 |

### 过滤器 2：优势可移植性

新市场需要的核心能力，你有哪些：

| 能力 | 在你当前市场的优势 | 在新市场的适用度 | 证据 |
|---|---|---|---|
| 产品/技术 | | 高/中/低 | |
| 客户关系 | | 高/中/低 | |
| 品牌/口碑 | | 高/中/低 | |
| 渠道/分发 | | 高/中/低 | |
| 运营 know-how | | 高/中/低 | |

**关键判断**：如果在当前市场做不到前三，进入新市场通常只会稀释资源。先在本市场建立可移植的优势，再谈进入。

### 过滤器 3：机会成本

| 考量 | 评估 |
|---|---|
| 进入新市场需要的核心团队注意力 | 多少人月？这些人在核心市场上能做什么？ |
| 进入期核心市场会受多大影响 | 如果核心市场在你忙着开拓新市场时被竞品侵蚀—— |
| 如果不进入的代价 | 窗口期有多久？错过了还能回来吗？ |

## 四种进入模式

| 模式 | 投入 | 速度 | 风险 | 适用场景 |
|---|---|---|---|---|
| **自然延伸** | 低 | 慢 | 低 | 新市场与现有市场高度相似——现有产品只需微调 |
| **战略伙伴** | 中 | 中 | 中 | 新市场需要本地伙伴的渠道或知识——你不必从零开始 |
| **小团队孵化** | 中高 | 中 | 中高 | 新市场需要独立的探索团队——与核心团队物理分离 |
| **并购进入** | 高 | 快 | 高 | 新市场已有成熟玩家——买比建快 |

### YrY 场景匹配

| 新市场场景 | 建议模式 | 理由 |
|---|---|---|
| YiAi API 对外开放（面向国内开发者） | 自然延伸 | 无需改变产品——增加 API 文档和开发者工具 |
| YiPet 推向海外 Chrome 用户 | 小团队孵化 | 市场差异大——本地化、用户习惯不同 |
| YiKnowledge 扩展到金融行业 | 战略伙伴 | 需要行业数据+监管知识——找金融数据供应商合作 |
| 进入非 AI 开发者工具市场 | 不进入 | 与核心差异化无关——分散精力 |

## 进入策略画布

| 要素 | 内容 |
|---|---|
| **目标客户** | 在新市场中，我们最初 12 个月的目标客户是谁？不是"所有人" |
| **差异化杠杆** | 我们在新市场中的独特价值——什么能力是可以从现有业务中借用的？ |
| **最小可行进入** | 不做完整产品发布——最小可验证假设的进入方式是什么？ |
| **成功标志** | 12 个月后什么信号能证明我们应该继续投入？ |
| **止损条件** | 什么信号说明我们应该退出或收缩？ |
| **所需资源** | 人、钱、管理注意力——从哪来？ |

## 进入成功的"2/3 法则"

进入新市场的成功预测因子——在以下三项中，至少两项是确定的：

1. **产品-市场匹配已在类似市场验证**——不是"应该会匹配"，是"已经匹配了"
2. **团队中有人深度理解这个新市场**——不是"聪明人能学会"，是"已经在这个市场里工作过"
3. **进入的时机是"客户在找你"而非"你在找客户"**——有需求信号而非你在创造需求

如果三项中只有一项成立——进入的成功率极低。

## YrY 的潜在新市场评估

### 场景 A：YiAi API 对外开放

| 过滤器 | 评估 |
|---|---|
| 市场吸引力 | 高——AI API 市场快速增长 |
| 优势可移植性 | 高——RPC 协议是成熟的，只需增加认证和文档 |
| 机会成本 | 中——需要投入文档、SDK、技术支持 |

**建议**：最高优先级的新市场机会——在 Q4 或 Q1 启动自然延伸。

### 场景 B：YiPet 海外用户

| 过滤器 | 评估 |
|---|---|
| 市场吸引力 | 中——Chrome 扩展全球分发天然无边界 |
| 优势可移植性 | 中——产品核心可用，但本地化需求不同 |
| 机会成本 | 高——YiPet 还在验证国内 PMF，分散精力风险大 |

**建议**：先验证国内 PMF，再考虑海外。

### 场景 C：垂直行业深度（金融/医疗等）

| 过滤器 | 评估 |
|---|---|
| 市场吸引力 | 中高——合规要求高的行业对私有部署 AI 需求大 |
| 优势可移植性 | 中低——YiAi 自托管架构是优势，但行业 know-how 不足 |
| 机会成本 | 高——需要大量行业专家投入 |

**建议**：长期机会。当前用战略伙伴模式探索——找一个金融/医疗行业的数据伙伴做试点。

## 反模式

| 反模式 | 为何失败 | 正确做法 |
|---|---|---|
| "那边市场更大" | 市场规模 ≠ 你能获得的份额 | 诚实地评估优势可移植性 |
| 同时进入多个市场 | 资源和管理注意力分散 | 一次只进一个——前一个稳定后再启动下一个 |
| 只派新人开拓 | 不熟悉新市场的团队成员被派去开拓——没人带 | 至少有一个"在新市场中有经验"的人加入 |
| 低估本地化 | "我们的产品是世界级的"——但不符合新市场的使用习惯 | 在最小可行进入中包含本地化 |
| 没有止损条件 | 投入越来越多但没有成果——因为没有定义"什么时候退出" | 进入时设定 12 个月的评审和退出条件 |
