# 波特五力模型

> **作为**高管，**我想要**理解塑造我行业的结构性力量，**以便**能将公司定位于力量最弱、利润最高的位置。
>
> **核心洞见**：行业利润不由产品好坏决定，而由行业结构决定。你可以在一个"坏"的行业里拥有好的产品但仍然不赚钱——五力模型告诉你这个行业是否值得投入。

## 定义

波特五力模型是行业结构分析框架。它评估决定行业盈利能力的五种竞争力量：

```
                    新进入者威胁
                        │
                        ▼
    供应商 ──────► 现有竞争者 ────── 买方
    议价能力       之间的竞争      议价能力
                        │
                        ▼
                    替代品威胁
```

每种力量评级从**低**（有利）到**高**（不利）。整体行业吸引力是五种力量的净效果。

## 适用场景

- 进入新市场或行业细分
- 评估是否留在或退出衰退的细分市场
- 理解利润受压的原因
- 并购目标筛选：这是个有吸引力的行业吗？
- 年度战略刷新：行业结构变了吗？
- 竞争格局发生重大变化时快速重评

## 设计步骤

### 步骤 1：定义行业边界

要具体。"AI"太宽泛。"东南亚企业客服对话式 AI 平台"是可操作的。行业边界定义越清晰，五力分析的结论越有价值。

### 步骤 2：逐力评估（低 / 中 / 高）

#### 1. 新进入者威胁（越高对在位者越不利）

| 因子 | 低威胁的条件 | 高威胁的条件 |
|---|---|---|
| 规模经济 | 需要大规模才能竞争 | 小玩家也能盈利 |
| 资本需求 | 高前期投入 | 低启动成本 |
| 转换成本 | 客户被锁定 | 客户转换容易 |
| 分销渠道 | 渠道被在位者控制 | 开放平台、自服务 |
| 监管 | 许可证、专利、合规壁垒 | 监管宽松 |

#### 2. 供应商议价能力（越高对你越不利）

| 因子 | 低议价能力的条件 | 高议价能力的条件 |
|---|---|---|
| 供应商集中度 | 供应商众多、商品化 | 供应商少、差异化 |
| 转换成本 | 更换供应商容易 | 更换困难/昂贵 |
| 前向整合威胁 | 供应商做不了你的事 | 供应商可能变成竞品 |
| 你对供应商的重要性 | 你是大客户 | 你是小客户 |

#### 3. 买方议价能力（越高对你越不利）

| 因子 | 低议价能力的条件 | 高议价能力的条件 |
|---|---|---|
| 买方集中度 | 众多小客户 | 少数大客户 |
| 转换成本 | 客户离开成本高 | 客户可轻易转换 |
| 价格敏感度 | 你的产品是关键任务 | 你的产品是锦上添花 |
| 后向整合 | 买方自己造不出来 | 买方可能自研 |

#### 4. 替代品威胁（越高对你越不利）

替代品是满足同一需求的**不同产品**——不是直接竞品。例如，电子邮件是 Slack 的替代品，Teams 不是。

| 因子 | 低威胁的条件 | 高威胁的条件 |
|---|---|---|
| 性价比 | 你的解决方案明显物有所值 | 替代品提供更好价值 |
| 转换成本 | 切换到替代品的成本高 | 低或无 |
| 买方意愿 | 客户未在寻找替代方案 | 客户主动寻找替代方案 |

#### 5. 现有竞争者之间的竞争（越高对所有人越不利）

| 因子 | 低竞争的条件 | 高竞争的条件 |
|---|---|---|
| 竞争对手数量 | 少、稳定 | 众多，或有一个激进颠覆者 |
| 行业增长 | 快速增长 | 缓慢或衰退 |
| 退出壁垒 | 容易退出 | 高固定成本、专用资产 |
| 差异化 | 产品有差异 | 产品被商品化 |

### 步骤 3：综合

为每种力量评级低/中/高并总结：

```
力量                   评级     关键驱动因素
─────────────────────────────────────────────
新进入者威胁             低      高资本需求 + 监管壁垒
供应商议价能力           中      云服务商有一定杠杆
买方议价能力             高      前 3 客户 = 收入 60%
替代品威胁              低      无对问题的可行替代方案
竞争者竞争              中      增长市场，4 个主要玩家
─────────────────────────────────────────────
整体吸引力：            中      买方议价能力是首要关注点
```

### 步骤 4：定义战略应对

对每种评级为高或中高的力量，定义具体行动：

| 力量 | 行动 |
|---|---|
| 买方议价能力高 | 多样化客户群；通过集成增加转换成本 |
| 供应商议价能力高 | 多源采购；构建内部替代方案；后向整合 |
| 竞争激烈 | 在竞品难以复制的维度上差异化 |

## YrY 在 AI 开发工具领域的波特五力分析

| 力量 | 评级 | YrY 特定分析 |
|---|---|---|
| 新进入者威胁 | 高 | AI 编程工具的启动成本极低（开源模型 + API）；新进入者层出不穷 |
| 供应商议价能力 | 中 | Ollama/开源模型降低了 LLM 供应商的锁定；但云计算供应商仍有杠杆 |
| 买方议价能力 | 中 | 自用为主（当前阶段）；若外部化，开发者用户的转换成本低 |
| 替代品威胁 | 高 | Cursor、Copilot、Claude Code 均满足"AI 辅助编程"需求，虽然是不同品类 |
| 竞争者竞争 | 高 | AI 编程工具领域融资活跃，巨头（微软、Anthropic）和创业公司激战 |

**战略含义**：YrY 不应在"AI 辅助编程"的通用维度上与巨头竞争。差异化在于流水线的完整性（需求 → 决策 → 建设 → 运维）和知识库的 RAG 原生特性。

## 核心产出

- 逐力评估含证据和评级
- 整体行业吸引力评级
- 对 1–2 种最强力量的战略应对计划
- 可能变化力量的监控计划

## 反模式

| 反模式 | 为何失败 | 正确做法 |
|---|---|---|
| 行业定义过宽 | 各细分的力量差异极大 | 缩窄到你竞争的具体细分市场 |
| 静态快照 | 行业结构会变化 | 每年重评；监控触发事件 |
| 忽略互补品 | 平台和生态系统改变竞争动态 | 若相关，将互补品视为第六力量 |
| 评级无证据 | "中"是猜测，不是分析 | 每个评级需要具体事实或数据点 |
| 五力是唯一分析 | 行业结构不等于战略 | 组合 [VRIO](./12-战略-VRIO框架.md) 和[蓝海战略](./01-战略-蓝海战略.md) |
