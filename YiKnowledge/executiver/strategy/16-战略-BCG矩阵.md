# BCG 增长-份额矩阵

> **作为**高管，**我想要**在多条业务线之间做出清醒的资源分配决策，**以便**不因惯性或情感而继续喂养应该收割或剥离的业务。
>
> **核心洞见**：不是所有业务都该得到同等资源。BCG 矩阵帮你打破"旱涝保收"的资源分配惯性——明星业务该重仓、金牛业务该收割、问号业务该选择性押注、瘦狗业务该退出。

## 定义

BCG 矩阵用两个维度将业务分为四种类型：

```
        高市场增长率
            │
    ★ 明星  │  ? 问号
   (Stars)  │ (Question Marks)
   持有/投资│ 选择性押注
            │
────────────┼──────────── 相对市场份额
            │
    $ 金牛  │  ✗ 瘦狗
  (Cash Cows)│  (Dogs)
    收割    │  剥离/退出
            │
        低市场增长率
```

- **相对市场份额** = 你的份额 / 最大竞争对手的份额。> 1.0 = 你是市场领导者。
- **市场增长率**：通常以行业平均增长率为分界线。

## 适用场景

- 年度资源分配评审：各业务线该拿多少预算
- 并购决策：收购后这个业务在我们的组合中扮演什么角色
- 剥离决策：什么时候该退出一个业务
- 投资人沟通：解释为什么有些业务投资多、有些不投资
- 平衡创新组合：确保既有现金牛支撑运营，也有明星业务支撑未来

## 四种业务类型

### 明星 (Stars)：高增长 × 高份额

**特征**：市场领导者，所在市场快速增长。需要大量现金来维持增长，但随市场成熟会变成金牛。

| 策略 | 行动 |
|---|---|
| 持有/投资 | 优先分配资源，保持或扩大市场领导地位 |
| 防御 | 阻止竞品侵蚀份额；加大研发和营销投入 |
| 不要 | 过早收割——现在牺牲份额会损失未来的金牛 |

**判断信号**：相对份额 > 1.5，市场增长率 > 15%。

### 金牛 (Cash Cows)：低增长 × 高份额

**特征**：成熟市场的领导者。增长低，但产生大量现金。用于喂养明星和问号。

| 策略 | 行动 |
|---|---|
| 收割 | 最小化投入，最大化现金流 |
| 维持 | 保持市场份额但不再追求增长 |
| 不要 | 大举再投资——低增长市场的高投入回报率低 |

**判断信号**：相对份额 > 1.0，市场增长率 < 10%。

### 问号 (Question Marks)：高增长 × 低份额

**特征**：快速增长市场中的落后者。消耗大量现金但份额不高。最需要判断力的象限。

| 策略 | 行动 |
|---|---|
| 选择性押注 | 只投资有明确路径成为明星的业务（最多 1-2 个） |
| 严格止损 | 无法突破的问号果断放弃——它们是最烧钱的无底洞 |
| 不要 | 同时养 5 个问号——没有足够现金和管理注意力 |

**判断信号**：相对份额 < 0.5，市场增长率 > 15%。

### 瘦狗 (Dogs)：低增长 × 低份额

**特征**：低增长市场中的落后者。消耗管理注意力，不产生现金。通常是"情感业务"。

| 策略 | 行动 |
|---|---|
| 剥离/退出 | 卖掉、关停、或并入其他业务 |
| 收割 | 如果不能退，最小化投入直到自然消亡 |
| 不要 | 继续投资以"扭转局面"——成功率极低 |

**判断信号**：相对份额 < 0.5，市场增长率 < 10%。

## 业务组合的健康分布

理想分布（成熟公司）：

```
明星：30-40%
金牛：40-50%
问号：10-15%
瘦狗：5-10%（尽量为 0）
```

**危险信号**：
- 没有金牛 → 现金流依赖融资，抗风险弱
- 全是问号 → 分散且高风险，管理带宽不够
- 全是瘦狗 → 每条业务都是情感负担
- 没有问号 → 短期健康但缺乏未来增长来源

## 业务线的生命周期路径

```
问号 ──(成功押注)──→ 明星 ──(市场成熟)──→ 金牛 ──(份额下降)──→ 瘦狗
  │                    │                    │
  └──(失败)──→ 瘦狗    └──(份额丢失)──→ 瘦狗  └──(创新)──→ 明星
```

**战略含义**：
- 金牛产生的现金应流向问号（押注）和明星（防守）
- 成功的问号变成明星后，需要持续投入直到成为金牛
- 瘦狗退出的现金和人力可以重新投入问号和明星

## 核心产出

- 各业务线的 BCG 矩阵分布图
- 各象限的资源分配比例
- 问号业务的选择标准（哪些投，哪些停）
- 瘦狗业务的退出时间表
- 金牛→问号的现金流转计划

## 反模式

| 反模式 | 为何失败 | 正确做法 |
|---|---|---|
| 所有业务平均分配资源 | 明星得不到滋养，瘦狗继续浪费 | 按象限分配：明星和问号占 60-70% |
| 情感喂养瘦狗 | 因为"这是我们起家的业务"继续投入 | 用数据说话；设立退出标准并执行 |
| 过早收割明星 | 短期追求利润，失去未来市场 | 明星阶段追求份额而非利润 |
| 同时押注所有问号 | 资源和注意力分散到无法突破的程度 | 最多同时培养 2 个问号 |
| BCG 当静态快照 | 业务象限位置随时间变化 | 每季度更新；追踪业务在矩阵中的移动轨迹 |
