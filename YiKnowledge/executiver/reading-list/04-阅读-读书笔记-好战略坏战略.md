# 读书笔记 — 好战略坏战略 (Good Strategy Bad Strategy)

> **作者**：Richard Rumelt | **阅读日期**：2026-08 ~ 2026-09 | **维度**：战略
>
> **一句话核心观点**：好战略的核心不是愿景或目标，而是一个清晰的"诊断 → 指导方针 → 连贯行动"的因果逻辑链。坏战略的典型特征是：用空洞的愿景替代具体的行动、拒绝做选择、把目标当战略。

## 关键章节摘要

| 章节 | 核心内容 | 与 YrY 关联 |
|---|---|---|
| 第 1 章：好战略的解剖 | 好战略 = 诊断 + 指导方针 + 连贯行动。三者缺一不可 | YrY 的战略文档应包含这三要素，而非只是目标列表 |
| 第 5 章：坏战略的特征 | 坏战略的四个标志：空话、不敢选择、模板式战略、目标当战略 | 审视 YrY 当前规划：有无"既要...又要..."的不可能三角 |
| 第 9 章：聚焦与取舍 | 战略是选择不做什么。聚焦不是指只做一件事，而是各行动之间能相互强化 | YrY 三项目（YiVad/YiAi/YiPet）的优先级取舍 |
| 第 11 章：使用杠杆 | 战略杠杆来自：对关键点的预见、对关键点的聚焦、对关键点的集中投入 | YiKnowledge RAG 作为战略杠杆点 |
| 第 15 章：近似目标 | 不确定环境下的战略不是精准计划，而是"近似目标"——有方向但不僵化 | AI 行业高速变化，年度计划需要弹性机制 |

## 精华摘录

1. "好战略的核心不是设定目标，而是识别关键挑战并设计一套连贯的行动来应对它。"

2. "坏战略不是没有目标，而是用华丽的愿景和雄心勃勃的目标清单，掩盖了不做选择的逃避。"

3. "战略杠杆来自对关键点的预见。你不能在所有地方都强——你必须在一个决定性的点上集中力量。"

4. "在不确定的环境中，好的战略更像是一个'近似目标'——有方向但不僵化，有意图但随时准备根据新信息调整。"

5. "组织最大的战略失败不是选错了方向，而是拒绝做出选择——试图同时追求所有选项，最终一个都没实现。"

## 与 YrY 战略框架的整合

本书的核心框架与 YrY 战略工具有以下对应关系：

| Rumelt 框架 | YrY 对应工具 | 整合方式 |
|---|---|---|
| 诊断 | SWOT + 波特五力 + VRIO | 当前分析工具的产出就是"诊断" |
| 指导方针 | 蓝海战略 + 安索夫矩阵 | 选择"在哪里竞争"就是指导方针 |
| 连贯行动 | 平衡计分卡 + OKR + Now/Next/Later | 四维指标 + 季度目标 + 优先级排序 = 连贯行动 |

**关键差距**：YrY 当前战略流程的分析和合成环节较强，但"连贯行动"环节较弱——各框架产出是独立的，缺乏一个验证"行动是否相互强化"的检查步骤。**建议**：在 QBR 和年度规划中增加"连贯性检查"环节。
