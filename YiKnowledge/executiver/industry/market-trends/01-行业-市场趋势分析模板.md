# 市场趋势分析模板

> **使用时机**：每季度定期更新，或在重大技术/市场/政策变化时。趋势分析帮助你区分"噪音"和"信号"——不是每个新事物都值得关注，但错过一个真正的趋势代价巨大。

## 适用场景

- 季度市场趋势扫描
- 年度战略规划的环境分析输入
- 新兴技术可行性评估
- 判断何时进入新市场或启动第二曲线
- 董事会/投资人沟通：证明你对市场的前瞻判断

## 1. 趋势总览

### 趋势评估矩阵

将所有趋势按两个维度分类：**对我方的影响程度** 和 **趋势的确定性**。

```
高确定性  │  必须行动           │  战略押注
         │  (确定且影响大)     │  (确定且影响大)
         │  立即投入资源       │  制定长期计划
         ├─────────────────────┤
         │  监控               │  准备预案
         │  (确定但影响小)     │  (不确定但影响大)
         │  定期扫描即可       │  制定情景计划
低确定性  │  忽略               │  关注
         │  (不确定且影响小)   │  (不确定但影响小)
         │  不值得花时间       │  每季度扫描一次
         └─────────────────────┘
          低影响              高影响
```

## 实践建议

### 趋势扫描频率

| 活动 | 频率 | 产出 |
|---|---|---|
| 竞品和技术新闻扫描 | 每周 | 3 条关键情报 |
| 趋势信号汇总 | 每月 | 月度趋势简报（1 页） |
| 详细趋势分析 | 每季度 | 本模板完整填写 |
| 半年度复盘 | 每半年 | 复盘报告 + 修正判断 |
| 前瞻展望 | 年度 | 下年度趋势预判 |

### 信息源

- 技术趋势：arXiv、Hacker News、GitHub Trending、各公司技术博客
- 市场趋势：CB Insights、Statista、Crunchbase、行业报告
- 政策趋势：政府公报、行业协会通知、法律数据库

## 反模式

| 反模式 | 为何失败 | 正确做法 |
|---|---|---|
| 追逐每个新趋势 | 资源分散，无法在任何趋势上建立优势 | 用评估矩阵筛选：只对"确定性高 + 影响大"的投入 |
| Gartner/媒体说什么就信什么 | 分析师预测有偏，媒体的目标是眼球 | 交叉验证 3 个来源，区分事实和观点 |
| 趋势分析当一次性的 | 趋势在变，半年前的分析已过时 | 季度更新，半年度复盘 |
| 只看技术不看市场和政策 | 技术可行不等于商业可行/政策允许 | 三个维度必须都覆盖 |
| 过度外推 | 线性外推当前趋势到未来 | 考虑 S 曲线：每个趋势都会遇到天花板 |
