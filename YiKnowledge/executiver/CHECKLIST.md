# 高管实战检查清单

> **目的**：将本目录 45 个框架中最常用的流程提炼为场景驱动的检查清单。在时间紧迫时，对照清单快速检查，确保不遗漏关键步骤。

## 产品优先级排序

参考 [strategy/47-战略-产品优先级.md](../strategy/47-战略-产品优先级.md)：
- [ ] 每个候选项目的 Reach（覆盖用户数）、Impact（影响 0.25-3）、Confidence（20%-100%）、Effort（人月）都估了吗？
- [ ] RICE 得分计算了吗？（Reach × Impact × Confidence / Effort）
- [ ] "不做"清单列出来了吗？每个"不做"有明确的理由吗？
- [ ] P0 项目总容量 ≤ 60% 吗？
- [ ] 有没有"竞品有所以我们也该有"的项目混入 P0？——用竞品响应三层过滤器再过一遍

## 数据飞轮检查

参考 [strategy/46-战略-AI数据策略.md](../strategy/46-战略-AI数据策略.md)：
- [ ] 查询日志在收集吗？（脱敏——不存用户身份）
- [ ] 高频查询主题本月分析了吗？优先入库了吗？
- [ ] 数据飞轮的四个齿轮都有负责人吗？

## 产品发布 (GTM)

参考 [strategy/52-战略-GTM策略.md](../strategy/52-战略-GTM策略.md)：
- [ ] GTM 策略画布填了吗？（目标客户/核心信息/渠道/定价/成功指标）
- [ ] 预发布阶段至少积累 4 周了吗？（设计伙伴+等候名单+内容预热）
- [ ] 发布公告的第一段是"问题场景"而非"功能列表"？
- [ ] 发布后 30 天信号评估准备了吗？（激活率/留存/推荐率）

## 用户研究

参考 [strategy/49-战略-用户研究.md](../strategy/49-战略-用户研究.md)：
- [ ] 这周和至少 2 个用户对话了吗？
- [ ] 访谈记录在 1 小时内整理了吗？（关键引用+观察）
- [ ] 本周最重要的 3 个发现分享给团队了吗？
- [ ] 有没有一个用户反馈转化为了具体的产品行动？

## 季度战略评审

- [ ] 竞品动态扫描——本周最重要的 3 条竞品情报是什么？[industry/competitors/](../industry/competitors/)
- [ ] 行业趋势信号——有触发"趋势评估矩阵"中任何预警条件吗？[industry/market-trends/02](../industry/market-trends/02-行业-2026H1-AI市场趋势分析.md)
- [ ] OKR 进度——每个 KR 当前的评分（0.0-1.0）是多少？[okr/2026-Q3/](../okr/2026-Q3/)
- [ ] 上一次 QBR 的决策日志——上次定的事做了吗？[roadmap/04](../roadmap/04-路线图-季度业务回顾.md)
- [ ] 技术债登记表——P0 债务是否在还？有新的战略性债务吗？[strategy/40](../strategy/40-战略-技术债策略.md)
- [ ] 关键人风险评估——有人得分上升了吗？[strategy/38](../strategy/38-战略-继任规划.md)

## 重大决策

参考 [strategy/18-战略-高管决策框架.md](../strategy/18-战略-高管决策框架.md)：
- [ ] 这是 Type 几的决策？（1=不可逆 / 2=高成本可逆 / 3=低成本可逆 / 4=不该由我做的）
- [ ] RAPID 角色明确了吗？（谁 Recommend / Agree / Decide？）
- [ ] 至少 3 个选项都列出来了吗？包括"不做决定"？
- [ ] 每个选项的假设前提是什么？如果假设被证明不成立——还有哪个选项可行？
- [ ] 决策写进决策日志了吗？（决定了什么 + 为什么 + 翻转条件）

## 竞品出招时

参考 [strategy/37-战略-竞争响应策略.md](../strategy/37-战略-竞争响应策略.md)：
- [ ] 三层过滤器：改变格局了吗？影响核心用户了吗？不响应 6 个月后最坏会怎样？
- [ ] 响应策略：忽略 / 监控 / 吸收 / 反击？（不要在恐慌中选反击）
- [ ] 如果吸收：是用我们的方式解决同一个问题——不是在复制竞品的功能
- [ ] 响应时机：是立即改变这个季度的路线图，还是纳入下个 OKR 周期？

## 危机发生时

参考 [strategy/24-战略-危机沟通框架.md](../strategy/24-战略-危机沟通框架.md)：
- [ ] 危机等级判定——L1/L2/L3/L4？
- [ ] H+1 内首次对外沟通——速度 > 完美
- [ ] 沟通三要素：已知的 / 正在查的 / 已采取的行动
- [ ] 指定唯一发言人——其他人统一口径
- [ ] H+4 详细更新——影响范围、根因（已知或调查中）、用户该做什么
- [ ] 不说的五句话——"没有数据受影响"/"只是小问题"/"是别人的错"/"不会再有下次"/"无可奉告"

## 招聘关键岗位

参考 [strategy/27-战略-高管招聘框架.md](../strategy/27-战略-高管招聘框架.md)：
- [ ] 成功画像写了吗？（不是 JD——是使命 + 能力 + 适配 + 红线）
- [ ] 阶段匹配：我们要的人是 0→1 型 / 1→10 型 / 10→50 型？
- [ ] 面试结构：能力深潜（追问 3 层）+ 情景测试（真实问题）+ 文化适配（情景选择题）
- [ ] 每位面试官独立打分——面试完不讨论，先各自填评分卡
- [ ] 背景调查问了那个最关键的问题："你会再次和这个人一起工作吗？"

## 重要合作评估

参考 [strategy/44-战略-战略合作.md](../strategy/44-战略-战略合作.md)：
- [ ] 合作就绪度自检：产品稳定吗？有对接人吗？能一句话讲清对方为什么该合作吗？
- [ ] 合作方五维评估——战略匹配/互补性/投入意愿/文化/不对等
- [ ] 合作画布双方对齐了吗？（目标 + 成功样 + 投入 + 不可接受底线 + 退出条件）

## 董事会/投资人准备

参考 [strategy/22-战略-董事会汇报准备.md](../strategy/22-战略-董事会汇报准备.md)：
- [ ] 材料包 ≤ 12 页？（超过的话是在放运营细节）
- [ ] CEO 信写了：好消息 + 坏消息 + 最大偏差 + 需要帮助的 1-3 件事？
- [ ] 至少 2 个深度议题，各有明确的"需要董事会做什么"（讨论？批准？）
- [ ] 最难的问题提前准备——不要在董事会上第一次面对

## 每周节奏

- [ ] **周一上午**：本周最重要的 1 件事是什么？（深度工作时段）
- [ ] **每天上午**：重大决策在 10-12 点做——下午 3 点后不做 Type 1 决策
- [ ] **1:1**：每个人的节奏在保持吗？还是在被挤压？
- [ ] **周五下午**：本周有需要复盘的事吗？（不需要正式复盘——15 分钟快速复盘也是复盘）
- [ ] **周日晚上**：下周最重要的 3 件事是什么？写在日历的空白时段里
