### 功能概述

将 YiPet Chrome 扩展的技术栈从 React 15 + Bootstrap 升级至 React 18.3 + Ant Design 5.21，实现现代化前端架构，支持函数组件 + Hooks 开发模式。

### 技术实现

#### React 升级

- React 15 → React 18.3，启用 Concurrent Mode 特性
- Class Component → Function Component + Hooks 全面迁移
- 使用 `createRoot` 替代 `ReactDOM.render`
- 组件生命周期从 `componentDidMount` / `componentWillUnmount` 迁移至 `useEffect`

#### UI 框架替换

- Bootstrap CSS → Ant Design 5.21 组件库
- 替换范围：Popup 窗口、Chat 窗口、设置面板
- 组件替换映射：
  - Bootstrap Modal → Ant Design Modal
  - Bootstrap Button → Ant Design Button
  - Bootstrap Form → Ant Design Form
  - Bootstrap Dropdown → Ant Design Dropdown
  - 自定义 CSS 布局 → Ant Design Grid / Space / Flex

#### Rsbuild 构建适配

- Ant Design 5 支持 tree-shaking，按需加载组件
- CSS 方案：Ant Design 内置 CSS-in-JS（无需额外 Less 配置）
- 与现有 Rsbuild 多入口构建（popup / chat / CDN / bootstrap）兼容

#### 迁移策略

- 渐进式迁移：先 popup 窗口，再 chat 窗口，最后 content script 渲染
- 每个模块迁移后功能回归测试
- 保留旧代码分支作为回退方案

### 关联模块

- 构建配置：`rsbuild.config.ts`
- Popup 入口：`src/popup/`
- Chat 入口：`src/chat/`
- 类型声明：`src/typings.d.ts`

### 验收标准

1. React 18.3 + Ant Design 5 完整替换 React 15 + Bootstrap
2. 所有现有功能迁移后无回归
3. Popup / Chat / Content Script 三入口均正常渲染
4. `npm run typecheck && npm run build` 通过
5. 构建产物大小不显著增加
