### 功能概述

将聊天窗口移植至 YiPet 扩展，实现多角色对话、会话管理（导出/分支/摘要/自动标题）和知识库 RAG 检索能力。

### 技术实现

#### 多角色聊天

- 角色选择器：支持 8 种预设角色（engineer / aier / producter / srer / curator / analyst / designer / manager）
- 每个角色有独立的系统提示词和对话风格
- 角色切换后新消息使用新角色，历史消息保留原角色

#### 会话管理

- **会话导出**：将当前会话导出为 Markdown 文件下载
- **会话分支**：从任意消息节点创建分支，支持多分支并行对话
- **会话摘要**：调用 AI 自动生成会话摘要
- **自动标题**：根据首条消息自动生成会话标题

#### 知识库 RAG

- 通过 YiAi RAG API 进行知识检索
- 检索结果在聊天中以内联引用卡片形式展示
- 支持关键词检索和向量检索混合模式
- 检索范围：YiKnowledge 8 个角色目录

#### API 层

- 四层架构：`ApiClient` → `chatEndpoints` → `chatTypes` → `chatService`
- SSE 流式响应处理：`chatService.streamChat()` 返回 `AsyncIterable`
- 请求/响应经过 RPC envelope：`{module_name, method_name, parameters}`

#### Content Script 注入

- Chat 窗口作为独立 Rsbuild 入口构建
- 通过 CDN 注入机制动态加载到页面
- 窗口支持拖拽、缩放、最小化
- 与 Popup 共享 `chrome.storage` 会话状态

### 关联模块

- 后端 API：`services.ai.chat_service.chat`（SSE 流式）
- 前端 API 层：`src/api/services/chatService.ts`
- Chat 组件：`src/chat/ChatWindow/`
- 状态管理：`useChatStore`、`useSessionStore`

### 验收标准

1. 多角色聊天功能正常，角色切换即时生效
2. 会话导出、分支、摘要、自动标题功能正常
3. RAG 检索结果正确展示
4. Chat 窗口拖拽/缩放/最小化功能正常
5. Content Script 与 Popup 会话状态同步
