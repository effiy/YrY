# 一、业务概述

## 1.1 业务背景

YiPet 作为 Chrome MV3 浏览器扩展，需要在浏览器中注入交互式宠物陪伴体验。七月迭代为 YiPet 的首个开发周期，聚焦三个核心方向：技术栈现代化升级（React 15→18 + Bootstrap→Ant Design 5）、工具链优化（ESLint+Prettier→Biome）、以及 Chat 窗口功能移植。

## 1.2 业务目标

- 建立现代化的前端技术栈，为后续功能开发奠定基础
- 统一代码检查与格式化工具，提升开发效率
- 实现多角色 AI 聊天能力，支持会话管理和知识库检索

## 1.3 适用对象

- 浏览器用户（Chrome 扩展使用者）
- 开发团队成员

## 1.4 系统范围

- YiPet Chrome MV3 Extension（Popup / Chat / Content Script）
- YiAi 后端（Chat SSE、RAG API）

# 二、功能详情

## 2.1 技术栈升级 (需求 1)

React 15→18.3 + Bootstrap→Ant Design 5.21，Class Component → Function Component + Hooks 全面迁移，渐进式迁移策略：Popup → Chat → Content Script。

## 2.2 工具链优化 (需求 2)

ESLint + Prettier → Biome 2.5，lint 性能提升 94%，format 性能提升 97%，CI 集成 `biome ci`。

## 2.3 Chat 窗口移植 (需求 3)

8 种预设角色多角色聊天，会话管理（导出/分支/摘要/标题），RAG 混合检索，Content Script CDN 注入机制。
