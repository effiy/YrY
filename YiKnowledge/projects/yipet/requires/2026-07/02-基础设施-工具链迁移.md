# Biome Adoption — ESLint+Prettier→Biome

## 基本信息

| 字段 | 值 |
|------|-----|

| 优先级 | 中 |
| 人天 | 2.0d |

### 功能概述

将 YiPet 的代码检查与格式化工具从 ESLint + Prettier 整合为 Biome 2.5，统一工具链，提升 lint/format 执行速度。

### 技术实现

#### 工具替换

- ESLint → Biome lint：规则迁移，保留等价规则，废弃不再适用的规则
- Prettier → Biome format：格式化配置迁移，保持代码风格一致
- 移除 `eslint`、`prettier`、`eslint-plugin-react` 等依赖

#### Biome 配置

- 配置文件：`biome.json`
- 启用规则集：`recommended` + 自定义规则
- 格式化配置：缩进 2 空格、单引号、尾逗号、行宽 100
- 与 TypeScript 5.5 strict mode 兼容

#### 性能提升

| 指标 | ESLint+Prettier | Biome | 提升 |
|------|-----------------|-------|------|
| Lint | ~8s | ~0.5s | 94% |
| Format | ~3s | ~0.1s | 97% |
| CI 检查 | ~12s | ~0.8s | 93% |

#### CI 集成

- pre-commit hook：`biome check --staged`
- CI 流程：`biome ci`
- VSCode 集成：Biome 扩展替代 ESLint + Prettier 扩展

### 关联模块

- 配置文件：`biome.json`
- CI 配置：`.github/workflows/ci.yml`
- 编辑器配置：`.vscode/settings.json`

### 验收标准

1. Biome 替换 ESLint + Prettier，lint 和 format 均正常
2. 所有现有规则迁移或有意识地放弃
3. 代码风格与迁移前保持一致
4. `biome ci` 在 CI 中通过
5. `npm run lint` 和 `npm run format` 脚本更新
