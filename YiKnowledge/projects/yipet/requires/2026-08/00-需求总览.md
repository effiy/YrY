# 一、业务概述

## 1.1 业务背景

YiPet 在七月迭代完成技术栈升级和 Chat 窗口移植后，八月迭代聚焦于 AI 能力提升（Agent π Loop 移植）、用户体验优化（Pet 情感记忆持久化）和安全合规（CSP 加固 + Privacy Manifest），为 Chrome Web Store 上架做准备。

## 1.2 业务目标

- 将 YiVad 的 Agent 自主循环模式移植至扩展，提升 AI 对话能力
- 实现 Pet 情感状态跨会话持久化，增强陪伴连续性
- 完成安全合规配置，满足 Chrome Web Store 审核要求

## 1.3 适用对象

- 浏览器用户（Chrome 扩展使用者）
- Chrome Web Store 审核团队

## 1.4 系统范围

- YiPet Chrome MV3 Extension（Popup / Chat / Content Script / Service Worker）
- YiAi 后端（Agent 模式 Chat API）

# 二、功能详情

## 2.1 Agent Mode Port (需求 4)

将 YiVad 的 Agent π Loop 模式移植至 YiPet 扩展 Chat 窗口。包含工具确认 UI、工具生命周期管理、模型切换、轮次预算控制。

## 2.2 Pet Emotion Memory (需求 5)

Pet 情感状态跨会话持久化，三维度情感模型（好感度/熟悉度/活跃度 0-100），情感衰减 + 交互加成，`chrome.storage.local` 存储，情感表达式系统。

## 2.3 CSP + Data-Privacy Compliance (需求 7)

CSP 加固（script-src/object-src/connect-src/style-src），Privacy Manifest 数据收集声明，权限最小化，HTTPS 传输。

## 2.4 Native Messaging Host Bridge (需求 6) — 已取消

经评估，Content Script fetch 直连方案已足够，Native Messaging 增加了不成比例的复杂度。
