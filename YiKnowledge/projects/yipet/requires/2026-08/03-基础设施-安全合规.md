### 功能概述

完成 Content Security Policy 加固和隐私清单（Privacy Manifest）配置，满足 Chrome Web Store 审核要求，确保扩展合规上架。

### 技术实现

#### Content Security Policy 加固

- 在 `manifest.json` 中配置 `content_security_policy` 字段
- MV3 CSP 规则：
  - `script-src: 'self'` — 禁止内联脚本和外部脚本
  - `object-src: 'self'` — 禁止插件内容
  - `connect-src: 'self' http://localhost:10086` — 仅允许连接 YiAi 后端
  - `style-src: 'self' 'unsafe-inline'` — 允许内联样式（Ant Design CSS-in-JS 需要）
- CDN 资源加载：通过 `content_security_policy` 白名单管理

#### Privacy Manifest

- Chrome Web Store 要求扩展声明数据收集和使用情况
- 隐私清单字段：
  - 收集的数据类型：用户输入（聊天内容）、网络请求（API 调用）
  - 数据用途：功能实现（AI 对话）、个性化（情感状态）
  - 数据共享：不向第三方共享
  - 数据保留：聊天记录存储于 YiAi 后端，用户可删除
- 隐私政策页面：`https://yipet.app/privacy`

#### 权限最小化

- 审查当前 `manifest.json` 权限列表
- 移除不必要的权限（如 `tabs`、`cookies` 等若未使用则移除）
- 将 `host_permissions` 限制为最小必要范围
- 使用 `optional_permissions` 处理非核心权限

#### 数据安全

- 聊天内容传输使用 HTTPS（生产环境）
- `chrome.storage` 不存储敏感数据
- API Key / Token 通过 Service Worker 安全存储
- 敏感数据不在日志中输出

### 关联模块

- Manifest 配置：`public/manifest.json`
- 隐私政策：`public/privacy.html`
- 安全配置：`src/config/security.ts`

### 验收标准

1. CSP 配置符合 Chrome Web Store MV3 要求
2. Privacy Manifest 完整准确，通过审核
3. 权限列表最小化，无多余权限
4. 数据传输加密（HTTPS），敏感数据不泄露
5. 通过 Chrome Web Store 安全审查
