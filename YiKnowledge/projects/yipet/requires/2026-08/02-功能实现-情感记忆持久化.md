### 功能概述

实现 Pet 情感状态的跨会话持久化，让用户再次打开浏览器时恢复与 Pet 的情感关系，提升陪伴体验的连续性。

### 技术实现

#### 情感状态模型

- 情感维度：好感度（0-100）、熟悉度（0-100）、活跃度（0-100）
- 情感衰减：随时间自然衰减，长时间未交互则好感度缓慢下降
- 情感加成：交互行为触发情感值变化（聊天 +5、点击 +1、喂食 +10）

#### 存储方案

- 情感状态存储于 `chrome.storage.local`（MV3 推荐方案）
- 数据结构：
  ```typescript
  interface PetEmotion {
    affection: number;    // 好感度 0-100
    familiarity: number;  // 熟悉度 0-100
    activity: number;     // 活跃度 0-100
    lastInteraction: number; // 最后交互时间戳
    totalInteractions: number; // 总交互次数
  }
  ```
- 存储限制：`chrome.storage.local` 上限 10MB（情感数据 < 1KB，安全）

#### 情感表达式

- 根据情感值组合展示不同的 Pet 表情和动作
- 好感度 < 20：冷漠/疏离表情
- 好感度 20-60：正常/友好表情
- 好感度 > 60：开心/热情表情 + 特殊动作
- 长时间未交互（> 7 天）：展示思念/委屈表情

#### 多设备同步

- 通过 `chrome.storage.sync` 实现跨设备情感同步（可选）
- 同步上限 100KB，仅同步核心情感数据

### 关联模块

- 存储：`chrome.storage.local` / `chrome.storage.sync`
- Pet 渲染：`src/content/rendering/`
- 状态管理：`usePetStore`

### 验收标准

1. Pet 情感状态跨浏览器会话持久化
2. 再次打开浏览器时 Pet 展示上次离开时的情感状态
3. 情感值随时间自然衰减
4. 交互行为正确触发情感值变化
5. 不同情感值对应不同的 Pet 表情
