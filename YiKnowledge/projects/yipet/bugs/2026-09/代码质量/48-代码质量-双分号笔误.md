# bootstrap.ts 中双冒号分号语法错误

## 现象

`content/bootstrap.ts:101` 行尾有两个分号 `; ;`：

```typescript
createPetOverlay(...);;
```

## 涉及文件

- `src/content/bootstrap.ts:101`

## 修复方案

移除多余分号。


## 影响范围

**影响模块**：存在多余分号（`;;`）的代码行。
**影响用户**：TypeScript/JavaScript 引擎通常能容忍双分号（解析为空语句），但它是代码质量的信号——可能暗示了复制粘贴或匆忙编辑。
**影响范围**：代码质量和可读性。
## 预防措施

| 层面 | 措施 | 责任人 |
|------|------|--------|
| 工具 | Prettier/ESLint 格式化规则自动移除多余分号 | DevOps |
| 工具 | CI 中启用 Prettier 格式检查，格式问题导致构建失败 | DevOps |
| 流程 | 配置编辑器保存时自动格式化 | 开发者 |


## 经验教训

虽然双分号在 JavaScript 中是合法的（空语句），但它是"代码味道"的信号——通常来自不完整的编辑或复制粘贴。自动格式化工具（Prettier）可以彻底消除这类问题，不需要人工干预。
