# _persistSetting 与 _loadPersistedState 存储键名前缀不一致

## 现象

扩展重载或浏览器重启后，以下用户设置全部丢失：
- 侧边栏宽度（sidebarWidth）— 重置为默认 320px
- 侧边栏折叠状态（sidebarCollapsed）— 重置为展开
- 聊天窗口位置和大小（windowState）— 重置为默认位置
- 颜色主题（chatColorIndex、chatCustomColor）— 重置为默认色
- 提示词历史（promptHistory）— 重置为空

## 根因分析

`_persistSetting(key, value)` 统一为所有键添加 `yipet:` 前缀后写入 chrome.storage.local：

```typescript
chrome.storage.local.set({ [`yipet:${key}`]: value });
```

但 `_loadPersistedState()` 读取时没有前缀：

```typescript
// 修复前：读键无前缀
const result = await chrome.storage.local.get([
  'sidebarWidth', 'sidebarCollapsed',         // 实际存储键: yipet:sidebarWidth
  'windowState',                               // 实际存储键: yipet:chatWindowState (名称也不同!)
  'chatColorIndex', 'chatCustomColor',         // 实际存储键: yipet:chatColorIndex
  'promptHistory',                             // 实际存储键: yipet:promptHistory
  ...
]);
```

### 受影响键完整清单

| 设置 | 写入键名 | 读取键名（修复前） | 影响 |
|------|----------|-------------------|------|
| `sidebarWidth` | `yipet:sidebarWidth` | `sidebarWidth` | 侧边栏宽度丢失 |
| `sidebarCollapsed` | `yipet:sidebarCollapsed` | `sidebarCollapsed` | 侧边栏折叠状态丢失 |
| `chatWindowState` | `yipet:chatWindowState` | `windowState` | 窗口位置+大小丢失（键名也不同） |
| `chatColorIndex` | `yipet:chatColorIndex` | `chatColorIndex` | 颜色主题丢失 |
| `chatCustomColor` | `yipet:chatCustomColor` | `chatCustomColor` | 自定义颜色丢失 |
| `promptHistory` | `yipet:promptHistory` | `promptHistory` | 提示词历史丢失 |

RAG 设置（`ragEnabled`、`ragScope` 等）不受影响 — 它们始终使用 `yipet:` 前缀直接调用 `chrome.storage.local.set`。

### 附加问题：windowState 键名不一致

`_persistSetting('chatWindowState', ...)` 写入的键名是 `yipet:chatWindowState`，但 `_loadPersistedState` 读取的是 `windowState`。即使修复了前缀，键名也不同。需要统一为 `chatWindowState`。

## 涉及文件

- `YiPet/src/chat/stores/chat.ts`
  - `_persistSetting()` — 第 354-366 行：添加 `yipet:` 前缀
  - `_loadPersistedState()` — 第 372-413 行：读取无前缀
  - `_persistWindowState()` — 第 368-370 行：使用 `chatWindowState`
  - `endSidebarResize()` — 通过 `useChatWindow.ts:114` 调用 `persistSetting('sidebarWidth', ...)`
  - `toggleSidebar()` — 第 1437 行：`_persistSetting('sidebarCollapsed', ...)`
  - `setColorIndex()` — 第 1213-1214 行：`_persistSetting('chatColorIndex'/'chatCustomColor', ...)`

## 修复方案

统一 `_loadPersistedState` 中的读键名，与 `_persistSetting` 写入的键名一致：

```diff
- 'sidebarWidth', 'sidebarCollapsed', 'weChatRobots', 'yipet:promptHistory',
- 'windowState', 'chatColorIndex', 'chatCustomColor',
+ 'yipet:sidebarWidth', 'yipet:sidebarCollapsed', 'weChatRobots', 'yipet:promptHistory',
+ 'yipet:chatWindowState', 'yipet:chatColorIndex', 'yipet:chatCustomColor',
```

同时修改访问器从 `result.sidebarWidth` 为 `result['yipet:sidebarWidth']` 等。
