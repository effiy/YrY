# Spec: Chat Controller Pattern

## Overview

本规范定义了 YiPet Chat 窗口的核心控制器模式，包括基于 `useSyncExternalStore` 的状态管理、`ChatState` 类型定义、actions 模式、SSE 流式对话处理、知识库接地等约定。

## 状态管理

### useSyncExternalStore 模式

```typescript
// src/chat/controller.ts
export class ChatController {
  private state: ChatState
  private listeners = new Set<() => void>()

  constructor(api: ApiServices) {
    this.state = createInitialState()
    this._api = api
    // 绑定方法
    this.getState = this.getState.bind(this)
    this.subscribe = this.subscribe.bind(this)
  }

  // 获取当前状态快照
  getState(): ChatState {
    return this.state
  }

  // 订阅状态变化
  subscribe(listener: () => void): () => void {
    this.listeners.add(listener)
    return () => this.listeners.delete(listener)
  }

  // 通知所有订阅者
  private _emit(): void {
    this.listeners.forEach((fn) => fn())
  }

  // 更新状态
  private _setState(patch: Partial<ChatState>): void {
    Object.assign(this.state, patch)
    this._emit()
  }
}
```


### Action 实现模式

```typescript
// 简单 action：直接修改状态
public setSidebarView(view: ChatState['sidebarView']): void {
  this._setState({ sidebarView: view })
  if (view === 'knowledge' && !this.state.knowledgeTree.length) {
    this.loadKnowledgeTree()
  }
  if (view === 'stories' && !this.state.knowledgeStories.length) {
    this.loadKnowledgeStories()
  }
  if (view === 'bugs' && !this.state.recentBugs.length) {
    this.loadRecentBugs()
  }
}

// 异步 action：加载数据 + 状态更新
public async loadKnowledgeTree(category?: string): Promise<void> {
  this._setState({ knowledgeLoading: true, knowledgeError: '' })
  try {
    const tree = await this._api.knowledge.scan(category)
    this._setState({ knowledgeTree: tree, knowledgeLoading: false })
  } catch (err) {
    this._setState({
      knowledgeLoading: false,
      knowledgeError: err instanceof Error ? err.message : 'Unknown error',
    })
  }
}

// 流式 action：分步状态更新
public async sendMessage(text: string): Promise<void> {
  if (this.state.isProcessing) return

  const userMessage = this._createMessage('user', text)
  const assistantMessage = this._createMessage('assistant', '', true)

  this._setState({
    messages: [...this.state.messages, userMessage, assistantMessage],
    isProcessing: true,
    streamingType: 'send',
    streamingPhase: this.state.knowledgeGrounded ? 'retrieving' : 'thinking',
    inputValue: '',
    inputTemplate: null,
  })

  try {
    const messages = this._buildMessagesForStream()
    await this._runStream(messages)
  } finally {
    this._setState({
      isProcessing: false,
      streamingType: null,
      streamingPhase: '',
    })
  }
}
```

## SSE 流式处理

### 流式调用流程

```typescript
// src/chat/controller.ts
private async _runStream(messages: ChatMessage[]): Promise<void> {
  let phaseFlipped = false
  const currentIndex = this.state.messages.length - 1

  const onToken = (text: string) => {
    if (!phaseFlipped) {
      this._setState({ streamingPhase: 'streaming' })
      phaseFlipped = true
    }
    const msgs = [...this.state.messages]
    msgs[currentIndex] = {
      ...msgs[currentIndex],
      content: msgs[currentIndex].content + text,
    }
    this.state.messages = msgs
    this._emit()
  }

  const onDone = async () => {
    const msgs = [...this.state.messages]
    msgs[currentIndex] = { ...msgs[currentIndex], streaming: false }
    this.state.messages = msgs
    this._persistSession()
    this._emit()
  }

  const onError = (err: Error) => {
    const msgs = [...this.state.messages]
    msgs[currentIndex] = {
      ...msgs[currentIndex],
      streaming: false,
      error: err.message,
    }
    this.state.messages = msgs
    this._emit()
  }

  const onSources = (sources: RagSource[]) => {
    this._setState({ ragSources: sources })
  }

  // 根据知识库接地状态选择调用方式
  if (this.state.knowledgeGrounded) {
    if (this.state.ragScopeIsFile) {
      await this._api.rag.streamFileChat({
        target_file: this.state.ragScope,
        question: messages[messages.length - 1].content,
        onToken,
        onDone,
        onError,
        onSources,
        signal: this._abortController.signal,
      })
    } else {
      await this._api.rag.streamChat({
        messages,
        scope: this.state.ragScope,
        category: this.state.knowledgeCategoryFilter,
        onToken,
        onDone,
        onError,
        onSources,
        signal: this._abortController.signal,
      })
    }
  } else {
    await this._api.chat.streamWithCallback({
      messages,
      model: this.state.model,
      system: this._getSystemPrompt(),
      onToken,
      onDone,
      onError,
      signal: this._abortController.signal,
    })
  }
}
```

### 中断处理

```typescript
private _abortController: AbortController | null = null

public stopSending(): void {
  if (this._abortController) {
    this._abortController.abort()
    this._abortController = null
  }
  // 标记当前消息为已中断
  const msgs = [...this.state.messages]
  const lastIdx = msgs.length - 1
  if (lastIdx >= 0 && msgs[lastIdx].streaming) {
    msgs[lastIdx] = { ...msgs[lastIdx], streaming: false, aborted: true }
  }
  this._setState({
    messages: msgs,
    isProcessing: false,
    streamingType: null,
    streamingPhase: '',
  })
}
```

```typescript
private async _persistSession(): Promise<void> {
  const session = this._getCurrentSession()
  if (!session) return

  const records = this.state.messages
    .filter((m) => !m.streaming)
    .map((m) => ({
      role: m.role,
      content: m.content,
      timestamp: m.timestamp,

  await this._api.sessions.upsert({

    title: this.state.title,
```

## Best Practices

### 正确示例

```typescript
// ✅ 状态更新后调用 _emit()
this._setState({ isProcessing: true })

// ✅ 异步操作使用 try/catch
try {
  const result = await this._api.knowledge.scan()
  this._setState({ knowledgeTree: result })
} catch (err) {
  this._setState({ knowledgeError: err.message })

// ✅ 乐观更新 + 持久化
this._setState({ messages: [...this.state.messages, newMsg] })

// ✅ 使用 useSyncExternalStore 订阅
const state = useSyncExternalStore(ctrl.subscribe, ctrl.getState)
```

### 错误示例

```typescript
// ❌ 直接修改 state 不调用 _emit()

// ❌ 不处理异步错误

// ❌ 在 action 中直接操作 DOM

// ❌ 使用 useState 管理全局状态
```

## Constraints

### MUST

- 使用 `ChatController` 单例管理所有 Chat 状态
- 组件通过 `useSyncExternalStore` 订阅状态
- 状态修改必须通过 `_setState()` + `_emit()` 通知订阅者
- SSE 流式调用的 `onToken` 回调中通过 `_emit()` 实时更新 UI
- 所有异步操作必须处理错误状态
- 会话变更后必须持久化到 `chrome.storage.local`
- 支持 `AbortController` 中断流式请求

### MUST NOT

- 不要在组件中使用 `useState` 管理应在 ChatController 中的状态
- 不要直接修改 `this.state`（必须通过 `_setState`）
- 不要在 action 中直接操作 DOM
- 不要在 `onToken` 回调中做昂贵的计算
- 不要忘记在 `finally` 中清除 `isProcessing` 和 `streamingPhase`

## 消息流式边角情况

### 网络中断处理

```typescript
// 处理 SSE 流式中断的所有边角情况
private async _runStream(messages: ChatMessage[]): Promise<void> {
  let phaseFlipped = false
  let chunkCount = 0
  const currentIndex = this.state.messages.length - 1

  const onToken = (text: string) => {
    if (!phaseFlipped) {
      this._setState({ streamingPhase: 'streaming' })
      phaseFlipped = true
    }
    chunkCount++
    const msgs = [...this.state.messages]

    // 边角情况 1：消息索引可能因并发操作而偏移
    if (currentIndex >= msgs.length) {
      console.warn('[Stream] 消息索引偏移，跳过 token')
      return
    }

    msgs[currentIndex] = {
      ...msgs[currentIndex],
      content: msgs[currentIndex].content + text,
    }
    this.state.messages = msgs
    this._emit()
  }

  const onDone = async () => {
    const msgs = [...this.state.messages]

    // 边角情况 2：流式完成但消息内容为空
    if (currentIndex < msgs.length) {
      if (!msgs[currentIndex].content.trim()) {
        msgs[currentIndex] = {
          ...msgs[currentIndex],
          content: t('errorEmptyResponse'),  // 空响应提示
          streaming: false,
          error: t('errorEmptyResponse'),
        }
      } else {
        msgs[currentIndex] = { ...msgs[currentIndex], streaming: false }
      }
      this.state.messages = msgs
    }

    // 边角情况 3：完成时已收到 0 个 chunk（后端立即返回了 done）
    if (chunkCount === 0) {
      console.warn('[Stream] 收到 0 个 chunk 就完成了，可能后端异常')
    }

    await this._persistSession()
    this._emit()
  }

  const onError = (err: Error) => {
    const msgs = [...this.state.messages]

    // 边角情况 4：区分不同错误类型
    if (err.name === 'AbortError') {
      // 用户主动取消，当前消息保留已收到的内容
      if (currentIndex < msgs.length) {
        msgs[currentIndex] = {
          ...msgs[currentIndex],
          streaming: false,
          aborted: true,
        }
      }
    } else if (err.message.includes('NetworkError') || err.message.includes('Failed to fetch')) {
      // 网络错误：保留已收到内容，追加错误提示
      if (currentIndex < msgs.length) {
        const existingContent = msgs[currentIndex].content
        msgs[currentIndex] = {
          ...msgs[currentIndex],
          content: existingContent + (existingContent ? '\n\n' : '') + `[${t('errorNetworkInterrupted')}]`,
          streaming: false,
          error: t('errorNetworkInterrupted'),
        }
      }
    } else {
      // 其他错误
      if (currentIndex < msgs.length) {
        msgs[currentIndex] = {
          ...msgs[currentIndex],
          streaming: false,
          error: err.message,
        }
      }
    }

    this.state.messages = msgs

    // 边角情况 5：错误时仍然持久化已收到的消息
    this._persistSession().catch(() => {
      // 持久化失败也不影响用户
    })

    this._emit()
  }

  // ... 发起 SSE 请求
}
```

### 边角情况清单

| 边角情况 | 触发条件 | 处理策略 |
|---------|---------|---------|
| 空响应 | 后端返回 `done` 但无内容 | 显示空响应提示 |
| 0 chunk 完成 | 流立即结束 | 记录警告，展示空消息 |
| 流式消息索引偏移 | 并发操作修改消息列表 | 校验索引，跳过无效 token |
| 网络中断 | `TypeError: Failed to fetch` | 保留已收内容，追加错误提示 |
| 用户主动取消 | `AbortError` | 保留已收内容，标记 aborted |
| 部分 chunk 丢失 | SSE 格式不完整 | 丢弃不完整行，继续处理 |
| 超时 | 指定时间内无新 chunk | 终止连接，展示超时提示 |

```typescript
class SSEParser {
  private buffer = ''

  parse(chunk: string): ParsedEvent[] {
    this.buffer += chunk
    const events: ParsedEvent[] = []
    const lines = this.buffer.split('\n')

    // 最后一行可能不完整，保留在 buffer 中
    this.buffer = lines.pop() || ''

    let currentEvent: ParsedEvent = { data: '' }

    for (const line of lines) {
      if (line === '') {
        // 空行表示事件结束
        if (currentEvent.data) {
          events.push(currentEvent)
          currentEvent = { data: '' }
        }
      } else if (line.startsWith('data: ')) {
        currentEvent.data += line.slice(6)
      } else if (line.startsWith('event: ')) {
        currentEvent.event = line.slice(7)
      } else if (line.startsWith('id: ')) {
        currentEvent.id = line.slice(4)
      }
      // 忽略注释行（以 : 开头）和其他未知字段
    }

    return events
  }
}
```

```typescript
  // ... 现有字段

  showBranchGraph: boolean     // 是否显示分支图

  /**
   * 从指定消息创建分支
   * 参数 timestamp 是分支点之前的最后一条消息的时间戳
   */
  branchFromMessage(timestamp: string): void {
    const forkIndex = this.state.messages.findIndex(m => m.timestamp === timestamp)
    if (forkIndex === -1) return

    // 1. 保存当前分支
    const currentBranch: ConversationBranch = {
      branchId: this.state.currentBranchId,
      parentBranchId: this._findParentBranchId(forkIndex),
      forkPoint: forkIndex,
      messages: [...this.state.messages],
      createdAt: new Date().toISOString(),
    }

    // 2. 创建新分支（不可变操作）
    const newBranchId = crypto.randomUUID()
    const forkedMessages = this.state.messages.slice(0, forkIndex + 1)

    const newBranch: ConversationBranch = {
      branchId: newBranchId,
      parentBranchId: currentBranch.branchId,
      forkPoint: forkIndex,
      messages: forkedMessages,
      createdAt: new Date().toISOString(),
    }

    // 3. 更新状态
    this._setState({
      branches: [...this.state.branches, currentBranch, newBranch],
      messages: forkedMessages,
      currentBranchId: newBranchId,
    })

    this._persistState()
  }

  /**
   * 切换到指定分支
   */
  switchToBranch(branchId: string): void {
    const branch = this.state.branches.find(b => b.branchId === branchId)
    if (!branch) return

    this._setState({
      messages: [...branch.messages],  // 不可变拷贝
      currentBranchId: branchId,
    })
  }

  // 查找父分支 ID
  private _findParentBranchId(forkIndex: number): string | null {
    // 查找包含此 forkIndex 的分支
    const parentBranch = this.state.branches.find(
      b => b.forkPoint <= forkIndex
        && b.messages.length > forkIndex
        && b.messages[forkIndex].timestamp === this.state.messages[forkIndex].timestamp
    )
    return parentBranch?.branchId || null
  }
```

```typescript
// 简单的 Token 估算（基于字符数，精确计数需要 tiktoken）
export function estimateTokens(text: string): number {
  // 中文字符：约 1 token/字符
  // 英文单词：约 1.3 token/单词
  // 代码：约 0.5 token/字符
  const chineseChars = (text.match(/[\u4e00-\u9fff]/g) || []).length
  const englishWords = (text.match(/[a-zA-Z]+/g) || []).length
  const otherChars = text.length - chineseChars - englishWords

  return Math.ceil(chineseChars * 1.0 + englishWords * 1.3 + otherChars * 0.5)
}

// 在消息中记录 Token 用量
export interface ChatMessage {
  role: 'user' | 'assistant' | 'system'
  content: string
  timestamp: string
  streaming?: boolean
  aborted?: boolean
  error?: string
  tokenCount?: number       // 本条消息的 token 数
  cumulativeTokens?: number // 累计 token 数
}

// 在 ChatController 中集成 Token 计数
export class ChatController {
  private _estimateTokens(): number {
    return this.state.messages.reduce(
      (sum, msg) => sum + estimateTokens(msg.content),
      0
    )
  }

  // 在每个 action 后更新 token 计数
  private _updateTokenCounts(): void {
    let cumulative = 0
    this.state.messages = this.state.messages.map(msg => {
      const tokens = estimateTokens(msg.content)
      cumulative += tokens
      return { ...msg, tokenCount: tokens, cumulativeTokens: cumulative }
    })
  }
}
```

```typescript
interface TokenBudgetConfig {
  warningThreshold: number    // 告警阈值（token 数），默认 6000
  criticalThreshold: number   // 严重告警阈值，默认 8000
  maxContextTokens: number    // 模型最大上下文，默认 8192（llama3）

export class ChatController {
  private tokenBudget: TokenBudgetConfig = {
    warningThreshold: 6000,
    criticalThreshold: 8000,
    maxContextTokens: 8192,
  }

  // 检查 Token 预算
  private _checkTokenBudget(): TokenBudgetStatus {
    const currentTokens = this._estimateTokens()
    const remaining = this.tokenBudget.maxContextTokens - currentTokens
    const usagePercent = (currentTokens / this.tokenBudget.maxContextTokens) * 100

    if (currentTokens >= this.tokenBudget.criticalThreshold) {
      return {
        level: 'critical',
        currentTokens,
        remaining,
        usagePercent,
        message: t('tokenBudgetCritical', [String(currentTokens)]),
      }
    }

    if (currentTokens >= this.tokenBudget.warningThreshold) {
      return {
        level: 'warning',
        currentTokens,
        remaining,
        usagePercent,
        message: t('tokenBudgetWarning', [String(currentTokens), String(remaining)]),
      }
    }

    return {
      level: 'normal',
      currentTokens,
      remaining,
      usagePercent,
      message: '',
    }
  }

  // 发送消息前检查预算
  async sendMessage(text: string): Promise<void> {
    if (this.state.isProcessing) return

    const budget = this._checkTokenBudget()

    if (budget.level === 'critical') {
      // 严重告警：自动压缩上下文
      await this._autoCompressContext()
    } else if (budget.level === 'warning') {
      // 告警：通知用户但继续
      this._setState({
        tokenBudgetStatus: budget,
      })
    }

    // ... 继续发送
  }
}
```

### 自动压缩策略

```typescript
// 上下文窗口管理
export class ChatController {
  /**
   * 上下文压缩策略：
   * 1. 保留最近的 N 条消息
   * 2. 对早期消息生成摘要
   * 3. 将摘要作为系统消息注入
   */
  private async _autoCompressContext(): Promise<void> {
    const KEEP_RECENT = 6  // 保留最近 6 条消息

    if (this.state.messages.length <= KEEP_RECENT) return

    const recentMessages = this.state.messages.slice(-KEEP_RECENT)
    const oldMessages = this.state.messages.slice(0, -KEEP_RECENT)

    // 生成早期对话摘要
    this._setState({ streamingPhase: 'compressing' })

    try {
      const summary = await this._api.chat.compress({
        messages: oldMessages,
        signal: this._abortController?.signal,
      })

      // 将摘要作为系统消息插入
      const summaryMessage: ChatMessage = {
        role: 'system',
        content: `[${t('contextSummary')}]\n${summary}`,
        timestamp: new Date().toISOString(),
      }

      this._setState({
        messages: [summaryMessage, ...recentMessages],
        streamingPhase: '',
      })

      console.log(`[Context] 压缩完成：${oldMessages.length} 条消息 -> 摘要`)
    } catch (err) {
      // 压缩失败：保留最近消息，丢弃旧消息
      this._setState({
        messages: recentMessages,
        streamingPhase: '',
      })
      console.warn('[Context] 压缩失败，已丢弃旧消息')
    }
  }

  /**
   * 智能截断：基于消息重要性评分
   */
  private _smartTruncate(maxTokens: number): ChatMessage[] {
    // 每条消息的重要性评分
    const scored = this.state.messages.map((msg, idx) => ({
      msg,
      idx,
      score: this._scoreMessage(msg, idx),
    }))

    // 按分数排序，保留高分消息
    scored.sort((a, b) => b.score - a.score)

    let tokenCount = 0
    const kept = new Set<number>()

    for (const { msg, idx } of scored) {
      const tokens = estimateTokens(msg.content)
      if (tokenCount + tokens <= maxTokens) {
        tokenCount += tokens
        kept.add(idx)
      }
    }

    // 按原始顺序返回保留的消息
    return this.state.messages.filter((_, idx) => kept.has(idx))
  }

  // 消息重要性评分
  private _scoreMessage(msg: ChatMessage, idx: number): number {
    let score = 0
    // 最近的消息更重要
    score += (idx / this.state.messages.length) * 10
    // 用户消息比 assistant 消息更重要
    score += msg.role === 'user' ? 5 : 0
    // 系统消息最重要
    score += msg.role === 'system' ? 10 : 0
    // 长消息可能包含更多信息
    score += Math.min(msg.content.length / 100, 5)
    return score
  }
}
```

```typescript
// 消息去重：防止同一消息被重复发送或显示
export class ChatController {
  // 使用消息内容哈希作为去重 key
  private _messageHashCache = new Set<string>()

  /**
   * 生成消息哈希
   */
  private _hashMessage(msg: Pick<ChatMessage, 'role' | 'content'>): string {
    const normalized = `${msg.role}:${msg.content.trim()}`
    // 简单哈希（生产环境可用 crypto.subtle.digest）
    let hash = 0
    for (let i = 0; i < normalized.length; i++) {
      const char = normalized.charCodeAt(i)
      hash = ((hash << 5) - hash) + char
      hash = hash & hash  // 转为 32 位整数
    }
    return hash.toString(36)
  }

  /**
   * 发送消息前检查是否重复
   */
  async sendMessage(text: string): Promise<void> {
    if (this.state.isProcessing) return

    const trimmed = text.trim()
    if (!trimmed) return

    const hash = this._hashMessage({ role: 'user', content: trimmed })

    // 检查是否与最后一条用户消息相同
    const lastUserMsg = [...this.state.messages]
      .reverse()
      .find(m => m.role === 'user')

    if (lastUserMsg) {
      const lastHash = this._hashMessage({ role: 'user', content: lastUserMsg.content })
      if (hash === lastHash) {
        console.warn('[Chat] 检测到重复消息，已忽略')
        return
      }
    }

    // 检查是否在最近 5 条消息中重复
    const recentHashes = this.state.messages
      .filter(m => m.role === 'user')
      .slice(-5)
      .map(m => this._hashMessage({ role: 'user', content: m.content }))

    if (recentHashes.includes(hash)) {
      console.warn('[Chat] 检测到近期重复消息，已忽略')
      return
    }

    // 缓存哈希（限制大小）
    this._messageHashCache.add(hash)
    if (this._messageHashCache.size > 100) {
      // 删除最旧的条目（Set 迭代顺序是插入顺序）
      const first = this._messageHashCache.values().next().value
      if (first !== undefined) {
        this._messageHashCache.delete(first)
      }
    }

    // ... 继续发送
  }
}
```

| 近期重复 | 最近 5 条用户消息 | 静默忽略 |

```typescript
      const msgs = [...this.state.messages]

      // 6. 失败：回滚乐观更新
      this._rollbackOptimisticMessages()
    } finally {
      this._setState({
        isProcessing: false,
        streamingType: null,
        streamingPhase: '',
      })
    }
  }

  /**
   * 回滚乐观消息
   */
  private _rollbackOptimisticMessages(): void {
    // 移除带 optimistic 标记的消息
    const rolledBack = this.state.messages.filter(m => !m.optimistic)

    // 如果回滚后没有消息丢失（即没有乐观消息），直接返回
    if (rolledBack.length === this.state.messages.length) return

    this._setState({
      messages: rolledBack,
      // 恢复输入框内容
      inputValue: this.state.messages.find(m => m.optimistic && m.role === 'user')?.content || '',
    })

    console.warn('[Chat] 乐观更新已回滚')
  }
```

```typescript
// 乐观发送失败后的自动重试
export class ChatController {
  private _maxRetryCount = 3

  async sendMessage(text: string): Promise<void> {
    // ... 乐观创建消息

    let retryCount = 0
    let lastError: Error | null = null

    while (retryCount <= this._maxRetryCount) {
      try {
        const messages = this._buildMessagesForStream()
        await this._runStream(messages)
        return  // 成功

        lastError = err as Error
        retryCount++

          msgs[assistantIdx] = {

          // 指数退避等待
          await new Promise(resolve =>
            setTimeout(resolve, 1000 * Math.pow(2, retryCount - 1))
          )
        }
      }
    }

    // 所有重试失败
    this._rollbackOptimisticMessages()
    this._setState({
      lastError: lastError?.message || t('errorSendFailed'),
    })
  }
}
```

```typescript
        recoverable: true,
        recovery: async () => {
          // 等待网络恢复后重试
          await this._waitForNetwork()
          await this._retryLastAction()
        },
      },
      TimeoutError: {
        severity: 'recoverable',
        code: 'TIMEOUT',
        message: t('errorTimeout'),
        recoverable: true,
        recovery: async () => {
          await this._retryLastAction()
        },
      },
      RateLimitError: {
        severity: 'recoverable',
        code: 'RATE_LIMIT',
        message: t('errorRateLimit'),
        recoverable: true,
        recovery: async () => {
          await new Promise(resolve => setTimeout(resolve, 30000))
        },
      },
      AuthError: {
        severity: 'degraded',
        code: 'AUTH_ERROR',
        message: t('errorAuthExpired'),
        recoverable: true,
        recovery: async () => {
          await this._refreshAuth()
        },
      },
      ServerError: {
        severity: 'degraded',
        code: 'SERVER_ERROR',
        message: t('errorServerError'),
        recoverable: false,
      },
      UnknownError: {
        severity: 'fatal',
        code: 'UNKNOWN',
        message: t('errorUnknown'),
        recoverable: false,
      },
    }

    // 匹配错误类型
    for (const [key, chatError] of Object.entries(errorMap)) {
      if (err.message.includes(key) || err.name === key) {
        return chatError
      }
    }

    return errorMap.UnknownError
  }

  /**
   * 自动恢复
   */
  private async _attemptRecovery(error: ChatError): Promise<boolean> {
    if (!error.recoverable || !error.recovery) return false

    try {
      console.log(`[Recovery] 尝试恢复: ${error.code}`)
      await error.recovery()
      console.log(`[Recovery] 恢复成功: ${error.code}`)
      return true
    } catch (err) {
      console.error(`[Recovery] 恢复失败: ${error.code}`, err)
      return false
    }
  }

  /**
   * 等待网络恢复
   */
  private async _waitForNetwork(timeout = 30000): Promise<void> {
    if (navigator.onLine) return

    const start = Date.now()
    return new Promise((resolve, reject) => {
      const check = () => {
        if (navigator.onLine) {
          resolve()
        } else if (Date.now() - start > timeout) {
          reject(new Error('Network recovery timeout'))
        } else {
          setTimeout(check, 1000)
        }
      }
      check()
    })
  }

  /**
   * 重试上次操作
   */
  private async _retryLastAction(): Promise<void> {
    const lastAction = this._lastAction
    if (!lastAction) return

    switch (lastAction.type) {
      case 'send':
        await this.sendMessage(lastAction.text)
        break
      case 'regenerate':
        await this.regenerateLastMessage()
        break
      case 'resend':
        await this.resendLastMessage()
        break
    }
  }

  // 记录最后一次操作
  private _lastAction: { type: string; text?: string } | null = null
}
```

## 反模式

### 错误：直接修改 this.state

```typescript
// ❌ 反模式：绕过 _setState 直接修改状态
this.state.messages.push(newMessage)    // 不会触发 UI 更新
this.state.isProcessing = true          // 不会触发 UI 更新
this.state.messages[0].content = 'xxx'  // 不会触发 UI 更新
```

**问题**：组件通过 `useSyncExternalStore` 订阅状态，直接修改不会触发 `_emit()`，UI 不会更新。

**正确做法**：始终通过 `_setState()` 修改状态，或手动修改后调用 `_emit()`。

### 错误：在 onToken 中做昂贵计算

```typescript
// ❌ 反模式：在每次 token 到达时执行昂贵操作
const onToken = (text: string) => {
  const fullText = msgs[currentIndex].content + text
  // 每次 token 都重新计算整个消息列表的 token 统计
  const totalTokens = messages.reduce((sum, m) => sum + estimateTokens(m.content), 0)
  // 每次 token 都重新渲染 Markdown
  const html = marked.parse(fullText)
  // 每次 token 都持久化
  chrome.storage.local.set({ messages: msgs })
}
```

**问题**：SSE 流式每次 token 到达都会触发 `onToken`，频率可达每秒 10-50 次。昂贵操作会导致 UI 卡顿。

**正确做法**：在 `onToken` 中仅做文本追加和 `_emit()`。将昂贵计算放在 `onDone` 或使用防抖。

### 错误：不处理并发发送

```typescript
// ❌ 反模式：未处理并发发送消息
async sendMessage(text: string): Promise<void> {
  // 没有检查 isProcessing 状态
  const userMessage = this._createMessage('user', text)
  this._appendMessage(userMessage)
  await this._runStream(messages)  // 如果用户快速点击发送，会并发执行
}
```

**问题**：如果用户快速点击发送按钮，会导致多个流式请求并发执行，消息列表混乱。

**正确做法**：在方法开头检查 `this.state.isProcessing`，如果正在处理则直接返回。

### 错误：忽略消息持久化失败

```typescript
// ❌ 反模式：持久化失败导致状态不一致
async _persistSession(): Promise<void> {
  await this._api.sessions.upsert({ ... })  // 如果失败，异常未被捕获
}
```

**问题**：持久化失败可能导致消息丢失，异常向上传播可能导致 UI 崩溃。

**正确做法**：使用 `try/catch` 包裹持久化操作，失败时静默处理或记录日志。

### 错误：在流式完成前切换会话

```typescript
// ❌ 反模式：不检查流式状态就切换会话
selectSession(sessionId: string): void {
  // 没有检查 isProcessing 状态
  this._loadSession(sessionId)  // 可能覆盖正在流式生成的消息
}
```

**问题**：如果用户在流式生成过程中切换会话，会导致正在生成的消息丢失或错乱。

**正确做法**：切换会话前检查 `isProcessing`，如果正在处理，先自动停止当前流式请求。
