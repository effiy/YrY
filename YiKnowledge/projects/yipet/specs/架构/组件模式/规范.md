### 目录规则

| 规则 | 说明 |
|------|------|
| 每个组件一个目录 | 目录名 = PascalCase 组件名 |
| 组件文件同名 | 目录内 TSX 文件名与目录名一致 |
| CSS co-located | 样式文件与组件同目录，同名 `.css` |
| 统一导出 | 每个 components/ 目录有 `index.ts` barrel export |
| 子组件目录 | 复杂组件的子组件放在父目录内 |

## Component Patterns

### Pattern 1: 函数组件 + Hooks

```typescript
// src/chat/components/ChatInput/ChatInput.tsx
import React, { useState, useRef, useCallback, useEffect } from 'react'
import { Button, Input } from 'antd'
import { SendOutlined } from '@ant-design/icons'
import './ChatInput.css'

interface ChatInputProps {
  onSend: (text: string) => void
  disabled?: boolean
  placeholder?: string
}

export const ChatInput: React.FC<ChatInputProps> = ({
  onSend,
  disabled = false,
  placeholder,
}) => {
  const [value, setValue] = useState('')
  const inputRef = useRef<HTMLTextAreaElement>(null)

  const handleSend = useCallback(() => {
    const trimmed = value.trim()
    if (!trimmed || disabled) return
    onSend(trimmed)
    setValue('')
  }, [value, disabled, onSend])

  const handleKeyDown = useCallback(
    (e: React.KeyboardEvent) => {
      if (e.key === 'Enter' && !e.shiftKey) {
        e.preventDefault()
        handleSend()
      }
    },
    [handleSend]
  )

  useEffect(() => {
    inputRef.current?.focus()
  }, [])

  return (
    <div className="yipet-chat-input">
      <Input.TextArea
        ref={inputRef}
        value={value}
        onChange={(e) => setValue(e.target.value)}
        onKeyDown={handleKeyDown}
        placeholder={placeholder}
        disabled={disabled}
        autoSize={{ minRows: 1, maxRows: 6 }}
      />
      <Button
        type="primary"
        icon={<SendOutlined />}
        onClick={handleSend}
        disabled={disabled || !value.trim()}
      />
    </div>
  )
}
```

### Pattern 5: 弹窗组件模式

```typescript
// src/chat/components/BugReportDialog/BugReportDialog.tsx
import React, { useState } from 'react'
import { Modal, Form, Input, Select, Button, message } from 'antd'
import type { BugSeverity, BugPriority } from '@/api/types'
import './BugReportDialog.css'

interface BugReportDialogProps {
  visible: boolean
  onClose: () => void
  onSubmit: (data: BugReportData) => Promise<void>
  initialData?: Partial<BugReportData>
}

export const BugReportDialog: React.FC<BugReportDialogProps> = ({
  visible,
  onClose,
  onSubmit,
  initialData,
}) => {
  const [loading, setLoading] = useState(false)
  const [form] = Form.useForm()

  const handleSubmit = async () => {
    try {
      const values = await form.validateFields()
      setLoading(true)
      await onSubmit(values)
      form.resetFields()
      onClose()
    } catch (err) {
      if (err instanceof Error) {
        message.error(err.message)
      }
    } finally {
      setLoading(false)
    }
  }

  return (
    <Modal
      title="Report Bug"
      open={visible}
      onCancel={onClose}
      onOk={handleSubmit}
      confirmLoading={loading}
      destroyOnClose
      width={640}
      className="yipet-bug-report-dialog"
    >
      <Form
        form={form}
        layout="vertical"
        initialValues={initialData}
      >
        {/* 表单字段 */}
      </Form>
    </Modal>
  )
}
```

| 模式 | 场景 | 示例 |
|------|------|------|

| **Ref + imperative handle** | 父调用子方法 | `useImperativeHandle` |

## Chat 组件 CSS 构建

### buildChatCSS 机制

Chat 组件的 CSS 文件通过 `rsbuild.config.ts` 的 `buildChatCSS()` 函数串联：

```typescript
// rsbuild.config.ts
function buildChatCSS(): string[] {
  return [
    'src/chat/components/ChatWindow/ChatWindow.css',
    'src/chat/components/ChatHeader/ChatHeader.css',
    'src/chat/components/ChatMessages/ChatMessages.css',
    'src/chat/components/ChatInput/ChatInput.css',
    'src/chat/components/MessageBubble/MessageBubble.css',
    'src/chat/components/ChatSidebar/ChatSidebar.css',
    'src/chat/components/ChatToolbar/ChatToolbar.css',
    'src/chat/components/SessionStatusBar/SessionStatusBar.css',
    'src/chat/components/ContextScopeBar/ContextScopeBar.css',
    // ... 其他组件 CSS
  ]
}
```

串联后的 CSS 输出到 `dist/cdn/styles/chat.css`，在 MAIN 世界运行时加载。

### 新增组件时

1. 在组件目录创建 `ComponentName.css`
2. 在 `rsbuild.config.ts` 的 `buildChatCSS()` 中添加文件路径
3. CSS 类名使用 `yipet-` 或 `yp-` 前缀避免与页面样式冲突

## Best Practices

### 正确示例

```typescript
// ✅ 函数组件 + Hooks
export const MyComponent: React.FC<Props> = ({ data, onAction }) => {
  const [state, setState] = useState(initial)
  return <div>{/* ... */}</div>
}

// ✅ Props 类型明确
interface MyComponentProps {
  data: MyData[]
  onAction: (item: MyData) => void
  loading?: boolean
}

// ✅ Co-located CSS
import './MyComponent.css'

// ✅ 使用 antd 组件
import { Button, Tooltip } from 'antd'

// ✅ 使用 @ant-design/icons
import { SendOutlined, LoadingOutlined } from '@ant-design/icons'

// ✅ 条件渲染处理各种状态
if (loading) return <Spin />
if (error) return <Alert type="error" message={error} />
if (!data.length) return <Empty />
```

### 错误示例

```typescript
// ❌ Class 组件
class MyComponent extends React.Component { ... }

// ❌ 使用 any 类型
interface Props { data: any; onAction: any }

// ❌ CSS 放在其他目录
import '../../styles/MyComponent.css'

// ❌ 硬编码样式
<div style={{ color: 'red', fontSize: '14px' }}>

// ❌ 不处理加载/错误/空状态
return <div>{data.map(...)}</div>

// ❌ 使用废弃的 React API
React.createElement('div', null, 'hello')
```

## Constraints

### MUST

- 使用 React 18 函数组件 + Hooks
- 组件目录名为 PascalCase，与组件名一致
- CSS 文件 co-located 在组件目录内
- 新增 Chat 组件 CSS 必须在 `buildChatCSS()` 中注册
- Props 必须定义明确的 TypeScript 接口
- 使用 antd 组件库，不引入其他 UI 库
- 图标使用 `@ant-design/icons`
- 处理加载、错误、空数据三种状态

### MUST NOT

- 不要使用 Class 组件
- 不要使用 `React.createElement` 直接调用
- 不要在 Props 中使用 `any` 类型
- 不要将 CSS 放在与组件不同的目录
- 不要硬编码样式值（应使用 CSS 变量或 co-located CSS）
- 不要在组件中直接调用 `fetch`
- 不要引入 Element Plus / Ant Design Vue 等 Vue 组件库

## React 18 高级模式

### Suspense + Lazy Loading

对于大型组件（如弹窗、抽屉、侧边栏面板），使用 `React.lazy` 和 `Suspense` 实现按需加载。

```typescript
// 按需加载弹窗组件
import React, { Suspense, lazy } from 'react'
import { Spin } from 'antd'

// 弹窗组件延迟加载
const BugReportDialog = lazy(() => import('./BugReportDialog/BugReportDialog'))
const SaveToKnowledgeDialog = lazy(() => import('./SaveToKnowledgeDialog/SaveToKnowledgeDialog'))
const SessionSummaryDialog = lazy(() => import('./SessionSummaryDialog/SessionSummaryDialog'))

// 加载占位符
const DialogFallback = () => (
  <div style={{ padding: 40, textAlign: 'center' }}>
    <Spin tip="加载中..." />
  </div>
)

// 使用
export const ChatWindow: React.FC = () => {
  const state = useSyncExternalStore(ctrl.subscribe, ctrl.getState)

  return (
    <div className="yipet-chat-window">
      {/* 主内容 */}

      {/* 按需加载的弹窗 */}
      <Suspense fallback={<DialogFallback />}>
        {state.bugReportVisible && <BugReportDialog />}
        {state.saveToKnowledgeVisible && <SaveToKnowledgeDialog />}
        {state.sessionSummaryVisible && <SessionSummaryDialog />}
      </Suspense>
    </div>
  )
}
```

### 弹窗预加载策略

```typescript
// 预加载：在用户可能打开弹窗前提前加载组件
const preloadBugReportDialog = () => {
  import('./BugReportDialog/BugReportDialog')

// 在鼠标悬停时预加载
```

### 懒加载决策矩阵

| 组件类型 | 加载策略 | 原因 |
|---------|---------|------|
| 主窗口 (ChatWindow) | 立即加载 | 始终可见 |
| 消息列表 (ChatMessages) | 立即加载 | 核心功能 |
| 弹窗 (Dialog) | lazy + Suspense | 低频使用，节省初始加载 |
| 抽屉 (Drawer) | lazy + Suspense | 低频使用 |
| 侧边栏面板 | lazy + Suspense | 按需切换 |
| 工具按钮组 | 立即加载 | 始终可见，体积小 |

## Error Boundary 组件

### 错误边界实现

```typescript
// src/chat/components/ErrorBoundary/ErrorBoundary.tsx
import React, { Component, type ErrorInfo, type ReactNode } from 'react'
import { Alert, Button } from 'antd'
import { ReloadOutlined } from '@ant-design/icons'
import './ErrorBoundary.css'

interface ErrorBoundaryProps {
  children: ReactNode
  fallback?: ReactNode
  onError?: (error: Error, errorInfo: ErrorInfo) => void
}

interface ErrorBoundaryState {
  hasError: boolean
  error: Error | null
}

/**
 * 错误边界组件
 * 捕获子组件树中的渲染错误，防止整个 Chat 窗口崩溃
 */
export class ErrorBoundary extends Component<ErrorBoundaryProps, ErrorBoundaryState> {
  constructor(props: ErrorBoundaryProps) {
    super(props)
    this.state = { hasError: false, error: null }
  }

  static getDerivedStateFromError(error: Error): ErrorBoundaryState {
    return { hasError: true, error }
  }

  componentDidCatch(error: Error, errorInfo: ErrorInfo): void {
    console.error('[ErrorBoundary] 组件渲染错误:', error, errorInfo)
    this.props.onError?.(error, errorInfo)
  }

  handleReset = (): void => {
    this.setState({ hasError: false, error: null })
  }

  render(): ReactNode {
    if (this.state.hasError) {
      if (this.props.fallback) {
        return this.props.fallback
      }

      return (
        <div className="yipet-error-boundary">
          <Alert
            type="error"
            message="组件渲染异常"
            description={this.state.error?.message || '未知错误，请刷新页面'}
            action={
              <Button
                size="small"
                icon={<ReloadOutlined />}
                onClick={this.handleReset}
              >
                重试
              </Button>
            }
          />
        </div>
      )
    }

    return this.props.children
  }
}

// src/chat/components/ErrorBoundary/ErrorBoundary.css
// .yipet-error-boundary {
//   padding: 16px;
// }
```

### 错误边界分层

```typescript
// 分层错误边界：不同粒度捕获不同范围的错误
export const ChatApp: React.FC = () => {
  return (
    <ErrorBoundary onError={reportError}>          {/* 第 1 层：全局兜底 */}
      <ChatWindow>
        <ErrorBoundary fallback={<SidebarError />}>  {/* 第 2 层：侧边栏 */}
          <ChatSidebar />
        </ErrorBoundary>

        <ErrorBoundary fallback={<MessagesError />}>  {/* 第 2 层：消息区 */}
          <ChatMessages />
```

```typescript
// 1. useDebounce：输入防抖
function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    const timer = setTimeout(() => setDebouncedValue(value), delay)
    return () => clearTimeout(timer)
  }, [value, delay])

  return debouncedValue
}

// 使用
const SearchBar: React.FC = () => {
  const [query, setQuery] = useState('')
  const debouncedQuery = useDebounce(query, 300)

  }, [debouncedQuery])

  return <Input value={query} onChange={e => setQuery(e.target.value)} />
}

// 2. usePrevious：获取上一次的值
function usePrevious<T>(value: T): T | undefined {
  const ref = useRef<T>()
  useEffect(() => {
    ref.current = value
  }, [value])
  return ref.current
}

// 使用
const previousSessionId = usePrevious(state.currentSessionId)
if (previousSessionId !== state.currentSessionId) {
  // 会话切换，执行清理操作

// 3. useAutoScroll：消息列表自动滚动
function useAutoScroll(
  containerRef: RefObject<HTMLDivElement>,
  deps: unknown[]
): void {
  const shouldAutoScroll = useRef(true)

  // 监听用户手动滚动
  const handleScroll = useCallback(() => {
    const el = containerRef.current
    if (!el) return
    const distanceFromBottom = el.scrollHeight - el.scrollTop - el.clientHeight
    shouldAutoScroll.current = distanceFromBottom < 60
  }, [containerRef])

  // 自动滚动到底部
  useEffect(() => {
    if (shouldAutoScroll.current && containerRef.current) {
      containerRef.current.scrollTop = containerRef.current.scrollHeight
    }
  }, deps)

  return { onScroll: handleScroll }
}

// 4. useStreamingToken：流式 token 处理
function useStreamingToken(message: ChatMessage | undefined): {
  displayContent: string
  isStreaming: boolean
} {
  const [displayContent, setDisplayContent] = useState(message?.content || '')

  useEffect(() => {
    if (!message?.streaming) {
      setDisplayContent(message?.content || '')
      return
    }
    // 流式更新时，平滑追加内容
    setDisplayContent(message.content)
  }, [message?.content, message?.streaming])

  return {
    displayContent,
    isStreaming: message?.streaming ?? false,
  }
}

// 5. usePageVisibility：页面可见性检测
function usePageVisibility(): boolean {
  const [isVisible, setIsVisible] = useState(!document.hidden)

  useEffect(() => {
    const handleChange = () => setIsVisible(!document.hidden)
    document.addEventListener('visibilitychange', handleChange)
    return () => document.removeEventListener('visibilitychange', handleChange)
  }, [])

  return isVisible
}

// 使用：页面不可见时降低动画频率
```

## 虚拟滚动

### 消息列表虚拟滚动

当消息数量超过 100 条时，使用虚拟滚动避免 DOM 节点过多导致的性能问题。

```typescript
// 使用 react-window 或自定义虚拟滚动
import { FixedSizeList as VirtualList } from 'react-window'

interface VirtualMessageListProps {
  messages: ChatMessage[]
  estimatedItemHeight: number  // 估算的消息高度，默认 80
}

export const VirtualMessageList: React.FC<VirtualMessageListProps> = ({
  messages,
  estimatedItemHeight = 80,
}) => {
  const listRef = useRef<VirtualList>(null)
  const containerRef = useRef<HTMLDivElement>(null)
  const [containerHeight, setContainerHeight] = useState(600)

  // 监听容器大小变化
  useEffect(() => {
    if (!containerRef.current) return
    const observer = new ResizeObserver(entries => {
      for (const entry of entries) {
        setContainerHeight(entry.contentRect.height)
      }
    })
    observer.observe(containerRef.current)
    return () => observer.disconnect()
  }, [])

  // 自动滚动到最新消息
  useEffect(() => {
    if (messages.length > 0 && listRef.current) {
      listRef.current.scrollToItem(messages.length - 1, 'end')
    }
  }, [messages.length])

  // 消息渲染器
  const MessageRow = ({ index, style }: { index: number; style: React.CSSProperties }) => {
    const message = messages[index]
    return (
      <div style={style}>
        <MessageBubble message={message} />
      </div>
    )
  }

  return (
    <div ref={containerRef} className="yipet-chat-messages">
      <VirtualList
        ref={listRef}
        height={containerHeight}
        itemCount={messages.length}
        itemSize={estimatedItemHeight}
        width="100%"
        overscanCount={5}  // 预渲染 5 条不可见消息
      >
        {MessageRow}
      </VirtualList>
    </div>
  )
}
```

### 虚拟滚动阈值

| 消息数量 | 渲染策略 | 原因 |
|---------|---------|------|
| 0 - 50 | 普通 DOM 渲染 | 性能无影响 |
| 50 - 100 | 普通 DOM 渲染 + React.memo | 轻微优化即可 |
| 100 - 500 | 虚拟滚动 | DOM 节点数显著减少 |
| 500+ | 虚拟滚动 + 分页加载 | 配合懒加载历史消息 |

```typescript
        y: Math.max(0, Math.min(window.innerHeight - 80, dragRef.current.startPosY + dy)),

      setIsDragging(false)

    document.addEventListener('mouseup', handleMouseUp)

      document.removeEventListener('mouseup', handleMouseUp)
    }
  }, [isDragging, position])

        position: 'fixed',
        left: position.x,
```

## 反模式

### 错误：大组件无拆分

```typescript
// ❌ 反模式：单文件 500+ 行组件
export const ChatWindow: React.FC = () => {
  // 所有逻辑、状态、渲染都在一个组件中
  const [messages, setMessages] = useState([])
  const [input, setInput] = useState('')

  // ... 300 行逻辑

    </div>
  )

```

**问题**：难以维护、测试和复用。性能差（任何状态变化都导致整个组件重新渲染）。

**正确做法**：拆分为 `ChatWindow`（容器） + `ChatMessages` + `ChatInput` + `ChatSidebar` 等子组件。

### 错误：滥用 useMemo/useCallback

```typescript
// ❌ 反模式：简单的值计算也用 useMemo
const doubled = useMemo(() => count * 2, [count])
const handleClick = useCallback(() => setCount(c => c + 1), [])
```

**问题**：`useMemo` 和 `useCallback` 本身有开销，对简单操作使用反而降低性能。

**正确做法**：仅在以下场景使用：
- 计算结果需要作为其他 Hook 的依赖
- 计算开销大（如数组的 filter + sort + map 链）
- 传递给使用 `React.memo` 的子组件

### 错误：错误边界放错位置

```typescript
// ❌ 反模式：错误边界包裹整个应用，一个组件错误导致整个页面白屏

  <ChatWindow />
</ErrorBoundary>
```

**问题**：一个子组件错误导致整个 Chat 窗口不可用。

**正确做法**：分层使用错误边界，隔离不同功能区域的错误影响。

### 错误：直接在渲染中创建内联对象/函数

```typescript
// ❌ 反模式：每次渲染创建新对象和函数

  message={message}
  style={{ padding: 8 }}                              // 每次渲染新对象

  options={[{ label: '复制', value: 'copy' }]}         // 每次渲染新数组
```

**正确做法**：使用 `useMemo` 和 `useCallback` 稳定引用，或将常量提取到组件外部。
