# Spec: i18n Conventions

## Overview

本规范定义了 YiPet 国际化文本的使用方式、文件组织、命名规范、locale 检测、时区处理等约定。

YiPet 使用 Chrome 扩展原生的 `chrome.i18n` API，而非 vue-i18n 或 react-intl 等第三方库。

---

## Core Functions

### t() 函数

```typescript
// src/shared/i18n/index.ts
import type { MessageKey } from './MessageKey'

/**
 * 获取国际化文本
 * @param key - messages.json 中的 key
 * @param substitutions - 插值参数（可选）
 * @returns 本地化文本
 */
export function t(key: MessageKey, substitutions?: string | string[]): string {
  return chrome.i18n.getMessage(key, substitutions)
}
```

### MessageKey 类型

`MessageKey` 是一个字符串联合类型，与 `public/_locales/en/messages.json` 中的 key 保持同步：

```typescript
// src/shared/i18n/MessageKey.ts
export type MessageKey =
  | 'appName'
  | 'appDescription'
  | 'sendButton'
  | 'cancelButton'
  | 'saveButton'
  | 'deleteButton'
  | 'searchPlaceholder'
  | 'noResults'
  | 'loading'
  | 'errorOccurred'
  | 'popupTitle'
  | 'popupSubtitle'
  | 'popupPreviewTitle'
  | 'popupModelLabel'
  | 'notifyModelUpdated'
  // ... 更多 key
```

### 使用示例

```typescript
import { t } from '@/shared/i18n'

// 基础用法
const label = t('sendButton')              // "Send" 或 "发送"
const title = t('appName')                 // "YiPet" 或 "小宠物"

// 带插值参数
const message = t('welcomeMessage', ['YiPet'])  // "Welcome to YiPet"
const count = t('messageCount', ['5'])          // "5 messages"

// 格式化日期
const formatted = t('lastUpdated', [new Date().toLocaleDateString()])
```

## 新增 i18n Key 流程

### 步骤

1. **在 `public/_locales/en/messages.json` 中添加 key**
   - `message` 字段为英文文本
   - `description` 字段说明用途
   - 如有插值参数，添加 `placeholders` 字段

2. **在 `public/_locales/zh_CN/messages.json` 中添加对应 key**
   - `message` 字段为中文翻译

3. **在 `src/shared/i18n/MessageKey.ts` 中添加 key**
   - 将新 key 加入 `MessageKey` 联合类型
   - 确保编译时类型检查覆盖

4. **在代码中使用 `t('newKey')`**

### 示例

```typescript
// 1. en/messages.json 添加
{
  "tooltipCopyMessage": {
    "message": "Copy message to clipboard",
    "description": "Tooltip for copy message button"
  }
}

// 2. zh_CN/messages.json 添加
{
  "tooltipCopyMessage": {
    "message": "复制消息到剪贴板",
    "description": "复制消息按钮的提示文本"
  }
}

// 3. MessageKey.ts 添加
export type MessageKey =
  | 'tooltipCopyMessage'  // 新增
  | // ... 其他 key

// 4. 代码中使用
<Tooltip title={t('tooltipCopyMessage')}>
  <Button icon={<CopyOutlined />} />
</Tooltip>
```

## Locale 检测

### 检测逻辑

```typescript
// src/shared/i18n/locale.ts

/**
 * 获取当前 locale
 * 优先使用 chrome.i18n.getUILanguage()，回退到 navigator.language
 */
export function getCurrentLocale(): string {
  try {
    // Chrome 扩展环境
    if (typeof chrome !== 'undefined' && chrome.i18n) {
      return chrome.i18n.getUILanguage()
    }
  } catch {
    // 非扩展环境（测试等）
  }
  return navigator.language || 'en'
}

/**
 * 获取简化的语言代码（如 zh、en）
 */
export function getLanguageCode(): string {
  return getCurrentLocale().split('-')[0]
}

/**
 * 判断是否为中文环境
 */
export function isChineseLocale(): boolean {
  const locale = getCurrentLocale()
  return locale.startsWith('zh')
}
```

### 支持的 locale

| 语言代码 | 语言 | messages.json 路径 |
|---------|------|-------------------|
| `en` | English | `public/_locales/en/messages.json` |
| `zh_CN` | 简体中文 | `public/_locales/zh_CN/messages.json` |

### 回退策略

当 key 缺失时，`chrome.i18n.getMessage` 的回退顺序：

1. 当前 locale 的 `messages.json`
2. 默认 locale (`en`) 的 `messages.json`
3. 返回空字符串 `""`（chrome.i18n 行为）
4. 可在 `t()` 函数中额外处理：`t(key) || key`

## 时区处理

### 时区检测

```typescript
// src/shared/i18n/timezone.ts

/**
 * 获取用户时区
 * 使用 Intl API 而非 chrome.i18n（更可靠）
 */
export function getUserTimezone(): string {
  return Intl.DateTimeFormat().resolvedOptions().timeZone
}

/**
 * 获取时区偏移量（分钟）
 */
export function getTimezoneOffset(): number {
  return new Date().getTimezoneOffset()
}

/**
 * 获取时区显示名称
 */
export function getTimezoneName(): string {
  const tz = getUserTimezone()
  const date = new Date()
  // 使用 Intl 获取时区全称
  const name = new Intl.DateTimeFormat('en', {
    timeZone: tz,
    timeZoneName: 'long',
  }).formatToParts(date).find(p => p.type === 'timeZoneName')?.value
  return name || tz
}
```

### 日期时间格式化

```typescript
// src/utils/datetime.ts
import { getUserTimezone } from '@/shared/i18n/timezone'

/**
 * 将 UTC 时间戳转换为用户时区显示
 * 所有时间戳存储为 ISO 8601 UTC 格式
 */
export function formatDateTimeUTC(isoString: string, options?: {
  showDate?: boolean
  showTime?: boolean
  showSeconds?: boolean
}): string {
  const date = new Date(isoString)
  const tz = getUserTimezone()

  const dateOptions: Intl.DateTimeFormatOptions = {
    timeZone: tz,
    year: 'numeric',
    month: 'short',
    day: 'numeric',
    hour: '2-digit',
    minute: '2-digit',
    second: options?.showSeconds ? '2-digit' : undefined,
    hour12: false,
  }

  return new Intl.DateTimeFormat(getCurrentLocale(), dateOptions).format(date)
}

/**
 * 相对时间显示（如 "2 minutes ago", "3 分钟前"）
 */
export function formatRelativeTime(isoString: string): string {
  const date = new Date(isoString)
  const now = new Date()
  const diffMs = now.getTime() - date.getTime()
  const diffSeconds = Math.floor(diffMs / 1000)
  const diffMinutes = Math.floor(diffSeconds / 60)
  const diffHours = Math.floor(diffMinutes / 60)
  const diffDays = Math.floor(diffHours / 24)

  if (diffSeconds < 60) return t('timeJustNow')
  if (diffMinutes < 60) return t('timeMinutesAgo', [String(diffMinutes)])
  if (diffHours < 24) return t('timeHoursAgo', [String(diffHours)])
  if (diffDays < 7) return t('timeDaysAgo', [String(diffDays)])
  return formatDateTimeUTC(isoString)
}
```

## i18n Key 命名规范

### 命名模式

| 类型 | 命名模式 | 示例 |
|------|---------|------|
| **按钮文本** | `[action]Button` | `sendButton`, `cancelButton`, `saveButton` |
| **占位符** | `[field]Placeholder` | `searchPlaceholder`, `inputPlaceholder` |
| **标题** | `[component]Title` | `popupTitle`, `chatWindowTitle` |
| **副标题** | `[component]Subtitle` | `popupSubtitle` |
| **标签** | `[field]Label` | `popupModelLabel`, `severityLabel` |
| **提示文本** | `tooltip[Description]` | `tooltipCopyMessage`, `tooltipEditSession` |
| **错误消息** | `error[Description]` | `errorOccurred`, `errorNetworkTimeout` |
| **成功消息** | `[action]Success` | `saveSuccess`, `deleteSuccess` |
| **确认消息** | `confirm[Action]` | `confirmDelete`, `confirmClear` |
| **状态文本** | `status[State]` | `statusLoading`, `statusConnected` |
| **时间文本** | `time[Relative]` | `timeJustNow`, `timeMinutesAgo` |
| **通知文本** | `notify[Event]` | `notifyModelUpdated`, `notifyConfigSaved` |

### 命名规则

- 使用 camelCase
- 避免使用缩写（除非是广泛认可的）
- 描述性命名，从 key 名即可推断用途
- 插值参数使用 `$1`, `$2` 等占位符

## Best Practices

### 正确示例

```typescript
// ✅ 使用 t() 函数
<Button>{t('sendButton')}</Button>

// ✅ 带插值参数
<Tooltip title={t('messageCount', ['5'])}>

// ✅ 占位符使用 t()
<Input placeholder={t('searchPlaceholder')} />

// ✅ 消息提示使用 t()
message.success(t('saveSuccess'))

// ✅ 错误提示使用 t()
message.error(t('errorNetworkTimeout'))

// ✅ 时间格式化使用工具函数
<span>{formatRelativeTime(message.timestamp)}</span>
```

### 错误示例

```typescript
// ❌ 硬编码文本
<Button>Send</Button>

// ❌ 硬编码占位符
<Input placeholder="Search..." />

// ❌ 硬编码消息
message.success('Saved successfully')

// ❌ 直接使用 key 字符串
const label = 'sendButton'

// ❌ 拼接国际化文本
const msg = t('hello') + ' ' + userName + ' ' + t('welcome')
// 应使用插值参数：t('helloUserWelcome', [userName])

// ❌ 在循环中重复调用 t()
items.map(item => t('itemLabel'))  // t() 可以缓存，但语义上不应该依赖 key 动态拼接
```

## Constraints

### MUST

- 所有用户可见文本必须使用 `t()` 函数
- 新增 key 必须同步更新 `en/messages.json`、`zh_CN/messages.json`、`MessageKey` 类型
- 时间戳存储使用 ISO 8601 UTC 格式
- 时间显示使用 `formatDateTimeUTC` 或 `formatRelativeTime`
- `t()` 的 key 参数必须是 `MessageKey` 类型

### MUST NOT

- 不要在模板、JSX 中硬编码文本
- 不要拼接字符串构建国际化文本（应使用插值参数）
- 不要直接使用 `chrome.i18n.getMessage`（应使用 `t()` 封装）
- 不要在组件中直接处理时区转换（应使用 `src/utils/datetime.ts`）
- 不要创建不符合命名规范的 i18n key

## 动态 Locale 切换

### 运行时切换语言

Chrome 扩展的 `chrome.i18n` 不支持运行时动态切换语言（`getUILanguage()` 返回的是浏览器语言，在扩展生命周期内不变）。但可以通过包装层实现类似效果。

```typescript
// src/shared/i18n/locale.ts

// 支持的语言列表
export const SUPPORTED_LOCALES = ['en', 'zh_CN'] as const
export type SupportedLocale = typeof SUPPORTED_LOCALES[number]

// 用户手动选择的 locale（存储在 chrome.storage）
let userLocaleOverride: SupportedLocale | null = null

/**
 * 设置用户手动选择的语言
 */
export async function setUserLocale(locale: SupportedLocale): Promise<void> {
  userLocaleOverride = locale
  await chrome.storage.local.set({ userLocale: locale })
  // 通知所有组件重新渲染
  localeChangeListeners.forEach(fn => fn(locale))
}

/**
 * 获取当前生效的 locale
 * 优先级：用户手动选择 > 浏览器语言 > 默认 en
 */
export function getEffectiveLocale(): SupportedLocale {
  if (userLocaleOverride) return userLocaleOverride

  const uiLang = chrome.i18n.getUILanguage()
  // 精确匹配
  if (SUPPORTED_LOCALES.includes(uiLang as SupportedLocale)) {
    return uiLang as SupportedLocale
  }
  // 前缀匹配（如 zh-TW -> zh_CN）
  if (uiLang.startsWith('zh')) return 'zh_CN'
  // 默认回退
  return 'en'
}

// locale 变化监听器
const localeChangeListeners = new Set<(locale: SupportedLocale) => void>()

export function onLocaleChange(listener: (locale: SupportedLocale) => void): () => void {
  localeChangeListeners.add(listener)
  return () => localeChangeListeners.delete(listener)
}

// 初始化时恢复用户选择
export async function initLocale(): Promise<void> {
  const result = await chrome.storage.local.get('userLocale')
  if (result.userLocale && SUPPORTED_LOCALES.includes(result.userLocale)) {
    userLocaleOverride = result.userLocale
  }
}
```

### 增强的 t() 函数

```typescript
// src/shared/i18n/index.ts

/**
 * 获取国际化文本（支持动态 locale）
 * @param key - 消息 key
 * @param substitutions - 插值参数
 * @param locale - 覆盖语言（可选，默认使用当前生效 locale）
 */
export function t(
  key: MessageKey,
  substitutions?: string | string[],
  locale?: SupportedLocale
): string {
  const effectiveLocale = locale || getEffectiveLocale()

  // chrome.i18n.getMessage 会自动根据浏览器语言选择
  // 但我们可以通过加载自定义 messages 来支持动态切换
  const message = chrome.i18n.getMessage(key, substitutions)

  // 如果返回空字符串（key 不存在），回退到 key 本身
  return message || key
}
```

### 语言切换 UI

```typescript
// 语言选择器组件
export const LocaleSwitcher: React.FC = () => {
```

## 回退链

### 完整回退链

```
用户请求 key "sendButton"
    │
    ▼
1. 用户手动选择的 locale 的 messages.json
   ├── 找到 → 返回翻译文本
   └── 未找到 → 继续
    │
    ▼
2. 浏览器语言 (chrome.i18n.getUILanguage) 的 messages.json
   ├── 找到 → 返回翻译文本
   └── 未找到 → 继续
    │
    ▼
3. 默认 locale (en) 的 messages.json  
   ├── 找到 → 返回英文文本
   └── 未找到 → 继续
    │
    ▼
4. chrome.i18n.getMessage 返回 ""（空字符串）
    │
    ▼
5. t() 函数兜底：返回 key 本身 "sendButton"
    ├── 开发模式：控制台警告 "缺失 i18n key: sendButton"
    └── 生产模式：静默返回 key
```

### 回退链实现

```typescript
export function t(key: MessageKey, substitutions?: string | string[]): string {
  // 尝试获取翻译
  const message = chrome.i18n.getMessage(key, substitutions)

  // 空字符串表示 key 不存在
  if (message === '') {
    // 开发模式警告
    if (process.env.NODE_ENV === 'development') {
      console.warn(`[i18n] 缺失翻译 key: "${key}"，已回退到 key 名称`)
    }
    return key
  }

  return message
}
```

```typescript
// 检测当前语言是否为 RTL
export function isRTL(locale?: string): boolean {
  const lang = locale || getEffectiveLocale()
  const rtlLanguages = ['ar', 'he', 'fa', 'ur']
  return rtlLanguages.some(rtl => lang.startsWith(rtl))
}

// 根据语言方向设置 HTML dir 属性
export function applyDirection(): void {
  const dir = isRTL() ? 'rtl' : 'ltr'
  document.documentElement.setAttribute('dir', dir)
}
```

## 复数规则

### chrome.i18n 复数支持

`chrome.i18n.getMessage` 原生支持复数形式，通过 `$<placeholder>@<plural_form>$` 语法。

```json
// public/_locales/en/messages.json
{
  "messageCount": {
    "message": "$COUNT$ $COUNT@plural$",
    "description": "消息数量",
    "placeholders": {
      "count": {
        "content": "$1"
      }
    }
  }
}
```

由于 `chrome.i18n` 的复数支持有限（仅支持 `@plural` 后缀），应使用自定义复数工具：

```typescript
// src/shared/i18n/pluralize.ts

type PluralRule = 'zero' | 'one' | 'two' | 'few' | 'many' | 'other'

/**
 * 根据 CLDR 复数规则获取复数形式
 */
function getPluralForm(count: number, locale: string): PluralRule {
  // 中文：所有数量使用同一形式
  if (locale.startsWith('zh')) return 'other'

  // 英文规则
  if (locale.startsWith('en')) {
    if (count === 1) return 'one'
    return 'other'
  }

  return 'other'
}

/**
 * 复数化翻译
 * @param keyBase - 基础 key，如 "messageCount"
 * @param count - 数量
 * @returns 复数化后的文本
 */
export function pluralize(keyBase: string, count: number): string {
  const locale = getEffectiveLocale()
  const form = getPluralForm(count, locale)

  // 尝试获取复数形式
  const pluralKey = `${keyBase}_${form}` as MessageKey
  const message = chrome.i18n.getMessage(pluralKey, [String(count)])

  if (message) return message

  // 回退到 other 形式
  const otherKey = `${keyBase}_other` as MessageKey
  return chrome.i18n.getMessage(otherKey, [String(count)]) || `${count} ${keyBase}`
}

// 使用示例
// en/messages.json:
//   "messageCount_one": "1 message"
//   "messageCount_other": "$1 messages"
// zh_CN/messages.json:
//   "messageCount_other": "$1 条消息"

const text = pluralize('messageCount', 5)  // "5 messages" 或 "5 条消息"
const text = pluralize('messageCount', 1)  // "1 message"
```

```typescript
/**
 * 格式化时间
 */
export function formatTime(
  date: Date | string,
  showSeconds = false
): string {
  const d = typeof date === 'string' ? new Date(date) : date
  const locale = getEffectiveLocale()

  return new Intl.DateTimeFormat(locale, {
    hour: '2-digit',
    minute: '2-digit',
    second: showSeconds ? '2-digit' : undefined,
    hour12: false,
  }).format(d)
}

/**
 * 日期时间完整格式
 */
export function formatDateTime(
  date: Date | string,
  options?: {
    showDate?: boolean
    showTime?: boolean
    showSeconds?: boolean
  }
): string {
  const d = typeof date === 'string' ? new Date(date) : date
  const locale = getEffectiveLocale()
  const opts = { showDate: true, showTime: true, showSeconds: false, ...options }

  const datePart = opts.showDate ? formatDate(d) : ''
  const timePart = opts.showTime ? formatTime(d, opts.showSeconds) : ''

  if (datePart && timePart) {
    // 中文使用空格分隔，英文也使用空格
    return `${datePart} ${timePart}`
  }
  return datePart || timePart
}
```

```typescript
 */
export function formatPercent(value: number, decimals = 1): string {
  return new Intl.NumberFormat(getEffectiveLocale(), {
    style: 'percent',
    minimumFractionDigits: decimals,
    maximumFractionDigits: decimals,
  }).format(value / 100)

/**
 * 格式化字节大小
 */
export function formatBytes(bytes: number, decimals = 1): string {
  if (bytes === 0) return '0 B'

  const k = 1024
  const sizes = ['B', 'KB', 'MB', 'GB']
  const i = Math.floor(Math.log(bytes) / Math.log(k))

  return `${(bytes / Math.pow(k, i)).toFixed(decimals)} ${sizes[i]}`
}

/**
 * 格式化时长
 */
export function formatDuration(ms: number): string {
  const seconds = Math.floor(ms / 1000)
  const minutes = Math.floor(seconds / 60)
  const hours = Math.floor(minutes / 60)

  if (hours > 0) {
    return `${hours}h ${minutes % 60}m`
  }
  if (minutes > 0) {
    return `${minutes}m ${seconds % 60}s`
  }
  return `${seconds}s`
}
```

```typescript
/**
 * 使用 Intl.RelativeTimeFormat 格式化相对时间
 */
export function formatRelativeTimeIntl(
  date: Date | string,
  now: Date = new Date()
): string {
  const d = typeof date === 'string' ? new Date(date) : date
  const locale = getEffectiveLocale()
  const rtf = new Intl.RelativeTimeFormat(locale, { numeric: 'auto' })

  const diffMs = d.getTime() - now.getTime()
  const diffSeconds = Math.round(diffMs / 1000)
  const diffMinutes = Math.round(diffSeconds / 60)
  const diffHours = Math.round(diffMinutes / 60)
  const diffDays = Math.round(diffHours / 24)
  const diffWeeks = Math.round(diffDays / 7)
  const diffMonths = Math.round(diffDays / 30)
  const diffYears = Math.round(diffDays / 365)

  if (Math.abs(diffSeconds) < 60) return rtf.format(diffSeconds, 'second')
  if (Math.abs(diffMinutes) < 60) return rtf.format(diffMinutes, 'minute')
  if (Math.abs(diffHours) < 24) return rtf.format(diffHours, 'hour')
  if (Math.abs(diffDays) < 7) return rtf.format(diffDays, 'day')
  if (Math.abs(diffWeeks) < 5) return rtf.format(diffWeeks, 'week')
  if (Math.abs(diffMonths) < 12) return rtf.format(diffMonths, 'month')
  return rtf.format(diffYears, 'year')
}

// 使用示例
formatRelativeTimeIntl('2026-09-01T10:00:00Z')  // "1 day ago" 或 "1 天前"
```

```typescript
/**
 * 增强的插值函数：支持命名参数
 * chrome.i18n.getMessage 只支持 $1, $2 位置参数
 * 此函数通过包裹层支持命名参数
 */
export function tWithNamed(
  key: MessageKey,
  params?: Record<string, string | number>
): string {
  let message = t(key)

  if (params) {
    for (const [name, value] of Object.entries(params)) {
      message = message.replace(
        new RegExp(`\\{\\{${name}\\}\\}`, 'g'),
        String(value)
      )
    }
  }

  return message
}
```

## 反模式

### 错误：硬编码 UI 文本

```typescript
// ❌ 反模式：硬编码文本
<Button>确定</Button>
<Input placeholder="搜索会话..." />
message.success('保存成功')
```

**问题**：无法国际化，修改文本需要改代码。

**正确做法**：所有用户可见文本使用 `t()` 函数。

### 错误：字符串拼接构建翻译文本

```typescript
// ❌ 反模式：字符串拼接
const text = t('hello') + ' ' + userName + ', ' + t('welcome')
// 英语：Hello Alice, Welcome
// 中文：你好 Alice, 欢迎  ← 语法错误，中文不需要逗号
```

**问题**：不同语言的语序和连接词不同，拼接无法适应所有语言。

**正确做法**：使用插值参数 `t('helloUserWelcome', ['Alice'])`，让翻译人员控制完整的句子结构。

### 错误：忽视 CSS 逻辑属性

```typescript
// ❌ 反模式：使用物理方向属性
.message {
  margin-left: 12px;
  text-align: left;
  border-right: 1px solid #eee;
}
```

**问题**：RTL 语言（阿拉伯语、希伯来语）下布局错乱。

**正确做法**：使用 CSS 逻辑属性 `margin-inline-start`、`text-align: start`、`border-inline-end`。

### 错误：i18n key 命名不规范

```typescript
// ❌ 反模式：随意命名 key
t('btn1')       // 含义不明
t('msg')        // 太泛化
t('send')       // 动词还是名词不明确
t('error_1')    // 数字编号无法理解含义
```

**问题**：key 名称无法传达语义，维护困难。

**正确做法**：使用 `[context][Action][Type]` 命名规范，如 `sendButton`、`errorNetworkTimeout`、`tooltipCopyMessage`。
