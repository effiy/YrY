## 信息卡片

Pet 工具提示展示实用信息卡片。

| 卡片类型 | 数据来源 |
|---------|---------|
| 天气 | 天气 API |
| 日历 | 系统日期 |
| 倒数日 | 用户自定义事件 |
| 系统信息 | 电池/网络/内存 |

---

## 一、需求背景

来源 PRD：146-功能实现-天气与信息卡片.md

### 用户痛点

1. **获取天气需要切换标签页**：出门前想快速查看天气
1. **Popup 信息密度低**：打开 Popup 只看到宠物，无实用信息
1. **无法自定义信息卡片**：用户只关心天气和时间，但无法隐藏其他

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 卡片类型 | 数据来源 |
| 天气 | 天气 API |
| 日历 | 系统日期 |
| 倒数日 | 用户自定义事件 |
| 系统信息 | 电池/网络/内存 |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |
| 2 | UI 组件开发 + Popup/Side Panel 集成 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |

## 四、实施步骤
