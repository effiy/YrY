## 一、方案概述

Vue 错误边界组件 + 分层降级策略：Chat Window 崩溃不影响 Floating Pet，Popup 错误不影响 Content Script。

### 降级层级

| 级别 | 场景 | 行为 |
|------|------|------|
| L1 | Vue 渲染错误 | ErrorBoundary 隔离，显示降级 UI |
| L2 | API 不可达 | 缓存数据 + 重试按钮 |
| L3 | CDN 加载失败 | 基础功能可用（无 UI 库） |
| L4 | 致命错误 | 清除注入 + 提示刷新 |
