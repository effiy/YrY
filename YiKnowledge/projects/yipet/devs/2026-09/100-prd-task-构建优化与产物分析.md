## 一、需求背景

来源 PRD：100-基础设施-构建优化与产物分析.md

### 用户痛点

1. **扩展加载缓慢**：注入 content script 时，大体积 JS 导致页面首次渲染延迟
1. **重复依赖浪费内存**：content script 和 popup 各自加载完整 Vue runtime
1. **构建时间过长**：每次 `npm run build` 需要 60s+，影响开发效率
