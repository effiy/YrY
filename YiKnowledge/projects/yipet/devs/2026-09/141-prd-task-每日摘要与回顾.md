# YP-09-134: 每日摘要与回顾 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-134 · 状态：方案已编写

## 每日摘要

每日定时生成 AI 使用摘要：对话次数、Token 消耗、主要话题。

| 内容 | 来源 |
|------|------|
| 对话统计 | 会话元数据 |
| Token 消耗 | API 响应统计 |
| 主要话题 | AI 摘要生成 |
| 知识沉淀 | 自动建议导出到 YiKnowledge |

---

## 一、需求背景

来源 PRD：141-功能实现-每日摘要与回顾.md

### 用户痛点

1. **对话价值未被充分利用**：有价值的对话内容在会话结束后被遗忘
1. **待办事项遗漏**：用户在对话中提到的待办未被系统追踪
1. **无定期回顾机制**：用户无法回顾一天/一周的对话收获

| 内容 | 来源 |

| 步骤 | 任务 |

| 2 | UI 组件开发 + Popup/Side Panel 集成 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
