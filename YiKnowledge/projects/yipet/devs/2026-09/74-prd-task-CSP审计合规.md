## 一、方案概述

CSP 审计：自动扫描 manifest.json + 构建产物，确保无 eval/inline-script/remote-code。

### 审计项

| 检查 | 工具 | 通过标准 |
|------|------|---------|
| 无 eval | `rg "eval\("` | 零匹配 |
| 无 inline script | CSP 头检查 | `script-src 'self'` |
| 无远程代码 | `rg "https?://" src/` 排除 API | 仅 YiAi 地址 |
| web_accessible | 仅 assets/*, cdn/* | 精确声明 |
