## 一、需求背景

来源 PRD：203-功能实现-文本排序工具.md

### 用户痛点

1. **跨应用排序流程割裂**：从 GitHub 复制配置列表 → 打开 VS Code 排序 → 复制回去
1. **编辑器不支持自然排序**：文件列表 "f1, f10, f2" 的字母排序的不正确结果
1. **去重需额外工具**：URL 列表去重需要打开 Excel 或写 Python 脚本
