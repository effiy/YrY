## 一、需求背景

来源 PRD：136-功能实现-阅读列表与稍后读.md

### 用户痛点

1. **想读的文章找不到，阅读意图丢失**：用户在社交媒体看到 10 篇技术文章，保存到标签页后忘记，一周后全部关闭
1. **阅读进度无法追踪，重复阅读**：用户打开一篇 5000 字的技术文章，读到 30% 被打断，下次打开从头开始
1. **阅读列表变成"数字坟墓"**：用户保存了 50 篇文章但从未打开，阅读列表成为焦虑来源而非阅读助手

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 添加页面 | 点击按钮/右键菜单 |
| 已读/未读 | 状态标记 |
| 阅读时间估算 | 正文长度÷阅读速度 |
| 离线阅读 | 缓存页面内容到 storage |
| 归档 | 已读自动归档 |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |
| 2 | UI 组件开发 + Popup/Side Panel 集成 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
