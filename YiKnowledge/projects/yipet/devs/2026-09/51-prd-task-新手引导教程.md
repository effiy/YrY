## 一、需求背景

来源 PRD：51-架构设计-新手引导教程.md

### 用户痛点

1. **新用户不知道右键菜单功能**：高
1. **皮肤切换入口在 Popup 中，难以发现**：低
1. **引导信息不可跳过/重复**：中

| 功能 | 实现方案 |

| 1 | 欢迎 |
| 2 | 聊天 |
| 3 | 设置 |
| 4 | 快捷键 |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
