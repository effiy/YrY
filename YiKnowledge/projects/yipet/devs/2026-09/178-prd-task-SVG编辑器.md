## 一、需求背景

来源 PRD：178-功能实现-SVG编辑器.md

### 用户痛点

1. **SVG Path 手写调试困难**：创建自定义 SVG 图标
1. **需要设计工具生成形状**：快速生成标准形状的 SVG 代码
1. **无实时预览**：修改 Path 后无法即时查看效果

| 功能 | 实现方案 |

| 导出 | PNG/SVG 下载 |
| 优化 | SVGO 压缩 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
