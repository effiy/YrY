## 一、方案概述

YiPet↔YiVad 桥接可靠性增强：超时重试、降级方案、错误恢复。

### 可靠性增强

| 场景 | 策略 |
|------|------|
| YiVad 不可达 | 重试 3 次，提示手动打开 |
| Session Key 过期 | 自动刷新 Key |
| window.open 被拦截 | 提示用户允许弹窗 |
| 跨域限制 | postMessage + origin 校验 |

### 降级方案

| 主方案 | 降级 |
|--------|------|
| window.open | 复制链接到剪贴板 |
| Session Key | 手动输入会话 ID |
