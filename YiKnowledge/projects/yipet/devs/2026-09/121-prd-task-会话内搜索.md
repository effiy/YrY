## 一、方案概述

当前会话内全文搜索消息内容，高亮匹配项，上下导航。

| 功能 | 说明 |
|------|------|
| 实时搜索 | 输入即搜，200ms 防抖 |
| 高亮匹配 | `<mark>` 标签包裹匹配文本 |
| 上下导航 | Enter/Shift+Enter 跳转命中项 |
| 搜索结果 | 显示匹配消息的预览片段 |
