# YP-09-19: 扩展遥测与匿名统计 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-19 · 状态：方案已编写

---

<a id="sec-1"></a>
## 一、方案概述

匿名使用统计：DAU/MAU、功能使用频率、崩溃率。用户可选择关闭。

### 统计指标

| 指标 | 说明 |
|------|------|
| DAU | 每日活跃用户 |
| 功能使用 | 聊天/Popup/Pet 交互次数 |
| 崩溃率 | 未捕获异常次数 |
| 性能 | 注入耗时/SSE 延迟 |

> 用户设置中可关闭遥测。

---

## 一、需求背景

来源 PRD：26-架构设计-扩展遥测与匿名统计.md

### 用户痛点

1. **无 DAU/MAU 数据——产品健康度无法量化**：高
1. **功能使用分布未知——可能 80% 用户只用 20% 功能**：高
1. **无用户留存数据——无法区分"试过即弃"和"长期使用"**：中

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 指标 | 说明 |
| DAU | 每日活跃用户 |
| 崩溃率 | 未捕获异常次数 |
| 性能 | 注入耗时/SSE 延迟 |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |
| 2 | UI 组件开发 + Popup/Side Panel 集成 |
| 3 | 边界场景处理 + 集成验证 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |

## 四、实施步骤
