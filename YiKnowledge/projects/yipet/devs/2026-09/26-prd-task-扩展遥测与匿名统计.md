<a id="sec-1"></a>
## 一、方案概述

匿名使用统计：DAU/MAU、功能使用频率、崩溃率。用户可选择关闭。

### 统计指标

| 指标 | 说明 |
|------|------|
| DAU | 每日活跃用户 |
| 功能使用 | 聊天/Popup/Pet 交互次数 |
| 崩溃率 | 未捕获异常次数 |
| 性能 | 注入耗时/SSE 延迟 |

> 用户设置中可关闭遥测。
