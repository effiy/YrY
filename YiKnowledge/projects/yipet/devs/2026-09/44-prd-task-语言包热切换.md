# YP-09-37: 语言包热切换 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-37

## 实现

无需刷新页面即可切换语言：监听 `chrome.storage.onChanged` 中 `lang` 键变化 → 重新设置 `chrome.i18n` 消息 → Vue i18n locale 更新。

| 功能 | 说明 |
|------|------|
| 即时切换 | 选择语言后 Pet/Chat/Popup 立即更新 |
| 记忆偏好 | chrome.storage 持久化语言选择 |
| 跟随系统 | 默认跟随 Chrome 语言设置 |
