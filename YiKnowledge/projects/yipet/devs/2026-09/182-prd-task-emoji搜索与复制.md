## 一、需求背景

来源 PRD：182-功能实现-emoji搜索与复制.md

### 用户痛点

1. **Emoji 查找效率低**：在邮件/文档中输入特定 Emoji
1. **肤色变体难选择**：需要特定肤色的手势 Emoji
1. **无使用历史**：经常重复使用同一组 Emoji

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 搜索 | 关键词匹配 |
| 分类 | 表情/动物/食物/旗帜 |
| 复制 | 点击复制到剪贴板 |
| 最近使用 | 最近 30 个 |
| 肤色 | Fitzpatrick 修饰符 |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |
| 2 | UI 组件开发 + Popup/Side Panel 集成 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
