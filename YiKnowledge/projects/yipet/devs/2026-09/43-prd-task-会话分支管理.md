## 一、方案概述

从任意消息创建会话分支，分支间独立演化，可视化分支树。

### 分支模型

```typescript
interface SessionBranch {
  id: string;
  parentMessageId: string;
  messages: Message[];
  createdAt: string;
  label?: string;  // 分支标签
}

// 分支树展示
// root → branch-A → branch-A1
//      → branch-B → branch-B1 → branch-B2
```
