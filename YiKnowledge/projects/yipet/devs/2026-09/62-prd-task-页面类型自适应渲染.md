# YP-09-55: 页面类型自适应渲染 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-55

## 自适应策略

| 页面类型 | 检测方式 | Pet 行为 |
|---------|---------|---------|
| 视频网站 | `document.querySelector('video')` | 缩小+安静模式 |
| 代码编辑器 | `document.querySelector('.monaco')` | 右下角固定 |
| 阅读页面 | 正文>5000字 | 仅显示工具提示 |
| 常规页面 | 默认 | 全功能 |
