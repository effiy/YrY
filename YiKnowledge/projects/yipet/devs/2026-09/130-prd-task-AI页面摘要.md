## 一、方案概述

一键获取当前网页的 AI 摘要：提取正文→发送到 YiAi→展示摘要。

### 流程

```
1. 用户点击「摘要」按钮
2. Content Script 提取页面正文 (document.body.innerText)
3. 截断到 4000 tokens
4. 发送到 YiAi chat_service
5. SSE 流式返回摘要
```

### 摘要格式

| 字段 | 说明 |
|------|------|
| 一句话总结 | 全文核心内容 |
| 要点 | 3-5 个关键点 |
| 标签 | 自动提取标签 |
