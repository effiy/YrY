## 一、方案概述

一键获取当前网页的 AI 摘要：提取正文→发送到 YiAi→展示摘要。

### 流程

```
1. 用户点击「摘要」按钮
2. Content Script 提取页面正文 (document.body.innerText)
3. 截断到 4000 tokens
4. 发送到 YiAi chat_service
5. SSE 流式返回摘要
```

### 摘要格式

| 字段 | 说明 |
|------|------|
| 一句话总结 | 全文核心内容 |
| 要点 | 3-5 个关键点 |
| 标签 | 自动提取标签 |

## 一、需求背景

来源 PRD：130-功能实现-AI页面摘要.md

### 用户痛点

1. **长文章阅读效率低，用户需要手动总结**：用户阅读 5000 字技术文章，想知道核心观点
1. **摘要操作步骤多，打断阅读流**：用户需要选中全文 → 复制 → 打开聊天 → 粘贴 → 输入总结指令
1. **同一页面重复摘要浪费资源**：用户在会话中多次返回同一页面，每次都需要重新生成摘要
