## 一、方案概述

SSE 流式连接稳定性增强：自动重连（指数退避）、断点续传、AbortSignal 清理。

### 增强项

| 增强 | 说明 |
|------|------|
| 自动重连 | 断连后指数退避重连（1s→2s→4s→8s，max 30s） |
| 断点续传 | 从最后接收的 token 位置继续 |
| AbortSignal 清理 | 页面关闭/组件卸载时取消 SSE |
| 错误传播 | `done` 帧携带 `error` 字段 |

### 实施步骤

| 步骤 | 内容 |
|------|------|
| 1 | 自动重连 + 指数退避 |
| 2 | AbortSignal + 断点续传 |
| 3 | 错误传播链路 |
