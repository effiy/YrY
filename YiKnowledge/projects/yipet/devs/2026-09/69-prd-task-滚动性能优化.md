## 优化策略

| 策略 | 说明 |
|------|------|
| passive 监听 | `{passive:true}` 避免阻塞滚动 |
| 节流 scroll | `requestAnimationFrame` 节流 |
| contain 布局 | `contain: strict` 限制重排范围 |
| 虚拟滚动 | 长列表仅渲染可视区 |
| will-change | 预提升合成层 |
