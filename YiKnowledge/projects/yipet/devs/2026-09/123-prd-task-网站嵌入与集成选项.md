## 一、需求背景

来源 PRD：123-功能实现-网站嵌入与集成选项.md

### 用户痛点

1. **触达范围受限**：网站访客无法使用 YiPet
1. **无法嵌入外部网站**：博客/文档站需要 AI 助手
1. **无标准化集成方式**：开发者不知如何集成

| 方式 | 说明 |

| 步骤 | 任务 |

| 2 | UI 组件开发 + Popup/Side Panel 集成 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
