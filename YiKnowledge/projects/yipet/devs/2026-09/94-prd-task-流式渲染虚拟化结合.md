# YP-09-87: 流式渲染虚拟化结合 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-87 · 状态：待开始

## 虚拟化+

流式渲染 + 虚拟滚动：新消息自动滚动到底 + 旧消息虚拟化。

| 场景 | 策略 |
|------|------|
| 新消息 | 自动滚底，渲染最新 N 条 |
| 历史消息 | 虚拟滚动，仅渲染可视区 |
| 大消息 | 内容截断 + 展开按钮 |
