## 虚拟化+

流式渲染 + 虚拟滚动：新消息自动滚动到底 + 旧消息虚拟化。

| 场景 | 策略 |
|------|------|
| 新消息 | 自动滚底，渲染最新 N 条 |
| 历史消息 | 虚拟滚动，仅渲染可视区 |
| 大消息 | 内容截断 + 展开按钮 |
