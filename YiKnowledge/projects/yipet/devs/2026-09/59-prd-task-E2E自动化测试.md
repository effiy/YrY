## 一、方案概述

Playwright/Puppeteer E2E 测试：扩展加载 → 注入验证 → 聊天消息 → 跨项目桥接。

### 测试场景

| 场景 | 验证点 |
|------|--------|
| 扩展加载 | Popup 渲染正常 |
| Content Script | Pet 注入 + 可见 |
| 聊天 | 发送消息 → SSE 流式接收 |
| 桥接 | YiPet → YiVad 跳转 |

### 测试命令

```bash
npm run test:e2e  # Playwright 自动化
```
