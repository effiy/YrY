> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

<a id="sec-1"></a>
## 一、方案概述

每条消息显示 Token 消耗：输入/输出/总 Token，成本估算，会话累计。

### Token 展示

| 位置 | 内容 |
|------|------|
| 消息底部芯片 | `📊 234 tokens · ¥0.001` |
| 会话顶部 | 累计 Token + 估算成本 |
| 设置页面 | 按模型/日期统计图表 |

> 低优先级。
