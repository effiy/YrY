# YP-09-120: 自定义 CSS 主题 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-120 · 状态：方案已编写

## 主题自定义

用户编写自定义 CSS 覆盖 Chat Window 和 Floating Pet 样式。

| 功能 | 说明 |
|------|------|
| CSS 编辑器 | CodeMirror 语法高亮 |
| 实时预览 | 输入即预览 |
| 预设主题 | 社区共享主题 |
| 安全限制 | 仅允许 CSS 属性白名单 |

---

## 一、需求背景

来源 PRD：127-功能实现-自定义CSS主题.md

### 用户痛点

1. **用户无法自定义视觉风格，个性化体验差**：用户希望将聊天窗口改为粉色系，但只能选深色/浅色
1. **主题在不同网页上表现不一致**：深色主题在深色背景网页上文字不可见
1. **部分主题色对比度不足，无障碍体验差**：浅灰文字在白色背景上难以辨认

## 二、功能实现

| 功能 | 实现方案 |

| 实时预览 | 输入即预览 |

| 安全限制 | 仅允许 CSS 属性白名单 |
| 步骤 | 任务 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
