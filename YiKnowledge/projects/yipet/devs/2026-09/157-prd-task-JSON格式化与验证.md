## 一、需求背景

来源 PRD：157-功能实现-JSON格式化与验证.md

### 用户痛点

1. **格式化效率低**：查看 API 响应时需要格式化 JSON
1. **字段定位困难**：深层嵌套 JSON 中查找特定字段
1. **结构验证缺失**：不知道 JSON 是否符合接口定义
