# YP-09-33: 图片粘贴拖拽上传 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-33

## 上传方式

| 方式 | 事件 | API |
|------|------|-----|
| Ctrl+V 粘贴 | `paste` 事件 | `e.clipboardData.files` |
| 拖拽上传 | `drop` 事件 | `e.dataTransfer.files` |
| 点击上传 | `click` 事件 | `input[type=file]` |

## 上传限制

| 限制 | 值 |
|------|-----|
| 最大大小 | 10MB |
| 允许类型 | image/png, image/jpeg, image/webp, image/gif |
