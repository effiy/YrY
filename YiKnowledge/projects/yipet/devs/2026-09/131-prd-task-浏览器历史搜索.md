# YP-09-124: 浏览器历史搜索 — 开发方案

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

> 需求编号：YP-09-124 · 状态：方案已编写

## 历史搜索

`chrome.history.search` 全文检索浏览历史。

| 功能 | API |
|------|-----|
| 关键词搜索 | `chrome.history.search({text})` |
| 时间范围 | `startTime/endTime` |
| 最近访问 | `chrome.history.getVisits` |
| 删除记录 | `chrome.history.deleteUrl` |

---

## 一、需求背景

来源 PRD：131-功能实现-浏览器历史搜索.md

### 用户痛点

1. **找不到之前浏览过的页面，只能凭记忆翻找**：用户想找回上周看过的技术文章，但不记得标题
1. **关键词搜索匹配不到语义相关的结果**：搜索"状态管理"，不匹配标题为"React 数据流方案"的页面
1. **历史记录分散，无法按主题浏览**：用户想回顾"最近一个月关于 AI 的所有浏览记录"

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 关键词搜索 | `chrome.history.search({text})` |
| 时间范围 | `startTime/endTime` |
| 最近访问 | `chrome.history.getVisits` |
| 删除记录 | `chrome.history.deleteUrl` |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |
| 2 | UI 组件开发 + Popup/Side Panel 集成 |
| 3 | 边界场景处理 + 集成验证 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
