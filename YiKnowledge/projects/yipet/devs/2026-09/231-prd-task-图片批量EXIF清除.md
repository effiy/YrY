## 一、需求背景

来源 PRD：231-功能实现-图片批量EXIF清除.md

### 用户痛点

1. **GPS 坐标泄露位置隐私**：在家中拍照片——分享到社交平台——暴露住址
1. **设备序列号可追踪**：敏感场景——多张照片关联到同一相机——构建用户画像
1. **时间线暴露行程**：拍摄时间序列暴露何时在家/何时外出

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 批量清除 | 移除全部 EXIF/IPTC/XMP |

| 隐私保护 | 移除 GPS 位置信息 |
| 步骤 | 任务 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
