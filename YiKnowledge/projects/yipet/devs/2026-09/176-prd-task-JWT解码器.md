## 一、需求背景

来源 PRD：176-功能实现-JWT解码器.md

### 用户痛点

1. **Token 调试流程繁琐**：联调 API 时需要查看 Token Claims
1. **Token 发送到第三方服务**：开发者将生产 Token 粘贴到 jwt.io
1. **过期时间不直观**：排查 401 错误时不确定 Token 是否过期

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 解码 | Base64 解码 Header+Payload |
| 验证 | 签名验证(需密钥) |
| 过期检测 | exp 字段检查 |
| 格式化 | JSON 美化展示 |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |
| 2 | UI 组件开发 + Popup/Side Panel 集成 |
| 3 | 边界场景处理 + 集成验证 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|

| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
