## 一、需求背景

来源 PRD：168-功能实现-邮件模板预览器.md

### 用户痛点

1. **HTML 邮件调试效率低**：每次修改→复制到邮件客户端→发送→检查
1. **响应式布局验证困难**：需要至少 2 台真实设备
1. **垃圾邮件评分不可见**：邮件进垃圾箱后才知道问题

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| HTML 编辑 | 编辑邮件 HTML |
| 实时预览 | iframe 沙箱渲染 |
| 响应式 | 桌面/移动端切换 |
| 发送测试 | 发送到指定邮箱 |
| 步骤 | 任务 |

| 2 | UI 组件开发 + Popup/Side Panel 集成 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
