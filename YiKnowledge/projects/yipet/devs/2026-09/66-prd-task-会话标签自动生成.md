## 一、需求背景

来源 PRD：66-架构设计-会话标签自动生成.md

### 用户痛点

1. **标签为空率 > 80%——大多数会话无标签**：高
1. **手动标签质量参差不齐——用户随意填写**：中
1. **AI 标签可能不准确——LLM 理解偏差**：低

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 标签类型 | 示例 |
| 技术栈 | Vue, React, Python |

| 步骤 | 任务 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
