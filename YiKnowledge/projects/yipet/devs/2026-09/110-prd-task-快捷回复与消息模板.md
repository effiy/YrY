<a id="sec-1"></a>
## 一、方案概述

预设回复模板一键发送，用户可自定义模板。

### 内置模板

| 模板 | 内容 |
|------|------|
| 翻译 | 请将以下内容翻译成中文 |
| 总结 | 请总结以下内容的要点 |
| 代码审查 | 请审查以下代码并给出建议 |
| 解释 | 请用简单的语言解释以下概念 |

### 自定义

用户可创建/编辑/删除个人模板，持久化到 chrome.storage。
