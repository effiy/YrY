## 资源管理

| 资源类型 | 生命周期 |
|---------|---------|
| Event Listener | 组件挂载注册 → 卸载移除 |
| MutationObserver | 页面加载创建 → 页面卸载 disconnect |
| AbortController | 请求发起创建 → 完成/卸载 abort |
| setInterval | 组件挂载启动 → 卸载 clearInterval |
| WebSocket | 页面加载连接 → 页面卸载 close |
