## 一、方案概述

导出会话为 Markdown/JSON，支持跨设备迁移。

### 导出格式

| 格式 | 用途 |
|------|------|
| Markdown | 人类可读，导入 YiKnowledge |
| JSON | 机器可读，跨设备迁移 |
| HTML | 浏览器可直接查看 |

### 导入

从 JSON 文件恢复会话到 chrome.storage。

## 一、需求背景

来源 PRD：105-功能实现-会话导出与迁移.md

### 用户痛点

1. **切换设备/重装扩展后会话丢失**：用户重装 Chrome 后发现所有对话消失
1. **无法将对话整合到笔记系统**：用户想将 AI 回复保存到 Obsidian
1. **无法从其他 AI 工具迁移**：从 ChatGPT 迁移到 YiPet 的用户
