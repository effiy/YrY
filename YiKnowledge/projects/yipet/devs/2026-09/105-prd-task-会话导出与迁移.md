## 一、方案概述

导出会话为 Markdown/JSON，支持跨设备迁移。

### 导出格式

| 格式 | 用途 |
|------|------|
| Markdown | 人类可读，导入 YiKnowledge |
| JSON | 机器可读，跨设备迁移 |
| HTML | 浏览器可直接查看 |

### 导入

从 JSON 文件恢复会话到 chrome.storage。
