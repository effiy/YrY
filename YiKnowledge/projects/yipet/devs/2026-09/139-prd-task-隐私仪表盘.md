## 一、需求背景

来源 PRD：139-功能实现-隐私仪表盘.md

### 用户痛点

1. **用户隐私不透明**：用户无法了解 YiPet 数据存储情况
1. **Chrome Web Store 合规风险**：隐私实践标签不达标导致审核不通过
1. **用户无法管理数据**：想清理某个站点的聊天记录但无操作方法

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 数据查看 | 扩展收集了哪些数据 |
| 数据删除 | 一键清除所有本地数据 |
| 权限审计 | 当前已授权的权限列表 |
| 遥测开关 | 开启/关闭匿名统计 |
| 步骤 | 任务 |

| 2 | UI 组件开发 + Popup/Side Panel 集成 |
| 3 | 边界场景处理 + 集成验证 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
