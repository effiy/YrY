## 一、方案概述

Tree Shaking 优化 + 动态导入 + vendor chunk 分离。

### 优化项

| 优化 | 预期收益 |
|------|---------|
| Element Plus 按需导入 | -200KB |
| marked/DOMPurify 动态导入 | 首屏 -80KB |
| Vendor chunk 分离 | 缓存命中率 ↑ |
| CSS 提取 | 减少 JS 体积 |
