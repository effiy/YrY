## 一、需求背景

来源 PRD：58-架构设计-资源优先级调度.md

### 用户痛点

1. **无网络感知——在 2G 网络下仍尝试 SSE 重连，浪费带宽和电量**：中
1. **无 CPU 负载感知——无法区分"页面空闲"和"页面繁忙"**：中
1. **资源消耗无优先级——动画、SSE、Markdown 渲染同等优先级**：中

## 二、功能实现

| 功能 | 实现方案 |
|------|----------|
| 优先级 | 资源 |
| Critical | Pet CSS/图片 |
| High | Vue/ElementPlus |
| Medium | Chat CSS |
| Low | 工具/特效 |
| 步骤 | 任务 |
| 1 | Composable 核心逻辑开发与单元测试 |
| 2 | UI 组件开发 + Popup/Side Panel 集成 |

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |

## 四、实施步骤

**总计：0.3d**
