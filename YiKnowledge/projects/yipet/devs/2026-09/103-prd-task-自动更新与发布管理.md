> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

<a id="sec-1"></a>
## 一、方案概述

Chrome Web Store 自动更新 + 版本检测 + 发布说明。

| 功能 | 说明 |
|------|------|
| 版本检测 | `chrome.runtime.onInstalled` 检测升级 |
| 更新日志 | 版本间 CHANGELOG 展示 |
| 强制更新 | 关键安全修复强制升级 |
| 灰度发布 | 百分比分阶段推送 |
