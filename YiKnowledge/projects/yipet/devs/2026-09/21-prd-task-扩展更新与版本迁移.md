<a id="sec-1"></a>
## 一、方案概述

扩展更新检测 + 数据迁移 + 更新日志展示。

### 更新流程

```
chrome.runtime.onInstalled → 检测版本变化
  ├── install: 首次安装 → 初始化默认配置
  ├── update: 版本升级 → 执行数据迁移
  └── 显示更新日志 (WhatsNew)
```

### 迁移脚本

版本间 storage 数据结构变化时执行迁移：`v1.0 → v1.1: 新增字段默认值`
