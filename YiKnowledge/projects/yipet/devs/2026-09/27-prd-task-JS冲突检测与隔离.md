<a id="sec-1"></a>
## 一、方案概述

检测宿主页面 JS 与 YiPet 的冲突：全局变量覆盖、原型链污染、事件监听器冲突。

### 检测项

| 冲突类型 | 检测方式 | 处理 |
|---------|---------|------|
| 全局变量 | `window` 属性覆盖检测 | Shadow DOM + IIFE 隔离 |
| 原型链 | `Array.prototype` 检查 | 不使用被污染的 API |
| 事件冲突 | `addEventListener` 重复 | namespace 前缀 `yipet:` |

### 隔离策略

Shadow DOM + IIFE + Symbol 私有属性 + WeakMap 避免内存冲突
