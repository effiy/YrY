## 一、需求背景

来源 PRD：208-功能实现-剪切板历史管理.md

### 用户痛点

1. **覆盖丢失已复制内容**：复制了一段重要文本→复制 URL→文本永久丢失
1. **跨应用重复复制**：VS Code 复制代码→浏览器粘贴→VS Code 再复制→来回切换
1. **常用内容重复复制**：每天复制 10 次公司邮箱——每次都从签名中复制

## 三、关键技术决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 纯前端浏览器 API 实现 | 无需服务端依赖，响应 < 50ms，离线可用 |
| 2 | 独立 Vue 3 Composable 封装 | 单一职责，可复用于 Popup + Side Panel |
