## 一、方案概述

聊天窗口交互增强：窗口拖拽调整大小、侧边栏拖拽宽度、消息操作（编辑/删除/重新生成）。

### 交互增强

| 功能 | 说明 |
|------|------|
| 窗口拖拽 | 顶部边缘拖拽调整窗口大小和位置 |
| 侧边栏拖拽 | 左右拖拽调整侧边栏宽度 |
| 消息操作 | 编辑/删除/重新生成/复制 |
| 快捷回复 | 预设回复模板一键发送 |

### 实施步骤

| 步骤 | 内容 |
|------|------|
| 1 | 窗口拖拽 (mousedown/mousemove/mouseup) |
| 2 | 侧边栏宽度拖拽 |
| 3 | 消息操作菜单 |
