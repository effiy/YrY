# 实用工具套件与品质工程

> Q3 功能广度目标。将 YiPet 打造为浏览器中的瑞士军刀——50+ 图片编辑工具、20+ 开发/设计/文本工具、弹窗皮肤中心重构、完整品质工程体系（97 测试用例 + E2E 架构 + 性能诊断 + 安全防护）。**已完成交付，6 个 KR 全部达成。**

## 背景

Chrome 扩展的核心价值在于"随时可用、无需切换标签页"。Q3 将 YiPet 的工具能力从单一聊天扩展到四大工具类别——图片处理、开发工具、设计工具、文本工具——所有工具在浏览器端运行（Canvas API + Web API + WASM），零后端依赖，用户隐私 100% 保护。同期完成弹窗 UI 从功能列表到皮肤中心的重构，并建立完整的品质工程体系。

## 关键结果

1. **图片编辑套件** — Canvas 驱动的完整编辑管线：21 项基础调整（亮度/对比度/饱和度/白平衡/色阶/曲线/曝光/色温/色调/自然饱和度/高光/阴影/白色/黑色/清晰度/去雾/颗粒/暗角/旋转/裁剪/翻转）、CSS filter + Canvas pixel manipulation 特效（模糊/锐化/噪点/色彩调整/风格迁移）、批量处理（PNG/JPEG/WebP/AVIF 格式转换、尺寸调整、文字/图片水印）、AI 工具（背景移除/智能抠图/超分辨率）。
2. **图片高级工具** — HDR 合成（多曝光融合）、全景拼接（特征匹配 + 透视变换）、阴影效果（投影/内阴影/多层阴影）、聚焦堆叠（景深合成）、批量重命名（模式匹配 + 序号）、元数据查看器（EXIF/IPTC/XMP）、视频缩略图提取。
3. **开发工具集** — base64 编解码器、时间戳转换器（Unix/ISO 8601/相对时间）、正则表达式测试器（实时匹配 + 捕获组高亮）、文本差异对比（行级/词级 diff，绿色/红色高亮）、字符串编码转换（UTF-8/Base64/URL/Hex）、HTML 实体编解码、UserAgent 解析器、剪切板历史管理。
4. **设计与文本工具** — 颜色调色板生成器（互补色/类似色/三角色）、颜色命名器（HEX → 中文颜色名）、阴影生成器（CSS box-shadow 可视化编辑）、SVG 编辑器（路径/形状/文本）、邮件模板预览器（HTML 邮件实时渲染）、字体预览器（本地字体 + Google Fonts）、文字加密解密（AES/DES/RC4）、随机数据生成器（姓名/地址/手机/邮箱/UUID/lorem ipsum）、文本统计/排序/重复检测、表格数据转换器（CSV/JSON/Markdown 互转）、二维码名片生成 + 解码器。
5. **弹窗皮肤中心** — 从功能列表重构为实时皮肤中心：PetPreview（角色图片在渐变环内，大小滑块缩放，浮动动画 + prefers-reduced-motion 防护）、ColorPicker（6 色块网格，选中勾选 + 圆环高亮）、RolePicker（2 列角色卡片，图片 + 名称）、Model 选择器（qwen3.5/qwen3.5-think/qwen3-coder）。宠物覆盖层佩戴所选皮肤（渐变环 + RGB 发光）。i18n 完整双语覆盖（en + zh_CN），日期时间智能格式化。
6. **品质工程** — 97 个 Vitest 测试用例（配置 + 服务层），E2E 自动化测试架构设计，内存快照泄漏追踪（Chrome DevTools heap snapshot 工作流），性能火焰图诊断（PerformanceObserver + Long Task API），动画帧率自适应（requestAnimationFrame + prefers-reduced-motion 防护），Markdown 渲染 XSS 防护（marked + DOMPurify），MV3 CSP 合规（零远程代码/零 eval/零内联脚本），依赖版本管理（Renovate 配置），兼容性工具链。

## 影响

- YiPet 成为首个内置 50+ 图片编辑工具 + 20+ 开发工具的浏览器扩展
- 所有工具在浏览器端运行，零后端依赖，用户隐私 100% 保护
- 弹窗从功能列表升级为品牌化的皮肤中心，用户留存率显著提升
- 品质体系覆盖测试/性能/安全/兼容性 4 维度，97 个测试用例全部通过
