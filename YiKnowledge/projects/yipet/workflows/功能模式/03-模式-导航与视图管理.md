# 导航与视图管理

> Chat Window 内部导航体系：侧边栏视图切换、会话路由、深度链接、模态管理、视图状态持久化。

**相关文档**：[Chat Store](./01-模式-ChatStore状态管理.md) · [核心模块](../架构设计/05-架构-核心模块.md) · [组件规范](../开发规范/09-规范-组件规范.md)

## 一、导航模型

Chat Window 是单窗口 SPA，内部通过侧边栏切换功能区：

```
ChatWindow（布局容器）
├── ChatSidebar（侧边栏导航）
│   ├── Tab: sessions / knowledge / stories / bugs
│   └── 视图内容区
├── ChatMain（主内容区）
│   ├── ChatHeader → ChatMessages → ChatInput
└── 模态叠加层（BugReport, KnowledgePreview, SaveToKnowledge, SessionEdit, SessionSummary）
```

## 二、侧边栏视图

| 视图 | 数据源 | 加载时机 | 搜索 | 持久化状态 |
|------|--------|----------|------|-----------|
| `sessions` | YiAi → MongoDB | 侧边栏打开 | 按标题 | `currentSessionId`, 滚动位置 |
| `knowledge` | YiAi → YiKnowledge | 切换视图 | 按文件名 | 展开节点, `ragScope` |
| `stories` | YiAi → MongoDB | 切换视图 | 按标题 | 排序方式 |
| `bugs` | YiAi → MongoDB | 切换视图 | 按严重度/状态 | 过滤条件 |

## 三、会话路由

```
无会话 → 首条消息自动创建 / 点击"+"手动创建
会话列表 → 点击切换 / 右键重命名/删除/导出
当前会话 → 发送消息自动标题 / 删除自动切换到最近会话
```

切换前先 `_persistSession()` 保存当前会话，再加载目标。

## 四、深度链接

支持 URL 参数跨项目桥接：

| 参数 | 示例 | 行为 |
|------|------|------|
| `session` | `#session=abc123` | 切换到指定会话 |
| `view` | `#view=knowledge` | 切换侧边栏视图 |
| `file` | `#file=projects/yivad/specs.md` | 打开知识文件 |
| `bug` | `#bug=bug-key-456` | 打开缺陷详情 |
| `chat` | `#chat` | 打开聊天窗口 |

**跨项目桥接**：`window.open(YiVAD_URL + '/aiChat?session=' + sessionKey)` → YiVad 加载会话。

## 五、模态管理

z-index 层级：1000（ChatWindow）→ 2000（侧边栏）→ 3000（遮罩）→ 4000（BugReportDialog）→ 5000（通知）。

ModalStack 管理焦点和关闭顺序：打开推入栈顶 → 关闭弹出 → 焦点始终在最上层。Esc 关闭当前模态，无模态时隐藏聊天窗口。

| 模态 | 触发 | 大小 | 关闭 |
|------|------|------|------|
| BugReportDialog | 快捷键/菜单 | 600×500 | ESC/遮罩/提交 |
| KnowledgePreview | 点击文件 | 自适应 | ESC/外部点击 |
| SessionEdit | 双击标题 | 400×300 | 保存/取消 |

## 六、键盘导航

| 快捷键 | 作用域 | 行为 |
|--------|--------|------|
| `Ctrl+Shift+X` | 全局 | 切换聊天窗口 |
| `Esc` | 聊天窗口 | 关闭模态 / 隐藏窗口 |
| `Ctrl+N` | 聊天窗口 | 新建会话 |
| `Ctrl+Shift+K` | 聊天窗口 | 切换知识库 |
| `Ctrl+1-4` | 聊天窗口 | 切换侧边栏视图 |
| `Ctrl+B` | 聊天窗口 | 切换侧边栏 |

## 七、视图状态持久化

| 状态 | 存储键 | 默认值 |
|------|--------|--------|
| 侧边栏视图 | `sidebarView` | `"sessions"` |
| 侧边栏展开 | `sidebarCollapsed` | `false` |
| 侧边栏宽度 | `sidebarWidth` | `280` |
| 聊天可见性 | `chatVisible` | `false` |
| 知识库开关 | `knowledgeGrounded` | `false` |

启动时从 `chrome.storage.local` 恢复，每次变更时持久化。

## 八、反模式

| 反模式 | 正确做法 | 原因 |
|--------|----------|------|
| 视图切换不持久化 | 同时写 `chrome.storage` | 刷新丢失 |
| z-index 硬编码 | ModalStack 管理 | 多模态层级混乱 |
| 深度链接不处理 | `handleDeepLink()` 解析 | 跨项目桥接失效 |
| 会话切换不保存 | 先 `_persistSession()` 再切 | 当前会话丢失 |

## 九、约束

**必须**：侧边栏状态持久化、会话切换前保存、深度链接初始化解析、ModalStack 管理 z-index、Esc 关闭当前模态。

**禁止**：硬编码 z-index、忽略 URL hash 深度链接、会话切换丢弃未保存消息、多模态同时抢占焦点。
