# 导航与视图管理

> Chat Window 内部导航体系：侧边栏视图切换、会话路由、深度链接、模态叠加、视图状态持久化。

## 一、导航模型

Chat Window 是一个单窗口 SPA，内部通过侧边栏切换不同功能区：

```
ChatWindow（布局容器）
├── ChatSidebar（侧边栏导航）
│   ├── 视图切换 Tab
│   │   ├── sessions（会话列表）
│   │   ├── knowledge（知识库目录树）
│   │   ├── stories（故事板）
│   │   └── bugs（缺陷列表）
│   └── 视图内容区
│       ├── SessionListItem（会话搜索 + 虚拟滚动）
│       ├── KnowledgeSidebar（目录树 + 文件预览）
│       ├── Stories 标签页（故事卡片）
│       └── Bugs 标签页（缺陷列表）
├── ChatMain（主内容区）
│   ├── ChatHeader（会话标题 + 操作按钮）
│   ├── ChatMessages（消息列表）
│   └── ChatInput（输入框）
└── 模态叠加层
    ├── BugReportDialog（Bug 报告弹窗）
    ├── KnowledgePreviewDialog（知识文件预览）
    ├── SaveToKnowledgeDialog（保存到知识库）
    └── SessionEditDialog / SessionSummaryDialog（会话编辑/摘要）
```

## 三、会话路由

### 会话生命周期导航

```
无会话（空状态）
  │ 用户发送第一条消息 → 自动创建会话
  └── 用户点击 "+" → 手动创建会话

会话列表
  │ 点击会话 → 切换到该会话
  │ 右键 → 重命名 / 删除 / 导出
  └── 搜索 → 过滤会话列表

当前会话
  │ 发送消息 → 自动生成标题（首条消息）
  │ 切换知识库开关 → 改变聊天模式
  │ 切换 RAG 范围 → 限制检索范围
  └── 删除当前会话 → 自动切换到最近会话
```

### 会话切换导航

```typescript
async function selectSession(id: string): Promise<void> {
  if (id === currentSessionId.value) return;

  // 保存当前会话
  if (currentSessionId.value) {
    await _persistSession();
  }

  // 加载目标会话
  const session = await api.session.getByKey(id);
  currentSessionId.value = id;
  messages.value = session.messages || [];
  title.value = session.title;

  // 滚动到底部
  _scrollToBottom();
}
```

## 四、深度链接

### 跨项目桥接导航

YiPet 通过 URL 参数支持跨项目深度链接：

```
YiVad → YiPet:
  window.open("http://target-page.com#yipet:chat?session=xxx")

YiPet 内部:
  Chat Store（Pinia）解析 URL hash → 自动加载指定会话
```

### 深度链接参数

| 参数 | 格式 | 说明 | 示例 |
|------|------|------|------|
| `session` | `?session=<id>` | 自动加载指定会话 | `#yipet:chat?session=abc123` |
| `context` | `?context=<url>` | 设置页面上下文 | `#yipet:chat?context=https://example.com` |
| `mode` | `?mode=rag` | 设置聊天模式 | `#yipet:chat?mode=rag&scope=engineer/` |
| `bug` | `?bug=<id>` | 打开 Bug 报告弹窗 | `#yipet:chat?bug=BUG-001` |

### 深度链接实现

```typescript
// src/chat/stores/chat.ts
async function handleDeepLink(): Promise<void> {
  const hash = window.location.hash;
  if (!hash.startsWith("#yipet:")) return;

  const [, command] = hash.split(":");
  const params = new URLSearchParams(hash.split("?")[1] || "");

  switch (command) {
    case "chat": {
      const sessionId = params.get("session");
      const contextUrl = params.get("context");
      const mode = params.get("mode");

      if (sessionId) {
        await selectSession(sessionId);
      }
      if (contextUrl) {
        contextEnabled.value = true;
        contextEditorDraft.value = contextUrl;
      }
      if (mode === "rag") {
        knowledgeGrounded.value = true;
        ragScope.value = params.get("scope") || "";
      }

      chatVisible.value = true;
      break;
    }
    case "bug": {
      const bugId = params.get("bug");
      if (bugId) {
        chatVisible.value = true;
        sidebarView.value = "bugs";
        selectedBugId.value = bugId;
      }
      break;
    }
  }
}
```

## 五、模态叠加层

### 模态管理

Chat Window 中可能同时存在多个模态层，需管理 z-index 和焦点：

```
z-index 层级:
  1000 — ChatWindow 基础层
  2000 — 侧边栏
  3000 — 模态遮罩
  4000 — BugReportDialog
  5000 — 全局通知
```

### 模态栈

```typescript
// 模态管理器
class ModalStack {
  private stack: Modal[] = [];

  open(modal: Modal): void {
    this.stack.push(modal);
    this._updateFocus();
  }

  close(modalId: string): void {
    this.stack = this.stack.filter(m => m.id !== modalId);
    this._updateFocus();
  }

  private _updateFocus(): void {
    // 焦点始终在最上层模态
    const topModal = this.stack[this.stack.length - 1];
    if (topModal) {
      topModal.focus();
    }
  }
}
```

### 模态类型

| 模态 | 触发方式 | 大小 | 关闭方式 | 嵌套模态 |
|------|----------|------|----------|----------|
| `BugReportDialog` | 键盘快捷键 / 菜单 | 600×500px | ESC / 点击遮罩 / 提交后 | 否 |
| `ContextFilesPanel` | 侧边栏按钮 | 侧边栏内部 | 切换视图 / 关闭按钮 | 否 |
| `RagSourcesPreviewDialog` | 输入框按钮 | 400×500px | ESC / 点击外部 | 是 |
| `SessionEditDialog` | 双击会话标题 | 400×300px | 保存 / 取消 | 是 |

## 六、视图状态持久化

### 持久化键

| 状态 | 存储键 | 类型 | 默认值 |
|------|--------|------|--------|
| 侧边栏视图 | `sidebarView` | `SidebarView` | `"sessions"` |
| 侧边栏展开 | `sidebarCollapsed` | `boolean` | `false` |
| 侧边栏宽度 | `sidebarWidth` | `number` | `280` |
| 当前会话 | `currentSessionId` | `string \| null` | `null` |
| 聊天可见性 | `chatVisible` | `boolean` | `false` |
| 知识库开关 | `knowledgeGrounded` | `boolean` | `false` |
| RAG 范围 | `ragScope` | `string` | `""` |

### 状态恢复

```typescript
async restoreNavigationState(): Promise<void> {
  const result = await chrome.storage.local.get([
    "sidebarView",
    "sidebarCollapsed",
    "sidebarWidth",
    "currentSessionId",
    "chatVisible",
    "knowledgeGrounded",
    "ragScope",
  ]);

  sidebarView.value = result.sidebarView || "sessions";
  sidebarCollapsed.value = result.sidebarCollapsed ?? false;
  sidebarWidth.value = result.sidebarWidth || 280;
  currentSessionId.value = result.currentSessionId || null;
  chatVisible.value = result.chatVisible ?? false;
  knowledgeGrounded.value = result.knowledgeGrounded || false;
  ragScope.value = result.ragScope || "";

  // 恢复上次会话
  if (currentSessionId.value) {
    await selectSession(currentSessionId.value);
  }
}
```

## 八、反模式

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 视图切换不持久化 | 仅修改内存状态 | 同时写入 `chrome.storage.local` | 标签页刷新后丢失视图状态 |
| 模态 z-index 硬编码 | `style="z-index: 9999"` | 使用 ModalStack 管理 | 多模态叠加时层级混乱 |
| 深度链接不处理 | 忽略 URL hash 参数 | `handleDeepLink()` 解析并执行 | 跨项目桥接失效 |
| 会话切换不保存 | 直接替换 `state.messages` | 先 `_persistSession()` 再切换 | 当前会话未保存 |
| 侧边栏宽度硬编码 | `width: 280px` | 从 `chrome.storage` 恢复 + 用户拖拽调整 | 无法个性化 |

## 九、约束

### 必须遵守
- 侧边栏视图状态持久化到 `chrome.storage.local`
- 会话切换前先保存当前会话
- 深度链接参数在 Chat Store（Pinia）初始化时解析
- 模态使用 ModalStack 管理 z-index 和焦点
- Esc 键关闭当前模态，无模态时隐藏聊天窗口

### 禁止
- 不硬编码 z-index 值
- 不忽略 URL hash 中的深度链接参数

## 十、深度链接实现

### 10.1 支持的深度链接参数

| 参数 | 示例 | 行为 |
|------|------|------|
| `session` | `#session=abc123` | 切换到指定会话 |
| `view` | `#view=knowledge` | 切换到指定侧边栏视图 |
| `file` | `#file=projects/yivad/specs.md` | 在知识库中打开指定文件 |
| `bug` | `#bug=bug-key-456` | 打开缺陷详情 |
| `chat` | `#chat` | 打开聊天窗口（如有隐藏） |

### 10.2 解析实现

```typescript
// src/chat/index.ts — 初始化时解析深度链接
function handleDeepLink(): void {
  const hash = window.location.hash.slice(1); // 去掉 #
  if (!hash) return;

  const params = new URLSearchParams(hash);

  if (params.has("session")) {
    const sessionId = params.get("session")!;
    chatStore.selectSession(sessionId);
    chatStore.chatVisible = true;
  }

  if (params.has("view")) {
    const view = params.get("view") as SidebarView;
    chatStore.setSidebarView(view);
  }

  if (params.has("file")) {
    const filePath = params.get("file")!;
    chatStore.setSidebarView("knowledge");
    chatStore.openKnowledgeFile(filePath);
  }

  if (params.has("bug")) {
    chatStore.openBugDetail(params.get("bug")!);
  }
}
```

## 十一、Modal 堆栈管理

### 11.1 堆栈实现

```typescript
// src/chat/utils/modalStack.ts
interface ModalEntry {
  id: string;
  zIndex: number;
  onClose: () => void;
}

class ModalStack {
  private stack: ModalEntry[] = [];
  private baseZIndex = 2000;

  open(id: string, onClose: () => void): number {
    const zIndex = this.baseZIndex + this.stack.length * 10;
    this.stack.push({ id, zIndex, onClose });
    return zIndex;
  }

  close(id: string): void {
    const index = this.stack.findIndex(m => m.id === id);
    if (index === -1) return;

    // 关闭当前及之上的所有 modal
    const removed = this.stack.splice(index);
    removed.forEach(m => m.onClose());
  }

  closeTop(): void {
    const top = this.stack.pop();
    top?.onClose();
  }

  get activeZIndex(): number {
    const top = this.stack[this.stack.length - 1];
    return top ? top.zIndex : this.baseZIndex;
  }

  get isModalOpen(): boolean {
    return this.stack.length > 0;
  }
}

export const modalStack = new ModalStack();
```
- 不在会话切换时丢弃未保存的消息
- 不让多个模态同时抢占焦点
