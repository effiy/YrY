# 构建依赖（运行时）

> YiPet 运行时依赖完整清单：核心框架、UI 组件库、工具库、CDN 资源。包含依赖关系图、选型理由、bundle 大小分析、替代方案对比。

## 一、依赖全景

### 运行时依赖关系

```
YiPet Extension
  │
  ├── Popup (src/popup/)
  │     ├── vue 3.5
  │     ├── pinia 4
  │     ├── element-plus 2.14
  │     └── @element-plus/icons-vue
  │
  ├── Chat Window (src/chat/)
  │     ├── vue 3.5 (通过 CDN 注入)
  │     ├── element-plus 2.14 (通过 CDN 注入)
  │     ├── marked 15 — Markdown 渲染
  │     ├── dayjs 1 — 日期格式化
  │     └── @vueuse/core 14 — 组合式工具
  │
  └── Content Script (src/content/)
        └── @vueuse/core 14 — 共享工具
```

### 依赖规模

| 层 | 包数量 | 体积影响 | 加载方式 |
|----|--------|----------|----------|
| 核心框架 | 2 | ~100KB gzip | npm bundle (Popup) / CDN 注入 (Chat) |
| UI 组件库 | 2 | ~200KB gzip | npm bundle (Popup) / CDN 注入 (Chat) |
| 工具库 | 3 | ~30KB gzip | npm bundle |
| CDN 资源 | 4 | 独立加载 | chrome.runtime.getURL |

### @vueuse/core 常用 API

| API | 用途 | 使用场景 |
|-----|------|----------|
| `useStorage` | localStorage 响应式绑定 | 持久化用户偏好设置 |
| `useEventListener` | 事件监听自动清理 | 快捷键监听、窗口事件 |
| `useMediaQuery` | 响应式媒体查询 | 暗色模式检测 |
| `useDebounceFn` | 防抖函数 | 搜索输入防抖 |
| `useThrottleFn` | 节流函数 | 滚动事件节流 |
| `useResizeObserver` | 元素尺寸监听 | Chat 窗口自适应 |
| `useIntersectionObserver` | 可见性检测 | 消息列表懒加载 |
| `useClipboard` | 剪贴板操作 | 复制消息内容 |
| `useTitle` | 页面标题 | 动态标题 |

### marked 使用示例

```typescript
import { marked } from 'marked';

// 配置渲染器
marked.setOptions({
  breaks: true,        // 换行符转 <br>
  gfm: true,           // GitHub Flavored Markdown
});

// 渲染 Markdown
const html = marked.parse(message.content);

// 流式渲染（增量更新）
const partialHtml = marked.parse(streamingContent);
```

### dayjs 使用示例

```typescript
import dayjs from 'dayjs';
import relativeTime from 'dayjs/plugin/relativeTime';
import 'dayjs/locale/zh-cn';

dayjs.extend(relativeTime);
dayjs.locale('zh-cn');

// 格式化时间
dayjs(message.created_at).format('YYYY-MM-DD HH:mm:ss');
dayjs(message.created_at).fromNow();  // "3 分钟前"
```

## 五、依赖说明

### 为什么选择这些依赖

| 依赖 | 选择理由 | 替代方案 | 为什么不选替代 |
|------|----------|----------|---------------|
| Vue 3.5 | 与 YiVad 共享技术栈 | React, Svelte | 团队技术栈统一，降低学习成本 |
| Element Plus 2.14 | 与 YiVad 一致 | Ant Design Vue, Naive UI | 与 YiVad 保持一致，减少跨项目样式差异 |
| Pinia 4 | 官方推荐、轻量级 | Vuex 4 | Vuex 已进入维护模式，Pinia 是官方替代 |
| marked 15 | 轻量级 Markdown 解析 | markdown-it, showdown | marked 最小、速度最快、GFM 支持好 |
| dayjs 1 | 2KB 轻量级 | moment.js, date-fns | moment.js 已停止维护且体积大；date-fns 需要额外配置 |
| @vueuse/core 14 | Vue 生态最佳实践 | 手写 composable | 避免重复造轮子，社区维护质量高 |

### 为什么不包含的常见依赖

| 未包含 | 原因 | 如果需要时 |
|--------|------|-----------|
| vue-router | 扩展内不需要路由（Popup 单页，Chat Window 单页） | 使用 hash 模式简单路由 |
| axios | 使用自定义 ApiClient（fetch 封装），更轻量且可控 | — |
| echarts | 扩展内不需要图表 | 按需引入 echarts 核心 |
| vue-i18n | 使用 `chrome.i18n` API 进行国际化 | — |
| React/Ant Design | 弹窗已从 React 迁移到 Vue 3 + Element Plus (2026-07-28) | — |
| lodash | 使用 @vueuse/core + 原生 ES 方法替代 | 按需引入 lodash-es |
| socket.io | SSE 流式传输，不需要 WebSocket 双向通信 | 如需要实时双向通信 |

## 六、CDN 资源（非 npm 依赖）

以下资源通过 CDN 注入到页面，不通过 npm 管理：

| 资源 | 用途 | 加载方式 | 大小 |
|------|------|----------|------|
| Vue 3 运行时 | Chat Window 渲染 | `chrome.runtime.getURL('cdn/vendor/vue@3.5.13/vue.global.prod.js')` | ~120KB |
| Bootstrap 5.2.3 | UI 组件 | `chrome.runtime.getURL('cdn/vendor/bootstrap@5.2.3/js/bootstrap.bundle.min.js')` | ~80KB |
| 全局样式 | 宠物皮肤、聊天窗口样式 | `chrome.runtime.getURL('cdn/styles/chat.css')` | ~10KB |
| 工具脚本 | API 客户端 + 工具函数 | `chrome.runtime.getURL('cdn/utils/index.js')` | ~5KB |

### CDN 资源加载策略

```
CDN 资源分为两类：

1. 关键资源（同步加载，阻塞渲染）
   ├── Vue 3 运行时 — Chat Window 必须
   ├── 全局样式 — 宠物皮肤必须
   └── 加载失败 → Chat Window 不初始化

2. 非关键资源（异步加载，不阻塞渲染）
   ├── Element Plus — UI 组件库
   ├── 工具脚本 — 辅助功能
   └── 加载失败 → 降级处理，不影响核心功能
```

### CDN 资源构建

```bash
# 构建 CDN 资源
npm run build:cdn

# 输出到 dist/cdn/
# ├── vue.js
# ├── element-plus.js
# ├── styles.css
# └── utils.js
```

## 七、Bundle 大小分析

### 各入口 Bundle 大小

| 入口 | 大小（gzip） | 主要内容 |
|------|-------------|----------|
| background.js | ~5KB | Service Worker 逻辑 |
| popup.js | ~150KB | Vue + Element Plus + Popup 逻辑 |
| content.js | ~10KB | Content Script 引导 |
| chat.js | ~80KB | Chat Store（Pinia）+ 工具库 |
| bootstrap.js | ~3KB | 注入脚本 |

### 体积优化策略

| 策略 | 效果 | 实现 |
|------|------|------|
| 按需导入 Element Plus | 减少 ~200KB | unplugin-vue-components 自动解析 |
| CDN 注入 Vue/Bootstrap 等 | Chat Window 不打包框架 | 独立构建，CDN 加载 |
| Tree Shaking | 移除未使用代码 | Rsbuild 生产模式自动启用 |
| 代码分割 | 并行加载 | Rsbuild 自动 splitChunks |
| Gzip 压缩 | 减少 60-70% | Rsbuild 生产模式自动启用 |

## 九、约束

### 必须遵守
- 运行时依赖通过 `package.json` 的 `dependencies` 管理
- Vue/Element Plus 在 Chat Window 中通过 CDN 注入，不在 bundle 中重复打包
- 新增依赖前评估体积影响（扩展对包体积敏感）
- 不在 Content Script 中引入大型依赖（保持在 10KB 以内）

### 禁止
- 不将开发依赖放入 `dependencies`
- 不在多个入口中重复打包相同的依赖
- 不引入需要 Node.js API 的依赖（扩展环境不支持）
- 不引入超过 500KB 的单个依赖
