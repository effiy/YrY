# 构建依赖（运行时）

> YiPet 运行时依赖：核心框架、UI 组件库、工具库、CDN 资源、选型理由、Bundle 体积。

## 一、依赖全景

```
YiPet Extension
  ├── Popup: vue 3.5 + pinia 4 + element-plus 2.14 + @element-plus/icons-vue
  ├── Chat Window: vue 3.5 (CDN) + element-plus 2.14 (CDN) + marked 15 + dayjs 1 + @vueuse/core 14
  └── Content Script: @vueuse/core 14
```

| 层 | 包数 | 体积 | 加载方式 |
|----|------|------|----------|
| 核心框架 | 2 | ~100KB gzip | npm (Popup) / CDN 注入 (Chat) |
| UI 组件库 | 2 | ~200KB gzip | npm (Popup) / CDN 注入 (Chat) |
| 工具库 | 3 | ~30KB gzip | npm bundle |

## 二、核心框架

| 包 | 版本 | 选型理由 |
|----|------|----------|
| vue | ^3.5.40 | 与 YiVad 共享技术栈、Composition API、SFC |
| pinia | ^4.0.2 | 官方推荐、轻量、TypeScript 友好、Setup Store 模式 |

**Pinia Store 结构**：`usePetStore`（角色/颜色/可见性/模型）、`useChatStore`（消息/会话/流式）、`useAuthStore`（Token/用户）、`useSettingsStore`（语言/主题/快捷键）。

## 三、UI 组件库

| 包 | 版本 | 选型理由 |
|----|------|----------|
| element-plus | ^2.14.3 | 与 YiVad 一致、中文友好、Vue 3 原生 |
| @element-plus/icons-vue | ^2.3.2 | 200+ 图标，按需引入 |

`unplugin-vue-components` 自动解析，模板中直接使用 `<ElButton>`、`<ElInput>` 等。

## 四、工具库

| 包 | 版本 | 用途 |
|----|------|------|
| @vueuse/core | ^14.3.0 | Vue Composition 工具集（useStorage/useEventListener/useDebounceFn/useResizeObserver 等） |
| dayjs | ^1.11.21 | 2KB 轻量日期处理，API 兼容 moment.js |
| marked | ^15.0.12 | Markdown 解析，GFM 支持，流式渲染友好 |

## 五、为什么不包含

| 未包含 | 原因 | 替代 |
|--------|------|------|
| vue-router | 扩展内无路由需求 | hash 参数简单路由 |
| axios | 自定义 ApiClient（fetch 封装）更轻量 | ApiClient |
| vue-i18n | `chrome.i18n` API 原生支持 | `t()` 封装 |
| lodash | @vueuse/core + 原生 ES 替代 | 按需 lodash-es |
| socket.io | SSE 流式传输，无需 WebSocket 双向通信 | SSE |

## 六、Bundle 体积（gzip）

| 入口 | 大小 | 内容 |
|------|------|------|
| background.js | ~5KB | SW 逻辑 |
| popup.js | ~150KB | Vue + Element Plus + Popup |
| content.js | ~10KB | CS 引导 |
| chat.js | ~80KB | Chat Store + 工具库 |
| bootstrap.js | ~3KB | 注入脚本 |

**优化**：按需导入 Element Plus（-200KB）、CDN 外部化 Vue/Bootstrap（Chat 不重复打包）、Tree Shaking（-20~30%）、Gzip（-60~70%）。

## 七、版本兼容矩阵

| 包 | 当前 | 最低 | 升级风险 |
|----|------|------|:---:|
| vue | 3.5.40 | 3.3.0 | 低 |
| pinia | 4.0.2 | 2.1.0 | 低 |
| element-plus | 2.14.3 | 2.5.0 | 中 |
| @vueuse/core | 14.3.0 | 10.0.0 | 低 |
| dayjs | 1.11.21 | 1.11.0 | 低 |
| marked | 15.0.12 | 5.0.0 | 低 |

## 八、CDN 资源（非 npm）

| 资源 | 加载方式 | 大小 |
|------|----------|------|
| Vue 3 运行时 | `chrome.runtime.getURL('cdn/vendor/vue@3.5.13/...')` | ~120KB |
| Bootstrap 5.2.3 | `chrome.runtime.getURL('cdn/vendor/bootstrap@5.2.3/...')` | ~80KB |
| 全局样式 | `chrome.runtime.getURL('cdn/styles/chat.css')` | ~10KB |
| 工具脚本 | `chrome.runtime.getURL('cdn/utils/index.js')` | ~5KB |

## 九、约束

**必须**：运行时依赖通过 `dependencies` 管理、Vue/Element Plus 在 Chat 中 CDN 注入不重复打包、新增依赖前评估体积、Content Script 不引入大型依赖（< 10KB）。

**禁止**：devDependencies 放入 dependencies、多入口重复打包同一依赖、引入需要 Node.js API 的依赖、单个依赖超过 500KB。
