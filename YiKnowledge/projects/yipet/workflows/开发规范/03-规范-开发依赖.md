## 一、依赖全景

```

  │
```

### 多入口构建配置

```typescript
// rsbuild.config.ts — 主配置
export default defineConfig({
  source: {
    entry: {
      background: './src/background/index.ts',
      popup: './src/popup/index.html',
      content: './src/content/index.ts',
    },
  },
  output: {
    copy: [
      { from: 'public', to: '.' },  // manifest.json, _locales, cdn/
    ],
  },
});

// rsbuild.config.chat.ts — 聊天窗口独立构建
export default defineConfig({
  source: {
    entry: { chat: './src/chat/index.html' },
  },
  plugins: [pluginVue(), pluginSass()],
});

// rsbuild.config.cdn.ts — CDN 资源构建
export default defineConfig({
  source: {
    entry: { cdn: './src/utils/cdn/index.ts' },
  },
  output: { distPath: { root: 'dist/cdn' } },
});

// rsbuild.config.bootstrap.ts — Bootstrap 脚本
export default defineConfig({
  source: {
    entry: { bootstrap: './src/content/bootstrap.ts' },
  },
  output: { distPath: { root: 'dist/content' } },
});
```

## 九、依赖升级指南

### 升级检查清单

| 步骤 | 操作 | 验证 |
|------|------|------|
| 1. 检查过时 | `npm outdated` | 查看可升级版本 |
| 2. 升级单个 | `npm install <package>@latest` | 避免批量升级 |
| 3. 类型检查 | `npm run typecheck` | 无新增错误 |
| 4. 代码检查 | `npm run lint` | 无新增错误 |
| 5. 构建验证 | `npm run build` | 构建成功 |
| 6. 扩展加载 | 在 Chrome 中加载测试 | 扩展正常工作 |

### 版本兼容注意事项

| 升级项 | 风险 | 注意 |
|--------|------|------|
| TypeScript 主版本 | 高 | 可能引入新的严格检查，先运行 `vue-tsc --noEmit` |
| ESLint 主版本 | 中 | 配置格式可能变化（flat config vs legacy） |
| Rsbuild 主版本 | 中 | 可能有 breaking changes，查阅 CHANGELOG |
| Vue 次版本 | 低 | 通常向后兼容，关注 deprecation 警告 |
| @types/chrome | 低 | 跟随 Chrome 版本更新 API 类型 |

### 安全漏洞检查

```bash
# npm 内置审计
npm audit

# 修复可自动修复的漏洞
npm audit fix

# 查看详细信息
npm audit --json
```

## 十、约束

### 必须遵守
- 所有开发依赖通过 `package.json` 的 `devDependencies` 管理
- 构建工具必须支持多入口（background, popup, content, chat, cdn, bootstrap）
- ESLint + Prettier + Stylelint 三件套配置完整
- 提交前通过 Husky + lint-staged 自动检查
- 类型定义文件（auto-imports.d.ts, components.d.ts）加入 `.gitignore`

### 禁止
- 不将开发依赖放入 `dependencies`（运行时依赖）
- 不在 pre-commit hook 中运行全量检查（仅检查暂存文件）
- 不跳过类型检查（`vue-tsc --noEmit` 必须通过）
- 不提交自动生成的类型定义文件
