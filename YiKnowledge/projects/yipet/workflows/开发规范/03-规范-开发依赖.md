# 开发依赖

> YiPet 开发依赖清单：构建工具、代码质量、Git 工具、自动导入、测试、类型定义。

## 一、工具链架构

```
源代码 (.ts/.vue/.scss)
  ├── TypeScript (vue-tsc) ── 类型检查
  ├── ESLint + Prettier ── 代码规范
  ├── Stylelint ── 样式检查
  ├── Rsbuild (Rspack) ── 多入口构建
  │     ├── @rsbuild/plugin-vue / plugin-vue-jsx / plugin-sass
  ├── unplugin-auto-import / unplugin-vue-components ── 自动导入
  └── Vitest ── 测试
```

## 七、升级指南

```bash
npm outdated            # 查看可升级版本
npm install <pkg>@latest  # 逐个升级（避免批量）
npm run typecheck       # 验证无新增错误
npm run build           # 验证构建成功
```

**升级风险**：TypeScript 主版本（高，新严格检查）、ESLint 主版本（中，配置格式可能变）、Rsbuild 主版本（中，查阅 CHANGELOG）、Vue 次版本（低）。

## 八、约束

**必须**：所有依赖通过 `package.json` devDependencies 管理、构建工具支持多入口、ESLint+Prettier+Stylelint 三件套完整、pre-commit 仅检查暂存文件、自动生成的类型文件加入 `.gitignore`。

**禁止**：devDependencies 放入 dependencies、pre-commit 全量检查、跳过 typecheck 提交、提交自动生成的类型文件。
