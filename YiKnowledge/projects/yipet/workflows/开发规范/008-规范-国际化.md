# 国际化

> YiPet 国际化体系：chrome.i18n API、消息文件结构、语言检测与回退链、MessageKey 类型安全、命名约定。

## 一、架构

```
public/_locales/
├── en/messages.json     # 英文源语言（基准，所有键先行）
└── zh_CN/messages.json  # 中文翻译（与 en 键一一对应）

src/shared/i18n/         # 封装层（t() 函数 + MessageKey 类型）
```

**原则**：英文为源语言先行，中文同步翻译。`MessageKey` 联合类型编译时检查。

## 二、chrome.i18n API

| API | 说明 |
|-----|------|
| `chrome.i18n.getMessage(key)` | 获取翻译文本（未找到返回 `""`） |
| `chrome.i18n.getMessage(key, substitutions)` | 带占位符替换 |
| `chrome.i18n.getUILanguage()` | 获取 Chrome UI 语言 |

**封装层 `t()` 回退链**：运行时缓存 → `chrome.i18n.getMessage` → key 原始值（开发模式 warn）。

## 三、消息文件格式

```json
{
  "sendButton": {
    "message": "Send",
    "description": "Button label for sending a chat message"
  },
  "welcomeMessage": {
    "message": "Hello, $NAME$!",
    "placeholders": {
      "name": { "content": "$1", "example": "User" }
    }
  }
}
```

使用：`t("sendButton")` → `"Send"`，`t("welcomeMessage", ["User"])` → `"Hello, User!"`

## 四、MessageKey 类型安全

```typescript
type MessageKey =
  | 'extName' | 'extDescription'
  | 'popupTitle' | 'popupRoleLabel' | 'popupColorLabel' | 'popupModelLabel'
  | 'chatInputPlaceholder' | 'sendButton' | 'stopButton'
  | 'notifyRoleChanged' | 'notifySessionExported' | 'notifyBugCreated'
  | 'statusThinking' | 'statusRetrieving' | 'statusStreaming'
  | 'errorOperationFailed' | 'errorContextInvalidated'
  // ...共 60+ 键

function t(key: MessageKey, substitutions?: string | string[]): string
```

**好处**：编译时捕获拼写错误、IDE 自动补全、重构安全重命名。

## 五、命名约定

| 约定 | 示例 |
|------|------|
| 驼峰命名 | `sendButton`, `chatInputPlaceholder` |
| 功能分组前缀 | `popup*`, `chat*`, `notify*`, `action*`, `status*`, `error*` |
| 描述性命名 | `notifySessionBranched`（非 `notify1`） |
| 避免缩写 | `actionDelete`（非 `actDel`） |

## 六、消息键分类

| 前缀 | 用途 | 示例 |
|------|------|------|
| `popup*` | 弹窗 UI | `popupTitle`, `popupRoleLabel` |
| `chat*` | 聊天窗口 | `chatInputPlaceholder` |
| `notify*` | 通知消息 | `notifyRoleChanged` |
| `action*` | 操作按钮 | `actionExport`, `actionDelete` |
| `status*` | 状态指示 | `statusThinking`, `statusStreaming` |
| `error*` | 错误消息 | `errorOperationFailed` |
| `about*` | 关于面板 | `aboutTitle`, `aboutVersion` |

## 七、新增内容流程

1. `en/messages.json` 添加英文源文本（含 `description`）
2. `zh_CN/messages.json` 添加中文翻译
3. `MessageKey` 类型联合添加新键
4. 代码中使用 `t("newKey")`

## 八、反模式

| 反模式 | 正确做法 | 原因 |
|--------|----------|------|
| 硬编码文本 | `t("key")` | 无法国际化 |
| 消息含 HTML | 占位符 `$LINK_START$...$LINK_END$` | 安全风险 |
| 键名无意义 | 描述性命名 | 不可维护 |
| 修改已有键语义 | 新增键并废弃旧键 | 其他语言翻译过时 |
| 缺少 description | 每个键添加用途说明 | 翻译者无上下文 |

## 九、约束

**必须遵守**：所有用户可见文本用 `t()`、en 源语言先行完整、新键先 en 后其他语言、驼峰 + 功能前缀命名、每个键加 `description`、MessageKey 与 messages.json 同步。

**禁止**：模板中硬编码文本、消息文件含 HTML 标签、修改已有键语义、创建无 description 的键。
