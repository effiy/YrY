# 快速开始

> 从零搭建 YiPet 开发环境、构建加载扩展、常用命令、调试入口。

## 一、环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Node.js | ≥ 18 | JavaScript 运行时 |
| npm | ≥ 9 | 包管理器 |
| Chrome | ≥ 88（MV3） | 扩展平台 |
| YiAi | 运行中 | 后端 `http://localhost:10086` |

验证：`node --version`、`npm --version`、`curl http://localhost:10086/health`

## 二、安装与构建

```bash
cd YiPet
npm install          # 安装依赖
npm run build        # 构建所有入口（6个）
npm run dev          # 开发模式（watch）
```

**分步构建**：`build:chat`、`build:popup`、`build:content`、`build:background`、`build:cdn`、`build:bootstrap`

## 三、加载扩展

1. Chrome → `chrome://extensions/`
2. 开启"开发者模式"
3. "加载已解压的扩展程序" → 选择 `YiPet/dist/`
4. 修改代码后：构建 + 扩展卡片刷新按钮（或 `npm run dev` watch 模式）

### 验证加载成功

- 打开任意网页，右下角应有浮动宠物
- 点击扩展图标，Popup 正常弹出
- `Ctrl+Shift+X` 打开聊天窗口

## 四、常用命令

| 命令 | 用途 | 时机 |
|------|------|------|
| `npm run dev` | Watch 所有入口 | 日常开发 |
| `npm run build` | 生产构建 | 发布前 |
| `npm run typecheck` | `vue-tsc --noEmit` | 提交前 |
| `npm test` | 运行测试 | 提交前 |
| `npm run lint` | ESLint + Stylelint | 提交前 |

## 五、调试入口

| 环境 | 打开方式 |
|------|----------|
| Service Worker | `chrome://extensions/` → "Service Worker" |
| Content Script | 页面 F12 → Console → 选 "Content Script" 上下文 |
| Popup | 右键扩展图标 → "检查弹出内容" |
| MAIN World | 页面 F12 → Console（默认 top frame） |

### 快速诊断

```js
// 页面控制台
window.__YIPET_LOADED__                           // 注入状态
document.querySelector("#yipet-chat-root")        // Vue 挂载点
chrome.storage.local.get(null, console.log)       // 存储数据（ISOLATED 上下文）
```

## 六、技术栈速览

| 技术 | 用途 | 入口 |
|------|------|------|
| Vue 3.5 | 前端框架 | Chat Window + Popup |
| TypeScript 5.x | 类型系统（strict） | 全部 |
| Rsbuild 1.x | 构建（5 入口） | 构建 |
| Element Plus 2.14 | UI 组件库 | Chat + Popup |
| Pinia 4 | 状态管理 | Chat Store |
| Vitest 2 | 测试 | 测试 |

## 七、常见问题

| 症状 | 排查 |
|------|------|
| 扩展不加载 | `dist/` 是否存在、`manifest.json` 格式 |
| 宠物不显示 | `__YIPET_LOADED__`、CDN 资源 404、CS 控制台日志 |
| 聊天无响应 | YiAi 是否运行、快捷键冲突、SW 控制台 |
| API 调用失败 | `curl :10086`、`RSBUILD_API_BASE`、参数名契约 |
| 热更新不生效 | watch 模式 + 刷新扩展 + 刷新页面 |

详见 [调试与排错指南](./04-指南-调试排错.md)。

## 八、与 YiVad 的关系

共享技术栈（Vue 3、Element Plus、TypeScript）和 YiAi 后端。跨项目桥接：YiPet 聊天 → `window.open` + session key → YiVad aiChat 页面。

## 九、约束

**必须**：YiAi 运行中、提交前 `typecheck` + `lint`、参数名遵循 RPC 契约。

**禁止**：MAIN World 调 chrome.*、Content Script 引入大型依赖、跳过类型检查提交。
