# 快速开始

> 从零搭建 YiPet 开发环境：环境要求、安装构建、加载扩展、开发工作流、调试技巧、架构速览、常见问题排查。

## 一、环境要求

| 依赖 | 最低版本 | 推荐版本 | 说明 |
|------|----------|----------|------|
| Node.js | >= 16.18.0 | 20.x LTS | JavaScript 运行时 |
| npm | >= 8 | 10.x | 包管理器 |
| Chrome | >= 88（MV3 支持） | 最新稳定版 | 浏览器 + 扩展平台 |
| YiAi 后端 | — | — | 必须运行在 `http://localhost:10086` |

### 验证环境

```bash
node --version   # 期望 >= 20.0.0
npm --version    # 期望 >= 10.0.0

# 验证 YiAi 后端
curl http://localhost:10086/health
# 期望: {"code": 0, "message": "ok", "data": {"status": "healthy"}}
```

## 二、安装与构建

### 首次安装

```bash
# 1. 进入项目目录
cd YiPet

# 2. 安装依赖
npm install

# 3. 构建所有入口
npm run build

# 4. 开发模式（watch 所有入口，自动重新构建）
npm run dev
```

### 分步构建

```bash
# 构建所有入口（生产模式）
npm run build

# 仅构建特定入口
npm run build:background    # Service Worker
npm run build:popup         # 弹出窗口
npm run build:content       # Content Script
npm run build:chat          # 聊天窗口
npm run build:cdn           # CDN 资源
npm run build:bootstrap     # Bootstrap 脚本
```

## 三、加载扩展

### 首次加载

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角**"开发者模式"**
4. 点击**"加载已解压的扩展程序"**
5. 选择 `YiPet/dist/` 目录
6. 扩展图标出现在工具栏中

### 更新扩展（修改代码后）

```bash
# 方式 1：开发模式自动 watch
npm run dev
# 代码修改后自动构建，然后在 chrome://extensions/ 中点击刷新按钮

# 方式 2：手动构建
npm run build
# 然后在 chrome://extensions/ 中点击刷新按钮
```

### 验证扩展加载成功

1. 打开任意网页（如 `https://example.com`）
2. 检查页面右下角是否出现浮动宠物
3. 点击扩展图标，检查 Popup 是否正常弹出
4. 按 `Ctrl+Shift+X`（Windows/Linux）或 `Cmd+Shift+X`（Mac），检查聊天窗口是否弹出

## 七、架构速览

### 双世界执行模型

```
┌─ MAIN World (页面上下文) ─────────────────────────────┐
│  src/chat/stores/chat.ts                                │
│    │ 直接操作 DOM，渲染 Vue 组件                        │
│    │ 通过 IPC Relay 调用 chrome.* API                  │
│    │ 直接 fetch 调用 YiAi 后端                          │
│    ▼                                                    │
│  dispatchSecureEvent('yipet:...', {...})                  │
├─ ISOLATED World (Content Script) ──────────────────────┤
│  src/content/ipc/relay.ts                              │
│    │ 监听 chrome.runtime.onMessage（Popup）               │
│    │ dispatchSecureEvent（CustomEvent + IPC_SECRET）      │
│    ▼                                                    │
│  chrome.runtime.sendMessage({action: ...})               │
├─ Service Worker ────────────────────────────────────────┤
│  src/background/index.ts                                │
│    │ 处理 chrome API 调用                                │
│    │ 管理快捷键、广播、存储                              │
│    ▼                                                    │
│  chrome.storage, chrome.tabs, chrome.runtime             │
└─────────────────────────────────────────────────────────┘
```

### API 调用路径

```
聊天消息（直连，不经过 IPC）:
  Chat Store（Pinia）→ ApiClient → fetch → YiAi :10086

Chrome API 操作（经过 IPC）:
  Chat Store（Pinia）→ dispatchSecureEvent → IPC Relay → chrome.runtime.sendMessage → Service Worker → Chrome API
```

## 八、常见开发工作流

### 8.1 修改聊天窗口

```bash
# 1. 编辑 src/chat/ 目录下的文件
# 2. 开发模式自动 watch
npm run dev
# 3. 在 chrome://extensions/ 中刷新扩展
# 4. 刷新目标页面测试（或按 Ctrl+Shift+X 打开聊天窗口）
```

### 8.2 修改 Popup

```bash
# 1. 编辑 src/popup/ 目录下的文件
npm run dev
# 2. 点击扩展图标打开 Popup 测试
# 3. 修改后关闭并重新打开 Popup
```

### 8.3 修改 Content Script

```bash
# 1. 编辑 src/content/ 目录下的文件
npm run dev
# 2. 在 chrome://extensions/ 中刷新扩展
# 3. 刷新目标页面
# 4. 打开 Chrome DevTools → Content Script 控制台查看日志
```

### 8.4 修改 Service Worker

```bash
# 1. 编辑 src/background/ 目录下的文件
npm run dev
# 2. 在 chrome://extensions/ 中刷新扩展
# 3. 打开 chrome://extensions/ → 扩展卡片 → "Service Worker" 查看控制台
```

### 8.5 新增 API 调用

```bash
# 1. 在 src/api/types.ts 中添加请求/响应类型
# 2. 在 src/api/services/ 中添加 Service 方法
# 3. 在 Chat Store 或 Popup 中调用
# 4. 验证：确保参数名使用 filter（非 query）、target_file（非 path）
```

### 8.6 添加国际化文本

```bash
# 1. 在 public/_locales/en/messages.json 中添加英文文本
# 2. 在 public/_locales/zh_CN/messages.json 中添加中文文本
# 3. 使用 chrome.i18n.getMessage("key") 获取文本
# 4. 在 Vue 组件中使用 t() 辅助函数
```

### 8.7 修改 CDN 资源

```bash
# 1. 编辑 public/cdn/ 或 src/utils/cdn/ 目录下的文件
npm run build:cdn
# 2. 在 chrome://extensions/ 中刷新扩展
# 3. 刷新目标页面
```

## 十、常见问题排查

### 扩展加载失败

**症状**：`chrome://extensions/` 中显示错误

**排查**：
- 检查 `dist/` 目录是否存在
- 确保 `manifest.json` 格式正确
- 检查 `dist/` 目录下是否有所有必需文件
- 查看错误详情（红色错误卡片）

```bash
# 重新构建
rm -rf dist
npm run build
```

### 扩展不工作

**症状**：扩展图标灰色，Popup 无响应

**排查**：
- 检查 Chrome 版本是否支持 MV3（>= 88）
- 打开 Service Worker 控制台查看错误
- 检查 Content Script 控制台是否有注入错误

### 聊天窗口不显示

**症状**：按快捷键无反应，页面无聊天窗口

**排查**：
```
1. 确保 YiAi 后端在 http://localhost:10086 运行
   curl http://localhost:10086/health

2. 检查 Content Script 是否成功注入
   页面 F12 → Console → 输入: window.__YIPET_LOADED__

3. 检查快捷键是否冲突
   chrome://extensions/shortcuts

4. 检查 Service Worker 控制台
   chrome://extensions/ → 扩展卡片 → "Service Worker"
```

### 构建失败

**症状**：`npm run build` 报错

**排查**：
```bash
# 清除缓存后重试
rm -rf dist node_modules .rsbuild
npm install
npm run build

# 检查 Node.js 版本
node --version  # 需要 >= 16.18.0

# 查看详细错误
npm run build -- --debug
```

### API 调用失败

**症状**：聊天消息发送失败，数据加载失败

**排查**：
```
1. 检查 YiAi 后端
   curl http://localhost:10086/health

2. 检查 RSBUILD_API_BASE 环境变量
   echo $RSBUILD_API_BASE

3. 查看 Service Worker 控制台中的网络请求
   chrome://extensions/ → 扩展卡片 → "Service Worker"

4. 检查 CORS 配置
   YiAi 需要允许 Chrome 扩展的 origin
```

### 热更新不生效

**症状**：修改代码后刷新页面，变化未生效

**排查**：
```
1. 确保使用 npm run dev（watch 模式）
2. 修改后刷新 Chrome 扩展
   chrome://extensions/ → 点击刷新按钮
3. 刷新目标页面
4. 检查是否有构建错误
```

### 类型检查失败

**症状**：`npm run typecheck` 报错

**排查**：
```bash
# 查看详细错误
npx vue-tsc --noEmit

# 检查 TypeScript 版本
npx tsc --version

# 清除类型缓存
rm -rf node_modules/.cache
npm run typecheck
```

## 十一、与 YiVad 的关系

### 共享技术栈

| 技术 | YiVad | YiPet | 共享方式 |
|------|-------|-------|----------|
| Vue 3.5 | 是 | 是 | 相同框架 |
| Element Plus 2.14 | 是 | 是 | 相同 UI 库 |
| TypeScript 5.x | 是 | 是 | 相同语言 |
| RPC 信封 | 是 | 是 | 相同 API 协议 |
| YiAi 后端 | 是 | 是 | 共享后端 |

### 跨项目桥接

YiPet 可以将聊天会话无缝传递到 YiVad：

```
YiPet 聊天窗口
  │ 用户点击 "在 YiVad 中打开"
  │
  ├── 1. 创建会话（YiAi API）
  │     POST / body: { module_name: "services.database.session_service", ... }
  │
  ├── 2. 获取 session_key
  │
  └── 3. 打开 YiVad
        window.open(`http://localhost:8848/#/aiChat?session=${session_key}`)
```

## 十二、约束

### 必须遵守
- 开发前确保 YiAi 后端在 `http://localhost:10086` 运行
- 提交前运行 `npm run typecheck` 和 `npm run lint`
- 新增 API 调用时使用正确的参数名称（`filter` 非 `query`，`target_file` 非 `path`）
- 修改 CDN 资源后需要运行 `npm run build:cdn`

### 禁止
- 不在 MAIN World 中直接调用 `chrome.*` API（通过 IPC Relay）
- 不在 Content Script 中引入大型依赖
- 不跳过类型检查提交代码
- 不在生产构建中使用 `npm run dev` 的输出
