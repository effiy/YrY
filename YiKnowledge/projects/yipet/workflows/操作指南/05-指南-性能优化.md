# 性能优化指南

> YiPet Chrome 扩展性能优化：注入性能、渲染优化、存储策略、网络优化、内存管理、Bundle 体积控制。

## 一、注入性能

**目标**：Content Script 注入不阻塞宿主页面加载（< 50ms 感知延迟）

| 优化 | 说明 | 效果 |
|------|------|------|
| CSS 优先并行加载 | 样式表并行注入，避免闪烁 | 减少首帧时间 |
| JS 串行按需加载 | 关键资源优先（Vue），非关键资源降级（Bootstrap） | 核心功能快速可用 |
| `__YIPET_LOADED__` 短路 | 已注入页面跳过整个流程 | O(1) 检测 |
| 全局存在性检查 | `window.Vue` 已存在 → 跳过注入 | 避免覆盖宿主 |

**不要做**：
- 在 Content Script 中引入大型依赖（保持 < 10KB）
- 在注入阶段同步读取 chrome.storage（异步执行）
- SPA 路由页重复注入（MutationObserver + URL 监听）

## 二、渲染优化

### Chat Window 渲染

| 优化 | 阈值 | 实现 |
|------|------|------|
| 虚拟滚动 | 消息 > 50 条 | `useVirtualScroll` composable |
| Markdown 防抖 | 流式输出 50ms debounce | 减少 marked 解析频率 |
| 代码高亮延迟 | 非当前消息延迟高亮 | IntersectionObserver |
| CSS contain | `contain: layout style paint` | 限制重绘范围 |

### Floating Pet 动画

- 使用 CSS `transform`/`opacity` 动画（触发 Composite，不触发 Layout）
- `requestAnimationFrame` 节流动画帧
- 非活动标签页暂停动画循环（`document.hidden` 检测）
- 简化动画状态机（5 个状态：idle/active/thinking/speaking/sleeping）

## 三、存储策略

| 策略 | 说明 |
|------|------|
| 消息截断 | 持久化只保留最近 100 条（`slice(-100)`） |
| Sessions 配额 | 总数据限制 ~1MB（约 500 条消息） |
| 写入防抖 | chrome.storage 写入 2 秒 debounce |
| LRU 清理 | 配额超限时清理最旧会话 |
| 分离存储 | 临时数据（ragSources）不持久化 |

**存储键规范**：

| 前缀 | 用途 | 示例 |
|------|------|------|
| 无前缀 | 配置/UI 状态 | `role`, `chatVisible` |
| `session_` | 会话数据 | `session_abc123` |
| `backup_` | 降级备份 | `backup_session_abc123` |
| `cache_` | 缓存数据 | `cache_knowledge_tree` |

## 四、网络优化

| 优化 | 说明 |
|------|------|
| SSE 直连 | 聊天消息从 MAIN World 直接 fetch（不经 IPC） |
| Token 持久化 | 不每次读取 storage，构造时注入 |
| 请求复用 | 同一 Service 实例复用 ApiClient |
| 超时控制 | 普通 30s / 流式 600s / 每读 30s |
| 重试仅网络错误 | HTTP 4xx/5xx 不重试，避免无效请求 |

## 五、内存管理

| 场景 | 策略 |
|------|------|
| 组件卸载 | 取消 AbortController、disconnect MutationObserver |
| 事件监听 | onUnmounted 中 removeEventListener |
| SW 终止 | 不依赖内存状态，全部持久化到 storage |
| 大对象 | 消息列表使用虚拟滚动，不一次性渲染全部 DOM |
| Blob URL | 导出后 `URL.revokeObjectURL()` |

## 六、Bundle 体积

### 各入口目标大小

| 入口 | 目标（gzip） | 说明 |
|------|-------------|------|
| background.js | < 5KB | Service Worker 逻辑 |
| bootstrap.js | < 5KB | 注入脚本（Content Script） |
| content.js | < 10KB | Content Script 引导 |
| chat.js | < 80KB | Chat Store + 工具库 |
| popup.js | < 150KB | Vue + Element Plus + Popup |

### 优化手段

| 手段 | 效果 | 实现 |
|------|------|------|
| Tree Shaking | -20~30% | Rsbuild 生产模式 |
| 按需导入 Element Plus | -200KB | unplugin-vue-components |
| CDN 外部化 Vue/Bootstrap | Chat 不重复打包 | 独立 CDN 构建入口 |
| Gzip 压缩 | -60~70% | Rsbuild 自动 |

### 体积检查

```bash
ls -lh dist/assets/
ls -lh dist/cdn/vendor/
# 关注：bootstrap.js < 50KB, chat.js < 500KB
# 检查 cdn/vendor/ 中是否有未使用的库
```

## 七、性能检查清单

- [ ] Content Script 注入 < 50ms
- [ ] bootstrap.js < 5KB（gzip）
- [ ] chat.js < 80KB（gzip）
- [ ] 消息列表 > 50 条启用虚拟滚动
- [ ] 动画使用 `transform`/`opacity`
- [ ] 非活动标签页暂停动画
- [ ] 存储写入 debounce
- [ ] 组件卸载清理所有 listener/observer
- [ ] 无未使用的 CDN vendor 库
