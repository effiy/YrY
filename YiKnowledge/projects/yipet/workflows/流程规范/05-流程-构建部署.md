# 构建部署

> Rsbuild 多入口构建配置、Chrome MV3 扩展打包、开发调试、构建约束、常见问题。

## 一、构建命令

| 命令 | 说明 | 产物位置 |
|------|------|----------|
| `npm run dev` | 开发模式（watch 所有入口） | `dist/` |
| `npm run build` | 构建所有入口 | `dist/` |
| `npm run build:cdn` | 仅构建 CDN 资源 | `dist/cdn/` |
| `npm run build:chat` | 仅构建聊天窗口 | `dist/assets/chat.js` |
| `npm run build:bootstrap` | 仅构建 Content Script | `dist/assets/bootstrap.js` |
| `npm run typecheck` | TypeScript 类型检查 | 无（仅检查） |
| `npm run clean` | 清除构建产物 | — |

## 二、多入口构建

### 入口总览

| 入口 | 配置文件 | 输出 | 目标环境 | 构建约束 |
|------|----------|------|----------|----------|
| popup | `rsbuild.config.ts` | `dist/popup.html` + `popup.js` | 扩展弹窗 | 独立 HTML |
| background | `rsbuild.config.ts` | `dist/assets/background.js` | Service Worker | 单文件，禁用代码分割 |
| chat | `rsbuild.config.chat.ts` | `dist/assets/chat.js` | MAIN World 注入 | 禁用文件名哈希 |
| cdn | `rsbuild.config.cdn.ts` | `dist/cdn/` | 按需注入 | 独立 chunk |
| bootstrap | `rsbuild.config.bootstrap.ts` | `dist/assets/bootstrap.js` | Content Script | 单文件，轻量 |

### 主构建配置（rsbuild.config.ts）

```typescript
// popup + background 入口
export default defineConfig(({ mode }) => ({
  plugins: [
    pluginVue(),
    pluginVueJsx(),
    pluginSass({
      sassLoaderOptions: {
        additionalData: `@use "@/styles/var.scss" as *;`,
      },
    }),
    yipetBuildPlugin(mode),  // 自定义插件：复制 manifest、写 build-meta、清理 background.html
  ],
  source: {
    entry: {
      popup: './src/popup/main.ts',
      background: './src/background/index.ts',
    },
  },
  output: {
    cleanDistPath: false,
    filenameHash: false,  // MV3 manifest 引用固定文件名
    distPath: {
      root: 'dist',
      js: 'assets',
      css: 'assets',
    },
  },
  tools: {
    rspack: {
      optimization: {
        splitChunks: false,   // Service Worker 必须单文件
        runtimeChunk: false,
      },
    },
  },
}));
```

### 构建约束

| 约束 | 说明 | 违反后果 |
|------|------|----------|
| 文件名哈希禁用 | 输出固定文件名如 `popup.js`、`chat.js` | manifest 引用失效 |
| 代码分割禁用（SW） | Service Worker 单文件输出 | SW 加载失败 |
| 自动导入 | unplugin 自动导入 Vue API | 手动导入增加体积 |
| 构建元数据 | 自动生成 `dist/build-meta.json` | 无法追踪版本 |
| `cleanDistPath: false` | 多入口构建不互相清理产物 | 后构建的入口覆盖先构建的 |
| manifest 复制 | 自定义插件自动复制 `manifest.json` | 扩展无法加载 |

## 三、构建流程

### 完整构建流程

```
npm run build
  │
  ├── 1. npm run build:cdn
  │     rsbuild build --config rsbuild.config.cdn.ts
  │     输出：dist/cdn/（vendor libs, styles, utils）
  │
  ├── 2. rsbuild build（主构建）
  │     popup → dist/popup.html + dist/assets/popup.js
  │     background → dist/assets/background.js
  │     + yipetBuildPlugin: 复制 manifest.json, 写 build-meta.json
  │
  ├── 3. npm run build:chat
  │     rsbuild build --config rsbuild.config.chat.ts
  │     输出：dist/assets/chat.js
  │
  └── 4. npm run build:bootstrap
        rsbuild build --config rsbuild.config.bootstrap.ts
        输出：dist/assets/bootstrap.js
```

### 开发模式

```bash
npm run dev
# 等价于：
# npm run build:cdn &&
# (rsbuild build --mode development --watch &
#  rsbuild build --mode production --watch --config rsbuild.config.chat.ts &
#  rsbuild build --mode development --watch --config rsbuild.config.bootstrap.ts)
```

注意：chat 入口在开发模式下使用 `--mode production` 构建，因为开发模式插件在 MAIN World 注入环境中不可用。

## 四、自定义构建插件

### yipetBuildPlugin

```typescript
function yipetBuildPlugin(mode: string) {
  return {
    name: 'yipet-build',
    setup(api: RsbuildPluginAPI) {
      api.onAfterBuild(() => {
        // 1. 复制 manifest.json 到 dist/
        copyFileSync('manifest.json', 'dist/manifest.json');

        // 2. 写入构建元数据
        writeFileSync('dist/build-meta.json', JSON.stringify({
          builtAt: Date.now(),
          mode,
          version: '1.2.0'
        }, null, 2));

        // 3. 删除 background.html（MV3 Service Worker 是 JS-only）
        const bgHtml = 'dist/background.html';
        if (existsSync(bgHtml)) rmSync(bgHtml, { force: true });
      });
    },
  };
}
```

## 五、构建产物

### 产物结构

```
dist/
├── manifest.json                 # Chrome MV3 扩展清单
├── build-meta.json               # 构建元数据
├── popup.html                    # 弹窗入口 HTML
├── assets/
│   ├── popup.js                  # 弹窗 JS
│   ├── popup.css                 # 弹窗样式
│   ├── background.js             # Service Worker
│   ├── chat.js                   # 聊天窗口（MAIN World 注入）
│   └── bootstrap.js              # Content Script
├── cdn/
│   ├── vendor/                   # 第三方库（Vue 3.5, Bootstrap 5.2, jQuery 等 50+）
│   ├── styles/                   # 全局样式 + 聊天组件 CSS
│   └── utils/                    # 工具脚本（utils/index.js）
├── _locales/
│   ├── en/messages.json          # 英文消息
│   └── zh_CN/messages.json       # 中文消息
└── icons/                        # 扩展图标
```

## 六、加载扩展

### 开发环境加载

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角**"开发者模式"**
4. 点击**"加载已解压的扩展程序"**
5. 选择 `YiPet/dist/` 目录
6. 扩展图标出现在工具栏中

### 更新扩展

修改代码后重新构建，在 `chrome://extensions/` 中点击扩展卡片上的刷新按钮。

### 调试

| 调试目标 | 打开方式 |
|----------|----------|
| Popup | 右键扩展图标 → 检查弹出内容 |
| Content Script | 目标页面 → F12 → Sources → Content Scripts |
| Service Worker | `chrome://extensions/` → 扩展卡片 → "Service Worker" 链接 |
| MAIN World | 目标页面 → F12 → Console（选择 top frame） |

## 七、构建优化

| 优化 | 说明 | 效果 |
|------|------|------|
| Tree Shaking | ES module 输出，自动消除未使用代码 | 减少 20-30% 体积 |
| CDN 资源分离 | 大型库（Vue, Bootstrap, jQuery 等）单独构建为 CDN 资源 | 多入口共享，避免重复 |
| 禁用文件名哈希 | 固定文件名满足 MV3 manifest 引用 | 构建产物可直接加载 |
| 代码分割禁用 | Service Worker 单文件输出 | 满足 MV3 规范 |
| 按需注入 | CDN 资源仅在需要时注入页面 | 减少无关页面开销 |
| 自动导入 | unplugin 自动导入 Vue API | 减少手动导入代码 |

### 体积分析

```bash
# 查看构建产物大小
ls -lh dist/assets/
ls -lh dist/cdn/vendor/

# 重点关注：
# 1. bootstrap.js 是否 < 50KB（轻量入口）
# 2. chat.js 是否过大（> 500KB 需优化）
# 3. cdn/vendor/ 是否有重复或未使用的库
```

## 十、常见问题

### 构建失败

```bash
# 清除缓存后重试
rm -rf dist node_modules
npm install
npm run build
```

### 扩展加载失败

- 检查 `dist/` 目录是否存在
- 确保 `dist/manifest.json` 格式正确
- 检查 `dist/` 目录下是否有所有必需文件（popup.html, assets/, cdn/）

### Service Worker 未注册

- 确保 `dist/assets/background.js` 存在且为单文件
- 检查 `dist/` 下是否有多余的 `background.html`（应被插件自动删除）
- 在 `chrome://extensions/` 中查看 Service Worker 状态

### 聊天窗口不显示

- 确保 YiAi 后端在 `http://localhost:10086` 运行
- 检查 Content Script 是否成功注入（F12 → Sources → Content Scripts）
- 检查 `window.__YIPET_LOADED__` 是否设置（Console 中执行）

### 热更新不生效

- 确保使用 `npm run dev`（watch 模式）
- 修改后刷新 Chrome 扩展
- 刷新目标页面

### jsxDEV is not a function

chat 入口在开发模式下使用 `--mode production` 构建。如果遇到此错误，检查 `npm run dev` 中 chat 构建命令是否使用了 `--mode production`。
