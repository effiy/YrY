# 构建部署

> Rsbuild 多入口构建配置、Chrome MV3 扩展打包、构建产物结构、开发调试、常见问题。

**相关文档**：[扩展发布流程](./06-流程-扩展发布流程.md) · [架构概览](../架构设计/01-架构-架构概览.md)

## 一、构建命令

| 命令 | 说明 | 产物 |
|------|------|------|
| `npm run build` | 构建所有 5 个入口 | `dist/` |
| `npm run dev` | Watch 所有入口 | `dist/` |
| `npm run build:chat` | 仅聊天窗口 | `dist/assets/chat.js` |
| `npm run build:cdn` | 仅 CDN 资源 | `dist/cdn/` |
| `npm run build:bootstrap` | 仅 Content Script | `dist/assets/bootstrap.js` |
| `npm run typecheck` | 类型检查 | 无 |

## 二、多入口构建

| 入口 | 输出 | 约束 |
|------|------|------|
| popup | `dist/popup.html` + `popup.js` | 独立 HTML |
| background | `dist/assets/background.js` | 单文件，禁代码分割 |
| chat | `dist/assets/chat.js` | 禁文件名哈希 |
| cdn | `dist/cdn/` | 独立 chunk |
| bootstrap | `dist/assets/bootstrap.js` | 单文件，< 50KB |

**构建约束**：文件名哈希禁用（MV3 manifest 引用固定路径）、代码分割禁用（SW/CS 需单文件）、`cleanDistPath: false`（多入口不互相清理）、自定义插件自动复制 manifest + 写 build-meta + 删 background.html。

## 三、构建流程

```
npm run build
  → build:cdn（vendor libs, styles, utils）
  → 主构建（popup + background + 复制 manifest + 写 build-meta）
  → build:chat（MAIN World 注入）
  → build:bootstrap（Content Script）
```

开发模式 chat 入口使用 `--mode production`（开发插件在 MAIN World 注入环境不可用）。

## 四、构建产物

```
dist/
├── manifest.json          # MV3 清单
├── build-meta.json        # 构建元数据
├── popup.html
├── assets/
│   ├── popup.js / popup.css
│   ├── background.js      # Service Worker
│   ├── chat.js            # MAIN World
│   └── bootstrap.js       # Content Script
├── cdn/
│   ├── vendor/            # 50+ 第三方库
│   ├── styles/            # 全局样式
│   └── utils/             # 工具脚本
├── _locales/              # en + zh_CN
└── icons/                 # 16/32/48/128
```

## 五、构建优化

| 优化 | 效果 |
|------|------|
| Tree Shaking（ES module） | -20~30% |
| CDN 资源分离 | 多入口共享，避免重复 |
| 禁止代码分割（SW/CS） | 满足 MV3 规范 |
| 启用文件名哈希（仅 CDN） | 缓存优化 |
| 自动导入 | unplugin 减少手动导入 |

**体积检查**：`ls -lh dist/assets/`，关注 bootstrap.js < 50KB，chat.js < 500KB。

## 六、环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `RSBUILD_API_BASE` | `http://localhost:10086` | YiAi 后端地址 |
| `NODE_ENV` | `development`/`production` | 构建模式 |

## 七、常见问题

| 症状 | 解决 |
|------|------|
| 构建失败 | `rm -rf dist node_modules && npm install && npm run build` |
| SW 未注册 | 确保 `background.js` 为单文件，无多余 `background.html` |
| chat.js jsxDEV 错误 | chat 入口需 `--mode production` |
| 热更新不生效 | watch + 刷新扩展 + 刷新页面 |
| 扩展加载失败 | 验证 `dist/manifest.json` 格式和必需文件 |
