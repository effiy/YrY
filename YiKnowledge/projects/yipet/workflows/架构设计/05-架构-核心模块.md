# 核心模块

> YiPet 核心模块详解：Chat Store（Pinia）、Popup 皮肤中心、Bootstrap 双世界注入、IPC Relay、CDN 加载器、Floating Pet 渲染引擎、Background Service Worker。

**专项文档**：[Chat Store](../功能模式/01-模式-ChatStore状态管理.md) · [IPC 通信](./06-架构-IPC跨世界通信.md) · [CDN 注入](./07-架构-CDN资源注入.md)

## 一、模块总览

| 模块 | 文件 | 环境 | 职责 |
|------|------|------|------|
| Chat Store | `src/chat/stores/chat.ts` | MAIN World | 聊天状态管理 + 流式处理（50+ actions） |
| Chat Window | `src/chat/stores/useChatWindow.ts` | MAIN World | 窗口拖拽/调整大小/显隐管理 |
| Popup | `src/popup/App.vue` | 扩展弹窗 | 皮肤中心（角色/颜色/模型选择） |
| Bootstrap | `src/content/bootstrap.ts` | ISOLATED → MAIN | 双世界入口 + CDN 注入 |
| IPC Relay | `src/content/ipc/relay.ts` | ISOLATED | chrome.runtime.onMessage + CustomEvent 安全分发 |
| CDN Injector | `src/content/cdn/injector.ts` | ISOLATED | 按需动态注入 JS/CSS |
| Floating Pet | `src/content/rendering/overlay.ts` | MAIN World | 皮肤环 + 动画 + 交互 |
| Background SW | `src/background/index.ts` | Service Worker | 命令分发 + 消息路由 + 快捷键 |
| Role/Theme Config | `src/content/config/` | ISOLATED | 角色配置(role-config.ts) + 主题配置(theme-config.ts) |

## 二、Chat Store（Pinia）

聊天窗口单一状态源，Pinia Setup Store（Composition API）。状态通过 `reactive()` 包裹，Vue 自动追踪依赖。

**核心操作**：

| 操作 | 说明 |
|------|------|
| `sendMessage(text)` | 发送消息 → 路由聊天模式 → SSE 流式回调 |
| `stopSending()` | AbortController 取消 + 保留已接收内容 |
| `selectSession(id)` | 保存当前 → 加载目标 → 恢复消息列表 |
| `createSession(opts?)` | 创建空会话 → 设为当前 |
| `deleteSession(id)` | 删除 → 若当前则切换到最近会话 |

**流式处理流程**：`sendMessage → 前置检查 → 推送用户消息 → 添加空 assistant 占位 → 路由模式（普通/RAG文件/RAG目录） → SSE 回调（onToken/onThinking/onDone/onError） → finally 清理 + 持久化`

详见 [Chat Store 状态管理](../功能模式/01-模式-ChatStore状态管理.md)。

## 三、Popup（皮肤中心）

独立 Vue 3 应用，6 个组件：AppHeader、PetPreview、RolePicker、ColorPicker、AppFooter、AboutCard。

**数据流**：`用户选择 → 更新本地状态 → chrome.storage.local.set → chrome.tabs.sendMessage（广播到所有标签页） → Content Script → dispatchSecureEvent → MAIN World 更新皮肤`

**配置项**：role（默认 `"cat"`）、color（默认 `"blue"`）、model（默认 `"qwen3.5"`）、petVisible（默认 `true`）、language（默认 `"zh_CN"`）

## 四、Bootstrap（双世界注入）

Content Script 入口，运行在 ISOLATED World。注入流程：

1. 检查 `window.__YIPET_LOADED__` → 已注入短路
2. 注入 CDN CSS（并行）
3. 注入 CDN Vendor JS（串行，保证依赖顺序）：Vue → Bootstrap → utils
4. 设置 `__YIPET_LOADED__ = true`
5. 创建 MAIN World `<script>` 标签加载 `chat.js`
6. MAIN World 挂载 Chat Window（Vue 3）+ 渲染 Floating Pet

**注入约束**：重复注入短路、关键资源重试 3 次（指数退避 500ms）、非关键资源失败降级、失败后清除标志允许下次重试。

详见 [扩展架构](./02-架构-扩展架构.md)。

## 五、IPC Relay（跨世界通信）

ISOLATED World 中的消息桥接器。三通道通信：

| 通道 | 方向 | 用途 | 安全 |
|------|------|------|------|
| `chrome.tabs.sendMessage` | Popup → CS | 配置变更 | Chrome 内部 API |
| `dispatchSecureEvent`（CustomEvent） | ISOLATED → MAIN | 可见性/聊天切换 | IPC_SECRET 签名 + 5s 过期 |
| `<script> dataset` | ISOLATED → MAIN | 初始配置传递（apiBase, token） | DOM 属性 |

详见 [IPC 跨世界通信](./06-架构-IPC跨世界通信.md)。

## 六、CDN Injector（资源加载器）

管理 50+ 第三方库的注入。资源目录（`CDN_CATALOG`）定义每个资源的 key、path、type、global（检测已加载）。

**加载策略**：CSS 优先并行 → JS 串行（保证依赖顺序）。通过 `loadByKey` 按需加载，`global` 属性检查避免重复注入。

详见 [CDN 资源注入](./07-架构-CDN资源注入.md)。

## 七、Floating Pet（渲染引擎）

纯 DOM 渲染（不依赖 Vue），5 个动画状态：idle → active → thinking → speaking → sleeping。

**动画系统**：CSS `@keyframes` + class toggle 驱动，9 种动画（glow-pulse、wiggle、blink、entrance、hover、bounce、tilt、sparkle、bubble-in/out）。状态通过监听 IPC 事件同步。

位置持久化到 `chrome.storage.local`（`petPosition: { x: 80, y: 50 }`）。

## 八、Background Service Worker

**职责**：命令分发（`chrome.commands` 快捷键）、消息路由（`chrome.runtime.onMessage`）、存储管理（受控读写）、标签页管理（`chrome.tabs`）。

**生命周期**：安装时初始化默认配置 → 运行时处理消息 → 空闲 30s 终止 → 新消息到达自动唤醒 → 从 storage 恢复状态。

**快捷键**：`Ctrl+Shift+P`（切换宠物显隐）、`Ctrl+Shift+X`（打开聊天窗口）。

## 十一、反模式

| 反模式 | 正确做法 | 原因 |
|--------|----------|------|
| 组件中直接调用 ApiClient | 通过 Chat Store Actions | 破坏状态管理 |
| MAIN World 调 chrome API | 通过 IPC Relay | MAIN World 无 chrome API |
| 绕过 CDN Injector | 使用 `createInjector` + `loadByKey` | 失去重复检测 |
| 直接修改 Store 状态 | 通过 Store Actions | 破坏响应式追踪 |
| 不处理 SSE 中断 | AbortSignal + onUnmounted 清理 | 资源泄漏 |
