# 双世界执行模型

> Chrome MV3 Content Script 的 ISOLATED World 与 MAIN World 双上下文执行模型。IPC 协议详见 [IPC 跨世界通信](../架构设计/06-架构-IPC跨世界通信.md)。

**相关文档**：[扩展架构](../架构设计/02-架构-扩展架构.md) · [IPC 通信](../架构设计/06-架构-IPC跨世界通信.md)

## 一、架构

```
┌─ Popup（Vue 3，独立窗口）──────────────────────────┐
│  chrome.tabs.sendMessage ←→ Content Script          │
├─ Content Script（ISOLATED World — manifest 声明）───┤
│  ✓ chrome.runtime / chrome.storage / CORS 豁免      │
│  ✗ 宿主 window 全局变量 / JS 对象                    │
├─ postMessage + CustomEvent（IPC_SECRET + 5s 过期）──┤
├─ Bootstrap（MAIN World — 动态 <script> 注入）───────┤
│  ✓ 宿主 window / DOM / CDN 资源                     │
│  ✗ chrome.runtime.* / extension URL                 │
└─────────────────────────────────────────────────────┘
```

## 二、能力边界

| 能力 | ISOLATED | MAIN | 说明 |
|------|:---:|:---:|------|
| `chrome.runtime.sendMessage` | ✓ | ✗ | ISOLATED 独有 |
| `chrome.storage.local` | ✓ | ✗ | 扩展隔离存储 |
| `fetch`（跨域 CORS 豁免） | ✓ | ✗ | ISOLATED 独有 |
| `chrome.runtime.getURL` | ✓ | ✗ | 扩展内资源加载 |
| `window.postMessage` | ✓ | ✓ | 唯一跨世界通道 |
| DOM 操作 | ✓ | ✓ | 同一 DOM 树 |
| 宿主 `window.myData` | ✗ | ✓ | 两个世界 window 属性不共享 |
| 宿主 Vue/React 实例 | ✗ | ✓ | MAIN 独有 |
| `eval` / `new Function` | ✗ | ✗ | MV3 CSP 禁止 |

## 三、CDN 资源注入流程

```
Content Script（ISOLATED）
  → 检查 __YIPET_LOADED__（已注入短路）
  → 注入 CDN CSS（<link>，ISOLATED 可直接操作 DOM）
  → 注入 CDN Vendor JS（<script> → 在 MAIN World 执行）
  → 注入 Bootstrap（<script> + dataset: ipcSecret, apiBase）
```

### 注入时机

| 页面类型 | 时机 | 策略 |
|----------|------|------|
| 静态 HTML | `document_idle` | 标准注入 |
| SPA（Vue/React） | `document_idle` + MutationObserver | 监听 app root |
| 动态路由 | MutationObserver + URL 监听 | 路由切换重新评估 |
| iframe | 仅顶层窗口 | `window.top === window.self` |

## 四、常见问题排查

### 宠物不显示（MAIN World 初始化失败）

```js
window.__YIPET_LOADED__                          // 应为 true
document.querySelector("#yipet-chat-root")       // 应存在
// Network → 过滤 "cdn/" → 找 404
```

### Popup 配置变更后宠物不响应

排查链路：Popup `sendMessage` → CS `onMessage` → `dispatchToMain` → MAIN `message` listener → 签名/时间戳验证。

### 跨域 fetch 失败

- ISOLATED World 有 CORS 豁免（manifest content_scripts 声明）
- 确保 `host_permissions` 声明
- MAIN World fetch 受宿主 CSP 限制

## 五、硬约束

- MAIN World **禁止**调 `chrome.runtime.*` → 由 ISOLATED 代理
- ISOLATED World **推荐**通过 `dispatchToMain` 让 MAIN 操作 DOM
- 跨世界通信须安全验证（IPC_SECRET + 5s 时间戳）
- IPC_SECRET 扩展安装时生成，`chrome.storage.local` 持久化
- `window.postMessage` 的 `targetOrigin` 用 `"*"`（同窗口通信，接收端验证来源）
- 所有 vendor 库通过 npm 安装后打包到 `cdn/vendor/`，`chrome.runtime.getURL` 加载
- 禁止 `eval`、`new Function`、内联 `<script>`（MV3 CSP）
