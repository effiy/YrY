## 二、目录职责速查

| 目录 | 职责 | 环境 | 禁止 |
|------|------|------|------|
| `api/` | HTTP 封装、RPC 信封、SSE 解析 | 所有 | 直接 fetch |
| `background/` | 命令分发、消息路由 | SW | 访问 DOM |
| `chat/` | 聊天 UI、流式处理、状态管理 | MAIN World | 使用 chrome.* |
| `content/` | 双世界注入、IPC、宠物渲染 | ISOLATED + MAIN | 混用世界状态 |
| `popup/` | 皮肤中心、配置管理 | 扩展弹窗 | 访问页面 DOM |
| `shared/` | i18n、storage、工具函数 | 所有 | 依赖特定世界 API |
| `types/` | 全局类型声明 | 编译时 | 运行时逻辑 |

## 三、依赖方向

```
chat/ + popup/ ──────────── UI 层（Vue 3）
  │ 依赖
  ▼
api/services/ ───────────── 服务层
  │ 依赖
  ▼
api/client.ts ───────────── ApiClient
  │ 依赖
  ▼
YiAi Backend ────────────── HTTP :10086
```

**禁止的依赖**：chat/ → chrome.*（MAIN 不可用）、chat/ → content/state（跨世界隔离）、background/ → DOM（SW 无 DOM）、popup/ → 页面 DOM（弹窗隔离）。

## 四、文件命名

| 约定 | 示例 | 适用 |
|------|------|------|
| PascalCase 组件 | `ChatWindow.vue` | Vue 组件 |
| camelCase 模块 | `client.ts`, `bootstrap.ts` | TS 模块 |
| kebab-case 目录 | `chat/`, `content/` | 目录和 CDN 文件 |
| `Service` 后缀 | `ChatService.ts` | API 服务类 |
| `types.ts` 后缀 | `src/chat/types.ts` | 类型定义 |

## 五、新增模块指南

| 模块类型 | 创建位置 | 还需修改 |
|----------|----------|----------|
| API Service | `src/api/services/<Domain>Service.ts` | `types.ts` + `index.ts` |
| Chat 组件 | `src/chat/components/<Name>.vue` | `ChatWindow.vue` 引入 |
| Popup 功能 | `src/popup/components/<Name>.vue` | `App.vue` 引入 |
| Content Script | `src/content/<module>.ts` | `relay.ts` 消息处理 |
| Composable | `src/chat/composables/use<Name>.ts` | 组件中 import |
