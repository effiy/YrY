# 扩展架构

> Chrome MV3 扩展架构详解：双世界执行、跨世界通信、多入口构建、注入流程、键盘快捷键、降级策略、CSP 安全、Service Worker 生命周期。

## 一、MV3 双执行上下文

Chrome MV3 扩展在两个隔离的 JavaScript 世界中运行：

```
┌──────────────────────────────────────────────────────────────┐
│  ISOLATED World（Content Script）                              │
│  ├── chrome.runtime API 可用                                  │
│  ├── chrome.storage API 可用                                  │
│  ├── chrome.tabs API 可用（通过 SW）                           │
│  ├── 通过 dispatchSecureEvent（CustomEvent + IPC_SECRET）与 MAIN World 通信  │
│  └── src/content/bootstrap.ts（第一阶段）                       │
│       ├── 检查 window.__YIPET_LOADED__                        │
│       ├── 注入 CDN 资源（Vue, Element Plus, 样式）             │
│       ├── 创建 MAIN World 脚本标签                             │
│       └── 运行 IPC Relay（消息转发）                          │
├──────────────────────────────────────────────────────────────┤
│  MAIN World（Page Context）                                    │
│  ├── 页面 DOM 完全访问                                         │
│  ├── window 全局变量（与页面共享）                              │
│  ├── chrome.runtime API 不可用                                │
│  └── src/content/bootstrap.ts（第二阶段，通过 <script> 注入）    │
│       ├── Chat Window（Vue 3 SPA）                             │
│       │   ├── Chat Store（Pinia）→ ApiClient（HTTP）→ YiAi        │
│       │   ├── 20+ UI 组件（消息列表、输入框、侧边栏...）        │
│       │   └── 3 种聊天模式（普通/RAG/Agent）                   │
│       └── Floating Pet（DOM overlay）                          │
│           ├── 皮肤环（角色图片轮换 + 光环动画）                 │
│           ├── 工具提示（状态信息气泡）                          │
│           └── 动画效果（idle, active, thinking, speaking）     │
└──────────────────────────────────────────────────────────────┘
```

### 双世界 API 可用性

| API | ISOLATED World | MAIN World | 说明 |
|-----|---------------|------------|------|
| `chrome.runtime` | 可用 | 不可用 | 消息通信、扩展管理 |
| `chrome.storage` | 可用 | 不可用 | 持久化存储 |
| `chrome.tabs` | 可用（通过 SW） | 不可用 | 标签页操作 |
| `chrome.commands` | 可用（通过 SW） | 不可用 | 键盘快捷键 |
| `chrome.i18n` | 可用 | 不可用 | 国际化消息 |
| `document` | 可用（隔离 DOM） | 可用（完整 DOM） | DOM 操作 |
| `window` | 可用（隔离） | 可用（共享） | 全局作用域 |
| `window.postMessage` | 可用 | 可用 | 跨世界通信 |
| `fetch` | 可用 | 可用 | HTTP 请求 |
| `localStorage` | 不可用（隔离） | 可用 | 页面存储 |

## 二、跨世界通信

### 通信架构

```
┌─ Popup（扩展弹窗）──────────────────────────────────────┐
│  App.vue                                                 │
│    │ 用户选择角色/颜色/模型                                │
│    │ chrome.tabs.sendMessage(tabId, {                     │
│    │   action: 'setRole', role: 'cat'                    │
│    │ })                                                   │
│    ▼                                                     │
├─ ISOLATED World（Content Script — IPC Relay）────────────┤
│  content/ipc/relay.ts                                    │
│    │ chrome.runtime.onMessage.addListener(handler)       │
│    │ 处理 action 消息 → dispatchSecureEvent               │
│    │ dispatchSecureEvent('yipet:roleChanged', {...})     │
│    ▼                                                     │
├─ MAIN World（Chat Window / Floating Pet）────────────────┤
│  chat/ + overlay.ts                                      │
│    │ window.addEventListener('yipet:roleChanged', ...)   │
│    │ IPC_SECRET 签名 + 时间戳验证（5s 过期）              │
│    ▼                                                     │
│  更新皮肤/聊天头部/系统提示词                              │
└──────────────────────────────────────────────────────────┘

反向通信（MAIN → ISOLATED → SW → Chrome API）:
  MAIN World: dispatchSecureEvent('yipet:discussPage', {...})
    → ISOLATED: chrome.runtime.sendMessage({ action: 'DISCUSS_PAGE', ... })
    → SW: chrome.tabs.create / chrome.storage.*
```

### 消息类型

| 消息方向 | 通道 | 消息格式 | 说明 |
|----------|------|----------|------|
| Popup → Content Script | `chrome.tabs.sendMessage` | `{ action: 'setRole', role: string }` | 角色变更 |
| Popup → Content Script | `chrome.tabs.sendMessage` | `{ action: 'setColor', color: string }` | 颜色变更 |
| Popup → Content Script | `chrome.tabs.sendMessage` | `{ action: 'setModel', model: string }` | 模型变更 |
| Popup → Content Script | `chrome.tabs.sendMessage` | `{ action: 'toggleChat' }` | 切换聊天窗口 |
| ISOLATED → MAIN | `dispatchSecureEvent` (CustomEvent) | `yipet:roleChanged` / `yipet:colorChanged` / `yipet:chatToggled` | 安全事件分发 |
| Content Script → SW | `chrome.runtime.sendMessage` | `{ action: 'DISCUSS_PAGE', data }` | 页面讨论请求 |
| SW → Content Script | `chrome.tabs.sendMessage` | `{ action: 'TOGGLE_PET' }` / `{ action: 'OPEN_CHAT' }` | 快捷键命令 |
| Token 传递 | `<script>` dataset | `chatEl.dataset.apiToken = token` | 启动时注入 |

### 通信安全

```typescript
// content/ipc/relay.ts
const IPC_SECRET = crypto.randomUUID();

function dispatchSecureEvent<T>(name: string, detail: T): void {
  window.dispatchEvent(new CustomEvent(name, {
    detail: {
      __yipet: true,
      __signature: IPC_SECRET,
      __timestamp: Date.now(),
      data: detail,
    },
  }));
}

// MAIN World 侧验证
window.addEventListener('yipet:roleChanged', ((e: CustomEvent) => {
  const { __yipet, __signature, __timestamp, data } = e.detail || {};
  // 1. 验证来源标记
  if (!__yipet) return;
  // 2. 验证签名（每次页面加载生成新的 IPC_SECRET）
  if (__signature !== IPC_SECRET) return;
  // 3. 验证时间戳（5 秒过期，防止重放）
  if (Date.now() - __timestamp > 5000) return;
  // 处理消息
  applyRole(data.role);
}) as EventListener);

// 监听 Popup 消息（ISOLATED World 侧）
chrome.runtime.onMessage.addListener((msg: PopupToContent, _sender, sendResponse) => {
  switch (msg.action) {
    case 'setRole':
      _petRole = validateRole(msg.role);
      applyRole(_petRole);
      persist();
      dispatchSecureEvent('yipet:roleChanged', { role: _petRole });
      sendResponse({ success: true });
      break;
    case 'toggleChat':
      dispatchSecureEvent('yipet:chatToggled', {});
      sendResponse({ success: true });
      break;
  }
  return true;  // 保持消息通道开放（异步响应）
});
```

## 三、注入流程

```
页面加载
  │ manifest.json content_scripts 匹配 URL 模式
  ▼
Content Script（bootstrap.ts）注入到 ISOLATED World
  │
  ├── 1. 检查 window.__YIPET_LOADED__
  │     │ 已加载 → 短路退出（防止重复注入）
  │     │ 未加载 → 继续
  │
  ├── 2. 注入 CDN 资源
  │     ├── Vue 3 运行时（关键资源，失败则放弃）
  │     ├── Bootstrap 5.2.3 UI 库（非关键，失败可降级）
  │     ├── 全局样式（变量 + 聊天样式 + 宠物皮肤）
  │     │     variables.css → chat.css → pet.css
  │     └── utils/index.js（API 客户端 + 工具函数，关键资源，必须在 chat.js 之前）
  │
  ├── 3. 设置全局标志
  │     window.__YIPET_LOADED__ = true
  │
  ├── 4. 创建 MAIN World 脚本标签
  │     const script = document.createElement("script")
  │     script.src = chrome.runtime.getURL("assets/chat.js")
  │     script.onload = () => { /* 初始化完成 */ }
  │     script.onerror = () => { /* 注入失败，重试 */ }
  │     document.documentElement.appendChild(script)
  │
  ▼
MAIN World 初始化
  │
  ├── 5. 挂载 Chat Window（Vue 3 SPA）
  │     createApp(ChatWindow).mount("#yipet-chat-root")
  │     ├── 初始化 Chat Store（Pinia）
  │     ├── 从 chrome.storage 恢复会话状态（通过 IPC）
  │     └── 注册全局快捷键监听
  │
  └── 6. 渲染 Floating Pet
        overlay.render(document.body)
        ├── 创建皮肤环 DOM 元素（CSS gradient）
        ├── 加载角色图片
        ├── 启动 idle 动画循环
        └── 绑定事件监听（hover, click, drag）
```

### 注入实现

```typescript
// src/content/bootstrap.ts
const YIPET_LOADED_KEY = "__YIPET_LOADED__";
const MAX_RETRIES = 3;
const RETRY_DELAY = 500;

async function inject(): Promise<void> {
  // 防止重复注入
  if ((window as any)[YIPET_LOADED_KEY]) return;
  (window as any)[YIPET_LOADED_KEY] = true;

  // 注入 CDN 资源（按顺序，关键资源优先）
  await injectStyles(chrome.runtime.getURL("cdn/styles/variables.css"));
  await injectStyles(chrome.runtime.getURL("cdn/styles/chat.css"));
  await injectStyles(chrome.runtime.getURL("cdn/styles/pet.css"));

  // 关键脚本：失败则重试
  await injectScriptWithRetry(chrome.runtime.getURL("cdn/vendor/vue@3.5.13/vue.global.prod.js"), MAX_RETRIES);
  await injectScriptWithRetry(chrome.runtime.getURL("cdn/utils/index.js"), MAX_RETRIES);

  // 非关键脚本：通过 loadByKey 按需加载
  try {
    await injector.loadByKey('bootstrap');
  } catch {
    console.warn("[Bootstrap] Bootstrap 加载失败，聊天窗口仍可用");
  }

  // 注入主应用
  await injectScriptWithRetry(chrome.runtime.getURL("assets/chat.js"), MAX_RETRIES);
}

async function injectScriptWithRetry(src: string, maxRetries: number): Promise<void> {
  for (let i = 0; i < maxRetries; i++) {
    try {
      await injectScript(src);
      return;
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await sleep(RETRY_DELAY * Math.pow(2, i));  // 指数退避
    }
  }
}

function injectScript(src: string): Promise<void> {
  return new Promise((resolve, reject) => {
    const script = document.createElement("script");
    script.src = src;
    script.onload = () => resolve();
    script.onerror = () => reject(new Error(`Failed to load: ${src}`));
    (document.head || document.documentElement).appendChild(script);
  });
}

function injectStyles(href: string): Promise<void> {
  return new Promise((resolve, reject) => {
    const link = document.createElement("link");
    link.rel = "stylesheet";
    link.href = href;
    link.onload = () => resolve();
    link.onerror = () => reject(new Error(`Failed to load CSS: ${href}`));
    (document.head || document.documentElement).appendChild(link);
  });
}

inject().catch((error) => {
  console.error("[Bootstrap] 注入失败:", error);
  // 清除全局标志，允许下次页面加载时重试
  delete (window as any)[YIPET_LOADED_KEY];
});
```

### 注入约束

| 约束 | 处理 | 降级行为 |
|------|------|----------|
| 重复注入 | `window.__YIPET_LOADED__` 全局检查短路 | 跳过注入 |
| 注入失败 | 重试 3 次，间隔 500ms（指数退避） | 清除标志，下次页面加载重试 |
| CDN 加载失败 | 关键资源失败则放弃注入，非关键资源可降级 | 关键资源失败 → 放弃注入；非关键 → 功能退化 |
| 页面 CSP 限制 | 使用 `chrome.runtime.getURL` 获取扩展内资源 | 满足 MV3 CSP 合规 |
| 页面已有 Vue | 扩展自带 Vue 3 运行时 (CDN)，不依赖页面 | 隔离运行，不冲突 |

## 四、多入口构建

| 入口 | 配置文件 | 输出 | 运行环境 | 构建约束 |
|------|----------|------|----------|----------|
| popup | `rsbuild.config.ts` | `dist/popup.html` + `popup.js` | 扩展弹窗 | 独立 HTML，可代码分割 |
| background | `rsbuild.config.ts` | `dist/assets/background.js` | Service Worker | 单文件，禁用代码分割 |
| chat | `rsbuild.config.chat.ts` | `dist/assets/chat.js` | MAIN World 注入 | 禁用文件名哈希 |
| cdn | `rsbuild.config.cdn.ts` | `dist/cdn/` | 按需注入 | 独立 chunk，可缓存 |
| bootstrap | `rsbuild.config.bootstrap.ts` | `dist/assets/bootstrap.js` | Content Script | 单文件，轻量（< 50KB） |

### 构建约束详解

| 约束 | 说明 | 违反后果 | 影响入口 |
|------|------|----------|----------|
| 文件名哈希禁用 | 输出固定文件名如 `chat.js` | manifest 引用失效 | 所有 |
| 代码分割禁用 | Service Worker 单文件输出 | SW 加载失败 | background, bootstrap |
| 自动导入 | unplugin 自动导入 Vue/Element Plus API | 手动导入增加体积 | chat, popup |
| 构建元数据 | 自动生成 `build-meta.json` | 无法追踪版本 | 所有 |
| 外部化 CDN 依赖 | Vue/Element Plus 不打包到 chat.js | 打包体积膨胀 | chat |

## 六、Chrome MV3 约束

| 约束 | 影响 | 处理方式 |
|------|------|----------|
| Service Worker 生命周期 | 非持久化，空闲 30s 后终止 | 状态持久化到 chrome.storage，启动时恢复 |
| 禁止远程代码执行 | 不能动态加载外部 JS | 所有代码预打包到扩展内 |
| Manifest V3 声明 | 权限和 host 声明式配置 | manifest.json 精确声明所需权限 |
| chrome.storage 配额 | 10MB（sync）/ 无限制（local） | 大数据使用 local，关键配置使用 sync |
| 禁止 eval/new Function | CSP 限制 | 避免动态代码执行 |
| Content Script 隔离 | 不能直接访问页面 JS 变量 | 通过 window.postMessage 通信 |
| 后台脚本替换 | Background Page → Service Worker | 无 DOM 访问，使用 chrome API |

### Service Worker 生命周期管理

```
Service Worker 启动
  │ chrome.runtime.onInstalled / onStartup
  │ 从 chrome.storage 恢复状态
  ▼
运行中（处理消息）
  │ chrome.runtime.onMessage
  │ chrome.commands.onCommand
  ▼
空闲 30s → 终止
  │ 状态已持久化到 chrome.storage
  ▼
新消息到达 → 自动唤醒
  │ 从 chrome.storage 恢复状态
  │ 继续处理消息
```

## 七、降级策略

| 场景 | 检测方式 | 降级行为 | 恢复方式 |
|------|----------|----------|----------|
| YiAi 不可达 | fetch 超时/连接拒绝 | 指数退避重试（1s→2s→4s→...max 30s） | YiAi 恢复后自动连接 |
| CDN 资源已加载 | `window.__YIPET_LOADED__` | 跳过注入，直接使用已有资源 | 无操作 |
| 存储配额超限 | `chrome.storage.local.getBytesInUse()` | 非关键数据静默失败，关键数据降级 | 用户清理存储 |
| 语言消息缺失 | `chrome.i18n.getMessage` 返回空 | 回退链：zh_CN → en → key 原始值 | 更新语言包 |
| Chrome MV3 不支持 | `typeof chrome?.runtime === "undefined"` | 优雅降级，禁用扩展功能 | 提示用户升级浏览器 |
| Content Script 注入失败 | bootstrap 超时 | 重试 3 次，间隔 500ms（指数退避） | 页面刷新后重试 |
| 页面 CSP 限制 | 资源加载被阻止 | 使用扩展内资源（`chrome.runtime.getURL`） | — |
| SSE 连接中断 | ReadableStream 关闭 | 自动重连（最多 3 次，指数退避） | 连接恢复后继续 |
| Bootstrap 等 UI 库加载失败 | script onerror | 聊天窗口仍可用（无 UI 组件库） | 页面刷新后重试 |

## 八、CSP 安全

### Content Security Policy

```json
// manifest.json
{
  "content_security_policy": {
    "extension_pages": "script-src 'self'; object-src 'self'"
  }
}
```

### 安全措施

| 层面 | 措施 | 实现 |
|------|------|------|
| 消息通信 | IPC_SECRET 签名验证 + 时间戳过期（5s） | IPC Relay (dispatchSecureEvent) |
| 存储 | Token 存 chrome.storage.session（key: apiToken），localStorage 迁移回退 | ApiClient |
| CSP | 禁止 inline script，禁止 eval，禁止远程脚本 | manifest.json |
| 权限 | 最小权限原则，仅声明必需权限 | manifest.json |
| XSS | 用户输入通过 DOMPurify 过滤 | 聊天输入 |
| 资源加载 | 仅加载扩展内资源（`chrome.runtime.getURL`） | CDN Injector |

## 九、反模式

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 在 MAIN World 使用 chrome API | `chrome.storage.local.get()` 在 chat.ts 中 | 通过 IPC Relay 转发到 ISOLATED World | MAIN World 无 chrome API |
| 动态加载外部 JS | `<script src="https://cdn.com/vue.js">` | 使用 `chrome.runtime.getURL("cdn/vendor/vue@3.5.13/vue.global.prod.js")` | MV3 CSP 禁止远程代码 |
| 忽略重复注入 | 不检查 `__YIPET_LOADED__` | 注入前检查全局标志 | 多次注入导致错误 |
| 不处理 SW 终止 | 依赖内存状态 | 状态持久化到 chrome.storage | SW 空闲 30s 后终止 |
| 信任所有 postMessage | `window.addEventListener("message", handler)` 无验证 | 使用 `dispatchSecureEvent` 的 `IPC_SECRET` + 时间戳验证 | 恶意页面可伪造消息 |
| 关键资源无重试 | 加载失败直接放弃 | 关键资源重试 3 次，指数退避 | 网络波动导致注入失败 |

## 十、约束

### 必须遵守
- Content Script 只负责消息转发和 DOM 注入，不包含业务逻辑
- Service Worker 只负责命令分发和 chrome API 调用，不直接操作 DOM
- Chat Window 不依赖 chrome API，可独立测试
- 注入前检查 `__YIPET_LOADED__` 防止重复注入
- 所有代码预打包到扩展内，禁止远程代码执行
- 状态持久化到 chrome.storage，不依赖内存状态

### 禁止
- 不在 MAIN World 中使用 chrome.* API
- 不动态加载外部 JS（MV3 CSP 限制）
- 不混用 Content Script 和 Service Worker 状态
- 不信任未经验证的 postMessage 消息
- 不跳过 CDN 资源的错误处理
