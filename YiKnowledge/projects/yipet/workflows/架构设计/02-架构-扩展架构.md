# 扩展架构

> Chrome MV3 扩展架构详解：双世界执行、注入流程、多入口构建、键盘快捷键、降级策略、CSP 安全、Service Worker 生命周期。

**专项文档**：[双世界模型](./03-架构-双世界执行模型.md) · [IPC 通信](./06-架构-IPC跨世界通信.md) · [CDN 注入](./07-架构-CDN资源注入.md) · [构建部署](../流程规范/05-流程-构建部署.md)

## 一、MV3 双执行上下文

```
┌─ ISOLATED World（Content Script）──────────────────────┐
│  chrome.runtime / chrome.storage / CORS 豁免            │
│  bootstrap.ts → CDN 注入 → IPC 转发 → MAIN World       │
├─ MAIN World（Page Context）────────────────────────────┤
│  页面 DOM / window / 无 chrome.* API                    │
│  Chat Window（Vue 3 SPA）+ Floating Pet（DOM overlay）  │
└────────────────────────────────────────────────────────┘
```

### API 可用性矩阵

| API | ISOLATED | MAIN | 说明 |
|-----|:---:|:---:|------|
| `chrome.runtime` | ✓ | ✗ | 消息通信 |
| `chrome.storage` | ✓ | ✗ | 持久化 |
| `chrome.tabs` | ✓ | ✗ | 通过 SW |
| `document` | ✓（隔离） | ✓（完整） | DOM 操作 |
| `window.postMessage` | ✓ | ✓ | 唯一跨世界通道 |
| `fetch` | ✓（CORS豁免） | ✓（受CSP限制） | HTTP 请求 |

## 二、注入流程

```
页面加载 → manifest.json content_scripts 匹配 URL
  → Content Script（bootstrap.ts）注入 ISOLATED World
    ├── 1. 检查 window.__YIPET_LOADED__ → 已注入短路
    ├── 2. 注入 CDN 资源（CSS 并行 → JS 串行）
    │     关键：Vue 3, utils/index.js（失败重试 3 次）
    │     非关键：Bootstrap, GSAP 等（失败降级）
    ├── 3. window.__YIPET_LOADED__ = true
    └── 4. 创建 MAIN World <script> 加载 chat.js
  → MAIN World 初始化
    ├── 挂载 Chat Window（Vue 3 SPA, Pinia）
    └── 渲染 Floating Pet（DOM overlay）
```

### 注入约束

| 约束 | 处理 | 降级 |
|------|------|------|
| 重复注入 | `__YIPET_LOADED__` 短路 | 跳过 |
| 注入失败 | 重试 3 次，指数退避 | 清除标志，下次重试 |
| CDN 加载失败 | 关键资源失败放弃；非关键降级 | 功能退化 |
| 页面 CSP 限制 | `chrome.runtime.getURL` 扩展内资源 | MV3 CSP 合规 |
| 页面已有 Vue | 扩展自带 Vue 3，`global` 检查短路 | 隔离运行 |

## 三、多入口构建

| 入口 | 输出 | 环境 | 关键约束 |
|------|------|------|----------|
| popup | `dist/popup.html` | 扩展弹窗 | 独立 HTML |
| background | `dist/assets/background.js` | Service Worker | 单文件，禁代码分割 |
| chat | `dist/assets/chat.js` | MAIN World | 禁文件名哈希 |
| cdn | `dist/cdn/` | 按需注入 | 独立 chunk |
| bootstrap | `dist/assets/bootstrap.js` | Content Script | 单文件，< 50KB |

**构建约束**：文件名哈希禁用（MV3 manifest 引用固定路径）、代码分割禁用（SW/CS 需单文件）、自动导入 Vue/Pinia API（unplugin）。

## 四、键盘快捷键

| 快捷键 | 命令 | 说明 |
|--------|------|------|
| `Ctrl+Shift+P` | `toggle-pet` | 切换宠物显隐 |
| `Ctrl+Shift+X` | `open-chat` | 打开聊天窗口 |

处理链路：`chrome.commands.onCommand → SW → chrome.tabs.sendMessage → CS → dispatchSecureEvent → MAIN`

## 五、Chrome MV3 约束

| 约束 | 处理 |
|------|------|
| SW 生命周期（空闲 30s 终止） | 状态持久化到 chrome.storage，启动时恢复 |
| 禁止远程代码执行 | 所有代码预打包到扩展内 |
| chrome.storage 配额 | local 无限制，关键配置可存 sync（10MB） |
| 禁止 eval | 避免动态代码执行 |
| Content Script 隔离 | window.postMessage 通信 |

### SW 生命周期

```
启动 → chrome.runtime.onInstalled/onStartup → 从 storage 恢复状态
  → 运行中（处理消息）→ 空闲 30s → 终止（状态已持久化）
  → 新消息到达 → 自动唤醒 → 从 storage 恢复 → 继续处理
```

## 六、降级策略

| 场景 | 降级行为 | 恢复 |
|------|----------|------|
| YiAi 不可达 | 指数退避重试（1s→2s→4s→max 30s） | 自动 |
| CDN 已加载 | `__YIPET_LOADED__` 短路 | 无操作 |
| 存储配额超限 | 非关键数据静默失败，关键数据降级 localStorage | 用户清理 |
| 语言消息缺失 | zh_CN → en → key 原始值 | 更新语言包 |
| Content Script 注入失败 | 重试 3 次 | 页面刷新 |
| SSE 连接中断 | 自动重连（最多 3 次，指数退避） | 自动 |

## 七、CSP 安全

| 层面 | 措施 |
|------|------|
| 消息通信 | IPC_SECRET 签名 + 5s 时间戳过期 |
| 存储 | Token 存 `chrome.storage.session`（安全存储） |
| CSP 声明 | `script-src 'self'; object-src 'self'` |
| 权限 | 最小权限原则 |
| XSS | 用户输入 DOMPurify 过滤 |
| 资源 | 仅 `chrome.runtime.getURL` 扩展内资源 |

## 八、反模式

| 反模式 | 正确做法 | 原因 |
|--------|----------|------|
| MAIN World 用 chrome API | IPC Relay 转发 | 无 chrome API |
| 远程 CDN 加载 JS | `chrome.runtime.getURL` 本地资源 | MV3 CSP 禁止 |
| 忽略重复注入 | `__YIPET_LOADED__` 检查 | 多次注入 |
| 依赖内存状态 | 持久化 chrome.storage | SW 空闲终止 |
| 信任所有 postMessage | IPC_SECRET + 时间戳验证 | 恶意伪造 |
| 关键资源无重试 | 重试 3 次指数退避 | 网络波动 |

## 九、约束

**必须遵守：**
- Content Script 只做转发和注入，不含业务逻辑
- SW 只做命令分发和 chrome API 调用
- Chat Window 不依赖 chrome API，可独立测试
- 注入前检查 `__YIPET_LOADED__`
- 状态持久化 chrome.storage

**禁止：**
- MAIN World 不用 chrome.* API
- 不动态加载外部 JS
- 不混用 CS 和 SW 状态
- 不信任未验证的 postMessage
