# YP-09-131: 电池与性能优化 — 电池状态检测、省电模式、电量指示器、低电量通知、性能预算、CPU/GPU 监控、热量感知、用户偏好

> 需求编号：YP-09-131 · 优先级：P2 · 人天：0.3d · 状态：需求已编写
> 依赖：YP-09-10（ContentScript 性能剖析）、YP-09-82（动画帧率自适应）、YP-09-126（网络质量自适应）、YP-09-105（动画与过渡效果系统）

## 背景

### 问题陈述

YiPet 作为常驻浏览器扩展，其宠物动画、SSE 连接、Content Script 注入等持续运行，在移动设备（笔记本/平板）上对电池续航产生显著影响。当前系统未考虑设备电源状态，导致：

1. **电池消耗过快**：宠物动画以 60fps 持续渲染，SSE 连接保持心跳，在电池供电时每小时消耗 5-8% 电量，用户感知明显
2. **无省电机制**：即使设备电量低于 10%，扩展仍以全性能运行，加速电池耗尽，用户可能在关键时刻（如视频会议）因电量不足而被迫关闭扩展
3. **资源浪费**：在低性能设备或电池供电场景下，全帧率动画和频繁的网络请求不仅浪费电量，还导致设备发热和风扇噪音
4. **用户无感知**：扩展未提供电池状态信息，用户不知道扩展对电池的影响程度，无法做出"是否关闭扩展"的决策
5. **热量累积**：长时间全性能运行导致设备发热，在移动设备上尤为明显，用户可能因设备过热而卸载扩展

**核心矛盾**：在保证 YiPet 功能完整性的前提下，根据设备电源状态（电池电量、是否充电、CPU/GPU 负载、温度）动态调整性能策略，在用户体验和电池续航之间取得平衡。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 电池供电时电量消耗过快 | 高 | 用户在咖啡厅用笔记本工作，YiPet 在后台运行，2 小时内电量从 100% 降至 60% |
| 2 | 低电量时无保护，设备突然关机 | 高 | 用户电量 5% 时 YiPet 仍在全性能运行，5 分钟后设备关机，未保存的工作丢失 |
| 3 | 低性能设备上运行卡顿 | 中 | 用户使用 5 年前的笔记本，宠物动画 60fps 导致设备风扇狂转 |
| 4 | 设备发热严重 | 中 | 用户在平板电脑上使用 YiPet，30 分钟后设备背面明显发热 |
| 5 | 用户无法评估扩展的电池影响 | 低 | 用户不知道 YiPet 对电池的影响程度，只能"感觉"耗电快 |

### 挑战

| 挑战 | 说明 |
|------|------|
| Battery Status API 支持有限 | `navigator.getBattery()` 在部分浏览器中已废弃或不可用，需降级方案 |
| CPU/GPU 监控精度 | 浏览器中无法直接获取 CPU 温度和 GPU 负载，需通过性能 API 间接估算 |
| 性能预算的平滑切换 | 省电模式切换时动画帧率变化需要平滑过渡，避免用户感知到卡顿 |
| 设备发热检测 | 浏览器无热量传感器 API，需通过 CPU 使用率、风扇转速等间接指标推断 |
| 用户偏好冲突 | 用户手动设置的性能偏好可能与系统自动检测的省电模式冲突 |
| Service Worker 中的性能控制 | 部分性能优化（如降低动画帧率）需要在 Content Script 中实现，SW 无法直接控制 |

## 二、设计决策

### 决策 1：电池状态检测方案 — Battery Status API vs 系统级 API vs 用户手动设置

| 选项 | 精度 | 兼容性 | 自动检测 | 实现复杂度 |
|------|------|--------|----------|------------|
| `navigator.getBattery()` | 高（电量、充电状态、剩余时间） | 低（Chrome 已限制，Firefox 已废弃） | 是 | 低 |
| 系统级 API（Native Messaging） | 高 | 低（需安装 Native Host） | 是 | 高 |
| 用户手动设置省电模式 | 低（依赖用户） | 高 | 否 | 低 |

**选择：navigator.getBattery() 为主，用户手动设置补充。** 尽管 Battery Status API 在部分浏览器中已受限，但在 Chrome 扩展的 Content Script 中仍可使用（扩展有更高的权限）。当 API 不可用时，降级为检测 `navigator.connection.saveData` 和用户手动设置。提供"省电模式"手动开关，用户可随时切换。

### 决策 2：省电模式触发策略 — 仅基于电量 vs 电量 + 充电状态 + 用户行为 vs 多维度综合

| 选项 | 准确度 | 用户体验 | 实现复杂度 |
|------|--------|----------|------------|
| 仅基于电量（< 20% 触发） | 低 | 中（可能在不必要的时候触发） | 低 |
| 电量 + 充电状态（未充电时更激进） | 中 | 好 | 中 |
| 多维度综合（电量 + 充电 + CPU + 用户活跃度 + 时间） | 高 | 最佳 | 高 |

**选择：多维度综合判断。** 省电模式触发条件综合考虑：电量阈值（< 20% 触发省电、< 10% 触发紧急省电）、充电状态（充电时恢复全性能）、用户活跃度（用户 5 分钟未交互时降低帧率）、时间段（夜间自动降低性能）、CPU 负载（持续 > 80% 时降频）。多维度判断避免单一条件的误触发。

### 决策 3：性能预算分级 — 3 级 vs 5 级 vs 连续可调

| 选项 | 灵活性 | 用户理解成本 | 实现复杂度 |
|------|--------|-------------|------------|
| 3 级（normal/saver/critical） | 中 | 低 | 低 |
| 5 级（ultra/saver/balanced/performance/ultra） | 高 | 中 | 中 |
| 连续可调（滑块 0-100%） | 最高 | 高 | 高 |

**选择：3 级性能预算 + 用户可配置参数。** 提供 3 个预设性能级别：正常（60fps 动画、5s 轮询、实时同步）、省电（30fps 动画、15s 轮询、延迟同步）、紧急（15fps 动画、30s 轮询、暂停同步）。用户可在设置中调整每个级别的具体参数（帧率、轮询间隔、同步频率）。3 级预设覆盖 90% 场景，高级用户可自定义。

### 决策 4：CPU/GPU 监控方案 — performance.now() 帧时间 vs 长任务 API vs 估算模型

| 选项 | 精度 | 性能开销 | 适用性 |
|------|------|----------|--------|
| 帧时间分析（requestAnimationFrame 时间差） | 中 | 低 | 检测渲染性能 |
| 长任务 API（PerformanceObserver） | 高 | 极低 | 检测主线程阻塞 |
| 启发式估算模型 | 低 | 极低 | 无合适 API 时的降级 |

**选择：长任务 API + 帧时间分析组合。** 使用 `PerformanceObserver` 监听 `longtask` 事件（> 50ms 的任务），统计长任务频率作为 CPU 负载指标。使用 `requestAnimationFrame` 回调时间差检测帧率下降（帧时间 > 16.6ms 表示无法维持 60fps）。热量检测通过长任务频率和持续时间间接推断（持续高频长任务表示 CPU 高负载，可能导致发热）。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 电池检测方案 | Battery API | Native Messaging | 手动设置 | **Battery API + 手动设置** | 兼容性与精度的平衡 |
| 省电触发策略 | 仅电量 | 电量+充电 | 多维度综合 | **多维度综合** | 避免误触发，体验最佳 |
| 性能预算分级 | 3 级 | 5 级 | 连续可调 | **3 级预设 + 自定义** | 简洁且灵活 |
| CPU/GPU 监控 | 帧时间 | 长任务 API | 估算模型 | **长任务 + 帧时间** | 精度高，开销低 |

```typescript
// src/background/BatteryMonitor.ts (新增)

class BatteryMonitor {
  private battery: BatteryState | null = null;
  private listeners: Array<(state: BatteryState) => void> = [];
  private pollingInterval: ReturnType<typeof setInterval> | null = null;

  async init(): Promise<BatteryState> {
    if ('getBattery' in navigator) {
      try {
        const battery = await (navigator as any).getBattery();
        this.battery = this.parseBatteryState(battery);
        battery.addEventListener('levelchange', () => this.updateState());
        battery.addEventListener('chargingchange', () => this.updateState());
        battery.addEventListener('chargingtimechange', () => this.updateState());
        battery.addEventListener('dischargingtimechange', () => this.updateState());
        this.battery.supported = true;
      } catch {
        this.battery = this.createFallbackState();
      }
    } else {
      this.battery = this.createFallbackState();
    }

    if (!this.battery.supported) {
      this.pollingInterval = setInterval(() => {
        this.checkFallbackSignals();
      }, 30000);
    }

    return this.battery;
  }

  getState(): BatteryState {
    if (!this.battery) return this.createFallbackState();
    return { ...this.battery };
  }

  onChange(listener: (state: BatteryState) => void): () => void {
    this.listeners.push(listener);
    return () => { this.listeners = this.listeners.filter(l => l !== listener); };
  }

  needsPowerSaving(thresholds: { saver: number; critical: number }): PerformanceMode {
    if (!this.battery) return 'normal';
    const { level, charging } = this.battery;
    if (charging) return 'normal';
    if (level <= thresholds.critical) return 'critical';
    if (level <= thresholds.saver) return 'saver';
    return 'normal';
  }

  destroy(): void {
    if (this.pollingInterval) clearInterval(this.pollingInterval);
    this.listeners = [];
  }

  private parseBatteryState(battery: any): BatteryState {
    return {
      level: battery.level || 1,
      charging: battery.charging || false,
      chargingTime: battery.chargingTime === Infinity ? Infinity : battery.chargingTime || 0,
      dischargingTime: battery.dischargingTime === Infinity ? Infinity : battery.dischargingTime || 0,
      supported: true,
    };
  }

  private updateState(): void { this.notifyListeners(); }

  private notifyListeners(): void {
    const state = this.getState();
    for (const listener of this.listeners) {
      try { listener(state); } catch (err) {
        console.error('[YiPet] 电池状态监听器错误:', err);
      }
    }
  }

  private createFallbackState(): BatteryState {
    return { level: 1, charging: true, chargingTime: 0, dischargingTime: Infinity, supported: false };
  }

  private checkFallbackSignals(): void {
    const connection = (navigator as any).connection;
    if (connection?.saveData) {
      this.battery = { ...this.createFallbackState(), level: 0.3, charging: false };
      this.notifyListeners();
    }
  }
}
```

```typescript
// src/background/CPUMonitor.ts (新增)

class CPUMonitor {
  private longTaskObserver: PerformanceObserver | null = null;
  private frameTimeSamples: number[] = [];
  private longTaskHistory: Array<{ duration: number; timestamp: number }> = [];
  private cpuState: CPUState;
  private frameCallback: number | null = null;
  private lastFrameTime: number = 0;

  constructor() {
    this.cpuState = this.createDefaultState();
  }

  init(): void {
    if ('PerformanceObserver' in self) {
      try {
        this.longTaskObserver = new PerformanceObserver((list) => {
          const now = performance.now();
          for (const entry of list.getEntries()) {
            this.longTaskHistory.push({ duration: entry.duration, timestamp: now });
          }
          this.updateCPUState();
        });
        this.longTaskObserver.observe({ type: 'longtask', buffered: true });
      } catch {
        console.warn('[YiPet] 长任务 API 不可用，使用帧时间估算');
      }
    }
    this.startFrameMonitoring();
  }

  getState(): CPUState { return { ...this.cpuState }; }

  detectThermalState(): ThermalState {
    const now = Date.now();
    const recentHistory = this.longTaskHistory.filter(h => now - h.timestamp < 10000);
    const totalDuration = recentHistory.reduce((s, h) => s + h.duration, 0);
    const longTaskRatio = recentHistory.length > 0 ? totalDuration / (recentHistory.length * 1000) : 0;
    const continuousHighLoad = this.isContinuousHighLoad(30000);

    if (continuousHighLoad && longTaskRatio > 0.5) return 'critical';
    if (continuousHighLoad && longTaskRatio > 0.3) return 'hot';
    if (longTaskRatio > 0.15) return 'warm';
    return 'normal';
  }

  destroy(): void {
    this.longTaskObserver?.disconnect();
    if (this.frameCallback) cancelAnimationFrame(this.frameCallback);
  }

  private startFrameMonitoring(): void {
    this.lastFrameTime = performance.now();
    const measure = (timestamp: number) => {
      const frameTime = timestamp - this.lastFrameTime;
      this.lastFrameTime = timestamp;
      if (frameTime < 100) {
        this.frameTimeSamples.push(frameTime);
        if (this.frameTimeSamples.length > 60) this.frameTimeSamples.shift();
      }
      this.updateCPUState();
      this.frameCallback = requestAnimationFrame(measure);
    };
    this.frameCallback = requestAnimationFrame(measure);
  }

  private updateCPUState(): void {
    const now = Date.now();
    this.longTaskHistory = this.longTaskHistory.filter(h => now - h.timestamp < 5000);
    const longTaskCount = this.longTaskHistory.length;
    const longTaskDuration = this.longTaskHistory.reduce((s, h) => s + h.duration, 0);
    const mainThreadBlocked = longTaskDuration > 2500;
    const frameRate = this.calculateFrameRate();
    const avgFrameTime = this.frameTimeSamples.length > 0
      ? this.frameTimeSamples.reduce((s, t) => s + t, 0) / this.frameTimeSamples.length : 16.6;
    const load = Math.min(1, longTaskDuration / 5000);

    this.cpuState = { load, longTaskCount, longTaskDuration, mainThreadBlocked, frameRate, frameTime: avgFrameTime };
  }

  private calculateFrameRate(): number {
    if (this.frameTimeSamples.length < 2) return 60;
    const avgFrameTime = this.frameTimeSamples.reduce((s, t) => s + t, 0) / this.frameTimeSamples.length;
    return Math.round(1000 / avgFrameTime);
  }

  private isContinuousHighLoad(duration: number): boolean {
    const now = Date.now();
    const relevantHistory = this.longTaskHistory.filter(h => now - h.timestamp < duration);
    const windowSize = duration / 10;
    const windows = new Array(10).fill(0);
    for (const h of relevantHistory) {
      const windowIndex = Math.floor((now - h.timestamp) / windowSize);
      if (windowIndex >= 0 && windowIndex < 10) windows[windowIndex] += h.duration;
    }
    return windows.every(w => w > windowSize * 0.1);
  }

  private createDefaultState(): CPUState {
    return { load: 0, longTaskCount: 0, longTaskDuration: 0, mainThreadBlocked: false, frameRate: 60, frameTime: 16.6 };
  }
}
```

```typescript
// src/background/PerformanceBudgetManager.ts (新增)

class PerformanceBudgetManager {
  private currentMode: PerformanceMode = 'normal';
  private currentBudget: PerformanceBudget;
  private batteryMonitor: BatteryMonitor;
  private cpuMonitor: CPUMonitor | null = null;
  private preferences: PowerPreferences;
  private listeners: Array<(budget: PerformanceBudget) => void> = [];

  constructor(batteryMonitor: BatteryMonitor) {
    this.batteryMonitor = batteryMonitor;
    this.preferences = this.getDefaultPreferences();
    this.currentBudget = this.getBudgetForMode('normal');
  }

  async init(): Promise<void> {
    const saved = await chrome.storage.local.get('yipet_power_preferences');
    if (saved.yipet_power_preferences) {
      this.preferences = { ...this.preferences, ...saved.yipet_power_preferences };
    }
    this.batteryMonitor.onChange(() => {
      if (this.preferences.autoMode) this.evaluateAndSwitch();
    });
    if (this.preferences.autoMode) {
      this.evaluateAndSwitch();
    } else if (this.preferences.manualMode) {
      this.switchMode(this.preferences.manualMode);
    }
  }

  getCurrentBudget(): PerformanceBudget { return { ...this.currentBudget }; }
  getCurrentMode(): PerformanceMode { return this.currentMode; }

  async switchMode(mode: PerformanceMode): Promise<void> {
    if (mode === this.currentMode) return;
    const previousMode = this.currentMode;
    this.currentMode = mode;
    this.currentBudget = this.getBudgetForMode(mode);
    this.notifyListeners();
    this.emitPowerEvent({ type: 'mode_switch', timestamp: Date.now(), previousMode, currentMode: mode });
  }

  async updatePreferences(updates: Partial<PowerPreferences>): Promise<void> {
    this.preferences = { ...this.preferences, ...updates };
    await chrome.storage.local.set({ yipet_power_preferences: this.preferences });
    if (this.preferences.autoMode) {
      this.evaluateAndSwitch();
    } else if (this.preferences.manualMode) {
      this.switchMode(this.preferences.manualMode);
    }
  }

  onBudgetChange(listener: (budget: PerformanceBudget) => void): () => void {
    this.listeners.push(listener);
    return () => { this.listeners = this.listeners.filter(l => l !== listener); };
  }

  private evaluateAndSwitch(): void {
    const battery = this.batteryMonitor.getState();
    const cpu = this.cpuMonitor?.getState();
    const thermal = this.cpuMonitor?.detectThermalState();
    let targetMode: PerformanceMode = 'normal';

    if (!battery.charging) {
      if (battery.level <= this.preferences.batteryThresholds.critical) targetMode = 'critical';
      else if (battery.level <= this.preferences.batteryThresholds.saver) targetMode = 'saver';
    }
    if (thermal === 'critical' || thermal === 'hot') {
      targetMode = targetMode === 'critical' ? 'critical' : 'saver';
    }
    if (cpu && cpu.load > 0.8 && !battery.charging) {
      targetMode = targetMode === 'critical' ? 'critical' : 'saver';
    }
    if (battery.charging && battery.level > 0.3) targetMode = 'normal';

    if (targetMode !== this.currentMode) {
      this.switchMode(targetMode);
      if (targetMode === 'critical' && this.preferences.notifications.lowBatteryWarning) {
        this.sendLowBatteryNotification(battery.level);
      }
    }
  }

  private getBudgetForMode(mode: PerformanceMode): PerformanceBudget {
    const baseBudgets: Record<PerformanceMode, PerformanceBudget> = {
      normal: {
        mode: 'normal',
        animation: { targetFps: 60, maxParticles: 50, shadowsEnabled: true,
          blurEnabled: true, backgroundAnimations: true, fullSpriteSheet: true },
        network: { pollingInterval: 5000, sseMode: 'stream', syncInterval: 5000,
          batchRequests: false, prefetch: true },
        background: { deferredTasks: false, deferDelay: 0, heartbeatInterval: 5000,
          storageWriteBatch: false, storageBatchInterval: 0 },
        ui: { iconUpdateInterval: 0, domUpdateDebounce: 0,
          tooltipAnimations: true, transitionEffects: true },
      },
      saver: {
        mode: 'saver',
        animation: { targetFps: 30, maxParticles: 20, shadowsEnabled: true,
          blurEnabled: false, backgroundAnimations: false, fullSpriteSheet: false },
        network: { pollingInterval: 15000, sseMode: 'long-poll', syncInterval: 30000,
          batchRequests: true, prefetch: false },
        background: { deferredTasks: true, deferDelay: 30000, heartbeatInterval: 15000,
          storageWriteBatch: true, storageBatchInterval: 30000 },
        ui: { iconUpdateInterval: 30000, domUpdateDebounce: 500,
          tooltipAnimations: false, transitionEffects: true },
      },
      critical: {
        mode: 'critical',
        animation: { targetFps: 15, maxParticles: 0, shadowsEnabled: false,
          blurEnabled: false, backgroundAnimations: false, fullSpriteSheet: false },
        network: { pollingInterval: 30000, sseMode: 'paused', syncInterval: 0,
          batchRequests: true, prefetch: false },
        background: { deferredTasks: true, deferDelay: 120000, heartbeatInterval: 30000,
          storageWriteBatch: true, storageBatchInterval: 60000 },
        ui: { iconUpdateInterval: 60000, domUpdateDebounce: 1000,
          tooltipAnimations: false, transitionEffects: false },
      },
    };

    const base = baseBudgets[mode];
    const custom = this.preferences.customBudget[mode];
    return custom ? this.deepMerge(base, custom) : base;
  }

  private deepMerge<T extends Record<string, any>>(base: T, override: Partial<T>): T {
    const result = { ...base };
    for (const key of Object.keys(override) as (keyof T)[]) {
      if (typeof override[key] === 'object' && !Array.isArray(override[key])) {
        result[key] = this.deepMerge(base[key] as any, override[key] as any);
      } else {
        result[key] = override[key] as any;
      }
    }
    return result;
  }

  private notifyListeners(): void {
    for (const listener of this.listeners) {
      try { listener(this.getCurrentBudget()); } catch (err) {
        console.error('[YiPet] 性能预算监听器错误:', err);
      }
    }
  }

  private sendLowBatteryNotification(level: number): void {

      buttons: [{ title: '查看设置' }],
    });
  }

  private emitPowerEvent(event: PowerEvent): void {
    chrome.runtime.sendMessage({ type: 'POWER_EVENT', data: event }).catch(() => {});
  }

  private getDefaultPreferences(): PowerPreferences {
    return {
      autoMode: true,
      batteryThresholds: { saver: 0.2, critical: 0.1 },
      notifications: { lowBatteryWarning: true, modeSwitchNotification: true },
      customBudget: {},
    };
  }
}
```

```typescript
// src/animation/FrameRateController.ts (新增)

class FrameRateController {
  private targetFps: number = 60;
  private frameInterval: number = 1000 / 60;
  private lastFrameTime: number = 0;
  private animFrameId: number | null = null;
  private callbacks: Array<(deltaTime: number) => void> = [];

  setTargetFps(fps: number): void {
    this.targetFps = fps;
    this.frameInterval = 1000 / fps;
  }

  addCallback(cb: (deltaTime: number) => void): void {
    this.callbacks.push(cb);
  }

  removeCallback(cb: (deltaTime: number) => void): void {
    this.callbacks = this.callbacks.filter(c => c !== cb);
  }

  start(): void {
    const loop = (timestamp: number) => {
      if (timestamp - this.lastFrameTime >= this.frameInterval) {
        const deltaTime = timestamp - this.lastFrameTime;
        this.lastFrameTime = timestamp;
        for (const cb of this.callbacks) {
          try { cb(deltaTime); } catch (err) {
            console.error('[YiPet] 帧回调错误:', err);
          }
        }
      }
      this.animFrameId = requestAnimationFrame(loop);
    };
    this.lastFrameTime = performance.now();
    this.animFrameId = requestAnimationFrame(loop);
  }

  stop(): void {
    if (this.animFrameId) {
      cancelAnimationFrame(this.animFrameId);
      this.animFrameId = null;
    }
  }
}
```

## 九、设计决策记录

### D-01：性能模式的触发优先级

- **问题**：多个触发条件（电量、热量、CPU 负载）同时满足时，如何确定最终模式
- **选项**：取最严格模式、取第一个触发条件、加权投票
- **选择**：取最严格模式（critical > saver > normal）
- **理由**：电池和性能保护应该保守，多个条件触发时采用最严格的模式确保设备安全。例如电量 5%（critical）且 CPU 过热（saver），应取 critical。充电状态是例外——充电时始终恢复 normal。

### D-02：帧率切换的平滑策略

- **问题**：帧率从 60fps 切换到 15fps 时，如何避免用户感知到明显的卡顿
- **选项**：立即切换、逐步降帧（60->45->30->15）、动画过渡
- **选择**：逐步降帧（每 1 秒降低 15fps）
- **理由**：立即从 60fps 跳到 15fps 在视觉上非常突兀，用户会明显感知到"卡顿"。逐步降帧（60->45->30->15）在 3 秒内完成过渡，用户感知为"动画变慢"而非"卡顿"。恢复时同样逐步升帧。

### D-03：电池指示器的显示位置

- **问题**：电池指示器应该显示在哪里——宠物浮层、Popup、独立页面
- **选项**：仅在宠物浮层、仅在 Popup、两者都显示
- **选择**：Pet 浮层显示精简版（图标 + 百分比），Popup 显示完整信息
- **理由**：宠物浮层空间有限，仅显示电池图标和电量百分比（2 个字符）。Popup 有更多空间，可显示完整信息（剩余时间、性能模式、开关）。用户最常看到的是宠物浮层，精简版指示器提供"一目了然"的电池状态。

### D-04：热量检测的阈值设定

- **问题**：如何定义"设备过热"的阈值，不同设备的热量表现差异大
- **选项**：固定阈值（长任务占比 > 30%）、自适应阈值（基于设备基线）、用户可配置
- **选择**：固定阈值 + 自适应基线
- **理由**：首次运行时使用固定阈值（长任务占比 > 30%）作为初始判断。运行 1 小时后，收集设备的长任务基线数据（P50、P95），自适应调整阈值。例如设备基线 P95 为 20%，则阈值调整为 40%（2 倍 P95）。这样在不同设备上都有合理的判断。
