# PE-09-110: 会话陈旧标记

> 内容管理：对齐 YiVad Knowledge Base 的 stale 检测模式，在侧边栏中为 7+ 天未更新的会话显示 "stale" 黄色徽章。

## 背景

YiVad Knowledge Base 有 stale 内容检测（stale_count + StaleRiskTimeline）。YiPet 会话列表无陈旧感知，用户积累大量旧会话后难以识别哪些需要清理或回顾。

## 范围

- `isStale` computed：updatedAt/createdAt 距今 > 7 天
- 会话行时间旁显示黄色 "stale" 徽章
- tooltip: "Not updated in 7+ days"

## 验收标准

- [ ] 7+ 天未更新的会话显示黄色 "stale" 徽章
- [ ] 最近会话不显示
- [ ] tooltip 说明含义
