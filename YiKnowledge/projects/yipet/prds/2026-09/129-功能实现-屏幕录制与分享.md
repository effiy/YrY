# YP-09-122: 屏幕录制与分享 — chrome.tabCapture 标签页录制、桌面/摄像头多模式、语音旁白、剪辑编辑、WebM/MP4导出、聊天内分享、录制指示器、存储管理

> 需求编号：YP-09-122 · 优先级：P2 · 人天：0.5d · 状态：需求已编写
> 依赖：YP-09-101（截图与标注工具）、YP-09-79（IndexedDB 持久化）

## 背景

### 问题陈述

YiPet 用户在与 AI 宠物伴侣对话时，经常需要录制屏幕内容来演示问题、记录操作步骤或分享内容。当前用户需要切换到外部录屏工具（如 OBS、QuickTime），操作繁琐且与聊天流程割裂。这导致：

1. **操作割裂**：用户需要离开聊天窗口，打开外部录屏工具，录制完成后手动导入分享
2. **录制内容孤岛**：录制视频无法自动关联到聊天会话上下文，回顾时缺乏对话背景
3. **快速分享困难**：录制完成后需要手动导出、压缩、上传，再粘贴链接到聊天中
4. **隐私顾虑**：全屏录制时可能意外捕捉到聊天窗口外的敏感内容（如银行信息、密码输入）
5. **存储管理缺失**：录制的视频文件占用大量磁盘空间，缺乏自动清理机制

**核心矛盾**：在浏览器扩展的安全限制下，提供便捷的屏幕录制功能，既要支持多模式录制（标签页/桌面/摄像头），又要控制文件体积和自动管理存储空间，同时保证录制分享与聊天上下文无缝衔接。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 录制屏幕需要切换工具，操作繁琐 | 高 | 用户想录制网页操作步骤发给 AI 分析 |
| 2 | 录制视频无法关联到会话 | 中 | 录制的 bug 演示视频与 bug 讨论上下文分离 |
| 3 | 录制内容意外包含隐私信息 | 中 | 全屏录制时捕捉到聊天窗口外的密码输入框 |
| 4 | 视频文件占用空间无管理 | 中 | 多次录制后磁盘空间被大量视频文件占满 |
| 5 | 录制的视频太大无法快速分享 | 中 | 10 分钟录制 > 500MB，上传耗时过长 |

### 挑战

| 挑战 | 说明 |
|------|------|
| Chrome 权限限制 | `chrome.tabCapture` 需要在 Manifest 中声明，且仅支持前台标签页 |
| 视频编码与体积 | 原始视频体积巨大，需要实时编码压缩，平衡质量与文件大小 |
| 多流同步 | 标签页画面 + 麦克风音频 + 系统音频需要精确同步，否则音画不同步 |
| 跨世界通信 | Service Worker 管理录制生命周期，Content Script 展示录制 UI，需要可靠通信 |
| 导出格式兼容 | WebM 在 Safari 中不支持，需要提供 MP4 转码选项 |

## 二、设计决策

### 决策 1：录制 API 选择 — chrome.tabCapture vs MediaRecorder + getUserMedia vs getDisplayMedia

| 选项 | 标签页录制 | 桌面录制 | 摄像头录制 | 音频支持 | 权限要求 |
|------|-----------|----------|-----------|----------|----------|
| chrome.tabCapture | 完美 | 不适用 | 不适用 | 标签页音频 | 低（扩展权限） |
| getDisplayMedia | 不适用 | 完美 | 不适用 | 系统音频 | 高（用户授权弹窗） |
| getUserMedia | 不适用 | 不适用 | 完美 | 麦克风 | 中（用户授权弹窗） |
| 组合使用 | 标签页 | 桌面 | 摄像头 | 标签页+麦克风+系统 | 混合 |

**选择：组合使用，以 chrome.tabCapture 为主。** 标签页录制是最高频场景（用户录制网页操作），使用 `chrome.tabCapture` 无需用户额外授权弹窗，体验最优。桌面录制和摄像头录制作为辅助模式，使用 `getDisplayMedia` 和 `getUserMedia`。所有录制流通过 `MediaRecorder` API 统一编码。

### 决策 2：视频编码格式 — WebM (VP8/VP9) vs WebM (AV1) vs MP4 (H.264)

| 选项 | 浏览器兼容性 | 文件体积 | 编码性能 | 播放兼容性 |
|------|-------------|----------|----------|-----------|
| WebM VP8 | Chrome 全支持 | 中 | 快 | 仅 Chrome/Firefox |
| WebM VP9 | Chrome 全支持 | 小 | 中 | 仅 Chrome/Firefox |
| WebM AV1 | Chrome 70+ | 最小 | 慢 | 仅 Chrome/Firefox |
| MP4 H.264 | 需转码 | 中 | 需服务端 | 全平台 |

**选择：WebM VP9 录制 + MP4 导出选项。** 录制时使用 VP9 编码（Chrome 原生支持，性能好，体积小），保证录制时 CPU 开销低。导出分享时，通过 YiAi 后端 FFmpeg 转码为 MP4 H.264，保证全平台兼容。用户可在设置中选择"自动转码为 MP4"。

### 决策 3：录制 UI 位置 — 聊天窗口内嵌 vs 独立工具栏 vs 混合

| 选项 | 可见性 | 操作便捷 | 页面干扰 | 实现复杂度 |
|------|--------|----------|----------|------------|
| 聊天窗口内嵌 | 需打开聊天窗口 | 中 | 低 | 低 |
| 独立浮动工具栏 | 始终可见 | 高 | 中 | 中 |
| 混合（工具栏 + 聊天内嵌） | 高 | 高 | 中 | 高 |

**选择：独立浮动工具栏 + 聊天窗口内嵌状态。** 录制时在页面右下角显示浮动录制指示器（红点 + 计时器 + 暂停/停止按钮），最小化对页面的干扰。录制完成后视频自动出现在聊天窗口中。聊天窗口内提供录制入口按钮。

### 决策 4：视频存储方案 — chrome.storage.local vs IndexedDB vs 文件系统直接

| 选项 | 容量 | 大文件支持 | 查询 | 持久性 |
|------|------|-----------|------|--------|
| chrome.storage.local | 10MB | 不支持 | 键值 | 高 |
| IndexedDB | 无限制 | 支持 | 丰富 | 高 |
| chrome.downloads | 无限制 | 支持 | 无 | 中 |

**选择：IndexedDB 存储录制元数据 + Blob，过期自动清理。** IndexedDB 无容量限制，支持存储 Blob 对象（视频数据），支持按日期/会话/大小查询。录制完成后立即写入 IndexedDB，同时提供"下载到本地"选项。7 天自动清理过期录制。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 录制 API | tabCapture | getDisplayMedia | 组合使用 | **组合使用** | 覆盖多场景 |
| 视频编码 | WebM VP8 | WebM VP9 | MP4 H.264 | **VP9+MP4导出** | 性能与兼容平衡 |
| 录制 UI | 聊天内嵌 | 浮动工具栏 | 混合 | **浮动工具栏** | 最小干扰 |
| 视频存储 | chrome.storage | IndexedDB | 文件系统 | **IndexedDB** | 容量无限制 |

### 4.2 录制管理器

```typescript
// src/content/recording/RecordingManager.ts (新增)

class RecordingManager {
  private mediaRecorder: MediaRecorder | null = null;
  private mediaStream: MediaStream | null = null;
  private recordedChunks: Blob[] = [];
  private currentRecording: Recording | null = null;
  private startTime: number = 0;
  private timerInterval: ReturnType<typeof setInterval> | null = null;
  private onStatusChange: ((status: RecordingStatus) => void) | null = null;
  private onTimerUpdate: ((elapsed: number) => void) | null = null;

  private readonly qualityConfigs = {
    low:    { frameRate: 15, videoBitrate: 1_000_000 },  // 1 Mbps
    medium: { frameRate: 15, videoBitrate: 2_500_000 },  // 2.5 Mbps
    high:   { frameRate: 30, videoBitrate: 4_000_000 },  // 4 Mbps
  };

  /**
   * 开始录制
   */
  async startRecording(config: RecordingConfig): Promise<void> {
    this.setStatus('preparing');

    try {
      this.mediaStream = await this.captureStream(config.mode);

      // 添加麦克风音轨
      if (config.includeMicrophone) {
        const micStream = await navigator.mediaDevices.getUserMedia({
          audio: { echoCancellation: true, noiseSuppression: true },
        });
        const micTrack = micStream.getAudioTracks()[0];
        this.mediaStream.addTrack(micTrack);
      }

      const qc = this.qualityConfigs[config.quality];
      const mimeType = this.getSupportedMimeType();

      this.mediaRecorder = new MediaRecorder(this.mediaStream, {
        mimeType,
        videoBitsPerSecond: qc.videoBitrate,
      });

      this.recordedChunks = [];
      this.mediaRecorder.ondataavailable = (event) => {
        if (event.data.size > 0) {
          this.recordedChunks.push(event.data);
        }
      };

      this.mediaRecorder.onstop = async () => {
        const blob = new Blob(this.recordedChunks, { type: mimeType });
        await this.finalizeRecording(blob);
      };

      this.mediaRecorder.onerror = () => {
        this.setStatus('failed');
      };

      // 开始录制，每秒产生一个数据块
      this.mediaRecorder.start(1000);
      this.startTime = Date.now();
      this.setStatus('recording');
      this.startTimer();

      // 最大录制时长自动停止
      if (config.maxDuration > 0) {
        setTimeout(() => {
          if (this.currentRecording?.status === 'recording') {
            this.stopRecording();
          }
        }, config.maxDuration * 1000);
      }

    } catch (error) {
      this.setStatus('failed');
      throw error;
    }
  }

  /**
   * 暂停录制
   */
  pauseRecording(): void {
    if (this.mediaRecorder?.state === 'recording') {
      this.mediaRecorder.pause();
      this.setStatus('paused');
      this.stopTimer();
    }
  }

  /**
   * 恢复录制
   */
  resumeRecording(): void {
    if (this.mediaRecorder?.state === 'paused') {
      this.mediaRecorder.resume();
      this.setStatus('recording');
      this.startTimer();
    }
  }

  /**
   * 停止录制
   */
  stopRecording(): void {
    if (this.mediaRecorder?.state !== 'inactive') {
      this.setStatus('stopping');
      this.mediaRecorder.stop();
      this.stopTimer();
    }
  }

  /**
   * 获取录制列表
   */
  async getRecordings(sessionId?: string): Promise<Recording[]> {
    const db = await this.openDB();
    const tx = db.transaction('recordings', 'readonly');
    const store = tx.objectStore('recordings');

    let recordings: Recording[];
    if (sessionId) {
      const index = store.index('sessionId');
      recordings = await this.getAllFromIndex(index, sessionId);
    } else {
      recordings = await this.getAll(store);
    }

    // 过滤掉已过期的
    const now = Date.now();
    return recordings.filter(r => r.expiresAt > now);
  }

  /**
   * 剪辑录制
   */
  async clipRecording(recordingId: string, clip: RecordingClip): Promise<Blob> {
    const recording = await this.getRecording(recordingId);
    if (!recording?.blob) {
      throw new Error('Recording not found');
    }

    // 使用 MediaSource API 或 FFmpeg.wasm 进行剪辑
    // 简化方案：使用 Canvas + 视频元素进行精确剪辑
    return this.extractClip(recording.blob, clip.startOffset, clip.endOffset);
  }

  /**
   * 导出录制
   */
  async exportRecording(
    recordingId: string,
    options: RecordingExportOptions
  ): Promise<{ blob: Blob; fileName: string }> {
    const recording = await this.getRecording(recordingId);
    if (!recording?.blob) {
      throw new Error('Recording not found');
    }

    let blob = recording.blob;

    // 如果有剪辑，先提取片段
    if (options.clip) {
      blob = await this.clipRecording(recordingId, options.clip);
    }

    // 如果需要 MP4 格式，通过 YiAi 转码
    if (options.format === 'mp4') {
      blob = await this.transcodeToMP4(blob);
    }

    const extension = options.format === 'mp4' ? 'mp4' : 'webm';
    const fileName = `recording-${recording.id.slice(0, 8)}.${extension}`;

    return { blob, fileName };
  }

  /**
   * 分享录制到聊天
   */
  async shareToChat(recordingId: string, sessionId: string): Promise<string> {
    const recording = await this.getRecording(recordingId);
    if (!recording?.blob) {
      throw new Error('Recording not found');
    }

    // 上传到 YiAi 文件存储
    const formData = new FormData();
    formData.append('file', recording.blob, `recording-${recordingId}.webm`);
    formData.append('session_id', sessionId);
    formData.append('type', 'recording');

    const response = await this.apiClient.uploadFile(
      'services.recording.upload',
      formData
    );

    // 标记为已分享
    await this.markAsShared(recordingId);

    return response.data.fileUrl;
  }

  /**
   * 清理过期录制
   */
  async cleanupExpired(): Promise<number> {
    const db = await this.openDB();
    const tx = db.transaction('recordings', 'readwrite');
    const store = tx.objectStore('recordings');
    const now = Date.now();

    const allRecordings = await this.getAll(store);
    let deletedCount = 0;

    for (const recording of allRecordings) {
      if (recording.expiresAt <= now) {
        store.delete(recording.id);
        deletedCount++;
      }
    }

    await tx.done;
    return deletedCount;
  }

  /**
   * 删除录制
   */
  async deleteRecording(recordingId: string): Promise<void> {
    const db = await this.openDB();
    const tx = db.transaction('recordings', 'readwrite');
    tx.objectStore('recordings').delete(recordingId);
    await tx.done;
  }

  // --- 私有方法 ---

  private async captureStream(mode: RecordingMode): Promise<MediaStream> {
    switch (mode) {
      case 'tab':
        return this.captureTab();
      case 'desktop':
        return this.captureDesktop();
      case 'camera':
        return this.captureCamera();
    }
  }

  private async captureTab(): Promise<MediaStream> {
    // 通过 Service Worker 获取 tabCapture 流
    return new Promise((resolve, reject) => {
      chrome.runtime.sendMessage(
        { type: 'start_tab_capture', tabId: chrome.runtime.id },
        (response) => {
          if (response.streamId) {
            // 在 Content Script 中通过 streamId 获取 MediaStream
            navigator.mediaDevices.getUserMedia({
              audio: false,
              video: {
                mandatory: {
                  chromeMediaSource: 'tab',
                  chromeMediaSourceId: response.streamId,
                },
              },
            } as any).then(resolve).catch(reject);
          } else {
            reject(new Error(response.error || 'Failed to start tab capture'));
          }
        }
      );
    });
  }

  private async captureDesktop(): Promise<MediaStream> {
    return navigator.mediaDevices.getDisplayMedia({
      video: { frameRate: { ideal: 15 } },
      audio: true, // 系统音频
    });
  }

  private async captureCamera(): Promise<MediaStream> {
    return navigator.mediaDevices.getUserMedia({
      video: { width: 1280, height: 720, frameRate: 30 },
      audio: false,
    });
  }

  private async finalizeRecording(blob: Blob): Promise<void> {
    if (!this.currentRecording) return;

    const duration = (Date.now() - this.startTime) / 1000;

    // 生成缩略图
    const thumbnailUrl = await this.generateThumbnail(blob);

    this.currentRecording = {
      ...this.currentRecording,
      status: 'completed',
      endTime: Date.now(),
      duration,
      blob,
      size: blob.size,
      thumbnailUrl,
      mimeType: blob.type,
    };

    await this.saveRecording(this.currentRecording);
    this.setStatus('completed');

    // 释放资源
    this.mediaStream?.getTracks().forEach(track => track.stop());
    this.mediaStream = null;
    this.mediaRecorder = null;
  }

  private async generateThumbnail(blob: Blob): Promise<string> {
    return new Promise((resolve) => {
      const video = document.createElement('video');
      video.src = URL.createObjectURL(blob);
      video.currentTime = 1; // 第 1 秒的画面

      video.onloadeddata = () => {
        const canvas = document.createElement('canvas');
        canvas.width = 320;
        canvas.height = 180;
        const ctx = canvas.getContext('2d')!;
        ctx.drawImage(video, 0, 0, canvas.width, canvas.height);
        resolve(canvas.toDataURL('image/jpeg', 0.7));
        URL.revokeObjectURL(video.src);
      };

      video.onerror = () => {
        resolve('');
        URL.revokeObjectURL(video.src);
      };
    });
  }

  private async extractClip(
    blob: Blob,
    startOffset: number,
    endOffset: number
  ): Promise<Blob> {
    // 使用 Canvas + MediaRecorder 重新录制剪辑片段
    // 简化实现：使用 OffscreenCanvas 进行精确帧提取
    return new Promise((resolve, reject) => {
      const video = document.createElement('video');
      video.src = URL.createObjectURL(blob);

      const canvas = document.createElement('canvas');
      const ctx = canvas.getContext('2d')!;
      const chunks: Blob[] = [];

      video.onloadedmetadata = () => {
        canvas.width = video.videoWidth;
        canvas.height = video.videoHeight;
        video.currentTime = startOffset;
      };

      video.onseeked = () => {
        const stream = canvas.captureStream(15);
        const recorder = new MediaRecorder(stream, {
          mimeType: 'video/webm;codecs=vp9',
          videoBitsPerSecond: 2_500_000,
        });

        recorder.ondataavailable = (e) => chunks.push(e.data);
        recorder.onstop = () => {
          resolve(new Blob(chunks, { type: 'video/webm' }));
          URL.revokeObjectURL(video.src);
        };

        recorder.start();
        video.play();

        // 到达结束时间时停止
        const checkEnd = setInterval(() => {
          if (video.currentTime >= endOffset) {
            video.pause();
            recorder.stop();
            clearInterval(checkEnd);
          }
        }, 100);
      };

      video.onerror = () => reject(new Error('Failed to load video'));
    });
  }

  private async transcodeToMP4(blob: Blob): Promise<Blob> {
    const formData = new FormData();
    formData.append('file', blob, 'input.webm');
    formData.append('target_format', 'mp4');

    const response = await this.apiClient.uploadFile(
      'services.recording.transcode',
      formData
    );

    // 下载转码后的 MP4
    const mp4Response = await fetch(response.data.downloadUrl);
    return mp4Response.blob();
  }

  private getSupportedMimeType(): string {
    const types = [
      'video/webm;codecs=vp9,opus',
      'video/webm;codecs=vp9',
      'video/webm;codecs=vp8',
      'video/webm',
    ];
    for (const type of types) {
      if (MediaRecorder.isTypeSupported(type)) {
        return type;
      }
    }
    return 'video/webm';
  }

  private setStatus(status: RecordingStatus): void {
    if (this.currentRecording) {
      this.currentRecording.status = status;
    }
    this.onStatusChange?.(status);
  }

  private startTimer(): void {
    this.timerInterval = setInterval(() => {
      const elapsed = Math.floor((Date.now() - this.startTime) / 1000);
      this.onTimerUpdate?.(elapsed);
    }, 1000);
  }

  private stopTimer(): void {
    if (this.timerInterval) {
      clearInterval(this.timerInterval);
      this.timerInterval = null;
    }
  }

  private async openDB(): Promise<IDBDatabase> {
    return new Promise((resolve, reject) => {
      const request = indexedDB.open('yipet_recordings', 1);
      request.onupgradeneeded = () => {
        const db = request.result;
        const store = db.createObjectStore('recordings', { keyPath: 'id' });
        store.createIndex('sessionId', 'sessionId', { unique: false });
        store.createIndex('createdAt', 'createdAt', { unique: false });
        store.createIndex('expiresAt', 'expiresAt', { unique: false });
      };
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
  }

  private async getAll(store: IDBObjectStore): Promise<Recording[]> {
    return new Promise((resolve, reject) => {
      const request = store.getAll();
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
  }

  private async getAllFromIndex(
    index: IDBIndex,
    value: string
  ): Promise<Recording[]> {
    return new Promise((resolve, reject) => {
      const request = index.getAll(value);
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
  }

  private async getRecording(id: string): Promise<Recording | undefined> {
    const db = await this.openDB();
    return new Promise((resolve, reject) => {
      const request = db.transaction('recordings', 'readonly')
        .objectStore('recordings')
        .get(id);
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
  }

  private async saveRecording(recording: Recording): Promise<void> {
    const db = await this.openDB();
    const tx = db.transaction('recordings', 'readwrite');
    tx.objectStore('recordings').put(recording);
    await tx.done;
  }

  private async markAsShared(id: string): Promise<void> {
    const db = await this.openDB();
    const tx = db.transaction('recordings', 'readwrite');
    const store = tx.objectStore('recordings');
    const recording = await new Promise<Recording>((resolve, reject) => {
      const request = store.get(id);
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(request.error);
    });
    recording.shared = true;
    store.put(recording);
    await tx.done;
  }

  private apiClient: any; // 注入的 ApiClient 实例
}
```

```typescript
// Service Worker 中处理 chrome.tabCapture
// 功能：
// - 监听 Content Script 的录制请求
// - 调用 chrome.tabCapture.getMediaStreamId 获取 streamId
// - 返回 streamId 给 Content Script
// - 监听 tabCapture 状态变化
// - 处理录制权限检查

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'start_tab_capture') {
    chrome.tabCapture.getMediaStreamId(
      { targetTabId: sender.tab?.id },
      (streamId) => {
        if (chrome.runtime.lastError) {
          sendResponse({ error: chrome.runtime.lastError.message });
        } else {
          sendResponse({ streamId });
        }
      }
    );
    return true; // 异步响应
  }
});
```

## 七、风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| chrome.tabCapture 在部分 Chrome 版本中不可用或被限制 | 低 | 高 | 检测 `chrome.tabCapture` API 可用性，不可用时自动降级为 `getDisplayMedia` 桌面录制模式 |
| 长时间录制导致 IndexedDB 写入性能下降，Blob 数据过大 | 中 | 中 | 每 10 秒将 chunks 写入 IndexedDB，避免内存积累。限制单次录制时长 10 分钟，超时自动停止 |
| 录制时页面切换标签页导致录制中断 | 中 | 中 | 监听 `visibilitychange` 事件，标签页隐藏时自动暂停录制，恢复时提示用户是否继续 |
| MediaRecorder 在某些情况下不触发 ondataavailable | 低 | 中 | 设置 `timeslice` 为 1000ms 确保数据块定期产生，添加 5 秒无数据超时检测 |
| 视频转码 MP4 时 YiAi 后端 FFmpeg 处理超时或失败 | 中 | 中 | 转码超时设置为 2 分钟，失败时返回原始 WebM 文件并提示用户 |
| 录制内容包含敏感信息（密码、银行卡号） | 低 | 高 | 提供"安全区域"录制选项，仅录制页面可见区域，排除地址栏和扩展图标。录制前提示用户检查页面内容 |

## 八、回滚策略

| 场景 | 回滚操作 | 影响 |
|------|----------|------|
| 录制导致页面性能严重下降 | 自动停止录制，释放 MediaStream 资源 | 录制不可用 |
| chrome.tabCapture 权限被拒绝 | 隐藏"当前标签页"模式，仅保留桌面和摄像头模式 | 标签页录制不可用 |
| IndexedDB 写入失败 | 降级为内存缓存，录制完成后提示下载到本地 | 录制不持久化 |
| 视频转码服务不可用 | 仅提供 WebM 格式下载，隐藏 MP4 选项 | 跨平台兼容性降低 |
| 剪辑功能导致内存溢出 | 禁用电视频剪辑功能，仅提供完整视频分享 | 剪辑不可用 |

## 九、设计决策记录

### D-01：录制 API 架构

- **问题**：如何在浏览器扩展中实现屏幕录制，选择哪种 API
- **选项**：仅 chrome.tabCapture、仅 getDisplayMedia、组合使用
- **选择**：组合使用（tabCapture 为主 + getDisplayMedia 辅助）
- **理由**：标签页录制是最高频场景（用户录制网页操作），chrome.tabCapture 无需用户授权弹窗，体验最优。桌面录制和摄像头录制作为补充，覆盖演示和视频消息场景。三种模式通过统一接口（RecordingManager）封装，调用方无需关心底层 API 差异。

### D-02：视频编码选择

- **问题**：录制时使用什么编码格式，如何平衡性能和质量
- **选项**：VP8（快但大）、VP9（中等）、AV1（慢但小）、H.264（兼容好）
- **选择**：VP9 录制 + H.264 转码导出
- **理由**：VP9 编码在 Chrome 中原生硬件加速支持，性能好且体积比 VP8 小 30-50%。录制时使用 VP9 保证实时编码性能，导出分享时通过服务端 FFmpeg 转码为 H.264 MP4 保证全平台播放兼容性。AV1 编码速度太慢不适合实时录制。

### D-03：剪辑实现方案

- **问题**：如何在浏览器中实现视频剪辑（裁剪起止时间）
- **选项**：FFmpeg.wasm（前端 WASM 转码）、Canvas 重新录制、服务端剪辑
- **选择**：Canvas + MediaRecorder 重新录制
- **理由**：FFmpeg.wasm 体积约 30MB，加载时间长且内存占用高，不适合扩展场景。Canvas 重新录制方案利用浏览器原生能力，无需额外依赖，对于 5 分钟以内的视频剪辑性能足够。服务端剪辑作为备选方案（大视频剪辑）。

### D-04：存储清理策略

- **问题**：录制的视频文件如何管理存储空间
- **选项**：永久保留、固定数量上限、过期时间自动删除
- **选择**：7 天过期自动删除 + 分享后永久保留
- **理由**：录制视频通常用于临时分享和问题演示，7 天后价值大幅降低。分享到聊天的视频会上传到 YiAi 后端持久化，本地仅保留 7 天缓存。用户可手动将重要录制"标记为保留"以跳过自动清理。

## 回归问题预测

| # | 预测问题 | 原因 | 验证方法 |
|---|---------|------|---------|
| 1 | chrome.tabCapture.getMediaStreamId 在 Service Worker 中调用时，因 SW 不活跃被浏览器终止，返回 undefined 或超时 | Service Worker 生命周期管理，空闲时浏览器会终止 SW，导致异步回调无法执行 | 在 SW 中使用 `chrome.runtime.connect` 保持长连接，录制期间 SW 不进入空闲状态。添加 3 秒超时和重试机制 |
| 2 | MediaRecorder 在标签页切换或浏览器最小化时，ondataavailable 事件停止触发，导致录制结束后 Blob 为空 | 浏览器在标签页不可见时会降低 MediaRecorder 的优先级，可能暂停数据块产生 | 在 `visibilitychange` 事件中检测录制状态，页面不可见时暂停录制并提示用户。避免在不可见时持续录制 |
| 3 | 视频剪辑时 Canvas 重新录制的视频与原始视频存在音画不同步，特别是长时间剪辑 | Canvas 的 captureStream 仅捕捉画面，音频需要单独处理，重新混流时可能出现同步偏移 | 剪辑时分别提取视频轨和音频轨，使用 AudioContext 的 `currentTime` 与视频帧时间戳对齐，确保音画同步 |
| 4 | IndexedDB 中存储的 Blob 引用在 Service Worker 更新后失效，导致已保存的录制无法播放 | Service Worker 更新会导致 IndexedDB Blob 引用失效，浏览器可能清理旧 SW 的 Blob 存储 | 在 Service Worker 更新前将 Blob 数据转为 ArrayBuffer 存储。或在 SW 更新时触发录制数据迁移 |
| 5 | 用户在录制过程中关闭了浏览器标签页，录制中断但未触发 onstop 事件，MediaStream 资源泄露 | 标签页关闭时 MediaRecorder 可能不会正常触发 onstop，导致 MediaStream 未释放 | 在 `beforeunload` 事件中主动调用 `stopRecording()` 和 `mediaStream.getTracks().forEach(t => t.stop())`，确保资源释放 |
| 6 | 录制工具栏的浮动定位使用 `position: fixed`，在某些使用了 CSS `transform` 的页面中定位异常（fixed 相对于 transform 容器） | CSS `position: fixed` 在父元素有 `transform`、`filter` 或 `perspective` 时，会相对于该父元素定位而非视口 | 使用 `position: absolute` + 动态计算视口坐标，或在 Shadow DOM 的 `:host` 中设置 `all: initial` 重置所有继承属性。定期检测工具栏实际位置与预期位置是否一致 |
