# PE-09-103: StatsBar 数据新鲜度指示器

> 跨项目 UI 对齐：YiVad Home 页面有绿点脉冲 + MM:SS 年龄显示 + Refresh 按钮（`DataFreshnessBar` 组件），YiPet StatsBar 无数据新鲜度感知。

## 背景

YiVad 首页（`views/home/index.vue`）和新增的 `DataFreshnessBar` 组件使用：
- 绿色脉冲圆点（2s 呼吸动画）表示数据新鲜（< 60s）
- 年龄显示：`just now` / `2:45` / `5m ago`
- Refresh 按钮重新获取数据

YiPet StatsBar（第 1 轮实现）展示会话/知识/Bug/今日统计，但无数据新鲜度感知。用户不知道数据是 5 秒前还是 5 分钟前同步的。

## 范围

**In scope**：
- Chat store 新增 `lastSyncTime` 字段（会话加载完成时设置）
- StatsBar 新增新鲜度区域：脉冲圆点 + 年龄标签 + 刷新按钮
- 绿色脉冲（2s 呼吸动画，< 60s）+ 灰色（> 60s）

**Out of scope**：
- 自动轮询刷新
- 知识/Bug 数据的独立时间戳

## 验收标准

- [ ] 会话加载完成后显示 `just now` + 绿色脉冲圆点
- [ ] 60s 后圆点变灰，显示 `1m ago`
- [ ] 点击刷新按钮重新加载数据
