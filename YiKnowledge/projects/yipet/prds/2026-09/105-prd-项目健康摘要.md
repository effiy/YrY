# PE-09-105: 项目健康摘要卡片

> 跨项目数据打通：YiPet 新增 `DashboardService.getSummary()` API（调用 YiAi `/dashboard/summary`），在 YiVad 项目页上自动展示项目健康摘要（Issues/Bugs/Done/Overdue + 子项目健康状况）。

## 背景

YiAi 新增 `GET /dashboard/summary` 端点（`server/routes/dashboard/live.py`），返回：
```json
{
  "active_projects": 4, "total_issues": 120, "open_issues": 45,
  "open_bugs": 12, "today_done": 8, "overdue": 3, "blocked": 2,
  "chat_sessions": 56, "knowledge_files": 230, "server_uptime": 48,
  "projects": [{"key":"yivad","name":"YiVad","open_issues":15,"open_bugs":3,"health":"healthy"},...]
}
```

YiPet 已注册 `DashboardService` 但未接入聊天 UI。在浏览 YiVad 项目页时，YiPet 可自动展示项目健康数据。

## 范围

**In scope**：
- `services.ts` 新增 `getDashboard()` 访问器，注入 `DashboardService`
- `ProjectHealthCard.vue` 组件 — 仅在 YiVad 项目页上显示
- 4 格统计（Issues/Bugs/Done/Overdue）+ 子项目列表（含健康色彩点）
- 自动检测 URL（`localhost:8848/*/project/*`）

| 优先级 | 故事 | 验收标准 |
|--------|------|----------|
| P1 | 服务注入 | DashboardService 可通过 getDashboard() 访问 |
| P1 | 健康卡片 | YiVad 项目页上显示 Issues/Bugs/Done/Overdue 统计 |
| P2 | 子项目列表 | 显示各子项目健康状态点（绿/黄/红）+ Issues/Bugs 数 |

## 验收标准

- [ ] 打开任意 YiVad 项目页（如 `/project/yivad`），聊天窗口显示项目健康卡片
- [ ] 打开非项目页（如百度首页），卡片不显示
- [ ] 卡片显示 4 格实时统计 + 最多 4 个子项目健康状态
- [ ] YiAi 不可达时显示错误提示，不影响聊天功能
