# YP-09-119: 书签与网页收藏管理 — chrome.bookmarks 集成、AI 摘要标签、语义搜索与死链检测

> 需求编号：YP-09-119 · 优先级：P2 · 人天：0.3d · 状态：需求已编写
> 依赖：YP-09-42（上下文感知菜单）、YP-09-99（右键菜单集成）

## 背景

### 问题陈述

YiPet 当前无法将用户浏览的网页与聊天上下文关联，用户的书签管理依赖浏览器原生功能，存在以下痛点：

1. **书签与对话脱节**：用户在对话中讨论某个网页，但该网页无法自动关联到会话上下文
2. **书签组织混乱**：浏览器自带书签管理器仅支持文件夹分类，缺少标签和语义搜索
3. **AI 无法感知书签**：AI 对话中无法引用用户的书签内容，回答缺少个人化上下文
4. **死链积累**：书签中长期积累的失效链接无人清理，点击后才发现 404
5. **导入导出不便**：浏览器书签 HTML 导出格式与其他工具兼容性一般

**核心矛盾**：在 Chrome 扩展中增强书签管理，既要利用 chrome.bookmarks API 读取和操作用户书签，又要提供 AI 驱动的摘要、标签和语义搜索能力，同时保持与浏览器原生书签系统的兼容性。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 对话中无法引用浏览的网页 | 高 | 用户说"帮我总结刚才那个页面"，AI 无法获取 |
| 2 | 书签太多找不到 | 中 | 用户有 500+ 书签，靠记忆搜索 |
| 3 | 书签失效无人知晓 | 中 | 收藏的 3 年前的页面已 404 |
| 4 | 阅读列表无法追踪进度 | 中 | 想稍后阅读的页面忘记了 |
| 5 | 书签无法导出到其他工具 | 低 | 换浏览器时迁移困难 |

### 挑战

| 挑战 | 说明 |
|------|------|
| chrome.bookmarks 权限 | 需要 `bookmarks` 权限，用户可能对隐私敏感 |
| AI 摘要质量 | 页面内容提取 + AI 摘要的质量直接影响搜索效果 |
| 语义搜索性能 | 需要对所有书签进行向量化存储和相似度搜索 |
| 死链检测效率 | 检测大量书签时需控制请求频率，避免被限流 |
| 与原生书签一致性 | 用户通过 YiPet 操作书签后，原生书签管理器需同步更新 |

## 二、设计决策

### 决策 1：书签存储 — 仅 chrome.bookmarks vs 独立存储 vs 双写

| 选项 | 与浏览器集成 | 扩展性 | 一致性 | 复杂度 |
|------|-------------|--------|--------|--------|
| 仅 chrome.bookmarks | 完全兼容 | 低（无自定义字段） | 自动 | 低 |
| 独立存储（IndexedDB） | 不兼容 | 高 | 手动维护 | 中 |
| 双写（bookmarks + 本地索引） | 完全兼容 | 高 | 需同步 | 中 |

**选择：双写模式。** 基础书签数据（标题、URL、文件夹、创建时间）通过 chrome.bookmarks API 读写，保证与浏览器原生书签完全兼容。AI 生成的摘要、标签、向量嵌入、阅读进度等扩展数据存储在 chrome.storage.local 中，通过书签 ID 关联。用户删除书签时同步清除扩展数据。

### 决策 2：AI 摘要生成 — 本地提取 vs 服务端 AI vs 混合

| 选项 | 延迟 | 质量 | 离线 | 成本 |
|------|------|------|------|------|
| 本地提取（页面 meta + 前 500 字） | 即时 | 中 | 是 | 无 |
| 服务端 AI（YiAi 全文摘要） | 2-5s | 高 | 否 | AI 推理 |
| 混合（本地提取 + AI 摘要） | 考虑 | 高 | 部分 | 低 |

**选择：混合模式。** 保存时立即生成本地摘要（提取页面 title、meta description、正文前 500 字），用户可即时看到结果。后台异步调用 YiAi AI 生成高质量摘要和标签（2-5s），完成后更新本地索引。AI 摘要失败时回退到本地提取结果。

### 决策 3：语义搜索 — 本地向量 vs 服务端向量 vs 关键词增强

| 选项 | 搜索质量 | 离线 | 存储 | 延迟 |
|------|----------|------|------|------|
| 本地向量（Transformers.js） | 高 | 是 | 大（每书签 ~1KB） | 中 |
| 服务端向量（YiAi RAG） | 高 | 否 | 小 | 高 |
| 关键词增强（TF-IDF + 同义词） | 中 | 是 | 小 | 低 |

**选择：关键词增强 + 服务端向量。** 前端使用 TF-IDF + 同义词扩展实现离线关键词搜索（覆盖 80% 场景）。需要语义理解时转发到 YiAi RAG 引擎进行向量搜索。避免在前端加载大型 ML 模型（Transformers.js 体积 > 50MB）。

### 决策 4：死链检测策略 — 全量扫描 vs 增量扫描 vs 按需检测

| 选项 | 覆盖面 | 网络开销 | 实时性 |
|------|--------|----------|--------|
| 全量扫描（所有书签） | 100% | 高 | 差 |
| 增量扫描（最近 N 天/新增） | 部分 | 低 | 中 |
| 按需检测（用户点击时） | 按需 | 极低 | 即时 |

**选择：增量扫描 + 按需检测。** 每周后台扫描一次超过 30 天的书签，每次限制 50 个（避免触发限流）。用户点击书签时实时检测链接可用性。死链标记为"可能失效"而非直接删除，用户确认后操作。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 书签存储 | 仅 chrome.bookmarks | 独立存储 | 双写 | **双写** | 兼容 + 扩展 |
| AI 摘要 | 本地提取 | 服务端 AI | 混合 | **混合** | 即时 + 高质量 |
| 语义搜索 | 本地向量 | 服务端向量 | 关键词增强 | **关键词+服务端** | 体积 + 离线 |
| 死链检测 | 全量扫描 | 增量扫描 | 按需检测 | **增量+按需** | 网络友好 |

## 四、具体改动

### 4.1 书签服务核心

```typescript
// src/service/BookmarkService.ts (新增)

interface BookmarkMetadata {
  bookmarkId: string;
  aiSummary: string;
  aiTags: string[];
  tags: string[];
  customNotes: string;
  readingProgress: {
    status: 'unread' | 'reading' | 'completed';
    scrollPosition: number;
    readPercentage: number;
    lastReadAt: number;
  };
  healthCheck: {
    lastChecked: number;
    status: 'ok' | 'timeout' | 'not_found' | 'error' | 'unknown';
    httpStatus: number | null;
    checkedAt: number;
  };
  savedAt: number;
  savedFrom: 'popup' | 'context_menu' | 'chat' | 'omnibox' | 'native';
  associatedSessionId: string;
  starred: boolean;
}

class BookmarkService {
  private metadataCache: Map<string, BookmarkMetadata> = new Map();
  private searchIndex: SearchIndex | null = null;
  private apiClient: ApiClient;

  async init(): Promise<void> {
    // 加载扩展元数据
    const stored = await chrome.storage.local.get('bookmark_metadata');
    if (stored.bookmark_metadata) {
      this.metadataCache = new Map(Object.entries(stored.bookmark_metadata));
    }

    // 构建搜索索引
    this.searchIndex = new SearchIndex(this.metadataCache);

    // 监听书签变化
    chrome.bookmarks.onCreated.addListener(this.handleBookmarkCreated.bind(this));
    chrome.bookmarks.onRemoved.addListener(this.handleBookmarkRemoved.bind(this));
    chrome.bookmarks.onChanged.addListener(this.handleBookmarkChanged.bind(this));
  }

  /**
   * 保存当前页面为书签（带 AI 摘要）
   */
  async saveCurrentPage(options?: {
    folderId?: string;
    tags?: string[];
    notes?: string;
    sessionId?: string;
  }): Promise<chrome.bookmarks.BookmarkTreeNode> {
    const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });
    if (!tab?.url || !tab?.title) {
      throw new Error('Cannot access current page');
    }

    // 1. 创建浏览器书签
    const bookmark = await chrome.bookmarks.create({
      parentId: options?.folderId,
      title: tab.title,
      url: tab.url,
    });

    // 2. 生成本地摘要
    const localSummary = await this.extractLocalSummary(tab);

    // 3. 创建元数据
    const metadata: BookmarkMetadata = {
      bookmarkId: bookmark.id,
      aiSummary: localSummary,
      aiTags: options?.tags || [],
      tags: options?.tags || [],
      customNotes: options?.notes || '',
      readingProgress: {
        status: 'unread',
        scrollPosition: 0,
        readPercentage: 0,
        lastReadAt: Date.now(),
      },
      healthCheck: {
        lastChecked: 0,
        status: 'unknown',
        httpStatus: null,
        checkedAt: 0,
      },
      savedAt: Date.now(),
      savedFrom: options?.sessionId ? 'chat' : 'popup',
      associatedSessionId: options?.sessionId || '',
      starred: false,
    };

    // 4. 存储元数据
    this.metadataCache.set(bookmark.id, metadata);
    this.searchIndex?.addDocument(bookmark.id, bookmark.title, metadata);
    await this.persistMetadata();

    // 5. 后台异步生成 AI 摘要
    this.generateAISummary(bookmark.id, tab.url!, tab.title!);

    return bookmark;
  }

  /**
   * 本地提取页面摘要
   */
  private async extractLocalSummary(tab: chrome.tabs.Tab): Promise<string> {
    try {
      const results = await chrome.scripting.executeScript({
        target: { tabId: tab.id! },
        func: () => {
          const meta = document.querySelector('meta[name="description"]')?.getAttribute('content') || '';
          const body = document.body.innerText.slice(0, 500).replace(/\s+/g, ' ');
          return meta || body;
        },
      });
      return results[0]?.result || '';
    } catch {
      return '';
    }
  }

  /**
   * 后台 AI 摘要生成
   */
  private async generateAISummary(bookmarkId: string, url: string, title: string): Promise<void> {
    try {
      const response = await this.apiClient.call('services.ai.summarize_page', {
        url,
        title,
      });

      const metadata = this.metadataCache.get(bookmarkId);
      if (metadata) {
        metadata.aiSummary = response.data.summary;
        metadata.aiTags = response.data.tags;
        this.searchIndex?.updateDocument(bookmarkId, title, metadata);
        await this.persistMetadata();
      }
    } catch (e) {
      console.warn('[BookmarkService] AI summary generation failed:', e);
      // 回退到本地摘要，无需额外处理
    }
  }

  /**
   * 搜索书签
   */
  async search(query: string, options?: {
    mode?: 'keyword' | 'semantic';
    tags?: string[];
    folderId?: string;
    limit?: number;
  }): Promise<BookmarkSearchResult[]> {
    const mode = options?.mode || 'keyword';

    if (mode === 'semantic') {
      return this.semanticSearch(query, options);
    }

    return this.keywordSearch(query, options);
  }

  /**
   * 关键词搜索
   */
  private keywordSearch(query: string, options?: {
    tags?: string[];
    folderId?: string;
    limit?: number;
  }): BookmarkSearchResult[] {
    if (!this.searchIndex) return [];

    let results = this.searchIndex.search(query);

    if (options?.tags?.length) {
      results = results.filter(r => {
        const meta = this.metadataCache.get(r.bookmarkId);
        return meta && options.tags!.some(tag => meta.tags.includes(tag));
      });
    }

    return results.slice(0, options?.limit || 20);
  }

  /**
   * 语义搜索（服务端 RAG）
   */
  private async semanticSearch(query: string, options?: {
    limit?: number;
  }): Promise<BookmarkSearchResult[]> {
    const response = await this.apiClient.call('services.rag.search_bookmarks', {
      query,
      limit: options?.limit || 20,
    });
    return response.data;
  }

  /**
   * 死链检测
   */
  async checkDeadLinks(bookmarkIds?: string[]): Promise<DeadLinkReport[]> {
    const targets = bookmarkIds
      ? bookmarkIds.map(id => chrome.bookmarks.get(id)).flat()
      : await this.getAllBookmarks();

    const reports: DeadLinkReport[] = [];
    const batchSize = 10;

    for (let i = 0; i < targets.length; i += batchSize) {
      const batch = targets.slice(i, i + batchSize);
      const batchResults = await Promise.allSettled(
        batch.map(async (bookmark) => {
          if (!bookmark.url) return null;

          const controller = new AbortController();
          const timeout = setTimeout(() => controller.abort(), 5000);

          try {
            const response = await fetch(bookmark.url, {
              method: 'HEAD',
              signal: controller.signal,
            });
            clearTimeout(timeout);

            const status: BookmarkMetadata['healthCheck']['status'] =
              response.ok ? 'ok' :
              response.status === 404 ? 'not_found' :
              'error';

            const metadata = this.metadataCache.get(bookmark.id);
            if (metadata) {
              metadata.healthCheck = {
                lastChecked: Date.now(),
                status,
                httpStatus: response.status,
                checkedAt: Date.now(),
              };
            }

            return {
              bookmarkId: bookmark.id,
              title: bookmark.title,
              url: bookmark.url,
              status,
              httpStatus: response.status,
            };
          } catch {
            clearTimeout(timeout);
            const metadata = this.metadataCache.get(bookmark.id);
            if (metadata) {
              metadata.healthCheck = {
                lastChecked: Date.now(),
                status: 'timeout',
                httpStatus: null,
                checkedAt: Date.now(),
              };
            }
            return {
              bookmarkId: bookmark.id,
              title: bookmark.title,
              url: bookmark.url!,
              status: 'timeout' as const,
              httpStatus: null,
            };
          }
        })
      );

      reports.push(
        ...batchResults
          .filter((r): r is PromiseFulfilledResult<DeadLinkReport | null> => r.status === 'fulfilled')
          .map(r => r.value)
          .filter((r): r is DeadLinkReport => r !== null)
      );

      // 批次间延迟，避免触发限流
      if (i + batchSize < targets.length) {
        await new Promise(resolve => setTimeout(resolve, 1000));
      }
    }

    await this.persistMetadata();
    return reports;
  }

  /**
   * 获取"稍后阅读"列表
   */
  async getReadingList(): Promise<BookmarkWithMeta[]> {
    const all = await this.getAllBookmarksWithMeta();
    return all
      .filter(b => b.metadata.readingProgress.status !== 'completed')
      .sort((a, b) => b.metadata.readingProgress.lastReadAt - a.metadata.readingProgress.lastReadAt);
  }

  /**
   * 更新阅读进度
   */
  async updateReadingProgress(bookmarkId: string, progress: {
    status?: 'unread' | 'reading' | 'completed';
    readPercentage?: number;
  }): Promise<void> {
    const metadata = this.metadataCache.get(bookmarkId);
    if (!metadata) return;

    if (progress.status) metadata.readingProgress.status = progress.status;
    if (progress.readPercentage !== undefined) {
      metadata.readingProgress.readPercentage = progress.readPercentage;
    }
    metadata.readingProgress.lastReadAt = Date.now();

    await this.persistMetadata();
  }

  /**
   * 导出书签为 HTML 格式
   */
  async exportBookmarks(format: 'html' | 'json' = 'html'): Promise<string> {
    if (format === 'json') {
      const all = await this.getAllBookmarksWithMeta();
      return JSON.stringify(all, null, 2);
    }

    // HTML 格式（与浏览器兼容）
    const tree = await chrome.bookmarks.getTree();
    return this.bookmarkTreeToHTML(tree);
  }

  private bookmarkTreeToHTML(tree: chrome.bookmarks.BookmarkTreeNode[]): string {
    let html = '<!DOCTYPE NETSCAPE-Bookmark-file-1>\n';
    html += '<META HTTP-EQUIV="Content-Type" CONTENT="text/html; charset=UTF-8">\n';
    html += '<TITLE>Bookmarks</TITLE>\n';
    html += '<H1>Bookmarks</H1>\n';
    html += '<DL><p>\n';
    html += this.traverseTree(tree);
    html += '</DL><p>\n';
    return html;
  }

  private traverseTree(nodes: chrome.bookmarks.BookmarkTreeNode[]): string {
    let html = '';
    for (const node of nodes) {
      if (node.url) {
        const meta = this.metadataCache.get(node.id);
        const tags = meta?.tags?.join(',') || '';
        html += `<DT><A HREF="${node.url}" ADD_DATE="${Math.floor((node.dateAdded || Date.now()) / 1000)}" TAGS="${tags}">${node.title}</A>\n`;
      }
      if (node.children) {
        html += `<DT><H3>${node.title}</H3>\n<DL><p>\n`;
        html += this.traverseTree(node.children);
        html += '</DL><p>\n';
      }
    }
    return html;
  }

  /**
   * 获取所有书签
   */
  private async getAllBookmarks(): Promise<chrome.bookmarks.BookmarkTreeNode[]> {
    const tree = await chrome.bookmarks.getTree();
    const bookmarks: chrome.bookmarks.BookmarkTreeNode[] = [];
    const flatten = (nodes: chrome.bookmarks.BookmarkTreeNode[]) => {
      for (const node of nodes) {
        if (node.url) bookmarks.push(node);
        if (node.children) flatten(node.children);
      }
    };
    flatten(tree);
    return bookmarks;
  }

  private async getAllBookmarksWithMeta(): Promise<BookmarkWithMeta[]> {
    const bookmarks = await this.getAllBookmarks();
    return bookmarks.map(b => ({
      bookmark: b,
      metadata: this.metadataCache.get(b.id) || this.createDefaultMetadata(b.id),
    }));
  }

  private createDefaultMetadata(bookmarkId: string): BookmarkMetadata {
    return {
      bookmarkId,
      aiSummary: '',
      aiTags: [],
      tags: [],
      customNotes: '',
      readingProgress: { status: 'unread', scrollPosition: 0, readPercentage: 0, lastReadAt: 0 },
      healthCheck: { lastChecked: 0, status: 'unknown', httpStatus: null, checkedAt: 0 },
      savedAt: Date.now(),
      savedFrom: 'native',
      associatedSessionId: '',
      starred: false,
    };
  }

  private async persistMetadata(): Promise<void> {
    const data = Object.fromEntries(this.metadataCache);
    await chrome.storage.local.set({ bookmark_metadata: data });
  }

  private handleBookmarkCreated(id: string, bookmark: chrome.bookmarks.BookmarkTreeNode): void {
    // 如果是通过本服务创建的，已经有元数据了
    if (!this.metadataCache.has(id) && bookmark.url) {
      this.metadataCache.set(id, this.createDefaultMetadata(id));
      this.persistMetadata();
      this.generateAISummary(id, bookmark.url, bookmark.title);
    }
  }

  private handleBookmarkRemoved(id: string): void {
    this.metadataCache.delete(id);
    this.searchIndex?.removeDocument(id);
    this.persistMetadata();
  }

  private handleBookmarkChanged(id: string, changeInfo: chrome.bookmarks.BookmarkChangeInfo): void {
    if (changeInfo.title || changeInfo.url) {
      const metadata = this.metadataCache.get(id);
      if (metadata && changeInfo.url) {
        this.generateAISummary(id, changeInfo.url, changeInfo.title || '');
      }
      this.searchIndex?.updateDocument(
        id,
        changeInfo.title || '',
        metadata || this.createDefaultMetadata(id)
      );
      this.persistMetadata();
    }
  }
}
```

```typescript
// src/service/SearchIndex.ts (新增)

interface SearchDoc {
  id: string;
  title: string;
  summary: string;
  tags: string[];
  url: string;
}

class SearchIndex {
  private documents: Map<string, SearchDoc> = new Map();
  private invertedIndex: Map<string, Set<string>> = new Map();
  private stopWords = new Set([
    '的', '是', '在', '和', '了', '有', '不', '这', '我', '也', '就', '都', '要', '与', '及', '或', '等',
    'the', 'a', 'an', 'is', 'are', 'was', 'were', 'be', 'been', 'in', 'on', 'at', 'to', 'for', 'of', 'and',
  ]);

  constructor(metadataCache: Map<string, BookmarkMetadata>) {
    // 从已有元数据构建索引
    for (const [id, meta] of metadataCache) {
      this.addDocument(id, '', meta);
    }
  }

  addDocument(id: string, title: string, meta: BookmarkMetadata): void {
    const doc: SearchDoc = {
      id,
      title,
      summary: meta.aiSummary,
      tags: [...meta.tags, ...meta.aiTags],
      url: '',
    };
    this.documents.set(id, doc);
    this.indexDocument(doc);
  }

  updateDocument(id: string, title: string, meta: BookmarkMetadata): void {
    this.removeDocument(id);
    this.addDocument(id, title, meta);
  }

  removeDocument(id: string): void {
    this.documents.delete(id);
    for (const [, docIds] of this.invertedIndex) {
      docIds.delete(id);
    }
  }

  search(query: string): BookmarkSearchResult[] {
    const tokens = this.tokenize(query);
    if (tokens.length === 0) return [];

    const scores = new Map<string, number>();

    for (const token of tokens) {
      const docIds = this.invertedIndex.get(token);
      if (!docIds) continue;

      for (const docId of docIds) {
        const doc = this.documents.get(docId);
        if (!doc) continue;

        let score = scores.get(docId) || 0;

        // 标题匹配权重更高
        if (doc.title.toLowerCase().includes(token)) {
          score += 3;
        }
        // 标签精确匹配
        if (doc.tags.some(t => t.toLowerCase() === token)) {
          score += 2;
        }
        // 摘要匹配
        if (doc.summary.toLowerCase().includes(token)) {
          score += 1;
        }

        scores.set(docId, score);
      }
    }

    return Array.from(scores.entries())
      .sort((a, b) => b[1] - a[1])
      .map(([bookmarkId, score]) => ({ bookmarkId, score }));
  }

  private tokenize(text: string): string[] {
    const cleaned = text.toLowerCase().replace(/[^\w\u4e00-\u9fff]/g, ' ');
    const tokens: string[] = [];

    // 中文：单字 + 双字组合
    const chinese = cleaned.match(/[\u4e00-\u9fff]+/g);
    if (chinese) {
      for (const word of chinese) {
        for (let i = 0; i < word.length; i++) {
          tokens.push(word[i]);
          if (i < word.length - 1) {
            tokens.push(word[i] + word[i + 1]);
          }
        }
      }
    }

    // 英文：按空格分词
    const english = cleaned.match(/[a-z]+/g);
    if (english) {
      for (const word of english) {
        if (word.length > 1 && !this.stopWords.has(word)) {
          tokens.push(word);
        }
      }
    }

    return tokens.filter(t => !this.stopWords.has(t) && t.length >= 1);
  }

  private indexDocument(doc: SearchDoc): void {
    const text = `${doc.title} ${doc.summary} ${doc.tags.join(' ')}`;
    const tokens = this.tokenize(text);

    for (const token of tokens) {
      if (!this.invertedIndex.has(token)) {
        this.invertedIndex.set(token, new Set());
      }
      this.invertedIndex.get(token)!.add(doc.id);
    }
  }
}
```

## 九、设计决策记录

### D-01：书签存储策略

- **问题**：扩展数据应存储在哪里
- **选项**：仅 chrome.bookmarks（无扩展字段）、独立存储（不与浏览器同步）、双写（bookmarks + 本地索引）
- **选择**：双写模式
- **理由**：chrome.bookmarks 保证与浏览器原生书签完全兼容，chrome.storage.local 存储 AI 摘要、标签、向量嵌入等扩展数据。通过书签 ID 关联，删除书签时同步清除扩展数据。

### D-02：搜索方案选择

- **问题**：如何实现高质量的书签搜索
- **选项**：仅浏览器原生搜索（仅标题）、TF-IDF 关键词搜索（标题+摘要+标签）、向量语义搜索（Transformers.js）
- **选择**：TF-IDF 关键词搜索为主，服务端向量搜索为辅
- **理由**：TF-IDF 覆盖 80% 搜索场景，离线可用，延迟 < 50ms。服务端语义搜索用于需要理解自然语言的复杂查询。避免在前端加载大体积 ML 模型。

### D-03：AI 摘要生成时机

- **问题**：何时生成 AI 摘要
- **选项**：保存时同步生成、保存时异步生成、用户手动触发
- **选择**：保存时异步生成
- **理由**：同步生成会阻塞保存操作（2-5s 延迟），用户体验差。异步生成在保存后立即显示本地摘要，AI 摘要完成后更新。用户手动触发作为补充，适用于已有书签。

### D-04：死链检测频率

- **问题**：多久检测一次死链
- **选项**：每天、每周、每月、仅手动
- **选择**：每周自动检测（30 天前的书签，每次 50 条）
- **理由**：每天检测频率过高会消耗网络资源，每月检测频率过低导致失效书签积压。每周 + 增量检测在覆盖面和资源消耗之间取得平衡。

| 1 | 用户有大量书签（5000+），初始加载时 chrome.bookmarks.getTree() 返回数据量过大，导致 BookmarkService.init() 阻塞主线程，Popup 打开延迟 > 2s | chrome.bookmarks API 不支持分页，getTree() 返回所有书签和文件夹，5000 条数据解析和元数据合并需要遍历所有节点 | 创建 5000 条测试书签，测量 init() 耗时，验证是否使用 Web Worker 处理大数据量，Popup 打开时间 < 500ms |
| 2 | 死链检测时，某些网站返回 403（禁止 HEAD 请求），但 GET 请求正常，导致误判为死链 | 部分网站（如某些 CDN、内网站点）拒绝 HEAD 请求，但允许 GET 请求，HEAD 失败不代表页面不可访问 | 对 HEAD 返回 403/405 的 URL 使用 GET 请求（仅请求前 1KB 数据）重新验证，或标记为 "uncertain" 而非 "not_found" |
| 3 | 用户通过浏览器原生书签管理器删除书签后，YiPet 的元数据未同步删除，导致元数据膨胀，搜索时出现无对应书签的结果 | chrome.bookmarks.onRemoved 在某些情况下不触发（如批量删除、同步删除），元数据缓存中的记录成为孤儿数据 | 在每次搜索前清理孤儿元数据（书签 ID 不在 chrome.bookmarks 中的记录），定期（每周）执行一次全量清理 |
| 4 | 书签导出 HTML 时，用户书签标题包含 HTML 特殊字符（<, >, &, "），未转义导致导出的 HTML 文件格式错误，浏览器无法导入 | chrome.bookmarks 的 title 字段可能包含任意字符，HTML 导出需要对这些字符进行转义 | 导出时使用 HTML 实体编码（< → &lt; 等），生成后使用 DOMParser 验证 HTML 格式是否合法 |
| 5 | 阅读进度更新使用 chrome.scripting.executeScript 注入页面时，页面尚未加载完成，innerText 为空，进度被错误计算为 0% | executeScript 在 document_end 执行，但 SPA 页面内容由 JS 动态渲染，此时 innerText 可能为空 | 使用 MutationObserver 监听页面内容变化，延迟计算阅读进度，或使用 IntersectionObserver 判断内容是否可见 |
| 6 | 语义搜索依赖 YiAi RAG 服务，RAG 需要所有书签的向量嵌入，但用户新保存的书签可能尚未生成嵌入，导致搜索遗漏新书签 | 向量嵌入是异步生成的（AI 摘要完成后），在生成完成前的窗口期内，新书签对语义搜索不可见 | 语义搜索时对无嵌入的书签回退到关键词搜索，结果合并时标注搜索方式，让用户知道覆盖范围 |

## 性能分析

### 书签操作各阶段耗时

| 阶段 | 预估耗时 | 说明 |
|------|----------|------|
| 保存书签（chrome.bookmarks.create） | ~10ms | 浏览器 API 调用 |
| 本地摘要提取 | ~50ms | executeScript + innerText 截取 |
| 元数据持久化 | ~5ms | chrome.storage.local.set |
| 搜索索引更新 | ~5ms | 分词 + 倒排索引插入 |
| AI 摘要生成（后台异步） | ~3s | YiAi 网络 + AI 推理 |
| 关键词搜索（500 条） | ~30ms | TF-IDF 内存查找 |
| 语义搜索（服务端） | ~1.5s | 网络 + RAG 向量检索 |
| 死链检测（单条） | ~3s | HEAD 请求超时 5s |
| 导出 HTML（500 条） | ~100ms | 字符串拼接 |
