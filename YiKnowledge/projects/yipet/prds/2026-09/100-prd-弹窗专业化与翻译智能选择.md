# YP-100: 弹窗样式专业化 + 翻译智能选择

## 一、需求背景

### 问题 1：CSS 回退值与主题调色板不一致

YiPet popup 的 CSS `var()` 回退值在 `App.vue` 和 `index.css` 之间不一致，且与默认 Lavender 主题调色板存在偏差。导致主题切换时出现微小颜色跳变。

### 问题 2：翻译引擎选择无智能推荐

YiPet 的翻译功能通过 YiAi RPC 调用，但无实时引擎健康排名参考。

## 二、解决方案

### R1：CSS 变量一致性

统一 `App.vue` 和 `index.css` 中所有 CSS 回退值为 Lavender 调色板实际值（共 10 处）：

| 变量 | 修正前 | 修正后 |
|------|--------|--------|
| border-subtle alpha | 0.15/0.12 | 0.2 |
| surface-sunken | #1e1a3b | #1c1926 |
| gradient-primary 方向 | 90deg | 135deg |
| primary-alpha alpha | 0.2 | 0.12 |

### R2：翻译智能选择 API

`src/api/services/translation.ts` 新增 `getProviderRecommend()`：
- 调用 YiAi `provider_recommend` RPC
- 返回按健康度+成功率排名的引擎列表
- Chat store 可调用此 API 做智能引擎选择

## 三、验收标准

- [x] 所有 CSS 回退值与 Lavender 调色板一致
- [x] 主题切换无颜色跳变
- [x] npm test 138/138 passed
- [x] typecheck passed
