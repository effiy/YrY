# PE-09-112: 会话项目自动标记

> 会话组织增强：创建会话时自动从页面 URL 检测所属项目（YiVad/YiAi/YiPet/GitHub），添加 `project:<name>` 标签。

## 范围

- `detectProject(url)` 辅助函数：localhost:8848→YiVad, :10086→YiAi, yipet://→YiPet, github.com→GitHub
- 所有会话创建路径自动添加 project 标签
- 已有 `sessionProjectFilter` 可利用标签过滤

## 验收标准

- [ ] 在 YiVad 页面上新建会话 → tags 包含 `project:YiVad`
- [ ] 在 GitHub 上新建 → tags 包含 `project:GitHub`
- [ ] createEmptySession 也添加 project 标签
