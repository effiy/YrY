# YP-09-118: 定时提醒与日程管理 — chrome.alarms 定时提醒、自然语言创建、循环提醒与跨设备同步

> 需求编号：YP-09-118 · 优先级：P2 · 人天：0.5d · 状态：需求已编写
> 依赖：YP-09-95（消息通知系统）、YP-09-66（设置跨设备同步）、YP-09-25（通知提醒系统）

## 背景

### 问题陈述

YiPet 当前仅支持实时对话交互，缺少定时提醒和日程管理能力。用户在对话中产生的待办事项、后续跟进需求无法自动提醒，导致：

1. **对话后续跟进断裂**：AI 建议"明天再检查这个问题"，但用户次日遗忘
2. **缺少日程整合**：用户需要切换到日历应用管理提醒，打断工作流
3. **无法定时总结**：用户希望每日/每周收到对话总结，但需要手动回顾
4. **提醒方式单一**：仅支持浏览器内通知，无法覆盖用户离线场景
5. **跨设备缺失**：提醒在设备间不互通，换设备后提醒丢失

**核心矛盾**：在 Chrome 扩展中实现轻量级提醒系统，既要利用 chrome.alarms API 保证 Service Worker 休眠后仍能触发，又要提供自然语言创建等便捷能力，同时保持跨设备同步。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 对话后续事项遗忘 | 高 | AI 建议"3 小时后跟进"，用户忘记 |
| 2 | 每日总结无法自动生成 | 中 | 用户希望每晚 8 点收到当日对话摘要 |
| 3 | 提醒创建流程繁琐 | 中 | 需要手动选择日期时间，而非自然语言输入 |
| 4 | 更换设备后提醒丢失 | 中 | 在家设置提醒，到公司后不存在 |
| 5 | 提醒无法循环 | 低 | 每周一上午的站会提醒需要手动重新创建 |

### 挑战

| 挑战 | 说明 |
|------|------|
| SW 休眠后唤醒 | chrome.alarms 可在 SW 休眠后触发，但需确保回调逻辑正确 |
| 自然语言解析 | "3 小时后提醒我"需要解析为精确的时间戳 |
| 时区处理 | 跨时区提醒需正确转换，用户旅行时提醒时间应调整 |
| 循环提醒复杂性 | cron 表达式支持 + 工作日/周末区分 + 节假日感知 |
| 存储同步 | chrome.storage.sync 有 100KB 限制，提醒数据需精打细算 |

## 二、设计决策

### 决策 1：定时触发机制 — chrome.alarms vs setTimeout vs Service Worker 定时器

| 选项 | SW 休眠后触发 | 精确度 | 限制 | 复杂度 |
|------|-------------|--------|------|--------|
| chrome.alarms | 是 | 1 分钟 | 最多 500 个 | 低 |
| setTimeout | 否 | 毫秒级 | 页面关闭即失效 | 极低 |
| SW 定时器同步 | 不可靠 | 取决于浏览器 | 无保证 | 高 |

**选择：chrome.alarms。** 这是 Chrome 扩展唯一可靠的定时触发机制，Service Worker 休眠后仍能唤醒触发。setTimeout 在 SW 休眠后失效，不可用于定时提醒。chrome.alarms 的最短间隔为 1 分钟，对于"3 小时后提醒"这种场景足够精确。

### 决策 2：自然语言解析 — 前端正则 vs AI 模型 vs 混合

| 选项 | 准确率 | 离线 | 延迟 | 覆盖范围 |
|------|--------|------|------|----------|
| 前端正则匹配 | 中（60%） | 是 | 即时 | 有限 |
| AI 模型（YiAi 端） | 高（90%+） | 否 | 1-2s | 广泛 |
| 混合（正则优先 + AI 兜底） | 高 | 部分 | 大部分即时 | 广泛 |

**选择：混合模式。** 常见模式（如"3 小时后提醒"、"明天下午 3 点"、"每周一上午"）使用前端正则匹配，即时解析。复杂自然语言（如"下次和老板开会时提醒我"）转发到 YiAi 端 AI 解析。前端正则覆盖 80% 的常见场景，AI 兜底覆盖剩余 20%。

### 决策 3：提醒存储与同步 — chrome.storage.sync vs chrome.storage.local vs 混合

| 选项 | 容量 | 同步 | 限制 |
|------|------|------|------|
| chrome.storage.sync | 100KB | 自动跨设备 | 容量受限 |
| chrome.storage.local | 10MB | 手动导出 | 仅本地 |
| 混合（sync 关键字段 + local 完整数据） | 兼顾 | 部分自动 | 数据一致性 |

**选择：混合模式。** 提醒的核心字段（id、标题、触发时间、循环规则、状态）存储到 chrome.storage.sync（每条约 200B，可存储 500+ 条），提醒的完整数据（描述、关联会话、自定义参数）存储到 chrome.storage.local。sync 容量足够存储所有活跃提醒的关键字段。

### 决策 4：循环提醒实现 — 自定义 cron vs 简单预设 vs 两者兼有

| 选项 | 灵活性 | 复杂度 | 用户理解 |
|------|--------|--------|----------|
| 自定义 cron 表达式 | 极高 | 高 | 难 |
| 简单预设（每天/每周/工作日） | 低 | 低 | 易 |
| 两者兼有 | 高 | 中 | 分层 |

**选择：两者兼有。** 预设模式（每天、每周、工作日、周末、每月）覆盖 90% 的循环需求，通过简单的 UI 选择器配置。高级模式支持 cron 表达式，满足"每月 15 日和最后一天"等复杂需求。预设模式生成对应的 cron 表达式内部存储，统一处理。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 定时触发 | chrome.alarms | setTimeout | SW 定时器 | **chrome.alarms** | SW 休眠后仍可触发 |
| 语义解析 | 前端正则 | AI 模型 | 混合 | **混合** | 性能 + 准确率 |
| 存储同步 | chrome.storage.sync | chrome.storage.local | 混合 | **混合** | 容量 + 同步兼顾 |
| 循环提醒 | 自定义 cron | 简单预设 | 两者兼有 | **两者兼有** | 易用 + 灵活 |

### 4.1 提醒服务核心

```typescript
// src/service/ReminderService.ts (新增)

interface Reminder {
  id: string;
  title: string;
  description: string;
  triggerTime: number;
  createdAt: number;
  status: 'pending' | 'fired' | 'snoozed' | 'dismissed';
  recurrence: Recurrence | null;
  associatedSessionId: string;
  source: 'chat' | 'manual' | 'ai_suggestion';
  notificationOptions: {
    priority: 0 | 1 | 2;
    silent: boolean;
    requireInteraction: boolean;
  };
}

interface Recurrence {
  type: 'daily' | 'weekly' | 'weekdays' | 'monthly' | 'cron';
  interval: number;
  daysOfWeek: number[];
  cronExpression: string | null;
  endDate: number | null;
  maxOccurrences: number | null;
}

class ReminderService {
  private reminders: Map<string, Reminder> = new Map();
  private alarmNamePrefix = 'yipet_reminder_';

  async init(): Promise<void> {
    // 从 storage 恢复提醒
    const stored = await chrome.storage.local.get('reminders');
    if (stored.reminders) {
      this.reminders = new Map(Object.entries(stored.reminders));
    }

    // 重新注册所有 pending 提醒到 chrome.alarms
    for (const reminder of this.reminders.values()) {
      if (reminder.status === 'pending') {
        this.registerAlarm(reminder);
      }
    }

    // 监听 alarm 触发
    chrome.alarms.onAlarm.addListener(this.handleAlarm.bind(this));
  }

  /**
   * 创建提醒
   */
  async createReminder(params: {
    title: string;
    triggerTime: number;
    recurrence?: Recurrence;
    description?: string;
    sessionId?: string;
    source?: 'chat' | 'manual' | 'ai_suggestion';
  }): Promise<Reminder> {
    const reminder: Reminder = {
      id: `rem_${Date.now()}_${Math.random().toString(36).slice(2, 8)}`,
      title: params.title,
      description: params.description || '',
      triggerTime: params.triggerTime,
      createdAt: Date.now(),
      status: 'pending',
      recurrence: params.recurrence || null,
      associatedSessionId: params.sessionId || '',
      source: params.source || 'manual',
      notificationOptions: {
        priority: 1,
        silent: false,
        requireInteraction: false,
      },
    };

    this.reminders.set(reminder.id, reminder);
    this.registerAlarm(reminder);
    await this.persist();
    await this.syncToDevices(reminder);

    return reminder;
  }

  /**
   * 注册 chrome.alarms
   */
  private registerAlarm(reminder: Reminder): void {
    const alarmName = `${this.alarmNamePrefix}${reminder.id}`;
    chrome.alarms.create(alarmName, {
      when: reminder.triggerTime,
    });
  }

  /**
   * 处理 alarm 触发
   */
  private async handleAlarm(alarm: chrome.alarms.Alarm): Promise<void> {
    if (!alarm.name.startsWith(this.alarmNamePrefix)) return;

    const reminderId = alarm.name.replace(this.alarmNamePrefix, '');
    const reminder = this.reminders.get(reminderId);
    if (!reminder || reminder.status !== 'pending') return;

    // 显示通知
    await this.showNotification(reminder);

    // 处理循环
    if (reminder.recurrence) {
      const nextTrigger = this.calculateNextTrigger(reminder);
      if (nextTrigger) {
        reminder.triggerTime = nextTrigger;
        this.registerAlarm(reminder);
      } else {
        reminder.status = 'fired';
      }
    } else {
      reminder.status = 'fired';
    }

    await this.persist();
  }

  /**
   * 显示 chrome.notifications
   */
  private async showNotification(reminder: Reminder): Promise<void> {
    chrome.notifications.create(`reminder_${reminder.id}`, {
      type: 'basic',
      iconUrl: chrome.runtime.getURL('icons/icon128.png'),
      title: reminder.title,
      message: reminder.description || '到时间了！',
      priority: reminder.notificationOptions.priority,
      requireInteraction: reminder.notificationOptions.requireInteraction,
      buttons: [
        { title: '延后 10 分钟' },
        { title: '关闭' },
      ],
    });
  }

  /**
   * 延后提醒
   */
  async snoozeReminder(reminderId: string, minutes: number = 10): Promise<void> {
    const reminder = this.reminders.get(reminderId);
    if (!reminder) return;

    reminder.status = 'snoozed';
    reminder.triggerTime = Date.now() + minutes * 60 * 1000;

    // 创建新的 alarm
    this.registerAlarm(reminder);

    // 重新设置为 pending
    setTimeout(() => {
      reminder.status = 'pending';
    }, 100);

    await this.persist();
  }

  /**
   * 关闭提醒
   */
  async dismissReminder(reminderId: string): Promise<void> {
    const reminder = this.reminders.get(reminderId);
    if (!reminder) return;

    reminder.status = 'dismissed';
    await chrome.alarms.clear(`${this.alarmNamePrefix}${reminderId}`);
    await this.persist();
  }

  /**
   * 计算下一次触发时间（循环）
   */
  private calculateNextTrigger(reminder: Reminder): number | null {
    const rec = reminder.recurrence;
    if (!rec) return null;

    const now = Date.now();
    const next = new Date(reminder.triggerTime);

    switch (rec.type) {
      case 'daily':
        next.setDate(next.getDate() + rec.interval);
        break;
      case 'weekly':
        next.setDate(next.getDate() + 7 * rec.interval);
        break;
      case 'weekdays':
        do {
          next.setDate(next.getDate() + 1);
        } while (next.getDay() === 0 || next.getDay() === 6);
        break;
      case 'monthly':
        next.setMonth(next.getMonth() + rec.interval);
        break;
      case 'cron':
        return this.evaluateCronExpression(rec.cronExpression!, now);
    }

    const nextTime = next.getTime();

    // 检查是否超过结束条件
    if (rec.endDate && nextTime > rec.endDate) return null;
    if (rec.maxOccurrences !== null) {
      // 计算已触发次数并判断
      // ... 实现略
    }

    return nextTime;
  }

  /**
   * 获取提醒列表
   */
  getReminders(filter?: { status?: string; sessionId?: string }): Reminder[] {
    let list = Array.from(this.reminders.values());
    if (filter?.status) {
      list = list.filter(r => r.status === filter.status);
    }
    if (filter?.sessionId) {
      list = list.filter(r => r.associatedSessionId === filter.sessionId);
    }
    return list.sort((a, b) => a.triggerTime - b.triggerTime);
  }

  /**
   * 持久化到 chrome.storage.local
   */
  private async persist(): Promise<void> {
    const data = Object.fromEntries(this.reminders);
    await chrome.storage.local.set({ reminders: data });
  }

  /**
   * 同步关键字段到 chrome.storage.sync
   */
  private async syncToDevices(reminder: Reminder): Promise<void> {
    const syncData = {
      id: reminder.id,
      title: reminder.title,
      triggerTime: reminder.triggerTime,
      status: reminder.status,
      recurrence: reminder.recurrence ? {
        type: reminder.recurrence.type,
        interval: reminder.recurrence.interval,
        cronExpression: reminder.recurrence.cronExpression,
      } : null,
    };
    const key = `reminder_sync_${reminder.id}`;
    await chrome.storage.sync.set({ [key]: syncData });
  }
}
```

### 4.2 自然语言解析

```typescript
// src/service/NLPReminderParser.ts (新增)

interface ParsedReminder {
  title: string;
  triggerTime: number;
  recurrence: Recurrence | null;
  confidence: number;  // 0-1 解析置信度
}

class NLPReminderParser {
  private patterns = [
    // "3 小时后提醒我检查代码"
    {
      regex: /(\d+)\s*(小时|分钟|天)后提醒我(.+)/,
      parse: (m: RegExpMatchArray) => {
        const value = parseInt(m[1]);
        const unit = m[2];
        const title = m[3].trim();
        let ms = 0;
        if (unit === '分钟') ms = value * 60 * 1000;
        else if (unit === '小时') ms = value * 3600 * 1000;
        else if (unit === '天') ms = value * 86400 * 1000;
        return { title, triggerTime: Date.now() + ms, recurrence: null, confidence: 0.95 };
      },
    },
    // "明天下午 3 点提醒我开会"
    {
      regex: /(今天|明天|后天|大后天)?\s*(上午|下午|晚上)?\s*(\d{1,2})\s*点(?:(\d{1,2})分)?提醒我(.+)/,
      parse: (m: RegExpMatchArray) => {
        const dayOffset = { '今天': 0, '明天': 1, '后天': 2, '大后天': 3 }[m[1] || '今天'] || 0;
        const isPM = m[2] === '下午' || m[2] === '晚上';
        let hour = parseInt(m[3]);
        if (isPM && hour < 12) hour += 12;
        if (m[2] === '上午' && hour === 12) hour = 0;
        const minutes = m[4] ? parseInt(m[4]) : 0;
        const title = m[5].trim();

        const date = new Date();
        date.setDate(date.getDate() + dayOffset);
        date.setHours(hour, minutes, 0, 0);

        return { title, triggerTime: date.getTime(), recurrence: null, confidence: 0.9 };
      },
    },
    // "每周一上午 9 点站会"
    {
      regex: /每(天|周|月)([一二三四五六日1-7])?\s*(上午|下午|晚上)?\s*(\d{1,2})\s*点(.+)/,
      parse: (m: RegExpMatchArray) => {
        const recType = m[1] === '天' ? 'daily' : m[1] === '周' ? 'weekly' : 'monthly';
        const dayMap: Record<string, number> = { '一': 1, '二': 2, '三': 3, '四': 4, '五': 5, '六': 6, '日': 0 };
        const dayOfWeek = m[2] ? (dayMap[m[2]] ?? parseInt(m[2])) : undefined;
        const isPM = m[3] === '下午' || m[3] === '晚上';
        let hour = parseInt(m[4]);
        if (isPM && hour < 12) hour += 12;
        const title = m[5].trim();

        const next = this.calculateNextDate(recType, dayOfWeek, hour);
        const recurrence: Recurrence = {
          type: recType,
          interval: 1,
          daysOfWeek: dayOfWeek !== undefined ? [dayOfWeek] : [],
          cronExpression: null,
          endDate: null,
          maxOccurrences: null,
        };

        return { title, triggerTime: next, recurrence, confidence: 0.85 };
      },
    },
    // "工作日每天 8 点"
    {
      regex: /工作日\s*(?:每天)?\s*(上午|下午|晚上)?\s*(\d{1,2})\s*点(.+)/,
      parse: (m: RegExpMatchArray) => {
        const isPM = m[1] === '下午' || m[1] === '晚上';
        let hour = parseInt(m[2]);
        if (isPM && hour < 12) hour += 12;
        const title = m[3].trim();

        const next = this.calculateNextWeekday(hour);
        const recurrence: Recurrence = {
          type: 'weekdays',
          interval: 1,
          daysOfWeek: [1, 2, 3, 4, 5],
          cronExpression: null,
          endDate: null,
          maxOccurrences: null,
        };

        return { title, triggerTime: next, recurrence, confidence: 0.85 };
      },
    },
  ];

  /**
   * 解析自然语言提醒
   */
  parse(input: string): ParsedReminder | null {
    for (const pattern of this.patterns) {
      const match = input.match(pattern.regex);
      if (match) {
        return pattern.parse(match);
      }
    }
    return null; // 前端解析失败，转发到 AI 解析
  }

  /**
   * 通过 AI 解析复杂自然语言
   */
  async parseWithAI(input: string): Promise<ParsedReminder> {
    const response = await this.apiClient.call('services.ai.parse_reminder', {
      text: input,
      current_time: Date.now(),
      timezone: Intl.DateTimeFormat().resolvedOptions().timeZone,
    });
    return response.data;
  }

  private calculateNextDate(type: string, dayOfWeek: number | undefined, hour: number): number {
    const now = new Date();
    const next = new Date();
    next.setHours(hour, 0, 0, 0);

    if (type === 'daily') {
      if (next.getTime() <= now.getTime()) next.setDate(next.getDate() + 1);
    } else if (type === 'weekly' && dayOfWeek !== undefined) {
      const currentDay = now.getDay();
      const daysUntil = (dayOfWeek - currentDay + 7) % 7;
      next.setDate(now.getDate() + (daysUntil === 0 ? 7 : daysUntil));
    } else if (type === 'monthly') {
      next.setMonth(next.getMonth() + 1);
    }

    return next.getTime();
  }

  private calculateNextWeekday(hour: number): number {
    const next = new Date();
    next.setHours(hour, 0, 0, 0);
    while (next.getDay() === 0 || next.getDay() === 6) {
      next.setDate(next.getDate() + 1);
    }
    if (next.getTime() <= Date.now()) {
      next.setDate(next.getDate() + 1);
      while (next.getDay() === 0 || next.getDay() === 6) {
        next.setDate(next.getDate() + 1);
      }
    }
    return next.getTime();
  }
}
```

## 六、测试规格

### 场景 1：自然语言创建提醒

**GIVEN** 用户在聊天中输入 "3 小时后提醒我检查代码审查"
**WHEN** ReminderService 解析并创建提醒
**THEN** 提醒标题为 "检查代码审查"
**AND** 触发时间为当前时间 + 3 小时（误差 < 1 分钟）
**AND** 提醒来源标记为 "chat"
**AND** 提醒关联到当前会话

### 场景 2：chrome.alarms 触发提醒通知

**GIVEN** 存在一个 triggerTime 为当前时间 + 1 分钟的提醒
**WHEN** 1 分钟后 chrome.alarms 触发
**THEN** chrome.notifications 弹出通知
**AND** 通知标题为提醒标题
**AND** 通知包含 "延后 10 分钟" 和 "关闭" 两个按钮
**AND** 提醒状态变更为 "fired"

**WHEN** 提醒首次在周一 9:00 触发
**THEN** 通知正确弹出
**AND** 下一次触发时间自动计算为下周一 9:00
**AND** chrome.alarms 重新注册下一次触发

### 场景 4：延后提醒

**GIVEN** 提醒触发后用户点击 "延后 10 分钟"
**WHEN** 10 分钟后
**THEN** 提醒再次触发

## 九、设计决策记录

### D-01：提醒触发机制

- **问题**：如何在 Service Worker 休眠后仍能触发提醒
- **选项**：setTimeout（不可靠）、chrome.alarms（可靠）、Web Push（复杂）
- **选择**：chrome.alarms
- **理由**：chrome.alarms 是 Chrome 扩展唯一的可靠定时触发 API，SW 休眠后仍能唤醒触发。setTimeout 在 SW 休眠后失效，Web Push 需要服务端支持且延迟较高。

### D-02：自然语言解析策略

- **问题**：如何解析用户输入的自然语言提醒
- **选项**：纯前端正则、纯 AI 解析、混合
- **选择**：混合（正则优先 + AI 兜底）
- **理由**：正则覆盖 80% 常见模式（即时、离线），AI 覆盖剩余 20% 复杂场景（准确但需要网络）。解析后展示确认对话框，让用户验证结果。

### D-03：跨设备同步策略

- **问题**：提醒数据如何在设备间同步
- **选项**：仅 local、仅 sync、混合
- **选择**：混合（sync 关键字段 + local 完整数据）
- **理由**：sync 自动同步但容量有限（100KB），仅存储关键字段（id、标题、触发时间、循环规则）足以在多设备间恢复提醒。完整描述和关联数据存储在 local。

### D-04：循环提醒实现

- **问题**：如何实现灵活的循环提醒
- **选项**：仅预设（每天/每周）、仅 cron、两者兼有
- **选择**：两者兼有
- **理由**：预设覆盖 90% 需求且易用，cron 提供高级灵活性。内部统一使用 cron 表达式或时间计算，外部提供分层 UI。

## 回归问题预测

| # | 预测问题 | 原因 | 验证方法 |
|---|---------|------|---------|
| 1 | SW 被浏览器终止后，chrome.alarms 仍然触发但 ReminderService 实例未初始化，导致 alarm 回调中 reminders Map 为空，提醒静默丢失 | alarm 回调中直接访问 this.reminders（存储在内存中），SW 重启后内存清空，但 alarm 回调已注册 | 在 Chrome DevTools 中手动终止 SW，等待 alarm 触发，验证回调中先执行 init() 恢复 storage 数据再处理 |
| 2 | 用户在 A 设备延后了提醒，B 设备通过 sync 同步到新状态，但 B 设备上的旧 alarm 未清除，导致提醒重复触发 | sync 同步只更新了 storage 数据，没有同步清除另一设备上的 chrome.alarms | 在 sync 的 onChanged 监听中，检测到提醒状态变更时，重新计算并更新本地 alarm 注册 |
| 3 | 自然语言解析 "明天下午 3 点" 在 23:00 时运行，解析的 "明天" 实际是指今天（因为已经过了午夜），导致提醒错过一天 | 正则解析中使用 `new Date()` 获取当前日期，23:00 后的 "明天" 在 Date 对象中仍是当天 | 自然语言解析时使用精确的日期计算，考虑跨日边界，并添加"确认对话框"展示解析后的日期时间 |
| 4 | 循环提醒 "每周一" 在跨月时计算错误（如 1 月 31 日 → 2 月 7 日），setDate 操作在月末边界行为不一致 | JavaScript 的 Date.setDate() 在月末自动进位，但 "每周一" 的计算逻辑需要先获取当前是周几再计算偏移 | 使用专业的日期库（如 date-fns）的 `nextDay` 函数替代手动计算，覆盖所有月末边界测试 |
| 5 | 提醒通知的 requireInteraction 设置为 true 时，通知一直显示在系统通知中心，用户关闭浏览器后通知仍然存在，点击后无法正确跳转 | chrome.notifications 的持久通知在浏览器关闭后依然存在，但点击回调需要 SW 运行 | requireInteraction 仅用于重要提醒（优先级 2），默认提醒使用非持久通知，浏览器关闭后自动清除 |
| 6 | 用户快速创建大量提醒（如 100 条），chrome.alarms 注册期间触发浏览器限流，部分 alarm 创建失败但未报错 | chrome.alarms 有创建频率限制，短时间内大量创建会被限流，但 API 调用不返回错误 | 实现创建队列，限制创建速率（10 条/秒），失败时重试最多 3 次，队列中等待的提醒状态为 "pending_queued" |
