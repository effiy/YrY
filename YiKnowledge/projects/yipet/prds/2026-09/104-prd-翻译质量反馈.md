# PE-09-104: 翻译质量反馈闭环

> 跨项目反馈闭环：YiPet translateSelection 功能产生翻译结果，用户可通过 👍/👎 评分反馈翻译质量，数据经 YiAi RPC 写入 MongoDB `translation_feedback`，最终在 YiVad TranslationAnalytics Dashboard 可视化。

## 背景

YiPet 已有 `translateSelection()` 功能（选中页面文本 → 调用 YiAi 翻译 → 填入输入框），但缺少翻译质量反馈机制。

反馈闭环链路：
```
YiPet ChatInput 👍/👎
  → store.submitTranslationFeedback('good'|'bad')
    → translationService.feedback({source, target, rating, provider, from_lang, to_lang})
      → YiAi translate_service.translation_feedback()
        → MongoDB translation_feedback.insert_one()
          → YiVad TranslationAnalytics Dashboard 展示好评/差评统计
```

## 范围

**In scope**：
- Chat store 新增 `_lastTranslation` 状态 + `submitTranslationFeedback`/`clearTranslationFeedback` 方法
- ChatInput footer 新增翻译结果反馈行（显示时带 👍/👎 按钮）
- 反馈通过 YiAi RPC `translation_feedback` 提交

| 优先级 | 故事 | 验收标准 |
|--------|------|----------|
| P1 | 反馈提交 | 翻译完成后的 👍 或 👎 点击成功提交到 YiAi |
| P1 | UI 展示 | 有翻译结果时输入区底部显示反馈按钮 |
| P2 | 数据闭环 | 反馈数据在 YiVad Dashboard 可查询 |

## 验收标准

- [ ] `translateSelection` 成功后存储翻译源文本/译文/引擎信息
- [ ] 输入区 footer 显示 "Rate translation: 👍 👎"
- [ ] 点击 👍 调用 `translation_feedback` RPC（rating: 'good'）
- [ ] 点击 👎 调用 `translation_feedback` RPC（rating: 'bad'）
- [ ] 反馈提交后按钮消失，显示成功通知
