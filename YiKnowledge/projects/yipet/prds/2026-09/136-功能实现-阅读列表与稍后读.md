# YP-09-129: 阅读列表与稍后读 — 页面保存、AI 摘要生成、阅读进度追踪、标签分类、离线阅读、阅读提醒、分享至聊天、阅读统计

> 需求编号：YP-09-129 · 优先级：P2 · 人天：0.3d · 状态：需求已编写
> 依赖：YP-09-24（右键菜单集成）、YP-09-119（书签与网页收藏管理）、YP-09-123（AI 页面摘要）、YP-09-95（消息通知系统）

## 背景

### 问题陈述

YiPet 当前作为浏览器伴侣，未提供阅读列表管理功能。用户在浏览过程中积累大量"想读但没时间读"的页面，面临严重的阅读管理问题：

1. **阅读意图丢失**：用户看到感兴趣的文章但当前没时间读，关闭标签页后很难再找到，Chrome 原生"阅读清单"功能简陋且无智能管理
2. **阅读进度无追踪**：用户保存了多篇文章，但不知道哪些已读、哪些未读、每篇还需要多少时间，阅读行为碎片化
3. **内容消化不充分**：用户快速浏览文章标题和摘要后保存，但从未真正阅读，阅读列表变成"数字坟墓"
4. **阅读时间无法估计**：用户打开一篇文章前不知道需要多少时间，导致频繁中断（读到一半被打断，下次重新开始）
5. **阅读习惯不可见**：用户没有阅读统计数据，不了解自己的阅读模式和习惯（每周读多少、主要读什么类型）

**核心矛盾**：在浏览器扩展的存储限制下，构建一个智能阅读列表系统，既要提供 AI 摘要、进度追踪、离线阅读等高级功能，又要保持轻量（不加载完整页面内容），避免成为另一个"收藏夹死库"。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 想读的文章找不到，阅读意图丢失 | 高 | 用户在社交媒体看到 10 篇技术文章，保存到标签页后忘记，一周后全部关闭 |
| 2 | 阅读进度无法追踪，重复阅读 | 中 | 用户打开一篇 5000 字的技术文章，读到 30% 被打断，下次打开从头开始 |
| 3 | 阅读列表变成"数字坟墓" | 高 | 用户保存了 50 篇文章但从未打开，阅读列表成为焦虑来源而非阅读助手 |
| 4 | 无法判断阅读时间，频繁中断 | 中 | 用户以为自己有 5 分钟可以读一篇短文，结果是一篇 8000 字长文，读了 10% 被迫中断 |
| 5 | 阅读习惯缺乏数据反馈 | 低 | 用户不知道自己一周读了多少文章，花多少时间，阅读行为缺乏正反馈循环 |

### 挑战

| 挑战 | 说明 |
|------|------|
| 离线内容缓存 | 缓存页面正文内容需占用存储空间，需在完整性和存储量之间平衡 |
| AI 摘要质量 | AI 摘要依赖页面内容提取，部分页面（SPA、登录墙后）无法提取内容 |
| 阅读进度估算 | 页面内容长度和阅读时间的关系受语言、排版、图表等因素影响，估算不精确 |
| 存储容量限制 | chrome.storage.local 最大 10MB，离线缓存页面不能超过此限制 |
| 阅读提醒时机 | 推送阅读提醒需要在不打扰用户的前提下，选择合适的时机触发 |
| 跨设备同步 | 阅读列表和进度可能需要在多设备间同步，但 chrome.storage.sync 容量仅 100KB |

## 二、设计决策

### 决策 1：阅读列表存储位置 — chrome.storage.local vs IndexedDB vs 后端同步

| 选项 | 容量 | 离线可用 | 跨设备同步 | 实现复杂度 |
|------|------|----------|------------|------------|
| chrome.storage.local | 10MB | 是 | 否 | 低 |
| IndexedDB | 无限制 | 是 | 否 | 中 |
| YiAi 后端同步 | 无限制 | 否 | 是 | 高 |

**选择：chrome.storage.local 为主，可选 YiAi 后端同步。** 阅读列表元数据（URL、标题、摘要、标签、进度）体积小（每篇 < 2KB），100 篇仅 200KB，chrome.storage.local 完全够用。离线页面正文缓存单独管理，使用 IndexedDB 存储（不受 10MB 限制）。跨设备同步为可选功能，通过 YiAi 后端实现。

### 决策 2：AI 摘要生成时机 — 保存时实时生成 vs 后台异步生成 vs 用户手动触发

| 选项 | 即时性 | 资源消耗 | 成功率 | 用户体验 |
|------|--------|----------|--------|----------|
| 保存时实时生成 | 高（即时可用） | 高（保存时等待） | 中（需页面仍在） | 保存时有等待感 |
| 后台异步生成 | 中（延迟数秒） | 中（分散负载） | 中 | 保存即时，摘要稍后出现 |
| 用户手动触发 | 低（需手动） | 低 | 低（用户可能忘记） | 摘要可能永远不会生成 |

**选择：后台异步生成，保存时立即显示占位摘要。** 用户保存文章时立即添加到阅读列表（显示"摘要生成中..."），后台通过 Service Worker 异步请求 AI 摘要。摘要生成完成后通过通知提醒用户。如果页面内容提取失败（SPA 或需要登录），使用页面标题和 meta description 作为降级摘要。

### 决策 3：阅读进度追踪方式 — 页面滚动位置 vs 阅读时间 vs 内容段落标记

| 选项 | 精确度 | 跨会话持久化 | 实现复杂度 | 适用场景 |
|------|--------|-------------|------------|----------|
| 滚动位置百分比 | 中 | 是（需注入 content script） | 中 | 所有页面 |
| 阅读时间计时 | 低 | 是 | 低 | 估计阅读时长 |
| 内容段落标记（锚点） | 高 | 是（需提取 DOM 结构） | 高 | 结构化内容 |

**选择：滚动位置百分比 + 阅读时间计时双重追踪。** 在阅读页面中注入轻量 content script，监听 scroll 事件并记录滚动百分比（防抖 500ms 后写入 storage）。同时记录页面聚焦时长作为阅读时间。当用户下次打开同一文章时，自动滚动到上次位置并显示"上次读到 35%，预计还需 8 分钟"。

### 决策 4：离线阅读缓存策略 — 完整页面 HTML vs 纯文本正文 vs Reader Mode 提取

| 选项 | 保真度 | 存储大小 | 离线体验 | 实现复杂度 |
|------|--------|----------|----------|------------|
| 完整页面 HTML | 高 | 大（每页 500KB-2MB） | 好 | 低 |
| 纯文本正文（提取后） | 低 | 极小（每页 5-20KB） | 中 | 中 |
| Reader Mode 提取（Mozilla Readability） | 中 | 小（每页 20-50KB） | 好 | 中 |

**选择：Reader Mode 提取（Mozilla Readability 算法）。** 使用 Readability.js 提取页面正文（标题、作者、正文 HTML、图片 URL），保留文章结构和基本排版。每篇缓存 20-50KB，可存储 200+ 篇在 10MB 限制内。离线阅读时在扩展内渲染简化版阅读视图（类似 Safari Reader Mode）。用户可手动触发"深度缓存"（包含图片 base64 编码）用于关键文章。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 存储位置 | chrome.storage.local | IndexedDB | YiAi 后端 | **chrome.storage.local + IndexedDB** | 元数据用小存储，正文用大存储 |
| AI 摘要时机 | 保存时实时 | 后台异步 | 手动触发 | **后台异步** | 保存即时，摘要不丢失 |
| 进度追踪 | 滚动位置 | 阅读时间 | 段落标记 | **滚动位置 + 阅读时间** | 双重保障，互补准确 |
| 离线缓存 | 完整 HTML | 纯文本 | Reader Mode | **Reader Mode 提取** | 保真度与存储大小的最优平衡 |

// src/background/ReadingListService.ts (新增，运行在 Service Worker)

class ReadingListService {
  private storageKey = 'yipet_reading_list';
  private maxItems = 500;        // 最大文章数
  private cacheExpireDays = 30;  // 缓存过期天数

  /**
   * 添加文章到阅读列表
   */
  async addArticle(params: {
    url: string;
    title: string;
    tags?: string[];
    triggerAbstract?: boolean;
  }): Promise<ReadingItem> {
    const existing = await this.findByUrl(params.url);
    if (existing) {
      throw new Error('文章已在阅读列表中');
    }

    // 检查数量限制
    const all = await this.getAll();
    if (all.length >= this.maxItems) {
      throw new Error(`阅读列表已满（最多 ${this.maxItems} 篇）`);
    }

    const item: ReadingItem = {
      id: crypto.randomUUID(),
      url: params.url,
      title: params.title,
      domain: this.extractDomain(params.url),
      faviconUrl: this.getFaviconUrl(params.url),
      abstract: '',
      abstractStatus: params.triggerAbstract !== false ? 'pending' : 'pending',
      status: 'unread',
      progress: 0,
      readingTime: 0,
      lastPosition: 0,
      wordCount: 0,
      estimatedMinutes: 0,
      remainingMinutes: 0,
      tags: params.tags || [],
      offlineCached: false,
      savedAt: Date.now(),
    };

    await this.saveItem(item);

    // 触发后台 AI 摘要生成
    if (params.triggerAbstract !== false) {
      this.generateAbstractInBackground(item.id);
    }

    return item;
  }

  /**
   * 获取所有阅读列表文章
   */
  async getAll(filter?: ReadingListFilter): Promise<ReadingItem[]> {
    let items = await this.readFromStorage();

    if (filter) {
      if (filter.query) {
        const q = filter.query.toLowerCase();
        items = items.filter(i =>
          i.title.toLowerCase().includes(q) ||
          i.abstract.toLowerCase().includes(q) ||
          i.url.toLowerCase().includes(q)
        );
      }
      if (filter.status) {
        items = items.filter(i => i.status === filter.status);
      }
      if (filter.tags && filter.tags.length > 0) {
        items = items.filter(i =>
          filter.tags!.some(t => i.tags.includes(t))
        );
      }
      if (filter.domain) {
        items = items.filter(i => i.domain === filter.domain);
      }
      if (filter.sortBy) {
        items = this.sortItems(items, filter.sortBy, filter.sortOrder || 'desc');
      }
    }

    return items;
  }

  /**
   * 更新阅读进度
   */
  async updateProgress(
    id: string,
    progress: number,
    readingTime: number,
    lastPosition: number
  ): Promise<void> {
    const items = await this.readFromStorage();
    const item = items.find(i => i.id === id);
    if (!item) return;

    item.progress = Math.min(100, Math.max(0, progress));
    item.readingTime = readingTime;
    item.lastPosition = lastPosition;
    item.lastReadAt = Date.now();

    if (item.status === 'unread') {
      item.status = 'reading';
    }

    // 计算剩余时间
    if (item.estimatedMinutes > 0) {
      item.remainingMinutes = Math.max(
        0,
        item.estimatedMinutes * (1 - item.progress / 100)
      );
    }

    await this.saveAll(items);
  }

  /**
   * 标记文章为已完成
   */
  async markCompleted(id: string): Promise<void> {
    const items = await this.readFromStorage();
    const item = items.find(i => i.id === id);
    if (!item) return;

    item.status = 'completed';
    item.progress = 100;
    item.completedAt = Date.now();
    item.remainingMinutes = 0;

    await this.saveAll(items);
  }

  /**
   * 删除文章
   */
  async removeArticle(id: string): Promise<void> {
    const items = await this.readFromStorage();
    const filtered = items.filter(i => i.id !== id);
    await this.saveAll(filtered);

    // 同时清理离线缓存
    await this.deleteOfflineCache(id);
  }

  /**
   * 归档文章
   */
  async archiveArticle(id: string): Promise<void> {
    const items = await this.readFromStorage();
    const item = items.find(i => i.id === id);
    if (!item) return;

    item.status = 'archived';
    item.archivedAt = Date.now();
    await this.saveAll(items);
  }

  /**
   * 获取阅读统计
   */
  async getStats(period: 'week' | 'month' | 'all' = 'week'): Promise<ReadingStats> {
    const items = await this.readFromStorage();
    const now = Date.now();
    const periodStart = period === 'week'
      ? now - 7 * 24 * 60 * 60 * 1000
      : period === 'month'
        ? now - 30 * 24 * 60 * 60 * 1000
        : 0;

    const periodItems = items.filter(i => i.savedAt >= periodStart);
    const completedItems = items.filter(
      i => i.status === 'completed' && (i.completedAt || 0) >= periodStart
    );
    const totalReadingTime = periodItems.reduce((s, i) => s + i.readingTime, 0);
    const totalWords = completedItems.reduce((s, i) => s + i.wordCount, 0);
    const averageSpeed = totalReadingTime > 0
      ? Math.round(totalWords / (totalReadingTime / 60))
      : 0;

    // 按标签统计
    const byTag: Record<string, number> = {};
    for (const item of periodItems) {
      for (const tag of item.tags) {
        byTag[tag] = (byTag[tag] || 0) + 1;
      }
    }

    // 按域名统计
    const byDomain: Record<string, number> = {};
    for (const item of periodItems) {
      byDomain[item.domain] = (byDomain[item.domain] || 0) + 1;
    }

    // 连续阅读天数
    const streak = this.calculateStreak(items);

    // 阅读时段分布
    const peakHours = this.calculatePeakHours(items);

    // 最近 7 天趋势
    const weeklyTrend = this.calculateWeeklyTrend(items);

    return {
      period,
      totalArticles: periodItems.length,
      readArticles: completedItems.length,
      completionRate: periodItems.length > 0
        ? completedItems.length / periodItems.length
        : 0,
      totalReadingTime,
      averageReadingSpeed: averageSpeed,
      byTag,
      byDomain,
      streak,
      peakHours,
      weeklyTrend,
    };
  }

    sortBy: string,
    sortOrder: 'asc' | 'desc'
  ): ReadingItem[] {
    const multiplier = sortOrder === 'asc' ? 1 : -1;
    return [...items].sort((a, b) => {
      const aVal = (a as any)[sortBy] || 0;
      const bVal = (b as any)[sortBy] || 0;
      return (aVal > bVal ? 1 : -1) * multiplier;
    });
  }

  private calculateStreak(items: ReadingItem[]): number {
    const readDates = new Set(
      items
        .filter(i => i.lastReadAt)
        .map(i => new Date(i.lastReadAt!).toDateString())
    );
    let streak = 0;
    const today = new Date();
    for (let i = 0; i < 365; i++) {
      const date = new Date(today);
      date.setDate(date.getDate() - i);
      if (readDates.has(date.toDateString())) {
        streak++;
      } else {
        break;
      }
    }
    return streak;
  }

  private calculatePeakHours(items: ReadingItem[]): number[] {
    const hourCounts = new Array(24).fill(0);
    for (const item of items) {
      if (item.lastReadAt) {
        const hour = new Date(item.lastReadAt).getHours();
        hourCounts[hour]++;
      }
    }
    // 返回最高的 3 个小时
    return hourCounts
      .map((count, hour) => ({ hour, count }))
      .sort((a, b) => b.count - a.count)
      .slice(0, 3)
      .map(h => h.hour);
  }

  private calculateWeeklyTrend(items: ReadingItem[]): number[] {
    const trend = new Array(7).fill(0);
    const now = Date.now();
    for (const item of items) {
      if (item.lastReadAt) {
        const daysAgo = Math.floor((now - item.lastReadAt) / (24 * 60 * 60 * 1000));
        if (daysAgo >= 0 && daysAgo < 7) {
          trend[6 - daysAgo]++;
        }
      }
    }
    return trend;
  }

// src/contentScript/readingProgress.ts (新增，注入到阅读页面)

class ReadingProgressTracker {
  private articleId: string;
  private totalWords: number;
  private startTime: number;
  private readingTime: number;
  private scrollHandler: (() => void) | null;

  constructor(articleId: string) {
    this.articleId = articleId;
    this.totalWords = this.countWords();
    this.startTime = Date.now();
    this.readingTime = 0;
    this.scrollHandler = null;
  }

  /**
   * 初始化进度追踪
   */
  init(): void {
    // 注入进度条 UI
    this.injectProgressBar();

    // 监听滚动事件（防抖 500ms）
    this.scrollHandler = this.debounce(() => {
      this.updateProgress();
    }, 500);
    window.addEventListener('scroll', this.scrollHandler, { passive: true });

    // 监听页面可见性变化
    document.addEventListener('visibilitychange', () => {
      if (document.hidden) {
        this.pauseTracking();
      } else {
        this.resumeTracking();
      }
    });

    // 初始化时发送字数信息
    this.sendMessage({
      type: 'READING_STARTED',
      articleId: this.articleId,
      totalWords: this.totalWords,
      estimatedMinutes: Math.ceil(this.totalWords / 400),
    });
  }

  /**
   * 销毁追踪器
   */
  destroy(): void {
    if (this.scrollHandler) {
      window.removeEventListener('scroll', this.scrollHandler);
    }
    this.removeProgressBar();
  }

  /**
   * 更新阅读进度
   */
  private updateProgress(): void {
    const scrollTop = window.scrollY;
    const docHeight = document.documentElement.scrollHeight - window.innerHeight;
    const progress = docHeight > 0 ? Math.round((scrollTop / docHeight) * 100) : 0;

    // 更新进度条
    this.updateProgressBar(progress);

    // 发送进度到 Service Worker
    this.sendMessage({
      type: 'READING_PROGRESS',
      articleId: this.articleId,
      progress,
      readingTime: this.readingTime + Math.floor((Date.now() - this.startTime) / 1000),
      lastPosition: scrollTop,
    });
  }

  /**
   * 暂停追踪（页面不可见时）
   */
  private pauseTracking(): void {
    this.readingTime += Math.floor((Date.now() - this.startTime) / 1000);
  }

  /**
   * 恢复追踪
   */
  private resumeTracking(): void {
    this.startTime = Date.now();
  }

  /**
   * 统计页面字数
   */
  private countWords(): number {

class ReadingReminderService {
  private config: ReadingReminderConfig;
  private alarmName = 'yipet-reading-reminder';
  private statsAlarmName = 'yipet-weekly-stats';

  constructor() {
    this.config = this.getDefaultConfig();
  }

  /**
   * 初始化提醒服务
   */
  async init(): Promise<void> {
    // 加载用户配置
    const saved = await chrome.storage.local.get('yipet_reminder_config');
    if (saved.yipet_reminder_config) {
      this.config = { ...this.config, ...saved.yipet_reminder_config };
    }

    // 设置每日提醒闹钟
    if (this.config.enabled) {
      this.scheduleDailyReminder();
    }

    // 设置周末总结闹钟
    if (this.config.weekendSummary) {
      this.scheduleWeekendSummary();
    }

    // 监听闹钟触发
    chrome.alarms.onAlarm.addListener((alarm) => {
      if (alarm.name === this.alarmName) {
        this.checkAndNotify();
      } else if (alarm.name === this.statsAlarmName) {
        this.sendWeeklySummary();
      }
    });
  }

  /**
   * 检查是否需要提醒
   */
  async checkAndNotify(): Promise<void> {
    const readingListService = new ReadingListService();
    const items = await readingListService.getAll({ status: 'unread' });

    if (items.length >= this.config.unreadThreshold) {
      // 检查是否在 idleHours 内未阅读
      const lastReadItem = items
        .filter(i => i.lastReadAt)
        .sort((a, b) => (b.lastReadAt || 0) - (a.lastReadAt || 0))[0];

      const idleTime = lastReadItem?.lastReadAt
        ? Date.now() - lastReadItem.lastReadAt
        : Infinity;

      if (idleTime >= this.config.idleHours * 60 * 60 * 1000) {
        this.sendNotification(items.length);
      }
    }

    // 更新扩展角标
    if (this.config.badgeCount) {
      chrome.action.setBadgeText({ text: items.length > 0 ? String(items.length) : '' });
      chrome.action.setBadgeBackgroundColor({ color: '#667eea' });
    }
  }

  /**
   * 发送阅读提醒通知
   */
  private sendNotification(unreadCount: number): void {
    const messages = [
      `你有 ${unreadCount} 篇文章待阅读，现在开始阅读吗？`,
      `${unreadCount} 篇文章在等你，抽空读一篇吧！`,
      `阅读列表中有 ${unreadCount} 篇未读文章，别让它们等待太久~`,
    ];

    chrome.notifications.create('reading-reminder', {
      type: 'basic',
      iconUrl: '/icons/icon128.png',
      title: 'YiPet 阅读提醒',
      message: messages[Math.floor(Math.random() * messages.length)],
      buttons: [{ title: '打开阅读列表' }],
      requireInteraction: false,
    });
  }

  /**
   * 发送每周阅读总结
   */
  private async sendWeeklySummary(): Promise<void> {
    const readingListService = new ReadingListService();
    const stats = await readingListService.getStats('week');

    if (stats.totalArticles === 0) return;

    const summary = [
      `📊 本周阅读总结`,
      `共阅读 ${stats.readArticles} 篇文章`,
      `总阅读时间 ${Math.round(stats.totalReadingTime / 60)} 分钟`,
      `连续阅读 ${stats.streak} 天`,
      stats.completionRate > 0.5
        ? `完成率 ${Math.round(stats.completionRate * 100)}%，表现不错！`
        : `还有 ${stats.totalArticles - stats.readArticles} 篇未读，加油！`,
    ].join('\n');

    chrome.notifications.create('weekly-summary', {
      type: 'basic',
      iconUrl: '/icons/icon128.png',
      title: 'YiPet 每周阅读报告',
      message: summary,
      buttons: [{ title: '查看详情' }],
    });
  }

  /**
   * 更新提醒配置
   */
  async updateConfig(updates: Partial<ReadingReminderConfig>): Promise<void> {
    this.config = { ...this.config, ...updates };
    await chrome.storage.local.set({ yipet_reminder_config: this.config });

    // 重新调度闹钟
    await chrome.alarms.clear(this.alarmName);
    if (this.config.enabled) {
      this.scheduleDailyReminder();
    }
  }

  // 调度和配置方法
  private scheduleDailyReminder(): void {
    const [hours, minutes] = this.config.dailyReminderTime.split(':').map(Number);
    chrome.alarms.create(this.alarmName, {
      when: this.getNextAlarmTime(hours, minutes),
      periodInMinutes: 24 * 60,
    });
  }

  private scheduleWeekendSummary(): void {
    // 周日 20:00
    chrome.alarms.create(this.statsAlarmName, {
      when: this.getNextSundayTime(20, 0),
      periodInMinutes: 7 * 24 * 60,
    });
  }

  private getNextAlarmTime(hours: number, minutes: number): number {
    const now = new Date();
    const target = new Date(now);
    target.setHours(hours, minutes, 0, 0);
    if (target <= now) {
      target.setDate(target.getDate() + 1);
    }
    return target.getTime();
  }

  private getNextSundayTime(hours: number, minutes: number): number {
    const now = new Date();
    const target = new Date(now);
    target.setHours(hours, minutes, 0, 0);
    // 周日 = 0
    const daysUntilSunday = (7 - target.getDay()) % 7 || 7;
    target.setDate(target.getDate() + daysUntilSunday);
    return target.getTime();
  }

  private getDefaultConfig(): ReadingReminderConfig {
    return {
      enabled: true,
      unreadThreshold: 3,
      idleHours: 24,
      dailyReminderTime: '20:00',
      weekendSummary: true,
      badgeCount: true,
    };
  }
}

class OfflineCacheService {
  private dbName = 'yipet_offline_cache';
  private storeName = 'articles';
  private db: IDBDatabase | null = null;

  /**
   * 初始化 IndexedDB
   */
  async init(): Promise<void> {
    return new Promise((resolve, reject) => {
      if (!('indexedDB' in self)) {
        reject(new Error('IndexedDB 不可用'));
        return;
      }

      const request = indexedDB.open(this.dbName, 1);
      request.onupgradeneeded = (event) => {
        const db = (event.target as IDBOpenDBRequest).result;
        if (!db.objectStoreNames.contains(this.storeName)) {
          db.createObjectStore(this.storeName, { keyPath: 'articleId' });
        }
      };
      request.onsuccess = (event) => {
        this.db = (event.target as IDBOpenDBRequest).result;
        resolve();
      };
      request.onerror = () => reject(new Error('IndexedDB 打开失败'));
    });
  }

  /**
   * 缓存文章内容
   */
  async cacheArticle(articleId: string, url: string): Promise<boolean> {
    try {
      // 使用 Readability 算法提取内容（通过 offscreen document）
      const content = await this.extractContent(url);
      if (!content) return false;

      await this.putToDb({
        articleId,
        content: content.text,
        title: content.title,
        byline: content.byline,
        excerpt: content.excerpt,
        cachedAt: Date.now(),
        size: new Blob([content.text]).size,
      });

      return true;
    } catch (err) {
      console.error('[YiPet] 离线缓存失败:', err);
      return false;
    }
  }

  /**
   * 获取缓存内容
   */
  async getCachedArticle(articleId: string): Promise<CachedArticle | null> {
    return this.getFromDb(articleId);
  }

  /**
   * 删除缓存
   */
  async deleteCache(articleId: string): Promise<void> {
    await this.deleteFromDb(articleId);
  }

  /**
   * 清理过期缓存（30 天未读）
   */
  async cleanExpiredCache(maxAge: number = 30 * 24 * 60 * 60 * 1000): Promise<number> {
    const all = await this.getAllFromDb();
    const now = Date.now();
    let cleaned = 0;

    for (const item of all) {
      if (now - item.cachedAt > maxAge) {
        await this.deleteFromDb(item.articleId);
        cleaned++;
      }
    }

    return cleaned;
  }

  /**
   * 获取缓存存储使用量
   */
  async getStorageUsage(): Promise<{ count: number; totalSize: number }> {
    const all = await this.getAllFromDb();
    return {
      count: all.length,
      totalSize: all.reduce((sum, item) => sum + item.size, 0),
    };
  }

  // IndexedDB CRUD 操作
  private async putToDb(item: CachedArticle): Promise<void> {
    return new Promise((resolve, reject) => {
      const tx = this.db!.transaction(this.storeName, 'readwrite');
      const store = tx.objectStore(this.storeName);
      store.put(item);
      tx.oncomplete = () => resolve();
      tx.onerror = () => reject(tx.error);
    });
  }

  private async getFromDb(articleId: string): Promise<CachedArticle | null> {
    return new Promise((resolve, reject) => {
      const tx = this.db!.transaction(this.storeName, 'readonly');
      const store = tx.objectStore(this.storeName);
      const request = store.get(articleId);
      request.onsuccess = () => resolve(request.result || null);
      request.onerror = () => reject(request.error);
    });
  }

  private async getAllFromDb(): Promise<CachedArticle[]> {
    return new Promise((resolve, reject) => {
      const tx = this.db!.transaction(this.storeName, 'readonly');
      const store = tx.objectStore(this.storeName);
      const request = store.getAll();
      request.onsuccess = () => resolve(request.result || []);
      request.onerror = () => reject(request.error);
    });
  }

  private async deleteFromDb(articleId: string): Promise<void> {
    return new Promise((resolve, reject) => {
      const tx = this.db!.transaction(this.storeName, 'readwrite');
      const store = tx.objectStore(this.storeName);
      store.delete(articleId);
      tx.oncomplete = () => resolve();
      tx.onerror = () => reject(tx.error);
    });
  }

  /**
   * 提取页面内容（通过 offscreen document 使用 Readability）
   */
  private async extractContent(url: string): Promise<{
    text: string;
    title: string;
    byline: string;
    excerpt: string;
  } | null> {
    try {
      const response = await fetch(url);
      const html = await response.text();
      // 实际实现：通过 chrome.offscreen API 创建离屏文档
      // 在离屏文档中使用 Readability.js 解析 HTML
      // 此处为简化实现
      return null;
    } catch {
      return null;
    }
  }
}

interface CachedArticle {
  articleId: string;
  content: string;
  title: string;
  byline: string;
  excerpt: string;
  cachedAt: number;
  size: number;
}

| 阅读提醒过于频繁导致用户关闭通知 | 中 | 低 | 提供细粒度的提醒设置（频率、时段、阈值），默认保守配置（每天最多 1 次提醒） |

## 九、设计决策记录

### D-01：阅读列表 vs 浏览器书签的定位

- **问题**：阅读列表与浏览器书签功能重叠，如何区分定位
- **选项**：完全替代书签、与书签共存互补、不实现阅读列表
- **选择**：与书签共存互补，定位为"主动阅读管理"而非"URL 收藏"
- **理由**：书签是永久性的 URL 收藏（如常用工具网站），阅读列表是临时性的阅读意图管理（如"稍后读"）。阅读列表提供书签不具备的进度追踪、AI 摘要、阅读提醒等功能。两者定位不同，用户可同时使用。

### D-02：AI 摘要的语言选择

- **问题**：AI 摘要应该生成中文还是保留原文语言
- **选项**：始终生成中文摘要、保留原文语言、用户可配置
- **选择**：始终生成中文摘要，用户可配置切换
- **理由**：YiPet 目标用户为中文用户，中文摘要最实用。但考虑到部分用户阅读英文原文，提供"保留原文语言"选项。默认中文，在设置中可切换。

### D-03：阅读时间估算的准确度

- **问题**：阅读时间估算基于字数统计，但不同语言和内容类型的阅读速度差异大
- **选项**：统一速度（400 字/分钟）、语言自适应速度、内容类型自适应速度
- **选择**：统一速度 400 字/分钟（中文），250 词/分钟（英文），代码块不计入
- **理由**：中文阅读速度约 300-500 字/分钟，取 400 字/分钟作为默认值。英文约 200-300 词/分钟，取 250 词/分钟。代码块被识别并排除在字数统计之外。显示为"预计约 12 分钟"（带"约"字降低精确度预期）。

### D-04：离线缓存的存储策略

- **问题**：离线缓存的页面内容存储在 chrome.storage.local 还是 IndexedDB
- **选项**：chrome.storage.local（10MB 限制）、IndexedDB（无限制）、两者结合
- **选择**：IndexedDB 存储离线缓存内容，chrome.storage.local 仅存储元数据
- **理由**：IndexedDB 没有 10MB 限制，适合存储页面正文内容。chrome.storage.local 仅存储元数据（URL、标题、摘要、进度），每篇 < 2KB。读取时先从 chrome.storage.local 获取列表，再按需从 IndexedDB 加载正文。

## 回归问题预测

| # | 预测问题 | 原因 | 验证方法 |
|---|---------|------|---------|
| 1 | 用户保存文章后立即关闭标签页，后台 AI 摘要生成时页面已不可用，摘要生成失败 | AI 摘要通过 `fetch(url)` 获取页面内容，但页面已关闭或需要登录 cookie，内容提取失败 | 在保存文章时同步提取页面内容（Readability.js），将提取的文本存储到 IndexedDB，AI 摘要从缓存内容生成，而非重新 fetch 页面 |
| 2 | 阅读进度 Content Script 注入到某些页面后，与页面原有的滚动监听冲突（如无限滚动页面），导致页面功能异常 | Content Script 的 scroll 事件监听器可能与页面的 `scroll` 事件处理器冲突，特别是使用 `preventDefault` 或修改滚动行为的页面 | 使用 `{ passive: true }` 选项注册 scroll 监听器，确保不阻止页面默认滚动行为。检测页面是否有自定义滚动容器（如 `overflow: scroll` 的 div），优先监听主滚动容器 |
| 3 | 用户阅读列表超过 100 篇时，chrome.storage.local 的 get/set 操作变慢，阅读列表加载时间超过 200ms | chrome.storage.local 的读写操作是异步的，数据量大时（>500KB）序列化/反序列化耗时增加 | 阅读列表数据超过 100 篇时，仅加载前 50 篇的完整数据，其余文章仅加载标题和状态（fields 子集），用户滚动到底部时懒加载更多文章 |
| 4 | 离线缓存了同一域名的多篇文章后，IndexedDB 中存储了大量重复的页面模板/导航 HTML，浪费存储空间 | Readability.js 提取的内容可能包含页面 chrome（导航栏、侧边栏）的残留文本，多篇同域名文章缓存时有大量重复内容 | 对 Readability 提取的内容进行去重处理：对比同域名文章的文本相似度，相似度 > 80% 的段落（通常是导航和页脚）标记为模板内容，仅存储一次 |
| 5 | 阅读提醒在用户正在忙碌时（如开会、编码）弹出，打断用户工作流，导致用户关闭通知权限 | 每日提醒使用固定时间（20:00），未考虑用户当前活动状态（是否在浏览器前、是否在忙碌） | 发送提醒前检查用户浏览器活动状态：最近 5 分钟内是否有键盘/鼠标事件，浏览器标签页是否活跃。如果用户正在活跃使用浏览器，延迟提醒 30 分钟后重试 |
| 6 | 同一篇文章的阅读进度在多个设备间不同步，用户在手机上读到 50%，在电脑上打开仍显示 0% | 阅读进度存储在 chrome.storage.local 中，不支持跨设备同步。如果用户启用 YiAi 后端同步，进度同步延迟可能导致数据覆盖 | 阅读进度更新时记录时间戳，同步时使用最后写入时间（last-write-wins）策略。同时记录设备 ID，在 UI 上显示"上次在 MacBook 上读到 50%" |
