# YiPet 运行时可靠性修复

> 需求编号：YP-09-100 · 优先级：P2 · 总人天：~0.25d · 涉及模块：background(1)、api(1)

---

## 一、需求背景

代码审查发现 2 处运行时隐患：

| 严重度 | 问题 | 影响 |
|--------|------|------|
| **P2-minor** | SW 异步初始化无 catch | 初始化失败时快捷键静默失效 |
| **P3-trivial** | SSE `data:` 无空格格式未处理 | 部分后端 SSE 数据被丢弃 |

---

## 二、技术方案

### 2.1 SW 初始化 Promise 链补全

```ts
// Before: fire-and-forget without error handling
swStateMachine.init().then(() => { ... });

// After: with catch
swStateMachine.init().then(...).catch((err) => {
  console.error('[YiPet] Service worker init failed:', err);
});
```

### 2.2 SSE data 前缀规范合规

```ts
// Before: only matches 'data: '
if (t.startsWith('data: ')) { dataStr += t.slice(6); }

// After: matches 'data:' with optional space
if (t.startsWith('data:')) { dataStr += t[5] === ' ' ? t.slice(6) : t.slice(5); }
```

---

## 三、验收标准

1. `npm run typecheck && npm run build` 通过
2. `npm test` 138 passed
3. SW 初始化失败时 console 有明确 error 输出
4. `data:hello` 和 `data: hello` 两种 SSE 格式均可正确解析
