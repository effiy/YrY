# PE-09-117: 会话悬停消息预览

> 会话识别增强：侧边栏会话项 hover 600ms 后弹出最近 3 条消息预览，帮助用户在不切换会话的情况下识别内容。

## 范围

- `previewMessages` computed：取最近 3 条消息的前 80 字符
- ElPopover hover 触发（600ms 延迟）
- 预览区分 user/AI 消息
- 无消息的会话不弹出

## 验收标准

- [ ] hover 会话项 600ms 后弹出消息预览
- [ ] 显示最近 3 条消息（You: ... / AI: ...）
- [ ] 空会话不弹出
