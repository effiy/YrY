# YP-09-117: 代码执行沙箱 — 浏览器内 JS/TS 沙箱、Python 远程执行、多语言代码运行与结果展示

> 需求编号：YP-09-117 · 优先级：P2 · 人天：1.0d · 状态：需求已编写
> 依赖：YP-09-47（代码高亮增强）、YP-09-70（兼容性工具链）

## 背景

### 问题陈述

YiPet 当前聊天功能仅支持文本对话，用户在对话中遇到代码相关问题时，需要手动切换到外部工具（如浏览器控制台、CodePen、本地 IDE）执行代码验证结果。这导致：

1. **上下文断裂**：用户需要离开聊天窗口才能执行代码，打断对话流
2. **安全性不可控**：用户自行在控制台执行代码存在安全风险，且无法限制执行范围
3. **结果无法留存**：外部执行的代码和结果无法自动关联到会话历史中
4. **多语言支持缺失**：不同语言需要不同的执行环境，用户需要分别配置
5. **协作困难**：无法将代码片段和运行结果分享给他人

**核心矛盾**：在浏览器扩展中提供安全的代码执行环境，既要支持多语言（JS/TS/Python/SQL/Bash），又要严格限制资源使用和权限，防止恶意代码对用户系统造成损害。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 代码验证需要离开聊天，效率低 | 高 | 用户询问 JS 数组方法，AI 给出代码，用户需手动验证 |
| 2 | 不安全代码可能破坏页面 | 高 | 用户在控制台执行 `document.body.innerHTML = ''` |
| 3 | 代码结果无法留存和复用 | 中 | 执行结果仅在当前会话可见，无法回顾 |
| 4 | 不支持 Python 等后端语言 | 中 | 数据分析、爬虫等 Python 代码无法执行 |
| 5 | 无法分享代码片段 | 低 | 用户想分享有趣的代码结果给朋友 |

### 挑战

| 挑战 | 说明 |
|------|------|
| 安全隔离 | 在浏览器中执行用户代码，必须防止 XSS、DOM 篡改、数据泄露 |
| 资源限制 | 需要限制执行时间、内存使用，防止无限循环或内存溢出 |
| 多语言运行时 | JS/TS 可在浏览器中执行，但 Python/SQL/Bash 需要远程服务 |
| 编辑器体验 | 需要在聊天窗口中嵌入代码编辑器，支持语法高亮和自动补全 |
| 结果展示 | stdout、stderr、返回值、执行时间需要清晰展示和区分 |

## 二、设计决策

### 决策 1：前端沙箱方案 — Web Worker 隔离 vs iframe 隔离 vs WebContainer

| 选项 | 隔离性 | 性能 | 兼容性 | 复杂度 |
|------|--------|------|--------|--------|
| Web Worker 隔离 | 中（无 DOM 访问） | 高 | 好 | 低 |
| iframe + sandbox 属性 | 高（完全隔离） | 中 | 好 | 中 |
| WebContainer (StackBlitz) | 高（完整 Node.js） | 中 | 仅 Chromium | 高 |

**选择：iframe + sandbox 属性为主，Web Worker 为辅助。** iframe 的 `sandbox` 属性提供最可靠的安全隔离（禁用脚本之外的权限），配合 `srcdoc` 注入代码执行环境。对于无需 DOM 的纯计算，使用 Web Worker 提供更低延迟的执行。WebContainer 作为未来 Node.js 支持的备选方案。

### 决策 2：Python 执行方案 — Pyodide WASM vs 服务端沙箱 vs 两者兼有

| 选项 | 离线可用 | 性能 | 库支持 | 安全风险 |
|------|----------|------|--------|----------|
| Pyodide (WASM) | 是 | 中（首次加载慢） | 有限（预编译包） | 低（浏览器沙箱） |
| 服务端沙箱 (YiAi) | 否 | 高 | 完整 pip | 中（需服务端隔离） |
| 两者兼有 | 部分 | 兼顾 | 兼顾 | 低+中 |

**选择：两者兼有。** 优先使用 Pyodide WASM 在浏览器中执行 Python（离线可用、无服务端压力），对于需要第三方库或大计算量的场景，转发到 YiAi 服务端沙箱执行。前端自动判断：标准库和 numpy/pandas 等 Pyodide 支持的包在浏览器执行，其他包转发到服务端。

### 决策 3：代码编辑器方案 — 独立编辑器组件 vs 增强代码块 vs CodeMirror/Monaco

| 选项 | 体积 | 功能 | 加载速度 | 集成难度 |
|------|------|------|----------|----------|
| 增强代码块（contenteditable） | 极小 | 基础 | 即时 | 低 |
| CodeMirror 6 | ~150KB | 丰富 | 快 | 中 |
| Monaco Editor | ~2MB | 完整 | 慢 | 高 |

**选择：CodeMirror 6。** 体积适中（~150KB gzipped），支持语法高亮、自动补全、多语言、主题定制，按需加载语言包。Monaco 功能最强但体积过大不适合扩展场景；增强代码块功能不足无法提供良好编辑体验。

### 决策 4：执行结果存储 — 内存 vs chrome.storage.local vs IndexedDB

| 选项 | 持久化 | 容量 | 查询 | 会话关联 |
|------|--------|------|------|----------|
| 内存 | 否 | 无限制 | 快 | 临时 |
| chrome.storage.local | 是 | 10MB | 键值 | 简单 |
| IndexedDB | 是 | 无限制 | 丰富 | 复杂 |

**选择：chrome.storage.local。** 代码执行结果体积小（每条 < 10KB），10MB 足以存储 1000+ 条记录。键值模型足以满足按会话查询和按时间排序的需求。IndexedDB 的丰富查询能力在此场景下是过度设计。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 前端沙箱 | Web Worker | iframe sandbox | WebContainer | **iframe sandbox** | 隔离性最强 |
| Python 执行 | Pyodide WASM | 服务端沙箱 | 两者兼有 | **两者兼有** | 兼顾离线与性能 |
| 代码编辑器 | 增强代码块 | CodeMirror 6 | Monaco | **CodeMirror 6** | 体积与功能平衡 |
| 结果存储 | 内存 | chrome.storage.local | IndexedDB | **chrome.storage.local** | 容量足够 |

### 3.3 安全沙箱配置

```
iframe sandbox 属性:
├── allow-scripts           # 允许脚本执行（必需）
├── 不设置 allow-same-origin # 禁止访问父页面
├── 不设置 allow-forms       # 禁止表单提交
├── 不设置 allow-popups      # 禁止弹窗
├── 不设置 allow-top-navigation # 禁止导航
└── 不设置 allow-modals      # 禁止 alert/confirm/prompt

执行限制:
├── 超时: 10s（Web Worker 中的 setTimeout 强制终止）
├── 内存: 128MB（Performance.memory 监控，超限终止）
├── 网络: 禁止（不设置 allow-network-access 或 CSP 阻止）
├── 文件系统: 禁止（不提供 file: 协议访问）
└── DOM 访问: 仅限沙箱内 srcdoc
```

### 3.4 性能指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| JS/TS 执行启动延迟 | < 50ms | iframe 创建 + srcdoc 注入 |
| Python 执行启动延迟 | < 200ms | Pyodide 首次加载后 < 50ms |
| 服务端执行往返延迟 | < 2s | 网络 + 执行 + 返回 |
| 编辑器加载延迟 | < 100ms | CodeMirror 按需加载 |
| 结果渲染延迟 | < 10ms | stdout/stderr 格式化展示 |

## 四、具体改动

### 4.1 沙箱执行引擎

```typescript
// src/content/sandbox/SandboxExecutor.ts (新增)

interface ExecutionResult {
  stdout: string;
  stderr: string;
  returnValue: unknown;
  executionTime: number;     // ms
  truncated: boolean;        // 输出是否被截断
  error: string | null;
}

interface ExecutionOptions {
  language: 'javascript' | 'typescript' | 'python' | 'sql' | 'bash';
  code: string;
  timeout: number;           // 默认 10000ms
  maxOutputLength: number;   // 默认 10000 字符
}

class SandboxExecutor {
  private pythonRuntime: PyodideRuntime | null = null;
  private executionHistory: ExecutionRecord[] = [];
  private sessionId: string;

  constructor(sessionId: string) {
    this.sessionId = sessionId;
  }

  /**
   * 执行代码，根据语言自动路由到不同的运行时
   */
  async execute(options: ExecutionOptions): Promise<ExecutionResult> {
    const startTime = performance.now();

    switch (options.language) {
      case 'javascript':
        return this.executeJavaScript(options);
      case 'typescript':
        return this.executeTypeScript(options);
      case 'python':
        return this.executePython(options);
      case 'sql':
      case 'bash':
        return this.executeOnServer(options);
      default:
        throw new Error(`Unsupported language: ${options.language}`);
    }
  }

  /**
   * JavaScript 在 iframe sandbox 中执行
   */
  private async executeJavaScript(options: ExecutionOptions): Promise<ExecutionResult> {
    return new Promise((resolve) => {
      const iframe = document.createElement('iframe');
      iframe.sandbox.add('allow-scripts');
      iframe.style.display = 'none';

      const startTime = performance.now();

      iframe.onload = () => {
        const win = iframe.contentWindow!;
        const outputs: string[] = [];
        const errors: string[] = [];

        // 注入 console 捕获
        win.eval(`
          console.log = (...args) => window.__stdout.push(args.map(String).join(' '));
          console.error = (...args) => window.__stderr.push(args.map(String).join(' '));
          console.warn = (...args) => window.__stderr.push(args.map(String).join(' '));
          window.__stdout = [];
          window.__stderr = [];
        `);

        const timeoutId = setTimeout(() => {
          resolve({
            stdout: outputs.join('\n'),
            stderr: 'Execution timeout (10s)',
            returnValue: undefined,
            executionTime: 10000,
            truncated: false,
            error: 'TIMEOUT',
          });
          iframe.remove();
        }, options.timeout);

        try {
          const result = win.eval(options.code);
          clearTimeout(timeoutId);

          const elapsed = performance.now() - startTime;

          resolve({
            stdout: (win as any).__stdout?.join('\n') || '',
            stderr: (win as any).__stderr?.join('\n') || '',
            returnValue: this.serializeResult(result),
            executionTime: Math.round(elapsed),
            truncated: false,
            error: null,
          });
        } catch (e: any) {
          clearTimeout(timeoutId);
          resolve({
            stdout: '',
            stderr: e.message,
            returnValue: undefined,
            executionTime: Math.round(performance.now() - startTime),
            truncated: false,
            error: e.name,
          });
        } finally {
          iframe.remove();
        }
      };

      iframe.srcdoc = '<html><body></body></html>';
      document.body.appendChild(iframe);
    });
  }

  /**
   * TypeScript 先编译再执行
   */
  private async executeTypeScript(options: ExecutionOptions): Promise<ExecutionResult> {
    try {
      // 使用 TypeScript 编译器 API（需预加载）
      const tsCode = (window as any).ts.transpile(options.code);
      return this.executeJavaScript({ ...options, code: tsCode, language: 'javascript' });
    } catch (e: any) {
      return {
        stdout: '',
        stderr: `TypeScript compilation error: ${e.message}`,
        returnValue: undefined,
        executionTime: 0,
        truncated: false,
        error: 'COMPILE_ERROR',
      };
    }
  }

  /**
   * Python 通过 Pyodide WASM 或服务端执行
   */
  private async executePython(options: ExecutionOptions): Promise<ExecutionResult> {
    // 检查是否包含需要服务端的库
    const needsServer = this.requiresServerPython(options.code);

    if (needsServer) {
      return this.executeOnServer(options);
    }

    // 使用 Pyodide
    if (!this.pythonRuntime) {
      this.pythonRuntime = await this.initPyodide();
    }

    try {
      const startTime = performance.now();
      this.pythonRuntime.runPython(`
import sys
from io import StringIO
__stdout = StringIO()
__stderr = StringIO()
sys.stdout = __stdout
sys.stderr = __stderr
      `);

      const result = this.pythonRuntime.runPython(options.code);
      const stdout = this.pythonRuntime.runPython('__stdout.getvalue()');
      const stderr = this.pythonRuntime.runPython('__stderr.getvalue()');

      return {
        stdout: stdout,
        stderr: stderr,
        returnValue: result,
        executionTime: Math.round(performance.now() - startTime),
        truncated: false,
        error: null,
      };
    } catch (e: any) {
      return {
        stdout: '',
        stderr: e.message,
        returnValue: undefined,
        executionTime: 0,
        truncated: false,
        error: 'PYTHON_ERROR',
      };
    }
  }

  /**
   * 通过 YiAi 服务端沙箱执行
   */
  private async executeOnServer(options: ExecutionOptions): Promise<ExecutionResult> {
    const response = await this.apiClient.call('services.sandbox.execute', {
      language: options.language,
      code: options.code,
      timeout: options.timeout,
    });
    return response.data;
  }

  private serializeResult(value: unknown): string {
    try {
      if (value === undefined) return 'undefined';
      if (typeof value === 'function') return '[Function]';
      if (typeof value === 'symbol') return value.toString();
      return JSON.stringify(value, null, 2);
    } catch {
      return String(value);
    }
  }

  private requiresServerPython(code: string): boolean {
    const serverOnlyImports = [
      'requests', 'selenium', 'beautifulsoup4', 'scrapy',
      'django', 'flask', 'fastapi', 'sqlalchemy',
      'psycopg2', 'pymongo', 'redis',
    ];
    const importPattern = /(?:import|from)\s+(\w+)/g;
    let match;
    while ((match = importPattern.exec(code)) !== null) {
      if (serverOnlyImports.includes(match[1])) return true;
    }
    return false;
  }
}
```

interface CodeSnippet {
  id: string;
  code: string;
  language: string;
  result: ExecutionResult | null;
  createdAt: number;
  sessionId: string;
  authorName: string;
}

class CodeSnippetManager {
  /**
   * 生成可分享的代码片段
   * 存储到 YiAi 后端，返回分享链接

  async shareSnippet(snippet: CodeSnippet): Promise<string> {

      result: snippet.result,

    const response = await this.apiClient.call('services.sandbox.get_snippet', {
      share_id: shareId,
    });
    return response.data;
  }
}

## 六、测试规格

### 场景 1：JavaScript 代码在沙箱中安全执行

**GIVEN** 聊天消息中包含 JavaScript 代码块 `console.log("hello"); 1 + 1`

**THEN** 代码在 iframe sandbox 中执行
**AND** stdout 显示 "hello"
**AND** return 显示 "2"
**AND** 执行时间 < 50ms
**AND** 父页面 DOM 未受影响

### 场景 2：执行超时自动终止

**GIVEN** 代码包含无限循环 `while(true) {}`
**WHEN** 用户点击"运行"
**THEN** 10 秒后执行被强制终止
**AND** stderr 显示 "Execution timeout (10s)"
**AND** error 字段为 "TIMEOUT"
**AND** iframe 被正确移除

### 场景 3：Python 代码通过 Pyodide 执行

**GIVEN** 聊天消息中包含 Python 代码 `print(sum(range(100)))`
**WHEN** 用户点击"运行"
**THEN** Pyodide WASM 运行时加载（首次）
**AND** stdout 显示 "4950"
**AND** 执行时间 < 200ms（首次加载后 < 50ms）

### 场景 4：服务端沙箱执行 SQL

**GIVEN** 聊天消息中包含 SQL 代码 `SELECT * FROM users LIMIT 5`
**WHEN** 用户选择语言为 SQL 并点击"运行"
**THEN** 请求发送到 YiAi 服务端沙箱
**AND** 返回查询结果表格
**AND** 执行时间 < 2s
**WHEN** YiAi 服务不可用

**GIVEN** 代码包含 TypeScript 语法 `const add = (a: number, b: number): number => a + b; console.log(add(1, 2));`
**WHEN** 用户选择语言为 TypeScript 并点击"运行"
**THEN** TypeScript 代码被编译为 JavaScript
**AND** 编译后的代码在沙箱中执行
**AND** stdout 显示 "3"
**AND** 编译错误时 stderr 显示具体错误信息

### 场景 6：代码片段分享与加载

**GIVEN** 用户执行了一段代码并获得结果

## 九、设计决策记录

### D-01：沙箱隔离方案选择

- **问题**：如何在浏览器中安全执行用户代码
- **选项**：eval（不安全）、Web Worker（无 DOM）、iframe sandbox（完全隔离）、WebContainer（Node.js）
- **选择**：iframe sandbox 为主，Web Worker 辅助
- **理由**：iframe sandbox 属性提供浏览器原生隔离机制，禁止脚本访问父页面、禁止网络请求、禁止表单提交。Web Worker 用于无需 DOM 的纯计算场景，延迟更低。

### D-02：Python 执行策略

- **问题**：Python 代码在浏览器端还是服务端执行
- **选项**：全部浏览器端（Pyodide）、全部服务端、智能路由
- **选择**：智能路由（标准库 → Pyodide，第三方库 → 服务端）
- **理由**：Pyodide 支持大部分标准库和 numpy/pandas 等数据科学包，浏览器端执行延迟低且离线可用。服务端覆盖需要 requests/selenium 等浏览器无法提供的库。

### D-03：编辑器选择

- **问题**：聊天中的代码编辑器方案
- **选项**：contenteditable 增强、CodeMirror 6、Monaco Editor
- **选择**：CodeMirror 6
- **理由**：CodeMirror 6 体积约 150KB（gzipped），支持 40+ 语言语法高亮、自动补全、主题定制，模块化按需加载。Monaco 体积超标（~2MB），contenteditable 功能不足。

### D-04：执行结果持久化

- **问题**：执行结果是否需要持久化存储
- **选项**：不持久化（仅内存）、持久化到 chrome.storage.local、持久化到 YiAi 后端
- **选择**：chrome.storage.local 为主，分享时存储到 YiAi
- **理由**：执行结果与会话关联，会话数据已在 chrome.storage.local 中，统一存储简化管理。分享时存储到 YiAi 后端生成分享链接。

## 回归问题预测

| # | 预测问题 | 原因 | 验证方法 |
|---|---------|------|---------|
| 1 | iframe sandbox 在某些 CSP 严格的页面（如 GitHub）上无法创建，导致所有 JS 代码执行失败 | CSP 的 `frame-src` 指令限制 iframe 来源，`srcdoc` 的 iframe 在某些 CSP 配置下也会被阻止 | 在 GitHub、Google Docs、Twitter 等 CSP 严格页面测试，验证降级到 Web Worker 执行的逻辑正常 |
| 2 | Pyodide WASM 首次加载 10MB 文件时，用户网络较慢导致加载超时，Python 执行一直处于 loading 状态 | Pyodide 的 `pyodide.js` 和 `pyodide.asm.wasm` 需要从 CDN 加载，弱网环境下载时间可能超过 30s | 在 Chrome DevTools 中限制网速为 Slow 3G，验证加载超时后自动降级到服务端执行的逻辑 |
| 3 | 执行结果中 returnValue 包含循环引用对象时，JSON.stringify 抛出异常，整个执行结果面板崩溃 | 用户在沙箱中创建了循环引用对象（如 `a = {}; a.self = a`），JSON.stringify 默认不支持循环引用 | 使用自定义序列化函数替换 JSON.stringify，检测循环引用后截断为 `[Circular]` 标记 |
| 4 | 代码编辑器在 Shadow DOM 内运行，CodeMirror 的 CSS 样式被 Shadow DOM 隔离，导致编辑器无样式 | CodeMirror 使用全局 CSS 注入，Shadow DOM 的样式隔离阻止了外部样式渗透 | 在 Shadow DOM 内创建 CodeMirror 实例，使用 `parent` 选项指定 ShadowRoot 作为挂载点，确保样式正确注入 |
| 5 | 服务端沙箱执行 SQL 时，用户输入了 DROP TABLE 或 DELETE 语句，导致 YiAi 后端数据库被破坏 | 沙箱 SQL 执行使用了真实数据库连接而非隔离的临时数据库 | 服务端沙箱使用 Docker 容器隔离，每次执行创建临时数据库，执行后销毁容器 |
| 6 | 执行历史中存储了大量代码和结果，chrome.storage.local 的 10MB 写满后，新的执行结果无法保存 | 每条执行记录约 10KB，1000 条即占满 10MB，且用户可能绑定多个会话 | 执行历史限制为最近 500 条，超出后移除最旧记录；单条结果截断为 5000 字符 |
