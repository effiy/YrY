# YP-09-130: 自定义搜索引擎 — OpenSearch 集成、AI 元搜索、搜索快捷指令、结果增强、搜索历史、默认引擎覆盖、隐私搜索、关键词提取

> 需求编号：YP-09-130 · 优先级：P2 · 人天：0.3d · 状态：需求已编写
> 依赖：YP-09-24（右键菜单集成）、YP-09-41（SW 跨域代理）、YP-09-97（键盘快捷键系统）、YP-09-123（AI 页面摘要）

## 背景

### 问题陈述

YiPet 当前作为浏览器扩展，未提供搜索引擎增强功能。用户在浏览器中搜索信息时，面临以下问题：

1. **搜索引擎锁定**：Chrome 默认仅支持少量搜索引擎（Google、Bing、DuckDuckGo 等），用户想添加自定义搜索源（如 GitHub 代码搜索、Stack Overflow、npm 包搜索）时，需要手动访问对应网站，操作繁琐
2. **搜索结果碎片化**：用户需要在不同搜索引擎间切换（先用 Google 搜索概念，再用 GitHub 搜索代码，再用 Stack Overflow 搜索解决方案），信息分散在多个标签页中
3. **搜索意图与引擎不匹配**：用户在开发者文档站想搜索 API 文档，但地址栏默认使用 Google，返回大量无关结果
4. **搜索无增强**：搜索结果仅为原始链接列表，缺少 AI 摘要、上下文关联、质量评分等增强信息
5. **搜索历史不可管理**：搜索历史分散在浏览器历史中，无法按搜索引擎、时间、主题检索和复用

**核心矛盾**：在 Chrome 扩展的权限限制下，构建一个搜索引擎增强系统，既要支持灵活的自定义搜索引擎集成（OpenSearch 标准），又要提供 AI 元搜索和结果增强能力，同时保证隐私（不将搜索内容发送到第三方）。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 无法添加自定义搜索引擎，频繁手动访问 | 高 | 开发者每天手动打开 GitHub 搜索代码 20+ 次，每次输入 `github.com/search?q=...` |
| 2 | 搜索结果碎片化，跨引擎切换低效 | 高 | 解决一个技术问题需要分别在 Google、Stack Overflow、GitHub 搜索，打开 10+ 标签页 |
| 3 | 特定网站上搜索体验差 | 中 | 在 Rust 文档站搜索 `Vec`，地址栏默认用 Google 搜索 "Vec"，返回一堆无关结果 |
| 4 | 搜索历史无法复用 | 中 | 用户 3 天前搜索过"Chrome extension CSP"，今天想复用但找不到历史记录 |
| 5 | 搜索结果无 AI 摘要，需逐个打开判断 | 中 | 用户搜索结果中有 20 个链接，需要逐个打开查看内容才能判断是否相关 |

### 挑战

| 挑战 | 说明 |
|------|------|
| 跨域搜索请求 | 从扩展向第三方搜索引擎发请求涉及跨域，需通过 Service Worker 代理 |
| OpenSearch 描述文件解析 | 不同网站的 OpenSearch 描述文件格式不完全一致，需兼容解析 |
| AI 元搜索结果合并 | 多个搜索引擎返回的结果格式不同，需要统一的排名和去重算法 |
| 搜索引擎覆盖检测 | 检测用户当前页面是否匹配某个自定义搜索引擎，需要高效的 URL 模式匹配 |
| 隐私搜索模式 | 隐私搜索引擎（如 DuckDuckGo）的 API 可能与普通搜索引擎不同 |
| 快捷指令冲突 | 搜索快捷指令（如 `!gh`）需要与现有键盘快捷键系统协调，避免冲突 |

## 二、设计决策

### 决策 1：搜索引擎配置方式 — 手动配置 URL 模板 vs OpenSearch 自动发现 vs 社区预设库

| 选项 | 灵活性 | 易用性 | 覆盖范围 | 实现复杂度 |
|------|--------|--------|----------|------------|
| 手动配置 URL 模板 | 高 | 低（需懂 URL 参数） | 高（任何网站） | 低 |
| OpenSearch 自动发现 | 中 | 高（自动检测） | 中（仅支持 OpenSearch 的网站） | 中 |
| 社区预设库（内置 50+ 引擎） | 低 | 高（即开即用） | 中（库内引擎） | 低 |

**选择：预设库 + OpenSearch 自动发现 + 手动配置，三者结合。** 内置 50+ 常用搜索引擎（GitHub、Stack Overflow、npm、MDN、Rust Docs、arXiv 等），用户开箱即用。访问支持 OpenSearch 的网站时自动检测并提供"添加为搜索引擎"选项。高级用户可手动配置 URL 模板（使用 `{searchTerms}` 占位符）。三种方式满足不同用户需求。

### 决策 2：AI 元搜索策略 — 客户端合并 vs 后端合并 vs 逐引擎展示

| 选项 | 延迟 | 结果质量 | 实现复杂度 | 服务器依赖 |
|------|------|----------|------------|------------|
| 客户端合并（本地排序） | 低（并行请求） | 中（简单去重排名） | 中 | 无 |
| 后端合并（YiAi 排序） | 高（需等待 AI） | 高（AI 理解排名） | 高 | 是 |
| 逐引擎展示（标签页切换） | 低 | 低（用户自行判断） | 低 | 无 |

**选择：客户端合并为主，可选 AI 增强排序。** 默认使用客户端合并：并行请求所有搜索引擎，对结果进行 URL 去重、标题相似度去重，按来源引擎权重和位置加权排名。用户可手动触发"AI 增强排序"（发送前 20 条结果给 YiAi，由 AI 根据用户搜索意图重新排序和摘要）。逐引擎展示作为备选（用户可通过标签页切换查看各引擎独立结果）。

### 决策 3：搜索快捷指令触发方式 — 地址栏关键字 vs 扩展面板输入 vs 全局快捷键

| 选项 | 便捷性 | 冲突风险 | 实现复杂度 |
|------|--------|----------|------------|
| 地址栏关键字（omnibox API） | 高（直接在地址栏输入） | 中（可能与 URL 冲突） | 中 |
| 扩展面板输入（Popup 搜索框） | 中 | 低 | 低 |
| 全局快捷键（键盘触发后输入） | 中 | 高（与系统快捷键冲突） | 中 |

**选择：omnibox API（地址栏关键字）为主，扩展搜索框为补充。** 用户在地址栏输入 `yp` + 空格激活 YiPet 搜索模式，然后输入 `!gh vue reactivity` 即可在 GitHub 搜索。omnibox API 提供 `onInputChanged` 和 `onInputEntered` 事件，支持实时建议和搜索执行。Popup 搜索框提供可视化搜索引擎选择器，方便不熟悉快捷指令的用户。

### 决策 4：隐私搜索模式实现 — 仅引擎选择 vs 流量代理 vs 数据隔离

| 选项 | 隐私程度 | 性能 | 实现复杂度 |
|------|----------|------|------------|
| 仅引擎选择（使用 DuckDuckGo 等） | 中 | 高 | 低 |
| 流量代理（通过 Tor 代理） | 高 | 低 | 高 |
| 数据隔离（本地不记录隐私搜索） | 中 | 高 | 低 |

**选择：隐私引擎 + 数据隔离。** 选择隐私友好的搜索引擎（DuckDuckGo、Startpage、SearX），隐私模式下的搜索不保存到搜索历史，不发送到 YiAi 后端。提供"隐私搜索"标签页，所有搜索请求通过隐私搜索引擎代理。不实现 Tor 代理（复杂度过高且用户群体小）。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 引擎配置方式 | 手动配置 | OpenSearch | 预设库 | **三者结合** | 覆盖不同用户需求 |
| AI 元搜索策略 | 客户端合并 | 后端合并 | 逐引擎展示 | **客户端合并 + 可选 AI 增强** | 默认快速，可选深度 |
| 快捷指令触发 | 地址栏 | 扩展面板 | 快捷键 | **omnibox API 为主** | 符合用户搜索习惯 |
| 隐私搜索模式 | 仅引擎选择 | Tor 代理 | 数据隔离 | **隐私引擎 + 数据隔离** | 实用的隐私保护 |

  constructor() {
    this.builtinEngines = this.getBuiltinEngines();
  }

  /**
   * 初始化引擎注册表
   */
  async init(): Promise<void> {
    const stored = await chrome.storage.local.get(this.storageKey);
    if (!stored[this.storageKey]) {
      // 首次安装，写入内置引擎
      await this.saveAll(this.builtinEngines);
    } else {
      // 合并内置引擎（新增的预设引擎）
      await this.mergeBuiltinEngines(stored[this.storageKey]);
    }
  }

  /**
   * 获取所有引擎
   */
  async getAll(): Promise<SearchEngine[]> {
    const stored = await chrome.storage.local.get(this.storageKey);
    return stored[this.storageKey] || this.builtinEngines;
  }

  /**
   * 获取已启用的引擎
   */
  async getEnabled(): Promise<SearchEngine[]> {
    const all = await this.getAll();
    return all.filter(e => e.isEnabled);

   */

    return all.find(e => e.shortcut === shortcut && e.isEnabled);
  }

   * 添加自定义引擎
   */
  async addEngine(engine: Omit<SearchEngine, 'id' | 'isBuiltin' | 'createdAt' | 'updatedAt'>): Promise<SearchEngine> {
    const all = await this.getAll();

    // 检查快捷指令冲突
    if (engine.shortcut) {
      const existing = all.find(e => e.shortcut === engine.shortcut);
      if (existing) {
        throw new Error(`快捷指令 "${engine.shortcut}" 已被 "${existing.name}" 使用`);
      }

    const newEngine: SearchEngine = {
      ...engine,
      id: crypto.randomUUID(),
      isBuiltin: false,
      createdAt: Date.now(),
      updatedAt: Date.now(),
    };

    all.push(newEngine);
    await this.saveAll(all);
    return newEngine;

   * 更新引擎配置
   */
  async updateEngine(id: string, updates: Partial<SearchEngine>): Promise<void> {
    const all = await this.getAll();
    const index = all.findIndex(e => e.id === id);
    if (index === -1) throw new Error('引擎不存在');

    all[index] = { ...all[index], ...updates, updatedAt: Date.now() };
    await this.saveAll(all);
  }

  /**
   * 删除自定义引擎
   */
  async removeEngine(id: string): Promise<void> {
    const all = await this.getAll();
    const engine = all.find(e => e.id === id);
    if (!engine) throw new Error('引擎不存在');
    if (engine.isBuiltin) throw new Error('不能删除内置引擎');

    const filtered = all.filter(e => e.id !== id);
    await this.saveAll(filtered);
  }

  /**
   * 启用/禁用引擎
   */
  async setEnabled(id: string, enabled: boolean): Promise<void> {
    await this.updateEngine(id, { isEnabled: enabled });
  }

  /**
   * 从 OpenSearch 描述文件注册引擎
   */
  async registerFromOpenSearch(
    description: OpenSearchDescription,
    pageUrl: string
  ): Promise<SearchEngine> {
    // 从页面 URL 提取域名作为引擎域名
    const domain = new URL(pageUrl).hostname;

    // 生成快捷指令
    const shortcut = this.generateShortcut(description.shortName);

    return this.addEngine({
      name: description.shortName,
      shortcut,
      category: 'other',
      icon: description.icon || `https://www.google.com/s2/favicons?domain=${domain}&sz=32`,
      searchUrl: description.url,
      suggestUrl: description.suggestUrl,
      encoding: description.encoding as 'utf-8' | 'iso-8859-1',
      method: description.method,
      postParams: description.postParams,
      weight: 0.5,
      isEnabled: true,

      siteOverride: [domain],
    });
  }

  /**
   * 导出引擎配置
   */
  async exportEngines(): Promise<string> {
    const all = await this.getAll();
    const customOnly = all.filter(e => !e.isBuiltin);
    return JSON.stringify(customOnly, null, 2);
  }

  /**

   */
  async importEngines(json: string): Promise<number> {
    const engines: SearchEngine[] = JSON.parse(json);
    let imported = 0;

    for (const engine of engines) {
      try {
        await this.addEngine({

          searchUrl: engine.searchUrl,

      } catch {

// src/background/MetaSearchEngine.ts (新增)

class MetaSearchEngine {
  private registry: SearchEngineRegistry;

  constructor(registry: SearchEngineRegistry) {
    this.registry = registry;
  }

  /**
   * 执行元搜索
   */
  async search(request: MetaSearchRequest): Promise<{
    results: SearchResult[];
    totalResults: number;
    enginesUsed: number;
    duration: number;
  }> {
    const startTime = Date.now();

    // 获取要使用的引擎
    let engines = request.engineIds
      ? (await this.registry.getAll()).filter(e => request.engineIds!.includes(e.id))
      : await this.registry.getEnabled();

    // 隐私模式下仅使用隐私引擎
    if (request.privacyMode) {
      engines = engines.filter(e => e.isPrivacy);
    }

    // 限制最大引擎数
    const maxEngines = 5;
    engines = engines.slice(0, maxEngines);

    const maxResults = request.maxResults || 10;

    // 并行请求所有引擎
    const searchPromises = engines.map(engine =>
      this.searchEngine(engine, request.query, maxResults)
        .catch(err => {
          console.error(`[YiPet] 搜索引擎 ${engine.name} 请求失败:`, err);
          return [];
        })
    );

    const allResults = await Promise.all(searchPromises);

    // 合并结果
    let mergedResults: SearchResult[] = [];
    if (request.mergeResults !== false) {
      mergedResults = this.mergeAndRank(allResults.flat(), engines);
    } else {
      mergedResults = allResults.flat();
    }

    // AI 增强排序
    if (request.aiEnhance && mergedResults.length > 0) {
      mergedResults = await this.aiEnhanceResults(
        request.query,
        mergedResults.slice(0, 20)
      );
    }

    return {
      results: mergedResults,
      totalResults: mergedResults.length,
      enginesUsed: engines.length,
      duration: Date.now() - startTime,
    };
  }

  /**
   * 单个搜索引擎搜索
   */
  private async searchEngine(
    engine: SearchEngine,
    query: string,
    maxResults: number
  ): Promise<SearchResult[]> {
    const url = engine.searchUrl.replace(
      '{searchTerms}',
      encodeURIComponent(query)
    );

    const fetchOptions: RequestInit = {
      method: engine.method,
      headers: {
        'Accept': 'text/html,application/json',
        'User-Agent': navigator.userAgent,
      },
    };

    if (engine.method === 'POST' && engine.postParams) {
      const body = new URLSearchParams();
      for (const [key, value] of Object.entries(engine.postParams)) {
        body.set(key, value.replace('{searchTerms}', query));
      }
      fetchOptions.body = body.toString();
    }

    const response = await fetch(url, fetchOptions);
    const html = await response.text();

    // 从 HTML 中提取搜索结果
    return this.extractResults(html, engine, maxResults);
  }

  /**
   * 从 HTML 中提取搜索结果
   */
  private extractResults(
    html: string,
    engine: SearchEngine,
    maxResults: number
  ): SearchResult[] {
    // 使用正则或 DOM 解析提取搜索结果
    // 不同引擎有不同的 HTML 结构，此处提供通用提取逻辑
    const results: SearchResult[] = [];

    // 提取页面标题（作为结果标题）
    const titleMatches = html.match(/<a[^>]*href="([^"]*)"[^>]*>([^<]*)<\/a>/gi);
    if (!titleMatches) return results;

    let position = 0;
    for (const match of titleMatches) {
      if (position >= maxResults) break;

      const hrefMatch = match.match(/href="([^"]*)"/i);
      const textMatch = match.match(/>([^<]*)</);

      if (hrefMatch && textMatch) {
        const url = hrefMatch[1];
        // 过滤掉非结果链接（导航、页脚等）
        if (url.startsWith('#') || url.startsWith('/') ||
            url.includes('javascript:') || url.includes('mailto:')) {
          continue;
        }

        results.push({
          id: this.hashUrl(url),
          title: textMatch[1].trim(),
          url: this.resolveUrl(url, engine.searchUrl),
          snippet: '',
          engineId: engine.id,
          engineName: engine.name,
          engineIcon: engine.icon,
          position,
          score: 0,
          relevance: 'medium',
        });

        position++;
      }
    }

    return results;
  }

  /**
   * 合并和排名搜索结果
   */
  private mergeAndRank(
    results: SearchResult[],
    engines: SearchEngine[]
  ): SearchResult[] {
    // URL 去重
    const seen = new Map<string, SearchResult>();
    for (const result of results) {
      const normalizedUrl = this.normalizeUrl(result.url);
      if (!seen.has(normalizedUrl)) {
        seen.set(normalizedUrl, result);
      } else {
        // 保留更高排名的结果
        const existing = seen.get(normalizedUrl)!;
        if (result.position < existing.position) {
          seen.set(normalizedUrl, result);
        }
      }
    }

    const unique = Array.from(seen.values());

    // 标题相似度去重
    const deduplicated = this.deduplicateByTitle(unique);

    // 计算得分
    const engineWeightMap = new Map(engines.map(e => [e.id, e.weight]));
    deduplicated.forEach(result => {
      const engineWeight = engineWeightMap.get(result.engineId) || 0.5;
      const positionWeight = 1 - result.position / 10;
      const keywordWeight = result.relevance === 'high' ? 1 : result.relevance === 'medium' ? 0.7 : 0.4;

      result.score = Math.round(
        (engineWeight * 0.3 + positionWeight * 0.4 + keywordWeight * 0.3) * 100
      );
    });

    // 按得分降序排列
    return deduplicated.sort((a, b) => b.score - a.score);
  }

  /**
   * AI 增强搜索结果
   */
  private async aiEnhanceResults(
    query: string,
    results: SearchResult[]
  ): Promise<SearchResult[]> {
    try {
      const resultList = results.map((r, i) =>
        `${i + 1}. [${r.engineName}] ${r.title}\n   ${r.url}\n   ${r.snippet}`
      ).join('\n\n');

      const prompt = `用户搜索了: "${query}"

以下是来自多个搜索引擎的搜索结果。请对结果进行重新排序，并给出以下 JSON 格式的增强结果:
[
  {
    "originalIndex": 0,
    "newRank": 1,
    "aiSummary": "该结果的简短摘要（50字以内）",
    "relevance": "high"
  },
  ...
]

搜索结果:
${resultList}

请直接返回 JSON 数组，不要包含其他内容。`;

      const response = await fetch('http://localhost:10086', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          module_name: 'services.ai.chat_service',
          method_name: 'chat',
          parameters: {
            messages: [{ role: 'user', content: prompt }],
            stream: false,
          },
        }),
      });

      const data = await response.json();
      const aiResult = JSON.parse(data.data?.content || '[]');

      // 应用 AI 增强
      for (const enhancement of aiResult) {
        if (results[enhancement.originalIndex]) {
          results[enhancement.originalIndex].aiSummary = enhancement.aiSummary;
          results[enhancement.originalIndex].relevance = enhancement.relevance;
          results[enhancement.originalIndex].score += 10; // AI 加分
        }
      }

      return results.sort((a, b) => b.score - a.score);
    } catch {
      console.error('[YiPet] AI 增强搜索结果失败');
      return results;
    }
  }

  // 工具方法
  private hashUrl(url: string): string {
    let hash = 0;
    for (let i = 0; i < url.length; i++) {
      hash = ((hash << 5) - hash) + url.charCodeAt(i);
      hash |= 0;
    }
    return `sr-${Math.abs(hash)}`;
  }

  private normalizeUrl(url: string): string {
    try {
      const parsed = new URL(url);
      parsed.search = '';
      parsed.hash = '';
      parsed.pathname = parsed.pathname.replace(/\/$/, '');
      return parsed.toString().toLowerCase();
    } catch {
      return url.toLowerCase();
    }
  }

  private resolveUrl(url: string, baseUrl: string): string {
    try {
      return new URL(url, baseUrl).toString();
    } catch {
      return url;
    }
  }

  private deduplicateByTitle(results: SearchResult[]): SearchResult[] {
    const deduped: SearchResult[] = [];
    for (const result of results) {
      const isDuplicate = deduped.some(existing =>
        this.titleSimilarity(existing.title, result.title) > 0.8
      );
      if (!isDuplicate) {
        deduped.push(result);
      }
    }
    return deduped;
  }

  private titleSimilarity(a: string, b: string): number {
    const longer = a.length > b.length ? a : b;
    const shorter = a.length > b.length ? b : a;
    if (longer.length === 0) return 1.0;

    const distance = this.levenshteinDistance(longer, shorter);
    return (longer.length - distance) / longer.length;
  }

  private levenshteinDistance(a: string, b: string): number {
    const matrix: number[][] = [];
    for (let i = 0; i <= a.length; i++) {
      matrix[i] = [i];
    }
    for (let j = 0; j <= b.length; j++) {
      matrix[0][j] = j;
    }
    for (let i = 1; i <= a.length; i++) {
      for (let j = 1; j <= b.length; j++) {
        matrix[i][j] = Math.min(
          matrix[i - 1][j] + 1,
          matrix[i][j - 1] + 1,
          matrix[i - 1][j - 1] + (a[i - 1] === b[j - 1] ? 0 : 1)
        );
      }
    }
    return matrix[a.length][b.length];
  }
}

class SearchShortcutManager {
  private registry: SearchEngineRegistry;

  constructor(registry: SearchEngineRegistry) {
    this.registry = registry;
  }

  /**
   * 解析搜索输入中的快捷指令
   * 例如: "!gh vue reactivity" → { engineId: "builtin-github", query: "vue reactivity" }
   */
  async parseShortcut(input: string): Promise<{
    engineId: string;
    engineName: string;
    query: string;
  } | null> {
    const trimmed = input.trim();
    const match = trimmed.match(/^!(\w+)\s+(.+)/);
    if (!match) return null;

    const shortcut = '!' + match[1];
    const query = match[2];

    const engine = await this.registry.findByShortcut(shortcut);
    if (!engine) return null;

    return {
      engineId: engine.id,
      engineName: engine.name,
      query,
    };
  }

  /**
   * 获取所有可用快捷指令
   */
  async getAvailableShortcuts(): Promise<SearchShortcut[]> {
    const engines = await this.registry.getEnabled();
    return engines.map(e => ({
      shortcut: e.shortcut,
      engineId: e.id,
      description: `在 ${e.name} 中搜索`,
      usageCount: 0,
    }));
  }

  /**
   * 注册 omnibox 关键字
   */
  async setupOmnibox(): Promise<void> {
    // omnibox 关键字为 "yp"
    chrome.omnibox.onInputChanged.addListener(async (text, suggest) => {
      const parsed = await this.parseShortcut(text);
      if (parsed) {
        suggest([
          {
            content: text,
            description: `在 ${parsed.engineName} 中搜索: "${parsed.query}"`,
          },
        ]);
      } else {
        // 显示所有可用快捷指令
        const shortcuts = await this.getAvailableShortcuts();
        suggest(
          shortcuts
            .filter(s => s.shortcut.includes(text) || s.description.includes(text))
            .slice(0, 5)
            .map(s => ({
              content: `${s.shortcut} `,
              description: `${s.shortcut} — ${s.description}`,
            }))
        );
      }
    });

    chrome.omnibox.onInputEntered.addListener(async (text) => {
      const parsed = await this.parseShortcut(text);
      if (parsed) {
        // 执行搜索
        const metaSearch = new MetaSearchEngine(this.registry);
        const result = await metaSearch.search({
          query: parsed.query,
          engineIds: [parsed.engineId],
        });

        // 打开搜索结果页面
        if (result.results.length > 0) {
          chrome.tabs.create({ url: result.results[0].url });
        }
      } else {
        // 默认搜索
        chrome.tabs.create({
          url: `https://www.google.com/search?q=${encodeURIComponent(text)}`,
        });
      }
    });
  }

## 九、设计决策记录

### D-01：预设引擎数量

- **问题**：内置预设引擎应该包含多少，覆盖哪些类别
- **选项**：10 个常用引擎、50 个全面引擎、100 个引擎
- **选择**：50+ 个引擎，覆盖 8 个类别
- **理由**：50 个引擎覆盖主流搜索需求（代码、文档、问答、学术、图片、视频、购物、隐私），用户开箱即用。100 个引擎过多，维护成本高且用户选择困难。10 个引擎不足以覆盖多样化需求。

### D-02：元搜索结果合并策略

- **问题**：多个搜索引擎返回的结果如何合并和排名
- **选项**：简单去重、加权排名、AI 排序
- **选择**：默认加权排名（客户端），可选 AI 排序
- **理由**：加权排名（引擎权重 + 位置权重 + 关键词匹配）在客户端即时完成，延迟低。AI 排序作为可选增强，在用户需要更精准的结果时手动触发。避免每次搜索都调用 AI 导致延迟和服务器成本。

### D-03：omnibox 关键字选择

- **问题**：omnibox 关键字应该用什么，如何处理冲突
- **选项**：固定关键字 `yp`、固定关键字 `search`、用户可配置
- **选择**：默认 `yp`，用户可配置
- **理由**：`yp` 是 YiPet 的缩写，简短且不易与其他扩展冲突。`search` 过于通用，容易冲突。用户可配置允许在冲突时修改为其他关键字。

### D-04：隐私搜索的数据处理

- **问题**：隐私搜索模式下，哪些数据需要特殊处理
- **选项**：仅不记录历史、不记录历史 + 不发送 YiAi、全部隔离
- **选择**：不记录历史 + 不发送 YiAi + 仅使用隐私引擎
- **理由**：隐私搜索的核心诉求是"搜索行为不被追踪"。因此搜索关键词不写入历史记录，搜索请求不发送到 YiAi 后端（即使 AI 增强功能可用），仅使用隐私友好的搜索引擎（DuckDuckGo 等）。这是最彻底的隐私保护方案。

## 回归问题预测

| # | 预测问题 | 原因 | 验证方法 |
|---|---------|------|---------|
| 1 | 用户使用 `!gh` 搜索代码时，GitHub 返回登录页面而非搜索结果，因为 GitHub 对未登录用户的搜索请求有频率限制 | 搜索引擎（如 GitHub）对未认证请求的 API 有限制，高频搜索可能触发验证码或登录墙 | 在搜索结果提取中检测登录页面/验证码页面特征（如标题包含"Sign in"），检测到时提示用户"该引擎需要登录，请先在浏览器中登录 GitHub"，并提供"打开登录页面"按钮 |
| 2 | 元搜索合并时，来自不同引擎的同一文档被错误去重（如 GitHub 和 GitLab 上同一项目的 README 被合并为一个结果） | 标题相似度去重过于激进，不同来源的相似标题被误判为重复 | 标题相似度去重仅在同一域名内执行，不同引擎/不同域名的结果即使标题相似也保留。增加"相同域名最多保留 3 个结果"的限制 |
| 3 | omnibox 建议在用户输入时频繁触发，导致 Service Worker 被频繁唤醒，影响浏览器性能 | `onInputChanged` 在每次按键时触发，如果用户输入 10 个字符，会触发 10 次 SW 唤醒和引擎查询 | 在 `onInputChanged` 处理中使用防抖（300ms），仅在用户输入暂停 300ms 后才发送建议请求。同时缓存快捷指令列表，避免每次都读取 storage |
| 4 | 用户添加了大量自定义搜索引擎（50+），元搜索时并行请求过多导致浏览器网络连接池耗尽 | Chrome 对同一扩展的并发请求数有限制（约 6 个），超过限制的请求排队等待，元搜索延迟大幅增加 | 限制元搜索最多使用 5 个引擎，用户可在设置中调整。超过限制的引擎按权重排序，仅使用权重最高的 5 个。提供"按类别搜索"选项（仅搜索代码引擎或仅搜索文档引擎） |
| 5 | 搜索结果提取的 HTML 解析逻辑对某些搜索引擎失效（如 Google 的搜索结果页面使用大量 JavaScript 渲染），提取到的链接是空的 | Google 等搜索引擎使用客户端渲染（CSR），`fetch` 获取的 HTML 中不包含搜索结果（结果由 JavaScript 动态生成） | 对于已知使用 CSR 的搜索引擎，改为使用其公开 API（如 Google Custom Search JSON API）或直接打开搜索结果页面（降级方案）。在元搜索设置中标记哪些引擎支持 HTML 提取，哪些需要降级为页面跳转 |
| 6 | 隐私搜索模式下，用户使用 DuckDuckGo 的 `!bangs` 功能（如 `!w` 搜索 Wikipedia），快捷指令解析器将其误识别为 YiPet 的 `!w` 指令 | DuckDuckGo 的 `!bangs` 语法与 YiPet 的快捷指令语法冲突（都使用 `!` 前缀），解析器无法区分用户意图 | 在隐私搜索模式下，禁用 YiPet 快捷指令解析，将整个搜索查询原样传递给隐私搜索引擎。仅在非隐私模式下解析 YiPet 快捷指令 |
