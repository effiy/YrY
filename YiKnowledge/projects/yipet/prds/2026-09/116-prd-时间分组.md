# PE-09-116: 侧边栏时间段分组

> 会话组织：侧边栏按时间分组（Today · This Week · Older），每个分组显示会话数量。

## 范围

- `groupedSessions` computed：按 updatedAt/createdAt 分组
- Today: 今天 00:00 起
- This Week: 7 天内
- Older: 7 天前

## 效果

```
Today · 3
  📄 CR YiVad bug fix    2h ago
  📄 AI Chat session     5h ago
  
This Week · 5
  📄 TL Architecture      2d ago
  
Older · 4
  📄 Old discussion       2w ago stale
```
