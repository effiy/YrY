# PE-09-102: 提示词模板系统

> 跨项目功能对齐：YiVad AI Chat 有 TemplatePicker（8 内置模板 + 4 分类 + 变量填充 + 预览），YiPet 仅有 ArrowUp 历史回忆，缺少结构化提示词模板。

## 背景

YiVad `views/ai-chat/components/TemplatePicker.vue` 提供 8 个内置模板：
- **Code**: Code Review, Bug Analysis
- **Documents**: Write PRD, API Documentation
- **Q&A**: Knowledge Q&A, Explain Concept
- **Analysis**: Data Analysis, Summarize Content

每个模板支持 `{{variable}}` 占位符，用户填写变量后预览并应用到输入框。YiPet 当前只有 `ArrowUp` 提示词历史回忆，无结构化模板支持。

## 范围

**In scope**：
- `TemplatePicker.vue` 组件（8 模板 + 4 分类 Tab + 搜索 + 变量表单 + 预览）
- 集成到 `ChatToolbar.vue` 左侧（PromptHistory 旁边）
- 使用 `--yp-*` CSS 变量适配 YiPet 主题

**Out of scope**：
- 用户自定义模板（后续迭代）
- 模板持久化（后续迭代）

| 优先级 | 故事 | 验收标准 |
|--------|------|----------|
| P1 | 模板列表 | 显示 8 个模板，按分类筛选，支持搜索 |
| P1 | 变量填充 | 选择模板后显示变量表单，实时预览 |
| P1 | 应用到输入 | 点击 Apply 后填充到聊天输入框 |

## 验收标准

- [ ] 工具栏显示模板按钮（Collection 图标）
- [ ] 点击弹出模板面板，4 个分类 Tab（Code/Docs/Q&A/Analysis）
- [ ] 选择模板进入变量表单，填写后预览显示替换结果
- [ ] Apply 将渲染文本写入 `state.inputTemplate`
- [ ] 样式使用 `--yp-*` 变量，与 YiPet 主题一致
