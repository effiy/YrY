# YP-09-125: 下载管理与文件整理 — chrome.downloads 集成、AI 分类重命名、批量操作、进度通知、自动清理、去重检测、类型子目录

> 需求编号：YP-09-125 · 优先级：P2 · 人天：0.3d · 状态：需求已编写
> 依赖：YP-09-95（消息通知系统）、YP-09-79（IndexedDB 持久化）

## 背景

### 问题陈述

YiPet 用户在日常浏览中频繁下载文件（文档、图片、代码、压缩包等），但 Chrome 默认的下载管理功能简陋，文件堆积在默认下载目录中，缺乏分类、重命名和自动清理能力。用户经常遇到下载文件夹混乱、找不到文件、重复下载同一文件等问题。这导致：

1. **下载文件夹混乱**：所有文件堆在同一个目录，无分类，文件命名不规范（如 `download (1).pdf`、`image_20240315.png`）
2. **文件查找困难**：Chrome 默认下载栏仅显示最近几个下载，历史下载需要打开 `chrome://downloads` 页面，搜索功能有限
3. **重复下载浪费**：用户不知道文件已下载过，重复下载同一文件，浪费磁盘空间和带宽
4. **存储空间失控**：长期累积的下载文件占用大量磁盘空间，缺乏自动清理机制
5. **下载失败无感知**：下载失败后用户可能未注意到，无法及时重试

**核心矛盾**：在 Chrome 扩展的权限范围内，如何提供超越浏览器默认能力的下载管理体验，包括 AI 文件分类、智能重命名、去重检测和自动清理，同时不侵入用户的文件系统隐私。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 下载文件夹混乱，难以找到文件 | 高 | 用户下载了 50 个文件，下载文件夹中文件名无规律，找不到目标文件 |
| 2 | 重复下载同一文件 | 中 | 用户从不同页面重复下载同一 PDF 白皮书，产生了 3 份副本 |
| 3 | 下载失败未及时发现和重试 | 中 | 网络中断导致下载失败，用户未注意，需要重新下载 |
| 4 | 磁盘空间被废弃下载文件占满 | 中 | 3 个月前的临时文件、安装包等仍占用空间 |
| 5 | 文件命名不规范，无法识别内容 | 中 | `paper.pdf` vs `2024-React-Concurrent-Mode-Deep-Dive.pdf` |

### 挑战

| 挑战 | 说明 |
|------|------|
| chrome.downloads API 权限 | 需要 `downloads` 权限，且部分操作（如打开文件、显示文件夹）需要用户交互触发 |
| 文件系统访问限制 | Chrome 扩展无法直接访问本地文件系统，只能通过 `chrome.downloads` API 间接管理下载 |
| 文件分类准确性 | AI 分类依赖文件名和 URL 信息，可能无法准确判断文件类型和内容 |
| 去重检测 | 判断两个文件是否重复，仅依赖文件名和文件大小不够准确，但无法读取文件内容 |
| 下载通知权限 | 需要 `notifications` 权限来显示下载完成通知，但需要用户授权 |


## 二、设计决策

### 决策 1：下载管理界面位置 — Popup 面板 vs 独立页面 vs 聊天窗口集成

| 选项 | 可见性 | 功能丰富度 | 实现复杂度 | 用户习惯 |
|------|--------|-----------|-----------|----------|
| Popup 面板 | 中（需点击扩展图标） | 中 | 低 | 高 |
| 独立页面（chrome-extension://） | 高（大空间） | 高 | 中 | 中 |
| 聊天窗口集成 | 高（聊天中管理） | 中 | 中 | 中 |

**选择：Popup 面板为主 + 聊天窗口集成。** Popup 面板提供快速查看最近下载和基本操作（打开、重试、删除），利用现有的 Popup 空间。聊天窗口集成提供下载管理对话（如"整理下载文件夹"、"清理 30 天前的下载"），通过自然语言交互管理下载。不创建独立页面，避免增加扩展复杂度。

### 决策 2：AI 文件分类方案 — 远程 AI vs 本地规则 vs 混合

| 选项 | 准确性 | 隐私 | 速度 | 实现复杂度 |
|------|--------|------|------|-----------|
| 远程 AI（YiAi 后端） | 高 | 需上传文件名 | 中 | 低 |
| 本地规则（扩展名 + 关键词） | 中 | 完全本地 | 快 | 低 |
| 混合（本地规则 + 远程 AI 可选） | 高 | 隐私可控 | 快 | 中 |

**选择：混合方案（本地规则优先 + 远程 AI 可选）。** 基于文件扩展名的本地规则覆盖 80% 的常见文件类型（PDF 归类为"文档"，ZIP 归类为"压缩包"，JPG/PNG 归类为"图片"）。对于无法判断的文件（如无扩展名、模糊命名），提供 AI 分类建议（需用户授权）。AI 重命名建议始终可选，用户可预览后确认。

### 决策 3：去重检测方案 — 文件名 vs 文件大小 vs URL 哈希

| 选项 | 准确性 | 误判率 | 实现复杂度 |
|------|--------|--------|-----------|
| 文件名匹配 | 低 | 高（同名不同文件） | 低 |
| 文件名 + 文件大小 | 中 | 中 | 低 |
| URL + 文件名 + 文件大小 | 中高 | 低 | 中 |
| 文件内容哈希 | 高 | 极低 | 高（需读取文件） |

**选择：URL + 文件名 + 文件大小组合判断。** 通过 `chrome.downloads` API 获取下载项的 `url`、`filename` 和 `fileSize` 进行组合判断。如果 URL 相同且文件大小相同，视为重复下载。如果文件名相同但 URL 不同，提示用户可能存在同名文件，询问是否覆盖或重命名。文件内容哈希作为未来增强，但需要读取文件内容，实现复杂度高。

### 决策 4：自动清理策略 — 固定天数 vs 文件类型 vs 混合

| 选项 | 灵活性 | 安全性 | 实现复杂度 |
|------|--------|--------|-----------|
| 固定天数（如 30 天） | 低 | 中（可能误删） | 低 |
| 文件类型 + 天数 | 中 | 高 | 中 |
| 混合（类型 + 天数 + 大小 + 来源） | 高 | 高 | 中 |

**选择：混合规则（文件类型 + 天数 + 来源域名）。** 用户可配置多条清理规则，如"删除 30 天前下载的 .zip 和 .dmg 文件"、"删除 7 天前从 github.com 下载的临时文件"。清理前显示预览列表，用户确认后执行。关键规则：默认不启用自动清理，需要用户手动配置。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 管理界面 | Popup 面板 | 独立页面 | 聊天集成 | **Popup + 聊天** | 不增加复杂度 |
| AI 分类 | 远程 AI | 本地规则 | 混合 | **混合** | 默认本地，AI 可选 |
| 去重检测 | 文件名 | 文件大小 | URL+大小+文件名 | **URL+大小+文件名** | 平衡准确和实现 |
| 自动清理 | 固定天数 | 类型+天数 | 混合规则 | **混合规则** | 灵活可配 |

## 四、具体改动

### 4.1 下载管理数据类型

```typescript
// src/types/downloads.ts (新增)

type DownloadStatus = 'in_progress' | 'complete' | 'failed' | 'paused' | 'interrupted';

type FileCategory = 'document' | 'image' | 'video' | 'audio' | 'archive' | 'code' | 'executable' | 'other';

interface DownloadItem {
  id: number;                   // chrome.downloads.DownloadItem.id
  url: string;                  // 下载来源 URL
  referrer: string;             // 引用页面 URL
  filename: string;             // 文件名
  fileSize: number;             // 文件大小（字节）
  totalBytes: number;           // 总大小（下载中时已知）
  receivedBytes: number;        // 已接收字节数
  status: DownloadStatus;
  startTime: string;            // 开始时间 ISO 字符串
  endTime?: string;             // 完成时间 ISO 字符串
  mime: string;                 // MIME 类型
  domain: string;               // 来源域名
  category: FileCategory;       // 文件分类
  suggestedName?: string;       // AI 建议的文件名
  isDuplicate: boolean;         // 是否疑似重复
  duplicateOf?: number;         // 重复的下载项 ID
  subfolder?: string;           // 建议的子目录
  error?: string;               // 错误信息（失败时）
  canResume: boolean;           // 是否可断点续传
  danger: 'safe' | 'accepted' | 'blocked'; // 安全状态
}

interface DownloadFilter {
  status?: DownloadStatus | 'all';
  category?: FileCategory | 'all';
  query?: string;               // 文件名/URL 搜索
  dateFrom?: string;            // 起始日期
  dateTo?: string;              // 截止日期
  domain?: string;              // 来源域名
  sortBy: 'time' | 'size' | 'filename';
  sortOrder: 'asc' | 'desc';
  limit: number;                // 最大结果数，默认 50
  offset: number;               // 分页偏移
}

interface DownloadStats {
  total: number;
  inProgress: number;
  complete: number;
  failed: number;
  paused: number;
  totalSize: number;            // 总大小（字节）
  duplicates: number;           // 疑似重复文件数
}

interface RenameSuggestion {
  originalName: string;
  suggestedName: string;
  confidence: number;           // 0-1
  reason: string;               // 建议理由
}

interface CleanupRule {
  id: string;
  enabled: boolean;
  fileTypes: string[];          // 文件扩展名列表
  olderThanDays: number;        // 超过 N 天
  sourceDomain?: string;        // 来源域名过滤
  minSize?: number;             // 最小文件大小过滤（字节）
  action: 'delete' | 'move_to_trash';
}
```

```typescript
  private downloadCache: Map<number, DownloadItem> = new Map();
  private cleanupRules: CleanupRule[] = [];
  private readonly CATEGORY_RULES: Record<string, FileCategory> = {
    // 文档
    pdf: 'document', doc: 'document', docx: 'document',
    xls: 'document', xlsx: 'document', ppt: 'document', pptx: 'document',
    txt: 'document', md: 'document', csv: 'document',
    // 图片
    jpg: 'image', jpeg: 'image', png: 'image', gif: 'image',
    svg: 'image', webp: 'image', bmp: 'image', ico: 'image',
    // 视频
    mp4: 'video', avi: 'video', mov: 'video', webm: 'video',
    mkv: 'video', flv: 'video',
    // 音频
    mp3: 'audio', wav: 'audio', flac: 'audio', aac: 'audio',
    ogg: 'audio', wma: 'audio',
    // 压缩包
    zip: 'archive', rar: 'archive', '7z': 'archive',
    tar: 'archive', gz: 'archive', bz2: 'archive',
    // 代码
    js: 'code', ts: 'code', py: 'code', java: 'code',
    html: 'code', css: 'code', json: 'code', xml: 'code',
    // 可执行文件
    exe: 'executable', msi: 'executable', dmg: 'executable',
    app: 'executable', apk: 'executable', deb: 'executable',
  };

  /**
   * 初始化下载监听器
   */
  initialize(): void {
    // 监听下载创建
    chrome.downloads.onCreated.addListener(this.onDownloadCreated.bind(this));

    // 监听下载进度变化
    chrome.downloads.onChanged.addListener(this.onDownloadChanged.bind(this));

    // 监听下载删除（用户通过 chrome://downloads 删除时）
    chrome.downloads.onErased.addListener(this.onDownloadErased.bind(this));

    // 加载清理规则
    this.loadCleanupRules();

    // 定时执行清理任务（每天一次）
    setInterval(() => this.executeCleanupRules(), 24 * 60 * 60 * 1000);
  }

  /**
   * 获取下载列表
   */
  async getDownloads(filter: DownloadFilter): Promise<{
    items: DownloadItem[];
    stats: DownloadStats;
  }> {
    const chromeFilter: chrome.downloads.StateType | undefined =
      filter.status && filter.status !== 'all'
        ? filter.status as chrome.downloads.StateType
        : undefined;

    const items = await this.searchDownloads({
      query: filter.query ? [filter.query] : undefined,
      state: chromeFilter,
      limit: filter.limit,
      startedAfter: filter.dateFrom,
      startedBefore: filter.dateTo,
    });

    let downloads = items.map(this.normalizeDownloadItem);

    // 域名过滤
    if (filter.domain) {
      downloads = downloads.filter(d => d.domain.includes(filter.domain));
    }

    // 分类过滤
    if (filter.category && filter.category !== 'all') {
      downloads = downloads.filter(d => d.category === filter.category);
    }

    // 排序
    downloads.sort((a, b) => {
      const order = filter.sortOrder === 'asc' ? 1 : -1;
      switch (filter.sortBy) {
        case 'time':
          return (new Date(a.startTime).getTime() - new Date(b.startTime).getTime()) * order;
        case 'size':
          return (a.fileSize - b.fileSize) * order;
        case 'filename':
          return a.filename.localeCompare(b.filename) * order;
      }
    });

    // 分页
    const total = downloads.length;
    const paged = downloads.slice(filter.offset, filter.offset + filter.limit);

    // 统计
    const stats = this.calculateStats(downloads);

    return { items: paged, stats };
  }

  /**
   * 检测重复下载
   */
  async checkDuplicate(download: DownloadItem): Promise<{
    isDuplicate: boolean;
    duplicateOf?: number;
  }> {
    // 搜索同 URL 同大小的已完成下载
    const existing = await this.searchDownloads({
      query: [download.url],
      state: 'complete',
      limit: 10,
    });

    for (const item of existing) {
      if (
        item.id !== download.id &&
        item.fileSize === download.fileSize &&
        item.fileSize > 0
      ) {
        // 确保不是同一次下载的不同状态
        return { isDuplicate: true, duplicateOf: item.id };
      }
    }

    // 检查文件名完全相同的已完成下载
    const sameName = await this.searchDownloads({
      query: [download.filename.split('/').pop() || download.filename],
      state: 'complete',
      limit: 10,
    });

    for (const item of sameName) {
      if (item.id !== download.id && item.fileSize === download.fileSize && item.fileSize > 0) {
        return { isDuplicate: true, duplicateOf: item.id };
      }
    }

    return { isDuplicate: false };
  }

  /**
   * 分类文件
   */
  categorizeFile(filename: string, mime: string): FileCategory {
    // 1. 扩展名匹配
    const ext = filename.split('.').pop()?.toLowerCase() || '';
    if (this.CATEGORY_RULES[ext]) {
      return this.CATEGORY_RULES[ext];
    }

    // 2. MIME 类型匹配
    if (mime.startsWith('image/')) return 'image';
    if (mime.startsWith('video/')) return 'video';
    if (mime.startsWith('audio/')) return 'audio';
    if (mime.includes('pdf')) return 'document';
    if (mime.includes('zip') || mime.includes('rar')) return 'archive';
    if (mime.includes('javascript') || mime.includes('json')) return 'code';

    return 'other';
  }

  /**
   * 获取 AI 重命名建议
   */
  async suggestRename(download: DownloadItem): Promise<RenameSuggestion | null> {
    // 仅对模糊命名提供建议
    const fuzzyPatterns = [
      /^download\b/i, /^下载\b/, /^image\b/i, /^photo\b/i,
      /^file\b/i, /^document\b/i, /^video\b/i, /^未命名/,
      /\(\d+\)/, // 包含 (1), (2) 等重复标记
    ];

    const baseName = download.filename.split('/').pop() || download.filename;
    const needsRename = fuzzyPatterns.some(pattern => pattern.test(baseName));

    if (!needsRename) return null;

    try {
      // 调用 YiAi 后端获取重命名建议
      const response = await this.apiClient.rpcCall('services.ai.downloads.suggest_rename', {
        filename: baseName,
        url: download.url,
        mime: download.mime,
        domain: download.domain,
        category: download.category,
      });

      return {
        originalName: baseName,
        suggestedName: response.suggestedName,
        confidence: response.confidence,
        reason: response.reason,
      };
    } catch {
      // AI 服务不可用时，使用本地规则生成建议
      return this.localRenameSuggestion(download);
    }
  }

  /**
   * 执行重命名（通过 chrome.downloads API 无法直接重命名已完成的文件，
   * 这里通过下载前拦截或建议用户手动操作）
   */
  async renameDownload(downloadId: number, newFilename: string): Promise<void> {
    // chrome.downloads API 不支持重命名已完成的文件
    // 对于进行中的下载，可通过 onDeterminingFilename 拦截
    // 对于已完成的文件，返回新文件名建议，由用户手动操作
    throw new Error('Chrome 扩展不支持重命名已完成的下载文件。建议用户手动重命名，或通过下载前拦截实现。');
  }

  /**
   * 批量操作
   */
  async batchOperation(operation: BatchOperation): Promise<BatchOperationResult> {
    const result: BatchOperationResult = { success: [], failed: [] };

    for (const id of operation.downloadIds) {
      try {
        switch (operation.type) {
          case 'retry':
            await this.retryDownload(id);
            break;
          case 'delete':
            await this.deleteDownload(id);
            break;
          case 'open_folder':
            chrome.downloads.show(id);
            break;
          case 'copy_path':
            await this.copyPath(id);
            break;
        }
        result.success.push(id);
      } catch (error: any) {
        result.failed.push({ id, error: error.message });
      }
    }

    return result;
  }

  /**
   * 重试失败的下载
   */
  async retryDownload(downloadId: number): Promise<number> {
    const [item] = await this.searchDownloads({ id: downloadId });
    if (!item) throw new Error('Download not found');

    // 重新下载
    const newId = await chrome.downloads.download({
      url: item.url,
      filename: item.filename.split('/').pop(),
      saveAs: false,
    });

    return newId;
  }

  /**
   * 删除下载
   */
  async deleteDownload(downloadId: number): Promise<void> {
    await chrome.downloads.erase({ id: downloadId });
  }

  /**
   * 复制文件路径
   */
  async copyPath(downloadId: number): Promise<void> {
    const [item] = await this.searchDownloads({ id: downloadId });
    if (!item) throw new Error('Download not found');

    // 通过 Service Worker 发送消息到 Content Script 复制路径
    // 因为 clipboard API 需要用户交互触发
    chrome.runtime.sendMessage({
      type: 'copy_download_path',
      path: item.filename,
    });
  }

  /**
   * 获取建议的子目录
   */
  getSubfolder(download: DownloadItem): string {
    const categoryFolders: Record<FileCategory, string> = {
      document: '文档',
      image: '图片',
      video: '视频',
      audio: '音乐',
      archive: '压缩包',
      code: '代码',
      executable: '安装包',
      other: '其他',
    };

    const category = categoryFolders[download.category];
    const date = new Date(download.startTime);
    const month = `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}`;

    // 按来源域名细分
    if (download.domain && download.domain !== 'unknown') {
      return `${category}/${download.domain}/${month}`;
    }

    return `${category}/${month}`;
  }

  // --- 清理规则 ---

  /**
   * 添加清理规则
   */
  async addCleanupRule(rule: Omit<CleanupRule, 'id'>): Promise<CleanupRule> {
    const newRule: CleanupRule = {
      ...rule,
      id: `rule_${Date.now()}_${Math.random().toString(36).slice(2, 7)}`,
    };
    this.cleanupRules.push(newRule);
    await this.saveCleanupRules();
    return newRule;
  }

  /**
   * 删除清理规则
   */
  async removeCleanupRule(ruleId: string): Promise<void> {
    this.cleanupRules = this.cleanupRules.filter(r => r.id !== ruleId);
    await this.saveCleanupRules();
  }

  /**
   * 预览清理结果
   */
  async previewCleanup(): Promise<CleanupPreview[]> {
    const previews: CleanupPreview[] = [];

    for (const rule of this.cleanupRules) {
      if (!rule.enabled) continue;

      const cutoffTime = new Date(
        Date.now() - rule.olderThanDays * 24 * 60 * 60 * 1000
      ).toISOString();

      const items = await this.searchDownloads({
        state: 'complete',
        startedBefore: cutoffTime,
        limit: 1000,
      });

      let downloads = items.map(this.normalizeDownloadItem);

      // 文件类型过滤
      if (rule.fileTypes.length > 0) {
        downloads = downloads.filter(d => {
          const ext = '.' + (d.filename.split('.').pop()?.toLowerCase() || '');
          return rule.fileTypes.includes(ext);
        });
      }

      // 来源域名过滤
      if (rule.sourceDomain) {
        downloads = downloads.filter(d =>
          d.domain.includes(rule.sourceDomain!)
        );
      }

      // 文件大小过滤
      if (rule.minSize) {
        downloads = downloads.filter(d => d.fileSize >= rule.minSize!);
      }

      if (downloads.length > 0) {
        previews.push({
          rule,
          matchedItems: downloads,
          totalSize: downloads.reduce((sum, d) => sum + d.fileSize, 0),
        });
      }
    }

    return previews;
  }

  /**
   * 执行清理规则
   */
  async executeCleanupRules(): Promise<{
    deletedCount: number;
    freedSpace: number;
  }> {
    const previews = await this.previewCleanup();
    let deletedCount = 0;
    let freedSpace = 0;

    for (const preview of previews) {
      for (const item of preview.matchedItems) {
        try {
          await chrome.downloads.erase({ id: item.id });
          deletedCount++;
          freedSpace += item.fileSize;
        } catch {
          // 单个删除失败不影响其他
        }
      }
    }

    return { deletedCount, freedSpace };
  }

  // --- 私有方法 ---

  private onDownloadCreated(downloadItem: chrome.downloads.DownloadItem): void {
    const item = this.normalizeDownloadItem(downloadItem);

    // 检查重复
    this.checkDuplicate(item).then(({ isDuplicate, duplicateOf }) => {
      if (isDuplicate) {
        item.isDuplicate = true;
        item.duplicateOf = duplicateOf;

        // 发送重复通知
        chrome.runtime.sendMessage({
          type: 'download_duplicate_detected',
          download: item,
        });
      }
    });

    this.downloadCache.set(item.id, item);
  }

  private onDownloadChanged(delta: chrome.downloads.DownloadDelta): void {
    const cached = this.downloadCache.get(delta.id);
    if (!cached) return;

    // 更新状态
    if (delta.state) {
      cached.status = this.mapDownloadState(delta.state.current);
    }

    // 更新进度
    if (delta.receivedBytes) {
      cached.receivedBytes = delta.receivedBytes.current;
    }

    if (delta.totalBytes) {
      cached.totalBytes = delta.totalBytes.current;
    }

    if (delta.fileSize) {
      cached.fileSize = delta.fileSize.current;
    }

    if (delta.endTime) {
      cached.endTime = delta.endTime.current;
    }

    if (delta.error) {
      cached.error = delta.error.current;
    }

    // 下载完成时触发分类和通知
    if (delta.state?.current === 'complete') {
      this.onDownloadComplete(cached);
    }

    // 下载失败时触发通知
    if (delta.state?.current === 'interrupted') {
      this.onDownloadFailed(cached);
    }

    // 发送进度更新
    chrome.runtime.sendMessage({
      type: 'download_progress',
      download: cached,
    });
  }

  private onDownloadErased(downloadId: number): void {
    this.downloadCache.delete(downloadId);
  }

  private async onDownloadComplete(item: DownloadItem): Promise<void> {
    // 分类
    item.category = this.categorizeFile(item.filename, item.mime);

    // 建议子目录
    item.subfolder = this.getSubfolder(item);

    // 显示完成通知
    chrome.notifications.create(`download_${item.id}`, {
      type: 'basic',
      iconUrl: 'icons/icon48.png',
      title: '下载完成',
      message: item.filename.split('/').pop() || item.filename,
      buttons: [
        { title: '打开文件' },
        { title: '打开文件夹' },
      ],
      priority: 0,
    });
  }

  private async onDownloadFailed(item: DownloadItem): Promise<void> {
    chrome.notifications.create(`download_failed_${item.id}`, {
      type: 'basic',
      iconUrl: 'icons/icon48.png',
      title: '下载失败',
      message: `${item.filename.split('/').pop()}: ${item.error || '未知错误'}`,
      buttons: [
        { title: '重试' },
        { title: '取消' },
      ],
      priority: 2,
    });
  }

  private searchDownloads(query: chrome.downloads.DownloadQuery): Promise<chrome.downloads.DownloadItem[]> {
    return new Promise((resolve) => {
      chrome.downloads.search(query, resolve);
    });
  }

  private normalizeDownloadItem(item: chrome.downloads.DownloadItem): DownloadItem {
    const filename = item.filename || '';
    return {
      id: item.id,
      url: item.url || '',
      referrer: item.referrer || '',
      filename,
      fileSize: item.fileSize || 0,
      totalBytes: item.totalBytes || 0,
      receivedBytes: item.receivedBytes || 0,
      status: this.mapDownloadState(item.state),
      startTime: item.startTime || new Date().toISOString(),
      endTime: item.endTime,
      mime: item.mime || '',
      domain: this.extractDomain(item.url || ''),
      category: this.categorizeFile(filename, item.mime || ''),
      isDuplicate: false,
      canResume: item.canResume || false,
      danger: (item.danger as 'safe' | 'accepted' | 'blocked') || 'safe',
    };
  }

  private mapDownloadState(state: string | undefined): DownloadStatus {
    const stateMap: Record<string, DownloadStatus> = {
      'in_progress': 'in_progress',
      'complete': 'complete',
      'interrupted': 'failed',
    };
    return stateMap[state || ''] || 'in_progress';
  }

  private extractDomain(url: string): string {
    try {
      return new URL(url).hostname;
    } catch {
      return 'unknown';
    }
  }

  private calculateStats(downloads: DownloadItem[]): DownloadStats {
    const stats: DownloadStats = {
      total: downloads.length,
      inProgress: 0,
      complete: 0,
      failed: 0,
      paused: 0,
      totalSize: 0,
      duplicates: 0,
    };

    for (const d of downloads) {
      switch (d.status) {
        case 'in_progress': stats.inProgress++; break;
        case 'complete':
          stats.complete++;
          stats.totalSize += d.fileSize;
          break;
        case 'failed': stats.failed++; break;
        case 'paused': stats.paused++; break;
      }
      if (d.isDuplicate) stats.duplicates++;
    }

    return stats;
  }

  private localRenameSuggestion(download: DownloadItem): RenameSuggestion {
    const baseName = download.filename.split('/').pop() || download.filename;
    const ext = baseName.split('.').pop() || '';

    // 从 URL 中提取有用信息
    let urlHint = '';
    try {
      const url = new URL(download.url);
      const pathParts = url.pathname.split('/').filter(Boolean);
      if (pathParts.length > 0) {
        urlHint = pathParts[pathParts.length - 1].split('.')[0];
      }
    } catch {}

    const date = new Date(download.startTime);
    const dateStr = `${date.getFullYear()}${String(date.getMonth() + 1).padStart(2, '0')}${String(date.getDate()).padStart(2, '0')}`;

    const suggestedName = urlHint
      ? `${urlHint}_${dateStr}.${ext}`
      : `download_${dateStr}.${ext}`;

    return {
      originalName: baseName,
      suggestedName,
      confidence: 0.3,
      reason: '基于 URL 和日期自动生成',
    };
  }

  private async loadCleanupRules(): Promise<void> {
    const result = await chrome.storage.local.get('cleanup_rules');
    this.cleanupRules = result.cleanup_rules || [];
  }

  private async saveCleanupRules(): Promise<void> {
    await chrome.storage.local.set({ cleanup_rules: this.cleanupRules });
  }

  private apiClient: any;
}
```

## 九、设计决策记录

### D-01：下载管理界面设计

- **问题**：下载管理功能应该放在哪里，Popup 面板 vs 独立页面 vs 聊天窗口
- **选项**：Popup 面板、独立页面（chrome-extension://）、聊天窗口集成
- **选择**：Popup 面板为主 + 聊天窗口集成
- **理由**：Popup 面板是用户最熟悉的 YiPet 入口，适合快速查看和管理下载。聊天窗口集成提供自然语言交互（如"清理下载文件夹"），符合 YiPet 的 AI 伴侣定位。不创建独立页面，避免增加扩展复杂度，同时 Popup 面板已经足够展示下载列表和基本操作。

### D-02：文件分类方案

- **问题**：如何对下载文件进行分类，AI 分类 vs 本地规则 vs 混合
- **选项**：远程 AI 分类、本地规则（扩展名匹配）、混合方案
- **选择**：混合方案（本地规则优先 + 远程 AI 可选）
- **理由**：基于文件扩展名的本地规则覆盖 80% 的常见文件类型，响应速度快（< 10ms），完全本地处理。对于无法判断的文件（如无扩展名），提供 AI 分类建议（需用户授权）。AI 分类通过 YiAi 后端分析文件名、URL 和 MIME 类型，提供更准确的分类。

### D-03：去重检测策略

- **问题**：如何判断两个下载文件是否重复
- **选项**：仅文件名、文件名+大小、URL+文件名+大小、文件内容哈希
- **选择**：URL + 文件名 + 文件大小组合判断
- **理由**：URL + 文件名 + 文件大小是可在 chrome.downloads API 层面获取的最准确信息组合。URL 相同且文件大小相同几乎可以确定是重复文件。文件名相同但 URL 不同时，提示用户可能存在同名文件。文件内容哈希虽然最准确，但需要读取文件内容，在浏览器扩展中难以实现且性能开销大。

### D-04：自动清理策略

- **问题**：如何设计自动清理规则，避免误删用户文件
- **选项**：固定天数清理、文件类型+天数、混合规则（类型+天数+域名+大小）
- **选择**：混合规则（类型 + 天数 + 域名 + 大小）
- **理由**：混合规则提供最大的灵活性，用户可以根据文件类型、下载时间、来源域名和文件大小组合配置清理规则。关键安全措施：默认不启用自动清理，清理前显示预览列表，提供"移动到回收站"选项，用户确认后执行。清理规则持久化到 chrome.storage.local。

## 回归问题预测

| # | 预测问题 | 原因 | 验证方法 |
|---|---------|------|---------|
| 1 | chrome.downloads.onChanged 事件在批量下载时高频触发，每个下载项的每次进度更新都触发一次，导致 Service Worker 消息队列堵塞 | 批量下载（如 10 个文件同时下载）时，每个文件每秒触发多次 onChanged 事件，短时间内产生大量事件 | 使用节流（500ms）+ 批量合并：收集 500ms 内的所有变化，一次性发送。监测 SW 消息队列长度，超过 100 时告警 |
| 2 | 去重检测使用 chrome.downloads.search 查询历史记录，但在大量历史记录（> 10000 条）时搜索耗时显著增加，可能导致下载创建事件处理延迟 | chrome.downloads.search 的查询性能随历史记录数量线性下降，大量记录时单次搜索耗时 > 500ms | 为去重检测建立 IndexedDB 索引（url + fileSize），避免每次搜索全量历史。异步执行去重检测，不阻塞下载创建 |
| 3 | 清理规则执行时逐个删除文件，如果匹配文件数量大（> 500），chrome.downloads.erase 调用过于频繁，可能触发 Chrome 的 API 调用频率限制 | Chrome 对扩展 API 调用有频率限制（通常 1 秒内不超过 N 次），大量删除操作可能被限流 | 删除操作分批执行（每批 10 个，间隔 200ms）。显示执行进度（如"已清理 50/200 个文件"）。单次清理最多 500 个文件 |
| 4 | 文件分类规则依赖文件扩展名，但部分下载文件的 MIME 类型与扩展名不匹配（如服务器返回错误的 Content-Type），导致分类错误 | 服务器配置错误或恶意文件伪装，MIME 类型不反映实际文件类型 | 优先使用扩展名分类（用户可直观看到），MIME 类型作为补充。对于无扩展名或扩展名不常见的文件，使用 MIME 类型分类。显示分类来源，用户可手动修改 |
| 5 | 下载通知的 chrome.notifications.create 在用户关闭了 Chrome 通知权限时静默失败，用户看不到下载完成通知 | Chrome 通知权限被系统级或浏览器级禁用，扩展无法检测权限状态 | 在通知创建失败时，降级为 Popup 内的消息提示。扩展初始化时检测通知权限状态，提示用户开启 |
| 6 | 下载管理面板在 Popup 中展示时，如果下载列表很长（> 100 条），虚拟滚动未实现导致渲染性能问题 | Popup 窗口小，渲染大量 DOM 节点导致滚动卡顿，Popup 关闭和重新打开时状态丢失 | 使用虚拟滚动（如 vue-virtual-scroller）渲染下载列表，仅渲染可见区域的条目。下载列表数据缓存到 Pinia store，Popup 重新打开时恢复状态 |
