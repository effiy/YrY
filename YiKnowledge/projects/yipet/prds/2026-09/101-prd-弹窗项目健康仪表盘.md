# YP-101: YiPet 弹窗项目健康仪表盘

## 一、背景

YiPet 弹出面板仅显示宠物设置，无项目健康概览。用户需单独打开 YiVad 才能查看项目状态。

## 二、方案

**`popup/components/DashboardSummary.vue`**（新增）

- 调用 YiAi `GET /dashboard/summary`（直接 fetch）
- 4 个 KPI 卡片：Open Issues / Open Bugs / Done Today / Overdue
- 前 3 个活跃项目 + 健康点（绿 healthy / 黄 warning / 红 critical）
- 加载/错误/空状态完整覆盖
- YiAi 不可用时显示错误提示，不阻塞宠物功能
- 使用 YiPet Lavender 调色板 CSS 变量

## 三、验收

- [x] YiAi 可用时显示 KPI 卡片 + 项目列表
- [x] YiAi 不可用时显示错误提示
- [x] 健康点颜色正确（healthy=绿, warning=黄, critical=红）
- [x] typecheck 通过
