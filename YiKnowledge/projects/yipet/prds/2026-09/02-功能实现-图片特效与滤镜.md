## 二、功能 1: 基础滤镜效果 (YP-09-218)

### 2.1 功能概述

提供 9 种基础图片滤镜实时调整：亮度(0.0-3.0)、对比度(0.0-3.0)、饱和度(0.0-3.0)、色相(0-360°)、模糊(0-20px)、锐化(0.0-2.0)、怀旧/Sepia(0.0-1.0)、灰度(0.0-1.0)、反相(0.0-1.0)。8个预设滤镜一键切换：暖色调、冷色调、复古、黑白、增强、褪色、戏剧化、柔光。支持原图对比(按住查看原图, 松开恢复滤镜)和一键重置。

### 2.2 设计决策

| 决策 | 方案A | 方案B | 方案C | 选择 | 理由 |
|------|------|------|------|------|------|
| 滤镜实现 | Canvas filter API | 像素操作 | WebGL shader | **Canvas filter + 像素混合** | CSS filter覆盖7/9种(GPU加速), 锐化用3x3卷积核 |
| 叠加策略 | 独立toggle | 累积栈 | 预设组合 | **独立toggle + 预设** | 灵活+快捷, 预设为固定参数快捷方式 |
| 锐化算法 | 简单3x3卷积核 | Unsharp Mask | Laplacian | **3x3卷积核** | 0.2d预算内足够, 后续可升级 |
| 预设定义 | 硬编码常量 | 可配置JSON | 用户自定义 | **硬编码** | TypeScript类型安全, 零加载风险 |
| 原图对比 | 按住按钮 | toggle切换 | — | **按住按钮** | 符合直觉, 不记忆当前模式 |

### 2.3 滤镜管线处理顺序 (固定)

```
原始 ImageData
  → Step 1: 亮度 (CSS filter: brightness)
  → Step 2: 对比度 (CSS filter: contrast)
  → Step 3: 饱和度 (CSS filter: saturate)
  → Step 4: 色相 (CSS filter: hue-rotate)
  → Step 5: 怀旧 (CSS filter: sepia)
  → Step 6: 灰度 (CSS filter: grayscale)
  → Step 7: 反相 (CSS filter: invert)
  → Step 8: 模糊 (CSS filter: blur)
  → Step 9: 锐化 (像素操作: 3x3卷积核)
  → 最终输出 Canvas
```

```typescript
// CSS filter 字符串构建
class FilterPipeline {
  private buildCssFilterString(): string {
    const parts: string[] = [];
    const f = this.filters;
    if (f.get('brightness')?.enabled) parts.push(`brightness(${f.get('brightness')!.value})`);
    if (f.get('contrast')?.enabled)   parts.push(`contrast(${f.get('contrast')!.value * 100}%)`);
    if (f.get('saturation')?.enabled) parts.push(`saturate(${f.get('saturation')!.value})`);
    if (f.get('hue-rotate')?.enabled) parts.push(`hue-rotate(${f.get('hue-rotate')!.value}deg)`);
    if (f.get('blur')?.enabled)       parts.push(`blur(${f.get('blur')!.value}px)`);
    if (f.get('sepia')?.enabled)      parts.push(`sepia(${f.get('sepia')!.value})`);
    if (f.get('grayscale')?.enabled)  parts.push(`grayscale(${f.get('grayscale')!.value})`);
    if (f.get('invert')?.enabled)     parts.push(`invert(${f.get('invert')!.value})`);
    return parts.join(' ');
  }

  // 锐化 3x3 卷积核 (像素操作)
  private applySharpen(intensity: number): void {
    const kernel = [0, -1, 0, -1, 4 + intensity, -1, 0, -1, 0];
    const srcData = this.ctx.getImageData(0, 0, this.canvas.width, this.canvas.height);
    const dstData = new Uint8ClampedArray(srcData.data);
    const w = this.canvas.width, h = this.canvas.height;
    for (let y = 1; y < h - 1; y++) {
      for (let x = 1; x < w - 1; x++) {
        for (let c = 0; c < 3; c++) {
          let sum = 0;
          for (let ky = -1; ky <= 1; ky++)
            for (let kx = -1; kx <= 1; kx++)
              sum += srcData.data[((y+ky)*w + (x+kx))*4 + c] * kernel[(ky+1)*3 + (kx+1)];
          dstData[(y*w + x)*4 + c] = Math.max(0, Math.min(255, sum));
        }
        dstData[(y*w + x)*4 + 3] = srcData.data[(y*w + x)*4 + 3];
      }
    }
    this.ctx.putImageData(new ImageData(dstData, w, h), 0, 0);
  }
}
```

### 2.7 测试场景

**场景1 — 亮度与对比度**：拖动亮度到1.4(偏暗截图整体变亮)、对比度到1.3(层次感增强)、极端值3.0仍可辨识。

**场景2 — 饱和度与色相**：饱和度1.5颜色更鲜艳、饱和度0→灰度等效、色相90°色调偏移(红→绿、蓝→红)。

**场景3 — 预设滤镜**：点击"暖色调"→亮度+饱和度设置生效、"黑白"→灰度=1对比度略增、"增强"→亮度/对比度/饱和度轻微提升+锐化轻微生效。应用预设后可继续手动微调。

**场景4 — 模糊与锐化**：模糊5px细节减少、锐化0.5部分抵消模糊、锐化>1.5出现噪点但不崩溃。

**场景5 — 原图对比**：按住"对比原图"→显示原始、松开→恢复滤镜，反复快速按/松无闪烁无延迟。

**场景6 — 重置与导出**：重置→全部恢复默认值，导出→PNG/JPEG包含所有滤镜效果。

## 三、功能 2: 像素化效果 (YP-09-232)

### 3.1 功能概述

将图片转换为像素艺术(Pixel Art)风格。可配置像素块大小(1-64px)、颜色数(2-256)、3种抖动模式(无/Floyd-Steinberg/有序Bayer)、9个复古游戏调色板预设(NES 56色/GameBoy 4级灰绿/CGA 16色/EGA 64色/Commodore 64 16色/Amiga 32色/1-bit黑白/8级灰度/4级灰度)、像素网格叠加(显示/隐藏)、前后对比。

### 3.2 设计决策

| 决策 | 方案A | 方案B | 方案C | 选择 | 理由 |
|------|------|------|------|------|------|
| 颜色量化 | Median Cut | K-means | Popularity | **Median Cut** | 确定性结果(相同输入→相同输出), O(N log N) |
| 抖动算法 | Floyd-Steinberg | 有序Bayer | 无 | **全支持(3种)** | 每种适用不同风格, 实现不超30行/种 |
| 调色板 | 手动N色 | 复古预设 | 自定义编辑 | **手动+预设** | 0.2d内最佳平衡 |
| 像素大小 | 总像素数 | 缩小比例 | 块大小 | **像素块大小** | 最直观概念("4px块") |

### 3.3 像素化处理管道

```
原始 ImageData
  → Step 1: Downscale (最近邻插值, 缩小到 原始/像素块大小 分辨率)
  → Step 2: Upscale (最近邻插值, 放大回原始尺寸, 形成像素块)
  → Step 3: 调色板缩减 (Median Cut 颜色量化到 N 色 / 复古调色板直接映射)
  → Step 4: 抖动处理 (无/Floyd-Steinberg误差扩散/有序抖动Bayer矩阵)
  → 最终输出
```

### 3.4 Median Cut 颜色量化算法

```typescript
private medianCut(pixels: RGB[], targetColors: number): RGB[] {
  // 1. 去重像素
  const unique = this.deduplicatePixels(pixels);
  if (unique.length <= targetColors) return unique;

  // 2. 初始化一个包围盒(涵盖所有像素)
  const boxes = [{ pixels: [...unique], rRange: [0,255], gRange: [0,255], bRange: [0,255] }];

  // 3. 迭代分割直到达到目标颜色数
  while (boxes.length < targetColors) {
    // 找RGB范围最大的盒子
    let maxBoxIdx = 0, maxRange = 0;
    for (let i = 0; i < boxes.length; i++) {
      const rRange = boxes[i].rRange[1] - boxes[i].rRange[0];
      const gRange = boxes[i].gRange[1] - boxes[i].gRange[0];
      const bRange = boxes[i].bRange[1] - boxes[i].bRange[0];
      const maxDim = Math.max(rRange, gRange, bRange);
      if (maxDim > maxRange) { maxRange = maxDim; maxBoxIdx = i; }
    }
    if (maxRange === 0) break;

    // 沿最大维度排序→在中位数处分割
    const box = boxes[maxBoxIdx];
    const sortKey = /* 最大维度的RGB分量 */;
    box.pixels.sort((a, b) => sortKey(a) - sortKey(b));
    const median = Math.floor(box.pixels.length / 2);
    boxes.splice(maxBoxIdx, 1,
      { pixels: box.pixels.slice(0, median), /* ranges */ },
      { pixels: box.pixels.slice(median),    /* ranges */ }
    );
  }
  // 4. 每个盒子的平均颜色 = 该盒子的代表颜色
  return boxes.map(box => /* average RGB */);
}
```

### 3.5 Floyd-Steinberg 误差扩散

```typescript
private floydSteinbergDither(imageData: ImageData): ImageData {
  const { width, height, data } = imageData;
  const result = new Uint8ClampedArray(data);
  const palette = this.collectPaletteFromImage(imageData);

  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const idx = (y * width + x) * 4;
      const oldR = result[idx], oldG = result[idx+1], oldB = result[idx+2];

      // 找最近调色板颜色
      const nearest = this.findNearestColor({r:oldR, g:oldG, b:oldB}, palette);
      result[idx]=nearest.r; result[idx+1]=nearest.g; result[idx+2]=nearest.b;

      // 误差 = 原始 - 量化后
      const errR = oldR - nearest.r, errG = oldG - nearest.g, errB = oldB - nearest.b;

      // 扩散到4个邻居: 右侧7/16, 左下3/16, 下方5/16, 右下1/16
      if (x+1 < width)                    this.addError(result, x+1, y,   width, errR, errG, errB, 7/16);
      if (x-1 >= 0 && y+1 < height)      this.addError(result, x-1, y+1, width, errR, errG, errB, 3/16);
      if (y+1 < height)                  this.addError(result, x,   y+1, width, errR, errG, errB, 5/16);
      if (x+1 < width && y+1 < height)   this.addError(result, x+1, y+1, width, errR, errG, errB, 1/16);
    }
  }
  return new ImageData(result, width, height);
}
```

## 四、功能 3: 素描效果 (YP-09-233)

### 4.1 功能概述

将照片转换为素描风格。4种模式：铅笔素描(灰度→反相→模糊→颜色减淡+边缘增强)、炭笔素描(灰度+噪声纹理+高对比度)、钢笔素描(Canny-style Sobel+NMS+滞后跟踪→细线条)、彩色素描(原图+Sobel边缘叠加半透明线条)。支持强度/线条粗细/暗度/纹理密度/线条颜色调节 + 原图对比。

### 4.2 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 边缘检测 | Sobel + 高斯预平滑 | 速度快(两个3×3卷积核), 去噪后边缘更干净 |
| 铅笔算法 | 灰度→反相→模糊→颜色减淡 + Sobel边缘增强(组合式) | 自然度高(模拟石墨在纸面沉积)+轮廓清晰(边缘辅助) |
| 炭笔效果 | 噪声纹理 + 高对比度 | 模拟炭条粗糙质感+纸面纹理 |
| 钢笔素描 | Canny-style( Sobel→NMS→滞后跟踪) | 1像素宽连续线条, 接近真实钢笔 |
| 彩色素描 | 原图+Sobel边缘叠加(半透明) | 保留全部色彩+增加手绘线条感 |
| 高斯模糊 | 分离卷积(水平+垂直) | 性能提升10倍(R=10时: 21次/像素 vs 441次/像素) |

### 4.3 铅笔素描处理管道

```
原始 ImageData
  → Step 1: 灰度转换 (NTSC: 0.299R + 0.587G + 0.114B)
  → Step 2: 对比度调整 (darkness 控制, 1 + darkness × 1.5)
  → Step 3: 高斯模糊 (lineWidth 控制半径, 分离卷积)
  → Step 4: 反相 (255 - pixel)
  → Step 5: 颜色减淡混合 (base + base × invert / (255 - invert))
  → Step 6: Sobel 边缘检测 + 边缘叠加 (intensity 控制权重 0-1)
  → 铅笔素描输出
```

### 4.4 钢笔素描 Canny-style 多阶段处理

```
原始 ImageData
  → Step 1: 高斯平滑 (减少噪点, 半径 = lineWidth × 0.3)
  → Step 2: Sobel 边缘检测 (获取幅值 magnitude + 方向 direction)
  → Step 3: 非极大值抑制 NMS (梯度方向量化到 4个方向 0/45/90/135, 边缘细化到1px)
  → Step 4: 双阈值滞后跟踪 (高阈值=0.3×(1-intensity×0.5), 低阈值=高阈值×0.4)
  → Step 5: 创建白底黑线 / 黑底白线(intensity>0.7)
  → 钢笔素描输出
```

### 4.5 颜色减淡混合公式

```typescript
private colorDodge(base: ImageData, blend: ImageData): ImageData {
  for (let i = 0; i < base.data.length; i += 4) {
    for (let c = 0; c < 3; c++) {
      const b = base.data[i + c], bl = blend.data[i + c];
      if (bl === 255) {
        result[i + c] = 255;  // 完全反相处→纯白
      } else {
        const dodged = b + (b * bl) / (255 - bl);
        result[i + c] = Math.min(255, Math.max(0, dodged));
      }
    }
    result[i + 3] = 255;
  }
}
```

### 5.4 聚光灯渲染核心代码

```typescript
function applySpotlight(imageData: ImageData, config: SpotlightConfig): ImageData {
  const { width, height, data } = imageData;
  const centerX = config.x * width, centerY = config.y * height;
  const maxRadius = Math.max(width, height) * config.radius;
  const result = new Uint8ClampedArray(data);

  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const distance = Math.sqrt((x-centerX)**2 + (y-centerY)**2);
      let lightFactor: number;
      if (distance <= maxRadius * (1 - config.feather)) {
        lightFactor = 1;  // 核心区域完全照亮
      } else if (distance <= maxRadius) {
        const t = (distance - maxRadius * (1 - config.feather)) / (maxRadius * config.feather);
        lightFactor = 1 - t;  // 羽化区域线性衰减
      } else {
        lightFactor = 0;  // 光照范围外无效果
      }
      if (lightFactor > 0) {
        const idx = (y * width + x) * 4;
        const lightIntensity = lightFactor * config.intensity;
        // 柔光混合 (soft light)
        result[idx]   = softLightBlend(result[idx],   r, lightIntensity);
        result[idx+1] = softLightBlend(result[idx+1], g, lightIntensity);
        result[idx+2] = softLightBlend(result[idx+2], b, lightIntensity);
      }
    }
  }
  return new ImageData(result, width, height);
}

function softLightBlend(base: number, blend: number, intensity: number): number {
  const b = base / 255, s = blend / 255;
  const result = b < 0.5
    ? (2 * b * s + b * b * (1 - 2 * s))
    : (2 * b * (1 - s) + Math.sqrt(b) * (2 * s - 1));
  return Math.round((b + (result - b) * intensity) * 255);
}
```

### 5.5 色温校正 (Tanner Helland 算法)

```typescript
function kelvinToRGB(kelvin: number): { r: number; g: number; b: number } {
  const temp = kelvin / 100;
  let r: number, g: number, b: number;
  if (temp <= 66) {
    r = 255;
    g = 99.4708025861 * Math.log(temp) - 161.1195681661;
    b = temp <= 19 ? 0 : 138.5177312231 * Math.log(temp - 10) - 305.0447927307;
  } else {
    r = 329.698727446 * Math.pow(temp - 60, -0.1332047592);
    g = 288.1221695283 * Math.pow(temp - 60, -0.0755148492);
    b = 255;
  }
  return {
    r: Math.max(0, Math.min(255, Math.round(r))),
    g: Math.max(0, Math.min(255, Math.round(g))),
    b: Math.max(0, Math.min(255, Math.round(b))),
  };
}
```

```typescript
class EffectChain {
  private effects: Array<{
    name: string;
    renderer: (data: ImageData) => ImageData;
    enabled: boolean;
  }> = [];

  addEffect(name: string, renderer: (data: ImageData) => ImageData, enabled = true): this {
    this.effects.push({ name, renderer, enabled });
    return this; // 链式调用
  }

  apply(sourceData: ImageData): ImageData {
    let current = sourceData;
    for (const effect of this.effects) {
      if (!effect.enabled) continue;
      const startTime = performance.now();
      current = effect.renderer(current);
      const elapsed = performance.now() - startTime;
      if (elapsed > 100) {
        console.warn(`[EffectChain] ${effect.name} took ${elapsed.toFixed(1)}ms`);
      }
    }
    return current;
  }

  static fromPreset(preset: VintagePreset): EffectChain {
    const chain = new EffectChain();
    return chain
      .addEffect('sepia', (data) => applySepia(data, preset.params.sepia.intensity))
      .addEffect('fade', (data) => applyFade(data, preset.params.fade))
      .addEffect('vignette', (data) => applyVignette(data, preset.params.vignette))

      .addEffect('dustScratches', (data) => preset.params.dustScratches.enabled
        ? applyDustScratches(data, preset.params.dustScratches) : data)
```

### 6.5 胶片颗粒生成 (泊松分布+多尺度)

```typescript
function applyGrain(imageData: ImageData, config: GrainConfig): ImageData {
  const { width, height, data } = imageData;
  const result = new Uint8ClampedArray(data);
  // 3个尺度模拟不同大小银盐颗粒
  const scales = [
    { size: config.size, weight: 0.5 },       // 粗颗粒
    { size: config.size * 0.5, weight: 0.3 },  // 中颗粒
    { size: config.size * 0.25, weight: 0.2 }, // 细颗粒
  ];
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      let totalGrain = 0;
      for (const scale of scales) {
        // 确定性伪随机(Box-Muller变换生成高斯分布)
        const u1 = pseudoRandom(x, y, scale.size);
        const u2 = pseudoRandom(y, x, scale.size + 1);
        const gaussian = Math.sqrt(-2 * Math.log(Math.max(u1, 0.001)))
          * Math.cos(2 * Math.PI * u2);
        totalGrain += gaussian * scale.weight;
      }
      const grainValue = totalGrain * config.intensity * config.roughness * 128;
      const idx = (y * width + x) * 4;
      result[idx]   = clamp(result[idx]   + grainValue, 0, 255);
      result[idx+1] = clamp(result[idx+1] + grainValue, 0, 255);
      result[idx+2] = clamp(result[idx+2] + grainValue, 0, 255);
    }
  }
  return new ImageData(result, width, height);
}
```

## 七、功能 6: 双色调效果 (YP-09-246)

### 7.1 功能概述

使用两种颜色替换图片的高光和阴影区域。支持高光/阴影取色器、HSL渐变映射(感知亮度+HSL插值)、20个经典双色调预设(4分类：经典/现代/怀旧/品牌)、20个品牌色板(Spotify/Instagram/Apple/Netflix/GitHub/Twitter等)、强度Alpha混合控制(0-100%)、照片分离色调(高光/阴影分别着色+balance分界点)。

### 7.2 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 亮度计算 | 感知亮度 `0.299R+0.587G+0.114B` (ITU-R BT.601) | 人眼对绿色最敏感, 最广泛使用的公式 |
| 颜色插值 | HSL空间插值 | 比RGB产生更鲜艳中间色, 色相最短路径处理 |
| 品牌色板 | 内置固定20个 | ~2KB不增加包体积, 色值不受版权保护 |
| 强度控制 | Alpha混合 `orig*(1-intensity) + duotone*intensity` | 0=原图, 100=完全双色调, 中间值平滑过渡 |
| 分离色调 | 亮度分界点 balance, 高光/阴影独立色调 | 类似 Lightroom 分离色调功能 |

### 7.3 渐变映射算法 (HSL插值)

```typescript
function applyGradientMap(imageData: ImageData, shadowColor: string, highlightColor: string): ImageData {
  const shadow = hexToRgb(shadowColor);
  const highlight = hexToRgb(highlightColor);
  const shadowHSL = rgbToHsl(shadow.r, shadow.g, shadow.b);
  const highlightHSL = rgbToHsl(highlight.r, highlight.g, highlight.b);

  // 色相环绕处理: 差值>180时走最短路径
  if (Math.abs(highlightHSL.h - shadowHSL.h) > 180) {
    if (highlightHSL.h < shadowHSL.h) highlightHSL.h += 360;
    else shadowHSL.h += 360;
  }

  for (let i = 0; i < data.length; i += 4) {
    // 感知亮度
    const luminance = 0.299 * data[i] + 0.587 * data[i+1] + 0.114 * data[i+2];

    // HSL 空间线性插值
    const h = lerp(shadowHSL.h, highlightHSL.h, luminance) % 360;
    const s = lerp(shadowHSL.s, highlightHSL.s, luminance);
    const l = lerp(shadowHSL.l, highlightHSL.l, luminance);
    const rgb = hslToRgb(h, s, l);

    result[i]=rgb.r; result[i+1]=rgb.g; result[i+2]=rgb.b;
  }
}
```

**性能优化**: 预计算256级亮度→颜色映射表(256×3字节=768字节), 双色调映射变为查表操作 O(1), 2000×2000 从 120ms 降至 ~10ms。

### 8.4 种子随机数生成器 (mulberry32)

```typescript
class SeededRNG {
  private state: number;
  constructor(seed: number) { this.state = seed | 0; }

  next(): number { // 返回 [0, 1)
    this.state |= 0;
    this.state = (this.state + 0x6D2B79F5) | 0;
    let t = Math.imul(this.state ^ (this.state >>> 15), 1 | this.state);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  }

  nextInt(min: number, max: number): number { return Math.floor(this.next() * (max - min)) + min; }
  nextFloat(min: number, max: number): number { return this.next() * (max - min) + min; }
  nextTriangular(min: number, max: number): number { return min + (max - min) * Math.min(this.next(), this.next()); }
  chance(probability: number): boolean { return this.next() < probability; }
}
```

### 8.5 RGB 通道偏移

```typescript
function applyRgbShift(imageData: ImageData, config: RgbShiftConfig): ImageData {
  // 分别处理 R/G/B 三通道, 各通道独立偏移量
  const channels = [
    { offsetX: config.redOffsetX,   offsetY: config.redOffsetY,   mask: 0 }, // R通道
    { offsetX: config.greenOffsetX, offsetY: config.greenOffsetY, mask: 1 }, // G通道
    { offsetX: config.blueOffsetX,  offsetY: config.blueOffsetY,  mask: 2 }, // B通道
  ];
  for (const channel of channels) {
    for (let y = 0; y < height; y++) {
      for (let x = 0; x < width; x++) {
        const srcX = x - channel.offsetX, srcY = y - channel.offsetY;
        // 边界处理 (extend=丢弃/wrap=循环/clamp=钳制)
        let finalX = srcX, finalY = srcY, valid = true;
        switch (config.edgeMode) {
          case 'clamp': finalX=clamp(srcX,0,width-1); finalY=clamp(srcY,0,height-1); break;
          case 'wrap':  finalX=((srcX%width)+width)%width; finalY=((srcY%height)+height)%height; break;
          case 'extend': if (srcX<0||srcX>=width||srcY<0||srcY>=height) valid=false; break;
        }
        if (!valid) continue;
        const srcIdx = (finalY * width + finalX) * 4;
        const dstIdx = (y * width + x) * 4;
        result[dstIdx + channel.mask] = data[srcIdx + channel.mask];
      }
    }
  }
  // Alpha通道不做偏移 (直接复制)
  for (let i = 3; i < data.length; i += 4) result[i] = data[i];
}
```

## 九、功能 8: HDR 效果 (YP-09-248)

### 9.1 功能概述

模拟高动态范围(HDR)色调映射。5步处理管道: 色调映射(Reinhard全局/Filmic S曲线可选)、阴影恢复(3级Luminance蒙版+高斯平滑)、高光恢复(亮部压缩)、局部对比度增强(3级高斯金字塔多尺度细节提取)、预设风格(色彩分级+暗角)。3种预设模式: 自然(Natural)、微妙(Subtle)、超现实(Surreal)。处理在 Web Worker 中执行, 大图不阻塞UI。

### 9.2 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 色调映射 | Reinhard全局(默认) + Filmic曲线(超现实模式) | Reinhard实现简单效果自然, Filmic戏剧化 |
| 阴影/高光分离 | 3级Luminance蒙版 + 高斯模糊平滑 | Chrome扩展中双边滤波开销过大(4K~10s), 蒙版方案可控在2s内 |
| 局部对比度 | 3级高斯金字塔多尺度细节增强 | 可分离纹理(小尺度)/边缘(中尺度)/结构(大尺度), 分别增强 |
| 预设风格 | 参数组合(色调映射+色彩分级+暗角) | 实现简单, 用户可控, 风格一致 |

### 9.3 HDR处理管道

```
原始 ImageData
  → Step 1: 色调映射 (RGB→Luminance, 应用Reinhard/Filmic, 还原RGB)
      Reinhard: L_d = L * (1 + L/L_white²) / (1 + L)
      Filmic (Uncharted 2): 五点S曲线拟合, 可调强度系数
  → Step 2: 阴影恢复 (Luminance蒙版: 暗部<0.3, 高斯模糊平滑, Gamma提升: pixel^gamma, gamma=0.7-0.9)
  → Step 3: 高光恢复 (Luminance蒙版: 亮部>0.7, 高斯模糊平滑, 亮部压缩: 1-(1-pixel)^gamma)
  → Step 4: 局部对比度 (3级高斯金字塔: 小尺度纹理×0.3 + 中尺度边缘×0.6 + 大尺度结构×1.0)
  → Step 5: 预设风格 (色彩分级: 高光暖色调+阴影冷色调; 暗角: 边缘亮度衰减)
  → 输出
```

### 9.4 Reinhard 色调映射实现

```typescript
function reinhardToneMap(luminance: number, strength: number): number {
  const L_white = 1.0 - strength * 0.5; // strength越大, 白点越低, 压缩越强
  const L = luminance;
  return (L * (1 + L / (L_white * L_white))) / (1 + L);
}

function filmicToneMap(x: number, strength: number): number {
  // Uncharted 2 五点可调S曲线
  const A = 0.22 * (1 + strength);
  const B = 0.30 * (1 - strength * 0.5);
  const C = 0.10; const D = 0.20 * (1 + strength * 0.5);
  const E = 0.01; const F = 0.30; const W = 11.2;
  const mapped = ((x * (A * x + C * B) + D * E) / (x * (A * x + B) + D * F)) - E / F;
  return Math.max(0, Math.min(1, mapped / (W - E / F)));
}
```

### 10.4 深度图生成 (径向渐变+焦点模式)

```typescript
function generateRadialDepthMap(
  width: number, height: number,
  focusX: number, focusY: number,  // 焦点位置 (归一化 0-1)
  focusRadius: number,             // 清晰区域半径 (归一化)
  transitionWidth: number          // 过渡带宽度 (归一化)
): Float32Array {
  const depthMap = new Float32Array(width * height);
  const cx = focusX * width, cy = focusY * height;
  const maxDist = Math.sqrt(width*width + height*height);
  const innerRadius = focusRadius * maxDist;
  const outerRadius = (focusRadius + transitionWidth) * maxDist;

  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const dist = Math.sqrt((x-cx)**2 + (y-cy)**2);
      if (dist <= innerRadius) {
        depthMap[y*width + x] = 0;       // 完全清晰
      } else if (dist >= outerRadius) {
        depthMap[y*width + x] = 1;       // 完全模糊
      } else {
        const t = (dist - innerRadius) / (outerRadius - innerRadius);
        depthMap[y*width + x] = t * t;   // 平方缓出, 过渡更自然
      }
    }
  }
  return depthMap;
}
```

### 10.5 散景渲染 (亮度阈值+卷积)

```typescript
// 仅对亮度 > threshold 的像素应用散景卷积核
function renderBokeh(imageData: ImageData, kernel: Float32Array, threshold: number, intensity: number): ImageData {
  const kernelSize = Math.sqrt(kernel.length);
  const radius = Math.floor(kernelSize / 2);
  for (let y = radius; y < height - radius; y++) {
    for (let x = radius; x < width - radius; x++) {
      const idx = (y*width + x)*4;
      const luminance = 0.299*data[idx] + 0.587*data[idx+1] + 0.114*data[idx+2];
      if (luminance > threshold * 255) {
        // 卷积叠加
        let r=0, g=0, b=0;
        for (let ky = -radius; ky <= radius; ky++) {
          for (let kx = -radius; kx <= radius; kx++) {
            const nIdx = ((y+ky)*width + (x+kx))*4;
            const w = kernel[(ky+radius)*kernelSize + (kx+radius)];
            r += data[nIdx]*w; g += data[nIdx+1]*w; b += data[nIdx+2]*w;
          }
        }
        result[idx]=clamp(data[idx]+(r-data[idx])*intensity);
        result[idx+1]=clamp(data[idx+1]+(g-data[idx+1])*intensity);
        result[idx+2]=clamp(data[idx+2]+(b-data[idx+2])*intensity);
      }
    }
  }
}
```

### 11.3 单应性矩阵求解 (DLT算法)

```typescript
/**
 * DLT (Direct Linear Transform) 求解单应性矩阵
 * 4对对应点 (src→dst) → 3x3 单应性矩阵 H
 * 使得 dst ~ H * src (齐次坐标)
 */
function computeHomography(
  srcPoints: [Point2D, Point2D, Point2D, Point2D],
  dstPoints: [Point2D, Point2D, Point2D, Point2D]
): HomographyMatrix {
  // 构建 8x9 矩阵 A, 每对点提供2个方程
  const A: number[] = [];
  for (let i = 0; i < 4; i++) {
    const { x: sx, y: sy } = srcPoints[i];
    const { x: dx, y: dy } = dstPoints[i];
    A.push(-sx, -sy, -1, 0, 0, 0, sx*dx, sy*dx, dx);
    A.push(0, 0, 0, -sx, -sy, -1, sx*dy, sy*dy, dy);
  }
  // SVD 分解 → 最小奇异值对应的右奇异向量 = H 的 9 个元素
  return solveHomographySVD(A);
}

// 应用单应性变换
function applyHomography(point: Point2D, H: HomographyMatrix): Point2D {
  const [h00, h01, h02, h10, h11, h12, h20, h21, h22] = H;
  const w = h20*point.x + h21*point.y + h22;
  return {
    x: (h00*point.x + h01*point.y + h02) / w,
    y: (h10*point.x + h11*point.y + h12) / w,
  };
}
```

```typescript
// k1 控制主畸变, k2 自动 = -0.5 * k1
function correctRadialDistortion(imageData: ImageData, k1: number): ImageData {
  const k2 = -0.5 * k1; // 自动推导
  const cx = width / 2, cy = height / 2;
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      // 归一化到 [-1, 1]
      const nx = (x - cx) / cx, ny = (y - cy) / cy;
      const r2 = nx*nx + ny*ny;
      // 畸变模型: r_distorted = r * (1 + k1*r² + k2*r⁴)
      const factor = 1 + k1 * r2 + k2 * r2 * r2;
      const srcX = cx + (x - cx) * factor;
      const srcY = cy + (y - cy) * factor;
      // 双线性插值
      result[y*width + x] = bilinearInterpolate(imageData, srcX, srcY);
    }
  }
}
```

## 十二、功能 11: 颗粒效果 (YP-09-275)

### 12.1 功能概述

为图片添加胶片颗粒(Grain)纹理。多尺度颗粒(细/中/粗3层, Box-Muller高斯噪点+空间域叠加)、亮度加权分布(暗部/中间调/高光三段 smoothstep 平滑蒙版, 3个独立滑块0-100)、单色/彩色颗粒(单色=RGB统一亮度颗粒; 彩色=70%相关+30%独立通道模型)、4个经典胶片预设(Tri-X 400/HP5+ 400/Portra 800/Delta 3200)、4种混合模式(overlay/soft-light/hard-light/add)、种子随机(mulberry32)可复现。

### 12.2 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 生成算法 | 高斯噪点(Box-Muller) + 亮度加权 + 多尺度叠加 | 自然度高+性能好+可控性强 |
| 颗粒颜色 | 相关RGB (70%共享+30%独立) | 模拟真实彩色负片(同银盐簇影响多感光层) |
| 亮度分段 | smoothstep平滑蒙版+3滑块(暗/中/高) | 直观(Lightroom经典做法)+无边界跳跃 |
| 多尺度 | 空间域3层(全分辨率+50%降采样放大+25%降采样) | 质量高+避免FFT频域复杂度 |
| 颗粒偏压 | 负偏压(以变暗为主) | 真实胶片颗粒是银盐阻挡光线→"减法"效果 |

### 12.3 颗粒混合流程

```
原始 ImageData
  → 提取亮度图 (Y = 0.299R + 0.587G + 0.114B)
  → 构建亮度权重LUT (256级, smoothstep 暗部0-85/中间调85-170/高光170-255)
  → 初始化种子随机数 (mulberry32, seed = userSeed or random)
  → 生成三层颗粒:
      细颗粒层: 全分辨率高斯噪点 × fineWeight
      中颗粒层: 50%分辨率高斯噪点 × midWeight → 双线性放大
      粗颗粒层: 25%分辨率高斯噪点 × coarseWeight → 放大
  → 三层叠加: grain_total = fine + mid + coarse
  → 逐像素: 亮度权重LUT查表 → 该像素颗粒量
  → 颗粒类型: 单色(RGB统一加grain) / 彩色(70%相关+30%独立RGB)
  → 混合模式 (overlay/soft-light/hard-light/add)
  → Clamp 0-255 → 输出
```

```typescript
  const { shadows, midtones, highlights, transitionWidth } = this.config.distribution;
  for (let i = 0; i < 256; i++) {
    const s = smoothstep(85 - tw/2, 85 + tw/2, i);   // 暗→中
    const h = smoothstep(170 - tw/2, 170 + tw/2, i);  // 中→高
    const wShadow = (1 - s) * (shadows / 100);
    const wMid = s * (1 - h) * (midtones / 100);
    const wHigh = h * (highlights / 100);
    this.lumaWeights[i] = Math.max(0, Math.min(1, wShadow + wMid + wHigh));
  }
}
```

## 十三、功能 12: 漏光效果 (YP-09-276)

### 13.1 功能概述

模拟复古相机漏光(Light Leak)效果。8种预设漏光图案(4角: 左上/右上/左下/右下, 2边: 上边缘/左边缘, 1多角: 左上+右下, 1齿孔: 左边缘3点状)、6种颜色预设(暖橙#FF8C42·灯丝灯泡/金黄#FFD700·暖光/红#FF3B3B·暗房安全灯/天蓝#87CEEB·日光/青#00CED1·荧光灯/品红#FF69B4·创意) + 自定义颜色、可调强度(0-100)/位置/旋转(0-360°)/缩放(0.5-2.0)、4种混合模式(Screen默认/Overlay/Soft-Light/Add)、多层漏光支持(图层的增删+独立显隐)。

### 13.2 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 图案生成 | 混合方案(程序化渐变+sin哈希噪声扰动+方向衰减) | 灵活(参数化)+自然(不规则性) |
| 图案分类 | 4类8种(角/边/多角/齿孔) | 覆盖95%漏光场景, 配合位置/旋转可衍生无限变化 |
| 颜色控制 | 单色+6种预设色温 | 真实漏光是单一光源, 单色+渐变透明度已产生丰富变化 |
| 混合模式 | 4种用户可选(Screen默认) | Screen模拟物理光叠加 `1-(1-a)(1-b)`, 保护高光细节 |

### 13.3 漏光生成+混合流程

```
原始 ImageData
  → 遍历漏光图层 (支持多层)
  → 获取当前图层配置: 预设图案+颜色+强度+位置+角度+混合模式
  → 程序化生成漏光蒙版:
      - 根据预设类型绘制基础光形 (Canvas径向/线性/多径向渐变)
      - 叠加sin哈希噪声扰动 (模拟光的不均匀性, 仅在有光区域)
      - 应用方向性衰减 (光从边缘向内部衰减, 投影公式)
      - 根据位置/角度/缩放变换 (Canvas translate+rotate+scale)
  → 逐像素: 漏光值 = 蒙版 × 强度 × 颜色
  → 混合模式融合: Screen/Overlay/Soft-Light/Add
  → 写入输出 ImageData
  → 下一图层 (重复)
  → 渲染到 Canvas
```

### 13.5 混合模式公式

```typescript
function blend(base: number, blend: number, mode: LeakBlendMode): number {
  switch (mode) {
    case 'screen':     return 255 * (1 - (1-base/255)*(1-blend/255)); // 物理光叠加
    case 'overlay':    return base<128 ? 2*base*blend/255 : 255-2*(255-base)*(255-blend)/255;
    case 'soft-light': return base + (2*blend/255 - 1)*(base - base*base/255);
    case 'add':        return base + blend; // 直接加法, 最强光效
  }
}
```

## 十四、功能 13: LUT 滤镜 (YP-09-277)

### 14.1 功能概述

3D LUT (Look-Up Table/颜色查找表) 滤镜。支持导入 .cube/.3dl 文件(行业标准格式, DaVinci Resolve/Premiere/Photoshop通用)、33³网格三线性插值引擎、8种内置程序化LUT预设(4分类: 电影/怀旧/情绪/黑白)、LUT强度控制(0-100%线性LERP混合)、导出当前LUT为.cube文件(可在专业软件中重用)、文件格式验证。

### 14.2 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| LUT网格大小 | 统一 33³ (35937个RGB三元组) | 行业标准, 8级间隔三线性插值精度, 视觉上连续 |
| 颜色空间 | sRGB 直接映射 | 兼容绝大多数免费LUT, 0.2d预算可行, 非电影母版场景足够 |
| 内置预设 | 程序化公式动态生成LUT | 体积小(~2KB代码 vs ~3.2MB静态数据), 可微调参数 |
| 强度控制 | 逐像素LERP线性混合 | `output = original + (lut_mapped - original) × intensity` |
| 大LUT(65³) | 使用Worker解析, >5MB拒绝 | 避免阻塞主线程和内存压力 |

### 14.3 .cube 文件格式解析

```typescript
class CubeParser {
  static parse(content: string, title?: string): Lut3D {
    const lines = content.split('\n').map(l => l.trim()).filter(l => l && !l.startsWith('#'));
    let size: LutSize = 33;
    let domainMin: [number,number,number] = [0,0,0];
    let domainMax: [number,number,number] = [1,1,1];
    const rgbValues: number[] = [];

    for (const line of lines) {
      const parts = line.split(/\s+/);
      if (line.startsWith('TITLE'))       lutTitle = line.replace('TITLE ','').replace(/"/g,'');
      else if (line.startsWith('LUT_3D_SIZE')) size = parseInt(parts[1],10); // 17/33/65
      else if (line.startsWith('DOMAIN_MIN')) domainMin = [parseFloat(parts[1]),...];
      else if (line.startsWith('DOMAIN_MAX')) domainMax = [parseFloat(parts[1]),...];
      else if (/^-?\d/.test(line)) rgbValues.push(parseFloat(parts[0]), parseFloat(parts[1]), parseFloat(parts[2]));
    }
    // 验证数据量: size³ × 3
    const expected = size * size * size * 3;
    if (rgbValues.length < expected) throw new Error(`LUT数据不完整: 期望${expected}个值, 实际${rgbValues.length}`);
    return { size, title: lutTitle, data: new Float32Array(rgbValues.slice(0, expected)), domainMin, domainMax };
  }
}
```

### 14.4 三线性插值引擎

```typescript
function trilinearLookup(r: number, g: number, b: number, data: Float32Array, size: number) {
  const maxIdx = size - 1;
  // 将 [0,1] 映射到 [0, size-1]
  const rf = r * maxIdx, gf = g * maxIdx, bf = b * maxIdx;
  const r0=Math.floor(rf), g0=Math.floor(gf), b0=Math.floor(bf);
  const r1=Math.min(r0+1,maxIdx), g1=Math.min(g0+1,maxIdx), b1=Math.min(b0+1,maxIdx);
  const dr=rf-r0, dg=gf-g0, db=bf-b0;

  // 获取8个角点
  const c000=getLutValue(data,size,r0,g0,b0); const c001=getLutValue(data,size,r0,g0,b1);
  const c010=getLutValue(data,size,r0,g1,b0); const c011=getLutValue(data,size,r0,g1,b1);
  const c100=getLutValue(data,size,r1,g0,b0); const c101=getLutValue(data,size,r1,g0,b1);
  const c110=getLutValue(data,size,r1,g1,b0); const c111=getLutValue(data,size,r1,g1,b1);

  // 沿R轴插值(4对) → 沿G轴(2对) → 沿B轴(1对)
  const c00=lerpRGB(c000,c100,dr); const c01=lerpRGB(c001,c101,dr);
  const c10=lerpRGB(c010,c110,dr); const c11=lerpRGB(c011,c111,dr);
  const c0=lerpRGB(c00,c10,dg);    const c1=lerpRGB(c01,c11,dg);
  return lerpRGB(c0,c1,db);
}
```

```typescript
// 每像素: output = original + (lut_mapped - original) × intensity/100
apply(imageData: ImageData, intensity?: number): ImageData {
  const intensityVal = (intensity ?? this.intensity) / 100;
  for (let py = 0; py < h; py++) {
    for (let px = 0; px < w; px++) {
      const mapped = this.trilinearLookup(r/255, g/255, b/255, lutData, lutSize);
      dst[idx]   = clamp((r) + (mapped.r*255 - r) * intensityVal);
```
