### 1.2 批量处理策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 串行逐张 | 一次一张, 内存最低 | 需要精确进度+用户可中途取消 |
| 分片并行(默认) | 4 Worker 并行池, 平衡速度与内存 | 大部分批量场景 |
| 流式处理 | 处理完一张立即释放, 不在内存累积 | 超大批量(100+) |

**Worker池管理**:
- 池大小: `Math.min(4, navigator.hardwareConcurrency || 4)`
- 获取: 预创建4个Worker, 空闲时分配
- 释放: 任务完成后归还池中
- 销毁: 池满时多余的Worker.terminate()
- 取消: `worker.terminate()` + 清理中间Blob缓存

## 二、功能 1: 图片压缩与优化 (YP-09-157)

### 2.1 功能概述

客户端本地图片压缩工具，全流程无网络传输。支持4种输出格式(JPEG/PNG/WebP/AVIF)、质量滑块(0-100)+数值输入联动、压缩前后大小对比(原始/压缩后/压缩率/节省字节数)、批量压缩(Worker池最多3并发)、拖拽界面、EXIF选择性保留(默认剥离所有/可选保留日期和方向/始终剥离GPS)。

### 2.2 设计决策

| 决策 | 选项A | 选项B | 选择 | 理由 |
|------|------|------|------|------|
| 压缩路径 | 主线程Canvas | Web Worker | **混合(小图主线程+大图Worker)** | 5MB阈值, 小图<100ms主线程OK |
| 格式支持 | JPEG+PNG | +WebP+AVIF | **全格式(渐进支持)** | 检测浏览器能力, 不支持时灰显 |
| 质量默认 | 统一80 | 按格式差异化 | **JPEG80/WebP75/AVIF60** | 各格式质量参数含义不同 |
| EXIF | 全部剥离 | 选择性保留 | **默认剥离+可选保留** | 隐私优先, 始终剥离GPS |
| 输出格式 | 保持原格式 | WebP推荐 | **保持原格式+标注推荐WebP** | 减少认知负担+引导高效格式 |
| 批量下载 | 逐个弹窗 | ZIP打包 | **ZIP+逐个按钮** | ZIP方便一键, 逐个适合提取 |

### 2.3 核心服务实现

```typescript
class CompressService {
  private workerPool: Worker[] = [];
  private readonly MAX_CONCURRENCY = 3;
  private readonly LARGE_IMAGE_THRESHOLD = 5 * 1024 * 1024; // 5MB

  async compressImage(file: File, options: CompressOptions): Promise<CompressResult> {
    // 1. 读取EXIF (可选)
    const exif = options.preserveEXIF ? await this.readEXIF(file) : undefined;

    // 2. 计算目标尺寸 (保持宽高比)
    const bitmap = await createImageBitmap(file);
    const { width, height } = this.calculateDimensions(
      bitmap.width, bitmap.height, options.maxWidth, options.maxHeight
    );

    // 3. 选择压缩路径
    let compressedBlob: Blob;
    if (file.size >= this.LARGE_IMAGE_THRESHOLD) {
      compressedBlob = await this.compressInWorker(bitmap, options, width, height);
    } else {
      compressedBlob = await this.compressInMainThread(bitmap, options, width, height);
    }

    return {
      original: { file, size: file.size, width: bitmap.width, height: bitmap.height, format: file.type },
      compressed: { blob: compressedBlob, size: compressedBlob.size, width, height, format: options.format },
      ratio: compressedBlob.size / file.size,
      saved: file.size - compressedBlob.size,
      exif,
    };
  }

  private async compressInMainThread(bitmap: ImageBitmap, options: CompressOptions, w: number, h: number): Promise<Blob> {
    const canvas = document.createElement('canvas');
    canvas.width = w; canvas.height = h;
    const ctx = canvas.getContext('2d')!;
    if (options.format === 'jpeg') { ctx.fillStyle = '#FFFFFF'; ctx.fillRect(0, 0, w, h); } // JPEG透明→白底
    ctx.drawImage(bitmap, 0, 0, w, h);
    return new Promise((resolve, reject) => {
      canvas.toBlob(blob => blob ? resolve(blob) : reject(new Error('编码失败')), mimeType, options.quality/100);
    });
  }

  async compressBatch(files: File[], options: CompressOptions, onProgress?: (done:number, total:number) => void): Promise<CompressResult[]> {
    const results: CompressResult[] = [];
    let completed = 0;
    const processNext = async (): Promise<void> => {
      if (queue.length === 0) return;
      const file = queue.shift()!;
      try { results.push(await this.compressImage(file, options)); }
      catch (err) { console.error(`${file.name}压缩失败:`, err); } // 单张失败不影响批次
      completed++; onProgress?.(completed, files.length);
      return processNext();
    };
    // 并发控制
    const workers = Array(Math.min(this.MAX_CONCURRENCY, files.length)).fill(null).map(() => processNext());
    await Promise.all(workers);
    return results;
  }
}
```

### 2.4 格式检测

```typescript
static getSupportedFormats(): OutputFormat[] {
  const canvas = document.createElement('canvas');
  canvas.width = 1; canvas.height = 1;
  const checkFormat = (mime: string): boolean => {
    const dataUrl = canvas.toDataURL(mime);
    return dataUrl.startsWith(`data:${mime}`);
  };
  const formats: OutputFormat[] = ['jpeg', 'png'];
  if (checkFormat('image/webp')) formats.push('webp');
  if (checkFormat('image/avif')) formats.push('avif');
  return formats;
}
```

### 4.4 差异叠加模式

```typescript
// highlight changes: 高亮显示压缩后的像素差异
function renderDiff(original: ImageData, compressed: ImageData, threshold: number): ImageData {
  for (let i = 0; i < original.data.length; i += 4) {
    const dr = Math.abs(original.data[i] - compressed.data[i]);
    const dg = Math.abs(original.data[i+1] - compressed.data[i+1]);
    const db = Math.abs(original.data[i+2] - compressed.data[i+2]);
    const diff = (dr + dg + db) / 3;
    if (diff > threshold) {
      // 差异像素用红色高亮
      result[i]=255; result[i+1]=0; result[i+2]=0;
    } else {
      // 相同像素用灰度(亮度)
      const luma = 0.299*compressed.data[i] + 0.587*compressed.data[i+1] + 0.114*compressed.data[i+2];
      result[i]=result[i+1]=result[i+2]=luma;
    }
  }
}
```

## 五、功能 4: 批量重命名 (YP-09-227)

### 5.1 功能概述

模式化批量重命名工具。支持前缀+日期+编号+后缀自由组合。EXIF日期自动提取(三级fallback: EXIF拍摄日期 → 文件修改日期 → 当前系统日期)、5种排序方式(EXIF日期/添加顺序/名称/文件修改日期/大小)、重名冲突检测+推荐备选名称、撤销重命名(恢复原始文件名)、命名预设保存/加载(3个内置+用户自定义)。

### 5.2 命名模式

```
{prefix}{date}{numbering}{suffix}.{extension}
示例: trip-20260115-001-edit.jpg
```

| 组件 | 配置 | 示例 |
|------|------|------|
| prefix | 用户输入, 可选 | `trip-` |
| date | 5种日期格式可选(YYYYMMDD/YYYY-MM-DD/YYMMDD/MMDD/YYYY-MM) | `20260115` |
| numbering | 起始值+步长+填充宽度 | `001` (start=1, step=1, padding=3) |
| suffix | 用户输入, 可选 | `-edit` |
| extension | 保持原始扩展名不变 | `.jpg` |

### 5.3 EXIF日期三级Fallback


```typescript
async function generatePDF(images: ImageFile[], config: PDFConfig): Promise<Blob> {
  const { jsPDF } = await import('jspdf');
  const doc = new jsPDF({
    orientation: config.orientation, // 'portrait' | 'landscape'
    unit: 'mm',
    format: config.pageSize === 'auto' ? undefined : config.pageSize, // 'a4' | 'letter' | [w,h]
  });

  const pageWidth = doc.internal.pageSize.getWidth();
  const pageHeight = doc.internal.pageSize.getHeight();
  const marginX = config.marginLeft + config.marginRight;
  const marginY = config.marginTop + config.marginBottom;
  const contentW = pageWidth - marginX;
  const contentH = pageHeight - marginY;

  for (let i = 0; i < images.length; i++) {
    if (i > 0) doc.addPage();

    const img = images[i];
    const imgW = img.width, imgH = img.height;
    let drawW: number, drawH: number;

    switch (config.fitMode) {
      case 'fit': {  // 等比适应
        const scale = Math.min(contentW / imgW, contentH / imgH);
        drawW = imgW * scale; drawH = imgH * scale;
        break;
      }
      case 'fill': { // 填充
        const scale = Math.max(contentW / imgW, contentH / imgH);
        drawW = imgW * scale; drawH = imgH * scale;
        break;
      }
      default: drawW = imgW; drawH = imgH; break;
    }

    const x = config.marginLeft + (contentW - drawW) / 2;
    const y = config.marginTop + (contentH - drawH) / 2;

    const dataUrl = await canvasToDataURL(img, config.quality);
    doc.addImage(dataUrl, 'JPEG', x, y, drawW, drawH);
  }

  return doc.output('blob');
}
```

```typescript
function renderTiledWatermark(ctx: CanvasRenderingContext2D, watermark: Watermark, spacingX: number, spacingY: number) {
  ctx.save();
  ctx.globalAlpha = watermark.opacity;
  const angle = (watermark.rotation * Math.PI) / 180;

  for (let y = spacingY; y < canvas.height; y += watermark.height + spacingY) {
    for (let x = spacingX; x < canvas.width; x += watermark.width + spacingX) {
      ctx.save();
      ctx.translate(x + watermark.width/2, y + watermark.height/2);
      ctx.rotate(angle);
      if (watermark.type === 'text') {
        ctx.font = `${watermark.fontSize}px ${watermark.fontFamily}`;
        ctx.fillStyle = watermark.color;
        ctx.textAlign = 'center';
        ctx.fillText(watermark.text, 0, 0);
      } else {
        ctx.drawImage(watermark.image, -watermark.width/2, -watermark.height/2, watermark.width, watermark.height);
      }
      ctx.restore();
    }
  }
  ctx.restore();
}
```

### 9.3 输出大小估算器

```typescript
class SizeEstimator {
  estimate(originalSize: number, originalFormat: string, targetFormat: OutputFormat, quality: number): number {
    const formatRatio: Record<OutputFormat, number> = {
      png: 1.0,       // 无损, 保持
      jpeg: 0.15 + (1-quality)*0.3,
      webp: 0.10 + (1-quality)*0.25,
      avif: 0.06 + (1-quality)*0.2,
      bmp: originalSize * 3,  // 无压缩, 可能增大
      tiff: originalSize * 3,
    };
    return Math.round(originalSize * formatRatio[targetFormat]);
  }
}
```

### 11.4 模板解析器实现

```typescript
class TemplateParser {
  // 解析模板 "{date}_{camera|Unknown}_{seq:04d}" → Token数组
  static parse(template: string): TemplateToken[] {
    const tokens: TemplateToken[] = [];
    const regex = /\{([^}]+)\}/g;
    let lastIndex = 0, match: RegExpExecArray | null;
    while ((match = regex.exec(template)) !== null) {
      if (match.index > lastIndex) tokens.push({ type: 'text', value: template.slice(lastIndex, match.index) });
      const fieldExpr = match[1];
      // 解析 colon(:)和pipe(|)
      const colonIdx = fieldExpr.indexOf(':'), pipeIdx = fieldExpr.indexOf('|');
      const fieldName = fieldExpr.slice(0, colonIdx > -1 ? colonIdx : pipeIdx > -1 ? pipeIdx : fieldExpr.length);
      let format: string | undefined, defaultVal: string | undefined;
      if (colonIdx > -1) {
        const afterColon = fieldExpr.slice(colonIdx + 1);
        const pipeInFormat = afterColon.indexOf('|');
        format = pipeInFormat > -1 ? afterColon.slice(0, pipeInFormat) : afterColon;
        if (pipeInFormat > -1) defaultVal = afterColon.slice(pipeInFormat + 1);
      } else if (pipeIdx > -1) { defaultVal = fieldExpr.slice(pipeIdx + 1); }
      tokens.push({ type: 'field', value: fieldName, format, default: defaultVal });
      lastIndex = match.index + match[0].length;
    }
    if (lastIndex < template.length) tokens.push({ type: 'text', value: template.slice(lastIndex) });
    return tokens;
  }

  // 渲染Token数组+EXIF数据→最终文件名
  static render(tokens: TemplateToken[], exif: ExifFields, baseName: string, seq: number, seqConfig: SequenceConfig): string {
    let result = '';
    for (const token of tokens) {
      if (token.type === 'text') result += token.value;
      else result += this.resolveField(token.value, token.format, token.default || 'Unknown', exif, baseName, seq, seqConfig);
    }
    return result.replace(/[<>:"/\\|?*]/g, '_'); // 清理非法字符
  }
}
```

```typescript
// 支持纯文本和正则两种模式, 大小写敏感可选, 多规则顺序执行
function applyFindReplace(baseName: string, rules: FindReplaceRule[]): string {
  let result = baseName;
  for (const rule of rules) {
    if (rule.useRegex) {
      const flags = rule.caseSensitive ? 'g' : 'gi';
      result = result.replace(new RegExp(rule.find, flags), rule.replace);
    } else {
      // 纯文本模式, 手动实现支持大小写敏感开关
      const search = rule.caseSensitive ? rule.find : rule.find.toLowerCase();
      const target = rule.caseSensitive ? result : result.toLowerCase();
      let idx = 0, output = '';
      while (idx < target.length) {
        const found = target.indexOf(search, idx);
        if (found === -1) { output += result.slice(idx); break; }
        output += result.slice(idx, found) + rule.replace;
        idx = found + rule.find.length;
      }
      result = output;
    }
  }
  return result || 'Untitled'; // 空则使用默认名称
}
```

```typescript
function calculateDrawParams(ow: number, oh: number, tw: number, th: number, mode: FitMode) {
  switch (mode) {
    case 'cover': {
      const scale = Math.max(tw/ow, th/oh);
      const sw = tw/scale, sh = th/scale;
      return { sx: (ow-sw)/2, sy: (oh-sh)/2, sw, sh, dx: 0, dy: 0, dw: tw, dh: th };
    }
    case 'contain': {
      const scale = Math.min(tw/ow, th/oh);
      const dw = ow*scale, dh = oh*scale;
      return { sx: 0, sy: 0, sw: ow, sh: oh, dx: (tw-dw)/2, dy: (th-dh)/2, dw, dh };
    }
    case 'stretch':
      return { sx: 0, sy: 0, sw: ow, sh: oh, dx: 0, dy: 0, dw: tw, dh: th };
  }
}
```

```typescript
class CropRegionCalculator {
  calculate(ow: number, oh: number, config: BatchCropConfig): CropRegion {
    let cropWidth: number, cropHeight: number;
    if (config.mode === 'ratio' && config.ratio) {
      const targetRatio = config.ratio.width / config.ratio.height;
      const imageRatio = ow / oh;
      if (imageRatio > targetRatio) { cropHeight = oh; cropWidth = Math.round(oh * targetRatio); }
      else { cropWidth = ow; cropHeight = Math.round(ow / targetRatio); }
    } else if (config.mode === 'size' && config.targetWidth && config.targetHeight) {
      const targetRatio = config.targetWidth / config.targetHeight;
      const imageRatio = ow / oh;
      if (imageRatio > targetRatio) { cropHeight = oh; cropWidth = Math.round(oh * targetRatio); }
      else { cropWidth = ow; cropHeight = Math.round(ow / targetRatio); }
    }
    const { sx, sy } = this.calculatePosition(ow, oh, cropWidth, cropHeight, config.position);
    return { sx, sy, sw: cropWidth, sh: cropHeight };
  }

  private calculatePosition(ow: number, oh: number, cw: number, ch: number, pos: CropPosition): {sx:number; sy:number} {
    switch (pos) {
      case 'top-left':      return { sx: 0, sy: 0 };
      case 'top-center':    return { sx: (ow-cw)/2, sy: 0 };
      case 'top-right':     return { sx: ow-cw, sy: 0 };
      case 'middle-left':   return { sx: 0, sy: (oh-ch)/2 };
      case 'center':        return { sx: (ow-cw)/2, sy: (oh-ch)/2 };
      case 'middle-right':  return { sx: ow-cw, sy: (oh-ch)/2 };
      case 'bottom-left':   return { sx: 0, sy: oh-ch };
      case 'bottom-center': return { sx: (ow-cw)/2, sy: oh-ch };
      case 'bottom-right':  return { sx: ow-cw, sy: oh-ch };
    }
  }

  // 人脸检测调整: 移动裁剪中心到人脸中心, 边界约束不超出图片
  adjustToFaceCenter(ow: number, oh: number, cw: number, ch: number, faceCenter: {x:number;y:number}): CropRegion {
    let sx = faceCenter.x - cw/2, sy = faceCenter.y - ch/2;
    sx = Math.max(0, Math.min(sx, ow - cw));
    sy = Math.max(0, Math.min(sy, oh - ch));
    return { sx, sy, sw: cw, sh: ch };
  }
}
```

```typescript
async function processItem(item: BatchRotateItem): Promise<void> {
  // 有效旋转角度 = EXIF基准旋转 + 用户旋转
  item.effectiveAngle = ((baseRotation + userAngle) % 360 + 360) % 360;

  // 计算旋转后画布尺寸
  const normAngle = item.effectiveAngle;
  const swapDimensions = normAngle === 90 || normAngle === 270;
  let cw = swapDimensions ? img.naturalHeight : img.naturalWidth;
  let ch = swapDimensions ? img.naturalWidth : img.naturalHeight;
  if (normAngle !== 0 && normAngle !== 90 && normAngle !== 180 && normAngle !== 270) {
    // 自定义角度: 包围盒
    const rad = (normAngle * Math.PI) / 180;
    cw = Math.ceil(img.naturalWidth * Math.abs(Math.cos(rad)) + img.naturalHeight * Math.abs(Math.sin(rad)));
    ch = Math.ceil(img.naturalWidth * Math.abs(Math.sin(rad)) + img.naturalHeight * Math.abs(Math.cos(rad)));
  }

  // Canvas变换
  const canvas = document.createElement('canvas');
  canvas.width = cw; canvas.height = ch;
  const ctx = canvas.getContext('2d')!;
  ctx.fillStyle = config.backgroundColor; // 默认白色, PNG可选透明
  ctx.fillRect(0, 0, cw, ch);

  ctx.save();
  ctx.translate(cw/2, ch/2);                         // 移到画布中心
  ctx.rotate((item.effectiveAngle * Math.PI) / 180); // 旋转
  // 翻转
  const sx = (config.flipMode === 'horizontal' || config.flipMode === 'both') ? -1 : 1;
  const sy = (config.flipMode === 'vertical' || config.flipMode === 'both') ? -1 : 1;
  ctx.scale(sx, sy);
  ctx.drawImage(img, -img.naturalWidth/2, -img.naturalHeight/2); // 居中绘制
  ctx.restore();

  item.resultBlob = await new Promise((resolve, reject) => {
    canvas.toBlob(b => b ? resolve(b) : reject(new Error('导出失败')), mimeType, config.jpegQuality);
  });
}
```

### 14.4 自定义角度 — 包围盒计算

```
非90度倍数旋转时, 画布需扩展以容纳旋转后的完整图片:

cw = ceil(ow * |cos(θ)| + oh * |sin(θ)|)
ch = ceil(ow * |sin(θ)| + oh * |cos(θ)|)

例如: 4000×3000 旋转45°
cw = ceil(4000×0.707 + 3000×0.707) = ceil(4949) → 注意可能超出浏览器Canvas尺寸限制(通常4096-16384)
```

```typescript
// 仅读前64KB (EXIF通常在JPEG头部)
async function readExifOrientation(file: File): Promise<number> {
  const buffer = await file.slice(0, 65536).arrayBuffer();
  const view = new DataView(buffer);
  if (view.getUint16(0, false) !== 0xFFD8) return 1; // 非JPEG
  // 遍历JPEG段 → 找APP1(0xFFE1) → 解析TIFF IFD → 找tag 0x0112(Orientation)
  let offset = 2;
  while (offset < view.byteLength) {
    const marker = view.getUint16(offset, false); offset += 2;
    if (marker === 0xFFE1) { /* 解析EXIF IFD, 提取Orientation */ }
    offset += view.getUint16(offset, false);
  }
  return 1; // 未找到→默认正常
}
```

| 风险 | 概率 | 影响 | 缓解措施 |

## 十六、回滚策略 (统一)

所有批量处理功能均为独立模块, 回滚方式统一:

| 场景 | 回滚操作 | 影响 |
|------|---------|------|
| 功能严重Bug | 隐藏工具入口(feature flag) | 仅该功能不可用 |
| Worker处理崩溃 | 降级到主线程同步处理(小图)或显示错误提示(大图) | 性能下降但功能可用 |
| ZIP打包失败 | 降级为逐个下载(浏览器多次下载弹窗) | 用户体验下降 |
| AVIF编码异常 | 禁用AVIF选项, 仅保留JPEG/PNG/WebP | 失去AVIF支持 |
| 人脸检测崩溃 | 禁用face-api.js, 仅保留9点位置预设 | 无人脸检测功能 |
| EXIF读取异常 | 禁用自动定向, 仅保留用户手动旋转 | EXIF方向错误需手动修正 |
| 完全移除 | 删除目录和路由, 保留相关单张工具 | 功能完全不可用 |

## 十八、代码审查检查清单 (公共)

- [ ] Worker池大小可配置(默认4, 通过navigator.hardwareConcurrency调整)
- [ ] 每张图片处理完成后立即释放ImageBitmap(`bitmap.close()`)和Canvas(`canvas.width=0`)
- [ ] AVIF编码前检查浏览器支持(`canvas.toBlob`回调Blob type验证)
- [ ] ZIP文件使用STORE压缩方法(图片已压缩, 二次压缩无意义且耗时)
- [ ] 文件夹结构使用`File.webkitRelativePath`(Chrome)或手动路径映射
- [ ] ZIP命名: `{功能名}-YYYYMMDD-HHmmss.zip`
- [ ] 进度条: 当前进度+处理速度(张/秒)+预计剩余时间(ETA)
- [ ] 支持取消操作: 中止Worker并清理中间Blob缓存
- [ ] 错误隔离: 单张失败不影响批次(单独标记error+继续处理其余)
- [ ] 尺寸调整时正确处理EXIF方向(使用`image-orientation: from-image`)
- [ ] JPEG透明背景→自动填充白色(`ctx.fillStyle='#FFF'; ctx.fillRect()`)
- [ ] BMP/TIFF编码器大端序(Big Endian)处理正确
- [ ] 自定义角度包围盒检查Canvas尺寸限制(超过4096时提示)
- [ ] 时间戳格式化: 先替换YYYY再YY(防止YYYY中的YY被二次替换)
- [ ] 冲突检测基于完整文件名(含扩展名), a.jpg vs a.png不算冲突
- [ ] 查找替换后baseName为空→使用"Untitled"兜底
- [ ] 9点位置计算边界约束(sx/sy不能超出图片范围)
- [ ] 人脸检测动态import, 不使用时零包体积开销
