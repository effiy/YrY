# PE-09-101: 个人活动统计条

> 跨项目体验对齐：YiVad Home 有 5 统计卡片（活跃 Issue、今日完成、Bug、逾期、完成率），YiPet 聊天窗口无个人数据总览。通过 YiAi 已有数据（sessions/bugs/knowledge_files）聚合展示。

## 背景

YiVad 首页（`views/home/index.vue`）展示 5 个统计卡片 + 知识动态 + 活动日志 + 工作负载，使用户对项目全局状态一目了然。

YiPet 聊天窗口当前只展示对话列表和消息区域，用户无法感知：
- 自己产生了多少会话
- 知识库有多少文件可用
- 报告了多少 Bug
- 今天的活跃度

这些数据已通过 YiAi `data_service` 存储在 MongoDB，且 YiPet chat store 已加载到内存（`state.sessions`/`state.knowledgeTree`/`state.recentBugs`），只需 UI 展示。

## 范围

**In scope**：
- `StatsBar.vue` 组件 — 紧凑 4 格统计条（会话数/知识文件/Bug 数/今日活跃）
- 集成到 `ChatWindow.vue` 的聊天主区域上方
- 数据源：现有 Pinia store 状态（无需新 API 调用）

**Out of scope**：
- 点击统计卡片跳转到详情页
- 实时轮询更新
- 跨项目聚合（YiVad + YiPet 合并统计）

| 优先级 | 故事 | 验收标准 |
|--------|------|----------|
| P1 | 统计条组件 | 显示会话数、知识文件数、Bug 数（有数据时） |
| P1 | 今日统计 | 显示今日创建的会话数 |
| P2 | 视觉对齐 | 配色方案与 YiVad Home stat cards 一致 |

## 验收标准

- [ ] 聊天窗口打开时，有会话/知识/Bug 数据时显示统计条
- [ ] 无数据时统计条不显示（不占空间）
- [ ] 统计数据来自 YiAi（通过现有 store 数据）
- [ ] 样式与 YiPet 主题一致（使用 `--yp-*` CSS 变量）
