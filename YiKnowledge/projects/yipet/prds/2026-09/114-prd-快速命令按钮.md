# PE-09-114: 空状态快速命令按钮

## 范围

- QuickButtons 新增第二行命令快捷按钮
- 3 个命令：/stats 📊 · /sessions 💬 · /help ❓
- 虚线边框样式区分于提示词按钮

## 效果

```
[🗺 Roadmap] [📋 ADR] [📊 Metrics]
[/stats Stats] [/sessions Sessions] [/help Help]
```
