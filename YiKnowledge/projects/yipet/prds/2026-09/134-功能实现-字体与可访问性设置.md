# YP-09-127: 字体与可访问性设置 — 字号调整、字体族选择、行高字间距、高对比度模式、减弱动画、色盲友好调色板、焦点指示器、设置预览、跨设备同步

> 需求编号：YP-09-127 · 优先级：P2 · 人天：0.3d · 状态：需求已编写
> 依赖：YP-09-26（主题系统）、YP-09-66（设置跨设备同步）、YP-09-83（可访问性增强）、YP-09-120（自定义CSS主题）

## 背景

### 问题陈述

YiPet 当前的聊天窗口和宠物浮层使用固定的字体样式（14px 系统默认字体），未提供任何可访问性相关的视觉调整选项。这导致：

1. **视力障碍用户无法使用**：低视力用户需要更大字号（18-24px）才能舒适阅读，但当前固定 14px 字号对他们是不可用的
2. **阅读障碍用户被忽视**：约 10% 人口有阅读障碍（dyslexia），他们需要特殊字体（如 OpenDyslexic）和更大的行间距来区分字母形状
3. **色觉障碍用户无法区分信息**：约 8% 男性和 0.5% 女性有色觉障碍，当前仅靠颜色传递信息（如绿色=成功、红色=错误）对他们不可用
4. **高对比度需求未满足**：部分用户需要更高的对比度来区分文字和背景，当前部分配色（如浅灰文字）对比度不足
5. **动画敏感用户不适**：前庭功能障碍用户可能因宠物动画而感到眩晕，但扩展未响应系统的 `prefers-reduced-motion` 设置

**核心矛盾**：在 Shadow DOM 样式隔离的架构下，提供一套完整的可访问性设置系统，既要覆盖多种残障类型（视力、色觉、认知、运动），又要保持设置简单直观，不增加普通用户的认知负担。

### 影响范围

| # | 影响 | 严重程度 | 典型场景 |
|---|------|----------|----------|
| 1 | 低视力用户无法阅读聊天内容 | 高 | 老年用户打开聊天窗口，14px 字号完全看不清，放弃使用 |
| 2 | 阅读障碍用户字母混淆 | 中 | 阅读障碍用户看聊天消息时，字母 b/d/p/q 混淆，理解困难 |
| 3 | 色盲用户无法区分状态指示 | 中 | 红绿色盲用户看到绿色成功和红色错误消息，无法区分两者 |
| 4 | 动画敏感用户眩晕 | 中 | 前庭功能障碍用户看到宠物跳动动画，引发眩晕和不适 |
| 5 | 弱视用户在低对比度下阅读困难 | 低 | 浅灰文字在白色背景上，弱视用户需要眯眼才能辨认 |

### 挑战

| 挑战 | 说明 |
|------|------|
| Shadow DOM 字体注入 | 字体族和字号必须穿透 Shadow DOM 边界，且不影响宿主页面样式 |
| 字体资源加载 | 特殊字体（如 OpenDyslexic）需要从 CDN 加载，弱网下可能超时 |
| 色盲模拟验证 | 开发阶段需要模拟不同色盲类型的效果，确保调色板实际可用 |
| 设置实时预览 | 用户调整字号/字体时，聊天窗口需要即时反映变化，不能有闪烁或重排 |
| 与主题系统协调 | 字体设置和主题系统中的颜色变量需要协调，避免冲突（如高对比度模式覆盖主题色） |
| chrome.storage.sync 容量限制 | 同步存储有 100KB 总量限制和 8KB 单项限制，设置需要精简 |

## 二、设计决策

### 决策 1：设置入口位置 — 独立设置页 vs 聊天窗口内嵌 vs Popup 快捷面板

| 选项 | 空间 | 可发现性 | 实时预览 | 实现复杂度 |
|------|------|----------|----------|--------|
| 独立设置页（options page） | 大 | 中 | 需传递到 content | 中 |
| 聊天窗口内嵌设置面板 | 大 | 高 | 直接 | 高 |
| Popup 快捷面板 | 小 | 高 | 需传递到 content | 低 |

**选择：聊天窗口内嵌设置面板为主，Popup 提供快捷开关。** 聊天窗口内嵌面板提供完整的设置控件和实时预览，用户无需离开当前页面即可看到效果。Popup 提供 3 个快捷开关（高对比度、减弱动画、增大字号），方便快速切换。

### 决策 2：字体族选择策略 — 仅系统字体 vs 包含 Web 字体 vs 混合方案

| 选项 | 加载速度 | 字体选择 | 一致性 | 实现复杂度 |
|------|----------|----------|--------|------------|
| 仅系统字体 | 即时 | 少（4-5 种） | 依赖系统 | 低 |
| 仅 Web 字体（Google Fonts） | 慢（需加载） | 多 | 高 | 中 |
| 混合方案（系统字体 + 按需加载阅读障碍字体） | 即时（系统字体）+ 按需（特殊字体） | 适中 | 高 | 中 |

**选择：混合方案。** 默认提供 4 种系统字体族（系统默认、无衬线、衬线、等宽），即时可用。阅读障碍友好字体（OpenDyslexic）作为可选扩展，用户首次选择时从 CDN 异步加载（约 50KB），加载后缓存在 `chrome.storage.local`。不引入 Google Fonts 等第三方 Web 字体以避免隐私问题和加载延迟。

### 决策 3：高对比度模式实现 — 独立主题 vs CSS 滤镜 vs 覆盖 CSS 变量

| 选项 | 效果 | 性能 | 灵活性 | 实现复杂度 |
|------|------|------|--------|------------|
| 独立高对比度主题 | 好 | 高 | 低（固定配色） | 中 |
| CSS `filter: contrast(1.5)` | 中 | 高 | 低（全局应用） | 低 |
| 覆盖 CSS 变量（强制黑白） | 好 | 高 | 中 | 中 |

**选择：覆盖 CSS 变量。** 高对比度模式不是简单的对比度提升，而是需要重新定义颜色方案（黑底白字或白底黑字，去除非必要的灰色调）。通过覆盖 CSS 变量实现：将所有文字颜色强制为纯黑/纯白，背景色强制为纯白/纯黑，边框加粗，链接加下划线。CSS `filter` 方案会影响图片和宠物渲染，不符合需求。

### 决策 4：设置存储与同步策略 — chrome.storage.local vs chrome.storage.sync vs 混合

| 选项 | 跨设备同步 | 容量限制 | 读写速度 | 适用场景 |
|------|-----------|----------|----------|----------|
| chrome.storage.local | 否 | 10MB | 快 | 所有设置 |
| chrome.storage.sync | 是 | 100KB 总量 / 8KB 单项 | 中 | 仅关键设置 |
| 混合（sync 存关键设置，local 存完整配置） | 是 | 不受限 | 快 | 最优 |

**选择：混合方案。** 关键设置（字号、字体族、高对比度开关、减弱动画开关、色盲模式）存储到 `chrome.storage.sync`（约 500B），实现跨设备同步。完整配置（包括自定义字体文件缓存、预览状态等）存储到 `chrome.storage.local`。同步优先级：字号 > 字体族 > 高对比度 > 减弱动画 > 色盲模式。

### 设计决策记录

| 决策 | 选项 A | 选项 B | 选项 C | 选择 | 理由 |
|------|--------|--------|--------|------|------|
| 设置入口 | 独立设置页 | 聊天窗口内嵌 | Popup 快捷面板 | **内嵌面板 + Popup 快捷开关** | 实时预览 + 快速切换 |
| 字体族选择 | 仅系统字体 | Web 字体 | 混合方案 | **混合方案（系统 + 按需 OpenDyslexic）** | 即时可用 + 特殊需求覆盖 |
| 高对比度模式 | 独立主题 | CSS 滤镜 | 覆盖 CSS 变量 | **覆盖 CSS 变量** | 精确控制，不影响图片 |
| 存储策略 | local | sync | 混合 | **混合（关键设置 sync + 完整 local）** | 跨设备同步 + 大容量 |

### 4.2 可访问性管理器

```typescript
// src/content/accessibility/AccessibilityManager.ts (新增)

class AccessibilityManager {
  private settings: AccessibilitySettings;
  private shadowRoot: ShadowRoot;
  private styleElement: HTMLStyleElement;
  private dyslexicFontLoaded = false;

  // 色盲友好调色板（模拟色盲感知颜色）
  private static COLOR_BLIND_PALETTES: Record<ColorBlindMode, ColorBlindPalette> = {
    none: {
      success: '#67C23A', error: '#F56C6C', warning: '#E6A23C',
      info: '#909399', primary: '#4A90D9',
    },
    protanopia: {
      // 红色盲：红色→黄褐，绿色→蓝灰
      success: '#8B9DC3', error: '#C2A34F', warning: '#C2A34F',
      info: '#909399', primary: '#4A90D9',
    },
    deuteranopia: {
      // 绿色盲：绿色→黄褐，红色→黄褐
      success: '#8B9DC3', error: '#C2A34F', warning: '#C2A34F',
      info: '#909399', primary: '#4A90D9',
    },
    tritanopia: {
      // 蓝色盲：蓝色→绿，黄色→粉
      success: '#67C23A', error: '#F56C6C', warning: '#E6A23C',
      info: '#909399', primary: '#4A90D9',
    },
  };

  constructor(shadowRoot: ShadowRoot) {
    this.shadowRoot = shadowRoot;
    this.styleElement = document.createElement('style');
    this.styleElement.id = 'yipet-accessibility';
    this.shadowRoot.appendChild(this.styleElement);
    this.settings = this.getDefaultSettings();
  }

  /**
   * 初始化：加载设置并应用
   */
  async init(): Promise<void> {
    await this.loadSettings();
    this.applyAll();
    this.watchSystemPreferences();
    this.watchSyncChanges();
    this.preloadDyslexicFont();
  }

  /**
   * 加载设置（优先从 sync 读取关键设置，local 读取完整配置）
   */
  private async loadSettings(): Promise<void> {
    const [syncResult, localResult] = await Promise.all([
      chrome.storage.sync.get('yipet_accessibility'),
      chrome.storage.local.get('yipet_accessibility_full'),
    ]);

    const syncSettings = syncResult.yipet_accessibility as AccessibilitySyncSettings | undefined;
    const localSettings = localResult.yipet_accessibility_full as AccessibilitySettings | undefined;

    if (syncSettings) {
      this.settings.font.fontSize = syncSettings.fontSize;
      this.settings.font.fontFamily = syncSettings.fontFamily;
      this.settings.highContrast = syncSettings.highContrast;
      this.settings.reducedMotion = syncSettings.reducedMotion;
      this.settings.colorBlindMode = syncSettings.colorBlindMode;
    }

    if (localSettings) {
      this.settings = { ...this.settings, ...localSettings };
    }
  }

  /**
   * 应用所有可访问性设置
   */
  applyAll(): void {
    this.applyFontSettings();
    this.applyHighContrast();
    this.applyReducedMotion();
    this.applyColorBlindPalette();
    this.applyFocusIndicator();
  }

  /**
   * 应用字体设置
   */
  private applyFontSettings(): void {
    const { font } = this.settings;
    const fontSizePx = FONT_SIZE_MAP[font.fontSize];
    const fontFamily = FONT_FAMILY_MAP[font.fontFamily];

    // 计算衍生字号（相对于基础字号）
    const xs = Math.round(fontSizePx * 0.75);
    const sm = Math.round(fontSizePx * 0.875);
    const lg = Math.round(fontSizePx * 1.125);
    const xl = Math.round(fontSizePx * 1.25);

    this.styleElement.textContent = `
      :host {
        --yp-font-family: ${fontFamily};
        --yp-font-size-base: ${fontSizePx}px;
        --yp-font-size-xs: ${xs}px;
        --yp-font-size-sm: ${sm}px;
        --yp-font-size-md: ${fontSizePx}px;
        --yp-font-size-lg: ${lg}px;
        --yp-font-size-xl: ${xl}px;
        --yp-line-height: ${font.lineHeight};
        --yp-letter-spacing: ${font.letterSpacing}em;
        --yp-font-dyslexic: ${font.fontFamily === 'dyslexic' ? 1 : 0};
      }
    `;

    // 如果选择了阅读障碍字体且未加载，触发加载
    if (font.fontFamily === 'dyslexic' && !this.dyslexicFontLoaded) {
      this.loadDyslexicFont();
    }
  }

  /**
   * 加载 OpenDyslexic 字体
   */
  private async loadDyslexicFont(): Promise<void> {
    try {
      // 检查缓存
      const cached = await chrome.storage.local.get('yipet_font_dyslexic');
      if (cached.yipet_font_dyslexic) {
        this.injectFontFace(cached.yipet_font_dyslexic);
        this.dyslexicFontLoaded = true;
        return;
      }

      // 从 CDN 加载
      const controller = new AbortController();
      const timeoutId = setTimeout(() => controller.abort(), 5000);

      const response = await fetch(
        'https://cdn.jsdelivr.net/npm/open-dyslexic@1.0.3/otf/OpenDyslexic-Regular.otf',
        { signal: controller.signal }
      );
      clearTimeout(timeoutId);

      const fontBuffer = await response.arrayBuffer();
      const base64 = this.arrayBufferToBase64(fontBuffer);

      // 缓存到 local storage
      await chrome.storage.local.set({ yipet_font_dyslexic: base64 });

      this.injectFontFace(base64);
      this.dyslexicFontLoaded = true;
    } catch {
      console.warn('[YiPet] OpenDyslexic 字体加载失败，降级为系统无衬线字体');
      // 降级为系统无衬线字体
      this.styleElement.textContent = this.styleElement.textContent!.replace(
        'var(--yp-font-family)',
        'Arial, Helvetica, sans-serif'
      );
    }
  }

  /**
   * 注入 @font-face 规则
   */
  private injectFontFace(base64: string): void {
    const fontFaceStyle = document.createElement('style');
    fontFaceStyle.textContent = `
      @font-face {
        font-family: 'OpenDyslexic';
        src: url(data:font/otf;base64,${base64}) format('opentype');
        font-weight: normal;
        font-style: normal;
        font-display: swap;
      }
    `;
    this.shadowRoot.appendChild(fontFaceStyle);
  }

  /**
   * 应用高对比度模式
   */
  private applyHighContrast(): void {
    const { highContrast } = this.settings;
    const highContrastStyle = document.createElement('style');
    highContrastStyle.id = 'yipet-high-contrast';

    if (highContrast === 'light-on-dark') {
      highContrastStyle.textContent = `
        :host {
          --yp-bg-primary: #000000 !important;
          --yp-bg-secondary: #1A1A1A !important;
          --yp-bg-tertiary: #2A2A2A !important;
          --yp-text-primary: #FFFFFF !important;
          --yp-text-secondary: #E0E0E0 !important;
          --yp-text-tertiary: #B0B0B0 !important;
          --yp-border-color: #FFFFFF !important;
          --yp-border-light: #444444 !important;
        }
        a, .link, [role="link"] { text-decoration: underline !important; }
        input, textarea, select { border: 2px solid var(--yp-border-color) !important; }
      `;
    } else if (highContrast === 'dark-on-light') {
      highContrastStyle.textContent = `
        :host {
          --yp-bg-primary: #FFFFFF !important;
          --yp-bg-secondary: #F5F5F5 !important;
          --yp-bg-tertiary: #EEEEEE !important;
          --yp-text-primary: #000000 !important;
          --yp-text-secondary: #1A1A1A !important;
          --yp-text-tertiary: #333333 !important;
          --yp-border-color: #000000 !important;
          --yp-border-light: #666666 !important;
        }
        a, .link, [role="link"] { text-decoration: underline !important; }
        input, textarea, select { border: 2px solid var(--yp-border-color) !important; }
      `;
    }

    // 移除旧的高对比度样式
    const existing = this.shadowRoot.getElementById('yipet-high-contrast');
    if (existing) existing.remove();
    if (highContrast !== 'off') {
      this.shadowRoot.appendChild(highContrastStyle);
    }
  }

  /**
   * 应用减弱动画（响应 prefers-reduced-motion）
   */
  private applyReducedMotion(): void {
    const { reducedMotion } = this.settings;
    const shouldReduce = reducedMotion === 'reduce'
      || (reducedMotion === 'auto' && window.matchMedia('(prefers-reduced-motion: reduce)').matches);

    const motionStyle = document.createElement('style');
    motionStyle.id = 'yipet-reduced-motion';

    if (shouldReduce) {
      motionStyle.textContent = `
        :host {
          --yp-pet-animation-speed: 0 !important;
          --yp-transition-duration: 0s !important;
        }
        :host *, :host *::before, :host *::after {
          animation-duration: 0s !important;
          animation-delay: 0s !important;
          transition-duration: 0s !important;
          transition-delay: 0s !important;
        }
        @keyframes yipet-pet-idle { 0%, 100% { transform: none; } }
        @keyframes yipet-pet-walk { 0%, 100% { transform: none; } }
        @keyframes yipet-pet-jump { 0%, 100% { transform: none; } }
      `;
    }

    const existing = this.shadowRoot.getElementById('yipet-reduced-motion');
    if (existing) existing.remove();
    this.shadowRoot.appendChild(motionStyle);
  }

  /**
   * 应用色盲友好调色板
   */
  private applyColorBlindPalette(): void {
    const { colorBlindMode } = this.settings;
    const palette = AccessibilityManager.COLOR_BLIND_PALETTES[colorBlindMode];

    const paletteStyle = document.createElement('style');
    paletteStyle.id = 'yipet-color-blind';
    paletteStyle.textContent = `
      :host {
        --yp-success: ${palette.success} !important;
        --yp-error: ${palette.error} !important;
        --yp-warning: ${palette.warning} !important;
        --yp-info: ${palette.info} !important;
        --yp-primary: ${palette.primary} !important;
      }
    `;

    const existing = this.shadowRoot.getElementById('yipet-color-blind');
    if (existing) existing.remove();
    if (colorBlindMode !== 'none') {
      this.shadowRoot.appendChild(paletteStyle);
    }
  }

  /**
   * 应用焦点指示器自定义
   */
  private applyFocusIndicator(): void {
    const { focusIndicator } = this.settings;
    const focusStyle = document.createElement('style');
    focusStyle.id = 'yipet-focus-indicator';
    focusStyle.textContent = `
      :host {
        --yp-focus-outline-width: ${focusIndicator.outlineWidth}px;
        --yp-focus-outline-color: ${focusIndicator.outlineColor};
        --yp-focus-outline-offset: ${focusIndicator.outlineOffset}px;
      }
      :host *:focus-visible {
        outline: var(--yp-focus-outline-width) solid var(--yp-focus-outline-color) !important;
        outline-offset: var(--yp-focus-outline-offset) !important;
      }
    `;

    const existing = this.shadowRoot.getElementById('yipet-focus-indicator');
    if (existing) existing.remove();
    this.shadowRoot.appendChild(focusStyle);
  }

  /**
   * 监听系统偏好变化
   */
  private watchSystemPreferences(): void {
    const motionQuery = window.matchMedia('(prefers-reduced-motion: reduce)');
    motionQuery.addEventListener('change', (e) => {
      if (this.settings.reducedMotion === 'auto') {
        this.applyReducedMotion();
      }
    });

    const contrastQuery = window.matchMedia('(prefers-contrast: high)');
    contrastQuery.addEventListener('change', (e) => {
      // 如果用户未手动设置高对比度，跟随系统
      if (this.settings.highContrast === 'off' && e.matches) {
        this.settings.highContrast = 'dark-on-light';
        this.applyHighContrast();
      }
    });
  }

  /**
   * 监听跨设备同步变化
   */
  private watchSyncChanges(): void {
    chrome.storage.onChanged.addListener((changes, namespace) => {
      if (namespace === 'sync' && changes.yipet_accessibility) {
        const syncSettings = changes.yipet_accessibility.newValue as AccessibilitySyncSettings;
        if (syncSettings) {
          this.settings.font.fontSize = syncSettings.fontSize;
          this.settings.font.fontFamily = syncSettings.fontFamily;
          this.settings.highContrast = syncSettings.highContrast;
          this.settings.reducedMotion = syncSettings.reducedMotion;
          this.settings.colorBlindMode = syncSettings.colorBlindMode;
          this.applyAll();
        }
      }
    });
  }

  /**
   * 预加载 OpenDyslexic 字体（如果用户之前使用过）
   */
  private async preloadDyslexicFont(): Promise<void> {
    if (this.settings.font.fontFamily === 'dyslexic') {
      await this.loadDyslexicFont();
    }
  }

  /**
   * 更新设置并保存
   */
  async updateSettings(partial: Partial<AccessibilitySettings>): Promise<void> {
    Object.assign(this.settings, partial);

    // 保存到 chrome.storage.local（完整配置）
    await chrome.storage.local.set({ yipet_accessibility_full: this.settings });

    // 保存到 chrome.storage.sync（关键设置）
    const syncSettings: AccessibilitySyncSettings = {
      fontSize: this.settings.font.fontSize,
      fontFamily: this.settings.font.fontFamily,
      highContrast: this.settings.highContrast,
      reducedMotion: this.settings.reducedMotion,
      colorBlindMode: this.settings.colorBlindMode,
    };
    await chrome.storage.sync.set({ yipet_accessibility: syncSettings });

    // 应用变更
    this.applyAll();
  }

  /**
   * 重置为默认设置
   */
  async resetToDefault(): Promise<void> {
    this.settings = this.getDefaultSettings();
    await chrome.storage.local.remove('yipet_accessibility_full');
    await chrome.storage.sync.remove('yipet_accessibility');
    this.applyAll();
  }

  private getDefaultSettings(): AccessibilitySettings {
    return {
      font: {
        fontSize: 'medium',
        fontFamily: 'system',
        lineHeight: 1.5,
        letterSpacing: 0,
      },
      highContrast: 'off',
      reducedMotion: 'auto',
      colorBlindMode: 'none',
      focusIndicator: {
        outlineWidth: 2,
        outlineColor: '#4A90D9',
        outlineOffset: 2,
        mode: 'default',
      },
    };
  }

  private arrayBufferToBase64(buffer: ArrayBuffer): string {
    const bytes = new Uint8Array(buffer);
    let binary = '';
    for (let i = 0; i < bytes.byteLength; i++) {
      binary += String.fromCharCode(bytes[i]);
    }
    return btoa(binary);
  }

  destroy(): void {
    // 清理
  }
}
```

## 九、设计决策记录

### D-01：字体族加载策略

- **问题**：阅读障碍友好字体（OpenDyslexic）是作为内置资源还是按需加载
- **选项**：内置到扩展包（增加 50KB）、按需从 CDN 加载、不提供
- **选择**：按需从 CDN 加载，首次加载后缓存到 `chrome.storage.local`
- **理由**：内置到扩展包会增加所有用户的安装包大小（包括 90% 不需要该字体的用户）。按需加载仅在用户选择时触发，加载后缓存避免重复下载。CDN 不可用时降级为系统无衬线字体。

### D-02：高对比度模式实现方式

- **问题**：高对比度模式通过什么机制实现
- **选项**：独立 CSS 主题、CSS `filter: contrast()`、覆盖 CSS 变量
- **选择**：覆盖 CSS 变量 + 独立样式规则
- **理由**：CSS `filter` 会影响图片和宠物渲染，不符合需求。独立主题需要维护另一套完整的主题配置，维护成本高。覆盖 CSS 变量精确控制颜色，配合独立样式规则（链接下划线、边框加粗）实现完整的高对比度体验。

### D-03：色盲友好模式的实现深度

- **问题**：色盲友好模式是仅调整调色板还是需要完整的色盲模拟渲染
- **选项**：仅调整调色板（4 种预设）、完整色盲模拟（SVG 滤镜）、两者兼有
- **选择**：仅调整调色板（4 种预设），开发阶段提供色盲模拟器
- **理由**：完整色盲模拟（SVG `feColorMatrix` 滤镜）会改变所有颜色包括图片，体验不佳。调整调色板（仅修改状态指示色）更精准且不影响其他视觉元素。开发阶段提供色盲模拟器（基于 Brettel 算法）用于验证调色板效果。

### D-04：设置跨设备同步范围

- **问题**：哪些设置需要跨设备同步
- **选项**：全部同步（sync）、仅关键设置同步（sync + local 混合）、不同步（仅 local）
- **选择**：关键设置同步（字号、字体族、高对比度、减弱动画、色盲模式），完整配置本地存储
- **理由**：`chrome.storage.sync` 有 100KB 总量和 8KB 单项限制。字体缓存文件（50KB base64）无法存入 sync。关键设置（5 个字段，约 500B）覆盖最常用的可访问性需求，跨设备同步可减少用户重复配置。完整配置（含焦点指示器颜色、自定义字体缓存）仅本地存储。
