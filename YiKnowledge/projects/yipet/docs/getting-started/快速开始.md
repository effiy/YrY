# 快速开始

## 环境要求

- **Node.js** >= 16.18.0
- **Chrome** 浏览器 (MV3 支持)
- **YiAi 后端** 必须运行在 \`http://localhost:10086\`

## 安装与启动

\`\`\`bash
cd YiPet

# 安装依赖
npm install

# 构建
npm run build

# 开发模式 (watch)
npm run dev

# 类型检查
npm run typecheck

# 运行测试
npm test
\`\`\`

## 加载扩展

1. 打开 Chrome → \`chrome://extensions/\`
2. 开启"开发者模式"
3. "加载已解压的扩展程序" → 选择 \`dist/\` 目录
