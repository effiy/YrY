# 构建部署

## 构建流程

```bash
npm run build
  → npm run build:cdn        # CDN 资源 (vendor libs, styles, utils)
  → rsbuild build            # popup + background
  → npm run build:chat       # 聊天窗口 (Vue 3 SPA)
  → npm run build:bootstrap  # Content Script (双世界入口)
```

## 构建特性

| 特性 | 说明 |
|------|------|
| 文件名哈希 | 禁用 — MV3 manifest 引用固定文件名 |
| 代码分割 | 禁用 — Service Worker 需要单文件 |
| 自动导入 | Element Plus 组件 + Vue API (unplugin) |
| 构建元数据 | 自动生成 `dist/build-meta.json` (时间戳/版本/env) |
| Manifest 复制 | 自动复制 `manifest.json` 到 `dist/` |

## 构建产物

```
dist/
├── manifest.json            # 扩展清单 (MV3)
├── build-meta.json          # 构建元数据
├── popup.html               # 弹窗页面
├── assets/
│   ├── popup.js             # 弹窗脚本 (皮肤中心)
│   ├── background.js        # Service Worker (命令分发)
│   ├── chat.js              # 聊天窗口 (Vue 3 SPA)
│   └── bootstrap.js         # Content Script (双世界入口)
├── cdn/                     # CDN 资源
│   ├── vendor/              # 第三方库
│   ├── styles/              # 主题样式
│   └── utils/               # 工具函数
└── _locales/                # i18n 消息文件 (en + zh_CN)
```

## 加载扩展

```bash
# 1. 构建
npm run build

# 2. 在 Chrome 中加载
# chrome://extensions/ → 开启"开发者模式" → "加载已解压的扩展程序" → 选择 dist/ 目录

# 3. 开发模式 (监听文件变更)
npm run dev
```

## 开发命令

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发模式 (watch + rebuild) |
| `npm run build` | 完整构建 |
| `npm run build:cdn` | 仅构建 CDN 资源 |
| `npm run build:chat` | 仅构建聊天窗口 |
| `npm run build:bootstrap` | 仅构建 Content Script |
| `npm run test` | 运行测试 (Vitest) |
| `npm run test:watch` | 测试监听模式 |
| `npm run type:check` | TypeScript 类型检查 |

## 版本管理

`manifest.json` 中的 `version` 字段由构建脚本自动更新，`build-meta.json` 记录构建时间戳和 Git commit hash。
