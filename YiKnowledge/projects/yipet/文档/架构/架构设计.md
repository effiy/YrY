# 架构设计

## 整体架构

```
┌─────────────────────────────────────────────────────────┐
│  Popup (Vue 3 + Element Plus)                           │
│  皮肤中心: 角色/颜色/模型选择 → chrome.storage           │
├─────────────────────────────────────────────────────────┤
│  Background Service Worker                              │
│  命令分发 + 消息路由 + chrome.storage 管理              │
├─────────────────────────────────────────────────────────┤
│  Content Script (ISOLATED World)                        │
│  bootstrap.ts → 消息转发 → MAIN World                   │
├─────────────────────────────────────────────────────────┤
│  Chat Window (Vue 3, MAIN World 注入)                   │
│  ChatController → ApiClient → YiAi Backend              │
├─────────────────────────────────────────────────────────┤
│  Floating Pet (MAIN World DOM)                          │
│  overlay.ts → 皮肤环 + 角色图片 + 工具提示               │
└─────────────────────────────────────────────────────────┘
```

## 双世界执行 (Dual-World)

Chrome MV3 扩展在两个隔离的 JavaScript 世界中运行：

| 世界 | 运行环境 | 职责 |
|------|---------|------|
| **ISOLATED World** | Content Script | 消息转发、DOM 注入、bootstrap |
| **MAIN World** | 页面注入 | Chat Window (Vue 3)、Floating Pet (DOM) |

ISOLATED World 通过 `window.postMessage` 与 MAIN World 通信，MAIN World 中的 Vue 实例独立运行，不污染宿主页面。

## 4-Tier API 层

```
ApiClient (fetch 封装)
  ├── 请求拦截: 注入 Token、Content-Type
  ├── RPC 信封: { module_name, method_name, parameters }
  ├── SSE 流式: 解析 text/event-stream
  ├── 错误处理: 指数退避重试 + 状态码映射
  └── 响应解析: StandardResponse → 业务数据
```

## 多入口构建

YiPet 使用 Rsbuild 多入口构建：

| 入口 | 输出 | 目标 |
|------|------|------|
| `popup/` | popup.html | 扩展弹窗 (皮肤中心) |
| `content/` | content.js | Content Script (ISOLATED) |
| `background/` | background.js | Service Worker |
| `chat/` | 注入到 MAIN World | 聊天窗口 (Vue 3 SPA) |
| `overlay/` | 注入到 MAIN World | 浮动宠物 (DOM 操作) |

## 跨项目桥接

| 功能 | 方向 | 机制 | 说明 |
|------|------|------|------|
| 讨论当前页面 | YiPet → YiVad | `window.open` + session key | 将当前页面 URL 作为上下文发送到 YiVad aiChat |
| 讨论 Bug | YiPet → YiVad | 深度链接 | 直接跳转到 Bug 详情页 |
| Bug 报告 | YiPet → YiVad + YiKnowledge | MongoDB `bugs` + 知识库 | 一键提交 Bug 到两个系统 |
| 保存到知识库 | YiPet → YiKnowledge | KnowledgeService.write | 将对话内容保存为知识文件 |

## Chrome MV3 约束

| 约束 | 影响 | 处理 |
|------|------|------|
| Service Worker 生命周期 | 非持久化，空闲时被终止 | 状态持久化到 chrome.storage |
| 禁止远程代码执行 | 不能动态加载外部 JS | 所有代码预打包 |
| Manifest V3 声明 | 权限和 host 声明式配置 | manifest.json 精确声明 |
| chrome.storage 配额 | 10MB (sync) / 无限制 (local) | 大数据使用 local |

## 降级策略

| 场景 | 处理 |
|------|------|
| YiAi 不可达 | API 客户端指数退避重试 (1s → 2s → 4s → ... max 30s) |
| CDN 资源已加载 | 全局存在检查短路 (`window.__YIPET_LOADED__`) |
| 存储配额超限 | 非关键数据写入静默失败，关键数据降级到 localStorage |
| 语言消息缺失 | 回退 en → key 原始值 |
| Chrome MV3 不支持 | 检测 `chrome.runtime` 可用性，优雅降级 |
| Content Script 注入失败 | 重试 3 次，间隔 500ms |
