# 组件分析

## ChatController — 核心状态管理

`src/chat/controller.ts` 是聊天窗口的**唯一状态管理中心** (~3000 行)。使用 `useSyncExternalStore` 模式实现响应式状态：

```ts
// 订阅模式
const state = chatController.getState()
const unsubscribe = chatController.subscribe((newState) => { ... })
```

核心操作：
- `sendMessage(text)` — 发送消息 (Chat/RAG/Agent)
- `regenerateMessageAt(ts)` — 重新生成指定消息
- `branchFromMessage(ts)` — 从指定消息分支对话
- `exportCurrentSessionMarkdown()` — 导出 Markdown
- `summarizeCurrentSession()` — 摘要当前会话
- `openMessageInYiVad(ts)` — 单条消息桥接到 YiVad
- `discussInYiVadAiChat()` — 讨论当前页面
- `previewRagSources(q)` — 预览 RAG 来源
- `decomposeRagQuestion(q)` — 子问题分解
- `openBugReport()` / `confirmBugReport()` — Bug 报告

状态字段：
- `messages: Message[]` — 消息列表
- `mode: 'chat' | 'rag' | 'agent'` — 当前模式
- `isStreaming: boolean` — 是否正在流式传输
- `sessionId: string` — 当前会话 ID
- `model: string` — 当前模型
- `tokenCount: number` — Token 计数

## 聊天窗口组件

| 组件 | 用途 |
|------|------|
| ChatWindow | 主窗口容器 (拖拽、缩放、全屏、最小化) |
| ChatInput | 输入框 (@mention 知识文件、prompt 历史、附件) |
| ChatMessages | 消息列表 (虚拟滚动、自动滚底) |
| MessageBubble | 消息气泡 (操作按钮、token 芯片、Agent 时间线) |
| ChatSidebar | 侧边栏 (会话列表/知识文件/Stories/Bugs) |
| ChatToolbar | 工具栏 (导出 Markdown/分支对话/跨项目桥接) |
| SessionStatusBar | 状态栏 (token 消耗/模型名称/sparkline 图表) |
| ContextScopeBar | 上下文范围条 (当前 RAG scope 显示) |

## Popup 组件

| 组件 | 用途 |
|------|------|
| AppHeader | 渐变色头部 (角色名 + 设置入口) |
| PetPreview | 宠物预览 (皮肤环旋转动画) |
| ColorPicker | 6 色皮肤选择器 (预设色板) |
