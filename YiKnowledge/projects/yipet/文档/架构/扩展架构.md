# 扩展架构

## MV3 双执行上下文

Chrome MV3 扩展在两个隔离的 JavaScript 世界中运行：

```
┌─────────────────────────────────────────────────────┐
│  ISOLATED World (Content Script)                     │
│  ├── chrome.runtime API 可用                         │
│  ├── chrome.storage API 可用                         │
│  ├── 通过 window.postMessage 与 MAIN World 通信       │
│  └── src/content/bootstrap.ts (第一阶段)              │
├─────────────────────────────────────────────────────┤
│  MAIN World (Page Context)                           │
│  ├── 页面 DOM 访问                                   │
│  ├── window 全局变量                                 │
│  ├── chrome.runtime API 不可用                       │
│  └── src/content/bootstrap.ts (第二阶段)              │
│       ├── Chat Window (Vue 3 SPA)                    │
│       └── Floating Pet (DOM overlay)                 │
└─────────────────────────────────────────────────────┘
```

## 跨世界通信

ISOLATED World 通过 `window.postMessage` 与 MAIN World 通信：

```
MAIN World (聊天窗口)
  │ 用户点击"讨论当前页面"
  │ → window.postMessage({ type: 'DISCUSS_PAGE', url })
  ↓
ISOLATED World (Content Script)
  │ chrome.runtime.sendMessage({ type: 'DISCUSS_PAGE', url })
  ↓
Background Service Worker
  │ 处理消息，调用 chrome.tabs API
  │ → window.open(YiVad aiChat + session key)
```

## 多入口构建

YiPet 使用 Rsbuild 多入口构建，每个入口有独立的配置文件：

| 入口 | 配置文件 | 输出 | 运行环境 |
|------|----------|------|----------|
| popup | `rsbuild.config.ts` | `dist/popup.html` + `popup.js` | 扩展弹窗 |
| background | `rsbuild.config.ts` | `dist/assets/background.js` | Service Worker |
| chat | `rsbuild.config.chat.ts` | `dist/assets/chat.js` | MAIN World 注入 |
| cdn | `rsbuild.config.cdn.ts` | `dist/cdn/` | 按需注入 |
| bootstrap | `rsbuild.config.bootstrap.ts` | `dist/assets/bootstrap.js` | Content Script |

### 构建约束

| 约束 | 说明 |
|------|------|
| 文件名哈希 | 禁用 — MV3 manifest 引用固定文件名 |
| 代码分割 | 禁用 — Service Worker 需要单文件 |
| 自动导入 | Element Plus 组件 + Vue API (unplugin) |
| 构建元数据 | 自动生成 `dist/build-meta.json` |

| 快捷键 | 命令 | 说明 |

## 注入流程

```
页面加载
  → Content Script (bootstrap.ts) 注入到 ISOLATED World
  → 检查 window.__YIPET_LOADED__ (防止重复注入)
  → 注入 CDN 资源 (Vue, Element Plus, 样式)
  → 创建 MAIN World 脚本标签
  → MAIN World 初始化 Chat Window + Floating Pet
  → Floating Pet 渲染到页面 DOM
```

## 降级策略

| 场景 | 处理 |
|------|------|
| CDN 资源已加载 | `window.__YIPET_LOADED__` 全局检查短路 |
| Content Script 注入失败 | 重试 3 次，间隔 500ms |
| chrome.runtime 不可用 | 检测可用性，优雅降级 |
| 存储配额超限 | 非关键数据静默失败，关键数据降级到 localStorage |
| 语言消息缺失 | 回退 en → key 原始值 |
