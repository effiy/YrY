# 网络请求 (API 层)

## 四层 API 架构

```
第 4 层: services/*.ts     → 领域服务类 (AuthService, ChatService, ...)
第 3 层: types.ts           → 请求/响应 TypeScript 接口
第 2 层: endpoints.ts       → API 路径常量
第 1 层: client.ts          → ApiClient (fetch + retry + SSE + RPC 信封)
```

## ApiClient 特性

| 特性 | 说明 |
|------|------|
| 基座 | `public/cdn/utils/api-client.ts` |
| 扩展 | 日志注入、SSE 流解析、YiAi RPC 信封解包 |
| RPC | `client.rpc(moduleName, methodName, params)` → 自动封装信封 |
| 流式 | `client.stream(path, body, signal)` → AsyncGenerator<string> |
| 重试 | 指数退避 (1s → 2s → 4s → ... max 30s) |
| 超时 | 普通请求 30s，流式请求 10 分钟 |
| 错误 | 状态码映射 + 业务错误码转换 |

## 请求/响应流

```
Service.rpc("services.ai.chat_service", "chat", params)
  → ApiClient.rpc()
    → POST /  body: { module_name, method_name, parameters }
    → 请求拦截: 注入 Token, Content-Type
    → fetch(url, { method: 'POST', body: JSON.stringify(envelope) })
    → 响应拦截: 解包 StandardResponse { code, message, data }
    → 错误处理: code !== 0 → 抛出业务异常
    → 返回 data
```

## SSE 流式请求

```
Service.streamChat(params, onChunk, onDone, onError)
  → ApiClient.stream('/agent/chat', body, signal)
    → fetch(url, { method: 'POST', body })
    → 获取 ReadableStream reader
    → 逐行解析 text/event-stream
    → data: {...} → JSON.parse → yield chunk
    → onChunk(chunk) 逐块回调
    → stream end → onDone()
    → stream error → onError(err)
```

## 领域服务

| 服务 | 文件 | 说明 |
|------|------|------|
| AuthService | `services/auth.ts` | 认证 (登录/Token 管理) |
| ChatService | `services/chat.ts` | AI 聊天 (SSE 流式)、Agent 聊天 |
| SessionService | `services/sessions.ts` | 会话 CRUD (list/get/create/update/delete) |
| KnowledgeService | `services/knowledge.ts` | 知识库扫描/读取/写入文件 |
| RagService | `services/rag.ts` | RAG 检索/聊天/子问题分解 |
| BugService | `services/bug.ts` | Bug 报告/列表 |

## 关键参数约定

| 正确 | 错误 | 说明 |
|------|------|------|
| `filter` | `query` | SessionService.list/get, 数据查询 |
| `target_file` | `path` | 文件读写接口 |
| `cname` | `collection_name` | 集合名称参数 |

## 服务工厂

```ts
// src/api/index.ts
export function createApiServices(baseUrl: string) {
  const client = new ApiClient(baseUrl)
  return {
    auth: new AuthService(client),
    chat: new ChatService(client),
    sessions: new SessionService(client),
    knowledge: new KnowledgeService(client),
    rag: new RagService(client),
    bug: new BugService(client),
  }
}
```
