# 核心代码

## 入口文件

| 文件 | 说明 |
|------|------|
| `manifest.json` | MV3 扩展清单：权限声明、Service Worker 注册、web_accessible_resources |
| `src/popup/main.ts` | Popup 入口：Vue 3 应用初始化，挂载皮肤中心 |
| `src/background/index.ts` | Service Worker 入口：命令分发 + 消息路由 |
| `src/content/bootstrap.ts` | Content Script 双世界入口：ISOLATED → MAIN World 注入 |
| `src/chat/index.tsx` | 聊天窗口入口：Vue 3 SPA 初始化 |

## 启动时序

```
Service Worker 注册
  → 页面加载 → Content Script 注入
  → bootstrap.ts: 检查 __YIPET_LOADED__
  → CDN Injector: 注入 Vue/Element Plus/样式
  → 创建 MAIN World 脚本标签
  → MAIN World 初始化:
    → ChatController 实例化
    → 从 chrome.storage 恢复会话
    → 渲染 Chat Window + Floating Pet
```

## 消息流

```
用户点击"讨论当前页面"
  → ChatWindow (MAIN World)
  → window.postMessage({ type: 'DISCUSS_PAGE' })
  → bootstrap.ts (ISOLATED World)
  → chrome.runtime.sendMessage(...)
  → Service Worker (background)
  → chrome.tabs.create(YiVad aiChat URL)
```
