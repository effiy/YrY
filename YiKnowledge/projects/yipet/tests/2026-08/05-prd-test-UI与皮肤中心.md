## 页面主题模式测试（2026-09-15 新增）

| 编号 | 用例 | 前置条件 | 操作 | 预期 | 优先级 |
|------|------|---------|------|------|--------|
| TC-PT-001 | 启用页面主题 | 在任意页面，选择 Slate Pro 主题 | 弹窗中开启"Apply theme to page" | 页面应用微弱的蓝灰色调滤镜，`<html>` 设置 `color-scheme: dark`；支持暗色模式的网站自动切换 | P1 |
| TC-PT-002 | 关闭页面主题恢复 | 页面主题已启用 | 弹窗中关闭"Apply theme to page" | 页面滤镜、`color-scheme`、`<body>` 样式全部移除，恢复原始外观 | P1 |
| TC-PT-003 | 切换主题时页面跟随 | 页面主题已启用（Slate Pro） | 弹窗中切换到 Ocean 主题 | 页面滤镜自动更新为 Ocean 对应的青蓝色调 | P1 |
| TC-PT-004 | None 主题禁用页面开关 | 选择 None 主题 | 查看页面主题开关 | 开关处于禁用状态（灰色），因为 None 意味着不使用任何页面主题 | P2 |
| TC-PT-005 | 页面主题持久化 | 启用页面主题后关闭弹窗 | 刷新页面 | 页面主题自动恢复（从 `chrome.storage.local` 读取 `pageThemeEnabled`） | P1 |
