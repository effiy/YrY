## 一、测试范围与目标

### 1.1 在范围内（13 个特效 + 4 个组件）

| 层 | 特效 | 测试重点 |
|----|------|---------|
| 像素操作 | 基础滤镜/老照片/双色调/LUT | 逐像素计算正确性、LUT 插值精度、效果链顺序 |
| 卷积 | 素描/光影/颗粒 | 卷积核数值、边缘检测阈值、亮度加权 |
| 变换 | 像素化/故障/HDR/景深/全景/漏光 | 颜色量化误差扩散、色调映射、金字塔模糊、单应性矩阵 |
| 组件 | EffectPanel/LUTImporter/PresetCarousel/BeforeAfterSlider | 参数绑定、文件解析、缩略图渲染、拖拽交互 |

### 1.2 不在范围内

| 排除项 | 原因 |
|--------|------|
| .3dl LUT 格式导入 | DEV §9 列为功能缺口 |
| HDR 多曝光合成 | DEV §9 列为功能缺口 |
| 素描纸张纹理 | DEV §9 列为功能缺口 |

## 四、单元测试 — 像素操作层

### 4.1 基础滤镜

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-BF-01 | 亮度 +50 | 中灰(128,128,128) | (178,178,178) |
| UT-BF-02 | 饱和度 0 → 灰度 | 红色(200,50,50) | R=G=B（HSL-S=0） |
| UT-BF-03 | 色相旋转 180° | 红色(255,0,0) | 青色(0,255,255) |
| UT-BF-04 | 模糊 5px | 单点白色像素 | 周围 5px 内出现非零值 |
| UT-BF-05 | 锐化卷积核 | 边缘像素(100,100,100)→(200,200,200) | 边缘对比度增强 |
| UT-BF-06 | 预设 "暖色" | 任意图片 | RGB 通道：R 增益 > B 增益 |
| UT-BF-07 | 反相 | (0,50,255) | (255,205,0) |

### 4.2 老照片

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-VT-01 | 效果链顺序 | 红色原图 | 棕褐色调先于颗粒（颜色→纹理） |
| UT-VT-02 | 年代预设 "1970s" | 任意图片 | 偏暖棕褐 + 较大颗粒 |
| UT-VT-03 | 日期戳叠加 | 启用日期戳 | 右下角有橙黄色文字 |

### 4.3 双色调

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-DT-01 | HSL 渐变映射 | 亮度 L=0 | 映射到阴影色 |
| UT-DT-02 | HSL 渐变映射 | 亮度 L=100 | 映射到高光色 |
| UT-DT-03 | 分离色调 | 暗部暖色+亮部冷色 | 暗部偏暖，高光偏冷 |

### 4.4 LUT 滤镜

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-LT-01 | 33³ 恒等 LUT | RGB(i,j,k) → LUT(i,j,k) | 输出 = 输入（ΔE=0） |
| UT-LT-02 | 三线性插值 8 点权重 | 查询点(0.5,0.5,0.5) | 8 个角点各 0.125 权重 |
| UT-LT-03 | .cube 文件解析 | `LUT_3D_SIZE 33` 头部 | 解析出 33³×3 float 数组 |
| UT-LT-04 | LUT 预设应用 | 选择 "电影感" 预设 | 对比度增强 + 暗部偏青 |
| UT-LT-05 | LUT 导出 | .cube 格式导出 | 与导入文件的数值误差 < 1e-6 |

<a id="sec-10"></a>
## 十、缺陷分级

| 级别 | 定义 | 示例 |
|------|------|------|
| S0 — 阻断 | 特效渲染崩溃 | 任何特效导致 Canvas 上下文丢失或 ImageData detached |
| S1 — 严重 | 核心特效结果错误 | LUT 插值输出全黑、Floyd-Steinberg 误差不守恒 |
| S2 — 一般 | 单个特效边界情况 | 极端参数（blur=200px）导致渲染超时 |
| S3 — 轻微 | 视觉瑕疵 | 故障艺术切片边缘有 1px 缝隙 |
| S4 — 建议 | 优化 | 金字塔模糊改用 GPU 加速 |
