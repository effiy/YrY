## 二、单元测试 — 图层与抠图

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-LY-01 | Normal 混合 | 上层(R=200,G=0,B=0,A=1)，下层(R=0,G=100,B=0,A=1) | 输出(R=200,G=0,B=0) |
| UT-LY-02 | Multiply 混合 | 上层(128,128,128)，下层(200,200,200) | 输出(100,100,100)：128×200/255 |
| UT-LY-03 | Screen 混合 | 上层(128,128,128)，下层(100,100,100) | 输出 > (128,128,128)（Screen 增亮） |
| UT-LY-04 | 透明度 50% | 上层(R=200,A=0.5)，下层(R=0) | 输出 R = 200×0.5 + 0×0.5 = 100 |
| UT-LY-05 | 图层蒙版 | 蒙版白色区域 = 上层可见，黑色 = 下层可见 | 蒙版边缘半透明过渡正确 |
| UT-CU-01 | GrabCut 前景/背景分离 | 前景蓝色、背景白色、标记蓝色/白色各 5 点 | 分割后前景区域包含蓝色像素 > 90% |
| UT-CU-02 | alpha matting 边缘 | 前景/背景边界 | alpha 通道不是硬切（0/1），存在 0.3-0.7 过渡值 |
| UT-BG-01 | 背景替换 | 抠图 alpha + 新背景 | 前景保留，背景为新背景 |

## 三、单元测试 — 频率域与变换

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-FF-01 | FFT → IFFT 往返 | 1080p 灰度图 | 像素误差 < 1（浮点舍入） |
| UT-FF-02 | 低通滤波 | 截止频率 0.1 | 高频细节（边缘/噪声）被平滑 |
| UT-FF-03 | 高通滤波 | 截止频率 0.3 | 低频被抑制，仅边缘保留 |
| UT-FF-04 | 陷波滤波 | 在频域选择 2 个亮点 → 陷波 | 对应空间频率的周期纹理被消除 |
| UT-WR-01 | 透视变形 | 4 点透视映射 | 四边形矫正为矩形 |
| UT-WR-02 | 球面变形 | 强度 50% | 中心区域放大，边缘压缩 |
| UT-WR-03 | 漩涡变形 | 角度 180° | 像素绕中心旋转，距离越远旋转越小 |
| UT-SR-01 | Lanczos 2× 放大 | 100×100 → 200×200 | 输出尺寸正确 |
| UT-SR-02 | Lanczos + Unsharp Mask | 2× 放大 + 锐化 | 边缘比纯 Lanczos 更锐利 |
| UT-WM-01 | 频域水印检测 | 含网纹水印的图片 | FFT 频谱中可见周期性亮点 |
| UT-WM-02 | 陷波滤波去水印 | 选择陷波点 → 应用 | 水印纹理减弱或消除 |

## 四、单元测试 — 分析与通道

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-CH-01 | 通道分离 | RGB 图片 | 3 个独立灰度图（R/G/B 单通道） |
| UT-CH-02 | 通道合并 | 3 个灰度图 | 还原为 RGB 彩色图 |
| UT-TH-01 | 全局阈值 128 | 灰度图 | ≥128 → 255，<128 → 0 |
| UT-TH-02 | 大津法自适应阈值 | 双峰直方图图片 | 阈值在两峰之间的谷底 |
| UT-TH-03 | 自适应阈值（局部均值） | 光照不均的文档 | 局部阈值适应光照变化 |
| UT-ED-01 | Sobel 边缘：清晰边缘 | 黑白交界图 | 交界处梯度幅值 > 0 |
| UT-ED-02 | Canny 边缘：连续无断点 | 简单几何图形 | 边缘线连续（双阈值连接生效） |
| UT-HG-01 | 直方图均衡化 | 低对比度图片 | 输出直方图更均匀（std dev 增大） |
| UT-QA-01 | 质量评估：清晰图片 | 高清照片 | sharpness > 70，blur < 20 |
| UT-QA-02 | 质量评估：模糊图片 | 高斯模糊处理后的图片 | sharpness < 30，blur > 50 |
| UT-QA-03 | 曝光评估 | 欠曝图片（直方图左偏） | under > 30%，over < 5% |
| UT-CA-01 | 调色板提取 | 含 5 种主色的图片 | 返回 5 种主要颜色（HEX） |
| UT-CA-02 | 互补色计算 | 主色 #FF0000（红） | 互补色 #00FFFF（青） |

<a id="sec-7"></a>
## 七、缺陷分级

| 级别 | 定义 | 示例 |
|------|------|------|
| S0 — 阻断 | FFT Worker 崩溃导致页面卡死 | Worker 未捕获异常导致主线程等待超时 |
| S1 — 严重 | 核心算法错误 | Layer composite 混合模式与 CSS 规范不一致、FFT→IFFT 误差 > 10 |
| S2 — 一般 | 单个工具问题 | GrabCut 在纯色背景下分割失败、EXIF 写入后 JPEG 无法打开 |
| S3 — 轻微 | 体验问题 | 图层拖拽排序非平滑动画 |
