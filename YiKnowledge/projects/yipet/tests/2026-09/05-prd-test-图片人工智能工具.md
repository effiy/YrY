## 二、单元测试 — 客户端工具

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-FS-01 | 液化变形半径衰减 | brush(50px), 距离中心 50px | 位移 = 0（边缘刚好失效） |
| UT-FS-02 | 液化变形中心最大 | brush(50px), 距离中心 0px | 位移 = strength × maxDisplacement |
| UT-FS-03 | smoothstep 过渡 | 距离从 0→50 | 位移单调递减（非阶梯） |
| UT-RE-01 | 红眼检测 | 红色瞳孔（R=200,G=50,B=50） | 识别为红眼区域 |
| UT-RE-02 | 非红眼不触发 | 正常黑色瞳孔 | 不触发红眼移除 |
| UT-RE-03 | 红眼移除效果 | 红眼区域 | R 分量降低 + 去饱和 |
| UT-SS-01 | 双边滤波边缘保留 | 黑白交界图（噪声+边缘） | 交界处像素值保留（边缘权重低 ≠ 模糊） |
| UT-SS-02 | 平滑区域内平坦化 | 纯色区域 + 噪声 | 噪声被平滑（空间高斯生效） |
| UT-TW-01 | 牙齿区域 L 通道 +20 | HSL-L=70 的牙齿区域 | L→90（clamp 100） |
| UT-TW-02 | 非牙齿区域不改变 | 嘴唇/皮肤区域 | HSL 不变 |
| UT-SC-01 | 显著区域检测 | 中心有物体 + 四周空白 | 返回中心物体的 bounding rect |
| UT-SC-02 | 中心偏置 | 两个相同大小的物体，一个在中心一个在角落 | 中心物体得分更高 |
| UT-PH-01 | pHash 缩放不变 | 原图 vs 0.5× 缩放 | 汉明距离 ≤ 5 |
| UT-PH-02 | pHash 不同图片 | 完全不同两张图 | 汉明距离 > 20 |
| UT-PH-03 | 旋转 < 5° 不变 | 原图 vs 旋转 3° | 汉明距离 ≤ 10 |

## 五、缺陷分级

| 级别 | 定义 | 示例 |
|------|------|------|
| S0 — 阻断 | face-api.js 模型加载失败导致崩溃 | 人脸工具初始化抛异常，后续编辑不可用 |
| S1 — 严重 | 人脸 landmark 定位严重偏移 | 瘦脸效果作用于非脸部区域 |
| S2 — 一般 | 单个工具精度不足 | 红眼移除漏检、相似度搜索误判 |
| S3 — 轻微 | 体验问题 | 液化笔刷非平滑 |
