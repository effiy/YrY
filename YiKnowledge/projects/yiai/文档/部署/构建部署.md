# 构建部署

## 启动配置

```yaml
server:
  host: "0.0.0.0"
  port: 10086
  reload: true                  # 开发模式热重载

uvicorn:
  limit_concurrency: 1000       # 最大并发连接数
  limit_max_requests: 10000     # 每个 worker 最大请求数
  timeout_keep_alive: 5         # Keep-Alive 超时 (秒)
```

## 启动流程

```
main.py
  → uvicorn.run("app:app", host, port, reload)
    → app.py: create_app()
      → setup_logging()              # 配置日志格式和级别
      → 注册异常处理器                # BusinessException → StandardResponse
      → 注册 Observer 中间件 (可选)   # 限流/采样/深度防护
      → 注册 20 个路由模块            # server/routes/*.py
      → 配置 CORS 中间件              # origins: ["*"]
      → 配置 Auth 中间件 (可选)       # header_verification_middleware
      → 挂载 MCP 服务                 # /mcp/*
      → 挂载静态文件                  # static/
      → lifespan:
        → 初始化 MongoDB              # Motor async client
        → 导入种子数据                # data/seeds/*.json
        → 初始化 RSS 系统             # 注册定时抓取任务
        → 初始化 Knowledge Watcher    # apscheduler 每 60s 轮询
        → 预加载 RAG 索引             # 从 MongoDB 构建 VectorStoreIndex
```

## 部署方式

```bash
# 开发环境 (热重载)
python main.py

# 生产环境 (多 worker)
uvicorn src.app:app --host 0.0.0.0 --port 10086 --workers 4

# 使用 Gunicorn (推荐生产)
gunicorn src.app:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:10086
```

## 环境依赖

| 服务 | 默认端口 | 用途 |
|------|---------|------|
| MongoDB | 27017 | 数据持久化 |
| Ollama | 11434 | LLM 推理 (可选) |

## 配置管理

`config.yaml` 通过 pydantic-settings 加载，支持环境变量覆盖：

```yaml
server:
  host: "0.0.0.0"
  port: 10086

mongodb:
  uri: "mongodb://localhost:27017"
  db_name: "ruiyi"

middleware:
  auth_enabled: false

knowledge:
  base_dir: "../YiKnowledge"

rag:
  embed_model: "nomic-embed-text"
  chunk_size: 512
  chunk_overlap: 50
```
