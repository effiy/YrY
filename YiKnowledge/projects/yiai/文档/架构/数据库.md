# 数据库

## MongoDB 架构

```
MongoDB (Motor async)
├── 数据库: ruiyi (config: mongodb.db_name)
├── 连接池: pool_size=10, max_pool_size=50
└── 集合:
    ├── sessions          # 聊天会话
    ├── menus             # 菜单配置
    ├── users             # 用户
    ├── projects          # 项目
    ├── issues            # 任务
    ├── cycles            # 迭代周期
    ├── releases          # 发布
    ├── modules           # 模块
    ├── pages             # 页面
    ├── labels            # 标签
    ├── bugs              # Bug
    ├── knowledge_files   # 知识文件元数据
    ├── static_files      # 静态文件备份
    ├── rss               # RSS 条目
    ├── chat_records      # 聊天记录
    └── ...               # 字典表
```

## 核心集合 Schema

### sessions
| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | ObjectId | 主键 |
| `session_id` | str | 会话唯一标识 |
| `title` | str | 会话标题 (首条消息截取) |
| `messages` | list | 消息列表 `[{role, content, ts, ...}]` |
| `model` | str | 使用的模型 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |

### knowledge_files
| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | ObjectId | 主键 |
| `file_path` | str | 文件路径 (相对于 YiKnowledge) |
| `title` | str | 标题 (from frontmatter) |
| `tags` | list | 标签列表 |
| `category` | str | 分类 |
| `status` | str | 状态 (stable/draft/deprecated) |
| `content` | str | 正文内容 |
| `roles` | list | 相关角色 |
| `created` | str | 创建日期 |
| `updated` | str | 更新日期 |
| `source` | str | 来源 (internal/external) |

### bugs
| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | ObjectId | 主键 |
| `title` | str | Bug 标题 |
| `description` | str | 详细描述 |
| `url` | str | 发现页面 URL |
| `status` | str | 状态 (open/in_progress/resolved/closed) |
| `severity` | str | 严重程度 |
| `reporter` | str | 报告人 |
| `created_at` | datetime | 创建时间 |

## 数据访问层

```
routes → services → repository → database (MongoDB 单例)
```

- `data/database.py` — MongoDB 单例：`find_one`, `find_many`, `insert_one`, `insert_many`, `update_one`, `delete_one`
- `data/repository.py` — 通用仓库：`query_documents` (分页/过滤/排序)
- `_build_filter(query_params)` — 将 HTTP 参数转为 Mongo 查询条件，支持 `$regex`, `$gte`, `$lte`, `$in` 等操作符

## 查询模式

```python
# 通用分页查询
result = await repository.query_documents(
    cname="issues",
    filter={"status": "open", "project_id": pid},
    pageNum=1,
    pageSize=20,
    orderBy="created_at",
    orderType="desc"
)
# → { list: [...], total: 100, pageNum: 1, pageSize: 20, totalPages: 5 }
```
