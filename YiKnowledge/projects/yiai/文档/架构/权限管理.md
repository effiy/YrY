# 权限管理

## 认证模式

YiAi 支持两种认证模式，通过 `middleware.auth_enabled` 配置切换：

### 开发模式 (auth_enabled: false)

所有端点公开，无需认证。适用于本地开发和内部网络。

### 生产模式 (auth_enabled: true)

- **中间件拦截** — `header_verification_middleware` 检查每个请求的 `X-Token` 请求头
- **JWT 验证** — `bcrypt` 密码哈希 + `PyJWT` Token 签发/验证
- **Token 过期** — 默认 1440 分钟 (24 小时)，通过 `jwt.expire_minutes` 配置
- **静态 Token** — 可通过 `middleware.auth_token` 配置静态 Token (开发/测试)

## 认证流程

```
用户登录
  → POST /auth/login { username, password }
  → bcrypt 验证密码哈希
  → PyJWT 签发 Token (含 user_id, role, exp)
  → 返回 { token, user }

后续请求
  → 携带 X-Token 请求头
  → header_verification_middleware 验证 Token
  → 提取 user 信息 → 注入 request.state.user
  → 路由处理函数可通过 request.state.user 获取当前用户
```

## CORS 配置

```yaml
cors:
  origins: ["*"]              # 允许所有来源
  allow_any_origin: true
```

## 安全配置

```yaml
middleware:
  auth_enabled: false          # 默认关闭，生产环境开启
  auth_token: "dev-token-change-me"

jwt:
  secret: "yi-ai-jwt-secret-change-in-production"
  expire_minutes: 1440
```

## 观察者 (Observer) 中间件

可选的请求监控中间件，通过 `observer.enabled` 配置：

```yaml
observer:
  enabled: false               # 默认关闭
  throttle_enabled: false      # 限流
  sampler_enabled: true        # 慢请求采样
  sampler_slow_threshold_ms: 5000.0
  guard_enabled: true          # 深度防护
  guard_max_depth: 3           # 最大请求体嵌套深度
```

| 组件 | 功能 |
|------|------|
| throttle | 请求频率限制 |
| sampler | 慢请求采样 (>5s)，记录到日志 |
| guard | 防止深度嵌套 JSON 攻击 (max 3 层) |

## Agent 安全

Agent 模式有额外的安全控制：
- **确认门控** — 写操作 (create/update/delete) 需用户确认，120s 超时自动拒绝
- **拒绝记忆** — 同 session 内用户拒绝的工具调用自动拦截
- **工具白名单** — 只有 `ToolRegistry` 注册的工具可被 Agent 调用
- **参数校验** — 工具调用前验证参数类型和必填项
