# 模块分析

## AI 聊天模块 (`domain/ai/`)

| 文件 | 职责 |
|------|------|
| `chat.py` | 聊天服务：Ollama/OpenAI/Anthropic 多后端，SSE 流式响应 |
| `agent.py` | Agent 循环 (Pi 风格)：多轮对话、工具调用、确认门控 |
| `tools.py` | 工具注册中心：`ToolRegistry` + `execute` + 参数校验 |
| `data_tools.py` | 通用数据工具：`db_list`, `db_schema`, `db_create`, `db_update`, `db_delete` |

Agent 循环特性：
- **确认门控** — 写操作需用户确认，120s 超时自动拒绝
- **拒绝记忆** — 同 session 内拒绝的调用自动拦截
- **模型切换** — 弱模型停滞时自动升级到更强模型 (`model_fallback`)
- **预算感知** — 剩余轮次不足时提醒模型压缩步骤
- **旋转检测** — 连续 3 次相同观察触发 nudge
- **结果裁剪** — 超大工具结果自动裁剪，防止上下文溢出
- **断连检测** — 客户端断开 (`asyncio.CancelledError`) 时自动中止

## RAG 模块 (`domain/rag/`)

| 文件 | 职责 |
|------|------|
| `engine.py` | 检索引擎：混合检索 (向量 + BM25)、LLM Rerank、HyDE 查询增强 |
| `builder.py` | 索引构建：从 MongoDB `knowledge_files` 构建 VectorStoreIndex |
| `chat.py` | RAG 聊天：SSE 流式 RAG 对话，内联引用编号 |

检索策略：
- **混合检索** — 向量相似度 + BM25 关键词，权重可配置
- **LLM Rerank** — 可选二阶段重排序，提升 Top-K 精度
- **HyDE** — 查询增强：用 LLM 生成假设文档再检索
- **Sentence Window** — 检索句子级片段，返回周围窗口上下文
- **Scope 过滤** — 支持文件级和文件夹级 scope 限定

## 文件模块 (`domain/files/`)

双写策略：磁盘 (主) + MongoDB (备份)。文件操作包括上传/下载/删除/列表，支持 OSS 存储 (降级到本地磁盘)。

## 知识库模块 (`domain/knowledge/`)

| 文件 | 职责 |
|------|------|
| `scanner.py` | 遍历 YiKnowledge 目录树，解析 YAML frontmatter + 正文 |
| `watcher.py` | apscheduler 每 60s 轮询，检测文件变更并同步到 MongoDB |

## 认证模块 (`domain/auth/`)

JWT + bcrypt 密码哈希。Token 签发/验证/刷新。支持静态 Token 模式 (开发环境) 和 JWT 模式 (生产环境)，通过 `auth_enabled` 配置开关。

## RSS 模块 (`domain/rss/`)

RSS 源管理、定时抓取 (apscheduler)、条目存储到 MongoDB。支持多源聚合和全文搜索。

## 执行模块 (`domain/execution/`)

通用模块执行引擎，支持动态加载和执行 Python 模块，用于插件化和扩展。

## 服务层 (`services/`)

| 目录 | Service | 说明 |

| `ai/` | `chat_service.py` | 聊天服务封装，SSE 流式响应 |

| `database/` | `session_service.py` | 会话管理 |

| `execution/` | `executor.py` | 模块执行引擎 |
