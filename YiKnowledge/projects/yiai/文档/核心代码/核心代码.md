## 生命周期管理

```
启动:
  setup_logging()
  → 注册异常处理器 (BusinessException → StandardResponse)
  → 注册中间件 (CORS, Auth, Observer)
  → 注册 20 个路由模块
  → 挂载 MCP 服务
  → 挂载静态文件
  → lifespan:
    → init MongoDB (Motor async client)
    → seed 种子数据 (menus, users, projects, ...)
    → init RSS 系统 (注册定时抓取)
    → init Knowledge Watcher (apscheduler 每 60s 轮询)
    → preload RAG 索引 (从 MongoDB 构建 VectorStoreIndex)

关闭:
  → shutdown Knowledge Watcher
  → shutdown RSS 系统
  → close MongoDB connection
```

## 请求处理流程

```
HTTP Request
  → CORS 中间件 (Origin 检查)
  → Auth 中间件 (X-Token 验证，可选)
  → Observer 中间件 (限流/采样/深度防护，可选)
  → 路由匹配
  → 路由处理函数
    → RPC 分发器: 解析 module_name.method_name → 定位 service
    → services 层: 参数校验 + 业务编排
    → domain 层: 核心业务逻辑
    → data 层: MongoDB 操作 (Motor async)
  → 响应 (StandardResponse 统一信封)
  → 异常时: BusinessException → ErrorCode → StandardResponse
```
