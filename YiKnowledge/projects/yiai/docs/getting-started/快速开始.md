# 快速开始

## 环境要求

- **Python** >= 3.10
- **MongoDB** 运行在 \`localhost:27017\`
- **Ollama** 运行在 \`localhost:11434\` (可选，AI 功能需要)

## 安装与启动

\`\`\`bash
cd YiAi

# 安装依赖
pip install -r requirements.txt

# 启动开发服务器 (http://localhost:10086)
python main.py
\`\`\`

## 前置条件

\`\`\`bash
# 确保 MongoDB 运行中
mongod --dbpath ./data

# 确保 Ollama 运行中 (如需 AI 功能)
ollama serve
ollama pull qwen3.5:4b
ollama pull nomic-embed-text
\`\`\`
