## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-WS-01|WS 连接建立|客户端发起 WS 连接|连接成功 101 状态码|P0 |
| UT-WS-02|心跳保活|30s 无消息|服务端发送 ping 客户端回 pong|P0 |
| UT-WS-03|心跳超时断开|3 次 ping 无 pong|断开连接|P0 |
| UT-WS-04|消息路由|订阅特定频道|仅收到该频道消息|P1 |
| UT-WS-05|数据变更推送|MongoDB 数据变更|实时推送给订阅者|P1 |
| UT-WS-06|连接数上限|连接数 > MAX_CONN|新连接被拒绝|P1 |
| UT-WS-07|消息压缩|大消息 > 1KB|自动压缩传输|P2 |
| UT-WS-08|重连机制|客户端断连自动重连|重连后恢复订阅|P2 |
