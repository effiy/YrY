## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-LT-01|基准负载测试|100 并发 持续 60s|P95 < 500ms 错误率 < 0.1%|P0 |
| UT-LT-02|压力递增测试|10->100->500 并发递增|找到系统瓶颈并发数|P0 |
| UT-LT-03|长时稳定性测试|50 并发 持续 30min|无内存泄漏无连接泄漏|P1 |
| UT-LT-04|突发流量测试|瞬时 500 并发|限流生效 429 返回|P1 |
| UT-LT-05|SSE 流式压力|100 个 SSE 并发连接|流正常推送不中断|P1 |
| UT-LT-06|MongoDB 写入压力|100 write/s 持续 5min|写入成功率 > 99.9%|P1 |
| UT-LT-07|压力报告生成|测试完成后|生成 HTML/JSON 报告|P2 |
| UT-LT-08|CI 集成|CI 中运行基准负载|负载测试结果阻挡发布|P2 |
