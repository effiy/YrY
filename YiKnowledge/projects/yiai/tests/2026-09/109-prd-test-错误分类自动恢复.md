## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-EC-01|5xx 可重试（幂等）|GET 返回 503|标记可重试|P0 |
| UT-EC-02|5xx 不可重试（非幂等）|POST 返回 500|标记不可重试|P0 |
| UT-EC-03|429 限流重试|返回 429 + Retry-After|等待指定时间重试|P0 |
| UT-EC-04|4xx 不重试|401/403/404|直接返回错误|P1 |
| UT-EC-05|网络超时重试|请求 5s 超时|重试 3 次指数退避|P0 |
| UT-EC-06|熔断器打开|连续 5 次 503|后续请求直接拒绝|P0 |
| UT-EC-07|半开探测|熔断 30s 后探测|成功则关闭熔断|P1 |
| UT-EC-08|最大重试次数|连续 3 次失败|返回最后一次错误|P0 |
