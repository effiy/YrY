# YA-09-99: 数据摘要智能截断 — 测试规格

> 来源 PRD：[103-需求-数据摘要智能截断](../../prds/2026-09/103-需求-数据摘要智能截断)
> 需求编号：YA-09-99 · 优先级：P2 · 人天：0.5d

> **文档职责**：本文档定义**怎么验证**（VERIFY），不含产品目标与实现方案。

---

## 一、测试范围与策略

### 1.1 测试范围

| 模块 | 测试重点 | 层级 |
|------|---------|------|
| SummaryGenerator | 摘要模板生成、字段聚合、截断逻辑 | 单元 |
| X-Summary 中间件 | HTTP Header 注入、`?summary=true` 参数处理 | 集成 |
| SmartTruncator | 完整词边界截断、省略号插入、摘要长度控制 | 单元 |
| Agent 上下文截断 | LLM 上下文窗口的智能截断策略 | 单元 |

### 1.2 测试策略

| 层级 | 框架 | 覆盖内容 | 占比 |
|------|------|---------|------|
| 单元测试 | pytest | 摘要生成器、截断器、模板引擎 | 70% |
| 集成测试 | pytest + httpx | 中间件行为、Header 注入、性能开销 | 30% |

---

## 二、测试数据与前置条件

| 组件 | 要求 |
|------|------|
| 测试数据 | 200 条会话数据、100 条知识库文件、50 条 Bug 记录 |
| 摘要模板 | 5 种数据类型模板（sessions/knowledge/bugs/users/audit_logs） |
| 配置参数 | `MAX_SUMMARY_LENGTH=200`, `TRUNCATION_CHAR_LIMIT=500` |

---

## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-SG-01 | 列表摘要生成 | 查询返回 200 条 sessions | `X-Summary: 共 200 条会话，涵盖 5 个主题` | P0 |
| UT-SG-02 | 聚合统计摘要 | 查询返回各状态 Bug 数 | `X-Summary: 共 50 条缺陷（open:20, resolved:15, closed:15）` | P0 |
| UT-SG-03 | `?summary=true` 仅返摘要 | 请求 `?summary=true` | 响应只有摘要 Header，body 为空 | P0 |
| UT-SG-04 | 截断完整词边界 | 文本 "Hello World This is long..." 截断到 20 字 | 截断点位于完整词后 "Hello World..." | P1 |
| UT-SG-05 | 摘要长度控制 | `MAX_SUMMARY_LENGTH=100` | 所有摘要 <= 100 字符 | P1 |
| UT-SG-06 | 空数据集摘要 | 集合查询返回 0 条 | `X-Summary: 共 0 条记录` | P1 |
| UT-SG-07 | Agent 上下文截断 | 10KB 文本注入 LLM 上下文 | 截断至配置的 max_context_chars，标注截断点 | P1 |
| UT-SG-08 | 不同数据类型不同模板 | sessions vs bugs 查询 | sessions 摘要含主题分布，bugs 含严重级别分布 | P1 |

## 四、边界与异常测试

### 4.1 边界场景

| 编号 | 场景 | 输入 | 预期 |
|------|------|------|------|
| BE-01 | 单条数据摘要 | 仅 1 条记录 | 摘要不含"共 X 条"的冗余描述 |
| BE-02 | 超长字段截断 | 单字段 10000 字 | 摘要中字段值截断到 50 字 |
| BE-03 | 模板缺失降级 | 未知数据类型查询 | 降级为通用模板"共 X 条记录" |
| BE-04 | HEAD 请求摘要 | HTTP HEAD 同路径 | 仅返回摘要 Header，不返回 body |

### 4.2 异常场景

| 编号 | 场景 | 触发条件 | 预期 |
|------|------|---------|------|
| EX-01 | MongoDB 查询失败 | 数据库连接超时 | 摘要返回"数据暂时不可用" |
| EX-02 | 摘要计算超时 | 复杂聚合查询 > 1s | 跳过摘要，不阻塞响应 |
| EX-03 | 内存限制 | 10000 条结果生成摘要 | 内存增长 < 10MB |
