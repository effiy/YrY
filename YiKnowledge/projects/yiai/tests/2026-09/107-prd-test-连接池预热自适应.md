## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-PW-01|启动预热建连|YiAi 启动|连接池预建 5 个连接|P0 |
| UT-PW-02|自适应扩容|QPS 从 10 升至 50|连接池 min_size 提升|P0 |
| UT-PW-03|低负载缩容|QPS 从 50 降至 5|连接池 min_size 降低|P0 |
| UT-PW-04|冷启动延迟对比|首次请求延迟|预热后延迟 < 无预热 x 0.5|P0 |

| UT-PW-06|历史均值预测|过去 7 天同时段均值|连接数 = 均值 x 1.2|P1 |
| UT-PW-07|预热不阻塞启动|启动时异步预热|启动延迟 < 2s|P1 |
| UT-PW-08|空闲连接回收|连接空闲 > 60s|回收至 min_size|P1 |
