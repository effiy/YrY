## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-TP-01|时间序列预测|过去 7 天小时级流量|预测未来 1h MAPE < 20%|P0 |
| UT-TP-02|扩容预警|预测 > 当前容量 x 0.8|提前 15min 告警|P0 |
| UT-TP-03|缩容建议|预测 < 当前容量 x 0.3 持续 2h|发出缩容建议|P1 |
| UT-TP-04|工作日/周末模式|周一 vs 周日|预测反映周模式|P1 |
| UT-TP-05|异常流量过滤|DDoS 异常峰值|不纳入预测模型|P1 |
| UT-TP-06|预测准确率跟踪|7 天预测 vs 实际|MAPE < 25%|P1 |
| UT-TP-07|冷启动降级|无历史数据|使用默认容量|P1 |
| UT-TP-08|节假日感知|法定节假日|使用节假日修正因子|P2 |
