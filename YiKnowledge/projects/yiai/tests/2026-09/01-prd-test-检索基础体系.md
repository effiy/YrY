## 一、测试范围与目标

### 1.1 在范围内

| 体系 | 模块 | 关键测试点 |
|------|------|----------|
| 查询理解 | 意图分类 | 分类准确率 > 85%（事实查询/分析查询/对话），分类器路由 |
| 查询理解 | 实体识别 | 项目名/模块名/日期提取，NER 准确率 |
| 预处理 | 同义词扩展 | 5 种扩展模式、权重分配、去重截断（max 5 变体） |
| 预处理 | 同义词词典管理 | CRUD、多领域隔离、语义版本、导入导出 |
| 预处理 | 同义词图构建 | 图构建、BFS 查询扩展（2 跳）、社区检测、权重更新 |
| 预处理 | 查询改写 (HyDE) | 假设文档生成 → 嵌入检索 |
| 预处理 | 停用词管理 | 加载、过滤、领域自定义 |
| 预处理 | 拼写纠正 | 编辑距离、候选排序、上下文感知 |
| 预处理 | 短语匹配 | 最长匹配优先、短语识别 |
| 预处理 | 查询模板 | 模板参数填充、模板 CRUD |
| 结果增强 | 重排序 (Cross-Encoder) | MRR 提升 > 10%、推理延迟 |
| 结果增强 | 去重融合 | 向量+BM25 结果去重、RRF 融合 |
| 结果增强 | 高亮片段 | 关键词高亮、片段截断、多字段片段 |
| 结果增强 | 摘要生成 | 抽取式/生成式摘要、长度控制 |
| 结果增强 | 查询建议 | 基于日志/共现/点击的建议生成 |
| 结果增强 | 零结果处理 | 查询改写重试、宽松匹配降级 |
| 结果增强 | 知识卡片 | 实体摘要卡片、结构化信息提取 |
| 结果增强 | 分面搜索 | 分面计数、分面筛选、分面排序 |
| 基础设施 | 查询日志 | 记录/查询/分析、隐私脱敏 |
| 基础设施 | 正则检索 | 正则编译缓存、超时保护 |
| 基础设施 | 嵌套查询 | AND/OR/NOT 嵌套、深度限制 |

### 1.2 不在范围内

| 排除项 | 原因 |
|--------|------|
| Embedding 模型推理性能 | 属 ModelRuntime 层测试范围 |
| 向量索引构建（HNSW/FAISS） | 属 RAG 引擎测试范围 |
| BM25 索引构建 | 属检索引擎核心测试范围 |

### 1.3 测试目标

| 目标 | 判定 |
|------|------|
| 同义词扩展：召回率提升 | ≥ 15%（对比无扩展基线） |
| 意图分类准确率 | > 85%（3 分类） |
| 重排序 MRR 提升 | ≥ 10%（对比无重排序基线） |
| 拼写纠正准确率 | > 90%（常见拼写错误） |
| 零结果率降低 | 零结果查询减少 ≥ 30% |

## 五、单元测试 — 同义词扩展体系

### 5.1 SynonymEngine — 同义词扩展

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-SE-01 | 短语级扩展 | 查询"检索增强生成" | 扩展包含"RAG"，权重 0.7 |
| UT-SE-02 | 词级扩展 | 查询"模型推理" | 扩展包含"model inference"，权重 0.7 |
| UT-SE-03 | 组合变体生成 | 查询含 2 个可扩展词 | 生成组合变体，权重 = 0.7² = 0.49 |
| UT-SE-04 | 去重截断 | 扩展变体 > 5 个 | 返回最多 5 个变体（按权重降序） |
| UT-SE-05 | 原始查询权重最高 | 任意查询 | 原始查询 weight=1.0，所有扩展 ≤ 0.7 |
| UT-SE-06 | 无匹配词降级 | 查询不含任何同义词 | 仅返回原始查询，无扩展 |
| UT-SE-07 | 词典为空 | SynonymEngine 无种子数据 | 返回原始查询，不报错 |
| UT-SE-08 | 扩展延迟 | 单次查询扩展 | < 5ms |

### 5.2 同义词词典管理

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-SD-01 | 创建词典 | `{domain: "tech", entries: [...]}` | 返回词典 ID，MDB 写入成功 |
| UT-SD-02 | 多领域隔离 | 查询 `domain="tech"` | 不返回 `domain="medical"` 的条目 |
| UT-SD-03 | 语义版本 | 新增同义词（minor bump） | 版本从 1.0.0 → 1.1.0 |
| UT-SD-04 | 版本回滚 | 回滚到 version 1.0.0 | 词典恢复 v1.0.0 的状态 |
| UT-SD-05 | 导入 JSON | 含 10 对的 JSON 文件 | 全部导入成功 |
| UT-SD-06 | 导入 CSV | CSV 格式的词典文件 | 解析正确，条数与 CSV 行数一致 |
| UT-SD-07 | 每领域上限 1000 条 | 第 1001 条插入 | 返回错误，提示超限 |
| UT-SD-08 | 内存缓存刷新 | 写入新同义词后立即查询 | 新同义词在扩展结果中出现 |

### 5.3 同义词图构建

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-SG-01 | 图构建 | 50 对种子同义词 | 节点数 = 不同术语数，边权重默认 0.9 |
| UT-SG-02 | BFS 查询扩展（1 跳） | 查询含直接同义词的术语 | 返回 1 跳邻居，权重 × 衰减⁰ = 0.9 |
| UT-SG-03 | BFS 查询扩展（2 跳）| 查询含传递同义词的术语 | 返回 2 跳邻居，权重 × 衰减¹ = 0.9×0.8=0.72 |
| UT-SG-04 | 权重衰减 | 2 跳扩展 | 权重 < 1 跳扩展的权重 |
| UT-SG-05 | 社区检测 | Louvain 算法 | 模块度 > 0（有效社区分组） |
| UT-SG-06 | 社区内优先 | 查询词所在社区的术语 | 权重 × 1.3（30% 提升） |
| UT-SG-07 | 权重更新 | 共现次数增加 | 贝叶斯平均权重从 0.9 向上调整 |

## 十一、缺陷分级

| 级别 | 定义 | 示例 |
|------|------|------|
| S0 — 阻断 | 检索管道崩溃，所有查询返回错误 | SynonymEngine 初始化失败导致所有请求 500 |
| S1 — 严重 | 核心功能异常，检索质量严重下降 | 同义词扩展始终返回空、拼写纠正错误率 > 50% |
| S2 — 一般 | 单个模块功能异常 | 知识卡片对特定实体返回空、分面计数偏差 > 5% |
| S3 — 轻微 | 边界情况处理不足 | 超长查询（> 500 字符）未截断导致 OOM、特殊 Unicode 字符导致高亮错位 |
| S4 — 建议 | 优化建议 | 同义词建议算法精度提升、知识卡片样式优化 |
