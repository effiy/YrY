## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-CM-01|敏感词过滤|输入含敏感词|标记为违规|P0 |
| UT-CM-02|正常内容放行|正常聊天内容|不标记违规|P0 |
| UT-CM-03|XSS 检测|输入含 script 标签|检测到 XSS 风险|P0 |
| UT-CM-04|SQL 注入检测|输入含 SQL 语句|检测到注入风险|P0 |
| UT-CM-05|路径穿越检测|输入 ../../../etc/passwd|检测到穿越风险|P1 |
| UT-CM-06|审核结果审计|每次检测记录|含检测类型/结果/时间|P1 |
| UT-CM-07|白名单绕过|管理员用户|可选跳过审核|P2 |
| UT-CM-08|审核性能开销|每次请求检测|延迟增加 < 5ms|P1 |
