## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-SC-01|新增可选字段兼容|v2 新增可选字段|检测通过（向后兼容）|P0 |
| UT-SC-02|删除必填字段不兼容|v2 删除 required 字段|检测失败|P0 |
| UT-SC-03|字段类型变更不兼容|int -> str|检测失败|P0 |
| UT-SC-04|新增必填字段不兼容|v2 新增 required 字段|检测失败|P0 |
| UT-SC-05|枚举值新增兼容|新增枚举成员|检测通过|P1 |
| UT-SC-06|枚举值删除不兼容|删除枚举成员|检测失败|P1 |
| UT-SC-07|CI 自动运行|PR 提交|自动运行检测|P0 |
| UT-SC-08|检测报告可读性|不兼容变更|精确指出字段路径和变更类型|P1 |
