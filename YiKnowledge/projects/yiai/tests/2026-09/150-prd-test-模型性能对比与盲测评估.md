## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-ER-01|会话一致性分配|同一 session_id 多次调用|每次返回相同模型|P0 |
| UT-ER-02|流量分配比例|traffic_split=0.3 1000 次|约 300 次到实验组|P0 |
| UT-ER-03|TTFT 指标采集|LLM 调用|记录首 token 时间|P0 |
| UT-ER-04|TPS 指标采集|LLM 调用|记录 tokens/s|P1 |
| UT-ER-05|评分采集|用户点赞/踩|正确记录 rating|P1 |
| UT-ER-06|成本计算|Token 数 x 单价|成本记录到分|P1 |
| UT-ER-07|结果聚合|100+ 样本后 get_results|按组统计延迟/Token/评分|P0 |
| UT-ER-08|实验启停|暂停实验|所有流量回对照组|P0 |
| UT-ER-09|自动熔断|实验组赞率 < 30%|自动停止实验|P1 |
| UT-ER-10|多实验隔离|2 个实验并行|互不干扰|P2 |
