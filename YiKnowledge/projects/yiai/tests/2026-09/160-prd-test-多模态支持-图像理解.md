# YA-09-154: 多模态支持 — 图像理解与视觉 LLM 集成 — 测试规格

> 来源 PRD：[160-需求-多模态支持-图像理解.md](../../prds/2026-09/160-需求-多模态支持-图像理解.md)
> 提取日期：2026-09-11 · 更新日期：2026-09-23

## 一、测试范围与策略

### 测试范围

- **图像预处理**：`src/domain/multimodal/image_processor.py`（新建）— 图片尺寸调整、格式转换（PNG/JPEG/WebP → base64）、分辨率校验、压缩参数调整
- **视觉模型适配**：`src/domain/multimodal/vision_adapter.py`（新建）— Ollama Vision API 适配，base64 编码图片注入到 chat messages
- **聊天集成**：`src/services/ai/chat_service.py`（修改）— SSE 流式中支持图片消息类型，多模态 messages 格式
- **文件上传**：`src/server/routes/upload.py`（新建/修改）— 图片上传端点，格式校验、大小限制
- **排除范围**：具体视觉模型（LLaVA/BakLLaVA）的推理质量测试（属于模型评估），OCR 准确率测试

## 四、边界与异常测试

### EC-01: 纯白色/纯黑色图片
- **步骤**：上传全白（RGB 255,255,255）或全黑（0,0,0）图片
- **预期**：正常编码，不崩溃

### EC-02: 损坏的图片文件
- **步骤**：上传被截断的 PNG 文件
- **预期**：Pillow 抛出异常，返回明确错误信息

### EC-03: 网络传输中图片数据流中断
- **步骤**：SSE 流式响应中，客户端中途断开
- **预期**：服务端清理临时文件，不泄漏资源

### EC-04: 并发上传多张超大图片
- **步骤**：5 个用户同时上传 10MB 图片
- **预期**：全部处理成功，内存使用不超标
