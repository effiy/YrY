# YA-09-79: Dashboard 预聚合快照 — 测试规格
> 来源 PRD：[83-需求-Dashboard预聚合快照.md](../../prds/2026-09/83-需求-Dashboard预聚合快照.md)

## 一、测试范围与策略
### 1.1 测试分层
| 层级 | 工具 | 环境依赖 | 执行时机 |
|------|------|---------|---------|
| L1 单元 | pytest | 无 | 每次提交 |
| L2 集成 | pytest + MongoDB | MongoDB 运行中 | 每次提交 |

### 1.2 覆盖范围
COV-1: 定时预聚合 (apscheduler) COV-2: 聚合结果正确性 COV-3: 快照表结构 COV-4: 快照查询性能优于实时
COV-5: 增量聚合 vs 全量刷新

## 二、测试用例
### 2.1 预聚合任务 (L1)
| 编号 | 用例 | 步骤 | 预期结果 | 优先级 | 状态 |
|------|------|------|---------|--------|------|

| TC-DSB-002 | 聚合数据正确——bugs 按 status 计数 | 1. 插入 bugs 各 status 各 5 条；2. 聚合 | `{open: 5, closed: 5, in_progress: 5}` | P0 | 待实现 |
| TC-DSB-003 | 聚合数据正确——sessions 按日期分组 | 1. 多天 session 数据 | 按日期分组的会话计数正确 | P0 | 待实现 |
