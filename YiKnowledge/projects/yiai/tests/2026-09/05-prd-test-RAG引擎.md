# YA-09-01: RAG 引擎稳定性修复 — 测试规格

> 来源 PRD：[05-需求-RAG引擎.md](../../prds/2026-09/05-需求-RAG引擎.md)
> 开发方案：[05-prd-task-RAG引擎.md](../../devs/2026-09/05-prd-task-RAG引擎.md)
> 需求编号：YA-09-01 · 优先级：P0

> **文档职责**：本文档定义**怎么验证**（VERIFY）。覆盖增量索引回滚、Embedding 维度校验。

---

## 一、单元测试

| 编号 | 用例 | 预期 |
|------|------|------|
| UT-RG-01 | 增量索引部分失败→回滚 | 5 个文件，第 3 个失败 → 索引恢复到快照状态 |
| UT-RG-02 | 增量索引全部成功 | 5 个文件 → 索引更新 + 旧快照被新快照替换 |
| UT-RG-03 | 维度一致→不重建 | dim=768=768 → 加载已有索引 |
| UT-RG-04 | 维度不一致→自动重建 | dim=1024≠768 → WARNING + 重建索引 |
| UT-RG-05 | 重建后检索正常 | 重建完成 → `rag_query` 返回结果 |

---

## 二、集成测试

| 编号 | 场景 | 预期 |
|------|------|------|
| IT-RG-01 | 切换 Embedding 模型 → 自动重建 | 修改 config → 检索 → 维度不匹配 → 重建 → 检索正常 |
| IT-RG-02 | 增量索引失败不丢数据 | 模拟第 3 个文件写入磁盘失败 → 索引保持旧状态 |

## 三、缺陷分级

| 级别 | 示例 |
|------|------|
| S0 — 阻断 | 增量索引部分失败导致索引损坏（检索全空） |
| S1 — 严重 | 维度不匹配但未触发重建（检索全空无告警） |
