# YA-09-66: 缓存智能失效 — 测试规格

> 来源 PRD：[70-需求-缓存智能失效.md](../../prds/2026-09/70-需求-缓存智能失效.md)

本文档定义缓存智能失效策略的**验证方式**——覆盖写操作触发失效、集合级失效、模式匹配失效、Bulk 失效、并发安全。

---

## 一、测试范围与策略

### 1.1 测试分层

| 层级 | 工具 | 环境依赖 | 执行时机 |
|------|------|---------|---------|
| L1 单元 | pytest + fakeredis | 无 | 每次提交 |
| L2 集成 | pytest + Redis + MongoDB | Redis + MongoDB 运行中 | 每次提交 |

### 1.2 覆盖范围

| 编号 | 被测对象 | 层级 |
|------|---------|------|
| COV-1 | create → 集合缓存失效 | L2 |
| COV-2 | update → 单 key 精确失效 | L2 |
| COV-3 | delete → 集合缓存失效 | L2 |
| COV-4 | 模式匹配失效（delete by pattern） | L1 |
| COV-5 | 事务内操作提交后统一失效 | L2 |
| COV-6 | 并发失效安全 | L1 |

### 1.3 测试数据

| 夹具 | 数据 | 用途 |
|------|------|------|
| `cache_keys` | `["query:bugs:*", "query:bugs:hash1", "query:sessions:hash2"]` | 缓存键模式 |
| `invalidation_events` | 写操作后发布的事件 | 触发失效检测 |

---

## 二、测试用例

### 2.1 写操作触发失效（COV-1~3 . L2）

| 编号 | 用例 | 步骤 | 预期结果 | 优先级 | 状态 |
|------|------|------|---------|--------|------|
| TC-CIN-001 | create_document 后相关缓存失效 | 1. 缓存查询结果；2. create 新文档；3. 再次查询 | 缓存未命中，重新查 DB | P0 | 待实现 |
| TC-CIN-002 | update_document 后精确 key 失效 | 1. 缓存单文档查询；2. update 该文档；3. 再次查询 | 该 key 缓存失效，其他 key 保留 | P0 | 待实现 |
| TC-CIN-003 | delete_document 后缓存失效 | 1. 缓存查询；2. delete 文档；3. 再次查询 | 缓存失效，查询结果不含已删文档 | P0 | 待实现 |
| TC-CIN-004 | 集合无关操作不触发失效 | 1. 操作 bugs 集合；2. 检查 sessions 缓存 | sessions 缓存仍有效 | P0 | 待实现 |

### 2.2 模式失效（COV-4 . L1）

| 编号 | 用例 | 步骤 | 预期结果 | 优先级 | 状态 |
|------|------|------|---------|--------|------|
| TC-CIN-005 | pattern 匹配 delete `query:bugs:*` | 1. 创建 5 个 bugs 缓存 key；2. 失效 bugs 集合 | 5 个 bugs 缓存全部删除，sessions 缓存保留 | P0 | 待实现 |
| TC-CIN-006 | 空 pattern 不删除任何 key | 1. 失效空模式 | 无 key 被删除，日志 WARNING | P1 | 待实现 |
| TC-CIN-007 | 模式匹配性能——1000 keys 中删除匹配 100 个 | 1. 预置 1000 keys；2. 失效 100 个匹配 key | 耗时 < 50ms | P1 | 待实现 |

### 2.3 事务与并发（COV-5~6 . L1+L2）

| 编号 | 用例 | 步骤 | 预期结果 | 优先级 | 状态 |
|------|------|------|---------|--------|------|
| TC-CIN-008 | 事务提交后统一失效 | 1. 事务内 create + update；2. commit | commit 后一次性失效相关缓存 | P1 | 待实现 |
| TC-CIN-009 | 事务回滚不失效缓存 | 1. 事务内 create 后 abort | 缓存保持有效（数据未真正变更） | P1 | 待实现 |
| TC-CIN-010 | 并发写操作失效不冲突 | 1. 10 并发 create_document | 所有缓存正确失效，无竞态 | P1 | 待实现 |
