## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-TF-01|流量复制|生产请求 1:1 复制|预发布收到相同请求|P0 |
| UT-TF-02|镜像不阻塞生产|复制到预发布超时|生产请求不受影响|P0 |
| UT-TF-03|响应差异对比|生产 vs 预发布响应|差异报告（字段/状态）|P0 |
| UT-TF-04|采样率可配置|仅复制 5% 生产流量|预发布负载可控|P1 |
| UT-TF-05|敏感数据脱敏后再镜像|请求含 Token|镜像请求脱敏后发送|P1 |
| UT-TF-06|镜像失败降级|预发布不可达|生产请求正常处理|P1 |
| UT-TF-07|差异告警|响应差异持续增加|发送告警通知|P2 |
| UT-TF-08|镜像流量隔离|镜像流量不写入预发布数据库|只读验证|P2 |
