## 三、测试用例

### 3.1 核心功能验证

| 编号 | 用例 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| UT-WH-01|Webhook 注册|注册 URL + 事件类型|注册成功生成 secret|P0 |
| UT-WH-02|事件触发推送|数据变更事件|POST 到注册的 URL|P0 |
| UT-WH-03|投递重试|首次投递失败|重试 3 次指数退避|P0 |
| UT-WH-04|签名验证|HMAC-SHA256 签名|接收方可验证来源|P1 |
| UT-WH-05|投递超时|目标 URL 10s 无响应|标记投递失败|P1 |
| UT-WH-06|投递历史记录|查询历史投递|含状态/耗时/重试次数|P1 |
| UT-WH-07|Webhook 启停|暂停某 Webhook|暂停期间不推送|P2 |
| UT-WH-08|批量事件推送|100 个事件|合并为一次 HTTP 请求|P2 |
