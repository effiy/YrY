# Spec: Auth Conventions

## Overview

本规范定义了 YiAi 的认证授权体系，包括 JWT + bcrypt 认证模式、X-Token 请求头验证、认证中间件配置以及 Agent 安全控制。

---

## 认证模式

YiAi 支持两种认证模式，通过 `middleware.auth_enabled` 配置切换：

### 开发模式 (auth_enabled: false)

所有端点公开，无需认证。适用于本地开发和内部网络。

### 生产模式 (auth_enabled: true)

- **中间件拦截** -- `header_verification_middleware` 检查每个请求的 `X-Token` 请求头
- **JWT 验证** -- `bcrypt` 密码哈希 + `PyJWT` Token 签发/验证
- **Token 过期** -- 默认 1440 分钟 (24 小时)，通过 `jwt.expire_minutes` 配置
- **静态 Token** -- 可通过 `middleware.auth_token` 配置静态 Token (开发/测试用)

---

## 认证流程

### 登录流程

```
用户登录
  -> POST /auth/login { username, password }
  -> bcrypt 验证密码哈希
  -> PyJWT 签发 Token (含 user_id, role, exp)
  -> 返回 { token, user }
```

```python
# domain/auth/ -- 登录逻辑
import bcrypt
import jwt
from datetime import datetime, timedelta
from shared.config import settings

async def login(username: str, password: str):
    """用户登录"""
    # 1. 查找用户
    user = await db.find_one("users", {"key": username})
    if not user:
        raise BusinessException(ErrorCode.UNAUTHORIZED, "用户不存在")

    # 2. 验证密码
    if not bcrypt.checkpw(password.encode(), user["password"].encode()):
        raise BusinessException(ErrorCode.UNAUTHORIZED, "密码错误")

    # 3. 签发 Token
    payload = {
        "user_id": user["key"],
        "role": user.get("role", "user"),
        "exp": datetime.utcnow() + timedelta(minutes=settings.jwt_expire_minutes)
    }
    token = jwt.encode(payload, settings.jwt_secret, algorithm="HS256")

    return {"token": token, "user": user}
```

### 请求验证流程

```
后续请求
  -> 携带 X-Token 请求头
  -> header_verification_middleware 验证 Token
  -> 提取 user 信息 -> 注入 request.state.user
  -> 路由处理函数可通过 request.state.user 获取当前用户
```

## 中间件实现

### 认证中间件

```python
# server/middleware.py
from fastapi import Request
from shared.config import settings
import jwt

async def header_verification_middleware(request: Request, call_next):
    """认证中间件: 验证 X-Token 请求头"""

    # 开发模式: 跳过认证
    if not settings.middleware_auth_enabled:
        return await call_next(request)

    # 静态 Token 模式 (开发/测试)
    if settings.middleware_auth_token:
        token = request.headers.get("X-Token")
        if token == settings.middleware_auth_token:
            request.state.user = {"key": "dev-user", "role": "admin"}
            return await call_next(request)

    # JWT 验证模式
    token = request.headers.get("X-Token")
    if not token:
        return StandardResponse.fail(ErrorCode.UNAUTHORIZED, "Missing X-Token header")

    try:
        payload = jwt.decode(token, settings.jwt_secret, algorithms=["HS256"])
        request.state.user = {
            "key": payload.get("user_id"),
            "role": payload.get("role", "user")
        }
    except jwt.ExpiredSignatureError:
        return StandardResponse.fail(ErrorCode.UNAUTHORIZED, "Token expired")
    except jwt.InvalidTokenError:
        return StandardResponse.fail(ErrorCode.UNAUTHORIZED, "Invalid token")

    return await call_next(request)
```

### 中间件注册

```python
# app.py
from server.middleware import header_verification_middleware

app = FastAPI(lifespan=lifespan)

# 添加认证中间件
```

## Agent 安全

Agent 模式有额外的安全控制：

### 确认门控

- 写操作 (create/update/delete) 需用户确认
- 120s 超时自动拒绝
- 确认通过 `POST /agent/confirm` 端点

### 拒绝记忆

- 同 session 内用户拒绝的工具调用自动拦截
- 拒绝签名: `{tool_name}|{json.dumps(args, sort_keys=True)}`
- 最多记忆 20 条，超过则丢弃最早的

### 工具白名单

- 只有 `ToolRegistry` 注册的工具可被 Agent 调用
- 写操作集合白名单: `_WRITABLE_COLLECTIONS`

### 断开检测

- 客户端断开连接 (`asyncio.CancelledError`) 时自动中止 Agent 循环
- 通过监听 ASGI receive channel 实现

---

## Constraints

### MUST

- 生产环境必须启用 `auth_enabled: true`
- JWT secret 必须修改为安全的随机字符串
- 写操作必须经过确认门控
- Agent 模式必须检查工具白名单
- 敏感字段（如 password）在查询时使用投影排除

### MUST NOT

- 不要在代码中硬编码 JWT secret
- 不要在生产环境使用静态 Token 模式
- 不要在 Agent 模式下绕过确认门控执行写操作
- 不要将密码明文存储

## JWT Refresh Token 轮换

### 双 Token 模式

```python
# domain/auth/tokens.py
import jwt
import uuid
from datetime import datetime, timedelta
from shared.config import settings

class TokenManager:
    """Token 管理器：支持 Access Token + Refresh Token 轮换"""

    def create_access_token(self, user_id: str, role: str) -> str:
        """创建短期 Access Token (15 分钟)"""
        payload = {
            "user_id": user_id,
            "role": role,
            "type": "access",
            "exp": datetime.utcnow() + timedelta(minutes=15),
            "iat": datetime.utcnow(),
            "jti": str(uuid.uuid4())  # 唯一标识，用于撤销
        }
        return jwt.encode(payload, settings.jwt_secret, algorithm="HS256")

    async def create_refresh_token(self, user_id: str) -> str:
        """创建长期 Refresh Token (7 天)"""
        payload = {
            "user_id": user_id,
            "type": "refresh",
            "exp": datetime.utcnow() + timedelta(days=7),
            "iat": datetime.utcnow(),
            "jti": str(uuid.uuid4())
        }
        token = jwt.encode(payload, settings.jwt_refresh_secret, algorithm="HS256")
        # 存储到 MongoDB，用于撤销
        await db.insert_one("refresh_tokens", {
            "jti": payload["jti"],
            "user_id": user_id,
            "expires_at": payload["exp"],
            "rotated": False
        })
        return token

    def verify_access_token(self, token: str) -> dict:
        """验证 Access Token"""
        payload = jwt.decode(token, settings.jwt_secret, algorithms=["HS256"])
        if payload.get("type") != "access":
            raise BusinessException(ErrorCode.UNAUTHORIZED, "无效的 Token 类型")
        return payload

    async def rotate_refresh_token(self, old_token: str) -> dict:
        """轮换 Refresh Token：旧 Token 失效，签发新 Token"""
        payload = jwt.decode(old_token, settings.jwt_refresh_secret, algorithms=["HS256"])

        # 标记旧 Token 为已使用（防止重放攻击）
        result = await db.db["refresh_tokens"].update_one(
            {"jti": payload["jti"], "rotated": False},
            {"$set": {"rotated": True}}
        )
        if result.modified_count == 0:
            raise BusinessException(ErrorCode.UNAUTHORIZED, "Token 已被使用或无效")

        # 签发新 Token
        return {
            "access_token": self.create_access_token(payload["user_id"], payload.get("role", "user")),
            "refresh_token": await self.create_refresh_token(payload["user_id"])
        }
```

### 登录时返回双 Token

```python
@router.post("/auth/login")
async def login(request: Request, data: dict):
    """登录返回 access_token + refresh_token"""
    username = data.get("username")
    password = data.get("password")

    user = await auth.login(username, password)

    token_manager = TokenManager()
    return StandardResponse.success({
        "user": user["user"],
        "access_token": token_manager.create_access_token(user["user"]["key"], user["user"].get("role", "user")),
        "refresh_token": await token_manager.create_refresh_token(user["user"]["key"]),
        "expires_in": 900,  # 15 分钟
        "token_type": "Bearer"
    })

@router.post("/auth/refresh")
async def refresh_token(request: Request, data: dict):
    """刷新 Access Token"""
    refresh_token = data.get("refresh_token")
    if not refresh_token:
        raise BusinessException(ErrorCode.INVALID_PARAMS, "缺少 refresh_token")

    token_manager = TokenManager()
    tokens = await token_manager.rotate_refresh_token(refresh_token)
    return StandardResponse.success(tokens)
```

### 反模式

**不要这样做** -- 单 Token 无过期时间或过期时间过长：

```python
# 错误：Token 有效期 30 天，泄露后无法及时撤销
payload = {
    "user_id": user["key"],
    "exp": datetime.utcnow() + timedelta(days=30)  # 30 天！
}
token = jwt.encode(payload, secret, algorithm="HS256")
# 一旦泄露，攻击者可以在 30 天内冒充用户
```

**不要这样做** -- 对 Refresh Token 不做轮换：

```python
# 错误：Refresh Token 永不过期，无轮换机制
# 攻击者获取 Refresh Token 后可以无限续期
```

## API Key 认证（服务间调用）

### API Key 模式

用于服务间调用（如 YiAi 内部服务间调用，或外部系统集成）：

```python
# domain/auth/api_key.py
import hashlib
import secrets

class ApiKeyManager:
    """API Key 管理：服务间认证"""

    @staticmethod
    def generate_api_key() -> tuple[str, str, str]:
        """生成 API Key 对 (prefix, full_key, secret_hash)
        
        Returns:
            (prefix, full_key, secret_hash) -- prefix 可明文存储，full_key 仅返回一次
        """
        prefix = "yak_" + secrets.token_hex(8)   # yak_16 位前缀
        secret = secrets.token_hex(32)             # 64 位密钥
        full_key = f"{prefix}.{secret}"

        # 存储 hash 到数据库
        secret_hash = hashlib.sha256(secret.encode()).hexdigest()
        return prefix, full_key, secret_hash

    async def create_api_key(self, user_id: str, name: str, scopes: list = None) -> dict:
        """为用户创建 API Key"""
        prefix, full_key, secret_hash = self.generate_api_key()

        await db.insert_one("api_keys", {
            "prefix": prefix,
            "secret_hash": secret_hash,
            "user_id": user_id,
            "name": name,
            "scopes": scopes or ["read"],
            "created_at": datetime.now(timezone.utc),
            "last_used_at": None,
            "revoked": False
        })

        return {"prefix": prefix, "api_key": full_key, "name": name}
        # 注意：full_key 仅在创建时返回一次，之后无法查看

    async def verify_api_key(self, api_key: str) -> dict:
        """验证 API Key"""
        parts = api_key.split(".")
        if len(parts) != 2:
            raise BusinessException(ErrorCode.UNAUTHORIZED, "无效的 API Key 格式")

        prefix, secret = parts
        secret_hash = hashlib.sha256(secret.encode()).hexdigest()

        key_doc = await db.find_one("api_keys", {
            "prefix": prefix,
            "secret_hash": secret_hash,
            "revoked": False
        })

        if not key_doc:
            raise BusinessException(ErrorCode.UNAUTHORIZED, "无效的 API Key")

        # 更新最后使用时间
        await db.update_one(
            "api_keys",
            {"prefix": prefix},
            {"$set": {"last_used_at": datetime.now(timezone.utc)}}
        )

        return key_doc
```

### API Key 认证中间件

```python
# server/middleware.py
async def api_key_middleware(request: Request, call_next):
    """API Key 认证中间件（X-Api-Key 请求头）"""
    api_key = request.headers.get("X-Api-Key")

    if not api_key:
        # 没有 API Key，回退到 JWT 认证
        return await call_next(request)

    api_key_manager = ApiKeyManager()
    try:
        key_doc = await api_key_manager.verify_api_key(api_key)
        request.state.user = {
            "key": key_doc["user_id"],
            "role": "api_key",
            "scopes": key_doc.get("scopes", ["read"])
        }
    except BusinessException:
        return StandardResponse.fail(ErrorCode.UNAUTHORIZED, "无效的 API Key")

    return await call_next(request)
```

### 反模式

**不要这样做** -- 明文存储 API Key：

```python
# 错误：API Key 明文存储，数据库泄露 = 所有 Key 泄露
await db.insert_one("api_keys", {
    "api_key": "yak_abc123.def456789...",  # 明文！
    "user_id": "admin"
})
# 任何人读取数据库都能看到所有有效的 API Key
```

## 角色权限控制 (RBAC)

### 角色定义

```python
# shared/permissions.py
from enum import Enum

class UserRole(str, Enum):
    ADMIN = "admin"           # 超级管理员：所有权限
    MANAGER = "manager"       # 管理员：管理用户 + 项目
    DEVELOPER = "developer"   # 开发者：CRUD 项目数据
    VIEWER = "viewer"         # 观察者：只读
    API_KEY = "api_key"       # API Key：受限权限

# 权限定义
class Permission(str, Enum):
    # 用户管理
    USER_READ = "user:read"
    USER_CREATE = "user:create"
    USER_UPDATE = "user:update"
    USER_DELETE = "user:delete"

    # 项目管理
    PROJECT_READ = "project:read"
    PROJECT_CREATE = "project:create"
    PROJECT_UPDATE = "project:update"
    PROJECT_DELETE = "project:delete"

    # 系统管理
    SYSTEM_CONFIG = "system:config"
    SYSTEM_LOGS = "system:logs"

    # AI 功能
    AI_CHAT = "ai:chat"
    AI_AGENT = "ai:agent"
    AI_RAG = "ai:rag"

# 角色权限映射
ROLE_PERMISSIONS = {
    UserRole.ADMIN: [p for p in Permission],  # 所有权限
    UserRole.MANAGER: [
        Permission.USER_READ,
        Permission.PROJECT_READ, Permission.PROJECT_CREATE,
        Permission.PROJECT_UPDATE, Permission.PROJECT_DELETE,
        Permission.AI_CHAT, Permission.AI_AGENT, Permission.AI_RAG,
    ],
    UserRole.DEVELOPER: [
        Permission.PROJECT_READ, Permission.PROJECT_CREATE,
        Permission.PROJECT_UPDATE,
        Permission.AI_CHAT, Permission.AI_RAG,
    ],
    UserRole.VIEWER: [
        Permission.PROJECT_READ,
        Permission.AI_CHAT,
    ],
    UserRole.API_KEY: [
        Permission.PROJECT_READ,
    ],
}
```

### 权限检查装饰器

```python
# shared/permissions.py
from functools import wraps
from fastapi import Request

def require_permission(permission: Permission):
    """权限检查装饰器"""
    def decorator(func):
        @wraps(func)
        async def wrapper(request: Request, *args, **kwargs):
            user = getattr(request.state, "user", None)
            if not user:
                raise BusinessException(ErrorCode.UNAUTHORIZED, "未登录")

            user_role = UserRole(user.get("role", "viewer"))
            allowed = ROLE_PERMISSIONS.get(user_role, [])

            if permission not in allowed:
                raise BusinessException(
                    ErrorCode.PERMISSION_DENIED,
                    f"需要权限: {permission.value}"
                )

            return await func(request, *args, **kwargs)
        return wrapper
    return decorator

# 使用
@router.delete("/projects/{project_id}")
@require_permission(Permission.PROJECT_DELETE)
async def delete_project(request: Request, project_id: str):
    """删除项目 (需要 project:delete 权限)"""
    # ...
```

## 权限缓存策略

### 缓存架构

```python
# domain/auth/permission_cache.py
import time
from collections import OrderedDict

class PermissionCache:
    """权限缓存：减少数据库查询，提升认证中间件性能"""

    def __init__(self, ttl: int = 300, max_size: int = 10000):
        self._cache = OrderedDict()
        self._ttl = ttl        # 缓存 TTL (秒)，默认 5 分钟
        self._max_size = max_size

    def get(self, user_id: str) -> Optional[dict]:
        """获取缓存的用户权限"""
        entry = self._cache.get(user_id)
        if not entry:
            return None

        if time.time() - entry["cached_at"] > self._ttl:
            del self._cache[user_id]
            return None

        # LRU: 移到末尾
        self._cache.move_to_end(user_id)
        return entry["data"]

    def set(self, user_id: str, data: dict):
        """缓存用户权限"""
        if len(self._cache) >= self._max_size:
            self._cache.popitem(last=False)  # 淘汰最旧的

        self._cache[user_id] = {
            "data": data,
            "cached_at": time.time()
        }

    def invalidate(self, user_id: str):
        """使指定用户的缓存失效"""
        self._cache.pop(user_id, None)

    def invalidate_all(self):
        """使所有缓存失效"""
        self._cache.clear()

# 全局实例
permission_cache = PermissionCache(ttl=300, max_size=10000)
```

### 缓存失效场景

| 场景 | 操作 |
|------|------|
| 用户角色变更 | `permission_cache.invalidate(user_id)` |
| 权限配置更新 | `permission_cache.invalidate_all()` |
| 用户被删除/禁用 | `permission_cache.invalidate(user_id)` |
| 系统重启 | 自动清空（内存缓存） |

### 反模式

**不要这样做** -- 每次请求都查数据库获取用户信息：

```python
# 错误：每次请求都查数据库，即使 Token 有效
async def middleware(request, call_next):
    token = request.headers.get("X-Token")
    payload = jwt.decode(token, secret, algorithms=["HS256"])
    user = await db.find_one("users", {"key": payload["user_id"]})
    # 每次请求一次数据库查询，高并发下成为瓶颈
    request.state.user = user
    return await call_next(request)
```

## 会话失效

### 主动失效机制

```python
# domain/auth/session.py
class SessionManager:
    """会话管理：支持主动失效和全设备登出"""

    async def invalidate_session(self, user_id: str, jti: str):
        """使指定 Token 失效"""
        await db.insert_one("token_blacklist", {
            "jti": jti,
            "user_id": user_id,
            "invalidated_at": datetime.now(timezone.utc),
            "expires_at": datetime.now(timezone.utc) + timedelta(days=7)
        })
        # 同时清除权限缓存
        permission_cache.invalidate(user_id)

    async def invalidate_all_sessions(self, user_id: str):
        """使该用户所有 Token 失效（全设备登出）"""
        # 记录失效时间，所有在此时间之前签发的 Token 都无效
        await db.update_one(
            "users",
            {"key": user_id},
            {"$set": {"token_invalidated_before": datetime.now(timezone.utc)}}
        )
        permission_cache.invalidate(user_id)

    async def is_token_valid(self, jti: str, user_id: str) -> bool:
        """检查 Token 是否已被撤销"""
        # 1. 检查黑名单
        blacklisted = await db.find_one("token_blacklist", {"jti": jti})
        if blacklisted:
            return False

        # 2. 检查全设备登出时间
        user = await db.find_one("users", {"key": user_id})
        if user and user.get("token_invalidated_before"):
            return False

        return True
```

## 用户级速率限制

### 速率限制配置

```python
# domain/auth/rate_limiter.py
from collections import defaultdict
import time

class UserRateLimiter:
    """用户级速率限制"""

    def __init__(self):
        # 端点级限制配置
        self._limits = {
            "auth/login": {"rate": 5, "window": 60},       # 60s 内最多 5 次登录
            "auth/register": {"rate": 3, "window": 3600},   # 1h 内最多 3 次注册
            "agent/chat": {"rate": 30, "window": 60},       # 60s 内最多 30 次 Agent 调用
            "ai/chat": {"rate": 60, "window": 60},          # 60s 内最多 60 次聊天
            "file/upload": {"rate": 20, "window": 60},      # 60s 内最多 20 次上传
            "default": {"rate": 100, "window": 60},         # 默认 60s 内 100 次
        }
        self._buckets = defaultdict(lambda: defaultdict(list))

    def check(self, user_id: str, endpoint: str) -> tuple[bool, dict]:
        """检查是否允许请求
        
        Returns:
            (allowed, headers)
        """
        limit = self._limits.get(endpoint, self._limits["default"])
        rate = limit["rate"]
        window = limit["window"]

        now = time.time()
        bucket = self._buckets[user_id][endpoint]

        # 清理过期的请求记录
        bucket[:] = [t for t in bucket if now - t < window]

        if len(bucket) >= rate:
            reset_at = int(bucket[0] + window) if bucket else int(now + window)
            return False, {
                "X-RateLimit-Limit": str(rate),
                "X-RateLimit-Remaining": "0",
                "X-RateLimit-Reset": str(reset_at),
                "Retry-After": str(int(reset_at - now))
            }

        bucket.append(now)
        return True, {
            "X-RateLimit-Limit": str(rate),
            "X-RateLimit-Remaining": str(rate - len(bucket)),
            "X-RateLimit-Reset": str(int(now + window))
        }

# 全局实例
user_rate_limiter = UserRateLimiter()
```

```python
# 响应头中提示 Token 即将过期
def _get_token_expiry_headers(payload: dict) -> dict:
    """检查 Token 剩余有效时间，添加提示头"""
    exp = payload.get("exp", 0)
    now = time.time()
    remaining = exp - now

    if remaining <= 0:
        return {"X-Token-Status": "expired"}

    if remaining < 300:  # 5 分钟内过期
        return {"X-Token-Status": "expiring_soon", "X-Token-Expires-In": str(int(remaining))}

    return {"X-Token-Status": "valid"}
```

### 多重认证方式优先级

```python
# 认证优先级：API Key > JWT Token > 静态 Token > 匿名
async def auth_middleware(request: Request, call_next):
    """多认证方式中间件"""

    # 1. API Key 优先
    api_key = request.headers.get("X-Api-Key")
    if api_key:
        return await _authenticate_with_api_key(request, call_next, api_key)

    # 2. JWT Token
    token = request.headers.get("X-Token")
    if token:
        return await _authenticate_with_jwt(request, call_next, token)

    # 3. 静态 Token (开发环境)
    if settings.middleware_auth_token:
        static_token = request.headers.get("X-Token")
        if static_token == settings.middleware_auth_token:
            request.state.user = {"key": "dev-user", "role": "admin"}
            return await call_next(request)

    # 4. 匿名访问
    if not settings.middleware_auth_enabled:
        return await call_next(request)

    return StandardResponse.fail(ErrorCode.UNAUTHORIZED)
```

### 密码强度校验

```python
import re

def validate_password_strength(password: str) -> tuple[bool, str]:
    """密码强度校验"""
    if len(password) < 8:
        return False, "密码长度至少 8 位"

    if not re.search(r"[A-Z]", password):
        return False, "密码必须包含大写字母"

    if not re.search(r"[a-z]", password):
        return False, "密码必须包含小写字母"

    if not re.search(r"\d", password):
        return False, "密码必须包含数字"

    if not re.search(r"[!@#$%^&*(),.?\":{}|<>]", password):
        return False, "密码必须包含特殊字符"

    return True, ""
```
