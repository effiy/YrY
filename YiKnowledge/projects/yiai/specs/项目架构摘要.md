# 项目架构摘要

## 一、技术栈概览

### 核心框架与库

| 类别 | 技术选型 | 版本/说明 |
|------|---------|----------|
| 语言 | Python | 3.10+ |
| Web 框架 | FastAPI | ASGI 异步框架 |
| 服务器 | uvicorn | ASGI 服务器，端口 10086 |
| 数据库 | MongoDB | Motor 异步驱动 |
| 配置 | pydantic-settings | YAML 配置源 (`YamlConfigSettingsSource`) |
| LLM 推理 | Ollama | 自托管，`http://localhost:11434` |
| RAG 引擎 | llama_index | 向量 + BM25 混合检索 |
| 认证 | bcrypt + PyJWT | 可选 X-Token 请求头验证 |
| 调度 | apscheduler | 知识库轮询扫描 |
| 重试 | tenacity | 网络/MongoDB/Ollama 瞬态故障重试 |

### 开发工具链

- **代码规范**: ruff (ruff.toml)
- **测试框架**: pytest 8 + pytest-asyncio + httpx + pytest-cov
- **配置**: `pyproject.toml` (pytest 配置), `ruff.toml` (lint 配置)

## 三、分层架构

```
┌──────────────────────────────────────────────┐
│  HTTP Layer (server/)                         │
│  Middleware -> Routes -> Exception Handlers   │
│  20 个路由模块，统一 RPC 分发器                │
├──────────────────────────────────────────────┤
│  Service Layer (services/)                    │
│  封装 domain 逻辑，提供 routes 调用接口        │
│  ai/ database/ execution/ knowledge/ rag/     │
│  rss/ storage/                                │
├──────────────────────────────────────────────┤
│  Domain Layer (domain/)                       │
│  业务逻辑: AI/Agent, Files, RAG, Knowledge,   │
│  RSS, Auth, Execution, State, WeWork, Search  │
├──────────────────────────────────────────────┤
│  Data Layer (data/)                           │
│  MongoDB 单例 -> Repository -> Session/Store  │
│  Motor async driver, 种子数据                  │
├──────────────────────────────────────────────┤
│  Shared Layer (shared/)                       │
│  Config, Response, ErrorCodes, Utils, Logging │
│  pydantic-settings + YAML 配置源              │
└──────────────────────────────────────────────┘
```

### 模块边界规则

| 层 | 可以导入 | 禁止导入 |
|----|---------|---------|
| `server/` | `services/`, `shared/` | `domain/`（通过 services 间接调用） |
| `services/` | `domain/`, `data/`, `shared/` | `server/` |
| `domain/` | `data/`, `shared/` | `server/`, `services/` |
| `data/` | `shared/` | `server/`, `services/`, `domain/` |
| `shared/` | 无 | `server/`, `services/`, `domain/`, `data/` |

## 四、数据流

### 4.1 RPC 请求流

```
YiPet / YiVad
   │ fetch() POST /  body: {module_name, method_name, parameters}
   ▼
FastAPI 根路由处理器
   │ 解析 module_name -> Python 模块路径
   │ 解析 method_name -> 可调用对象
   │ 解析 parameters -> kwargs
   ▼
services.<domain>.<service>.<method>(**parameters)
   │ 参数校验 + 业务编排
   ▼
domain 层: 核心业务逻辑
   ▼
data 层: MongoDB 操作 (Motor async)
   ▼
StandardResponse(code=0, message="ok", data=result)
```

### 4.2 Chat SSE 流

```
POST /agent/chat  { messages, model, max_turns, system?, tools? }
   │
   ▼
Agent.run() 循环
   │ 每轮:
   │   turn_start -> LLM 推理
   │   -> 解析响应 (text + tool_calls)
   │   -> 工具调用: tool_execution_start -> 确认门控 -> tool_execution_end
   │   -> turn_end
   │ 循环直到 stop=completed 或 max_turns
   ▼
SSE 流: text/event-stream
   data: {"type":"turn_start","turn":1}
   data: {"type":"tool_call","tool":"db_list","args":{...}}
   data: {"type":"confirmation_required","tool":"db_create"}
   data: {"type":"tool_execution_start","tool":"db_create"}
   data: {"type":"tool_execution_end","tool":"db_create","result":{...}}
   data: {"type":"turn_end","summary":"..."}
   data: {"type":"agent_end","stop_reason":"completed","turns":3}
```

### 4.3 文件双写持久化

```
POST /write-file {target_file, content}
   │ 1. 写入本地磁盘 (主存储，失败则整体失败)
   │ 2. best-effort upsert 到 MongoDB static_files 集合 (备份)
   ▼
成功
```

### 4.4 知识库扫描

```
YiKnowledge Markdown 文件树
   ↓ apscheduler 每 60s 轮询
Knowledge Watcher -> 解析 frontmatter + 正文
   ↓ 同步到 MongoDB knowledge_files 集合
llama_index 索引构建
   ↓ VectorStoreIndex + BM25
混合检索 (向量 + BM25)
   ↓ 可选 LLM Rerank
   ↓ HyDE 查询增强
   ↓ Sentence Window 检索
RAG 查询结果 -> 用户
```

### 5.2 pydantic-settings 加载流程

```python
# shared/config.py
class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        yaml_file="config.yaml",
        yaml_file_encoding="utf-8",
    )

    @classmethod
    def settings_customise_sources(cls, ...):
        # YAML 文件 -> 环境变量 -> 默认值
        return (YamlConfigSettingsSource, ...)

settings = Settings()  # 全局单例
```

## 六、降级策略

| 场景 | 行为 |
|------|------|
| MongoDB 不可用 | 写入失败，读取返回空结果 |
| Ollama 不可用 | 聊天端点返回 `ErrorCode.AI_UNAVAILABLE` |
| OSS 不可用 | 文件存储回退到本地磁盘 |
| Auth 禁用 | 所有端点公开 (开发环境默认) |
| Agent 模型停滞 | 自动切换到 fallback 模型 |
| Agent 断连 | `asyncio.CancelledError` -> 保存当前状态 -> 清理 |
| RAG 索引缺失 | 返回空结果 -> 提示先构建索引 |
