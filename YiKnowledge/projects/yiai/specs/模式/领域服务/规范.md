# Pattern: Domain Service

## Overview

领域服务模式是 YiAi 的核心架构模式。每个业务领域封装在 `domain/` 下的独立模块中，通过 `services/` 层对外暴露，最终由 `server/routes/` 调用。本模式定义了从 domain 到 service 到 route 的完整实现规范。

**相关规范**：
- [模块结构规范](../../架构/模块结构/规范.md) -- 目录结构和分层规则
- [API 规范](../../架构/api规范/规范.md) -- 路由和 RPC 协议
- [数据库规范](../../架构/数据库规范/规范.md) -- MongoDB 访问模式

## 架构层次

```
server/routes/example.py     # HTTP 路由: 参数提取 + 响应格式化
        |
        v
services/example/
  example_service.py         # 服务层: 参数校验 + 业务编排
        |
        v
domain/example/
  __init__.py                # 公共 API 导出
  core.py                    # 核心业务逻辑
  helpers.py                 # 辅助函数
        |
        v
data/
  database.py                # MongoDB 单例
  repository.py              # 通用仓库
```

## Domain 模块结构

### 简单模块 (单文件)

适用于逻辑简单的领域，不需要 `__init__.py`：

```
domain/auth/
├── auth.py          # JWT + bcrypt 逻辑
```

```python
# domain/auth/auth.py
import bcrypt
import jwt
from datetime import datetime, timedelta
from shared.config import settings
from shared.exceptions import BusinessException
from shared.error_codes import ErrorCode
from data.database import db

async def login(username: str, password: str) -> dict:
    """用户登录"""
    user = await db.find_one("users", {"key": username})
    if not user:
        raise BusinessException(ErrorCode.UNAUTHORIZED, "用户不存在")

    if not bcrypt.checkpw(password.encode(), user["password"].encode()):
        raise BusinessException(ErrorCode.UNAUTHORIZED, "密码错误")

    payload = {
        "user_id": user["key"],
        "role": user.get("role", "user"),
        "exp": datetime.utcnow() + timedelta(minutes=settings.jwt_expire_minutes)
    }
    token = jwt.encode(payload, settings.jwt_secret, algorithm="HS256")

    return {"token": token, "user": {k: v for k, v in user.items() if k != "password"}}

async def verify_token(token: str) -> dict:
    """验证 Token"""
    payload = jwt.decode(token, settings.jwt_secret, algorithms=["HS256"])
    return {"user_id": payload["user_id"], "role": payload.get("role", "user")}
```

### 复杂模块 (多文件 + __init__.py)

适用于逻辑复杂的领域，通过 `__init__.py` 定义公共 API：

```
domain/files/
├── __init__.py      # 公共 API 导出
├── local.py         # 本地文件操作
├── storage.py       # OSS 存储操作
└── paths.py         # 路径处理工具
```

```python
# domain/files/__init__.py
from .local import read_file, write_file, delete_file, rename_file
from .local import delete_folder, rename_folder
from .storage import upload_image

__all__ = [
    "read_file",
    "write_file",

```

```python
# domain/files/local.py
import os
import base64
from datetime import datetime, timezone
from data.database import db
from .paths import resolve_path

async def read_file(target_file: str) -> dict:
    """读取文件内容"""
    file_path = resolve_path(target_file)

    if not os.path.exists(file_path):
        raise BusinessException(ErrorCode.DATA_NOT_FOUND, f"File not found: {target_file}")

    with open(file_path, "r", encoding="utf-8") as f:
        content = f.read()

    return {"file_path": target_file, "content": content}

async def write_file(target_file: str, content: str, is_base64: bool = False) -> dict:
    """写入文件 (磁盘 + MongoDB 双写)"""
    file_path = resolve_path(target_file)
    os.makedirs(os.path.dirname(file_path), exist_ok=True)

    # 1. 主存储: 写入磁盘
    if is_base64:
        content = base64.b64decode(content).decode("utf-8")
    with open(file_path, "w", encoding="utf-8") as f:
        f.write(content)

    # 2. 备份: MongoDB (best-effort)
    try:
        await db.update_one(
            "static_files",
            {"file_path": target_file},
            {"$set": {
                "file_path": target_file,
                "content": content,
                "updated_at": datetime.now(timezone.utc)
            }},
            upsert=True
        )
    except Exception as e:
        logger.warning(f"Failed to backup file to MongoDB: {e}")

    return {"file_path": target_file, "status": "ok"}
```

## Service 层封装

### Service 类模式

```python
# services/example/example_service.py
from domain.example import do_something
from domain.example.helpers import validate_params
from shared.exceptions import BusinessException
from shared.error_codes import ErrorCode

class ExampleService:
    """示例服务，封装 domain 逻辑"""

    async def create_item(self, data: dict) -> dict:
        """创建条目"""
        # 1. 参数校验
        if not data.get("name"):
            raise BusinessException(ErrorCode.INVALID_PARAMS, "name is required")

        validate_params(data)

        # 2. 调用 domain 逻辑
        result = await do_something(data)

        return result

    async def list_items(self, filter: dict = None, pageNum: int = 1, pageSize: int = 20) -> dict:
        """列表查询"""
        from data.repository import Repository
        repository = Repository()

        return await repository.query_documents(
            cname="items",
            filter=filter,
            pageNum=pageNum,
            pageSize=pageSize,
            orderBy="created_at",
            orderType="desc"
        )
```

### Service 调用示例

```python
# 在路由中使用
```

## RPC 分发模式

### 服务注册

```python
# app.py 中的 RPC 分发器
_SERVICE_MAP = {
    "services.database.data_service": DataService(),
    "services.database.session_service": SessionService(),
    "services.ai.chat_service": ChatService(),
    "services.knowledge.knowledge_service": KnowledgeService(),
    "services.rag.rag_service": RagService(),
    "services.rss.feed_service": FeedService(),
}

def _resolve_service(module_name: str):
    """根据 module_name 定位 service 实例"""
    service = _SERVICE_MAP.get(module_name)
    if not service:
        raise BusinessException(ErrorCode.INVALID_PARAMS, f"Unknown module: {module_name}")
    return service
```

### RPC 调用

```python
@router.post("/")
async def rpc_handler(request: Request, body: dict):
    """RPC 分发器"""
    module_name = body.get("module_name")
    method_name = body.get("method_name")
    parameters = body.get("parameters", {})

    service = _resolve_service(module_name)
    method = getattr(service, method_name, None)

    if not method:
        raise BusinessException(ErrorCode.INVALID_PARAMS,
                               f"Unknown method: {method_name}")

    result = await method(**parameters)
    return StandardResponse.success(result)
```

## 完整示例: 新增一个领域模块

### Step 1: 创建 domain 模块

```python
# domain/notification/__init__.py
from .sender import send_notification, send_bulk_notifications

__all__ = ["send_notification", "send_bulk_notifications"]
```

```python
# domain/notification/sender.py
import logging
from data.database import db
from shared.exceptions import BusinessException
from shared.error_codes import ErrorCode

logger = logging.getLogger(__name__)

async def send_notification(user_id: str, message: str, channel: str = "system") -> dict:
    """发送单条通知"""
    if not user_id or not message:
        raise BusinessException(ErrorCode.INVALID_PARAMS, "user_id and message are required")

    doc = {
        "user_id": user_id,
        "message": message,
        "channel": channel,
        "read": False,
        "created_at": datetime.now(timezone.utc)
    }

    doc_id = await db.insert_one("notifications", doc)

    logger.info(f"Notification sent to user {user_id}: {message[:50]}...")
    return {"id": doc_id, "status": "sent"}

async def send_bulk_notifications(user_ids: list, message: str) -> dict:
    """批量发送通知"""
    docs = [
        {
            "user_id": uid,
            "message": message,
            "read": False,
            "created_at": datetime.now(timezone.utc)
        }
        for uid in user_ids
    ]

    doc_ids = await db.insert_many("notifications", docs)
    return {"ids": doc_ids, "count": len(doc_ids), "status": "sent"}
```

### Step 2: 创建 service 封装

```python
# services/notification/notification_service.py
from domain.notification import send_notification, send_bulk_notifications
from shared.exceptions import BusinessException
from shared.error_codes import ErrorCode

class NotificationService:
    """通知服务"""

    async def send(self, user_id: str, message: str, channel: str = "system") -> dict:
        """发送通知 -- 参数校验 + 业务编排"""
        if not user_id:
            raise BusinessException(ErrorCode.INVALID_PARAMS, "user_id is required")
        if not message:
            raise BusinessException(ErrorCode.INVALID_PARAMS, "message is required")
        if len(message) > 1000:
            raise BusinessException(ErrorCode.INVALID_PARAMS, "message too long (max 1000 chars)")

        return await send_notification(user_id, message, channel)

    async def send_bulk(self, user_ids: list, message: str) -> dict:
        """批量发送"""
        if not user_ids:
            raise BusinessException(ErrorCode.INVALID_PARAMS, "user_ids is required")
        if len(user_ids) > 100:
            raise BusinessException(ErrorCode.INVALID_PARAMS, "max 100 users per batch")

        return await send_bulk_notifications(user_ids, message)
```

### Step 3: 创建路由

```python
# server/routes/notification.py
from fastapi import APIRouter, Request
from services.notification.notification_service import NotificationService
from shared.response import StandardResponse

router = APIRouter()
notification_service = NotificationService()

@router.post("/notification/send")
async def send_notification(request: Request, data: dict):
    """发送通知"""
    result = await notification_service.send(
        user_id=data.get("user_id"),
        message=data.get("message"),
        channel=data.get("channel", "system")
    )
    return StandardResponse.success(result)

@router.post("/notification/send-bulk")
async def send_bulk_notifications(request: Request, data: dict):
    """批量发送通知"""
    result = await notification_service.send_bulk(
        user_ids=data.get("user_ids", []),
        message=data.get("message")
    )
    return StandardResponse.success(result)
```

### Step 4: 注册路由

```python
# app.py
from server.routes import notification

app.include_router(notification.router)
```

## Checklist

新增领域模块时检查：

- [ ] domain 模块在 `domain/` 下创建，仅依赖 `data/` 和 `shared/`
- [ ] 如有多个内部文件，通过 `__init__.py` 导出公共 API
- [ ] service 封装在 `services/` 下，进行参数校验
- [ ] 路由在 `server/routes/` 下创建，使用 `APIRouter()`
- [ ] 在 `app.py` 中注册路由
- [ ] 业务异常使用 `BusinessException` 抛出
- [ ] 响应使用 `StandardResponse.success()` / `StandardResponse.fail()`
- [ ] 数据库操作通过 `db` 单例或 `Repository` 进行
- [ ] 异步函数使用 `async/await`

## 服务依赖注入模式

### 依赖注入设计

通过构造函数注入依赖，而非在服务内部直接实例化：

```python
# services/example/example_service.py
from data.database import MongoDB
from data.repository import Repository
from domain.notification import NotificationSender

class ExampleService:
    """示例服务：通过构造函数注入依赖"""

    def __init__(
        self,
        db: MongoDB = None,
        repository: Repository = None,
        notifier: NotificationSender = None
    ):
        self._db = db or db
        self._repository = repository or Repository()
        self._notifier = notifier

    async def create_item(self, data: dict) -> dict:
        """创建条目，创建成功后发送通知"""
        if not data.get("name"):
            raise BusinessException(ErrorCode.INVALID_PARAMS, "name is required")

        result = await self._repository.create_document("items", data)

        # 使用注入的 notifier
        if self._notifier:
            await self._notifier.send(
                user_id=data.get("owner_key"),
                message=f"新条目创建: {data['name']}"
            )

        return result
```

### 服务工厂模式

```python
# services/__init__.py
from data.database import db
from data.repository import Repository
from domain.notification import NotificationSender

class ServiceFactory:
    """服务工厂：统一管理服务实例的创建和依赖注入"""

    _instances = {}

    @classmethod
    def get_example_service(cls) -> "ExampleService":
        """获取 ExampleService 实例（单例）"""
        if "example" not in cls._instances:
            cls._instances["example"] = ExampleService(
                db=db,
                repository=Repository(),
                notifier=NotificationSender(db)
            )
        return cls._instances["example"]

    @classmethod
    def get_data_service(cls) -> "DataService":
        """获取 DataService 实例"""
        if "data" not in cls._instances:
            cls._instances["data"] = DataService(
                db=db,
                repository=Repository()
            )
        return cls._instances["data"]

    @classmethod
    def reset(cls):
        """重置所有服务实例（测试用）"""
        cls._instances.clear()

# 使用
from services import ServiceFactory

data_service = ServiceFactory.get_data_service()
example_service = ServiceFactory.get_example_service()
```

### 依赖注入的好处

| 好处 | 说明 |
|------|------|
| 可测试性 | 测试时可注入 mock 依赖 |
| 解耦 | 服务不依赖具体实现，只依赖接口 |
| 可替换 | 需要替换实现时只需修改工厂 |
| 清晰依赖 | 构造函数的参数明确声明了依赖关系 |

### 反模式

**不要这样做** -- 在服务内部直接实例化依赖：

```python
# 错误：服务内部直接创建依赖，无法在测试中替换
class ExampleService:
    async def create_item(self, data: dict) -> dict:
        db = MongoDB()  # 直接实例化，无法 mock
        result = await db.insert_one("items", data)
        return result
```

**不要这样做** -- 使用全局变量传递依赖：

```python
# 错误：全局变量，测试间互相干扰
current_db = None  # 模块级全局变量

class ExampleService:
    async def create_item(self, data: dict) -> dict:
        global current_db
        result = await current_db.insert_one("items", data)
        return result
```

### 反模式

**不要这样做** -- 测试中使用真实数据库：

```python
# 错误：测试依赖真实 MongoDB，运行慢且不可靠
async def test_create_item():

```

```python
# domain/ai/context.py
from contextlib import asynccontextmanager
from typing import AsyncGenerator

class ModelRuntime:
    """LLM 模型运行时：需要显式初始化和清理"""

    def __init__(self, model_name: str):
        self.model_name = model_name
        self._client = None

    async def initialize(self):
        """初始化模型连接"""
        self._client = await create_ollama_client(self.model_name)
        logger.info(f"模型 {self.model_name} 初始化完成")

    async def close(self):
        """清理资源"""
        if self._client:
            await self._client.close()
            logger.info(f"模型 {self.model_name} 连接已关闭")

    async def chat(self, messages: list) -> str:
        if not self._client:
            raise RuntimeError("模型未初始化，请先调用 initialize()")
        return await self._client.chat(messages)

@asynccontextmanager
async def model_session(model_name: str) -> AsyncGenerator[ModelRuntime, None]:
    """模型会话上下文管理器"""
    runtime = ModelRuntime(model_name)
    try:
        await runtime.initialize()
        yield runtime
    finally:
        await runtime.close()
```

```python
# domain/knowledge/watcher.py
import asyncio

class BackgroundWatcher:
    """后台轮询任务：知识库变更检测"""

    def __init__(self, poll_interval: int = 60):
        self._poll_interval = poll_interval
        self._task = None
        self._running = False

    async def start(self):
        """启动后台轮询"""
        self._running = True
        self._task = asyncio.create_task(self._poll_loop())

    async def stop(self):
        """停止后台轮询"""
        self._running = False
        if self._task:
            self._task.cancel()
            try:
                await self._task
            except asyncio.CancelledError:
                pass

    async def _poll_loop(self):
        """轮询循环"""
        while self._running:
            try:
                await self._check_for_changes()
            except Exception as e:
                logger.error(f"轮询检查失败: {e}")

            await asyncio.sleep(self._poll_interval)

    async def _check_for_changes(self):
        """检查知识库变更"""
        # 扫描文件树，检测变更
        changes = await self._scanner.scan()
        if changes:
            await self._sync_to_mongodb(changes)
            await self._rebuild_index()
```

## 事件驱动通信

### 事件总线

```python
# shared/event_bus.py
import asyncio
from collections import defaultdict
from typing import Callable, Dict, List

class EventBus:
    """轻量级事件总线，用于服务间解耦通信"""

    def __init__(self):
        self._handlers: Dict[str, List[Callable]] = defaultdict(list)

    def on(self, event: str, handler: Callable):
        """注册事件处理器"""
        self._handlers[event].append(handler)

    def off(self, event: str, handler: Callable):
        """移除事件处理器"""
        if event in self._handlers:
            self._handlers[event].remove(handler)

    async def emit(self, event: str, **data):
        """触发事件，异步通知所有处理器"""
        handlers = self._handlers.get(event, [])
        if not handlers:
            return

        tasks = [handler(**data) for handler in handlers]
        results = await asyncio.gather(*tasks, return_exceptions=True)

        for handler, result in zip(handlers, results):
            if isinstance(result, Exception):
                logger.error(f"事件处理器 {handler.__name__} 失败: {result}")

# 全局实例
event_bus = EventBus()
```

## Constraints

### MUST

- domain 模块只依赖 `data/` 和 `shared/`
- service 层负责参数校验和业务编排
- 路由层只做参数提取和响应格式化
- 有多个内部文件的 domain 模块必须通过 `__init__.py` 导出公共 API
- 业务异常使用 `BusinessException` 抛出
- 所有异步函数使用 `async/await`
- 服务依赖通过构造函数注入
- 使用 `async with` 管理资源生命周期
- 耗时操作使用后台任务处理
- 服务间通信使用事件总线

### MUST NOT

- 不要在 domain 中导入 `server/` 或 `services/`
- 不要在路由中直接调用 domain 模块
- 不要在 service 中处理 HTTP 请求/响应
- 不要绕过 `__init__.py` 直接导入 domain 内部文件
- 不要创建循环依赖
- 不要使用全局变量传递依赖
- 不要在请求处理中执行耗时操作
- 不要在领域逻辑中直接调用不相关的服务
