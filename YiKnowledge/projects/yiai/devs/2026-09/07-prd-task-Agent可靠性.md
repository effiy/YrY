<a id="sec-1"></a>
## 一、问题背景

Agent 在工具调用和 LLM 推理阶段缺乏超时保护——单次工具调用卡住会导致整个对话循环僵死。SSE 流中的错误也未正确传播到前端。

### 分层超时

```mermaid
flowchart TD
  A["Agent 对话循环"] --> B["LLM 推理超时: 120s"]
  B --> C["工具调用超时: 30s/工具"]
  C --> D["单次 HTTP 请求超时: 10s"]
  D -- 超时 --> E["向上传播 TimeoutError"]
  E --> F["前端 SSE 收到 error 帧"]
```

---

<a id="sec-2"></a>
## 二、实施步骤

| 步骤 | 内容 | 验证 | 人天 |
|------|------|------|------|
| 1 | 分层超时（LLM 120s / 工具 30s / HTTP 10s） | 各层超时正确触发 | 1.0 |
| 2 | SSE 错误帧传播 | 前端收到 `{"error": "..."}` | 0.75 |
| 3 | Agent 循环恢复——超时后继续下一轮 | 不僵死 | 0.75 |

**合计：2.5d**。
