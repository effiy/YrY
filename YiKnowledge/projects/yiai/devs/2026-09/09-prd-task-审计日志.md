## 一、方案

将 [YA-08-04 审计装饰器](../2026-08/04-prd-task-预写审计日志.md) 和 [YA-08-08 增强版](../2026-08/08-prd-task-预写审计日志系统.md) 全面集成到所有关键 RPC 方法，并提供查询 API。

### 集成范围

| RPC 方法 | 审计内容 |
|----------|---------|
| `data_service.create_document` | 创建的集合、文档 key、内容 |
| `data_service.update_document` | 变更字段 diff |
| `data_service.delete_document` | 删除的集合、文档 key |
| `chat_service.chat` | 会话 key、消息长度（不含内容） |
| `/write-file` | 文件路径、大小 |
