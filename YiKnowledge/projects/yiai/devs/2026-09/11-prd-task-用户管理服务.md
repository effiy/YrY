## 一、方案

扩展 YA-07-06 认证系统的基础用户 CRUD，增加批量导入导出、部门树、字典端点。

### 新增端点

| 端点 | 功能 |
|------|------|
| `POST /users/import` | CSV 批量导入用户 |
| `GET /users/export` | CSV 导出用户列表 |
| `GET /dict/department` | 部门字典树 |
| `GET /dict/role` | 角色字典 |
| `GET /dict/status` | 状态字典 |
