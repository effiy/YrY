## 二、关键技术决策

### D-01：多轮检索 — 查询融合而非独立检索

对话历史中的查询提供额外上下文。第 N 轮检索时，将前 N-1 轮 query 的 Embedding 加权平均（衰减因子 0.7）融合到当前查询，提升上下文的语义连贯性。

### D-02：可解释性 — 相关性分维度拆解

不返回单一的 `score`，拆解为 `{bm25_score, vec_score, freshness_bonus, field_match}` 四维度，前端展示"为什么这条结果排在前面"。

### D-03：结果聚类 — 基于标签+Embedding 双重

先按 frontmatter `category`/`tags` 字段快速分桶，桶内按 Embedding 相似度细分为子类。聚类标签自动生成（取类内 top-3 高频词）。
