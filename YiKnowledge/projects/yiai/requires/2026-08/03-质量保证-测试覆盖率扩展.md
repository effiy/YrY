### 功能概述

扩展 YiAi 后端的 pytest 测试覆盖范围，覆盖 `shared/`、`data/` 和 `domain/` 模块。已落地 76 个测试用例（2026-08-21），`shared/` 模块接近 100% 覆盖。

### 技术实现

#### 测试框架

- **测试框架**：pytest + pytest-asyncio（异步测试支持）
- **Mock 工具**：unittest.mock + pytest-mock
- **覆盖率工具**：pytest-cov
- **CI 集成**：`.github/workflows/ci.yml`

#### 测试范围

| 模块 | 当前覆盖 | 目标覆盖 | 说明 |
|------|----------|----------|------|
| `shared/` | ~95% | 100% | 工具函数、配置、常量 |
| `data/` | ~60% | 85% | MongoDB 数据服务层 |
| `domain/ai/` | ~40% | 80% | AI Chat / Agent 服务 |
| `domain/knowledge/` | ~50% | 80% | Knowledge Watcher |
| `domain/rag/` | ~30% | 75% | RAG 检索服务 |
| `domain/files/` | ~20% | 70% | 文件管理 |
| `domain/rss/` | ~10% | 60% | RSS 聚合 |
| `domain/wework/` | ~10% | 60% | WeCom 消息 |

#### 测试类型

- **单元测试**：纯函数和工具方法
- **集成测试**：MongoDB 操作（需要测试数据库）
- **API 测试**：FastAPI TestClient 端到端测试
- **Mock 测试**：外部依赖（Ollama、文件系统）Mock

#### 运行命令

```bash
# 运行全部测试
pytest

# 运行指定模块
pytest tests/shared/ tests/data/

# 生成覆盖率报告
pytest --cov=. --cov-report=html

# CI 模式（失败时阻止合并）
pytest --cov=. --cov-report=term --cov-fail-under=70
```

#### CI 集成

- CI 流程中执行 `pytest --cov=. --cov-fail-under=70`
- 覆盖率低于 70% 阻止合并
- 生成覆盖率报告供 Review 查看

### 关联模块

- 测试目录：`tests/`
- 配置文件：`pytest.ini` / `pyproject.toml`
- CI 配置：`.github/workflows/ci.yml`
- 依赖：`requirements-dev.txt`

### 验收标准

1. `shared/` 模块覆盖率达到 100%
2. `data/` 模块覆盖率达到 85%
3. `domain/` 核心模块覆盖率达到 75%+
4. 整体覆盖率不低于 70%
5. CI 中 pytest 通过，覆盖率检查通过
6. 测试用例数量 ≥ 150
