# YiAi 翻译服务智能引擎推荐 — 需求规格

> 编号: YA-09-237 · 优先级: P1 · 工时: ~0.3d · 状态: 已完成

> **文档职责**: 定义基于实时健康数据的翻译引擎智能推荐 RPC 方法，打通跨项目数据流。

---

## 一、背景

Translation client apps calling YiAi RPC for translation need to know which engine is most reliable for a given language pair. Previously this wasn't available — apps either hardcoded engine priority lists or required manual selection, without data-driven decision making.

YiAi 后端已有 `provider_health` 方法和 `translation_records` 集合存储每次翻译的成功/失败记录，但缺少一个面向消费者的推荐接口。

## 二、功能需求

### FR-1: provider_recommend RPC 方法

**RPC 路径**: `services.translation.translate_service.provider_recommend`

**输入**:
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `from_lang` | string | `"auto"` | 源语言 |
| `to_lang` | string | `"zh"` | 目标语言 |
| `limit` | int | `5` | 返回引擎数上限 |

**输出**:
```json
{
  "from_lang": "auto",
  "to_lang": "zh",
  "recommended": "openai",
  "providers": [
    {"name": "openai", "success_rate": 0.96, "status": "healthy", "total": 142, "failed": 6},
    {"name": "google", "success_rate": 0.91, "status": "healthy", "total": 89, "failed": 8},
    {"name": "deepl",  "success_rate": 0.78, "status": "degraded", "total": 45, "failed": 10}
  ],
  "healthy_count": 2,
  "degraded_count": 1,
  "down_count": 0
}
```

**排名逻辑**:
1. 按健康状态分组: healthy > degraded > down
2. 同组内按成功率降序
3. 成功率接近时按调用量降序

**数据源**: MongoDB `translation_records` 集合近 24h 数据，实时聚合计算。

### FR-2: YiVad TranslationAnalytics 排名面板

**文件**: `YiVad/src/views/dashboard/analytics/TranslationAnalytics.vue`

新增 "Smart Provider Ranking" 卡片:
- 实时展示引擎排名（#1, #2, #3...）
- 每个引擎: 名称、状态标签、成功率、调用量
- 最佳引擎高亮 "Best" 标记
- 底部汇总 healthy/degraded/down 计数

### FR-3: YiVad API 层

**文件**: `YiVad/src/api/modules/translationService.ts`

新增 `ProviderRecommendation` 接口和 `getProviderRecommend()` 函数。

## 三、跨项目数据流

```
┌──────────────────────────────────────────────────────────┐
│                    YiAi :10086                            │
│  translate_service.provider_recommend                     │
│    ├── 查询 translation_records (近 24h)                  │
│    ├── 按健康度 + 成功率排名                              │
│    └── 返回推荐结果                                       │
└──────────┬───────────────────────────────┬───────────────┘
           │                               │
    ┌──────┴──────┐
    │ Client Apps │                 │   YiVad     │
    │ 翻译前调用  │                 │ 仪表盘展示  │
    │ 自动选引擎  │                 │ 实时排名    │
    └─────────────┘                 └─────────────┘
           │
    翻译成功/失败 → write translation_records → 排名实时更新
```
