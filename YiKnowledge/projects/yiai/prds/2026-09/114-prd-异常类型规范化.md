# YA-09-114: 异常类型规范化

> **PRD 版本**：v1.0 · **状态**：已完成

## 1. 背景

YiAi 的 RPC 调度器通过 `except BusinessException` 捕获业务异常并转换为标准错误响应。但在 `domain/state/service.py` 和 `domain/rss/scheduler.py` 中存在 4 处裸 `ValueError`，导致参数校验或资源未找到时返回 `code: 9999`（未知内部错误）而非正确的 `1002`（参数验证失败）或 `1004`（资源不存在）。

## 2. 修复

| 文件 | 位置 | 原异常 | 新异常 |
|------|------|--------|--------|
| `domain/state/service.py` | `update()` | `ValueError("Record...not found")` | `BusinessException(DATA_NOT_FOUND)` |
| `domain/state/service.py` | `delete()` | `ValueError("Record...not found")` | `BusinessException(DATA_NOT_FOUND)` |
| `domain/rss/scheduler.py` | `set_config()` | `ValueError("interval...<60")` | `BusinessException(INVALID_PARAMS)` |
| `domain/rss/scheduler.py` | `set_config()` | `ValueError("{field} must be...")` | `BusinessException(INVALID_PARAMS)` |

## 3. 验收标准

- [x] `state/service.py` 无裸 `ValueError` raise
- [x] `rss/scheduler.py` 无裸 `ValueError` raise
- [x] `test_state.py` 测试断言更新为 `BusinessException`
- [x] 457 个单元测试全部通过
