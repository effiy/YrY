# 对话模板与场景库

## 背景

用户在使用 AI 对话时，经常需要手动编写结构化的提示词，效率低且质量不稳定：
- 代码审查时每次手动描述审查要求
- 写 PRD 时每次手动列出文档结构
- 新用户不知道如何有效使用 AI

## 用户故事

- 作为开发者，我希望一键选择"代码审查"模板开始审查
- 作为产品经理，我希望选择"PRD 撰写"模板快速生成文档框架
- 作为新用户，我希望看到预设场景来了解 AI 能力

## 功能需求

1. **预置模板**：8+ 场景模板（code review/bug analysis/PRD/API doc/知识问答/解释概念/数据分析/摘要）
2. **参数化模板**：`{{variable}}` 占位符 → 用户填写表单
3. **分类浏览**：按 Code/Documents/Q&A/Analysis 分类
4. **实时预览**：填写参数时预览最终 prompt
5. **自定义模板**：用户创建/编辑/删除个人模板

## 非功能需求

- 模板选择到应用 < 3 次点击
- 参数表单自动聚焦第一个变量

## 验收标准

- [ ] 预置 8 个场景模板
- [ ] 参数替换正确
- [ ] 一键应用到输入框
- [ ] 用户可创建自定义模板
