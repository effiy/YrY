# 用户反馈闭环

## 背景

当前 YiAi 缺乏用户反馈收集机制：
- 无法量化用户对 AI 回答的满意度
- 低质量回答无法被系统性地发现和改进
- 缺少数据驱动质量优化的闭环

## 用户故事

- 作为用户，我希望对 AI 的回答点赞或点踩
- 作为用户，当回答不满意时，我希望说明哪里出了问题
- 作为产品经理，我希望通过反馈数据了解 AI 质量趋势

## 功能需求

1. **消息级反馈**：每条 AI 回复底部 👍/👎 按钮
2. **详细评分**：点踩后弹出准确性/有用性/安全性三维评分（1-5 星）
3. **可选评论**：用户可输入具体问题描述
4. **反馈持久化**：通过 RPC 存储到 MongoDB user_feedback 集合
5. **防重复**：同一消息不可重复评价（toggle 取消）
6. **统计分析**：后端聚合反馈数据，按模型/时间/维度统计

## 非功能需求

- 反馈提交延迟 < 500ms
- 流式消息生成中不显示反馈按钮
- 用户消息不显示反馈按钮

## 验收标准

- [ ] 点赞/点踩按钮在 AI 消息底部可见
- [ ] 点踩后弹出评分表单
- [ ] 反馈数据正确持久化
- [ ] 同一消息不可重复评价
- [ ] 后端提供维度聚合统计 API
