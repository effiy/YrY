# 个性化记忆系统

## 背景

当前 YiAi 每次对话独立，无用户长期记忆：
- 用户偏好（语言、风格）每次需重新说明
- 用户事实（职业、技能）无法跨会话复用
- 历史对话经验无法沉淀

## 用户故事

- 作为用户，我说过一次"用中文回答"后，后续对话应默认中文
- 作为用户，我告知过自己的角色（前端开发）后，AI 应给出更有针对性的建议
- 作为用户，我希望查看和管理 AI 记住的关于我的信息

## 功能需求

1. **6 种记忆类型**：preference/fact/summary/command/relationship/goal
2. **5 级重要性**：CRITICAL 永久保留，MINIMAL 7 天衰减
3. **自动提取**：从对话中提取偏好和事实
4. **智能注入**：每次对话前注入相关记忆到 system prompt
5. **用户管理**：前端可查看/删除记忆

## 非功能需求

- 记忆提取延迟 < 200ms
- 高重要性记忆注入率 100%
- 用户可一键清除所有记忆

## 验收标准

- [ ] 偏好类记忆自动提取并应用到后续对话
- [ ] MINIMAL 记忆 7 天后自动归档
- [ ] 前端记忆面板按重要性排序
- [ ] 用户可手动删除任意记忆
