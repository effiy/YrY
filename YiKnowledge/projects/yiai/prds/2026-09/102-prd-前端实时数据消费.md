# YA-102: 前端实时数据消费

## 一、背景

YiAi 已提供 `/dashboard/live` SSE 端点（每 5s 推送 KPI），但 YiVad 前端尚未连接。当前 YiVad 首页通过 60s 轮询获取数据。

## 二、解决方案

**`src/hooks/useLiveMetrics.ts`**（新增）：

```typescript
const { data, connected, error, retry } = useLiveMetrics();
// data.value → LiveMetricData (实时更新)
// connected.value → true/false (SSE 连接状态)
// error.value → 错误消息
// retry() → 手动重连
```

特性：
- 自动重连（断开后 10s 重试）
- 连接状态追踪（connected ref）
- 错误降级（SSE 不可用不阻塞页面）
- 组件卸载时自动清理

## 三、验收标准

- [x] 自动连接 YiAi `/dashboard/live`
- [x] 连接断开自动重连
- [x] 组件卸载时清理 EventSource
- [x] SSE 不可用时不影响现有轮询
