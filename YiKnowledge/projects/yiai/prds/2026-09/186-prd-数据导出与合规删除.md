# 数据导出与合规删除

## 背景

当前 YiAi 缺乏用户数据可移植和合规删除能力，不符合 GDPR 要求：
- 用户无法导出自己的对话数据
- 用户无法彻底删除账户及相关数据
- 删除操作无确认机制和安全保护

## 用户故事

- 作为用户，我希望导出我的所有对话历史为可读格式
- 作为用户，我希望彻底删除我的账户和所有关联数据
- 作为合规人员，我希望删除操作有审计记录

## 功能需求

1. **数据导出**：JSON/CSV/HTML 格式，包含 sessions + bugs + files
2. **级联删除**：用户→sessions→messages→files 全部清除
3. **删除确认**：邮件确认 + 48h 冷静期
4. **异步导出**：大数据集使用任务队列，前端轮询进度
5. **审计日志**：记录所有导出和删除操作

## 非功能需求

- 导出文件 24h 后自动删除
- 级联删除不残留孤儿数据
- 导出格式符合 GDPR 数据可移植要求

## 验收标准

- [ ] 导出文件包含完整用户数据
- [ ] 删除前发送确认邮件
- [ ] 48h 内可取消删除
- [ ] 级联删除后无残留数据
