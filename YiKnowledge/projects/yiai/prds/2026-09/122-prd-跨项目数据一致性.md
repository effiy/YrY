# YA-09-122: 跨项目数据一致性 — YiVad/YiPet 数据流统一

> **PRD 版本**：v2.0 · **状态**：已完成 · **完成日期**：2026-09-23

## 1. 现状分析

### 1.1 实施前的数据流问题

| # | 问题 | 严重度 | 影响 |
|---|------|--------|------|
| 1 | YiPet `DashboardSummary.vue` 使用 raw `fetch()` 绕过四层 API 架构 | **严重** | 无认证、无错误处理、无类型安全 |
| 2 | YiPet `ProviderHealth.vue` 手动构造 RPC 信封 | **严重** | 与已有 `TranslationService.getProviderHealth()` 重复 |
| 3 | YiPet `popup/main.ts` 未初始化 API 客户端 | **严重** | `DashboardService`/`TranslationService` 已构建但无法使用 |
| 4 | YiPet DashboardSummary 无轮询 | 高 | 数据仅在弹窗打开时获取一次 |
| 5 | YiPet ProjectHealthCard 无轮询 | 中 | 项目页面上的健康数据不更新 |
| 7 | YiVad RAG 概览无自动刷新 | 中 | 索引状态需手动刷新 |
| 8 | YiVad TranslationAnalytics 无数据时效提示 | 低 | 用户无法判断数据新鲜度 |
| 9 | YiVad 项目详情 Todo List dev/test 过滤器失效 | **严重** | `todoDevs`/`todoTests` 计算但未合并到 `todoItems` |
| 10 | 三项目轮询节奏不一致 | 中 | 60s vs 30s vs 无轮询，体验不统一 |

### 1.2 已打通的跨项目数据流（实施前）

| 数据流 | 方向 | 机制 | 实时性 |
|--------|------|------|--------|
| AI 对话 | YiPet → YiAi → YiVad aiChat | `window.open` + `?session=key` | 即时跳转 |
| 知识文件 | YiKnowledge → YiAi → YiVad/Pet | watcher 轮询（60s） | 近实时 |
| 缺陷报告 | YiPet → YiAi MongoDB + YiKnowledge | `BugService.createBug` | 实时写入 |

## 2. 改进方案与实施

### 2.1 YiPet — API 架构修复（P0）

**问题**：`DashboardSummary.vue` 和 `ProviderHealth.vue` 使用 raw `fetch()`，绕过已构建的四层 API 架构。

**实施**：
1. `popup/main.ts` — 在 bootstrap 中调用 `createApiServices({ baseUrl })`，存储到 `window.__yipet_services`
2. `popup/services/api.ts`（新建）— `getApiServices()` 类型安全访问桥
3. `ProviderHealth.vue` — 替换 raw `fetch()` → `svc.translation.getProviderHealth(24)`，新增 data-age 显示
4. `DashboardSummary.vue` — 替换 raw `fetch()` → `svc.dashboard.getSummary()`，新增 60s 轮询 + 数据年龄，统计从 4 项扩展到 6 项，项目列表可点击跳转 YiVad
5. `ProjectHealthCard.vue` — 新增 60s 轮询 + 数据年龄，离开项目页面时清理定时器

### 2.3 YiVad — 数据新鲜度增强（P1-P2）

**问题**：RAG 概览无自动刷新，TranslationAnalytics 无时效提示，Todo List dev/test 过滤器有 bug。

**实施**：
1. `TranslationAnalytics.vue` — 新增 `useNow` + `lastFetched` 数据时效指示器
2. `rag/index.vue` — 新增 60s 自动刷新 + `useNow` 实时时间戳
3. `ActivityTimeline.vue` + `useActivityTimeline.ts` — 统一摘要栏、周环比趋势、56 天热力图
4. `DetailOverview.vue` — **Bug 修复**：合并 `todoDevs`/`todoTests` 到 `todoItems`，接入 PRD 引用，堆叠进度条，逾期徽章

## 3. 统一轮询节奏（实施后）
