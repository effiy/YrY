# YA-09-120: 迁移模块时区一致性

> **PRD 版本**：v1.0 · **状态**：已完成

## 1. 背景

`shared/migration.py` 中 2 处 `datetime.now()` 未指定时区。迁移记录的时间戳因此使用本地时间而非 UTC，与其他模块（均使用 `datetime.now(timezone.utc)`）不一致。

## 2. 修复

- 导入 `timezone`
- `datetime.now()` → `datetime.now(timezone.utc)`（2 处）

## 3. 验收标准

- [x] `datetime.now()` 零残留（`grep -rn 'datetime.now()' src/` = 0）
- [x] 502 单元测试全部通过
