# 上下文窗口可视化

## 背景

当前用户无法感知 LLM 上下文窗口使用情况：
- 超出窗口时静默截断早期消息，用户无感知
- 用户不知道何时需要压缩对话或开启新会话
- 无法预估还能发送多少内容

## 用户故事

- 作为用户，我希望看到当前对话占用了多少 token
- 作为用户，当接近上下文窗口上限时，我希望收到警告
- 作为用户，我希望了解 token 的分配（系统/用户/助手各占多少）

## 功能需求

1. **Token 用量进度条**：绿色（< 40%）/ 隐藏（40-70%）/ 黄色（70-90%）/ 红色（> 90%）
2. **详细分解**：Hover 显示 system/user/assistant/response reserve
3. **超限警告**：> 90% 时 pulse 动画 + 输入框上方警告条
4. **实时更新**：每次消息变更后重新估算

## 非功能需求

- 估算误差 < 20%
- 进度条更新延迟 < 100ms

## 验收标准

- [ ] 进度条颜色按阈值正确切换
- [ ] Hover 显示详细 breakdown
- [ ] > 90% 时显示警告和 compact 建议
- [ ] 紧凑后进度条回落到正常范围
