<a id="sec-4"></a>
## 四、PRD 文档结构

每个 PRD 文件遵循标准结构（参考 [PRD 模板](../模板/00-模板-需求文档.md)）：

```
1. 背景 — 业务背景、核心挑战
2. 现状与目标 — 改造前/后、能力全景 (Mermaid)、边界
3. 需求范围 — 范围内/外
4. 功能需求 — FR-01 到 FR-0N
5. 领域模型 — 数据模型、状态机
6. 非功能需求 — 安全/性能/可用性/可观测性
7. 设计决策 — 选项对比、选择理由
8. 验收标准 — 逐条可验证 AC
9. 风险与缓解 — 风险矩阵、回滚策略
10. 后续演进 — 技术债登记
11. 关联需求 — 依赖/开发方案/测试用例
```
