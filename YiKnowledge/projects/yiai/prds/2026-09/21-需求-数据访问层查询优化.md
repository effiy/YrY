# YA-09-17: 数据访问层查询优化 — MongoDB 聚合管道与索引策略

> 需求编号：YA-09-17 · 优先级：P2 · 人天：1.5d · 状态：需求已编写
> 依赖：YA-09-02（数据层稳定性）

## 背景

YiAi 的 `data_service` 提供通用 CRUD 查询接口，前端通过 `filter` 参数传递任意 MongoDB 查询条件。当前查询方式为基础 `collection.find(filter)`，缺少聚合管道支持、索引覆盖分析和慢查询监控。

| 问题 | 影响 |
|------|------|
| Dashboard 统计查询（YV-09-20）逐集合多次查询 | N+1 查询——前端做聚合 |
| `sessions` 集合无 `messages.content` 查询优化 | 全表扫描 50K 文档 |
| 缺少 `explain` 分析——不知道查询是否命中索引 | 慢查询排查困难 |

### 量化指标

| 指标 | 当前值 | 目标值 | 说明 |
|------|--------|--------|------|
| Dashboard 统计查询次数 | 5-8 次 (N+1) | 1 次 (聚合管道) | 前端聚合 → 后端聚合 |
| 慢查询阈值 | 无 | > 500ms WARNING, > 2s CRITICAL | 企业微信告警 |
| 索引命中率 | 未知 | > 80% | explain 分析驱动 |
| 全表扫描查询数 | 未知 | 0 | 索引覆盖度检查 |
| sessions 集合查询延迟 (P95) | ~800ms | < 50ms | 添加索引后 |
| 连接池等待时间 (P95) | 无监控 | < 100ms | Motor 连接池事件 |

## 六、边缘场景处理

### 6.1 聚合管道内存溢出
- **场景**：`$group` 产生大量分组（如按用户 ID 分组 100K 文档），结果集超过 MongoDB 100MB 内存限制
- **处理**：管道添加 `allowDiskUse: true` —— 允许 MongoDB 使用磁盘临时存储
- **配置**：`collection.aggregate(pipeline, allowDiskUse=True, maxTimeMS=30_000)`

### 6.2 聚合管道超时
- **场景**：复杂管道（多级 `$lookup` + `$unwind`）在 50K 文档上执行超过 30s
- **处理**：`maxTimeMS=30_000` 超时后抛出 `pymongo.errors.ExecutionTimeout`，返回 500 错误
- **前端提示**：`"聚合查询超时，请缩小查询范围"`

### 6.3 索引创建阻塞写入
- **场景**：生产环境 `createIndex` 在前台执行，阻塞所有写入操作
- **处理**：所有 `createIndex` 使用 `background: true`（MongoDB 4.2+ 默认后台）
- **验证**：`db.currentOp()` 检查是否有长时间运行的索引创建

### 6.4 文本索引不支持中文分词
- **场景**：`createIndex({name: "text"})` 对中文使用空格分词，搜索效果差
- **处理**：`default_language: 'none'` 禁用内置分词，依赖应用层分词（如 jieba）
- **替代**：使用 `$regex` 进行中文模糊匹配（性能较差，但准确）

### 6.5 复合索引字段顺序影响查询性能
- **场景**：`{project_key: 1, status: 1}` 索引在仅查询 `status` 时无法使用
- **处理**：ESR 规则（Equality → Sort → Range）——等值查询字段在前，排序字段次之，范围字段最后
- **文档**：在索引定义中添加注释说明 ESR 顺序

### 6.6 慢查询日志包含敏感数据
- **场景**：`_log_slow_query` 记录的 `filter` 包含用户密码、Token 等敏感信息
- **处理**：敏感字段脱敏——`filter_summary = mask_sensitive_fields(filter, ['password', 'token', 'secret'])`
- **实现**：`mask_sensitive_fields` 将敏感字段值替换为 `***`

### 6.7 索引过多导致写入性能下降
- **场景**：每个集合创建 10+ 个索引，每次 `insert/update` 需更新所有索引
- **处理**：索引覆盖率检查——`check_index_coverage` 报告冗余索引
- **阈值**：每个集合索引数 ≤ 5 个

### 6.8 聚合管道中的 `$lookup` 性能问题
- **场景**：`$lookup` 跨集合关联查询，在 100K 文档上执行
- **处理**：为 `$lookup` 的 `foreignField` 添加索引
- **优化**：使用 `$lookup` 的 `pipeline` 语法（MongoDB 3.6+），在关联子管道中先过滤再关联

### 6.9 分页查询越界
- **场景**：前端请求 `page=1000`，但集合只有 500 条文档
- **处理**：`skip` 超过文档总数时返回空数组（而非错误）
- **优化**：返回 `total` 字段，前端可判断分页上限

### 6.10 连接池耗尽
- **场景**：多个慢查询同时执行，占用所有连接池槽位，导致新请求排队
- **处理**：`maxPoolSize=100` + `waitQueueTimeoutMS=5000` —— 等待 5s 后抛出异常
- **告警**：连接池等待时间 > 100ms 时 WARNING 日志

### 7.1 完整聚合管道服务

```python
# YiAi/src/services/database/data_service.py

import time
from dataclasses import dataclass
from typing import Any, Optional

from loguru import logger
from motor.motor_asyncio import AsyncIOMotorCollection
from pymongo.errors import ExecutionTimeout, PyMongoError

from shared.config import settings
from shared.wework import WeWorkNotifier


@dataclass
class SlowQueryLog:
    collection: str
    operation: str
    filter_summary: str
    duration_ms: float
    docs_examined: int
    docs_returned: int
    index_used: bool


class DataService:
    """数据服务——聚合管道 + 索引分析 + 慢查询监控。"""

    def __init__(self, db):
        self.db = db
        self._wework = WeWorkNotifier()
        self._slow_queries: list[SlowQueryLog] = []
        self._slow_query_threshold_ms = getattr(
            settings, 'SLOW_QUERY_THRESHOLD_MS', 500
        )
        self._slow_query_alert_threshold_ms = getattr(
            settings, 'SLOW_QUERY_ALERT_THRESHOLD_MS', 2000
        )

    async def aggregate_documents(
        self,
        cname: str,
        pipeline: list[dict],
        allow_disk_use: bool = True,
        max_time_ms: int = 30_000,
    ) -> list[dict]:
        """MongoDB 聚合管道——替代前端多次查询+聚合的模式。"""
        collection = self.db[cname]
        start = time.perf_counter()

        try:
            cursor = collection.aggregate(
                pipeline,
                allowDiskUse=allow_disk_use,
                maxTimeMS=max_time_ms,
            )
            results = await cursor.to_list(length=500)
            elapsed = (time.perf_counter() - start) * 1000

            await self._log_slow_query(
                cname, 'aggregate', str(pipeline)[:200], elapsed,
                docs_examined=0, docs_returned=len(results),
            )
            return results

        except ExecutionTimeout:
            logger.error(f"[DataService] 聚合管道超时: {cname}")
            raise
        except PyMongoError as e:
            logger.error(f"[DataService] 聚合管道异常: {cname} - {e}")
            raise
        finally:
            if 'cursor' in locals():
                await cursor.close()

    async def query_documents(
        self,
        cname: str,
        filter: dict,
        page: int = 1,
        page_size: int = 10,
        sort: list[tuple] | None = None,
    ) -> dict:
        """分页查询文档——自动 explain 分析。"""
        collection = self.db[cname]
        start = time.perf_counter()

        skip = (page - 1) * page_size
        sort = sort or [('_id', -1)]

        cursor = collection.find(filter).sort(sort).skip(skip).limit(page_size)

        try:
            results = await cursor.to_list(length=page_size)
            total = await collection.count_documents(filter)
            elapsed = (time.perf_counter() - start) * 1000

            # 慢查询日志
            await self._log_slow_query(
                cname, 'find', str(filter)[:200], elapsed,
                docs_examined=total, docs_returned=len(results),
            )

            return {
                'list': results,
                'total': total,
                'page': page,
                'pageSize': page_size,
                'totalPages': max(1, (total + page_size - 1) // page_size),
            }

        except PyMongoError as e:
            logger.error(f"[DataService] 查询异常: {cname} - {e}")
            raise

    async def explain_query(self, cname: str, filter: dict) -> dict:
        """分析查询计划——是否命中索引、扫描文档数。"""
        collection = self.db[cname]
        plan = await collection.find(filter).explain()

        query_planner = plan.get('queryPlanner', {})
        exec_stats = plan.get('executionStats', {})

        docs_examined = exec_stats.get('totalDocsExamined', 0)
        docs_returned = exec_stats.get('nReturned', 0)

        return {
            'index_used': bool(query_planner.get('winningPlan', {}).get('inputStage')),
            'winning_plan': str(query_planner.get('winningPlan', {}))[:500],
            'docs_examined': docs_examined,
            'docs_returned': docs_returned,
            'execution_time_ms': exec_stats.get('executionTimeMillis', 0),
            'index_efficient': docs_examined == docs_returned,
            'scan_ratio': docs_examined / max(docs_returned, 1),
        }

    async def _log_slow_query(
        self, collection: str, operation: str, filter_summary: str,
        duration_ms: float, docs_examined: int, docs_returned: int,
    ):
        """记录慢查询——分级日志 + 企微告警。"""
        if duration_ms < self._slow_query_threshold_ms:
            return

        log_entry = SlowQueryLog(
            collection=collection,
            operation=operation,
            filter_summary=filter_summary,
            duration_ms=duration_ms,
            docs_examined=docs_examined,
            docs_returned=docs_returned,
            index_used=docs_examined == docs_returned,
        )
        self._slow_queries.append(log_entry)

        if duration_ms > self._slow_query_alert_threshold_ms:
            logger.error(
                f"[SlowQuery CRITICAL] {collection}.{operation}: "
                f"{duration_ms:.0f}ms, examined={docs_examined}, "
                f"returned={docs_returned}"
            )
            await self._wework.send(
                f"[SlowQuery] {collection}.{operation}: {duration_ms:.0f}ms\n"
                f"filter: {filter_summary}\n"
                f"examined: {docs_examined}, returned: {docs_returned}"
            )
        else:
            logger.warning(
                f"[SlowQuery WARNING] {collection}.{operation}: "
                f"{duration_ms:.0f}ms"
            )

    @property
    def slow_query_stats(self) -> dict:
        return {
            'total': len(self._slow_queries),
            'last_10': [
                {
                    'collection': q.collection,
                    'operation': q.operation,
                    'duration_ms': q.duration_ms,
                    'index_used': q.index_used,
                }
                for q in self._slow_queries[-10:]
            ],
        }
```

### 7.2 索引覆盖度检查

```python
# YiAi/src/services/database/index_checker.py

async def check_index_coverage(db) -> dict:
    """启动时检查——核心查询是否都有对应索引。"""

    REQUIRED_INDEXES = {
        'sessions': [
            {'fields': {'key': 1}, 'unique': True},
            {'fields': {'updatedAt': -1}},
            {'fields': {'tags': 1}},
        ],
        'bugs': [
            {'fields': {'project_key': 1, 'status': 1}},
            {'fields': {'severity': 1}},
            {'fields': {'createdAt': -1}},
        ],
        'knowledge_files': [
            {'fields': {'frontmatter.category': 1}},
            {'fields': {'frontmatter.tags': 1}},
            {'fields': {'frontmatter.status': 1}},
            {'fields': {'path': 1}, 'unique': True},
        ],
        'projects': [
            {'fields': {'name': 'text', 'description': 'text'},
             'options': {'default_language': 'none'}},
        ],
        'rss_entries': [
            {'fields': {'feed_url': 1, 'published': -1}},
            {'fields': {'link': 1}, 'unique': True},
        ],
    }

    results = {}
    missing_indexes = []

    for cname, required in REQUIRED_INDEXES.items():
        existing = await db[cname].index_information()
        results[cname] = {'existing': len(existing), 'required': len(required)}

        for req_idx in required:
            found = False
            for idx_name, idx_info in existing.items():
                if idx_name == '_id_':
                    continue
                if idx_info.get('key') == list(req_idx['fields'].items()):
                    found = True
                    break
            if not found:
                missing_indexes.append({
                    'collection': cname,
                    'fields': req_idx['fields'],
                })

    if missing_indexes:
        logger.warning(f"[IndexCheck] 缺失 {len(missing_indexes)} 个索引: {missing_indexes}")

    return {
        'collections': results,
        'missing': missing_indexes,
        'total_missing': len(missing_indexes),
    }
```

### 7.3 敏感字段脱敏

```python
# YiAi/src/shared/sanitize.py

SENSITIVE_FIELDS = {'password', 'token', 'secret', 'api_key', 'authorization',
                     'credential', 'private_key', 'access_token'}

def mask_sensitive_fields(data: dict, extra_fields: set | None = None) -> dict:
    """脱敏敏感字段——将敏感值替换为 ***。"""
    sensitive = SENSITIVE_FIELDS | (extra_fields or set())
    masked = {}

    for key, value in data.items():
        if key.lower() in sensitive or any(s in key.lower() for s in sensitive):
            masked[key] = '***'
        elif isinstance(value, dict):
            masked[key] = mask_sensitive_fields(value, extra_fields)
        elif isinstance(value, list):
            masked[key] = [
                mask_sensitive_fields(v, extra_fields) if isinstance(v, dict) else v
                for v in value
            ]
        else:
            masked[key] = value

    return masked


def summarize_filter(filter: dict) -> str:
    """生成 filter 摘要（脱敏后）。"""
    masked = mask_sensitive_fields(filter)
    summary = str(masked)
    return summary[:200] if len(summary) > 200 else summary
```

## 经验教训

1. **根本原因**：开发过程中对边界情况和异常路径的考虑不足是此类问题的共同根因
2. **设计阶段**：在接口设计和模块实现时，应主动考虑异常输入、空值、超时等边界场景
3. **代码审查**：审查时应检查是否存在类似的反模式（如未捕获异常、无超时控制、缺少参数校验等）
4. **测试覆盖**：异常路径的测试覆盖率应与正常路径同等重视
5. **团队分享**：此类问题应在团队周会或技术分享中讨论，形成团队共识
