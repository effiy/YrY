# YA-09-118: URL 安全守卫抽取 + 可选依赖声明

> **PRD 版本**：v1.0 · **状态**：已完成

## 1. 背景

B21 和 B28 分别在 `server/routes/search.py` 和 `domain/ai/tools/builtin/web_tools.py` 中添加了 `_is_private_url()` SSRF 防护，产生 70 行重复代码。同时 `pyproject.toml` 缺少 observer 可选依赖声明。

## 2. 修复

### 2.1 URL 守卫抽取 (B30)

新增 `shared/url_guard.py`，导出 `is_private_url()`。`search.py` 和 `web_tools.py` 均改为导入共享函数，删除本地 ~35 行重复代码。

### 2.2 可选依赖声明

```toml
[project.optional-dependencies]
observer = ["yi-observer>=0.1.0"]
```

## 3. 验收标准

- [x] `shared/url_guard.py` 提供唯一 `is_private_url()` 实现
- [x] `search.py` 和 `web_tools.py` 从共享模块导入
- [x] `pyproject.toml` 包含 observer 可选依赖
- [x] 457 个单元测试全部通过
