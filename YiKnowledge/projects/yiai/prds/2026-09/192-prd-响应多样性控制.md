# LLM 响应多样性控制

## 背景

当前 LLM 使用固定采样参数，无法根据场景调整：
- 创意场景（写作、头脑风暴）输出过于保守
- 事实场景（技术问答）可能出现幻觉
- 重复场景输出单调，用户多次 regenerate 得到相似结果
- 缺乏统一的"创意程度"控制入口

## 用户故事

- 作为用户，当我需要创意输出时，希望拖动滑块获得更多样化的回答
- 作为用户，当我需要精确事实时，希望保证回答的确定性
- 作为用户，当我 regenerate 时，希望得到明显不同的回答

## 功能需求

1. **创意滑块**：0=precise → 0.5=balanced → 1=creative 三档
2. **参数联动**：temperature + presence_penalty + frequency_penalty 同步调整
3. **n-gram 后处理**：移除连续 3+ 重复的句子
4. **意图预设**：结合自适应温度（183），自动推荐滑块位置

## 非功能需求

- 滑块调整后下次发送生效（无需刷新）
- n-gram 去重不影响正常输出

## 验收标准

- [ ] precise→temperature=0.3, creative→temperature=1.0
- [ ] n-gram 去重正确移除重复句
- [ ] 用户手动设置后不再自动调整
- [ ] 滑块位置持久化（localStorage）
