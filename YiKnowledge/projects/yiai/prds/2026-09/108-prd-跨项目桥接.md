# YA-09-108: 跨项目桥接

> **PRD 版本**：v3.0

## 1. 背景

YiPet 用户可将聊天内容"桥接"到 YiVad aiChat（`discussInYiVadAiChat`）。需一次性 token 机制安全传递会话上下文。

## 2. 范围

**In scope**：`bridge_service.py` — 生成/验证一次性 bridge token，过期自动失效

| 优先级 | 故事 | 验收标准 |
|--------|------|---------|
| P1 | 桥接 Token 生成 | 一次性使用，过期失效 |
| P1 | YiVad 接收桥接 | session key 参数传递 |
