# YA-09-113: 状态常量统一

> **PRD 版本**：v1.0 · **状态**：已完成

## 1. 背景

`shared/status.py` 于 2026-09-23 创建，定义了 `Status` 类、`CLOSED_STATUSES`/`ACTIVE_STATUSES` 等分组常量和 `normalize_status_list()` 等工具函数。但 `services/analytics/aggregator/quality.py` 仍使用本地硬编码的状态集：

```python
DONE_STATUSES = {"closed", "resolved", "done"}
OPEN_STATUSES = {"open", "in_progress", "reopened"}
```

这与 `shared/status.py` 定义一致，但缺少 `cancelled` 等状态，且无法利用 `normalize_status_list()` 的遗留混合大小写兼容能力。

## 2. 修复

**文件**：`services/analytics/aggregator/quality.py`

- 移除 `DONE_STATUSES` 和 `OPEN_STATUSES` 硬编码定义
- 导入 `CLOSED_STATUSES`、`ACTIVE_STATUSES`、`normalize_status_list` 从 `shared.status`
- 将 `list(DONE_STATUSES)` (9 处) 替换为 `normalize_status_list(CLOSED_STATUSES)`

**收益**：
1. 扩展状态覆盖：新增 `cancelled` 状态自动纳入统计
2. 遗留数据兼容：`normalize_status_list` 同时匹配 `"Done"`/`"Closed"` 等大小写变体
3. 单一真相来源：未来新增状态只需修改 `shared/status.py`

## 3. 验收标准

- [x] `quality.py` 中不再有本地 `DONE_STATUSES`/`OPEN_STATUSES` 定义
- [x] 全部 9 处状态引用使用 `normalize_status_list(CLOSED_STATUSES)`
- [x] 457 个单元测试全部通过
