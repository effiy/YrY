# YiAi 后端数据质量统一 — 需求规格

> 编号: YA-09-236 · 优先级: P1 · 工时: ~0.5d · 状态: 已完成

> **文档职责**: 定义 YiAi 后端状态值规范化和 Dashboard 实时数据推送需求。

---

## 一、背景

### 问题识别

| 问题 | 现状 | 影响 |
|------|------|------|
| 状态值大小写混用 | 数据库中存在 `done`/`Done`、`todo`/`To Do`、`in_progress`/`In Progress` | 查询遗漏、统计偏差 |
| 状态常量分散 | 6+ 服务文件各自维护状态列表 | 不一致风险、维护成本 |
| Dashboard 无实时推送 | YiVad 60s 轮询 (`POLL_INTERVAL_MS`) | 数据滞后、资源浪费 |
| 前端兼容层 | YiVad `STATUS_MERGE` 映射表处理大小写 | 技术债务 |

### 目标

1. 创建单一真相来源的状态常量模块
2. 提供向后兼容的规范化函数
3. 新增 SSE 实时 Dashboard 端点
4. 零破坏性变更 — 所有现有消费者兼容

---

## 二、功能需求

### FR-1: 共享状态常量模块

**文件**: `YiAi/src/shared/status.py` (新增)

定义 `Status` 类提供所有 Issue/Bug 状态的 canonical 字符串常量:
- `DONE`, `IN_PROGRESS`, `TODO`, `BACKLOG`, `IN_REVIEW`, `CANCELLED`, `BLOCKED`
- `OPEN`, `CLOSED`, `RESOLVED`

预定义状态分组:
- `CLOSED_STATUSES`: `{done, closed, resolved, cancelled}`
- `ACTIVE_STATUSES`: `{todo, in_progress, in_review}`
- `NOT_DONE_STATUSES`: `{done, cancelled, backlog}`

兼容函数:
- `normalize_status(status: str) -> str`: 将遗留大小写混合值标准化
- `normalize_status_list(statuses) -> list[str]`: 批量标准化
- `is_closed(status: str) -> bool`: 判断是否关闭状态

### FR-2: 服务迁移

| 文件 | 迁移内容 |
|------|---------|
| `services/analytics/project_dashboard.py` | `CLOSED` 硬编码列表 → `normalize_status_list(CLOSED_STATUSES)` |
| `services/analytics/aggregator/helpers.py` | `DONE_STATUSES` 本地常量 → 导入 `Status.DONE` |
| `services/analytics/collector.py` | `done` 字符串匹配 → `normalize_status_list([Status.DONE])` |
| `services/milestone/milestone_service.py` | 硬编码 `"done"` → `Status.DONE` |
| `services/analytics/file_alerts.py` | 硬编码状态字符串 → `Status` 常量 |

### FR-3: Dashboard SSE 实时端点

**文件**: `YiAi/src/server/routes/dashboard/live.py` (新增)

| 端点 | 方法 | 功能 |
|------|------|------|
| `/dashboard/live` | GET (SSE) | 每 5s 推送实时 KPI 快照 |
| `/dashboard/live-snapshot` | GET (REST) | 返回单次快照 |

SSE 事件格式:
```json
{
  "active_issues": 23, "open_bugs": 8, "today_done": 12,
  "today_created": 5, "overdue_count": 3, "blocked_count": 1,
  "total_issues": 145, "total_bugs": 42, "server_uptime": 86400,
  "timestamp": 1700000000
}
```
