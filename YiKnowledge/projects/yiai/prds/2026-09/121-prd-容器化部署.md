# YA-09-121: 容器化部署

> **PRD 版本**：v1.0 · **状态**：已完成

## 1. 背景

YiAi 此前无 Docker 部署配置。生产部署依赖手动 `python main.py`，无健康检查、无容器编排。

## 2. 交付物

| 文件 | 用途 |
|------|------|
| `Dockerfile` | Python 3.11-slim 基础镜像，uvloop 编译依赖，HEALTHCHECK |
| `.dockerignore` | 排除缓存/日志/测试产物 |
| `docker-compose.yml` | YiAi + MongoDB 7 + Ollama 三服务编排 |

## 3. 使用

```bash
docker compose up -d        # 启动全栈
docker compose logs -f yiai # 查看日志
docker compose down         # 停止
```

## 4. 验收标准

- [x] `Dockerfile` 存在且包含 HEALTHCHECK
- [x] `.dockerignore` 排除缓存/测试/日志目录
- [x] `docker-compose.yml` 编排三服务（yiai + mongo + ollama）
