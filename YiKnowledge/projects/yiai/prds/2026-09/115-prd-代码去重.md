# YA-09-115: RSS 时间戳解析 DRY 重构

> **PRD 版本**：v1.0 · **状态**：已完成

## 1. 背景

`server/routes/dashboard/rss.py:rss_stats()` 中定义了一个 22 行的 `_article_ts()` 内部函数，其逻辑与 `data/date_helpers.py:parse_ms_ts()` 完全一致——两者都处理 RSS 时间戳的 schema drift（秒/毫秒数值、数字字符串、ISO 格式）。

## 2. 修复

删除 `_article_ts()` 内联定义，改为调用共享函数：

```python
# Before: 22 行内联函数
def _article_ts(a: dict) -> int | None:
    ts = a.get("published_parsed") or a.get("createdTime") or a.get("published")
    # ... 15 行重复的解析逻辑

# After: 1 行调用
from data.date_helpers import parse_ms_ts
ts = parse_ms_ts(a.get("published_parsed") or a.get("createdTime") or a.get("published"))
```

同时移除了不再需要的 `from datetime import datetime` 和 `from datetime import timezone as tz` 导入。

## 3. 验收标准

- [x] `rss.py` 不再包含内联 `_article_ts()` 函数
- [x] `rss_stats()` 使用 `parse_ms_ts()` 进行时间戳解析
- [x] 无未使用的导入残留
- [x] 457 个单元测试全部通过
