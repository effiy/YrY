# YiAi 运行时防御性修复

> 需求编号：YA-09-101 · 优先级：P1 · 总人天：~0.25d · 涉及模块：executor(1)、analytics(1)

---

## 一、需求背景

代码审查发现 2 处运行时风险：

| 严重度 | 问题 | 影响 |
|--------|------|------|
| **P1-major** | `executor.py` allowlist 为 None 时 `set(None)` TypeError | 模块导入时崩溃 |
| **P2-minor** | `analytics.py` asyncio.gather 缺少 `return_exceptions` | 单查询失败拖垮整个端点 |

---

## 二、技术方案

### 2.1 executor allowlist None 防护

```python
# Before: None → set(None) → TypeError
allowlist = settings.module_allowlist
if isinstance(allowlist, str): ...
EXEC_ALLOWLIST = set(allowlist)

# After: None → [] → set([])
if allowlist is None:
    allowlist = []
```

### 2.2 analytics gather 错误隔离

```python
# Before: any exception propagates
efficiency_data, quality_data = await asyncio.gather(
    get_efficiency_metrics(params),
    get_quality_metrics(params),
)

# After: exceptions captured per-task
efficiency_data, quality_data = await asyncio.gather(..., return_exceptions=True)
efficiency_data = efficiency_data if not isinstance(efficiency_data, BaseException) else {}
```

---

## 三、验收标准

1. `python -m pytest tests/ -q` 598+ 通过
2. 删除 `module_allowlist` 配置后模块导入不崩溃
3. analytics 单查询失败时另一查询结果正常返回

---

## 四、风险评估

| 风险 | 缓解 |
|------|------|
| allowlist 为空时所有 RPC 调用返回 PERMISSION_DENIED | `*` 通配符模式下不受影响；显式 allowlist 模式需用户确保配置 |
