## 约束

### MUST

- 所有 API 端点使用 RPC 信封 `{module_name, method_name, parameters}`
- 响应统一使用 `{code, message, data}` 格式
- 参数名遵守跨项目契约（`filter` 而非 `query`，`target_file` 而非 `path`）
- Service 层通过依赖注入获取 Repository
- MongoDB 操作通过 Motor 异步驱动

### MUST NOT

- 不在 routes 中直接调用 `data/` 层
- 不在 domain 层导入 `server/`
- 不混用同步和异步代码
- 不绕过 RPC 信封直接暴露 REST 端点
