## 二、导入规则

```
server/ → services/ → domain/ → data/ → shared/
```

| 层 | 可导入 | 禁止导入 |
|----|--------|---------|
| `server/` | services/, shared/ | data/, domain/ |
| `services/` | domain/, data/, shared/ | server/ |
| `domain/` | data/, shared/ | server/, services/ |
| `data/` | shared/ | domain/, server/, services/ |
| `shared/` | — | 所有业务模块 |

**单向依赖**：上层依赖下层，下层绝不依赖上层。`shared/` 是最底层。

## 三、文件命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 模块文件 | snake_case | `chat_service.py`, `error_codes.py` |
| 路由文件 | snake_case | `agent.py`, `knowledge.py` |
| 测试文件 | test_ 前缀 | `test_utils.py`, `test_agent.py` |
| 目录 | snake_case | `domain/ai/`, `services/database/` |

## 四、服务注册模式

```python

    execution, files, health, knowledge, maintenance, mcp,
    metrics, notification, openai_compat, rag, search, state,
    system, users, wework)
from server.routes.dashboard import ai, health as dash_health, organization,
    performance, rag as dash_rag, rss, service

app.include_router(agent.router)
app.include_router(auth.router)
# ... 等
```
