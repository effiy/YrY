# 架构概览

> **读完你将能够**：理解 YiAi 技术栈、分层架构、数据流、Agent/RAG 引擎

> YiAi 是 YrY 单体仓库的唯一后端（FastAPI，端口 10086），为 YiVad 和 YiPet 提供统一的 RPC 服务。

## 一、技术定位

| 属性 | 值 |
|------|-----|
| 项目类型 | FastAPI 后端服务 |
| 端口 | 10086 |
| 运行时 | Python 3.10+ |
| 数据库 | MongoDB（Motor async driver） |
| LLM 推理 | Ollama（自托管，支持 OpenAI/Anthropic 多后端） |
| RAG 引擎 | llama_index（混合检索：向量 + BM25） |
| 消费者 | YiVad（Vue 3.5 SPA）+ YiPet（Chrome MV3 扩展） |
| 通信协议 | RPC 信封 `{module_name, method_name, parameters}` |

**核心框架**：FastAPI + uvicorn + pydantic + Motor + Ollama + llama_index + bcrypt/PyJWT + tenacity + pytest

## 二、目录结构

```
YiAi/src/
├── app.py                  # FastAPI 应用工厂 + 生命周期
├── shared/                 # 配置、响应、错误码、日志（零业务依赖）
├── middleware/              # auth, observer
├── server/routes/          # 20 个路由模块（execution.py = RPC 分发器）
├── services/               # 17 个服务模块（ai/, database/, knowledge/, rag/, rss/, ...）
├── domain/                 # 11 个领域模块（ai/, auth/, files/, knowledge/, rag/, ...）
└── data/                   # MongoDB 单例 + Repository + seeds/
```

## 三、分层架构

```
server/routes/  →  services/  →  domain/  →  data/  →  shared/
   HTTP 层         编排层        业务层      持久层      共享层
```

**导入规则**：server 可导入 services/shared；services 可导入 domain/data/shared；domain 可导入 data/shared；data 仅导入 shared；shared 零依赖。

## 四、请求生命周期

```
HTTP Request
  → CORS → Auth（可选） → Observer（可选） → 路由匹配
  → RPC 分发器：module_name.method_name → service
  → services 参数校验 → domain 业务逻辑 → data MongoDB 操作
  → StandardResponse {code, message, data}
```

启动顺序（lifespan）：MongoDB 连接 → 种子数据 → 索引 → Knowledge Watcher → RAG 预加载 → RSS 调度器。

## 五、RPC 分发

`POST /` body: `{module_name, method_name, parameters}` → 动态路由到对应 service 方法。

核心服务：`data_service`（CRUD）、`chat_service`（SSE 聊天）、`knowledge_service`（知识库）、`rag_service`（RAG 检索）、`rss.feed_service`（RSS）、`bridge_service`（YiPet→YiVad）。

## 六、Agent 循环

```
turn_start → LLM 推理 → tool_call → [confirmation_required(120s)] → tool_execution → turn_end → 循环 → agent_end
```

特性：确认门控、拒绝记忆（20 条）、模型自动升级、预算感知、断连检测。

## 七、RAG 管道

```
YiKnowledge/*.md → Knowledge Watcher(60s) → MongoDB → llama_index(向量+BM25) → [HyDE] → [Rerank] → top_k 结果
```

## 八、降级策略

| 场景 | 行为 |
|------|------|
| MongoDB 不可用 | 写入失败，读取空 |
| Ollama 不可用 | 返回 AI_UNAVAILABLE |
| RAG 索引缺失 | 返回空，提示构建 |
| Agent 模型停滞 | 自动切换 fallback |

## 九、关键约束

- 统一信封 `{code, message, data}`
- 参数名：`filter`（非 `query`）、`target_file`（非 `path`）、`cname`（非 `collection_name`）
- 文件双写：磁盘（主）+ MongoDB（备份）
- 分层不妥协：server 不调 data，domain 不调 server
