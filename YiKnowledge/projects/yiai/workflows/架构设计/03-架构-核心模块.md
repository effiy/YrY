# 核心模块

> **读完你将能够**：理解 Agent 循环、RAG 引擎、知识库监视器等核心模块的实现

## 一、main.py（应用入口）

```python
import uvicorn
if __name__ == "__main__":
    uvicorn.run("src.app:app", host="0.0.0.0", port=10086, reload=True, reload_dirs=["src"])
```

## 二、app.py（应用工厂）

```python
from contextlib import asynccontextmanager

@asynccontextmanager
async def lifespan(app: FastAPI):
    # 启动：MongoDB → 种子数据 → 索引 → Knowledge Watcher → RAG 预加载 → RSS
    await db.connect(config.mongodb.uri, config.mongodb.db_name)
    await seed_database()
    await create_indexes()
    if config.knowledge.watcher_enabled: start_knowledge_watcher()
    if os.path.exists("data/rag_store/docstore.json"): preload_rag_index()
    if config.rss.enabled: start_rss_scheduler()
    yield
    # 关闭
    stop_knowledge_watcher(); stop_rss_scheduler(); await db.disconnect()

def create_app() -> FastAPI:
    app = FastAPI(lifespan=lifespan)
    # 中间件：CORS → Observer → Auth
    # 路由：20 个模块
    # 异常处理器
    return app
```

## 三、Agent 循环（domain/ai/）

```
turn_start → LLM 推理 → tool_call → [confirmation_required(120s)] → tool_execution → turn_end → 循环 → agent_end
```

关键特性：确认门控（写操作需用户确认）、拒绝记忆（20 条）、模型自动升级（弱→强）、预算感知（剩余轮次 ≤ 3 时压缩步骤）、旋转检测（连续 3 次相同观察触发 nudge）、断连检测（CancelledError → 保存 → 清理）、结果裁剪（6000 字符）。

完整性检查点：命名工具检查、无写入提示、计数感知、叙述守卫、预算警告。

## 四、AI 聊天（domain/ai/chat.py）

多后端支持：Ollama / OpenAI / Anthropic。SSE 流式响应 `text/event-stream`。

## 五、RAG 引擎（domain/rag/）

管道：YiKnowledge → Knowledge Watcher（60s） → MongoDB knowledge_files → llama_index VectorStoreIndex + BM25 → 混合检索 → [HyDE 增强] → [Rerank] → top_k。

配置：`rag.hybrid_search`、`rag.use_hyde`、`rag.use_rerank`、`rag.chunk_size`（512）、`rag.top_k`（5）。

## 六、知识库监视器（domain/knowledge/watcher.py）

apscheduler 每 60s 轮询 YiKnowledge 目录树 → 解析 frontmatter → 对比 content_hash → upsert MongoDB knowledge_files。

## 七、数据层（data/）

- `database.py`：MongoDB 线程安全单例（Motor async，连接池 pool_size=10, max_pool_size=50）
- `repository.py`：通用 CRUD + `_build_filter` 查询构建 + 分页排序
- `sessions.py`：会话数据操作
- `seeds/`：14 个 JSON 种子文件，仅在集合为空时导入
