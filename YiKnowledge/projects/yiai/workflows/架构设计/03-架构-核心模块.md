## 一、应用入口与工厂（app.py）

`app.py` 使用 `create_app()` 工厂函数构建 FastAPI 实例，通过 `lifespan` 管理启动/关闭流程：

```python
# app.py（简化，完整代码见源文件）
def create_app(*, enable_auth=None, init_db=None, init_rss=None, init_knowledge=None) -> FastAPI:
    app = FastAPI(
        title="YiAi API", version="1.0.0",
        lifespan=_build_lifespan(init_db, init_rss, init_knowledge),
        default_response_class=ORJSONResponse,
    )
    register_exception_handlers(app)
    # 注册 21 个路由模块 + dashboard 子包
    app.include_router(execution.router, tags=["Execution"])
    # ... 其余 20 个路由 + dashboard
    # 中间件栈（从内到外）: FastGZip → BodySizeLimit → ResponseTime → RequestId → CORS → Auth → GracefulShutdown
    app.add_middleware(FastGZipMiddleware, minimum_size=512, compression_level=1)
    app.add_middleware(BodySizeLimitMiddleware)
    app.add_middleware(ResponseTimeMiddleware)
    app.add_middleware(RequestIdMiddleware)
    app.add_middleware(CORSMiddleware, ...)
    if auth_enabled: app.add_middleware(AuthMiddleware, enabled=True)
    app.add_middleware(GracefulShutdownMiddleware)  # 始终在最外层
    return app

# 启动顺序（lifespan）
# configure_runtime() → db.initialize() → _seed_all_if_empty() → cache.initialize()
# → init_knowledge_watcher() → setup_backup_scheduler() → _warmup_cache()
#   (menus 缓存 → knowledge scan 缓存 → RAG 预加载 → 热模块预导入 → Ollama 预连接)

# 关闭顺序（lifespan yield 之后）
# warmup_task cancel → GracefulShutdownMiddleware drain → shutdown_knowledge_watcher()
# → shutdown_rss_system() → shutdown_backup_scheduler() → db.close()
# → 关闭所有 httpx 客户端
```

## 二、Agent 循环（domain/ai/）

```
turn_start → LLM 推理 → tool_call → [confirmation_required(120s)] → tool_execution → turn_end → 循环 → agent_end
```

关键特性：
- **确认门控**：写操作（文件写入/删除/API 调用）需用户确认，120s 超时
- **拒绝记忆**：最近 20 条被拒工具调用记录，避免重复建议
- **模型自动升级**：弱模型连续失败 → 自动切换更强模型
- **预算感知**：剩余轮次 ≤ 3 时压缩步骤描述
- **旋转检测**：连续 3 次相同观察触发 nudge 提示
- **断连检测**：CancelledError → 保存当前状态 → 清理资源
- **结果裁剪**：工具输出超过 6000 字符自动截断

## 四、RAG 引擎（domain/rag/）

管道流程：
```
YiKnowledge/*.md → Knowledge Watcher(60s) → MongoDB knowledge_files
→ llama_index VectorStoreIndex + BM25 → 混合检索(QueryFusionRetriever)
→ [HyDE 增强] → [LLMRerank] → [_NumberSourcesPostprocessor] → top_k 结果
```

关键模块：
- `engine.py`：`rag_query`、`rag_chat_stream`、`rag_file_query`、`rag_file_chat_stream`
- `indexer.py`：`get_kb_index`（懒加载）、`build_file_index`（全量/增量）、`is_index_available`、`preload_kb_index`
- `settings.py`：RAG 配置（chunk_size=512, top_k=5, 混合检索/HyDE/Rerank 开关）
- `chat_history.py` / `history.py`：对话历史管理

配置开关（`config.yaml` → `shared/config.py`）：`rag.hybrid_search`、`rag.use_hyde`、`rag.use_rerank`。

## 七、中间件栈

中间件注册顺序（从内到外，实际由 Starlette 逆序执行）：

| 顺序 | 中间件 | 文件 | 职责 |
|------|--------|------|------|
| 1 (最内) | FastGZipMiddleware | `server/gzip_middleware.py` | zlib level 1 压缩（3-4× 比 Starlette 默认 gzip 快） |
| 2 | BodySizeLimitMiddleware | `server/middleware.py` | 请求体大小限制 |
| 3 | ResponseTimeMiddleware | `server/middleware.py` | X-Response-Time-Ms 响应头 |
| 4 | RequestIdMiddleware | `server/middleware.py` | X-Request-ID 追踪 |
| 5 | CORSMiddleware | FastAPI 内置 | 跨域请求处理 |
| 6 | AuthMiddleware | `server/middleware.py` | JWT 认证（可选，默认禁用） |
| 7 (最外) | GracefulShutdownMiddleware | `server/middleware.py` | inflight 请求计数，优雅关闭 |
