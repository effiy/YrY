# XS-09-001: YrY 跨项目数据流全景

> 11 轮迭代的跨项目数据打通成果汇总。所有数据通过 YiAi 单一数据源流转，各项目消费一致、实时的数据。

## 数据闭环清单

### 1. 翻译分析闭环
```
YiPot TargetArea 翻译 ─┐
YiPet ChatInput 翻译  ─┤
                        ├→ YiAi translate RPC
                        │    → MongoDB translation_records
                        │      → provider_health / hourly_trend / provider_breakdown
                        │        → YiPot History 页统计 (7d翻译量/语种对/缓存)
                        │        → YiVad TranslationAnalytics Dashboard (KPI + 图表)
                        └── 数据一致，实时聚合
```

### 2. 翻译反馈闭环
```
YiPot 👍/👎 ─┐
YiPet 👍/👎 ─┤
              ├→ YiAi translate_service.translation_feedback()
              │    → MongoDB translation_feedback {rating: 'good'|'bad'}
              │      → provider_health RPC {feedback: {good, bad}}
              │        → YiPot History 页 N% 👍
              │        → YiVad TranslationAnalytics 好评/差评统计
              └── 全链路闭环
```

### 3. 智能引擎推荐闭环
```
YiPot TargetArea 语言选择
  → YiAi provider_recommend(from_lang, to_lang)
    → provider_health(24h) → MongoDB 聚合
      ← {recommended, providers: [{name, status, success_rate}], ...}
        → YiPot 下拉菜单健康点 (绿/黄/红) + Best 徽章
        → YiVad Smart Provider Ranking 面板
```

### 4. 流式翻译闭环
```
YiPot TargetArea (openai/ollama)
  → YiAi translate_stream RPC (SSE)
    → provider.translate_stream() → httpx stream
      → text/event-stream chunks
        → YiPot UI 逐字实时显示
```

### 5. RAG 上下文闭环
```
YiKnowledge markdown 树
  → YiAi knowledge watcher (apscheduler 轮询)
    → MongoDB knowledge_files + llama_index 向量索引
      → YiAi translate_with_context_detailed(domain)
        → _fetch_rag_sources() → RAG query
          ← [{file_path, score, snippet}]
            → YiPot RAG 来源芯片 (yiKnowledge 文件路径)
            → YiVad/YiPet RAG 增强对话
```

### 6. 项目健康闭环
```
YiPet ProjectHealthCard (在 YiVad /project/ 页)
  → DashboardService.getSummary()
    → YiAi GET /dashboard/summary
      → MongoDB aggregate (issues + bugs + sessions)
        ← {open_issues, open_bugs, today_done, overdue, projects: [...]}
          → 4 格统计 + 子项目健康色彩点
```

### 7. 翻译记忆缓存闭环
```
YiPot/YiPet 重复翻译
  → YiAi memory_service.lookup() → SHA256 哈希查询
    → MongoDB translation_memory
      → 命中 → {cached: true} → YiPot ⚡ Cached 徽章
      → 未命中 → 第三方 API → memory_service.store()
    → YiPot History 页 N cached 统计
```

### 8. 个人活动统计闭环
```
YiPet StatsBar
  → 本地 Pinia store (已从 YiAi 加载)
    → 会话数 (sessions) + 知识文件数 (knowledgeTree) + Bug 数 (recentBugs)
      → 4 格统计 + 数据新鲜度脉冲 (绿点 < 60s)
```

### 9. 提示词模板闭环
```
YiPet TemplatePicker (8 内置模板)
  → 用户选择 → 填写变量 → 实时预览
    → 应用到输入框 (setInputText)
      → 发送到 YiAi chat_service.chat
```

### 10. 项目仪表盘闭环
```
YiPet ProjectHealthCard
  → YiVad 项目页自动检测 (URL pattern)
    → 数据自动刷新 (watch URL 变化)
      → 优雅降级 (YiAi 不可达不阻塞聊天)
```

## 数据一致性保障

| 原则 | 实现 |
|------|------|
| 单一数据源 | 所有分析数据通过 YiAi MongoDB 聚合，前端不直接访问 |
| RPC 协议统一 | `{module_name, method_name, parameters}` 信封 |
| 参数名称契约 | `filter` (非 `query`)、`target_file` (非 `path`) |
| 类型对齐 | YiVad/YiPot/YiPet 共享 TypeScript 类型定义 |
| 实时性 | SSE 流式翻译 + 30s 轮询分析 + 手动刷新 |
