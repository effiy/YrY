# 编码规范

> 写出符合 YiAi 项目风格的 Python 代码。所有示例均来自 `src/` 实际代码。

## 一、分层导入规则

```
server/  →  services/  →  domain/  →  data/  →  shared/
```

| 层 | 可导入 | 禁止导入 |
|----|--------|---------|
| `server/` | services/, shared/ | data/, domain/ |
| `services/` | domain/, data/, shared/ | server/ |
| `domain/` | data/, shared/ | server/, services/ |
| `data/` | shared/ | domain/, server/, services/ |
| `shared/` | — | 所有业务模块 |

**注意**：导入路径不带 `src.` 前缀（pyproject.toml → `pythonpath = ["src"]`）。

```python
# 正确
from shared.error_codes import ErrorCode
from shared.exceptions import BusinessException
from data.database import db

# 错误：带了 src. 前缀
from src.shared.error_codes import ErrorCode
```

## 二、命名约定

| 类型 | 约定 | 示例 |
|------|------|------|
| 文件 | snake_case | `chat_service.py`, `error_codes.py` |
| 类 | PascalCase | `StandardResponse`, `BusinessException` |
| 函数/变量 | snake_case | `query_documents`, `page_num` |
| 常量 | UPPER_SNAKE_CASE | `_QUERY_MAX_TIME_MS`, `_LIGHTWRITE_COLLECTIONS` |
| 私有函数 | `_` 前缀 | `_build_filter`, `_write_concern` |
| 测试文件 | `test_` + snake_case | `test_utils.py`, `test_config.py` |

## 三、代码风格

### 异步优先
```python
# 正确
async def query_documents(params: dict[str, Any]) -> dict[str, Any]:
    return await db.db[collection_name].aggregate(pipeline).to_list(1)

# 错误：混用同步/异步
def query_documents(params):
    return db.db[collection_name].find(filter_dict)  # 阻塞事件循环
```

### 类型注解
```python
# 正确：完整类型注解（Python 3.10+ union 语法）
async def initialize(self) -> None:
    self._client: AsyncIOMotorClient | None = AsyncIOMotorClient(...)

# 错误：缺少或使用旧式注解
def initialize(self):
    self._client: Optional[AsyncIOMotorClient] = ...
```

### 错误处理
```python
# 正确：ErrorCode 枚举 + BusinessException
from shared.error_codes import ErrorCode
from shared.exceptions import BusinessException

if not document:
    raise BusinessException(ErrorCode.DATA_NOT_FOUND, "文档不存在")

# 错误：返回裸字典或裸异常
if not document:
    return {"error": "文档不存在"}          # 绕过统一错误处理
    raise Exception("文档不存在")            # 无错误码分类
```

### 响应封装
```python
# 正确：success() / fail() 辅助函数
from shared.response import success, fail

@router.get("/health")
async def health():
    return success(data={"status": "ok"})

@router.post("/something")
async def something():
    if not doc:
        return fail(ErrorCode.DATA_NOT_FOUND, "文档不存在")

# 错误：自己构造字典或使用不存在的 API
return {"code": 0, "message": "ok", "data": items}
return StandardResponse.success(items)  # StandardResponse 无此方法
```

**`success()` 签名**：`success(data=None, message="success", code=0, pagination=None, http_code=200, cache_ttl=None)` → `ORJSONResponse`

**`fail()` 签名**：`fail(error: ErrorCode, message=None, data=None)` → `ORJSONResponse`

### 导入组织
```python
# 标准顺序：标准库 → 第三方 → 本地模块
from datetime import datetime, timezone
import logging
import threading

from motor.motor_asyncio import AsyncIOMotorClient
from pymongo import monitoring

from shared.config import settings
from shared.error_codes import ErrorCode
```

## 四、并发模式

```python
# 正确：asyncio.gather 并发，带 return_exceptions
async def _warmup_cache():
    menus, scan, rag = await asyncio.gather(
        _warm_menus(),
        _warm_knowledge_scan(),
        _preload_rag_index(),
        return_exceptions=True,  # 单个失败不影响其他
    )

# 错误：串行等待
menus = await _warm_menus()
scan = await _warm_knowledge_scan()
rag = await _preload_rag_index()
```

## 五、日志规范

| 级别 | 场景 |
|------|------|
| DEBUG | 函数参数、中间变量、跳过的预热 |
| INFO | 服务启动、索引构建、连接建立 |
| WARNING | 配置缺失、慢查询（>200ms）、重试 |
| ERROR | API 失败、异常处理 |

```python
logger = logging.getLogger(__name__)
logger.info("MongoDB connected: %s", database_name)
# 使用 %s 格式化（延迟求值），不用 f-string
```

## 六、测试规范

```python
# 命名：test_<模块>_<场景>_<预期>
def test_query_documents_with_filter_returns_filtered(): ...
def test_query_documents_empty_collection_returns_empty(): ...

# 使用 pytest fixtures
# tests/conftest.py 提供 shared fixtures (sample_text, sample_json_text 等)
```

覆盖率目标：`shared/` ≥ 90%、`data/` ≥ 80%、`domain/` ≥ 70%、`services/` ≥ 70%

## 七、代码审查清单

- [ ] 分层导入正确（domain 不导入 server，import 不带 `src.` 前缀）
- [ ] 异步一致（所有 I/O 用 async/await）
- [ ] 类型注解完整（Python 3.10+ `X | None` 语法）
- [ ] 使用 `ErrorCode` 枚举 + `BusinessException` 处理异常
- [ ] 使用 `success()` / `fail()` 封装响应
- [ ] `_id` 通过 projection `{'_id': 0}` 排除，不返回给前端
- [ ] 日志用 `logger`（`%s` 格式化），而非 `print`
- [ ] 外部 I/O 用 `asyncio.timeout` 包装
- [ ] 裸 `except Exception` 替换为具体异常类型
- [ ] `ruff check` 通过 (`ruff.toml` 配置)
