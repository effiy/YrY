## 二、核心框架

| 包 | 版本 | 用途 | 为什么选它 |
|----|------|------|-----------|
| fastapi | >= 0.140.0 | Web 框架（ASGI 异步） | 原生 async/await、自动 OpenAPI、类型安全 |
| uvicorn | >= 0.51.0 | ASGI 服务器 | 高性能、支持热重载、与 FastAPI 官方推荐 |
| pydantic | >= 2.13.4 | 数据验证 | 类型安全、序列化/反序列化、与 FastAPI 深度集成 |
| pydantic-settings | >= 2.14.2 | 配置管理 | YAML + 环境变量覆盖、类型安全配置 |

### FastAPI 依赖关系

```
fastapi
  ├── starlette（内置）— ASGI 框架核心
  │     ├── 路由匹配
  │     ├── 中间件（CORS, Auth, Observer）
  │     └── 异常处理器
  ├── pydantic — 请求/响应模型验证
  └── uvicorn — ASGI 服务器
```

## 三、数据库

| 包 | 版本 | 用途 | 为什么选它 |
|----|------|------|-----------|
| motor | >= 3.7.1 | MongoDB 异步驱动 | 与 FastAPI async 兼容、连接池管理、官方推荐 |
| pymongo | >= 4.17.0 | MongoDB 同步驱动 | 种子数据导入（启动时同步操作） |

### Motor vs PyMongo 使用场景

| 场景 | 使用 | 原因 |
|------|------|------|
| API 请求中的数据库操作 | motor | 异步非阻塞，不阻塞事件循环 |
| 启动时种子数据导入 | pymongo | 启动阶段无需异步，同步代码更简单 |
| 数据迁移脚本 | pymongo | 脚本通常同步执行 |
| 测试 | motor (pytest-asyncio) | 异步测试框架 |

### 连接池配置

```python
# src/data/database.py
AsyncIOMotorClient(
    uri,
    maxPoolSize=50,           # 最大连接数（并发峰值）
    minPoolSize=10,           # 最小连接数（避免冷启动延迟）
    maxIdleTimeMS=30000,      # 空闲连接 30s 后回收
    connectTimeoutMS=5000,    # 连接超时 5s
    serverSelectionTimeoutMS=5000,  # 服务器选择超时
)
```

## 四、AI/ML

| 包 | 版本 | 用途 | 为什么选它 |
|----|------|------|-----------|
| ollama | >= 0.6.2 | Ollama API 客户端 | 本地 LLM 推理、无需 GPU、模型管理方便 |
| llama-index | >= 0.13.0 | RAG 框架 | 混合检索（向量+BM25）、多种嵌入模型支持 |
| llama-index-embeddings-ollama | >= 0.6.0 | Ollama Embedding | 与 Ollama 服务集成，统一部署 |
| llama-index-llms-ollama | >= 0.6.0 | Ollama LLM | 本地 LLM 推理集成 |
| openai | >= 1.0.0 | OpenAI API 客户端 | 兼容 OpenAI 格式的 API（多后端支持） |
| anthropic | >= 0.40.0 | Anthropic API 客户端 | Claude API 集成 |
| rank-bm25 | >= 0.2.2 | BM25 关键词检索 | 轻量级、无外部依赖、与向量检索互补 |
| transformers | >= 5.14.1 | HuggingFace Transformers | 分词器、模型加载（可选） |

### LLM 后端支持矩阵

| 后端 | 协议 | 使用场景 | 配置 |
|------|------|----------|------|
| Ollama | Ollama API | 本地开发、离线环境 | `ollama.base_url` |
| OpenAI | OpenAI API | 生产环境、云端推理 | `openai.api_key` |
| Anthropic | Anthropic API | 复杂推理任务 | `anthropic.api_key` |

### RAG 混合检索架构

```
用户查询
  │
  ├── 向量检索（llama-index）
  │     └── embedding model → 语义相似度 → top_k 结果
  │
  ├── BM25 检索（rank-bm25）
  │     └── 关键词频率 → 精确匹配 → top_k 结果
  │
  └── 融合排序（RRF）
        └── 合并去重 → 最终结果
```

### 重试策略配置

```python
from tenacity import retry, stop_after_attempt, wait_exponential

@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=1, max=10),
    reraise=True,
)
async def call_external_api(url: str):
    """外部 API 调用，自动重试 3 次，指数退避"""
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as resp:
            return await resp.json()
```

## 七、不包含的依赖（为什么）

| 未包含 | 替代方案 | 原因 |
|--------|----------|------|
| Django/Flask | FastAPI | 需要原生 async/await 支持，OpenAPI 自动生成 |
| SQLAlchemy | Motor (MongoDB) | MongoDB 文档模型，不需要 ORM |
| Alembic | 手动迁移脚本 | MongoDB 无 Schema，不需要 DDL 迁移 |
| Celery | apscheduler | 轻量级定时任务，不需要消息队列 |
| Redis | MongoDB | 会话数据存储在 MongoDB，无需额外缓存层 |
| gRPC | RPC 信封 (HTTP) | 前端通过 HTTP 调用，不需要 gRPC |
| GraphQL | RPC 信封 | 统一的 RPC 协议，不需要 GraphQL 层 |
| Docker | 直接部署 | 单机部署，不需要容器化 |
| Kubernetes | 直接部署 | 单服务，不需要编排 |

## 八、安装

### 完整安装

```bash
pip install -r requirements.txt
```

### 按场景安装

```bash
# 仅核心依赖（不含 AI/ML，适用于纯 CRUD 服务）
pip install fastapi uvicorn pydantic pydantic-settings \
            motor pymongo PyYAML apscheduler aiohttp aiofiles \
            bcrypt PyJWT python-multipart tenacity

# 仅 AI/ML 依赖
pip install ollama llama-index llama-index-embeddings-ollama \
            llama-index-llms-ollama openai anthropic rank-bm25

# 仅测试依赖
pip install pytest pytest-asyncio httpx pytest-cov

# 开发依赖（包含所有）
pip install -r requirements.txt
pip install pytest pytest-asyncio httpx pytest-cov
```

### 版本锁定

```bash
# 生成锁定文件
pip freeze > requirements-lock.txt

# 从锁定文件安装
pip install -r requirements-lock.txt
```

## 十、约束

### 必须遵守
- 所有依赖通过 `requirements.txt` 管理，版本固定下限
- 新增依赖前评估：是否已有替代品、是否积极维护、许可证兼容性
- AI/ML 依赖保持多后端支持（不锁定单一提供商）
- 测试依赖与生产依赖分离

### 禁止
- 不添加仅用于单一功能的重量级依赖
- 不引入需要额外系统服务（如 Redis、RabbitMQ）的依赖
- 不在生产代码中使用 `pip install` 直接安装
- 不锁定过紧的版本上限（使用 `>=` 而非 `==`）
- 不忽略依赖安全漏洞警告
