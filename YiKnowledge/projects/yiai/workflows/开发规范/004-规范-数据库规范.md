# 数据库规范

> YiAi 使用 MongoDB + Motor 异步驱动，通过数据层单例 + 模块级函数封装数据访问。以下代码均来自 `src/data/` 实际源文件。

## 一、MongoDB 单例（database.py）

```python
# src/data/database.py — 全局单例
class MongoDB:
    _instance: Optional['MongoDB'] = None
    _lock: threading.Lock = threading.Lock()
    _client: AsyncIOMotorClient | None = None
    _db = None
    _initialized: bool = False

    def __new__(cls): ...  # 线程安全双重检查

    async def initialize(self):
        """从 settings 读取 mongodb_url/mongodb_db_name，创建连接池"""
        if self._initialized:
            return
        self._client = AsyncIOMotorClient(
            settings.mongodb_url,
            appname="YiAi",
            maxPoolSize=settings.mongodb_max_pool_size,    # 默认 50
            minPoolSize=settings.mongodb_pool_size,        # 默认 10
            maxIdleTimeMS=30000,
            waitQueueTimeoutMS=10000,
            socketTimeoutMS=30000,
            connectTimeoutMS=5000,
            serverSelectionTimeoutMS=5000,
            retryWrites=True,
            retryReads=True,
            maxConnecting=2,
        )
        self._db = self._client[settings.mongodb_db_name]
        await self._ensure_indexes()
        self._initialized = True

db = MongoDB()  # 全局单例
```

**关键差异 vs 旧文档**：`initialize()` 无参数，从 `settings` 读取配置，而非 `connect(uri, db_name)`。

## 二、Repository 访问层（repository.py）

实际代码是**模块级函数**，不是 Class：

```python
# src/data/repository.py — 模块级函数
async def query_documents(params: dict[str, Any]) -> dict[str, Any]:
    """分页查询 → {list, total, pageNum, pageSize, totalPages}"""
    # 支持 cname 和 collection_name 两种参数名
    collection_name = params.get('collection_name') or params.get('cname')
    # 从 params 弹出 filter → 合并到查询参数
    filter_param = params.pop('filter', None)
    if filter_param and isinstance(filter_param, dict):
        params.update(filter_param)
    # 分页参数带上下限约束
    page_num = max(1, int(params.pop('pageNum', 1)))
    page_size = min(settings.pagination_max_size,
                    max(settings.pagination_min_size,
                        int(params.pop('pageSize', settings.pagination_default_size))))
    # 排序
    sort_param = params.pop('orderBy', 'order')
    sort_order = -1 if params.pop('orderType', 'asc').lower() == 'desc' else 1
    # 构建查询
    filter_dict = build_filter(params)  # 来自 data/filter_helpers.py
    # 投影：sessions 自动排除 pageContent，users 自动排除 password
    projection = _build_projection(collection_name, fields_param, exclude_fields_param)
    # $facet 单次查询分页（替代 find + count_documents 两次往返）
    collection = db.db[collection_name]
    pipeline = [
        {'$match': filter_dict},
        {'$sort': {sort_param: sort_order}},
        {'$facet': {
            'list': [{'$skip': (page_num - 1) * page_size}, {'$limit': page_size}],
            'total': [{'$count': 'count'}]
        }}
    ]
    result = await collection.aggregate(pipeline, maxTimeMS=_QUERY_MAX_TIME_MS).to_list(1)
    ...
```

**关键差异 vs 旧文档**：
- 不是 `class Repository`，是模块级 `async def query_documents(params)`
- `_build_filter` → `build_filter`（在 `data/filter_helpers.py` 中）
- 使用 `$facet` 聚合管道（单次查询）替代 `find()` + `count_documents()`（两次往返）
- 支持 `cname` 和 `collection_name` 双参数名
- 自动排除敏感字段（sessions.pageContent、users.password）

## 三、写关注分级（w=0 优化）

非关键集合使用 `w=0` (fire-and-forget)，减少写延迟：

```python
# src/data/database.py
_LIGHTWRITE_COLLECTIONS: frozenset[str] = frozenset({
    "audit_logs",       # settings.audit_collection
    "state_records",    # settings.collection_state_records
    "chat_records",     # settings.collection_chat_records
})

def _write_concern(collection_name: str) -> int:
    return 0 if (_LIGHTWRITE_ENABLED and collection_name in _LIGHTWRITE_COLLECTIONS) else 1

# insert_one / insert_many 自动应用
result = await self.db[collection_name].with_options(
    write_concern=_write_concern(collection_name)
).insert_one(document)
```

可通过 `config.yaml` → `mongodb_lightwrite_enabled: false` 关闭此优化。

## 四、慢查询监控

```python
# src/data/database.py — PyMongo CommandListener
class _SlowQueryLogger(monitoring.CommandListener):
    def succeeded(self, event):
        elapsed_ms = (time.monotonic() - t0) * 1000
        if elapsed_ms >= _SLOW_QUERY_THRESHOLD_MS:  # 默认 200ms
            logger.warning(f"Slow query: {cmd} — {elapsed_ms:.0f}ms")

monitoring.register(_SlowQueryLogger())  # 导入时注册，全局生效
```

其他性能参数：
- `_QUERY_MAX_TIME_MS`：查询超时，默认 30000ms（`mongodb_query_timeout_ms`）
- `_CURSOR_BATCH_SIZE`：游标批量大小，默认 500（`mongodb_cursor_batch_size`，减少~5× 往返）

## 五、索引策略

以下是 `_ensure_indexes()` 中定义的实际索引（精确）：

| 集合 | 索引 | 类型 | 查询模式 |
|------|------|------|---------|
| `rss` | `{link: 1}` | 唯一 | RSS 去重 |
| `knowledge_files` | `{path: 1}` | 唯一 | 知识文件查找 |
| `knowledge_files` | `{category: 1, path: 1}` | 复合 | 按分类筛选 |
| `state_records` | `{expiresAt: 1}` | TTL | 自动过期 |
| `sessions` | `{updatedTime: -1}` | 降序 | 会话列表 |
| `sessions` | `{projectName: 1, storyName: 1}` | 复合 | 任务面板查询 |
| `bugs` | `{status: 1, severity: 1}` | 复合 | 缺陷筛选 |
| `bugs` | `{project: 1, createdTime: -1}` | 复合 | 项目缺陷列表 |
| `issues` | `{project_key: 1, status: 1}` | 复合 | 项目任务列表 |
| `rss` | `{createdTime: -1}` | 降序 | Feed 列表 |
| `menus` | `{order: 1}` | 升序 | 菜单树构建 |
| `chat_records` | `{createdTime: -1}` | 降序 | 聊天记录 |
| `state_records` | `{skill_name: 1, createdTime: -1}` | 复合 | 技能状态查询 |
| `audit_logs` | `{collection: 1, action: 1}` | 复合 | 审计日志查询 |

种子数据使用 **upsert** 策略（非仅空集合导入）：每次启动对所有 seed 文档执行 `replace_one(..., upsert=True)`，确保新增/修改的 seed 条目自动同步。

## 七、约束

- 所有 MongoDB 操作通过 `db` 单例或 `data/repository.py` 模块函数
- 分页参数 `filter`（非 `query`），集合参数支持 `cname` 和 `collection_name`
- `_id` 返回前序列化为字符串（通过 projection `{'_id': 0}` 排除）
- 种子数据 **upsert**（非仅空集合），每次重启同步新增条目
- 非关键集合（audit_logs/state_records/chat_records）默认 w=0
- Motor 游标 `batch_size=500`，查询 `maxTimeMS=30000`
