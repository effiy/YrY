## 一、MongoDB 架构

### 整体架构

```
MongoDB（Motor async driver）
├── 数据库：ruiyi（config: mongodb.db_name）
├── 连接池：pool_size=10, max_pool_size=50
├── 连接 URI：mongodb://localhost:27017（config: mongodb.uri）
├── 驱动：motor（异步），禁止混用同步 pymongo
└── 集合（15+）：
    ├── sessions           # 聊天会话
    ├── menus              # 菜单配置
    ├── users              # 用户
    ├── projects           # 项目
    ├── issues             # 任务/Issue

    ├── labels             # 标签
    ├── bugs               # Bug 跟踪
```

### 连接管理

```python
# src/data/database.py
from motor.motor_asyncio import AsyncIOMotorClient, AsyncIOMotorDatabase
from contextlib import asynccontextmanager

class MongoDB:
    """MongoDB 单例 — Motor async driver"""

    client: AsyncIOMotorClient
    db: AsyncIOMotorDatabase

    def __init__(self):
        self.client = None
        self.db = None

    async def connect(self, uri: str, db_name: str):
        """连接 MongoDB"""
        self.client = AsyncIOMotorClient(
            uri,
            maxPoolSize=50,        # 最大连接池大小
            minPoolSize=10,        # 最小连接池大小
            maxIdleTimeMS=30000,   # 空闲连接超时 30s
            connectTimeoutMS=5000, # 连接超时 5s
            serverSelectionTimeoutMS=5000,
        )
        self.db = self.client[db_name]

        # 验证连接
        await self.client.admin.command("ping")
        logger.info(f"MongoDB connected: {db_name}")

    async def disconnect(self):
        """断开 MongoDB 连接"""
        if self.client:
            self.client.close()
            logger.info("MongoDB disconnected")

    # ── CRUD 方法 ──

    async def find_one(self, collection: str, query: dict) -> dict | None:
        return await self.db[collection].find_one(query)

    async def find_many(
        self, collection: str, query: dict,
        sort: list[tuple] | None = None,
        skip: int = 0, limit: int = 0,
        projection: dict | None = None
    ) -> list[dict]:
        cursor = self.db[collection].find(query, projection)
        if sort:
            cursor = cursor.sort(sort)
        if skip:
            cursor = cursor.skip(skip)
        if limit:
            cursor = cursor.limit(limit)
        return await cursor.to_list(length=None)

    async def insert_one(self, collection: str, document: dict):
        return await self.db[collection].insert_one(document)

    async def insert_many(self, collection: str, documents: list[dict]):
        return await self.db[collection].insert_many(documents)

    async def update_one(self, collection: str, query: dict, update: dict, upsert: bool = False):
        return await self.db[collection].update_one(query, update, upsert=upsert)

    async def delete_one(self, collection: str, query: dict):
        return await self.db[collection].delete_one(query)

    async def aggregate(self, collection: str, pipeline: list[dict]) -> list[dict]:
        cursor = self.db[collection].aggregate(pipeline)
        return await cursor.to_list(length=None)

    async def count_documents(self, collection: str, query: dict = {}) -> int:
        return await self.db[collection].count_documents(query)

# 全局单例
db = MongoDB()
```

> 单例方法仅在调用者需要时才扩展。不要推测性地添加方法。

### 通用仓库

```python
# src/data/repository.py
from src.data.database import db
from math import ceil

async def query_documents(
    cname: str,
    filter: dict | None = None,
    pageNum: int = 1,
    pageSize: int = 20,
    orderBy: str | None = None,
    orderType: str = "desc",
    fields: list[str] | None = None,
    excludeFields: list[str] | None = None
) -> dict:
    """通用分页查询
    Returns: { list, total, pageNum, pageSize, totalPages }
    """
    query = filter or {}

    # 构建 projection
    projection = None
    if fields:
        projection = {f: 1 for f in fields}
    if excludeFields:
        projection = projection or {}
        projection.update({f: 0 for f in excludeFields})

    # 排序
    sort = None
    if orderBy:
        sort = [(orderBy, -1 if orderType == "desc" else 1)]

    # 总数
    total = await db.count_documents(cname, query)

    # 分页
    skip = (pageNum - 1) * pageSize
    items = await db.find_many(cname, query, sort=sort, skip=skip, limit=pageSize, projection=projection)

    # 序列化 ObjectId
    for item in items:
        if "_id" in item:
            item["_id"] = str(item["_id"])

    return {
        "list": items,
        "total": total,
        "pageNum": pageNum,
        "pageSize": pageSize,
        "totalPages": ceil(total / pageSize) if total > 0 else 0
    }

async def create_document(cname: str, data: dict) -> dict:
    """创建文档"""
    result = await db.insert_one(cname, data)
    return {"inserted_id": str(result.inserted_id)}

async def update_document(cname: str, key: dict, data: dict) -> dict:
    """更新文档"""
    result = await db.update_one(cname, key, {"$set": data})
    return {"modified_count": result.modified_count}

async def delete_document(cname: str, key: dict) -> dict:
    """删除文档"""
    result = await db.delete_one(cname, key)
    return {"deleted_count": result.deleted_count}

async def get_document(cname: str, key: dict) -> dict | None:
    """获取单个文档"""
    doc = await db.find_one(cname, key)
    if doc and "_id" in doc:
        doc["_id"] = str(doc["_id"])
    return doc
```

## 四、查询模式

### _build_filter 查询构建

`_build_filter(query_params)` 将 HTTP 参数转为 Mongo 查询条件：

| 参数模式 | Mongo 操作符 | 示例输入 | 生成查询 |
|----------|-------------|----------|----------|
| 精确值 | `$eq` | `{"status": "open"}` | `{"status": "open"}` |
| 字符串 | `$regex` | `{"name": "proj"}` | `{"name": {"$regex": "proj", "$options": "i"}}` |
| 范围（2 元素列表） | `$gte, $lte` | `{"created_at": ["2024-01-01", "2024-12-31"]}` | `{"created_at": {"$gte": "...", "$lte": "..."}}` |
| 列表 | `$in` | `{"tags": ["work", "personal"]}` | `{"tags": {"$in": ["work", "personal"]}}` |
| 排除 | `$ne` | `{"status": "!archived"}` | `{"status": {"$ne": "archived"}}` |
| 存在性 | `$exists` | `{"assignee": "!null"}` | `{"assignee": {"$exists": True, "$ne": None}}` |

```python
# src/data/query_builder.py
def _build_filter(params: dict) -> dict:
    """将前端查询参数转为 MongoDB 查询条件"""
    query = {}

    for key, value in params.items():
        if value is None or value == "":
            continue

        # 排除条件：!value
        if isinstance(value, str) and value.startswith("!"):
            query[key] = {"$ne": value[1:]}
        # 空值检查：!null
        elif isinstance(value, str) and value == "!null":
            query[key] = {"$exists": True, "$ne": None}
        # 范围查询：[min, max]
        elif isinstance(value, list) and len(value) == 2:
            query[key] = {"$gte": value[0], "$lte": value[1]}
        # 列表包含：$in
        elif isinstance(value, list):
            query[key] = {"$in": value}
        # 字符串模糊匹配
        elif isinstance(value, str):
            query[key] = {"$regex": value, "$options": "i"}
        # 精确匹配
        else:
            query[key] = value

    return query
```

## 五、聚合管道

### 常用聚合示例

```python
# 按状态统计
pipeline = [
    {"$match": {"project_id": "proj-001"}},
    {"$group": {"_id": "$status", "count": {"$sum": 1}}},
    {"$sort": {"count": -1}}
]
results = await db.aggregate("issues", pipeline)
# → [{_id: "open", count: 15}, {_id: "resolved", count: 30}, ...]

# 按项目统计 Bug 严重程度
pipeline = [
    {"$match": {"status": {"$ne": "closed"}}},
    {"$group": {
        "_id": {"project": "$project", "severity": "$severity"},
        "count": {"$sum": 1}
    }},
    {"$sort": {"count": -1}}
]
results = await db.aggregate("bugs", pipeline)

# 知识文件按分类统计
pipeline = [
    {"$match": {"status": "active"}},
    {"$group": {
        "_id": "$category",
        "count": {"$sum": 1},
        "latest": {"$max": "$scanned_at"}
    }},
    {"$sort": {"count": -1}}
]
results = await db.aggregate("knowledge_files", pipeline)
```

```python
# src/data/seeds/__init__.py
import json
import os

async def seed_database():
    """导入种子数据 — 仅当集合为空时"""
    seeds_dir = os.path.dirname(__file__)

    for filename in os.listdir(seeds_dir):
        if not filename.endswith(".json"):
            continue

        collection = filename.replace(".json", "")
        count = await db.count_documents(collection)

        if count == 0:
            with open(os.path.join(seeds_dir, filename), "r") as f:
                data = json.load(f)

            if isinstance(data, list) and len(data) > 0:
                await db.insert_many(collection, data)
                logger.info(f"Seeded {collection}: {len(data)} documents")
```

### 连接池调优

| 配置项 | 默认值 | 说明 | 调优建议 |
|--------|--------|------|----------|
| `min_pool_size` | 10 | 最小连接数 | 保持默认，避免冷启动延迟 |
| `max_pool_size` | 50 | 最大连接数 | 并发高时增大，但不超过 MongoDB 最大连接数 |
| `max_idle_time_ms` | 30000 | 空闲连接超时 | 30s 足够，过短导致频繁重连 |
| `connect_timeout_ms` | 5000 | 连接超时 | 5s 合理，内网环境可降到 2s |
| `server_selection_timeout_ms` | 5000 | 服务器选择超时 | 副本集环境适当增大 |

## 九、反模式

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 在路由中直接操作 MongoDB | 路由中 `await db.find_one(...)` | 路由 → Service → Repository → MongoDB | 分层架构破坏，难以测试和维护 |
| 混用同步 pymongo | `import pymongo; client = pymongo.MongoClient()` | 统一使用 motor `AsyncIOMotorClient` | 阻塞事件循环 |
| 推测性添加方法 | 给 MongoDB 单例添加 `find_by_regex` 方法 | 仅在调用者需要时扩展 | 死代码积累 |
| 硬编码集合名称 | `db.find_one("projects", ...)` | 使用常量 `PROJECTS_COLLECTION = "projects"` | 集合名变更需改多处 |
| 无索引查询 | 在大集合上无索引字段查询 | 为常用查询字段创建索引 | 全表扫描，性能差 |
| 内存排序 | 无索引排序 `sort("created_at")` | 创建 `created_at` 索引 | 超过 32MB 内存限制时报错 |
| N+1 查询 | 循环中逐个查询 | 使用 `$in` 或聚合管道 | 性能差 |
| 忽略 ObjectId 序列化 | 直接返回 `doc["_id"]` (ObjectId) | 转为字符串 `str(doc["_id"])` | JSON 序列化失败 |
| 大文档 | 单个文档超过 16MB | 拆分为多个文档或使用 GridFS | MongoDB 文档大小限制 |
| 无超时配置 | 不设置 `connectTimeoutMS` | 设置连接超时和服务器选择超时 | 连接失败时长时间阻塞 |

## 十、约束

### 必须遵守

- 所有数据库操作通过 `data/` 层，不直接在 routes 或 services 中操作 MongoDB
- 使用 Motor async driver，不混用同步 pymongo
- 新增集合时在 `data/seeds/` 中添加种子数据
- 查询使用 `_build_filter` 构建，不手写 Mongo 查询条件
- 为常用查询字段创建索引
- 返回前将 ObjectId 转为字符串
- 文档大小控制在 16MB 以内
- 设置连接超时和服务器选择超时

### 禁止

- 不在 routes 中直接调用 `database.py` 的方法
- 不推测性地向 MongoDB 单例添加方法
- 不使用同步 pymongo（除非有充分理由并记录）
- 不在查询中硬编码集合名称
- 不在循环中逐个查询（N+1 问题）
- 不在大集合上做无索引的排序或查询
