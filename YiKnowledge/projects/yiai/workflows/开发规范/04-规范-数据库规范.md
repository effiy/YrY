# 数据库规范

> **读完你将能够**：掌握 MongoDB 操作规范、Repository 模式、数据模型

> YiAi 使用 MongoDB + Motor 异步驱动，通过 Repository 模式封装数据访问。

## 一、MongoDB 单例

```python
# src/data/database.py
class MongoDB:
    _instance = None
    _lock = threading.Lock()
    _client: AsyncIOMotorClient | None = None
    _db = None

    def __new__(cls):
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance

    async def connect(self, uri: str, db_name: str):
        self._client = AsyncIOMotorClient(uri, maxPoolSize=50, minPoolSize=10)
        self._db = self._client[db_name]

db = MongoDB()  # 全局单例
```

## 二、Repository 模式

```python
# src/data/repository.py
class Repository:
    async def query_documents(self, cname, filter=None, pageNum=1, pageSize=20,
                              orderBy=None, orderType="desc", fields=None, excludeFields=None):
        """分页查询 → {list, total, pageNum, pageSize, totalPages}"""
        mongo_filter = _build_filter(filter or {})
        total = await db.db[cname].count_documents(mongo_filter)
        cursor = db.db[cname].find(mongo_filter, projection)
        if orderBy:
            cursor = cursor.sort(orderBy, -1 if orderType == "desc" else 1)
        items = await cursor.skip((pageNum-1)*pageSize).limit(pageSize).to_list(pageSize)
        for item in items:
            if "_id" in item: item["_id"] = str(item["_id"])
        return {"list": items, "total": total, "pageNum": pageNum, "pageSize": pageSize,
                "totalPages": ceil(total/pageSize) if total > 0 else 0}
```

## 三、_build_filter 查询构建

支持的查询模式：
- 精确值：`{"status": "open"}`
- 模糊匹配：`{"name": "proj"}` → `{"$regex": "proj", "$options": "i"}`
- 范围查询：`{"created_at": ["2024-01-01", "2024-12-31"]}` → `{"$gte": ..., "$lte": ...}`
- IN 查询：`{"tags": ["a", "b"]}` → `{"$in": ["a", "b"]}`
- 排除：`{"status": "!archived"}` → `{"$ne": "archived"}`

## 四、集合与数据模型

| 集合 | 用途 | 唯一键 | 关键字段 |
|------|------|--------|---------|
| `sessions` | 聊天会话 | `key` | title, messages[], tags[], pageContent |
| `bugs` | 缺陷追踪 | `key` | title, project, severity, status, assignee |
| `menus` | 动态菜单 | `path` | name, component, meta, parent, children |
| `users` | 用户 | `key` | username, password_hash, roles, permissions |
| `projects` | 项目 | `key` | name, status, leader, members |
| `issues` | 任务 | `key` | title, status, assignee, project_key |
| `knowledge_files` | 知识元数据 | `path` | title, tags, category, frontmatter, content_hash |
| `static_files` | 文件备份 | `path` | content, is_base64 |
| `state_records` | 状态存储 | `key` | record_type, title, payload, tags |
| `audit_logs` | 审计日志 | — | timestamp, user, action, details |

## 五、文件双写

```python
# 1. 主存储：写入磁盘（失败即返回错误）
with open(file_path, "w") as f:
    f.write(content)

# 2. 备份：MongoDB（尽力而为，失败不阻塞）
try:
    await db.update_one("static_files", {"file_path": target_file},
                        {"$set": {"content": content}}, upsert=True)
except Exception as e:
    logger.warning(f"MongoDB 备份失败: {e}")
```

## 六、索引策略

| 集合 | 索引 |
|------|------|
| `sessions`, `bugs`, `menus`, `state_records` | `{key/path: 1}` 唯一 |
| `knowledge_files`, `static_files` | `{path: 1}` 唯一 |
| `audit_logs` | `{timestamp: -1}` |
| `chat_records` | `{session_id: 1, timestamp: -1}` 复合 |

## 七、约束

- 所有 MongoDB 操作通过 `db` 单例或 Repository
- 分页参数 `filter`（非 `query`），集合参数 `cname`（非 `collection_name`）
- ObjectId 返回前序列化为字符串
- 种子数据仅在集合为空时导入
- 文件写入使用双写（磁盘 + MongoDB 备份）
