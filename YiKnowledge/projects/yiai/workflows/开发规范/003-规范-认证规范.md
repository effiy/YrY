# 认证规范

> YiAi 的认证体系：`domain/auth/core.py`（密码哈希 + JWT）、`server/middleware.py`（`AuthMiddleware` 纯 ASGI）、`server/routes/auth.py`（登录/登出/菜单）。

## 一、认证模式

```yaml
# config.yaml — 实际 flat keys
middleware_auth_enabled: false    # 开发模式默认关闭
auth_token: ""                    # 静态 token（X-Token 回退）
jwt_secret: "yi-ai-dev-secret"   # 生产环境必须覆盖
jwt_expire_minutes: 1440         # 24h
```

### 开发模式（默认）
`middleware_auth_enabled: false` — `AuthMiddleware` 对所有请求放行。

### 生产模式
`middleware_auth_enabled: true` — `AuthMiddleware` 验证每个非白名单请求。

## 二、AuthMiddleware（server/middleware.py）

```python
# src/server/middleware.py — 实际代码（纯 ASGI 协议）
class AuthMiddleware:
    """Optional auth via X-Token or JWT Authorization: Bearer."""

    def __init__(self, app, enabled: bool = False):
        self.app = app
        self._enabled = enabled
        self._required_token = settings.auth_token if enabled else ""

    async def __call__(self, scope, receive, send):
        # OPTIONS 预检 → 直接放行
        if scope["method"] == "OPTIONS":
            return await self.app(scope, receive, send)
        # 静态文件 → 直接放行
        # 白名单路径 → 直接放行（/health, /about/index, /login, /openai-compat/* 等）
        # 认证关闭 → 直接放行

        headers = {n.decode().lower(): v.decode() for n, v in scope.get("headers", [])}

        # 1. JWT Bearer token（优先）
        auth_header = headers.get("authorization", "")
        if auth_header.startswith("Bearer "):
            payload = verify_jwt(auth_header[7:])
            if payload:
                scope.setdefault("state", {})["user_id"] = payload.get("sub", "")
                return await self.app(scope, receive, send)
            return await _unauthorized_response(...)

        # 2. X-Token 静态 token（回退）
        x_token = headers.get("x-token", "")
        if x_token != self._required_token:
            return await _unauthorized_response(...)

        return await self.app(scope, receive, send)
```

**注册**（app.py）：
```python
if auth_enabled:
    app.add_middleware(AuthMiddleware, enabled=True)
```

**关键差异 vs 旧文档**：
- 是 `class AuthMiddleware`（纯 ASGI `__call__(scope, receive, send)`），不是函数 `header_verification_middleware(request, call_next)`
- 支持 `Authorization: Bearer <jwt>` 和 `X-Token: <static>` 双模式
- 使用白名单路径跳过认证（非全有/全无）

## 三、登录流程（server/routes/auth.py）

```python
# src/server/routes/auth.py — 实际代码（Pydantic 校验）
class LoginRequest(BaseModel):
    username: str
    password: str

@router.post("/login")
async def login(body: LoginRequest):
    await db.initialize()
    user = await db.db["users"].find_one({"username": body.username})
    if not user:
        raise BusinessException(ErrorCode.UNAUTHORIZED, "Incorrect username or password")
    if not verify_password(body.password, user.get("password", "")):
        raise BusinessException(ErrorCode.UNAUTHORIZED, "Incorrect username or password")
    token = create_jwt(str(user.get("key", "")), body.username)
    return success(data={"access_token": token, "username": body.username})
```

## 四、密码与 JWT（domain/auth/core.py）

```python
# src/domain/auth/core.py — 实际函数
def hash_password(plain: str) -> str:
    """bcrypt(plain) — 创建/更新用户时调用"""
    return bcrypt.hashpw(plain.encode("utf-8"), bcrypt.gensalt()).decode("utf-8")

def verify_password(plain: str, stored: str) -> bool:
    """bcrypt.checkpw — 永不抛异常，失败返回 False"""
    if not plain or not stored:
        return False
    try:
        return bcrypt.checkpw(plain.encode("utf-8"), stored.encode("utf-8"))
    except (ValueError, TypeError):
        return False

def create_jwt(user_id: str, username: str) -> str:
    """签发 JWT，payload: {sub, username, iat, exp}"""
    payload = {
        "sub": user_id,
        "username": username,
        "iat": datetime.now(timezone.utc),
        "exp": datetime.now(timezone.utc) + timedelta(minutes=expire_minutes),
    }
    return jwt.encode(payload, secret, algorithm="HS256")

def verify_jwt(token: str) -> dict | None:
    """解码 JWT，失败返回 None（不抛异常）"""
```

## 五、Agent 安全

- **确认门控**：写操作需用户确认，120s 超时自动拒绝
- **拒绝记忆**：最近 20 条被拒调用自动拦截
- **工具白名单**：仅 `ToolRegistry` 注册的工具可被调用
- **断连检测**：`CancelledError` → 保存状态 → 清理资源

## 六、约束

- 生产环境必须 `middleware_auth_enabled: true`
- JWT secret 通过环境变量覆盖（`jwt_secret`），禁止硬编码
- 密码用 `hash_password()`，不存储明文
- Agent 写操作必须经过确认门控
- `verify_password` 永不抛异常（返回 bool），登录路由据此返回 401
- `verify_jwt` 永不抛异常（返回 `dict | None`），中间件据此放行/拒绝
