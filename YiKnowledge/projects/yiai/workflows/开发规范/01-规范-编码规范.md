# 编码规范

> **读完你将能够**：写出符合 YiAi 项目风格的 Python 代码

## 一、分层导入规则

```
server/  →  services/  →  domain/  →  data/  →  shared/
```

| 层 | 可导入 | 禁止导入 |
|----|--------|---------|
| `server/` | services/, shared/ | data/, domain/ |
| `services/` | domain/, data/, shared/ | server/ |
| `domain/` | data/, shared/ | server/, services/ |
| `data/` | shared/ | domain/, server/, services/ |
| `shared/` | — | 所有业务模块 |

## 二、命名约定

| 类型 | 约定 | 示例 |
|------|------|------|
| 文件 | snake_case | `chat_service.py`, `error_codes.py` |
| 类 | PascalCase | `StandardResponse`, `BusinessException` |
| 函数/变量 | snake_case | `query_documents`, `page_num` |
| 常量 | UPPER_SNAKE_CASE | `MAX_PAGE_SIZE` |
| 私有函数 | `_` 前缀 | `_build_filter`, `_resolve_service` |
| 测试文件 | `test_` + snake_case | `test_agent.py` |

## 三、代码风格

### 异步优先
```python
# 正确
async def query_documents(cname: str, filter: dict | None = None) -> dict:
    return await db.find_many(cname, filter or {})

# 错误：混用同步/异步
def query_documents(cname, filter=None):
    return db.find_many_sync(cname, filter)  # 阻塞事件循环
```

### 类型注解
```python
# 正确：完整类型注解
async def create_document(cname: str, data: dict[str, Any]) -> dict[str, Any]: ...

# 错误：缺少注解
async def create_document(cname, data): ...
```

### 错误处理
```python
# 正确：ErrorCode + BusinessException
from src.shared.error_codes import ErrorCode
from src.shared.exceptions import BusinessException

if not document:
    raise BusinessException(ErrorCode.NOT_FOUND, "文档不存在")

# 错误：返回裸错误
if not document:
    return {"error": "文档不存在"}
```

### 响应封装
```python
# 正确：StandardResponse
return StandardResponse.success(items)
return StandardResponse.fail(ErrorCode.NOT_FOUND, "项目不存在")

# 错误：原始字典
return {"data": items}
```

## 四、并发模式

```python
# 正确：asyncio.gather 并发
projects, issues, bugs = await asyncio.gather(
    repo.query("projects", {"owner": user_id}),
    repo.query("issues", {"assignee": user_id}),
    repo.query("bugs", {"reporter": user_id}),
)

# 错误：串行等待
projects = await repo.query("projects", ...)
issues = await repo.query("issues", ...)
bugs = await repo.query("bugs", ...)
```

## 五、日志规范

| 级别 | 场景 |
|------|------|
| DEBUG | 函数参数、中间变量 |
| INFO | 服务启动、API 调用、索引构建 |
| WARNING | 配置缺失、重试操作 |
| ERROR | API 失败、文件读取异常 |

```python
logger = logging.getLogger(__name__)
logger.info("Creating document collection=%s", cname)
# 正确：用 %s 而非 f-string（延迟求值）
# 错误：print("creating...")
```

## 六、测试规范

```python
# 命名：test_<功能>_<场景>_<预期>
def test_query_documents_with_filter_returns_filtered_results(): ...
def test_query_documents_empty_collection_returns_empty_list(): ...
```

覆盖率目标：`shared/` >= 90%、`data/` >= 80%、`domain/` >= 70%、`services/` >= 70%

## 七、代码审查清单

- [ ] 分层导入正确（domain 不导入 server）
- [ ] 异步一致（所有 I/O 用 async/await）
