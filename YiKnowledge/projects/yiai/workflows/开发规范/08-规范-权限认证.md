# 权限认证

> JWT + bcrypt 认证、中间件链、CORS 配置、Observer 安全、Agent 安全控制、Token 管理、RBAC 权限模型、安全最佳实践、反模式。

## 一、认证架构

### 认证模式

YiAi 支持两种认证模式，通过 `middleware.auth_enabled` 配置切换：

| 模式 | 配置 | 说明 | 适用场景 |
|------|------|------|----------|
| 开发模式 | `auth_enabled: false` | 所有端点公开，无需认证 | 本地开发、内部网络 |
| 生产模式 | `auth_enabled: true` | JWT Token 认证 + 静态 Token 回退 | 生产环境 |

### 认证层次

```
请求到达
  │
  ├── 1. 公开端点（/about, /health, /auth/*）
  │     → 跳过认证，直接处理
  │
  ├── 2. 可选认证端点（/, /agent/*, /files/*, /knowledge/*, /rag/*）
  │     → 有 Token 则注入用户，无 Token 也可访问
  │
  └── 3. 强制认证端点（/users/*, /system/*, /execution/*, /wework/*）
        → 无 Token 返回 401
```

### 认证组件

| 组件 | 技术 | 说明 |
|------|------|------|
| 密码哈希 | bcrypt | 不可逆哈希，自动加盐 |
| Token 签发 | PyJWT | HS256 签名，含 user_id、role、exp |
| Token 验证 | PyJWT | 验证签名 + 过期时间 |
| 中间件 | FastAPI Middleware | 拦截请求，提取 X-Token，注入 request.state.user |
| 静态 Token | 字符串比较 | 开发/测试用，通过 `auth_token` 配置 |

## 二、认证流程

### 登录流程

```
POST /auth/login { username, password }
  │
  ├── 1. 查询用户：db.find_one("users", {"username": username})
  │     └── 用户不存在 → 返回 401
  │
  ├── 2. 验证密码：bcrypt.checkpw(password, user["password_hash"])
  │     └── 密码错误 → 返回 401
  │
  ├── 3. 签发 Token：jwt.encode({user_id, username, role, exp})
  │     └── exp = now + expire_minutes * 60
  │
  └── 4. 返回：{ code: 0, data: { token, user: { id, username, role } } }
```

### 登录实现

```python
# src/domain/auth/auth_service.py
import bcrypt
import jwt
from datetime import datetime, timedelta

async def login(username: str, password: str) -> dict:
    """用户登录"""
    # 1. 查询用户
    user = await db.find_one("users", {"username": username})
    if not user:
        raise ValueError("用户名或密码错误")

    # 2. 验证密码
    if not bcrypt.checkpw(password.encode(), user["password_hash"].encode()):
        raise ValueError("用户名或密码错误")

    # 3. 签发 Token
    expire_minutes = config.jwt.expire_minutes  # 1440 (24h)
    payload = {
        "user_id": str(user["_id"]),
        "username": user["username"],
        "role": user.get("role", "user"),
        "exp": datetime.utcnow() + timedelta(minutes=expire_minutes),
        "iat": datetime.utcnow(),
    }
    token = jwt.encode(payload, config.jwt.secret, algorithm="HS256")

    return {
        "token": token,
        "user": {
            "id": str(user["_id"]),
            "username": user["username"],
            "role": user.get("role", "user"),
        }
    }

async def register(username: str, password: str, role: str = "user") -> dict:
    """用户注册"""
    # 检查用户名是否已存在
    existing = await db.find_one("users", {"username": username})
    if existing:
        raise ValueError("用户名已存在")

    # 密码哈希
    password_hash = bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()

    # 创建用户
    result = await db.insert_one("users", {
        "username": username,
        "password_hash": password_hash,
        "role": role,
        "created_at": datetime.utcnow(),
    })

    return {"user_id": str(result.inserted_id)}
```

### 请求认证

```
后续请求
  │
  ├── 1. 提取 Token：request.headers.get("X-Token")
  │     └── 无 Token + 端点需要认证 → 返回 401
  │
  ├── 2. 验证 Token：jwt.decode(token, secret, algorithms=["HS256"])
  │     └── Token 无效/过期 → 返回 401
  │
  ├── 3. 提取用户信息：payload → { user_id, username, role }
  │
  └── 4. 注入请求状态：request.state.user = { user_id, username, role }
```

### 认证中间件

```python
# src/middleware/auth.py
import jwt
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.responses import JSONResponse

# 不需要认证的端点
PUBLIC_PATHS = {"/about", "/health", "/auth/login", "/auth/register", "/auth/refresh"}

# 可选认证的端点前缀
OPTIONAL_AUTH_PREFIXES = {"/agent", "/files", "/knowledge", "/rag", "/search", "/mcp", "/v1"}

class AuthMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        # 公开端点跳过
        if request.url.path in PUBLIC_PATHS:
            return await call_next(request)

        token = request.headers.get("X-Token")

        # 可选认证端点
        is_optional = any(request.url.path.startswith(p) for p in OPTIONAL_AUTH_PREFIXES)
        if not token and request.url.path == "/":
            is_optional = True  # RPC 分发器

        if not token:
            if is_optional:
                request.state.user = None
                return await call_next(request)
            return JSONResponse({"code": 401, "message": "未提供认证 Token", "data": None})

        try:
            # JWT 验证
            payload = jwt.decode(token, config.jwt.secret, algorithms=["HS256"])
            request.state.user = {
                "user_id": payload["user_id"],
                "username": payload["username"],
                "role": payload.get("role", "user"),
            }
        except jwt.ExpiredSignatureError:
            return JSONResponse({"code": 401, "message": "登录已过期", "data": None})
        except jwt.InvalidTokenError:
            # 回退到静态 Token
            if token == config.middleware.auth_token:
                request.state.user = {"user_id": "static", "username": "dev", "role": "admin"}
            else:
                return JSONResponse({"code": 401, "message": "Token 无效", "data": None})

        return await call_next(request)
```

### Token 刷新

```
POST /auth/refresh { token }
  │
  ├── 1. 验证旧 Token（允许过期 Token，仅验证签名）
  │
  ├── 2. 签发新 Token（重置过期时间）
  │
  └── 3. 返回：{ code: 0, data: { token } }
```

```python
async def refresh_token(old_token: str) -> dict:
    """刷新 Token — 允许过期 Token 刷新"""
    try:
        # 验证签名（允许过期）
        payload = jwt.decode(old_token, config.jwt.secret, algorithms=["HS256"],
                            options={"verify_exp": False})
    except jwt.InvalidTokenError:
        raise ValueError("Token 无效")

    # 签发新 Token
    expire_minutes = config.jwt.expire_minutes
    new_payload = {
        "user_id": payload["user_id"],
        "username": payload["username"],
        "role": payload.get("role", "user"),
        "exp": datetime.utcnow() + timedelta(minutes=expire_minutes),
        "iat": datetime.utcnow(),
    }
    new_token = jwt.encode(new_payload, config.jwt.secret, algorithm="HS256")

    return {"token": new_token}
```

## 三、认证配置

```yaml
# config.yaml
middleware:
  auth_enabled: false              # 默认关闭，生产环境开启
  auth_token: "dev-token-change-me"  # 静态 Token（开发模式回退）

jwt:
  secret: "yi-ai-jwt-secret-change-in-production"
  expire_minutes: 1440              # 24 小时
  algorithm: "HS256"                # 签名算法
```

### 配置最佳实践

| 配置项 | 开发环境 | 生产环境 |
|--------|----------|----------|
| `auth_enabled` | `false` | `true` |
| `jwt.secret` | 任意值 | 强随机 64+ 字符 |
| `jwt.expire_minutes` | `1440` (24h) | `60` (1h) — 短 Token + 刷新 |
| `auth_token` | 简单值 | 不使用（仅 JWT） |
| Token 传输 | HTTP Header | HTTPS Header |
| Token 存储 | 内存/localStorage | httpOnly Cookie |

## 五、Observer 中间件

可选的请求监控和安全防护中间件：

```yaml
observer:
  enabled: false                    # 默认关闭
  throttle_enabled: false           # 限流
  sampler_enabled: true             # 慢请求采样
  sampler_slow_threshold_ms: 5000.0 # 慢请求阈值
  guard_enabled: true               # 深度防护
  guard_max_depth: 3                # 最大请求体嵌套深度
```

### Observer 组件

| 组件 | 功能 | 配置 | 默认值 |
|------|------|------|--------|
| throttle | 请求频率限制，防止滥用 | `throttle_enabled` | `false` |
| sampler | 慢请求采样（>5s），记录到日志 | `sampler_slow_threshold_ms` | `5000.0` |
| guard | 防止深度嵌套 JSON 攻击（max 3 层） | `guard_max_depth` | `3` |

### 深度嵌套防护

```python
# src/middleware/observer.py
def check_json_depth(obj, current_depth: int = 0, max_depth: int = 3):
    """递归检查 JSON 嵌套深度，防止 DoS 攻击"""
    if current_depth > max_depth:
        raise ValueError(f"JSON 嵌套深度超过限制: {max_depth}")

    if isinstance(obj, dict):
        for value in obj.values():
            check_json_depth(value, current_depth + 1, max_depth)
    elif isinstance(obj, list):
        for item in obj:
            check_json_depth(item, current_depth + 1, max_depth)
```

## 六、Agent 安全

Agent 模式有额外的安全控制层，因为 LLM 可以自主决定调用工具。

### 安全层级

| 层级 | 控制 | 说明 | 实现 |
|------|------|------|------|
| 传输层 | CORS | 限制允许的来源域名 | CORSMiddleware |
| 认证层 | JWT + bcrypt | Token 验证 + 密码哈希 | AuthMiddleware |
| 请求层 | Observer guard | 深度嵌套 JSON 攻击防护 | ObserverMiddleware |
| 操作层 | 确认门控 | 写操作需用户确认 | Agent 事件流 |
| 会话层 | 拒绝记忆 | 防止重复已拒绝操作 | LRU 缓存 |
| 工具层 | 白名单 + 参数校验 | 限制可调用的工具和参数 | ToolRegistry |

### 确认门控

```
写操作（create/update/delete）
  │
  ├── 1. Agent 发出 tool_call 事件
  │
  ├── 2. 检查工具是否标记 requires_confirmation=True
  │     └── 读操作（query/list）→ 直接执行
  │
  ├── 3. 发出 confirmation_required 事件
  │
  ├── 4. 等待用户确认（120s 超时）
  │     ├── approved → 执行工具
  │     ├── rejected → 跳过工具，记录拒绝
  │     └── timeout → 自动拒绝
  │
  └── 5. 发出 tool_execution_end 事件
```

### 拒绝记忆

```python
# src/domain/ai/agent/deny_memory.py
import hashlib
import json
from collections import OrderedDict

class DenyMemory:
    """拒绝记忆 — 同 session 内相同调用自动拦截"""

    def __init__(self, max_size: int = 20):
        self._memory: OrderedDict[str, str] = OrderedDict()
        self.max_size = max_size

    def _hash_call(self, tool_name: str, arguments: dict) -> str:
        """计算调用签名"""
        raw = json.dumps({"tool": tool_name, "args": arguments}, sort_keys=True)
        return hashlib.sha256(raw.encode()).hexdigest()[:16]

    def record_deny(self, tool_name: str, arguments: dict):
        """记录拒绝"""
        key = self._hash_call(tool_name, arguments)
        self._memory[key] = f"{tool_name}({json.dumps(arguments)})"
        if len(self._memory) > self.max_size:
            self._memory.popitem(last=False)  # LRU 淘汰

    def is_denied(self, tool_name: str, arguments: dict) -> bool:
        """检查是否已被拒绝"""
        return self._hash_call(tool_name, arguments) in self._memory

    def clear(self):
        self._memory.clear()
```

### 工具白名单

```python
# src/domain/ai/tools.py
from pydantic import BaseModel
from typing import Callable, Any

class ToolDef(BaseModel):
    name: str
    description: str
    parameters: dict  # JSON Schema
    handler: Callable
    requires_confirmation: bool = False

class ToolRegistry:
    """工具注册表 — 只有注册的工具可被 Agent 调用"""

    _tools: dict[str, ToolDef] = {}

    @classmethod
    def register(cls, tool: ToolDef):
        cls._tools[tool.name] = tool

    @classmethod
    def get(cls, name: str) -> ToolDef | None:
        return cls._tools.get(name)

    @classmethod
    def list_tools(cls) -> list[ToolDef]:
        return list(cls._tools.values())

    @classmethod
    def get_schemas(cls) -> list[dict]:
        """返回 OpenAI function calling 格式的工具列表"""
        return [
            {
                "type": "function",
                "function": {
                    "name": t.name,
                    "description": t.description,
                    "parameters": t.parameters,
                }
            }
            for t in cls._tools.values()
        ]

# 注册工具示例
ToolRegistry.register(ToolDef(
    name="db_list",
    description="列出 MongoDB 集合中的文档",
    parameters={
        "type": "object",
        "properties": {
            "cname": {"type": "string", "description": "集合名称"},
            "filter": {"type": "object", "description": "查询条件"},
        },
        "required": ["cname"]
    },
    handler=db_list_handler,
    requires_confirmation=False,  # 读操作不需要确认
))

ToolRegistry.register(ToolDef(
    name="db_create",
    description="在 MongoDB 集合中创建文档",
    parameters={
        "type": "object",
        "properties": {
            "cname": {"type": "string", "description": "集合名称"},
            "data": {"type": "object", "description": "文档数据"},
        },
        "required": ["cname", "data"]
    },
    handler=db_create_handler,
    requires_confirmation=True,  # 写操作需要确认
))
```

## 七、RBAC 权限模型

### 角色定义

| 角色 | 权限范围 | 说明 |
|------|----------|------|
| `admin` | 全部 | 系统管理、用户管理、所有数据 CRUD |
| `user` | 个人数据 | 个人会话、个人文件、知识库读取 |
| `viewer` | 只读 | 查询、读取，不可修改 |

### 权限检查

```python
# src/domain/auth/permissions.py
from functools import wraps

def require_role(*roles: str):
    """装饰器 — 检查用户角色"""
    def decorator(func):
        @wraps(func)
        async def wrapper(request: Request, *args, **kwargs):
            user = getattr(request.state, "user", None)
            if not user:
                raise PermissionError("未认证")
            if user.get("role") not in roles:
                raise PermissionError(f"需要角色: {roles}")
            return await func(request, *args, **kwargs)
        return wrapper
    return decorator

# 使用示例
@router.post("/users/create")
@require_role("admin")
async def create_user(request: Request):
    """只有 admin 可以创建用户"""
    ...
```

## 八、中间件注册顺序

中间件按以下顺序注册（顺序影响请求处理流程）：

```
1. CORS 中间件              — 最先处理，Origin 检查
2. Observer 中间件（可选）   — 限流/采样/深度防护
3. Auth 中间件（可选）       — X-Token 验证
4. 请求日志中间件            — 记录请求信息
5. 路由匹配                  — 20 个路由模块
6. 异常处理器                — 全局异常捕获
```

## 九、安全最佳实践

### 生产环境检查清单

- [ ] `auth_enabled: true`
- [ ] 修改 `jwt.secret` 为强随机字符串（64+ 字符）
- [ ] 修改 `middleware.auth_token`（如使用静态 Token，生产环境建议关闭）
- [ ] `cors.origins` 限制为具体域名
- [ ] `observer.enabled: true`（启用限流和深度防护）
- [ ] 使用 HTTPS（通过反向代理 Nginx/Caddy）
- [ ] 定期轮换 JWT secret（建议每 90 天）
- [ ] Token 过期时间设置为 1 小时（`expire_minutes: 60`）
- [ ] 启用 Token 刷新机制
- [ ] 密码最小长度 8 位，包含大小写和数字
- [ ] 登录失败限流（5 次/分钟）

### 安全编码规范

```python
# ✅ 正确：使用 bcrypt 哈希
password_hash = bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()

# ❌ 错误：使用 MD5/SHA1
password_hash = hashlib.md5(password.encode()).hexdigest()

# ✅ 正确：使用参数化查询
await db.find_one("users", {"username": username})

# ❌ 错误：字符串拼接（MongoDB 注入风险）
await db.db.command("eval", f"db.users.findOne({{username: '{username}'}})")

# ✅ 正确：不在日志中输出敏感信息
logger.info(f"User login: {username}")

# ❌ 错误：日志中包含 Token
logger.info(f"User login: {username}, token: {token}")
```

## 十、反模式

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 硬编码 JWT secret | `jwt.encode(payload, "my-secret")` | 从 config 读取 `config.jwt.secret` | 密钥泄露风险 |
| 日志输出 Token | `logger.info(f"Token: {token}")` | 不输出 Token 到日志 | Token 泄露 |
| URL 参数传递 Token | `GET /api?token=xxx` | 使用 `X-Token` 请求头 | URL 被浏览器历史/server 日志记录 |
| 弱密码哈希 | `hashlib.md5(pwd)` | `bcrypt.hashpw(pwd, bcrypt.gensalt())` | MD5 可被彩虹表破解 |
| 无确认门控 | 写操作直接执行 | 写操作标记 `requires_confirmation=True` | Agent 可能误操作 |
| 无路径遍历防护 | `open(user_path, "r")` | `os.path.realpath()` 验证 | 安全漏洞，可读取任意文件 |
| 无过期时间 | `jwt.encode(payload, secret)` 无 exp | 设置 `exp: now + timedelta(minutes=60)` | Token 永不过期 |
| 无深度嵌套防护 | 直接解析 JSON | `observer.guard_enabled: true` | JSON bomb DoS 攻击 |

## 十一、约束

### 必须遵守

- 密码使用 bcrypt 哈希，禁止 MD5/SHA1
- JWT Token 必须设置过期时间（`exp` 字段）
- 生产环境 JWT secret 使用 64+ 字符强随机字符串
- 文件操作使用 `os.path.realpath()` 进行路径遍历防护
- Token 通过 `X-Token` 请求头传递，不在 URL 中
- Agent 写操作必须标记 `requires_confirmation=True`
- 不将 Token 或密码输出到日志
- 中间件按正确顺序注册（CORS → Observer → Auth → 路由 → 异常处理）

### 禁止

- 不将 JWT secret 硬编码在代码中
- 不在日志中输出 Token 或密码
- 不在 URL 参数中传递 Token
- 不使用弱密码哈希算法（必须 bcrypt）
- 不跳过 Agent 确认门控（写操作必须确认）
- 不将用户输入直接拼接到 MongoDB 查询中
