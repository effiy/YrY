## 核心集合详细定义

### sessions（聊天会话）

```typescript
interface Session {
  key: string;                    // 唯一标识（UUID 或 URL 派生）
  title: string;                  // 会话标题
  messages: Message[];            // 消息数组
  pageContent?: string;           // 页面上下文（截断至 8000 字符）
  tags: string[];                 // 标签（source:YiPet, project:YiVad, from:url）
  createdTime: string;            // ISO 8601 UTC
  updatedTime: string;            // ISO 8601 UTC
}

interface Message {
  role: 'user' | 'assistant' | 'system';
  content: string;
  timestamp: string;              // ISO 8601 UTC
  streaming?: boolean;            // 流式传输中
  aborted?: boolean;              // 被中止
  error?: string;                 // 错误信息
}
```

### bugs（缺陷追踪）

```typescript
interface BugDocument {
  key: string;                    // 唯一标识（slug + base36 时间戳）
  title: string;                  // 缺陷标题
  project: string;                // 所属项目（YiVad, YiAi, YiPet, YiKnowledge）
  project_key: string;            // 项目键（yivad, yiai, yipet, yiknowledge）
  module: string;                 // 功能模块
  severity: 'critical' | 'major' | 'minor' | 'trivial';
  priority: 'p0' | 'p1' | 'p2' | 'p3';
  status: 'open' | 'in_progress' | 'resolved' | 'closed' | 'wontfix';
  type: 'functional' | 'ui' | 'data' | 'performance' | 'security' | 'compatibility';
  frequency: 'always' | 'sometimes' | 'rarely' | 'once';
  assignee: string;               // 负责人
  reporter: string;               // 报告人
  environment: string;            // 环境（development, staging, production）
  affectedVersion: string;        // 影响版本
  fixedVersion: string;           // 修复版本
  tags: string[];                 // 标签
  contentPath: string;            // YiKnowledge 内容路径
  createdAt: number;              // Unix 毫秒时间戳
  updatedAt: number;              // Unix 毫秒时间戳
  dueDate: number | null;         // 截止日期
  issue_key?: string;             // 关联问题键
  iteration?: string;             // 迭代
  defectUrl?: string;             // 缺陷链接
}
```

### menus（动态菜单）

```typescript
interface MenuItem {
  path: string;                   // 唯一标识（路由路径）
  name: string;                   // 路由名称（缓存/权限键）
  component: string;              // 组件路径（对应 src/views/ 下的文件）
  meta: {
    title: string;                // 菜单标题
    icon?: string;                // 图标
    keepAlive?: boolean;          // 是否缓存
    hidden?: boolean;             // 是否隐藏
    sort?: number;                // 排序
  };
  parent?: string;                // 父菜单路径
  children?: MenuItem[];          // 子菜单
}
```

## RPC 查询参数

### query_documents 参数

```typescript
interface QueryDocumentsParams {
  cname: string;                    // 集合名称（必填）
  filter?: Record<string, any>;     // Mongo 过滤条件（**必须用 `filter`，非 `query`**）
  pageNum?: number;                 // 页码（默认 1）
  pageSize?: number;                // 每页条数（默认 2000，最大 100000000）
  limit?: number;                   // 限制条数
  fields?: string[];                // 返回字段白名单
  excludeFields?: string[];         // 返回字段黑名单
  orderBy?: string;                 // 排序字段
  orderType?: 'asc' | 'desc';       // 排序方向
}
```

### 响应格式

```typescript
interface QueryDocumentsResponse<T> {
  list: T[];                        // 文档列表
  total: number;                    // 总条数
  pageNum: number;                  // 当前页码
  pageSize: number;                 // 每页条数
  totalPages: number;               // 总页数
}
```

## 文件操作数据模型

### 读文件
```typescript
// POST /read-file
{ target_file: string }  // **必须用 `target_file`，非 `path`**
// → { code: 0, data: { content: string, is_base64: boolean } }
```

### 写文件
```typescript
// POST /write-file
{ target_file: string, content: string, is_base64?: boolean }
// → { code: 0, data: { path: string } }
```

### 上传图片到 OSS
```typescript
// POST /upload-image-to-oss
{ data_url: string, filename: string, directory: string }
// → { code: 0, data: { url: string } }
```

| `bugs` | `{ key: 1 }` | 唯一 |
| `menus` | `{ path: 1 }` | 唯一 |
| `state_records` | `{ key: 1 }` | 唯一 |
| `knowledge_files` | `{ path: 1 }` | 唯一 |
| `static_files` | `{ path: 1 }` | 唯一 |

## 关键约束

- 所有 `key`/`path` 字段在各自集合中唯一
- `filter` 参数通过 `_build_filter` 合并到 Mongo 查询——支持 `$eq`、`$in`、`$regex`、`$gt`/`$lt`、`$exists` 等标准 Mongo 操作符
- 文件双写：磁盘（主存储）+ MongoDB `static_files`（备份，尽力而为 upsert）
- 种子数据仅在集合为空时自动填充（`replace_one` + `upsert`）
