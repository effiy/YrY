# 认证规范

> **读完你将能够**：实现 YiAi 的认证授权体系

> YiAi 支持两种模式：开发模式（auth_enabled: false，所有端点公开）和生产模式（auth_enabled: true，JWT + bcrypt）。

## 一、认证模式

```yaml
# config.yaml
middleware:
  auth_enabled: false    # 开发模式
jwt:
  secret: "change-in-production"
  expire_minutes: 1440   # 24h
```

### 开发模式
所有端点公开，无需认证。`observer.enabled: false`。

### 生产模式
- `header_verification_middleware` 检查每个请求的 `X-Token`
- `bcrypt` 密码哈希 + `PyJWT` Token 签发/验证
- 静态 Token 回退（`middleware.auth_token`）

## 二、登录流程

```python
# POST /auth/login { username, password }
async def login(username: str, password: str):
    user = await db.find_one("users", {"key": username})
    if not user:
        raise BusinessException(ErrorCode.UNAUTHORIZED, "用户不存在")
    if not bcrypt.checkpw(password.encode(), user["password"].encode()):
        raise BusinessException(ErrorCode.UNAUTHORIZED, "密码错误")
    payload = {"user_id": user["key"], "role": user.get("role", "user"),
               "exp": datetime.utcnow() + timedelta(minutes=settings.jwt_expire_minutes)}
    token = jwt.encode(payload, settings.jwt_secret, algorithm="HS256")
    return {"token": token, "user": {k: v for k, v in user.items() if k != "password"}}
```

## 三、中间件验证

```python
async def header_verification_middleware(request: Request, call_next):
    if not settings.middleware_auth_enabled:
        return await call_next(request)  # 开发模式跳过

    token = request.headers.get("X-Token")
    # 静态 Token 回退
    if settings.middleware_auth_token and token == settings.middleware_auth_token:
        request.state.user = {"key": "dev-user", "role": "admin"}
        return await call_next(request)

    if not token:
        return StandardResponse.fail(ErrorCode.UNAUTHORIZED, "Missing X-Token")
    try:
        payload = jwt.decode(token, settings.jwt_secret, algorithms=["HS256"])
        request.state.user = {"key": payload["user_id"], "role": payload.get("role", "user")}
    except jwt.ExpiredSignatureError:
        return StandardResponse.fail(ErrorCode.UNAUTHORIZED, "Token expired")
    return await call_next(request)
```

## 四、Agent 安全

- **确认门控**：写操作（create/update/delete）需用户确认，120s 超时自动拒绝
- **拒绝记忆**：同 session 内拒绝的调用自动拦截（最近 20 条）
- **工具白名单**：仅 `ToolRegistry` 注册的工具可被 Agent 调用
- **断连检测**：客户端断开时 `asyncio.CancelledError` → 保存状态 → 清理

## 五、配置速查

```yaml
jwt:
  secret: "yi-ai-jwt-secret-change-in-production"
  expire_minutes: 1440

middleware:
  auth_enabled: false
  auth_token: "dev-token-change-me"

cors:
  origins: ["*"]
  allow_any_origin: true

observer:
  enabled: false
  throttle_enabled: false
  sampler_enabled: true
  sampler_slow_threshold_ms: 5000.0
  guard_enabled: true
  guard_max_depth: 3
```

## 六、约束

- 生产环境必须 `auth_enabled: true`
- JWT secret 必须修改为安全随机字符串
- 不在代码中硬编码 secret
- 密码用 bcrypt 哈希，不存储明文
- Agent 写操作必须经过确认门控
