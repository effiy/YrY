# YiAi Workflows

## 新成员推荐阅读路径

1. [**速查卡**](操作指南/00-速查卡-YiAi开发速查.md) — 5 分钟了解常用命令和格式
2. [**快速开始**](操作指南/01-指南-快速开始.md) — 搭建开发环境
3. [**架构概览**](架构设计/01-架构-架构概览.md) — 理解整体技术栈和分层
4. [**模块结构规范**](架构设计/04-架构-模块结构规范.md) — 掌握各层职责和边界
5. [**编码规范**](开发规范/01-规范-编码规范.md) — 写出符合项目风格的代码

之后按角色深入：
- **API 开发** → [API 规范](开发规范/02-规范-API规范.md) → [RPC 协议](开发规范/05-规范-RPC协议规范.md) → [新增领域模块](操作指南/02-指南-添加领域模块.md)

- **数据处理** → [数据库规范](开发规范/04-规范-数据库规范.md) → [Repository 模式](设计模式/02-模式-Repository模式.md)
- **测试/质量** → [测试策略](操作指南/07-指南-测试策略.md) → [编码规范](开发规范/01-规范-编码规范.md)
