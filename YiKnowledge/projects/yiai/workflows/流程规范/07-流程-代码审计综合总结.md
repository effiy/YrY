## 缺陷分类

### 关键 (3)
- `RATE_LIMITED`/`RESOURCE_ALREADY_EXISTS` 共享业务码 1003 → 解耦
- `INTERNAL_ERROR`/`DATABASE_ERROR` 共享业务码 5001 → 解耦
- `notification.py` 导入不存在的 `verify_token` → `verify_jwt`

### 安全 (3)
- `/web-fetch` 端点无 SSRF 防护 → 9 段私有 IP 拦截
- Agent `web_fetch` 工具无 SSRF 防护 → 同上
- Sandbox allowlist `YiPett`→`YiPot`，移除幽灵 `YiWeb`

### 异常处理 (6)
- 6 处裸 `ValueError`/`Exception` → `BusinessException` + `ErrorCode`

### Python 兼容性 (1 类·15 处)
- 全部 `datetime.utcnow()` → `datetime.now(timezone.utc)`

### 性能/资源 (3)
- `OpenAIRuntime` 每次创建客户端 → 模块级共享
- `OllamaRuntime.complete()` 对所有异常重试 → 仅瞬态重试
- `CacheManager` TTLCache 忽略逐条目 TTL → 按条目 dict

### 代码质量 (12)
- 死代码移除、魔法数字消除、状态常量统一、代码去重、测试同步等
