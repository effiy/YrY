# 构建部署

> **读完你将能够**：正确部署 YiAi 到开发和生产环境

## 一、启动方式

```bash
# 开发（热重载）
python main.py
# 等效：uvicorn src.app:app --host 0.0.0.0 --port 10086 --reload

# 生产（多 worker）
uvicorn src.app:app --host 0.0.0.0 --port 10086 --workers 4 --no-reload

# Gunicorn + uvicorn workers
gunicorn src.app:app --workers 4 --worker-class uvicorn.workers.UvicornWorker --bind 0.0.0.0:10086
```

## 二、完整栈启动

```bash
# 终端 1: MongoDB
mongod --dbpath ./data

# 终端 2: Ollama
ollama serve

# 终端 3: YiAi
cd YiAi && python main.py

# 终端 4: YiVad（如需）
cd YiVad && pnpm dev
```

## 三、生产配置

```yaml
# config.yaml（生产）
server:
  reload: false
mongodb:
  uri: "mongodb://prod-server:27017"
middleware:
  auth_enabled: true
  cors_origins: ["https://yivad.example.com"]
jwt:
  secret: "${JWT_SECRET}"  # 环境变量
```

环境变量覆盖：`mongodb.uri` → `MONGODB_URI`，`jwt.secret` → `JWT_SECRET`。

## 四、健康检查

```bash
# 负载均衡器探活
curl http://localhost:10086/health
# → { "code": 0, "data": { "status": "healthy", "mongodb": "connected" } }

curl http://localhost:10086/about
# → { "code": 0, "data": { "version": "1.0.0" } }
```

## 五、CI/CD 流水线

```bash
# 构建步骤
pip install -r requirements.txt
ruff check src/
python -m pytest tests/ -v --cov=src --cov-report=term-missing

# 部署
uvicorn src.app:app --host 0.0.0.0 --port 10086 --workers 4
```

## 六、性能优化

- **连接池**：`mongodb.pool_size=10, max_pool_size=50`
- **Worker 数**：`CPU 核心数 × 2`
- **RAG 优化**：关闭 `use_rerank`（每个查询 +2-5s），`top_k=3`
- **SSE**：设置 `X-Accel-Buffering: no` 禁用 Nginx 缓冲

## 七、约束

- 生产环境 `reload: false`，`auth_enabled: true`
- 敏感信息通过环境变量，不进 config.yaml
- 部署前 `ruff check` + `pytest` 必须通过
