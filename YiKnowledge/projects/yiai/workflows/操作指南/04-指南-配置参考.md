# YiAi 配置参考

> 基于 2026-09-23 全量代码审计更新。标记 ★ 的为审计后新增/修正的配置项。

## 关键配置

```yaml
# ★ observer — 可选依赖，未安装时须设为 false
observer:
  enabled: false

# ★ middleware — 认证默认关闭
middleware:
  auth_enabled: false

# 数据库连接池
mongodb:
  pool_size: 10
  max_pool_size: 50
  query_timeout_ms: 30000

# RAG 配置
rag:
  auto_rebuild_enabled: true
  auto_rebuild_debounce_seconds: 30
  hybrid_retrieval_enabled: true
  rerank_enabled: true
  chunk_size: 1024
  top_k: 8
```

## 审计后变更

| 配置项 | 旧默认值 | 新默认值 | 原因 |
|--------|---------|---------|------|
| `observer.enabled` | `True` | `False` | observer 包未安装 |
| `datetime.utcnow()` | 15 处 | 0 处 | Python 3.12+ 废弃 |
| 错误码唯一性 | 3 对冲突 | 全部唯一 | 测试门禁 |

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `API_X_TOKEN` | 无 | 静态 X-Token 认证（优先级高于 config.yaml） |
| `YIAI_LOG_AUTH` | `0` | 设为 `1` 启用认证请求日志 |
| `PYTHONASYNCIODEBUG` | `0` | 运行时自动设置 |
