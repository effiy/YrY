# 快速开始

> **读完你将能够**：从零搭建 YiAi 开发环境并启动服务

## 一、环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | >= 3.10 | 运行时 |
| MongoDB | >= 6.0 | 数据库 |
| Ollama | >= 0.6.2 | LLM 推理（AI 功能需要） |

```bash
python --version && mongod --version && ollama --version
```

## 二、安装与启动

```bash
cd YiAi
pip install -r requirements.txt   # 建议先创建虚拟环境
python main.py                     # 启动开发服务器 :10086
curl http://localhost:10086/health # 验证
```

## 三、前置服务

```bash
# MongoDB
mongod --dbpath ./data
# 或 Docker: docker run -d -p 27017:27017 --name mongodb mongo:7

# Ollama（AI 功能需要）
ollama serve
ollama pull qwen2.5           # 聊天模型
ollama pull nomic-embed-text   # Embedding（RAG 需要）
```

## 四、完整栈启动

```bash
# 终端 1: mongod --dbpath ./data
# 终端 2: ollama serve
# 终端 3: cd YiAi && python main.py
# 终端 4: cd YiVad && pnpm dev
```

## 五、配置关键项

```yaml
# config.yaml 最小配置
server: { host: "0.0.0.0", port: 10086 }
mongodb: { uri: "mongodb://localhost:27017", db_name: "ruiyi" }
middleware: { auth_enabled: false }  # 开发模式
```

## 六、常用命令

| 命令 | 用途 |
|------|------|
| `python main.py` | 启动开发服务器 |
| `ruff check src/` | 代码检查 |
| `python -m pytest tests/ -v` | 运行测试 |
| `curl localhost:10086/health` | 健康检查 |
| `curl localhost:10086/docs` | API 文档 |

## 七、常见问题

**MongoDB 连接失败**：检查 `mongod` 是否运行，确认 `config.yaml` 中 `mongodb.uri`。

**Ollama 连接失败**：检查 `ollama serve` 是否运行，`ollama list` 确认模型已拉取。

**端口被占用**：`lsof -i :10086` 查找占用进程，修改 `config.yaml` 中的 `server.port`。

**热重载不生效**：确认 `config.yaml` 中 `server.reload: true`，检查语法错误。

## 八、附录：Python 依赖

### 核心依赖

| 包 | 用途 |
|----|------|
| fastapi, uvicorn | Web 框架 + ASGI 服务器 |
| pydantic, pydantic-settings | 数据验证 + 配置 |
| motor | MongoDB 异步驱动 |
| ollama, llama-index | LLM 推理 + RAG |
| bcrypt, PyJWT | 认证 |
| tenacity | 重试策略 |
| apscheduler | 定时任务 |

### 按场景安装

```bash
# 核心（不含 AI）
pip install fastapi uvicorn pydantic motor PyYAML bcrypt PyJWT python-multipart tenacity apscheduler

# AI/ML
pip install ollama llama-index openai anthropic rank-bm25

# 测试
pip install pytest pytest-asyncio httpx pytest-cov
```

### 依赖升级检查清单

1. 阅读 CHANGELOG → 2. `pip install --upgrade <pkg>` → 3. `ruff check` → 4. `pytest` → 5. `curl /health` → 6. 更新 requirements.txt
