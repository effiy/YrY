# 添加领域模块

> 按标准流程在 YiAi 中新增一个完整的业务领域模块。所有示例来自 `src/` 实际代码模式。

## 前置条件

- 阅读 [RPC 协议规范](../开发规范/05-规范-RPC协议规范.md) 了解跨项目契约
- 阅读 [领域服务模式](../设计模式/01-模式-领域服务模式.md) 了解分层架构

## 一、分层回顾

```
server/routes/<module>.py        ← HTTP 层：APIRouter + success()/fail()
services/<module>/<module>_service.py ← 服务层：模块级函数，参数校验 + 编排
domain/<module>/core.py          ← 领域层：核心业务逻辑（与框架无关）
data/repository.py               ← 数据层：模块级函数 query_documents(params)
```

**铁律**：下层不能导入上层。domain 不导入 server/services。service 不导入 server。

## 二、步骤总览

```
1. 数据模型（可选，如简单则跳过）
2. Domain 核心逻辑
3. Service 封装
4. Route 注册
5. app.py 注册
6. 测试
```

## 三、步骤详解

### Step 1：数据模型（可选，在 models/schemas.py）

```python
# models/schemas.py — 新增 Pydantic 模型
from pydantic import BaseModel, Field

class MyFeatureCreate(BaseModel):
    name: str = Field(..., min_length=2, max_length=50)
    status: str = "active"
```

### Step 2：Domain 核心逻辑

```python
# domain/my_feature/core.py — 模块级函数（非 class）
from data.repository import query_documents, create_document
from shared.exceptions import BusinessException
from shared.error_codes import ErrorCode

async def get_my_feature(key: str) -> dict:
    """获取单个资源"""
    result = await query_documents({
        "cname": "my_features",
        "filter": {"key": key},
        "pageSize": 1,
    })
    if not result["list"]:
        raise BusinessException(ErrorCode.DATA_NOT_FOUND, f"不存在: {key}")
    return result["list"][0]

async def list_my_features(filter: dict = None, pageNum=1, pageSize=20) -> dict:
    """分页列表"""
    return await query_documents({
        "cname": "my_features",
        "filter": filter or {},
        "pageNum": pageNum,
        "pageSize": pageSize,
    })
```

**要点**：
- 使用模块级函数，非 class
- `query_documents(params: dict)` — 所有参数在 dict 中
- 使用 `ErrorCode.DATA_NOT_FOUND`（不是不存在的 `RESOURCE_NOT_FOUND`）
- `BusinessException(ErrorCode.XXX, "detail")`

### Step 3：Service 封装

```python
# services/my_feature/my_feature_service.py — 模块级函数
from domain.my_feature.core import get_my_feature, list_my_features

async def get_feature(key: str) -> dict:
    """参数校验 + 调用 domain"""
    if not key or not isinstance(key, str):
        raise BusinessException(ErrorCode.INVALID_PARAMS, "key is required")
    return await get_my_feature(key)

async def list_features(params: dict) -> dict:
    return await list_my_features(
        filter=params.get("filter"),
        pageNum=params.get("pageNum", 1),
        pageSize=params.get("pageSize", 20),
    )
```

**要点**：
- 模块级函数，非 class
- 参数校验 + 调用 domain
- 不直接操作 MongoDB

### Step 4：Route 注册

```python
# server/routes/my_feature.py
from fastapi import APIRouter
from shared.response import success, fail
from shared.error_codes import ErrorCode
from services.my_feature.my_feature_service import get_feature, list_features

router = APIRouter()

@router.post("/my-feature-list")
async def my_feature_list(request: dict):
    try:
        result = await list_features(request)
        return success(data=result)
    except BusinessException as e:
        return fail(e.error_code, e.message)
```

**要点**：
- 使用 `success(data=...)` / `fail(error_code, message)`
- 路由只做参数提取 + 调用 service + 响应格式化
- `StandardResponse.success()` 是**不存在**的 API

### Step 5：app.py 注册

```python
# src/app.py
from server.routes import my_feature
app.include_router(my_feature.router, tags=["MyFeature"])
```

### Step 6：测试

```python
# tests/test_my_feature.py
import pytest

@pytest.mark.asyncio
async def test_get_feature_not_found():
    with pytest.raises(BusinessException) as exc:
        await get_my_feature("nonexistent")
    assert exc.value.error_code == ErrorCode.DATA_NOT_FOUND
```

## 四、检查清单

- [ ] Domain 使用模块级函数（非 class）
- [ ] Service 使用模块级函数（非 class）
- [ ] 错误使用 `BusinessException(ErrorCode.XXX, "detail")`
- [ ] 响应使用 `success(data=...)` / `fail(error_code, message)`
- [ ] `query_documents` 参数在 dict 中（`{"cname": ..., "filter": ...}`）
- [ ] Route 不直接调用 domain 或 data 层
- [ ] app.py 中 `include_router`
