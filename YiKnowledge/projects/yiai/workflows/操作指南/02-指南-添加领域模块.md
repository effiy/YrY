# 添加领域模块

> **读完你将能够**：按标准流程在 YiAi 中新增一个完整的业务领域模块

> 7 步标准流程：数据模型 → Domain → Service → Route → 注册 → 测试 → 验证。

## 前置条件

- 阅读 [RPC 协议规范](../开发规范/05-规范-RPC协议规范.md) 了解跨项目契约
- MongoDB 和 Ollama 运行中（如需要）

## 一、分层回顾

```
server/routes/<module>.py     ← HTTP/RPC 层：参数提取、调用 service
services/<module>_service.py  ← 服务层：校验、编排、StandardResponse
domain/<module>/core.py       ← 领域层：核心业务逻辑、BusinessException
data/repository.py            ← 数据访问层：MongoDB CRUD（通用，通常复用）
```

**铁律**：下层不能导入上层。

## 二、步骤总览

```
数据模型 → Domain 逻辑 → Service 封装 → Route 注册 → 测试 → 验证
```

## 三、步骤详解

### Step 1：数据模型

```python
# domain/my_feature/models.py
from pydantic import BaseModel, Field
from enum import Enum

class MyFeatureStatus(str, Enum):
    ACTIVE = "active"
    ARCHIVED = "archived"

class MyFeatureCreate(BaseModel):
    name: str = Field(..., min_length=2, max_length=50)
    status: MyFeatureStatus = MyFeatureStatus.ACTIVE
```

### Step 2：Domain 逻辑

```python
# domain/my_feature/core.py
class MyFeatureDomain:
    def __init__(self, repository=None):
        self._repo = repository or Repository("my_features")

    async def create(self, payload: MyFeatureCreate) -> dict:
        doc = payload.model_dump()
        return await self._repo.insert_one(doc)

    async def get(self, key: str) -> dict:
        doc = await self._repo.find_one({"key": key})
        if not doc:
            raise BusinessException(ErrorCode.RESOURCE_NOT_FOUND, f"不存在: {key}")
        return doc
```

### Step 3：Service 封装

```python
# services/my_feature/my_feature_service.py
class MyFeatureService:
    def __init__(self):
        self._domain = MyFeatureDomain()

    async def create(self, data: dict) -> dict:
        payload = MyFeatureCreate(**data)  # pydantic 自动校验
        return await self._domain.create(payload)

    async def list(self, filter: dict = None, pageNum=1, pageSize=20) -> dict:
        return await repository.query_documents("my_features", filter=filter,
                                                 pageNum=pageNum, pageSize=pageSize)
```

### Step 4：Route 注册

```python
# server/routes/my_feature.py
from fastapi import APIRouter, Request
router = APIRouter(prefix="/my-feature")

@router.post("/create")
async def create(request: Request, data: dict):
    result = await my_feature_service.create(data)
    return StandardResponse.success(result)
```

### Step 5：应用注册

```python
# src/app.py
from server.routes import my_feature
app.include_router(my_feature.router)
```

### Step 6：测试

```python
# tests/domain/test_my_feature.py
@pytest.mark.asyncio
async def test_create_success(mock_db):
    domain = MyFeatureDomain(repository=Repository(mock_db))
    payload = MyFeatureCreate(name="Test")
    result = await domain.create(payload)
    assert result["name"] == "Test"

@pytest.mark.asyncio
async def test_get_not_found():
    with pytest.raises(BusinessException):
        await domain.get("nonexistent")
```

### Step 7：验证

```bash
curl -X POST http://localhost:10086/ \
  -H "Content-Type: application/json" \
  -d '{"module_name":"services.my_feature.my_feature_service","method_name":"list","parameters":{"pageNum":1,"pageSize":10}}'
```

## 四、检查清单

- [ ] Domain 只导入 data/ + shared/
- [ ] Service 进行参数校验
- [ ] Route 只做参数提取 + 响应格式化
- [ ] BusinessException 处理异常
- [ ] StandardResponse 封装响应
- [ ] 异步函数使用 async/await
- [ ] 测试覆盖 happy path + 异常路径
- [ ] `ruff check` + `pytest` 通过
