# 添加领域模块

> 在 YiAi 后端中添加新业务领域模块的完整 7 步标准流程。覆盖领域模型设计、数据访问层、服务层封装、RPC 路由注册、pytest 测试、异常处理、日志规范的端到端指南。

## 前置条件

- 阅读 [YiAi/CLAUDE.md](../../CLAUDE.md) 了解模块边界和分层约束
- 阅读 [RPC 协议规范](../../specs/开发规范/09-规范-RPC协议规范.md) 了解跨项目契约
- MongoDB 和 Ollama 运行中（如需要）
- Python >= 3.10，已安装虚拟环境依赖

---

## 一、模块分层回顾

每个新领域模块必须严格遵守 YiAi 的四层架构：

```
server/routes/<module>.py    ← HTTP/RPC 层：接收请求、参数提取、调用 service
        │
services/<module>_service.py ← 服务层：业务编排、StandardResponse 封装
        │
domain/<module>/core.py      ← 领域层：核心业务逻辑、校验、异常抛出
        │
data/repository.py           ← 数据访问层：MongoDB CRUD（通用，通常不新建）
        │
shared/                      ← 共享层：config、response、error_codes（不新建）
```

| 层 | 职责 | 可以做 | 禁止做 |
|----|------|--------|--------|
| `server/routes/` | HTTP 请求处理 | 参数提取、调用 service、返回响应 | 直接访问 data/、业务逻辑 |
| `services/` | 业务编排 | 调用 domain、封装 StandardResponse | 导入 server/、核心业务逻辑 |
| `domain/` | 核心业务逻辑 | 调用 data/、抛出 BusinessException | 导入 server/、HTTP 相关 |
| `data/` | 数据访问 | MongoDB CRUD、索引管理 | 导入 domain/services/server |

**铁律**：下层不能导入上层。`data/` 只依赖 `shared/`，`domain/` 只依赖 `data/` + `shared/`。

```
1. 数据模型定义  →  2. Repository（如需）  →  3. Domain 核心逻辑

                        │

```

## 三、步骤详解

### 步骤 1：数据模型定义

定义 Pydantic 模型和 MongoDB 集合常量的位置取决于模块类型：

**场景 A：使用通用 Repository（大多数情况）**

如果新模块只需要对 MongoDB 集合做标准 CRUD，不需要新建 domain 目录——直接复用 `data_service` 的通用 RPC 方法。只需：
1. 在 `src/data/seeds/` 中添加种子数据（如需要）
2. 前端通过 `data_service.query_documents(cname="new_collection", ...)` 访问

**场景 B：有特定业务逻辑（需要新建 domain）**

```python
# src/domain/my_feature/__init__.py
from .core import MyFeatureDomain
from .models import MyFeatureDocument, MyFeatureCreatePayload, MyFeatureStatus

__all__ = [
    "MyFeatureDomain",
    "MyFeatureDocument",
    "MyFeatureCreatePayload",
    "MyFeatureStatus",
]
```

```python
# src/domain/my_feature/models.py
from pydantic import BaseModel, Field
from datetime import datetime
from enum import Enum
from typing import Optional

class MyFeatureStatus(str, Enum):
    """状态枚举 — 使用 str 基类确保 JSON 序列化"""
    ACTIVE = "active"
    INACTIVE = "inactive"
    ARCHIVED = "archived"

class MyFeatureDocument(BaseModel):
    """MongoDB 文档模型"""
    key: str = Field(default_factory=lambda: str(ObjectId()))  # 使用 key 而非 _id
    name: str = Field(..., min_length=2, max_length=50)
    description: str = Field(default="", max_length=500)
    status: MyFeatureStatus = MyFeatureStatus.ACTIVE
    tags: list[str] = Field(default_factory=list)
    metadata: dict = Field(default_factory=dict)
    created_at: datetime = Field(default_factory=datetime.utcnow)
    updated_at: datetime = Field(default_factory=datetime.utcnow)

class MyFeatureCreatePayload(BaseModel):
    """创建请求载荷"""
    name: str = Field(..., min_length=2, max_length=50)
    description: str = Field(default="", max_length=500)
    status: MyFeatureStatus = MyFeatureStatus.ACTIVE
    tags: list[str] = Field(default_factory=list)

class MyFeatureUpdatePayload(BaseModel):
    """更新请求载荷 — 所有字段可选"""
    name: Optional[str] = Field(None, min_length=2, max_length=50)
    description: Optional[str] = Field(None, max_length=500)
    status: Optional[MyFeatureStatus] = None
    tags: Optional[list[str]] = None
```

### 步骤 2：Repository（如需自定义数据访问）

大多数情况下直接使用 `src/data/repository.py` 的通用 Repository。仅在以下情况需要自定义 Repository：

- 需要复杂的聚合管道（aggregation pipeline）
- 需要事务支持（multi-document transactions）
- 需要特殊的索引管理

```python
# src/domain/my_feature/repository.py
from src.data.repository import BaseRepository
from typing import Optional

class MyFeatureRepository(BaseRepository):
    """自定义 Repository — 扩展通用 CRUD"""

    def __init__(self):
        super().__init__(collection_name="my_features")

    async def find_by_status(
        self,
        status: str,
        page: int = 1,
        page_size: int = 20,
    ) -> dict:
        """按状态查询 — 封装复杂查询逻辑"""
        return await self.query(
            filter_expr={"status": status},
            page_num=page,
            page_size=page_size,
            sort_field="created_at",
            sort_order=-1,
        )

    async def aggregate_status_counts(self) -> list[dict]:
        """聚合管道 — 按状态统计数量"""
        pipeline = [
            {"$group": {"_id": "$status", "count": {"$sum": 1}}},
            {"$sort": {"_id": 1}},
        ]
        return await self.aggregate(pipeline)

    async def bulk_update_status(
        self, keys: list[str], status: str
    ) -> int:
        """批量更新 — 事务性操作"""
        from pymongo import UpdateOne
        operations = [
            UpdateOne(
                {"key": key},
                {"$set": {"status": status, "updated_at": datetime.utcnow()}},
            )
            for key in keys
        ]
        result = await self.collection.bulk_write(operations)
        return result.modified_count
```

### 步骤 3：Domain 核心业务逻辑

```python
# src/domain/my_feature/core.py
import logging
from datetime import datetime
from typing import Optional

from src.shared.error_codes import ErrorCode
from src.shared.exceptions import BusinessException
from src.data.repository import BaseRepository
from .models import (
    MyFeatureDocument,
    MyFeatureCreatePayload,
    MyFeatureUpdatePayload,
    MyFeatureStatus,
)

logger = logging.getLogger(__name__)

class MyFeatureDomain:
    """功能管理领域对象"""

    def __init__(self, repository: Optional[BaseRepository] = None):
        self._repo = repository or BaseRepository(collection_name="my_features")

    async def create(self, payload: MyFeatureCreatePayload) -> dict:
        """创建功能记录"""
        # 1. 业务校验
        await self._check_name_unique(payload.name)

        # 2. 构建文档
        doc = MyFeatureDocument(
            name=payload.name,
            description=payload.description,
            status=payload.status,
            tags=payload.tags,
        )

        # 3. 持久化
        inserted = await self._repo.insert_one(doc.dict())
        logger.info("Feature created key=%s name=%s", inserted["key"], doc.name)
        return inserted

    async def update(self, key: str, payload: MyFeatureUpdatePayload) -> dict:
        """更新功能记录"""
        # 1. 存在性校验
        existing = await self._repo.find_one({"key": key})
        if not existing:
            raise BusinessException(
                ErrorCode.RESOURCE_NOT_FOUND,
                f"功能不存在: {key}",
            )

        # 2. 名称唯一性校验（如果变更了名称）
        update_data = payload.dict(exclude_none=True)
        if "name" in update_data and update_data["name"] != existing["name"]:
            await self._check_name_unique(update_data["name"], exclude_key=key)

        # 3. 更新时间戳
        update_data["updated_at"] = datetime.utcnow()

        # 4. 执行更新
        updated = await self._repo.find_one_and_update(
            {"key": key},
            {"$set": update_data},
        )
        logger.info("Feature updated key=%s fields=%s", key, list(update_data.keys()))
        return updated

    async def delete(self, keys: list[str]) -> int:
        """批量删除功能记录"""
        if not keys:
            raise BusinessException(ErrorCode.PARAM_VALIDATION_FAILED, "keys 不能为空")

        # 1. 确认所有 key 都存在
        existing = await self._repo.find_many({"key": {"$in": keys}})
        existing_keys = {d["key"] for d in existing}
        missing = set(keys) - existing_keys
        if missing:
            raise BusinessException(
                ErrorCode.RESOURCE_NOT_FOUND,
                f"功能不存在: {missing}",
            )

        # 2. 执行删除
        deleted_count = await self._repo.delete_many({"key": {"$in": keys}})
        logger.info("Features deleted count=%d keys=%s", deleted_count, keys)
        return deleted_count

    async def query(
        self,
        filter_expr: Optional[dict] = None,
        page: int = 1,
        page_size: int = 20,
        sort_field: str = "created_at",
        sort_order: int = -1,
    ) -> dict:
        """分页查询功能列表"""
        return await self._repo.query(
            filter_expr=filter_expr,
            page_num=page,
            page_size=page_size,
            sort_field=sort_field,
            sort_order=sort_order,
        )

    async def get_status_statistics(self) -> dict:
        """获取状态分布统计"""
        stats = await self._repo.aggregate([
            {"$group": {"_id": "$status", "count": {"$sum": 1}}},
        ])
        return {item["_id"]: item["count"] for item in stats}

    async def _check_name_unique(self, name: str, exclude_key: Optional[str] = None):
        """内部校验：名称唯一性"""
        filter_expr = {"name": name}
        if exclude_key:
            filter_expr["key"] = {"$ne": exclude_key}

        existing = await self._repo.find_one(filter_expr)
        if existing:
            raise BusinessException(
                ErrorCode.RESOURCE_ALREADY_EXISTS,
                f"名称已存在: {name}",
            )
```

**Domain 层核心原则：**
- 所有业务校验在此层完成（不为 routes/services 保留校验逻辑）
- 使用 `BusinessException` + `ErrorCode` 抛出结构化异常
- 使用 `logger`（非 `print`）记录关键操作
- 确保 `created_at`/`updated_at` 时间戳在创建/更新时设置

### 步骤 4：Service 服务层

```python
# src/services/my_feature/my_feature_service.py
import logging
from typing import Optional

from src.shared.response import StandardResponse
from src.shared.error_codes import ErrorCode
from src.shared.exceptions import BusinessException
from src.domain.my_feature import MyFeatureDomain, MyFeatureStatus
from src.domain.my_feature.models import MyFeatureCreatePayload, MyFeatureUpdatePayload

logger = logging.getLogger(__name__)

# 模块级单例 — 在 app.py 中初始化
_domain: Optional[MyFeatureDomain] = None

def init_service():
    """由 app.py 在启动时调用，注入 domain 实例"""
    global _domain
    _domain = MyFeatureDomain()
    logger.info("MyFeatureService initialized")


async def query_my_features(
    filter: Optional[dict] = None,
    page: int = 1,
    page_size: int = 20,
    sort: Optional[dict] = None,
) -> StandardResponse:
    """查询功能列表（RPC 方法）"""
    if _domain is None:
        raise RuntimeError("MyFeatureService not initialized")

    # 参数校验
    if page < 1:
        page = 1
    if page_size < 1 or page_size > 100:
        page_size = 20

    sort_field = sort.get("field", "created_at") if sort else "created_at"
    sort_order = sort.get("order", "desc") if sort else "desc"
    sort_order_int = -1 if sort_order == "desc" else 1

    result = await _domain.query(
        filter_expr=filter,
        page=page,
        page_size=page_size,
        sort_field=sort_field,
        sort_order=sort_order_int,
    )
    return StandardResponse.success(result)


async def create_my_feature(
    cname: str = "my_features",  # cname 保留以兼容通用 RPC 格式
    document: Optional[dict] = None,
    **kwargs,
) -> StandardResponse:
    """创建功能记录（RPC 方法）"""
    if _domain is None:
        raise RuntimeError("MyFeatureService not initialized")

    # 从通用 RPC 格式提取数据
    payload = document or kwargs
    create_payload = MyFeatureCreatePayload(**payload)

    created = await _domain.create(create_payload)
    return StandardResponse.success(created)


async def update_my_feature(
    cname: str = "my_features",
    key: Optional[str] = None,
    update: Optional[dict] = None,
    **kwargs,
) -> StandardResponse:
    """更新功能记录（RPC 方法）"""
    if _domain is None:
        raise RuntimeError("MyFeatureService not initialized")

    payload = update or kwargs
    target_key = key or payload.pop("key", None)
    if not target_key:
        raise BusinessException(ErrorCode.PARAM_VALIDATION_FAILED, "缺少 key 参数")

    update_payload = MyFeatureUpdatePayload(**payload)
    updated = await _domain.update(target_key, update_payload)
    return StandardResponse.success(updated)


async def delete_my_features(
    cname: str = "my_features",
    keys: Optional[list[str]] = None,
    **kwargs,
) -> StandardResponse:
    """批量删除功能记录（RPC 方法）"""
    if _domain is None:
        raise RuntimeError("MyFeatureService not initialized")

    target_keys = keys or kwargs.get("keys", [])
    deleted_count = await _domain.delete(target_keys)
    return StandardResponse.success({"deleted_count": deleted_count})
```

**Service 层核心原则：**
- 负责参数提取和格式转换（通用 RPC 格式 → Domain 期望格式）
- 使用 `StandardResponse.success()` / `StandardResponse.error()` 封装响应
- 不包含业务逻辑——只做编排和参数校验
- 一个 Service 文件可包含多个 RPC 方法（前端通过 `method_name` 区分）

### 步骤 5：路由注册

#### 5.1 RPC 路由（推荐 — 前端通过信封调用）

RPC 路由通过 `module_name` 自动发现 service 模块中的方法，无需手动注册路由：

```
前端调用：
POST /  body: {
  "module_name": "services.my_feature.my_feature_service",
  "method_name": "query_my_features",
  "parameters": {
    "cname": "my_features",
    "filter": {"status": "active"},
    "page": 1,
    "page_size": 20
  }
}
```

**RPC 方法命名约定：**
- 服务模块路径：`services.<domain>.<domain>_service`
- 方法名：snake_case，与服务文件中函数名一致
- 参数名遵守 RPC 契约：`filter`（非 `query`）、`cname`（非 `collection_name`）

#### 5.2 REST 端点（如需独立端点）

```python
# src/server/routes/my_feature_routes.py
from fastapi import APIRouter, Request, Query
from src.shared.response import StandardResponse
from src.services.my_feature.my_feature_service import (
    query_my_features,
    create_my_feature,
    update_my_feature,
    delete_my_features,
)

router = APIRouter(prefix="/my-feature", tags=["功能管理"])


@router.get("/list")
async def list_features(
    request: Request,
    status: str = Query(None, description="状态筛选"),
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=100),
):
    """GET /my-feature/list?status=active&page=1&page_size=20"""
    filter_expr = {"status": status} if status else None
    return await query_my_features(filter=filter_expr, page=page, page_size=page_size)


@router.post("/create")
async def create_feature(request: Request, payload: MyFeatureCreatePayload):
    """POST /my-feature/create"""
    return await create_my_feature(document=payload.dict())


@router.put("/{key}")
async def update_feature(request: Request, key: str, payload: MyFeatureUpdatePayload):
    """PUT /my-feature/{key}"""
    return await update_my_feature(key=key, update=payload.dict(exclude_none=True))


@router.delete("/batch")
async def batch_delete(request: Request, keys: list[str]):
    """DELETE /my-feature/batch"""
    return await delete_my_features(keys=keys)
```

#### 5.3 注册到应用

```python
# src/app.py
from src.server.routes.my_feature_routes import router as my_feature_router
from src.services.my_feature.my_feature_service import init_service as init_my_feature

def create_app() -> FastAPI:

    @app.on_event("startup")
    async def startup():
        # 初始化 service 单例
```

## 四、完整检查清单

### 架构分层
- [ ] Domain 层不导入 `server/`
- [ ] Service 层不导入 `server/`
- [ ] 所有层不交叉导入（下层不导入上层）
- [ ] 公共 API 在 `__init__.py` 中导出

### 代码质量
- [ ] 所有公共函数有完整类型注解
- [ ] 所有 I/O 操作使用 `async/await`
- [ ] 使用 `BusinessException` + `ErrorCode`（非 `raise Exception`）
- [ ] 响应使用 `StandardResponse` 封装（非原始 dict）
- [ ] 日志使用 `logger.info/error`（非 `print`）
- [ ] Pydantic 模型用于数据校验（非手动校验字典键）

### RPC 契约
- [ ] 参数名使用 `filter`（非 `query`）
- [ ] 参数名使用 `cname`（非 `collection_name`）
- [ ] Service 方法签名兼容 RPC 信封参数格式
- [ ] 分页参数有范围限制（page >= 1, 1 <= page_size <= 100）

### 数据库操作
- [ ] 通过 Repository 访问 MongoDB（非直接使用 Motor）
- [ ] ObjectId 在返回前序列化为字符串
- [ ] 查询使用字段投影（避免返回完整文档）
- [ ] Bulk write 用于批量操作

### 测试

## 五、常见反模式

| 反模式 | 正确做法 | 原因 |
|--------|----------|------|
| `raise Exception("错误")` | `raise BusinessException(ErrorCode.XXX, "描述")` | Exception 无法区分错误类型 |
| `return {"data": result}` | `return StandardResponse.success(result)` | 不符合 RPC 响应格式 |
| 在 route 中直接访问 `data/` | Route → Service → Domain → data/ | 违反分层隔离 |
| `print("用户创建了记录")` | `logger.info("Record created key=%s", key)` | print 无法分级/不持久化 |
| `page_size: int = 20`（不校验范围） | 校验 `1 <= page_size <= 100` | 可能返回大量数据导致 OOM |
| 在 Domain 中导入 `FastAPI` 相关 | Domain 不依赖 HTTP 框架 | 违反领域层纯粹性 |
| 不写 `__init__.py` 导出 | 通过 `__init__.py` 暴露公共 API | 调用方直接引用内部文件导致耦合 |
| 没有 mock Repository 的测试 | 使用 `AsyncMock` mock 数据访问层 | 测试速度慢，依赖 MongoDB |
