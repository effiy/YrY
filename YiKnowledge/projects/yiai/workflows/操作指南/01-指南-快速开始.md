# 快速开始

> 从零搭建 YiAi 开发环境：环境要求、安装启动、配置关键项、常见工作流、故障排查。

## 一、环境要求

| 依赖 | 最低版本 | 说明 |
|------|----------|------|
| Python | >= 3.10 | 运行时（全局优先 async/await） |
| MongoDB | >= 6.0 | 数据库，运行在 `localhost:27017` |
| Ollama | >= 0.6.2 | LLM 推理（可选，AI 功能需要） |
| Git | >= 2.30 | 版本控制 |

### 验证环境

```bash
python --version   # >= 3.10
mongod --version   # >= 6.0
ollama --version   # >= 0.6.2（可选）
```

---

## 二、安装与启动

```bash
# 1. 进入项目目录
cd YiAi

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动开发服务器（默认端口 10086，热重载）
python main.py

# 4. 验证服务
curl http://localhost:10086/about
```

### 首次安装注意事项

- 建议使用虚拟环境：`python -m venv venv && source venv/bin/activate`
- 如果安装 `llama-index` 失败，确保系统已安装 C++ 编译工具
- macOS 用户如遇到 `motor` 安装问题，确保已安装 `openssl`

## 三、前置服务

### MongoDB

# 启动 MongoDB
mongod --dbpath ./data

docker run -d -p 27017:27017 --name mongodb mongo:7

## 四、配置关键项

`config.yaml` 核心配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `server.host` | 服务监听地址 | `0.0.0.0` |
| `server.port` | 服务端口 | `10086` |
| `server.reload` | 热重载（开发模式） | `true` |
| `mongodb.uri` | MongoDB 连接地址 | `mongodb://localhost:27017` |
| `mongodb.db_name` | 数据库名 | `ruiyi` |
| `middleware.auth_enabled` | 认证开关 | `false`（开发） |
| `knowledge.base_dir` | 知识库路径 | `../YiKnowledge` |
| `knowledge.watcher_poll_seconds` | 知识库轮询间隔 | `60` |
| `rag.embed_model` | Embedding 模型 | `nomic-embed-text` |
| `rag.chunk_size` | RAG 分块大小 | `512` |

### 最小配置（开发环境）

```yaml
server:
  host: "0.0.0.0"
  port: 10086

mongodb:
  uri: "mongodb://localhost:27017"
  db_name: "ruiyi"

middleware:
  auth_enabled: false
```

## 八、常见开发工作流

### 8.1 新增 API 端点

```
1. 在 server/routes/<name>.py 中创建路由模块
2. 定义 pydantic 请求/响应模型
3. 在 src/app.py 中注册路由
4. 添加单元测试
→ 详细规范见 architecture/api.md
```

### 8.2 新增领域模块

```
1. 在 domain/<name>/ 下创建模块目录
2. 创建 __init__.py 定义公共 API
3. 在 services/<name>/ 下创建 service 封装
4. 在 server/routes/<name>.py 中创建路由
→ 详细规范见 architecture/overview.md
```

### 8.3 新增 MongoDB 集合

```
1. 在 models/ 中定义集合名称
2. 在 data/seeds/ 中添加种子数据
3. 通过 repository.query_documents 进行 CRUD
→ 详细规范见 architecture/database.md
```

## 九、常见问题

### MongoDB 连接失败

```bash
# 检查 MongoDB 是否运行
curl http://localhost:27017

# 检查 config.yaml 中的 mongodb.uri 配置
# 确保 MongoDB 服务已启动
```

### Ollama 连接失败

```bash
# 检查 Ollama 是否运行
curl http://localhost:11434/api/tags

# 确保已拉取所需模型
ollama list
```

### 端口被占用

```bash
# 查找占用 10086 端口的进程
lsof -i :10086

# 修改 config.yaml 中的 server.port
```

### 依赖安装失败

```bash
# 使用虚拟环境
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 升级 pip
pip install --upgrade pip
```

### RAG 索引为空

```bash
# 确保 YiKnowledge 目录存在且有内容
ls ../YiKnowledge/

# 手动触发索引构建
curl -X POST http://localhost:10086/rag/build-index
```

### 热重载不生效

- 确保 `config.yaml` 中 `server.reload: true`
- 检查是否有语法错误阻止重载
- 尝试重启服务

### 种子数据未导入

- 检查 `src/data/seeds/` 目录是否存在
- 查看启动日志中的种子数据导入信息
- 确保 MongoDB 连接正常

## 十、项目架构速览

### 分层架构

```
client (YiVad / YiPet)
  │ HTTP POST /  body: { module_name, method_name, parameters }
  ▼
src/server/routes/          # HTTP 层 — 20 个路由模块
  │ 依赖
  ▼
src/services/               # 服务层 — 业务编排
  │ 依赖
  ▼
src/domain/                 # 领域层 — 核心业务逻辑
  │ 依赖
  ▼
src/data/                   # 数据访问层 — MongoDB Motor
  │ 依赖
  ▼
src/shared/                 # 共享层 — 配置、响应、错误码
```

### 关键模块速查

| 模块 | 路径 | 职责 |
|------|------|------|
| 应用工厂 | `src/app.py` | FastAPI 创建、中间件注册、路由注册、生命周期 |
| 数据库 | `src/data/database.py` | MongoDB 单例（Motor 异步驱动） |
| 通用仓库 | `src/data/repository.py` | 通用 CRUD、查询构建、分页排序 |
| 认证 | `src/domain/auth/auth.py` | JWT 签发/验证、登录/注册 |
| AI 聊天 | `src/domain/ai/chat.py` | 多后端 LLM 调用（Ollama/OpenAI/Anthropic） |
| 知识库 | `src/domain/knowledge/watcher.py` | YiKnowledge 目录树扫描同步 |
| RAG 引擎 | `src/domain/rag/engine.py` | 混合检索（向量+BM25）、SSE 流式 RAG |
| 配置 | `src/shared/config.py` | YAML + pydantic-settings |

### SSE 事件流（AI 聊天）

```
client POST /  body: { module_name: "services.ai.chat_service", method_name: "chat", parameters: { model, messages, stream: true } }
  │
  ▼
services/ai/chat_service.py
  │
  ▼
StreamingResponse(media_type="text/event-stream")
  │
  ├── data: {"data": {"message": "你好"}}
  ├── data: {"data": {"message": "，今天"}}
  ├── data: {"data": {"message": "天气不错"}}
  └── data: {"done": true}
```

## 十二、环境变量覆盖

所有 `config.yaml` 中的配置可以通过环境变量覆盖：

```bash
# 使用环境变量覆盖配置
export MONGODB_URI="mongodb://prod-server:27017"
export MONGODB_DB_NAME="ruiyi_prod"
export JWT_SECRET_KEY="production-secret-key"
export MIDDLEWARE_AUTH_ENABLED="true"

# 启动服务
python main.py
```

### 环境变量命名规则

| config.yaml 路径 | 环境变量 | 说明 |
|-----------------|----------|------|
| `mongodb.uri` | `MONGODB_URI` | 双下划线替换点号 |
| `mongodb.db_name` | `MONGODB_DB_NAME` | 全大写 |
| `jwt.secret_key` | `JWT_SECRET_KEY` | snake_case → UPPER_SNAKE_CASE |
| `middleware.auth_enabled` | `MIDDLEWARE_AUTH_ENABLED` | 布尔值 "true"/"false" |

## 十三、生产部署

### 生产启动

```bash
# 使用 uvicorn 多 worker 启动
uvicorn src.app:app \
  --host 0.0.0.0 \
  --port 10086 \
  --workers 4 \
  --log-level info \
  --no-reload  # 生产环境禁用热重载

# 或使用 gunicorn + uvicorn workers
gunicorn src.app:app \
  --workers 4 \
  --worker-class uvicorn.workers.UvicornWorker \
  --bind 0.0.0.0:10086
```

### 生产配置

```yaml
# config.yaml 生产环境配置
server:
  host: "0.0.0.0"
  port: 10086
  reload: false                    # 生产环境禁用

mongodb:
  uri: "mongodb://prod-server:27017"
  db_name: "ruiyi"

middleware:
  auth_enabled: true               # 生产环境启用认证
  cors_origins:                     # 限制 CORS 来源
    - "https://yivad.example.com"

rag:
  embed_model: "nomic-embed-text"
  chunk_size: 512
  top_k: 5
  hybrid_search: true
  use_rerank: false                # 生产环境可开启

knowledge:
  watcher_enabled: true
  watcher_poll_seconds: 60
```

## 十四、约束

### 必须遵守
- 开发前确保 MongoDB 和 Ollama（如需 AI 功能）已启动
- 提交前运行 `ruff check src/` 和 `python -m pytest tests/ -v`
- 新增 API 端点时使用正确的参数名称（`filter` 非 `query`）
- 新增依赖时更新 `requirements.txt`

### 禁止
- 不在生产环境启用 `server.reload: true`
- 不在生产环境禁用认证（`auth_enabled: false`）
- 不将 `config.yaml` 中的敏感信息提交到版本控制（使用环境变量覆盖）
- 不跳过测试直接部署
