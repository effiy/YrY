# 跨项目开发工作流

> **读完你将能够**：掌握跨 YiVad/YiPet/YiAi 的端到端开发流程

> 跨三个项目的标准流程：契约先行 → 后端实现 → 前端 YiVad → 扩展 YiPet → 端到端验证。

## 一、前置条件

1. 阅读根目录和各项目的 CLAUDE.md
2. YiAi 后端运行中（`cd YiAi && python main.py`）
3. 了解 [RPC 协议规范](../开发规范/05-规范-RPC协议规范.md)

## 二、数据流

```
YiPet（浏览器）──RPC──→ YiAi（:10086）←──RPC── YiVad（:8848）
                              │
                         MongoDB（Motor）
```

**铁律**：前端不直接访问 MongoDB——所有数据操作通过 YiAi RPC 信封。

## 三、变更决策树

```
需求 → 只需前端？→ 现有 API 够用？→ 只改前端
                  → 需要新 API？→ 改 YiAi + 前端
     → 只需后端？→ 不影响 RPC 契约？→ 只改 YiAi
                  → 修改 RPC 签名？→ 同步所有消费端
     → 涉及 3 项目？→ YiAi 后端 → YiVad → YiPet
```

## 四、标准流程

### 阶段 1：契约设计（最重要）

在写代码前先定义 API 契约：

```markdown
## 契约草稿
### RPC 方法
| module_name | method_name | 参数 | 返回 |
| services.my_feature.service | query | filter, page, page_size | {list, total} |

### 参数名审计
- [ ] filter（非 query）
- [ ] cname（非 collection_name）
- [ ] target_file（非 path）
```

### 阶段 2：YiAi 后端
```
domain/<name>/ → services/<name>_service.py → server/routes/<name>.py → app.py 注册 → pytest
```

### 阶段 3：YiVad 前端
```
src/api/interface/ → src/api/modules/ → src/stores/ → src/views/ → src/languages/
验证: pnpm type:check && pnpm lint && pnpm dev
```

### 阶段 4：YiPet 扩展
```
src/api/types.ts → src/api/services/ → src/stores/ → src/popup/components/
验证: npm run typecheck && npm run build
```

### 阶段 5：端到端验证

```bash
# 后端
curl -X POST localhost:10086/ -H "Content-Type: application/json" \
  -d '{"module_name":"services.my_feature.service","method_name":"query","parameters":{}}'

# 前端参数名审查
grep -rn '"query"' YiVad/src/api/     # 应返回空（应为 filter）
grep -rn '"collection_name"' YiVad/src/api/  # 应返回空（应为 cname）
```

## 五、常见陷阱

### 陷阱 1：参数名不匹配（最高频 Bug）
使用 `query` 而非 `filter`——后端静默忽略，返回全部数据。**原因**：RPC 路由用 `**kwargs` 接收参数，不识别的参数名不报错。

### 陷阱 2：前后端分页参数不一致
前端 `pageNum`/`pageSize`（驼峰）vs 后端 `page`/`page_size`（snake_case）。统一使用后端标准。

### 陷阱 3：修改 RPC 签名未通知所有消费端
改了后端方法签名，只测了 YiVad，YiPet 默默坏了。修改前搜索所有消费端。

### 陷阱 4：忘记更新 YiKnowledge
做了跨项目变更但经验未沉淀。变更完成后将新模式/陷阱更新到 YiKnowledge。

## 六、提交前检查清单

### YiAi
- [ ] `pytest` 全部通过
- [ ] `ruff check` 零错误
- [ ] 参数名 `filter`/`cname`/`target_file`（非 query/collection_name/path）
- [ ] ObjectId 序列化为字符串

### YiVad
- [ ] `pnpm type:check` 零错误
- [ ] RPC 参数名审查（grep query/collection_name 无结果）
- [ ] DevTools Network 验证请求格式

### YiPet
- [ ] `npm run typecheck` 零错误
- [ ] RPC 通过 ApiClient 封装（非直接 fetch）
- [ ] 双世界通信使用正确 IPC 模式
