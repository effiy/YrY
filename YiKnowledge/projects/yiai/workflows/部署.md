# 部署规范

> 本文档定义 YiAi 项目的部署流程、服务配置、环境搭建和运维指南。

---

## 一、服务启动

### 1.1 开发环境启动

```bash
# 进入项目目录
cd YiAi

# 安装依赖
pip install -r requirements.txt

# 启动服务 (开发模式)
python main.py
```

### 1.2 生产环境启动

```bash
# 使用 uvicorn 直接启动
uvicorn src.app:app \
  --host 0.0.0.0 \
  --port 10086 \
  --workers 4 \
  --log-level info \
  --access-log
```

### 1.3 启动参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--host` | `0.0.0.0` | 监听地址 |
| `--port` | `10086` | 监听端口 |
| `--workers` | `1` | 工作进程数 (生产环境建议 4) |
| `--log-level` | `info` | 日志级别 (debug/info/warning/error) |
| `--access-log` | 关闭 | 启用访问日志 |
| `--reload` | 关闭 | 热重载 (仅开发环境) |

## 二、配置文件

### 2.1 config.yaml 完整结构

```yaml
# 服务配置
service:
  host: "0.0.0.0"
  port: 10086

# MongoDB 配置
mongodb:
  url: "mongodb://localhost:27017"
  db_name: "ruiyi"
  pool_size: 10
  max_pool_size: 50

# 认证配置
middleware:
  auth_enabled: false          # 生产环境必须设为 true
  auth_token: "dev-token-change-me"

# JWT 配置
jwt:
  secret: "yi-ai-jwt-secret-change-in-production"
  expire_minutes: 1440

# 知识库配置
knowledge:
  base_dir: "../YiKnowledge"
  watcher_enabled: true
  watcher_poll_seconds: 60

# RAG 配置
rag:
  embed_model: "bge-m3"
  llm_model: "qwen3"
  top_k: 5
  chunk_size: 1024
  hybrid_retrieval: true
  rerank_enabled: false
  citations_enabled: true

# Ollama 配置
ollama:
  base_url: "http://localhost:11434"
  default_model: "qwen3"
  model_fallback: ["qwen3-coder"]

# CORS 配置
cors:
  origins: ["*"]
  allow_any_origin: true

# 静态文件配置
static:
  base_dir: "./static"

# OSS 配置
oss:
  endpoint: ""
  access_key: ""
  secret_key: ""
  bucket: ""

# 观察者配置
observer:
  enabled: false
  throttle_enabled: false
  sampler_enabled: true
  sampler_slow_threshold_ms: 5000.0
  guard_enabled: true
  guard_max_depth: 3

# 企业微信配置
wework:
  enabled: false
  webhook_url: ""
```

### 2.2 环境变量覆盖

配置文件中的值可以通过环境变量覆盖，环境变量优先级更高：

| 配置项 | 环境变量 |
|--------|---------|
| `mongodb.url` | `MONGODB_URL` |
| `mongodb.db_name` | `MONGODB_DB_NAME` |
| `jwt.secret` | `JWT_SECRET` |
| `middleware.auth_enabled` | `AUTH_ENABLED` |
| `ollama.base_url` | `OLLAMA_BASE_URL` |

```bash
# 生产环境启动示例
export MONGODB_URL="mongodb://prod-mongo:27017"
export MONGODB_DB_NAME="ruiyi_prod"
export JWT_SECRET="production-secret-key"
export AUTH_ENABLED="true"

uvicorn src.app:app --host 0.0.0.0 --port 10086 --workers 4
```

## 三、环境搭建

### 3.1 系统要求

| 组件 | 版本要求 |
|------|---------|
| Python | 3.10+ |
| MongoDB | 5.0+ |
| Ollama | 最新版 |

### 3.2 依赖安装

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 安装依赖
pip install -r requirements.txt
```

### 3.3 MongoDB 准备

```bash
# 启动 MongoDB (如未运行)
mongod --dbpath /data/db

# 验证连接
mongosh --eval "db.runCommand({ ping: 1 })"
```

### 3.4 Ollama 准备

```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 拉取所需模型
ollama pull qwen3
ollama pull qwen3-coder
ollama pull bge-m3

# 验证模型
ollama list
```

### 3.5 首次启动

```bash
# 1. 确保 MongoDB 和 Ollama 运行中
# 2. 启动 YiAi
cd YiAi
python main.py

# 3. 验证服务
curl http://localhost:10086/health
# -> {"code":0,"message":"ok","data":{"status":"healthy"}}

# 4. 验证 RPC 分发器
curl -X POST http://localhost:10086/ \
  -H "Content-Type: application/json" \
  -d '{"module_name":"services.database.data_service","method_name":"query_documents","parameters":{"cname":"users","pageNum":1,"pageSize":10}}'
```

## 四、服务管理

### 4.1 systemd 服务 (Linux)

```ini
# /etc/systemd/system/yiai.service
[Unit]
Description=YiAi FastAPI Backend
After=network.target mongod.service

[Service]
Type=simple
User=yiai
WorkingDirectory=/opt/YrY/YiAi
Environment="PATH=/opt/YrY/YiAi/venv/bin"
Environment="MONGODB_URL=mongodb://localhost:27017"
Environment="JWT_SECRET=production-secret"
Environment="AUTH_ENABLED=true"
ExecStart=/opt/YrY/YiAi/venv/bin/uvicorn src.app:app \
  --host 0.0.0.0 \
  --port 10086 \
  --workers 4 \
  --log-level info
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启动服务
sudo systemctl daemon-reload
sudo systemctl enable yiai
sudo systemctl start yiai

# 查看状态
sudo systemctl status yiai

# 查看日志
sudo journalctl -u yiai -f
```

### 4.2 Docker 部署

```dockerfile
# Dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制源码
COPY src/ ./src/
COPY config.yaml .
COPY main.py .

# 创建数据目录
RUN mkdir -p /app/data/rag_store

EXPOSE 10086

CMD ["uvicorn", "src.app:app", "--host", "0.0.0.0", "--port", "10086", "--workers", "4"]
```

```yaml
# docker-compose.yml
version: '3.8'

services:
  yiai:
    build: .
    ports:
      - "10086:10086"
    environment:
      - MONGODB_URL=mongodb://mongo:27017
      - OLLAMA_BASE_URL=http://ollama:11434
      - JWT_SECRET=production-secret
      - AUTH_ENABLED=true
    volumes:
      - ./config.yaml:/app/config.yaml
      - ./data:/app/data
      - ../YiKnowledge:/YiKnowledge
    depends_on:
      - mongo
      - ollama
    restart: always

  mongo:
    image: mongo:6
    ports:
      - "27017:27017"
    volumes:
      - mongo_data:/data/db
    restart: always

  ollama:
    image: ollama/ollama:latest
    ports:
      - "11434:11434"
    volumes:
      - ollama_data:/root/.ollama
    restart: always

volumes:
  mongo_data:
  ollama_data:
```

## 五、健康检查

### 5.1 健康检查端点

```bash
# 基础健康检查
GET /health
# -> {"code":0,"message":"ok","data":{"status":"healthy"}}

# 服务信息
GET /about
# -> {"code":0,"message":"ok","data":{"version":"1.0.0","python":"3.10",...}}
```

### 5.2 健康检查脚本

```bash
#!/bin/bash
# health_check.sh

HEALTH_URL="http://localhost:10086/health"
TIMEOUT=5

response=$(curl -s --max-time $TIMEOUT "$HEALTH_URL")
code=$(echo "$response" | python -c "import sys,json; print(json.load(sys.stdin)['code'])")

if [ "$code" = "0" ]; then
    echo "OK: YiAi is healthy"
    exit 0
else
    echo "ERROR: YiAi health check failed: $response"
    exit 1
fi
```

## 六、监控与日志

### 6.1 日志配置

```python
# shared/logging.py
import logging

def setup_logging():
    logging.basicConfig(
        level=logging.INFO,
        format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
```

### 6.2 慢请求采样

通过 observer 中间件监控慢请求：

```yaml
observer:
  enabled: true
  sampler_enabled: true
  sampler_slow_threshold_ms: 5000.0  # 5s 以上记录
```

### 6.3 关键指标

| 指标 | 说明 | 监控方式 |
|------|------|---------|
| 服务可用性 | `/health` 端点可用 | 定期 curl + 告警 |
| MongoDB 连接 | 数据库连接状态 | 连接池状态日志 |
| Ollama 可用性 | LLM 推理可用 | 模型列表端点 |
| 慢请求 | >5s 的请求 | observer sampler |
| 错误率 | 5xx 错误比例 | 访问日志分析 |

## 七、安全配置

### 7.1 生产环境必须修改

| 配置项 | 默认值 | 生产要求 |
|--------|--------|---------|
| `jwt.secret` | `yi-ai-jwt-secret-change-in-production` | 随机 64+ 字符 |
| `middleware.auth_enabled` | `false` | `true` |
| `middleware.auth_token` | `dev-token-change-me` | 删除或设为空 |

### 7.2 网络安全

- 生产环境不应直接暴露 10086 端口
- 使用 Nginx 反向代理，配置 HTTPS
- 配置防火墙规则，限制访问来源

```nginx
# nginx.conf
server {
    listen 443 ssl;
    server_name api.example.com;

    ssl_certificate /etc/ssl/certs/example.com.crt;
    ssl_certificate_key /etc/ssl/private/example.com.key;

    location / {
        proxy_pass http://127.0.0.1:10086;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 支持
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
    }
}
```

## 九、故障排查

### 9.1 常见问题

| 问题 | 排查步骤 |
|------|---------|
| 服务无法启动 | 检查端口占用: `lsof -i :10086` |
| MongoDB 连接失败 | 检查 MongoDB 状态: `mongosh --eval "db.runCommand({ping:1})"` |
| Ollama 不可用 | 检查 Ollama 状态: `curl http://localhost:11434/api/tags` |
| RAG 索引异常 | 检查索引目录: `ls data/rag_store/` |
| 知识库扫描失败 | 检查 YiKnowledge 路径: `ls ../YiKnowledge/` |

### 9.2 日志排查

```bash
# 查看实时日志
tail -f logs/yiai.log

# 搜索错误
grep ERROR logs/yiai.log

# 查看最近 100 行
tail -100 logs/yiai.log
```
