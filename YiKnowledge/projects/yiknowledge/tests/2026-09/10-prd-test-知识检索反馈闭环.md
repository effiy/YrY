# YK-09-07: 知识检索反馈闭环 — 测试用例

> **文档职责**：本文档定义**怎么验证**（VERIFY）。覆盖 👍👎 反馈、聚合去重、权重调整、策展人通知。

## 一、测试范围

| 组件 | 测试重点 |
|------|---------|
| 反馈记录 | 👍+1 / 👎-1、同一用户去重、匿名模式 |
| 每日聚合 | 至少 3 人投票、净评分、权重 ±0.05 |
| 权重限制 | 累积上限 ±0.3、不低于 0.1 |
| 策展人通知 | net_score < -5 触发、企微消息 |

---

## 二、单元测试

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-FB-01 | 记录 👍 | rating=+1 | search_feedback 新增一条记录 |
| UT-FB-02 | 记录 👎 | rating=-1 | 记录正确 |
| UT-FB-03 | 同一用户重复投票（去重） | user A 对同一 (query,doc) 先后投 👍和👎 | 仅保留最新一条（👎） |
| UT-FB-04 | 匿名模式 | 未登录用户投票 | user="anonymous", IP+UA hash 去重 |
| UT-FB-05 | 每日聚合：不足 3 人 | 2 人投票，1👍1👎 | 不触发权重调整 |
| UT-FB-06 | 每日聚合：≥3 人净正 | 3👍0👎 → net_score=+3 | weight +0.05 |
| UT-FB-07 | 每日聚合：≥3 人净负 | 1👍4👎 → net_score=-3 | weight -0.05 |
| UT-FB-08 | 累积上限 +0.3 | weight 已从 1.0 → 1.3 | 不再增加 |
| UT-FB-09 | 累积下限 -0.3（但≥0.1） | weight 已降至 0.1 | 不再降低 |
| UT-FB-10 | 策展人审查阈值 | net_score=-6（累积） | 企微通知策展人 |

## 三、集成测试

| 编号 | 场景 | 预期 |
|------|------|------|
| IT-FB-01 | 反馈闭环全链路 | 用户检索 → 👍/👎 → 每日聚合 → weight 更新 → 下次检索排序变化 |
| IT-FB-02 | 匿名 + 登录用户混合 | 匿名和登录用户对同一文档投票 | 各自独立去重 |
| IT-FB-03 | TTL 90 天清理 | 插入 91 天前的反馈 | MongoDB TTL 索引清理 |
| IT-FB-04 | 前端 👍👎 组件 | 点击 👍 → API 调用 → 状态切换为已投票 |

## 四、缺陷分级
