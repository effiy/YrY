<a id="sec-4"></a>
## 四、单元测试 — 知识工程

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| UT-KC-01 | 知识卡生成 JSON schema | 架构设计文档 | 输出含 `title/summary/key_points/related_docs/difficulty/reading_time` |
| UT-KC-02 | 知识卡摘要 ≤ 200 字 | 长篇文档（5000 字） | `len(summary)` ≤ 200 |
| UT-KC-03 | 知识卡关键点 3-5 条 | 任意文档 | `3 ≤ len(key_points) ≤ 5` |
| UT-GR-01 | 规则提取：Frontmatter related | `related: [./other.md]` | 图中存在 `current → other` 的 `related` 边 |
| UT-GR-02 | 规则提取：标签共现 | 两文档共享 tag "RAG" | 图中存在 `tag_cooccurrence` 边 |
| UT-GR-03 | LLM 提取置信度标注 | 语义关系提取 | 边带 `confidence` 字段（0-1） |
| UT-LP-01 | 学习路径无环 | 10 篇文档的知识图谱 | DAG 拓扑排序成功（无环） |
| UT-LP-02 | 学习路径 prereq 排序 | 文档 A（基础）→ B（进阶） | B 排在 A 之后 |
| UT-RC-01 | 内容推荐（冷启动） | 无用户历史的推荐请求 | 基于 TF-IDF 相似度的内容推荐 |
| UT-RC-02 | 自动关联：阈值过滤 | 语义相似度 0.6 的文档对 | 相似度 > 0.5 时创建关联边 |
| UT-AB-01 | AB 分流一致性 | 相同 user_id 两次请求 | 返回相同 variant |
| UT-AB-02 | AB 分流比例 | 100 个不同 user_id，50:50 配置 | variant A 和 B 各约 50（±10%） |

<a id="sec-8"></a>
## 八、集成测试 — RPC 契约

| 编号 | RPC 方法 | 场景 | 预期 |
|------|---------|------|------|
| IT-KC-01 | `knowledge_card.generate` | 单文档知识卡 | 返回结构化 JSON（含 schema 校验） |
| IT-KC-02 | `knowledge_card.batch_generate` | 10 个文档 | 返回 10 个知识卡 |
| IT-GR-01 | `graph.build` | 全库图谱 | 返回 nodes + edges（node > 0, edge > 0） |
| IT-GR-02 | `graph.find_path` | 两文档间最短路径 | 返回路径边列表（Dijkstra） |
| IT-RC-01 | `recommend.similar` | 查询相似文档 | 返回 5 篇推荐（按相似度降序） |
| IT-RC-02 | `recommend.learning_path` | "RAG 入门" 学习路径 | 有序文档列表 + prereq |
| IT-I18N-01 | `i18n.extract` | 提取可本地化字符串 | 返回字符串列表（不含代码块） |
| IT-I18N-02 | `i18n.translate` | 中→英翻译 | 返回翻译结果 + TM 匹配数 |
| IT-LC-01 | `lifecycle.transition` | draft→in_review | 事件写入成功，重放状态正确 |
| IT-LC-02 | `lifecycle.get_history` | 查询事件历史 | 按时间戳排序的事件列表 |
| IT-BK-01 | `backup.create` → `backup.restore` | 创建快照 → 修改数据 → 恢复 | 数据恢复到快照时状态 |

## 九、端到端场景

### 场景 1：知识发现流程

| 步骤 | 操作 | 验证点 |
|------|------|--------|
| 1 | 打开知识库首页 | 仪表盘显示知识卡推荐 |
| 2 | 点击 "RAG 检索增强生成" 知识卡 | 知识卡展开：摘要/关键点/关联文档/难度等级 |
| 3 | 点击"查看关系图谱" | D3.js 力导向图展示，中心节点 = 当前文档 |
| 4 | 点击图谱中的关联节点 | 跳转到关联文档的知识卡 |
| 5 | 点击"学习路径" | 展示从入门→进阶→专家 3 级学习路径 |
| 6 | 切换语言为 English | 知识卡/图谱标签/学习路径全部切换 |

### 场景 2：备份与恢复

| 步骤 | 操作 | 验证点 |
|------|------|--------|
| 1 | 创建快照 "2026-09-15-daily" | 快照文件生成，含 Git tag |
| 2 | 修改 3 篇文档的 Frontmatter | 数据变更 |
| 3 | 恢复快照 | MongoDB 恢复到快照状态，3 篇文档 Frontmatter 回滚 |
| 4 | Git checkout 对应 tag | 文件系统恢复到快照时状态 |

## 十一、缺陷分级

| 级别 | 定义 | 示例 |
|------|------|------|
| S0 — 阻断 | 知识工程服务崩溃 | 图谱构建导致 OOM、备份恢复破坏原始数据 |
| S1 — 严重 | 核心功能错误 | 知识卡 LLM 输出格式 100% 不合法、学习路径存在回环 |
| S2 — 一般 | 单个模块异常 | 推荐冷启动仅返回 1 篇文档、翻译记忆库匹配率 0% |
| S3 — 轻微 | 边界情况 | 知识卡对无标题文档返回空摘要 |
| S4 — 建议 | 优化 | 图谱渲染动画掉帧、axe-core 规则集更新 |
