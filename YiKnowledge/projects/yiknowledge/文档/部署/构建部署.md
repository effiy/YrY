# 构建部署

## 部署方式

YiKnowledge 是纯 Markdown 知识库，无需构建。部署即文件同步。

## 与 YiAi 集成

YiAi 的知识库监听器 (`apscheduler`) 每 60 秒轮询 `YiKnowledge/` 目录树：

```
YiKnowledge (Markdown 文件树)
  ↓ apscheduler 每 60s 轮询
YiAi Knowledge Watcher (src/domain/knowledge/scanner.py)
  ↓ 解析 frontmatter + 正文
MongoDB knowledge_files 集合
  ↓ llama_index 索引构建
Vector Index (data/rag_store/)
```

## 配置

```yaml
# YiAi config.yaml
knowledge:
  base_dir: "../YiKnowledge"
  watcher_enabled: true
  watcher_poll_seconds: 60
```

## 健康检查

```bash
# 检查知识库文件数
find YiKnowledge -name "*.md" | wc -l

# 检查 MongoDB 同步状态
# 通过 YiAi API: POST / { module_name: "services.knowledge.knowledge_service", method_name: "get_stats" }

# 检查 RAG 索引状态
ls -la YiAi/data/rag_store/
```

## 维护操作

```bash
# 重建 RAG 索引
curl -X POST http://localhost:10086/rag/rebuild

# 强制重新扫描知识库
curl -X POST http://localhost:10086/knowledge/rescan

# 查找过期内容
rg "^last_verified: 2025" YiKnowledge -l

# 查找已废弃内容
rg "^status: deprecated" YiKnowledge -l
```
