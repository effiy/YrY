# 开发依赖

## 核心工具

| 工具 | 用途 |
|------|------|
| Markdown 编辑器 | 编辑知识文件 (VS Code / Obsidian) |
| Git | 版本控制和协作 |
| ripgrep (rg) | 全文搜索知识库 |
| yq / yaml | YAML frontmatter 校验 |

## 可选工具

| 工具 | 用途 |
|------|------|
| Obsidian | 可视化知识图谱 |
| Markdownlint | Markdown 格式检查 |
| Frontmatter CMS | 批量 frontmatter 管理 |

## 质量检查命令

```bash
# 检查缺失 title
rg -L "^title:" YiKnowledge --glob "*.md"

# 检查缺失 tags
rg -L "^tags:" YiKnowledge --glob "*.md"

# 检查文件名规范 (不应有下划线或数字)
find YiKnowledge -name "*_*" -o -name "*[0-9]*" | grep -v node_modules

# 统计各角色文件数
for d in YiKnowledge/{producter,leader,engineer,srer,executiver,aier,curator}; do
  echo "$d: $(find $d -name '*.md' | wc -l)"
done
```
