# 知识管理规范

## 文件命名

- **格式**: kebab-case (小写字母 + 连字符)
- **禁止**: 下划线 `_`、数字
- **语义**: 中文语义保留在 frontmatter `title:` 和 `aliases:` 中
- **目录层级**: 最多 3 层 — `role/problem-domain/file.md`

## YAML Frontmatter 规范

```yaml
---
标题: 文件标题                      # 必填
aliases: [别名1, 别名2]              # 推荐
标签: [标签1, 标签2, 标签3]           # 必填, 3-5 个
分类: 根目录
创建时间: YYYY-MM-DD                  # 必填
更新时间: YYYY-MM-DD                  # 必填
来源: internal | url               # 必填
类型: summary | original | template | prompt  # 必填
状态: draft | stable | deprecated  # 必填
生命周期: inbox | triage | active | reference | archive
评审周期: weekly | monthly | quarterly | yearly
最后验证: YYYY-MM-DD
角色: [role1, role2]
收益: "简短描述"
验收标准:
  - "可验证的条款"
相关:
  - relative/path/to/file.md
---
```

## 内容结构

1. Summary (摘要)
2. Core viewpoints (核心观点)
3. Key information (关键信息)
4. Action recommendations (行动建议)
5. Anti-patterns (反模式)
6. Related links (相关链接)

## 知识生命周期

```
inbox → triage → active → reference → archive
  ↓        ↓        ↓         ↓          ↓
 新入库   分类中   活跃使用   参考归档   已废弃
```
