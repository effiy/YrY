# YK-09-63: RAG 检索排序算法对比 — BM25/向量/Learn-to-Rank 评估

> 需求编号：YK-09-63 · 优先级：P2 · 人天：0.5d · 状态：需求已编写
> 依赖：YK-09-04（RAG 检索质量监控）、YK-09-69（学习排序融合）

---

## 一、背景

### 1.1 问题陈述

RAG 检索的排序算法直接影响检索质量。当前默认使用线性加权 `alpha * BM25 + (1-alpha) * Vector`，alpha 固定为 0.7。然而，这种单一的固定加权方案存在以下问题：

- **无法适应不同查询类型**：关键词查询（适合 BM25）和语义查询（适合向量）需要不同的 alpha
- **未考虑其他排序信号**：文档权威性、新鲜度、质量评分等未被纳入排序
- **缺乏系统化评估**：没有量化指标对比不同排序方案的效果
- **无法证明当前方案是最优的**：RRF、Multiplicative、LambdaMART 等方案可能更好

### 1.2 影响范围

| 影响维度 | 具体表现 | 严重程度 |
|----------|----------|----------|
| 检索精度 | 不合适的排序算法导致正确结果排在后面 | 高 |
| 用户满意度 | 用户需要翻页才能找到想要的内容 | 中 |
| 算法选择 | 缺乏数据支撑，无法做出有信心的算法选型 | 中 |
| 持续优化 | 缺乏基准数据集，无法评估优化效果 | 中 |

### 1.3 核心挑战

| 挑战 | 说明 |
|------|------|
| 评估数据集 | 需要人工标注的 Ground Truth（查询→相关文档） |
| 评估指标选择 | Recall/MRR/NDCG 各有侧重，需综合评估 |
| 参数敏感性 | 不同算法对参数（alpha, k）敏感度不同 |
| 统计显著性 | 样本量不足时，评估结果可能不可靠 |

## 二、现状分析

### 2.1 当前排序流程

```mermaid
flowchart TD
    A[查询] --> B[BM25 检索]
    A --> C[向量检索]
    B --> D[分数归一化]
    C --> D
    D --> E[alpha * BM25 + (1-alpha) * Vector]
    E --> F[排序返回 Top-K]
```

### 2.2 根因矩阵

| 根因 | 贡献比例 | 解决难度 | 优先级 |
|------|----------|----------|--------|
| 无评估数据集 | 35% | 高（需人工标注） | P0 |
| 无多方案对比框架 | 30% | 中 | P0 |
| 无参数调优 | 20% | 中 | P1 |
| 无统计显著性检验 | 15% | 低 | P2 |

### 2.3 候选排序方案

| 方案 | 公式 | 特点 |
|------|------|------|
| Linear Weighted | `alpha * BM25 + (1-alpha) * Vector` | 简单、可解释 |
| RRF (Reciprocal Rank Fusion) | `1/(k+rank_BM25) + 1/(k+rank_Vector)` | 无需分数归一化 |
| Multiplicative | `BM25 * Vector` | 强调共现 |
| Weighted RRF | `w1/(k+rank_BM25) + w2/(k+rank_Vector)` | 加权版 RRF |
| LambdaMART | 学习特征→排序分数 | 从反馈中学习 |

## 三、设计决策

### D-01: 评估指标选择

| 指标 | 含义 | 适用场景 | 计算方式 | 结论 |
|------|------|----------|----------|------|
| Recall@K | Top-K 中包含相关文档的比例 | 评估覆盖能力 | 相关文档在 Top-K 中的数量 / 总相关文档数 | **必须** |
| MRR | 第一个相关文档排名的倒数均值 | 评估首位精度 | `1/rank_of_first_relevant` | **必须** |
| NDCG@K | 归一化折损累计增益 | 评估排序质量 | 考虑位置权重的相关性分数 | **必须** |
| Precision@K | Top-K 中相关文档的比例 | 评估精确率 | 相关文档数 / K | 可选 |
| MAP | 平均精度均值 | 综合评估 | 各查询平均精度的均值 | 可选 |

**决策**：核心指标使用 Recall@5 + MRR + NDCG@5，理由：
- 三位一体：Recall 覆盖能力、MRR 首位精度、NDCG 排序质量
- 通用标准：信息检索领域公认的评估指标
- 可比较：与其他系统（如 BEIR benchmark）的评估结果可比

### D-02: 评估数据集构建

| 方案 | 描述 | 标注成本 | 代表性 | 结论 |
|------|------|----------|--------|------|
| A: 人工标注 50 条 | 策展人标注 50 个查询的相关文档 | 高（2-3 人天） | 中 | 起步方案 |
| B: 自动生成+人工校验 | 利用已有反馈数据生成候选标注 | 中（1 人天） | 中 | **推荐** |
| C: 众包标注 | 团队多人标注取交集 | 高（5+ 人天） | 高 | 长期方案 |

**决策**：选择方案 B（自动生成+人工校验），理由：
- 利用已有的用户反馈（点击、点赞）作为弱标注信号
- 策展人校验修正，降低成本
- 可逐步扩展标注数据集

### D-03: 参数搜索策略

| 方案 | 描述 | 精确度 | 计算成本 | 结论 |
|------|------|--------|----------|------|
| A: 网格搜索 | 遍历所有参数组合 | 高 | 高 | 小参数空间 |
| B: 随机搜索 | 随机采样参数组合 | 中 | 中 | **推荐** |
| C: 贝叶斯优化 | 基于先验的序贯优化 | 最高 | 低 | 未来优化 |

**决策**：选择方案 B（随机搜索），理由：
- 参数空间小（alpha 0.1-0.9, k 20-80），网格搜索也可行
- 随机搜索在参数敏感度低时更高效

```python
# YiAi/src/domain/rag/ranking_benchmark.py

import numpy as np
from dataclasses import dataclass
from statistics import mean

@dataclass
class EvalMetrics:
    """评估指标。"""
    recall_at_5: float
    recall_at_10: float
    mrr: float
    ndcg_at_5: float
    ndcg_at_10: float
    precision_at_5: float

class RankingBenchmark:
    """排序算法基准测试——多方案对比。"""

    # 候选排序方案
    METHODS = {
        'linear_weighted_a07': lambda results, alpha=0.7: sorted(
            results, key=lambda r: alpha*r['bm25_score'] + (1-alpha)*r['vector_score'],
            reverse=True
        ),
        'linear_weighted_a05': lambda results, alpha=0.5: sorted(
            results, key=lambda r: alpha*r['bm25_score'] + (1-alpha)*r['vector_score'],
            reverse=True
        ),
        'rrf_k60': lambda results, k=60: sorted(
            results, key=lambda r: 1/(k+r['bm25_rank']) + 1/(k+r['vector_rank']),
            reverse=True
        ),
        'rrf_k40': lambda results, k=40: sorted(
            results, key=lambda r: 1/(k+r['bm25_rank']) + 1/(k+r['vector_rank']),
            reverse=True
        ),
        'rrf_k80': lambda results, k=80: sorted(
            results, key=lambda r: 1/(k+r['bm25_rank']) + 1/(k+r['vector_rank']),
            reverse=True
        ),
        'multiplicative': lambda results: sorted(
            results, key=lambda r: r['bm25_score'] * r['vector_score'],
            reverse=True
        ),
        'weighted_rrf': lambda results, w1=0.5, w2=0.5, k=60: sorted(
            results,
            key=lambda r: w1/(k+r['bm25_rank']) + w2/(k+r['vector_rank']),
            reverse=True
        ),
    }

    def __init__(self):
        self._dataset: list[dict] = []
        self._ground_truth: dict[str, list[str]] = {}

    async def load_dataset(self, dataset_path: str = None):
        """加载评估数据集。

        数据集格式:
        [
            {
                'id': 'q001',
                'query': '如何优化 RAG 检索延迟',
                'relevant_docs': ['aier/rag-optimization.md', 'engineer/performance.md'],
            },
            ...
        ]
        """
        if dataset_path:
            import json
            with open(dataset_path) as f:
                dataset = json.load(f)
        else:
            # 从 MongoDB 加载
            dataset = await db.rag_eval_dataset.find({}).to_list(None)

        self._dataset = dataset
        self._ground_truth = {
            item['id']: item['relevant_docs']
            for item in dataset
        }

        logger.info(f"[RankingBenchmark] 加载数据集: {len(dataset)} 条查询")

    async def benchmark(self, top_k: int = 20) -> list[dict]:
        """评估所有排序方案——对比 Recall@5 / MRR / NDCG。"""
        if not self._dataset:
            raise ValueError("未加载评估数据集")

        results = []

        for method_name, method_fn in self.METHODS.items():
            metrics = {
                'recall_at_5': [],
                'recall_at_10': [],
                'mrr': [],
                'ndcg_at_5': [],
                'ndcg_at_10': [],
                'precision_at_5': [],
            }

            for query_item in self._dataset:
                # 获取原始检索结果
                raw_results = await self._retrieve_raw(query_item['query'], top_k)

                # 添加排名信息
                for i, r in enumerate(raw_results):
                    r['bm25_rank'] = i + 1
                    r['vector_rank'] = i + 1

                # 应用排序方案
                ranked = method_fn(raw_results)

                # 计算指标
                gt = self._ground_truth.get(query_item['id'], [])
                metrics['recall_at_5'].append(self._recall_at_k(ranked, gt, 5))
                metrics['recall_at_10'].append(self._recall_at_k(ranked, gt, 10))
                metrics['mrr'].append(self._mrr(ranked, gt))
                metrics['ndcg_at_5'].append(self._ndcg(ranked, gt, 5))
                metrics['ndcg_at_10'].append(self._ndcg(ranked, gt, 10))
                metrics['precision_at_5'].append(self._precision_at_k(ranked, gt, 5))

            # 汇总
            results.append({
                'method': method_name,
                'avg_recall_at_5': round(mean(metrics['recall_at_5']), 3),
                'avg_recall_at_10': round(mean(metrics['recall_at_10']), 3),
                'avg_mrr': round(mean(metrics['mrr']), 3),
                'avg_ndcg_at_5': round(mean(metrics['ndcg_at_5']), 3),
                'avg_ndcg_at_10': round(mean(metrics['ndcg_at_10']), 3),
                'avg_precision_at_5': round(mean(metrics['precision_at_5']), 3),
                'std_recall_at_5': round(np.std(metrics['recall_at_5']), 3),
                'std_mrr': round(np.std(metrics['mrr']), 3),
                'std_ndcg_at_5': round(np.std(metrics['ndcg_at_5']), 3),
            })

        # 按 NDCG@5 排序
        return sorted(results, key=lambda r: r['avg_ndcg_at_5'], reverse=True)

    async def _retrieve_raw(self, query: str, top_k: int) -> list[dict]:
        """获取原始检索结果（BM25 + 向量）。"""
        # 调用现有检索服务
        return await rag_service.retrieve_raw(query, top_k)

    def _recall_at_k(self, ranked: list[dict], ground_truth: list[str], k: int) -> float:
        """Recall@K——Top-K 中包含的相关文档比例。"""
        if not ground_truth:
            return 0.0

        retrieved_paths = [r.get('path', '') for r in ranked[:k]]
        relevant_retrieved = sum(1 for p in retrieved_paths if p in ground_truth)
        return relevant_retrieved / len(ground_truth)

    def _mrr(self, ranked: list[dict], ground_truth: list[str]) -> float:
        """MRR——第一个相关文档排名的倒数。"""
        for i, r in enumerate(ranked):
            if r.get('path', '') in ground_truth:
                return 1.0 / (i + 1)
        return 0.0

    def _ndcg(self, ranked: list[dict], ground_truth: list[str], k: int) -> float:
        """NDCG@K——归一化折损累计增益。"""
        # 计算 DCG
        dcg = 0.0
        for i, r in enumerate(ranked[:k]):
            relevance = 1.0 if r.get('path', '') in ground_truth else 0.0
            dcg += relevance / np.log2(i + 2)  # i+2 因为 log2(1)=0

        # 计算 IDCG（理想排序）
        ideal_relevance = sorted(
            [1.0] * len(ground_truth) + [0.0] * (k - len(ground_truth)),
            reverse=True
        )[:k]
        idcg = sum(rel / np.log2(i + 2) for i, rel in enumerate(ideal_relevance))

        return dcg / idcg if idcg > 0 else 0.0

    def _precision_at_k(self, ranked: list[dict], ground_truth: list[str], k: int) -> float:
        """Precision@K——Top-K 中相关文档的比例。"""
        if not ranked:
            return 0.0

        retrieved_paths = [r.get('path', '') for r in ranked[:k]]
        relevant = sum(1 for p in retrieved_paths if p in ground_truth)
        return relevant / k

    async def parameter_grid_search(self, method_name: str,
                                     param_grid: dict) -> list[dict]:
        """参数网格搜索——寻找最优参数组合。"""
        # 实现略——遍历参数组合，评估每个组合
        pass

    async def statistical_significance_test(self, method_a: str,
                                              method_b: str,
                                              metric: str = 'ndcg_at_5') -> dict:
        """配对 t 检验——判断两个方案的差异是否统计显著。"""
        from scipy import stats

        scores_a = []
        scores_b = []

        for query_item in self._dataset:
            raw_results = await self._retrieve_raw(query_item['query'], 20)
            gt = self._ground_truth.get(query_item['id'], [])

            ranked_a = self.METHODS[method_a](raw_results)
            ranked_b = self.METHODS[method_b](raw_results)

            if metric == 'ndcg_at_5':
                scores_a.append(self._ndcg(ranked_a, gt, 5))
                scores_b.append(self._ndcg(ranked_b, gt, 5))
            elif metric == 'mrr':
                scores_a.append(self._mrr(ranked_a, gt))
                scores_b.append(self._mrr(ranked_b, gt))

        t_stat, p_value = stats.ttest_rel(scores_a, scores_b)

        return {
            'method_a': method_a,
            'method_b': method_b,
            'metric': metric,
            'mean_a': round(mean(scores_a), 3),
            'mean_b': round(mean(scores_b), 3),
            't_statistic': round(t_stat, 3),
            'p_value': round(p_value, 4),
            'significant': p_value < 0.05,
        }
```
