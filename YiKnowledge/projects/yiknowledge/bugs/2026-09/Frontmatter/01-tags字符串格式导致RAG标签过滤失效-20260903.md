## Description

部分知识库文件的 frontmatter 中 `tags` 字段使用了 YAML 字符串格式 `tags: "example"` 而非数组格式 `tags: [example]`。YAML 解析器将字符串解析为单个字符串值，而非字符串数组。RAG 检索器的标签过滤器（`MetadataFilter.tags in [...]`）期望 `tags` 为 `List[str]` 类型，类型不匹配导致过滤条件被静默忽略——用户按标签过滤时，该文件始终被排除。

**影响范围：**
- RAG 检索结果缺失该文件（标签过滤场景）
- YiVad Knowledge 页面的标签筛选功能不准确
- YiAi `rag_service` 的 `tags` 参数过滤失效

**发现方式：** RAG 检索测试中，按标签 `example` 过滤时，该文件未出现在结果中。检查 frontmatter 发现 `tags` 为字符串而非数组。

## Steps to Reproduce

1. 创建知识文件，frontmatter 中 `tags: "example"`（字符串格式）
2. 等待 YiAi Knowledge Watcher 扫描（5s 轮询）
3. 在 YiVad Knowledge 页面按标签 `example` 筛选
4. 该文件不在筛选结果中

## Expected Result

`tags: "example"` 应被解析为 `["example"]`，标签过滤正常工作。

## Actual Result

YAML 解析器将 `tags: "example"` 解析为字符串 `"example"`，RAG 检索器的 `tag in tags` 检查失败（`"example" in "example"` → `True`，但 `MetadataFilter` 的类型检查 `isinstance(tags, list)` 返回 `False`），过滤条件被跳过。

## Root Cause

YAML 规范中 `tags: example` 和 `tags: [example]` 是不同的数据类型：
- `tags: example` → 字符串 `"example"`
- `tags: [example]` → 数组 `["example"]`
- `tags:`\n`  - example` → 数组 `["example"]`

部分作者不熟悉 YAML 数组语法，误用字符串格式。YiAi 的 frontmatter 解析器（`domain/knowledge/parser.py`）未做类型归一化处理。

**问题代码：**

```python
# domain/knowledge/parser.py:56 — 修复前
def parse_frontmatter(content: str) -> dict:
    _, fm, _ = content.split("---", 2)
    metadata = yaml.safe_load(fm)
    # tags 未归一化——可能是字符串或数组
    return metadata
```

## Fix

### 1. Frontmatter 解析时归一化 tags

```python
# domain/knowledge/parser.py
def parse_frontmatter(content: str) -> dict:
    _, fm, _ = content.split("---", 2)
    metadata = yaml.safe_load(fm)

    # 归一化 tags 为数组
    tags = metadata.get("tags", [])
    if isinstance(tags, str):
        metadata["tags"] = [t.strip() for t in tags.split(",") if t.strip()]
    elif not isinstance(tags, list):
        metadata["tags"] = []

    return metadata
```

### 2. 就绪检查清单增加 tags 格式校验

在 [就绪检查清单](../curator/governance/readiness-checklist.md) 中添加：

```markdown
- [ ] `tags` 字段为 YAML 数组格式（`tags: [tag1, tag2]` 或 `tags:\n  - tag1\n  - tag2`）
- [ ] `tags` 字段不为空数组
```

### 3. 修正受影响的文件

```bash
# 查找 tags 为字符串格式的文件
grep -r "^tags: [^\[\n]" YiKnowledge/ --include="*.md" -l
```

## Verification

- `tags: "example"` → 解析为 `["example"]`，RAG 标签过滤正常
- `tags: [example]` → 解析为 `["example"]`，行为不变
- `tags:\n  - example` → 解析为 `["example"]`，行为不变
- `tags: ""` → 解析为 `[]`，不触发过滤
- 空 frontmatter（无 tags 字段） → 默认 `[]`

## Prevention

- **工具层面：** 添加 pre-commit hook 校验 frontmatter 格式（使用 `yaml.safe_load` + 类型检查）
- **流程层面：** 提交知识文件前运行就绪检查清单
- **文档层面：** 在 [Frontmatter 规范](../specs/frontmatter.md) 中标注 `tags` 必须为数组格式，提供正反例
- **测试层面：** RAG 检索测试覆盖 `tags` 为字符串的边界情况
