## Description

知识库文件 `YiKnowledge/engineer/build/wip_features.md` 的文件名使用了**下划线**（`_`）而非 **kebab-case**（连字符 `-`）。YiKnowledge 规范要求所有文件名使用 kebab-case（仅连字符，不使用下划线或数字）。

YiAi 的 `knowledge/parser.py` 在解析文件路径时，使用 `-` 作为路径段的单词分隔符来生成 RAG 元数据（如 `path_tokens` 用于 BM25 分词）。下划线被当作单词的一部分，而非分隔符，导致该文件的路径分词结果异常——`wip_features` 被当作单个 token，而非 `["wip", "features"]`。

**影响：**
- RAG BM25 检索时，搜索 "features" 不会匹配到该文件
- 文件路径在 YiVad Knowledge 页面中显示异常（`wip_features` 而非 `wip-features`）
- 自动化命名规范检查工具标记该文件为违规

## Steps to Reproduce

1. 创建文件 `YiKnowledge/engineer/build/wip_features.md`
2. 等待 Knowledge Watcher 扫描
3. 在 YiVad Knowledge 页面搜索 "features"
4. 该文件不在搜索结果中
5. 将文件重命名为 `wip-features.md` 后重新扫描 → 搜索正常

## Expected Result

文件名应使用 kebab-case：`wip-features.md`。

## Actual Result

文件名使用下划线 `wip_features.md`，违反命名规范，影响 RAG 路径分词。

## Root Cause

作者在创建文件时使用了 Python 的 snake_case 命名习惯（Python 文件使用下划线），而非 YiKnowledge 的 kebab-case 规范。

**根本原因：** 缺少自动化命名规范检查工具。作者提交前无法自动检测文件名违规。

## Fix

### 1. 重命名文件

```bash
mv YiKnowledge/engineer/build/wip_features.md \
   YiKnowledge/engineer/build/wip-features.md
```

### 2. 添加 Git pre-commit hook

```bash
#!/bin/bash
# .git/hooks/pre-commit — 检查 YiKnowledge 文件命名规范

KNOWLEDGE_DIR="YiKnowledge"
INVALID_FILES=$(git diff --cached --name-only --diff-filter=A |
  grep "^${KNOWLEDGE_DIR}/" |
  grep -E '\.md$' |
  grep -E '[A-Z_]' || true)

if [ -n "$INVALID_FILES" ]; then
  echo "ERROR: YiKnowledge files must use kebab-case (no uppercase or underscores):"
  echo "$INVALID_FILES"
  echo ""
  echo "Rename examples:"
  echo "  wip_features.md → wip-features.md"
  echo "  MyFile.md → my-file.md"
  exit 1
fi
```

### 3. 路径解析容错

```python
# domain/knowledge/parser.py
def parse_file_path(filepath: str) -> dict:
    """Parse knowledge file path into metadata."""
    rel_path = os.path.relpath(filepath, KNOWLEDGE_DIR)
    parts = rel_path.replace("_", "-").split("/")  # 容错：下划线视为连字符
    filename = os.path.splitext(parts[-1])[0]
    path_tokens = []
    for part in parts:
        path_tokens.extend(part.split("-"))
    return {
        "rel_path": rel_path,
        "filename": filename,
        "path_tokens": path_tokens,
    }
```

## Verification

- 文件重命名为 `wip-features.md`
- Pre-commit hook 阻止提交包含下划线文件名的文件
- RAG 搜索 "features" 正确匹配到该文件
- `path_tokens` 包含 `["wip", "features"]`

## Prevention

- **工具层面：** Git pre-commit hook 自动检查文件命名规范
- **流程层面：** 提交前运行就绪检查清单中的 "文件命名规范" 检查项
- **文档层面：** 在 [File Standards 规范](../specs/file-standards.md) 中明确 kebab-case 要求，提供正反例
- **CI 层面：** 添加 CI 检查步骤，扫描所有 YiKnowledge 文件的命名规范
