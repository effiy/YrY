## AI 检索架构

\`\`\`
YiKnowledge (Markdown 文件树)
  ↓ apscheduler 每 60s 轮询
YiAi Knowledge Watcher
  ↓ 解析 frontmatter + 正文
MongoDB knowledge_files 集合
  ↓ llama_index 索引构建
Vector Index (data/rag_store/)
  ↓ 混合检索 (向量 + BM25)
RAG 查询 → 用户
\`\`\`

## 设计原则

1. **角色优先，边界清晰** — 每条知识属于唯一角色目录
2. **描述性文件名** — 动词短语 slug
3. **外部内容双文件** — \`*-original.md\` + \`*-summary.md\`
4. **YAML frontmatter 必填** — 检索信号
5. **统一正文结构** — Summary / Core viewpoints / Key information / Action recommendations
6. **新鲜度标记** — \`last_verified\` + \`review_cycle\`
7. **最多 3 层目录** — \`role/problem-domain/file.md\`
