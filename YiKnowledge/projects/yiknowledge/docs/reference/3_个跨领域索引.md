## 检索策略

1. **流水线阶段优先** — 从你所在的阶段开始
2. **角色目录** — 按角色索引找到具体问题域
3. **角色内 INDEX** — 每个角色都有 INDEX.md 导航
4. **跨角色** — 使用领域索引
5. **文件名 grep** — \`rg "^tags:.*keyword" YiKnowledge -l\`
6. **Frontmatter 扫描** — \`head -15 file.md\`
