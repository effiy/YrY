# 知识管理规范

## 文件命名

- **格式**: kebab-case (小写字母 + 连字符)
- **禁止**: 下划线 \`_\`、数字
- **语义**: 中文语义保留在 frontmatter \`title:\` 和 \`aliases:\` 中
- **目录层级**: 最多 3 层 — \`role/problem-domain/file.md\`

## YAML Frontmatter 规范

\`\`\`yaml
---
title: 文件标题                      # 必填
aliases: [别名1, 别名2]              # 推荐
tags: [标签1, 标签2, 标签3]           # 必填, 3-5 个
category: root | <role>/<subdir>     # 必填
created: YYYY-MM-DD                  # 必填
updated: YYYY-MM-DD                  # 必填
source: internal | url               # 必填
type: summary | original | template | prompt  # 必填
status: draft | stable | deprecated  # 必填
lifecycle: inbox | triage | active | reference | archive
review_cycle: weekly | monthly | quarterly | yearly
last_verified: YYYY-MM-DD
roles: [role1, role2]
benefit: "简短描述"
acceptance_criteria:
  - "可验证的条款"
related:
  - relative/path/to/file.md
---
\`\`\`

## 内容结构

1. Summary (摘要)
2. Core viewpoints (核心观点)
3. Key information (关键信息)
4. Action recommendations (行动建议)
5. Anti-patterns (反模式)
6. Related links (相关链接)

## 知识生命周期

\`\`\`
inbox → triage → active → reference → archive
  ↓        ↓        ↓         ↓          ↓
 新入库   分类中   活跃使用   参考归档   已废弃
\`\`\`
