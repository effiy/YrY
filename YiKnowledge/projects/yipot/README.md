## 项目概况

| 维度 | 值 |
|------|-----|
| 名称 | Pot (派了个萌的翻译器) |
| 类型 | Tauri 桌面应用 |
| 版本 | 3.0.7 |
| 前端 | React 18 + Jotai + NextUI |
| 后端 | Rust (Tauri 1.6) |
| 平台 | Windows / macOS / Linux |
| 包管理 | pnpm |
| 构建 | Vite 5 |

## 核心功能

- **划词翻译** — 鼠标选中文本，快捷键触发翻译
- **输入翻译** — 快捷键呼出翻译窗口，手动输入翻译
- **剪切板监听** — 自动检测剪切板内容并翻译
- **截图 OCR** — 框选区域进行文字识别
- **截图翻译** — 框选区域直接翻译
- **语音合成** — 多接口 TTS 朗读
- **生词本** — 导出到 Anki / 欧路词典
- **插件系统** — 扩展翻译/OCR/TTS/生词本服务
- **多语言** — 20+ 语言国际化支持
