# YP-09-S04: 系统托盘与通知

> 需求编号：YP-09-S04 · 优先级：P1 · 人天：1.0d · 状态：已完成

## 背景

Pot 作为常驻后台的桌面工具，需要系统托盘支持让用户快速访问功能，同时不占用任务栏/Dock 空间。

## 需求

### 托盘图标

- 应用启动时创建系统托盘图标
- macOS: 使用模板图标（黑白适配）
- Windows/Linux: 使用彩色图标

### 托盘菜单

```
┌─────────────────────┐
│ 划词翻译    [启用✓]  │
│ 输入翻译            │
│ 截图 OCR            │
│ 截图翻译            │
│ ────────────────    │
│ 设置                │
│ 关于                │
│ ────────────────    │
│ 退出                │
└─────────────────────┘
```

### macOS 特殊处理

```rust
app.set_activation_policy(tauri::ActivationPolicy::Accessory);
// 不显示 Dock 图标，仅托盘运行
```

### 单实例检测

```rust
tauri_plugin_single_instance::init(|app, _, cwd| {
    Notification::new(...)
        .title("程序已在运行，请勿重复启动")
        .show();
})
```

## 验收标准

- [ ] 系统托盘图标在所有平台正常显示
- [ ] 右键菜单项全部可用
- [ ] macOS 不显示 Dock 图标
- [ ] 重复启动弹出通知提示
- [ ] 托盘菜单"退出"可完全关闭应用

## 用户画像与使用场景

### 典型用户

| 画像 | 角色 | 核心诉求 | 使用频率 |
|------|------|---------|---------|
| macOS 极简用户 | 偏好 Dock 栏干净的 Mac 用户 | 仅菜单栏图标运行，不占 Dock 栏 | 持续后台运行 |
| Windows 常驻工具用户 | 需要翻译随时待命的办公人员 | 后台静默运行，托盘图标快速访问 | 持续后台运行 |

### 使用场景

1. **快速功能访问**: 用户右键托盘图标 → 点击"输入翻译" → 期望: 立即弹出翻译窗口，比快捷键更直观
2. **重复启动防护**: 用户不小心再次双击 Pot.app → 弹出"程序已运行"通知 → 期望: 不启动第二个实例
3. **退出应用**: 用户右键托盘 → 点击退出 → 期望: 所有窗口关闭，后台进程完全退出

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| Linux 无托盘库 | 异常 | 检测 `libayatana-appindicator`，缺失时提示 | 不显示托盘，仅窗口模式可用 |
| macOS 菜单栏空间不足 | 边界 | 系统自动隐藏（由 macOS 管理） | — |
| 首次启动无托盘图标 | 异常 | 日志记录失败原因 | 应用主窗口仍可正常使用 |
| 托盘菜单点击频率过高 | 边界 | 正常处理每次点击 | — |
| 应用退出后托盘残留 | 异常 | 确保进程完全退出 | — |
| 通知权限未开启 | 边界 | Windows: 通知不弹出，不影响功能 | — |

## 通知分类与优先级

### 通知类型

| 类型 | 优先级 | 触发条件 | 显示方式 | 是否可关闭 |
|------|--------|---------|---------|-----------|
| 更新可用 | 高 | 检测到新版本 | 托盘提示 + 通知气泡 | 是（暂不更新） |
| 功能状态变更 | 中 | 快捷键冲突/权限不足 | 通知气泡 | 是 |
| 服务不可用 | 中 | API Key 失效/翻译失败 | 托盘图标变灰 + 通知 | 是 |
| 剪切板监听状态 | 低 | 开启/关闭剪切板监听 | 托盘图标角标 | 是 |
| 单实例检测 | 中 | 重复启动 | 通知气泡 | 自动消失 |
| 操作确认 | 低 | 备份成功/配置导入完成 | 通知气泡 | 自动消失 (3s) |

### 通知生命周期

| 阶段 | 行为 |
|------|------|
| 触发 | 事件驱动，不轮询 |
| 显示 | 系统通知 API (macOS: UNNotification / Windows: Toast / Linux: libnotify) |
| 消失 | 自动消失 5s (或用户手动关闭) |
| 点击 | 跳转到设置相关页面 (仅更新通知) |

### 托盘状态同步

```
应用状态 → 托盘图标
├─ 正常运行     → 彩色/模板图标 (正常)
├─ 翻译服务不可用 → 图标灰色叠加层 + 角标感叹号
├─ 剪切板监听中  → 图标绿色小圆点角标
└─ 更新可用     → 图标红色小圆点角标
```
