# 项目概览活动模块优化 — 需求规格

> 需求编号：YP-09-101 · 优先级：P2 · 人天：~0.3d

> **文档职责**：定义 YiVad 项目概览页面 "Recent Activity" 活动时间线组件的渲染优化需求。

---

## 背景

### 组件架构

"Recent Activity" 模块位于项目详情概览 Tab（`DetailOverview.vue`），由以下三层构成：

```
DetailOverview.vue                 ← 页面容器，传递 props
  └─ ActivityTimeline.vue          ← 渲染组件，分组 + 滚动
       └─ useActivityTimeline.ts   ← 数据聚合 composable
            ├─ Issues（Requirement 类型）
            ├─ Bugs
            ├─ Modules
            └─ Knowledge Files (PRD/Dev/Test/OKR/Workflow)
```

数据聚合后按日期分组（Today / Yesterday / YYYY-MM-DD·Dow），每条活动渲染为时间线节点（dot + line + content badge）。

### 现存问题

经过代码审查和实际使用，识别出以下 6 个渲染缺陷：

| # | 问题 | 分类 | 严重度 |
|---|------|------|--------|
| 1 | `.do-timeline-target` 硬编码 `max-width: 200px`，宽屏浪费 60%+ 可用空间，长标题过早截断 | 布局 | 中 |
| 2 | `.do-timeline-line` 连接线 `bottom: 0`，尾部无隐藏逻辑，最后一项下方残留 16px 空白线段 | 视觉 | 低 |
| 3 | `:key="activityTypeFilter"` 导致筛选切换时 Vue 完全重建 DOM 子树，触发 `timeline-enter` 动画闪烁 | 性能 | 中 |
| 4 | Issues 有 `description` 字段，但 `contentPreview` 从未赋值，活动项缺失上下文预览 | 功能缺失 | 中 |
| 5 | Bugs 有 `description` 字段，同样缺失 `contentPreview` | 功能缺失 | 中 |
| 6 | 文档 `contentPreview` 仅使用 `meta.description`，大量知识文件无此字段（命中率 < 30%） | 功能缺失 | 中 |

---

## 功能需求

### FR-1: 标题自适应宽度

**涉及文件**：`YiVad/src/styles/DetailOverview.scss`

将 `.do-timeline-target` 的布局方式从固定 `max-width: 200px` 改为 `flex: 1; min-width: 0`，配合父容器 flex 布局让标题填充所有可用空间，窄空间下仍可正常截断。

**技术要点**：`min-width: 0` 是 flex 子元素中 `text-overflow: ellipsis` 正常工作的必要条件。

### FR-2: 连接线尾部溢出修复

**涉及文件**：`YiVad/src/styles/DetailOverview.scss`

为 `.do-timeline-item--last .do-timeline-line` 添加 `display: none`，作为模板层 `v-if` 条件的 CSS 兜底。

### FR-3: 筛选无闪烁切换

**涉及文件**：`YiVad/src/views/project/components/ActivityTimeline.vue`

移除 `.do-timeline` 容器上的 `:key="activityTypeFilter"` 绑定。Vue 响应式系统中，`activityTypeFilter` 变化 → `filteredActivity` 重计算 → `v-for` 以 `a.id` 为 key 高效增删 DOM 节点，无需销毁整个子树。

### FR-4: Issues 内容预览

**涉及文件**：`YiVad/src/views/project/composables/useActivityTimeline.ts`

在 requirement-issue builder 中新增 `contentPreview: cleanPreview(i.description || "")`。`Issue.description` 为可选 `string` 字段，Markdown 格式，经 `cleanPreview` 去标签/标题/表格后展示为纯文本预览。

### FR-5: Bugs 内容预览

**涉及文件**：`YiVad/src/views/project/composables/useActivityTimeline.ts`

在 bug builder 中新增 `contentPreview: cleanPreview(b.description || "")`。`BugDocument.description` 为可选 `string` 字段。

### FR-6: 文档预览回退链

**涉及文件**：`YiVad/src/views/project/composables/useActivityTimeline.ts`

新增 `buildDocPreview(meta)` 辅助函数，按以下优先级回退：

```
meta.description          → 最常用，PRD/Dev/Test 均可能有
meta.acceptance_criteria[0] → PRD 文件常用，数组第一项
meta.benefit              → 决策/架构文档常用
""                        → 无可用字段，不展示预览
```

每层均做 `typeof === "string"` 类型保护，防止 YAML 解析为对象/数组导致 `[object Object]` 渲染。

### FR-7: 预览文本质量优化

**涉及文件**：`YiVad/src/views/project/composables/useActivityTimeline.ts`

优化 `cleanPreview` 函数：
- 保留段落换行（`\n\n` → `\n`），而非全部挤压为单行
- 150 字符截断 + 末尾 `…`，避免超长预览撑破 2-line clamp

## 验收标准

### 视觉验收

- [ ] 窗口宽度 ≥ 1400px 时，活动标题使用全部可用宽度（验证 `.do-timeline-target` 计算宽度约 400-600px）
- [ ] 每组最后一项活动下方无连接线残留
- [ ] 点击类型筛选按钮（All → Requirements → Bugs → Modules → Docs），列表项平滑出现/消失，无闪烁
- [ ] 有 `description` 的 Issue 在活动项底部显示灰色内容预览块（max 2 行）
- [ ] 有 `description` 的 Bug 在活动项底部显示灰色内容预览块（max 2 行）
- [ ] 有 `acceptance_criteria` 的 PRD 文档显示第一条验收标准为预览
- [ ] 有 `benefit` 的决策文档显示 benefit 文本为预览
- [ ] 无任何 frontmatter 描述的文档不显示预览块

### 技术验收

- [ ] `pnpm type:check` 零错误
- [ ] `contentPreview` 为纯文本，无 Markdown 语法残留
- [ ] `buildDocPreview` 对非 string 类型的 `acceptance_criteria` 元素正确跳过
