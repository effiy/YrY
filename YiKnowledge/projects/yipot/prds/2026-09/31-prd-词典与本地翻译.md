# YP-09-S20: 词典与本地翻译服务

> 需求编号：YP-09-S20 · 优先级：P2 · 人天：0.5d · 状态：已完成

## 必应词典 (bing_dict)

- 免费，无需 API Key
- 返回音标、词性、释义、例句
- 适用于单词查询场景

## 剑桥词典 (cambridge_dict)

- 免费在线词典
- 英英释义 + 例句
- 适合英语学习者

## ECDICT 本地词典

- 离线可用，无需网络
- 本地词库文件
- 快速响应

## Lingva 自托管

- 开源翻译前端
- 支持私有化部署
- 隐私保护

## 验收标准

- [ ] 必应词典返回完整单词信息
- [ ] ECDICT 离线可查词
- [ ] Lingva 自定义服务器可用
- [ ] 词典服务在单词查询时自动激活

---

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 输入为短语/句子（非单词） | 边界 | 词典服务自动跳过，仅翻译服务响应 | — |
| 必应词典不可达 | 异常 | 提示"必应词典暂时不可用" | 降级到 ECDICT |
| 剑桥词典不可达 | 异常 | 提示"剑桥词典暂时不可用" | — |
| ECDICT 词库文件缺失 | 异常 | 提示"本地词库未找到，请重新下载" | — |
| Lingva 自定义服务器不可达 | 异常 | 提示"Lingva 服务器无法连接" | 检查 URL 配置 |

---

## 非功能需求

| 类别 | 指标 | 目标值 | 验证方法 |
|------|------|--------|---------|
| 性能 | ECDICT 本地查询 | ≤ 50ms | 100 次查词计时 |
| 性能 | 必应词典响应 | P95 ≤ 1s | 100 次计时 |
| 可用性 | ECDICT 离线可用 | 100%（词库完整时） | 离线测试 |
| 存储 | ECDICT 词库大小 | ~50MB | 磁盘检查 |

## 模块交互依赖

| 依赖方向 | 模块 | 交互方式 | 数据格式 |
|---------|------|---------|---------|
| 依赖 | 必应词典 API | HTTPS GET | `{word} → {pronunciation, definitions, examples}` |
| 依赖 | 剑桥词典 | HTML 抓取 | `{word} → {definitions, examples}` |
| 依赖 | ECDICT 本地词库 | 本地文件读取 | 词库索引查询 |
| 依赖 | Lingva (自托管) | HTTPS GET | `{word, source, target}` |
| 被依赖 | 划词翻译核心 | 插件接口 | 单词查询自动激活词典模式 |
