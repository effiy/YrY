# 语音合成与生词本 — 需求规格

> 需求编号：YP-09-M04 · 优先级：P1 · 人天：~2d

> **文档职责**：本文档定义语音合成（TTS）朗读和生词本导出功能的产品需求。

---

## 一、语音合成（TTS）

### 用户故事
> 作为语言学习者，我希望听到翻译结果的标准发音，帮助纠正发音和学习新词汇。

### 交互流程

1. 翻译结果显示后，点击朗读按钮
2. 系统调用 TTS 服务合成语音
3. 播放翻译结果的语音

### 支持的 TTS 接口

| 接口 | 语言支持 | 需要 API Key |
|------|---------|-------------|
| 百度 TTS | 中/英/日/韩 | 是 |
| 腾讯 TTS | 中/英 | 是 |
| Azure TTS | 100+ 语言 | 是 |
| 系统 TTS | 系统语言 | 否 |

### 验收标准

- [ ] 点击朗读按钮后 < 1s 开始播放
- [ ] 支持调节语速和音量
- [ ] 支持中断播放
- [ ] 系统 TTS 离线可用

---

## 二、生词本导出

### 用户故事
> 作为语言学习者，我希望将翻译过的词汇保存到生词本中，方便后续复习。

### 交互流程

1. 翻译结果中点击收藏按钮
2. 词汇加入本地收藏列表
3. 可选择导出到 Anki 或欧路词典

### 支持的导出目标

| 目标 | 方式 | 特性 |
|------|------|------|
| Anki | AnkiConnect 插件 | 自动创建卡片 |
| 欧路词典 | HTTP API | 一键添加生词 |

### 验收标准

- [ ] 收藏按钮一键添加词汇
- [ ] 本地收藏列表支持查看和管理
- [ ] Anki 导出支持字段映射配置
- [ ] 欧路词典导出支持自定义词典

## 用户画像与使用场景

### 典型用户

| 画像 | 角色 | 核心诉求 | 使用频率 |
|------|------|---------|---------|
| 语言初学者 | 每天学习 20 个新单词的英语学习者 | 听到标准发音、收藏生词定期复习 | 日均 30+ 次朗读、20+ 次收藏 |
| 备考学生 | 准备托福/雅思/JLPT 的考生 | 通过 Anki 间隔复习翻译过的词汇 | 日均 15+ 次收藏导出 |

### 使用场景

1. **单词发音学习**: 用户翻译了一个新单词 → 点击朗读按钮 → 期望: 听到标准美式/英式发音，可调节 0.5x 慢速跟读
2. **Anki 复习流程**: 用户翻译了一批专业术语 → 点击收藏 → 每日导出到 Anki → 期望: 字段映射自动匹配（正面=原文，背面=译文+音标）
3. **离线 TTS**: 用户无网络时 → 使用系统 TTS → 期望: 至少能用系统语音朗读英文和中文
4. **语速调节**: 用户听快速发音 → 调节语速 0.5x → 期望: 语速变化自然，无机械感/卡顿

## 量化验收标准

| 编号 | 验收项 | 量化指标 | 测量方法 | 优先级 |
|------|--------|---------|---------|--------|
| AC-01 | TTS 首音延迟（网络） | ≤ 1s（百度/Azure） | 点击朗读到声音输出计时 | P1 |
| AC-02 | TTS 首音延迟（系统） | ≤ 500ms | 同上 | P1 |
| AC-03 | 语速调节范围 | 0.5x ~ 2.0x，步长 0.1x | 功能验证 | P2 |
| AC-04 | Anki 导出成功率 | ≥ 99%（AnkiConnect 运行中） | 100 次导出测试 | P1 |
| AC-05 | 收藏操作响应 | ≤ 100ms（按钮反馈） | UI 事件计时 | P2 |
| AC-06 | 本地收藏列表容量 | 支持 ≥ 1000 条 | 压力测试 | P2 |

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 朗读空文本 | 边界 | 按钮禁用，不触发朗读 | — |
| 朗读超长文本（> 500 字符） | 边界 | 截断至 500 字符，提示"文本过长已截断" | 取前 500 字符 |
| 朗读中切换 TTS 服务 | 边界 | 停止当前朗读，切换到新服务 | — |
| 网络断开时 TTS | 异常 | 自动降级到系统 TTS | 降级链: Azure→百度→系统 |
| TTS 服务返回空音频 | 异常 | 显示"语音合成失败"，不播放 | — |
| AnkiConnect 未启动 | 异常 | 提示"请先启动 Anki 并安装 AnkiConnect 插件" | 引导安装链接 |
| 欧路词典未安装 | 异常 | 提示"未检测到欧路词典，请先安装" | — |
| 重复收藏同一词汇 | 边界 | 显示"已收藏"，不重复添加 | 前端去重检查 |
| 收藏导出文件过大 | 边界 | 分批导出，每批 200 条 | CSV 分片 |

## 非功能需求

| 类别 | 指标 | 目标值 | 验证方法 |
|------|------|--------|---------|
| 性能 | TTS 音频缓存命中率 | ≥ 80%（相同文本不重复请求） | 缓存命中日志 |
| 性能 | 收藏列表渲染 | ≤ 200ms（1000 条） | React Profiler |
| 可用性 | 系统 TTS 离线可用 | macOS/Windows 100% 离线可用 | 离线测试 |
| 可用性 | 朗读中断响应 | ≤ 100ms | 点击停止到静音计时 |
| 数据 | 导出 CSV 编码 | UTF-8 BOM（兼容 Excel 中文） | 文件编码检查 |
