# YP-09-S06: 窗口定位与多显示器

> 需求编号：YP-09-S06 · 优先级：P1 · 人天：1.0d · 状态：已完成

## 背景

翻译窗口需要智能定位——在鼠标附近弹出、不超出屏幕边界、多显示器下正确识别当前显示器。

## 需求

### 显示器检测

```rust
fn get_current_monitor(x: i32, y: i32) -> Monitor {
    // 遍历所有显示器
    // 判断鼠标落在哪个显示器范围内
    // 返回该显示器对象
}
```

### 定位策略

| 模式 | 配置值 | 行为 |
|------|--------|------|
| 鼠标跟随 | `mouse` | 在鼠标附近弹出，自动边界检测 |
| 固定位置 | `fixed` | 使用 `translate_window_position_x/y` |

### 边界检测

```rust
// 窗口右边界超出 → 向左偏移
if mouse.x + width * dpi > monitor_right {
    mouse.x -= width * dpi;
}
// 窗口下边界超出 → 向上偏移
if mouse.y + height * dpi > monitor_bottom {
    mouse.y -= height * dpi;
}
```

### 窗口尺寸记忆

- `translate_window_width` / `translate_window_height` — 翻译窗口
- `recognize_window_width` / `recognize_window_height` — OCR 窗口
- DPI 感知缩放

## 验收标准

- [ ] 鼠标在左屏 → 翻译窗口在左屏弹出
- [ ] 鼠标在右屏 → 翻译窗口在右屏弹出
- [ ] 窗口不超出显示器边界
- [ ] 固定位置模式窗口位置不变
- [ ] 4K 200% 缩放下窗口大小正确

## 量化验收标准

| 编号 | 验收项 | 量化指标 | 测量方法 | 优先级 |
|------|--------|---------|---------|--------|
| AC-01 | 显示器检测准确率 | 100%（任意显示器组合） | 双屏/三屏环境全覆盖测试 | P1 |
| AC-02 | 鼠标跟随窗口弹出延迟 | ≤ 100ms（快捷键按下到窗口显示） | 高速计时 50 次取 P95 | P1 |
| AC-03 | 窗口边界检测准确率 | 100%（不出屏幕任意边缘） | 屏幕四角 + 四边各 10 次测试 | P1 |
| AC-04 | 跨显示器迁移延迟 | ≤ 300ms（拔插显示器后窗口重组） | 模拟显示器热插拔 | P2 |
| AC-05 | DPI 缩放正确率 | 100%（125%/150%/175%/200%） | 各缩放比例截图对比 | P1 |

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 鼠标在显示器边缘 | 边界 | 检查方向，窗口偏移到内侧 | 四方向自动翻转 |
| 仅一个显示器 | 边界 | 始终使用该显示器，简化逻辑 | — |
| 显示器热插拔 | 边界 | 实时重检测显示器列表 | 监听 display_change 事件 |
| 窗口尺寸记忆值异常 | 边界 | 校验范围（100-2000px），异常用默认值 | 默认 350x420 |
| 固定位置坐标越界 | 边界 | 自动修正到显示器范围内 | — |
