# YP-09-S01: 百度翻译服务集成

> 需求编号：YP-09-S01 · 优先级：P0 · 人天：0.5d · 状态：已完成

## 背景

百度翻译是国内使用最广泛的翻译 API，中文翻译质量最高，免费额度充足（每月 200 万字符）。作为中文用户最常用的翻译服务，优先级 P0。

## 用户场景

1. **中英互译**: 用户在阅读英文论文 → 选中专业术语 → 百度翻译在 500ms 内返回高质量中文翻译，含音标和词典释义
2. **单词查询**: 用户查询单词 "algorithm" → 百度返回译文"算法" + 音标 + 词性 + 词典释义（基础释义、网络释义）

## 需求

### API 认证

- App ID + Secret Key → MD5 签名 (`md5(appId + text + salt + secret)`)
- 支持标准文本翻译 + 垂直领域翻译（baidu_field 独立插件）

### 翻译功能

- 200+ 语言对支持
- 返回译文 + 词典释义（单词查询时自动激活）
- 音标展示（英文单词）

## 量化验收标准

| 编号 | 验收项 | 量化指标 | 测量方法 | 优先级 |
|------|--------|---------|---------|--------|
| AC-01 | 翻译响应时间 | ≤ 500ms (P95) | 100 次请求取 P95 | P0 |
| AC-02 | 签名正确率 | 100% | 有效/无效/边缘字符 各 50 次 | P0 |
| AC-03 | 单词查询词典返回 | 返回音标 + 释义 (≥ 2 条) | 50 个常见单词测试 | P1 |
| AC-04 | 中文翻译质量 | BLEU score ≥ 0.35 (en→zh 通用文本) | 标准测试集 | P2 |

## 边界条件

| 输入 | 预期行为 |
|------|---------|
| 空文本 | 不发起 API 请求 |
| 超长文本 (> 5000 字符) | 截断至 5000 并提示 |
| 不支持语言对 | 返回错误提示 "不支持的语言组合" |
| App ID 无效 | 显示 "认证失败 (App ID)" |
| Secret 错误 | 显示 "认证失败 (签名不匹配)" |
| 网络超时 | 5s 超时，显示 "百度翻译请求超时" |
