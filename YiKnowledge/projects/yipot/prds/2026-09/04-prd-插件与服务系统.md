# 插件与服务系统 — 需求规格

> 需求编号：YP-09-M05 · 优先级：P1 · 人天：~3d

> **文档职责**：本文档定义插件架构和服务配置管理的产品需求。

---

## 一、插件架构

### 设计目标

将翻译、OCR、TTS、生词本四类服务全部插件化，实现：
- 新增服务无需修改核心代码
- 第三方可独立开发服务插件
- 用户按需安装/启用插件

### 插件接口规范

每个插件需实现以下标准接口：

```
info.ts    — 插件元信息（名称、版本、作者、接口类型）
index.jsx  — 插件主逻辑（翻译/OCR/TTS/生词本调用）
Config.jsx — 插件配置界面（API Key、参数设置）
```

### 插件类型

| 类型 | 目录 | 核心方法 |
|------|------|---------|
| 翻译 | `services/translate/` | `translate(text, from, to)` |
| OCR | `services/recognize/` | `recognize(image)` |
| TTS | `services/tts/` | `synthesize(text, lang)` |
| 生词本 | `services/collection/` | `add(word, translation)` |

### 验收标准

- [ ] 新增翻译接口仅需添加插件目录
- [ ] 插件配置界面自动注册到设置页
- [ ] 插件安装/卸载不影响其他插件
- [ ] 内置插件与第三方插件行为一致

## 二、服务配置管理

### 功能描述

为每个服务实例提供独立的配置管理，支持多账号切换。

### 配置项

| 配置 | 说明 |
|------|------|
| API Key / Secret | 服务认证凭据 |
| 自定义 API 地址 | 私有化部署支持 |
| 启用/禁用 | 控制服务可用性 |
| 优先级排序 | 拖拽调整多接口查询顺序 |

### 验收标准

- [ ] 每个服务实例独立保存配置
- [ ] API Key 本地加密存储
- [ ] 支持拖拽调整服务优先级
- [ ] 禁用服务不参与并行查询

## 用户画像与使用场景

### 典型用户

| 画像 | 角色 | 核心诉求 | 使用频率 |
|------|------|---------|---------|
| 第三方开发者 | 想为 Pot 开发新的翻译/OCR 接口插件 | 清晰的插件接口规范、独立的开发测试环境 | 低频（开发时） |
| 高级用户 | 同时使用多个翻译服务，需要灵活配置 | 自由安装/卸载插件、独立配置每个服务 | 低频（配置时） |

### 使用场景

1. **新服务插件开发**: 第三方开发者想接入某小众翻译 API → 按插件规范创建 `info.ts + index.jsx + Config.jsx` → 期望: 拖拽到 Pot 即可安装，自动注册到服务列表
2. **服务优先级管理**: 用户需要百度优先、DeepL 备用 → 在设置页拖拽调整服务顺序 → 期望: 并行查询按优先级排序展示，失败自动 fallback 到下一个
3. **多账号切换**: 用户有个人和公司两个百度翻译账号 → 同一服务插件创建两个实例 → 期望: 每个实例独立配置 API Key，翻译时可选择使用哪个实例
4. **插件生命周期管理**: 用户不再使用某个翻译服务 → 禁用或卸载插件 → 期望: 卸载清理所有关联配置，不影响其他插件

## 量化验收标准

| 编号 | 验收项 | 量化指标 | 测量方法 | 优先级 |
|------|--------|---------|---------|--------|
| AC-01 | 新增翻译插件时间 | ≤ 3 分钟（有 API 文档前提下） | 开发者实测 | P1 |
| AC-02 | 插件配置界面自动注册 | 100% 自动出现在设置页 | 安装后检查设置页 | P1 |
| AC-03 | 插件隔离性 | 单个插件崩溃不影响其他插件 | 注入异常插件测试 | P1 |
| AC-04 | 服务优先级拖拽 | 拖拽≤3次完成排序，结果持久化 | 可用性测试 | P2 |
| AC-05 | 插件安装包大小 | ≤ 500KB（不含语言包） | 构建产物检查 | P2 |

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 插件缺少必需文件（info.ts） | 异常 | 安装失败，提示"插件格式不正确：缺少 info.ts" | — |
| 插件版本不兼容 | 异常 | 提示"插件要求 Pot ≥ v3.1.0，当前 v3.0.7" | 阻止安装 |
| 同名插件已存在 | 边界 | 提示"插件已安装，是否覆盖？" | 覆盖前备份旧版本 |
| 插件 info.ts 格式错误 | 异常 | 安装失败，显示具体错误行 | — |
| 服务 API Key 为空时查询 | 边界 | 跳过该服务，仅查询已启用且有 Key 的服务 | 该服务自动置灰 |
| 拖拽排序冲突 | 边界 | 原子操作：拖拽完成一次性保存 | 禁止拖拽到非法位置 |
| 卸载插件时配置残留 | 异常 | 提示"是否同时删除该插件的配置数据？" | 默认保留配置 30 天 |

## 非功能需求

| 类别 | 指标 | 目标值 | 验证方法 |
|------|------|--------|---------|
| 性能 | 插件加载时间 | ≤ 100ms/插件 | 动态 import 计时 |
| 性能 | 设置页插件列表渲染 | ≤ 200ms（20 个插件） | React Profiler |
| 安全 | 第三方插件沙箱 | 限制文件系统/网络访问范围 | 安全审计 |
| 安全 | 插件 API Key 存储 | 与核心服务的 Key 共用加密方案 | 代码审查 |
| 兼容性 | 插件向前兼容 | 新版本 Pot 兼容旧版本插件（至少 2 个大版本） | 回归测试 |

## 插件生命周期

```
┌──────────┐   install   ┌──────────┐   enable   ┌──────────┐
│  未安装   │ ──────────► │  已安装   │ ─────────► │  已启用   │
│          │             │  (禁用)   │            │          │
└──────────┘             └────┬─────┘            └────┬─────┘
                              │         disable       │
                              │◄─────────────────────┘
                              │
                              │  uninstall
                              ▼
                         ┌──────────┐
                         │  已卸载   │
                         │ (清理配置) │
                         └──────────┘
```
