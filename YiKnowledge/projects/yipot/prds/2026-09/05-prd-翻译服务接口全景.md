# 翻译服务接口全景 — 需求规格

> 需求编号：YP-09-M07 · 优先级：P0 · 人天：~6d

> **文档职责**：定义 YiPot 集成的全部 21 个翻译服务接口的产品需求。

---

## 一、通用翻译服务（12 个）

### 1.1 百度翻译 (baidu)
| 属性 | 值 |
|------|-----|
| 类型 | 通用翻译 |
| API Key | App ID + Secret Key |
| 语言 | 200+ 语言对 |
| 特点 | 中文翻译质量最高、免费额度大 |

**需求**: 支持标准文本翻译，返回译文 + 词典释义

## 二、词典服务（5 个）

### 2.1 必应词典 (bing_dict)
- 返回: 发音音标、词性、释义、例句
- 适用: 单词查询

### 2.2 剑桥词典 (cambridge_dict)
- 返回: 英英释义、例句
- 适用: 英语学习

### 2.3 ECDICT (ecdict)
- 类型: 本地词典
- 特点: 离线可用、无需网络

### 2.4 Lingva (lingva)
- 类型: 自托管翻译
- 特点: 隐私保护、可私有化部署

## 四、验收标准

- [ ] 每个翻译服务独立可启用/禁用
- [ ] API Key 错误时显示明确提示
- [ ] 多服务并行查询不相互阻塞
- [ ] 网络超时 < 10s 自动降级
- [ ] 支持服务拖拽排序调整优先级
- [ ] 本地服务 (Ollama/ECDICT) 无需网络

## 用户画像与使用场景

### 典型用户

| 画像 | 角色 | 核心诉求 | 使用频率 |
|------|------|---------|---------|
| 多语种翻译需求者 | 需要在中日英德法之间频繁翻译 | 覆盖所有需要的语言对，质量有保障 | 日均 20+ 次 |
| 隐私敏感型用户 | 翻译涉密/商业敏感文档 | 使用本地/离线翻译服务，数据不出本机 | 日均 5+ 次 |

### 使用场景

1. **多接口对比**: 用户翻译一段专业德语 → 同时查询百度/DeepL/OpenAI → 期望: 在 2s 内看到三个结果，对比选择最优译法
2. **离线本地翻译**: 用户处理敏感合同 → 使用 Ollama 本地模型 → 期望: 无需网络，完全离线，翻译数据不离开本机
3. **免费替代方案**: 用户没有 API Key → 使用 Google 免费接口 + ECDICT 本地词典 → 期望: 中译英基本可用，单词查询准确
4. **国内特殊环境**: 用户在国内无法访问 Google → 通过代理使用 Google/Bing → 期望: 代理设置对所有翻译接口生效

## 量化验收标准

| 编号 | 验收项 | 量化指标 | 测量方法 | 优先级 |
|------|--------|---------|---------|--------|
| AC-01 | 单接口翻译成功率 | ≥ 99%（有有效 API Key 的网络接口） | 每个接口 100 次测试 | P0 |
| AC-02 | 多接口并行成功率 | ≥ 66%（3 个接口并行至少 2 个成功） | 100 次并行测试 | P0 |
| AC-03 | API Key 错误提示时效 | ≤ 500ms 显示错误信息 | 错误触发到提示渲染 | P1 |
| AC-04 | 网络超时降级 | 单接口 > 10s 自动标记不可用 | 超时计时 + 状态变更 | P0 |
| AC-05 | 翻译服务启用/禁用响应 | ≤ 200ms（UI 状态切换） | UI 事件计时 | P2 |
| AC-06 | 服务拖拽排序持久化 | 重启后 100% 保持 | 重启验证 | P2 |

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| API Key 格式错误（长度不匹配） | 异常 | 提示"API Key 格式无效" | 提供各服务 Key 格式示例 |
| API 返回非 JSON | 异常 | 提示"翻译服务返回格式异常" | 记录原始响应用于调试 |
| API 返回 403/401 | 异常 | 提示"认证失败，请检查 API Key" | 该服务标记为认证失败 |
| API 返回 429 限流 | 异常 | 提示"请求过于频繁，请稍后再试 30s" | 自动等待 Retry-After 时间 |
| 网络 DNS 解析失败 | 异常 | 提示"无法解析服务域名" | 该服务标记不可用 |
| 目标语言与源语言相同 | 边界 | 直接返回原文，不调用 API | — |
| 翻译后文本为空 | 边界 | 显示"（翻译结果为空）" | — |
| 多个服务同时超时 | 异常 | 显示"所有翻译服务超时" | 自动切换到离线服务 |

## 非功能需求

| 类别 | 指标 | 目标值 | 验证方法 |
|------|------|--------|---------|
| 性能 | 单接口请求超时 | 10s | HTTP 超时配置 |
| 性能 | 并行请求不阻塞 UI | 主线程空闲率 ≥ 80% | Performance 面板 |
| 可靠性 | 网络抖动重试 | 最多 2 次，间隔 1s/3s | 网络模拟 |
| 安全 | API Key 传输 | HTTPS 强制 | 网络抓包 |
| 安全 | 本地服务隔离 | Ollama 仅 127.0.0.1 | 网络配置检查 |
