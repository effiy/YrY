# YP-09-S07: TTS 语音合成服务

> 需求编号：YP-09-S07 · 优先级：P2 · 人天：0.5d · 状态：已完成

## 背景

朗读翻译结果帮助语言学习者纠正发音。支持多个 TTS 服务，包括系统原生 TTS。

## 需求

### 支持的 TTS 服务

| 服务 | 语言 | 需要 API Key |
|------|------|-------------|
| 系统 TTS | 系统语言 | 否 |
| Azure TTS | 100+ | 是 |
| 百度 TTS | 中/英/日/韩 | 是 |
| 腾讯 TTS | 中/英 | 是 |

### useVoice Hook

```javascript
// hooks/useVoice.jsx
const { speak, stop, isSpeaking } = useVoice();

speak("Hello World", "en");  // 朗读
stop();                       // 停止
```

### 交互设计

- 翻译结果旁显示朗读按钮
- 朗读中按钮显示停止图标
- 语速/音量可在设置中调节

## 验收标准

- [ ] 点击朗读按钮播放语音
- [ ] 再次点击停止播放
- [ ] 系统 TTS 离线可用
- [ ] 语速调节生效

---

## 量化验收标准

| 编号 | 验收项 | 量化指标 | 测量方法 | 优先级 |
|------|--------|---------|---------|--------|
| AC-01 | 系统 TTS 朗读延迟 | ≤ 300ms（点击朗读到出声） | 50 次计时取 P95 | P2 |
| AC-02 | Azure TTS 首字延迟 | ≤ 1s（网络良好时） | 流式首包计时 50 次 | P2 |
| AC-03 | 百度/腾讯 TTS 响应时间 | ≤ 2s（短文本 ≤ 50 字） | 50 次计时取 P95 | P2 |
| AC-04 | 朗读停止响应 | ≤ 100ms（点击停止到静音） | 50 次计时 | P2 |
| AC-05 | 语速调节精度 | ±5% 偏差（0.5x ~ 2.0x 范围内） | 音频时长测量 | P2 |
| AC-06 | 需 API Key 服务的认证检测 | 无 Key 时朗读按钮置灰 | 功能验证 | P2 |
| AC-07 | TTS 音频缓存命中率 | ≥ 80%（相同文本+语言+语速） | 缓存命中日志统计 | P2 |

---

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 朗读超长文本 | 边界 | 截断至 500 字符 | — |
| 当前 TTS 服务不可用 | 异常 | 自动降级到系统 TTS | 降级链: Azure→百度→系统 |
| 系统 TTS 无对应语言 | 异常 | 提示"系统不支持该语言朗读" | — |
| 朗读中切换语言 | 边界 | 停止当前朗读，重新合成 | — |
| TTS 音频缓存 | 边界 | 相同文本+语言+语速命中缓存 | 内存缓存 50 条 |
