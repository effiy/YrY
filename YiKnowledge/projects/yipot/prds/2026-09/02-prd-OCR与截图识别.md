# OCR 与截图识别 — 需求规格

> 需求编号：YP-09-M03 · 优先级：P0 · 人天：~4d

> **文档职责**：本文档定义截图 OCR、截图翻译、系统 OCR 集成的产品需求。

---

## 一、截图 OCR

### 用户故事
> 作为用户，我希望框选屏幕任意区域后能识别其中的文字，用于提取图片/PDF/不可选文本中的内容。

### 交互流程

1. 按下截图 OCR 快捷键
2. 屏幕进入截图模式（半透明遮罩）
3. 用户拖拽框选目标区域
4. 系统截取区域图片 → 调用 OCR 服务
5. 弹出识别结果窗口，显示识别文字

### 验收标准

- [ ] 截图模式支持拖拽框选
- [ ] 支持取消（Esc）和确认（Enter）
- [ ] OCR 结果支持复制全文
- [ ] 识别结果支持二次翻译
- [ ] 支持多 OCR 接口并行识别

---

## 二、截图翻译

### 用户故事
> 作为用户，我希望框选屏幕区域后直接看到翻译结果，省略手动复制 OCR 文本的步骤。

### 交互流程

1. 按下截图翻译快捷键
2. 框选目标区域
3. 系统截图 → OCR 识别 → 自动翻译
4. 显示翻译结果（可选叠加原文）

### 验收标准

- [ ] 截图 → OCR → 翻译全流程 < 4s
- [ ] 翻译结果浮窗可拖动
- [ ] 支持切换目标语言

---

## 三、系统 OCR 集成

### 功能描述

在支持的系统上使用原生 OCR 能力，实现离线识别。

| 平台 | 引擎 | 特性 |
|------|------|------|
| macOS | Vision Framework | 离线、中文优化 |
| Windows | Windows.Media.OCR | 离线、系统语言支持 |
| Linux | Tesseract.js (fallback) | 离线、多语言 |

### 验收标准

- [ ] macOS 系统 OCR 离线可用
- [ ] Windows 系统 OCR 离线可用
- [ ] 系统 OCR 作为默认选项，无需配置 API Key

## 用户画像与使用场景

### 典型用户

| 画像 | 角色 | 核心诉求 | 使用频率 |
|------|------|---------|---------|
| 论文研究者 | 从扫描版 PDF/图片中提取外文 | 截图 OCR 后翻译，处理不可选中文本 | 日均 15+ 次 |
| 设计师 | 从设计稿/截图中提取文字 | 快速准确提取 UI 文案 | 日均 5+ 次 |

### 使用场景

1. **扫描文档处理**: 用户拿到一份日文扫描件 PDF → 截图 OCR 快捷键框选段落 → 期望: 系统 OCR 离线识别日文，然后点击翻译按钮进行二次翻译
2. **图片文字提取**: 社交媒体上的英文截图 → 截图 OCR → 期望: 中文识别准确率 ≥ 95%，可直接复制使用
3. **离线快速识别**: 飞机上无网络 → 系统 OCR (macOS Vision) → 期望: 离线识别速度 < 1s，中英文均可正确识别
4. **混合语言场景**: 图片中同时包含中英文 → 截图翻译 → 期望: OCR 识别出所有文字，翻译仅处理外文部分

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 截图区域过小（< 50x50px） | 边界 | 提示"截图区域过小，请扩大选区" | — |
| 截图中无文字（纯图） | 边界 | 显示"未识别到文字" | 建议用户确认截图内容 |
| 截图中文字模糊/倾斜 | 边界 | 标注识别置信度低的字符 | 建议使用高精度 OCR |
| 网络断开时云 OCR | 异常 | 云 OCR 全部不可用，自动降级到系统 OCR/Tesseract | 降级链: 云→系统→Tesseract |
| OCR 返回空结果 | 异常 | 显示"识别无结果"，保留截图供检查 | — |
| 图片过大（> 10MB base64） | 边界 | 压缩至 2048px 宽后传输 | JPEG 质量 80% 压缩 |
| macOS 辅助功能权限未开启 | 异常 | 提示"需要辅助功能权限"，引导至设置 | — |
| 多个 OCR 接口均超时 | 异常 | 显示"识别超时"，提供重试按钮 | 切换接口超时阈值: 云 5s/本地 3s |
