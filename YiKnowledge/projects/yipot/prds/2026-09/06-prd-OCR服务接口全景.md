## 用户画像与使用场景

### 典型用户

| 画像 | 角色 | 核心诉求 | 使用频率 |
|------|------|---------|---------|
| 文档数字化人员 | 将纸质/扫描文档转为可编辑文本 | 高精度 OCR，支持多种文件格式 | 日均 10+ 次 |
| 学术研究者 | 从论文截图中提取公式和文字 | 公式识别转 LaTeX、多语言混合识别 | 日均 5+ 次 |

### 使用场景

1. **多语言混合识别**: 用户截取了一篇中日英混合的论文段落 → 使用火山多语言 OCR → 期望: 同时正确识别三种语言的文字
2. **公式论文提取**: 数学专业学生截图公式 → 使用讯飞 LaTeX OCR → 期望: 返回可编译的 LaTeX 代码 `\frac{d}{dx}...`
3. **名片/证件识别**: 用户拍摄名片 → 使用合合信息 OCR → 期望: 结构化返回姓名/电话/公司/职位
4. **二维码快速跳转**: 用户截图二维码 → 期望: 自动解码并显示 URL，可点击打开

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 截图中无文字 | 边界 | 显示"未识别到文字" | 建议使用高精度 OCR 重试 |
| 截图中文字过小 (< 12px) | 边界 | 识别置信度偏低，标注低置信度字符 | 建议放大截图 |
| 图片包含复杂背景/水印 | 边界 | 可能误识别背景文字 | 预处理（灰度化+二值化） |
| 图片格式不支持 | 异常 | 提示"不支持的图片格式" | 自动转 PNG |
| OCR 服务返回空结果 | 异常 | 显示"识别无结果" | 自动尝试系统 OCR |
| 百度 OCR 免费额度耗尽 | 异常 | 提示"API 调用次数已用完，剩余 0 次" | 自动切换到系统 OCR |
| Tesseract 语言包下载失败 | 异常 | 提示"语言包下载失败，请检查网络" | 允许手动导入语言包 |
| 二维码图片模糊 | 边界 | 无法解码时提示"二维码无法识别" | — |

## 服务选择策略与优先级

### 默认优先级（从高到低）

| 优先级 | 服务 | 适用场景 | 切换条件 |
|--------|------|---------|---------|
| 1 | 系统 OCR (system) | 离线/隐私场景 | 始终首选（无 API Key 时） |
| 2 | 百度精准 OCR (baidu_accurate) | 中文高精度 | 系统 OCR 置信度 < 80% |
| 3 | 火山多语言 (volcengine_multi_lang) | 多语言混合 | 检测到 ≥ 2 种语言 |
| 4 | 腾讯通用 OCR (tencent) | 通用降级 | 百度/火山不可用 |
| 5 | Tesseract.js (tesseract) | 最终降级 | 所有云服务不可用 |

### 自动切换规则

```
用户截图 → 系统 OCR (离线)
    ├─ 置信度 ≥ 80% → 返回结果
    └─ 置信度 < 80% → 尝试云 OCR
        ├─ 中文文本 → 百度精准 OCR
        ├─ 多语言 → 火山 OCR
        └─ 通用 → 腾讯 OCR
            └─ 全部失败 → Tesseract 降级
```

### 并行识别策略

多服务并行时，结果合并规则：
1. 按置信度排序，取置信度最高者
2. 各服务识别的文字区域取并集
3. 重叠区域保留高置信度结果

## 错误恢复与重试机制

| 错误类型 | 重试次数 | 退避策略 | 最大等待 | 最终降级 |
|---------|---------|---------|---------|---------|
| 网络超时 | 3 次 | 1s → 3s → 5s 指数退避 | 9s | 系统 OCR |
| API 限流 (429) | 2 次 | 等待 Retry-After 头 | 10s | 下一优先级服务 |
| 认证失败 (401) | 0 次 | 不重试 | — | 提示用户检查 API Key |
| 服务不可用 (503) | 2 次 | 2s → 5s 固定间隔 | 7s | 下一优先级服务 |
| 图片过大 (> 10MB) | 0 次 | 不重试 | — | 自动压缩至 4MB 后重试 |
| 语言包加载失败 | 3 次 | 3s 固定重试 | 9s | 提示手动下载 |
