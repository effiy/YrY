# YP-09-S10: Google 翻译服务集成

> 需求编号：YP-09-S10 · 优先级：P0 · 人天：0.3d · 状态：已完成

## 背景

Google 翻译是全球使用最广泛的免费翻译服务，支持 100+ 语言，无需 API Key。作为默认翻译服务的首选。

## 需求

- 免费接口（无需 API Key）
- 支持 100+ 语言对
- 自动语言检测
- 返回译文 + 源语言检测结果

## 验收标准

- [ ] 无需 API Key 即可使用
- [ ] 中英互译正确
- [ ] 自动检测源语言准确

---

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| Google 翻译不可达（国内网络） | 异常 | 提示"Google 翻译无法访问，请使用代理" | 自动使用其他可用服务 |
| 免费接口限流 | 异常 | 显示"Google 翻译暂时不可用，请稍后再试" | 建议使用代理或切换到其他服务 |
| 自动检测语言错误 | 边界 | 允许用户手动覆盖检测结果 | 提供语言切换按钮 |

---

## 非功能需求

| 类别 | 指标 | 目标值 | 验证方法 |
|------|------|--------|---------|
| 性能 | API 响应时间 | P95 ≤ 1s（通过代理时 ≤ 2s） | 100 次计时 |
| 可用性 | 无需 API Key | 开箱即用 | 无配置直接使用 |
| 可用性 | 自动语言检测准确率 | ≥ 95% | 100 条各语言样本 |

## 模块交互依赖

| 依赖方向 | 模块 | 交互方式 | 数据格式 |
|---------|------|---------|---------|
| 依赖 | Google Translate API (免费) | HTTPS POST | `{q, source, target, format}` |
| 依赖 | 代理配置 | Rust env var | HTTP_PROXY（如配置） |
| 被依赖 | 划词翻译核心 | 插件接口 | `translate(text, from, to) → {text, from, to}` |

## 量化验收标准

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 翻译响应时间 (P50) | < 500ms (直连) / < 1,500ms (代理) | fetch 计时，各 100 次 |
| 翻译响应时间 (P95) | < 1,500ms (直连) / < 3,000ms (代理) | fetch 计时 |
| 翻译准确率 (中→英) | BLEU > 0.40 | WMT 中英标准测试集 (100 条) |
| 翻译准确率 (英→中) | BLEU > 0.38 | WMT 英中标准测试集 (100 条) |
| 自动语言检测准确率 | >= 95% | 100 条各语言样本 (中/英/日/韩/法/德/西/俄/阿) |
| 零配置可用性 | 安装后无需任何配置即可翻译 | 全新安装 → 划词翻译 |
| 支持语言对数量 | >= 100 种 | 对照 Google Translate 语言列表验证 |
| 音译返回 (非拉丁文字) | 中文→日文返回假名、泰文→英文返回罗马字 | dt=rm 参数测试 |
| 长文本处理 | >= 1,800 字符 GET / >= 5,000 字符 POST | 边界值测试 |
| 代理环境兼容 | 支持 HTTP_PROXY / HTTPS_PROXY 环境变量 | 代理开启/关闭各 10 次 |
