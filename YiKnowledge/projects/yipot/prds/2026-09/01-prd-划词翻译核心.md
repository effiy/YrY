# 划词翻译核心 — 需求规格

> 需求编号：YP-09-M02 · 优先级：P0 · 人天：~5d

> **文档职责**：本文档定义划词翻译、输入翻译、剪切板监听三大翻译模式的产品需求。

---

## 一、划词翻译

### 用户故事
> 作为用户，我希望选中任意文本后按快捷键即可看到翻译结果，无需切换窗口。

### 交互流程

1. 用户在任意应用中选中文本
2. 按下划词翻译快捷键（默认 `Ctrl+Shift+T`）
3. 系统读取选中文本 → 检测语言 → 调用翻译接口
4. 浮窗显示翻译结果（原文 + 译文）

### 验收标准

- [ ] 选中文本后快捷键触发翻译，时延 < 500ms
- [ ] 支持多接口并行查询，结果同时展示
- [ ] 翻译浮窗始终置顶，点击外部自动关闭
- [ ] 支持语言自动检测和手动切换
- [ ] 支持翻译结果复制

---

## 二、输入翻译

### 用户故事
> 作为用户，我希望通过快捷键呼出翻译窗口，手动输入文本进行翻译。

### 交互流程

1. 按下输入翻译快捷键
2. 弹出翻译窗口，焦点在输入框
3. 输入/粘贴文本 → 自动检测语言 → 按 Enter 翻译
4. 显示翻译结果

### 验收标准

- [ ] 输入框支持多行文本
- [ ] 自动检测源语言
- [ ] 支持手动选择源语言和目标语言
- [ ] 翻译历史记录保留在窗口中

---

## 三、剪切板监听

### 用户故事
> 作为用户，我希望开启剪切板监听后，复制任意文本即可自动翻译。

### 交互流程

1. 在翻译面板点击剪切板监听按钮
2. 任意位置复制文本
3. 系统自动检测剪切板变化 → 读取新内容 → 翻译
4. 翻译结果自动更新

### 验收标准

- [ ] 点击按钮一键开启/关闭监听
- [ ] 复制文本后 < 1s 内显示翻译
- [ ] 不监听非文本内容
- [ ] 状态指示器明确显示监听状态

---

## 四、多接口并行

### 功能描述

同时向多个翻译服务发起请求，并行展示结果。

### 支持的翻译接口

| 接口 | 类型 | 需要 API Key |
|------|------|-------------|
| 百度翻译 | 通用 | 是 |
| 腾讯翻译 | 通用 | 是 |
| 阿里翻译 | 通用 | 是 |
| Google 翻译 | 通用 | 否 |
| DeepL | 专业 | 是 |
| OpenAI | AI | 是 |
| 有道翻译 | 通用 | 是 |
| Caiyun 小译 | 通用 | 是 |

### 验收标准

- [ ] 至少 2 个接口可同时查询
- [ ] 每个接口结果独立展示，含服务名称标签
- [ ] 单个接口失败不影响其他接口结果

## 用户画像与使用场景

### 典型用户

| 画像 | 角色 | 核心诉求 | 使用频率 |
|------|------|---------|---------|
| 外文资料浏览者 | 每天快速浏览英文网页/文档 | 选中文本即译，不打断阅读心流 | 日均 50+ 次 |
| 多语言对比者 | 需要对比多个翻译结果的专业译者 | 同时看 3-4 个翻译结果 | 日均 10+ 次 |

### 使用场景

1. **快速阅读理解**: 用户在 Chrome 阅读英文技术博客 → 选中不认识的句子 → Ctrl+Shift+T → 期望: 浮窗出现在鼠标旁，0.5s 内显示翻译，读完即关
2. **专业翻译对比**: 译者翻译合同文档 → 使用多接口并行 → 期望: 百度/DeepL/OpenAI 三个结果并排展示，可对比选择最优译法
3. **连续阅读模式**: 用户开启剪切板监听 → 连续复制多个段落 → 期望: 每复制一段自动翻译，无需反复按快捷键或切换窗口

## 边界条件与异常处理

| 输入条件 | 分类 | 预期行为 | 降级策略 |
|---------|------|---------|---------|
| 选中纯空格/换行 | 边界 | 不触发翻译，无提示 | — |
| 选中文本 > 5000 字符 | 边界 | 截断至 5000 字符并提示"文本过长已截断" | 取前 5000 字符翻译 |
| 选中 Emoji/特殊符号 | 边界 | 原样保留在结果中 | — |
| 选中混合语言文本 | 边界 | 自动检测主要语言（占比 > 50%） | — |
| 剪切板内容为图片 | 边界 | 忽略，不触发翻译 | — |
| 剪切板连续相同内容 | 边界 | 去重，不重复触发翻译 | 内容 hash 比对 |
| 所有翻译接口超时 | 异常 | 显示"所有翻译服务不可用，请检查网络" | 缓存上次接口列表，下次优先用快速接口 |
| 单个翻译接口返回空 | 异常 | 该接口显示"（无结果）" | 其他接口结果正常展示 |
| 快捷键被系统占用 | 异常 | 注册失败时提示冲突，建议更换组合键 | 自动推荐可用组合键 |
| 获取选中文本失败 | 异常 | 显示"无法获取选中文本，请检查辅助功能权限" | macOS: 引导至系统偏好设置 |

## 三模式状态机

翻译系统的三种模式及其转换关系：

```
            ┌──────────────┐
            │   空闲状态    │
            └──┬───┬───┬──┘
               │   │   │
  选中+快捷键  │   │   │  按输入翻译快捷键
              ▼   │   ▼
  ┌───────────┐  │  ┌───────────┐
  │ 划词翻译   │  │  │ 输入翻译   │
  │ (popup)   │  │  │ (window)  │
  └─────┬─────┘  │  └─────┬─────┘
        │        │        │
   结果展示      │   结果展示
   自动关闭      │   保持窗口
        │        │        │
        ▼        │        ▼
  ┌──────────┐   │  ┌──────────────┐
  │  空闲     │◄──┘  │ 输入/粘贴     │
  └──────────┘      │ 新文本 → 翻译  │
        ▲           └──────────────┘
        │
  ┌─────┴────────┐
  │ 剪切板监听    │ ← 翻译面板点击按钮
  │ (持续自动)   │
  └──────────────┘
```
