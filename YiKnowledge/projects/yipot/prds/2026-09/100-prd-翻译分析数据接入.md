# YiPot 翻译分析数据接入 — 需求规格

> 需求编号：YP-09-100 · 优先级：P2 · 人天：~0.2d

> **文档职责**：定义 YiPot 前端接入 YiAi 翻译分析数据的 API 层需求。

---

## 背景

YiAi 后端已实现 Provider 健康监控、小时级趋势、Provider 用量细分等分析接口。YiVad 管理后台已通过仪表盘消费这些数据。YiPot 作为桌面翻译应用，应在其 API 层中接入相同的分析端点，为未来的翻译统计 UI 提供数据基础。

## 功能需求

| 编号 | 方法 | RPC endpoint | 用途 |
|------|------|-------------|------|
| FR-1 | `getAnalytics(days)` | `translation_analytics` | 翻译量、语言分布 |
| FR-2 | `getProviderHealth(hours)` | `provider_health` | Provider 成功率、健康状态 |
| FR-3 | `feedback(params)` | `translation_feedback` | 翻译质量反馈 |

## 验收标准

- [ ] `TranslationService.getAnalytics()` 返回翻译统计数据
- [ ] `TranslationService.getProviderHealth()` 返回 Provider 健康状态
- [ ] `TranslationService.feedback()` 提交翻译质量反馈
- [ ] 所有方法错误时抛出明确的 Error
- [ ] `pnpm build` 通过
