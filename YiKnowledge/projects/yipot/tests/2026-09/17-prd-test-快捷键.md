# 快捷键系统 — 测试方案

## 功能测试

### TC-HK-001: 划词翻译快捷键

| 步骤 | 选中文本 → 按下快捷键 |
| 预期 | 翻译窗口弹出，显示选中文本翻译 |

### TC-HK-002: 输入翻译快捷键

| 步骤 | 按下快捷键 |
| 预期 | 翻译窗口弹出，输入框聚焦 |

### TC-HK-003: 截图 OCR 快捷键

| 步骤 | 按下快捷键 |
| 预期 | 进入截图模式 |

### TC-HK-004: 截图翻译快捷键

| 步骤 | 按下快捷键 → 框选区域 |
| 预期 | OCR → 翻译串联执行 |

## 自定义测试

### TC-HK-010: 修改快捷键

| 步骤 | 设置页修改划词翻译快捷键为 Ctrl+Alt+T |
| 预期 | 新快捷键生效，旧快捷键失效 |

### TC-HK-011: 冲突检测

| 步骤 | 两个功能设置相同快捷键 |
| 预期 | 提示冲突 |

### TC-HK-012: 空快捷键

| 步骤 | 清空快捷键 |
| 预期 | 该功能不再响应快捷键 |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 单键快捷键 | 仅注册 "F1" 无修饰键 | 允许注册，但提示可能与系统功能冲突 | P2 |
| TC-EDGE-02 | 多修饰键组合 | Ctrl+Alt+Shift+Meta+T | 允许注册，正常响应 | P3 |
| TC-EDGE-03 | 空快捷键 (清除) | 将某功能快捷键设为空 | 该功能不再响应任何快捷键，仅通过 UI 触发 | P1 |
| TC-EDGE-04 | macOS Cmd 与 Windows Ctrl 自动映射 | macOS 注册 Cmd+T → 配置同步到 Windows | Windows 端自动映射为 Ctrl+T | P1 |
| TC-EDGE-05 | 方向键组合 | Ctrl+→ 注册为翻译快捷键 | 允许注册，浏览器/编辑器可能先捕获 | P2 |
| TC-EDGE-06 | 数字小键盘按键 | Ctrl+NumPad1 | 与主键盘数字键区分，可独立注册 | P3 |
| TC-EDGE-07 | 功能键 F13-F24 | 注册 F13 快捷键 | 仅全键盘设备支持，笔记本需特殊处理 | P3 |
| TC-EDGE-08 | 中文字符按键 | 注册 Ctrl+中文字符 | 拒绝注册，快捷键仅支持 ASCII 可见字符 + 功能键 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 系统全局快捷键冲突 | 注册已被系统占用的快捷键 | 注册时警告"与系统快捷键冲突"，仍允许注册 | 可手动修改 |
| TC-ERR-02 | 应用内快捷键冲突 | 两个功能注册相同快捷键 | 显示红色冲突提示，阻止保存 | 修改其中一个后保存成功 |
| TC-ERR-03 | 浏览器内快捷键冲突 | Web 页面内 Ctrl+T | 应用快捷键优先级高于页面/浏览器 (需系统级注册) | — |
| TC-ERR-04 | 窗口失焦时快捷键 | 最小化应用窗口后按快捷键 | 快捷键仍可触发 (全局热键) | — |
| TC-ERR-05 | 快捷键注册失败 (OS 拒绝) | 模拟 OS API 注册失败 | 显示"快捷键注册失败，请尝试其他组合" | 更换组合后成功 |
| TC-ERR-06 | Wayland 下快捷键 | Linux Wayland 环境 | 若全局热键 API 不可用，提示"Wayland 下快捷键可能受限" | X11 下正常 |
| TC-ERR-07 | 快速重复按键 | 100ms 内按 5 次快捷键 | 防抖处理，仅触发一次 | — |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 快捷键按下到窗口弹出 | 端到端延迟 | ≤ 100ms | > 300ms | 20 次采样 |
| TC-PERF-02 | 快捷键注册耗时 | 注册系统热键 API 调用 | ≤ 5ms | > 20ms | 应用启动时批量注册 |
| TC-PERF-03 | 快捷键冲突检测 | 100 个已注册快捷键 + 新增检测 | ≤ 10ms | > 50ms | 全量比对 O(n) |
| TC-PERF-04 | 修饰键按下到主键识别 | 系统事件传播延迟 | ≤ 20ms | > 50ms | OS 级，仅监控 |
