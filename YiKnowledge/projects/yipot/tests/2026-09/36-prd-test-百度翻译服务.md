# 百度翻译服务 — 测试方案

> **文档职责**：本文档定义百度翻译 API (App ID + Secret MD5 签名) 的核心功能、签名验证、词典释义、错误处理的完整验证方案。

---

## 测试分层

| 层级 | 工具 | 覆盖 |
|------|------|------|
| L1 单元 | Vitest | MD5 签名算法、参数拼装、词典解析 |
| L2 集成 | Vitest + HTTP mock | API 请求/响应、错误码处理 |
| L3 E2E | 手动 (真实 API) | 真实百度翻译 API 调用、多语言覆盖 |

---

## 一、核心翻译功能用例

### TC-BD-01: 基本中英互译

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 配置正确的 App ID + Secret Key | — |
| 2 | 翻译 "hello world" en→zh | 返回"你好世界" |
| 3 | 翻译 "人工智能" zh→en | 返回 "artificial intelligence" |
| 4 | 测量 100 次 P95 响应时延 | ≤ 500ms |

### TC-BD-02: 单词词典查询

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 翻译单词 "algorithm" en→zh | 返回译文"算法" |
| 2 | 检查返回数据 | 包含音标 (phonetic) |
| 3 | 检查词典释义 | 包含 ≥ 2 条释义 (基础释义 + 网络释义) |
| 4 | 测试 50 个常见英文单词 | 所有单词均返回音标 + ≥ 2 条释义 |

### TC-BD-03: 多语言翻译

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 翻译 en→ja (英语→日语) | 返回日语译文 |
| 2 | 翻译 ja→ko (日语→韩语) | 返回韩语译文 |
| 3 | 翻译 en→fr (英语→法语) | 返回法语译文 |
| 4 | 测试不支持的语言对 (如 xx→yy) | 返回错误提示"不支持的语言组合" |

### TC-BD-04: 垂直领域翻译 (baidu_field)

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 启用 baidu_field 插件 (垂直领域) | — |
| 2 | 翻译科技文本 "neural network" | 返回"神经网络"(科技领域术语) |
| 3 | 翻译医药领域 "hypertension" | 返回"高血压"(医药领域术语) |

## 二、API 签名验证用例

### TC-SIGN-01: MD5 签名正确性

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 计算 `md5(appId + text + salt + secret)` | 签名与百度 API 文档一致 |
| 2 | 测试 50 次不同文本签名 | 100% API 返回 code 0 (签名通过) |
| 3 | 测试边缘字符签名 (emoji/换行/特殊符号) | 50 次全部签名通过 |
| 4 | 检查 salt 参数 | 每次请求 salt 不同 (随机数) |

### TC-SIGN-02: 错误 App ID

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 配置无效 App ID "invalid_app_id" | — |
| 2 | 触发翻译 | 显示"认证失败 (App ID)" |

### TC-SIGN-03: 错误 Secret Key

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 配置错误 Secret "wrong_secret" | — |
| 2 | 触发翻译 | 显示"认证失败 (签名不匹配)" |

## 三、边界与异常测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 空文本 | 翻译空字符串 | 不发起 API 请求，按钮禁用 | 输入文本后可用 |
| TC-ERR-02 | 超长文本 (6000 字符) | 翻译长文本 | 截断至 5000 字符并提示 | — |
| TC-ERR-03 | 不支持语言对 | 翻译 "test" xx→yy | 显示"不支持的语言组合" | 选择支持的语言对 |
| TC-ERR-04 | 网络超时 | 阻塞百度 API 域名 | 5s 超时后显示"百度翻译请求超时" | 网络恢复后正常 |
| TC-ERR-05 | API 额度耗尽 (54003) | 高频调用触发 | 显示"API 调用次数已用完" | 等待下月重置 |
| TC-ERR-06 | 并发请求 (10 并行) | 同时触发 10 次翻译 | 全部正常返回 | — |

## 四、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 翻译响应时延 (P95) | API 请求到结果展示 | ≤ 500ms (国内) | > 1s | 100 次测时 |
| TC-PERF-02 | 签名计算耗时 | MD5 签名生成 | ≤ 1ms | > 5ms | 单次计时 |
| TC-PERF-03 | 单词查询词典返回 | 音标+释义数 | 音标 + ≥ 2 条释义 | 仅译文无词典 | 50 单词测试 |
| TC-PERF-04 | 中文翻译质量 (BLEU) | en→zh 通用文本 | BLEU ≥ 0.35 | < 0.30 | 标准测试集 |

## 五、安全测试
