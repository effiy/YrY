# 快捷键注册管理 — 测试方案

## 核心功能测试

### 四大快捷键功能

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-HK-01 | 划词翻译 | 选中文本 → 按下快捷键 | 翻译窗口弹出，显示选中文本翻译 |
| TC-HK-02 | 输入翻译 | 按下快捷键 (无选区) | 翻译窗口弹出，输入框自动聚焦 |
| TC-HK-03 | 截图 OCR | 按下快捷键 | 进入截图模式，选区后 OCR 识别 |
| TC-HK-04 | 截图翻译 | 按下快捷键 | 截图模式 → 框选 → OCR → 翻译串联执行 |
| TC-HK-05 | Pot 不在前台时响应 | 切换到 VS Code → 选中文 → 快捷键 | 翻译窗口正确弹出 (全局热键) |
| TC-HK-06 | 启动时自动注册 | 重启 Pot → 直接按快捷键 | 所有 4 个快捷键立即生效 |

### 快捷键自定义

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-HK-10 | 修改快捷键 | 设置页修改划词翻译为 Ctrl+Alt+T | 新快捷键生效，旧失效 |
| TC-HK-11 | 录制快捷键 | 点击录制 → 按 Cmd+Shift+K | 显示 "Cmd+Shift+K" |
| TC-HK-12 | 清空快捷键 | 设置页清空截图 OCR 快捷键 | 该功能不再响应任何快捷键 |
| TC-HK-13 | 恢复默认 | 修改后 → 点击恢复默认 | 所有快捷键恢复为初始值 |
| TC-HK-14 | 重启后保持自定义 | 自定义快捷键 → 重启 | 自定义快捷键保持生效 |

### 冲突检测

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-HK-20 | 功能间冲突 | 两个功能设置相同快捷键 | 提示 "快捷键与 [功能名] 冲突" |
| TC-HK-21 | 系统快捷键冲突 | 设置为已有系统快捷键 (Cmd+Space) | 提示与系统快捷键冲突警告 |
| TC-HK-22 | 空快捷键不检测冲突 | 功能 A 清空，功能 B 设为任意 | 不提示冲突 |

### 平台适配

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-HK-30 | macOS Cmd 修饰键 | Cmd+Shift+T | 正确注册并响应 |
| TC-HK-31 | Windows Ctrl 修饰键 | Ctrl+Shift+T | 正确注册并响应 |
| TC-HK-32 | Linux Ctrl 修饰键 | Ctrl+Shift+T | 正确注册并响应 |
| TC-HK-33 | macOS Fn 组合键 | Fn+F1 | 正确注册并响应 |
| TC-HK-34 | 单键快捷键 | F12 | 可注册（不推荐但允许） |
| TC-HK-35 | 三键组合 | Ctrl+Alt+Shift+T | 可注册并响应 |

## 增强边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-HK-E01 | 注册失败的快捷键 | 已被系统独占的按键组合 | 提示注册失败，不崩溃 | P1 |
| TC-HK-E02 | 极短间隔触发 | 0.1 秒内连续触发快捷键 5 次 | 去抖处理，仅触发 1-2 次 | P1 |
| TC-HK-E03 | 系统切换输入法时触发 | 中文输入法 → 选中文 → 快捷键 | 不干扰输入法组合键 | P2 |
| TC-HK-E04 | 全屏游戏/应用中触发 | 全屏模式下按快捷键 | 窗口正常弹出或提示 | P2 |
| TC-HK-E05 | 快捷键 JSON 损坏 | 手动篡改配置文件 | 使用默认快捷键，不崩溃 | P1 |
| TC-HK-E06 | 快捷键值含非法字符 | 配置文件中 Key="AB!@#" | 使用默认值 | P1 |
| TC-HK-E07 | 所有快捷键清空 | 4 个快捷键全部清空 | 应用正常运行，无快捷键功能 | P2 |
| TC-HK-E08 | Rust global_shortcut_manager 报错 | 模拟注册异常 | 错误日志记录，不崩溃 | P1 |
| TC-HK-E09 | 快速切换快捷键 | 录制 → 立即修改 → 再次修改 | 每次注册覆盖旧值，不冲突 | P2 |
| TC-HK-E10 | 复制粘贴快捷键重叠 | 功能 A 使用 Cmd+T / 浏览器使用 Cmd+T | 系统快捷键优先，前后台不同 | P2 |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-HK-P01 | 注册 4 个快捷键 | 启动耗时 | ≤ 20ms | > 50ms | 冷启动计时 |
| TC-HK-P02 | 热键响应延迟 | 按键到回调触发 | ≤ 10ms | > 30ms | 50 次测量 |
| TC-HK-P03 | invoke 注册延迟 | React → Rust 注册 | ≤ 50ms | > 200ms | 20 次测量 |
| TC-HK-P04 | 冲突检测计算 | 遍历已注册快捷键 | ≤ 5ms | > 20ms | 50 次测量 |
