# 构建发布与安全隐私 — 测试方案

> **文档职责**：本文档定义三平台构建 (macOS/Windows/Linux)、自动更新、API Key 安全、macOS 权限、代码签名、隐私保护的完整验证方案。

---

## 测试分层

| 层级 | 工具 | 覆盖 |
|------|------|------|
| L1 构建 | GitHub Actions CI | 三平台构建矩阵、产物检查、代码签名 |
| L2 安全审计 | 手动 + 工具 | API Key 加密、CSP 审查、日志审计 |
| L3 安装测试 | 手动 | macOS .dmg 公证验证、Windows .msi 安装、Linux .AppImage 运行 |
| L4 自动更新 | 手动 | 更新检查、下载、安装、重启验证 |

---

## 一、构建系统核心用例

### TC-BUILD-01: 三平台构建矩阵

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | CI 触发 macOS x86_64 构建 | 构建成功，产出 .dmg |
| 2 | CI 触发 macOS arm64 构建 | 构建成功，产出 .dmg |
| 3 | CI 触发 Windows x64 构建 | 构建成功，产出 .msi + .exe |
| 4 | CI 触发 Linux x64 构建 | 构建成功，产出 .deb + .AppImage + .rpm |
| 5 | 检查所有构建产物大小 | macOS ≤ 50MB, Windows ≤ 60MB, Linux ≤ 50MB |

### TC-BUILD-02: macOS 公证验证

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | macOS Apple Developer 签名 | CI 签名步骤通过 |
| 2 | Apple 公证 (notarization) | notarization 通过 |
| 3 | `spctl --assess --verbose /Applications/Pot.app` | 返回 `accepted` |
| 4 | 双击打开 Pot.app | 不弹出"无法验证开发者"警告 |

### TC-BUILD-03: Windows 安装体验

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 运行 .msi 安装包 | 安装向导正常完成 |
| 2 | 安装后启动 Pot | 正常启动 |
| 3 | 检查程序目录 | 文件完整，无缺失 |
| 4 | 运行 .exe 绿色便携版 | 直接启动，无需安装 |
| 5 | Windows Defender 扫描 | 无病毒误报 (有代码签名时) |

### TC-BUILD-04: Linux AppImage 便携运行

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | `chmod +x Pot.AppImage` | — |
| 2 | `./Pot.AppImage` | 正常运行，无需安装依赖 |
| 3 | `dpkg -i pot.deb` | 安装成功 |
| 4 | `rpm -i pot.rpm` | 安装成功 |

## 二、自动更新用例

### TC-UPDATE-01: 更新检查

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 启动 Pot | 启动时自动检查更新，不阻塞启动 |
| 2 | 有新版本可用 | 弹出更新提示 (显示版本号 + changelog) |
| 3 | 点击"跳过此版本" | 关闭提示，不再提醒当前版本 |
| 4 | 点击"更新" | 开始下载更新包 |

### TC-UPDATE-02: 更新下载与安装

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 点击更新下载 | 显示下载进度 |
| 2 | 下载期间收起更新窗口 | 后台继续下载 |
| 3 | 下载完成 → 安装 | 自动安装 |
| 4 | 安装完成后 | 提示"重启以完成更新" |

### TC-UPDATE-03: 更新失败恢复

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 下载至 50% 时中断网络 | 下载暂停 |
| 2 | 恢复网络 | 支持断点续传，从 50% 继续 |
| 3 | 磁盘空间不足 | 提示"需要 XX MB"，不开始下载 |
| 4 | 更新安装失败 | 回滚到旧版本，不影响正常使用 |

## 三、安全与隐私用例

### TC-SECURITY-01: API Key 加密存储

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 配置百度翻译 API Key "abc123" | — |
| 2 | 检查磁盘配置文件 | 不含明文 "abc123" |
| 3 | 重启 Pot | 百度翻译正常使用 |
| 4 | 磁盘搜索 "abc123" | 0 条结果 |

### TC-SECURITY-02: 日志不含翻译内容

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 翻译敏感文本 "password is 12345" | — |
| 2 | 检查所有日志文件 | 不包含 "password is 12345" |
| 3 | 检查临时文件 | 翻译内容已清理 |

### TC-SECURITY-03: macOS 辅助功能权限

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 关闭辅助功能权限 | — |
| 2 | 触发划词翻译 | 检测到权限不足，提示"需要在系统偏好设置中授予辅助功能权限" |
| 3 | 引导点击跳转系统设置 | 打开系统偏好设置 - 辅助功能 |
| 4 | 授权后 | 划词翻译功能恢复 |

### TC-SECURITY-04: 隐私保护验证

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 使用系统 OCR 识别 | 抓包确认截图像素不发送到外部 |
| 2 | 使用 Ollama 本地翻译 | 抓包确认翻译文本不发送到外部 |
| 3 | HTTP 服务仅绑定 127.0.0.1 | 外部设备无法连接 |
| 4 | 剪切板监听关闭 | 不读取剪切板内容 |

### TC-SECURITY-05: CSP (Content Security Policy)

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 检查 Tauri 配置中 CSP 设置 | 禁止 eval / inline script |
| 2 | 检查外部连接白名单 | 仅允许已知翻译/OCR API 域名 |
| 3 | 尝试在控制台 eval 代码 | 被 CSP 阻止 |

## 四、边界与异常测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | macOS 公证失败 | CI 签名证书过期 | CI 通知开发者，不发布 | 更新证书后重新公证 |
| TC-ERR-02 | Windows Defender 误报 | 未签名 .exe 提交扫描 | 误报时向 Microsoft 提交误报申请 | 代码签名证书降低误报率 |
| TC-ERR-03 | 自动更新下载中断 | 下载中暂停/恢复网络 | 支持断点续传 | 从断点继续下载 |
| TC-ERR-04 | 磁盘空间不足 | 目标磁盘剩余 < 100MB | 提示"磁盘空间不足，需要 XX MB" | 清理空间后重试 |
| TC-ERR-05 | macOS 辅助功能权限撤销 | 系统设置中关闭权限 | 检测到权限移除，提示重新授权 | 引导至系统设置 |
| TC-ERR-06 | 构建时网络错误 | CI 中 npm/cargo 下载失败 | 自动重试 3 次 | CI 缓存策略加速 |
