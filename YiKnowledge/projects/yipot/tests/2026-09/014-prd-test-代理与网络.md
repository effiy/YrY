## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 空代理地址 | 启用代理但留空地址 | 不设置代理，直连 | P1 |
| TC-EDGE-02 | 代理端口边界 | 端口 1 / 端口 65535 | 允许有效范围，拒绝无效端口 | P2 |
| TC-EDGE-03 | 代理端口 0 或负值 | 端口 0 或 -1 | 校验拒绝 | P2 |
| TC-EDGE-04 | IPv6 代理地址 | [::1]:8080 | 正确解析 IPv6 地址 | P3 |
| TC-EDGE-05 | SOCKS5 代理 | socks5://127.0.0.1:1080 | 支持 SOCKS5 协议代理 | P2 |
| TC-EDGE-06 | HTTP 代理鉴权 | 含用户名密码的代理 | 正确传递鉴权信息 | P2 |
| TC-EDGE-07 | 代理地址含中文 | 域名含中文字符 | 正确编码处理 | P3 |
| TC-EDGE-08 | 切换网络后代理 | WiFi → 热点切换 | 代理自动重连或提示 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 代理服务器不可达 | 配置不存在的主机 | 显示"代理连接失败"，翻译请求超时 | 修正地址后正常 |
| TC-ERR-02 | 代理服务器拒绝连接 | 未启动代理服务 | 显示连接被拒绝 | 启动代理后正常 |
| TC-ERR-03 | 代理认证失败 | 错误的用户名/密码 | 显示"代理认证失败" | 修正凭据后正常 |
| TC-ERR-04 | 代理超时 | 代理转发极慢 | 显示超时错误，不无限等待 | 更换代理后正常 |
| TC-ERR-05 | 网络接口切换 | WiFi → 以太网切换 | 服务不崩溃，自动适应 | 翻译请求正常 |
| TC-ERR-06 | DNS 解析失败 | 配置不存在域名 | 显示"域名解析失败" | 修正域名后正常 |
| TC-ERR-07 | 代理与直连混用 | 部分服务启用代理，部分直连 | 各自使用配置的通道，互不干扰 | — |
| TC-ERR-08 | SSL 中间人代理 | 代理修改 HTTPS 证书 | 证书校验失败提示 | 添加信任证书后正常 |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 代理启用对翻译延迟影响 | 增量延迟 | ≤ 100ms | > 300ms | 对比直连 vs 代理 P50 |
| TC-PERF-02 | 代理配置加载 | 启动读取代理设置 | ≤ 10ms | > 50ms | 冷启动计时 |
| TC-PERF-03 | 代理切换生效速度 | 启用/禁用到生效 | ≤ 1s | > 3s | 切换后首次请求 |
| TC-PERF-04 | 网络变化检测延迟 | 网络断开到应用感知 | ≤ 5s | > 15s | OS 事件传播 |
