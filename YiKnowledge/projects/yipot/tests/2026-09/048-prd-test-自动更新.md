# 自动更新 — 测试方案

## 核心功能测试

### 更新检查

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-AU-01 | 启动时检查更新 | 启动 Pot，有新版本 | 非阻塞检查，约 30s 后弹窗提示 |
| TC-AU-02 | 启动时无更新 | 启动 Pot，已是最新版 | 无弹窗，检查动作静默完成 |
| TC-AU-03 | 当前版本获取 | 检查 "关于" 页面 | 显示当前版本号 (SemVer) |
| TC-AU-04 | 版本号比较 | 当前 1.0.0 vs 最新 1.1.0 | 正确识别为新版本 |
| TC-AU-05 | 版本号相同 | 当前 1.1.0 vs 最新 1.1.0 | 不提示更新 |
| TC-AU-06 | 预发布版本 | 当前 1.0.0 vs 最新 2.0.0-beta | 根据配置决定是否提示 |
| TC-AU-07 | GitHub Release API | 请求 GitHub API | 正确解析 tag_name 和 assets |

### 更新窗口

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-AU-10 | 显示更新信息 | 弹窗出现 | 显示当前版本、最新版本、更新日志 |
| TC-AU-11 | 下载进度 | 点击 "更新" | 进度条显示下载百分比 |
| TC-AU-12 | 下载完成 | 下载 100% | 显示 "安装并重启" 按钮 |
| TC-AU-13 | 取消下载 | 下载中 → 关闭更新窗口 | 下载中断，临时文件清理 |
| TC-AU-14 | 安装并重启 | 下载完成 → 点击安装 | 替换二进制 → 自动重启为最新版本 |
| TC-AU-15 | 更新日志 markdown 渲染 | GitHub Release body | 正确渲染 markdown 格式 |
| TC-AU-16 | 待机更新 | 下载完成后不立即安装 | 下次启动时自动安装 |

### macOS 特殊处理

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-AU-20 | macOS damaged 修复 | 更新后提示 "damaged" | updater-for-fix-runtime.mjs 自动修复 |
| TC-AU-21 | macOS 签名验证 | 更新后启动 | 无 Gatekeeper 弹窗 |

## 增强边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-AU-E01 | GitHub API 不可用 | 断网 → 启动 | 静默跳过更新检查，不报错 | P1 |
| TC-AU-E02 | GitHub API 限流 | 模拟 403 响应 | 静默跳过，不弹窗 | P1 |
| TC-AU-E03 | Release 无 assets | 空 Release | 不提示更新 | P1 |
| TC-AU-E04 | 下载中断 | 下载 50% → 网络断开 | 提示下载失败，支持重试 | P1 |
| TC-AU-E05 | 磁盘空间不足 | 磁盘满 → 下载 | 提示"磁盘空间不足，无法下载更新" | P1 |
| TC-AU-E06 | 安装包校验失败 | 下载文件哈希不匹配 | 提示"安装包校验失败"，删除文件 | P1 |
| TC-AU-E07 | 二进制替换失败 | 进程占用中 → 替换 | 标记待更新，下次启动替换 | P1 |
| TC-AU-E08 | 版本回退 | 当前 2.0.0 vs 最新 1.5.0 | 不提示"更新"(不允许降级) | P2 |
| TC-AU-E09 | 并发检查 | 手动检查中 → 自动检查触发 | 合并为一次，不重复请求 | P2 |
| TC-AU-E10 | 更新窗口重复打开 | 已有更新窗口 → 再次触发 | 聚焦已有窗口而非新建 | P2 |
| TC-AU-E11 | Proxy 网络环境 | HTTP 代理配置下检查 | 正确使用代理 | P2 |
| TC-AU-E12 | 更新结束后残留文件 | 重启后检查安装目录 | updater 脚本和下载包已清理 | P1 |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-AU-P01 | 启动时检查耗时 | API 请求时间 | ≤ 3s | > 10s | 冷启测量 |
| TC-AU-P02 | 更新检查非阻塞 | 启动到可用 | ≤ 500ms | > 1000ms | 用户可操作时间 |
| TC-AU-P03 | 下载速度显示 | 进度更新频率 | ≥ 2Hz | < 1Hz | 下载中观察 |
| TC-AU-P04 | 安装包大小 | Mac/Win/Linux | ≤ 50MB | > 100MB | 构建产物 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
