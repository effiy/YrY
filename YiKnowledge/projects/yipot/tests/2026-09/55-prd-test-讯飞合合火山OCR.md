## 一、核心功能测试

### 1.1 科大讯飞 OCR

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-XF-01 | 讯飞通用中文 | 截中文段落 → 讯飞通用 | 中文识别率 >= 95% |
| TC-XF-02 | 讯飞通用英文 | 截英文段落 → 讯飞通用 | 英文正确识别 |
| TC-XF-03 | APPID+Key+Secret | 配置讯飞三重凭证 → OCR | 认证通过，正常返回结果 |
| TC-XF-04 | 缺少 APISecret | 仅填 APPID 和 APIKey | 认证失败，提示"配置不完整" |

### 1.2 合合信息 (结构化识别)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-HH-01 | 名片识别 | 截图名片 → 合合信息 | 返回姓名、公司、职位、电话、邮箱、地址（至少 4 个有值） |
| TC-HH-02 | 证件识别 | 截图身份证 → 合合信息 | 返回证件号、姓名等结构化字段 |
| TC-HH-03 | 普通文字降级 | 截图普通文字 → 合合信息 | 空结构化字段，fallback 到通用文字 |
| TC-HH-04 | 结构化字段准确率 | 100 张名片测试 | 结构化字段准确率 >= 90% |

### 1.3 讯飞 LaTeX 公式

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-LTX-01 | 简单公式 | 截 `E=mc^2` → 讯飞 LaTeX | 返回有效 LaTeX 代码 |
| TC-LTX-02 | 复杂公式 | 截多行积分/矩阵 → 讯飞 LaTeX | LaTeX 准确率 >= 92% |
| TC-LTX-03 | KaTeX 渲染验证 | 识别结果传入 KaTeX 渲染 | 无语法错误，正确渲染为公式 |
| TC-LTX-04 | 非公式图片 | 截纯文字 → 讯飞 LaTeX | 返回空或原始文字，提示"未检测到公式" |

### 1.4 火山 OCR

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-HS-01 | 火山通用中文 | 截中文 → 火山通用 | 准确率 >= 95% |
| TC-HS-02 | 火山多语言日语 | 截日文 → 火山多语言 | 识别率 >= 90% |
| TC-HS-03 | 火山多语言韩语 | 截韩文 → 火山多语言 | 识别率 >= 90% |
| TC-HS-04 | 火山多语言阿拉伯语 | 截阿拉伯文 → 火山多语言 | 识别率 >= 90%（含 RTL） |
| TC-HS-05 | 多语言覆盖 | 枚举 100+ 语言代码列表 | 可选语言列表包含 100+ |

### 1.5 Simple LaTeX (本地)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SLTX-01 | 单行简单公式 | 截单行公式 → Simple LaTeX | 返回 LaTeX 代码，准确率 >= 85% |
| TC-SLTX-02 | 复杂公式降级 | 截多行矩阵公式 → Simple LaTeX | 返回部分结果或空，降级到讯飞 LaTeX |
| TC-SLTX-03 | 离线可用 | 断网 → Simple LaTeX | 正常识别（纯本地） |
| TC-SLTX-04 | 20 token 限制 | 截含 30+ token 的公式 | 仅识别前 20 token，标注不完整 |

### 1.6 二维码 (jsQR)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-QR-01 | 标准 URL 二维码 | 截含 URL 的 QR Code → 识别 | 解码成功，返回 URL |
| TC-QR-02 | 中文内容二维码 | 截含中文文字的 QR Code | 中文正确解码 |
| TC-QR-03 | 模糊二维码 | 截低分辨率 QR Code | 解码失败，提示"无法识别二维码" |
| TC-QR-04 | 破损二维码 | 截破损/遮挡的 QR Code | 解码失败或置信度低 |
| TC-QR-05 | 非 QR Code 格式 | 截图 Data Matrix / PDF417 | 跳过，提示"仅支持 QR Code" |
| TC-QR-06 | 响应速度 | 100 次标准 QR Code 识别 | P95 < 500ms |
