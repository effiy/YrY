---

## 一、HTTP Server 测试

### TC-HTTP-001: 服务启动

| 步骤 | 启动 Pot → `curl http://127.0.0.1:60828/` |
|------|------------------------------------------|
| 预期 | 服务正常响应 |

### TC-HTTP-002: 翻译接口

| 步骤 | `curl -X POST http://127.0.0.1:60828/translate -d '{"text":"hello","from":"en","to":"zh"}'` |
|------|-------------------------------------------------------------------------------------------|
| 预期 | 弹出翻译窗口，返回翻译结果 |

### TC-HTTP-003: 划词翻译接口

| 步骤 | 选中文本 → `curl .../selection_translate` |
|------|-----------------------------------------|
| 预期 | 读取选中文本并翻译 |

### TC-HTTP-004: 输入翻译接口

| 步骤 | `curl .../input_translate -d '{"text":"hello"}'` |
|------|------------------------------------------------|
| 预期 | 打开翻译窗口，填充文本 |

### TC-HTTP-005: OCR 接口

| 步骤 | `curl .../ocr_recognize?screenshot=true` |
|------|----------------------------------------|
| 预期 | 触发截图 OCR |

### TC-HTTP-006: 配置接口

| 步骤 | `curl .../config` |
|------|-----------------|
| 预期 | 打开配置窗口 |

## 五、增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 端口边界 1 | 设置端口 1024 (系统保留边界) | 允许但有提示 | P2 |
| TC-EDGE-02 | 端口边界 2 | 设置端口 65535 (最大值) | 允许 | P2 |
| TC-EDGE-03 | 端口 0 或负值 | 设置端口 0 或 -1 | 校验拒绝，提示"无效端口号" | P1 |
| TC-EDGE-04 | 请求体为空 | POST /translate 空 body | 返回 400 "请求体不能为空" | P1 |
| TC-EDGE-05 | 请求体超长 | POST 10MB 文本到 /translate | 返回 413 或截断处理 | P1 |
| TC-EDGE-06 | 非 JSON Content-Type | POST text/plain | 返回 415 "仅支持 application/json" | P2 |
| TC-EDGE-07 | CLI 参数缺省 | `pot --translate` 无文本 | 空翻译窗口或提示缺少参数 | P2 |
| TC-EDGE-08 | CLI 未知参数 | `pot --unknown-flag` | 显示帮助信息 | P3 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 端口被其他程序占用 | 启动另一个占用 60828 的程序 | 服务尝试自动换端口或提示 | 释放端口后正常 |
| TC-ERR-02 | 并发请求压力 | 100 个并发 POST /translate | 正常排队处理，不崩溃 | 请求队列清空后正常 |
| TC-ERR-03 | 慢客户端攻击 | 客户端极慢发送请求体 | 超时断开，不影响其他客户端 | 正常客户端仍可用 |
| TC-ERR-04 | HTTP Server 运行时关闭 | 关闭 Pot → 客户端请求中 | 优雅关闭，处理完当前请求 | 无需恢复 |
| TC-ERR-05 | 请求方法错误 | GET /translate | 返回 405 Method Not Allowed | — |
| TC-ERR-06 | 路径不存在 | GET /nonexistent | 返回 404 | — |
| TC-ERR-07 | 请求体中 unknown 字段 | POST 含额外字段的 JSON | 忽略额外字段，正常处理 | — |

## 六、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | HTTP Server 启动时延 | 启动到可接受请求 | ≤ 500ms | > 2s | 冷启动计时 |
| TC-PERF-02 | /translate 响应时间 | 端到端 (含翻译服务) | ≤ 1s | > 2s | P95 100 次 |
| TC-PERF-03 | / 健康检查响应 | GET / | ≤ 5ms | > 20ms | 100 次采样 |
| TC-PERF-04 | 并发 50 请求 | 全部完成时间 | ≤ 3s | > 10s | 压力测试 |
| TC-PERF-05 | HTTP Server 内存占用 | 处理 1000 请求后 | ≤ 50MB 增量 | > 100MB | 对比前后 |
| TC-PERF-06 | 请求队列排队延迟 | 高并发下 P95 | ≤ 500ms | > 2s | 50 并发 |

## 七、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 仅回环地址绑定 | 外部设备访问 http://<IP>:60828 | 连接被拒绝 | P0 |
| TC-SEC-02 | 请求体限制 | 发送 1GB 数据 | 拒绝请求，不耗尽内存 | P1 |
| TC-SEC-03 | 无认证 → 本地访问不受限 | 本地 curl 不提供 token | 正常响应（本地信任模型） | P1 |
| TC-SEC-04 | CLI 参数注入 | `pot --translate "$(cat /etc/passwd)"` | 不执行 shell 命令，参数安全处理 | P1 |
| TC-SEC-05 | 路径遍历 | curl /../../etc/passwd | 返回 404，不暴漏系统文件 | P1 |
| TC-SEC-06 | HTTP Header 注入 | 请求含恶意 Header | 正确转义，不反射到响应 | P2 |
| TC-SEC-07 | 超时连接自动断开 | 建立连接但不发送数据 | 30s 后自动断开 | P2 |
| TC-SEC-08 | 翻译内容不记录到日志 | POST 翻译 → 检查 HTTP 日志 | 请求参数中的 text 不记录 | P1 |
