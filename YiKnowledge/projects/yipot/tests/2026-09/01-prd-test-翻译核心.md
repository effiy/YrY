# 翻译核心 — 测试方案

> **文档职责**：本文档定义翻译核心功能的验证方案。

---

## 一、划词翻译测试

### TC-TR-001: 基本划词翻译

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 在浏览器中选中一段英文 | 文本被选中 |
| 2 | 按下 Ctrl+Shift+T | 翻译浮窗弹出 |
| 3 | 查看翻译结果 | 显示中文翻译 |
| 4 | 点击浮窗外部 | 浮窗关闭 |

### TC-TR-002: 多接口并行翻译

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 启用百度翻译和 Google 翻译 | 两个服务均启用 |
| 2 | 选中文本触发翻译 | 浮窗弹出 |
| 3 | 查看结果面板 | 百度结果 + Google 结果并排显示 |

### TC-TR-003: 语言检测

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 选中英文文本触发翻译 | 自动检测为 en → zh |
| 2 | 选中中文文本触发翻译 | 自动检测为 zh → en |
| 3 | 手动切换目标语言为日语 | 翻译为 ja |

---

## 二、输入翻译测试

### TC-TI-001: 手动输入翻译

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 按 Ctrl+Shift+F | 翻译窗口弹出 |
| 2 | 输入 "Hello World" | 输入框显示文本 |
| 3 | 按 Enter | 显示中文翻译 |

### TC-TI-002: 语言手动选择

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 打开翻译窗口 | — |
| 2 | 切换源语言为法语 | 语言选择器显示 fr |
| 3 | 输入法语文本并翻译 | 正确识别为法语 |

---

## 三、剪切板监听测试

### TC-CL-001: 剪切板自动翻译

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 点击剪切板监听按钮 | 状态变为"监听中" |
| 2 | 复制一段英文文本 | 翻译结果自动更新 |
| 3 | 再次点击监听按钮 | 状态变为"已停止" |
| 4 | 复制文本 | 不再触发翻译 |

## 四、边界与异常测试

### TC-TR-E01: 空文本

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 选中空内容触发翻译 | 提示"未选中文本" |

### TC-TR-E02: 网络异常

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 断开网络 | — |
| 2 | 触发翻译 | 显示"翻译失败"错误提示 |

### TC-TR-E03: API 配置缺失

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 启用未配置 API Key 的服务 | — |
| 2 | 触发翻译 | 该服务显示"未配置 API Key" |

### TC-TR-E04: 多接口部分失败

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 启用 3 个翻译服务，其中 1 个 API Key 错误 | — |
| 2 | 触发翻译 | 2 个成功结果正常显示，1 个显示错误 |

## 五、增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 空文本翻译 | 空字符串 "" | 提示"未选中文本" | P1 |
| TC-EDGE-02 | 单字符翻译 | "a" | 返回翻译结果 | P2 |
| TC-EDGE-03 | 超长文本 (10000 字) | 10000 字英文本 | 正常翻译或截断提示，不崩溃 | P1 |
| TC-EDGE-04 | 特殊字符 | "!@#$%^&*()" | 原样返回或忽略，不崩溃 | P2 |
| TC-EDGE-05 | 混合语言 | "Hello 你好 Bonjour" | 检测主语言或分段处理 | P2 |
| TC-EDGE-06 | 纯数字 | "12345.67" | 原样返回，不翻译 | P3 |
| TC-EDGE-07 | Emoji 文本 | "Hello 😊 World 🌍" | 保留 Emoji，仅翻译文字 | P3 |
| TC-EDGE-08 | 不可见字符 | "\n\t\r   " | 过滤空白后相当于空文本 | P3 |
| TC-EDGE-09 | 全角/半角混合 | "Ｈｅｌｌｏ World" | 正确归一化后翻译 | P3 |
| TC-EDGE-10 | Unicode 控制字符 | 含 RTL override 字符的文本 | 不影响翻译结果 | P3 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 网络断开 | 断网后触发翻译 | 显示"网络连接失败"，不崩溃 | 恢复网络后正常 |
| TC-ERR-02 | API 超时 | Mock 10s 延迟 | 显示"请求超时，请重试" | 其他服务仍可用 |
| TC-ERR-03 | API 返回非 JSON | Mock HTML 响应 | 显示"服务异常"或解析错误 | 不影响其他服务 |
| TC-ERR-04 | API Key 过期 | 使用已失效的 Key | 显示"认证失败"或 API 错误 | 该服务标记为错误状态 |
| TC-ERR-05 | 并发请求过多 | 连续选中 10 次快速换词 | 防抖处理，仅执行最后一次 | 历史请求自动取消 |
| TC-ERR-06 | 不支持的语言对 | 选择 zh→不存在的目标语言 | 显示"不支持的语言对" | — |
| TC-ERR-07 | 相同源语言和目标语言 | 设置 en→en | 原样返回或提示无效 | — |
| TC-ERR-08 | 选中包含富文本的文本 | 从 Word 复制含格式文本 | 自动提取纯文本后翻译 | — |

## 六、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 划词翻译端到端时延 | P50/P95/P99 | ≤ 300/500/800ms | > 600/1000/1500ms | 100 次采样，中文 50 + 英文 50 |
| TC-PERF-02 | 输入翻译端到端时延 | P50/P95 | ≤ 300/500ms | > 600/1000ms | 50 次采样 |

| TC-PERF-04 | 剪切板监听延时 | 复制到翻译展示 | ≤ 1s | > 2s | 20 次采样 |
| TC-PERF-05 | 浮窗打开/关闭响应 | 操作到完成 | ≤ 100ms | > 300ms | 高频操作 50 次 |

## 七、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | API Key 不通过 URL 传递 | 抓包检查翻译请求 | API Key 在请求体中，URL 中不可见 | P0 |
| TC-SEC-02 | HTTPS 强制 | 配置 HTTP 的 API 地址 | 提示建议使用 HTTPS | P1 |
| TC-SEC-03 | 翻译结果不残留 | 翻译敏感文本 → 关闭浮窗 → 重新选中其他文本 | 前次翻译内容不在内存中残留 | P2 |
| TC-SEC-04 | 浮窗不记录选中文本 | 选中密码 → 触发翻译后取消 | 日志和缓存中不含选中文本 | P1 |
