# 安全加密存储 — 测试方案

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-SEC-01 | API Key 磁盘检查 | 非明文存储 |
| TC-SEC-02 | 跨机解密 | 配置文件复制到其他机器无法解密 |
| TC-SEC-03 | 日志不含 Key | 全文搜索 API Key 值 |
| TC-SEC-04 | 备份不含明文 Key | 导出 JSON 检查 |
| TC-SEC-05 | AES 加密强度 | AES-256-CBC 验证 |

## 性能基准

| 指标 | 基准 |
|------|------|
| 加密 | < 1ms |
| 解密 | < 1ms |

## 边界与异常测试

| 场景 | 操作步骤 | 预期结果 |
|------|----------|----------|
| 加密后手动修改密文 | 用十六进制编辑器修改加密配置文件 | 解密失败，配置重置为默认 |
| 跨平台解密 | macOS 加密的配置复制到 Windows | 无法解密，需重新输入 API Key |
| 空配置加密 | 所有 API Key 为空 | 加密正常执行，无崩溃 |
| 极长 API Key（10000 字符） | 输入超长 Key 后加密 | 加密解密正常，无截断 |
| 并发读写配置文件 | 两个设置页面同时修改并保存 | 后者覆盖前者，数据不损坏 |
| 磁盘空间不足（加密写入时） | 模拟磁盘满（macOS `dd`） | 写入失败提示，旧配置不丢失 |
| 旧版本无加密配置迁移 | 读取旧版明文配置文件 | 自动加密迁移，删除明文备份 |
| 多进程同时解密 | 主进程 + CLI 进程同时读取 | 无竞态，解密结果一致 |

## 性能基准测试

| 场景 | 测试方法 | 基准 |
|------|----------|------|
| 单字段 AES-256-CBC 加密 | `crypto.subtle.encrypt` 调用完成 | < 1ms |
| 单字段 AES-256-CBC 解密 | `crypto.subtle.decrypt` 调用完成 | < 1ms |
| 完整配置文件加密（20 个 Key） | 逐字段加密总时间 | < 10ms |
| 密钥派生（PBKDF2） | `deriveKey` 首次调用 | < 100ms |
| 配置文件读取（含解密） | 应用启动时完整流程 | < 50ms |

## 回归测试清单

- [ ] 磁盘上 API Key 非明文存储（`strings` 命令验证）
- [ ] 跨机器复制加密文件无法解密
- [ ] 日志中不出现 API Key 明文（grep 验证）
- [ ] 备份导出文件不含明文 Key
- [ ] 配置重置后重新加密正常
- [ ] AES-256-CBC 算法验证（已知明文/密文对照）
