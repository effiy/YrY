# 配置管理与备份 — 测试方案

---

## 一、配置存储测试

### TC-CFG-001: 配置持久化

| 步骤 | 修改任意配置 → 重启应用 |
|------|----------------------|
| 预期 | 所有修改的配置保持不变 |

### TC-CFG-002: 默认值回退

| 步骤 | 删除配置文件 → 启动应用 |
|------|----------------------|
| 预期 | 使用默认配置，无崩溃 |

### TC-CFG-003: 并发写入

| 步骤 | 快速连续修改多个配置项 |
|------|----------------------|
| 预期 | 所有修改正确保存，不丢失 |

### TC-CFG-004: 配置迁移

| 步骤 | 从旧版本升级 → 启动 |
|------|-------------------|
| 预期 | 旧配置兼容或提示迁移 |

## 二、备份测试

### TC-BK-001: 本地导出 JSON

| 步骤 | 备份 → 选择本地 → 导出 |
|------|----------------------|
| 预期 | 生成包含完整配置的 JSON 文件 |

### TC-BK-002: 本地导入 JSON

| 步骤 | 清除配置 → 导入之前导出的 JSON |
|------|----------------------------|
| 预期 | 配置完全恢复 |

### TC-BK-003: 选择性备份

| 步骤 | 仅备份服务配置（不含快捷键）|
|------|--------------------------|
| 预期 | JSON 仅含服务配置 |

### TC-BK-004: WebDAV 上传

| 前提 | 搭建 WebDAV 服务器 |
|------|-------------------|
| 步骤 | 配置 URL + 用户名 + 密码 → 上传 |
| 预期 | 配置文件上传到 WebDAV |

### TC-BK-005: WebDAV 下载

| 前提 | WebDAV 已有备份 |
|------|---------------|
| 步骤 | 配置 WebDAV → 下载配置 |
| 预期 | 配置从 WebDAV 恢复到本地 |

### TC-BK-006: 阿里云 OSS 同步

| 步骤 | 配置 OSS Bucket → 上传/下载 |
|------|--------------------------|
| 预期 | 配置文件正常同步 |

### TC-BK-007: 备份失败处理

| 步骤 | 错误的 WebDAV 密码 → 导出 |
|------|------------------------|
| 预期 | 显示错误提示，不崩溃 |

## 五、增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 配置文件为空 | 配置文件内容为 {} | 使用所有默认配置 | P1 |
| TC-EDGE-02 | 配置文件超限 (10MB) | 向配置注入大量无效数据 | 加载时校验大小，提示配置异常 | P2 |
| TC-EDGE-03 | 配置项值为极限 | 字号 999，窗口位置 (-9999, -9999) | 值被限制到合理范围 | P2 |
| TC-EDGE-04 | 备份大文件 (100 个服务) | 配置全部服务 → 导出 | JSON 文件 < 5MB，导出成功 | P2 |
| TC-EDGE-05 | WebDAV URL 含中文 | URL 路径含中文字符 | URL 正确编码处理 | P2 |
| TC-EDGE-06 | OSS 大文件上传 | 导出 10MB+ 配置包 | 分片上传或提示限制 | P3 |
| TC-EDGE-07 | 同名备份覆盖 | 再次导出到相同路径 | 提示覆盖或自动更名 | P3 |
| TC-EDGE-08 | 选择性备份勾选全部/全不选 | 全选 → 导出 / 全不选 → 导出 | 全选=完整备份，全不选=提示至少选一项 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 配置文件权限错误 | chmod 000 → 启动 | 创建新配置文件（默认值），提示旧文件无法读取 | 恢复权限后可读取 |
| TC-ERR-02 | 配置写入磁盘满 | 填满磁盘 → 修改配置 | 提示"保存失败" | 清理空间后正常 |
| TC-ERR-03 | 导入非 Pot 格式 JSON | 导入随机 JSON 文件 | 校验格式，提示"不是有效的配置文件" | — |
| TC-ERR-04 | 导入旧版本 (v1) 配置 | 导入 v1 格式配置 | 兼容迁移或提示升级 | 迁移后正常使用 |
| TC-ERR-05 | WebDAV 密码错误 | 配置错误密码 → 同步 | 显示"认证失败" | 修改密码后成功 |
| TC-ERR-06 | WebDAV SSL 证书过期 | 自签名证书过期 | 显示证书错误，提供忽略选项 | 更新证书后正常 |
| TC-ERR-07 | OSS AccessKey 过期 | OSS 凭证过期 → 同步 | 显示"认证失败" | 更新凭证后成功 |
| TC-ERR-08 | 配置迁移中断 | 升级过程中应用崩溃 | 下次启动恢复迁移流程 | 迁移完成后正常 |
| TC-ERR-09 | 并发读写配置 | 外部 HTTP + UI 同时修改配置 | 最后一次写入生效，不损坏文件 | — |

## 六、性能基准测试

| TC-PERF-05 | 本地导入 | 导入含 100 服务配置的 JSON | ≤ 1s | > 3s | 含文件对话框 |
| TC-PERF-06 | WebDAV 上传 | 局域网 WebDAV | ≤ 3s | > 10s | 100KB 配置包 |
| TC-PERF-07 | 恢复出厂设置 | 清空所有配置 | ≤ 500ms | > 1s | 含 UI 刷新 |

## 七、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | API Key 明文检查 | 导出备份 → 打开 JSON | 所有 API Key/Secret 加密存储 | P0 |
| TC-SEC-02 | 导入文件来源安全 | 导入含恶意字段的 JSON | 仅加载已知配置项，忽略未知字段 | P1 |
| TC-SEC-03 | 配置文件权限 | 检查配置文件权限位 | 用户可读写，其他用户不可读 (chmod 600) | P1 |
| TC-SEC-04 | WebDAV HTTPS 强制 | 使用 HTTP WebDAV 地址 | 对包含敏感配置的上传建议 HTTPS | P2 |
| TC-SEC-05 | 恢复出厂设置确认 | 误点击恢复出厂 | 需二次确认，不可逆操作有警告 | P1 |
| TC-SEC-06 | 配置备份不包含临时数据 | 对比导出前后磁盘增量 | 不导出翻译历史/临时日志 | P2 |
