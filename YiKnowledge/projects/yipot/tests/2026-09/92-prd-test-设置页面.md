# 设置页面 — 测试方案

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-CFG-01 | 侧边栏导航 | 10 个页面正常切换 |
| TC-CFG-02 | 语言切换 | 即时生效，持久化 |
| TC-CFG-03 | 主题切换 | 3 种模式正常 |
| TC-CFG-04 | 字体选择 | 列表正确，即时生效 |
| TC-CFG-05 | 服务管理 | 启用/禁用/配置 |
| TC-CFG-06 | 快捷键录制 | 检测冲突，即时生效 |
| TC-CFG-07 | 备份导出导入 | JSON 完整 |

## 回归

- [ ] 所有设置项持久化
- [ ] 设置页不阻塞翻译功能

## 边界与异常测试

| 场景 | 操作步骤 | 预期结果 |
|------|----------|----------|
| 配置文件 JSON 语法错误 | 手动在配置文件中写入 `{invalid}` | 回退默认配置，日志记录解析错误 |
| 快捷键设置为系统保留键 | 录制 `Cmd+Q` (macOS 退出) | 提示"此快捷键为系统保留" |
| 语言切换至 RTL 语言（阿拉伯语） | 设置语言为 Arabic | 布局自动切换为 RTL，无样式错乱 |
| 字体大小设为极端值（1px / 200px） | 手动输入越界值 | 限制在 8-72px 范围 |
| 服务配置保存时网络断开 | 编辑服务配置点保存 | 本地持久化成功，服务状态标记"待同步" |
| 同时打开两个设置页面（多窗口） | 两次进入设置页面 | 后保存的配置生效，不冲突 |
| 透明窗口透明度设为 0%（完全不可见） | 拖动滑块至最左 | 最小锁定在 10%，防止窗口不可操作 |

## 性能基准测试

| 场景 | 测试方法 | 基准 |
|------|----------|------|
| 设置页面首次加载 | `React.Profiler` onRender 回调 | < 300ms |
| 侧边栏页面切换 | 点击侧边栏到子页面渲染完成 | < 100ms |
| 配置保存到磁盘 | `onChange` 触发到 debounce 写入完成 | < 350ms (含 300ms debounce) |
| 配置文件启动加载 | 应用启动 → 配置注入 Pinia | < 50ms |
| 快捷键录制响应 | 按键按下到 UI 显示 | < 16ms (1 帧) |

## 回归测试清单

- [ ] 服务管理：启用/禁用/配置均持久化
- [ ] 备份导入：JSON 完整且字段类型正确
- [ ] 配置重置：所有值恢复默认
