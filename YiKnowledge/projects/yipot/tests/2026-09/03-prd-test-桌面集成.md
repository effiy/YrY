# 桌面集成 — 测试方案

> **文档职责**：本文档定义桌面集成功能（快捷键、托盘、窗口、备份）的验证方案。

---

## 一、全局快捷键测试

### TC-HK-001: 默认快捷键功能

| 快捷键 | 预期 |
|--------|------|
| Ctrl+Shift+T | 触发划词翻译 |
| Ctrl+Shift+F | 弹出输入翻译窗口 |
| Ctrl+Shift+O | 进入截图 OCR 模式 |
| Ctrl+Shift+S | 进入截图翻译模式 |

### TC-HK-002: 快捷键自定义

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 打开设置 → 快捷键 | 显示当前快捷键列表 |
| 2 | 点击修改划词翻译快捷键 | 进入录制模式 |
| 3 | 按下 Ctrl+Alt+T | 新快捷键保存 |
| 4 | 按下新快捷键 | 触发划词翻译 |

### TC-HK-003: 快捷键冲突检测

| 步骤 | 设置两个功能使用相同快捷键 |
|------|--------------------------|
| 预期 | 提示快捷键冲突 |

---

## 二、系统托盘测试

### TC-TR-001: 托盘基础功能

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 启动 Pot | 系统托盘出现图标 |
| 2 | 右键托盘图标 | 弹出菜单 |
| 3 | 选择"输入翻译" | 弹出翻译窗口 |
| 4 | 选择"设置" | 弹出设置窗口 |

### TC-TR-002: 托盘退出

| 步骤 | 右键托盘 → 退出 |
|------|---------------|
| 预期 | 应用完全退出，托盘图标消失 |

---

## 三、配置备份测试

### TC-BK-001: 本地备份恢复

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 配置 3 个翻译服务 | — |
| 2 | 导出配置为 JSON 文件 | 文件生成成功 |
| 3 | 清除所有配置 | — |
| 4 | 导入之前的 JSON 文件 | 3 个服务配置恢复 |

### TC-BK-002: WebDAV 同步

| 步骤 | 配置 WebDAV 服务器 → 点击同步 |
|------|----------------------------|
| 预期 | 配置上传到 WebDAV，另一设备可拉取 |

---

## 四、窗口管理测试

### TC-WN-001: 窗口置顶

| 步骤 | 打开翻译窗口 → 点击其他应用 |
|------|--------------------------|
| 预期 | 翻译窗口始终在最前 |

### TC-WN-002: 窗口位置记忆

| 步骤 | 拖动翻译窗口到指定位置 → 关闭 → 重新打开 |
|------|---------------------------------------|
| 预期 | 窗口出现在上次关闭的位置 |

## 六、增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 快捷键注册到系统保留组合 | 注册 Ctrl+Alt+Del | 提示"快捷键已被系统占用" | P1 |
| TC-EDGE-02 | 快捷键清空 | 删除所有快捷键 | 该功能仅可通过托盘/菜单触发 | P2 |
| TC-EDGE-03 | 托盘图标缩放 | 高 DPI 显示器 | 托盘图标清晰不模糊 | P2 |
| TC-EDGE-04 | 窗口拖动到屏幕外 | 拖到屏幕边缘外 | 窗口位置修正回可视区域 | P3 |
| TC-EDGE-05 | 最小窗口尺寸 | 窗口缩小到 0 | 窗口有最小尺寸限制 | P3 |
| TC-EDGE-06 | WebDAV 路径含空格 | WebDAV URL 含空格 | 正确处理 URL 编码 | P2 |
| TC-EDGE-07 | 备份文件命名冲突 | 同一文件名导出两次 | 自动追加时间戳或序号 | P3 |
| TC-EDGE-08 | 多显示器窗口位置 | 主显示器变更后 | 窗口不出现在已移除的显示器 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 快捷键注册失败 | 模拟系统 API 失败 | 提示注册失败，功能仍可通过托盘/菜单使用 | 重启或修改后重试 |
| TC-ERR-02 | 系统托盘不可用 (无桌面环境) | 远程 SSH 终端启动 | 降级为纯窗口模式，托盘功能提示不可用 | 正常桌面环境恢复 |
| TC-ERR-03 | WebDAV 连接超时 | Mock WebDAV 10s 超时 | 显示连接超时，不影响本地配置 | 修改配置后重试 |
| TC-ERR-04 | WebDAV 空间不足 | WebDAV 服务器限额满 | 显示"存储空间不足" | 清理空间后同步 |
| TC-ERR-05 | 备份文件损坏 | 导入被手工修改的 JSON | 校验失败，提示文件格式无效 | 修复后重试 |
| TC-ERR-06 | 窗口被其他应用遮挡后点击 | 翻译浮窗被遮挡 → 点击任务栏图标 | 浮窗提升到最前 | 置顶策略恢复 |
| TC-ERR-07 | 外部程序同时调用 HTTP 接口 | 2 个外部程序并发调用 /translate | 正确处理并发，顺序响应 | 无状态错乱 |

## 七、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 快捷键按下到浮窗显示 | 端到端时延 | ≤ 200ms | > 400ms | 30 次采样取 P95 |
| TC-PERF-02 | 托盘菜单弹出响应 | 右键到菜单显示 | ≤ 100ms | > 300ms | 10 次采样 |
| TC-PERF-03 | 窗口拖动流畅度 | FPS | ≥ 30fps | < 20fps | 拖拽窗口观察 |
| TC-PERF-04 | 窗口打开动画 | 动画时长 | ≤ 200ms | > 500ms | 录屏逐帧分析 |
| TC-PERF-05 | 配置备份导出 (大配置) | 100 个服务配置导出 | ≤ 2s | > 5s | 模拟大配置 |
| TC-PERF-06 | WebDAV 同步时延 | 上传/下载 | ≤ 3s | > 10s | 局域网 WebDAV |

## 八、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 托盘菜单敏感操作确认 | 右键托盘 → 退出 | 需二次确认或可配置 | P2 |
| TC-SEC-02 | 备份文件不含明文 API Key | 导出配置 → 打开 JSON 查看 | API Key 加密存储 | P0 |
| TC-SEC-03 | WebDAV 密码加密存储 | 检查配置存储 | WebDAV 密码不以明文存储 | P1 |
| TC-SEC-04 | 快捷键仅限全局注册 | 其他应用检查 | 快捷键不注入到其他应用 | P1 |
| TC-SEC-05 | 窗口不捕获全屏应用内容 | 全屏游戏中触发翻译 | 不干扰全屏应用 | P2 |
