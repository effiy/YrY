# 百度翻译 — 测试方案

## 功能测试

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-BD-01 | 中译英 | "你好世界" zh→en | 返回 "Hello World" |
| TC-BD-02 | 英译中 | "Hello World" en→zh | 返回 "你好世界" |
| TC-BD-03 | 单词释义 | "hello" en→zh | 返回译文 + 音标 + 释义 ≥ 2 条 |
| TC-BD-04 | 签名错误 | 错误 Secret | 显示 "Secret 错误 (54001)" |
| TC-BD-05 | App ID 无效 | 错误 App ID | 显示 "App ID 无效 (52003)" |

## 边界测试

| 编号 | 场景 | 预期 |
|------|------|------|
| TC-BD-E01 | 空文本 | 不发起请求 |
| TC-BD-E02 | 5000+ 字符 | 截断提示 |
| TC-BD-E03 | 特殊字符 `<>&` | 正常翻译 |

## 性能基准

| 缓存命中 | < 5ms | 50 次命中 |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 空文本 | 空字符串 "" | 不发起请求，前端拦截 | P1 |
| TC-EDGE-02 | 单字符 | "a" | 返回该字符的翻译 | P3 |
| TC-EDGE-03 | 超长文本 (6000+ 字符) | 6000+ 字符 | 截断提示或正常返回 | P1 |
| TC-EDGE-04 | HTML 文本 | "<p>Hello</p>" | 正常翻译或去除标签 | P2 |
| TC-EDGE-05 | 纯数字 | "12345" | 原样返回 | P3 |
| TC-EDGE-06 | Emoji 混合 | "Hello 😊" | 保留 Emoji，翻译文字 | P3 |
| TC-EDGE-07 | 不支持的语言对 | 中文→冰岛语 | 显示"不支持的语言方向" | P2 |
| TC-EDGE-08 | 百度未开通接口权限 | 未开通翻译 API 的账号 | 显示"未开通此接口权限" | P1 |
| TC-EDGE-09 | 全角/半角混合 | "Ｈｅｌｌｏ World" | 正确归一化后翻译 | P3 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | AppID 不存在 | 使用不存在的 AppID | 显示"App ID 无效 (52003)" | 修正 AppID 后正常 |
| TC-ERR-02 | 签名错误 | 篡改 Secret | 显示"Secret 错误 (54001)" | 修正 Secret 后正常 |
| TC-ERR-03 | 超过每日配额 | 达到免费额度上限 | 显示"当日翻译额度已用完" | 次日重置后正常 |
| TC-ERR-04 | 并发限制触发 | 短时间内高频请求 | 显示"请求过于频繁"，自动降速 | 频率控制后正常 |
| TC-ERR-05 | 百度服务降级 | 百度 API 返回 500/503 | 显示"百度翻译服务暂时不可用" | 恢复后正常 |
| TC-ERR-06 | 网络超时 | Mock 超时无响应 | 显示超时提示，不阻塞其他服务 | 网络恢复后正常 |
| TC-ERR-07 | 返回格式异常 | Mock 非标准响应 | 显示"解析翻译结果失败" | 不影响其他服务 |
| TC-ERR-08 | DNS 解析失败 | fanyi-api.baidu.com 不可达 | 显示"网络连接失败" | DNS 恢复后正常 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | AppID/Secret 加密存储 | 检查配置存储文件 | 不以明文存储 | P0 |
| TC-SEC-02 | 签名不在 URL 暴露 | 抓包检查 | 签名在 POST body，URL 无敏感参数 | P0 |
| TC-SEC-03 | HTTPS 强制连接 | 配置 HTTP 地址尝试连接 | 提示建议使用 HTTPS | P1 |
| TC-SEC-04 | 翻译内容不写磁盘 | 翻译含敏感词后检查 | 翻译请求文本不写入磁盘缓存 | P1 |
| TC-SEC-05 | Salt 随机数防重放 | 连续两次相同请求抓包 | 签名不同 (salt 随机) | P2 |
| TC-SEC-06 | AppID 不写日志 | 检查日志文件 | 日志中不含 AppID/Secret | P1 |
