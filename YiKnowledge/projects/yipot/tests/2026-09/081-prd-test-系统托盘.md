# 系统托盘 — 测试方案

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-TRAY-01 | 托盘图标显示 | 启动后托盘出现 |
| TC-TRAY-02 | 右键菜单 | 7 个菜单项可用 |
| TC-TRAY-03 | macOS 无 Dock 图标 | Activity Monitor 验证 |
| TC-TRAY-04 | 单实例检测 | 重复启动弹通知 |
| TC-TRAY-05 | 退出 | 进程完全终止 |

## 平台验证

| 测试项 | macOS | Windows | Linux |
|--------|-------|---------|-------|
| 托盘图标 | ✓ | ✓ | ✓ |
| 右键菜单 | ✓ | ✓ | ✓ |
| 无 Dock (macOS) | ✓ | — | — |

## 边界与异常测试

| 场景 | 操作步骤 | 预期结果 |
|------|----------|----------|
| 系统托盘区域已满（Windows） | Win 任务栏图标溢出区 | 图标隐藏在溢出区，右键仍可用 |
| 系统托盘进程崩溃恢复 | `kill -9` 托盘进程后重启 | 自动重新注册托盘图标 |
| 右键菜单打开时窗口失焦 | 打开右键菜单后点击其他窗口 | 菜单关闭，不残留 |
| 双显示器切换 | 笔记本外接/断开显示器 | 托盘图标不消失 |
| 高 DPI 缩放（200%+） | Windows 250% 缩放 | 图标清晰不模糊，菜单位置正确 |
| 系统主题切换（暗/亮） | macOS 切换暗色模式 | 托盘图标切换为对应色版本 |
| 快速重复右键（100ms 内双击） | 连续快速右键点击 | 无菜单闪烁，仅打开一个菜单 |
| 托盘图标资源缺失 | 删除图标文件 | 显示默认占位图标，不崩溃 |

## 性能基准测试

| 场景 | 测试方法 | 基准 |
|------|----------|------|
| 托盘图标注册 | `performance.now()` 测量 `setup_tray()` | < 200ms |
| 右键菜单弹出 | 从右键按下到菜单可见 | < 100ms |
| 单实例锁检测 | 第二个进程启动到弹通知 | < 500ms |
| 托盘消息通知 | `send_notification()` 调用到显示 | < 50ms |

## 回归测试清单

- [ ] 三平台 (macOS/Windows/Linux) 托盘图标均正常显示
- [ ] 右键菜单项全部可点击且功能正确
- [ ] 点击托盘图标可呼出主窗口
- [ ] 单实例检测：重复启动不创建新窗口
- [ ] 退出菜单项可完全终止进程（`pgrep -f pot` 无结果）
- [ ] 系统重启后托盘图标自动恢复（如果有开机启动设置）
