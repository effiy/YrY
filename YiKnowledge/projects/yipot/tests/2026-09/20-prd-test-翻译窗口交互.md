# 翻译窗口交互 — 测试方案

### TC-TW-001: 选中文本触发

| 步骤 | 选中文本 → 按快捷键 |
| 预期 | 翻译窗口在鼠标附近弹出 |

### TC-TW-002: 点击外部关闭

| 步骤 | 翻译窗口打开 → 点击窗口外部 |
| 预期 | 窗口关闭 |

### TC-TW-003: Esc 关闭

| 步骤 | 翻译窗口聚焦 → 按 Esc |
| 预期 | 窗口关闭 |

### TC-TW-004: 输入翻译模式

| 步骤 | 按输入翻译快捷键 → 输入文本 → Enter |
| 预期 | 显示翻译结果 |

### TC-TW-005: 窗口拖拽调整

| 步骤 | 拖拽窗口边缘 |
| 预期 | 窗口大小改变，下次保持新尺寸 |

### TC-TW-006: 复制按钮

| 步骤 | 翻译完成 → 点击复制按钮 |
| 预期 | 译文复制到剪切板 |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 鼠标在屏幕边缘 | 鼠标在屏幕右下角边缘 → 触发翻译 | 窗口不超出屏幕，自动调整位置 | P1 |
| TC-EDGE-02 | 多显示器环境 | 鼠标在副显示器 → 触发翻译 | 窗口在副显示器鼠标附近弹出 | P1 |
| TC-EDGE-03 | 极小窗口尺寸 | 拖拽窗口到 100x50 像素 | 最小尺寸限制 (如 250x150)，不无限缩小 | P2 |
| TC-EDGE-04 | 极大窗口尺寸 | 拖拽窗口到超出屏幕 | 最大尺寸为屏幕可见区域 | P2 |
| TC-EDGE-05 | 超长翻译结果 | 翻译 5000 字文本 | 结果区域可滚动，不撑爆窗口 | P1 |
| TC-EDGE-06 | 极短翻译结果 | 翻译 "Hi" → "嗨" | 窗口自动收缩到合适尺寸 | P3 |
| TC-EDGE-07 | RTL 语言结果 (阿拉伯语) | 翻译为阿拉伯语 | 文本方向正确 (RTL)，复制时保持方向 | P2 |
| TC-EDGE-08 | 输入框粘贴大文本 | 粘贴 10000 字到输入框 | 输入框截断或提示超出限制 | P1 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 窗口动画过程中关闭 | 打开窗口 → 动画未完成按 Esc | 动画中断，窗口正常关闭，无残留事件 | 下次打开正常 |
| TC-ERR-02 | 快速切换翻译/OCR 窗口 | 翻译窗口打开 → 立即按 OCR 快捷键 | 翻译窗口关闭，OCR 窗口打开，不重叠 | — |
| TC-ERR-03 | 窗口拖拽到屏幕外 | 快速拖拽窗口标题栏到屏幕外 | 窗口被屏幕边界吸住，不完全不可见 | 下次打开在可见位置 |
| TC-ERR-04 | 输入中关闭窗口 | 输入框有未翻译文本 → 关闭窗口 | 输入文本不保存到历史，下次打开为空 | — |
| TC-ERR-05 | 复制按钮失败 (剪切板锁) | 翻译完成 → 其他程序锁定剪切板 → 点复制 | 显示"复制失败，请重试" | 锁释放后正常 |
| TC-ERR-06 | 窗口失去焦点后恢复 | 翻译中切换应用 → 切回来 | 翻译结果保持，窗口状态不丢失 | — |
| TC-ERR-07 | 多次连续打开关闭 | 1 秒内开/关窗口 10 次 | 不卡死，不内存泄漏，每次正常响应 | — |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 窗口首次打开 | 从快捷键按下到窗口可见 | ≤ 150ms | > 300ms | 包含创建 + 渲染 + 定位 |
| TC-PERF-02 | 窗口再次打开 (热启动) | 复用已有窗口 | ≤ 50ms | > 150ms | 隐藏/显示而非销毁/重建 |
| TC-PERF-03 | 窗口拖拽调整大小 | 帧率 (FPS) | ≥ 30 FPS | < 15 FPS | 拖拽过程中监测 requestAnimationFrame |
| TC-PERF-04 | 输入到结果显示 | 输入 "Hello" → Enter → 翻译结果渲染 | ≤ 500ms | > 1s | 端到端 (含网络) |
| TC-PERF-05 | 滚动长翻译结果 | 滚动帧率 | ≥ 50 FPS | < 30 FPS | 1000+ 行结果滚动 |
