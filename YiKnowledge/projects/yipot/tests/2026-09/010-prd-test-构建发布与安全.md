# 构建发布与安全 — 测试方案

---

## 一、构建测试

### TC-BLD-001: macOS 构建

| 步骤 | `pnpm tauri build --target universal-apple-darwin` |
|------|--------------------------------------------------|
| 预期 | 生成 .dmg 文件，可正常安装运行 |

### TC-BLD-002: Windows 构建

| 步骤 | `pnpm tauri build --target x86_64-pc-windows-msvc` |
|------|---------------------------------------------------|
| 预期 | 生成 .msi 安装包 |

### TC-BLD-003: Linux 构建

| 步骤 | `pnpm tauri build --target x86_64-unknown-linux-gnu` |
|------|-----------------------------------------------------|
| 预期 | 生成 .deb 和 .AppImage |

## 二、自动更新测试

### TC-UPD-001: 更新检查

| 步骤 | 启动应用 → 检查日志 |
|------|------------------|
| 预期 | `check_update` 执行，无新版本时静默 |

### TC-UPD-002: 发现新版本

| 步骤 | 服务器发布新版本 → 检查更新 |
|------|--------------------------|
| 预期 | 弹窗提示新版本，显示更新日志 |

### TC-UPD-003: 下载更新

| 步骤 | 点击更新 → 下载 |
|------|---------------|
| 预期 | 显示下载进度，完成后提示安装 |

## 三、安全测试

### TC-SEC-001: API Key 加密

| 步骤 | 配置 API Key → 检查配置存储文件 |
|------|------------------------------|
| 预期 | API Key 不以明文存储 |

### TC-SEC-002: 翻译内容不记录

| 步骤 | 翻译敏感文本 → 检查日志文件 |
|------|--------------------------|
| 预期 | 日志中不含翻译内容 |

### TC-SEC-003: macOS 辅助功能权限

| 步骤 | 首次启动 → 检查权限提示 |
|------|----------------------|
| 预期 | 若未授权，提示用户开启辅助功能 |

### TC-SEC-004: 屏幕录制权限

| 步骤 | 首次截图 OCR → macOS |
|------|--------------------|
| 预期 | 若未授权，提示开启屏幕录制权限 |

### TC-SEC-005: 剪切板数据安全

| 步骤 | 开启剪切板监听 → 复制密码 → 关闭监听 |
|------|----------------------------------|
| 预期 | 关闭监听后不再读取剪切板 |

### TC-SEC-006: 本地 OCR 隐私

| 步骤 | 使用系统 OCR → 断网 |
|------|------------------|
| 预期 | 图片不发送到网络，本地处理 |

| TC-EDGE-04 | 旧版 Pot 覆盖安装 | 1.x 安装 2.x | 配置文件兼容迁移 | P1 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 构建时网络断开 | 构建中切断网络 | 构建失败，清理临时文件 | 恢复网络后重试 |
| TC-ERR-02 | 构建时磁盘空间不足 | 剩余空间 < 500MB | 构建失败，提示空间不足 | 清理后重试 |
| TC-ERR-03 | 更新下载中断 | 下载中切断网络 | 断点续传或提示重试 | 恢复网络后重新下载 |
| TC-ERR-04 | 更新安装权限不足 | Windows 非管理员安装 | 提示需要管理员权限或使用用户级安装 | 授权后完成 |
| TC-ERR-05 | 更新服务器不可达 | 更新服务器宕机 | 静默失败，不影响应用使用 | 服务器恢复后正常检查 |
| TC-ERR-06 | 更新包 hash 不匹配 | 下载后 hash 校验失败 | 删除损坏的包，提示重新下载 | 重新下载成功 |
| TC-ERR-07 | macOS 公证失败 | 未签名的构建提交公证 | 公证拒绝，给出具体原因 | 修复签名后重试 |
| TC-ERR-08 | 应用被杀毒软件拦截 | Windows Defender 标记 Pot | 提交误报申诉，使用代码签名减少误报 | 加入白名单后正常 |
