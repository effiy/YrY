# 设置页面架构 — 测试方案

> 覆盖 YP-09-S26：侧边栏导航、10 个子页面、配置持久化、服务管理、快捷键录制、主题切换

---

## 一、核心功能测试

### 1.1 导航与路由

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-CFG-001 | 侧边栏导航切换 | 点击"翻译"导航 → 再点"快捷键" | 右侧内容区切换对应页面，< 100ms |
| TC-CFG-002 | URL 路由直达 | 输入路由 URL | 直接定位到目标页面，侧边栏高亮 |
| TC-CFG-003 | 导航分组显示 | 打开设置页 | 左侧显示四组：通用/服务/工具/关于 |
| TC-CFG-004 | 设置页面懒加载 | 首次打开设置页 | 仅加载当前页面的组件，< 500ms |

### 1.2 通用设置 (General)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-CFG-010 | 语言切换 | 切换到英文 → 重启 | 界面显示英文 |
| TC-CFG-011 | 主题切换 (亮/暗) | 切换暗色主题 | 界面立即变暗，< 200ms |
| TC-CFG-012 | 字体设置 | 选择用户自定义字体 | 翻译窗口使用该字体 |
| TC-CFG-013 | 代理配置 | 填入 host:port → 启用 | 翻译/OCR 请求通过代理 |

### 1.3 服务管理 (Translate/Recognize/TTS/Collection)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-CFG-020 | 服务列表扫描 | 打开翻译服务页 | 扫描 `services/translate/` 自动生成服务列表 |
| TC-CFG-021 | 服务启用/禁用 | 切换 Google 翻译 toggle | 翻译窗口即时反映（启用/不出现） |
| TC-CFG-022 | 服务排序拖拽 | 拖拽百度翻译到最前 | 翻译结果中百度在最前 |
| TC-CFG-023 | 单服务配置 | 点击百度翻译 → ConfigModal | 编辑 API Key、自定义参数 |
| TC-CFG-024 | 插件选择弹窗 | 在服务配置页点击"添加" | SelectPluginModal 列出可选插件 |

### 1.4 快捷键 (Hotkey)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-CFG-030 | 快捷键录制 | 点击录制 → 按下 Ctrl+Shift+T | 正确捕获组合键，< 50ms 响应 |
| TC-CFG-031 | 快捷键冲突检测 | 录制已有快捷键 | 弹窗提示冲突，显示当前占用功能 |
| TC-CFG-032 | 快捷键生效 | 设置翻译快捷键 → 保存 | 按下快捷键触发翻译 |

## 二、边界与异常测试

| 编号 | 场景 | 触发条件 | 预期行为 | 恢复策略 |
|------|------|----------|----------|----------|
| TC-CFG-EDGE-01 | 配置文件损坏 | JSON 解析失败 | 使用默认配置覆盖，弹窗提示 | 自动备份为 `.pot.dat.bak` |
| TC-CFG-EDGE-02 | 配置写入磁盘失败 | 磁盘满/权限不足 | 弹窗"配置保存失败" | 保留内存中修改 |
| TC-CFG-EDGE-03 | 快捷键冲突 | 录制已占用按键 | 弹窗 + 允许覆盖或重录 | 显示冲突功能 |
| TC-CFG-EDGE-04 | 导入配置版本不兼容 | JSON 缺少字段 | 合并模式：仅导入可识别字段 | 报告跳过字段列表 |
| TC-CFG-EDGE-05 | 服务 Key 明文泄露 | 截图/日志含 Key | 密码输入框 `type="password"` | 日志脱敏 |
| TC-CFG-EDGE-06 | 字体未安装 | 选未安装字体 | 显示"字体不可用" + fallback | — |
| TC-CFG-EDGE-07 | 重复设置窗口 | 再次打开设置 | 聚焦已有设置窗口，不新建 | `WebviewWindow::get_by_label` |
| TC-CFG-EDGE-08 | 配置防抖写入 | 快速连改 10 次 | 仅触发 1 次持久化写磁盘 | 500ms 防抖 |
