# 安全加密存储 — 测试方案

## 核心功能测试

### 加密存储

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SE-01 | API Key 加密存储 | 配置百度 AppID/Secret → 检查配置文件 | Secret 字段为 AES 密文 "U2FsdGVkX1..." |
| TC-SE-02 | Azure Key 加密 | 配置 Azure API Key → 检查配置文件 | Key 字段为密文 |
| TC-SE-03 | 阿里 AccessKey 加密 | 配置 AccessKey ID + Secret | ACCESS_KEY_SECRET 字段为密文 |
| TC-SE-04 | 腾讯 SecretKey 加密 | 配置 SecretId + SecretKey | SecretKey 字段为密文 |
| TC-SE-05 | 非敏感字段不加密 | 检查 enable/语言/等配置 | enable, language 等字段明文存储 |
| TC-SE-06 | 机器指纹密钥生成 | 检查加密密钥来源 | 基于 hostname+OS+username 的哈希生成 |
| TC-SE-07 | 配置文件跨机器不可解密 | 复制配置到其他机器 | 打开 Pot 提示配置加载失败，需重新输入 |
| TC-SE-08 | 配置读写正常 | 加密配置 → 重启 → 使用翻译 | 自动解密，翻译服务正常调用 |

### 安全边界

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SE-10 | HTTP 服务仅 localhost | 检查监听地址 | HTTP 服务绑定 127.0.0.1，不接受外部连接 |
| TC-SE-11 | 日志不含 API Key | 启用日志 → 使用所有翻译服务 | 日志中无 API Key 明文 |
| TC-SE-12 | 错误信息不含 Key | API Key 错误 → 查看错误提示 | 提示如 "Secret 错误" 而非显示 Secret 值 |
| TC-SE-13 | 配置文件不在网络传输 | 使用抓包检查 | 配置文件不通过 HTTP 传输 |

## 增强边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-SE-E01 | 配置文件被篡改 | 手动修改密文 | 解密失败，该 Key 视为失效 | P1 |
| TC-SE-E02 | 机器指纹变更 | 修改 hostname → 重启 | 已存 Key 解密失败，需重新输入 | P1 |
| TC-SE-E03 | crypto-js 降级 | 模拟 crypto-js 不可用 | 回退到明文存储，提示安全警告 | P2 |
| TC-SE-E04 | 加密字段为空 | apiKey="" | 不加密空值，存储为空字符串 | P1 |
| TC-SE-E05 | 极长 API Key (500 字符) | 输入超长 Key | 正常加密存储，不过长截断 | P2 |
| TC-SE-E06 | Unicode 密码 | hostname 含中文/emoji | 指纹生成函数正确处理 Unicode | P1 |
| TC-SE-E07 | 并发修改配置 | 两个窗口同时修改 API Key | 最后写入生效，无数据损坏 | P2 |
| TC-SE-E08 | 配置文件损坏 | JSON 格式错误 | 重置配置为空默认值，原文件备份 | P1 |
| TC-SE-E09 | 加密算法升级迁移 | 旧加密格式 → 新加密格式 | 自动检测并迁移 | P2 |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-SE-P01 | AES 加密 (单 Key) | CPU 时间 | ≤ 5ms | > 20ms | 100 次平均 |
| TC-SE-P02 | AES 解密 (单 Key) | CPU 时间 | ≤ 5ms | > 20ms | 100 次平均 |
| TC-SE-P03 | 全量配置解密 (15 个 Key) | 启动耗时 | ≤ 50ms | > 200ms | 冷启动 |
| TC-SE-P04 | 指纹生成 | CPU 时间 | ≤ 1ms | > 5ms | 1000 次平均 |

## 安全测试 (深度)

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SE-S01 | AES 加密强度 | 检查算法 | 使用 AES-256，非 ECB 模式 | P0 |
| TC-SE-S02 | 密文不可逆 | 尝试无密钥解密 | 无法恢复明文 | P0 |
| TC-SE-S03 | IV/Nonce 随机 | 同一 Key 加密两次 | 两次密文不同 | P1 |
| TC-SE-S04 | 配置文件权限 | 检查文件权限位 | 仅当前用户可读写 (0600/0640) | P1 |
| TC-SE-S05 | 内存中 Key 不交换 | 检查 swap/休眠文件 | API Key 不写入 pagefile/swap | P2 |
| TC-SE-S06 | WebDAV 同步安全 | 启用 WebDAV → 检查传输 | 配置文件传输时保持加密状态 | P1 |
| TC-SE-S07 | 剪贴板无 Key | 复制配置值 → 检查剪贴板 | 密文或屏蔽 (不暴露明文) | P2 |
| TC-SE-S08 | Key 密文不写日志 | 检查所有日志输出 | 日志不输出加密密文 | P1 |
