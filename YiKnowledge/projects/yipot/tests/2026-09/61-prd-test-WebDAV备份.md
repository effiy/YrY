# WebDAV 与阿里云备份 — 测试方案

> 覆盖 YP-09-S28：本地 JSON 导出/导入、WebDAV 上传/下载、阿里云 OSS 同步、连接测试

---

## 一、核心功能测试

### 1.1 本地备份

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-BK-001 | 导出完整配置 | 备份 → 本地 → 导出全部 | JSON 文件包含完整配置，< 500ms |
| TC-BK-002 | 选择性导出 | 仅导出服务配置（不含快捷键） | JSON 仅含服务配置字段 |
| TC-BK-003 | 导入恢复配置 | 清除配置 → 导入导出的 JSON | 配置完全恢复，< 500ms |
| TC-BK-004 | 导入合并模式 | 当前有配置 → 导入部分字段 JSON | 合并导入，仅覆盖匹配字段 |

### 1.2 WebDAV 同步

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-BK-010 | 连接测试成功 | 填入正确 URL/用户名/密码 → 测试 | PROPFIND 成功，< 5s |
| TC-BK-011 | 上传配置 | 配置正确 → 点击上传 | 配置文件上传到 WebDAV，< 3s |
| TC-BK-012 | 下载恢复 | 配置正确 → 点击下载 | 配置从 WebDAV 恢复到本地，< 3s |
| TC-BK-013 | 认证失败 | 填写错误密码 → 测试连接 | 提示"用户名或密码错误" |

### 1.3 阿里云 OSS 同步

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-BK-020 | 连接测试成功 | 正确 AK/SK/Bucket/Region → 测试 | HeadBucket 成功，< 5s |
| TC-BK-021 | OSS 上传 | 配置正确 → 上传 | 配置文件上传到 OSS，< 3s |
| TC-BK-022 | OSS 下载 | 配置正确 → 下载 | 配置从 OSS 恢复到本地，< 3s |
| TC-BK-023 | AK/SK 无效 | 错误 AK/SK → 操作 | 提示"AccessKey 无效或已过期" |
| TC-BK-024 | Bucket 不存在 | 不存在的 Bucket → 操作 | 提示"Bucket 不存在或区域错误" |

## 二、边界与异常测试

| 编号 | 场景 | 触发条件 | 预期行为 | 恢复策略 |
|------|------|----------|----------|----------|
| TC-BK-EDGE-01 | WebDAV 网络超时 | 15s 无响应 | 提示"连接超时" | 保留"待同步"标记 |
| TC-BK-EDGE-02 | WebDAV 认证失败 | 401 响应 | 提示"用户名或密码错误" | 不清除已存凭据 |
| TC-BK-EDGE-03 | WebDAV 无写入权限 | 403 响应 | 提示"无写入权限" | — |
| TC-BK-EDGE-04 | 阿里云 AK/SK 无效 | 403 响应 | 提示"AccessKey 无效" | 引导更新 |
| TC-BK-EDGE-05 | 阿里云 Bucket 不存在 | 404 响应 | 提示"Bucket 不存在" | 验证 region |
| TC-BK-EDGE-06 | 导入 JSON 格式错误 | 非 JSON 内容 | 弹窗"格式错误"，拒绝导入 | — |
| TC-BK-EDGE-07 | 导入 JSON schema 不匹配 | 缺少必填字段 | 合并模式，仅导入匹配字段 | 报告跳过字段 |
| TC-BK-EDGE-08 | 同时多次同步点击 | 快速点击上传 | 按钮 disabled 防竞态 | — |
| TC-BK-EDGE-09 | OSS 超大文件下载 | > 5MB | 拒绝下载，提示"配置文件异常" | 手动检查 |
| TC-BK-EDGE-10 | 磁盘空间不足 | ENOSPC 写入 | 提示"磁盘空间不足" | 保留当前配置 |
| TC-BK-EDGE-11 | WebDAV HTTP 模式 | 使用 HTTP 地址 | 警告但允许（内网场景） | — |
