# Tesseract 离线 OCR — 测试方案

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-TES-01 | 中英混合识别 | 两种语言均识别 |
| TC-TES-02 | 语言包自动下载 | 首次使用自动下载 |
| TC-TES-03 | Linux 离线可用 | 无网络正常识别 |
| TC-TES-04 | 多语言支持 | 100+ 语言包可用 |

## 性能基准

| 场景 | 首次 | 后续 |
|------|------|------|
| 中文识别 | ~4s | ~1.2s |
| 英文识别 | ~3s | ~0.8s |

## 回归检查

- [ ] Worker 复用生效

## 边界与异常测试

| 场景 | 操作步骤 | 预期结果 |
|------|----------|----------|
| 纯图片无文字 | OCR 自然风景照片 | 返回空字符串，不报错 |
| 极端低分辨率 (50x50) | OCR 极小区域截图 | 返回低置信度结果或空 |
| 混排方向（横排+竖排混合） | 日文竖排 + 英文横排混合区域 | 仅识别主流方向文字 |
| 透明背景 PNG | OCR 带透明通道的截图 | 正常识别，透明部分不干扰 |
| 多语言混合（中日英） | 同一截图含三种语言 | 分别正确识别各语言区域 |
| WASM 加载失败 | 模拟 CDN 不可达 | 降级至 JS-only 模式并日志警告 |
| 识别进行中关闭窗口 | OCR 中关闭翻译窗口 | worker 正确 terminate，无泄漏 |
| 连续 10 次识别 | 循环执行 10 次 OCR | worker 复用生效，每次 < 1.5s |

## 性能基准测试

| 场景 | 测试方法 | 基准 |
|------|----------|------|
| 中文识别（首次） | 无缓存，首次创建 worker | < 5s |
| 中文识别（复用） | worker 已预热 | < 1.5s |
| 英文识别（复用） | worker 已预热 | < 1s |
| 语言包下载（50MB 数据） | CDN 下载 `chi_sim.traineddata` | < 30s（稳定网络） |
| worker 创建 + 销毁 | `createWorker` → `terminate` 完整周期 | < 500ms（不含识别） |

## 回归测试清单

- [ ] Worker 复用生效（第二次识别快于第一次）
- [ ] 语言包缓存不丢失（重启后仍可用）
- [ ] 离线环境完全可用（断开网络后验证）
- [ ] 100+ 语言包列表可正常加载
- [ ] 低置信度结果（< 60%）正常标记
- [ ] worker 泄漏检测（`terminate` 后内存回收）
