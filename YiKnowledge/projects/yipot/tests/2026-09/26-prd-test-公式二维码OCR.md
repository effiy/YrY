# 公式/二维码 OCR — 测试方案

## LaTeX 公式

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-LTX-01 | 简单公式 | `\frac{d}{dx}x^2 = 2x` |
| TC-LTX-02 | 复杂积分 | 正确 LaTeX 代码 |
| TC-LTX-03 | 错误公式 | 置信度低 + 提示 |

## 二维码

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-QR-01 | 标准 URL | 解码成功，显示 URL |
| TC-QR-02 | 中文内容 | 正确解码中文 |
| TC-QR-03 | 破损二维码 | 提示无法识别 |
| TC-QR-04 | 响应速度 | < 500ms |

## 性能基准

| 场景 | 基准 |
|------|------|
| 二维码识别 | ≤ 100ms (P95) |
| LaTeX 简单公式 | ≤ 1s |
| LaTeX 复杂公式 | ≤ 2s |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | LaTeX 空公式/空白图片 | 截图无公式的纯白区域 | 返回空或提示"未检测到公式" | P1 |
| TC-EDGE-02 | LaTeX 超长公式 (多行) | 截图 5 行 align 环境公式 | 正确识别并输出多行 LaTeX 代码 | P2 |
| TC-EDGE-03 | LaTeX 含特殊符号 | `\sum_{i=1}^{\infty} \int_0^1 f(x) dx` | 正确识别 \\sum \\int \\infty 等符号 | P1 |
| TC-EDGE-04 | LaTeX 手写公式 | 手写拍照的数学公式 | 置信度低时提示"手写识别准确率较低" | P2 |
| TC-EDGE-05 | 二维码极小尺寸 | 30x30 像素二维码 | 提示"二维码太小，请放大后尝试" | P2 |
| TC-EDGE-06 | 二维码含中文 URL | 解码后 URL 含中文字符 | 正确解码中文内容 | P1 |
| TC-EDGE-07 | 二维码多种类型 (QR/Micro QR/Data Matrix) | 截图 Data Matrix 码 | QR 识别，Data Matrix 可能不支持 | P2 |
| TC-EDGE-08 | 图片中混合公式 + 文字 + 二维码 | 截图含三种元素 | 根据选择的 OCR 类型分别处理，不混淆 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 破损二维码 (遮挡 30%) | 截图部分遮挡的二维码 | 显示"无法识别二维码，可能已损坏" | 完整二维码可识别 |
| TC-ERR-02 | 模糊二维码 (低分辨率) | 截图过度压缩的二维码 | 提示"二维码模糊，请重新截图" | 高清截图后正常 |
| TC-ERR-03 | 非标准公式语法 | 截图含错误 LaTeX 语法 | 返回识别的原始内容，标注"格式可能不正确" | — |
| TC-ERR-04 | LaTeX OCR 引擎不可用 | API Key 无效或无网络 | 显示"公式识别服务不可用，请检查配置" | 修正 Key 后正常 |
| TC-ERR-05 | 二维码解码为恶意 URL | 二维码指向钓鱼网站地址 | 显示识别结果但不自动打开，提示"请谨慎访问" | — |
| TC-ERR-06 | 图片格式不支持 | WebP/GIF 格式公式图片 | 自动转为 PNG/JPG 后识别，或提示格式不支持 | 转换为 PNG 后正常 |
| TC-ERR-07 | 二维码颜色反转 (白底黑码) | 截图反色二维码 | 部分解码库可自动检测反转，否则提示 | — |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|

| TC-PERF-03 | LaTeX 简单公式识别 | P50/P95 | ≤ 500/1000ms | > 1000/2000ms | 20 次单行公式 |
| TC-PERF-04 | LaTeX 复杂多行公式 | P95 | ≤ 2s | > 4s | 10 次多行 align 公式 |
| TC-PERF-05 | 公式+二维码混合检测 | 混合图片分类耗时 | ≤ 100ms | > 300ms | 图片预处理+分类 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 二维码恶意链接不自动跳转 | 识别 phishing/doubleclick 链接 | 仅显示文字结果，不自动打开浏览器 | P0 |
| TC-SEC-02 | 二维码含 JavaScript 伪协议 | 识别 `javascript:alert(1)` 二维码 | 仅显示文本，不执行也不可点击 | P0 |
| TC-SEC-03 | LaTeX 公式渲染 XSS 防止 | LaTeX 渲染为 HTML 预览 | 公式渲染沙箱化，不执行注入脚本 | P1 |
| TC-SEC-04 | 公式/二维码截图不落盘 | 截图 → 识别 → 检查磁盘 | 截图数据仅存内存，不持久化 | P1 |
