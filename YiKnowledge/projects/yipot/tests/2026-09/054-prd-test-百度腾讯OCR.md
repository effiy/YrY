# 百度/腾讯 OCR — 测试方案

> 覆盖 YP-09-S21：百度 OCR（通用/精准/图片）和腾讯 OCR（通用/精准/图片）共 6 个服务

---

## 一、核心功能测试

### 1.1 百度 OCR 服务

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-BDOCR-01 | 百度通用中文 | 截中文段落 → 选择百度通用 | 中文识别准确率 >= 95% |
| TC-BDOCR-02 | 百度通用英文 | 截英文段落 → 选择百度通用 | 英文识别准确率 >= 93% |
| TC-BDOCR-03 | 百度精准含坐标 | 截文字区域 → 选择百度精准 | 返回文字 + bounding box 四元组 `(x, y, w, h)` |
| TC-BDOCR-04 | 百度精准 IoU | 与标注框对比位置坐标 | IoU >= 0.9 |
| TC-BDOCR-05 | 百度图片 PNG | 上传 PNG 图片 → 百度图片 | 正确识别文字内容 |
| TC-BDOCR-06 | 百度图片 JPG/WEBP/BMP | 分别上传 JPG/WEBP/BMP | 三种格式均正确识别 |
| TC-BDOCR-07 | API Key 未配置 | 不填百度 API Key → 选择百度服务 | 服务灰显标记不可用 |

### 1.2 腾讯 OCR 服务

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-TXOCR-01 | 腾讯通用中英 | 截中英混合段落 → 腾讯通用 | 中文 >= 95%，英文 >= 93% |
| TC-TXOCR-02 | 腾讯精准高精度 | 截高清晰文本 → 腾讯精准 | 识别准确率 >= 97% |
| TC-TXOCR-03 | 腾讯多语言日文 | 截日文段落 → 腾讯 OCR | 日文识别正确 |
| TC-TXOCR-04 | 腾讯多语言韩文 | 截韩文段落 → 腾讯 OCR | 韩文识别正确 |
| TC-TXOCR-05 | 多语言混合 15 种 | 依次测试 15 种语言 | 至少中日韩英法德西葡俄阿识别正确 |
| TC-TXOCR-06 | 腾讯图片识别 | 上传图片 → 腾讯图片 | 正确返回文字内容 |

### 1.3 服务独立控制

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SVC-01 | 单服务启用 | 仅启用百度通用 → OCR | 仅百度通用参与调度 |
| TC-SVC-02 | 多服务并行 | 同时启用百度通用 + 腾讯通用 | 两个结果独立展示 |
| TC-SVC-03 | 全部禁用 | 禁用所有百度/腾讯服务 | 错误提示"请至少启用一个 OCR 服务" |

## 二、边界与异常测试

| 编号 | 场景 | 输入 | 预期行为 | 恢复策略 |
|------|------|------|----------|----------|
| TC-BT-EDGE-01 | API Key 过期 | 已过期 Key | 返回 401/403，提示"密钥已过期" | 引导用户更新 Key |
| TC-BT-EDGE-02 | 配额耗尽 (429) | 超出每日调用量 | 返回配额错误，提示"今日配额已用尽" | 次日自动恢复 |
| TC-BT-EDGE-03 | 空白图片 | 纯色/空白图片 | 返回空结果，提示"未检测到文字" | — |
| TC-BT-EDGE-04 | 超大图片 | > 10MB 图片 | 拒绝请求，提示"图片过大，请压缩" | 自动压缩到 <= 4MB |
| TC-BT-EDGE-05 | 网络超时 | 10s 无响应 | AbortController 取消，显示"网络连接超时" | 自动重试 1 次（间隔 2s） |
| TC-BT-EDGE-06 | 百度精准无文字 | 风景/纯色图片 | 返回空数组 `[]`，不报错 | 降级到通用 OCR |
| TC-BT-EDGE-07 | 腾讯并发限制 | 同时 5 个请求 | 超出请求排队等待 | 队列长度 <= 10，超限拒绝 |
| TC-BT-EDGE-08 | 特殊字符/Emoji | 截含特殊字符的文字 | 正常返回，不截断不替换 | — |
| TC-BT-EDGE-09 | 图片 4MB 边界 | 上传恰好 4MB 图片 | 正常处理（含 4MB） | — |
