## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 空白图片 (纯白) | 截图纯白区域 | 返回空结果或提示"未检测到文字" | P1 |
| TC-EDGE-02 | 极低分辨率图片 | 50x50 像素截图 | 提示"图片分辨率过低，建议重新截图" | P2 |
| TC-EDGE-03 | 高分辨率图片 | 4K 截图 | 正常识别，处理时间可接受 | P2 |
| TC-EDGE-04 | 竖排文字 (中文) | 截图竖排中文 | macOS/Windows 系统 OCR 尝试识别，结果可能不准确 | P2 |
| TC-EDGE-05 | 多语言混合 | 截图含中/英/日/韩 | 识别主语言，其他语言可能乱码 | P2 |
| TC-EDGE-06 | 手写文字 | 截图手写笔记 | 系统 OCR 尝试识别，准确率依赖系统能力 | P3 |
| TC-EDGE-07 | 小字号文字 (8pt) | 截图 8pt 文字 | 若分辨率足够可识别，过低提示放大 | P2 |
| TC-EDGE-08 | 反色文字 (白底黑字 vs 黑底白字) | 截图深色模式界面 | 正确识别，无颜色依赖 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | macOS VisionKit 不可用 | macOS 11 以下系统 | 降级到 Tesseract.js 或提示系统版本过低 | 升级系统后可用 |
| TC-ERR-02 | Windows OCR 语言包缺失 | Windows 未安装中文语言包 | 提示安装语言包或降级到 Tesseract | 安装语言包后正常 |
| TC-ERR-03 | Tesseract.js 语言包下载失败 | 断网时首次使用某语言 | 提示"语言包下载失败，请检查网络" | 联网后重试成功 |
| TC-ERR-04 | 截图区域无文字 | 截图纯图标 UI | 返回空结果，不报错 | — |
| TC-ERR-05 | OCR 引擎初始化失败 | Tesseract WASM 加载失败 | 显示"OCR 引擎初始化失败"，降级到其他引擎 | 重启后正常 |
| TC-ERR-06 | 内存不足时大图 OCR | 低内存设备上 OCR 4K 图 | 内存溢出时崩溃恢复，下次限制图片尺寸 | 重启后正常 |
| TC-ERR-07 | 并发生成多个 OCR 任务 | 连续 3 次截图 OCR 未等完成 | 队列处理或取消前序任务，仅处理最新 | — |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | macOS VisionKit 中文识别 | P50/P95 | ≤ 200/500ms | > 500/1000ms | 50 次 100 字截图 |
| TC-PERF-02 | macOS VisionKit 英文识别 | P50/P95 | ≤ 150/400ms | > 400/800ms | 50 次 100 字截图 |
| TC-PERF-03 | Tesseract.js 中英混合 | P50/P95 | ≤ 500/1500ms | > 1000/3000ms | 20 次采样 |
| TC-PERF-04 | Windows OCR 识别 | P50/P95 | ≤ 300/800ms | > 600/1500ms | 30 次采样 |
| TC-PERF-05 | 截图到 OCR 结果展示 | 端到端延迟 | ≤ 1s | > 2s | 截图框选完成到文字出现的完整链路 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 离线 OCR 数据不出设备 | 断网后 OCR 截图 | 正常识别，数据不发送到远程 | P0 |
| TC-SEC-02 | OCR 结果不写入磁盘缓存 | OCR 含密码/敏感信息后检查磁盘 | 截图和识别结果不持久化到磁盘 | P1 |
| TC-SEC-03 | Tesseract WASM 本地加载 | 检查 Tesseract 语言包来源 | 从本地或官方 CDN 加载，不经过第三方 | P2 |
| TC-SEC-04 | 截图缓存即时清除 | OCR 完成后检查内存 | 截图像素数据从内存释放 | P1 |
