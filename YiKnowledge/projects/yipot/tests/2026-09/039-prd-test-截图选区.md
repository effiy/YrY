# 截图与选区 — 测试方案

## 核心功能测试

### macOS 系统截图

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SS-01 | screencapture 交互截图 | 触发截图 → screencapture -i -r 执行 | 系统截图十字光标出现，截图保存为 PNG |
| TC-SS-02 | 截图取消 (Esc) | 触发截图 → 系统截图界面按 Esc | 无文件生成，无窗口残留 |
| TC-SS-03 | 截图确认 | 框选区域 → 确认 | PNG 文件生成，base64 传递给 OCR |
| TC-SS-04 | 无屏幕录制权限 | 关闭权限 → 触发截图 | 提示"需要屏幕录制权限"并引导系统设置 |
| TC-SS-05 | screencapture 进程失败 | 模拟进程异常退出 | 回退到自定义截图窗口 |

### Win/Linux 自定义截图窗口

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SS-10 | 全屏遮罩渲染 | 触发截图 | 全屏半透明遮罩覆盖所有显示器 |
| TC-SS-11 | 选区拖拽 | 鼠标按下拖动 300x200 | Canvas 绘制选区矩形，显示尺寸标注 |
| TC-SS-12 | Esc 取消 | 遮罩状态下按 Esc | 截图窗口关闭，无残留 DOM/Canvas |
| TC-SS-13 | Enter 确认 | 选区完成 → Enter | 截图保存，关闭窗口，传递 base64 |
| TC-SS-14 | 选区拖拽帧率 | 快速拖动选区 | 60fps 流畅，无明显卡顿 |
| TC-SS-15 | 跨显示器选区 | 双屏，从主屏拖到副屏 | 选区坐标正确跨越显示器边界 |

## 增强边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-SS-E01 | 选区过小 (< 10x10px) | 拖拽 5x5 选区 | 取消截图，不生成文件 | P1 |
| TC-SS-E02 | 选区过大 (> 8K) | 7690x4320 全屏截图 | 正常截取，PNG 编码 ≤ 200ms | P2 |
| TC-SS-E03 | 截图窗口被其他窗口遮挡 | 截图时弹窗 | 截图窗口保持置顶 | P1 |
| TC-SS-E04 | 截图过程按 Ctrl+C | 自定义截图窗口按 Ctrl+C | 忽略，保持 Esc 取消逻辑 | P3 |
| TC-SS-E05 | 磁盘空间不足 | 填充磁盘 → 截图 | 提示"截图保存失败，磁盘空间不足"，降级内存缓存 | P1 |
| TC-SS-E06 | 截图文件路径含特殊字符 | 系统用户名含空格/中文 | 路径正确编码，文件写入成功 | P2 |
| TC-SS-E07 | PNG 编码性能 | 1920x1080 区域 | 编码耗时 ≤ 100ms | P1 |
| TC-SS-E08 | base64 转换 | 4K 截图 | 转换 ≤ 50ms，无内存溢出 | P1 |
| TC-SS-E09 | 连续截图 | 连续 10 次 Enter 确认 | 每次截图独立保存，不覆盖 | P2 |
| TC-SS-E10 | macOS 强制使用自定义窗口 | 模拟 screencapture 不可用 | 降级到自定义截图窗口，功能正常 | P1 |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-SS-P01 | macOS screencapture 截图 | 端到端耗时 | ≤ 300ms | > 600ms | 50 次采样 |
| TC-SS-P02 | Win/Linux 全屏遮罩渲染 | 首帧渲染 | ≤ 50ms | > 100ms | React Profiler |
| TC-SS-P03 | 选区拖拽帧率 | FPS | ≥ 55fps | < 45fps | Canvas FPS 监测 |
| TC-SS-P04 | PNG 编码 (1920x1080) | 编码时间 | ≤ 100ms | > 200ms | 编码计时 |
| TC-SS-P05 | base64 转换 (1920x1080) | 转换时间 | ≤ 50ms | > 100ms | 转换计时 |
| TC-SS-P06 | 连续截图内存 | 10 次截图后堆内存 | 增长 ≤ 50MB | > 100MB | Memory Profiler |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SS-S01 | 截图文件权限 | 检查截图文件权限 | 仅当前用户可读 (0600/0640) | P1 |
| TC-SS-S02 | 截图不泄露到剪贴板(未配置时) | 截图后检查系统剪贴板 | 截图内容不写入剪贴板 | P2 |
| TC-SS-S03 | 临时文件清理 | 截图完成后检查临时目录 | 临时截图文件已清理 | P1 |
