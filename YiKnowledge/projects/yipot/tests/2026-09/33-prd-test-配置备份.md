# 配置管理与备份 — 测试方案

> **文档职责**：本文档定义配置存储系统、JSON 备份/恢复、WebDAV/阿里云 OSS 同步、代理设置、API Key 加密存储、配置版本迁移的完整验证方案。

---

## 测试分层

| 层级 | 工具 | 覆盖 |
|------|------|------|
| L1 单元 | Vitest + Rust cargo test | JSON schema 校验、PBKDF2 密钥派生、AES-256-CBC 加密 |
| L2 集成 | Vitest + Tauri mock | 配置持久化、备份导入/导出、WebDAV 同步 |
| L3 E2E | 手动测试 | 完整配置迁移、WebDAV 服务器连接、OSS 上传下载 |
| L4 安全审计 | 手动 + 工具 | API Key 密文检查、跨设备解密验证 |

## 二、JSON 备份/恢复用例

### TC-BACKUP-01: 完整备份导出

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 配置所有服务 API Key + 快捷键 + 主题 | — |
| 2 | 设置页 → 备份 → 完整导出 | 生成 JSON 文件 |
| 3 | 解析 JSON | 包含 version/exported_at/config 字段 |
| 4 | 对比 config 字段与当前配置 | 100% 配置项无遗漏 |

### TC-BACKUP-02: 选择性备份

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 选择"仅快捷键"备份 | JSON 仅包含 4 个 hotkey_* 字段 |
| 2 | 检查 API Key 是否在 JSON 中 | L3 机密级 Key 不出现在选择性备份中 |
| 3 | 选择"仅服务配置" | JSON 包含服务配置但不含快捷键 |

### TC-BACKUP-03: JSON 导入

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 使用合法 JSON 文件导入 | 配置正确合并，≥ 99% 成功率 |
| 2 | 检查导入后功能 | 快捷键/服务/主题均正常工作 |
| 3 | 导入版本兼容的 JSON | 与当前版本一致，直接合并 |
| 4 | 导入来自旧版本 (v3.0) 的 JSON | 执行迁移规则 (如 proxy_host 拆分) |

### TC-BACKUP-04: 完整备份加密导出

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 选择"完整备份"，勾选"加密" | 需输入密码 |
| 2 | 输入备份密码并确认 | JSON 中 L3 机密字段以 AES-256 加密 |
| 3 | 导入加密备份 | 需输入解密密码，密码正确才可恢复 |

## 六、边界与异常测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 导入 JSON 格式错误 | 提供 `{"key": }` 无效 JSON | 提示"配置文件格式错误: line X, col Y" | 拒绝导入，不影响现有配置 |
| TC-ERR-02 | 导入 JSON 缺少必要字段 | 提供仅含 version 的 JSON | 使用默认值填充缺失字段 | 列出缺失项供确认 |
| TC-ERR-03 | 导入版本不兼容 | 旧版本 JSON | 提示版本不兼容，允许强制导入但标注风险 | — |
| TC-ERR-04 | WebDAV 连接失败 | 使用无效 URL | 重试 3 次 (2s/5s/10s)，最终提示"无法连接" | 网络恢复后同步正常 |
| TC-ERR-05 | WebDAV 认证失败 | 使用错误密码 | 提示"用户名或密码错误" | 更正后连接成功 |
| TC-ERR-06 | OSS AccessKey 无效 | 使用失效 Key | 提示"OSS 认证失败，请检查 AccessKey" | — |
| TC-ERR-07 | 配置文件过大 (> 10MB) | 生成 15MB 配置 | 提示"配置文件过大"，建议清理历史数据 | — |
| TC-ERR-08 | 密钥跨设备解密 | 在另一台电脑导入加密备份 | 解密失败 (密钥与机器绑定) | 提示"配置由其他设备导出，请使用密码解密" |

## 八、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | API Key AES-256 加密 | 检查配置文件磁盘内容 | L3 机密字段均为密文 | P0 |
| TC-SEC-02 | 加密密钥机器绑定 | 导出加密配置 → 在另一台电脑导入 | 解密失败 (hostname+OS+username 不同) | P0 |
| TC-SEC-03 | PBKDF2 迭代次数 | 代码审查密钥派生 | 100,000 次迭代 | P1 |
| TC-SEC-04 | WebDAV HTTPS 强制 | URL scheme 检查 | 禁止 http:// URL (非 localhost) | P1 |
| TC-SEC-05 | 代理配置安全 | 检查代理 URL 是否加密存储 | L2 敏感级，明文存储 (用户可见) | P2 |
| TC-SEC-06 | JSON 导入 schema 校验 | 导入任意 JSON | 仅合并已知字段，拒绝注入新字段 | P1 |
| TC-SEC-07 | API Key 在内存中不常驻 | 配置加载后检查全局变量 | API Key 使用后释放，不缓存在全局变量 | P2 |
