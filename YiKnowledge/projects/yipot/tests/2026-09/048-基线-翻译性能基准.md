## 三、执行命令脚本块

### 3.1 ab 压测翻译端点 :60828

```bash
# 翻译接口压测 300 次 / 并发 10
ab -n 300 -c 10 -s 30 \
  -H "Content-Type: application/json" \
  -p datasets/zh_en_30pairs_batch.json \
  -T application/json \
  http://127.0.0.1:60828/translate \
  | tee artifacts/048_ab_translate_$(date +%F).log

# 单条 SSE 首字节打点
for i in {1..21}; do
  python scripts/measure_sse_ttfb.py \
    --engine $(jq -r ".engines[$i-1].name" datasets/engines_21.json) \
    --text "$(jq -r '.pairs[0].zh' datasets/zh_en_30pairs_batch.json)" \
    --endpoint http://127.0.0.1:60828/translate/stream \
    --runs 30
done | tee artifacts/048_sse_ttfb_21engines.csv
```

### 3.2 剪贴板监听 CPU 采样

```bash

# 另开终端触发剪贴板高频写入（模拟用户复制）
```

### 3.3 SQLite history.db 写入延迟

```bash
sqlite3 ~/Library/Application\ Support/YiPot/history.db <<'SQL'
.timer on
PRAGMA journal_mode=WAL;
BEGIN;
EXPLAIN QUERY PLAN INSERT INTO history(src, dst, text, translated, engine, created_at)
VALUES('zh','en','性能基线测试','performance baseline test','google',unixepoch());
COMMIT;
SQL

# 批量写入 1000 条打 p95
python - <<'PY'
import sqlite3, time, statistics
conn = sqlite3.connect(os.path.expanduser("~/Library/Application Support/YiPot/history.db"))
lat=[]
for i in range(1000):
    t=time.perf_counter()
    conn.execute("INSERT INTO history(src,dst,text,translated,engine,created_at) VALUES(?,?,?,?,?,?)",
        ("zh","en",f"test {i}",f"translation {i}","bench",int(time.time())))
    conn.commit()
    lat.append((time.perf_counter()-t)*1000)
conn.close()
lat.sort()
print("p50=%.1f p95=%.1f p99=%.1f ms"%(lat[500],lat[950],lat[990]))
PY
```

## 七、优化建议

1. **OpenAI 系列首字节 > 600ms**：在 `/translate` 层新增 LRU 令牌预生成（参考 yiai 45-prd），并将 prompt 模板按 token 数缓存编码，可将 gpt-4o-mini p95 降至 ≤ 480ms。
2. **性能问题 001：剪贴板 CPU 峰值 9.4%**：Tauri 侧将 `clipboard-watcher` 轮询从 50ms 降为 200ms，并用 `NSNotificationCenter` 事件驱动替换 Darwin 侧 polling，峰值可收至 4% 以内。
3. **history.db 写入 p95 偏高**：将单条 commit 改为 batch 20 条一次事务 + WAL `synchronous=NORMAL`，写入 p95 可进一步降至 ≤ 22ms。
