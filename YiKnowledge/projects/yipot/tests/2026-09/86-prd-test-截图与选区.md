# 截图与选区 — 测试方案

> **文档职责**：验证 macOS screencapture 截图和 Win/Linux 自定义截图窗口的功能正确性。

---

## 一、测试层级

```
截图与选区交互
├── macOS 截图
│   ├── screencapture -i 交互截图
│   ├── 截图保存为 PNG
│   └── 截图 base64 传递
├── Win/Linux 截图窗口
│   ├── 全屏半透明遮罩
│   ├── Canvas 选区绘制
│   ├── 拖拽选区和调整大小
│   ├── Esc 取消 / Enter 确认
│   └── 选区高亮 + 尺寸标注
├── 截图窗口特性
│   ├── 全屏 + 置顶 + 无边框
│   ├── 跳过任务栏
│   └── Esc 关闭
└── 图片处理
    ├── PNG 格式保存
    ├── base64 编码传递
    └── 裁剪前预览
```

---

## 二、核心测试用例

### 2.1 macOS 截图

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-MAC-001 | 基本截图 | 按截图 OCR 快捷键 → 框选区域 | 系统 screencapture -i 被调用，选区截图保存 | P0 |
| TC-MAC-002 | 截图无声 | 触发截图 → 检查音效 | 无相机快门音效 (screencapture -r) | P2 |
| TC-MAC-003 | 截图取消 (Esc) | screencapture 交互中 → 按 Esc | 截图取消，无图片生成，无 OCR 触发 | P1 |
| TC-MAC-004 | 截图 PNG 格式 | 截图完成 → 检查临时文件 | 图片格式为 PNG | P1 |
| TC-MAC-005 | 截图 base64 传递 | 截图完成 → 检查传递给 OCR 的数据 | base64 编码正确，可解码回原图 | P1 |

## 三、边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 极小选区 (10x10 px) | 框选 10x10 像素区域 | 允许截取或提示最小尺寸 | P2 |
| TC-EDGE-02 | 全屏选区 | 框选整个屏幕 | 正常截取全屏 | P2 |
| TC-EDGE-03 | 选区面积为 0 | 点击即释放 (无拖拽) | Windows/Linux: 不触发截图，macOS: screencapture 行为 | P2 |
| TC-EDGE-04 | 选区跨显示器 (Win/Linux) | 双屏 → 跨屏拖拽选区 | 选区正确截取两个显示器的区域 | P2 |
| TC-EDGE-05 | 截图快捷键快速双击 | 双击截图快捷键 | 只触发一次截图窗口 | P2 |
| TC-EDGE-06 | 截图窗口自动聚焦 | 截图窗口出现 → 尝试其他操作 | 截图窗口保持焦点，Esc/Enter 优先响应 | P3 |
| TC-EDGE-07 | 暗色背景选区 | 黑色背景 + 黑色文字截图 | 选区边框有足够对比度 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | macOS screencapture 不可用 | 删除 /usr/sbin/screencapture (需 SIP 关闭) | 提示截图命令不可用 | 恢复后正常 |
| TC-ERR-02 | macOS 屏幕录制权限未授权 | 系统设置中关闭屏幕录制权限 | 首次截图时提示授权 | 授权后正常 |
| TC-ERR-03 | 磁盘空间不足 | 填满临时目录所在磁盘 | 提示"磁盘空间不足" | 清理后正常 |
| TC-ERR-04 | 截图过程中断电/休眠 | 截图窗口打开 → 系统休眠 | 恢复后截图窗口仍在或已取消 | 重新截图正常 |
| TC-ERR-05 | GPU 渲染异常 (Wayland) | 部分 Wayland 合成器截全屏 | 截图可能为黑色/透明 | 提示使用系统截图工具 |
| TC-ERR-06 | 截图窗口抢占焦点 | 截图窗口出现时其他程序弹出对话框 | 截图窗口保持置顶 | 关闭对话框后继续截图 |
| TC-ERR-07 | 多截图窗口并发 | 快速按两次不同截图快捷键 | 第二次快捷键被忽略（已有截图窗口） | 第一次取消后第二次才触发 |

## 四、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试工具 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | macOS 截图 (screencapture) | 快捷键到图片就绪 | ≤ 1s | > 3s | 含用户框选时间 |
| TC-PERF-02 | Win/Linux 截图窗口启动 | 快捷键到遮罩出现 | ≤ 500ms | > 1s | 10 次采样 |
| TC-PERF-03 | Win/Linux 确认到图片生成 | Enter 到 base64 就绪 | ≤ 200ms | > 500ms | 10 次采样 |
| TC-PERF-04 | 截图窗口渲染 (4K) | 遮罩 + 选区绘制帧率 | ≥ 30fps | < 15fps | 拖拽时 FPS |
| TC-PERF-05 | base64 编码 (4K) | 编码耗时 | ≤ 500ms | > 2s | 4K 全屏编码 |
| TC-PERF-06 | 截图窗口内存峰值 | 截图过程中内存 | ≤ 100MB 增量 | > 200MB 增量 | 对比截图前后 |

## 五、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 截图临时文件权限 | 检查临时 PNG 文件权限 | 仅当前用户可读 (0600) | P1 |
| TC-SEC-02 | 截图完成后临时文件清理 | OCR 完成后 ls /tmp 或 %TEMP% | 临时截图文件已删除 | P1 |
| TC-SEC-03 | 截图不保存到磁盘 (可选) | 配置"不保存截图到磁盘" | 仅内存传递 base64 | P2 |
| TC-SEC-04 | 截图区域不应包含 Pot 窗口 | 截图时 Pot 窗口可见 | 截图窗口遮罩不截取自身 UI | P2 |
| TC-SEC-05 | 截图数据不跨网络泄露 | 系统 OCR 模式 → Wireshark 抓包 | 图片数据不经网络发送 | P1 |
