# OCR 识别窗口交互 — 测试方案

> 覆盖 YP-09-S25：截图预览、文字展示/编辑、复制/翻译/重新识别操作、跨窗口联动

---

## 一、核心功能测试

### 1.1 窗口显示与基础布局

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-RW-001 | 截图后窗口弹出 | 截图框选 → 确认 | OCR 窗口弹出，< 800ms |
| TC-RW-002 | 双栏布局 | OCR 窗口打开 | 左侧截图预览 + 右侧文字展示 |
| TC-RW-003 | 首条 OCR 文字展示 | 窗口弹出后 | 首个服务识别结果 < 1500ms |
| TC-RW-004 | 图片预览缩放 | 鼠标滚轮缩放截图 | 缩放范围 0.5x ~ 3x |
| TC-RW-005 | 图片拖拽 | 截图大于容器时拖拽 | 可拖动查看不同区域 |

### 1.2 文字编辑与操作

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-RW-010 | 文字可编辑 | 点击文字区域修改 OCR 结果 | contentEditable 正常编辑 |
| TC-RW-011 | 还原原始识别 | 修改文字 → 点击还原按钮 | 恢复到 OCR 原始结果 |
| TC-RW-012 | 全选文字 | Ctrl+A / Cmd+A | 所有识别文字被选中 |
| TC-RW-013 | 鼠标拖选 | 鼠标拖选文字 | 可选择部分文字 |

### 1.3 操作按钮

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-RW-020 | 复制全文 | 点击复制按钮 | 所有服务结果合并复制到剪切板，< 100ms |
| TC-RW-021 | 一键翻译 | 点击翻译按钮 | 翻译窗口弹出，传入 OCR 文字 + 源语言，< 500ms |
| TC-RW-022 | 重新框选 | 点击重新识别 | 关闭当前 OCR 窗口 → 触发截图模式，< 300ms |
| TC-RW-023 | 系统 OCR toggle | 切换系统 OCR/在线 API | 对应服务结果为系统 OCR 或在线结果 |

### 1.4 多服务结果展示

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-RW-030 | 多服务结果独立 | 启用 3 个 OCR → 截图 | 3 个服务结果独立展示，不做合并 |
| TC-RW-031 | 结果不一致 | 百度 5 行 vs 腾讯 4 行 | 均展示，用户自行判断 |
| TC-RW-032 | 置信度低标注 | 模糊截图 → OCR | 标注"识别精度有限" |

## 二、边界与异常测试

| 编号 | 场景 | 输入 | 预期行为 | 恢复策略 |
|------|------|------|----------|----------|
| TC-RW-EDGE-01 | 截图无文字 | 纯色/风景截图 | OCR 返回空，显示"未检测到文字" | 提供"重新截图"按钮 |
| TC-RW-EDGE-02 | 截图模糊 | 低分辨率/极小截图 | OCR 置信度低，标注"识别精度有限" | 建议重新截取高清区域 |
| TC-RW-EDGE-03 | 图片过大 | > 10MB 截图 | Rust 层压缩到 <= 4MB 后上传 | 显示压缩提示 |
| TC-RW-EDGE-04 | 系统 OCR 不可用 | Linux 无系统 OCR | 系统 OCR 结果区显示"不可用" | 仅展示在线 API 结果 |
| TC-RW-EDGE-05 | 翻译窗口已存在 | OCR → 翻译时翻译窗口已开 | 在已有窗口追加文字（不替换） | Tauri event 发送新文字 |
| TC-RW-EDGE-06 | 剪贴板图片非截图 | 用户粘贴外部图片 | 走 OCR 流程，标注图片来源 | — |
| TC-RW-EDGE-07 | 截图原图大内存 | 4K 截图 Base64 | Rust 层缓存，JS 不持有原始大字符串 | — |
| TC-RW-EDGE-08 | 编辑后还原场景 | 大量修改后点击还原 | 完整恢复到原始 OCR 快照 | — |
