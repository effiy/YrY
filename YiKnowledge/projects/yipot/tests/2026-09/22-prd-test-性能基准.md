# 性能基准 — 测试方案

## 翻译性能

### TC-PERF-001: 划词翻译响应

| 步骤 | 选中 100 字文本 → 快捷键 |
| 预期 | 窗口弹出 + 翻译完成 < 1s |

### TC-PERF-002: 缓存命中

| 步骤 | 翻译 "Hello" → 关闭 → 再次翻译 "Hello" |
| 预期 | 第二次 < 100ms（缓存命中） |

## 内存测试

### TC-MEM-001: 空闲内存

| 步骤 | 启动后 5 分钟无操作 |
| 预期 | 内存 < 100MB |

### TC-MEM-002: 持续使用

| 步骤 | 连续翻译 50 次 |
| 预期 | 内存增长 < 50MB，无泄漏 |

## 启动测试

### TC-START-001: 冷启动

| 步骤 | 完全退出 → 启动 |
| 预期 | 托盘图标出现 < 2s |

### TC-START-002: 热启动

| 步骤 | 窗口已关闭 → 快捷键呼出翻译 |
| 预期 | 窗口弹出 < 500ms |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 长时间运行内存泄漏 (24h) | 开启所有功能 → 每小时翻译 10 次 → 持续 24h | 内存增长 < 50MB，无 OOM | P0 |
| TC-EDGE-02 | 高频翻译压力测试 | 1 分钟内连续翻译 60 次 (1 次/s) | 全部完成，无崩溃，无请求丢失 | P1 |
| TC-EDGE-03 | 大量缓存条目 | 翻译 1000 个不同短语后缓存池 | 缓存命中率 > 30%，查询 < 10ms | P2 |
| TC-EDGE-04 | 窗口反复创建/销毁 | 开/关翻译窗口 500 次 | 无 GDI/Window 句柄泄漏，内存稳定 | P1 |
| TC-EDGE-05 | Service Worker 唤醒延迟 | Chrome 休眠 SW → 触发翻译 | SW 唤醒 + 处理 < 2s | P1 |
| TC-EDGE-06 | 截图+OCR+翻译全链路 | 30 次连续截图 → OCR → 翻译 | 每次完成 < 3s，无累积劣化 | P1 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 内存压力下行为 | 系统内存 < 500MB 可用 → 触发翻译 | 正常翻译或降级 (减少缓存)，不崩溃 | 内存恢复后全功能 |
| TC-ERR-02 | CPU 满载下响应 | CPU 100% (挖矿/编译) → 触发快捷键 | 窗口弹出 < 2s (尽力)，不 ANR | CPU 空闲后正常 |
| TC-ERR-03 | 磁盘空间满 | 磁盘 0 字节可用 → 缓存写入 | 缓存写入失败静默跳过，不崩溃 | 清理磁盘后缓存恢复 |
| TC-ERR-04 | 500 次翻译后性能劣化 | 翻译 500 次 → 对比第 1 次和第 500 次延迟 | P95 增长 < 50% | 重启后恢复基线 |

## 增强性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 划词翻译端到端 | P50/P95/P99 | ≤ 500/1000/2000ms | > 800/1500/3000ms | 100 次 50 字中译英 |
| TC-PERF-02 | 缓存命中响应 | P50/P95 | ≤ 10/30ms | > 30/100ms | 50 次命中 |
