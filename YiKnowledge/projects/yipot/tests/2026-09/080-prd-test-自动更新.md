# 自动更新 — 测试方案

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-UPD-01 | 无新版本 | 静默，不弹窗 |
| TC-UPD-02 | 有新版本 | 弹窗显示版本号 + 更新日志 |
| TC-UPD-03 | 下载成功 | 校验通过，提示安装 |
| TC-UPD-04 | 下载中断 | 断点续传或提示重试 |
| TC-UPD-05 | SHA256 不匹配 | 拒绝安装，重新下载 |
| TC-UPD-06 | 更新服务器不可达 | 静默失败，不影响使用 |

## 性能基准

| 场景 | 基准 |
|------|------|
| 检查更新 | < 3s |
| 下载 50MB | < 60s (稳定网络) |

## 回归检查

- [ ] 启动时检查更新（非阻塞）
- [ ] 有更新时弹窗
- [ ] 下载进度显示
- [ ] 安装后配置不丢失

## 边界与异常测试

| 场景 | 操作步骤 | 预期结果 |
|------|----------|----------|
| GitHub API 限流 (403) | 短时间内多次检查更新 | 退避等待后重试，不弹错误提示 |
| 网络完全断开 | 断网后点击"检查更新" | 静默失败，提示"无法连接更新服务器" |
| 磁盘空间不足（安装包 2x 需要空间不足） | 模拟小磁盘分区 | 下载前检查空间，不足时提示清理 |
| 下载过程中网络中断 | 下载 50% 时断网 | 断点续传恢复后从 50% 继续 |
| SHA256 校验故意不匹配 | 篡改下载文件后校验 | 拒绝安装，提示重新下载 |
| 安装过程中用户强制关机 | 安装到一半重启系统 | 重启后旧版本仍可正常运行 |
| macOS 公证验证失败 | 未签名的 .dmg 安装包 | Gatekeeper 拦截，引导用户手动允许 |
| 版本号非标准格式 (v1.2.3-beta.1) | GitHub 发布 pre-release 版本 | 正确解析 semver，不崩溃 |

## 性能基准测试

| 场景 | 测试方法 | 基准 |
|------|----------|------|
| 检查更新 | `check_update()` 调用到结果返回（有缓存） | < 500ms |
| 检查更新 | `check_update()` 调用到结果返回（无缓存/首次） | < 3s |
| 50MB 下载 | 本地 100Mbps 网络 | < 60s |
| SHA256 校验（50MB） | Rust `sha2` crate 计算 | < 500ms |
| 更新弹窗渲染 | 从检查完成到弹窗可交互 | < 200ms |

## 回归测试清单

- [ ] 启动时自动检查更新（异步非阻塞，不延迟主窗口）
- [ ] 有新版本时弹窗显示版本号 + Markdown 更新日志
- [ ] 下载进度条实时更新（无卡顿）
- [ ] SHA256 校验通过后方可安装
- [ ] 安装完成后用户配置和 API Key 不丢失
- [ ] 静默失败场景：网络不可达不弹任何提示
