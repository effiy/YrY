# Google 翻译 — 测试方案

## 核心功能测试

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-GG-01 | 无需 API Key | 不配置任何 Key → 翻译 en→zh | 正常返回翻译结果 |
| TC-GG-02 | 中译英 | "你好世界" zh→en | 返回 "Hello World" |
| TC-GG-03 | 英译中 | "Artificial Intelligence" en→zh | 返回 "人工智能" |
| TC-GG-04 | 日译中 | "こんにちは" ja→zh | 返回日译中翻译 |
| TC-GG-05 | 韩译英 | "안녕하세요" ko→en | 返回韩译英翻译 |
| TC-GG-06 | 自动语言检测 | 翻译 "Bonjour" (未指定源语言) | 自动检测为法语，正确翻译 |
| TC-GG-07 | 检测日语 | 翻译日语句子 (auto detect) | detectedLanguage=ja |
| TC-GG-08 | 检测韩语 | 翻译韩语句子 (auto detect) | detectedLanguage=ko |
| TC-GG-09 | 返回检测结果 | 任意文本 auto→zh | 响应含 detectedLanguage 字段 |
| TC-GG-10 | 100+ 语言支持 | 遍历已知语言列表 | 每种可用语言均返回翻译 |
| TC-GG-11 | 长文本翻译 | 翻译 3000 字符段落 | 正常返回完整翻译 |
| TC-GG-12 | 特殊字符文本 | "C++ & Java" en→zh | 特殊字符保留，正常翻译 |
| TC-GG-13 | Emoji 混合 | "I love 🍕" en→zh | Emoji 保留，翻译文字部分 |

## 增强边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-GG-E01 | 空文本 | "" | 不发起请求 | P1 |
| TC-GG-E02 | 超长文本 (> 5000 字符) | 5000+ 字符 | 正常返回或分段处理 | P1 |
| TC-GG-E03 | 纯数字 | "12345" | 返回原文本 | P3 |
| TC-GG-E04 | 纯标点符号 | "!!!???..." | 返回原文本 | P3 |
| TC-GG-E05 | 相同源语言和目标语言 | "Hello" en→en | 返回原文本 | P2 |
| TC-GG-E06 | Google 服务不可用 | 模拟网络不通 | 显示"Google 翻译服务不可用" | P1 |
| TC-GG-E07 | 返回格式异常 | Mock 非标准 JSON | 显示"解析翻译结果失败" | P1 |
| TC-GG-E08 | 检测置信度低 | 混合语言文本 "Hello 你好" | 检测为置信度最高的语言 | P2 |
| TC-GG-E09 | 并发请求限流 | 短时间 20 次请求 | 触发限流后正确提示，不崩溃 | P1 |
| TC-GG-E10 | 离线状态 | 完全断网 | 显示网络错误提示，降级到离线服务 | P1 |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-GG-P01 | 短文本翻译 | P50/P95/P99 | ≤ 150/300/500ms | > 300/600/1000ms | 100 次采样 |
| TC-GG-P02 | 长文本翻译 (3000 字符) | P50/P95 | ≤ 400/800ms | > 800/1600ms | 20 次采样 |
| TC-GG-P03 | 自动语言检测 | P50 | ≤ 200ms | > 400ms | 50 次采样 |
| TC-GG-P04 | 缓存命中 (相同文本) | P50 | ≤ 10ms | > 30ms | 50 次命中 |
| TC-GG-P05 | 首次请求冷启动 | 端到端 | ≤ 500ms | > 1000ms | 10 次测量 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-GG-S01 | 无 API Key 泄露风险 | 检查配置/日志 | 无 Key 可泄露 (本身无需 Key) | P1 |
| TC-GG-S02 | 翻译内容不写磁盘 | 翻译敏感文本后检查 | 翻译请求/响应不缓存到磁盘 | P1 |
| TC-GG-S03 | HTTPS 连接 | 抓包检查 | 使用 HTTPS，无明文传输 | P1 |
