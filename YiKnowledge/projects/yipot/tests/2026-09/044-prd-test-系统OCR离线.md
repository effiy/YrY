# 系统 OCR 离线识别 — 测试方案

## 核心功能测试

### macOS Vision Framework

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SOC-01 | 中文识别 | 截图中文段落 → 系统 OCR | 正确识别中文，准确率 ≥ 95% |
| TC-SOC-02 | 英文识别 | 截图英文段落 → 系统 OCR | 正确识别英文，准确率 ≥ 97% |
| TC-SOC-03 | 日文识别 | 截图日文段落 → 系统 OCR | 正确识别日文 (假名+汉字) |
| TC-SOC-04 | 韩文识别 | 截图韩文段落 → 系统 OCR | 正确识别韩文 |
| TC-SOC-05 | 法文识别 | 截图法文段落 → 系统 OCR | 正确识别法文 (含变音符号) |
| TC-SOC-06 | 德文识别 | 截图德文段落 → 系统 OCR | 正确识别德文 (含 Umlaut) |
| TC-SOC-07 | 中英混合 | 截图中英混合段落 | 两种语言均正确识别 |
| TC-SOC-08 | 离线可用 | 断网 → 系统 OCR 中英文 | 正常识别，无需网络 |
| TC-SOC-09 | 竖排中文 | 截图竖排中文文本 | 正确识别竖排文字 |
| TC-SOC-10 | 多列文本 | 截图多列排版 | 按正确排序识别 |

### Windows OCR Engine

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SOC-20 | 系统语言识别 | 截图 Windows 系统语言文本 | 正确识别已安装语言包的语言 |
| TC-SOC-21 | 离线可用 | 断网 → Windows OCR | 正常识别，无需网络 |
| TC-SOC-22 | 语言包缺失 | 未安装目标语言包 | 提示"请安装对应语言包" |
| TC-SOC-23 | 不同字体 | 截图 Serif/Sans/Mono 字体 | 字体差异不影响识别 |

### 通用功能

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-SOC-30 | 无需 API Key | 无任何 API Key 配置 | OCR 正常工作 |
| TC-SOC-31 | 识别速度 | 截图 400x300 → OCR | 耗时 ≤ 1s |
| TC-SOC-32 | 识别结果可翻译 | 系统 OCR 结果 → 翻译 | 识别文本作为翻译输入 |
| TC-SOC-33 | 语言参数传递 | 指定 language="zh-Hans" | 按指定语言识别 |

## 增强边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-SOC-E01 | 空白截图 | 截图无文字区域 | 返回空字符串 | P1 |
| TC-SOC-E02 | 超低对比度 | 浅灰文字 + 浅灰背景 | 尽力识别，准确率可降低 | P2 |
| TC-SOC-E03 | 极小字号 | 截图 6pt 文字 | 尽力识别，可能失败 | P2 |
| TC-SOC-E04 | 旋转文字 | 截图倾斜 30 度文字 | macOS 可识别，Windows 可能失败 | P2 |
| TC-SOC-E05 | 手写体文字 | 截图手写英文 | 尽力识别，准确率约 70-80% | P3 |
| TC-SOC-E06 | 背景水印干扰 | 文字叠加水印背景 | 主要文字正确识别，忽略水印 | P2 |
| TC-SOC-E07 | 不支持的语言 | macOS 9 种以外的语言 | 返回空或提示不支持 | P2 |
| TC-SOC-E08 | macOS 版本 < 10.15 | 模拟旧系统 | 提示系统版本不支持 Vision | P2 |
| TC-SOC-E09 | 超大截图 (8K) | 7680x4320 截图 | 正常识别，耗时 ≤ 3s | P1 |
| TC-SOC-E10 | Vision 请求失败 | 模拟 VNRecognizeTextRequest 错误 | 重试 1 次，失败则提示 | P1 |
