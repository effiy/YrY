# 剪切板监听 — 测试方案

## 功能测试

### TC-CL-001: 开启监听

| 步骤 | 点击剪切板监听按钮 |
| 预期 | 状态指示灯变绿，提示"监听已开启" |

### TC-CL-002: 复制触发翻译

| 步骤 | 开启监听 → 复制 "Hello World" |
| 预期 | 1s 内自动显示翻译结果 |

### TC-CL-003: 关闭监听

| 步骤 | 再次点击监听按钮 |
| 预期 | 指示灯变灰，复制文本不再触发翻译 |

### TC-CL-004: 状态持久化

| 步骤 | 开启监听 → 关闭应用 → 重新打开 |
| 预期 | 监听状态保持开启 |

## 去重测试

### TC-CL-010: 重复内容不翻译

| 步骤 | 复制 "Hello" → 翻译完成 → 再次复制 "Hello" |
| 预期 | 不触发新的翻译请求 |

### TC-CL-011: 新内容触发翻译

| 步骤 | 复制 "Hello" → 翻译 → 复制 "World" |
| 预期 | 第二次触发新翻译 |

## 边界测试

### TC-CL-E01: 复制图片

| 步骤 | 复制图片文件到剪切板 |
| 预期 | 不触发翻译，无报错 |

### TC-CL-E02: 复制空内容

| 步骤 | 复制空白文本 |
| 预期 | 不触发翻译 |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 空文本复制 | 复制空白字符串 | 不触发翻译 | P1 |
| TC-EDGE-02 | 单字符复制 | 复制 "a" | 正常触发翻译 | P2 |
| TC-EDGE-03 | 超长文本复制 (100000 字) | 复制 100000 字文本 | 超出阈值时提示或截断 | P1 |
| TC-EDGE-04 | 富文本复制 | 从 Word 复制格式化文本 | 提取纯文本后翻译 | P2 |
| TC-EDGE-05 | HTML 片段复制 | 复制含 HTML 标签的文本 | 提取纯文本 | P2 |
| TC-EDGE-06 | 文件复制 | 复制文件 (非文本) | 不触发翻译 | P2 |
| TC-EDGE-07 | 密码/银行卡复制 | 复制 "6217001234567890" | 仍触发翻译 (功能设计如此，用户需自行关闭监听) | P2 |
| TC-EDGE-08 | 多语言混合复制 | 复制混合语言文本 | 正确检测主语言 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 剪切板读取权限不足 | macOS 关闭辅助功能权限 | 监听按钮提示需要权限 | 授权后正常 |
| TC-ERR-02 | 系统剪切板被锁定 | 其他程序独占剪切板 | 读取失败后静默等待，下次轮询重试 | 锁释放后正常 |
| TC-ERR-03 | 剪切板内容为空/损坏 | 复制损坏的剪切板内容 | 不触发翻译，无报错 | — |
| TC-ERR-04 | 快速连续复制 | 100ms 内连续复制 5 次 | 防抖处理，仅翻译最后一次内容 | 历史翻译请求取消 |
| TC-ERR-05 | 监听过程中应用崩溃 | 翻译中 Kill 进程 | 下次启动监听状态恢复 | 状态持久化正常 |
| TC-ERR-06 | 剪切板大数据量 | 复制 10MB 图片 | 仅处理文本，跳过非文本数据 | 不影响后续文本复制 |
| TC-ERR-07 | 剪切板格式切换 | 先复制文本 → 再复制图片 → 再复制文本 | 正确判断文本变更触发翻译 | — |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 剪切板轮询周期 | 复制到检测间隔 | ≤ 500ms | > 1s | 20 次采样 |
| TC-PERF-02 | 复制到翻译窗口弹出 | 端到端时延 | ≤ 1s | > 2s | 20 次采样 |
| TC-PERF-03 | 剪切板监听 CPU 占用 (空闲) | CPU% | ≤ 0.5% | > 2% | 监听开启无复制时的稳态 |
| TC-PERF-04 | 去重判断 | 相同文本重新复制的处理 | ≤ 50ms | > 200ms | 对比 hash 计算 |
| TC-PERF-05 | 内存占用 (监听中) | 内存增量 | ≤ 10MB | > 30MB | 对比监听开关前后的内存 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 复制密码时监听 | 复制 "password123" | 触发翻译（设计行为），需提示可关闭 | P2 |
| TC-SEC-02 | 剪切板内容不写日志 | 开启监听 → 复制敏感文本 → 检查日志 | 日志不记录剪切板内容 | P1 |
| TC-SEC-03 | 剪切板内容不持久化 | 复制文本 → 重启应用 | 重启后剪切板内容不从磁盘恢复 | P1 |
| TC-SEC-04 | 其他应用可读取剪切板的影响 | 其他剪切板插件同时运行 | 不冲突，各自独立轮询 | P3 |
| TC-SEC-05 | 剪切板监听关闭确认 | 关闭监听后立即复制 | 不再读取剪切板内容 | P1 |
