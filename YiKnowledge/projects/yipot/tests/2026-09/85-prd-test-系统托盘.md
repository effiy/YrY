# 系统托盘与通知 — 测试方案

> **文档职责**：验证系统托盘图标、右键菜单、单实例检测和通知功能的正确性。

---

## 一、测试层级

```
系统托盘与通知
├── 托盘图标
│   ├── macOS 模板图标
│   ├── Windows/Linux 彩色图标
│   └── 托盘图标状态变化
├── 托盘菜单
│   ├── 菜单项完整性
│   ├── 菜单项可用性
│   ├── 菜单项勾选状态
│   └── 分隔线布局
├── macOS 特殊行为
│   ├── 无 Dock 图标
│   ├── ActivationPolicy::Accessory
│   └── 状态栏保留
├── 单实例检测
│   ├── 重复启动拦截
│   └── 通知提示
└── 通知
    ├── 系统通知显示
    └── 通知交互
```

## 二、核心测试用例

### 2.1 托盘图标

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-TRAY-001 | macOS 托盘图标显示 | 在 macOS 上启动 Pot | 菜单栏出现模板图标 (黑白适配) | P1 |
| TC-TRAY-002 | Windows 托盘图标显示 | 在 Windows 上启动 Pot | 系统托盘出现彩色图标 | P1 |
| TC-TRAY-003 | Linux 托盘图标显示 | 在 Linux 上启动 Pot | 系统托盘出现彩色图标 | P1 |
| TC-TRAY-004 | 托盘图标暗色模式适配 (macOS) | macOS 切换暗色模式 | 图标变为白色轮廓 | P2 |
| TC-TRAY-005 | 托盘图标亮色模式适配 (macOS) | macOS 切换亮色模式 | 图标变为黑色轮廓 | P2 |
| TC-TRAY-006 | 托盘图标右键响应 | 右键点击托盘图标 | 弹出托盘菜单 | P1 |
| TC-TRAY-007 | 托盘图标左键响应 | 左键点击托盘图标 | 弹出托盘菜单 (与右键一致) | P2 |

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |

| TC-MENU-003 | 输入翻译菜单操作 | 点击"输入翻译" | 打开输入翻译窗口 | P1 |

| TC-MENU-006 | 设置菜单操作 | 点击"设置" | 打开设置窗口 | P1 |

### 2.3 macOS 特殊行为

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-MAC-001 | 无 Dock 图标 | macOS 启动 Pot | Dock 中不出现 Pot 图标 | P1 |
| TC-MAC-002 | 仅托盘运行 | 关闭所有窗口 | 应用不退出，仅保留托盘图标 | P1 |
| TC-MAC-003 | Cmd+Tab 不出现 | 切换应用 (Cmd+Tab) | Pot 不在应用切换列表中 | P1 |
| TC-MAC-004 | 菜单栏图标始终可见 | 全屏应用下 | 菜单栏托盘图标不隐藏 | P2 |
| TC-MAC-005 | 从启动项启动 | 添加到登录项 → 重启 | 托盘图标自动出现 | P2 |

### 2.4 单实例检测

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-SINGLE-001 | 重复启动拦截 | Pot 已运行 → 再次双击启动 | 弹出系统通知"程序已在运行，请勿重复启动" | P1 |
| TC-SINGLE-002 | 命令行重复启动 | `pot` 终端启动 → 再执行 `pot` | 第二个实例检测到已运行，退出并通知 | P2 |
| TC-SINGLE-003 | 重复启动通知可关闭 | 收到重复启动通知 → 点击关闭 | 通知消失，不影响已运行的实例 | P2 |
| TC-SINGLE-004 | 跨用户实例隔离 | 用户A启动 → 用户B启动 (同机器) | 各自运行，不冲突 (macOS 用户隔离) | P3 |

## 三、边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 托盘菜单快速开关 | 1 秒内连续打开/关闭菜单 10 次 | 菜单正常显示/消失，不残留 | P2 |
| TC-EDGE-02 | 系统托盘区已满 (Windows) | Windows 隐藏图标溢出区 | 托盘图标进入溢出区，功能正常 | P3 |
| TC-EDGE-03 | 菜单项超长文字 | 系统语言设置为超长翻译 | 菜单文字截断或自适应宽度 | P3 |
| TC-EDGE-04 | 系统通知堆叠 | 同时 5 条通知 | 通知排队显示，不丢失 | P2 |
| TC-EDGE-05 | macOS 菜单栏图标被隐藏 | Bartender 等工具隐藏菜单栏图标 | 托盘功能仍可通过系统托盘菜单访问 | P3 |
| TC-EDGE-06 | 托盘菜单打开时失去焦点 | 打开托盘菜单 → 点击桌面 | 菜单关闭 | P3 |
| TC-EDGE-07 | 系统语言切换 | 托盘菜单打开时切换系统语言 | 菜单文字在下次打开时更新 | P3 |
| TC-EDGE-08 | 高分屏托盘图标 | 4K 200% 缩放 | 图标清晰不模糊 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 系统托盘创建失败 | Linux 无托盘服务 (如无 gnome-shell-extension-appindicator) | 降级为普通窗口运行，不崩溃 | 安装托盘服务后正常 |
| TC-ERR-02 | 通知服务不可用 | Linux 无通知守护进程 | 静默忽略通知，不影响功能 | 启动通知服务后恢复正常 |
| TC-ERR-03 | 托盘图标文件缺失 | 删除图标资源文件 → 启动 | 使用默认图标或占位符 | 恢复图标文件后正常 |
| TC-ERR-04 | 单实例锁文件残留 | 上次异常退出 → 锁文件未清理 | 启动时清理过期锁，正常启动 | — |
| TC-ERR-05 | 托盘崩溃恢复 | 托盘进程被 kill | 应用继续运行 (无托盘)，日志记录错误 | 重启后托盘恢复 |
| TC-ERR-06 | macOS Accessibility 无托盘 | 使用 `Accessory` + 无屏幕 | 仍然运行，菜单栏不可见但功能正常 | — |

## 四、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试工具 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 托盘图标创建 | 启动到托盘图标出现 | ≤ 1s | > 3s | 冷启动计时 |
| TC-PERF-02 | 右键菜单弹出延迟 | 右键点击到菜单显示 | ≤ 200ms | > 500ms | 10 次采样 |
| TC-PERF-03 | 菜单项点击响应 | 点击到操作触发 | ≤ 100ms | > 300ms | 10 次采样 |
| TC-PERF-04 | 单实例检测 | 第二个实例启动到通知 | ≤ 1s | > 3s | 10 次采样 |
| TC-PERF-05 | 系统通知延迟 | 事件触发到通知显示 | ≤ 500ms | > 1s | OS 通知耗时 |
| TC-PERF-06 | 托盘内存占用 | 仅托盘运行 (无窗口) | ≤ 30MB | > 80MB | 稳态内存 |
