# 百度/腾讯 OCR — 测试方案

## 百度 OCR

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-BDOCR-01 | 通用中英 | 截中文段落 → 百度通用 | 正确识别 |
| TC-BDOCR-02 | 精准+位置 | 截文字 → 百度精准 | 返回文字 + location 坐标 |
| TC-BDOCR-03 | 图片格式 | WebP 图片 → 百度图片 | 正确识别 |

## 腾讯 OCR

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-TXOCR-01 | 通用识别 | 文字正确返回 |
| TC-TXOCR-02 | 签名验证 | 错误 SecretKey → 认证失败提示 |

## 性能基准

| 场景 | P50 | P95 |
|------|-----|-----|
| 百度通用 | 500ms | 1s |
| 百度精准 | 800ms | 1.5s |
| 腾讯通用 | 500ms | 1s |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 百度 OCR 空图片 | 纯白/纯黑图片 | 返回空结果或提示"未检测到文字" | P1 |
| TC-EDGE-02 | 百度 OCR 图片超限 | 8K+ 分辨率图片 base64 编码后超 4MB | 提示"图片过大，请缩小后重试" | P1 |
| TC-EDGE-03 | 百度精准 OCR 多角度文字 | 倾斜 30° 的文字截图 | 位置坐标正确，识别准确率可接受 | P2 |
| TC-EDGE-04 | 腾讯 OCR 不支持的语言 | 截图阿拉伯语/泰语文字 | 返回空或提示"不支持的语言" | P2 |
| TC-EDGE-05 | 百度表格 OCR | 截图含表格线 | 正确识别表格结构和内容 | P2 |
| TC-EDGE-06 | 腾讯 OCR 图片格式 (WebP/GIF) | 上传 WebP 格式截图 | 若 API 不支持则自动转为 PNG 后上传 | P2 |
| TC-EDGE-07 | 百度 OCR 单字符识别 | 截图仅含 "A" | 正确识别单个字符，含位置信息 | P3 |
| TC-EDGE-08 | 混合字体/字号文本 | 截图中文字 14pt 中文 + 10pt 英文 | 两种语言均正确识别 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 百度 OCR AppID/Secret 无效 | 错误凭据 → 调用 OCR | 显示"认证失败，请检查 AppID/Secret" | 修正凭据后正常 |
| TC-ERR-02 | 百度 OCR 每日配额耗尽 | 达到免费额度上限 | 显示"当日识别额度已用完" | 次日重置后正常 |
| TC-ERR-03 | 腾讯 OCR SecretKey 错误 | 错误 SecretKey → 签名失败 | 显示"签名验证失败" | 修正后正常 |
| TC-ERR-04 | 百度 OCR 服务降级 (500) | 百度 OCR API 返回 5xx | 显示"百度 OCR 服务暂时不可用" | 恢复后正常 |
| TC-ERR-05 | 图片 base64 编码损坏 | 截断的 base64 数据 → OCR | 显示"图片数据异常，请重新截图" | 重新截图正常 |
| TC-ERR-06 | 网络超时 | Mock 百度 OCR 超时 | 显示超时提示，不阻塞其他 OCR 服务 | 网络恢复后正常 |
| TC-ERR-07 | 并发 OCR 请求限制 | 10 个 OCR 请求同时发出 | 请求排队或触发频率限制，不全部失败 | — |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 百度 OCR AppID/Secret 加密存储 | 检查配置存储 | 不以明文存储 | P0 |
| TC-SEC-02 | 腾讯 OCR SecretKey 加密存储 | 检查配置存储 | 不以明文存储 | P0 |
| TC-SEC-03 | 截图数据仅发送到目标 OCR API | 抓包检查 OCR 请求 | 图片仅发送到配置的 OCR 服务 endpoint | P0 |
| TC-SEC-04 | HTTPS 强制连接 | 配置 HTTP OCR endpoint | 确保 TLS 加密或警告不安全 | P1 |
| TC-SEC-05 | OCR 结果不缓存到磁盘 | OCR 含敏感文字后检查 | 识别结果和图片不写入磁盘缓存 | P1 |
