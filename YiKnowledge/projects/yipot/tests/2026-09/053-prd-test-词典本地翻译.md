# 词典与本地翻译 — 测试方案

> 覆盖 YP-09-S20：必应词典、剑桥词典、ECDICT 本地词典、Lingva 自托管翻译

---

## 一、核心功能测试

### 1.1 必应词典 (bing_dict)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-DICT-01 | 英文单词查询 | 选中英文单词 → 触发词典查询 | 返回音标、词性、释义、例句 |
| TC-DICT-02 | 中文词汇查询 | 选中中文词汇 → 触发查询 | 返回对应英文释义 |
| TC-DICT-03 | 无结果单词 | 输入不存在的单词"asdfgh" | 返回提示"未找到该单词" |
| TC-DICT-04 | API 无需 Key | 不配置任何 Key → 查询 | 正常返回结果（免费服务） |

### 1.2 剑桥词典 (cambridge_dict)

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-DICT-10 | 英英释义查询 | 查询"serendipity" | 返回英文释义 + 英文例句 |
| TC-DICT-11 | 词性标注 | 查询"lead" | 标注多词性（动词/名词）|
| TC-DICT-12 | 学习型例句 | 查询基础词汇 | 例句适合英语学习者理解 |

### 1.3 ECDICT 本地词典

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-DICT-20 | 离线查词 | 断开网络 → 查词 | 从本地词库返回结果 |
| TC-DICT-21 | 冷启动加载 | 首次加载本地词库 | 词库加载完成 < 2s |
| TC-DICT-22 | 词库缺失 | 删除本地词库文件 → 查词 | 提示"词库文件未找到" |
| TC-DICT-23 | 快速响应 | 本地查 100 个单词取均值 | P95 < 50ms（无网络延迟） |

### 1.4 Lingva 自托管

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-DICT-30 | 自定义服务器 | 填入自建 Lingva 地址 → 翻译 | 使用自建实例完成翻译 |
| TC-DICT-31 | 服务器不可达 | 填入不存在的地址 → 翻译 | 提示"服务器连接失败" |
| TC-DICT-32 | 默认服务器 | 不填地址，使用默认公共实例 | 正常翻译（公共实例可用时） |

### 1.5 词典服务集成

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-DICT-40 | 单词查询自动激活 | 划词长度 <= 3 个单词 → 翻译 | 词典服务自动参与并行调度 |
| TC-DICT-41 | 长句不激活词典 | 划词长度 > 5 个单词 → 翻译 | 词典服务不参与，仅翻译服务 |
| TC-DICT-42 | 词典服务排序 | 在设置中调整词典服务优先级 | 结果按用户设置的优先级排列 |

## 二、边界与异常测试

| 编号 | 场景 | 输入 | 预期行为 | 恢复策略 |
|------|------|------|----------|----------|
| TC-DICT-EDGE-01 | 空文本查询 | 空字符串 | 不发起查询，静默忽略 | — |
| TC-DICT-EDGE-02 | 纯标点符号 | "!!!???" | 返回空结果或"无匹配" | — |
| TC-DICT-EDGE-03 | 超长单词 | 200+ 字符的拼接字符串 | 截断或返回"无效单词" | — |
| TC-DICT-EDGE-04 | 特殊 Unicode 字符 | "cafe"（含变音符） | 正确处理 Unicode，返回结果 | — |
| TC-DICT-EDGE-05 | ECDICT 词库文件损坏 | 二进制损坏的 .db 文件 | 提示"词库文件已损坏，请重新下载" | 引导用户重新下载词库 |
| TC-DICT-EDGE-06 | 必应词典网络超时 | 网络延迟 > 10s | 显示"必应词典暂不可用"，不影响其他服务 | 下次查询自动恢复 |
| TC-DICT-EDGE-07 | Lingva 自签证书 | 自建 Lingva 使用自签名 TLS | 显示证书警告，提供信任选项 | — |
| TC-DICT-EDGE-08 | 词库文件路径含空格 | 词库放在含空格的路径 | 正常加载，路径正确转义 | — |
| TC-DICT-EDGE-09 | ECDICT 编码错误 | 词库文件非 UTF-8 编码 | 使用 fallback 编码，或提示错误 | 建议使用标准词库 |

## 三、性能基准测试

## 四、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-DICT-SEC-01 | Lingva 服务器地址校验 | 填入 `http://internal-server` | 允许 HTTP（内网场景），但不推荐 | P2 |
| TC-DICT-SEC-02 | Lingva URL 注入 | 填入恶意 URL 含 JS 代码 | URL 作为纯文本处理，不被执行 | P1 |
| TC-DICT-SEC-03 | 本地词库完整性 | 对比词库文件 SHA256 | 与官方词库指纹一致 | P2 |
| TC-DICT-SEC-04 | 必应词典请求不泄露 | 检查必应 API 请求头 | 不含用户隐私信息，仅发送查询词 | P1 |
