## 一、通用翻译服务测试

### TC-TSP-001: 百度翻译基本功能

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 配置有效的百度 AppID + Secret | 保存成功 |

## 六、增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 空文本 | 空字符串 "" | 提示"请输入文本"或返回空白 | P1 |
| TC-EDGE-02 | 超长文本 (10000 字) | 10000 字文本 | 部分服务可能截断或报错，需统一处理 | P1 |
| TC-EDGE-03 | 含 XML/HTML 的文本 | "<p>Hello</p>" | 所有服务正确处理标签，无注入 | P1 |
| TC-EDGE-04 | 含 Markdown 的文本 | "**bold** and *italic*" | 根据服务能力处理格式化标记 | P2 |
| TC-EDGE-05 | 稀有语言对 | 中文→冰岛语 | 部分服务不支持，应提示或降级 | P2 |
| TC-EDGE-06 | 无网络时云端服务 | 断网 → 百度/Google 翻译 | 显示网络错误 | P1 |
| TC-EDGE-07 | 混合 API 协议 | 同时使用 REST + WebSocket 服务 | 各自独立处理，不互相阻塞 | P3 |
| TC-EDGE-08 | 服务语言对不匹配 | 百度翻译设为 zh→冰岛语 | 百度不支持 → 显示"不支持的语种" | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 21 个服务同时启用 | 全部勾选 → 翻译 | UI 可滚动，不崩溃 | 禁用部分后正常 |
| TC-ERR-02 | 翻译 API 限流 (429) | 高频触发翻译触发限流 | 显示"请求过于频繁，请稍后重试" | 冷却后正常 |
| TC-ERR-03 | 翻译 API 返回 500 | Mock 服务器错误 | 显示"服务不可用" | 服务恢复后正常 |
| TC-ERR-04 | 百度签名算法变更 | 百度 API v2→v3 迁移 | 服务标记为不可用，更新后可用 | 插件更新后可配 |
| TC-ERR-05 | 词典服务数据损坏 | ECDICT 本地数据损坏 | 提示重新下载词典数据 | 重新下载后正常 |
| TC-ERR-06 | 多个词典同时查询 | 启用 3 个词典 → 查询 | 3 个结果并排显示 | — |
| TC-ERR-07 | 服务配置热切换 | 翻译过程中启用/禁用服务 | 当前请求不受影响，下次生效 | 配置立即生效 |
