### TC-YD-001: 基本翻译

| 步骤 | 配置 AppKey+Secret → 翻译 "Hello" en→zh |
| 预期 | 返回中文翻译 + 可能含词典释义 |

| 步骤 | 翻译单词 "apple" en→zh |

## 增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 空文本 | 空字符串 "" | 前端拦截，不发起请求 | P1 |
| TC-EDGE-02 | 超长文本 (5000+ 字符) | 有道 API 单次限制 ~5000 字符 | 截断提示或分段翻译 | P1 |
| TC-EDGE-03 | 不支持的语言对 | 中文→冰岛语 | 显示"不支持的语言方向" | P2 |
| TC-EDGE-04 | 有道词典模式 vs 翻译模式 | 翻译单词 "run" | 返回词典结果 (释义 + 词组 + 例句) vs 翻译结果 | P2 |
| TC-EDGE-05 | 有道语音朗读 | 翻译后点击朗读按钮 | 调用有道 TTS，正确发音 | P3 |
| TC-EDGE-06 | 含 HTML 实体的文本 | `&amp; &lt; &gt;` 翻译 | 正确解析 HTML 实体后翻译 | P2 |
| TC-EDGE-07 | 纯数字文本 | "12345" | 原样返回不翻译 | P3 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 签名错误 (202) | 篡改 Secret | 显示"签名检验失败 (202)" | 修正 Secret 后正常 |
| TC-ERR-02 | AppKey 无效 (101) | 使用不存在的 AppKey | 显示"AppKey 无效 (101)" | 修正 AppKey 后正常 |
| TC-ERR-03 | 账户欠费 (401) | 使用配额耗尽的 Key | 显示"账户欠费，请充值" | 充值后生效 |
| TC-ERR-04 | 超过并发限制 (411) | 短时间内高频请求 | 显示"访问频率受限"，自动降速 | 频率控制后恢复 |
| TC-ERR-05 | 有道 API 服务降级 | 有道返回 500/503 | 显示"有道翻译服务暂时不可用" | 恢复后正常 |
| TC-ERR-06 | 网络超时 | Mock 超时无响应 | 显示超时提示，不阻塞其他服务 | 网络恢复后正常 |
| TC-ERR-07 | 返回数据格式异常 | Mock 非标准 JSON | 显示"解析翻译结果失败" | 不影响其他服务 |
