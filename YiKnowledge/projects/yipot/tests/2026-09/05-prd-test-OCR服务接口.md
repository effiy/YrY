|------|-----------------|

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 空白图片 | 纯白色 1920x1080 PNG | 返回空结果或"未识别到文字" | P1 |

| TC-EDGE-03 | 极大文字 (72pt) | 截取 72pt 标题 | 正常识别 | P3 |
| TC-EDGE-04 | 彩色文字 (红/蓝/绿) | 截取彩色文字截图 | 正确识别颜色文字 | P2 |
| TC-EDGE-05 | 艺术字体/手写体 | 截取艺术字体标题 | 部分识别或无法识别 | P2 |
| TC-EDGE-06 | 二维码 + 文字混合 | 截取含文字说明的二维码 | 二维码服务识别码，OCR 识别文字 | P2 |
| TC-EDGE-07 | 图片含表格 | 截取表格区域 | 按行/列识别，保留结构信息 | P2 |

| TC-EDGE-09 | 透明背景图片 | 截取含透明区域的 PNG | 正确处理透明通道 | P3 |
| TC-EDGE-10 | 低对比度文字 | 浅灰文字在白色背景 | 低置信度或无法识别 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 百度 OCR API 配额耗尽 | 超出每日免费额度 | 显示"API 配额已用尽" | 次日重置后正常 |
| TC-ERR-02 | 腾讯 OCR Secret 过期 | 临时凭证过期 | 显示"认证失败" | 更新凭证后恢复 |
| TC-ERR-03 | Tesseract 语言包下载中断 | 下载中切断网络 | 下载失败提示，可重试 | 重新下载成功后可用 |
| TC-ERR-04 | macOS 系统 OCR 语言不支持 | 日语文本在无日语包的系统 | 降级提示或返回空 | 安装语言包后可用 |
| TC-ERR-05 | 合合信息 OCR 图片格式不支持 | 发送 WebP 格式图片 | 提示格式不支持或自动转换 | 转换 PNG 后正常 |
| TC-ERR-06 | 二维码识别的码已损坏 | 截图破损的二维码 | 解码失败提示 | 不影响其他 OCR 服务 |
| TC-ERR-07 | LaTeX 公式渲染异常 | 截图畸形的数学表达式 | 返回空或部分识别 | — |
| TC-ERR-08 | 火山 OCR 不支持的语言 | 输入不支持的小语种图片 | 提示语种不支持 | 切换到支持该语种的服务 |

## 八、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 本地 OCR 不联网 | Wireshark 抓包 + 系统 OCR | 无网络包发出，纯本地处理 | P0 |
| TC-SEC-02 | 云 OCR HTTPS 强制 | 抓包检查 | 图片上传使用加密连接 | P0 |

| TC-SEC-05 | 名片 OCR 不记录 PII | 识别含身份证号的图片 | 结果不写入持久化日志 | P1 |
