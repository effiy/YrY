# 生词本导出 — 测试方案

## 核心功能测试

### Anki 导出

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-VE-01 | Anki 卡片创建 | 翻译 "Hello" → 导出到 Anki | AnkiConnect 创建卡片，正面="Hello"，背面=翻译 |
| TC-VE-02 | Anki Application 不可用 | 未安装 Anki → 导出 | 提示 "Anki 未启动，请确认 AnkiConnect 插件已安装" |
| TC-VE-03 | AnkiConnect 端口错误 | Anki 使用非标准端口 | 提示连接失败，不崩溃 |
| TC-VE-04 | 自定义牌组 | 配置牌组="English" → 导出 | 卡片添加到 "English" 牌组 |
| TC-VE-05 | 自定义笔记类型 | 配置笔记类型="Basic" → 导出 | 使用 Basic 类型创建笔记 |
| TC-VE-06 | 字段映射 (word→正面) | 配置 word 映射到 Front | 正面显示单词 |
| TC-VE-07 | 字段映射 (translation→背面) | 配置 translation 映射到 Back | 背面显示翻译 |
| TC-VE-08 | 连续导出 20 条 | 连续翻译 20 个单词 → 全部导出 | 20 张卡片成功创建 |

### 欧路词典导出

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-VE-10 | 欧路添加生词 | 翻译 → 导出到欧路 | 成功添加到欧路生词本 |
| TC-VE-11 | 自定义词典 | 配置目标词典 → 导出 | 生词添加到指定词典 |
| TC-VE-12 | 欧路不可用 | 欧路未启动 → 导出 | 提示 "欧路词典未启动" |

## 增强边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-VE-E01 | 空文本导出 | 导出空内容 | 前端拦截，不发起导出 | P1 |
| TC-VE-E02 | 超长单词 (> 200 字符) | 导出超长文本 | 字段截断或正常保存 | P2 |
| TC-VE-E03 | 特殊字符字段 | 导出含 `{"` 的翻译 | 正确编码转义 | P1 |
| TC-VE-E04 | AnkiConnect 超时 | 模拟 API 慢响应 | 30s 超时提示 | P1 |
| TC-VE-E05 | AnkiConnect 异常响应 | Mock 非标准 JSON | 提示 "AnkiConnect 返回异常" | P1 |
| TC-VE-E06 | 重复导出同一单词 | 导出已存在的卡片 | Anki 更新现有卡片或提示重复 | P2 |
| TC-VE-E07 | 字段映射缺失 | 未配置映射字段 | 使用默认映射 word→Front, translation→Back | P1 |
| TC-VE-E08 | 网络断开 (AnkiConnect localhost) | 禁用 localhost 回环 | 提示 "无法连接 AnkiConnect" | P2 |
| TC-VE-E09 | 同时导出多个目标 | 同时导出到 Anki + 欧路 | 两个导出独立执行，不冲突 | P1 |

## 性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-VE-P01 | 单条导出到 Anki | 端到端 | ≤ 200ms | > 500ms | 20 次测量 |
| TC-VE-P02 | 批量导出 50 条 | 总耗时 | ≤ 5s | > 15s | 5 批次 |
| TC-VE-P03 | AnkiConnect 首次连接 | 握手耗时 | ≤ 100ms | > 300ms | 10 次测量 |
| TC-VE-P04 | 欧路词典 API 响应 | 端到端 | ≤ 200ms | > 500ms | 20 次测量 |

## 安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-VE-S01 | AnkiConnect 仅 localhost | 检查连接地址 | 仅连接 127.0.0.1:8765，不连接外部 | P1 |
| TC-VE-S02 | 导出内容不泄露 | 检查外部网络请求 | 生词内容不发送到非 localhost | P1 |
| TC-VE-S03 | 字段注入防护 | 导出含 Anki 模板语法的文本 | 字段内容被转义，不执行模板 | P2 |
