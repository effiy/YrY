# 窗口定位与多显示器 — 测试方案

## 核心功能测试

### 显示器检测

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-WP-01 | 单显示器检测 | 仅一个显示器 | 返回正确 Monitor 对象 (x, y, w, h, dpi) |
| TC-WP-02 | 双显示器检测 | 左右排列双屏 | 枚举 2 个 Monitor，位置坐标不重叠 |
| TC-WP-03 | DPI 读取 | 4K 200% 缩放 | 返回 dpi=2.0 |
| TC-WP-04 | 鼠标定位 | 鼠标在左屏 (100, 200) | get_current_monitor 返回左屏 Monitor |
| TC-WP-05 | 鼠标跨屏 | 鼠标从主屏移到副屏 | 窗口跟随鼠标切换到副屏显示器 |

### 定位策略

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-WP-10 | 鼠标跟随模式 | 模式=mouse → 翻译 | 窗口在鼠标附近弹出 |
| TC-WP-11 | 固定位置模式 | 模式=fixed → 翻译 | 窗口在配置的 x/y 位置弹出 |
| TC-WP-12 | 右边界越界 | 鼠标距右边缘 50px → 弹出 | 窗口自动向左偏移 |
| TC-WP-13 | 下边界越界 | 鼠标距下边缘 50px → 弹出 | 窗口自动向上偏移 |
| TC-WP-14 | 右下角越界 | 鼠标在右下角 10px 处 | 窗口同时向左+向上偏移 |
| TC-WP-15 | 左上角不越界 | 鼠标在左上角 (0, 0) | 窗口正常向右下展开 |

### 窗口尺寸记忆

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-WP-20 | 翻译窗口尺寸记忆 | 调整翻译窗口为 500x600 → 关闭 → 重新打开 | 新窗口使用 500x600 |
| TC-WP-21 | OCR 窗口尺寸记忆 | 调整 OCR 窗口为 600x400 → 关闭 → 重新打开 | 新窗口使用 600x400 |
| TC-WP-22 | DPI 缩放感知 | 4K 200% → 窗口 400x300 (逻辑) | 实际像素 800x600，逻辑坐标 400x300 |
| TC-WP-23 | 异常尺寸恢复 | 尺寸记忆值=3000 → 重启 | 自动修正到 ≤ 2000px |

## 增强边界与异常测试

|------|--------|----------|---------|--------|
| TC-WP-E01 | 显示器热插拔 | 运行时外接/断开显示器 | 实时重检测，窗口移至现有显示器 | P1 |
| TC-WP-E02 | 混合 DPI 双屏 | 主屏 1x + 副屏 2x | 窗口切换到副屏时正确缩放 | P1 |
| TC-WP-E03 | DPI 动态变化 | 运行时修改显示器缩放 | 窗口位置/尺寸重新计算 | P2 |
| TC-WP-E04 | 尺寸记忆值=0 | 配置文件被篡改 | 使用默认值 350x420 | P1 |
| TC-WP-E05 | 尺寸记忆值=负数 | 配置文件被篡改 | 使用默认值 | P2 |
