## 五、增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 切换到未翻译的语言 | 选择仅有 30% 覆盖率的语言 | 未翻译部分显示英文 fallback 或 key 名称 | P1 |
| TC-EDGE-02 | 系统字体不包含 CJK 字符 | 选择不含中文的字体 → 显示中文界面 | 自动回退到系统默认中文字体 | P1 |
| TC-EDGE-03 | 字号极限小 (8pt) | 设置 8pt 字号 | UI 仍可读，不裁剪文字 | P2 |
| TC-EDGE-04 | 字号极限大 (48pt) | 设置 48pt 字号 | UI 不自适应溢出，滚动显示 | P2 |
| TC-EDGE-05 | 主题色自定义 | 输入 #000000 纯黑 | 文字和按钮可见，对比度足够 | P2 |
| TC-EDGE-06 | RTL + 翻译结果对比 | 阿拉伯语界面 + 英文翻译结果 | 翻译结果方向正确（通常 LTR） | P2 |
| TC-EDGE-07 | 同时切换语言和主题 | 中文 → 英文 + 浅色 → 深色 | 两者同时生效，无闪烁 | P3 |
| TC-EDGE-08 | 字体文件缺失 | 选择不存在的系统字体 | 回退到默认字体 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | i18n 翻译文件损坏 | 手动篡改 JSON locale 文件 | 回退到英文默认翻译 | 替换正确文件后正常 |
| TC-ERR-02 | 系统主题切换失败 | 权限问题导致无法读取系统主题 | 默认使用浅色主题 | 修复权限后恢复跟随 |
| TC-ERR-03 | 字体加载失败 | 选择损坏的字体文件 | 回退到 fallback 字体 | 移除损坏字体后正常 |
| TC-ERR-04 | RTL 布局下的对话框 | RTL 模式下打开确认对话框 | 按钮顺序镜像（确认左/取消右） | — |
| TC-ERR-05 | 语言资源异步加载失败 | 断网加载远程语言包 | 使用已缓存的本地版本 | 恢复网络后加载新版本 |
| TC-ERR-06 | 语言切换时的动态内容 | 翻译浮窗打开中切换语言 | 已打开的窗口不立即更新（需重新打开） | 新窗口使用新语言 |

## 六、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 语言切换响应 | 点击到 UI 刷新 | ≤ 200ms | > 500ms | 10 次采样 |
| TC-PERF-02 | 主题切换响应 | 切换到完成 | ≤ 100ms | > 300ms | 10 次采样 |
| TC-PERF-03 | 系统主题跟随检测 | 系统切换主题到应用响应 | ≤ 500ms | > 1s | OS 层面切换 |
| TC-PERF-04 | i18n 资源加载 | 冷启动加载所有 locale | ≤ 100ms | > 300ms | 启动计时 |
| TC-PERF-05 | RTL 布局计算 | 切换到 RTL 语言 | ≤ 200ms | > 500ms | 包含重新布局 |
| TC-PERF-06 | 字体渲染 (复杂脚本) | 阿拉伯语/印地语渲染 | 帧率影响 ≤ 5% | > 10% | 对比 LTR 渲染 |
