## 四、增强边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-EDGE-01 | 空文本朗读 | 无翻译结果点击朗读 | 按钮禁用或提示"无文本可朗读" | P1 |
| TC-EDGE-02 | 超长文本朗读 | 10000+ 字文本 | 截取前 N 字或分段朗读 | P2 |
| TC-EDGE-03 | 纯符号文本 | "!@#$%" | 部分 TTS 引擎跳过或发出描述音 | P2 |
| TC-EDGE-04 | 混合语言朗读 | "Hello 世界" | 按主语言选择 TTS 引擎 | P2 |
| TC-EDGE-05 | 生词本空列表 | 无收藏时打开 | 显示"暂无收藏词汇" | P1 |
| TC-EDGE-06 | 生词本大量词汇 | 收藏 1000+ 词汇 | 列表分页/虚拟滚动，不卡顿 | P2 |
| TC-EDGE-07 | Anki 字段映射为空 | 导出时未配置字段映射 | 使用默认字段映射 | P2 |
| TC-EDGE-08 | 重复收藏同一词汇 | 再次点击收藏已收藏词汇 | 提示"已收藏"或取消收藏 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | TTS 音频设备未连接 | 拔掉耳机/音箱 | 显示"未检测到音频设备" | 连接设备后正常 |
| TC-ERR-02 | TTS 并发播放 | 点击两次朗读 | 停止第一次，开始第二次 | 无重叠播放 |
| TC-ERR-03 | 系统 TTS 引擎崩溃 | 强制终止系统 TTS 进程 | 提示播放失败，不崩溃 | 重启后可用 |
| TC-ERR-04 | AnkiConnect 未运行 | Anki 关闭 → 导出 | 显示"请先启动 Anki" | 启动 Anki 后可用 |
| TC-ERR-05 | Anki 连接断开 | 导出中关闭 Anki | 显示导出失败，本地收藏不丢失 | 重新导出成功 |
| TC-ERR-06 | 欧路词典 API 不可用 | 模拟 API 超时 | 显示导出失败提示 | 重试后成功 |
| TC-ERR-07 | Lingva 服务不可达 | 关闭 Lingva 后端 | 显示连接错误 | 恢复服务后正常 |
| TC-ERR-08 | 生词本数据损坏 | 手动修改本地生词本数据库 | 加载时跳过损坏记录，提示用户 | 恢复备份后正常 |

## 五、性能基准测试

| 编号 | 测试场景 | 测量指标 | 基准值 | 劣化阈值 | 测试方法 |
|------|---------|---------|--------|---------|---------|
| TC-PERF-01 | 系统 TTS 朗读首字节 | 点击朗读到声音开始 | ≤ 500ms | > 1s | 10 次采样 |
| TC-PERF-02 | Lingva TTS 朗读延迟 | 点击到声音开始 | ≤ 2s | > 4s | 局域网环境 |
| TC-PERF-03 | 生词本打开 (1000 词) | 列表展示时间 | ≤ 300ms | > 800ms | 冷启动打开 |
| TC-PERF-04 | Anki 导出 (100 词) | 导出完成时间 | ≤ 3s | > 10s | 含 AnkiConnect 通信 |
| TC-PERF-05 | TTS 语速调节实时生效 | 拖拽滑块到采样变化 | ≤ 200ms | > 500ms | — |
| TC-PERF-06 | TTS 内存占用 | 连续朗读 10 句 | ≤ 100MB 增量 | > 200MB 增量 | 对比朗读前后 |
