# 翻译窗口交互 — 测试方案

> 覆盖 YP-09-S24：窗口布局、交互细节、组件结构、键盘操作、语言切换、跨窗口联动

---

## 一、核心功能测试

### 1.1 窗口显示与关闭

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-TW-001 | 选中文本弹出 | 选中文本 → 快捷键 | 翻译窗口在鼠标附近弹出，< 500ms |
| TC-TW-002 | 点击外部关闭 | 翻译窗口打开 → 点击窗外 | 窗口关闭，< 100ms |
| TC-TW-003 | Esc 关闭 | 翻译窗口聚焦 → 按 Esc | 窗口关闭，< 50ms |
| TC-TW-004 | 窗口大小拖拽 | 拖拽窗口边缘调整大小 | 窗口大小改变，下次保持新尺寸 |
| TC-TW-005 | 窗口位置记忆 | 拖拽窗口到某位置 → 关闭 → 重新触发 | 窗口在记住的位置弹出 |
| TC-TW-006 | 窗口超出屏幕 | 窗口贴近屏幕边缘弹出 | 自动调整位置到可见区域 |

### 1.2 翻译结果展示

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-TW-010 | 多服务结果独立 | 启用 3 个翻译服务 → 翻译 | 3 个结果卡片独立展示，标注服务名 |
| TC-TW-011 | 首条翻译展示 | 窗口弹出后 | 首条翻译 < 1000ms（含网络请求） |
| TC-TW-012 | 翻译结果虚拟滚动 | 启用 5+ 翻译服务 → 翻译 | 结果区可滚动，无卡顿 |
| TC-TW-013 | 语言自动检测 | 选中中文文本 → 翻译 | 源语言自动检测为 zh |

### 1.3 操作按钮

| 编号 | 用例 | 操作 | 预期 |
|------|------|------|------|
| TC-TW-020 | 复制按钮 | 翻译完成 → 点击复制 | 译文复制到剪切板，< 100ms |
| TC-TW-021 | 朗读按钮 | 点击朗读（目标语言有 TTS） | 语音播报译文 |
| TC-TW-022 | 朗读不可用 | 选择无 TTS 的语言 → 翻译 | 朗读按钮灰显，tooltip "不支持该语言" |
| TC-TW-023 | 收藏按钮 | 点击收藏 | 翻译记录存入 Collection |
| TC-TW-024 | 语言切换 | 切换源/目标语言 | 重新发起翻译，< 200ms 触发新调度 |

## 二、边界与异常测试

| 编号 | 场景 | 输入 | 预期行为 | 恢复策略 |
|------|------|------|----------|----------|
| TC-TW-EDGE-01 | 选中文本为空 | 空白/仅空格 | 不弹出窗口，静默忽略 | — |
| TC-TW-EDGE-02 | 选中文本超长 | > 5000 字符 | 截断到 5000 + "..."，原文区可滚动 | — |
| TC-TW-EDGE-03 | 选中非文本区域 | 图片/Canvas | 不弹出窗口，静默忽略 | — |
| TC-TW-EDGE-04 | 无可用翻译服务 | 所有服务禁用 | 弹出窗口显示"请启用翻译服务" | 链接到设置页 |
| TC-TW-EDGE-05 | 全部服务返回错误 | 断网 → 翻译 | 窗口保留，显示错误信息 + 重试按钮 | 点击重试 |
| TC-TW-EDGE-06 | 快速连续选文 | 500ms 内 2 次选中 | 取消前一次请求，显示最新 | AbortController 取消旧请求 |
| TC-TW-EDGE-07 | 原文编辑后翻译 | 用户修改原文 | 防抖 300ms 后重新翻译 | 避免每次按键触发 |
| TC-TW-EDGE-08 | 窗口位置超出屏幕 | availWidth/Height 边缘 | 自动调整到可见区域 | 无溢出 |
| TC-TW-EDGE-09 | 朗读不支持当前语言 | TTS 无该语言 | 朗读按钮灰显 + tooltip | — |
