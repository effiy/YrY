# 窗口定位与多显示器 — 测试方案

> **文档职责**：验证翻译/OCR 窗口的智能定位、显示器检测、边界检测、DPI 缩放和窗口尺寸记忆功能。

---

## 一、测试层级

```
窗口定位与多显示器
├── 显示器检测
│   ├── 单显示器定位
│   ├── 多显示器识别
│   └── 鼠标所在显示器判断
├── 定位策略
│   ├── 鼠标跟随模式
│   ├── 固定位置模式
│   └── 定位模式切换
├── 边界检测
│   ├── 右边界超出 → 左移
│   ├── 下边界超出 → 上移
│   └── 上/左边界处理
├── 窗口尺寸记忆
│   ├── 翻译窗口尺寸
│   ├── OCR 窗口尺寸
│   └── 重启后尺寸保持
└── DPI 感知
    ├── 100% 缩放
    ├── 125%/150%/200% 缩放
    └── 多 DPI 混合环境
```

## 二、核心测试用例

### 2.1 显示器检测

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-MON-001 | 单显示器定位 | 单屏 → 鼠标在屏幕中央 → 触发翻译 | 翻译窗口在鼠标附近弹出 | P0 |
| TC-MON-002 | 鼠标在左屏 | 双屏 (左主右副) → 鼠标在左屏 → 翻译 | 窗口在左屏弹出 | P0 |
| TC-MON-003 | 鼠标在右屏 | 双屏 → 鼠标在右屏 → 翻译 | 窗口在右屏弹出 | P0 |
| TC-MON-004 | 鼠标跨屏移动 | 左屏划线 → 右屏释放 → 翻译 | 窗口在右屏弹出 (释放时位置) | P1 |
| TC-MON-005 | 三显示器定位 | 三屏 → 鼠标在中间屏 → 翻译 | 窗口在中间屏弹出 | P2 |
| TC-MON-006 | 显示器断开后定位 | 外接显示器断开 → 翻译 | 窗口在主屏正常弹出，无偏移 | P1 |

### 2.2 定位策略

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-POS-001 | 鼠标跟随模式 | 配置模式为"鼠标跟随"→ 不同位置翻译 | 窗口始终在鼠标附近弹出 | P0 |
| TC-POS-002 | 固定位置模式 | 配置模式为"固定位置"→ 设坐标 (100, 100) | 窗口始终在屏幕 (100, 100) | P1 |
| TC-POS-003 | 固定位置多屏 | 固定位置 (100, 100) → 鼠标在右屏翻译 | 窗口在主屏 (100, 100) | P2 |
| TC-POS-004 | 定位模式切换 | 鼠标跟随 → 切换到固定位置 → 翻译 | 新翻译使用固定位置 | P2 |
| TC-POS-005 | 固定位置边界处理 | 固定位置设 (5000, 5000) | 自动修正到有效屏幕范围内 | P2 |

### 2.3 边界检测

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-BOUND-001 | 右边界超出 | 鼠标在屏幕右边缘 → 翻译 | 窗口向左偏移，不超出右边界 | P1 |
| TC-BOUND-002 | 下边界超出 | 鼠标在屏幕底边 → 翻译 | 窗口向上偏移，不超出底边 | P1 |
| TC-BOUND-003 | 右下角边界 | 鼠标在右下角 → 翻译 | 窗口整个在屏幕内显示 | P1 |
| TC-BOUND-004 | 左上角边界 | 鼠标在左上角 (0, 0) → 翻译 | 窗口向右下偏移，不超出屏幕 | P2 |
| TC-BOUND-005 | 多屏边界 | 鼠标在左屏右边缘 → 窗口跨屏 | 窗口完整在左屏或右屏，不跨屏 | P2 |
| TC-BOUND-006 | 任务栏/Dock 区域 | 鼠标贴近任务栏 → 翻译 | 窗口不覆盖任务栏区域 | P2 |

### 2.4 窗口尺寸记忆

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-SIZE-001 | 翻译窗口尺寸记忆 | 手动调整翻译窗口大小 → 关闭 → 重新翻译 | 新窗口使用上次尺寸 | P1 |
| TC-SIZE-002 | OCR 窗口尺寸记忆 | 调整 OCR 窗口大小 → 关闭 → 重新 OCR | 新窗口使用上次尺寸 | P1 |
| TC-SIZE-003 | 尺寸重启保持 | 调整窗口 → 重启应用 → 翻译 | 窗口尺寸从持久化配置恢复 | P2 |
| TC-SIZE-004 | 窗口最小尺寸限制 | 拖动到极小 (50x50) | 有最小尺寸约束 | P2 |
| TC-SIZE-005 | 窗口最大尺寸限制 | 拖动到超过屏幕尺寸 | 不超过当前显示器工作区 | P2 |

### 2.5 DPI 感知

| 编号 | 测试项 | 步骤 | 预期结果 | 优先级 |
|------|--------|------|---------|--------|
| TC-DPI-001 | 100% 缩放 | Windows/macOS 100% 缩放 → 翻译 | 窗口大小和位置正确 | P0 |
| TC-DPI-002 | 125% 缩放 | Windows 125% 缩放 → 翻译 | 窗口正确缩放，不模糊 | P1 |
| TC-DPI-003 | 150% 缩放 | 150% 缩放 → 翻译 | 窗口清晰，坐标不偏移 | P1 |
| TC-DPI-004 | 200% 缩放 (Retina/4K) | macOS Retina 或 4K 200% | 窗口清晰，物理和逻辑坐标正确 | P0 |
| TC-DPI-005 | 多 DPI 混合 | 笔记本 125% + 外接 200% → 翻译 | 两台显示器上窗口大小各自正确 | P2 |
| TC-DPI-006 | DPI 运行时切换 | 翻译窗口打开 → 切换缩放比 | 新窗口使用新 DPI，旧窗口不变 | P2 |

## 三、边界与异常测试

### 边界值测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-EDGE-01 | 鼠标在负坐标 | 多显示器布局中副屏坐标为负 | 正确映射到对应显示器 | P2 |
| TC-EDGE-02 | 显示器非常大 | 8K 显示器 (7680x4320) | 窗口定位正常 | P3 |
| TC-EDGE-03 | 极小显示器 | 1024x768 分辨率 | 窗口不超出屏幕 | P2 |
| TC-EDGE-04 | 窗口尺寸 = 屏幕大小 | 拉伸窗口到全屏 → 重新翻译 | 窗口不超出边界 | P2 |
| TC-EDGE-05 | 固定位置设为 0,0 | 窗口从屏幕原点开始 | 不遮挡菜单栏和 Dock | P2 |
| TC-EDGE-06 | 复制模式双屏 | 两个显示器显示相同内容 | 窗口在主显示器弹出 | P3 |
| TC-EDGE-07 | 纵向排列显示器 | 上方主屏 + 下方副屏 | 跨屏检测正确 | P2 |
| TC-EDGE-08 | 缩放比例 300% | 4K 13 寸 300% | 窗口大小正常 | P2 |

### 异常场景测试

| 编号 | 异常场景 | 模拟方式 | 预期行为 | 恢复验证 |
|------|---------|---------|---------|---------|
| TC-ERR-01 | 显示器信息获取失败 | Tauri 无法获取显示器列表 | 使用主屏默认位置 (100, 100) | 重新获取后正常 |
| TC-ERR-02 | 显示器热插拔 | 翻译窗口打开 → 断开外接显示器 | 窗口移至主屏可见区域 | 窗口不丢失 |
| TC-ERR-03 | 无显示器 (远程桌面断开) | RDP 断开 → Pot 运行中 | 窗口创建时不崩溃 | 重新连接后窗口可见 |
| TC-ERR-04 | 鼠标坐标异常值 | macOS Accessibility 返回 (-32000, -32000) | 使用屏幕中央作为备选位置 | 修复权限后恢复正常定位 |
| TC-ERR-05 | 固定位置超出范围 | 配置值 (99999, 99999) | 自动限制到主屏范围内 | — |
| TC-ERR-06 | DPI 值取 0 | 报错返回 scale_factor=0 | 使用 1.0 作为默认值 | — |
| TC-ERR-07 | 多显示器同时断开 | 两个外接屏幕同时移除 | 所有窗口移至主屏 | 重新连接后窗口恢复原位置 |

## 五、安全测试

| 编号 | 测试项 | 测试方法 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-SEC-01 | 窗口位置不做屏幕录制 | 检查窗口定位 API 调用 | 仅读取显示器参数，不捕获屏幕内容 | P2 |
| TC-SEC-02 | 多屏信息不泄露 | 检查日志输出 | 显示器序列号/名称不在日志中 | P2 |
| TC-SEC-03 | 固定位置不可通过外部修改 | HTTP API → 尝试设置窗口位置 | 窗口位置配置仅 UI 或配置文件可修改 | P2 |
