# 翻译历史记录 — 测试方案

> 来源 PRD：[51-prd-翻译历史记录](../../prds/2026-09/51-prd-翻译历史记录.md)

## 一、核心功能测试

| 编号 | 测试项 | 操作步骤 | 预期结果 | 优先级 |
|------|--------|---------|---------|--------|
| TC-HIST-01 | 翻译后自动记录 | 1. 翻译 "Hello" → 查看历史 | 历史列表中新增一条记录 | P0 |
| TC-HIST-02 | 翻译窗口最近 20 条 | 1. 连续翻译 25 次 → 打开翻译窗口历史 | 显示最近 20 条，最早的 5 条已移除 | P0 |
| TC-HIST-03 | 点击历史回填 | 1. 翻译 "Hello" → 翻译 "World" → 点击历史中的 "Hello" | 翻译输入框回填 "Hello" 并显示上次翻译结果 | P1 |
| TC-HIST-04 | 清除单条记录 | 1. 翻译 3 次 → 悬停第 2 条 → 点击删除 | 第 2 条记录消失，第 1、3 条保留 | P1 |
| TC-HIST-05 | 清除全部记录 | 1. 翻译 5 次 → 设置页 History → 清除全部 | 所有记录被清空，显示空状态 | P1 |
| TC-HIST-06 | 关闭应用后清除 | 1. 翻译 3 次 → 关闭 Pot → 重新打开 | 历史记录为空（仅内存存储，不持久化） | P0 |
| TC-HIST-07 | 搜索历史 | 1. 翻译 "Hello"/"World"/"你好" → 搜索 "Hello" | 仅显示包含 "Hello" 的记录 | P1 |
| TC-HIST-08 | 搜索无匹配 | 1. 搜索 "zzznotexist" | 显示空状态提示"无匹配记录" | P2 |
| TC-HIST-09 | LRU 淘汰 | 1. 翻译 20 次 → 翻译第 21 次 | 第 1 条被移除，第 2-21 条保留 | P0 |
| TC-HIST-10 | 空翻译不记录 | 1. 打开翻译窗口 → 不输入文本 → 按 Enter | 历史列表不增加 | P1 |

## 二、边界与异常测试

| 编号 | 测试项 | 输入/场景 | 预期结果 | 优先级 |
|------|--------|----------|---------|--------|
| TC-HIST-E01 | 超长文本显示 | 翻译 10000+ 字文本 | 列表中截断显示 200 字 + "..."，hover Tooltip 显示全文 | P1 |
| TC-HIST-E02 | 特殊字符搜索 | 搜索 `(test)` | 正确转义正则元字符，匹配文字 `(test)` | P1 |
| TC-HIST-E03 | 并发快速翻译 | 0.1s 内连续触发 5 次翻译 | 所有结果正确记录，时间戳精确到毫秒，顺序正确 | P2 |
| TC-HIST-E04 | 清除时新增翻译 | 点击"清除全部"同时触发新翻译 | 新翻译不被清除，竞态安全 | P2 |
| TC-HIST-E05 | 多窗口历史隔离 | 翻译窗口 + 设置页 History 同时打开 | 两处数据一致，任一修改另一处实时更新 | P2 |
| TC-HIST-E06 | 内存不足 | 翻译 1000 次（模拟大量记录） | 不 OOM，如启用虚拟滚动则渲染 < 20 条 DOM 节点 | P2 |
| TC-HIST-E07 | 富文本粘贴 | 从 Word 复制含格式文本 → 翻译 | 历史中显示为纯文本，不含 HTML 标签 | P1 |
