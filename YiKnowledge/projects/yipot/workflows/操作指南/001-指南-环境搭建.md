# 环境搭建

> 从零搭建 YiPot 开发环境。包括系统依赖、Rust/Node.js 安装、项目启动、IDE 配置。

## 一、系统依赖

### macOS

```bash
# Xcode Command Line Tools
xcode-select --install

# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Node.js (推荐使用 fnm/nvm)
brew install fnm
fnm install 20
fnm use 20

# pnpm
corepack enable && corepack prepare pnpm@latest --activate
```

### Windows

```powershell
# Microsoft Visual Studio C++ Build Tools
# 下载: https://visualstudio.microsoft.com/visual-cpp-build-tools/

# Rust
# 下载: https://rustup.rs/

# Node.js (推荐使用 fnm)
scoop install fnm
fnm install 20

# pnpm
corepack enable
```

### Linux (Ubuntu/Debian)

```bash
# 系统依赖
sudo apt update
sudo apt install -y libwebkit2gtk-4.0-dev build-essential \
  curl wget libssl-dev libgtk-3-dev libayatana-appindicator3-dev \
  librsvg2-dev

# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Node.js + pnpm
curl -fsSL https://fnm.vercel.app/install | bash
fnm install 20
corepack enable
```

## 二、验证环境


## 三、快速启动

```bash
# 1. 克隆仓库
git clone https://github.com/pot-app/pot-desktop.git
cd pot-desktop

# 2. 安装前端依赖
pnpm install

# 3. 启动开发模式
pnpm tauri dev     # React :1420 + Rust 后端

# 或仅启动前端
pnpm dev            # React :1420 (不含 Rust)
```

## 补充：Docker 开发环境

使用 Docker 提供一致化的开发环境，避免系统依赖差异。

### Dockerfile

```dockerfile
# Dockerfile.dev
FROM ubuntu:22.04

# 系统依赖
RUN apt update && apt install -y \
    curl wget git build-essential \
    libwebkit2gtk-4.0-dev libgtk-3-dev \
    libayatana-appindicator3-dev librsvg2-dev \
    libssl-dev pkg-config cmake \
    # Rust 需要
    && rm -rf /var/lib/apt/lists/*

# 安装 Rust
RUN curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
ENV PATH="/root/.cargo/bin:${PATH}"

# 安装 Node.js (fnm)
RUN curl -fsSL https://fnm.vercel.app/install | bash
ENV PATH="/root/.local/share/fnm:${PATH}"
RUN fnm install 20 && fnm default 20

# 安装 pnpm
RUN corepack enable && corepack prepare pnpm@latest --activate

# 挂载项目目录
WORKDIR /workspace
VOLUME ["/workspace"]

CMD ["/bin/bash"]
```

### Docker Compose

```yaml
# docker-compose.dev.yml
version: "3.8"
services:
  pot-dev:
    build:
      context: .
      dockerfile: Dockerfile.dev
    volumes:
      - ./:/workspace
      # 保留 cargo 缓存，加速重复构建
      - cargo-cache:/root/.cargo/registry
      - cargo-target:/workspace/src-tauri/target
    environment:
      - DISPLAY=${DISPLAY}  # Linux X11 转发
      - WAYLAND_DISPLAY=${WAYLAND_DISPLAY}  # Wayland 转发
    # 允许 GUI 显示（仅 Linux）
    network_mode: host
    stdin_open: true
    tty: true

volumes:
  cargo-cache:
  cargo-target:
```

### Docker 使用流程

```bash
# 1. 构建镜像
docker compose -f docker-compose.dev.yml build

# 2. 启动环境
docker compose -f docker-compose.dev.yml run --rm pot-dev

# 3. 容器内操作
pnpm install
pnpm tauri dev  # 注意：GUI 应用需要 X11/Wayland 转发

# 4. macOS 上使用 Docker GUI
# 安装 XQuartz: brew install xquartz
# 启动 XQuartz: open -a XQuartz
# 允许网络连接: xhost +localhost
# docker run 时添加: -e DISPLAY=host.docker.internal:0
```

### Docker 限制说明

- **macOS**: Docker 不支持直接运行 GUI 应用，需要 XQuartz 中间层
- **Windows**: WSL2 更适合开发，Docker for Windows 的 GUI 支持有限
- **Linux**: 最直接的支持，`network_mode: host` 即可

**推荐**: Docker 主要用于 CI/CD 和依赖复现场景，日常开发优先使用本地环境。

```bash

{

  "tasks": [
    {
      "label": "YiPot Dev",
      "type": "shell",
      "command": "pnpm tauri dev",
      "isBackground": true,
      "problemMatcher": []
    }
  ]
}
```

### 环境一致性检查脚本

```bash
#!/bin/bash
# scripts/check-env.sh
echo "=== YiPot 环境检查 ==="

# Node.js
node_version=$(node --version 2>/dev/null || echo "未安装")
echo "[Node.js] $node_version"

# pnpm
pnpm_version=$(pnpm --version 2>/dev/null || echo "未安装")
echo "[pnpm] $pnpm_version"

# Rust
rust_version=$(rustc --version 2>/dev/null || echo "未安装")
echo "[Rust] $rust_version"

# Tauri 系统依赖（macOS/Linux）
if [[ "$OSTYPE" == "darwin"* ]]; then
    echo "[macOS] Xcode: $(xcodebuild -version 2>/dev/null || echo '未安装')"
elif [[ "$OSTYPE" == "linux-gnu"* ]]; then
    echo "[Linux] webkit2gtk: $(dpkg -l libwebkit2gtk-4.0-dev 2>/dev/null | tail -1 || echo '未安装')"
fi

# 项目依赖
echo "[项目] pnpm install 状态: $(test -d node_modules && echo '已安装' || echo '未安装')"
echo "[Rust] cargo check 状态: $(test -d src-tauri/target && echo '已编译' || echo '未编译')"

# 推荐版本检查
echo ""
echo "=== 推荐版本 ==="
echo "Node.js ≥ 18.0.0"
echo "pnpm ≥ 8.0.0"
echo "Rust ≥ 1.70.0"
```
