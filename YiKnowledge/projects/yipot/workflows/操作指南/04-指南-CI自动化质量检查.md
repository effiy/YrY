# YiPot CI/CD 自动化质量检查集成指南

> 基于 17 轮审计发现的缺陷模式，推荐自动化检查配置。

---

## 一、GitHub Actions 工作流

```yaml
name: Quality Checks
on: [push, pull_request]

jobs:
  rust:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: cd src-tauri && cargo check
      - run: cd src-tauri && cargo clippy -- -W clippy::unwrap_used -D warnings

  frontend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - run: pnpm install
      - run: pnpm build
```

## 四、服务 config safety 自动化检查脚本

```bash
#!/bin/bash
# scripts/check-config-defaults.sh
# 检查所有服务 index.jsx 中 config 是否有默认值

missing=$(grep -rn "const { config } = options" src/services/*/index.jsx | grep -v "= {}")
if [ -n "$missing" ]; then
  echo "ERROR: Services without config default value:"
  echo "$missing"
  exit 1
fi
echo "All services have config default values."
```

## 五、i18n 键完整性检查

```bash
#!/bin/bash
# scripts/check-i18n-keys.sh
python3 -c "
import json, os
ref = json.load(open('src/i18n/locales/en_US.json'))
ref_trans = ref.get('translation', ref)
def get_keys(d, p=''):
    keys = set()
    for k, v in d.items():
        full = f'{p}.{k}' if p else k
        if isinstance(v, dict): keys.update(get_keys(v, full))
        else: keys.add(full)
    return keys
ref_keys = get_keys(ref_trans)
for f in os.listdir('src/i18n/locales'):
    if f == 'en_US.json': continue
    loc = json.load(open(f'src/i18n/locales/{f}'))
    loc_keys = get_keys(loc.get('translation', loc))
    missing = ref_keys - loc_keys
    if missing:
        print(f'{f}: {len(missing)} keys missing')
"
```

## 六、推荐检查矩阵

| 检查 | 工具 | 频率 | 阻断 |
|------|------|------|------|
| Rust 编译 | `cargo check` | 每次 push | ✅ |
| Rust unwrap 使用 | `cargo clippy -- -W clippy::unwrap_used` | 每次 push | ✅ |
| 前端构建 | `pnpm build` | 每次 push | ✅ |
| Config 默认值 | 自定义脚本 (见上) | 每次 PR | ⚠️ |
| i18n 键完整性 | 自定义脚本 (见上) | 每周 | 否 |
| 安全依赖审计 | `cargo audit` + `pnpm audit` | 每周 | 否 |
