# YiPot 3.0.8 运营手册

> 面向运维人员的启动、排错和监控指南

---

## 一、启动检查

```bash
# 1. 依赖验证
cd YiPot && pnpm build           # 前端构建
cd src-tauri && cargo check      # Rust 编译

# 2. 配置检查
bash .scripts/check-config-defaults.sh  # 服务 config 完整性

# 3. 启动开发模式
cd .. && pnpm tauri dev
```

---

## 二、日志位置

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Logs/com.pot-app.desktop/` |
| Windows | `%APPDATA%\com.pot-app.desktop\logs\` |
| Linux | `~/.local/share/com.pot-app.desktop/logs/` |

## 三、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 翻译无响应 | API Key 未配置 | 设置 → 服务 → 配置 |
| TTS 无声 | AudioContext 挂起 | 点击播放按钮激活 |
| 截图 OCR 失败 | 权限不足 | macOS: 系统偏好设置 → 隐私 → 辅助功能 |
| 窗口不弹出 | 快捷键冲突 | 设置 → 快捷键 → 修改 |
| 构建失败 | TS 语法 | 检查 `.jsx` 文件无 TS 类型注解 |

## 四、配置恢复

```bash
# 备份
cp ~/.config/com.pot-app.desktop/config.json ~/pot-config-backup.json

# 恢复默认
rm ~/.config/com.pot-app.desktop/config.json
# 重启应用自动重建
```
