# 开发任务

> 常见开发任务的逐步操作指南。

## 一、添加新的翻译服务

### 步骤

1. 创建目录 `services/translate/{service_name}/`

2. 创建 `info.ts`：
```typescript
export const info = {
  id: "my_translator",
  name: "我的翻译",
  type: "translate",
  languages: ["auto", "zh", "en", "ja", "ko"],
  configurable: true,
  needs: [
    { name: "apiKey", message: "API Key" }
  ]
};
```

3. 创建 `index.jsx` 实现翻译逻辑

4. 创建 `Config.jsx` 配置界面

5. 测试：`pnpm tauri dev`

### 服务自动注册

无需手动注册——Vite 构建时自动扫描 `services/` 目录。

## 二、添加新的 OCR 服务

1. 创建目录 `services/recognize/{service_name}/`

2. 实现 `info.ts`、`index.jsx`、`Config.jsx`

3. OCR 服务需处理图片 base64 输入

## 三、添加新的 TTS 服务

1. 创建目录 `services/tts/{service_name}/`

2. 返回格式为 ArrayBuffer (音频数据)

3. 前端使用 `useVoice` hook 播放

## 四、修改快捷键默认值

1. 修改 Rust 端注册逻辑 (`hotkey.rs`)
2. 修改设置页默认值 (`Config/pages/Hotkey/`)
3. 更新配置文档

## 五、新增设置页面

1. 在 `Config/pages/` 创建新页面组件
2. 在 `Config/routes/index.jsx` 注册路由
3. 在 `Config/components/SideBar/` 添加导航项

## 六、修改 Rust 后端

1. 在对应的 `.rs` 文件中添加 `#[tauri::command]` 函数
2. 在 `main.rs` 的 `invoke_handler` 中注册
3. 前端通过 `invoke("command_name", { args })` 调用

## 七、添加新语言

1. 在 `src/i18n/locales/` 创建语言包 JSON
2. 在 `src/i18n/index.jsx` 导入并注册
3. 在设置页语言列表中添加选项

## 补充：性能剖析步骤

### React 前端性能剖析

#### 1. React DevTools Profiler

```
1. 安装 React DevTools 浏览器扩展
2. 开发模式下打开 Pot，按 F12 打开 DevTools
3. 切换到 Profiler 标签
4. 点击 Record → 执行操作（如触发翻译）→ 停止录制
5. 分析火焰图 (Flamegraph)：
   - 黄色/橙色: 渲染耗时较长的组件
   - 灰色: 未重新渲染的组件（良好）
   - 关注渲染次数异常多的组件
```

#### 2. Jotai 状态追踪

```javascript
// 使用 jotai-devtools 查看 atom 读写模式
import { useAtomDevtools } from "jotai-devtools";

// 对关键 atom 添加调试
const translateResultAtom = atom(null);
translateResultAtom.debugLabel = "translateResult";

// 在组件中
useAtomDevtools(translateResultAtom);
```

#### 3. Invoke 调用性能分析

```javascript
// 包装 invoke 添加计时
const timedInvoke = async (command, args) => {
  const start = performance.now();
  try {
    const result = await invoke(command, args);
    const duration = performance.now() - start;
    if (duration > 500) {
      warn(`Slow invoke: ${command} took ${duration.toFixed(0)}ms`, args);
    }
    return result;
  } catch (err) {
    const duration = performance.now() - start;
    error(`Failed invoke: ${command} after ${duration.toFixed(0)}ms`, err);
    throw err;
  }
};
```

#### 4. 性能基准目标

| 操作 | 目标 | 测量点 |
|------|------|--------|
| 快捷键触发→翻译窗口显示 | <200ms | `invoke("get_text")` 完成 → 窗口显示 |
| 翻译API请求→结果渲染 | <1s | fetch → TranslateResult 渲染 |
| OCR截图→结果显示 | <2s | screenshot → OCR结果渲染 |
| 设置页面打开 | <500ms | Config窗口创建 → 首页渲染完成 |
| 应用冷启动 | <3s | 进程启动 → 托盘图标显示 |
| 剪切板轮询循环 | <10ms/次 | 单次 `get_selected_text` 调用 |

## 补充：内存泄漏排查

### React 端泄漏排查

#### 常见泄漏模式

1. **未清理的 useEffect 订阅**

```javascript
// 错误: 缺少清理函数
useEffect(() => {
  listen("new_text", handler);  // 每次重新渲染都会新增监听！
}, []);  // 虽然有[]，但组件卸载后未取消

// 正确: 返回清理函数
useEffect(() => {
  const unlisten = listen("new_text", handler);
  return () => { unlisten.then(fn => fn()); };
}, []);
```

2. **Jotai atom 持有大对象引用**

```javascript
// 错误: atom 中持有 base64 图片数据
const screenshotAtom = atom(null);  // 存储截图 base64 (可能 10MB+)

// 正确: 使用后及时清理
const clearScreenshot = () => {
  setScreenshot(null);  // 清除引用让 GC 回收
};
```

3. **闭包持有过期引用**

```javascript
// 错误: setInterval 中的闭包持有旧 state
useEffect(() => {
  const timer = setInterval(() => {
    console.log(config);  // 始终引用初始 config 值
  }, 1000);
  return () => clearInterval(timer);
}, []);  // 空依赖导致闭包陈旧

// 正确: 使用 ref 存储最新值
const configRef = useRef(config);
configRef.current = config;
useEffect(() => {
  const timer = setInterval(() => {
    console.log(configRef.current);  // 始终获取最新值
  }, 1000);
  return () => clearInterval(timer);
}, []);
```

### Rust 端泄漏排查

```bash
# 1. 使用 valgrind 检测内存泄漏（Linux）
valgrind --leak-check=full --show-leak-kinds=all ./target/debug/pot

# 2. macOS 使用 Instruments → Leaks 模板
# Xcode → Open Developer Tool → Instruments → Leaks

# 3. 检查 Tauri 窗口是否正确销毁
# 每个 translate/recognize 窗口关闭时应释放 webview
# 关注: window.close() 调用后 Rust 侧 Window 对象是否被 drop
```

### 内存基准

| 组件 | 正常范围 | 警告阈值 | 检查方法 |
|------|---------|---------|---------|
| daemon窗口 | 20-40MB | >80MB | 任务管理器/活动监视器 |
| translate窗口 | 15-30MB | >60MB | 同上 |
| recognize窗口 | 15-30MB | >60MB | 同上 |
| config窗口 | 20-40MB | >80MB | 同上 |
| 总计(3窗口) | 80-150MB | >250MB | 同上 |
| Rust后端进程 | 10-30MB | >50MB | 同上 |
