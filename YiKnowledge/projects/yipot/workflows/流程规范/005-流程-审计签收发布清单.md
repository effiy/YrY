## 三、发布步骤

1. `git checkout main && git pull`
2. `pnpm install && cd src-tauri && cargo check`
3. `cd .. && pnpm build`
4. `bash .scripts/check-config-defaults.sh`
5. `pnpm tauri build`
6. 签名（macOS）/ 代码签名（Windows）
7. 上传至发布渠道
