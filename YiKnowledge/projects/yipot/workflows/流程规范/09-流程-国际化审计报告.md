# YiPot i18n 区域设置键完整性审计

> 审计基准：en_US.json（完整）· 审计范围：20 个 locale 文件

---

## 一、审计结果

| Locale | 缺失键数 | 严重程度 | 说明 |
|--------|---------|---------|------|
| `en_US` | 0 | — | 基准参考 |
| `zh_CN` | 0 | — | 完整 |
| `zh_TW` | 1 | 轻微 | 仅缺 `ecdict.title`，fallback 到 zh_CN |
| `de_DE` | 15 | 轻微 | 缺 Ollama/Ecdict 新增键 |
| `he_IL` | 45 | 中等 | 缺备份/OCR 新增键 |
| `it_IT` | 33 | 中等 | 缺备份/DevMode/语言键 |
| `es_ES` | 121 | 严重 | 缺备份/OCR/翻译设置键 |
| `ko_KR` | 123 | 严重 | 缺 OCR/TTS/生词本键 |
| `ja_JP` | 249 | 严重 | 缺备份/服务/更新器键 |
| `fa_IR` | 245 | 严重 | 同上 |
| `tk_TM` | 274 | 严重 | 缺大部分新增键 |
| `nb_NO` | 340 | 严重 | 仅含基础语言键 |
| `nn_NO` | 340 | 严重 | 同上 |
| `tr_TR` | 340 | 严重 | 同上 |

---

## 二、Fallback 机制

```js
fallbackLng: {
    default: ['en'],  // 所有缺失键 → 显示英语
}
```

**影响**：非英语用户会看到中英混合界面（已翻译部分显示母语，未翻译部分显示英语）。

## 三、建议

| 优先级 | 动作 |
|--------|------|
| P2 | 优先补全 ja_JP/ko_KR/es_ES（高用户量语言） |
| P3 | 使用 i18n 管理平台（如 Crowdin/Lokalise）自动化翻译 |
| P3 | CI 中添加 i18n 键完整性检查（对比 en_US 基准） |
