# YiPot Tauri 安全配置审计

> 审计范围：`src-tauri/tauri.conf.json` 安全相关配置
> 版本：Tauri 1.x

---

## 一、配置项审计

### 1.1 CSP (Content Security Policy)

```json
"csp": "default-src * data: ; img-src * 'self' asset: https: data: ; style-src * 'unsafe-inline'; worker-src 'self' blob: ; script-src * 'unsafe-eval';"
```

| 指令 | 值 | 风险评估 |
|------|-----|---------|
| `default-src` | `* data:` | **高** — 允许加载任意来源资源 |
| `script-src` | `* 'unsafe-eval'` | **高** — 允许任意脚本 + `eval()` |
| `style-src` | `* 'unsafe-inline'` | 中 — 允许内联样式（NextUI 需要） |
| `img-src` | `* 'self' asset: https: data:` | 低 — 翻译服务 Logo 需要跨域加载 |
| `worker-src` | `'self' blob:` | 低 — Tesseract.js Worker 需要 blob: |

**根因**：插件系统通过 `eval()` 执行 `.potext` 插件代码，翻译服务需调用任意第三方 API 域名。

**缓解建议**（Tauri 2.x 迁移时考虑）：
- 限制 `default-src` 为 `'self'` + 已知翻译 API 域名白名单
- 插件执行改用沙箱 iframe 替代 `eval()`

### 1.2 Daemon 窗口 — `--disable-web-security`

```json
"additionalBrowserArgs": "--disable-web-security"
```

**风险**：禁用同源策略。Daemon 窗口虽隐藏且仅含静态 HTML，但若有 XSS 漏洞，攻击面扩大。

**现状**：Tauri 1.x 多窗口架构需要此标志以允许窗口间通信。Tauri 2.x 已移除该需求。

### 1.3 HTTP Scope

```json
"http": { "all": true, "request": true, "scope": ["http://**", "https://**"] }
```

**风险**：允许向任意 URL 发送 HTTP 请求。翻译/OCR/TTS 服务调用任意第三方 API 需要此权限。

**缓解**：限制 scope 为已知翻译 API 域名白名单（需评估 21 个翻译引擎 + 15 个 OCR 引擎的域名）。

### 1.4 Shell Open

```json
"shell": { "all": true, "open": ".*" }
```

**风险**：允许打开任意 URL。帮助链接、社区链接使用。

**缓解**：限制正则表达式为已知域名白名单。

### 1.5 File System

```json
"fs": { "all": true, "scope": ["$APPCONFIG/**", "$APPCACHE/**"] }
```

**评估**：合理。限制在应用配置和缓存目录。

## 二、已确认的安全设计决策

| 决策 | 理由 | 风险接受 |
|------|------|---------|
| `eval()` 插件执行 | 插件系统核心机制，与上游 Pot-App 一致 | 用户需手动安装插件 |
| 任意 HTTP 请求 | 翻译/OCR 服务需调用 36+ 个第三方 API | 与上游一致 |
| `--disable-web-security` | Tauri 1.x 多窗口通信需求 | Tauri 2.x 可移除 |
| API Key 明文存储 | `tauri-plugin-store` JSON 文件 | 已知限制，YiAi 后端可缓解 |
