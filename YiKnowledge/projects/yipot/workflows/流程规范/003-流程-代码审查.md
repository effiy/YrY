# 代码审查

> PR 提交前的自检清单和 Reviewer 审查要点。

## 一、自检清单（提交者）

- [ ] TypeScript 无 `any` 类型
- [ ] 新的服务插件包含 info.ts / index.jsx / Config.jsx 三个文件
- [ ] Rust 函数标注了 `#[tauri::command]` 并在 main.rs 注册
- [ ] 无硬编码的 API Key / Secret
- [ ] 无 `console.log` 残留（使用 `info!/warn!` from tauri-plugin-log）
- [ ] 翻译/OCR 结果缓存命中逻辑正确
- [ ] 错误处理覆盖网络超时和认证失败
- [ ] i18n 键值在 22 个语言包中均已添加
- [ ] 窗口关闭时清理资源（timer/listener/AbortController）

## 二、Reviewer 检查要点

### React 组件

- 使用函数组件 + Hooks
- Props 类型定义完整
- useEffect 有清理函数
- 无直接 DOM 操作

### Rust 代码

- 错误使用 `Result<T, E>` 而非 panic
- `#[tauri::command(async)]` 用于可能阻塞的操作
- 平台特定代码用 `#[cfg]` 隔离

### 服务插件

- info.ts 完整且类型正确
- index.jsx 正确处理错误
- Config.jsx 支持配置验证

## 三、常见问题

| 问题 | 注意 |
|------|------|
| 忘记注册 Tauri command | 必须在 main.rs invoke_handler 中注册 |
| 剪贴板未恢复 | get_selected_text 必须恢复原始内容 |
| 跨窗口状态不同步 | 使用 Tauri event 广播状态变更 |
| RTL 布局异常 | 使用 CSS 逻辑属性 |
