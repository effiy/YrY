# 测试策略与 CI

> YiPot 的测试策略、CI/CD 配置、质量门禁。

## 一、测试分层

| 层级 | 工具 | 覆盖 |
|------|------|------|
| L1 单元 | Vitest (React) + cargo test (Rust) | 工具函数、服务逻辑、Rust 模块 |
| L2 集成 | Vitest + Tauri mock | 前后端通信、快捷键流程 |
| L3 E2E | 手动测试矩阵 | 全平台完整链路 |
| L4 平台兼容 | 真机测试 | macOS/Windows/Linux |

## 二、前端测试 (Vitest)

```javascript
// 服务插件测试
describe("Baidu Translate", () => {
  it("should translate hello to Chinese", async () => {
    const result = await translate("Hello", "en", "zh", mockOptions);
    expect(result.text).toBeTruthy();
    expect(result.from).toBe("en");
    expect(result.to).toBe("zh");
  });
});
```

## 三、Rust 测试 (cargo test)

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_lang_detect_english() {
        let result = detect_language("Hello World");
        assert_eq!(result, "en");
    }

    #[test]
    fn test_lang_detect_chinese() {
        let result = detect_language("你好世界");
        assert_eq!(result, "zh");
    }
}
```

## 四、CI 流程

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - run: pnpm lint
      - run: pnpm typecheck
  test:
    runs-on: ubuntu-latest
    steps:
      - run: pnpm test
      - run: cargo test
  build:
    strategy:
      matrix:
        os: [macos-latest, windows-latest, ubuntu-latest]
    steps:
      - run: pnpm tauri build
```
