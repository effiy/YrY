# 安全开发指南

> YiPot 安全开发的核心原则和实践规范。

## 一、API Key 安全管理

### 存储规范

```javascript
// 正确：通过 needs 声明，由配置系统加密存储
export const info = {
  needs: [{ name: "apiKey", message: "API Key" }]
};

// 通过 options 获取，绝不硬编码
export default async function translate(text, from, to, options) {
  const key = options.apiKey; // 由系统注入
}
```

### 禁止事项

| 禁止 | 说明 |
|------|------|
| 硬编码 API Key | 必须通过配置系统 |
| 日志中打印 Key | 使用 `***` 遮蔽 |
| URL 参数传递 Key | 放在 POST body 或 Header |
| 明文存储到磁盘 | 使用 AES-256 加密 |

## 二、网络安全

### HTTPS 强制

```javascript
// 插件中检查 API URL
if (!options.apiUrl?.startsWith("https://") && !options.apiUrl?.startsWith("http://localhost")) {
  console.warn("非 HTTPS 连接，建议使用加密传输");
}
```

### CSP 策略

```json
// tauri.conf.json
{
  "tauri": {
    "security": {
      "csp": "default-src 'self'; connect-src https://* http://localhost:*"
    }
  }
}
```

## 三、本地数据保护

### 配置文件权限

- Unix: `chmod 600 ~/.config/com.pot-app.pot/.pot.dat`
- Windows: 限制为当前用户可读写

### 临时文件清理

```rust
// OCR 截图完成后清理临时文件
fn cleanup_temp_files() {
    let cache_dir = get_cache_dir();
    if cache_dir.exists() {
        fs::remove_dir_all(cache_dir).ok();
    }
}
```

## 四、HTTP 服务安全

```rust
// 仅绑定回环地址
let server = Server::http("127.0.0.1:60828")?; // 非 0.0.0.0

// 请求体大小限制
const MAX_BODY_SIZE: usize = 64 * 1024; // 64KB
```

## 五、权限最小化

| 权限 | 用途 | 最小化策略 |
|------|------|-----------|
| 辅助功能 | 读取选中文本 | 仅读取，不模拟输入 |
| 屏幕录制 | 截图 OCR | 截图后立即清理 |
| 文件系统 | 配置读写 | 仅访问应用目录 |
| 网络 | API 调用 | 白名单域名 |
