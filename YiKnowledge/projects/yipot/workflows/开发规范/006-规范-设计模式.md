# 设计模式

> YiPot 代码库中使用的主要设计模式及其 Rust/React 实现。

## 一、策略模式 (Strategy) — 服务插件

**场景**: 21 个翻译服务、15 个 OCR 服务需要统一接口，运行时动态选择。

```typescript
// 策略接口
interface TranslateStrategy {
  translate(text: string, from: string, to: string): Promise<TranslateResult>;
}

// 具体策略: 百度翻译
const baiduStrategy: TranslateStrategy = {
  translate: async (text, from, to) => { /* MD5 签名 + API 调用 */ }
};

// 上下文: 翻译调度器根据用户配置选择策略
async function translateAll(text, from, to) {
  const strategies = getEnabledServices(); // 运行时选择
  return Promise.allSettled(strategies.map(s => s.translate(text, from, to)));
}
```

## 二、观察者模式 (Observer) — Tauri Event Bus

**场景**: Rust 后端状态变化通知多个前端窗口。

```rust
// Rust — 发布事件
window.emit("new_text", text).unwrap();
app_handle.emit_all("clipboard-changed", content).ok();
```

```javascript
// React — 订阅事件
import { listen } from "@tauri-apps/api/event";
const unlisten = await listen("new_text", (event) => handleTranslate(event.payload));
```

## 三、单例模式 (Singleton) — 全局 AppHandle

**场景**: 多个 Rust 模块需要访问同一个 Tauri AppHandle。

```rust
// main.rs
pub static APP: OnceCell<tauri::AppHandle> = OnceCell::new();

// 各模块通过 APP.get() 获取全局实例
let app_handle = APP.get().unwrap();
```

## 四、代理模式 (Proxy) — 配置存储

**场景**: 前端 useConfig Hook 作为配置读写的代理层。

```
React 组件 → useConfig Hook (代理)
  → Jotai atom (内存缓存)
    → tauri-plugin-store (Rust 代理)
      → JSON 文件 (真实存储)
```

## 五、命令模式 (Command) — Tauri Commands

**场景**: 前端通过命名命令调用 Rust 功能。

```rust
#[tauri::command]
fn get_text() -> String { /* 实现 */ }

// 注册
.invoke_handler(tauri::generate_handler![get_text, cut_image, system_ocr, ...])
```

```javascript
// 调用
const text = await invoke("get_text");
```

## 六、工厂模式 (Factory) — 窗口创建

**场景**: 根据窗口 label 创建不同类型的窗口。

```rust
fn build_window(label: &str, title: &str) -> (Window, bool) {
    // 统一工厂方法
    // 根据 label 决定窗口配置 (尺寸/位置/装饰)
}
```

## 七、适配器模式 (Adapter) — 平台抽象

**场景**: 统一不同平台的截图、OCR、剪贴板 API。

```rust
fn screenshot() -> Vec<u8> {
    #[cfg(target_os = "macos")] { macos_screenshot() }
    #[cfg(target_os = "windows")] { windows_screenshot() }
    #[cfg(target_os = "linux")] { linux_screenshot() }
}
```
