# 构建与发布

> YiPot 的跨平台构建流程、代码签名、自动更新机制、CI/CD 配置。

## 一、开发构建

```bash
# 安装依赖
pnpm install

# 启动开发服务器 (React :1420)
pnpm dev

# 启动 Tauri 开发模式 (React + Rust)
pnpm tauri dev
```

## 二、前端构建

### Vite 配置要点

```javascript
// vite.config.js
{
  clearScreen: false,
  server: { port: 1420, strictPort: true },
  envPrefix: ["VITE_", "TAURI_"],
  build: {
    target: process.env.TAURI_PLATFORM === "windows" ? "chrome105" : "safari13",
    minify: !process.env.TAURI_DEBUG ? "esbuild" : false,
    sourcemap: !!process.env.TAURI_DEBUG
  }
}
```

### 环境变量

| 变量 | 说明 |
|------|------|
| `TAURI_PLATFORM` | 目标平台 (windows/macos/linux) |
| `TAURI_DEBUG` | 是否调试模式 |

## 三、平台构建命令

### macOS

```bash
pnpm tauri build --target universal-apple-darwin
# 产物: src-tauri/target/release/bundle/dmg/*.dmg
```

签名要求：
- Apple Developer ID Application 证书
- `com.pot_app.pot.metainfo.xml` — AppStream 元数据
- 公证: `xcrun notarytool submit`

### Windows

```bash
pnpm tauri build --target x86_64-pc-windows-msvc
# 产物: .msi 和 .exe 安装包
```

### Linux

```bash
pnpm tauri build --target x86_64-unknown-linux-gnu
# 产物: .deb / .AppImage / .rpm
```

## 六、自动更新

### 更新检查流程

```
启动 → check_update()
  → 请求 GitHub Release API / 更新服务器
  → 比较版本号
  → 有新版本 → 打开 updater 窗口
  → 用户确认 → 下载新版本
  → updater.mjs 替换二进制 → 重启
```

### 更新器脚本

- `updater/updater.mjs` — 标准更新流程
- `updater/updater-for-fix-runtime.mjs` — 修复损坏的运行时

## 补充：CI/CD 详细配置

### GitHub Actions 工作流

```yaml
# .github/workflows/build.yml
name: Build and Release
on:
  push:
    tags: ["v*"]
  pull_request:
    branches: [main, dev]

jobs:
  # 1. Lint + Type Check
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v4
        with: { node-version: "20", cache: "pnpm" }
      - run: pnpm install
      - run: pnpm lint
      - run: pnpm tsc --noEmit
      # 插件 info.ts 验证
      - run: node scripts/validate-services.mjs

  # 2. macOS Build
  build-macos:
    needs: [check]
    if: startsWith(github.ref, 'refs/tags/v')
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v4
        with: { node-version: "20", cache: "pnpm" }
      - run: pnpm install
      - name: Build Tauri App (macOS universal)
        run: pnpm tauri build --target universal-apple-darwin
        env:
          APPLE_SIGNING_IDENTITY: ${{ secrets.APPLE_SIGNING_IDENTITY }}
          APPLE_CERTIFICATE: ${{ secrets.APPLE_CERTIFICATE }}
          APPLE_CERTIFICATE_PASSWORD: ${{ secrets.APPLE_CERTIFICATE_PASSWORD }}
          APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
      - name: Notarize
        run: |
          xcrun notarytool submit target/release/bundle/dmg/*.dmg \
            --apple-id ${{ secrets.APPLE_ID }} \
            --team-id ${{ secrets.APPLE_TEAM_ID }} \
            --password ${{ secrets.APPLE_NOTARY_PASSWORD }} \
            --wait
          xcrun stapler staple target/release/bundle/dmg/*.dmg
      - uses: actions/upload-artifact@v4
        with: { name: macos-dmg, path: "src-tauri/target/release/bundle/dmg/*.dmg" }

  # 3. Windows Build  
  build-windows:
    needs: [check]
    if: startsWith(github.ref, 'refs/tags/v')
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v4
        with: { node-version: "20", cache: "pnpm" }
      - run: pnpm install
      - name: Build Tauri App (Windows x64)
        run: pnpm tauri build --target x86_64-pc-windows-msvc
        env:
          TAURI_PRIVATE_KEY: ${{ secrets.TAURI_PRIVATE_KEY }}
      - uses: actions/upload-artifact@v4
        with: { name: windows-msi, path: "src-tauri/target/release/bundle/msi/*.msi" }

  # 4. Linux Build
  build-linux:
    needs: [check]
    if: startsWith(github.ref, 'refs/tags/v')
    runs-on: ubuntu-22.04
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v4
        with: { node-version: "20", cache: "pnpm" }
      - run: |
          sudo apt update
          sudo apt install -y libwebkit2gtk-4.0-dev libgtk-3-dev \
            libayatana-appindicator3-dev librsvg2-dev
      - run: pnpm install
      - name: Build Tauri App (Linux x64)
        run: pnpm tauri build --target x86_64-unknown-linux-gnu
      - uses: actions/upload-artifact@v4
        with: { name: linux-packages, path: "src-tauri/target/release/bundle/deb/*.deb" }

  # 5. Create Release
  release:
    needs: [build-macos, build-windows, build-linux]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/download-artifact@v4
      - name: Create GitHub Release
        uses: softprops/action-gh-release@v1
        with:
          files: |
            macos-dmg/*.dmg
            windows-msi/*.msi
            linux-packages/*.deb
          generate_release_notes: true
```

### CI 环境密钥配置

| Secret | 用途 | 获取方式 |
|--------|------|---------|
| `APPLE_SIGNING_IDENTITY` | macOS 签名证书标识 | Apple Developer Portal |
| `APPLE_CERTIFICATE` | macOS 签名证书 (base64) | Apple Developer Portal → 导出 p12 → base64 |
| `APPLE_CERTIFICATE_PASSWORD` | 证书密码 | 导出时设置 |
| `APPLE_TEAM_ID` | Apple Team ID | developer.apple.com/account |
| `APPLE_NOTARY_PASSWORD` | 公证密码 | appstoreconnect.apple.com → App-Specific Password |
| `TAURI_PRIVATE_KEY` | Tauri 更新签名密钥 | `pnpm tauri signer generate` |

## 补充：构建优化技巧

### 1. Rust 编译缓存

```bash
# 启用 sccache 加速 Rust 编译（CI 中使用）
export RUSTC_WRAPPER=sccache
export SCCACHE_GHA_ENABLED=true  # GitHub Actions 集成

# CI 缓存 sccache 目录
# 首次构建: ~15min (三平台)
# 缓存后: ~5min (三平台)
```

### 2. Vite 构建优化

```javascript
// vite.config.js 优化配置
export default {
  build: {
    // 代码分割策略: 窗口级按需加载
    rollupOptions: {
      output: {
        manualChunks: {
          'window-translate': ['./src/window/Translate/'],
          'window-recognize': ['./src/window/Recognize/'],
          'window-config': ['./src/window/Config/'],
          'vendor-react': ['react', 'react-dom'],
          'vendor-nextui': ['@nextui-org/react'],
          'vendor-animation': ['framer-motion', 'react-spring'],
        }
      }
    },
    // Sourcemap 策略: 仅 release 生成 hidden sourcemap
    sourcemap: process.env.TAURI_DEBUG ? true : 'hidden',
  },
  // CSS 优化
  css: {
    postcss: {
      plugins: [
        require('autoprefixer'),
        require('cssnano')({
          preset: ['default', { discardComments: { removeAll: true } }]
        })
      ]
    }
  }
}
```

### 3. Tauri 包体积优化

| 优化项 | 方法 | 效果 |
|--------|------|------|
| Rust LTO (Link Time Optimization) | `Cargo.toml`中添加 `lto = true` | 二进制缩小15-20% |
| 移除 `strip = "none"` | release构建使用`strip = true` | 二进制缩小10% |
| 代码分割 | Vite manualChunks（见上） | 冷启动减少200ms |
| 字体子集化 | 中文渲染字体仅打包必需字符 | 减少3-5MB |
| 图标压缩 | 使用`pngquant`压缩图标资源 | 减少50-80KB |

### 4. 跨平台构建加速策略

```bash
# macOS: 使用 universal binary 替代分平台构建
# 一次构建同时包含 x86_64 + arm64
cargo build --release --target universal-apple-darwin

# Linux: AppImage 复用，deb/rpm 从AppImage提取
# 一次构建生成三种格式
linuxdeploy --appdir AppDir --output appimage
linuxdeploy --appdir AppDir --output deb
linuxdeploy --appdir AppDir --output rpm

# CI 并行：lint/typecheck 与三平台构建并行运行
# check job 独立且快速(<2min)，作为后续构建的前置条件
```
