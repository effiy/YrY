## 经验教训汇总

> Q3 关键经验，影响后续Q4规划和架构演进。

| 编号 | 经验 | 来源目标 | 优先级 | 影响 |
|------|------|---------|--------|------|
| L1 | Tauri多窗口Jotai atom不跨窗口共享，需Rust事件总线中转 | yipot-003 | 高 | 影响所有跨窗口状态同步 |
| L2 | 剪切板轮询100ms间隔为三平台最优值 | yipot-001 | 中 | 性能基准，变更需重新验证 |
| L3 | macOS Vision OCR中文识别率>95%远优于Windows.Media.OCR(80%) | yipot-002 | 高 | 平台测试覆盖面需扩大 |
| L4 | AI翻译prompt模板质量对结果影响巨大 | yipot-001 | 中 | 加入预设模板库 |
| L5 | 插件三文件模式是社区贡献增长的关键（80%插件来自社区） | yipot-004 | 高 | 保持简单性，不加额外复杂度 |
| L6 | 自动更新成功率95%，5%失败因Windows文件占用 | yipot-004 | 中 | Windows更新流程需改进 |
| L7 | `tiny_http`高并发场景排队明显，但本地足够 | yipot-003 | 低 | 暂不迁移，持续监控 |
| L8 | i18next 22语言包仅150KB，RTL CSS适配量远超预期(30%) | yipot-004 | 中 | RTL需独立测试矩阵 |
