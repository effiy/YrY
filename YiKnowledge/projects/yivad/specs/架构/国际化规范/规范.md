# Spec: i18n Conventions

## 概述

本规范定义了 YiVad 的国际化文本使用方式、文件组织、命名规范等约定。YiVad 使用 Vue-i18n 11，支持中文（zh-CN）和英文（en）两种语言。

## 核心配置

### Vue-i18n 实例创建

```typescript
// src/languages/index.ts
import { createI18n } from "vue-i18n";
import { getBrowserLang } from "@/utils";
import { messages } from "./modules";

const i18n = createI18n({
  legacy: false,          // 使用 Composition API 模式
  locale: getBrowserLang(), // 从浏览器获取默认语言
  fallbackLocale: "en",   // 回退语言
  missingWarn: isDev,     // 开发环境显示缺失警告
  fallbackWarn: isDev,    // 开发环境显示回退警告
  messages
});
```

## 语言文件命名规范

### 模块命名

| 模块 | 目录 | 说明 |
|------|------|------|
| common | `common/` | 公共文本（按钮、提示、通用标签） |
| aichat | `aichat/` | AI 聊天相关文本 |
| story | `story/` | Story 管理相关文本 |
| topicdetail | `topicdetail/` | 话题详情相关文本 |
| rss | `rss/` | RSS 订阅相关文本 |
| home | `home/` | 首页/仪表盘相关文本 |
| kanban | `kanban/` | 看板相关文本 |
| roadmap | `roadmap/` | 路线图相关文本 |

### i18n Key 命名规范

| 类型 | 命名模式 | 示例 |
|------|----------|------|
| 公共按键 | `common.{action}` | `common.confirm`, `common.cancel` |
| 字段标签 | `{module}.{field}` | `project.name`, `issue.status` |
| 提示信息 | `{module}.{action}Tip` | `project.deleteTip` |
| 页面标题 | `{module}.title` | `project.title` |

## 组件中使用 i18n

### 模板中使用

```vue
<template>
  <!-- 直接使用 $t -->
  <el-button>{{ $t("common.confirm") }}</el-button>
  <el-input :placeholder="$t('common.search')" />

  <!-- 使用 v-bind -->
  <el-table-column :label="$t('common.status')" prop="status" />
</template>
```

### Script 中使用

```typescript
import { useI18n } from "vue-i18n";

const { t } = useI18n();

// 获取翻译文本
const confirmText = t("common.confirm");

// 带参数
const tipText = t("common.deleteTip", { name: "项目A" });
```

### 在全局 Store 中切换语言

```typescript
import { useGlobalStore } from "@/stores/modules/global";

const globalStore = useGlobalStore();
// 切换语言
globalStore.setLanguage("zh"); // 或 "en"
```

## 语言检测与切换

### 浏览器语言检测

```typescript
// src/utils/index.ts
export const getBrowserLang = () => {
  const browserLang = navigator.language;
  // 支持 zh-CN 和 en
  return browserLang.startsWith("zh") ? "zh" : "en";
};
```

### 持久化语言偏好

`globalStore` 中的 `language` 状态通过 `pinia-plugin-persistedstate` 持久化到 localStorage，用户下次访问时自动恢复语言偏好。

## 约束

### 必须遵守

- 所有用户可见文本必须使用国际化（`$t()` 或 `t()`）
- 语言文件按功能域模块化管理（`common/`, `aichat/`, `story/` 等）
- 新增语言文件时在 `src/languages/modules/index.ts` 中汇总导入
- 语言切换通过 `globalStore.setLanguage()` 进行

### 禁止

- 不要在模板、标签、提示等地方硬编码中文文本
- 不要在组件中直接操作 `localStorage` 修改语言
- 不要混合使用中文和英文文本（应统一使用 i18n key）
