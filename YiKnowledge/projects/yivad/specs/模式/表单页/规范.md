# Pattern: Form Page

## 概述

表单页是 YiVad 中用于数据创建和编辑的页面模式。YiVad 使用 **Element Plus 表单组件** 配合 **Vue 3 Composition API** 实现表单校验、数据绑定和提交逻辑。

**相关规范**：
- [组件结构规范](../../架构/组件模式/规范.md)
- [TypeScript 类型规范](../../架构/typescript规范/规范.md)
- [国际化规范](../../架构/国际化规范/规范.md)
- [API 规范](../../架构/api规范/规范.md)

## 表单模式类型

YiVad 中有三种表单使用场景：

| 场景 | 模式 | 说明 |
|------|------|------|
| 创建页 | `create.vue` | 新增数据，表单为空 |
| 编辑页 | `edit.vue` | 修改已有数据，表单预填充 |
| 详情页 | `detail.vue` | 查看数据，表单只读 |

## 完整模板

### 创建/编辑页组件

```vue
<template>
  <div class="form-page">
    <el-card>
      <!-- 页面标题 -->
      <template #header>
        <span>{{ isEdit ? $t("common.edit") : $t("common.add") }}</span>
      </template>

      <!-- 表单 -->
      <el-form
        ref="formRef"
        :model="formData"
        :rules="rules"
        label-width="120px"
        :disabled="isView"
      >
        <el-row :gutter="24">
          <el-col :span="12">
            <el-form-item :label="$t('common.name')" prop="name">
              <el-input
                v-model="formData.name"
                :placeholder="$t('common.pleaseInput')"
                clearable
              />
            </el-form-item>
          </el-col>
          <el-col :span="12">
            <el-form-item :label="$t('common.status')" prop="status">
              <el-select
                v-model="formData.status"
                :placeholder="$t('common.pleaseSelect')"
                clearable
              >
                <el-option
                  v-for="item in statusOptions"
                  :key="item.value"
                  :label="item.label"
                  :value="item.value"
                />
              </el-select>
            </el-form-item>
          </el-col>
        </el-row>

        <el-row :gutter="24">
          <el-col :span="24">
            <el-form-item :label="$t('common.description')" prop="description">
              <el-input
                v-model="formData.description"
                type="textarea"
                :rows="4"
                :placeholder="$t('common.pleaseInput')"
              />
            </el-form-item>
          </el-col>
        </el-row>
      </el-form>

      <!-- 操作按钮 -->
      <div class="form-footer">
        <el-button @click="handleCancel">
          {{ $t("common.cancel") }}
        </el-button>
        <el-button type="primary" :loading="submitting" @click="handleSubmit">
          {{ $t("common.save") }}
        </el-button>
      </div>
    </el-card>
  </div>
</template>

<script setup lang="ts">
import { ref, reactive, onMounted } from "vue";
import { useRouter, useRoute } from "vue-router";
import { useI18n } from "vue-i18n";
import { ElMessage } from "element-plus";
import type { FormInstance, FormRules } from "element-plus";
import { createDocument, updateDocument } from "@/api/modules/dataService";
import type { YiAiEnvelope } from "@/api/interface/yiweb";

const { t } = useI18n();
const router = useRouter();
const route = useRoute();

// 页面模式
const isEdit = ref(false);
const isView = ref(false);

// 表单引用
const formRef = ref<FormInstance>();

// 提交状态
const submitting = ref(false);

// 表单数据
const formData = reactive({
  name: "",
  status: "",
  description: ""
});

// 表单校验规则
const rules: FormRules = {
  name: [
    { required: true, message: t("common.pleaseInput"), trigger: "blur" },
    { min: 2, max: 50, message: "长度在 2 到 50 个字符", trigger: "blur" }
  ],
  status: [
    { required: true, message: t("common.pleaseSelect"), trigger: "change" }
  ]
};

// 状态选项
const statusOptions = [
  { label: "启用", value: "active" },
  { label: "禁用", value: "inactive" }
];

// 加载编辑数据
const loadData = async (id: string) => {
  const res = await createDocument("collection_name", {});
  // 实际应使用 queryDocuments 获取数据
  // 此处用示例数据
  Object.assign(formData, {
    name: "示例名称",
    status: "active",
    description: "示例描述"
  });
};

// 提交表单
const handleSubmit = async () => {
  if (!formRef.value) return;

  const valid = await formRef.value.validate().catch(() => false);
  if (!valid) return;

  submitting.value = true;
  try {
    if (isEdit.value) {
      await updateDocument("collection_name", { _id: route.params.id }, { ...formData });
    } else {
      await createDocument("collection_name", { ...formData });
    }
    ElMessage.success(t("common.saveSuccess"));
    router.back();
  } catch (error) {
    ElMessage.error(t("common.saveFailed"));
  } finally {
    submitting.value = false;
  }
};

// 取消
const handleCancel = () => {
  router.back();
};

// 初始化
onMounted(() => {
  const id = route.params.id as string;
  if (id) {
    isEdit.value = true;
    loadData(id);
  }
});
</script>

<style lang="scss" scoped>
.form-page {
  padding: 16px;

  .form-footer {
    margin-top: 24px;
    text-align: center;
  }
}
</style>
```

## 表单提交模式

### 标准提交流程

```typescript
const handleSubmit = async () => {
  // 1. 校验表单
  const valid = await formRef.value?.validate().catch(() => false);
  if (!valid) return;

  // 2. 设置 loading
  submitting.value = true;

  try {
    // 3. 调用 API
    if (isEdit.value) {
      await updateApi(id, formData);
    } else {
      await createApi(formData);
    }

    // 4. 成功提示
    ElMessage.success("保存成功");

    // 5. 返回上一页
    router.back();
  } catch (error) {
    // 6. 错误提示
    ElMessage.error("保存失败");
  } finally {
    // 7. 关闭 loading
    submitting.value = false;
  }
};
```

## 多步骤表单向导

对于复杂的数据录入场景（如创建项目需要填写基本信息、配置成员、设置权限），使用多步骤表单（Wizard）：

```vue
<template>
  <div class="form-wizard">
    <!-- 步骤条 -->
    <el-steps :active="currentStep" align-center finish-status="success">
      <el-step :title="$t('form.stepBasicInfo')" />
      <el-step :title="$t('form.stepMembers')" />
      <el-step :title="$t('form.stepPermission')" />
      <el-step :title="$t('form.stepConfirm')" />
    </el-steps>

    <!-- 步骤内容 -->
    <div class="step-content">
      <!-- 步骤 1：基本信息 -->
      <el-form
        v-show="currentStep === 0"
        ref="step1Ref"
        :model="formData"
        :rules="step1Rules"
        label-width="120px"
      >
        <el-form-item :label="$t('common.name')" prop="name">
          <el-input v-model="formData.name" />
        </el-form-item>
        <el-form-item :label="$t('common.description')" prop="description">
          <el-input v-model="formData.description" type="textarea" :rows="4" />
        </el-form-item>
      </el-form>

      <!-- 步骤 2：成员配置 -->
      <div v-show="currentStep === 1">
        <MemberSelector v-model="formData.members" />
      </div>

      <!-- 步骤 3：权限设置 -->
      <div v-show="currentStep === 2">
        <PermissionConfig v-model="formData.permissions" />
      </div>

      <!-- 步骤 4：确认提交 -->
      <div v-show="currentStep === 3">
        <el-descriptions :column="2" border>
          <el-descriptions-item :label="$t('common.name')">
            {{ formData.name }}
          </el-descriptions-item>
          <el-descriptions-item :label="$t('common.members')">
            {{ formData.members.length }} 人
          </el-descriptions-item>
          <!-- ... -->
        </el-descriptions>
      </div>
    </div>

    <!-- 步骤操作按钮 -->
    <div class="step-actions">
      <el-button v-if="currentStep > 0" @click="prevStep">
        {{ $t("common.prev") }}
      </el-button>
      <el-button
        v-if="currentStep < 3"
        type="primary"
        @click="nextStep"
      >
        {{ $t("common.next") }}
      </el-button>
      <el-button
        v-if="currentStep === 3"
        type="primary"
        :loading="submitting"
        @click="handleSubmit"
      >
        {{ $t("common.submit") }}
      </el-button>
    </div>
  </div>
</template>

<script setup lang="ts">
const currentStep = ref(0);
const step1Ref = ref<FormInstance>();

// 步骤校验
const stepValidators: Record<number, () => Promise<boolean>> = {
  0: async () => {
    return await step1Ref.value?.validate().then(() => true).catch(() => false);
  },
  1: async () => {
    return formData.members.length > 0;
  },
  2: async () => {
    return true; // 权限配置非必选
  }
};

const nextStep = async () => {
  const validator = stepValidators[currentStep.value];
  if (validator && !(await validator())) {
    ElMessage.warning("请完成当前步骤");
    return;
  }
  currentStep.value++;
};

const prevStep = () => {
  currentStep.value--;
};

// 提交时合并所有步骤数据
const handleSubmit = async () => {
  submitting.value = true;
  try {
    await createApi(formData);
    ElMessage.success("创建成功");
    router.back();
  } finally {
    submitting.value = false;
  }
};
</script>
```

## 草稿自动保存

对于内容较多的表单，实现草稿自动保存，防止用户意外丢失数据：

```typescript
// src/hooks/useAutoSave.ts
import { watch, onBeforeUnmount } from "vue";
import { useDebounceFn } from "@vueuse/core";

export function useAutoSave<T extends Record<string, any>>(
  formData: T,
  options: {
    storageKey: string;       // localStorage 键名
    debounceMs?: number;      // 防抖延迟，默认 3000
    enabled?: () => boolean;  // 是否启用自动保存
  }
) {
  const { storageKey, debounceMs = 3000, enabled = () => true } = options;

  // 保存草稿
  const saveDraft = useDebounceFn(() => {
    if (!enabled()) return;
    const draft = {
      data: formData,
      savedAt: new Date().toISOString()
    };
    localStorage.setItem(storageKey, JSON.stringify(draft));
  }, debounceMs);

  // 恢复草稿
  const restoreDraft = (): T | null => {
    const raw = localStorage.getItem(storageKey);
    if (!raw) return null;

    try {
      const draft = JSON.parse(raw);
      const savedAt = new Date(draft.savedAt);
      const hoursSinceSave = (Date.now() - savedAt.getTime()) / (1000 * 60 * 60);

      // 草稿超过 24 小时自动清除
      if (hoursSinceSave > 24) {
        clearDraft();
        return null;
      }

      return draft.data;
    } catch {
      clearDraft();
      return null;
    }
  };

  // 清除草稿
  const clearDraft = () => {
    localStorage.removeItem(storageKey);
  };

  // 监听表单数据变化，自动保存
  watch(
    () => formData,
    () => saveDraft(),
    { deep: true }
  );

  // 组件卸载时保存一次
  onBeforeUnmount(() => {
    saveDraft();
  });

  return { saveDraft, restoreDraft, clearDraft };
}

// 使用示例
const formData = reactive({ name: "", description: "", status: "" });

const { restoreDraft, clearDraft } = useAutoSave(formData, {
  storageKey: `draft-project-${route.params.id || "new"}`,
  debounceMs: 3000
});

onMounted(() => {
  const draft = restoreDraft();
  if (draft) {
    ElMessageBox.confirm(
      "检测到未保存的草稿，是否恢复？",
      "恢复草稿",
      { confirmButtonText: "恢复", cancelButtonText: "放弃" }
    ).then(() => {
      Object.assign(formData, draft);
    }).catch(() => {
      clearDraft();
    });
  }
});
```

## 表单脏状态检测

在用户离开页面时，检测表单是否有未保存的修改：

```typescript
// src/hooks/useFormDirty.ts
import { ref, watch, onBeforeUnmount } from "vue";
import { onBeforeRouteLeave } from "vue-router";

export function useFormDirty<T extends Record<string, any>>(
  formData: T,
  originalData: T
) {
  const isDirty = ref(false);

  // 深度比较表单数据与原始数据
  const checkDirty = () => {
    isDirty.value = JSON.stringify(formData) !== JSON.stringify(originalData);
  };

  watch(() => formData, checkDirty, { deep: true });

  // 路由离开前确认
  onBeforeRouteLeave(async () => {
    if (!isDirty.value) return true;

    try {
      await ElMessageBox.confirm(
        "有未保存的修改，确定离开吗？",
        "提示",
        { type: "warning", confirmButtonText: "离开", cancelButtonText: "留下" }
      );
      return true;
    } catch {
      return false;
    }
  });

  // 浏览器关闭/刷新前确认
  const handleBeforeUnload = (e: BeforeUnloadEvent) => {
    if (isDirty.value) {
      e.preventDefault();
      e.returnValue = "";
    }
  };
  window.addEventListener("beforeunload", handleBeforeUnload);
  onBeforeUnmount(() => {
    window.removeEventListener("beforeunload", handleBeforeUnload);
  });

  return { isDirty };
}
```

## 动态表单字段

支持用户动态添加/删除表单字段（如多个联系方式、多个附件）：

```vue
<template>
  <el-form :model="formData" label-width="120px">
    <!-- 动态字段列表 -->

          v-model="item.type"

          style="width: 120px"
        >
          <el-option label="手机" value="phone" />
          <el-option label="邮箱" value="email" />
          <el-option label="微信" value="wechat" />
        </el-select>
        <el-input
          v-model="item.value"
          :placeholder="$t('form.contactValue')"
          style="flex: 1"
        />
        <el-button
          type="danger"
          :icon="Delete"
          circle
          :disabled="formData.contacts.length <= 1"
          @click="removeContact(index)"
        />
      </div>
    </el-form-item>

    <el-button type="primary" link @click="addContact">
      + {{ $t("form.addContact") }}
    </el-button>
  </el-form>
</template>

<script setup lang="ts">
import { Delete } from "@element-plus/icons-vue";

interface ContactItem {
  key: string;
  type: string;
  value: string;
}

const formData = reactive({
  contacts: [
    { key: generateKey(), type: "phone", value: "" }
  ] as ContactItem[]
});

const contactRules = [
  { required: true, message: "请输入联系方式", trigger: "blur" }
];

const addContact = () => {
  formData.contacts.push({
    key: generateKey(),
    type: "phone",
    value: ""
  });
};

const removeContact = (index: number) => {
  formData.contacts.splice(index, 1);
};

function generateKey(): string {
  return `contact_${Date.now()}_${Math.random().toString(36).slice(2)}`;
}
</script>
```

## 级联选择

```vue
<template>
  <el-form :model="formData" label-width="120px">
    <el-form-item :label="$t('common.project')" prop="projectId">
      <el-select
        v-model="formData.projectId"

      >
        <el-option
          v-for="p in projectOptions"
          :key="p.value"
          :label="p.label"
          :value="p.value"
        />
      </el-select>
    </el-form-item>

    <el-form-item :label="$t('common.module')" prop="moduleId">
      <el-select
        v-model="formData.moduleId"
        :placeholder="$t('common.pleaseSelect')"
        :loading="moduleLoading"
        :disabled="!formData.projectId"
      >
        <el-option
          v-for="m in moduleOptions"
          :key="m.value"
          :label="m.label"
          :value="m.value"
        />
      </el-select>
    </el-form-item>
  </el-form>
</template>

<script setup lang="ts">
const moduleOptions = ref<Option[]>([]);
const moduleLoading = ref(false);

const handleProjectChange = async (projectId: string) => {
  // 重置下级选择
  formData.moduleId = "";

  if (!projectId) {
    moduleOptions.value = [];
    return;
  }

  moduleLoading.value = true;
  try {
    const res = await queryDocuments({
      cname: "modules",
      filter: { projectId }
    });
    const data = (res as YiAiEnvelope<{ list: any[] }>).data;
    moduleOptions.value = data.list.map((m: any) => ({
      label: m.name,
      value: m._id
    }));
  } finally {
    moduleLoading.value = false;
  }
};
</script>
```

## 文件上传与预览

在表单中集成文件上传，支持图片预览和文件列表：

```vue
<template>
  <el-form :model="formData" label-width="120px">
    <!-- 图片上传（带预览） -->
    <el-form-item :label="$t('form.coverImage')" prop="coverImage">
      <el-upload
        :action="uploadUrl"
        :headers="uploadHeaders"
        :file-list="coverImageList"
        list-type="picture-card"
        :limit="1"
        :on-success="handleCoverSuccess"
        :on-remove="handleCoverRemove"
        :before-upload="beforeImageUpload"
      >
        <el-icon><Plus /></el-icon>
      </el-upload>
    </el-form-item>

    <!-- 附件上传 -->
    <el-form-item :label="$t('form.attachments')" prop="attachments">
      <el-upload
        :action="uploadUrl"
        :headers="uploadHeaders"
        :file-list="attachmentList"
        :on-success="handleAttachmentSuccess"
        :on-remove="handleAttachmentRemove"
        :before-upload="beforeFileUpload"
        multiple
      >
        <el-button type="primary">
          {{ $t("form.uploadFile") }}
        </el-button>
        <template #tip>
          <div class="upload-tip">
            支持 pdf、doc、xlsx、zip，单文件不超过 10MB
          </div>
        </template>
      </el-upload>
    </el-form-item>
  </el-form>
</template>

<script setup lang="ts">
import { Plus } from "@element-plus/icons-vue";
import type { UploadFile, UploadFiles } from "element-plus";
import { useUserStore } from "@/stores/modules/user";

const userStore = useUserStore();
const uploadUrl = `${import.meta.env.RSBUILD_API_BASE}/upload`;
const uploadHeaders = {
  Authorization: `Bearer ${userStore.token}`
};

// 图片上传
const coverImageList = ref<UploadFile[]>([]);

const handleCoverSuccess = (response: any, file: UploadFile) => {
  formData.coverImage = response.data.url;
};

const handleCoverRemove = () => {
  formData.coverImage = "";
};

const beforeImageUpload = (file: File) => {
  const isImage = file.type.startsWith("image/");
  const isLt5M = file.size / 1024 / 1024 < 5;

  if (!isImage) {
    ElMessage.error("只能上传图片文件");
    return false;
  }
  if (!isLt5M) {
    ElMessage.error("图片大小不能超过 5MB");
    return false;
  }
  return true;
};

// 附件上传
const attachmentList = ref<UploadFile[]>([]);

const handleAttachmentSuccess = (response: any, file: UploadFile) => {
  formData.attachments.push({
    name: file.name,
    url: response.data.url,
    size: file.size
  });
};

const handleAttachmentRemove = (file: UploadFile) => {
  const index = formData.attachments.findIndex(
    (a: any) => a.name === file.name
  );
  if (index > -1) {
    formData.attachments.splice(index, 1);
  }
};

const beforeFileUpload = (file: File) => {
  const maxSize = 10 * 1024 * 1024; // 10MB
  if (file.size > maxSize) {
    ElMessage.error("文件大小不能超过 10MB");
    return false;
  }
  return true;
};
</script>
```

## 表单提交进度

对于包含文件上传或耗时操作的表单，显示提交进度：

```vue
<template>
  <div class="form-page">
    <el-card>
      <el-form ref="formRef" :model="formData" :rules="rules">
        <!-- 表单内容 -->
      </el-form>

      <div class="form-footer">
        <!-- 提交进度条 -->
        <div v-if="submitting" class="submit-progress">
          <el-progress
            :percentage="submitProgress"
            :status="submitProgress === 100 ? 'success' : undefined"
            :stroke-width="8"
          />
          <span class="progress-text">{{ submitStatusText }}</span>
        </div>

        <el-button @click="handleCancel" :disabled="submitting">
          {{ $t("common.cancel") }}
        </el-button>
        <el-button type="primary" :loading="submitting" @click="handleSubmit">
          {{ submitting ? submitStatusText : $t("common.save") }}
        </el-button>
      </div>
    </el-card>
  </div>
</template>

<script setup lang="ts">
const submitting = ref(false);
const submitProgress = ref(0);
const submitStatusText = ref("");

const handleSubmit = async () => {
  const valid = await formRef.value?.validate().catch(() => false);
  if (!valid) return;

  submitting.value = true;

  // 模拟多步骤提交
  const steps = [
    { text: "正在保存基本信息...", progress: 30 },
    { text: "正在上传附件...", progress: 60 },
    { text: "正在处理中...", progress: 90 },
    { text: "保存成功", progress: 100 }
  ];

  try {
    for (const step of steps) {
      submitStatusText.value = step.text;
      submitProgress.value = step.progress;
      await new Promise(resolve => setTimeout(resolve, 500));
    }

    await createApi(formData);
    ElMessage.success("保存成功");

    // 成功后再延迟一下让用户看到 100%
    await new Promise(resolve => setTimeout(resolve, 500));
    router.back();
  } catch (error) {
    ElMessage.error("保存失败");
    submitProgress.value = 0;
    submitStatusText.value = "";
  } finally {
    submitting.value = false;
  }
};
</script>
```

## 边界情况

### 表单数据边界

| 边界情况 | 处理方式 | 说明 |
|----------|----------|------|
| 编辑时数据加载失败 | 显示错误提示，提供返回按钮 | 用户可返回列表页 |
| 编辑时数据不存在 | 显示 404 状态，"数据不存在或已被删除" | 区分"加载失败"和"数据不存在" |
| 提交时网络断开 | 捕获错误，保留表单数据，提示用户稍后重试 | 不丢失用户已填写的数据 |
| 提交后后端返回错误 | 显示具体错误信息，不关闭表单 | 用户可修改后重新提交 |
| 富文本内容为空 | 校验时检查纯文本内容，过滤 HTML 标签 | 防止用户只输入空格/换行 |
| 数字输入超出范围 | 使用 `el-input-number` 的 `:min` 和 `:max` 限制 | 前端校验 + 后端校验双重保障 |
| 日期选择无效范围 | 使用 `disabledDate` 禁用不可选日期 | 如开始日期不能晚于结束日期 |
| 表单字段联动 | 使用 `watch` 监听联动字段变化，重置下游字段 | 如项目变化时重置模块选择 |

### 表单提交流程边界

| 边界情况 | 处理方式 |
|----------|----------|
| 重复提交 | 提交时禁用按钮（`submitting` 状态），使用 `ElMessageBox.confirm` 二次确认 |
| 提交耗时过长 | 显示进度条，超时（30s）后提示用户 |
| 提交成功后立即返回 | 成功提示后延迟 500ms 再返回，避免提示被跳转覆盖 |
| 浏览器后退/刷新 | 使用 `useFormDirty` 检测未保存修改，弹出确认提示 |
| 多标签页同时编辑 | 提交时检测数据版本（`updatedAt` 字段），提示冲突 |

### 草稿边界

| 边界情况 | 处理方式 |
|----------|----------|
| 草稿超过 24 小时 | 自动清除，不提示恢复 |
| 草稿数据与当前表单结构不匹配 | 恢复时字段校验，丢失字段使用默认值 |
| 多个草稿（不同 ID） | 使用 `storageKey` 区分（如 `draft-project-${id}`） |
| localStorage 已满 | 捕获 `QuotaExceededError`，提示用户清理 |

## 反模式

### 不要这样做

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 跳过表单校验 | 直接调用 API 不先校验 | `await formRef.value?.validate()` 后再提交 | 脏数据提交到后端 |
| 不处理提交 loading | 点击提交后按钮无反馈，用户可重复点击 | 使用 `submitting` 状态禁用按钮 + 显示 loading | 重复提交导致数据重复 |
| 不处理提交失败 | `try { await api } catch {}` 空 catch | catch 中显示 `ElMessage.error`，保留表单数据 | 用户不知道失败，数据丢失 |
| 在模板中硬编码文本 | `{{ "请输入名称" }}` | `{{ $t("form.pleaseInputName") }}` | 国际化缺失 |
| 不使用 Element Plus 表单组件 | 手动用 `<input>` 和自定义校验 | 使用 `el-form` + `el-input` + `FormRules` | 舍弃 Element Plus 的表单校验和布局能力 |
| 表单数据不定义类型 | `const formData = reactive({})` | `const formData = reactive<ProjectForm>({ ... })` | 失去类型检查和 IDE 智能提示 |
| 提交时不清理草稿 | 提交成功后草稿仍存在 | 提交成功后调用 `clearDraft()` | 下次打开仍提示恢复草稿 |
| 编辑时直接用返回按钮 | 点击返回不检查修改 | 使用 `useFormDirty` 检测，有修改时弹出确认 | 用户意外丢失修改 |
| 级联选择不重置下游 | 选择项目后模块选择仍保留旧值 | 在 `handleProjectChange` 中重置 `formData.moduleId = ""` | 提交了不匹配的关联数据 |
| 动态字段使用 index 作为 key | `:key="index"` | `:key="item.key"`（使用唯一 ID） | 删除中间项时组件复用导致状态错乱 |
| 大文件上传无进度提示 | 上传 500MB 文件无进度反馈 | 使用 `el-upload` 的 `on-progress` 或进度条 | 用户不知道上传进度 |
| 不设置上传文件大小限制 | 允许上传任意大小的文件 | 使用 `before-upload` 检查文件大小 | 后端拒绝或超时 |
