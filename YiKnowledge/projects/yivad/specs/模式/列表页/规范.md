# Pattern: List Page

## 概述

列表页是 YiVad 中最常见的页面模式。YiVad 使用 **ProTable 组件** 作为标准表格，配合 **useTable Hook** 管理表格数据状态。本规范定义了列表页的完整实现模式。

## 核心组件

### ProTable

ProTable 是 YiVad 的标准表格组件，位于 `src/components/ProTable/`。封装了 ElTable + ElPagination + 工具栏，通过 `request` 函数驱动数据加载，内置 loading/empty/error 状态。所有列表页面都应使用 ProTable，禁止直接使用 `el-table`。

**Props**：

| Prop | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `columns` | `ColumnProps[]` | 是 | — | 列定义（见下方 ColumnProps） |
| `request` | `(params: RequestParams) => Promise<{list: any[], total: number}>` | 是 | — | 数据请求函数，组件自动传入分页+排序+筛选参数 |
| `searchForm` | `SearchField[]` | 否 | `[]` | 搜索表单配置，传入后自动渲染内置 SearchForm |
| `selection` | `boolean` | 否 | `false` | 是否开启多选 |
| `rowKey` | `string` | 否 | `'id'` | 行唯一键，多选时用于跨页保持 |
| `pageSize` | `number` | 否 | `20` | 默认每页条数 |
| `pageSizes` | `number[]` | 否 | `[10, 20, 50, 100]` | 每页条数选项 |
| `tableProps` | `Partial<ElTableProps>` | 否 | `{}` | 透传给 ElTable 的额外属性（border, stripe 等） |
| `showPagination` | `boolean` | 否 | `true` | 是否显示分页器 |
| `showToolbar` | `boolean` | 否 | `true` | 是否显示工具栏区域 |

**ColumnProps**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `prop` | `string` | 是 | 列字段名 |
| `label` | `string` | 是 | 列标题 |
| `width` | `string \| number` | 否 | 列宽 |
| `minWidth` | `string \| number` | 否 | 最小列宽 |
| `fixed` | `'left' \| 'right'` | 否 | 固定列 |
| `sortable` | `boolean \| 'custom'` | 否 | 是否可排序 |
| `align` | `'left' \| 'center' \| 'right'` | 否 | 对齐方式，默认 `'left'` |
| `formatter` | `(row: any, column: ColumnProps, cellValue: any) => string` | 否 | 单元格格式化函数 |
| `render` | `(scope: {row: any, $index: number}) => VNode` | 否 | 自定义渲染函数（用于复杂单元格） |
| `showOverflowTooltip` | `boolean` | 否 | 文本溢出时显示 tooltip |

**Events**：

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `selection-change` | `(selection: any[])` | 多选变化 |
| `row-click` | `(row: any, column: any, event: Event)` | 行点击 |
| `sort-change` | `(sort: {prop: string, order: 'ascending' \| 'descending' \| null})` | 排序变化 |
| `current-change` | `(page: number)` | 页码变化 |
| `size-change` | `(size: number)` | 每页条数变化 |

**Slots**：

| 插槽名 | 作用域 | 说明 |
|--------|--------|------|
| `toolbar` | `{selection: any[], refresh: () => void}` | 工具栏区域（批量操作按钮等） |
| `toolbar-left` | — | 工具栏左侧区域 |
| `toolbar-right` | — | 工具栏右侧区域 |
| `column-{prop}` | `{row: any, $index: number}` | 列自定义插槽，prop 为列字段名 |
| `empty` | — | 空数据自定义展示 |

**Expose**（ref 可调用方法）：

| 方法 | 参数 | 说明 |
|------|------|------|
| `refresh()` | — | 刷新当前页数据 |
| `reload()` | — | 重置到第一页并刷新 |
| `clearSelection()` | — | 清空所有选中行 |
| `getSelection()` | — | 获取当前所有选中行 |
| `setSearchParams(params)` | `Record<string, any>` | 外部设置搜索参数并触发查询 |

### useTable Hook

`useTable` Hook（`src/hooks/useTable.ts`）管理表格数据状态，适用于需要自定义表格布局的场景：

```typescript
export const useTable = (
  api?: (params: any) => Promise<any>,  // 请求函数
  initParam?: object,                    // 初始参数
  isPageable?: boolean,                  // 是否分页，默认 true
  dataCallBack?: (data: any) => any,     // 数据处理回调
  requestError?: (error: any) => void    // 错误处理回调
) => {
  return {
    tableData,        // 表格数据
    pageable,         // 分页数据 { pageNum, pageSize, total }
    searchParam,      // 搜索参数
    search,           // 执行搜索
    reset,            // 重置搜索
    handleSizeChange, // 每页大小变化
    handleCurrentChange, // 当前页变化
    getTableList      // 刷新表格数据
  };
};
```

> **注意**：`useTable` Hook 用于需要自定义表格布局的场景。大多数列表页直接使用 ProTable 组件即可，其内部已封装了 `useTableData` + `useTableSelection` 两个 composable，无需手动调用 `useTable`。

## 完整模板

### 列表页组件

```vue
<template>
  <div class="list-page">
    <!-- ProTable：内置 SearchForm + 工具栏 + 表格 + 分页 -->
    <ProTable
      ref="tableRef"
      :columns="columns"
      :request="fetchTableData"
      :search-form="searchFields"
      :selection="true"
      row-key="_id"
      :table-props="{ border: true, stripe: true }"
      @selection-change="handleSelectionChange"
      @row-click="handleRowClick"
    >
      <!-- 工具栏左侧 -->
      <template #toolbar-left="{ selection }">
        <el-button v-auth="'add'" type="primary" @click="handleAdd">
          {{ $t('common.add') }}
        </el-button>
        <el-button
          v-if="selection.length"
          v-auth="'delete'"
          type="danger"
          @click="handleBatchDelete(selection)"
        >
          {{ $t('common.delete') }} ({{ selection.length }})
        </el-button>
      </template>

      <!-- 操作列 -->
      <template #column-operation="{ row }">
        <el-button v-auth="'edit'" text type="primary" @click="handleEdit(row)">
          {{ $t('common.edit') }}
        </el-button>
        <el-button v-auth="'delete'" text type="danger" @click="handleDelete(row)">
          {{ $t('common.delete') }}
        </el-button>
      </template>
    </ProTable>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import { useRouter } from 'vue-router';
import { useI18n } from 'vue-i18n';
import { ElMessage, ElMessageBox } from 'element-plus';
import ProTable from '@/components/ProTable/index.vue';
import type { ColumnProps, SearchField, RequestParams } from '@/components/ProTable/types';
import { queryDocuments, deleteDocument } from '@/api/modules/dataService';
import type { YiAiEnvelope } from '@/api/interface/yiweb';

const { t } = useI18n();
const router = useRouter();

const tableRef = ref<InstanceType<typeof ProTable>>();

// 搜索表单配置
const searchFields: SearchField[] = [
  { type: 'input', key: 'name', label: t('common.name'), placeholder: '请输入' },
  { type: 'select', key: 'status', label: t('common.status'), options: [] },
];

// 表格列配置
const columns: ColumnProps[] = [
  { prop: 'name', label: t('common.name'), minWidth: '200px', showOverflowTooltip: true },
  { prop: 'status', label: t('common.status'), width: '120px' },
  { prop: 'createTime', label: t('common.createTime'), width: '180px', sortable: 'custom' },
  { prop: 'operation', label: t('common.action'), width: '200px', fixed: 'right' },
];

// 获取表格数据
const fetchTableData = async (params: RequestParams) => {
  const res = await queryDocuments({
    cname: 'collection_name',
    filter: params.filter || {},
    pageNum: params.page || 1,
    pageSize: params.pageSize || 20,
  });
  const data = (res as YiAiEnvelope<{ list: any[]; total: number }>).data;
  return { list: data.list, total: data.total };
};

// 搜索（ProTable 内置 SearchForm 自动处理，无需手动监听）
// 重置（同上）

// 选择变化
const handleSelectionChange = (selection: any[]) => {
  // selection 为当前所有选中行的数组
};

// 行点击
const handleRowClick = (row: any) => {
  router.push(`/module/detail/${row._id}`);
};

// 新增
const handleAdd = () => {
  router.push('/module/create');
};

// 编辑
const handleEdit = (row: any) => {
  router.push(`/module/detail/${row._id}`);
};

// 删除
const handleDelete = async (row: any) => {
  await ElMessageBox.confirm(t('common.deleteTip'), t('common.confirm'), { type: 'warning' });
  await deleteDocument('collection_name', { _id: row._id });
  ElMessage.success(t('common.deleteSuccess'));
  tableRef.value?.refresh();
};

// 批量删除
const handleBatchDelete = async (selection: any[]) => {
  const ids = selection.map((item: any) => item._id);
  await ElMessageBox.confirm(
    `确定删除选中的 ${ids.length} 条记录吗？`,
    t('common.confirm'),
    { type: 'warning' },
  );
  await deleteDocument('collection_name', { _id: { $in: ids } });
  ElMessage.success(t('common.deleteSuccess'));
  tableRef.value?.reload();
};
</script>

<style lang="scss" scoped>
.list-page {
  padding: 16px;
}
</style>
```

## 搜索模式

### SearchForm 配置

ProTable 内置 SearchForm，通过 `searchForm` prop 配置。详细配置见 [SearchForm 模式规范](../search-form/spec.md)。

```typescript
const searchFields: SearchField[] = [
  { type: 'input', key: 'name', label: '名称', placeholder: '请输入' },
  { type: 'select', key: 'status', label: '状态', options: statusOptions },
  { type: 'date-range', key: 'createTime', label: '创建时间' },
  { type: 'date', key: 'createDate', label: '创建日期' },
];
```

### 搜索流程

1. 用户在 SearchForm 中输入搜索条件
2. 点击搜索按钮，ProTable 自动组装参数并调用 `request` 函数
3. 自动重置到第一页
4. 点击重置按钮清空表单，重新加载全部数据

## 分页模式

ProTable 自动处理分页逻辑：

1. `request` 函数接收 `{ page, pageSize, sort, ...filter }` 参数
2. 后端返回 `{ list, total }` 格式
3. 分页变化时自动调用 `request` 并更新页码
4. 通过 `pageSize`/`pageSizes` prop 自定义分页选项

## 操作列模式

### 通过 column-{prop} 插槽

推荐使用插槽方式渲染操作列，直接在模板中编写，比 `render` 函数更直观：

```vue
<ProTable :columns="columns" :request="fetchData">
  <template #column-operation="{ row }">
    <el-button text type="primary" @click="handleView(row)">查看</el-button>
    <el-button v-auth="'edit'" text type="primary" @click="handleEdit(row)">编辑</el-button>
    <el-button v-auth="'delete'" text type="danger" @click="handleDelete(row)">删除</el-button>
  </template>
</ProTable>
```

### 通过 render 函数（备选）

## 状态展示模式

### 加载骨架屏

当表格数据首次加载时，显示骨架屏占位，提升感知性能：

```vue
<template>
  <div class="list-page">
    <!-- 骨架屏加载状态 -->
    <template v-if="isFirstLoading">
      <el-skeleton :rows="8" animated />
    </template>

    <!-- 正常表格 -->
    <template v-else>
      <SearchForm ... />
      <div class="toolbar">...</div>
      <ProTable ... />
    </template>
  </div>
</template>

<script setup lang="ts">
const isFirstLoading = ref(true);

const fetchTableData = async (params: any) => {
  try {
    const res = await queryDocuments({ ... });
    // ...
    isFirstLoading.value = false;
  } catch (error) {
    isFirstLoading.value = false;
  }
};

// 骨架屏仅在首次加载时显示，后续刷新不显示
const handleRefresh = () => {
  tableRef.value?.refresh(); // 不触发骨架屏
};
</script>
```

|------|----------|----------|

### 错误状态与重试

当数据请求失败时，显示错误信息并提供重试入口：

```vue
<template>
  <div class="list-page">
    <!-- 错误状态 -->
    <el-result
      v-if="errorState.hasError"
      icon="error"
      :title="$t('common.loadFailed')"
      :sub-title="errorState.message"
    >
      <template #extra>
        <el-button type="primary" @click="handleRetry">
          {{ $t("common.retry") }}
        </el-button>
        <el-button @click="handleGoBack">
          {{ $t("common.back") }}
        </el-button>
      </template>
    </el-result>

    <!-- 正常内容 -->
    <template v-else>
      <SearchForm ... />
      <div class="toolbar">...</div>
      <ProTable
        ref="tableRef"
        :columns="columns"
        :request="fetchTableData"
        ...
      />
    </template>
  </div>
</template>

<script setup lang="ts">
const errorState = reactive({
  hasError: false,
  message: "",
  retryCount: 0
});

// 请求错误回调（useTable 的 requestError 参数）
const handleRequestError = (error: any) => {
  errorState.hasError = true;
  errorState.message = error?.message || "数据加载失败，请稍后重试";
};

// 重试
const handleRetry = () => {
  errorState.hasError = false;
  errorState.retryCount++;
  tableRef.value?.refresh();
};
</script>
```

## 批量操作与选择

### 批量操作工具栏

批量操作按钮放在 ProTable 的 `#toolbar-left` 或 `#toolbar` 插槽中，通过作用域获取当前选中行。

```vue
<template>
  <div class="list-page">
    <ProTable
      ref="tableRef"
      :columns="columns"
      :request="fetchTableData"
      :selection="true"
      row-key="_id"
      @selection-change="handleSelectionChange"
    >
      <template #toolbar-left="{ selection }">
        <el-button v-auth="'add'" type="primary" @click="handleAdd">
          {{ $t('common.add') }}
        </el-button>
        <template v-if="selection.length">
          <el-button v-auth="'delete'" type="danger" @click="handleBatchDelete(selection)">
            {{ $t('common.batchDelete') }} ({{ selection.length }})
          </el-button>
          <el-button v-auth="'export'" @click="handleBatchExport(selection)">
            {{ $t('common.batchExport') }} ({{ selection.length }})
          </el-button>
        </template>
      </template>
    </ProTable>
  </div>
</template>

<script setup lang="ts">
const selectedRows = ref<any[]>([]);

const handleSelectionChange = (selection: any[]) => {
  selectedRows.value = selection;
};

// 批量删除（带进度提示）
const handleBatchDelete = async (selection: any[]) => {
  const ids = selection.map((item: any) => item._id);
  await ElMessageBox.confirm(
    `确定删除选中的 ${ids.length} 条记录吗？此操作不可撤销。`,
    '批量删除',
    { type: 'warning', confirmButtonText: '确认删除' },
  );

  const loadingInstance = ElLoading.service({
    text: `正在删除 ${ids.length} 条记录...`,
    background: 'rgba(0, 0, 0, 0.7)',
  });

  try {
    await deleteDocument('collection_name', { _id: { $in: ids } });
    loadingInstance.close();
    ElMessage.success(`成功删除 ${ids.length} 条记录`);
    tableRef.value?.reload();
  } catch (error) {
    loadingInstance.close();
    ElMessage.error('批量删除失败');
  }
};
</script>
```

## 响应式列可见性

根据屏幕宽度动态调整列的显示：

```typescript
import { useWindowSize } from "@vueuse/core";

const { width: windowWidth } = useWindowSize();

// 响应式列配置
const columns = computed<ColumnProps[]>(() => {
  const baseColumns: ColumnProps[] = [
    { prop: "name", label: "名称", width: 200 },
    { prop: "status", label: "状态", width: 120 },
    { prop: "priority", label: "优先级", width: 100 },
    { prop: "assignee", label: "负责人", width: 120 },
    { prop: "createTime", label: "创建时间", width: 180 },
    { prop: "updateTime", label: "更新时间", width: 180 },
    { prop: "action", label: "操作", width: 200, fixed: "right" }
  ];

  // 小屏幕隐藏次要列
  if (windowWidth.value < 1024) {
    return baseColumns.filter(col =>
      ["name", "status", "action"].includes(col.prop)
    );
  }

  // 中等屏幕显示主要列
  if (windowWidth.value < 1440) {
    return baseColumns.filter(col =>
      !["updateTime", "assignee"].includes(col.prop)
    );
  }

  return baseColumns;
});
```

**响应式断点建议**：

| 断点 | 宽度 | 显示列数 | 隐藏列 |
|------|------|----------|--------|
| 大屏 | >= 1440px | 全部 | 无 |
| 中屏 | 1024px - 1439px | 5-6 列 | 次要信息列（更新时间、备注等） |
| 小屏 | < 1024px | 3-4 列 | 仅保留核心列（名称、状态、操作） |

## URL 查询参数同步

将搜索条件和分页状态同步到 URL，支持分享链接和浏览器前进后退：

```typescript
import { useRoute, useRouter } from "vue-router";

const route = useRoute();
const router = useRouter();

// 从 URL 恢复搜索参数
const restoreSearchParams = (): Record<string, any> => {
  const query = route.query;
  const params: Record<string, any> = {};

  if (query.keyword) params.keyword = query.keyword;
  if (query.status) params.status = query.status;
  if (query.pageNum) params.pageNum = Number(query.pageNum);
  if (query.pageSize) params.pageSize = Number(query.pageSize);

  return params;
};

// 将搜索参数同步到 URL
const syncToUrl = (params: Record<string, any>) => {
  const query: Record<string, string> = {};

  if (params.keyword) query.keyword = params.keyword;
  if (params.status) query.status = params.status;
  if (params.pageNum && params.pageNum > 1) query.pageNum = String(params.pageNum);
  if (params.pageSize && params.pageSize !== 10) query.pageSize = String(params.pageSize);

  router.replace({ query });
};

// 搜索时同步 URL
const handleSearch = (params: any) => {
  syncToUrl(params);
  tableRef.value?.setSearchParams(params);
};

// 重置时清除 URL 参数
const handleReset = () => {
  router.replace({ query: {} });
  tableRef.value?.reload();
};

// 初始化时恢复参数
onMounted(() => {
  const savedParams = restoreSearchParams();
  if (Object.keys(savedParams).length > 0) {
    tableRef.value?.setSearchParams(savedParams);
  }
});
```

## 边界情况

### 数据加载边界

| 边界情况 | 处理方式 | 说明 |
|----------|----------|------|
| 首次加载数据为空 | 显示 `el-empty` + 引导操作 | 区分"初始无数据"和"搜索无结果" |
| 搜索后数据为空 | 显示 `el-empty` + "未找到匹配结果" + 清空筛选按钮 | 给用户明确的反馈 |
| 请求超时 | 显示错误状态 + 重试按钮 | 不替换已有数据 |
| 分页超出范围 | 自动重置到最后一页 | 防止删除最后一页最后一条后的空页 |
| 快速切换页码 | 使用请求去重，仅保留最新请求 | 防止数据错乱 |
| 同一页面多次请求 | `AxiosCanceler` 自动取消前一次请求 | 防止竞态条件 |
| 数据量极大（> 10000） | 启用虚拟滚动 + 限制导出数量 | 防止浏览器卡死 |

### 选择操作边界

| 边界情况 | 处理方式 |
|----------|----------|
| 跨页选择 | 记录已选 ID，切换页码时保留选择状态（或清空并提示用户） |
| 全选后取消单项 | 更新全选状态，正确计算已选数量 |
| 批量操作进行中 | 禁用操作按钮，防止重复提交 |
| 批量操作无权限 | 隐藏或禁用批量操作按钮（`v-auth` 指令） |
| 选择数量为 0 | 隐藏批量操作按钮，不显示"已选择 0 项" |

### 搜索与筛选边界

| 边界情况 | 处理方式 |
|----------|----------|
| 搜索条件为空 | 发送空 filter，显示全部数据 |
| 搜索条件全为默认值 | 不发送无效参数（空字符串不传） |
| 日期范围只选开始 | 结束日期默认为当天 |
| 多选筛选全不选 | 视为不筛选，不传该条件 |
| 输入框快速连续输入 | 添加防抖（300ms），避免频繁请求 |

## 反模式

### 不要这样做

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 直接使用 el-table | `<el-table :data="data">` 手动管理分页/搜索 | 使用 `<ProTable :columns="columns" :request="api" />` | 重复实现分页、搜索、选择逻辑 |
| 不处理空状态 | 数据为空时表格显示空白行 | 使用 ProTable 的 `#empty` 插槽 + `el-empty` | 用户困惑，以为加载失败 |
| 不处理加载状态 | 按钮点击后无反馈，数据加载中无提示 | 显示骨架屏（首次）+ 加载中提示（后续） | 用户以为无响应，重复点击 |
| 不处理错误状态 | 请求失败后表格空白，无任何提示 | 显示错误状态 + 错误信息 + 重试按钮 | 用户不知道发生了什么 |
| 在模板中硬编码文本 | `{{ "暂无数据" }}` | `{{ $t("common.noData") }}` | 国际化缺失 |
| 搜索参数不防抖 | `@input="handleSearch"` 每次输入都请求 | 添加 300ms 防抖，或使用 `@search` 事件 | 频繁请求，浪费后端资源 |
| 批量操作不确认 | 点击批量删除后直接执行 | 使用 `ElMessageBox.confirm` 二次确认 | 误操作无法恢复 |
| 批量操作无进度提示 | 删除 100 条时无进度反馈 | 使用 `ElLoading.service` 或进度条 | 用户不知道操作是否完成 |
| 手动刷新整个页面 | `location.reload()` | `tableRef.value?.refresh()` | 丢失所有状态，体验差 |
| 搜索后不重置页码 | 搜索后仍停留在第 3 页 | ProTable 自动重置到第一页 | 搜索后可能显示空页 |
| 删除后不刷新表格 | 删除成功后手动 `fetchTableData()` | `tableRef.value?.refresh()` | 使用 ProTable 统一刷新方法 |
