# Pattern: Upload

## 概述

Upload 是 YiVad 的通用文件上传组件，位于 `src/components/Upload/`。封装 ElUpload + 导入模板下载 + 上传进度 + 结果反馈，内置文件类型和大小校验。

**相关规范**：
- [列表页模式](../list-page/spec.md)
- [组件结构规范](../../架构/组件模式/规范.md)
- [API 规范](../../架构/api规范/规范.md)

## 核心组件

### Upload

**Props**：

| Prop | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `action` | `string` | 是 | — | 上传接口地址 |
| `template` | `string` | 否 | — | 导入模板文件路径，传入后显示"下载模板"链接 |
| `accept` | `string` | 否 | `'.xlsx,.xls,.csv'` | 接受的文件类型 |
| `maxSize` | `number` | 否 | `10` | 文件大小限制（MB） |
| `limit` | `number` | 否 | `1` | 单次上传数量限制 |
| `headers` | `Record<string, string>` | 否 | `{}` | 请求头 |
| `data` | `Record<string, any>` | 否 | `{}` | 上传时附加的参数 |
| `showFileList` | `boolean` | 否 | `true` | 是否显示文件列表 |
| `drag` | `boolean` | 否 | `false` | 是否启用拖拽上传 |

**Events**：

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `success` | `(response: any, file: UploadFile)` | 上传成功回调 |
| `error` | `(error: Error, file: UploadFile)` | 上传失败回调 |
| `progress` | `(percentage: number, file: UploadFile)` | 上传进度回调 |
| `exceed` | `(files: File[])` | 超出数量限制回调 |
| `change` | `(file: UploadFile, fileList: UploadFile[])` | 文件状态变化 |

## 使用方式

### 基础用法

```vue
<template>
  <Upload
    action="/api/import"
    template="/templates/import-template.xlsx"
    @success="handleSuccess"
    @error="handleError"
  />
</template>

<script setup lang="ts">
import { ElMessage } from 'element-plus';
import Upload from '@/components/Upload/index.vue';

const handleSuccess = (response: any) => {
  ElMessage.success('导入成功');
};

const handleError = (error: Error) => {
  ElMessage.error('导入失败：' + error.message);
};
</script>
```

### 拖拽上传

```vue
<Upload
  action="/api/upload"
  :drag="true"
  :max-size="20"
  accept=".xlsx,.xls"
  @success="handleSuccess"
/>
```

### 带额外参数

```vue
<Upload
  action="/api/import"
  :data="{ category: 'product', source: 'web' }"
  :headers="{ Authorization: `Bearer ${token}` }"
  @success="handleSuccess"
/>
```

## 文件校验

Upload 内置 `beforeUpload` 钩子，自动校验文件类型和大小：

```typescript
// 组件内部校验逻辑
const beforeUpload = (file: File) => {
  // 1. 类型校验
  const ext = file.name.split('.').pop()?.toLowerCase()
  const allowedExts = props.accept.split(',').map(e => e.trim().replace('.', ''))
  if (!allowedExts.includes(ext || '')) {
    ElMessage.error(`仅支持 ${props.accept} 格式文件`)
    return false
  }
  // 2. 大小校验
  if (file.size > props.maxSize * 1024 * 1024) {
    ElMessage.error(`文件大小不能超过 ${props.maxSize}MB`)
    return false
  }
  return true
}
```

| 校验项 | 触发时机 | 错误提示 |
|--------|----------|----------|
| 文件类型 | 选择文件时 | `仅支持 .xlsx,.xls,.csv 格式文件` |
| 文件大小 | 选择文件时 | `文件大小不能超过 10MB` |
| 数量限制 | 超过 limit 时 | ElUpload 内置提示 |

## 模板下载

当 `template` prop 传入时，Upload 组件上方显示"下载导入模板"按钮：

```typescript
const downloadTemplate = () => {
  if (!props.template) return
  const a = document.createElement('a')
  a.href = props.template
  a.download = props.template.split('/').pop() || 'template.xlsx'
  a.click()
}
```

模板文件推荐放置在 `/public/templates/` 目录下，`template` prop 传入相对路径即可：

```vue
<Upload
  action="/api/import"
  template="/templates/import-template.xlsx"
/>
```

## 上传流程

```
选择文件 → beforeUpload 校验 → 上传到服务器 → 服务器返回结果
  ├─ 校验失败 → 阻止上传，ElMessage 提示
  ├─ 上传成功 → @success 事件 → 刷新列表/展示结果
  └─ 上传失败 → @error 事件 → 显示错误信息
```

## 反模式

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 手动写上传逻辑 | 页面中写 `<el-upload>` + 自定义校验 | 使用 `Upload` 组件，传入 `action`/`template` | 模板下载、校验逻辑重复 |
| 不校验文件类型 | 接受任意文件上传 | 设置 `accept` prop | 后端可能收到不支持的文件格式 |
| 不限制文件大小 | 允许上传大文件 | 设置 `maxSize` prop | 大文件上传可能超时，浪费带宽 |
| 模板下载链接触发页面跳转 | `window.open(template)` | 使用 `<a>` 标签 download 属性 | `window.open` 可能被浏览器拦截 |
| 上传后不刷新列表 | 上传成功后无后续操作 | 在 `@success` 中调用 `tableRef.refresh()` | 用户看不到最新数据 |
