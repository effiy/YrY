# Pattern: SearchForm

## 概述

SearchForm 是 YiVad 的通用搜索表单组件，位于 `src/components/SearchForm/`。封装 ElForm + 搜索/重置按钮，支持折叠模式（超过 n 个字段时折叠多余字段），通过配置式 `fields` 数组驱动渲染。

## 核心组件

### SearchForm

**Props**：

| Prop | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `fields` | `SearchField[]` | 是 | — | 搜索字段配置 |
| `modelValue` | `Record<string, any>` | 否 | `{}` | 表单值（v-model） |
| `collapsed` | `boolean` | 否 | `true` | 是否折叠多余字段 |
| `collapseCount` | `number` | 否 | `3` | 折叠时显示的字段数 |
| `labelWidth` | `string` | 否 | `'80px'` | 标签宽度 |
| `showSearch` | `boolean` | 否 | `true` | 是否显示搜索按钮 |
| `showReset` | `boolean` | 否 | `true` | 是否显示重置按钮 |

### SearchField

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | `'input' \| 'select' \| 'date' \| 'date-range' \| 'select-v2' \| 'cascader'` | 是 | 字段类型 |
| `label` | `string` | 是 | 标签文字 |
| `key` | `string` | 是 | 字段键名，对应 modelValue 的 key |
| `placeholder` | `string` | 否 | 占位文字 |
| `options` | `{label: string, value: any}[]` | 否 | select/select-v2/cascader 的下拉选项 |
| `props` | `Record<string, any>` | 否 | 透传给对应 El 组件的额外属性 |
| `clearable` | `boolean` | 否 | 是否可清空，默认 `true` |

**Events**：

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `search` | `(formData: Record<string, any>)` | 点击搜索按钮 |
| `reset` | — | 点击重置按钮 |
| `update:modelValue` | `(formData: Record<string, any>)` | v-model 更新 |

## 使用方式

### 独立使用

```vue
<template>
  <SearchForm
    v-model="searchData"
    :fields="searchFields"
    @search="handleSearch"
    @reset="handleReset"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue';
import SearchForm from '@/components/SearchForm/index.vue';
import type { SearchField } from '@/components/SearchForm/types';

const searchData = ref<Record<string, any>>({});

const searchFields: SearchField[] = [
  { type: 'input', key: 'name', label: '名称', placeholder: '请输入名称' },
  { type: 'select', key: 'status', label: '状态', options: [
    { label: '启用', value: 'active' },
    { label: '禁用', value: 'inactive' },
  ]},
  { type: 'date-range', key: 'dateRange', label: '日期范围' },
];

const handleSearch = (formData: Record<string, any>) => {
  // 调用 API 搜索
  fetchData(formData);
};

const handleReset = () => {
  // 清空搜索条件，加载全部数据
  fetchData({});
};
</script>
```

### 嵌入 ProTable

ProTable 内置 SearchForm，通过 `searchForm` prop 配置即可，无需手动引入 SearchForm 组件：

```vue
<template>
  <ProTable
    :columns="columns"
    :request="fetchData"
    :search-form="searchFields"
  />
</template>
```

## 折叠模式

字段数超过 `collapseCount`（默认 3）时，自动折叠多余字段，显示"展开"按钮：

```vue
<SearchForm
  :fields="searchFields"
  :collapsed="true"
  :collapse-count="3"
/>
```

| 行为 | 说明 |
|------|------|
| 字段 ≤ 3 | 全部显示，不显示展开/收起按钮 |
| 字段 > 3 | 折叠时仅显示前 3 个字段 + "展开"按钮 |
| 点击展开 | 显示全部字段，按钮变为"收起" |
| 点击收起 | 恢复折叠状态 |

## 完整字段类型示例

```typescript
const searchFields: SearchField[] = [
  // 文本输入
  { type: 'input', key: 'keyword', label: '关键词', placeholder: '请输入' },

  // 下拉选择（ElSelect）
  {
    type: 'select',
    key: 'status',
    label: '状态',
    options: [
      { label: '全部', value: '' },
      { label: '启用', value: 'active' },
      { label: '禁用', value: 'inactive' },
    ],
  },

  // 虚拟滚动下拉（ElSelectV2，适用于大量选项）
  {
    type: 'select-v2',
    key: 'category',
    label: '分类',
    options: categoryOptions,  // 大量选项时使用
  },

  // 日期选择
  { type: 'date', key: 'date', label: '日期', placeholder: '选择日期' },

  // 日期范围
  {
    type: 'date-range',
    key: 'dateRange',
    label: '日期范围',
  },

  // 级联选择
  {
    type: 'cascader',
    key: 'region',
    label: '地区',
    options: regionTree,
  },
];
```

## 搜索流程

1. 用户输入搜索条件
2. 点击"搜索"按钮，触发 `@search` 事件，参数为当前表单数据
3. 调用方接收表单数据，发起 API 请求
4. 点击"重置"按钮，清空所有字段，触发 `@reset` 事件

## 反模式

| 反模式 | 错误示例 | 正确做法 | 原因 |
|--------|----------|----------|------|
| 手动拼接搜索表单 | 页面中写 `<el-form>` + 多个 `<el-form-item>` | 使用 `SearchForm` + `fields` 配置 | 重复代码，搜索/重置逻辑需手动实现 |
| 搜索不重置页码 | 搜索后停留在第 3 页 | ProTable 内置 SearchForm 自动重置到第一页 | 搜索结果可能只有 1 页，显示空页 |
| 字段 key 与后端不一致 | `{ key: 'query' }` | `{ key: 'filter' }`（遵守 RPC 参数名契约） | 后端忽略不匹配的参数名 |
| 下拉选项硬编码 | 在模板中写死 `<el-option>` | 通过 `options` 配置传入，支持字典/接口动态获取 | 选项变更需要改代码 |
