# 动态路由初始化中的 ElNotification 硬编码英文字符串

## 现象

`src/routers/modules/dynamicRouter.ts` 的 `initDynamicRouter` 函数中使用硬编码英文字符串调用 `ElNotification`，而非通过 `$t()` 国际化：

```typescript
ElNotification({
  title: "No Permission",
  message: "This account has no menu permissions. Please contact the system administrator!",
  type: "warning",
  duration: 3000
});
```

## 根因分析

- 路由初始化在 Vue 应用挂载前执行，可能无法访问 i18n 实例
- 开发者为了方便直接写了英文字符串
- 与 bug #24（system 视图硬编码中文）和 #25（hooks 硬编码字符串）属于同一模式的不同模块

## 涉及文件

- `src/routers/modules/dynamicRouter.ts:27-32` — 权限不足通知
- `src/routers/modules/dynamicRouter.ts:56-60` — 菜单加载失败处理（无通知但静默重定向）

## 修复方案

1. 从 `@/languages` 导入 i18n 实例使用 `i18n.global.t()`
2. 或在 `ElNotification` 中使用已注册的 i18n 消息键
3. router 层面的通知也应有中/英文支持

## 预防措施

- 全局搜索 `ElNotification`、`ElMessage` 调用确保无硬编码字符串

## 影响范围

- **影响组件/页面**：详见描述章节
- **影响用户**：所有用户
- **是否影响 API 契约**：否
- **是否影响其他前端项目**：否（仅 YiVad）
