# 菜单和面包屑多语言支持

## 现象

YiVad 侧边栏菜单、面包屑导航、标签页标题、菜单搜索弹窗中的标题均为后端 MongoDB 存储的硬编码字符串（中文为主）。切换语言为英文后，这些位置仍然显示中文，只有页面内容区的 i18n 正常工作。

## 根因分析

- 菜单数据源是 MongoDB `menus` 集合，`meta.title` 为单一语言字符串
- 7 个渲染位置直接使用 `meta.title` 或 `title`，未经过 vue-i18n 翻译：
  - `SubMenu.vue` — 侧边栏菜单（3 处）
  - `Breadcrumb.vue` — 面包屑（含硬编码 `"Home"`）
  - `LayoutTransverse/index.vue` — 横向布局菜单（2 处）
  - `LayoutColumns/index.vue` — 分栏布局菜单
  - `SearchMenu.vue` — 菜单搜索弹窗
  - `Tabs/index.vue` — 标签页标题（2 处）

## 修复方案

**Route name 驱动的 i18n 查找 + 回退机制**：

1. 使用路由 `name`（稳定标识符）作为 i18n key：`menu.{routeName}`
2. 创建 `useMenuI18n` composable：`te('menu.' + name)` 存在时返回翻译，否则回退到原始 `meta.title`
3. 在 `common/zh.ts` 和 `common/en.ts` 中添加 `menu` 翻译段
4. 全部 7 个渲染位置统一调用 `translateTitle(name, fallback)` 替换直接引用

**优势**：
- 无需后端或数据库变更
- 自定义动态菜单无 i18n key 时自动回退，不受影响
- 利用现有 vue-i18n 响应式系统，切换语言即时生效
