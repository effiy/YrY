# 缺少 .npmrc 统一包管理器配置

## 现象

YiVad 使用 pnpm 但无 `.npmrc` 强制包管理器版本或设置 `shamefully-hoist`。如果团队成员用 npm/yarn 安装，lockfile 会冲突。

## 涉及文件

- 缺少 `YiVad/.npmrc`

## 修复方案

```ini
engine-strict=true
package-manager-strict-version=true
```

## 预防措施

所有 Node 项目应有 `.npmrc` 或 `package.json` 的 `packageManager` 字段。

## 影响范围

- **影响组件/页面**：详见描述章节
- **影响用户**：所有用户
- **是否影响 API 契约**：否
- **是否影响其他前端项目**：否（仅 YiVad）

## 经验教训

- **`.npmrc` 是团队协作的守护配置**：`engine-strict=true` 阻止使用错误的 Node 版本，`package-manager-strict-version=true` 防止 npm/yarn 用户意外修改 lockfile。缺少 `.npmrc` 的代价是「一切正常直到某个成员用不同工具安装了依赖」
