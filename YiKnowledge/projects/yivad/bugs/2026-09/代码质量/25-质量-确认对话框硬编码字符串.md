# OkrRecommendPanel 删除确认对话框使用硬编码中文

## 现象

`OkrRecommendPanel.vue` 的删除确认对话框使用硬编码中文字符串，而项目中英文语言包已完整：

```typescript
// components/OkrRecommend/OkrRecommendPanel.vue:731
await ElMessageBox.confirm("确认删除该条目？", "删除确认", {
  confirmButtonText: "删除", cancelButtonText: "取消", type: "warning"
});
```

其他几处也存在确认对话框混用中英文的问题：

| 文件 | 语言 |
|------|------|
| `OkrRecommendPanel.vue:731` | 中文 |
| `bug/index.vue:672` | 英文 `Delete ${ids.length} selected bugs?` |
| `module/detail.vue:518` | 英文 `Delete module "${mod.value.name}"?` |
| `MessageActions.vue:41` | 英文 `Delete this message?` |
| `Avatar.vue:41` | 英文 `Are you sure you want to log out?` |

## 根因分析

- 与 bug #24、#25、#33 同模式——i18n 未统一覆盖所有用户可见字符串
- 确认对话框的文案在开发时临时写入，后续未提取到语言包
- 中英文混用说明缺乏统一的 i18n 审查流程

## 涉及文件

- `components/OkrRecommend/OkrRecommendPanel.vue:731` — 中文删除确认
- `views/bug/index.vue:672` — 英文批量删除
- `views/module/detail.vue:518, index.vue:619` — 英文模块删除
- `views/aiChat/components/MessageBubble/MessageActions.vue:41` — 英文消息删除
- `layouts/components/Header/components/Avatar.vue:41` — 英文注销确认

## 修复方案

1. 将所有 `ElMessageBox.confirm` 的文案提取到 `@/languages` 语言包
2. 使用 `$t('confirm.delete', { name: '...' })` 模式
3. 添加 `confirmButtonText` 和 `cancelButtonText` 的 i18n 键

## 预防措施

- 禁止在 `ElMessageBox` 中使用字面量字符串

## 影响范围

- **影响组件/页面**：详见描述章节
- **影响用户**：所有用户
- **是否影响 API 契约**：否
- **是否影响其他前端项目**：否（仅 YiVad）
