# system 模块视图存在硬编码中文字符串未使用 i18n

## 现象

`YiVad/src/views/system/` 目录下的角色管理、用户管理、菜单管理视图中，存在多处硬编码的中文字符串，未使用 `$t()` 或 `useI18n()` 进行国际化处理。这导致：

- 切换到英文界面时，这些文案仍显示为中文
- 与项目其他模块的 i18n 实践不一致

## 根因分析

这些视图是较早开发的管理后台功能，当时可能未强制要求 i18n。项目大部分模块已使用 i18n（如 `kanban/index.vue` 使用 `t("kanban.createDialog.createSuccess")`），但 system 模块未跟进。

## 修复方案

1. 在 `src/languages/zh-CN.ts` 和 `src/languages/en-US.ts` 中添加 system 模块的 i18n key
2. 将所有硬编码字符串替换为 `t("system.roleManage.createSuccess")` 等 i18n 调用
3. 使用 `useI18n()` 获取 `t` 函数，在模板中使用 `$t()`

## 预防措施

- ESLint 规则配置：禁止在 Vue 模板中使用中文字符串字面量
- 代码审查时检查新增文案是否使用 i18n
