# 核心代码

## 入口文件

### src/main.ts
应用入口，按顺序初始化：创建 Vue 应用实例 → 注册 Pinia → 注册 Vue Router → 注册 Element Plus → 注册自定义指令 → 注册全局组件 → 注册 i18n → 挂载应用

## 核心模块

### src/api/index.ts — RequestHttp
封装 Axios 实例，统一处理请求/响应拦截。JWT Token 自动附加。请求取消管理 (`CancelToken`)。全屏 Loading 控制。错误状态码映射 (401 → 登录页, 403 → 无权限, 500 → 服务器错误)。

### src/stores/modules/aiChat.ts — AI 聊天状态
管理对话历史和流式响应。支持三种模式：普通聊天 (SSE 流式)、Agent 模式 (工具调用/确认/steer/follow-up)、RAG 聊天 (检索增强)。消息持久化到后端。自动转发到 WeCom。断连检测和重连。

### src/stores/modules/user.ts — 用户状态
用户信息管理。Token 存储 (localStorage + Pinia persist)。登录/登出逻辑。角色和权限信息缓存。

### src/stores/modules/auth.ts — 权限状态
菜单树管理。按钮权限列表。动态路由生成 (`generateIndexRouter`)。菜单展开/折叠状态持久化。

### src/routers/beforeEach.ts — 路由守卫
权限验证。动态路由加载 (首次进入时从 API 获取菜单)。登录状态检查和重定向。NProgress 进度条控制。

### src/hooks/useMarkdown.ts — Markdown 渲染
使用 marked 库解析 Markdown。支持代码高亮 (highlight.js)、表格、任务列表、Mermaid 图表嵌入。XSS 防护 (DOMPurify)。

### src/utils/continuation.ts — 连续性判断
判断用户消息是否为继续指令 (如 "继续"/"go on"/"continue")。与后端 Agent 的连续性语义一致，用于 Agent 模式下的 follow-up 消息排队。

### src/utils/confirmationAnswer.ts — 确认答案解析
从聊天消息中解析确认/拒绝意图。支持中文 (确认/好的/可以/行/拒绝/取消/不行) 和英文 (yes/ok/sure/confirm/no/cancel/reject) 关键词。用于 Agent 工具调用确认门控。

### SSE 流式解析模式
```ts
const response = await fetch(url, { body: rpcEnvelope })
const reader = response.body.getReader()
const decoder = new TextDecoder()
while (true) {
  const { done, value } = await reader.read()
  if (done) break
  // 解析 text/event-stream: data: {...}\n\n
  for (const line of decoder.decode(value).split('\n\n')) {
    if (line.startsWith('data: ')) onChunk(JSON.parse(line.slice(6)))
  }
}
```
