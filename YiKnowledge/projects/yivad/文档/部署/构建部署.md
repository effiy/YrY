# 构建部署

## 构建命令

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 启动开发服务器 (端口 8848) |
| `pnpm build:dev` | 开发环境构建 |
| `pnpm build:test` | 测试环境构建 |
| `pnpm build:pro` | 生产环境构建 |
| `pnpm preview` | 构建并预览 |
| `pnpm type:check` | TypeScript 类型检查 (`vue-tsc --noEmit`) |

## Rsbuild 配置

`rsbuild.config.ts` 关键配置：

### 插件
- `@rsbuild/plugin-vue` — Vue 3 SFC 编译
- `@rsbuild/plugin-vue-jsx` — JSX/TSX 支持
- `@rsbuild/plugin-sass` — SCSS 预处理 (全局注入 `var.scss`)
- `@rsbuild/plugin-babel` — Babel 转译
- `unplugin-auto-import` — 自动导入 (Vue, Router, Pinia, Element Plus)
- `unplugin-vue-components` — 组件自动注册 (Element Plus resolvers)

### 自定义插件
- `svgSpritePlugin` — SVG 雪碧图生成，自动收集 `src/assets/icons/` 下所有 SVG
- `viewsGlobPlugin` — 视图文件 glob 导入，自动注册页面组件

### 输出配置
- 输出目录: `dist/`
- JS 分块: `assets/js/[name]-[hash].js`
- CSS 分块: `assets/css/[name]-[hash].css`
- 生产环境启用压缩 (esbuild + cssnano)，关闭 SourceMap
- 静态资源: `assets/[name]-[hash].[ext]`

### 代理配置
通过 `RSBUILD_ENV_PROXY` 环境变量配置 JSON 代理规则，用于开发环境跨域：
```json
[["/api", "http://localhost:10086"]]
```

## 部署流程

```bash
# 1. 类型检查
pnpm type:check

# 2. 构建
pnpm build:pro

# 3. 部署 dist/ 目录到静态服务器 (Nginx/CDN)
# 确保配置正确的 PUBLIC_PATH (如 /admin/)

# 4. 健康检查
curl http://your-server/your-path/index.html
```

## Nginx 配置示例

```nginx
location /admin {
    root /var/www;
    index index.html;
    try_files $uri $uri/ /admin/index.html;
}
```

## 构建优化

| 优化 | 说明 |
|------|------|
| Tree Shaking | ES module 输出，自动消除未使用代码 |
| 代码分割 | 路由级懒加载，按视图拆分 chunk |
| CSS 提取 | 生产环境提取为独立 CSS 文件 |
| Gzip | Nginx 层开启 `gzip_static on` |
| 缓存策略 | JS/CSS 文件名带 content hash |
