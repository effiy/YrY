# 快速开始

## 环境要求

- **Node.js** >= 16.18.0
- **pnpm** >= 8 (推荐包管理器)
- **YiAi 后端** 必须运行在 `http://localhost:10086`

## 安装与启动

```bash
# 1. 安装依赖
cd YiVad
pnpm install

# 2. 启动开发服务器
pnpm dev

# 3. 访问
# 浏览器打开 http://localhost:8848
```

## 环境变量

YiVad 使用 `RSBUILD_*` 前缀的环境变量（Rsbuild 约定）：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `RSBUILD_API_BASE` | 后端 API 地址 | `http://localhost:10086` |
| `RSBUILD_PORT` | 开发服务器端口 | `8848` |
| `RSBUILD_PUBLIC_PATH` | 部署路径 | `/` |
| `RSBUILD_GLOB_APP_TITLE` | 应用标题 | `YiVad` |
| `RSBUILD_OPEN` | 启动时自动打开浏览器 | `false` |
| `RSBUILD_PROXY` | 代理配置 (JSON) | `[]` |

## 完整栈启动

```bash
# 1. 启动 YiAi 后端 (终端 1)
cd YiAi && python main.py

# 2. 启动 YiVad 前端 (终端 2)
cd YiVad && pnpm dev

# 3. 构建并加载 YiPet 扩展 (终端 3)
cd YiPet && npm run build
# 然后在 Chrome 中加载 dist/ 为未打包扩展
```

## 可用命令

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 启动开发服务器 (HMR 热更新) |
| `pnpm build:dev` | 开发环境构建 |
| `pnpm build:test` | 测试环境构建 |
| `pnpm build:pro` | 生产环境构建 |
| `pnpm preview` | 构建并预览生产产物 |
| `pnpm type:check` | TypeScript 类型检查 |
| `pnpm lint` | ESLint 代码检查 |
| `pnpm lint:style` | Stylelint 样式检查 |
