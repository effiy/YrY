# 权限管理

## 权限体系

YiVad 的权限管理分为三个层级，从粗到细逐级控制：

### 1. 路由级权限

动态路由从后端菜单 API 加载，根据用户角色返回不同的菜单树。路由守卫在每次导航时验证权限，未授权路由不会注册到 Vue Router。

```
用户登录 → GetUserMenus API → 菜单树 (含角色过滤)
  → generateIndexRouter() → router.addRoutes()
  → 只有授权路由可见/可访问
```

### 2. 按钮级权限 (`v-auth` 指令)

```vue
<template>
  <!-- 只有拥有 delete 权限的用户才能看到此按钮 -->
  <el-button v-auth="'delete'">删除</el-button>

  <!-- 多个权限满足其一即可 -->
  <el-button v-auth="['admin', 'super']">管理</el-button>
</template>
```

权限值从后端菜单 API 的 `buttons` 字段获取，存储在 `useAuthStore` 中。指令通过 `hasPermission` 函数检查当前用户权限列表是否包含目标权限。

### 3. 接口级权限

后端 RPC 层根据 `X-Token` 中的角色信息限制数据访问范围。前端不做数据过滤，所有权限控制以后端为准。

## 权限数据流

```
GetUserMenus API
  → { menus: [...], buttons: ['add','edit','delete',...], roles: [...] }
  → authStore.setMenus(menus) + authStore.setButtons(buttons)
  → router.generateRoutes(menus) → 动态路由注册
  → v-auth 指令读取 authStore.buttons → 显示/隐藏按钮
```

## 自定义指令系统

| 指令 | 用途 | 文件 |
|------|------|------|
| `v-auth` | 按钮权限控制 | `directives/modules/auth.ts` |
| `v-copy` | 一键复制文本 | `directives/modules/copy.ts` |
| `v-waterMarker` | 页面水印 | `directives/modules/waterMarker.ts` |
| `v-draggable` | 元素拖拽 | `directives/modules/draggable.ts` |

| `v-throttle` | 事件节流 | `directives/modules/throttle.ts` |
| `v-longpress` | 长按事件 | `directives/modules/longpress.ts` |

## 权限使用规范

- 所有按钮权限必须通过 `v-auth` 指令检查，**禁止**使用内联 `v-if` 基于权限判断
- 权限值从后端菜单 API 的 `buttons` 字段获取，前端不做硬编码
- 指令注册在 `directives/index.ts` 的 `install` 方法中
- 路由守卫在 `routers/beforeEach.ts` 中统一处理权限验证和登录重定向
- Token 过期时 (401) 自动清除 user/auth stores 并重定向到登录页
