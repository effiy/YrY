# 组件分析

## 核心组件

### ProTable (标准表格)

最核心的表格组件，封装了分页、搜索、排序、选择、导出等功能。所有列表页面都应使用 ProTable，禁止直接使用 `el-table`。

| 特性 | 说明 |
|------|------|
| 分页 | 自动处理 `page`/`pageSize`，通过 `request` 回调驱动 |
| 搜索 | 内置 `SearchForm` 集成，通过 `searchForm` prop 配置，自动重置页码 |
| 排序 | 列头点击排序，`sort` 参数透传 |
| 选择 | 行选择 + 全选，支持跨页保持（`rowKey` + `reserve-selection`） |
| 工具栏 | `toolbar`/`toolbar-left`/`toolbar-right` 插槽，支持批量操作 |
| 状态 | 内置 loading/empty/error 状态，支持自定义 `#empty` 插槽 |
| 导出 | 当前页/全部数据导出为 Excel |

**核心 Props**：`columns`、`request`、`searchForm`、`selection`、`rowKey`、`tableProps`
**核心 Events**：`selection-change`、`row-click`、`sort-change`
**核心 Slots**：`toolbar`、`toolbar-left`、`toolbar-right`、`column-{prop}`、`empty`
**Expose 方法**：`refresh()`、`reload()`、`clearSelection()`、`getSelection()`、`setSearchParams()`

> 详细 API 参考 [列表页模式规范](../../specs/模式/列表页/规范.md)

### AiChatBox (AI 聊天框)

AI 聊天界面组件，支持多种模式：

| 模式 | 说明 |
|------|------|
| 普通聊天 | 多轮对话，SSE 流式传输 |
| Agent 模式 | 多轮工具调用循环，确认门控，模型切换 |
| 知识库聊天 | 基于知识文件的上下文聊天 |
| RAG 聊天 | 基于检索增强生成的问答 |

子组件：`ChatInput` (输入框 + Agent 控制) / `MessageList` (消息列表 + 确认横幅) / `MessageBubble` (消息气泡 + 工具时间线) / `AgentTimeline` (Agent 工具调用时间线) / `AgentEventsPanel` (Agent 事件面板) / `ConversationSidebar` (会话侧边栏) / `KnowledgeChatPanel` (知识聊天面板)

### ECharts (图表封装)

对 ECharts 6 的 Vue 3 封装，支持响应式图表渲染和主题切换。自动处理 resize、主题变量注入、暗黑模式。

### EntityBreadcrumb (实体面包屑)

可复用的面包屑导航组件，显示实体层级关系 (Project → Cycle → Release → 当前)。支持懒加载父级名称，带实体类型图标。

### KnowledgePreviewDialog (知识预览)

知识库文件的预览弹窗，支持 Markdown 渲染和 YAML frontmatter 展示。`KnowledgeMetaStrip` 子组件渲染 frontmatter 元数据 (status/lifecycle/tags/roles/related)。

### SearchForm (搜索表单)

通用搜索表单组件，封装 ElForm + 搜索/重置按钮，通过配置式 `fields` 数组驱动渲染。

| 特性 | 说明 |
|------|------|
| 字段类型 | 支持 `input`/`select`/`select-v2`/`date`/`date-range`/`cascader` 六种类型 |
| 折叠模式 | 超过 3 个字段时自动折叠，可展开/收起 |
| v-model | 支持双向绑定表单值 |
| 内置按钮 | 搜索/重置按钮，可通过 `showSearch`/`showReset` 控制显隐 |
| 透传属性 | 通过 `props` 字段透传任意属性给底层 El 组件 |

**核心 Props**：`fields`、`modelValue`、`collapsed`、`collapseCount`、`labelWidth`
**核心 Events**：`search`、`reset`、`update:modelValue`

> 详细 API 参考 [SearchForm 模式规范](../../specs/模式/搜索表单/规范.md)

### Upload (文件上传)

通用文件上传组件，封装 ElUpload + 导入模板下载 + 上传进度 + 结果反馈。

| 特性 | 说明 |
|------|------|
| 文件校验 | 内置文件类型 + 大小校验（`accept`/`maxSize`） |
| 模板下载 | 通过 `template` prop 显示"下载导入模板"按钮 |
| 拖拽上传 | 通过 `drag` prop 启用拖拽区域 |
| 上传进度 | `@progress` 事件回调上传百分比 |
| 请求头/参数 | 支持自定义 `headers` 和 `data` |

**核心 Props**：`action`、`template`、`accept`、`maxSize`、`limit`、`drag`
**核心 Events**：`success`、`error`、`progress`、`exceed`

> 详细 API 参考 [Upload 模式规范](../../specs/模式/上传/规范.md)

## 组件注册

所有组件通过 `src/components/index.ts` 统一注册，支持按需导入和全局注册两种方式。全局注册的组件在 `main.ts` 中通过 `app.use(Components)` 安装。
