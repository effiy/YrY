<a id="sec-1"></a>
## 一、方案概述

增强面包屑组件：支持动态标题（从 API 获取）、路径点击跳转、与标签页同步。

### 面包屑生成

```typescript
// 从 route.matched 生成
const breadcrumbs = computed(() =>
  route.matched
    .filter(r => r.meta?.title)
    .map((r, i, arr) => ({
      title: r.meta.title,
      path: i < arr.length - 1 ? r.path : undefined, // 最后一级不可点击
    }))
);
```

### 关键改进

| 改进 | 说明 |
|------|------|
| 动态标题 | `route.meta.title` 在守卫中通过 API 设置（如会话名） |
| 路径点击 | 非最后一级可点击跳转 |
| 标签页同步 | 标签页标题与面包屑最后一级一致 |

### 实施步骤

| 步骤 | 内容 | 人天 |
|------|------|------|
| 1 | 面包屑动态生成 + 点击跳转 | 0.25 |
| 2 | 守卫中动态设置 meta.title | 0.25 |

**合计：0.5d**
