<a id="sec-1"></a>
## 一、方案概述

项目所有者可将项目移交给其他成员，移交后原所有者降为成员。

### 流程

```
1. 项目设置 → 「移交项目」
2. 选择新所有者（项目成员）
3. 输入确认文本
4. 新所有者接受 → 完成移交
```

> 低优先级。
