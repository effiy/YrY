<a id="sec-1"></a>
## 一、方案概述

用户可查看登录历史：时间/IP/设备/状态（成功/失败）。

### 日志字段

| 字段 | 说明 |
|------|------|
| 时间 | 登录时间 |
| IP | 登录 IP |
| 设备 | UserAgent 解析 |
| 状态 | 成功 / 失败（密码错误/锁定等） |
| 位置 | IP 地理位置（可选） |

> 数据由 YiAi 认证服务记录。
