<a id="sec-1"></a>
## 一、方案概述

将一个项目拆分为多个子项目：选择 Issue/模块分配到不同目标项目。

### 拆分流程

```
1. 选择源项目
2. 创建目标项目（可多个）
3. 分配 Issue/模块到各目标项目
4. 确认拆分 → 执行迁移
5. 源项目归档
```

> 低优先级。
