<a id="sec-1"></a>
## 一、方案概述

迭代/Sprint 结束后的团队复盘工具：What went well / What didn't / Action items，数据持久化到 MongoDB。

### 复盘模板

```markdown
## 回顾：{迭代名称} · {日期范围}

### 👍 What went well
- 

### 👎 What didn't go well
- 

### 💡 Action items
- [ ] 
```

### 功能

| 功能 | 说明 |
|------|------|
| 创建复盘 | 选择项目 + 迭代 + 模板填充 |
| 协作编辑 | 团队成员可共同编辑 |
| 历史查看 | 按迭代/时间查看过往复盘 |
| Action 追踪 | 将 Action items 转为 Issue 跟踪 |

> 当前阶段：低优先级。
