<a id="sec-1"></a>
## 一、方案概述

增强知识库管理界面：批量操作（移动/删除/标签）、知识生命周期状态可视化、健康检查面板。

### 批量操作

| 操作 | 说明 |
|------|------|
| 批量移动 | 转移文件到其他角色目录 |
| 批量标签 | 添加/移除标签 |
| 批量删除 | 确认后删除，支持撤销 |
| 批量导出 | 导出为 Markdown 压缩包 |

### 健康面板

| 指标 | 阈值 |
|------|------|
| 缺 frontmatter 文件 | 0 |
| stale 文件 (>90 天未更新) | < 10% |
| 命名不规范 | 0 |

### 实施步骤：0.5d

- 批量操作工具栏 + 健康面板
