<a id="sec-1"></a>
## 一、方案概述

用户可申请删除账号（GDPR 合规）：确认→冷静期→执行删除。

### 流程

```
1. 用户在安全设置中点击「删除账号」
2. 输入密码确认 + 阅读删除后果
3. 进入 7 天冷静期（可取消）
4. 7 天后自动执行：匿名化内容 → 清除个人信息 → 不可恢复
```

> 实施步骤：0.25d — 删除确认页面 + 状态展示
