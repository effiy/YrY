<a id="sec-1"></a>
## 一、方案概述

TOTP 两步验证：扫码绑定 → 验证码确认 → 启用/禁用。

### 流程

```
1. 用户进入安全设置
2. 点击「启用两步验证」
3. 扫码绑定（二维码 + 手动密钥）
4. 输入 6 位验证码确认
5. 保存恢复码（一次性展示）
```

> 依赖 YiAi 后端 TOTP 服务。
