## 一、方案概述

第三方集成市场，提供常用工具的连接器：GitHub/GitLab/Jira/Slack/企业微信/飞书。

### 集成类型

| 集成 | 功能 |
|------|------|
| GitHub | Issue PR 关联、Commit 引用 |
| Jira | Issue 双向同步 |
| Slack/企微/飞书 | 消息通知推送 |
| Webhook | 自定义事件回调 |

> 当前阶段：低优先级。
