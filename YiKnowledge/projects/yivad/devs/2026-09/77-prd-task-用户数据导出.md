## 一、方案概述

用户可导出个人数据（GDPR 合规）：个人信息/会话/创建内容，JSON/CSV 格式。

### 导出内容

| 数据 | 说明 |
|------|------|
| 个人信息 | 姓名/邮箱/部门/职位 |
| 会话记录 | AI 聊天历史 |
| 创建内容 | 创建的 Issue/Bug/文档 |
| 活动日志 | 操作记录 |

> 异步生成 + 邮件通知下载链接。
