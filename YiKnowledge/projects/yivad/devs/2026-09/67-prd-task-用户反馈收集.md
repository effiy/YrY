<a id="sec-1"></a>
## 一、方案概述

页面右下角反馈按钮，用户可提交 Bug/建议/好评，附带截图和页面上下文。

### 反馈类型

| 类型 | 必填字段 |
|------|---------|
| Bug 报告 | 标题、描述、截图（可选） |
| 功能建议 | 标题、描述 |
| 好评 | 评分（1-5）、评论（可选） |

### 自动采集上下文

| 字段 | 说明 |
|------|------|
| 当前页面 URL | 用户所在页面 |
| UserAgent | 浏览器信息 |
| 截图 | 当前页面截图（可选） |

> 低优先级。
