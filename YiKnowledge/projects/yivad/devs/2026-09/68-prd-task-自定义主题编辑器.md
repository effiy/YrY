<a id="sec-1"></a>
## 一、方案概述

可视化主题编辑器：自定义品牌色/背景色/字体/圆角等 CSS 变量。

### 可编辑变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| --brand-color | #409EFF | 品牌色 |
| --bg-color | #f5f7fa | 背景色 |
| --text-color | #303133 | 文字色 |
| --border-radius | 4px | 圆角 |
| --font-family | system-ui | 字体 |

> 低优先级。
