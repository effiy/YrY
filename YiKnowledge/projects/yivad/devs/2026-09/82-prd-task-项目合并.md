<a id="sec-1"></a>
## 一、方案概述

将两个项目合并为一个：源项目的 Issue/模块/文档迁移到目标项目。

### 合并选项

| 选项 | 说明 |
|------|------|
| 合并 Issue | 源项目 Issue 迁移到目标项目 |
| 合并模块 | 模块去重后合并 |
| 保留源项目 | 合并后保留或归档源项目 |

> 低优先级。
