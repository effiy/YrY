## 一、方案概述

Incident 管理：创建/升级/解决事件，值班排班表，事件时间线。

### 事件生命周期

```
open → investigating → identified → mitigated → resolved → postmortem
```

### 值班排班

| 功能 | 说明 |
|------|------|
| 排班表 | 按周/日显示值班人员 |
| 轮换 | 自动通知下一班值班人员 |
| 升级 | 超时未响应自动升级 |

> 低优先级。
