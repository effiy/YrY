<a id="sec-1"></a>
## 一、方案概述

管理员发布系统公告（维护通知/新功能/紧急通知），用户在 Header 区域看到公告条。

### 公告类型

| 类型 | 样式 | 场景 |
|------|------|------|
| info | 蓝色 | 新功能上线 |
| warning | 橙色 | 计划维护 |
| error | 红色 | 紧急故障 |
| success | 绿色 | 维护完成 |

### 公告配置

| 字段 | 说明 |
|------|------|
| 内容 | Markdown 支持 |
| 类型 | info/warning/error/success |
| 生效时间 | 定时发布 |
| 过期时间 | 自动下线 |
| 可关闭 | 用户可点击关闭 |

### 实施步骤：0.5d

- 公告 CRUD + Header 公告条
