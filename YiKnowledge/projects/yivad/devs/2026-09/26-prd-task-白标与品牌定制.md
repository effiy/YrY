<a id="sec-1"></a>
## 一、方案概述

支持自定义 Logo、品牌色、应用标题，通过管理后台配置。

### 可定制项

| 项目 | 配置方式 | 默认值 |
|------|---------|--------|
| Logo | 图片上传 | YiVad 默认 Logo |
| 品牌色 | 颜色选择器 | #409EFF |
| 应用标题 | 文本输入 | "YiVad" |
| Favicon | 图片上传 | 默认 favicon |

### 实现方式

CSS 变量注入 + `document.title` 动态设置：

```css
:root {
  --brand-color: #409EFF;
  --brand-logo: url('/default-logo.png');
}
```

> 当前阶段：低优先级，按需启动。
