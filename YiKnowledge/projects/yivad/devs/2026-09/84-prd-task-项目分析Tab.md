## 一、方案概述

项目详情页新增「分析」Tab：燃尽图、Bug 趋势、模块进度、成员贡献等可视化图表。

### 图表清单

| 图表 | 类型 | 数据 |
|------|------|------|
| Issue 燃尽图 | ECharts 折线 | 按日 done/total |
| Bug 趋势 | ECharts 柱状 | 按周 open/closed |
| 模块进度 | 进度条 | Module Issue % |
| 成员贡献 | 饼图 | 按成员 Issue 数 |

### 实施步骤：1.0d

| 步骤 | 内容 | 人天 |
|------|------|------|
| 1 | 数据聚合 API | 0.25 |
| 2 | ECharts 图表渲染 | 0.5 |
| 3 | Tab 集成 + 日期联动 | 0.25 |
