# YV-09-48: API 调试控制台 — 开发方案

> 需求编号：YV-09-48 · 人天：1.0d

> **文档职责**：本文档定义**怎么做、为什么这么做、实际做成什么样**（HOW），不含产品目标与测试用例。

---

<a id="sec-1"></a>
## 一、方案概述

内置 API 调试控制台，支持选择 RPC 方法、填写参数、发送请求、查看响应的完整调试流程。

### 核心功能

| 功能 | 说明 |
|------|------|
| 方法列表 | 从 RPC 模块注册表加载可用方法 |
| 参数编辑 | JSON 编辑器，语法高亮 + 校验 |
| 请求发送 | 通过 RequestHttp 发送 RPC 请求 |
| 响应展示 | JSON 格式化 + 耗时 + 状态码 |
| 请求历史 | 最近 20 条请求历史 |

### 界面布局

```
┌──────────────────────────────┐
│ Module: [data_service     ▼] │
│ Method: [query_documents  ▼] │
├──────────────────────────────┤
│ Parameters (JSON):           │
│ ┌──────────────────────────┐ │
│ │ { "cname": "projects" }  │ │
│ └──────────────────────────┘ │
│ [Send]                       │
├──────────────────────────────┤
│ Response: (200 · 45ms)       │
│ ┌──────────────────────────┐ │
│ │ { "code": 0, "data": {} }│ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

### 实施步骤：1.0d

| 步骤 | 内容 |
|------|------|
| 1 | 控制台 UI (方法选择 + 参数编辑 + 响应展示) |
| 2 | RPC 调用集成 + 请求历史 |
