<a id="sec-1"></a>
## 一、方案概述

用户可生成 API Token 用于外部调用 YiAi，支持创建/查看/撤销，Token 仅创建时显示一次。

### Token 管理

```typescript
interface ApiToken {
  _id: string;
  name: string;         // "CI/CD Pipeline"
  prefix: string;       // "yivad_..." (仅显示前 8 位)
  lastUsed: string;     // 最后使用时间
  createdAt: string;
  expiresAt?: string;   // 过期时间
}
```

### 安全约束

| 约束 | 说明 |
|------|------|
| 仅创建时显示 | Token 仅在创建弹窗中显示一次，关闭后不可查看 |
| 前缀识别 | 列表中仅显示 `yivad_ab****` 前缀 |
| 过期支持 | 可选过期时间（30/60/90 天） |
| 撤销即时 | 撤销后立即失效 |

### 实施步骤：0.5d

- Token 生成/列表/撤销页面
