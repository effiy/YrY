<a id="sec-1"></a>
## 一、方案概述

全站键盘导航：Tab 序合理、焦点可见、Skip Link、快捷键不冲突。

### 改进项

| 项目 | 说明 |
|------|------|
| Tab 序 | 表单字段、按钮、链接按逻辑顺序 |
| 焦点环 | `:focus-visible` 可见焦点指示 |
| Skip Link | 「跳转到内容」链接 |
| 快捷键 | 不与浏览器/屏幕阅读器冲突 |

> 低优先级。
