## 一、方案概述

WCAG 2.1 AA 色彩对比度合规审计：文字/背景对比度 ≥ 4.5:1。

### 审计范围

| 元素 | 要求 |
|------|------|
| 正文文字 | ≥ 4.5:1 |
| 大文字 (≥18px) | ≥ 3:1 |
| 图标/按钮 | ≥ 3:1 |
| 焦点环 | ≥ 3:1 |

> 低优先级。
