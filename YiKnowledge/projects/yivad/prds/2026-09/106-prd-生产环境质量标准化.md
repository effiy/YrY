# YV-09-106: 生产环境质量标准化

> 消除 3 处生产 console.log 泄漏 + 1 处 void 死代码模式，建立生产质量基线。

---

## 背景

### 问题 1: 调试日志泄漏

AI Chat 相关代码中 3 处 `console.log` 在生产环境输出内部状态：

| 位置 | 内容 | 频率 |
|------|------|------|
| `aiChat.ts:146` | 消息数组长度变化 | 每次消息更新（50-100/s） |
| `useStreaming.ts:299` | 流完成时间戳 | 每次对话结束 |
| `chatService.ts:77` | HTTP 状态码 + content-type | 每次 SSE 连接 |

### 问题 2: void 死代码

`issue/index.vue` 中 `useIssueExport` 被导入但从未使用，用 `void exportCSV; void exportJSON` 抑制警告。

## 验收标准

- `grep "console.log(" dist/` → 0 匹配（生产构建）
- 无 `void export` 模式的代码
- `vue-tsc --noEmit` → 0 errors

## 修复

| 问题 | 方案 | 文件 |
|------|------|------|
| console.log ×3 | `if (import.meta.env.DEV)` 守卫 | aiChat.ts, useStreaming.ts, chatService.ts |
| void 死代码 | 删除 import + 解构 + void 行 | issue/index.vue |
