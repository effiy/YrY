# YV-100: 前端代码质量提升

## 一、需求背景

### 问题 1：时间格式化函数大量重复

YiVad 代码库中存在 **12 个** 独立实现的 `formatTime`/`timeAgo` 函数，分散在：
- 3 个通知组件（NotificationBell、NotificationItem、notification/index）
- 2 个报告组件（ReportBuilder、ReportPreview）
- 5 个知识页面（product、curator、goals、sre、metrics）
- 2 个仪表盘组件（RssArticlePanel、CodeHealthPanel）

每个实现行为略有不同（中/英文、ISO/时间戳输入、短/长格式输出），导致时间显示不一致。

### 问题 2：首页数据新鲜度显示不够专业

原有显示 `Xs ago` → `Xm ago`，无法精确表达实时性。

## 二、解决方案

### R1：统一时间格式化

创建 `src/utils/time.ts` 作为唯一时间格式化源：
- `parseTime()` — 统一解析 ISO/时间戳/Date
- `timeAgo(value, locale?)` — 相对时间
- `formatDate(value, locale?)` — 绝对日期
- `formatDateTime(value, locale?)` — 日期+时间
- `formatDuration(ms)` — 时长格式化

`useTagHelpers.formatRelativeTime` → 委托到 `utils/time.ts`（向后兼容）

### R2：淘汰重复实现

| 文件 | 变更 |
|------|------|
| NotificationBell.vue | 12 行本地 `formatTime` → `timeAgo(iso, "zh")` |
| NotificationItem.vue | 同上 |
| notification/index.vue | 同上 |

### R3：首页数据新鲜度优化

- < 5s → "just now"
- 5s–60s → "0:03" (MM:SS)
- 60s–300s → "2:45" (M:SS)
- ≥ 300s → "5m ago"

**脉冲指示器**：从一次性动画改为持续呼吸动画

### R4：数据新鲜度基础设施

- `useDataFreshness` composable — 轻量级新鲜度跟踪
- `DataFreshnessBar` 组件 — 可复用绿点+时间+刷新按钮

## 三、验收标准

- [x] `utils/time.ts` 覆盖所有常见格式化场景
- [x] 3 个通知组件不再包含本地 `formatTime`
- [x] `useTagHelpers.formatRelativeTime` 向后兼容
- [x] 首页年龄显示 MM:SS 格式
- [x] 脉冲动画持续呼吸效果
- [x] `useDataFreshness` composable 可独立使用
