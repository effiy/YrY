# YV-09-105: TypeScript 类型安全全面恢复

> 从 7 个 vue-tsc 错误降至 0，实现编译时类型安全全覆盖。

---

## 背景

审计前 `vue-tsc --noEmit` 报告 7 个 TypeScript 错误：

| # | 错误 | 文件 | 类型 |
|---|------|------|------|
| 1 | `Property 'ucl' does not exist` | FlowMetricsRow.vue | 类型定义缺失 |
| 2 | `Expected 0-1 arguments, but got 2` | bug/index.vue | 函数签名不匹配 |
| 3 | `Property 'clearInterval' does not exist` | FileAlertsDashboard.vue | 模板标识符遮蔽 |
| 4 | `Property 'setInterval' does not exist` | FileAlertsDashboard.vue | 同上 |
| 5 | `Property 'submitForm' does not exist` | issue/index.vue | 方法不存在 |
| 6-7 | `Type 'string' is not assignable` | leader/index.vue | ECOption 字面量类型 |

另有 2 个附加发现：
- `useLiveMetrics.ts` → `yiAiBaseUrl` 未导出（零消费者，确认安全）
- `ReportBuilder.vue` → `config` 可能 undefined（v-if 窄化不足）

## 验收标准

- `vue-tsc --noEmit` → **0 errors**
- 无新增 `// @ts-ignore` 注释
- `pnpm build:pro` 成功
- ESLint `--quiet` 无新增错误

## 修复策略

| 策略 | 适用错误 | 实施 |
|------|----------|------|
| 导入正确类型 | #2 confirm 参数 | import { confirm } from hook |
| 模板标识符提取 | #3 #4 clearInterval | 内联 → 命名方法 + ref |
| 引用纠正 | #5 submitForm | actions.submitForm → submit |
| 初始化守卫 | #config undefined | openConfig 确保 config 初始化 + v-if 窄化 |
| 字面量断言 | #6 #7 ECOption | 字符串 → as const |
