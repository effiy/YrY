## 二、覆盖缺口

| 缺口 | 影响 | 优先级 |
|------|------|--------|
| **aiChat store** (useStreaming, useConversations, useContextFiles) 无测试 | 聊天核心逻辑无回归保护 | P0 |
| **routers** (dynamicRouter 权限守卫) 无测试 | 路由安全无验证 | P1 |
| **API modules** (chatService, ragService, knowledgeService) 大部分无测试 | RPC 调用无 mock 验证 | P1 |
| **Views** (pages) 无组件测试 | 页面渲染逻辑无回归 | P2 |
| **ErrorHandler** 2 处 console.log → 应使用 spy 验证 | 已修复 | ✅ |
| **useNotificationSSE** 未测试 localStorage key 正确性 | 认证回归风险 | P2 |
| **useTable** 竞态条件 | 已通过手动验证，无自动化测试 | P1 |
