# YiVad 运行时稳定性修复

> 需求编号：YV-09-100 · 优先级：P0 · 总人天：~0.5d · 涉及模块：stores(1)、utils(2)、routers(1)

---

## 一、需求背景

YiVad 代码审查中发现 4 处运行时风险：

| 严重度 | 问题 | 影响 |
|--------|------|------|
| **P0-critical** | `tabs.ts` 模块级 `useKeepAliveStore()` 调用 | 懒加载场景下应用白屏崩溃 |
| **P2-minor** | `errorHandler.ts` HTTP 错误过滤不完整 | 4xx/5xx 错误重复弹 toast |
| **P3-trivial** | `router/index.ts` `toLocaleLowerCase()` 土耳其语问题 | 登录页路由在特定区域匹配失败 |
| **P2-minor** | `errorReporter.ts` 硬编码 API 路径 | 非标准部署时错误报告丢失 |

## 三、技术方案

### 3.1 Pinia 模块级调用 → defineStore 回调内

```ts
// Before: module-level — executes before app.use(pinia)
const keepAliveStore = useKeepAliveStore();
export const useTabsStore = defineStore("yivad-tabs", () => { ... });

// After: inside setup — executes lazily after pinia is installed
export const useTabsStore = defineStore("yivad-tabs", () => {
  const keepAliveStore = useKeepAliveStore();
  ...
});
```

### 3.2 错误过滤器：同时检查 error.status 和 error.response.status

```ts
// Before: only checks error.status (Axios puts status on error.response.status)
if ((error as any).status !== undefined || ...) return;

// After: checks both locations
const httpStatus = (error as any).status ?? (error as any).response?.status;
if (httpStatus !== undefined) return;
```

### 3.3 路由：toLocaleLowerCase → toLowerCase

```ts
// Before: locale-sensitive (Turkish "I" → "ı")
if (to.path.toLocaleLowerCase() === LOGIN_URL)

// After: ASCII-safe
if (to.path.toLowerCase() === LOGIN_URL)
```

### 3.4 API 路径：使用 RSBUILD_ENV_API_URL

```ts
// Before: hardcoded
navigator.sendBeacon("/api/error-report", payload);

// After: env-aware
const reportUrl = `${apiBase}/api/error-report`;
```
