# YV-09-104: 关键基础设施漏洞专项修复

> 修复 3 个影响面广的基础设施级漏洞：Grid KeepAlive 监听器泄漏（全部页面）、SSE 通知认证失效（通知系统）、跨项目 feedback RPC 契约断裂（AI Chat 反馈）。

---

## 背景

在全面代码审计中，发现 3 个基础设施级问题：

### 漏洞 1: Grid KeepAlive 监听器泄漏

Grid 组件在 `onMounted` 和 `onActivated` 中都注册 `window.resize`，但 `onDeactivated` 仅移除一次。每次 activate/deactivate 周期净增 1 个监听器。影响所有使用 Grid 组件的 KeepAlive 页面。

**影响面**: SearchForm 等所有使用 Grid 布局的页面

### 漏洞 2: SSE 认证失效

通知 SSE 从 `localStorage.getItem("user-store")` 读取 token，但 Pinia store 配置的 persisted key 是 `"yivad-user"`。auth disabled 时无影响，启用后 SSE 连接永远不带 token。

**影响面**: 通知中心的实时推送功能

### 漏洞 3: 跨项目 RPC 契约断裂

feedbackService 调用 `services.ai.feedback_service` 模块，该模块在 YiAi 中不存在。AI Chat 的 👍/👎 反馈功能形同虚设。

**影响面**: AI Chat 反馈数据从未持久化

---

## 验收标准

### AC-1: Grid 监听器不泄漏
- **When** KeepAlive 页面切换 10 次
- **Then** `window.resize` 监听器数始终为 1

### AC-2: SSE 携带 Token
- **Given** YiAi auth enabled
- **When** SSE 连接建立
- **Then** URL 包含有效 `?token=` 参数

### AC-3: 反馈数据持久化
- **When** 用户在 AI Chat 点击 👍/👎
- **Then** 反馈数据存入 MongoDB `feedback` 集合
- **And** 可通过 `getSessionFeedback` 查询

### AC-4: 类型安全不回归
- **When** `vue-tsc --noEmit`
- **Then** 0 TypeScript 错误
