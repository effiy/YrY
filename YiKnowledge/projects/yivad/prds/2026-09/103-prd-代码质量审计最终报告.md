## 四、六大防护模式

从 18 个 bug 提炼的可持续防护模式（详见 #102）：

1. **竞态守卫**: `++seq → await → check seq` 模式
2. **模板函数名校验**: 模板 `{{ fn }}` ↔ 脚本 `function fn`
3. **KeepAlive 守卫**: `onMounted` + `onActivated` 幂等保护
4. **localStorage Key**: 与 `piniaPersistConfig(id)` 一致
5. **v-model 路径**: 复杂路径用 computed getter/setter
6. **Timer Ref 化**: `let timer` → `const timer = ref()`
