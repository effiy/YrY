# YV-101: 代码专业化提升

## 一、背景

部分 YiVad 页面存在硬编码英文字符串，未使用 i18n 国际化：

| 页面 | 硬编码文本 |
|------|-----------|
| ExportHistory.vue | `label="Rows"`, 无 `empty-text` |
| import/index.vue | `rows detected` |

## 二、修复

- **ExportHistory.vue**: `label="Rows"` → `:label="$t('common.rows')"`, 添加 `empty-text="No exports yet"`
- **import/index.vue**: `rows detected` → `$t("common.rows") + $t("common.import.detected")`

## 三、验收

- [x] ExportHistory 表格列标签使用 i18n
- [x] ExportHistory 空表格显示提示文本
- [x] import 页面行数提示使用 i18n
