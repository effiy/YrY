#### TC-FORECAST-003：速度预测 — 移动平均 vs 指数平滑

| 项目 | 内容 |
|------|------|
| **优先级** | P2 |
| **前置条件** | 历史 8 个 Sprint 速率呈上升趋势：[10, 12, 11, 14, 13, 16, 15, 18] |
| **测试步骤** | 1. 查看速度预测图 2. 切换预测方法（移动平均 / 指数平滑） |
