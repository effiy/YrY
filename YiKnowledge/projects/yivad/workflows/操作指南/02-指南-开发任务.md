# 开发任务

> 常见开发任务的标准操作流程。每个任务提供完整步骤、代码模板、验证方式和常见陷阱。

## 一、新增列表页

这是最常用的开发任务。标准模式：ProTable + useTable composable。

### 操作步骤

```
1. 定义类型 → 2. 创建 API 模块 → 3. 创建 Store → 4. 创建页面 → 5. 国际化 → 6. 注册菜单 → 7. 验证
```

### 详细步骤

**1. 定义类型** — `src/api/interface/myFeature.ts`

```typescript
export interface MyItem {
  _id: string;
  name: string;
  status: "active" | "archived";
  createdAt: string;
}

export interface MyItemQueryParams {
  cname: string;
  filter?: Record<string, unknown>;
  pageNum?: number;
  pageSize?: number;
}
```

**2. 创建 API 模块** — `src/api/modules/myFeatureService.ts`

```typescript
import { http } from "@/api";
import type { MyItem, MyItemQueryParams } from "@/api/interface/myFeature";

export async function queryMyItems(params: MyItemQueryParams) {
  return http.post("/", {
    module_name: "services.database.data_service",
    method_name: "query_documents",
    parameters: params,  // 注意：参数名是 filter，不是 query
  });
}
```

**3. 创建 Store**（如需跨组件共享状态）— `src/stores/modules/myFeature.ts`

```typescript
export const useMyFeatureStore = defineStore("yivad-myfeature", () => {
  const list = ref<MyItem[]>([]);
  const loading = ref(false);

  async function fetchList(params: MyItemQueryParams) {
    loading.value = true;
    try {
      const data = await queryMyItems(params);
      list.value = data.list;
    } finally {
      loading.value = false;
    }
  }

  return { list, loading, fetchList };
});
```

**4. 创建页面** — `src/views/myFeature/index.vue`

```vue
<script setup lang="ts">
import ProTable from "@/components/ProTable/ProTable.vue";
import { useTable } from "@/hooks/useTable";
import { queryMyItems } from "@/api/modules/myFeatureService";
import type { ColumnProps } from "@/components/ProTable/interface";

const { tableData, loading, pagination, search, refresh } = useTable({
  requestApi: queryMyItems,
  defaultParams: { cname: "my_collection" },
});

const columns: ColumnProps[] = [
  { prop: "name", label: "名称", search: { el: "input" } },
  { prop: "status", label: "状态", search: { el: "select" }, enum: STATUS_OPTIONS },
  { prop: "createdAt", label: "创建时间", sortable: true },
];
</script>

<template>
  <ProTable
    :columns="columns"
    :data="tableData"
    :loading="loading"
    :pagination="pagination"
    @page-change="refresh"
  />
</template>
```

**5. 国际化** — `src/languages/modules/myFeature/{zh,en}.ts`

```typescript
// zh.ts
export default {
  myFeature: {
    list: { title: "我的功能", searchPlaceholder: "搜索名称" },
    dialog: { createTitle: "新建", editTitle: "编辑", nameRequired: "请输入名称" },
  }
};
```

**6. 注册菜单** — 在 YiAi 后端 MongoDB `menus` 集合中添加菜单项：

```json
{
  "path": "/myFeature",
  "name": "myFeature",
  "component": "/myFeature/index",
  "meta": { "title": "我的功能", "icon": "icon-feature", "isHide": false, "isFull": false }
}
```

**7. 验证**

```bash
pnpm typecheck && pnpm lint && pnpm dev
# 访问 http://localhost:8848/#/myFeature
# 检查：表格渲染、搜索筛选、分页切换、空状态
```

### 常见陷阱

| 陷阱 | 表现 | 修复 |
|------|------|------|
| 参数名用 `query` | 搜索无效、数据不更新 | 改为 `filter` |
| `cname` 与后端集合名不一致 | 返回空列表 | 确认 MongoDB 集合名 |
| 忘记 `{ loading: false }` | 每次请求触发整页 loading | 在 API 调用时传入 |
| 列定义缺少 `search.el` | 表头无搜索框 | 添加 search 配置 |
| 未处理 `_id` 序列化 | 表格渲染 `[object Object]` | Store 层 `_id` → 字符串 |

## 二、新增表单页（创建/编辑）

### 模式选择

| 模式 | 场景 | 组件 |
|------|------|------|
| 弹窗表单 | 简单创建/编辑，不离开列表 | `el-dialog` + `ProForm` |
| 独立页面 | 复杂表单、多步骤 | 独立路由 + `ProForm` |

### 弹窗模式示例

```vue
<script setup lang="ts">
import { ref } from "vue";
import ProForm from "@/components/ProForm/ProForm.vue";
import type { FormItemProps } from "@/components/ProForm/interface";

const visible = ref(false);
const formRef = ref();

const formItems: FormItemProps[] = [
  { prop: "name", label: "名称", el: "input", rules: [{ required: true, message: "请输入名称" }] },
  { prop: "description", label: "描述", el: "input", type: "textarea" },
  { prop: "status", label: "状态", el: "select", enum: STATUS_OPTIONS },
];

async function handleSubmit(formData: Record<string, unknown>) {
  await createDocument({ cname: "my_collection", data: formData });
  ElMessage.success("创建成功");
  visible.value = false;
  refresh(); // 刷新列表
}
</script>

<template>
  <el-button type="primary" @click="visible = true">新建</el-button>
  <el-dialog v-model="visible" title="新建">
    <ProForm ref="formRef" :items="formItems" @submit="handleSubmit" />
  </el-dialog>
</template>
```

### 常见陷阱

| 陷阱 | 表现 | 修复 |
|------|------|------|
| 弹窗关闭后表单校验残留 | 再次打开时红色提示还在 | `formRef.value?.resetFields()` |
| 编辑回显时直接修改 props | 数据污染 | 深拷贝后再绑定 |
| 提交后未刷新列表 | 列表数据过时 | `handleSubmit` 最后调 `refresh()` |

## 三、新增 API 调用

### 操作步骤

1. **定义类型** — `src/api/interface/index.ts`

```typescript
export interface CreateParams {
  cname: string;
  data: Record<string, unknown>;
}

export interface UpdateParams {
  cname: string;
  key: Record<string, unknown>;
  data: Record<string, unknown>;
}
```

2. **添加 API 方法** — `src/api/modules/dataService.ts`

```typescript
export async function createDocument(params: CreateParams): Promise<{ _id: string }> {
  return http.post("/", {
    module_name: "services.database.data_service",
    method_name: "create_document",
    parameters: params,
  });
}
```

3. **在 Store/Hook 中调用**

```typescript
async function create(data: Record<string, unknown>) {
  loading.value = true;
  try {
    await createDocument({ cname: "my_collection", data });
    ElMessage.success("创建成功");
    await fetchList(); // 刷新列表
  } catch {
    // 错误提示已由 RequestHttp 拦截器统一处理
  } finally {
    loading.value = false;
  }
}
```

### RPC 参数名契约（强制）

| 正确 | 错误 | 说明 |
|------|------|------|
| `filter` | `query` | 数据查询过滤条件 |
| `target_file` | `path` | 文件读写目标路径 |
| `cname` | `collection_name` | MongoDB 集合名称 |
| `pageNum` | `page` | 页码 |
| `pageSize` | `limit` | 每页条数 |

## 四、新增 Store

### 模板

```typescript
// stores/modules/myFeature.ts
import { defineStore } from "pinia";
import { ref, computed } from "vue";
import { queryMyItems, createDocument, updateDocument, deleteDocument } from "@/api/modules/myFeatureService";
import type { MyItem } from "@/api/interface/myFeature";

export const useMyFeatureStore = defineStore("yivad-myfeature", () => {
  // 1. 状态
  const list = ref<MyItem[]>([]);
  const loading = ref(false);
  const currentItem = ref<MyItem | null>(null);

  // 2. 派生
  const activeItems = computed(() => list.value.filter(item => item.status === "active"));

  // 3. 动作
  async function fetchList(params?: Record<string, unknown>) {
    loading.value = true;
    try {
      const data = await queryMyItems({ cname: "my_collection", filter: params });
      list.value = data.list;
    } finally {
      loading.value = false;
    }
  }

  async function create(data: Record<string, unknown>) {
    await createDocument({ cname: "my_collection", data });
    await fetchList();
  }

  async function update(id: string, data: Record<string, unknown>) {
    await updateDocument({ cname: "my_collection", key: { _id: id }, data });
    await fetchList();
  }

  async function remove(id: string) {
    await deleteDocument({ cname: "my_collection", key: { _id: id } });
    await fetchList();
  }

  return { list, loading, currentItem, activeItems, fetchList, create, update, remove };
});
```

### Store 设计原则

| 原则 | 说明 |
|------|------|
| 单一业务域 | 一个 Store 一个业务域，不做万能 Store |
| 方法暴露 | 暴露方法而非直接暴露 mutable state |
| loading/error | 异步操作统一管理 loading 状态 |
| 通过 API 层 | 不直接导入 axios/fetch，通过 API 模块调用 |

## 五、提交代码

### 标准流程

```bash
# 1. 质量检查
pnpm typecheck          # TypeScript 类型检查
pnpm lint               # ESLint + Stylelint

# 2. 运行测试
pnpm test               # Vitest 单元测试

# 3. 交互式提交（推荐）
pnpm commit             # cz-git 引导填写 type/scope/描述

# 4. 或直接提交
git add <files>
git commit -m "feat(myFeature): add list page with ProTable"
```

### 提交前检查清单

- [ ] `pnpm typecheck` 通过（无类型错误）
- [ ] `pnpm lint` 通过（无 ESLint/Stylelint 错误）
- [ ] 表格使用 ProTable，非 el-table
- [ ] 权限使用 v-auth，非 v-if 内联
- [ ] 文本使用 $t()，非硬编码中文
- [ ] API 参数名使用 filter/target_file/cname
- [ ] 无 console.log 残留
- [ ] 无未使用的导入
