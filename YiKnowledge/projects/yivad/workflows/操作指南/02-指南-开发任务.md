# 开发任务

> 常见开发任务的标准操作流程。

## 新增列表页

1. 定义类型 → `src/api/interface/myFeature.ts`
2. 创建 API 模块 → `src/api/modules/myFeatureService.ts`
3. 创建 Store（如需）→ `src/stores/modules/myFeature.ts`
4. 创建页面 → `src/views/myFeature/index.vue`（使用 ProTable + useTable）
5. 添加国际化 → `src/languages/modules/myFeature/`
6. 注册菜单 → 后端 MongoDB `menus` 集合
7. 验证 → `pnpm typecheck && pnpm lint && pnpm dev`

## 新增表单页

1. 创建编辑页 → `src/views/myFeature/edit.vue`
2. 使用 `ProForm` + `FormItemProps[]` 声明式配置
3. Store 中添加 create/update 方法
4. 路由配置 `hidden: true`（不在侧边栏显示）
5. 添加国际化（标签、校验提示）

## 新增 API 调用

1. 在 `api/interface/` 定义请求/响应类型
2. 在 `api/modules/<domain>Service.ts` 添加方法
3. 使用 RPC 信封：`{ module_name, method_name, parameters }`
4. 参数名强制：`filter`（非 `query`）、`cname`（非 `collection_name`）、`target_file`（非 `path`）
5. 在 Store 或 Hook 中调用并处理响应/错误

## 提交代码

```bash
pnpm typecheck && pnpm lint     # 质量检查
pnpm commit                      # cz-git 交互式提交
```
