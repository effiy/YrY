# 环境搭建

> 从零搭建 YiVad 开发环境。包括环境要求、安装启动、IDE 配置、调试技巧、常见问题排查。

## 一、环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Node.js | ≥ 18（推荐 20 LTS） | JavaScript 运行时 |
| pnpm | ≥ 8（**强制**，禁止 npm/yarn） | 包管理器，通过 `corepack enable` 或 `npm i -g pnpm` 安装 |
| YiAi | — | 后端必须运行在 `:10086` |
| Git | ≥ 2.30 | 版本控制 |
| Chrome | 最新稳定版 | 开发调试 |

### 验证环境

```bash
node --version   # ≥ 18.0.0
pnpm --version   # ≥ 8.0.0
git --version    # ≥ 2.30.0

# 验证 YiAi 后端
curl http://localhost:10086/health
# 期望: {"code": 0, "message": "ok", "data": {"status": "healthy"}}
```

## 二、快速启动

### 前端独立启动

```bash
cd YrY/YiVad
pnpm install        # 首次：安装依赖
pnpm dev            # 启动开发服务器 → http://localhost:8848
```

### 全栈启动（推荐）

```bash
# 终端 1: 启动 YiAi 后端
cd YrY/YiAi && python main.py

# 终端 2: 启动 YiVad 前端
cd YrY/YiVad && pnpm dev
```

### 启动后验证

1. 浏览器访问 `http://localhost:8848`
2. 登录页应正常显示（默认 token 模式，参考 YiAi 配置）
3. F12 打开控制台，确认无红色报错
4. Network 面板检查 `/auth/menu/list` 请求是否 200

## 三、IDE 配置

推荐 VS Code + 以下扩展：

| 扩展 | ID | 用途 |
|------|-----|------|
| Vue - Official | `Vue.volar` | 语法高亮、类型检查、模板 IntelliSense |
| ESLint | `dbaeumer.vscode-eslint` | 实时代码检查 |
| Prettier | `esbenp.prettier-vscode` | 保存时自动格式化 |
| Stylelint | `stylelint.vscode-stylelint` | SCSS 样式检查 |

### VS Code 配置建议

```json
// .vscode/settings.json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "[vue]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "typescript.tsdk": "node_modules/typescript/lib"
}
```

### Takeover Mode（禁用 Vetur）

如果之前安装过 Vetur，必须禁用以避免冲突：

1. 在已安装扩展中搜索 "Vetur"
2. 右键 → "禁用（工作区）"
3. 或：`.vscode/extensions.json` 中添加 `"recommendations": ["Vue.volar"]`

## 四、环境变量

前缀统一使用 `RSBUILD_*`，通过 `.env.{mode}` 文件管理：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `RSBUILD_API_BASE` | `http://localhost:10086` | YiAi 后端地址 |
| `RSBUILD_PORT` | `8848` | 开发服务器端口 |
| `RSBUILD_PUBLIC_PATH` | `/` | 静态资源路径 |
| `RSBUILD_ROUTER_MODE` | `hash` | 路由模式（hash/history） |

**文件优先级：** `.env.{mode}.local` > `.env.{mode}` > `.env`

**常见配置：**

```bash
# .env.development.local（本地覆盖，不进 git）
RSBUILD_API_BASE=http://192.168.1.100:10086  # 连远程后端
```

## 五、常用命令速查

| 命令 | 用途 | 何时使用 |
|------|------|---------|
| `pnpm dev` | 开发服务器 | 日常开发 |
| `pnpm build:pro` | 生产构建 | 发布前验证 |
| `pnpm typecheck` | 类型检查（vue-tsc --noEmit） | 提交前必过 |
| `pnpm lint` | ESLint + Stylelint | 提交前必过 |
| `pnpm test` | 运行 Vitest 测试 | 提交前 |
| `pnpm test:coverage` | 测试覆盖率报告 | 定期检查 |
| `pnpm commit` | cz-git 交互式提交 | 每次提交 |
| `pnpm preview` | 预览构建产物 | 验证生产构建 |

## 六、调试技巧

### 浏览器 DevTools

| 面板 | 用途 |
|------|------|
| Console | 查看日志、运行时错误 |
| Network | 检查 API 请求（RPC 信封）、SSE 流 |
| Vue DevTools | 组件树、Pinia 状态、路由 |
| Application | localStorage/persisted state、IndexedDB |

### Vue DevTools 安装

1. Chrome Web Store 搜索 "Vue.js devtools"
2. 安装后，DevTools 中出现 "Vue" 标签
3. 可查看组件树、Props、Pinia Stores、路由

### 调试权限问题

```javascript
// 浏览器控制台
// 1. 查看当前权限状态
const authStore = useAuthStore();
console.log("菜单:", authStore.authMenuListGet);
console.log("按钮:", authStore.authButtonListGet);
console.log("路由名:", authStore.routeName);

// 2. 模拟降级（断开 YiAi 后刷新页面）
// 菜单应来自 authMenuList.json

// 3. 检查 v-auth 判定
// 在元素上右键 → 检查 → 确认 DOM 中是否存在
```

### 调试 RPC 调用

```javascript
// Network 面板过滤 "/"
// 查看 Request Payload:
{
  "module_name": "services.database.data_service",
  "method_name": "query_documents",
```

## 七、常见问题排查

### pnpm install 失败

```bash
# 清除缓存
rm -rf node_modules pnpm-lock.yaml
pnpm install

# 检查 registry
pnpm config get registry
# 应为 https://registry.npmmirror.com 或默认 npm registry
```

### 端口 8848 被占用

```bash
# 查找占用进程
lsof -i :8848
# 杀死进程或修改端口
RSBUILD_PORT=8849 pnpm dev
```

### API 请求 401 / CORS 错误

1. 确认 YiAi 后端运行：`curl http://localhost:10086/health`
2. 检查 YiAi CORS 配置（`config.yaml` → `cors.allow_any_origin: true`）
3. 检查 `RSBUILD_API_BASE` 环境变量是否正确

### 类型检查报错

```bash
# 查看详细错误
pnpm typecheck

# 常见原因：
# - Props 类型不匹配
# - 导入路径错误
# - node_modules 类型不兼容（升级依赖）
```

### 菜单为空/页面白屏

1. 确认 YiAi 运行且 `/auth/menu/list` 返回数据
2. 检查浏览器控制台是否有 401
3. 检查 `authMenuList.json` 兜底文件是否有效
4. 清除 localStorage → 刷新页面重新登录

### 热更新不生效

- Rsbuild 默认 HMR，修改 `.vue`/`.ts` 文件自动更新
- 如果修改 `rsbuild.config.ts` 或环境变量，需重启 `pnpm dev`
- 路由配置变更后需刷新页面（HMR 不会重新注册路由）

## 八、多环境切换

```bash
# 连接不同后端
RSBUILD_API_BASE=http://dev-server:10086 pnpm dev    # 开发环境
RSBUILD_API_BASE=http://test-server:10086 pnpm dev   # 测试环境
RSBUILD_API_BASE=http://localhost:10086 pnpm dev     # 本地后端
```
