# 环境搭建

> 从零搭建 YiVad 开发环境。

## 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Node.js | ≥ 18（推荐 20 LTS） | 运行时 |
| pnpm | ≥ 8（**强制**，禁止 npm/yarn） | 包管理器 |
| YiAi | — | 后端必须运行在 `:10086` |
| Git | ≥ 2.30 | 版本控制 |

## 快速启动

```bash
cd YrY/YiVad
pnpm install
pnpm dev        # → http://localhost:8848
```

## 全栈启动

```bash
# 终端 1: 后端
cd YrY/YiAi && python main.py

# 终端 2: 前端
cd YrY/YiVad && pnpm dev
```

## IDE 配置

推荐 VS Code + 以下扩展：

- **Vue - Official** (`Vue.volar`) — 语法高亮、类型检查
- **ESLint** (`dbaeumer.vscode-eslint`) — 实时检查
- **Prettier** (`esbenp.prettier-vscode`) — 格式化
- **Stylelint** (`stylelint.vscode-stylelint`) — 样式检查

保存时自动格式化：`"editor.formatOnSave": true`

## 环境变量

前缀 `RSBUILD_*`，通过 `.env.{mode}` 文件管理：

| 变量 | 默认值 |
|------|--------|
| `RSBUILD_API_BASE` | `http://localhost:10086` |
| `RSBUILD_PORT` | `8848` |
| `RSBUILD_PUBLIC_PATH` | `/` |

优先级：`.env.{mode}.local` > `.env.{mode}` > `.env`
