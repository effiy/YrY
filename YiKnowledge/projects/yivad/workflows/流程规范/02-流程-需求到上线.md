# 需求到上线

> 从 PRD 到 Proposal 到构建部署的完整生命周期。

## 阶段流程

```
PRD 评审 → Proposal → 开发实现 → Code Review → 测试验证 → 构建部署
```

## PRD → Proposal

1. 需求方提供 PRD（YiKnowledge `prds/` 目录）
2. 开发者评估可行性、工时、技术方案
3. 输出 Proposal：技术方案 + 改动范围 + 风险评估
4. Proposal 需要明确模块边界和 API 契约变更

## 构建部署

```bash
pnpm build:dev      # 开发环境
pnpm build:test     # 测试环境
pnpm build:pro      # 生产环境（压缩、无 SourceMap）
```

**部署前检查：**
- `vue-tsc --noEmit` 通过
- 所有单元测试通过
- 新增 API 参数名遵循 RPC 契约
- 国际化文本已添加（zh + en）
- CLAUDE.md 已更新（如引入新模块或模式）

## 发布后

- 监控生产环境错误日志
- 验证关键功能可用
- 标记对应 issue/bug 状态
