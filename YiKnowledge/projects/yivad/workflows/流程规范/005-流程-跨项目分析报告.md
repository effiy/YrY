### 高相关度页面详情

#### 1. Translation Analytics (`/dashboard/analytics`)

**功能**：5 KPI 卡片 + 3 ECharts 图表 + Provider 明细表 + Smart Provider Ranking

**数据源**：
- `translation_analytics` — 翻译量、语言分布
- `provider_health` — Provider 成功率、健康状态
- `hourly_trend` — 7 天趋势
- `provider_breakdown` — 30 天 Provider 细分
- `provider_recommend` — 实时引擎排名

**YiPet 桥接**：✅ TranslationService 新增 6 个方法 + ProviderHealth Popup Widget
**YiPot 桥接**：✅ TranslationService 已含全部方法

#### 2. AI Chat (`/ai-chat`)

**功能**：SSE 流式对话、会话管理、RAG 上下文注入、文件提及、企业微信转发、技能选择器

**数据源**：`chat_service.chat` (SSE)、sessions CRUD

**YiPet 桥接**：✅ ChatService 已实现 SSE stream + prompt
**YiPot 桥接**：— 桌面翻译应用无聊天需求

#### 3. RAG Overview (`/rag`)

**功能**：索引状态卡片、检索配置、快捷查询、近期查询表、来源分析图表

**数据源**：`rag-status`、`rag-query`、`rag-build`

**YiPot 桥接**：✅ KnowledgeService 已含 ragStatus/ragQuery/rebuildRag
**YiPet 桥接**：— 扩展无需管理 RAG 索引

#### 4. Project Detail (`/project/:key`)

**功能**：概览（README、Stats、Activity Timeline、Todo List）、OKR、PRD、Dev、Test、Bug、Workflow、Analytics

**数据源**：issues/bugs/modules/knowledge_files CRUD

**YiPet 桥接**：✅ DashboardSummary 展示项目健康（open issues/bugs/overdue）
**YiPot 桥接**：— 桌面应用无项目管理需求

## 二、跨项目 RPC 契约一致性矩阵

### 翻译服务 (`services.translation.translate_service`)

| RPC 方法 | YiVad | YiPot | YiPet | 参数契约 | 返回类型 |
|----------|-------|-------|-------|---------|---------|
| `translate` | — | ✅ | ✅ | `{text, from_lang, to_lang, providers}` | `TranslateResult[]` |
| `translation_analytics` | ✅ | ✅ | ✅ | `{days}` | `{total_translations, by_target_language}` |
| `provider_health` | ✅ | ✅ | ✅ | `{hours}` | `{providers, memory_entries, feedback}` |
| `hourly_trend` | ✅ | ✅ | ✅ | `{days}` | `Array<{hour, count, chars}>` |
| `provider_breakdown` | ✅ | ✅ | ✅ | `{days}` | `Array<{provider, count, success}>` |
| `translation_memory_stats` | ✅ | ✅ | ✅ | `{}` (无参数) | `{total, languages, providers}` |
| `provider_recommend` | ✅ | ✅ | ✅ | `{from_lang, to_lang}` | `{recommended, providers[], healthy_count}` |
| `translation_feedback` | ✅ | ✅ | ✅ | `{source, target, rating, provider}` | `{success}` |
| `translate_stream` | — | ✅ | ✅ | `{text, from_lang, to_lang, provider}` | SSE chunks |
| `translate_with_context` | — | ✅ | — | `{text, from_lang, to_lang, domain}` | `{translation, sources[]}` |

**✅ 三项目 RPC 契约完全一致 — 无参数名不匹配，无返回类型差异。**

### 数据服务 (`services.database.data_service`)

三个项目均通过 `query_documents({cname, filter, pageNum, pageSize})` 访问 MongoDB，参数名契约一致（`filter` 非 `query`）。

### 文件服务 (`/read-file`, `/write-file`)

YiVad 和 YiPet 使用 `{target_file}`（非 `path`）参数名，契约一致。

## 三、实时性架构

```
┌─────────────────────────────────────────────────────────┐
│                        YiAi :10086                       │
│  ┌─────────────┐  ┌──────────────┐  ┌───────────────┐  │
│  │ chat_service │  │ translate_svc│  │ provider_health│  │
│  │   (SSE)      │  │  (SSE/RPC)   │  │    (RPC)       │  │
│  └──────┬───────┘  └──────┬───────┘  └───────┬───────┘  │
│         │                 │                   │          │
└─────────┼─────────────────┼───────────────────┼──────────┘
          │                 │                   │
    ┌─────┴─────┐    ┌──────┴──────┐    ┌───────┴───────┐
    │  YiVad    │    │   YiPot     │    │    YiPet      │
    │  SSE chat │    │ SSE stream  │    │ SSE chat +    │
    │  30s poll │    │ on-demand   │    │ translate     │
    │  charts   │    │ translate   │    │ 60s poll      │
    └───────────┘    └─────────────┘    └───────────────┘
```

| 项目 | 实时机制 | 刷新频率 | 实现方式 |
|------|---------|---------|---------|
| YiVad | SSE (chat) + 轮询 (analytics) | 30s | TranslationAnalytics toggle |
| YiPot | SSE (translate_stream) + 按需 (health) | 按需 | translateStream async generator |
| YiPet | SSE (chat) + SSE (translate) + 轮询 (health) | 60s | ProviderHealth setInterval |
