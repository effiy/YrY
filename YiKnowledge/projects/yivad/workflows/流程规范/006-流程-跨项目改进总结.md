## 六、架构关键决策

1. **ApiClient 统一入口** — 所有项目通过四层 API 架构（client → endpoints → types → services）与 YiAi 通信，禁止 raw `fetch()`
2. **60s 统一轮询** — 三项目使用相同节奏，数据年龄可视化（绿色 ≤60s / 灰色 >60s）
3. **YiKnowledge 作为单一真相来源** — 所有改进均有对应的 PRD/开发方案/测试用例文档
4. **YiAi 作为数据一致性枢纽** — 所有跨项目数据通过 YiAi RPC 信封流转，格式统一
