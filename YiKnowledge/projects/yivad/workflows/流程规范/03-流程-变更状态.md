# 变更状态管理

> Issue/Bug/Module 的状态生命周期和流转规则。

## Issue 状态流转

```
backlog → in_progress → done / cancelled
```

| 转换 | 触发条件 |
|------|----------|
| backlog → in_progress | 开始开发 |
| in_progress → done | 完成并验证 |
| in_progress → backlog | 暂时搁置 |
| * → cancelled | 需求取消 |

## Bug 状态流转

```
open → in_progress → resolved → closed
  ↻ reopened
```

| 转换 | 触发条件 |
|------|----------|
| open → in_progress | 开始修复 |
| in_progress → resolved | 修复完成、已部署 |
| resolved → closed | 验证通过 |
| resolved → reopened | 问题复现 |

## 模块管理

- 模块通过 `moduleService` 管理，关联到项目（`project_key`）
- 模块状态：`active` / `archived`
- Bug 关联模块时使用模块名称匹配

## 跟踪原则

- Issue/Bug 的 `updated_at` 在状态变更时同步更新
- 优先级标记：`p0`(urgent) > `p1`(high) > `p2`(medium) > `p3`(low)
- 逾期的 Issue/Bug 在概览页高亮标记
