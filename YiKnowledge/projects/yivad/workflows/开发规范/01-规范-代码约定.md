# 代码约定

> 组件风格、命名、TypeScript、导入顺序 —— 所有代码必须遵守的基线规则。

## 组件风格

- 仅使用 `<script setup lang="ts">`，禁止 Options API
- Props/Emits 使用泛型声明：`defineProps<{...}>()` / `defineEmits<{...}>()`
- 样式使用 `<style lang="scss" scoped>`，变量来自 `src/styles/var.scss`

## 命名约定

| 格式 | 适用范围 |
|------|----------|
| PascalCase | 组件、类型、接口 |
| camelCase | composables、变量、函数、Store 模块、API 模块 |
| kebab-case | CSS 类名、文件路由 |
| UPPER_SNAKE_CASE | 常量、枚举值 |
| snake_case | 后端 YiAi（Python） |

## TypeScript 规则

- 接口优先于类型别名（对象形状用 `interface`，联合/交叉类型用 `type`）
- 禁止 `any` → 用 `unknown` + 类型收窄替代
- 禁止 `as` 断言 → 用类型收窄替代
- 禁止 `@ts-ignore`、非空断言 `!`
- 使用 `?.` 和 `??` 进行安全访问
- 仅类型导入使用 `import type`

## 导入顺序

```
1. Vue 核心 (vue, vue-router, vue-i18n)
2. 第三方库 (element-plus, echarts)
3. Stores (@/stores/modules/*)
4. API 模块 (@/api/modules/*)
5. Hooks/Utils (@/hooks/*, @/utils/*)
6. 组件 (@/components/*)
7. 类型导入 (import type { ... })
```

## 硬约束

- 页面表格**必须**使用 `ProTable`，禁止直接用 `el-table`
- Store **禁止**直接导入 `axios`/`fetch`，必须通过 `@/api/modules/*`
- 权限判断**必须**使用 `v-auth` 指令，禁止 `v-if` 内联权限
- 模板文本**必须**使用 `$t()` 国际化，禁止硬编码
