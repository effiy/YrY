# 组件开发

> ProTable/ProForm 核心组件使用模式、组件通信、复用策略、注册规范。

## 一、ProTable 列定义

ProTable 通过 `ColumnProps[]` 声明列配置，统一处理渲染、搜索、排序、格式化：

```typescript
import type { ColumnProps } from "@/components/ProTable/interface";

const columns: ColumnProps[] = [
  // 基础列
  { prop: "name", label: "名称", width: 200 },

  // 可搜索列
  { prop: "status", label: "状态", search: { el: "select" }, enum: STATUS_OPTIONS },

  // 可排序列
  { prop: "createdAt", label: "创建时间", sortable: true, width: 180 },

  // 自定义渲染
  {
    prop: "tags",
    label: "标签",
    render: (scope: { row: Item }) =>
      h("el-tag", { size: "small" }, scope.row.tags?.join(", ")),
  },

  // 操作列
  { prop: "operation", label: "操作", width: 200, fixed: "right" },
];
```

**搜索类型支持：** `input`、`select`、`date-picker`、`date-range`、`cascader`、`tree-select`

**列配置要点：**
- `width` 固定列宽，避免表格抖动
- `fixed: "right"` 固定操作列在右侧
- `minWidth` 替代 `width` 用于弹性列
- `search.el` 指定搜索控件类型
- `enum` 搭配 `search.el: "select"` 使用

## 二、ProForm 表单配置

```typescript
import type { FormItemProps } from "@/components/ProForm/interface";

const formItems: FormItemProps[] = [
  // 输入框
  { prop: "name", label: "名称", el: "input", rules: [{ required: true }] },

  // 文本域
  { prop: "description", label: "描述", el: "input", type: "textarea", rows: 4 },

  // 选择器
  { prop: "status", label: "状态", el: "select", enum: STATUS_OPTIONS },

  // 数字输入
  { prop: "priority", label: "优先级", el: "input-number", min: 1, max: 99 },

  // 开关
  { prop: "enabled", label: "启用", el: "switch" },

  // 日期
  { prop: "deadline", label: "截止日期", el: "date-picker", type: "date" },

  // 条件显隐
  {
    prop: "reason",
    label: "原因",
    el: "input",
    type: "textarea",
    hidden: (form) => form.status !== "rejected",
  },
];
```

**表单控件类型：** `input`、`input-number`、`select`、`switch`、`date-picker`、`time-picker`、`radio`、`checkbox`、`cascader`、`upload`、`slot`

**表单约束：**
- 校验规则在 `rules` 字段声明，支持 Element Plus 全部校验规则
- `hidden` 函数实现条件显隐
- `disabled` 函数实现条件禁用
- 自定义控件用 `el: "slot"` + 具名插槽

## 三、组件通信模式

| 方向 | 机制 | 场景 |
|------|------|------|
| 父 → 子 | Props (`defineProps`) | 数据传递 |
| 子 → 父 | Emits (`defineEmits`) | 事件通知 |
| 跨层级 | `provide`/`inject` | 主题、配置下发 |
| 兄弟组件 | 共享 Store 或父组件状态提升 | 状态同步 |
| 全局 | Pinia Store | 跨页面共享状态 |

```vue
<!-- 父组件 -->
<EditDialog
  :visible="dialogVisible"
  :data="currentRow"
  @close="dialogVisible = false"
  @saved="handleSaved"
/>

<!-- 子组件 -->
<script setup lang="ts">
interface Props { visible: boolean; data?: Item }
const props = withDefaults(defineProps<Props>(), { data: undefined });

const emit = defineEmits<{
  (e: "close"): void;
  (e: "saved", payload: Item): void;
}>();
</script>
```

## 四、组件注册策略

| 方式 | 适用 | 配置 |
|------|------|------|
| 全局注册 | 高频复用组件（ProTable、ProForm） | `components/index.ts` → `app.component()` |
| 局部注册 | 页面/模块内使用 | `import` 后直接使用（`<script setup>` 自动注册） |
| 自动导入 | Element Plus 组件 | `unplugin-vue-components` |

```typescript
// src/components/index.ts — 全局组件注册
import ProTable from "./ProTable/ProTable.vue";
import ProForm from "./ProForm/ProForm.vue";
import ErrorMessage from "./ErrorMessage/index.vue";

export function registerGlobalComponents(app: App) {
  app.component("ProTable", ProTable);
  app.component("ProForm", ProForm);
  app.component("ErrorMessage", ErrorMessage);
}
```

**规则：**
- 全局组件需满足：被 5 个以上页面使用
- 全局组件名使用 PascalCase
- 局部组件放在 `views/<page>/components/`

## 五、组件目录结构

```
src/components/<ComponentName>/
├── index.vue              # 入口（或 ComponentName.vue）
├── interface.ts           # Props/Emits/Slots 类型
├── hooks/                 # 组件私有 composables
│   └── useComponentLogic.ts
├── components/            # 子组件（仅此组件使用）
│   └── SubFeature.vue
└── style/                 # 组件私有样式
    └── index.scss
```

**命名规则：**
- 组件文件：`PascalCase.vue`（如 `ProTable.vue`）
- 类型文件：`interface.ts`
- 样式文件：`style/index.scss`

## 六、插槽与暴露

### 插槽模式

```vue
<!-- ProTable 暴露常用插槽 -->
<ProTable :columns="columns" :data="tableData">
  <!-- 表头操作区 -->
  <template #tableHeader>
    <el-button type="primary" @click="handleAdd">新增</el-button>
  </template>

  <!-- 列自定义内容 -->
  <template #status="scope">
    <el-tag :type="statusType(scope.row.status)">
      {{ $t(`common.status.${scope.row.status}`) }}
    </el-tag>
  </template>

  <!-- 空状态 -->
  <template #empty>
    <EmptyState :description="$t('common.empty.noData')" />
  </template>
</ProTable>
```

### `defineExpose` 暴露方法

```vue
<script setup lang="ts">
// 子组件暴露方法供父组件通过 ref 调用
const formRef = ref();

function reset() { formRef.value?.resetFields(); }
function validate() { return formRef.value?.validate(); }

defineExpose({ reset, validate });
</script>
```

**原则：** 优先通过 Props/Emits 通信，`defineExpose` 仅用于表单校验、焦点管理等必须命令式操作的场景。

## 七、组件开发约束

| 约束 | 说明 |
|------|------|
| Props 泛型声明 | `defineProps<{...}>()`，不用运行时声明 |
| Emits 泛型声明 | `defineEmits<{...}>()`，精确类型 |
| 样式隔离 | `<style lang="scss" scoped>`，变量来自 `var.scss` |
| 禁止 Options API | 仅 `<script setup lang="ts">` |
| 禁止直接 axios | 必须通过 API 模块 |
| 单一职责 | 一个组件做一件事，超过 300 行拆分 |

## 八、组件与 composable 的界线

| 场景 | 用组件 | 用 composable |
|------|--------|---------------|
| 需要渲染 DOM | 是 | 否 |
| 纯逻辑/状态管理 | 否 | 是 |
| 跨组件复用逻辑 | 否 | 是 |
| UI + 逻辑封装 | 是 | 否 |
| 生命周期管理 | 否 | 是 |
