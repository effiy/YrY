# 质量构建

> 代码质量门禁、测试策略、提交规范、构建配置。

## 质量门禁

| 阶段 | 检查 | 失败行为 |
|------|------|----------|
| 保存 | Prettier + ESLint 自动修复 | — |
| pre-commit | lint-staged (ESLint + Stylelint) | 阻止提交 |
| commit-msg | commitlint | 阻止提交 |
| CI 构建 | `vue-tsc --noEmit` | 阻止构建 |

## 工具链

ESLint 10 + Prettier 3 + Stylelint 17 + Husky 9 + lint-staged 17 + commitlint 21 + vue-tsc 2

## 测试策略

| 类型 | 框架 | 命令 |
|------|------|------|
| 类型检查 | vue-tsc | `pnpm typecheck` |
| 单元测试 | Vitest + @vue/test-utils + jsdom | `pnpm test` |
| 代码检查 | ESLint + Prettier + Stylelint | `pnpm lint` |

## 提交规范

Conventional Commits，使用 `cz-git` 交互式提交：

```
<type>: <description>
```

常用 type：`feat` / `fix` / `refactor` / `style` / `docs` / `perf` / `test` / `chore` / `ci`

**规则：** 一个功能点一个提交，不混入无关修改。提交前执行 `pnpm typecheck && pnpm lint`。

## 构建命令

| 命令 | 用途 |
|------|------|
| `pnpm dev` | 开发服务器 :8848 |
| `pnpm build:dev` | 开发环境构建 |
| `pnpm build:test` | 测试环境构建 |
| `pnpm build:pro` | 生产环境构建 |
| `pnpm preview` | 本地预览构建产物 |

环境变量使用 `RSBUILD_*` 前缀，通过 `.env.{mode}` 文件管理。
