# 页面模式

> 四种标准页面模式：列表页、表单页、搜索表单、文件上传。

## 列表页模式

标准模式：`ProTable` + `useTable` hook

```typescript
const { tableData, loading, pagination, search, refresh } = useTable({
  requestApi: queryDocuments,
  defaultParams: { cname: "my_collection" }
});
```

- 分页、排序、筛选由 ProTable 统一处理
- 搜索参数通过 `search` reactive 对象管理
- 表格列定义使用 `ColumnProps[]` 类型

## 表单页模式

标准模式：`ProForm` + 校验规则

- 表单配置使用 `FormItemProps[]` 声明式定义
- 校验规则在 formItem 的 `rules` 字段声明
- 提交逻辑在 Store 或 Hook 中封装

## 搜索表单模式

- 搜索参数与表格分页参数合并为 `SearchParams`
- 搜索按钮触发 `search.value = { ...searchParams }`
- 重置按钮清空 search reactive 并重新请求

## 文件上传模式

- 使用 Element Plus `el-upload` 组件
- 上传前校验类型和大小
- 通过 `fileService.uploadFile()` 或 `/write-file` 端点写入
