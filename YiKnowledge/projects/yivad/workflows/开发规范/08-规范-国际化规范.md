# 国际化（i18n）规范

> 从 **locale 键命名** 到 **运行时切换** — 保证多语言一致性、完整性与可维护性的完整工程规范。

## 核心原则

| 原则 | 说明 | 反模式 |
|------|------|--------|
| **零硬编码** | 所有面向用户的可见文本必须走 `$t()` / `t()` | 模板中直接写中文/英文 |
| **完整翻译** | 新增一个 locale 键必须同时提供 zh + en 两个版本 | 只加中文、漏掉英文 |
| **语义化键** | 键名按「模块 → 子模块 → 语义」层级命名 | `btn_ok`、`title1` 这类无意义短键 |
| **单向依赖** | 组件只依赖 `t()`，不直接 import locale 文件 | 在组件中 `import zh from "./zh"` |
| **动态内容** | 动态拼接使用 ICU MessageFormat（`{n}` / `{0}`） | 字符串拼接 `t("a") + count + t("b")` |

## 技术栈

```
vue-i18n 11.x（Composition API 模式，legacy: false）
  ├── locale: zh / en
  ├── fallbackLocale: en
  └── 模块命名空间：<module>/zh.ts + <module>/en.ts
```

## 键命名规范

### 三层结构

```
<module>.<subModule>.<semantic>
  │        │           │
  │        │           └── 语义：title / placeholder / confirm / empty.noData / ...
  │        └─────────────── 子模块：list / dialog / detail / tabs / stats / ...
  └──────────────────────── 模块名：project / issue / bug / common / ...
```

**示例：**

```ts
// ✅ 推荐
t("project.list.title")                 // 模块=project, 子=list, 语义=title
t("project.dialog.nameRequired")        // 项目弹窗：名称必填
t("common.confirm")                     // 公共：确认
t("issue.table.empty.noMatch")          // Issue 表格：无匹配

// ❌ 禁止
t("title")                              // 层级过浅，冲突风险大
t("project_name")                       // 以下划线代替层级
t("p.l.t")                              // 缩写无法理解
```

### 常见语义后缀速查

| 后缀 | 含义 | 示例 |
|------|------|------|
| `.title` | 区块/页面标题 | `project.list.title` |
| `.description` | 副标题/描述 | `project.list.description` |
| `.placeholder` | 输入框占位 | `project.list.searchPlaceholder` |
| `.tooltip` | 悬浮提示 | `project.list.starTooltip` |
| `.empty` / `.empty.noData` / `.empty.noMatch` | 空状态 | `project.list.empty.noProjects` |
| `.confirm` / `.cancel` / `.save` | 按钮 | `common.confirm` |
| `.xxxRequired` / `.xxxPattern` | 表单校验 | `project.dialog.nameRequired` |
| `.success` / `.fail` / `.confirm` | 操作结果 | `project.list.archiveSuccess` |
| `.count` / `.countLabel` | 带数量的文案 | `project.list.countLabel` |
| `.today` / `.yesterday` / `.tomorrow` | 相对时间 | `project.overview.activity.today` |

## ICU MessageFormat 用法

**插值**：
```ts
// locale
"countLabel": "共 {total} 个项目，显示 {shown} 个"

// 调用
t("project.list.countLabel", { total: 100, shown: 20 })
```

**复数**：
```ts
// locale — 使用 | 分隔 zero / one / other 规则
"archiveSuccess": "{n} 个项目已归档 | 1 个项目已归档 | {n} 个项目已归档"
```

**链接/HTML 片段**：使用 `@/hooks/useMarkdown` 或 `v-html` + 消毒，**不要**在 locale 中硬写 `<a>` 标签。

## 在组件中使用

### 模板中：`$t()`

```vue
<template>
  <!-- 纯文本 -->
  <h1>{{ $t("project.list.title") }}</h1>

  <!-- 属性绑定 -->
  <el-input :placeholder="$t('project.list.searchPlaceholder')" />

  <!-- 带插值 -->
  <span>{{ $t("project.list.countLabel", { total, shown }) }}</span>

  <!-- Element Plus 组件的国际化 slot（注意语言要透传） -->
  <el-empty :description="$t('project.list.empty.noProjects')" />
</template>
```

### `<script setup>` 中：`t()`

```ts
import { useI18n } from "vue-i18n";

const { t } = useI18n();

function doSomething() {
  ElMessage.success(t("project.dialog.createSuccess"));
  ElMessageBox.confirm(
    t("project.list.archiveConfirm", { n: 3 }),
    t("project.list.batch.archive"),
    { type: "warning" }
  );
}
```

### Hooks / composables 中：同样用 `useI18n`

```ts
// @/hooks/useDetailTabs.ts
export function useDetailTabs(...) {
  const { t } = useI18n();              // ✅ 每次调用 hook 时都能拿到最新 locale
  return computed(() => [
    { name: "overview", label: t("project.detail.tabs.overview") },
    // ...
  ]);
}
```

### 路由/菜单中：`useMenuI18n` + `translateTitle`

```ts
import { useMenuI18n } from "@/hooks/useMenuI18n";

const { translateTitle } = useMenuI18n();
// 优先查找 menuTitles.<name>，找不到就回退到 fallback
const title = translateTitle(menu.name, menu.name);
```

### ElMessage / ElNotification 等

```ts
// ✅ 正确：把 t() 直接塞进 El* 选项
ElNotification({
  title: t("common.noPermission"),
  message: t("common.noPermissionMsg"),
  type: "warning"
});

// ❌ 错误：直接写字符串
ElMessage.success("创建成功");
```

## 新增 locale 键的标准流程

1. **定位模块**：确定文本属于哪个页面/组件，选择对应 `languages/modules/<name>/`
2. **双写 zh + en**：同时编辑 `zh.ts` 和 `en.ts`，保持完全相同的对象结构
3. **校验层级**：键名遵守 `module.subModule.semantic`，不要出现新的顶级键
4. **开发模式查缺**：`NODE_ENV !== "production"` 时 `missingWarn` 会在控制台打印缺失键 —— CI 前必须清零
5. **回归**：切换语言（中文 ⇄ 英文）至少走一遍涉及的页面

> 💡 快捷键：在 IDE 中搜索「国际化规范」跳到本文件顶部的 **常见语义后缀速查表** 快速选名字。

## 新增模块 locale 的步骤

例：新增 `foo` 模块。

```bash
YiVad/src/languages/modules/
  ├── foo/
  │   ├── zh.ts      # export default { foo: { ... } }
  │   └── en.ts      # export default { foo: { ... } }
  └── index.ts       # import 两个文件，展开进 zh {} / en {}
```

`modules/index.ts` 中添加：

```ts
import zhFoo from "./foo/zh";
import enFoo from "./foo/en";

export const messages = {
  zh: {
    // ...
    ...zhFoo,        // 不要漏这一行
  },
  en: {
    // ...
    ...enFoo,        // 也不要漏这一行
  }
};
```

## 语言切换机制

### 用户交互（顶部 Language.vue）

```ts
const i18n = useI18n();
const globalStore = useGlobalStore();

function changeLanguage(lang: "zh" | "en") {
  i18n.locale.value = lang;                        // 1) 立即驱动所有 $t() 重算
  globalStore.setGlobalState("language", lang);    // 2) 持久化到 localStorage
}
```

### 启动时默认值

```ts
// languages/index.ts
import { getBrowserLang } from "@/utils";

const i18n = createI18n({
  legacy: false,
  locale: getBrowserLang(),                        // 浏览器语言 → zh / en
  fallbackLocale: "en",                            // 缺翻译时的兜底
  missingWarn: process.env.NODE_ENV !== "production",
  fallbackWarn: process.env.NODE_ENV !== "production",
  messages
});
```

`getBrowserLang` 会归一化：
- `zh-CN` / `zh` / `cn` / `zh-cn` → `zh`
- 其他 → `en`

## 完整性与一致性校验

### 开发期：`missingWarn` / `fallbackWarn`

开发环境打开浏览器控制台，如果出现：

```
[intlify] Not found 'project.xxx' key in 'zh' locale messages.
[intlify] Fall back to translate 'project.xxx' key with 'en' locale.
```

→ 说明你漏了 zh.ts 的键，**必须补齐**再提交。

### 静态结构 diff

CI 可执行一个小型校验脚本，断言：
1. `messages.zh` 与 `messages.en` 的键路径集合完全一致
2. 所有含 `{n}`、`{total}` 等占位符的键，zh / en 占位符名称完全一致
3. 没有以 `test` / `tmp` / `foo` 等无意义词开头的键

### 代码审查 checklist

PR 中若涉及 UI 文本变更，审查者必须确认：

- [ ] 没有硬编码中/英文字符串出现在 `<template>` 或 `ElMessage` 中
- [ ] 新增 locale 键同时提供 zh + en
- [ ] 键名层级合理（遵循 `module.subModule.semantic`）
- [ ] 动态拼接使用 `{param}` 而不是 JS 字符串拼接
- [ ] 表格列标题、Tab 标签、空状态、校验消息这些「容易漏」的位置都有翻译

## 硬编码排查指引

### 正则搜中文（含模板 + TS）

```bash
# 在 YiVad/src 下搜裸中文字符串（排除注释的难度较高，需结合上下文）
rg '"[^"]*[\u4e00-\u9fa5][^"]*"' src/
rg "'[^']*[\u4e00-\u9fa5][^']*'" src/
```

### 正则搜模板内裸中文

```bash
rg '>\s*[\u4e00-\u9fa5]' src/**/*.vue
```

### 常见「漏网之鱼」

| 位置 | 为什么容易漏 | 修复方式 |
|------|-------------|----------|
| `<el-option label="中文">` | 写在属性里 | `:label="$t('xxx')"` |
| `<el-tooltip content="中文">` | 同上 | `:content="$t('xxx')"` |
| `rules: [{ message: "..." }]` | 写在 TS 对象里 | `message: t("xxx")` 或直接用 computed |
| `console.error("出错了")` | 不面向用户，原则上可以不翻译，但建议国际化到 common.error 下 | 视情况 |
| Tab 标签数组 | 在 hook 中通过 computed + t() 生成，不要写死字符串 | 参考 `useDetailTabs.ts` |
| 路由 `meta.title` | 在动态路由装配时用 `translateTitle()` 翻译 | 参考 `dynamicRouter.ts` + `useMenuI18n.ts` |
| 相对时间 "今天"/"昨天" | Activity 时间线里常硬编码 | locale 中定义 `.today` / `.yesterday` / `.unknownDate` |

## 常见陷阱

### ❌ 在顶层作用域调用 `t()`

```ts
// ❌ 错误：脚本加载时语言还没切，之后切换不会更新
const TITLE = t("project.list.title");

// ✅ 正确：用 computed 保持响应式
const title = computed(() => t("project.list.title"));
```

### ❌ 用 JS 拼接翻译

```ts
// ❌ 中英文语序不同会出错
t("common.successPrefix") + count + t("common.successSuffix");

// ✅ 用 MessageFormat
t("project.list.archiveSuccess", { n: 5 });
```

### ❌ 复用「看起来一样」的键

```ts
// ❌ "确认" 在确认框和菜单里英文可能不同
t("common.confirm")  // 不要在所有场景都用同一个

// ✅ 语义分开
t("project.dialog.confirmDelete")   // Confirm Delete
t("common.confirm")                 // OK / Confirm
```

### ❌ 把枚举值直接 `t(status)`

```ts
// ❌ status = "active" 可能映射到不同模块的不同单词
t(status)

// ✅ 命名空间
t(`project.dialog.status${capitalize(status)}`)  // statusActive / statusArchived
```

## 性能与体积

- `createI18n` 的 `messages` 默认打包进主 chunk；模块 >15 个时可按 locale 分包懒加载（`i18n.global.setLocaleMessage`）
- 单个 locale 文件不要超过 500 行；超过就继续按子模块拆分
- **不要**把大段 Markdown 塞 locale；对于文档/说明类文本，用 `KnowledgePreviewDialog` + 真实 `.md` 文件，走知识库国际化目录

## FAQ

**Q：后端返回的枚举（status、role）要翻译吗？**  
A：前端统一维护 `dict.<name>.<value>`，后端返回原始值，前端用字典 lookup 渲染。不要让后端直接返回中文/英文。

**Q：新增一个语言（比如 ja-JP）要改哪些地方？**  
A：1) `Language.vue` 的下拉选项；2) `getBrowserLang` 的归一化；3) 新建 `modules/*/ja.ts`；4) `messages` 中加 `ja` key。

**Q：`$t("a.b.c")` 没找到会怎么样？**  
A：dev 环境打印 warning，fallback 到 en；en 也没有就返回 `"a.b.c"` 本身（非常显眼，容易发现）。

**Q：日期、数字、货币怎么本地化？**  
A：使用 [Intl.DateTimeFormat](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat) / [Intl.NumberFormat](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat)，参考 `@/utils/datetime.ts`。
