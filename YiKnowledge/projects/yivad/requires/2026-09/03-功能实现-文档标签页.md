## 二、搜索与过滤

| 功能 | 实现方式 | 说明 |
|------|----------|------|
| 文件名搜索 | `docSearch` ref + `filteredDocItems` computed | `title` 字段 `includes` 模糊匹配，大小写不敏感 |
| 标签过滤 | `docTagFilter` ref + 标签下拉选择 | 单选，默认 "全部" |
| 排序切换 | `docSortBy` ref (`"title"` / `"updatedAt"`) | 点击列头切换，默认 `updatedAt` 降序 |

## 三、预览交互

| 文档类型 | 数据来源 | 预览方式 | 原因 |
|---------|---------|---------|------|
| 普通 .md 文档 | `knowledgeFiles`（知识库文件树） | `open(path)` | 文件在知识库中，可直接通过路径预览 |
| CLAUDE.md | `readProjectFile` API | `openRaw({ title, content })` | CLAUDE.md 不在知识库文档目录下，需通过文件 API 读取 |

- 复用现有 `KnowledgePreviewDialog` 组件
- 普通文档：调用 `previewDlgRef.value?.open(filePath)` 直接预览
- CLAUDE.md：先调用 `readProjectFile(projectKey, "CLAUDE.md")` 获取内容，再 `previewDlgRef.value?.openRaw({ title, content })`

## 四、空状态设计

| 场景 | 显示内容 |
|------|----------|
| 无 `文档/` 目录下的 `.md` 文件 | `el-empty description="No documentation files"` |
| 有文档文件（含 CLAUDE.md） | 表格正常渲染 |
| `knowledgeFiles` 未加载 | 不渲染（由父级 loading 状态处理） |
| 搜索无匹配 | `el-empty description="无匹配文档"` |
| 标签过滤无匹配 | `el-empty description="该标签下无文档"` |

> `docItems.length > 1` 作为渲染条件，因为 CLAUDE.md 总是被 `unshift` 到列表头部。仅 CLAUDE.md 而无其他文档时仍显示空状态。

## 1. 文档列表计算逻辑（DetailDocs.vue）

```ts
const docItems = computed<DocItem[]>(() => {
  const key = props.project?.key || ''
  const prefix = `projects/${key}/文档/`
  const items = props.knowledgeFiles
    .filter(f => f.path.startsWith(prefix) && f.path.endsWith('.md'))
    .map(f => {
      const rel = f.path.slice(prefix.length)
      const tag = rel.split('/')[0] || 'unknown'
      return {
        title: (f.meta?.title as string) || f.name.replace(/\.md$/, ''),
        path: f.path,
        tag,
        updatedAt: (f.meta?.updated as string) || '',
        isSpecial: false,
      }
    })
    .sort((a, b) => (b.updatedAt || '').localeCompare(a.updatedAt || ''))

  // CLAUDE.md 始终置顶
  items.unshift({
    title: 'CLAUDE.md',
    path: 'CLAUDE.md',
    tag: 'ai-guide',
    updatedAt: '',
    isSpecial: true,
  })
  return items
})
```

### 搜索与过滤

```ts
const docSearch = ref('')
const docTagFilter = ref('')
const docSortBy = ref<'title' | 'updatedAt'>('updatedAt')

const filteredDocItems = computed(() => {
  let list = docItems.value

  // 搜索过滤
  if (docSearch.value) {
    const q = docSearch.value.toLowerCase()
    list = list.filter(d => d.title.toLowerCase().includes(q))
  }

  // 标签过滤
  if (docTagFilter.value) {
    list = list.filter(d => d.tag === docTagFilter.value)
  }

  // 排序
  if (docSortBy.value === 'title') {
    list = [...list].sort((a, b) => a.title.localeCompare(b.title))
  }
  // updatedAt 降序已在 docItems 中处理

  return list
})
```

## 4. CLAUDE.md 特殊处理

### 加载流程

```
点击 CLAUDE.md 行
  ├── 1. claudeLoading = true（行内 loading spinner）
  ├── 2. readProjectFile(project.key, "CLAUDE.md")
  │     ├── 成功 → previewDlgRef.value?.openRaw({ title: "CLAUDE.md", content })
  │     └── 失败 → ElMessage.warning("Failed to load CLAUDE.md")
  └── 3. claudeLoading = false
```

### 与普通文档的差异

| 维度 | 普通文档 | CLAUDE.md |
|------|----------|-----------|
| 数据来源 | `knowledgeFiles`（已在内存） | `readProjectFile` API（需网络请求） |
| 预览方式 | `open(path)` — 同步 | `openRaw({ title, content })` — 需等待 API |
| 加载状态 | 无需（数据已就绪） | 需要 loading 状态 |
| 错误处理 | 无需（路径已验证） | 需要 error 提示 |
| 列表位置 | 按 `updatedAt` 排序 | 始终置顶 |
| 视觉区分 | 普通行样式 | 左侧 `ai-guide` 标签 + 特殊图标 |

## 实现注意事项

### 空状态判断

`docItems.length > 1` 作为渲染条件（而非 `> 0`），避免只有一行 CLAUDE.md 的尴尬表格。

### 样式一致性

与 Requirements Tab 保持视觉一致：相同的表格样式、间距、字体大小。复用 `DetailRequirements.vue` 中的 SCSS 变量和 mixin。

### 性能

| 场景 | 策略 |
|------|------|
| 大量文档文件（>100） | `el-table` 默认启用虚拟滚动，无需额外处理 |
| CLAUDE.md 加载失败 | 显示 warning 提示，不阻塞其他文档的预览 |
| 重复点击同一文档 | 每次打开预览弹窗，不复用缓存（内容可能已更新） |
| 知识库文件列表更新 | `knowledgeFiles` prop 变化时，`docItems` computed 自动重算 |
| 搜索输入 | 使用 `debounce` 300ms 防抖，避免频繁 computed 重算 |
