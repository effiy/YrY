# Project 页面国际化

> 需求编号：YV-09-01-6 · 优先级：P1 · 人天：1.0d · 状态：已完成
> 依赖：YV-09-01-1 (组件拆分完成后才能统一替换)
> 模块：`src/languages/modules/project/`

## 背景

当前 Project 页面所有文案均为硬编码英文，不符合 YiVad 已建立的中英双语 i18n 规范（vue-i18n 11，已有 kanban/story/home 等模块先例）。本需求为 Project 页面创建 `project` i18n 模块，覆盖列表页和详情页的全部文案。

# 技术方案

## Key 命名规范

遵循现有模块惯例：`project.<区域>.<含义>`，嵌套层级不超过 4 层。

| 命名空间 | 覆盖范围 | 示例 Key |
|----------|---------|---------|
| `project.list.*` | 列表页：标题、搜索、排序、过滤、空状态、批量操作 | `project.list.title`, `project.list.empty.noProjects` |
| `project.stats.*` | 统计卡片：Issue 计数、完成率 | `project.stats.issues`, `project.stats.done` |
| `project.analytics.*` | 图表：状态分布、优先级分布、活跃度 | `project.analytics.statusDistribution` |
| `project.risks.*` | 风险标记：逾期、停滞、未分配 | `project.risks.overdue`, `project.risks.health.good` |
| `project.filters.*` | 过滤维度标签 | `project.filters.dimension.status` |
| `project.dialog.*` | 创建/编辑对话框 | `project.dialog.createTitle`, `project.dialog.nameRequired` |
| `project.detail.*` | 详情页框架：Tab 标签、返回按钮 | `project.detail.tabs.overview` |
| `project.overview.*` | Overview Tab | `project.overview.readme.noFile` |
| `project.requirements.*` | Requirements Tab | `project.requirements.stats.total` |
| `project.members.*` | Members Tab | `project.members.addMember` |
| `project.docs.*` | Docs Tab | `project.docs.empty` |
| `project.error.*` | 错误提示 | `project.error.loadOverview` |

### 命名检查清单

- [ ] 使用 `.` 分隔层级，不超过 4 层
- [ ] 使用 `camelCase` 命名末尾段
- [ ] 布尔/状态类使用形容词（`empty`, `active`, `visible`）
- [ ] 动作类使用动词开头（`addMember`, `clearFilters`）
- [ ] 带参数的使用 `{}` 占位符（`{n}`, `{date}`, `{username}`）
- [ ] 避免 Key 中包含业务数据（如项目名、用户名）

## 文案替换模式

### 1. 静态文案

```html
<!-- 之前 -->
<span>New Project</span>
<el-button>Export CSV</el-button>

<!-- 之后 -->
<span>{{ $t("project.list.newProject") }}</span>
<el-button>{{ $t("project.list.export") }}</el-button>
```

### 2. 带参数文案

```html
<!-- 之前 -->
<span>{{ filtered.length }} of {{ projects.length }} projects</span>

<!-- 之后 -->
<span>{{ $t("project.list.countLabel", { shown: filtered.length, total: projects.length }) }}</span>
```

### 3. 属性中的文案

```html
<!-- 之前 -->
<el-input placeholder="Search projects..." />
<el-table-column label="Status" />

<!-- 之后 -->
<el-input :placeholder="$t('project.list.searchPlaceholder')" />
<el-table-column :label="$t('project.requirements.table.status')" />
```

### 4. 动态 Key 拼接

```typescript
// 排序选项
const sortOptions = [
  { label: t("project.list.sortBy.updated"), value: "updated" },
  { label: t("project.list.sortBy.name"), value: "name" },
  { label: t("project.list.sortBy.issues"), value: "issues" },
];

// 或使用 computed 动态拼接
const sortLabel = computed(() => t(`project.list.sortBy.${sortBy.value}`));
```

> 使用动态 key 拼接时，确保拼接结果在语言文件中存在。缺失 key 时 vue-i18n 回退到 key 本身，不会报错。

### 5. ECharts 图表文案

```typescript
// chartOptions 必须为 computed 以响应语言切换
const { t, locale } = useI18n();

const chartOptions = computed(() => ({
  title: { text: t("project.analytics.statusDistribution") },
  tooltip: { trigger: "item" },
  series: [{
    data: [
      { name: t("project.analytics.open"), value: openCount },
      { name: t("project.analytics.done"), value: doneCount },
    ],
  }],
}));

// 语言切换时重新 setOption
watch(() => locale.value, () => {
  chartInstance?.setOption(chartOptions.value, true); // true = notMerge
});
```

### 6. 脚本中的文案（ElMessage / ElMessageBox）

```typescript
// 之前
ElMessage.success("Project created");
ElMessageBox.confirm(`Archive ${n} projects?`);

// 之后
ElMessage.success(t("project.dialog.createSuccess"));
ElMessageBox.confirm(t("project.list.archiveConfirm", { n }));
```

## 实现注意事项

### 不翻译的 Key

以下 Key 在两种语言中保持英文（文件名、技术术语）：

| Key | 值 | 原因 |
|-----|-----|------|
| `project.overview.readme.title` | `README.md` | 文件名，不翻译 |
| `project.requirements.table.prd` | `PRD` | 业务缩写，中英一致 |
| `project.list.export` | `Export CSV` / `导出 CSV` | `CSV` 保持英文，前缀翻译 |

### 单复数处理

- 英文：使用 `(s)` 语法，如 `{n} project(s)`
- 中文：量词不变化，如 `{n} 个项目`
- 不复用 vue-i18n 复数规则（`|` 管道语法），保持与现有模块一致

### 图表库文案（ECharts）

`chartOptions` 需为 `computed` 以响应语言切换。ECharts 实例需在 `watch` 语言变化时调用 `setOption` 重新设置：

```typescript
const { t, locale } = useI18n();

const chartOptions = computed(() => ({
  title: { text: t("project.analytics.statusDistribution") },
  tooltip: { trigger: "item" },
  series: [{
    data: [
      { name: t("project.analytics.open"), value: openCount },
      { name: t("project.analytics.done"), value: doneCount },
    ],
  }],
}));

watch(() => locale.value, () => {
  chartInstance?.setOption(chartOptions.value, true); // true = notMerge，完全替换
});
```

### 动态 Key 安全性

```typescript
// 安全：排序选项的 value 与 key 后缀一一对应，不会产生不存在的 key
const sortBy = ref<"updated" | "name" | "issues" | "done" | "risk">("updated");
const sortLabel = computed(() => t(`project.list.sortBy.${sortBy.value}`));

// 不安全：用户输入或后端数据不应直接拼接到 i18n key 中
// ❌ t(`project.status.${userInput}`)  — userInput 可能不在语言文件中
```

### 迁移策略

1. **先创建语言文件**：`en.ts` 和 `zh.ts`，包含所有 ~136 个 Key
2. **注册模块**：在 `modules/index.ts` 中添加 import 和注册
3. **逐文件替换**：从简单组件开始（DetailDocs → DetailMembers → ... → index.vue）
4. **每文件替换后验证**：切换语言，检查该文件涉及的文案

### 迁移前后对比

| 指标 | 迁移前 | 迁移后 |
|------|--------|--------|
| 硬编码文案 | ~136 处 | 0 处 |
| 语言支持 | 仅英文 | 中英双语 |
| 新增语言成本 | 需改动所有组件文件 | 仅需新增语言包文件 |
| 文案一致性 | 散落各组件，难以统一修改 | 集中在 `project/` 语言包 |
| 语言切换 | 不支持 | vue-i18n 即时切换，无刷新 |
