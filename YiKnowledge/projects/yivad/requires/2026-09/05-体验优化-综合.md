### 实现方案

**DetailOverview.vue — 状态管理：**

```typescript
const loading = ref(false)
const error = ref<string | null>(null)
const dataLoaded = ref(false)

async function loadData() {
  if (dataLoaded.value) return // 缓存命中
  loading.value = true
  error.value = null
  try {
    await loadWithTimeout(Promise.all([loadOverviewStats(), loadDescFile()]), 10_000)
    dataLoaded.value = true
  } catch (e) {
    error.value = e instanceof Error ? e.message : 'Failed to load overview data'
  } finally {
    loading.value = false
  }
}

onMounted(() => loadData())

watch(() => props.filterDateStr, () => {
  dataLoaded.value = false
  loadData()
})
```

**loadWithTimeout 工具函数：**

```typescript
async function loadWithTimeout<T>(promise: Promise<T>, ms = 10_000): Promise<T> {
  const timeout = new Promise<never>((_, reject) =>
    setTimeout(() => reject(new Error('Request timeout')), ms)
  )
  return Promise.race([promise, timeout])
}
```

**detail.vue — 移除全局 spinner：**

```html
<!-- 改前 -->

</el-tabs>

<!-- 改后 -->

  <!-- 各 Tab 自行管理加载状态 -->
</el-tabs>
```

### 缓存生命周期

| 事件 | dataLoaded | loading | error | 行为 |
|------|-----------|---------|-------|------|
| 组件首次挂载 | `false` | `true` | `null` | 显示 skeleton → 加载 |
| 加载成功 | `true` | `false` | `null` | 正常渲染 |
| 加载失败 | `false` | `false` | `"message"` | 显示错误卡片 + Try Again |
| 点击 Try Again | `false` | `true` | `null` | 重新加载 |
| 切换到其他 Tab 再切回 | `true` | `false` | `null` | 缓存命中，直接渲染 |
| `filterDateStr` 变化 | `false` | `true` | `null` | 清除缓存 → 重新加载 |

### 与其他 Tab 的隔离

| Tab | 加载状态来源 | 与 Overview 的关系 |
|-----|-------------|-------------------|
| Issues/Modules/Bugs | 各自组件内部管理 | 完全独立 |
| Requirements/Docs | 依赖 `knowledgeFiles` prop | `knowledgeFiles` 由 detail.vue 加载，与 Overview 无关 |
| Members | `project.members` 即时可用 | 无加载状态 |

## 过滤状态持久化 (YV-09-01-7, 0.5d)

### 现状问题

| 问题 | 影响 | 严重程度 |
|------|------|----------|
| 页面刷新后过滤/排序/视图状态丢失 | 用户每次刷新需重新设置偏好 | 中 |
| 分享 URL 不携带过滤状态 | 无法通过链接分享特定过滤视图 | 低 |
| 过滤状态与用户偏好混在一起 | 语义不清，难以区分"可分享"和"个人偏好" | 低 |

### 双通道持久化策略

| 通道 | 存储内容 | 生命周期 | 适用场景 |
|------|----------|----------|----------|
| **URL query** | 搜索关键词、过滤条件、日期、排序 | 当前标签页 | 可分享的视图状态 |
| **localStorage** | 视图模式、排序偏好、Starred 筛选、Analytics 展开 | 跨会话 | 个人偏好，不应污染 URL |

### 实现方案

**URL query 通道（可分享状态）：**

```typescript
// index.vue — 从 URL 恢复状态
const route = useRoute();
const router = useRouter();

// 搜索关键词 → URL ?q=xxx
const searchText = ref((route.query.q as string) || "");

// 过滤状态 → URL ?filter=status:active,risk:overdue
function syncFilterToUrl(filter: FilterState) {
  const parts = Object.entries(filter).map(([k, v]) => `${k}:${v}`);
  router.replace({ query: { ...route.query, filter: parts.join(",") || undefined } });
}

// 日期过滤 → URL ?date=2026-09-04
watch(filterDateStr, (date) => {
  router.replace({ query: { ...route.query, date: date || undefined } });
});
```

**localStorage 通道（个人偏好）：**

当前已实现，使用 `@/utils/storage` 工具函数：

```typescript
const PREF = {
  view: "project.viewMode",        // grid | list
  sort: "project.sortBy",          // updated | name | issues | done | risk
  starred: "project.starredOnly",   // boolean
  analytics: "project.analyticsExpanded" // boolean
};

const viewMode = ref(loadStr(PREF.view, "grid") === "list" ? "list" : "grid");
const sortBy = ref(loadStr(PREF.sort, "updated"));
const showStarredOnly = ref(loadBool(PREF.starred, false));
const analyticsExpanded = ref(loadBool(PREF.analytics, true));

watch(viewMode, v => saveStr(PREF.view, v));
watch(sortBy, v => saveStr(PREF.sort, v));
watch(showStarredOnly, v => saveBool(PREF.starred, v));
watch(analyticsExpanded, v => saveBool(PREF.analytics, v));
```

### 状态恢复优先级

```
页面加载
  ├── 1. URL query 参数（最高优先级，覆盖 localStorage）
  │     ?q=xxx → searchText
  │     ?filter=status:active → activeFilter
  │     ?date=2026-09-04 → filterDate
  │     ?sort=issues&dir=asc → sortBy + sortDir
  ├── 2. localStorage（URL 无对应参数时使用）
  │     project.viewMode → viewMode
```

### 实现方案

**通用快捷键 Hook：**

```typescript
// src/hooks/useKeyboardShortcuts.ts
import { onMounted, onBeforeUnmount } from "vue";

interface Shortcut {
  key: string;
  handler: () => void;
  ctrl?: boolean;
  meta?: boolean;
}

export function useKeyboardShortcuts(shortcuts: Shortcut[]) {
  function onKeydown(e: KeyboardEvent) {
    // 在 input/textarea 中不触发快捷键（除 Escape）
    const tag = (e.target as HTMLElement)?.tagName;
    const isInput = tag === "INPUT" || tag === "TEXTAREA" || tag === "SELECT";
    if (isInput && e.key !== "Escape") return;

    for (const s of shortcuts) {
      const ctrlMatch = s.ctrl ? (e.ctrlKey || e.metaKey) : true;
      const metaMatch = s.meta ? (e.ctrlKey || e.metaKey) : true;
      if (e.key === s.key && ctrlMatch && metaMatch) {
        e.preventDefault();
        s.handler();
        return;
      }
    }
  }

  onMounted(() => window.addEventListener("keydown", onKeydown));
  onBeforeUnmount(() => window.removeEventListener("keydown", onKeydown));
}
```

## 实现注意事项

### 与现有构建流程的关系

- 不涉及新依赖，无需修改 `package.json`
- `vue-tsc --noEmit` 需通过
- `useKeyboardShortcuts` hook 为通用工具，放在 `src/hooks/` 下供其他页面复用

### URL 持久化注意事项

- 使用 `router.replace`（非 `router.push`）避免产生冗余历史记录
- 过滤条件编码使用 `key:value` 逗号分隔格式，简单可读
- 空过滤时移除 `filter` 参数而非保留空字符串

### 快捷键冲突处理

- 在 `input/textarea/select` 元素中，除 `Escape` 外不触发快捷键
- 详情页 `1-6` 快捷键与 Element Plus Tab 组件无冲突（Tab 切换不依赖数字键）
