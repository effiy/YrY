> 需求编号：YV-09-01-1 · 优先级：P0 · 人天：2.0d

# 技术方案

> 所有共享数据由 `detail.vue` 通过 props 单向传递，子组件通过 emits 向上通知。不引入 `provide/inject`。

## 组件接口协议

### Props 映射

| 共享数据 | 类型 | 来源 | 消费方 |
|----------|------|------|--------|
| `project` | `Project` | `useProjectStore.currentProject` | Overview, Requirements, Members, Docs |
| `knowledgeFiles` | `KnowledgeFileEntry[]` | `listKnowledgeFiles` API | Overview, Requirements, Docs |
| `filterDate` | `Date \| null` | `useDateFilter` | Overview |
| `filterDateStr` | `string` | `useDateFilter` (computed) | Overview |
| `previewDlgRef` | `Ref<KnowledgePreviewDialog \| null>` | detail.vue 模板引用 | Overview, Requirements, Docs |
| `allIssues` | `Issue[]` | `getIssueList` API | Overview |

### Emits 映射

| 事件 | 来源组件 | 载荷 | 说明 |
|------|---------|------|------|
| `navigate` | DetailOverview | `tab: string` | 请求切换到其他 Tab |
| `update:members` | DetailMembers | `members: ProjectMember[]` | 成员增删后通知父级更新 |

### 各组件规格总览

| 组件 | Props | Emits | 内部状态 (ref/reactive) |
|------|-------|-------|----------------------|
| DetailOverview | `project`, `filterDate`, `filterDateStr`, `knowledgeFiles`, `previewDlgRef`, `allIssues` | `navigate` | `loading`, `error`, `dataLoaded`, `overviewStats`, `overviewModules`, `overviewActivity`, `descContent`, `descMeta` |
| DetailRequirements | `project`, `knowledgeFiles`, `previewDlgRef` | — | `reqStatusFilter`, `reqSearch`, `requireItems`(c), `reqStatusCounts`(c), `reqStats`(c), `filteredRequireItems`(c) |
| DetailMembers | `project` | `update:members` | `memberDialog: { visible, submitting, username, role }` |
| DetailDocs | `project`, `knowledgeFiles` | — | `docItems`(c) |

> (c) = computed，无独立 ref 声明。

### 关键实现细节

| # | 关注点 | 实现方式 |
|---|--------|---------|
| 1 | 数据加载时机 | `onMounted` 时加载，`watch(filterDateStr)` 变化时重新加载 |
| 2 | 缓存策略 | `dataLoaded` 标志位，切换 Tab 后回来不重新加载 |
| 3 | README.md 加载 | 调用 `readProjectFile(project.key, "README.md")`，失败时回退到 `project.description` |
| 4 | 模块 Issue 标题映射 | 通过 `issueTitleMap` 查找模块关联 Issue 的标题和状态 |
| 5 | 活动颜色 | `activityColor(type)` — issue→`#409eff`, module→`#9b59b6`, bug→`#f56c6c` |
| 6 | 优先级颜色 | `priorityColor(p)` — urgent→`#f56c6c`, high→`#e6a23c`, medium→`#409eff`, low→`#909399` |

### 数据加载逻辑

```typescript
const loading = ref(false)
const error = ref<string | null>(null)
const dataLoaded = ref(false)

const loadData = async () => {
  if (dataLoaded.value) return // 缓存命中

  loading.value = true
  error.value = null

  try {
    const [stats, desc] = await Promise.all([
      loadOverviewStats(),
      loadDescFile(),
    ])
    overviewStats.value = stats
    descContent.value = desc.content
    descMeta.value = desc.meta
    dataLoaded.value = true
  } catch (e: any) {
    error.value = e.message || 'Failed to load overview data'
  } finally {
    loading.value = false
  }
}

onMounted(() => loadData())

// 日期过滤变化时重新加载
watch(filterDateStr, () => {
  dataLoaded.value = false
  loadData()
})
```

### README.md 加载

```typescript
const loadDescFile = async () => {
  try {
    const res = await readProjectFile(props.project.key, 'README.md')
    return { content: res.content, meta: res.meta }
  } catch {
    // 回退到 project.description
    return { content: props.project.description || '', meta: null }
  }
}
```

### 边界条件

| 场景 | 处理方式 |
|------|---------|
| `project` 为 null | 不渲染（由父级 `v-if="project"` 保证） |
| `descContent` 为空 | 显示 "No README.md found" 空状态 |
| `overviewModules` 为空 | 显示 "No modules" 空状态 |
| `overviewActivity` 为空 | 显示 "No recent activity" 空状态 |
| README.md 加载失败 | 回退到 `project.description` 渲染 |
| 快速切换 Tab 后回来 | `dataLoaded` 缓存，不重复请求 |

### 搜索与过滤

```typescript
const reqStatusFilter = ref<string | null>(null)
const reqSearch = ref('')

// 搜索字段：title / assignee / prd_task_id，大小写不敏感，与状态过滤叠加（AND）
const filteredRequireItems = computed(() => {
  let items = requireItems.value
  if (reqStatusFilter.value) {
    items = items.filter(i => i.status === reqStatusFilter.value)
  }
  if (reqSearch.value) {
    const q = reqSearch.value.toLowerCase()
    items = items.filter(i =>
      i.title.toLowerCase().includes(q) ||
      i.assignee.toLowerCase().includes(q) ||
      i.prd_task_id.toLowerCase().includes(q)
    )
  }
  return items
})
```

### 添加/删除成员

```typescript
const memberDialog = reactive({
  visible: false,
  submitting: false,
  username: '',
  role: 'member' as MemberRole,
})

const handleAddMember = async () => {
  memberDialog.submitting = true
  try {
    const newMember: ProjectMember = {
      username: memberDialog.username,
      role: memberDialog.role,
    }
    const updated = [...props.project.members, newMember]
    await store.editProject(props.project.key, { members: updated })
    emit('update:members', updated)
    memberDialog.visible = false
  } finally {
    memberDialog.submitting = false
  }
}

const handleRemoveMember = async (username: string) => {
  const updated = props.project.members.filter(m => m.username !== username)
  await store.editProject(props.project.key, { members: updated })
  emit('update:members', updated)
}
```

## 组件懒加载策略

采用条件渲染 + `visitedTabs` 追踪策略，首屏 Tab 直接渲染，非首屏 Tab 首次访问后才渲染：

```typescript
const visitedTabs = ref(new Set<string>(['overview']))

watch(activeTab, (tab) => {
  visitedTabs.value.add(tab)
})
```

| 策略 | 说明 |
|------|------|
| 首屏 Tab (Overview) | 直接渲染，不懒加载 |
| 非首屏 Tab | 首次访问后 `visitedTabs.add(tab)`，之后保持渲染 |
| 不采用 `defineAsyncComponent` | 拆分后组件体积小（≤400 行），异步加载的收益不如条件渲染 |

## 实现注意事项

### 拆分顺序

1. **先拆分简单组件**（DetailMembers → DetailDocs → DetailRequirements → DetailOverview）
2. **每拆分一个，立即验证**：dev server 对比原 detail.vue 对应 Tab 的渲染效果
3. **最后精简 detail.vue**：所有 Tab 组件就位后，删除内联代码

### 样式处理

- 各组件使用 `<style scoped>` 避免样式泄漏
- 公共 markdown 样式使用 `@include markdown-preview` mixin
- 从 detail.vue 中删除原有的 70 行非 scoped markdown 样式

### 样式迁移映射

| 原 detail.vue 样式块 | 迁移目标 |
|---------------------|---------|
| `.overview-*` 系列 | DetailOverview.vue `<style scoped>` |
| `.requirements-*` 系列 | DetailRequirements.vue `<style scoped>` |
| `.members-*` 系列 | DetailMembers.vue `<style scoped>` |
| `.markdown-preview` 公共样式 | 保留为全局 mixin，各组件 `@include` |
| `.project-detail` 框架样式 | 保留在 detail.vue |

### 模板引用传递

`previewDlgRef` 作为模板引用通过 props 传递。注意 Vue 3 中模板引用的类型为 `Ref<ComponentPublicInstance | null>`，需使用 `InstanceType<typeof KnowledgePreviewDialog>` 进行类型标注。

### 组件通信

- **父 → 子**：通过 props 传递共享数据，单向数据流
- **子 → 父**：DetailOverview 通过 `emit("navigate", tab)` 请求切换 Tab；DetailMembers 通过 `emit("update:members", members)` 通知成员变更
- **跨组件**：`previewDlgRef` 通过 props 传递模板引用

### 错误边界

- 每个 Tab 组件独立处理自身加载失败，不波及其他 Tab
- 父级 detail.vue 仅处理项目不存在（404）的全局错误
- `onErrorCaptured` 钩子可用于捕获子组件渲染异常

### 边界情况

| 场景 | 处理方式 |
|------|---------|
| 项目不存在 | detail.vue 展示 `el-result` 错误状态 |
| 项目无成员 | DetailMembers 展示空状态，允许添加第一个成员 |
| 项目无需求文件 | DetailRequirements 展示空状态 |
| README.md 不存在 | DetailOverview 回退到 `project.description` |
| 日期过滤下无数据 | 各组件正常渲染空列表，不报错 |
| 快速切换 Tab | Vue 条件渲染，未访问的 Tab 不渲染，无性能问题 |
| 浏览器后退 | Vue Router 自动恢复 `?tab=` 参数，`onMounted` 中还原 |
