# 暗色主题切换

> 需求编号：YV-08-01-7 · 优先级：P2 · 人天：3.0d · 状态：已完成
> 依赖：无

## 主题体系对照（前后端统一）

| 含义 | 字段/标识 | 值举例 / 枚举 |
|------|----------|------|
| 暗色模式 | `isDark` | `false`（亮色）/ `true`（暗色），全局 Store 持久化 |
| 灰色模式 | `isGrey` | `false` / `true`，`filter: grayscale(1)` |
| 色弱模式 | `isWeak` | `false` / `true`，`filter: invert(80%)` |
| 主题色 | `primary` | `#409EFF`（默认），支持颜色选择器自定义 |
| 侧边栏主题 | `asideInverted` | `false`（亮色）/ `true`（反转），独立于暗色模式 |
| 顶栏主题 | `headerInverted` | `false`（亮色）/ `true`（反转），独立于暗色模式 |
| 暗色激活方式 | `html class="dark"` | 设置 `document.documentElement.className = "dark"` |
| 持久化 | `pinia-plugin-persistedstate` | `localStorage` key: `yivad-global` |

暗色模式与侧边栏/顶栏反转是独立的两个维度，可组合使用。暗色模式下侧边栏/顶栏自动切换为 `dark` 主题。

## 背景

管理后台长时间使用，亮色主题在暗光环境下造成视觉疲劳。Element Plus 2.x 已内置暗色 CSS 变量方案（`element-plus/theme-chalk/dark/css-vars.css`），接入成本低。需支持一键切换 + 偏好持久化。

## 二、useTheme Hook（核心实现）

`src/hooks/useTheme.ts` — 统一管理暗色切换、主题色、灰色/色弱模式、侧边栏/顶栏主题：

### 2.1 switchDark — 暗色模式切换

```typescript
const switchDark = () => {
  const html = document.documentElement as HTMLElement;
  if (isDark.value) html.setAttribute("class", "dark");
  else html.setAttribute("class", "");
  changePrimary(primary.value);  // 重新计算主题色变量
  setAsideTheme();               // 更新侧边栏 CSS 变量
  setHeaderTheme();              // 更新顶栏 CSS 变量
};
```

### 2.2 changePrimary — 主题色切换

根据当前亮/暗模式计算 Element Plus 主题色变量（`--el-color-primary` + `--el-color-primary-light-1` ~ `light-9` + `dark-2`）：

```typescript
const changePrimary = (val: string | null) => {
  if (!val) { val = DEFAULT_PRIMARY; /* 重置为默认主题色 */ }
  document.documentElement.style.setProperty("--el-color-primary", val);
  document.documentElement.style.setProperty(
    "--el-color-primary-dark-2",
    isDark.value ? `${getLightColor(val, 0.2)}` : `${getDarkColor(val, 0.3)}`
  );
  for (let i = 1; i <= 9; i++) {
    const primaryColor = isDark.value
      ? `${getDarkColor(val, i / 10)}`
      : `${getLightColor(val, i / 10)}`;
    document.documentElement.style.setProperty(`--el-color-primary-light-${i}`, primaryColor);
  }
  globalStore.setGlobalState("primary", val);
};
```

暗色模式下主题色变体使用 `getDarkColor`（加深），亮色模式下使用 `getLightColor`（变浅），确保两种背景下主题色始终可辨识。

### 2.3 changeGreyOrWeak — 灰色/色弱模式

```typescript
const changeGreyOrWeak = (type: Theme.GreyOrWeakType, value: boolean) => {
  const body = document.body as HTMLElement;
  if (!value) return body.removeAttribute("style");
  const styles: Record<Theme.GreyOrWeakType, string> = {
    grey: "filter: grayscale(1)",
    weak: "filter: invert(80%)"
  };
  body.setAttribute("style", styles[type]);
};
```

### 2.4 侧边栏/顶栏主题

侧边栏和顶栏各有三套主题（light / inverted / dark），通过 CSS 变量独立控制：

```
暗色模式切换：
  switchDark()
    ├── html.className = "dark" | ""
    ├── changePrimary()     → 更新 --el-color-primary-* 系列
    ├── setAsideTheme()     → 更新 --el-aside-* 系列
    └── setHeaderTheme()    → 更新 --el-header-* 系列

侧边栏反转切换：
  setAsideTheme()
    → type = asideInverted ? "inverted" : (isDark ? "dark" : "light")
    → 应用 asideTheme[type] CSS 变量
    → setMenuTheme()

顶栏反转切换：
  setHeaderTheme()
    → type = headerInverted ? "inverted" : (isDark ? "dark" : "light")
    → 应用 headerTheme[type] CSS 变量
    → setMenuTheme()
```

## 2. useTheme Hook (`src/hooks/useTheme.ts`)

### 2.1 五个核心函数

| 函数 | 触发时机 | 作用 |
|------|---------|------|
| `switchDark()` | `isDark` 变化 | 设置 `html.className` + 重新计算主题色 + 更新侧边栏/顶栏/菜单 |
| `changePrimary(val)` | 主题色选择器变化 | 计算 `--el-color-primary-*` 系列 11 个 CSS 变量 |
| `changeGreyOrWeak(type, value)` | 灰色/色弱开关变化 | 设置 `body.style.filter` |
| `setAsideTheme()` | 侧边栏反转变化 / 暗色切换 | 应用 `asideTheme[type]` CSS 变量 |
| `setHeaderTheme()` | 顶栏反转变化 / 暗色切换 | 应用 `headerTheme[type]` CSS 变量 |

### 2.2 主题色计算策略

| 模式 | 变浅方向 | 加深方向 |
|------|---------|---------|
| 亮色 | `getLightColor(val, i/10)` → `light-1`~`light-9` | `getDarkColor(val, 0.3)` → `dark-2` |
| 暗色 | `getDarkColor(val, i/10)` → `light-1`~`light-9` | `getLightColor(val, 0.2)` → `dark-2` |

亮色模式下背景为白色，需要浅色变体；暗色模式下背景为深色，需要深色变体。`getLightColor`/`getDarkColor` 来自 `src/utils/color.ts`，基于 `mix()` 颜色混合算法。

### 2.3 侧边栏/顶栏主题类型决策

```
类型决策：
  if (isDark) → "dark"
  else if (xxxInverted) → "inverted"
  else → "light"
```

暗色模式优先级最高，覆盖反转设置。

## 实现注意事项

### 暗色模式与侧边栏/顶栏反转的关系

暗色模式、侧边栏反转、顶栏反转是三个独立维度。暗色模式切换时，侧边栏和顶栏自动跟随（`isDark → "dark"`），但用户可以单独开启反转（`inverted`）而不开启暗色模式。暗色模式优先级最高。

### 主题色计算

`getLightColor`/`getDarkColor` 基于 `mix()` 颜色混合算法（`src/utils/color.ts`），暗色和亮色模式下使用不同的变体方向。切换暗色模式时必须重新计算主题色，因为 `light-1`~`light-9` 的语义在两种背景下相反。

### 灰色/色弱模式

灰色模式和色弱模式互斥（同一时间只能启用一个）。两者通过 `body.style.filter` 实现，不影响 `html.className` 和 Element Plus 变量。

### 无闪烁加载

当前方案在 `index.html` 内联脚本中仅设置 loading 背景色，未在 Vue 挂载前设置 `html.className`。这意味着暗色模式下，loading 动画期间背景为深色，但 Vue 挂载后 `initTheme()` 才设置 `html.className = "dark"`，存在短暂的亮→暗跳变。进一步优化可在内联脚本中直接设置 `html.className`。

### 打印

当前未实现 `@media print` 暗色覆盖，打印时保持当前主题颜色。如需强制亮色打印，可在 `element-dark.scss` 中增加 `@media print { html.dark { ... } }`。

### ECharts 图表

ECharts 组件通过响应式 `theme` 属性适配暗色模式，需确保图表实例在主题切换时重新 `setOption` 或 `dispose` + `init`。
