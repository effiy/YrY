# ProTable 通用表格组件体系

> 需求编号：YV-08-01-3 · 优先级：P1 · 人天：8.0d · 状态：已完成
> 依赖：无

## 背景

当前 YiVad 中 issue、bug、project、knowledge 等模块的列表页各自实现了表格+搜索+分页逻辑，存在大量重复代码。各页面自行封装 ElTable + ElPagination + ElForm，props/events 不统一，维护成本高。上传功能分散在多个页面，模板下载、文件校验逻辑重复。

目标：提取通用组件体系，统一 API，消除约 40% 的重复模板代码。

---

## 一、组件体系架构

### 1.1 整体架构

```
ProTable (主组件, ~343 行)
├── SearchForm (内置搜索表单, ~95 行)
│   ├── Grid + GridItem (响应式布局)
│   └── SearchFormItem (动态字段渲染, ~110 行)
├── ElTable (表格主体)
│   ├── TableColumn (单元格渲染器, ~58 行)
│   │   ├── enum 字典映射
│   │   ├── tag 标签渲染
│   │   └── 自定义 render 函数
│   └── ColSetting (列设置抽屉, ~46 行)
├── Pagination (分页组件, ~34 行，支持 header/footer 双位置)
└── SortableJS (拖拽排序，仅 type:"sort" 列存在时初始化)
    │
    ├── useTable()     — 数据请求 + 分页 + 搜索状态 (~145 行)
    └── useSelection() — 多选数据操作 (~35 行)
```

### 1.2 数据流

```
View 定义 columns + requestApi
  │
  ├── columns: ColumnProps[]  →  列定义 + 搜索配置 + 枚举字典
  └── requestApi(params)      →  API 请求函数
        │
        ▼
ProTable 组件挂载
  ├── requestAuto === true → getTableList()
  ├── flatColumns() → 展平多级表头 + 注入默认值 + setEnumMap()
  ├── searchColumns → 过滤 search 配置 + 按 order 排序
  └── 渲染：SearchForm + ElTable + Pagination
        │
        ▼
useTable Hook
  ├── getTableList() → requestApi({ pageNum, pageSize, ...searchParam })
  ├── search() → 重置到第 1 页 + 合并搜索参数 → getTableList()
  ├── reset() → 恢复默认搜索参数 → getTableList()
  ├── handleSizeChange() / handleCurrentChange() → getTableList()
  └── 维护：tableData, pageable, searchParam, searchInitParam, totalParam
```

### 1.3 组件注册

通过 `src/components/index.ts` 统一 barrel 导出，外部使用 `import { ProTable } from "@/components"` 即可：

```typescript
export { default as ProTable } from "./ProTable/index.vue";
export { default as SearchForm } from "./SearchForm/index.vue";
export { default as UploadImg } from "./Upload/Img.vue";
export { default as UploadImgs } from "./Upload/Imgs.vue";
export type { ColumnProps, ProTableInstance } from "./ProTable/interface";
```

## 二、ProTable 主组件

### 2.1 Props

| Prop | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `columns` | `ColumnProps[]` | 是 | `[]` | 列定义（含搜索配置、枚举字典） |
| `requestApi` | `(params: any) => Promise<any>` | 否 | — | 数据请求函数，返回 `{ list, total }` 或直接数组 |
| `data` | `any[]` | 否 | — | 静态表格数据（与 requestApi 二选一） |
| `requestAuto` | `boolean` | 否 | `true` | 是否自动执行首次请求 |
| `requestError` | `(params: any) => void` | 否 | — | 请求错误回调 |
| `dataCallback` | `(data: any) => any` | 否 | — | 返回数据处理回调 |
| `pagination` | `boolean` | 否 | `true` | 是否显示分页 |
| `headerPagination` | `boolean` | 否 | `false` | 分页器是否渲染在表头右侧（而非表格下方） |
| `initParam` | `object` | 否 | `{}` | 初始请求参数（变化时自动重新请求） |
| `border` | `boolean` | 否 | `true` | 是否显示纵向边框 |
| `toolButton` | `("refresh" \| "setting" \| "search")[]` \| `boolean` | 否 | `true` | 工具栏按钮配置，`true` 显示全部，`false` 全部隐藏 |
| `rowKey` | `string` | 否 | `"id"` | 行唯一键，用于优化渲染和多选 |
| `searchCol` | `number \| Record<BreakPoint, number>` | 否 | `{ xs:1, sm:2, md:2, lg:3, xl:4 }` | 搜索项列数配置（支持响应式断点） |

| 字段 | 类型 | 必填 | 说明 |

| `width` | `string \| number` | 否 | 列宽 |
| `minWidth` | `string \| number` | 否 | 最小列宽 |
| `fixed` | `"left" \| "right"` | 否 | 固定列 |
| `sortable` | `boolean \| "custom"` | 否 | 是否可排序 |
| `align` | `"left" \| "center" \| "right"` | 否 | 对齐方式，默认 `"center"` |
| `showOverflowTooltip` | `boolean` | 否 | 文本溢出显示 tooltip，非操作列默认 `true` |

## 三、SearchForm 搜索表单

### 3.1 定位

响应式搜索表单，作为 ProTable 的内置模块，通过 `columns` 中 `search` 配置自动渲染。搜索字段定义在 `ColumnProps.search` 上，无需单独配置 `SearchField[]`。

### 3.2 搜索字段类型

| 类型 | 对应 Element Plus 组件 | 说明 |
|------|----------------------|------|
| `input` | `ElInput` | 文本输入 |
| `input-number` | `ElInputNumber` | 数字输入 |
| `select` | `ElSelect` + `ElOption` | 下拉选择 |
| `select-v2` | `ElSelectV2` | 虚拟化下拉选择 |
| `tree-select` | `ElTreeSelect` | 树形选择 |
| `cascader` | `ElCascader` | 级联选择 |
| `date-picker` | `ElDatePicker` | 日期选择 |
| `time-picker` | `ElTimePicker` | 时间选择 |
| `time-select` | `ElTimeSelect` | 时间选择 |
| `switch` | `ElSwitch` | 开关 |
| `slider` | `ElSlider` | 滑块 |

### 3.3 折叠模式

通过 Grid 的响应式断点自动计算是否需要折叠。当搜索字段 span 总和超过 `searchCol` 配置的列数时，自动显示展开/收起按钮。默认折叠（`collapsed = true`）。

### 3.4 响应式断点

| 断点 | 宽度 | 默认列数 |
|------|------|----------|
| `xs` | < 768px | 1 |
| `sm` | ≥ 768px | 2 |
| `md` | ≥ 992px | 2 |
| `lg` | ≥ 1200px | 3 |
| `xl` | ≥ 1920px | 4 |

## 五、useTable Hook

### 5.1 定位

表格数据请求 + 分页 + 搜索状态管理。ProTable 内部使用，也可独立使用。

### 5.2 接口

```typescript
export const useTable = (
  api?: (params: any) => Promise<any>,   // 数据请求函数
  initParam: object = {},                 // 初始请求参数
  isPageable: boolean = true,             // 是否启用分页
  dataCallBack?: (data: any) => any,      // 返回数据处理回调
  requestError?: (error: any) => void     // 请求错误回调
) => {
  // 返回
  tableData, pageable, searchParam, searchInitParam, totalParam,
  getTableList, search, reset, handleSizeChange, handleCurrentChange, updatedTotalParam
}
```

### 5.3 状态管理

| 状态 | 类型 | 说明 |
|------|------|------|
| `tableData` | `any[]` | 表格数据 |
| `pageable` | `{ pageNum: 1, pageSize: 10, total: 0 }` | 分页数据 |
| `searchParam` | `object` | 搜索参数（仅搜索条件） |
| `searchInitParam` | `object` | 初始默认搜索参数 |
| `totalParam` | `object` | 总参数（分页 + 搜索） |

### 5.4 搜索参数处理

- `search()` 将 `searchParam` 合并到 `totalParam`，重置到第 1 页，调用 `getTableList()`
- `reset()` 将 `searchParam` 恢复为 `searchInitParam`，重置到第 1 页，调用 `getTableList()`
- 空值过滤：`updatedTotalParam()` 中过滤掉空字符串/`null`/`undefined`，但保留 `false`/`0`

### 1.2 数据模式切换

`processTableData` computed (`index.vue:198-205`) 处理三种数据来源：

| 模式 | 条件 | 行为 |
|------|------|------|
| API 分页 | `!props.data` | 使用 `tableData.value`（useTable 管理） |
| 静态不分页 | `props.data && !props.pagination` | 直接渲染 `props.data` |
| 静态分页 | `props.data && props.pagination` | 前端切片 `data.slice(...)` |

### 1.3 flatColumns 展平与枚举注入

`flatColumnsFunc` (`index.vue:239-253`) 递归展平多级表头：

```typescript
const flatColumnsFunc = (columns: ColumnProps[], flatArr: ColumnProps[] = []) => {
  columns.forEach(async col => {
    if (col._children?.length) flatArr.push(...flatColumnsFunc(col._children));
    flatArr.push(col);
    col.isShow = col.isShow ?? true;
    col.isSetting = col.isSetting ?? true;
    col.isFilterEnum = col.isFilterEnum ?? true;
    await setEnumMap(col);
  });
  return flatArr.filter(item => !item._children?.length);
};
```

`setEnumMap` (`index.vue:218-233`) 处理枚举字典的三种形态：

| enum 类型 | 处理方式 |
|-----------|---------|
| 静态数组 | 直接存入 `enumMap` |
| `Ref<EnumProps[]>` | `unref()` 后存入 |
| 异步函数 | 先以 `[]` 占位（防重复请求），API 返回后更新 |

`enumMap` 通过 `provide("enumMap", enumMap)` 注入，子组件（SearchFormItem、TableColumn）通过 `inject` 获取。

const getTableList = async () => {

## 实现注意事项

### 枚举字典异步加载

`enum` 为函数时，ProTable 在 `flatColumns` 阶段调用并缓存结果到 `enumMap`。为防止慢 API 导致重复请求，先以空数组 `[]` 占位，API 返回后更新。`enumMap` 通过 `provide/inject` 在组件树中共享。

### 拖拽排序守卫

`dragSort` 有两层守卫：`hasSortCol` 检查列定义中是否存在 `type: "sort"`；`tbody` 存在性检查防止表格未渲染时 `Sortable.create` 报错。拖拽手柄限定为 `.move` class。

### 搜索表单折叠

通过 `useBreakpoint` 响应式断点 + Grid 的 `collapsed` prop 实现。`showCollapse` computed 根据字段 span 总和判断是否需要展开/收起按钮。

### 排序字段命名约定

组件内部排序参数格式为 `{ prop, order: 'ascending' | 'descending' }`，业务层 `requestApi` 函数中自行转换为后端需要的排序格式。

### 浮点精度

表格中的金额/百分比列使用 `render` 或 `formatter` 时需注意精度处理，统一使用 `Number(v).toFixed(n)` 或项目已有的精度工具函数。

### 组件注册

通过 `src/components/index.ts` 统一 barrel 导出，外部使用 `import { ProTable } from "@/components"` 即可。类型（`ColumnProps`、`ProTableInstance`）也通过 barrel 导出。

### 与 v-auth 权限指令的兼容

组件内部不处理权限，操作列通过 `column-{prop}` 插槽由业务层自行使用 `v-auth` 控制按钮显示。

### 与 RequestHttp 的集成

`requestApi` 函数内部使用 `RequestHttp.post()`，注意参数名契约：`filter` 而非 `query`。

## 九、新模块迁移指南

### 9.1 迁移步骤

4. **自定义列迁移**：原 `<template #default="scope">` 改为 `column-{prop}` 插槽或 `render` 函数
5. **清理状态**：删除 `loading/page/pageSize/total/list/searchForm` 等手动维护的 ref
6. **验证**：确认分页、搜索、排序、多选功能正常，`vue-tsc --noEmit` 通过

### 9.2 常见场景

| 场景 | 方案 |
|------|------|
| 需要表格加载状态 | `tableLoading` 通过 `v-loading` 绑定 ProTable 的 `element` ref |

| 需要表格数据导出 | 通过 `proTableRef.value?.tableData` 获取当前数据 |
| 需要外部触发搜索 | `proTableRef.value?.search()` 或 `proTableRef.value?.getTableList()` |
| 搜索表单需要联动 | `search.render` 函数中访问 `searchParam` 实现联动逻辑 |
| 需要树形表格 | 在 `ColumnProps` 上设置 `type: "expand"` 并通过 `column-{prop}` 插槽渲染子表 |

### 9.3 注意事项

- **不要在 `requestApi` 外维护分页状态**：pageNum/pageSize/total 由 ProTable 内部管理
- **空值搜索参数**：ProTable 自动过滤空字符串/null/undefined，但保留 false/0，无需手动处理
- **枚举与搜索下拉共用**：`enum` 数组同时用于搜索下拉选项和单元格值格式化，无需重复定义
- **操作列固定**：操作列设置 `fixed: "right"` 和 `width`，通过 `column-operation` 插槽渲染

---

## 总结

ProTable 组件体系将 YiVad 中 5 个模块的列表页从 ~40 行模板缩减至 ~12 行（-70%），消除了手动维护的 6+ 个状态 ref，统一了表格+搜索+分页的 API。组件通过 `ColumnProps` 类型安全配置实现列定义、搜索字段、枚举字典的三合一，支持 11 种搜索字段类型、响应式折叠、拖拽排序、列设置、多选等完整功能。Upload 组件统一了图片上传的校验/预览/编辑/删除流程。

后续新增列表页应以 ProTable 为规范模式，不再使用原始 `el-table`。
