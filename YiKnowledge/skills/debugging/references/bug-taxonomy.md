# Bug 分类与严重级别

## Bug 分类体系

基于 `YiKnowledge/projects/` 中各项目的 Bug 历史，将 Bug 分为以下类别：

| 类别 | 说明 | 典型示例 |
|------|------|---------|
| **认证** | 认证/授权相关 | JWT 密钥硬编码、权限检查缺失、Token 泄漏 |
| **数据** | 数据存储/查询 | 连接池耗尽、类型不匹配、空查询全表扫描 |
| **接口** | API/RPC 契约 | 参数名不匹配、响应格式错误、静默忽略错误参数 |
| **搜索** | 搜索/查询 | 空查询无防护、索引缺失、查询超时 |
| **配置** | 配置管理 | 键名冲突、环境变量未设置默认值、配置热更新失效 |
| **状态** | 状态管理 | TTL 未执行、状态残留、竞态条件 |
| **代码质量** | 可维护性 | 未使用的导入、命名模糊、类型标注缺失 |
| **大模型** | LLM 集成 | Embedding 维度不匹配、模型加载失败、推理超时 |
| **执行** | 任务执行 | 超时缺失、资源限制缺失、错误吞没 |
| **中间件** | 中间件/拦截器 | 异常处理器吞错误、日志缺失关键信息 |
| **前端** | UI/交互 | 组件渲染异常、路由跳转错误、SSE 断连 |
| **扩展** | Chrome Extension | Service Worker 休眠、消息通道断开 |

## 严重级别定义

| 级别 | 标签 | 定义 | 响应时间 | 示例 |
|------|------|------|---------|------|
| **critical** | 🔴 严重 | 系统不可用、数据丢失、安全漏洞 | 立即 | 数据库连接池耗尽导致所有请求失败 |
| **high** | 🟠 高 | 核心功能异常、用户明显受影响 | 24h 内 | SSE 流断连导致聊天功能不可用 |
| **medium** | 🟡 中 | 非核心功能异常、有 workaround | 当前迭代 | 分页后列头丢失（刷新可恢复） |
| **low** | 🟢 低 | 体验问题、边界情况 | 有空时 | 某个按钮 hover 颜色与设计稿有偏差 |

## 判定矩阵

判断严重级别时，同时考虑两个维度：**影响范围** × **影响程度**。

| 影响范围 \ 影响程度 | 功能完全不可用 | 功能部分异常 | 仅体验问题 |
|---------------------|-------------|------------|----------|
| **所有用户** | critical | high | medium |
| **部分用户** | high | medium | low |
| **极少数用户** | medium | low | low |
| **仅开发环境** | low | low | low |

## 分类归档路径

Bug 文档在 `YiKnowledge/projects/<project>/bugs/` 中的归档路径：

```
bugs/
└── YYYY-MM/
    └── <分类>/
        └── <序号>-<分类>-<简短描述>.md
```

示例：
```
bugs/2026-09/认证/01-认证-JWT-Secret硬编码默认值.md
bugs/2026-09/数据/01-数据-MongoDB连接池耗尽.md
bugs/2026-09/接口/01-接口-RPC参数query-vs-filter静默忽略.md
```
