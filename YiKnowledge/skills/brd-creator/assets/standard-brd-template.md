# 标准 BRD 模板

## 模板概述

- **名称**: 标准 BRD
- **描述**: 适用于企业项目的标准业务需求文档
- **版本**: 1.0.0

## 章节

### 1. 概述
- **排序**: 1
- **必填**: true
- **最低评分**: 0.6
- **描述**: 背景、问题、预期解决方案。

### 2. 范围与目标
- **排序**: 2
- **必填**: true
- **最低评分**: 0.6
- **描述**: 业务范围、渠道、产品、数据、KPI。

### 3. 干系人与角色
- **排序**: 3
- **必填**: true
- **最低评分**: 0.6
- **描述**: 业务负责人、运营、IT、区域团队、经销商代表名单；角色与职责。

### 4. 现状流程
- **排序**: 4
- **必填**: true
- **最低评分**: 0.6
- **描述**: 当前流程、相关系统、SLA、TAT、BPMN。

### 5. 目标流程
- **排序**: 5
- **必填**: true
- **最低评分**: 0.6
- **描述**: 目标流程、架构、集成/流程图。

### 6. 功能需求 (FR)
- **排序**: 6
- **必填**: true
- **最低评分**: 0.6
- **描述**: 列出 >= 10 条功能需求，每条附明确的验收标准。

### 7. 集成需求
- **排序**: 7
- **必填**: true
- **最低评分**: 0.6
- **描述**: 与 DMS、ERP、CRM、数据平台的集成；API 规范、消息队列、数据格式。

### 8. 非功能需求 (NFR)
- **排序**: 8
- **必填**: true
- **最低评分**: 0.6
- **描述**: 性能、安全、高可用/灾备、审计日志、可扩展性、运维。

### 9. 用户角色与权限
- **排序**: 9
- **必填**: true
- **最低评分**: 0.6
- **描述**: 经销商、区域经理、总部运营、管理员；基于角色的权限映射。

### 10. 收益
- **排序**: 10
- **必填**: true
- **最低评分**: 0.6
- **描述**: 量化收益（TAT、自动化率、FTE）和定性收益（CSAT、流程优化）。

### 11. 风险与缓解
- **排序**: 11
- **必填**: false
- **最低评分**: 0.6
- **描述**: 业务、技术、安全、法律风险；缓解计划。
