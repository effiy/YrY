## 请求代码审查 AI 智能体

### 快速开始

```
你：[刚完成 task-planning 步骤 3]

助手：[请求审查模式]
  准备审查上下文...
  
  审查范围：步骤 3 的 3 个文件 (+120/-30)
  关联文档：task_plan 步骤 3 + 验收标准
  测试状态：3/3 tests passed
  类型检查：0 errors
  
  → 提交审查请求 → code-review 技能自动触发
```

### 为什么需要专门的请求审查技能？

**为什么不直接触发 code-review？**
请求审查不只是触发审查——它需要准备正确的上下文、确定合适的范围、在正确的时机触发。没有准备的审查 = 浪费审查者的时间。

**为什么早审查、常审查？**
一个小步骤的审查发现 1 个问题 → 修复 5 分钟。全部做完后审查发现同样的问题 → 可能需要重构半天。

### Review 三角

```
requesting-code-review → code-review → receiving-code-review
     (请求)                (执行)           (处理)
```
