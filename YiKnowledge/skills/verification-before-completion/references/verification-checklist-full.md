# 完整验证检查清单

## 通用检查项（所有项目）

### 代码质量
- [ ] 无未使用的导入和变量
- [ ] 无 `console.log` / `print` 调试残留
- [ ] 无注释掉的代码块
- [ ] 无硬编码的配置值（端口、URL、密钥）
- [ ] 错误消息清晰可操作（不是「出错了」）

### 功能验证
- [ ] 正常路径：按照验收标准操作，结果符合预期
- [ ] 空状态：无数据时界面不崩溃，显示合理的空状态
- [ ] 错误状态：网络断开、权限不足时有合理的错误提示
- [ ] 加载状态：数据加载中有 loading 指示器
- [ ] 边界值：最大值、最小值、空字符串、特殊字符

### 回归检查
- [ ] 相关功能未受影响（改了 A 模块，B 模块正常）
- [ ] 已有的测试仍然通过
- [ ] git diff 确认没有意外修改其他文件

## YiVad 专项

### 组件验证
- [ ] 组件在独立路由下正常渲染
- [ ] Props 传递正确，类型匹配
- [ ] Emits 事件正确触发
- [ ] 组件销毁后无遗留的定时器/事件监听器
- [ ] 响应式数据更新后视图同步刷新

### ProTable 验证
- [ ] 分页切换后列配置保持
- [ ] 排序功能正常
- [ ] 筛选条件正确传递到 API
- [ ] 空数据和单页数据的分页组件显示正确

### 路由验证
- [ ] 动态路由注册正确
- [ ] 路由参数变化时组件正确更新
- [ ] 404 页面正常显示
- [ ] 路由守卫逻辑正确（认证、权限）

### Store 验证
- [ ] Pinia store 初始化状态正确
- [ ] 持久化插件正常（刷新后状态恢复）
- [ ] store 之间的依赖关系正确

## YiAi 专项

### RPC 契约
- [ ] 参数名使用 `filter`（非 `query`）
- [ ] 文件路径使用 `target_file`（非 `path`）
- [ ] 集合名使用 `cname`（非 `collection_name`）
- [ ] 响应格式符合 RPC 信封 `{code, message, data}`

### 数据访问
- [ ] MongoDB 查询有 `limit` 限制
- [ ] 异步操作正确 `await`
- [ ] 数据库连接正确释放
- [ ] 查询有适当的索引覆盖

### 错误处理
- [ ] 异常返回正确的错误码（非 500）
- [ ] 错误信息不泄露内部实现细节
- [ ] 日志包含足够的调试信息但不含敏感数据

## YiPet 专项

### 扩展生命周期
- [ ] Service Worker 安装/激活正常
- [ ] Content Script 在目标页面正确注入
- [ ] Popup 打开时数据正常加载
- [ ] 扩展更新后状态迁移正常

### 消息通信
- [ ] Content Script ↔ Service Worker 消息正常
- [ ] Popup ↔ Service Worker 消息正常
- [ ] 消息超时和错误有处理

### 存储
- [ ] chrome.storage.local 读写正常
- [ ] 存储配额未超限
- [ ] 敏感数据不存储在 storage 中
- [ ] 快捷键不冲突
