GitHub 的 **Trending** 页面（[https://github.com/trending](https://github.com/trending)）会根据语言、仓库类型（如 Popular / Recent）展示当前最热门的开源项目。以下是获取和解析该排名列表的几种方法：

---

### **1. 直接访问 GitHub Trending 页面**
- **默认分类**：  
  默认会显示 **All**（所有语言）的 **Popular**（热门）项目，按 stars 数量排序。
- **筛选方式**：  
  点击页面顶部的筛选器（如 **All**, **JavaScript**, **Python** 等），可按语言分类。  
  选择 **Popular**（热门）或 **Recent**（近期）来调整排序方式。

---

### **2. 通过 GitHub API 获取数据**
GitHub 提供了官方 API 接口，可获取 Trending 项目的列表。  
**API 文档**：[https://developer.github.com/v3/repos/](https://developer.github.com/v3/repos/)

#### **请求示例（获取所有语言的热门项目）**
```bash
GET https://api.github.com/search/repositories?q=language:python+sort=stars+order=desc
```
- **参数说明**：
  - `q`：搜索查询（如 `language:python` 表示 Python 语言）。
  - `sort`：排序方式（`stars`、`forks`、`updated`）。
  - `order`：升序（`asc`）或降序（`desc`）。

#### **Python 示例代码**
```python
import requests

url = "https://api.github.com/search/repositories"
params = {
    "q": "language:python",
    "sort": "stars",
    "order": "desc"
}
headers = {"Accept": "application/vnd.github.v3+json"}

response = requests.get(url, params=params, headers=headers)
data = response.json()

for repo in data["items"]:
    print(f"{repo['name']} - {repo['html_url']} - {repo['stargazers_count']} stars")
```

### **4. 解析 GitHub Trending 页面的 HTML**
如果需要直接抓取网页内容，可以使用工具如 **Selenium** 或 **BeautifulSoup**（需注意反爬虫机制）。

#### **示例（Python + BeautifulSoup）**
```python
import requests
from bs4 import BeautifulSoup

url = "https://github.com/trending"
response = requests.get(url)
soup = BeautifulSoup(response.text, "html.parser")

for repo in soup.select(".repo-list-item"):
    name = repo.select_one("h3 a").text.strip()
    link = repo.select_one("h3 a")["href"]
    stars = repo.select_one(".repo-stats .octicon-star").text
    print(f"{name} - {link} - {stars} stars")
```
