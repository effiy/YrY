2. **看 frontmatter**：先 `head -15 file.md` 读 YAML，判断相关性后再读全文。
3. **看本 INDEX**：跳到对应一级分类，从 leaf README 进入。
4. **grep 关键词**：`rg "^tags:.*关键词" YiKnowledge -l` 快速筛选。
