# 标准笔记 — ISO/IEC 27701:2019 隐私信息管理系统（PIMS）控制项 × 我方差距矩阵

- **标准名称**：ISO/IEC 27701:2019 Information technology — Security techniques — Extension to ISO/IEC 27001 and ISO/IEC 27002 for privacy information management
- **发布机构**：ISO/IEC JTC 1/SC 27
- **版本**：2019 第一版 + Amd 1:2023（隐私扩展）
- **标准编号锚定**：GDPR / 个保法 / 数据安全法 2021 三法并轨映射
- **创建日 / 更新日**：2026-10-09
- **评审周期**：每季度一次（QBR 时同步 A-07 指标）
- **主线 OKR**：exec-002-04（合规底座 Q4-2026）
- **评级**：★★★★★

## §1 理论根基：PIMS 三域（PII 控制者/处理者/主体权利）× 安全 SECURITY + 数据层 013

1.1 **ISO/IEC 27701 PIMS 三域**：
  - **域一 PIMS-P（PII Controller 控制者要求，27701 §5）**：我们作为用户数据控制者，承担目的限制/合法性/透明性 8 项义务；
  - **域二 PIMS-PII（PII Processor 处理者要求，27701 §6）**：我们处理他人 PII 的 7 项义务；
  - **域三 DSR（Data Subject Rights 数据主体权利，27701 §7）**：8 项主体权利（访问/更正/删除/限制/可携带/反对/自动化决策撤回/投诉）。
1.2 **个保法 / GDPR 三法并轨**：ISO27701 §5.4 同意 = 个保法第 13、14、24 条；§7 DSR = 个保法第四章 + GDPR Chapter 3。
1.3 **× 013 DDIA Kleppmann 可靠性三性**：PII 加密/备份 = 013 Reliability（可靠性）子集；PII 可维护 = 013 Maintainability。
1.4 **PII 生命周期（收集→存储→使用→共享→删除）= 5 阶段 × 每阶段至少 4 条控制 = 20 条控制项（§3 正好 ≥20）**。
1.5 **支撑 README I-06（合规 4 支柱：安全/隐私/数据治理/供应链）**：本 025 是 I-06 第 1 本隐私标准。
