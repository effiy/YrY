# 标准笔记 — IEEE 829-2008 + ISO/IEC/IEEE 29119 测试文档体系控制项 × 差距矩阵

- **标准名称**：
  - IEEE Std 829-2008 *IEEE Standard for Software and System Test Documentation*（测试文档 8 种）
  - ISO/IEC/IEEE 29119-1:2022 Part 1 Concepts & definitions / 29119-2:2022 Part 2 Test processes / 29119-3:2022 Part 3 Test documentation
- **发布机构**：IEEE Computer Society / ISO/IEC JTC 1/SC 7
- **创建日/更新日**：2026-10-09
- **主线 OKR**：exec-002-04（质量体系 Q4-2026）
- **评审周期**：每季度 1 次（QBR 同步 A-07）

---

## §1 理论根基：IEEE 829 8 文档 + 29119 过程模型 × DORA 006 加速 + 谷歌测试 70/20/10

1.1 **IEEE 829 核心 8 文档**：① Master Test Plan（MTP 主测试计划）② Level Test Plan（LTP）③ Test Design Spec（TDS 设计说明）④ Test Case Spec（TCS 用例说明）⑤ Test Procedure Spec（TPS 步骤）⑥ Test Log（TL 日志）⑦ Test Incident Report（TIR 缺陷）⑧ Test Summary Report（TSR 总结）。
1.2 **ISO/IEC/IEEE 29119 三层过程（组织 / 管理 / 动态）**：
  - 组织层 Org Test Process：文档治理、度量、风险；
  - 管理层 Test Mgmt：计划/设计/执行/评估/评审；
  - 动态层 Dynamic Test：具体测试级别（UT/IT/ST/E2E）。
1.3 **× 谷歌 70/20/10 金字塔（019）**：IEEE 29119 动态测试级别 × 70/20/10 = UT（70%）/IT（20%）/ST（10%）的文档齐套要求。
1.4 **× DORA 006 加速**：可追溯覆盖率 ≥85% → 降低 CFR（变更失败率）。
1.5 **× 013 DDIA（可靠性三性）**：测试退出准则 95% 通过 = 可靠性三性的质量代理。
1.6 **支撑 README I-04（工程效能 4 指标）**：本 026 是 I-04 第 7 本质量底座标准。
