2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **intent Intent**: ambition / boundary / principle / path; no leakage
4. **combination Portfolio**: business / stage / capital / risk; no leakage
5. **parenting Parenting**: value / governance / synergy / shared; no leakage

7. **Measurement Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: from intent → combination → parenting → governance → measurement gradual; no skipping levels
