## Action recommendations

1. **Five dimensions**: hierarchy + audience + proof + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by differentiation + trust + conversion + speed + cost; not sloganeering
3. **Hierarchy Hierarchy**: pillar / theme / proof / persona / channel; do not omit
4. **Audience Audience**: buyer / user / champion / economic / decision; do not omit
5. **Proof Proof**: case studies / data / third-party / demo / customer; do not omit
6. **Governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement Measure**: differentiation + trust + conversion + speed + cost; do not omit
8. **Not one-shot**: progressive from hierarchy → audience → proof → governance → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link to gtm-messaging**: Framework + GTM co-build
13. **Link to value-proposition**: Framework + ValueProp co-build
14. **Link to positioning-statement**: Framework + Positioning co-build
15. **Link to brand-voice**: Framework + BrandVoice co-build
16. **Link to messaging-house**: Framework + House co-build
17. **Toolchain**: Gong / Highspot / Seismic / Showpad / Notion
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must we have a Framework; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by relying on improvised talking points; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (differentiation / trust / conversion / cost) 
23. **Occam**: Framework the simpler the better; cut redundant layers
