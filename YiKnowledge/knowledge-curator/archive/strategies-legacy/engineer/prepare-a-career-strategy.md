## Action recommendations

1. **Five dimensions**: Planning + Development + Movement + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Planning**: self / opportunity / target / cadence; none missing
4. **Development**: skills / experience / relationships / feedback; none missing
5. **Movement**: vertical / lateral / project / cross-region; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from Planning → Development → Movement → Governance → Measurement; no skipping levels
9. **Not report-only**: paths are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Career-development links**: career + development co-build
13. **Career-pathing links**: career + path co-build
14. **Talent links**: career + talent co-build
15. **Talent-development links**: career + development co-build
16. **People links**: career + people co-build
17. **Toolchain**: Workday / Eightfold / Gloat / Fuel50 / Pathlight
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must a career strategy exist; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: career the simpler the better; cut redundant layers
