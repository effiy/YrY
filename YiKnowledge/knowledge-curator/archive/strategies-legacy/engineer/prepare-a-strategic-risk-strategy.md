1. **Five dimensions**: hypothesis + deviation + adjustment + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Hypothesis / Assumption**: strategy / closed loop; none missing
4. **Deviation**: signal / closed loop; none missing
5. **Adjustment**: path / closed loop; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: efficiency + trust + speed + risk + cost; none missing
8. **Not one-shot**: progressive from hypothesis → deviation → adjustment → governance → measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with risk-management**: StrategicRisk + riskManagement co-build
