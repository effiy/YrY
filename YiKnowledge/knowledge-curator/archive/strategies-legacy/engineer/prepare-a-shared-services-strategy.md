## Action recommendations

1. **Five dimensions**: scope + SLA + operations + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; not sloganeering
3. **scope Scope**: finance / HR / IT / procurement; do not omit
4. **SLA**: response / accuracy / capacity / satisfaction; do not omit
5. **operations Operations**: process / platform / people / automation; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: from scope → SLA → operations → governance → measurement gradual; no skipping
9. **not report-ized**: centralization only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **and operational-excellence link**: shared + excellence co-built
13. **and process-improvement link**: shared + process improvement co-built
14. **and cost-management link**: shared + cost co-built
15. **and shared-service-center link**: shared + SSC co-built
16. **and org-design link**: shared + organization design co-built
17. **Toolchain**: SAP S/4HANA / Oracle Cloud / Workday / ServiceNow / Salesforce Service Cloud
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must shared services strategy; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by default; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (growth / trust / speed / risk)
23. **Occam**: shared services the simpler the better; cut redundant layers
