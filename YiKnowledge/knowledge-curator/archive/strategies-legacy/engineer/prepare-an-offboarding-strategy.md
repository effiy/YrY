## Action recommendations

1. **Five dimensions**: notify + handover + exit + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by risk + trust + speed + compliance + cost; not sloganeering
3. **Notify**: intent / communication / documentation / legal / care; do not omit
4. **Handover**: tasks / documentation / permissions / knowledge / relationships; do not omit
5. **Exit**: equipment / accounts / departure / certificate / survey; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: risk + trust + speed + compliance + cost; do not omit
8. **Not one-shot**: progress from notify -> handover -> exit -> governance -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with employee-experience**: OB + EX co-build
13. **Link with succession-management**: OB + Succession co-build
14. **Link with hr-operations**: OB + HROps co-build
15. **Link with data-protection**: OB + DataProtection co-build
16. **Link with chro**: OB + CHRO co-build
17. **Toolchain**: Workday HCM / BambooHR / Sapling / Offboarding.com / Click Boarding
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must OB; worst consequence of not doing it
21. **Inversion thinking**: see how much a process can solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (risk / trust / speed / compliance)
23. **Occam**: OB the simpler the better; cut redundant steps
