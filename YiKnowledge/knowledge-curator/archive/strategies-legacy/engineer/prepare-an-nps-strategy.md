## Action recommendations

1. **Five dimensions**: survey + segmentation + closed loop + action + measurement; no missing dimension
2. **Business-value driven**: prioritize by NPS + retention + repeat purchase + referral; no empty slogans
3. **Survey Survey**: transactional + relational + cohort + timing + touchpoints + frequency; no leakage
4. **Segment Segment**: promoter + passive + detractor + industry + tier; no leakage
5. **Closed loop Loop**: follow-up + referral + win-back + upgrade + root-cause; no leakage
6. **Action Action**: detractor win-back + promoter referral + passive upgrade + systemic improvement; no leakage
7. **Measurement Measure**: NPS + response-rate + trend + cohort + retention correlation; no leakage
8. **Not one-shot**: gradual from survey → segmentation → closed loop → action → measurement; no skipping levels
9. **No report-ism**: a report is just the start; not the end
10. **No empty slogans**: every principle must have implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with csat**: NPS + CSAT co-build
13. **Link with customer-experience**: NPS + experience co-build
14. **Link with customer-success**: NPS + customer success co-build
15. **Link with customer-health**: NPS + health co-build
16. **Link with feedback-loop**: NPS + feedback co-build
17. **Toolchain**: NPS-Framework / Qualtrics / SurveyMonkey / Typeform / Delighted / AskNicely / Wootric / Promoter.io / Hotjar
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolves and updates; not one-shot
20. **First principles**: why an NPS strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved by relying on intuition; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after the strategy (cost / risk / retention / business)
23. **Occam's razor**: simpler NPS is better; cut redundant steps
