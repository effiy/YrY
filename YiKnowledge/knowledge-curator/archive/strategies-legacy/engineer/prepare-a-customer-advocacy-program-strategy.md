## Action recommendations

1. **Five dimensions**: Recruit + enable + Governance + incentive + Measurement; no missing dimension
2. **Business-value driven**: prioritize by referral ARR + case study + NPS + retention + referral rate; no empty slogans
3. **Recruit**: profile + source + qualification + invite + onboarding; none missing
4. **Enable**: training + resource + contact + milestone + escalation; none missing
5. **Governance**: charter + criteria + retirement + owner + budget; none missing
6. **Incentive**: honor + experience + network + impact + tangible; none missing
7. **Measure**: referral ARR + case study + NPS + retention + referral rate; none missing
8. **Not one-shot**: progressive from recruit → enable → Governance → incentive → Measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with customer-advocacy**: program + advocacy co-build
13. **Link with customer-advisory-board**: program + CAB co-build
14. **Link with user-group**: program + user group co-build
15. **Link with referral-program**: program + referral co-build
16. **Link with customer-success**: program + CS co-build
17. **Toolchain**: Influitive / Advocately / launchtactics / kasfuse / ReferenceEdge / kajabi / Salesforce-PRM
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must customer advocacy program strategy; worst consequence of not doing it
21. **Inversion**: how much can natural word-of-mouth solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / referral / business)
23. **Occam**: advocacy program the simpler the better; cut redundant steps
