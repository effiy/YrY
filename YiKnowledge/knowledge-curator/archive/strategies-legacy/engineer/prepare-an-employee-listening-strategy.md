## Action recommendations

1. **Five dimensions**: collection + analysis + action + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by adoption + trust + speed + risk + cost; not sloganeering
3. **Collect**: annual / pulse / always-on / focus / exit; do not omit
4. **Analyze**: quantitative / qualitative / theme / sentiment / stratified; do not omit
5. **Act**: interpret / prioritize / responsibility / closure / feedback; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: adoption + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from collection -> analysis -> action -> governance -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with employee-engagement**: EL + Engagement co-build
13. **Link with internal-communications**: EL + Internal co-build
14. **Link with culture**: EL + Culture co-build
15. **Link with voc**: EL + VoC co-build
16. **Link with chro**: EL + CHRO co-build
17. **Toolchain**: Glint / Peakon / Culture Amp / Qualtrics EX / Lattice
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must EL; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by intuition; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (adoption / trust / speed / risk) 
23. **Occam**: EL the simpler the better; cut redundant questions
