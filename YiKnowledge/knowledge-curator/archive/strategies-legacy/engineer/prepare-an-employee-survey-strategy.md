## Action recommendations

1. **Five dimensions**: design + collect + action + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by efficiency + trust + speed + risk + cost; no empty slogans
3. **Design**: questions / scales / audience / anonymity; no leakage
4. **Collect**: distribution / reminders / channels / return rate; no leakage
5. **Act**: analysis / priority / plan / follow-through; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: return rate + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: progress from design → collect → action → governance → measurement; no skipping levels
9. **No report-ism**: numbers are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with employee-feedback**: survey + employee feedback co-build
13. **Link with employee-pulse**: survey + employee pulse co-build
14. **Link with employee-engagement**: survey + employee engagement co-build
15. **Link with employee-net-promoter**: survey + eNPS co-build
16. **Link with employee-experience**: survey + employee experience co-build
17. **Toolchain**: Culture Amp / Glint / Peakon / SurveyMonkey / Qualtrics
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must an employee-survey strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam's razor**: employee surveys simpler is better; cut redundant layers
