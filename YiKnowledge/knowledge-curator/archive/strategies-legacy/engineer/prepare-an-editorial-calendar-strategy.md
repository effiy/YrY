## Action recommendations

1. **Five dimensions**: topics + cadence + responsibility + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by traffic + conversion + consistency + trust + cost; no empty slogans
3. **Topics**: pillar / cluster / seasonal / event / pain points; no leakage
4. **Cadence**: daily / weekly / monthly / quarterly / ad-hoc; no leakage
5. **Owner**: author / edit / review / publish / measurement; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: traffic + conversion + consistency + trust + cost; no leakage
8. **Not one-shot**: progressive from topics -> cadence -> responsibility -> governance -> measurement; no skipping levels
9. **No report-ism**: the report is only the start; not the end
10. **No empty slogans**: every principle must have implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with content-calendar**: Editorial + Calendar co-build
13. **Link with content**: Editorial + Content co-build
14. **Link with content-operations**: Editorial + ContentOps co-build
15. **Link with brand-voice**: Editorial + BrandVoice co-build
16. **Link with blog**: Editorial + Blog co-build
17. **Toolchain**: Notion / Airtable / CoSchedule / ContentCal / Trello
18. **Publicly discoverable**: the strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why an Editorial Calendar is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved with ad-hoc publishing; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (traffic / conversion / consistency / trust) 
23. **Occam's razor**: a simpler editorial calendar is better; cut redundant columns
