## Action recommendations

1. **Five dimensions**: handover + exit + retrospective + governance + measurement; no missing dimension.
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans.
3. **Handover**: projects / docs / permissions / relationships; none missing.
4. **Exit**: administrative / equipment / accounts / exit interview; none missing.
5. **Retrospective review**: reason / lessons / improvements / knowledge retention; none missing.
6. **Governance**: owner / cadence / review / docs / drift; none missing.
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing.
8. **Not one-shot**: progressive from handover → exit → retrospective → governance → measurement; no skipping levels.
9. **Not report-only**: interview counts are only the starting point; not the endpoint.
10. **No empty slogans**: every principle must have landed evidence; no ambiguity.
11. **Versioned**: the strategy has versions; evolution is traceable.
12. **Link with employee-onboarding**: offboarding + onboarding co-build.
13. **Link with employee-retention**: offboarding + retention co-build.
14. **Link with internal-communications**: offboarding + internal comms co-build.
15. **Link with knowledge-transfer**: offboarding + knowledge transfer co-build.
16. **Link with corporate-culture**: offboarding + culture co-build.
17. **Toolchain**: Workday / BambooHR / Sapling / Gusto / SAP SuccessFactors.
18. **Publicly accessible**: the strategy is accessible to everyone; not hidden.
19. **Regular review**: evolve and update; not one-shot.
20. **First principles**: why we must do an employee-offboarding strategy; the worst consequence of not doing it.
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy.
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk).
23. **Occam**: simpler offboarding is better; cut redundant layers.
