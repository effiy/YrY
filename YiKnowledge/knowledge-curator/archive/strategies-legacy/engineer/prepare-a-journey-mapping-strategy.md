## Action recommendations

1. **Five dimensions**: persona + stages + touchpoints + emotion + opportunity; no missing dimension
2. **Business-value driven**: prioritize by business impact + user value + risk + opportunity; not sloganeering
3. **Persona**: user profile + goals + pain points + scenarios + JTBD; do not omit
4. **Stages**: awareness + consideration + purchase + first use + continued use + loyalty + churn multiple stages; do not omit
5. **Touchpoints**: channels + touch + behavior + system + data; do not omit
6. **Emotion**: satisfaction + pain points + high points + low points + expectations; do not omit
7. **Opportunity**: opportunity points + prioritization + solutions + measurement + landing; do not omit
8. **Not one-shot**: gradual from persona -> stages -> touchpoints -> emotion -> opportunity; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with user-research**: journey map + user co-build
13. **Link with customer-experience**: journey map + experience co-build
14. **Link with customer-segmentation**: journey map + segmentation co-build
15. **Link with product-strategy**: journey map + strategy co-build
16. **Link with usability-testing**: journey map + usability testing co-build
17. **Link with jobs-to-be-done**: journey map + JTBD co-build
18. **Toolchain**: Journey-Mapping Framework / Miro / Mural / Smaply / UXPressia / Canvan / UserTesting / Figma / FigJam
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why must journey mapping; worst consequence of not doing
22. **Inversion thinking**: how much can be solved by using intuition; if solvable, do not introduce heavy strategy
23. **Second-order thinking**: second-order consequences after strategy (cost / risk / speed / business)
24. **Occam**: the simpler journey map the better; cut redundant steps
