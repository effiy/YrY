## Action recommendations

1. **Five dimensions**: values + behavior + incentives + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Values Value**: data-driven / truth-seeking; do not omit
4. **Behavior Behavior**: look at data before decisions / experiment first; do not omit
5. **Incentives Incentive**: assessment / rewards / recognition; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: penetration rate + behavior rate + decision rate + risk + cost; do not omit
8. **not one-shot**: from values -> behavior -> incentives -> governance -> measurement gradual; no skipping
9. **not report-ized**: training headcount is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with data-literacy**: culture + literacy co-built
13. **Link with data-maturity**: culture + maturity co-built
14. **Link with data-democratization**: culture + democratization co-built
15. **Link with data**: culture + data strategy co-built
16. **Link with corporate-culture**: data culture + corporate culture co-built
17. **Toolchain**: culture-survey / OKR platform / internal LMS / data community / champion program
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must data culture; worst consequence of not doing it
21. **inversion thinking**: how much can tool promotion solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: data culture simpler is better; cut redundant layers
