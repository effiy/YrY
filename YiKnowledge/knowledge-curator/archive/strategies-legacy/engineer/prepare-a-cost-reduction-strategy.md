## Action recommendations

1. **Five dimensions**: identify + solution + implementation + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by growth + trust + speed + risk + cost; no empty slogans
3. **Identify**: structure / operations / procurement / finance; no leakage
4. **Solution**: zero-based / automation / consolidation / exit; no leakage
5. **Execute**: pilot / rollout / training / institutionalize; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: from identify -> solution -> implementation -> governance -> measurement gradual; no skipping levels
9. **No report-ism**: layoffs are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with cost-management**: reduction + cost management co-build
13. **Link with spend-management**: reduction + spend management co-build
14. **Link with finance**: reduction + finance co-build
15. **Link with profit-margin**: reduction + profit margin co-build
16. **Link with procurement**: reduction + procurement co-build
17. **Toolchain**: Anaplan / Oracle EPM / SAP BPC / Bain Insight / McKinsey Insight
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must there be a reduction strategy; worst consequence of not doing
21. **Inversion**: how much can be solved by relying on defaults; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (growth / trust / speed / risk) 
23. **Occam's razor**: reduction, simpler is better; cut redundant layers
