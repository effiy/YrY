## Action recommendations

1. **Five dimensions**: classification + analysis + control + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by growth + trust + speed + risk + cost; not sloganeering
3. **Taxonomy**: direct / indirect / temporary / capital; do not omit
4. **Analyze**: amount / trend / opportunity / risk; do not omit
5. **Control**: strategy / threshold / approval / variance; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **Not one-shot**: from classification -> analysis -> control -> governance -> measurement gradual; no skipping
9. **Not report-ized**: reimbursement is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with cost-management**: spend + cost management co-build
13. **Link with cost-reduction**: spend + reduction co-build
14. **Link with procurement**: spend + procurement co-build
15. **Link with expense-management**: spend + expense management co-build
16. **Link with finance**: spend + finance co-build
17. **Toolchain**: Coupa Spend Analysis / Sievo / SAP Ariba Spend Control Tower / Sievo / Emptoris
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must a spend strategy; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by default; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (growth / trust / speed / risk) 
23. **Occam**: spend, the simpler the better; cut redundant layers
