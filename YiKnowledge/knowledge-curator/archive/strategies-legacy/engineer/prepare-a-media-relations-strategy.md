## Action recommendations

1. **Five dimensions**: media + story + release + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Media**: list / preference / relationship / trust; no leakage
4. **Story**: topic / angle / evidence / case study; no leakage
5. **Release**: press release / exclusive / briefing / track; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: from media → story → release → governance → measurement gradual; no skipping levels
9. **No report-ism**: press releases are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with public-relations**: media + PR co-build
13. **Link with analyst-relations**: media + analyst co-build
14. **Link with influencer-marketing**: media + influencer co-build
15. **Link with content**: media + content co-build
16. **Link with crisis-management**: media + crisis co-build
17. **Toolchain**: Cision / Meltwater / PR Newswire / Business Wire / Muck Rack
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why a media-relations strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam's razor**: media relations simpler is better; cut redundant layers
