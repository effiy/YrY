## Action recommendations

1. **Five dimensions**: Questions + evaluation + response + governance + measurement; no missing dimension
2. **Business-value driven**: Prioritize by insight + decision + speed + cost + risk; not sloganeering
3. **Questions Question**: function / technology / price / integration / security; do not omit
4. **Evaluation Evaluate**: fit / strategy / risk / qualifications / case studies; do not omit
5. **Response Respond**: template / collaboration / review / submit / archive; do not omit
6. **Governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement Measure**: insight + decision + speed + cost + risk; do not omit
8. **Not one-shot**: Progress from questions → evaluation → response → governance → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with rfp**: RFI + RFP co-built
13. **Link with vendor-analysis**: RFI + Vendor Analysis co-built
14. **Link with competitor-analysis**: RFI + Competitor Analysis co-built
15. **Link with market-research**: RFI + Market Research co-built
16. **Link with product-strategy**: RFI + Product Strategy co-built
17. **Toolchain**: Loopio / RFPIO / Notion / Airtable / Confluence
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must RFI; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by web pages; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / decision / speed)
23. **Occam**: RFI — the simpler the better; cut redundant questions
