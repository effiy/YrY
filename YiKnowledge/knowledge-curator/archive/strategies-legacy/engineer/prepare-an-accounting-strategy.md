## Action recommendations

1. **Five dimensions**: recognition + measurement + records + reporting + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by growth + trust + speed + risk + cost; no empty slogans
3. **Recognize**: elements / timing / amount; no leakage
4. **Measure**: historical / fair value / impairment / valuation; no leakage
5. **Record**: journal entries / general ledger / sub-ledgers / vouchers; no leakage
6. **Report**: statements / notes / disclosures / audit; no leakage
7. **Governance**: owner / cadence / review / documentation / drift; no leakage
8. **Measurement strategy**: coverage + adoption + cost + risk + satisfaction; no leakage
9. **Not one-shot**: progress from recognition → measurement → records → reporting → governance → measurement; no skipping levels
10. **No report-ism**: bookkeeping is only the start; not the end
11. **No empty slogans**: every principle must mark implementation evidence; no vagueness
12. **Versioned**: strategy is versioned; evolution is traceable
13. **Link with audit**: accounting + audit co-build
14. **Link with finance**: accounting + finance co-build
15. **Link with accounts-payable**: accounting + payables co-build
16. **Link with accounts-receivable**: accounting + receivables co-build
17. **Toolchain**: SAP S/4HANA / Oracle Cloud Financials / Workday Financials / NetSuite / Microsoft Dynamics
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must an accounting strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam's razor**: accounting simpler is better; cut redundant layers
