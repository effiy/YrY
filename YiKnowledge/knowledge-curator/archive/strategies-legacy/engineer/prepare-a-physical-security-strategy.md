## Action recommendations

1. **Five dimensions**: Perimeter + monitoring + access + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by human life + trust + speed + risk + cost; not sloganeering
3. **Perimeter**: fences / gates / walls; do not omit
4. **Monitoring Surveillance**: cctv / patrol / alarm; do not omit
5. **Access Control**: access control / cards / biometrics; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: incident count + response time + false-positive rate + risk + cost; do not omit
8. **not one-shot**: from perimeter → monitoring → access → governance → measurement gradual; no skipping
9. **not report-ized**: camera count is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with cybersecurity**: physical + network co-built
13. **Link with emergency-response**: physical + emergency co-built
14. **Link with zero-trust**: physical + zero-trust co-built
15. **Link with insider-threat**: physical + insider threat co-built
16. **Link with security-awareness**: physical + security awareness co-built
17. **Toolchain**: CCTV / access control system / alarm system / visitor system / security patrol
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must physical security; worst consequence of not doing
21. **inversion thinking**: how much can be solved by iron doors and locks; if solvable do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (human life / trust / speed / risk)
23. **Occam**: physical security the simpler the better; cut redundant layers
