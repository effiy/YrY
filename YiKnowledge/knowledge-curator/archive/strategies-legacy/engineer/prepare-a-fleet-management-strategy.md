2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Asset**: vehicle / trailer / equipment / closed loop; none missing
4. **Dispatch**: route / driver / closed loop; none missing
5. **Maintenance**: preventive / closed loop / fault / closed loop; none missing

7. **Measurement**: efficiency + trust + speed + risk + cost; none missing
