## Action recommendations

1. **Five dimensions**: acquisition + operations + maintenance + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Acquire**: selection / procurement / financing / depreciation; no leakage
4. **Operate**: scheduling / routing / drivers / fuel; no leakage
5. **Maintain**: servicing / repair / detection / retirement; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: gradual from acquisition → operations → maintenance → governance → measurement; no skipping levels
9. **No report-ism**: vehicles are only the start; not the end
10. **No empty slogans**: every principle must have implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with transportation**: fleet + transportation co-build
13. **Link with shipping**: fleet + shipping co-build
14. **Link with freight**: fleet + freight co-build
15. **Link with last-mile**: fleet + last-mile co-build
16. **Link with logistics-network**: fleet + logistics network co-build
17. **Toolchain**: Samsara / Geotab / Verizon Connect / KeepTruckin / Teletrac Navman
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why fleet strategy is a must; worst consequence of not doing
21. **Inversion**: how much can defaults solve; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (growth / trust / speed / risk)
23. **Occam's razor**: simpler fleet is better; cut redundant layers
