## Action recommendations

1. **Five dimensions**: positioning + experience + communication + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by attraction + retention + cost + trust + speed; no empty slogans
3. **positioning Positioning**: differentiation + value + positioning; none missing
4. **experience Experience**: candidate + employee + departure multiple touchpoints; none missing
5. **communication Communication**: channel + content + cadence; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: awareness + attraction + retention + recommendation + cost; none missing
8. **Not one-shot**: progressive from positioning -> experience -> communication -> governance -> measurement; no skipping levels
9. **Not report-only**: slogans are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **links with employer-branding**: brand + brand building co-build
13. **links with employer-value-proposition**: brand + value proposition co-build
14. **links with corporate-branding**: employer + corporate brand co-build
15. **links with corporate-identity**: brand + identity co-build
16. **links with talent-acquisition**: brand + recruiting co-build
17. **Toolchain**: LinkedIn / Glassdoor / Indeed / Universum / Talentry
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must employer brand strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (attraction / retention / cost / trust)
23. **Occam**: employer brand the simpler the better; cut redundant layers
