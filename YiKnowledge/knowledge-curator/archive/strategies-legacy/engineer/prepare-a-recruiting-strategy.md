## Action recommendations

1. **Five dimensions**: requirement + source + assessment + experience + measurement; no missing dimension
2. **Business-value driven**: prioritize by fill-rate + time-to-hire + quality + retention + experience; no empty slogans
3. **Requirement Demand**: JD / role / headcount / priority / SLA; no leakage
4. **Source Source**: inbound / outbound / referral / agency / event; no leakage
5. **Assessment Assess**: screen / interview / case / reference / decision; no leakage
6. **Experience Experience**: communication / feedback / process / offer / rejection; no leakage
7. **Governance Governance**: owner / cadence / review / documentation / drift; no leakage
8. **Measurement Measure**: fill-rate + time-to-hire + quality + retention + experience; no leakage
9. **Not one-shot**: gradual from requirement → source → assessment → experience → measurement; no skipping levels
10. **No report-ism**: a report is just the start; not the end
11. **No empty slogans**: every principle must have implementation evidence; no vagueness
12. **Versioned**: strategy is versioned; evolution is traceable
13. **Link with talent**: Recruiting + Talent co-build
14. **Link with hiring-plan**: Recruiting + Hiring Plan co-build
15. **Link with employer-branding**: Recruiting + Employer Brand co-build
16. **Link with DEI**: Recruiting + DEI co-build
17. **Link with onboarding-flow**: Recruiting + Onboarding co-build
18. **Toolchain**: Greenhouse / Lever / Ashby / LinkedIn Recruiter / Gem / Hired
19. **Publicly discoverable**: strategy is publicly discoverable; not hidden
20. **Regular review**: evolves and updates; not one-shot
21. **First principles**: why Recruiting is necessary; worst consequence of not doing it
22. **Inversion**: how much can be solved by relying on internal transfers; if solvable, do not introduce a heavy strategy
23. **Occam's razor**: simpler Recruiting is better; cut redundant processes
