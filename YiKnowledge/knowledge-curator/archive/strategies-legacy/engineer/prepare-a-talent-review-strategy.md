## Action recommendations

1. **Five dimensions**: talent + potential + gap + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by strategy + succession + speed + risk + trust; no empty slogans
3. **Talent**: performance / potential / key / high-potential / risk; none missing
4. **Potential**: 9-box / talent graph / key roles / succession / actions; none missing
5. **Gap**: current / future / key / risk / hiring; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: strategy + succession + speed + risk + trust; none missing
8. **Not one-shot**: progress from talent → potential → gap → governance → measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Links with talent-acquisition**: Talent Review + TA co-build
13. **Links with performance-management**: Talent Review + Performance co-build
14. **Links with succession-planning**: Talent Review + Succession co-build
15. **Links with leadership**: Talent Review + Leadership co-build
16. **Links with workforce-planning**: Talent Review + Workforce co-build
17. **Toolchain**: Lattice / 15Five / Workday / ChartHop / Luno
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why Talent Review is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved by annual rating; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (strategy / succession / risk / trust) 
23. **Occam**: Talent Review: the simpler the better; cut redundant dimensions
