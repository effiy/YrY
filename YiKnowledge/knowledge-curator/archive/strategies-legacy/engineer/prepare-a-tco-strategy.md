## Action recommendations

1. **Five dimensions**: direct + indirect + hidden + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by TCO savings + revenue + renewal + NRR + decision efficiency; no empty slogans
3. **Direct**: license / hardware / implementation / integration / training; none missing
4. **Indirect**: ops / escalation / support / training / resources; none missing
5. **Hidden**: risk / interruption / safety / compliance / retirement; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: TCO savings + revenue + renewal + NRR + decision efficiency; none missing
8. **Not one-shot**: progressive from direct → indirect → hidden → governance → measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with roi-calculator**: TCO + ROI co-build
13. **Link with payback**: TCO + payback co-build
14. **Link with business-case**: TCO + business case co-build
15. **Link with value-selling**: TCO + value selling co-build
16. **Link with competitor-analysis**: TCO + competitor analysis co-build
17. **Toolchain**: Excel / Google-Sheets / Salesforce / Clari / 6sense / TCO-Calculator
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must TCO; worst consequence of not doing it
21. **Inversion**: how much can list price solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / retention)
23. **Occam**: the simpler TCO is, the better; cut redundant dimensions
