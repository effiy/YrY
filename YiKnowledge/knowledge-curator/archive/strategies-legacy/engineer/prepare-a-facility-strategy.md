## Action recommendations

1. **Five dimensions**: planning + service + maintenance + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **planning Plan**: site / space / system / standard; none missing
4. **service Service**: cleaning / catering / security / front desk; none missing
5. **maintenance Maintain**: upkeep / repair / consumables / emergency; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from planning → service → maintenance → Governance → Measurement; no skipping levels
9. **Not report-only**: buildings are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **link with property**: facility + property co-build
13. **link with real-estate**: facility + real estate co-build
14. **link with asset**: facility + asset co-build
15. **link with workplace**: facility + workplace co-build
16. **link with health-and-safety**: facility + safety co-build
17. **Toolchain**: IBM TRIRIGA / ServiceNow FMS / Archibus / Planon / FM:Systems
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must facility strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
