## Action recommendations

1. **Five dimensions**: workload + vendor + migration + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Workload**: assessment / classification / fit / priority; do not omit
4. **Vendor**: capability / price / compliance / exit; do not omit
5. **Migrate**: strategy / tools / cadence / validation; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **Not one-shot**: from workload → vendor → migration → governance → measurement progressively; no skipping
9. **Not report-ized**: moving to the cloud is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with cloud-cost**: cloud + cost co-built
13. **Link with it-strategy**: cloud + IT co-built
14. **Link with security**: cloud + security co-built
15. **Link with digital-transformation**: cloud + digital co-built
16. **Link with enterprise-architecture**: cloud + architecture co-built
17. **Toolchain**: AWS / Azure / GCP / CloudHealth / Apptio
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must cloud strategy; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by default; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: cloud the simpler the better; cut redundant layers
