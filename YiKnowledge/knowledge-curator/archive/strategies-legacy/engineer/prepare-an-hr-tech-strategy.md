## Action recommendations

1. **Five dimensions**: selection + integration + experience + governance + measurement; none can be missing
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Select**: requirements / evaluation / closed loop; do not omit
4. **Integrate**: interface / data / closed loop; do not omit
5. **Experience**: UX / adoption / closed loop; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: efficiency + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from selection → integration → experience → governance → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with hr-operations**: HRTech + HROperations co-build
13. **Link with hr-analytics**: HRTech + HRAnalytics co-build
14. **Link with people-analytics**: HRTech + PeopleAnalytics co-build
15. **Link with talent-management**: HRTech + TalentManagement co-build
16. **Link with performance-management**: HRTech + PerformanceManagement co-build
17. **Toolchain**: Workday / SAP SuccessFactors / Oracle HCM / BambooHR / Rippling
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why HR Tech is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can Excel solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk) 
23. **Occam**: HR Tech — the simpler the better; cut redundant systems
