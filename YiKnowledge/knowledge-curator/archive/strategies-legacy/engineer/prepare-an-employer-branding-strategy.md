## Action recommendations

1. **Five dimensions**: value + experience + channel + content + measurement; no missing dimension
2. **Business-value driven**: set priority by candidate NPS + recruiting cost + retention + revenue per employee + brand exposure; no empty slogans
3. **Value**: EVP + mission + values + differentiation + authenticity; none missing
4. **Experience**: candidate + onboarding + in-role + alumni + offboarding; none missing
5. **Channel**: career site + LinkedIn + Glassdoor + GitHub + events; none missing
6. **Content**: stories + case studies + video + data + transparency; none missing
7. **Measure**: candidate NPS + recruiting cost + retention + Glassdoor + brand exposure; none missing
8. **Not one-shot**: from value -> experience -> channel -> content -> measurement progressive; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with hr**: EB + HR co-build
13. **Link with talent**: EB + talent co-build
14. **Link with culture**: EB + culture co-build
15. **Link with brand-voice**: EB + brand co-build
16. **Link with content**: EB + content co-build
17. **Toolchain**: LinkedIn Talent Solutions / Glassdoor / Indeed / Breezy / TalentLyft / SmashFly / Beamery / Pathmotion
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must EB strategy; worst consequence of not doing it
21. **Inversion**: how much can be solved by relying on natural word-of-mouth; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / retention / business) 
23. **Occam**: EB, the simpler the better; cut redundant steps
