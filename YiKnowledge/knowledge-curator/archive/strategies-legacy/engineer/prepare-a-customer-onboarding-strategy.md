## Action recommendations

1. **Five dimensions**: activation + value + retention + extension + recommendation; no missing dimension
2. **Customer-value driven**: prioritize by customer scenario + ARR + time-to-value; no empty slogans
3. **Activation**: registration + auth + config + first value; no leakage
4. **Value**: milestone + time-to-Aha + north star; no leakage
5. **Retention**: core loop + notification + recall; no leakage
6. **Extension**: upgrade + cross-team + use-case expansion; no leakage
7. **Recommendation**: NPS + case study + word-of-mouth; no leakage
8. **Not one-shot**: progressive from activation -> value -> retention -> extension -> recommendation; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with customer-success**: onboarding + success co-build
13. **Link with saas-tenant**: onboarding + tenancy co-build
14. **Link with training**: onboarding + training co-build
15. **Link with metrics**: onboarding + metric co-build
16. **Link with KT**: onboarding + knowledge transfer co-build
17. **Link with docs**: onboarding + documentation co-build
18. **Link with advisory**: onboarding + advisory co-build
19. **Toolchain**: Pendo / Appcues / Userflow / Intercom / Gainsight
20. **Publicly discoverable**: strategy is publicly discoverable; not hidden
21. **Regular review**: Evolve and update; not one-shot
22. **First principles**: why must onboarding; worst consequence of not doing it
23. **Inversion**: how much can be solved by documentation + self-serve; if solvable, do not introduce heavy strategy
24. **Second-order thinking**: second-order consequence after strategy (cost / complexity / experience / business) 
25. **Occam's razor**: onboarding simpler is better; cut redundant steps
