## Action recommendations

1. **Five dimensions**: audience + story + value + risk + measurement; no missing dimension
2. **Business-value driven**: prioritize by win-rate + ACV + cycle-time + renewal + NRR; no empty slogans
3. **Audience**: executive / business / technology / finance / user; no leakage
4. **Story**: current state / pain point / vision / path / measurement; no leakage
5. **Value**: ROI / TCO / business / strategy / risk; no leakage
6. **Risk**: competition / budget / time / decision / implementation; no leakage
7. **Measure**: win-rate + ACV + cycle-time + renewal + NRR; no leakage
8. **Not one-shot**: progress gradually from audience -> story -> value -> risk -> measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Work with sales-playbook**: deal presentation + sales playbook co-build
13. **Work with deal-review**: deal presentation + deal-review co-build
14. **Work with proposal**: deal presentation + proposal document co-build
15. **Work with roi-calculator**: deal presentation + ROI calculator co-build
16. **Work with value-selling**: deal presentation + value selling co-build
17. **Toolchain**: PowerPoint / Google Slides / Beautiful.ai / Pitch / Gong / Salesforce
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why a deal presentation is needed; worst consequence of not doing it
21. **Inversion**: how much can be solved by improvising; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (cost / risk / revenue / retention) 
23. **Occam's razor**: deal presentation simpler is better; cut redundant pages
