## Action recommendations

1. **Five dimensions**: material + spiritual + experience + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by efficiency + trust + speed + risk + cost; no empty slogans
3. **Material**: base / variable / equity / bonus; none missing
4. **Recognition**: recognition / awards / values; none missing
5. **Experience**: development / benefits / well-being / experience; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progress from material → spiritual → experience → governance → measurement; no skipping levels
9. **Not report-only**: bonus categories are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with total-rewards**: bonus + all-side rewards co-build
13. **Link with recognition**: bonus + recognition co-build
14. **Link with employee-compensation**: bonus + employee compensation co-build
15. **Link with employee-benefits**: bonus + employee benefits co-build
16. **Link with employee-experience**: bonus + employee experience co-build
17. **Toolchain**: Workday / Bonusly / Awardco / Kazoo / Nectar
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must a bonus strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: bonus the simpler the better; cut redundant layers
