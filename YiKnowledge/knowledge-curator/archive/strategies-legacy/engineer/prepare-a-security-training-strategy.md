## Action recommendations

1. **Five dimensions**: courses + drills + assessment + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Course**: onboarding / role-based; do not omit
4. **Drill**: table-top / hands-on; do not omit
5. **Assess**: exam / phishing simulation / behavior observation; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: completion rate + pass rate + behavior change + risk + cost; do not omit
8. **Not one-shot**: from courses → drills → assessment → governance → measurement progressive; no skipping
9. **Not report-ized**: headcount trained is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with security-awareness**: training + awareness co-built
13. **Link with phishing-simulation**: training + phishing simulation co-built
14. **Link with secure-coding**: training + secure coding co-built
15. **Link with secure-sdlc**: training + secure SDLC co-built
16. **Link with insider-threat**: training + insider threat co-built
17. **Toolchain**: KnowBe4 / Proofpoint Security Awareness / Cofense / SANS / internal LMS
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why security training is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by self-study; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: simpler security training is better; cut redundant layers
