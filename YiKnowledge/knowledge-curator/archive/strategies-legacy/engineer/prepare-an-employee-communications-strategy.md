## Action recommendations

1. **five dimensions**: audience + message + channel + governance + measurement; no missing dimension
2. **Business-value driven**: prioritise by growth + trust + speed + risk + cost; no empty slogans
3. **audience Audience**: onboarding / in-role / offboarding / transfer; no leakage
4. **message Message**: policy / business / welfare / change; no leakage
5. **channel Channel**: email / intranet / IM / town hall; no leakage
6. **Governance Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: from audience → message → channel → governance → measurement gradual; no skipping levels
9. **no report-ism**: announcements are only the start; not the end
10. **no empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **link with internal-communications**: employee + internal co-build
13. **link with external-communications**: employee + external co-build
14. **link with organizational-culture**: employee + culture co-build
15. **link with employer-branding**: employee + employer brand co-build
16. **link with corporate-communications**: employee + corporate communication co-build
17. **Toolchain**: Workday Peakon / Simpplr / Staffbase / Poppulo / Microsoft Viva
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must employee communication strategy; worst consequence of not doing
21. **Inversion**: how much can be solved by default; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (growth / trust / speed / risk)
23. **Occam's razor**: employee communication simpler is better; cut redundant layers
