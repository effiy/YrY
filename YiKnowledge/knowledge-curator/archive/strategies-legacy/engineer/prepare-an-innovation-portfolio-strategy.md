## Action recommendations

1. **Five dimensions**: portfolio + assess + prioritize + governance + measurement; no missing dimension
2. **business-value driven**: by growth + speed + risk + cost + differentiation set priority; not sloganeering
3. **portfolio Portfolio**: core / adjacent / disruptive / option; do not omit
4. **assess Assess**: strategy / market / technology / financial; do not omit
5. **prioritize Prioritize**: score / sort / resource / exit; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: from portfolio → assess → prioritize → governance → measurement gradual; no skipping
9. **not report-ism**: sort is only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **and innovation link**: portfolio + innovation co-build
13. **and open-innovation link**: portfolio + open co-build
14. **and innovation-lab link**: portfolio + lab co-build
15. **and product-innovation link**: portfolio + product co-build
16. **and research-and-development link**: portfolio + R&D co-build
17. **Toolchain**: Brightidea / Itonics / Hype Innovation / Planbox / Spira
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must innovation portfolio strategy; worst consequence of not doing
21. **inversion thinking**: rely on default how much can be solved; if solvable, do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (growth / speed / risk / cost) 
23. **Occam**: innovation portfolio the simpler the better; cut redundant layers
