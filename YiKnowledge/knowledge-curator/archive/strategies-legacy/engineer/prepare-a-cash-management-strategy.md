## Action recommendations

1. **Five dimensions**: inflow + outflow + liquidity + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Inflow**: collections / notes / closed loop; no leakage
4. **Outflow**: payments / payroll / closed loop; no leakage
5. **Liquidity**: pooling / sweeping / closed loop; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: efficiency + trust + speed + risk + cost; no leakage
8. **Not one-shot**: gradual from inflow -> outflow -> liquidity -> governance -> measurement; no skipping levels
9. **No report-ism**: reports are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with financial-planning**: CashManagement + FinancialPlanning co-build
13. **Link with treasury**: CashManagement + Treasury co-build
14. **Link with working-capital**: CashManagement + WorkingCapital co-build
15. **Link with accounts-payable**: CashManagement + AccountsPayable co-build
16. **Link with accounts-receivable**: CashManagement + AccountsReceivable co-build
17. **Toolchain**: Kyriba / FIS / ION / Wall Street Systems / SAP S/4HANA
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must CashManagement; worst consequence of not doing
21. **Inversion**: how much can be solved by relying on bank balances; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (efficiency / trust / speed / risk)
23. **Occam's razor**: simpler CashManagement is better; cut redundant accounts
