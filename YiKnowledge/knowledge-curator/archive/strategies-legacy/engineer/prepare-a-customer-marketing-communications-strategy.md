## Action recommendations

1. **Five dimensions**: segment + content + channel + journey + measurement; no missing dimension
2. **Business-value driven**: prioritize by renewal + expansion + NPS + referrals + revenue share; no empty slogans
3. **Segment**: high-value + at-risk + new + existing + churned; none missing
4. **Content**: Case study + value + education + escalation + alert; none missing
5. **Channel**: email / in-app / call / event / community; none missing
6. **Journey**: onboarding / adoption / advocacy / renewal / win-back; none missing
7. **Measurement**: renewal + expansion + NPS + referrals + satisfaction; none missing
8. **Not one-shot**: progressive from segment → content → channel → journey → measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Links with customer-success**: CMC + CS co-build
13. **Links with customer-communications**: CMC + communications co-build
14. **Links with customer-advocacy**: CMC + advocacy co-build
15. **Links with lifecycle-marketing**: CMC + LCM co-build
16. **Links with customer-journey**: CMC + journey co-build
17. **Toolchain**: Gainsight / Totango / ChurnZero / Marketo / HubSpot / Customer.io / Iterable / AppFusions
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why a CMC strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can reactive customer service solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / retention / business)
23. **Occam**: the simpler CMC is, the better; cut redundant steps
