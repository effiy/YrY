## Action recommendations

1. **Five dimensions**: identify + design + execute + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Identify**: end-to-end / subprocess / activity / role; none missing
4. **Design**: benchmark / standard / improve / consistent; none missing
5. **Execute**: people / systems / data / monitoring; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progress gradually from identify → design → execute → governance → measurement; no skipping levels
9. **Not report-only**: drawing diagrams is only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with business-architecture**: process + business architecture co-built
13. **Link with process-optimization**: process + optimization co-built
14. **Link with process-automation**: process + automation co-built
15. **Link with operating-model**: process + operating model co-built
16. **Link with value-stream**: process + value stream co-built
17. **Toolchain**: ARIS / BiZZdesign / Signavio / Microsoft Visio / Lucidchart
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why a business process strategy is necessary; the worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: the simpler the business process, the better; cut redundant layers
