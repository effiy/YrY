## Action recommendations

1. **Five dimensions**: audience + script + cadence + channel + Measurement; no missing dimension
2. **Business-value driven**: prioritize by connect rate + conversion + leads + revenue + experience; no empty slogans
3. **audience Audience**: ICP / role / list / segment / region; none missing
4. **script Script**: opener / probing / value / objection / close; none missing
5. **cadence Cadence**: frequency / time slot / interval / follow-up / exit; none missing
6. **channel Channel**: phone / IVR / SMS / broadcast / hybrid; none missing
7. **Governance**: owner / cadence / review / docs / drift; none missing
8. **Measure**: connect rate + conversion + leads + revenue + experience; none missing
9. **Not one-shot**: from audience -> script -> cadence -> channel -> Measurement progressive; no skipping levels
10. **Not report-only**: reports are only the starting point; not the endpoint
11. **No empty slogans**: every principle must have landed evidence; no ambiguity
12. **Versioned**: strategy has versions; evolution is traceable
13. **Link with outbound**: Telemarketing + Outbound co-build
14. **Link with cold-outreach**: Telemarketing + Cold Outreach co-build
15. **Link with lead-scoring**: Telemarketing + Lead Scoring co-build
16. **Link with territory-plan**: Telemarketing + Territory Plan co-build
17. **Link with sdr**: Telemarketing + SDR co-build
18. **Toolchain**: Outreach / Salesloft / Aircall / RingCentral / NICE
19. **Publicly accessible**: strategy accessible to everyone; not hidden
20. **Regular review**: evolve and update; not one-shot
21. **First principles**: why must Telemarketing; worst consequence of not doing it
22. **Inversion**: how much can email + automation solve; if solvable, don't introduce a heavy strategy
23. **Occam**: Telemarketing simpler is better; cut redundant actions
