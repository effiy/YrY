## Action recommendations

1. **Five dimensions**: DMAIC (define + measure + analyze + improve + control); no missing dimension
2. **Business-value driven**: set priority by efficiency + trust + speed + risk + cost; no empty slogans
3. **Define**: problem / customer / scope / target / team; no leakage
4. **Measure**: data / baseline / defect / capacity / stability; no leakage
5. **Analyze**: cause / validation / priority / fishbone / hypothesis; no leakage
6. **Improve**: solution / experiment / implement / validation / closed loop; no leakage
7. **Control**: standard / monitor / feedback / documentation / persistence; no leakage
8. **Not one-shot**: progressive from define → measure → analyze → improve → control; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with lean**: SS + Lean co-build
13. **Link with quality-management**: SS + Quality co-build
14. **Link with process-excellence**: SS + Process co-build
15. **Link with operations**: SS + Ops co-build
16. **Link with coo**: SS + COO co-build
17. **Toolchain**: Minitab / JMP / SigmaXL / EngineRoom / Power BI
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why SS is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved by experience; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after the strategy (efficiency / trust / speed / risk) 
23. **Occam's razor**: SS, simpler is better; cut redundant tools
