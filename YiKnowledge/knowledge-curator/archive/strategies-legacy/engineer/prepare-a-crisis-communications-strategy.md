## Action recommendations

1. **Five dimensions**: audience + content + channel + cadence + Measurement; no missing dimension
2. **Business-value driven**: set priority by trust + retention + revenue + Risk + SOV-sentiment; no empty slogans
3. **Audience**: customer + media + analyst + government + employee + partners; no leakage
4. **Content**: facts + action + responsibility + remediation + follow-up + commentary; no leakage
5. **Channel**: email / website / social / media / intranet / hotline; no leakage
6. **Cadence**: T+0 / T+1h / T+4h / T+24h / follow-up; no leakage
7. **Measurement**: trust + retention + revenue + Risk + SOV-sentiment; no leakage
8. **Not one-shot**: gradual from audience -> content -> channel -> cadence -> Measurement; no skipping levels
9. **no report-ism**: report is just the start; not the end
10. **no empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with corporate-communications**: crisis + corporate communication co-build
13. **Link with public-relations**: crisis + PR co-build
14. **Link with incident-postmortem**: crisis + Retrospective co-build
15. **Link with business-continuity**: crisis + BCP co-build
16. **Link with internal-communications**: crisis + internal communication co-build
17. **Toolchain**: Everbridge / OnSolve / Rave-Mobile-Safety / AlertMedia / Crises-Control / Meltwater / Cision / Prowly
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why must crisis communication strategy; worst consequence of not doing
21. **Inversion**: how much can be solved by relying on ad-hoc response when it happens; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (cost / Risk / trust / business)
23. **Occam's razor**: crisis communication simpler is better; cut redundant steps
