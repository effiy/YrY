## Action recommendations

1. **Five dimensions**: assets + metadata + workflow + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by speed + consistency + cost + trust + risk; not sloganeering
3. **Asset**: image / video / doc / audio / 3D; do not omit
4. **Metadata**: tag / category / rights / version / relationship; do not omit
5. **Workflow**: upload / review / annotation / publish / archive; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: speed + consistency + cost + trust + risk; do not omit
8. **Not one-shot**: progressive from assets → metadata → workflow → governance → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Links with content-operations**: DAM + ContentOps co-built
13. **Links with content**: DAM + Content co-built
14. **Links with content-governance**: DAM + Governance co-built
15. **Links with brand**: DAM + Brand co-built
16. **Links with content-calendar**: DAM + Calendar co-built
17. **Toolchain**: Bynder / Brandfolder / Adobe AEM / Canto / Frontify
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must DAM; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by a shared drive; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (speed / consistency / cost / trust)
23. **Occam**: DAM the simpler the better; cut redundant fields
