## Action recommendations

1. **Five dimensions**: input + node + feedback + compound benefit + Measurement; no missing dimension
2. **Business-value driven**: prioritize by flywheel contribution to revenue + LTV + retention + conversion + NPS; no empty slogans
3. **input Input**: content / users / paid / recommendation / network; none missing
4. **node Node**: touchpoint + conversion + activation + retention + recommendation; none missing
5. **feedback Feedback**: bidirectional + data + copy + UX + algorithm; none missing
6. **compound Compound**: time + network + data + brand + ecosystem; none missing
7. **Measure**: flywheel contribution to revenue + LTV + retention + conversion + NPS; none missing
8. **Not one-shot**: progressive from input -> node -> feedback -> compound benefit -> Measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **link with growth-experiments**: Flywheel + experiment co-build
13. **link with pirate-funnel**: Flywheel + AARRR co-build
14. **link with north-star-metric**: Flywheel + North-star co-build
15. **link with product-analytics**: Flywheel + product analytics co-build
16. **link with self-serve-growth**: Flywheel + self-serve growth co-build
17. **Toolchain**: Amplitude / Mixpanel / PostHog / Statsig / GrowthBook / Heap / Iterately
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why must flywheel; worst consequence of not doing it
21. **Inversion**: how much can one-shot ad spend solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / brand) 
23. **Occam**: Flywheel the simpler the better; cut redundant steps
