## Action recommendations

1. **Five dimensions**: audience + message + cadence + channel + measurement; none can be missing
2. **Business-value driven**: prioritize by conversion + meetings + revenue + speed + experience; not sloganeering
3. **Audience**: ICP / role / pain points / signals / intent; do not omit
4. **Message**: hook / value / personalization / CTA / A/B; do not omit
5. **Cadence**: step count / interval / channel / trigger / exit; do not omit
6. **Channel**: email / phone / social / video / direct-mail; do not omit
7. **Governance**: owner / cadence / review / documentation / drift; do not omit
8. **Measurement**: conversion + meetings + revenue + speed + experience; do not omit
9. **Not one-shot**: progressive from audience → message → cadence → channel → measurement; no skipping
10. **Not report-ized**: reports are only the start; not the end
11. **Not sloganeering**: every principle must have landing evidence; not vague
12. **Versioned**: strategy has versions; evolution is traceable
13. **Link with lead-scoring**: Outreach + Scoring co-build
14. **Link with abm**: Outreach + ABM co-build
15. **Link with sales-development**: Outreach + SDR co-build
16. **Link with icp**: Outreach + ICP co-build
17. **Link with value-selling**: Outreach + Value Selling co-build
18. **Toolchain**: Outreach / Salesloft / Apollo / Lemlist / ZoomInfo / Salesforce
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why Cold Outreach is necessary; worst consequence of not doing it
22. **Inversion thinking**: how much can inbound solve; if solvable, don't introduce a heavy strategy
23. **Occam**: Outreach — the simpler the better; cut redundant assumptions
