## Action recommendations

1. **Five dimensions**: define + collection + analysis + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by growth + trust + speed + risk + cost; no empty slogans
3. **Define**: name / formula / unit / threshold; no gap
4. **Collection**: source / frequency / responsibility / quality; no gap
5. **Analysis**: comparison / trend / attribution / prediction; no gap
6. **Governance**: owner / cadence / review / documentation / drift; no gap
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; no gap
8. **Not one-shot**: gradual from define → collection → analysis → governance → measurement; no skipping levels
9. **Not report-only**: data are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Linked with business-performance**: metrics + performance co-build
13. **Linked with business-strategy**: metrics + business strategy co-build
14. **Linked with corporate-strategy**: metrics + corporate strategy co-build
15. **Linked with governance**: metrics + governance co-build
16. **Linked with operating-model**: metrics + operating model co-build
17. **Toolchain**: Tableau / Power BI / Looker / Anaplan / Adaptive Insights
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why a business metrics strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after the strategy (growth / trust / speed / risk)
23. **Occam's razor**: the simpler business metrics are, the better; cut redundant layers
