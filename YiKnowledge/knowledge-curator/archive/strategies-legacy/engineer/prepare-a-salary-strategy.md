## Action recommendations

1. **Five dimensions**: structure + benchmark + adjust + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Structure**: base / variable / benefits / long-term; none missing
4. **benchmark Benchmark**: role / grade / market / position; none missing
5. **adjust Adjust**: general adjust / individual adjust / promotion / differential; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from structure → benchmark → adjust → governance → measurement; no skipping levels
9. **Not report-only**: numbers are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **link with compensation**: salary + total compensation co-build
13. **link with pay**: salary + pay co-build
14. **link with incentive**: salary + incentive co-build
15. **link with rewards**: salary + total rewards co-build
16. **link with job-evaluation**: salary + job evaluation co-build
17. **Toolchain**: Mercer / Radford / Payscale / Salary.com / Korn Ferry
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must salary strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: salary the simpler the better; cut redundant layers
