## Action recommendations

1. **Five dimensions**: brand + network + content + interaction + measurement; no missing dimension
2. **Business-value driven**: prioritize by leads + meetings + revenue + influence + experience; no empty slogans
3. **brand Brand**: profile / avatar / banner / tagline / SEO; no leakage
4. **network Network**: connections / follows / circles / champion / KOL; no leakage
5. **content Content**: original / reposts / comments / video / live; no leakage
6. **interaction Engagement**: comments / DM / groups / events / private messages; no leakage
7. **Governance Governance**: owner / cadence / review / documentation / drift; no leakage
8. **Measurement Measure**: leads + meetings + revenue + influence + experience; no leakage
9. **Not one-shot**: gradual from brand → network → content → interaction → measurement; no skipping levels
10. **no report-ism**: report is just the start; not the end
11. **no empty slogans**: every principle must mark implementation evidence; no vagueness
12. **Versioned**: strategy is versioned; evolution is traceable
13. **links with cold-outreach**: Social + Outreach co-build
14. **links with abm**: Social + ABM co-build
15. **links with content**: Social + Content co-build
16. **links with personal-branding**: Social + Personal Brand co-build
17. **links with sales-enablement**: Social + Enablement co-build
18. **Toolchain**: LinkedIn Sales Navigator / Hootsuite / Sprout / Buffer / Salesforce
19. **Publicly discoverable**: strategy is publicly discoverable; not hidden
20. **Regular review**: evolve and update; not one-shot
21. **First principles**: why Social Selling is necessary; worst consequence of not doing it
22. **Inversion**: how much can cold-call solve; if solvable, do not introduce a heavy strategy
23. **Occam's razor**: Social Selling — simpler is better; cut redundant actions
