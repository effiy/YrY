## Action recommendations

1. **Five dimensions**: ownership + protection + monetization + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by value + risk + trust + speed + cost; not sloganeering
3. **Ownership Ownership**: invention / filing / ownership; do not omit
4. **Protection Protection**: filing / monitoring / enforcement / defense; do not omit
5. **Monetize Monetize**: licensing / transfer / equity / litigation; do not omit
6. **Governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement Measure**: coverage + adoption + cost + value + risk; do not omit
8. **Not one-shot**: progressive from ownership → protection → monetization → governance → measurement; no skipping
9. **Not report-ized**: filing is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with legal-ops**: IP + legal ops co-built
13. **Link with intellectual-property**: operations + IP co-built
14. **Link with brand-protection**: IP + brand protection co-built
15. **Link with brand-licensing**: IP + brand licensing co-built
16. **Link with contract-operations**: IP + contract operations co-built
17. **Tooling**: Anaqua / CPA Global / PatSnap / Clarivate / Innography
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why an IP operations strategy is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by default; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (value / risk / trust / speed)
23. **Occam**: IP operations the simpler the better; cut redundant layers
