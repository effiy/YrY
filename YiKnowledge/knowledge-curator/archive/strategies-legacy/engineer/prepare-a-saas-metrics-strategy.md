## Action recommendations

1. **Five dimensions**: definition + calculation + decomposition + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by SaaS metrics' impact on revenue + renewal + NRR + retention + efficiency; no empty slogans
3. **Definition Definition**: growth / retention / efficiency / monetization / health; no leakage
4. **Calculation Calculation**: ARR / NRR / GRR / LTV / CAC / Magic-Number / Rule-of-40; no leakage
5. **Decompose Decomposition**: cohort / segment / stage / channel / industry; no leakage
6. **Governance Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement Measure**: SaaS metrics' impact on revenue + renewal + NRR + retention + efficiency; no leakage
8. **Not one-shot**: gradual from definition → calculation → decomposition → governance → measurement; no skipping levels
9. **No report-ism**: a report is just the start; not the end
10. **No empty slogans**: every principle must have implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with north-star-metric**: SaaS metrics + north star co-build
13. **Link with pirate-funnel**: SaaS metrics + pirate metrics co-build
14. **Link with arr**: SaaS metrics + ARR co-build
15. **Link with nrr**: SaaS metrics + NRR co-build

17. **Toolchain**: Snowflake / Tableau / Looker / ChartMogul / Baremetrics / SaaSOptics / Salesforce
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolves and updates; not one-shot
20. **First principles**: why SaaS metrics are necessary; worst consequence of not doing it
