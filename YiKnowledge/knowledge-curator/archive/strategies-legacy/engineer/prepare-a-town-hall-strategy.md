## Action recommendations

1. **five dimensions**: cadence + agenda + interaction + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by adoption + trust + speed + risk + cost; no empty slogans
3. **cadence Cadence**: frequency / duration / cancel / reschedule / buffer; no leakage
4. **agenda Agenda**: topic / priority / buffer / closed loop / audit trail; no leakage
5. **interaction Interaction**: Q&A / voting / anonymous / switch broadcast / closed loop; no leakage
6. **Governance Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement Measure**: adoption + trust + speed + risk + cost; no leakage
8. **Not one-shot**: from cadence -> agenda -> interaction -> Governance -> Measurement gradual; no skipping levels
9. **no report-ism**: report is just the start; not the end
10. **no empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with internal-communications**: TH + InternalComms co-build
13. **Link with executive-communications**: TH + EC co-build
14. **Link with all-hands**: TH + AllHands co-build
15. **Link with corporate-communications**: TH + CorpComms co-build
16. **Link with leadership**: TH + Leadership co-build
17. **Toolchain**: Slido / Mentimeter / Pigeonhole / Staffbase / Yotribe
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must TH; worst consequence of not doing it
21. **Inversion**: how much can email solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (adoption / trust / speed / risk)
23. **Occam's razor**: TH simpler is better; cut redundant steps
