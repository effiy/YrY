## Action recommendations

1. **Five dimensions**: self + path + tools + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by talent + trust + speed + risk + cost; not sloganeering
3. **Self**: interest / strengths / values / goals / assessment; do not omit
4. **Path**: vertical / lateral / dual-ladder / lattice / portfolio; do not omit
5. **Tools**: map / mentor / coach / projects / feedback; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: talent + trust + speed + risk + cost; do not omit
8. **not one-shot**: progressive from self → path → tools → governance → measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **Link with mentoring**: CD + Mentoring co-build
13. **Link with mobility**: CD + Mobility co-build
14. **Link with learning-and-development**: CD + L&D co-build
15. **Link with talent-review**: CD + Talent co-build
16. **Link with job-architecture**: CD + JobArchitecture co-build
17. **Toolchain**: Fuel50 / Gloat / Eightfold / Workday Career / Degreed
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must CD; worst consequence of not doing it
21. **inversion thinking**: how much can promotion solve; if solvable, don't introduce a heavy strategy
22. **second-order thinking**: second-order consequences after strategy (talent / trust / speed / risk)
23. **Occam**: CD the simpler the better; cut redundant paths
