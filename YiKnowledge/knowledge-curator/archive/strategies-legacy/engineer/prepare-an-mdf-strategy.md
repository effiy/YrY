## Action recommendations

1. **Five dimensions**: budget + application + approval + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by MDF ROI + revenue + leads + conversion + retention; no empty slogans
3. **Budget**: pool / tier / source / cadence / threshold; no leakage
4. **Application**: use / plan / expected / reimbursement / credentials; no leakage
5. **Approval**: standard / cadence / SLA / rejection / escalation; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: MDF ROI + revenue + leads + conversion + retention; no leakage
8. **Not one-shot**: progressive from budget → application → approval → governance → measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with partner-compensation**: MDF + compensation co-build
13. **Link with partner-marketing**: MDF + partner marketing co-build
14. **Link with co-marketing**: MDF + co-marketing co-build
15. **Link with budget-planning**: MDF + budget co-build
16. **Link with partner-program**: MDF + partner program co-build
17. **Toolchain**: Salesforce PRM / Impartner / Allbound / Tackle / Marketo
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must MDF; worst consequence of not doing
21. **Inversion**: how much can rebates solve; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (cost / risk / revenue / retention)
23. **Occam's razor**: simpler MDF is better; cut redundant process
