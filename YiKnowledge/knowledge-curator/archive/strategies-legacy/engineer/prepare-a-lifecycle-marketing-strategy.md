## Action recommendations

1. **Five dimensions**: stage + trigger + content + channel + measurement; no missing dimension
2. **Business-value driven**: prioritize by activation + retention + repurchase + LTV + churn drop; no empty slogans
3. **Stages**: onboarding + engagement + retention + win-back + reactivation; none missing
4. **Trigger**: behavior + time + attribute + event + threshold; none missing
5. **Content**: welcome + education + case study + hint + warning + recall; none missing
6. **Channel**: email + push + in-app + SMS + community + phone; none missing
7. **Measure**: open + click + conversion + retention + LTV + unsubscribe; none missing
8. **Not one-shot**: from stage → trigger → content → channel → measurement progressive; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with customer-journey**: lifecycle + journey co-build
13. **Link with customer-success**: lifecycle + customer success co-build
14. **Link with retention**: lifecycle + retention co-build
15. **Link with churn-reduction**: lifecycle + churn co-build
16. **Link with product-analytics**: lifecycle + measurement co-build
17. **Toolchain**: Lifecycle-Marketing-Framework / Customer.io / Braze / Iterable / Intercom / Appcues / Userflow / OneSignal / Braze / Vero
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why lifecycle marketing is necessary; worst consequence of not doing it
21. **Inversion**: how much can product nature solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / retention / business)
23. **Occam**: lifecycle the simpler the better; cut redundant steps
