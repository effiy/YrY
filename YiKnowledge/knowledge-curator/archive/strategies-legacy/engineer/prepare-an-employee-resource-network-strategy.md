## Action recommendations

1. **Five dimensions**: connect + resource + support + governance + measurement; no missing dimension
2. **business-value driven**: by efficiency + trust + speed + risk + cost set priority; not sloganeering
3. **connect Connect**: theme / role / experience / interest; do not omit
4. **resource Resource**: content / tools / platform / data; do not omit
5. **support Support**: mentor / coach / peer / expert; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: from connect → resource → support → governance → measurement gradual; no skipping
9. **not report-ism**: member count is only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **and employee-resource-group link**: network + resource group co-build
13. **and employee-affinity-group link**: network + affinity group co-build
14. **and employee-engagement link**: network + engagement co-build
15. **and inclusion-belonging link**: network + inclusion-belonging co-build
16. **and employee-wellbeing link**: network + wellbeing co-build
17. **Toolchain**: Disco / ERGify / Teambuild / Bonusly / Workday
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must employee resource network strategy; worst consequence of not doing
21. **inversion thinking**: rely on default how much can be solved; if solvable, do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk) 
23. **Occam**: employee resource network the simpler the better; cut redundant layers
