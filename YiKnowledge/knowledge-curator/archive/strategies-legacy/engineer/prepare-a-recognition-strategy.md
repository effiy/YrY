## Action recommendations

1. **Five dimensions**: design + channel + frequency + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by adoption + trust + speed + risk + cost; no empty slogans
3. **Design**: values / behavior / standard / tier / fairness; no leakage
4. **Channel**: peer / manager / system / public / ceremony; no leakage
5. **Frequency**: real-time / weekly / monthly / quarterly / annual; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: adoption + trust + speed + risk + cost; no leakage
8. **Not one-shot**: gradual from design → channel → frequency → governance → measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with total-rewards**: RN + TR co-build
13. **Link with employee-engagement**: RN + Engagement co-build
14. **Link with culture**: RN + Culture co-build
15. **Link with performance-management**: RN + Performance co-build
16. **Link with chro**: RN + CHRO co-build
17. **Toolchain**: Bonusly / Kazoo / Workhuman / Awardco / Nectar
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why RN is necessary; worst consequence of not doing it
21. **Inversion**: how much can salary raises solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after the strategy (adoption / trust / speed / risk)
23. **Occam's razor**: simpler RN is better; cut redundant layers
