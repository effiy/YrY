## Action recommendations

1. **Five dimensions**: vision + strategy + organization + Governance + Measurement; no missing dimension
2. **Business-value driven**: set priority with value + trust + speed + Risk + cost; no empty slogans
3. **Vision**: mission / vision / value / cadence / communication; no leakage
4. **Strategy**: direction / resource / priority / partner / closed loop; no leakage
5. **Organization**: leadership / culture / talent / decision / boundary; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: value + trust + speed + Risk + cost; no leakage
8. **Not one-shot**: gradual from vision → strategy → organization → Governance → Measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with coo**: CEO + COO Co-build
13. **Link with cfo**: CEO + CFO Co-build
14. **Link with board-of-directors**: CEO + Board Co-build
15. **Link with leadership**: CEO + Leadership Co-build
16. **Link with corporate-governance**: CEO + Governance Co-build
17. **Toolchain**: Cambridge Leadership / McKinsey CEO / BCG CEO / Spencer Stuart / Heidrick
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why must CEO; worst consequence of not doing
21. **Inversion**: how much can be solved relying on middle management; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (value / trust / speed / Risk)
23. **Occam's razor**: CEO simpler is better; cut redundant layers
