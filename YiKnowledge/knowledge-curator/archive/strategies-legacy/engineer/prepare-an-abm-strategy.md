## Action recommendations

1. **Five dimensions**: account + content + channel + orchestration + measurement; no missing dimension
2. **Business-value driven**: prioritize by ABM revenue + conversion + ACV + speed + retention; not sloganeering
3. **Account**: tier / ICP / intent / cluster / industry; do not omit
4. **Content**: message / asset / personalization / stage / trigger; do not omit
5. **Channel**: email / ads / direct mail / social / event; do not omit
6. **Orchestration**: cadence / trigger / escalation / linkage / governance; do not omit
7. **Governance**: owner / cadence / review / documentation / drift; do not omit
8. **Measure**: ABM revenue + conversion + ACV + speed + retention; do not omit
9. **Not one-shot**: from account → content → channel → orchestration → measurement progressive; no skipping
10. **Not report-ized**: reports are only the start; not the end
11. **Not sloganeering**: every principle must have landing evidence; not vague
12. **Versioned**: strategy has versions; evolution is traceable
13. **Link with abx**: ABM + ABX co-built
14. **Link with account-tiering**: ABM + Tiering co-built
15. **Link with icp**: ABM + ICP co-built
16. **Link with account-plan**: ABM + Account Plan co-built
17. **Link with marketing-attribution**: ABM + Attribution co-built
18. **Toolchain**: 6sense / Demandbase / RollWorks / Salesforce / Marketo / Outreach
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why ABM is necessary; worst consequence of not doing it
22. **Inversion thinking**: how much can broad-funnel solve; if solvable, do not introduce a heavy strategy
23. **Occam**: ABM the simpler the better; cut redundant assumptions
