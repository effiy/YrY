- Links with competitor-analysis + competitive-intelligence + sales-enablement + sales-coaching + positioning
- Publicly accessible; not hidden

## Action recommendations

1. **Five dimensions**: competitor + advantage + weakness + tactic + measurement; no missing dimension
2. **Business-value driven**: prioritize by win-rate + ACV + speed + retention + experience; no empty slogans
3. **Competitor**: direct / indirect / adjacent / emerging / substitute; none missing
4. **Advantage**: differentiation / value / case study / data / evidence; none missing
5. **Weakness**: capability / price / concentration / service / strategy; none missing
6. **Tactic**: trap / problem / rebuttal / escalate / exit; none missing
7. **Governance**: owner / cadence / review / docs / drift; none missing
8. **Measure**: win-rate + ACV + speed + retention + experience; none missing
9. **Not one-shot**: from competitor → advantage → weakness → tactic → measurement progressive; no skipping levels
10. **Not report-only**: reports are only the starting point; not the endpoint
11. **No empty slogans**: every principle must have landed evidence; no ambiguity
12. **Versioned**: strategy has versions; evolution is traceable
13. **Link with competitor-analysis**: Battle Card + Competitor Analysis co-build
14. **Link with competitive-intelligence**: Battle Card + CI co-build
15. **Link with sales-enablement**: Battle Card + Enablement co-build
16. **Link with sales-coaching**: Battle Card + Coaching co-build
17. **Link with positioning**: Battle Card + Positioning co-build
18. **Toolchain**: Klue / Crayon / Crossbeam / Salesforce / Highspot
19. **Publicly accessible**: strategy accessible to everyone; not hidden
20. **Regular review**: Evolve and update; not one-shot
21. **First principles**: why must Battle Card; worst consequence of not doing it
22. **Inversion**: how much can be solved by sales experience; if solvable, don't introduce a heavy strategy
23. **Occam**: Battle Card the simpler the better; cut redundant items
