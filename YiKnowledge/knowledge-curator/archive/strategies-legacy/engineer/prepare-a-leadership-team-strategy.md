1. **Five dimensions**: composition + operation + development + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **composition Compose**: role / diversity / complementary / capability; none missing
4. **operation Operate**: cadence / decision / conflict / communication; none missing
5. **development Develop**: coaching / experience / retrospective / peer; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from composition → operation → development → governance → measurement; no skipping levels
9. **Not report-only**: headcount is only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
