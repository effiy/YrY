## Action recommendations

1. **Five dimensions**: Catalog + Experience + Fulfillment + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by conversion + order value + retention + trust + cost; not sloganeering
3. **Catalog**: category / attribute / price / inventory / related; do not omit
4. **Experience**: search / detail / cart / checkout / after-sales; do not omit
5. **Fulfillment**: order / logistics / warehousing / returns / customer service; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: conversion + order value + retention + trust + cost; do not omit
8. **Not one-shot**: progressive from Catalog → Experience → Fulfillment → Governance → Measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Web linkage**: Ecommerce + Web co-build
13. **PIM linkage**: Ecommerce + PIM co-build
14. **DAM linkage**: Ecommerce + DAM co-build
15. **Pricing linkage**: Ecommerce + Pricing co-build
16. **Content linkage**: Ecommerce + Content co-build
17. **Toolchain**: Shopify / Salesforce Commerce / BigCommerce / commercetools / Magento
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must Ecommerce exist; worst consequence of not doing it
21. **Inversion thinking**: how much can offline channels solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (conversion / retention / trust / cost)
23. **Occam**: Ecommerce the simpler the better; cut redundant plugins
