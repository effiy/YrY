## Action recommendations

1. **Five dimensions**: new + expansion + churn + contraction + Measurement; no missing dimension
2. **Business-value driven**: prioritize by ARR growth + renewal + NRR + win-rate + ACV; no empty slogans
3. **new**: new customer / new revenue / cohort / segment / channel; none missing
4. **expansion**: expansion / cross-sell / upsell / multi-year / multi-product; none missing
5. **churn**: stream loss / customer / revenue / cohort / reason; none missing
6. **contraction**: contraction / downgrade / subtract seats / subtract product / subtract years; none missing
7. **Measure**: ARR growth + renewal + NRR + win-rate + ACV; none missing
8. **Not one-shot**: progressive from new -> expansion -> churn -> contraction -> Measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **link with saas-metrics**: ARR + SaaS metric co-build
13. **link with nrr**: ARR + NRR co-build
14. **link with grr**: ARR + GRR co-build
15. **link with acv**: ARR + ACV co-build
16. **link with renewal-forecast**: ARR + renewal forecast co-build
17. **Toolchain**: Snowflake / ChartMogul / Baremetrics / SaaSOptics / Salesforce / Clari
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must ARR; worst consequence of not doing it
21. **Inversion**: how much can relying on revenue totals solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / retention)
23. **Occam**: ARR the simpler the better; cut redundant dimensions
