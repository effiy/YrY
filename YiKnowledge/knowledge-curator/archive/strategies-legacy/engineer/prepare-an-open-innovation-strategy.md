## Action recommendations

1. **Five dimensions**: network + co-creation + IP + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by speed + trust + risk + cost + differentiation; no empty slogans
3. **Network**: academic / startup / supplier / customer; none missing
4. **Co-create**: joint R&D / joint marketing / joint investment; none missing
5. **IP**: ownership / licensing / confidentiality / exit; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from network → co-creation → IP → governance → measurement; no skipping levels
9. **Not report-only**: procurement bidding is only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with innovation**: open + innovation co-build
13. **Link with innovation-portfolio**: open + portfolio co-build
14. **Link with innovation-lab**: open + lab co-build
15. **Link with product-innovation**: open + product co-build
16. **Link with research-and-development**: open + R&D co-build
17. **Toolchain**: Hype Innovation / Planbox / Ninesigma / Innocentive / Itonics
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why open innovation strategy is a must; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (speed / trust / risk / cost)
23. **Occam**: the simpler open innovation is the better; cut redundant layers
