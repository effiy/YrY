## Action recommendations

1. **Five dimensions**: problem + data + method + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **problem Problem**: north star / assumption / decision; do not omit
4. **data Data**: source / quality / governance; do not omit
5. **method Method**: descriptive / diagnostic / predictive / prescriptive; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: adoption + value + risk + cost + satisfaction; do not omit
8. **not one-shot**: progressive from problem → data → method → governance → measurement; no skipping
9. **not report-ized**: report counts are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **links with analytics-engineering**: analytics + engineering co-build
13. **links with self-serve-bi**: analytics + self-serve BI co-build
14. **links with data-literacy**: analytics + data literacy co-build
15. **links with data-democratization**: analytics + democratization co-build
16. **links with metrics-layer**: analytics + metrics layer co-build
17. **toolchain**: Tableau / Power BI / Looker / Mode / Hex
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why data analytics is necessary; worst consequence of not doing it
21. **inversion thinking**: how much can gut feel solve; if solvable, don't introduce a heavy strategy
22. **second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: data analytics — the simpler the better; cut redundant layers
