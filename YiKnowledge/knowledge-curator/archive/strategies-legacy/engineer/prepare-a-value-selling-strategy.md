## Action recommendations

1. **Five dimensions**: pain points + value + measurement + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by win-rate + ACV + cycle-time + renewal + NRR; not sloganeering
3. **Pain**: business / technical / financial / strategic / risk; do not omit
4. **Value**: ROI / TCO / business / strategic / risk; do not omit
5. **Measure**: business KPI + measurement cadence + measurement method + measurement data + measurement owner; do not omit
6. **Governance**: cadence / owner / escalation / documentation / drift; do not omit
7. **Measure (external)**: win-rate + ACV + cycle-time + renewal + NRR; do not omit
8. **Not one-shot**: progressive from pain → value → measurement → governance → measurement; no skipping
9. **Not report-only**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with deal-presentation**: value selling + presentation co-build
13. **Link with roi-calculator**: value selling + ROI co-build
14. **Link with sales-playbook**: value selling + sales playbook co-build
15. **Link with proposal**: value selling + proposal documentation co-build
16. **Link with product-positioning**: value selling + product positioning co-build
17. **Toolchain**: Gong / Clari / Salesforce / 6sense / LinkedIn-Sales-Nav / Boost-UP
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why value selling is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by feature demonstration alone; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / retention)
23. **Occam**: the simpler value selling is, the better; cut redundant steps
