## Action recommendations

1. **Five dimensions**: audience + keywords + ads + cadence + measurement; no missing dimension
2. **Business-value driven**: prioritize by MQL + SQL + revenue + CAC + ROAS; no empty slogans
3. **audience Audience**: ICP + intent + retargeting + lookalike + exclusion; none missing
4. **keywords Keywords**: seed / long-tail / brand / competitor / negative; none missing
5. **ads Ads**: copy / extension / sitelink / callout / video; none missing
6. **cadence Cadence**: daily / weekly / monthly / quarterly / yearly; none missing
7. **Measurement**: MQL + SQL + revenue + CAC + ROAS; none missing
8. **Not one-shot**: from audience → keywords → ads → cadence → measurement progressive; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **link with paid-media**: paid search + paid media co-build
13. **link with organic-search**: paid search + organic search co-build
14. **link with demand-generation**: paid search + funnel co-build
15. **link with lead-scoring**: paid search + scoring co-build
16. **link with campaign-planning**: paid search + campaign co-build
17. **Toolchain**: Google-Ads / Bing-Ads / Baidu-SEM / Kadmir / Skai / WordStream / Optmyzr / kKarno
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must paid search strategy; worst consequence of not doing it
21. **Inversion**: how much can be solved by SEO; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / CAC)
23. **Occam**: paid search — the simpler the better; cut redundant steps
