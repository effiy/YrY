## Action recommendations

1. **Five dimensions**: Principles + decisions + training + governance + measurement; no missing dimension
2. **Business-value driven**: Prioritize by trust + speed + risk + compliance + cost; no empty slogans
3. **Principles**: Honesty / responsibility / fairness / transparency / care; no leakage
4. **Decisions**: Framework / escalation / committee / balance / audit trail; no leakage
5. **Training**: New hire / annual / high-risk / leadership / dedicated items; no leakage
6. **Governance**: Owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: Trust + speed + risk + compliance + cost; no leakage
8. **Not one-shot**: From principles → decisions → training → governance → measurement progressively; no skipping levels
9. **No report-ism**: Reports are just the start; not the end
10. **No empty slogans**: Every principle must have implementation evidence; no vagueness
11. **Versioned**: Strategy is versioned; evolution is traceable
12. **Links with code-of-conduct**: Ethics + Conduct co-build
13. **Links with whistleblower**: Ethics + Whistleblower co-build
14. **Links with corporate-governance**: Ethics + Governance co-build
15. **Links with compliance**: Ethics + Compliance co-build
16. **Links with ai-ethics**: Ethics + AI Ethics co-build
17. **Toolchain**: LRN / Convercent / NAVEX / SAI360 / EthicsPoint
18. **Publicly discoverable**: Strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: Why must Ethics; worst consequence of not doing it
21. **Inversion**: How much can intuition solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: Second-order consequences after the strategy (trust / speed / risk / compliance) 
23. **Occam's razor**: Ethics simpler is better; cut redundant rules
