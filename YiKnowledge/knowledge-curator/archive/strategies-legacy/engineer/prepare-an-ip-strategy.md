## Action recommendations

1. **Five dimensions**: creation + protection + operations + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by exclusivity + trust + speed + risk + cost; not sloganeering
3. **Creation**: invention / design / brand / work / secret; do not omit
4. **Protection**: patent / trademark / copyright / trade-secret / design; do not omit
5. **Operations**: licensing / transfer / permission / enforcement / standards; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: exclusivity + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from creation -> protection -> operations -> governance -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Interplay with r-and-d**: IP + R&D co-built
13. **Interplay with technology**: IP + Technology co-built
14. **Interplay with product**: IP + Product co-built
15. **Interplay with compliance**: IP + Compliance co-built
16. **Interplay with legal-operations**: IP + Legal co-built
17. **Toolchain**: Anaqua / CPA Global / PatSnap / Lecorpio / IPfolio
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why IP is required; the worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by keeping secrets; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (exclusivity / trust / speed / risk)
23. **Occam**: the simpler the IP the better; cut redundant filings
