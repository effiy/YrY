## Action recommendations

1. **Five dimensions**: narrative + channel + cadence + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Narrative**: mission / strategy / priorities / story; none missing
4. **Channel**: email / all-hands / video / self-service / cross-functional; none missing
5. **Cadence**: weekly / monthly / quarterly / event; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progress from narrative → channel → cadence → Governance → Measurement; no skipping levels
9. **Not report-only**: send counts are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with executive-communications**: leadership communications + executive communications co-build
13. **Link with leadership**: leadership communications + leadership co-build
14. **Link with internal-communications**: leadership communications + internal communications co-build
15. **Link with corporate-storytelling**: leadership communications + corporate narrative co-build
16. **Link with change-communications**: leadership communications + change communications co-build
17. **Toolchain**: Workday / Microsoft Viva / SocialChorus / Poppulo / Firstup
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must leadership-communications strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: leadership communications the simpler the better; cut redundant layers
