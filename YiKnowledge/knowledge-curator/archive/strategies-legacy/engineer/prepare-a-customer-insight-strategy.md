## Action recommendations

1. **Five dimensions**: collect + analyze + insight + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Collect**: rows / attitudes / closed loop; none missing
4. **Analyze**: stats / model / closed loop; none missing
5. **Insight**: driving / decision / closed loop; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: efficiency + trust + speed + risk + cost; none missing
8. **Not one-shot**: progress from collect -> analyze -> insight -> Governance -> Measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with voice-of-customer**: Insight + VoC co-build
13. **Link with customer-feedback**: Insight + Feedback co-build
14. **Link with customer-listening**: Insight + Listening co-build
15. **Link with customer-analytics**: Insight + Analytics co-build
16. **Link with market-research**: Insight + MarketResearch co-build
17. **Toolchain**: Amplitude / Mixpanel / Hotjar / Qualtrics / Medallia
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why CustomerInsight is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved by intuition; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: the simpler CustomerInsight is the better; cut redundant layers
