## Action recommendations

1. **Five dimensions**: capital + financing + investment + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Capital**: equity / debt / ratio / rating; no leakage
4. **Financing**: issuance / syndication / private placement / repayment; no leakage
5. **Investing**: projects / M&A / dividends / buybacks; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: progressive from capital -> financing -> investment -> Governance -> Measurement; no skipping levels
9. **No report-ism**: bookkeeping is only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with fp-and-a**: corporate finance + FP&A co-build
13. **Link with finance**: corporate finance + finance co-build
14. **Link with treasury**: corporate finance + treasury co-build
15. **Link with capital-planning**: corporate finance + capital planning co-build
16. **Link with mergers-and-acquisitions**: corporate finance + M&A co-build
17. **Toolchain**: Anaplan / Oracle EPM / SAP BPC / Workday Adaptive Planning / Bloomberg Terminal
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must corporate finance strategy; worst consequence of not doing
21. **Inversion**: rely on defaults to solve how much; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (growth / trust / speed / risk) 
23. **Occam's razor**: corporate finance simpler is better; cut redundant layers
