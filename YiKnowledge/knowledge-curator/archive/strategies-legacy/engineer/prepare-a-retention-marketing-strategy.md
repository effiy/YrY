## Action recommendations

1. **Five dimensions**: segment + trigger + content + channel + measurement; no missing dimension
2. **Business-value driven**: prioritize by retention + renewal + revenue + retention + experience; not sloganeering
3. **segment Segment**: risk / health / value / stage / behavior; none missing
4. **trigger Trigger**: behavior / time / signal / risk / value; none missing
5. **content Content**: education / case study / hint / coupon / escalate; none missing
6. **channel Channel**: email / in-app / push / social / community; none missing
7. **Governance**: owner / cadence / review / docs / drift; none missing
8. **Measure**: retention + renewal + revenue + retention + experience; none missing
9. **Not one-shot**: from segment → trigger → content → channel → measurement progressively; no skipping levels
10. **Not report-only**: reports are only the starting point; not the endpoint
11. **No sloganeering**: every principle must have landed evidence; no ambiguity
12. **Versioned**: strategy has versions; evolution is traceable
13. **link with retention**: Retention Marketing + Retention co-build
14. **link with customer-lifecycle**: Retention Marketing + lifecycle cadence co-build
15. **link with lifecycle-email**: Retention Marketing + Lifecycle Email co-build
16. **link with customer-health**: Retention Marketing + Health Score co-build
17. **link with win-back**: Retention Marketing + Win-back co-build
18. **Toolchain**: Marketo / HubSpot / Customer.io / Iterable / Braze / Gainsight
19. **Publicly accessible**: strategy accessible to everyone; not hidden
20. **Regular review**: evolve and update; not one-shot
21. **First principles**: why Retention Marketing must exist; worst consequence of not doing it
