## Action recommendations

1. **Five dimensions**: problem + data + model + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **problem Problem**: business / audience / decision / action; do not omit
4. **data Data**: source / quality / governance / integration; do not omit
5. **model Model**: descriptive / diagnostic / predictive / prescriptive; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: progressive from problem -> data -> model -> governance -> measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with bi**: Analytics + BI co-build
13. **link with data-strategy**: Analytics + Data co-build
14. **link with data-platform**: Analytics + Platform co-build
15. **link with ai-strategy**: Analytics + AI co-build
16. **link with digital-transformation**: Analytics + Digital transformation co-build
17. **Toolchain**: Tableau / Power BI / Looker / ThoughtSpot / MicroStrategy
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must analytics strategy; worst consequence of not doing it
21. **inversion thinking**: how much can relying on defaults solve; if solvable, do not introduce a heavy strategy
22. **second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: Analytics the simpler the better; cut redundant layers
