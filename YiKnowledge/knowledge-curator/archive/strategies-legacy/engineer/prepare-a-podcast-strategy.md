## Action recommendations

1. **Five dimensions**: audience + topic + cadence + distribution + Measurement; no missing dimension
2. **Business-value driven**: set priority by listeners + conversion + revenue + brand + retention; no empty slogans
3. **Audience**: ICP / Role / Platform / habits / feedback; no leakage
4. **Topic**: positioning / guests / topic selection / reuse / scheduling; no leakage
5. **Cadence**: season / episode / frequency / length / adjust; no leakage
6. **Distribution**: Apple / Spotify / Google / RSS / embed; no leakage
7. **Governance**: owner / cadence / review / documentation / drift; no leakage
8. **Measurement**: listeners + conversion + revenue + brand + retention; no leakage
9. **Not one-shot**: gradual from audience -> topic -> cadence -> distribution -> Measurement; no skipping levels
10. **No report-ism**: report is just the start; not the end
11. **No empty slogans**: every principle must mark implementation evidence; no vagueness
12. **Versioned**: strategy is versioned; evolution is traceable
13. **Link with content**: Podcast + Content co-build
14. **Link with thought-leadership**: Podcast + Thought Leadership co-build
15. **Link with personal-branding**: Podcast + Personal Branding co-build
16. **Link with video**: Podcast + Video co-build
17. **Link with blog**: Podcast + Blog co-build
18. **Toolchain**: Riverside / Squadcast / Descript / Buzzsprout / Transistor
19. **Publicly discoverable**: strategy is publicly discoverable; not hidden
20. **Regular review**: Evolve and update; Not one-shot
21. **First principles**: why must Podcast; worst consequence of not doing
22. **Inversion**: how much can be solved by relying on blog + video; if solvable, do not introduce heavy strategy
23. **Occam's razor**: Podcast simpler is better; cut redundant steps
