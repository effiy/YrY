## Action recommendations

1. **Five dimensions**: audience + story + evidence + governance + measurement; no missing dimension.
2. **Business-value driven**: prioritize by win rate + speed + ACV + experience + retention; no empty slogans.
3. **Audience**: executives / technology / business / procurement / decision; no leakage.
4. **Story**: opening / pain points / solution / value / closing; no leakage.
5. **Evidence**: data / case studies / demo / references / ROI; no leakage.
6. **Governance**: owner / cadence / review / documentation / drift; no leakage.
7. **Measurement**: win rate + speed + ACV + experience + retention; no leakage.
8. **Not one-shot**: from audience → story → evidence → governance → measurement, gradual; no skipping levels.
9. **No report-ism**: reports are just the start; not the end.
10. **No empty slogans**: every principle must be backed by implementation evidence; no vagueness.
11. **Versioned**: strategy is versioned; evolution is traceable.
12. **Link with deal-presentation**: Presentation + Deal Presentation co-build.
13. **Link with demo**: Presentation + Demo co-build.
14. **Link with proposal**: Presentation + Proposal co-build.
15. **Link with messaging-house**: Presentation + Messaging House co-build.
16. **Link with value-proposition**: Presentation + Value Proposition co-build.
17. **Toolchain**: PowerPoint / Pitch / Beautiful.ai / Highspot / Seismic.
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden.
19. **Regular review**: evolve and update; not one-shot.
20. **First principles**: why must Presentation; worst consequence of not doing it.
21. **Inversion**: how much can relying on verbal communication solve; if solvable, do not introduce a heavy strategy.
22. **Second-order thinking**: second-order consequence after the strategy (cost / risk / win rate / ACV).
23. **Occam's razor**: simpler presentations are better; cut redundant slides.
