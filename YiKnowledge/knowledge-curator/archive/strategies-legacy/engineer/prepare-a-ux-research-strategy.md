## Action recommendations

1. **Five dimensions**: question + method + insight + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; not sloganeering
3. **Question**: behavior / motivation / barriers / opportunities; do not omit
4. **Method**: interview / usability / card sorting / tree testing; do not omit
5. **Insight**: discovery / assumption / priority / landing; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **Not one-shot**: gradual from question → method → insight → governance → measurement; no skipping
9. **Not report-only**: usability is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with user-research**: UX + user co-built
13. **Link with design-research**: UX + design co-built
14. **Link with usability-testing**: UX + usability co-built
15. **Link with user-flow**: UX + flow co-built
16. **Link with ethnographic-research**: UX + ethnographic co-built
17. **Toolchain**: UserTesting / Maze / Lookback / Dovetail / Reframer
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must UX research strategy; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by default; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (growth / trust / speed / risk)
23. **Occam**: UX research simpler is better; cut redundant layers
