## Action recommendations

1. **Five dimensions**: qualification + content + channel + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by reference impact on revenue + win-rate + cycle-time + renewal + NRR; not sloganeering
3. **qualification Qualify**: customer / industry / use case / value / consent; do not omit
4. **content Content**: case / testimonial / reference-call / demo / video; do not omit
5. **channel Channel**: sales / marketing / PR / website / events; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: reference impact on revenue + win-rate + cycle-time + renewal + NRR; do not omit
8. **not one-shot**: from qualification → content → channel → governance → measurement gradual; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **and customer-advocacy link**: reference program + customer advocacy co-build
13. **and case-study link**: reference program + case study co-build
14. **and testimonial link**: reference program + testimonial co-build
15. **and customer-advocacy-program link**: reference program + advocacy program co-build
16. **and customer-marketing link**: reference program + customer marketing co-build
17. **Toolchain**: Salesforce / Influitive / Boast / Case-Study-Interactive / Vidyard
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must reference program; worst consequence of not doing
21. **inversion thinking**: how much can ad-hoc solve; if solvable do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (cost / risk / revenue / retention)
23. **Occam**: reference program the simpler the better; cut redundant types
