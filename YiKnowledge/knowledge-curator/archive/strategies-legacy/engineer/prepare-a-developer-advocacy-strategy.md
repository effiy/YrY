## Action recommendations

1. **Five dimensions**: audience + content + channel + feedback + measurement; no missing dimension
2. **business-value driven**: prioritize by API calls + integrations + active developers + revenue share + NPS; not sloganeering
3. **audience Audience**: third-party developers + customer developers + internal developers + partners + students; do not omit
4. **content Content**: tutorial / sample / blog / video / talk + resource library; do not omit
5. **channel Channel**: portal / forum / GitHub / Stack Overflow / X / Discord; do not omit
6. **feedback Feedback**: listen + classify + prioritize + follow-up + transparency; do not omit
7. **measurement Measure**: API calls + integrations + active developers + revenue share + NPS; do not omit
8. **not one-shot**: progressive from audience → content → channel → feedback → measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with devrel**: dev-advocacy + DevRel co-build
13. **link with developer-portal**: dev-advocacy + portal co-build
14. **link with community-engagement**: dev-advocacy + community co-build
15. **link with content**: dev-advocacy + content co-build
16. **link with partnership**: dev-advocacy + partnership co-build
17. **Toolchain**: GitHub / Stack Overflow / Dev.to / Hashnode / Discord / Slack / Twitch / YouTube Live / Orbit / Bevy
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must dev-advocacy strategy; worst consequence of not doing it
21. **inversion thinking**: how much can developer self-study solve; if solvable, do not introduce a heavy strategy
22. **second-order thinking**: second-order consequences after strategy (cost / risk / retention / business) 
23. **Occam**: dev-advocacy the simpler the better; cut redundant steps
