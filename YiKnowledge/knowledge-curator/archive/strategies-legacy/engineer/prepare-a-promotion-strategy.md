## Action recommendations

1. **Five dimensions**: goal + mechanism + evaluation + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by efficiency + trust + speed + risk + cost; not sloganeering
3. **Goal**: traffic / order value / closed loop; do not omit
4. **Mechanism**: discount / gift-with-purchase / closed loop; do not omit
5. **Evaluate**: roi / increment / closed loop; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: efficiency + trust + speed + risk + cost; do not omit
8. **Not one-shot**: from goal -> mechanism -> evaluation -> governance -> measurement gradual; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with pricing**: Promotion + Pricing co-build
13. **Link with merchandising**: Promotion + Merchandising co-build
14. **Link with markdown**: Promotion + Markdown co-build
15. **Link with category-management**: Promotion + CategoryManagement co-build
16. **Link with assortment**: Promotion + Assortment co-build
17. **Toolchain**: Salesforce / SymphonyAI / Blue Yonder / SAP / Oracle
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must Promotion; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by relying on year-round discounts; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (efficiency / trust / speed / risk) 
23. **Occam**: Promotion, the simpler the better; cut redundant mechanisms
