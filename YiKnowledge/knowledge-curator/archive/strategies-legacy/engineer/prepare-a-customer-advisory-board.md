## Action recommendations

1. **first principles**: first ask "what question must CAB answer / what if no meeting / ROI / customer ROI"; do not meet for meeting's sake; see [first-principles-summary.md](../../knowledge-curator/templates/thinking/first-principles.md). 
2. **inversion**: first imagine "CAB could go out of control (customer churn / expectation gap / info leak / feedback no closed loop / sponsor unhappy)" then set guardrails; see [inversion-summary.md](../../knowledge-curator/templates/thinking/inversion.md). 
3. **strong opinions loosely held**: must run [strong-opinions-loosely-held-summary.md](../../knowledge-curator/templates/thinking/strong-opinions-loosely-held.md) when communicating with customers; neither humble nor arrogant. 
4. **second-order effects**: one CAB -> customer expectations change -> renewal impact; follow [second-order-thinking-summary.md](../../knowledge-curator/templates/thinking/second-order-thinking.md). 
5. **select customer**: must run [stakeholder-map.md](../../knowledge-curator/people/stakeholders/stakeholder-map.md); select 8-12 by industry / scale / strategic value / renewal / influence. 
6. **cadence**: must run [communication-cadence.md](../../knowledge-curator/people/stakeholders/communication-cadence.md); quarterly CAB + monthly 1:1 + instant reporting. 
7. **agenda**: must run [meeting-notes-template.md](../../knowledge-curator/templates/meeting-notes.md); strategy report + roadmap + feedback + Q&A. 
8. **NDA**: must run [data-compliance-process.md](../../engineer/infrastructure/data-compliance.md) + NDA + scope marking + confidentiality period. 
9. **JTBD**: must run [jobs-to-be-done-summary.md](../../product-manager/frameworks/jobs-to-be-done.md) to understand customer real needs. 
10. **kano**: must run [kano-model-summary.md](../../product-manager/frameworks/kano-model.md); distinguish must-have / expected / excitement. 
11. **roadmap**: must run [now-next-later-roadmap-summary.md](../../executive/strategy/now-next-later-roadmap.md); now / next / later three sections + customer feedback embedded. 
12. **metrics**: must run [north-star-metric-summary.md](../../product-manager/discovery/metrics/north-star-metric.md) + [retention-and-churn-summary.md](../../product-manager/discovery/metrics/retention-and-churn.md); CAB looks at customer health + renewal risk. 
13. **feedback loop**: must run [i-want-to-handle-customer-feedback.md](./handle-customer-feedback.md); CAB feedback must land in backlog + must feedback progress + must close loop. 
14. **cross timezone**: must run [cross-timezone-collaboration-summary.md](../../engineer/processes/collaboration/cross-timezone-collaboration.md); multi-timezone windows + recording. 
15. **RACI**: must run [raci-matrix-summary.md](../../engineer/processes/collaboration/raci-matrix.md); host / speaker / customer success / sponsor / scribe / archive graded. 
16. **draft**: use [weekly-report-prompt.md](../../ai-engineer/methodology/prompts/weekly-report.md) to let AI draft + human edit. 
17. **preview**: send agenda + pre-read materials 7-14 days in advance; follow [communication-cadence.md](../../knowledge-curator/people/stakeholders/communication-cadence.md). 
18. **recording**: must record + must subtitle + must archive + must be replayable; follow [knowledge-transfer-process.md](../../engineer/processes/knowledge-transfer.md). 
19. **retrospective**: must run [retrospective-template.md](../../knowledge-curator/templates/retrospective.md) to retrospect CAB itself + improve agenda. 
20. **archive**: must run [knowledge-leaf-template.md](../../knowledge-curator/templates/knowledge-leaf.md) + [review-log.md](../../knowledge-curator/governance/review-log.md) to archive CAB minutes + feedback closed loop. 
21. **quarterly audit**: follow [review-log.md](../../knowledge-curator/governance/review-log.md) to scan whether CAB members still represent customer distribution + whether feedback is still closed loop. 
22. **flywheel**: CAB -> feedback lands -> trust rises -> renewal -> more customers willing to join CAB; see [flywheel-effect-summary.md](../../knowledge-curator/templates/thinking/flywheel-effect.md).
