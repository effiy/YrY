## Action recommendations

1. **Five dimensions**: inventory + assessment + rationalization + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Inventory**: applications / business / technology / value; do not omit
4. **Assessment**: business / technology / integration / risk; do not omit
5. **Rationalize**: retain / invest / migrate / retire; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **Not one-shot**: progressive from inventory -> assessment -> rationalization -> governance -> measurement; no skipping
9. **Not report-ized**: the list is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with enterprise-architecture**: portfolio + enterprise architecture co-build
13. **Link with solution-architecture**: portfolio + solution co-build
14. **Link with it-strategy**: portfolio + IT co-build
15. **Link with technology**: portfolio + technology co-build
16. **Link with integration**: portfolio + integration co-build
17. **Toolchain**: Planview LeanIX / Ardoq / Avolution ADOit / Sparx EA / Cast Highlight
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must application portfolio strategy; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by default; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: application portfolio the simpler the better; cut redundant layers
