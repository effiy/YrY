## Action recommendations

1. **Five dimensions**: Target + difference + value + consistent + Measurement; no missing dimension
2. **Business-value driven**: prioritize by business growth + market share + Risk + opportunity; no empty slogans
3. **Target**: Target user + scenario + pain point + mental; no leakage
4. **difference Differentiation**: unique value + inimitable + defensible + benchmarked; no leakage
5. **value Value Prop**: core value + one sentence + evidence + Measurement; no leakage
6. **consistent Consistent**: cross-channel + cross-scenario + cross-time + cross-Role consistent; no leakage
7. **Measurement Measure**: mind share + mention rate + preference + repurchase + NPS; no leakage
8. **Not one-shot**: gradual from Target → difference → value → consistent → Measurement; no skipping levels
9. **no report-ism**: report is just the start; not the end
10. **no empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with product-strategy**: positioning + strategy co-build
13. **Link with competitive-analysis**: positioning + competitor co-build
14. **Link with brand-strategy**: positioning + brand co-build
15. **Link with go-to-market**: positioning + GTM co-build
16. **Link with pitch**: positioning + fundraising co-build
17. **Link with market-research**: positioning + market co-build
18. **Toolchain**: Positioning Framework / April Dunford / 3Cs / STP / Perceptual Map / Miro / Wynter / SurveyMonkey / Brand Tracker
19. **Publicly discoverable**: strategy is publicly discoverable; not hidden
20. **Regular review**: Evolve and update; Not one-shot
21. **First principles**: why must positioning; worst consequence of not doing
22. **Inversion**: how much can be solved using intuition; if solvable, do not introduce a heavy strategy
23. **Second-order thinking**: second-order consequence after strategy (cost / Risk / growth / business) 
24. **Occam's razor**: positioning simpler is better; cut redundant steps
