## Action recommendations

1. **Five dimensions**: Partners + Content + Channel + Cadence + Measurement; no missing dimension
2. **Business-value driven**: prioritize by co-sourced ARR + revenue share + MQL + SQL + retention; not sloganeering
3. **Partners**: tech / reseller / ISV / cloud / SI + tier; do not omit
4. **Content**: co-branded blog / ebook / webinar / event / case + resource library; do not omit
5. **Channel**: both parties' websites / email / social / in-person / sales; do not omit
6. **Cadence**: daily / monthly / quarterly / event + upgrade; do not omit
7. **Measurement**: co-sourced ARR + revenue share + MQL + SQL + retention; do not omit
8. **Not one-shot**: progressive from Partners → Content → Channel → Cadence → Measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Partnership linkage**: co-marketing + partnership co-build
13. **Partner-program linkage**: co-marketing + program co-build
14. **Partner-marketing linkage**: co-marketing + PM co-build
15. **Content linkage**: co-marketing + content co-build
16. **Campaign-planning linkage**: co-marketing + campaign co-build
17. **Toolchain**: Crossbeam / Reveal / PartnerStack / Allbound / Channeltapest / Impartner / 6sense / Demandbase
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must a co-marketing strategy exist; worst consequence of not doing it
21. **Inversion thinking**: how much can single-party marketing solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / brand)
23. **Occam**: co-marketing the simpler the better; cut redundant steps
