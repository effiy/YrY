## Action recommendations

1. **Five dimensions**: capital + budget + assessment + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Capital**: capex / opex / closed-loop; none missing
4. **Budget**: annual / project / closed-loop; none missing
5. **Assessment**: NPV / IRR / closed-loop; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measurement**: efficiency + trust + speed + risk + cost; none missing
8. **Not one-shot**: progressive from capital → budget → assessment → governance → measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with financial-planning**: Capital Planning + Financial Planning co-build
13. **Link with budgeting**: Capital Planning + Budgeting co-build
14. **Link with asset-management**: Capital Planning + Asset Management co-build
15. **Link with financial-reporting**: Capital Planning + Financial Reporting co-build
16. **Link with treasury**: Capital Planning + Treasury co-build
17. **Toolchain**: Anaplan / Oracle EPM / SAP BPC / Workday / Hyperion
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why Capital Planning is necessary; worst consequence of not doing it
21. **Inversion**: how much can single approval solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: simpler Capital Planning is better; cut redundant steps
