## Action recommendations

1. **Five dimensions**: scope + cadence + action + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by revenue + accuracy + action + cycle-time + retention; not sloganeering
3. **scope Scope**: AE / team / segment / region / company-wide; do not omit
4. **cadence Cadence**: weekly / monthly / quarterly / deal / segment; do not omit
5. **action Action**: next-step / escalation / adjustment / retirement / measurement; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: revenue + accuracy + action + cycle-time + retention; do not omit
8. **not one-shot**: progressive from scope -> cadence -> action -> governance -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **link with sales-pipeline**: pipeline review + sales pipeline co-built
13. **link with deal-review**: pipeline review + deal-review co-built
14. **link with forecast-accuracy**: pipeline review + forecast accuracy co-built
15. **link with sales-forecast**: pipeline review + sales forecast co-built
16. **link with deal-coaching**: pipeline review + deal coaching co-built
17. **Toolchain**: Clari / Salesforce / Gong / Boost-UP / Insight-Square / People-AI
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must pipeline review; worst consequence of not doing it
21. **inversion thinking**: how much can relying on freeform solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (cost / risk / revenue / retention)
23. **Occam**: pipeline review the simpler the better; cut redundant steps
