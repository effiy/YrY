## Action recommendations

1. **First principles**: first ask "what does skip-level 1:1 solve / what happens if not done / ROI / user impact"; do not do for the sake of doing; see [first-principles-summary.md](../../knowledge-curator/templates/thinking/first-principles.md).
2. **Inversion**: first imagine "how could skip-level fail (intermediate TL on guard / employees dare not speak / feedback without closed loop / trust collapse)" then set guardrails; see [inversion-summary.md](../../knowledge-curator/templates/thinking/inversion.md).
3. **Second-order effects**: skip-level -> TL on guard -> employee feedback -> another skip-level; follow [second-order-thinking-summary.md](../../knowledge-curator/templates/thinking/second-order-thinking.md).
4. **Occam**: satisfy needs with the simplest agenda that wins; do not pile up topics; see [ockhams-razor-summary.md](../../knowledge-curator/templates/thinking/ockhams-razor.md).
5. **Purpose**: must run "listen + closed loop + trust" + must clarify not replacing intermediate TL; do not make decisions across levels.
6. **Agenda**: must run [one-on-one-template.md](../../knowledge-curator/templates/one-on-one.md) + must be open + must be employee-led.
7. **Psychological safety**: must run psychological safety + must be confidential + must not retaliate + must be no retaliation.
8. **Listen**: must run 80/20 (employee 80%) + must not interrupt + must paraphrase + must probe.
9. **Strong opinions loosely held**: must run [strong-opinions-loosely-held-summary.md](../../knowledge-curator/templates/thinking/strong-opinions-loosely-held.md); clear stance + leave dialogue space.
10. **Closed loop**: must run "feedback -> organize -> communicate sponsor + TL -> landing -> retrospective" + must 30-day follow-up.
11. **Communication**: must run [communication-cadence.md](../../knowledge-curator/people/stakeholders/communication-cadence.md) communicate inside and outside + must not name individuals + must aggregate.
12. **Pulse survey**: must run quarterly pulse + must be anonymous + must compare trends + must NPS.
13. **OKR**: must run [okr-design-summary.md](../../product-manager/frameworks/okr-design.md) alignment + must quarterly check.
14. **Cross-timezone**: must run [cross-timezone-collaboration-summary.md](../../engineer/processes/collaboration/cross-timezone-collaboration.md); remote skip-level needs double evidence.
15. **RACI**: must run [raci-matrix-summary.md](../../engineer/processes/collaboration/raci-matrix.md); sponsor / TL / HR owner.
16. **Retrospective**: after skip-level must run [retrospective-template.md](../../knowledge-curator/templates/retrospective.md) retrospective + Archive [review-log.md](../../knowledge-curator/governance/review-log.md).
17. **Quarterly audit**: follow [governance.md](../../knowledge-curator/governance/governance.md) + [review-log.md](../../knowledge-curator/governance/review-log.md) sweep skip-level cadence whether still accurate + pulse whether still reasonable.
18. **ADR**: skip-level decision must land ADR; see [adr-template.md](../../knowledge-curator/templates/adr.md).
19. **Flywheel**: skip-level smooth -> trust rise -> communication smooth -> business rise; see [flywheel-effect-summary.md](../../knowledge-curator/templates/thinking/flywheel-effect.md).
