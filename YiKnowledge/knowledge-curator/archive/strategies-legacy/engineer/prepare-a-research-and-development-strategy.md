## Action recommendations

1. **Five dimensions**: direction + investment + portfolio + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by innovation + trust + speed + risk + cost; no empty slogans
3. **Direction**: basic / applied / experimental / product / process; none missing
4. **Investment**: people / money / time / facilities / partnerships; none missing
5. **Portfolio**: stage / risk / return / option / termination; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: innovation + trust + speed + risk + cost; none missing
8. **Not one-shot**: progress gradually from direction -> investment -> portfolio -> governance -> measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Links with technology**: R&D + Technology co-build
13. **Links with product**: R&D + Product co-build
14. **Links with ip**: R&D + IP co-build
15. **Links with cto**: R&D + CTO co-build
16. **Links with innovation**: R&D + Innovation co-build
17. **Toolchain**: Aha / Productboard / Jira / ITONIC / Hype Innovation
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why R&D is needed; worst consequence of not doing it
21. **Inversion**: how much can be solved by following; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (innovation / trust / speed / risk) 
23. **Occam**: R&D the simpler the better; cut redundant projects
