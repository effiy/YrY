## Action recommendations

1. **Five dimensions**: portfolio + site selection + finance + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **portfolio Portfolio**: owned / leased / shared / remote / hybrid; do not omit
4. **site Site**: city / region / park / building; do not omit
5. **finance Finance**: cost / revenue / depreciation / tax; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: from portfolio → site selection → finance → governance → measurement gradual; no skipping
9. **not report-ized**: area numbers are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with corporate-real-estate**: portfolio + corporate real-estate co-build
13. **link with workplace**: portfolio + workplace co-build
14. **link with facilities**: portfolio + facilities co-build
15. **link with workplace-experience**: portfolio + workplace experience co-build
16. **link with capacity-planning**: portfolio + capacity planning co-build
17. **toolchain**: JLL / CBRE / CoStar / Yardi / MRI
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must real-estate portfolio strategy; worst consequence of not doing
21. **inversion thinking**: how much can be solved by default; if solvable don't introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk) 
23. **Occam**: real-estate portfolio the simpler the better; cut redundant layers
