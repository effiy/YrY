## Action recommendations

1. **Five dimensions**: account + experience + channel + orchestration + measurement; no missing dimension
2. **Business-value driven**: set priority by ABM revenue + pipeline + win-rate + ACV + NRR; no empty slogans
3. **Account**: ICP / tier / role / pain / signal; none missing
4. **Experience**: content / channel / cadence / personalization / consistent; none missing
5. **Channel**: email / ads / direct mail / social / 1:1; none missing
6. **Orchestration**: marketing / sales / CS / executive / champion; none missing
7. **Measure**: ABM revenue + pipeline + win-rate + ACV + NRR; none missing
8. **Not one-shot**: progressive from account → experience → channel → orchestration → measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with account-based-selling**: ABX + ABS co-build
13. **Link with account-mapping**: ABX + account map co-build
14. **Link with account-engagement**: ABX + account manager engagement co-build
15. **Link with account-tiering**: ABX + account tiering co-build
16. **Link with customer-engagement**: ABX + customer engagement co-build
17. **Toolchain**: 6sense / Demandbase / Engagio / Salesforce / Marketo / LinkedIn-Sales-Nav / Drift
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why ABX is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved by a single channel; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / retention) 
23. **Occam**: ABX, the simpler the better; cut redundant channels
