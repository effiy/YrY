## Action recommendations

1. **Five dimensions**: courses + practice + assessment + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **courses Course**: basic / role-based; do not omit
4. **practice Practice**: projects / workshops / experiments; do not omit
5. **assessment Assess**: exam / behavior / projects; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: completion rate + pass rate + behavior change + risk + cost; do not omit
8. **not one-shot**: from courses → practice → assessment → governance → measurement gradual; no skipping
9. **not report-ized**: training headcount only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **and data-culture link**: literacy + culture co-built
13. **and data-maturity link**: literacy + maturity co-built
14. **and data-democratization link**: literacy + democratization co-built
15. **and data link**: literacy + data strategy co-built
16. **and self-serve-bi link**: literacy + self-serve BI co-built
17. **Toolchain**: Data Literacy Project / Qlik Academy / Tableau Learning / Coursera / internal LMS
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must data literacy; worst consequence of not doing
21. **inversion thinking**: how much can self-service tools solve; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: data literacy the simpler the better; cut redundant layers
