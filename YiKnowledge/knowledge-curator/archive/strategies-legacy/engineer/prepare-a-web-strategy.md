## Action recommendations

1. **Five dimensions**: content + experience + performance + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by traffic + conversion + retention + trust + cost; not sloganeering
3. **Content**: marketing / docs / app / e-commerce / support; do not omit
4. **Experience UX**: navigation / information architecture / interaction / visual / accessibility; do not omit
5. **Performance**: Core Web Vitals / TTFB / LCP / CLS / INP; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: traffic + conversion + retention + trust + cost; do not omit
8. **Not one-shot**: from content → experience → performance → governance → measurement gradual; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with mobile**: Web + Mobile co-build
13. **Link with content**: Web + Content co-build
14. **Link with seo**: Web + SEO co-build
15. **Link with design-system**: Web + Design co-build
16. **Link with accessibility**: Web + A11y co-build
17. **Toolchain**: Next.js / Astro / WordPress / Contentful / Vercel
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must Web; worst consequence of not doing
21. **inversion thinking**: how much can App solve; if solvable do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after the strategy (traffic / conversion / trust / cost)
23. **Occam**: Web the simpler the better; cut redundant pages
