## Action recommendations

1. **five dimensions**: structure + threshold + compute + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by revenue + achievement rate + retention + AE satisfaction + fairness; no empty slogans
3. **Structure**: base+variable / tiered / accelerator / SPIF / multi-product; no leakage
4. **Threshold**: OTE / floor / cap / threshold / kickers; no leakage
5. **Calculation**: revenue / renewal / retention / performance / adjust; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: revenue + achievement rate + retention + AE satisfaction + fairness; no leakage
8. **Not one-shot**: progressive from structure → threshold → compute → Governance → Measurement; no skipping levels
9. **no report-ism**: report is just the start; not the end
10. **no empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **link with quota-plan**: commission + quota co-build
13. **link with territory-plan**: commission + territory plan co-build
14. **link with sales-ops**: commission + sales operations co-build
15. **link with partner-compensation**: commission + partner compensation co-build
16. **link with sales-pipeline**: commission + sales pipeline co-build
17. **Toolchain**: Xactly / Varicent / Salesforce / Clari / Captivate / Boost-UP
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must commission plan; worst consequence of not doing
21. **Inversion**: rely on gut call how much can be solved; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (cost / risk / revenue / retention) 
23. **Occam's razor**: commission simpler is better; cut redundant tiers
