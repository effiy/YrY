## Action recommendations

1. **Five dimensions**: channel + collection + analysis + closed loop + measurement; none can be missing
2. **Business-value driven**: prioritize by retention + conversion + NPS + repeat purchase + win-back; not sloganeering
3. **Channel**: survey + interview + review + in-app + support + social; do not omit
4. **Collect**: timing + copy + scale + anonymous + incentive; do not omit
5. **Analyze**: classification + theme + quantification + sentiment + trend; do not omit
6. **Loop**: response + responsibility + SLA + retrospective + transparency; do not omit
7. **Measurement**: feedback volume + response rate + closed-loop rate + NPS + repeat purchase; do not omit
8. **Not one-shot**: progressive from channel → collection → analysis → closed loop → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with voice-of-customer**: feedback + VoC co-build
13. **Link with customer-insights**: feedback + insights co-build
14. **Link with nps**: feedback + NPS co-build
15. **Link with csat**: feedback + CSAT co-build
16. **Link with customer-journey**: feedback + journey co-build
17. **Toolchain**: Qualtrics / Typeform / SurveyMonkey / Delighted / Hotjar / UserVoice / Productboard / Canny / Dovetail / Gong
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why a feedback strategy is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can passive customer service response solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (cost / risk / retention / business) 
23. **Occam**: feedback — the simpler the better; cut redundant steps
