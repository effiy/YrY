## Action recommendations

1. **Five dimensions**: audience + value + format + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by acquisition + conversion + retention + trust + cost; not sloganeering
3. **Audience**: buyer / user / champion / economic / decision; do not omit
4. **Value**: pain point / solution / benefit / trust / action; do not omit
5. **Format**: ebook / template / checklist / webinar / tool; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: acquisition + conversion + retention + trust + cost; do not omit
8. **not one-shot**: progressive from audience -> value -> format -> governance -> measurement; no skipping
9. **not report-ism**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **linked with content**: LeadMagnet + Content co-build
13. **linked with inbound**: LeadMagnet + Inbound co-build
14. **linked with lead-scoring**: LeadMagnet + Scoring co-build
15. **linked with lead-nurturing**: LeadMagnet + Nurturing co-build
16. **linked with content-operations**: LeadMagnet + ContentOps co-build
17. **Toolchain**: HubSpot / Marketo / Pardot / Instapage / Unbounce
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must Lead Magnet; worst consequence of not doing
21. **inversion thinking**: how much can be solved relying on natural traffic; if solvable, don't introduce a heavy strategy
22. **second-order thinking**: second-order consequences after strategy (acquisition / conversion / trust / cost) 
23. **Occam**: Lead Magnet the simpler the better; cut redundant formats
