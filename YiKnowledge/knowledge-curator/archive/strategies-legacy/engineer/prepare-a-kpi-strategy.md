## Action recommendations

1. **Five dimensions**: definition + goal + tracking + responsibility + retrospective; no missing dimension
2. **business-value driven**: prioritize by business growth + user value + retention + LTV; not sloganeering
3. **definition**: metric name + definition + data source + formula + unit + dimension; do not omit
4. **goal**: baseline + goal value + threshold + time window + stretch; do not omit
5. **tracking**: daily / weekly / monthly / quarterly + dashboard + trend + exception + alert; do not omit
6. **responsibility**: every KPI single owner + team shared + collaborators; do not omit
7. **retrospective**: periodic + scoring + experience + adjustment + next-cadence improvement; do not omit
8. **not one-shot**: progressive from definition → goal → tracking → responsibility → retrospective; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with okr**: KPI + OKR co-build
13. **link with north-star-metric**: KPI + north star co-build
14. **link with product-strategy**: KPI + product strategy co-build
15. **link with product-analytics**: KPI + measurement co-build
16. **link with pirate-funnel**: KPI + funnel co-build
17. **link with heart-aarrr**: KPI + pirate metrics co-build
18. **Toolchain**: KPI Framework / Lark KPI / Mixpanel / Amplitude / Looker / Tableau / Metabase / Google Data Studio / Power BI
19. **publicly queryable**: strategy everyone can look up; not hidden
20. **periodic review**: evolution updates; not one-shot
21. **first principles**: why must KPI; worst consequence of not doing it
22. **inversion thinking**: how much can intuition solve; if solvable, do not introduce a heavy strategy
23. **second-order thinking**: second-order consequences after strategy (cost / risk / growth / business) 
24. **Occam**: KPI the simpler the better; cut redundant steps
