2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **card Card**: content / quantity / label / subset; none missing
4. **task Task**: open / closed / hybrid / template; none missing
5. **analysis Analyze**: cluster / consistent / standard tree / re-stack; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: from card → task → analysis → Governance → Measurement progressive; no skipping levels
9. **Not report-only**: sorting only the starting point; not the endpoint
