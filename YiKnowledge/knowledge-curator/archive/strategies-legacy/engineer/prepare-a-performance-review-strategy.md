## Action recommendations

1. **Five dimensions**: Cadence + calibration + development + Governance + Measurement; no missing dimension
2. **Business-value driven**: set priority by growth + trust + speed + Risk + cost; no empty slogans
3. **Cadence Cycle**: annual / semi-annual / quarterly / project; no leakage
4. **Calibration**: distribution / review / alignment / appeal; no leakage
5. **Development**: target / action / resource / retrospective; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: coverage + adoption + cost + Risk + satisfaction; no leakage
8. **Not one-shot**: gradual from Cadence → calibration → development → Governance → Measurement; no skipping levels
9. **No report-ism**: scores are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Links with performance-management**: review + management co-build
13. **Links with feedback**: review + feedback co-build
14. **Links with succession**: review + succession co-build
15. **Links with people**: review + people co-build
16. **Links with incentive**: review + incentive co-build
17. **Toolchain**: Lattice / 15Five / Culture Amp / Workday Performance / SuccessFactors Performance
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must performance-review strategy; worst consequence of not doing
21. **Inversion**: rely on defaults to solve how much; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (growth / trust / speed / Risk)
23. **Occam's razor**: performance review simpler is better; cut redundant layers
