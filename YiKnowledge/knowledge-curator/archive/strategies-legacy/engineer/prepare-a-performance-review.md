## Action recommendations

1. **Five dimensions**: goal + behavior + impact + feedback + growth; no missing dimension
2. **Goal alignment**: OKR + ladder alignment; not vague
3. **Behavior rubric**: each level must tag behavior indicators; not by gut feel
4. **Impact**: not only output; impact + scope + governance
5. **Bidirectional**: self-assessment + manager assessment + peer 360; not one-way
6. **Feedback**: not only scoring + feedback + actions; not only a name list
7. **Growth**: each review must tag a growth path; not vague
8. **Not one-shot**: periodic + triggered; not only annual
9. **Traceable**: each review goes into the decision log; do not omit
10. **Budget**: compensation + equity + promotion aligned; not disconnected
11. **Calibration**: cross-team calibration; not deviating
12. **Open process**: process + rubric public; not black-box
13. **Link with ladder**: performance aligned to ladder
14. **Link with 1on1**: 1on1 tracks progress
15. **Link with quarterly retrospective**: quarterly retrospective follows performance
16. **Link with mentor**: mentor guides performance growth
17. **Link with decision log**: performance decision archived
18. **Link with handling underperformance**: underperformance goes through the handling process
19. **Publicly queryable**: everyone can look up process + rubric; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why performance is necessary; worst consequence of not doing it
22. **Inversion thinking**: how much can be solved with 1on1; if solvable, do not introduce performance
23. **Second-order thinking**: second-order consequences after performance (fairness / retention / hiring / trust) 
24. **Occam**: performance: the simpler the better; cut redundant steps
