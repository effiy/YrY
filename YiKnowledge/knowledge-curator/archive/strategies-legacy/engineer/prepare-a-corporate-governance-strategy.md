## Action recommendations

1. **Five dimensions**: Structure + process + disclosure + governance + measurement; no missing dimension
2. **Business-value driven**: Prioritize by trust + compliance + risk + speed + cost; no empty slogans
3. **Structure**: Board / committee / executive / audit / risk; none missing
4. **Process**: Agenda / resolutions / assessment / closed loop / drift; none missing
5. **Disclosure**: Finance / risk / governance / ESG / restatements; none missing
6. **Governance**: Owner / cadence / review / docs / drift; none missing
7. **Measure**: Trust + compliance + risk + speed + cost; none missing
8. **Not one-shot**: From structure → process → disclosure → governance → measurement progressively; no skipping levels
9. **Not report-only**: Reports are only the starting point; not the endpoint
10. **No empty slogans**: Every principle must have landed evidence; no ambiguity
11. **Versioned**: Strategy has versions; evolution is traceable
12. **Links with board-of-directors**: Governance + Board co-build
13. **Links with compliance**: Governance + Compliance co-build
14. **Links with risk**: Governance + Risk co-build
15. **Links with leadership**: Governance + Leadership co-build
16. **Links with operating-model**: Governance + Operating co-build
17. **Toolchain**: Diligent / BoardEffect / OnBoard / Nasdaq Boardvantage / Azeus
18. **Publicly accessible**: Strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: Why must Corporate Governance; worst consequence of not doing it
21. **Inversion**: How much can CEO self-determination solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: Second-order consequences after the strategy (trust / compliance / risk / speed) 
23. **Occam**: Governance the simpler the better; cut redundant committees
