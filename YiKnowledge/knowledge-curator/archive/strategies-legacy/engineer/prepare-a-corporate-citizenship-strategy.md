## Action recommendations

1. **Five dimensions**: responsibility + action + report + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Responsibility**: themes / commitments / closed loop; no leakage
4. **Action**: projects / volunteering / closed loop; no leakage
5. **Report**: disclosure / audit / closed loop; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: efficiency + trust + speed + risk + cost; no leakage
8. **Not one-shot**: gradual from responsibility → action → report → governance → measurement; no skipping levels
9. **Not report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must have implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with corporate-social-responsibility**: Corporate Citizenship + CSR co-build
13. **Link with corporate-sustainability**: Corporate Citizenship + sustainability co-build
14. **Link with corporate-philanthropy**: Corporate Citizenship + philanthropy co-build
15. **Link with stakeholder-engagement**: Corporate Citizenship + stakeholder engagement co-build
16. **Link with corporate-foundation**: Corporate Citizenship + foundation co-build
17. **Toolchain**: Benevity / CyberGrants / YourCause / Blackbaud / Point of Light
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must there be Corporate Citizenship; worst consequence of not doing
21. **Inversion**: how much can be solved by relying on donations; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (efficiency / trust / speed / risk)
23. **Occam's razor**: simpler Corporate Citizenship is better; cut redundant layers
