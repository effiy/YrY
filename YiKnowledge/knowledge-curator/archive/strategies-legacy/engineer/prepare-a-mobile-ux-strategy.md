## Action recommendations

1. **Five dimensions**: gestures + thumb zone + offline + notifications + performance; no missing dimension
2. **Business-value driven**: prioritize by business impact + user value + risk + opportunity; not sloganeering
3. **Gestures**: swipe + long press + drag + two-finger + shake + discoverability; do not omit
4. **Thumb zone**: one-handed + main actions low + safe area + notch + bottom navigation; do not omit
5. **Offline**: cache + queue + conflict + sync + placeholder + tips; do not omit
6. **Notifications**: push + in-app + silent + grouping + frequency + do-not-disturb; do not omit
7. **Performance**: startup + frame rate + memory + battery + data usage + network switching; do not omit
8. **Not one-shot**: progress gradually from gestures → thumb zone → offline → notifications → performance; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with product-strategy**: mobile UX + strategy co-built
13. **Link with usability-testing**: mobile UX + usability testing co-built
14. **Link with conversational-ux**: mobile UX + conversational co-built
15. **Link with cross-cultural-ux**: mobile UX + cross-cultural co-built
16. **Link with user-research**: mobile UX + user research co-built
17. **Link with journey-mapping**: mobile UX + journey map co-built
18. **Toolchain**: Mobile-UX Framework / Human Interface Guidelines / Material Design / React Native / Flutter / PWA / Lottie / Firebase / OneSignal / Sentry
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why mobile UX is necessary; the worst consequence of not doing it
22. **Inversion thinking**: how much can be solved with desktop UX alone; if solvable, do not introduce a heavy strategy
23. **Second-order thinking**: second-order consequences after the strategy (cost / risk / speed / business)
24. **Occam**: the simpler mobile UX is, the better; cut redundant steps
