## Action recommendations

1. **Five dimensions**: Capability + gap + investment + governance + measurement; no missing dimension
2. **Business-value driven**: Prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Capability**: Current / target / strategic / boundary; do not omit
4. **Gap**: Current / target / shortfall / priority; do not omit
5. **Investment**: Projects / resources / cadence / exit; do not omit
6. **Governance**: Owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: Coverage + adoption + cost + risk + satisfaction; do not omit
8. **Not one-shot**: From capability → gap → investment → governance → measurement progressively; no skipping
9. **Not report-ized**: Project list is only the start; not the end
10. **Not sloganeering**: Every principle must have landing evidence; not vague
11. **Versioned**: Strategy has versions; evolution is traceable
12. **Links with business-capability**: Planning + Business Capability co-build
13. **Links with strategic-planning**: Planning + Strategic Planning co-build
14. **Links with business-architecture**: Planning + Business Architecture co-build
15. **Links with operating-model**: Planning + Operating Model co-build
16. **Links with target-operating-model**: Planning + TOM co-build
17. **Toolchain**: BiZZdesign / Sparx EA / Aris / Planview LeanIX / Avolution
18. **Publicly queryable**: Strategy everyone can look up; not hidden
19. **Periodic review**: Evolution updates; not one-shot
20. **First principles**: Why must capability-based planning strategy; worst consequence of not doing it
21. **Inversion thinking**: How much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: Second-order consequences after the strategy (efficiency / trust / speed / risk) 
23. **Occam**: Capability-based planning the simpler the better; cut redundant layers
