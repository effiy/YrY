## Action recommendations

1. **Five dimensions**: Happiness + Engagement + Adoption + Retention + Task Success + Acquisition + Activation + Retention + Revenue + Referral; no missing dimension
2. **Business-value driven**: prioritize by business growth + user value + retention + LTV; not sloganeering
3. **Happiness**: NPS + CSAT + satisfaction + survey + rating; do not omit
4. **Engagement**: DAU / WAU / MAU + duration + frequency + depth; do not omit
5. **Adoption**: new feature adoption rate + active rate + time window + trend; do not omit
6. **Retention**: D1 / D7 / D30 / D90 + cohort + trend + churn; do not omit
7. **Task Success**: completion rate + duration + error rate + conversion + satisfaction; do not omit
8. **Acquisition**: channel + CAC + conversion + LTV / CAC ratio + ROAS; do not omit
9. **Activation**: aha moment + time window + steps + conversion + optimization; do not omit
10. **Revenue**: ARPU + ARPPU + LTV + MRR + ARR + churn rate; do not omit
11. **Referral**: K factor + invite rate + acceptance rate + viral coefficient + NPS; do not omit
12. **Not one-shot**: progress from Happiness → Engagement → Adoption → Retention → Task Success → Acquisition → Activation → Retention → Revenue → Referral; no skipping
13. **Not report-ized**: reports are only the start; not the end
14. **Not sloganeering**: every principle must have landing evidence; not vague
15. **Versioned**: strategy has versions; evolution is traceable
16. **Linked with pirate-funnel**: HEART+AARRR + funnel co-built
17. **Linked with kpi**: HEART+AARRR + KPI co-built
18. **Linked with north-star-metric**: HEART+AARRR + north star co-built
19. **Toolchain**: HEART Framework / AARRR Framework / Amplitude / Mixpanel / Heap / Google Analytics / Hotjar / FullStory / Looker
20. **Publicly queryable**: strategy everyone can look up; not hidden
21. **Periodic review**: evolution updates; not one-shot
22. **First principles**: why HEART+AARRR is needed; worst consequence of not doing it
23. **Inversion thinking**: how much can be solved by a single metric; if solvable, don't introduce a heavy strategy
24. **Second-order thinking**: second-order consequences after the strategy (cost / risk / growth / business)
25. **Occam**: HEART+AARRR, the simpler the better; cut redundant steps
