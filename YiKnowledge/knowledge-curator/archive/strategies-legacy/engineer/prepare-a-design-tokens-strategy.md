## Action recommendations

1. **Five dimensions**: color + spacing + typography + components + theme; no missing dimension
2. **Business-value driven**: prioritize by business impact + user value + consistency + efficiency; not sloganeering
3. **Color**: palette + semantic + state + dark + contrast + color-blind; do not omit
4. **Spacing**: grid + spacing scale + padding/margin + responsive + safe area; do not omit
5. **Typography**: font family + font size + line height + font weight + letter spacing + multi-language; do not omit
6. **Components**: base + composite + patterns + states + variants + documentation; do not omit
7. **Theme**: light + dark + brand + multi-platform + multi-brand + switching; do not omit
8. **Not one-shot**: from color → spacing → typography → components → theme progressively; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with design-system**: tokens + system co-built
13. **Link with product-strategy**: tokens + strategy co-built
14. **Link with cross-cultural-ux**: tokens + cross-cultural co-built
15. **Link with mobile-ux**: tokens + mobile co-built
16. **Link with web-ux**: tokens + Web co-built
17. **Link with brand-strategy**: tokens + brand co-built
18. **Toolchain**: Design Tokens Framework / W3C Design Tokens Format / Style Dictionary / Tokens Studio / Figma Variables / Theo / Lona / Diez / Storybook / Chromatic / Framer
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why must design tokens; worst consequence of not doing it
22. **Inversion thinking**: how much can be solved with hardcoded values; if solvable do not introduce heavy strategy
23. **Second-order thinking**: second-order consequences after strategy (cost / risk / consistency / business)
24. **Occam**: tokens the simpler the better; cut redundant steps
