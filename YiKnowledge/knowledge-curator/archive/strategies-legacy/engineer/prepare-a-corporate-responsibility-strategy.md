## Action recommendations

1. **Five dimensions**: commitment + actions + report + Governance + Measurement; no missing dimension
2. **Business-value driven**: set priority by trust + speed + risk + compliance + cost; no empty slogans
3. **commitment Commit**: direction / target / cadence / resource / boundary; none missing
4. **actions Act**: project / partner / cadence / resource / closed loop; none missing
5. **report Report**: standard / data / assurance / disclosure / communicate; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: trust + speed + risk + compliance + cost; none missing
8. **Not one-shot**: progressive from commitment -> actions -> report -> Governance -> Measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **linked with sustainability**: CR + Sustainability co-build
13. **linked with esg**: CR + ESG co-build
14. **linked with environmental**: CR + Environmental co-build
15. **linked with social-impact**: CR + SocialImpact co-build
16. **linked with corporate-governance**: CR + Governance co-build
17. **Toolchain**: Workiva / Diligent / Enablon / Cority / Sphera
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why CR is required; worst consequence of not doing it
21. **Inversion**: how much can be solved by PR; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (trust / speed / risk / compliance)
23. **Occam**: CR the simpler the better; cut many redundant topics
