## Action recommendations

1. **Five dimensions**: structure + agenda + oversight + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by oversight + trust + strategy + risk + speed; no empty slogans
3. **Structure**: independent / executive / investor / observer / committee; no gap
4. **Agenda**: strategy / finance / risk / talent / compliance; no gap
5. **Oversight**: CEO / finance / risk / talent / compliance; no gap
6. **Governance**: owner / cadence / review / documentation / drift; no gap
7. **Measurement**: oversight + trust + strategy + risk + speed; no gap
8. **Not one-shot**: gradual from structure → agenda → oversight → governance → measurement; no skipping levels
9. **Not report-only**: a report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Linked with corporate-governance**: BoD + Governance co-build
13. **Linked with executive-sponsorship**: BoD + Sponsor co-build
14. **Linked with leadership**: BoD + Leadership co-build
15. **Linked with investor-relations**: BoD + IR co-build
16. **Linked with risk**: BoD + Risk co-build
17. **Toolchain**: Diligent / BoardEffect / OnBoard / Nasdaq Boardvantage / Azeus
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why a BoD is necessary; worst consequence of not having one
21. **Inversion**: how much can CEO self-decision solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after the strategy (oversight / trust / strategy / risk)
23. **Occam's razor**: the simpler BoD is, the better; cut redundant members
