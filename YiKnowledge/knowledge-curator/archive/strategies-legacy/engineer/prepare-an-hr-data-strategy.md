## Action recommendations

1. **Five dimensions**: governance + integration + insight + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **governance Govern**: standards / master data / privacy / security; do not omit
4. **integration Integrate**: sources / stream / warehouse / self-service; do not omit
5. **insight Insight**: descriptive / diagnostic / predictive / prescriptive; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: from governance → integration → insight → governance → measurement gradual; no skipping
9. **not report-ized**: report numbers only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **and people-analytics link**: HR data + people analytics co-built
13. **and hr-operations link**: HR data + HR operations co-built
14. **and hr-transformation link**: HR data + HR transformation co-built
15. **and workforce-analytics link**: HR data + workforce analytics co-built
16. **and hr-tech link**: HR data + HR technology co-built
17. **Toolchain**: Workday Prism / SAP SuccessFactors HANA / Oracle HCM Cloud / Visier / OneModel
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must HR data strategy; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by default; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: HR data the simpler the better; cut redundant layers
