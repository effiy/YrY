## Action recommendations

1. **Five dimensions**: audience + message + channel + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Audience**: customer / partner / media / analyst; none missing
4. **Message**: brand / product / campaign / content; none missing
5. **Channel**: advertising / PR / social media / event; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progress gradually from audience -> message -> channel -> governance -> measurement; no skipping levels
9. **Not report-only**: advertising is only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Links with marketing**: marketing communications + marketing co-build
13. **Links with messaging**: marketing communications + message co-build
14. **Links with product-marketing**: marketing communications + product marketing co-build
15. **Links with corporate-communications**: marketing communications + corporate communications co-build
16. **Links with brand**: marketing communications + brand co-build
17. **Toolchain**: HubSpot / Marketo / Salesforce Marketing Cloud / Adobe Experience Cloud / Hootsuite
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why a marketing communications strategy is needed; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: marketing communications the simpler the better; cut redundant layers
