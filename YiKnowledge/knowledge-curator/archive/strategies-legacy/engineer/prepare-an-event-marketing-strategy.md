## Action recommendations

1. **Five dimensions**: audience + content + channel + cadence + measurement; no missing dimension
2. **Business-value driven**: prioritize by SQL + revenue contribution + retention + NPS + SOV; no empty slogans
3. **Audience**: customer + partner + analyst + KOL + internal; none missing
4. **Content**: keynote / session / demo / hospitality / booth / demonstration; none missing
5. **Channel**: on-site + online + social + email + live-stream; none missing
6. **Cadence**: before + during + after + follow-up + year-round; none missing
7. **Measurement**: SQL + revenue contribution + retention + NPS + SOV; none missing
8. **Not one-shot**: progressive from audience -> content -> channel -> cadence -> measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landing evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with campaign-planning**: event + campaign co-build
13. **Link with field-marketing**: event + regional co-build
14. **Link with content**: event + content co-build
15. **Link with demand-generation**: event + funnel co-build
16. **Link with brand**: event + brand co-build
17. **Toolchain**: Cvent / Bizzabo / Brello / Splash / Eventbrite / Hopin / Zoom-Events / Rainfocus
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why an event marketing strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved with pure online marketing; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / brand) 
23. **Occam**: event marketing the simpler the better; cut redundant steps
