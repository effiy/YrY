## Action recommendations

1. **Five dimensions**: audience + touchpoints + content + channels + measurement; no missing dimension
2. **Business-value driven**: prioritize by awareness + preference + traffic + leads + revenue; not sloganeering
3. **Audience**: ICP / role / region / stage / feedback; do not omit
4. **Touchpoint**: ads / content / events / PR / word-of-mouth; do not omit
5. **Content**: theme / format / personalization / cadence / reuse; do not omit
6. **Channel**: social / search / media / events / KOL; do not omit
7. **Governance**: owner / cadence / review / documentation / drift; do not omit
8. **Measurement**: aided + unaided + share-of-voice + impression + reach; do not omit
9. **Not one-shot**: progressive from audience -> touchpoints -> content -> channels -> measurement; no skipping
10. **Not report-ized**: reports are only the start; not the end
11. **Not sloganeering**: every principle must have landing evidence; not vague
12. **Versioned**: strategy has versions; evolution is traceable
13. **Link with brand**: Awareness + Brand co-built
14. **Link with inbound**: Awareness + Inbound co-built
15. **Link with content**: Awareness + Content co-built
16. **Link with event-marketing**: Awareness + Event co-built
17. **Link with pr**: Awareness + PR co-built
18. **Toolchain**: Google Ads / Meta Ads / LinkedIn Ads / SEMrush / Brandwatch
19. **Publicly queryable**: everyone can look up the strategy; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why Awareness is necessary; worst consequence of not doing it
22. **Inversion thinking**: how much can be solved with cold sales calls; if solvable do not introduce heavy strategy
23. **Occam**: Awareness the simpler the better; cut redundant channels
