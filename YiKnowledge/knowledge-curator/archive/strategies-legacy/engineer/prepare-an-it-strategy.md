## Action recommendations

1. **Five dimensions**: Vision + capability + roadmap + governance + measurement; no missing dimension
2. **Business-value driven**: Prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **Vision Vision**: business alignment / digital ambition / boundary; no leakage
4. **Capability Capability**: infrastructure / application / data / security / governance; no leakage
5. **Roadmap Roadmap**: stage / dependency / resource / milestone; no leakage
6. **Governance Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: Progress gradually from vision → capability → roadmap → governance → measurement; no skipping levels
9. **No report-ism**: budgets are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with enterprise-architecture**: IT + Architecture co-build
13. **Link with technology**: IT + technology co-build
14. **Link with digital-transformation**: IT + digital co-build
15. **Link with cloud**: IT + cloud co-build
16. **Link with security**: IT + security co-build
17. **Toolchain**: TOGAF / Gartner / Forrester / McKinsey / IT Capital Planning
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must IT strategy; worst consequence of not doing
21. **Inversion**: how much can be solved by defaults; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after the strategy (efficiency / trust / speed / risk)
23. **Occam's razor**: IT strategy — simpler is better; cut redundant layers
