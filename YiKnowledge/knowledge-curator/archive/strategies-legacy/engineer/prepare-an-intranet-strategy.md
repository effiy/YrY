## Action recommendations

1. **Five dimensions**: information + applications + collaboration + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Information**: publishing / categorization / search / multimedia / drift; do not omit
4. **Applications**: process / form / self-service / integration / workflow; do not omit
5. **Collaboration**: social / groups / comments / collaboration / feedback; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: efficiency + trust + speed + risk + cost; do not omit
8. **not one-shot**: progress gradually from information -> applications -> collaboration -> governance -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with internal-communications**: Intranet + InternalComms co-built
13. **Link with digital-workplace**: Intranet + DW co-built
14. **Link with employee-experience**: Intranet + EX co-built
15. **Link with corporate-communications**: Intranet + CorpComms co-built
16. **Link with knowledge-management**: Intranet + KM co-built
17. **Toolchain**: SharePoint / Staffbase / Simpplr / LumApps / Interact
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must Intranet; worst consequence of not doing it
21. **inversion thinking**: how much can be solved by email; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: Intranet the simpler the better; cut redundant sections
