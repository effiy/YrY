## Action recommendations

1. **Five dimensions**: inventory + lifecycle + value + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; not sloganeering
3. **Inventory**: identify / classify / state / tag; do not omit
4. **Lifecycle**: acquire / use / maintain / dispose; do not omit
5. **Value**: valuation / depreciation / impairment / disposal; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **Not one-shot**: from inventory → lifecycle → value → governance → measurement gradual; no skipping
9. **Not report-ized**: inventory is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with property**: asset + property co-build
13. **Link with facility**: asset + facility co-build
14. **Link with it-asset-management**: asset + IT asset co-build
15. **Link with corporate-real-estate**: asset + corporate real estate co-build
16. **Link with real-estate**: asset + real estate co-build
17. **Toolchain**: IBM Maximo / ServiceNow SAM / Infor EAM / SAP EAM / Oracle EAM
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must asset strategy; worst consequence of not doing
21. **inversion thinking**: how much can defaults solve; if solvable do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: assets the simpler the better; cut redundant layers
