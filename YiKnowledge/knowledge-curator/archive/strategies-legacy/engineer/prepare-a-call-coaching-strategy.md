1. **Five dimensions**: standards + scoring + feedback + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by win-rate + cycle-time + ACV + renewal + NRR; no empty slogans
3. **Standards**: opening / pain points / value / risk / closing; no leakage
4. **Scoring**: stage / behavior / content / cadence / measurement; no leakage
5. **Feedback**: strengths / weaknesses / actions / resources / upgrades; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: win-rate + cycle-time + ACV + renewal + NRR; no leakage
8. **Not one-shot**: gradual from standards -> scoring -> feedback -> governance -> measurement; no skipping levels
