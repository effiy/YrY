## Action recommendations

1. **Five dimensions**: activity + value + cost + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Activity**: primary / support / internal / external; do not omit
4. **Value**: customer / business / financial / strategic; do not omit
5. **Cost**: direct / indirect / opportunity / sunk; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: progress gradually from activity -> value -> cost -> governance -> measurement; no skipping
9. **not report-ized**: Porter's model is only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **Link with value-stream**: value chain + value stream co-built
13. **Link with business-architecture**: value chain + business architecture co-built
14. **Link with business-strategy**: value chain + business strategy co-built
15. **Link with corporate-strategy**: value chain + corporate strategy co-built
16. **Link with operating-model**: value chain + operating model co-built
17. **Toolchain**: Porter's Value Chain / BiZZdesign / Sparx EA / Strategyzer / McKinsey
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must value chain strategy; worst consequence of not doing it
21. **inversion thinking**: how much can be solved by default; if solvable, do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: value chain the simpler the better; cut redundant layers
