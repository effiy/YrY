## Action recommendations

1. **Five dimensions**: semantic + model + permission + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Semantic**: metrics / measurement / dimensions; do not omit
4. **Model**: managed data model; do not omit
5. **Permission**: role / row-level / column-level; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: active users + self-serve rate + data story count + risk + cost; do not omit
8. **Not one-shot**: progressive from semantic → model → permission → governance → measurement; no skipping
9. **Not report-ized**: dashboard count is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with data-democratization**: self-serve BI + democratization co-built
13. **Link with embedded-bi**: self-serve BI + embedded BI co-built
14. **Link with semantic-layer**: self-serve BI + semantic layer co-built
15. **Link with data-literacy**: self-serve BI + literacy co-built
16. **Link with data-catalog**: self-serve BI + data catalog co-built
17. **Toolchain**: Tableau / Power BI / Looker / Sigma Computing / ThoughtSpot
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must self-serve BI; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by IT ticketing; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: self-serve BI the simpler the better; cut redundant layers
