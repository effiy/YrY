## Action recommendations

1. **Five dimensions**: identify + model + apply + governance + measurement; none can be missing
2. **Business-value driven**: prioritize by adoption + trust + speed + risk + cost; not sloganeering
3. **Identify**: role / position / strategy / high performers / gaps; do not omit
4. **Model**: behavior / skill / knowledge / trait / level; do not omit
5. **Apply**: hire / develop / use / evaluate / retain; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: adoption + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from identify → model → apply → governance → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with training-and-enablement**: CM + T&E co-build
13. **Link with skills-matrix**: CM + Skills co-build
14. **Link with talent-review**: CM + Talent co-build
15. **Link with leadership**: CM + Leadership co-build
16. **Link with performance-management**: CM + Performance co-build
17. **Toolchain**: Lominger / Korn Ferry / DDI / SHL / HR Avatar
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why a CM is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can a JD solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (adoption / trust / speed / risk) 
23. **Occam**: CM — the simpler the better; cut redundant competencies
