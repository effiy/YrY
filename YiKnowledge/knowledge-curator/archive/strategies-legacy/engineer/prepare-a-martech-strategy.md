## Action recommendations

1. **Five dimensions**: stack + integration + data + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Stack**: CDP / MAP / CMS / analytics; none missing
4. **Integration**: API / event / label / reverse ETL; none missing
5. **Data**: identity / event / audience / semantic; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from stack -> integration -> data -> Governance -> Measurement; no skipping levels
9. **Not report-only**: tool stack is only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **and marketing links**: tech + marketing co-build
13. **and marketing-ops links**: tech + Operations co-build
14. **and marketing-analytics links**: tech + analytics co-build
15. **and customer-data-platform links**: tech + CDP co-build
16. **and content-distribution links**: tech + distribution co-build
17. **Toolchain**: HubSpot / Marketo / Salesforce Marketing Cloud / Segment / mParticle
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why must marketing tech strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: marketing tech the simpler the better; cut redundant layers
