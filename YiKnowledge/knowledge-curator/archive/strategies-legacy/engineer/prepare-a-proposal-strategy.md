## Action recommendations

1. **Five dimensions**: structure + content + pricing + risk + Measurement; no missing dimension
2. **Business-value driven**: prioritize by win-rate + ACV + cycle-time + renewal + NRR; no empty slogans
3. **Structure**: executive summary / pain / solution / value / pricing / timetable / risk; none missing
4. **content Content**: business / tech / finance / case study / roadmap; none missing
5. **pricing Pricing**: list price / discount / options / terms / renewal; none missing
6. **risk risk**: competition / budget / decision / implementation / compliance; none missing
7. **Measure**: win-rate + ACV + cycle-time + renewal + NRR; none missing
8. **Not one-shot**: progress from structure → content → pricing → risk → Measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with deal-presentation**: proposal + presentation co-build
13. **Link with sales-playbook**: proposal + sales playbook co-build
14. **Link with roi-calculator**: proposal + ROI calculator co-build
15. **Link with pricing**: proposal + pricing co-build
16. **Link with deal-review**: proposal + deal-review co-build
17. **Toolchain**: Salesforce-CPQ / PandaDoc / Conga / DocuSign / Loopio / Responsive
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must proposal; worst consequence of not doing it
21. **Inversion**: how much can be solved by free-form drafting; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / retention)
23. **Occam**: proposal the simpler the better; cut redundant sections
