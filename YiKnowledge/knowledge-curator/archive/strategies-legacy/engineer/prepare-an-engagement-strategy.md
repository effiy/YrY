## Action recommendations

1. **Five dimensions**: behavior + frequency + depth + notification + measurement; no missing dimension
2. **Business-value driven**: prioritize by DAU + WAU + MAU + frequency + LTV; not sloganeering
3. **Behavior**: core + secondary + derived + trigger + flow; do not omit
4. **Frequency**: DAU / WAU / MAU + frequency distribution + habit + trigger; do not omit
5. **Depth**: session + path + feature + data + custom; do not omit
6. **Notification**: push + email + in-app + time + frequency; do not omit
7. **Measure**: DAU / WAU / MAU + stickiness + frequency + depth + funnel; do not omit
8. **Not one-shot**: progressive from behavior → frequency → depth → notification → measurement; no skipping
9. **Not report-only**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with adoption**: engagement + adoption co-built
13. **Link with retention**: engagement + retention co-built
14. **Link with lifecycle**: engagement + lifecycle co-built
15. **Link with product-analytics**: engagement + measurement co-built
16. **Link with community**: engagement + community co-built
17. **Toolchain**: Engagement-Framework / Braze / Customer.io / Iterable / Intercom / OneSignal / Appcues / Pendo / Amplitude / Mixpanel / PostHog
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must engagement strategy; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by natural usage; if solvable do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (cost / risk / frequency / business)
23. **Occam**: engagement the simpler the better; cut redundant steps
