## Action recommendations

1. **five dimensions**: language + layout + colour + icon + customs; no missing dimension
2. **business-value driven**: prioritise by business growth + user value + risk + opportunity; not sloganeering
3. **language Language**: copy + terminology + tense + gender + honorifics + tone; do not omit
4. **layout Layout**: LTR / RTL + character length + font + line height + line wrap + whitespace; do not omit
5. **colour Color**: cultural meaning + brand + contrast + colour blindness + threshold; do not omit
6. **icon Icon**: meaning + culture + taboo + alternative + recognisability; do not omit
7. **customs Custom**: festival + holiday + numbers + direction + naming + taboo; do not omit
8. **not one-shot**: from language → layout → colour → icon → customs gradual; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with product-strategy**: cross-cultural UX + strategy co-built
13. **link with user-research**: cross-cultural UX + user co-built
14. **link with mobile-ux**: cross-cultural UX + mobile co-built
15. **link with multi-region**: cross-cultural UX + multi-region co-built
16. **link with customer-experience**: cross-cultural UX + experience co-built
17. **link with journey-mapping**: cross-cultural UX + journey map co-built
18. **toolchain**: Cross-Cultural-UX Framework / i18next / FormatJS / ICU MessageFormat / Lokalise / Phrase / Crowdin / Transifex / LTR-RTL / Google Noto Fonts
19. **publicly queryable**: strategy everyone can look up; not hidden
20. **periodic review**: evolution updates; not one-shot
21. **first principles**: why must cross-cultural UX; worst consequence of not doing
22. **inversion thinking**: how much can be solved with a single language; if solvable do not introduce heavy strategy
23. **second-order thinking**: second-order consequences after strategy (cost / risk / growth / business)
24. **Occam**: cross-cultural UX the simpler the better; cut redundant steps
