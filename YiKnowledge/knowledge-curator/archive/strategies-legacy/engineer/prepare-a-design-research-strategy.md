## Action recommendations

1. **Five dimensions**: method + data + analysis + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **method Method**: explore / assess / validation / walkthrough; none missing
4. **data Data**: scenario / row for / hypothesis / prototype; none missing
5. **analysis Analyze**: insight / opportunity / priority / landing; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from method -> data -> analysis -> governance -> measurement; no skipping levels
9. **Not report-only**: sketches are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **links with ux-research**: design + UX co-build
13. **links with ethnographic-research**: design + ethnography co-build
14. **links with contextual-inquiry**: design + context co-build
15. **links with user-research**: design + users co-build
16. **links with design-ops**: design + operations co-build
17. **Toolchain**: Figma / Miro / Maze / Dovetail / Notion
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must design research strategy; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: design research the simpler the better; cut redundant layers
