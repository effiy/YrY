## Action recommendations

1. **Five dimensions**: intent + content + channel + cadence + measurement; no missing dimension
2. **Business-value driven**: prioritize by organic + MQL + revenue + ranking + CTR; not sloganeering
3. **Intent**: informational / commercial / transactional / navigational; do not omit
4. **Content**: pillar / cluster / retire / update / link; do not omit
5. **Channel**: Google / Bing / Baidu / Yandex / Naver; do not omit
6. **Cadence**: daily / weekly / monthly / quarterly / yearly; do not omit
7. **Measure**: organic + MQL + revenue + ranking + CTR; do not omit
8. **Not one-shot**: gradual from intent → content → channel → cadence → measurement; no skipping
9. **Not report-only**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with SEO**: organic search + SEO co-build
13. **Link with content-marketing**: organic search + content marketing co-build
14. **Link with paid-search**: organic search + paid search co-build
15. **Link with demand-generation**: organic search + funnel co-build
16. **Link with content**: organic search + content co-build
17. **Toolchain**: Google-Search-Console / Bing-Webmaster / Ahrefs / Semrush / Moz / Botify / -krudo
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must organic search strategy; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by paid; if solvable don't introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (cost / risk / revenue / brand)
23. **Occam**: organic search simpler is better; cut redundant steps
