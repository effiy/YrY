## Action recommendations

1. **Five dimensions**: Audience + content + cadence + tool + measurement; no missing dimension
2. **Business-value driven**: Set priority by win-rate + revenue + quota-attainment + retention + speed; no empty slogans
3. **Audience**: AE / SDR / AM / SE + tier + stage; no leakage
4. **Content**: Skill + will + deal + behavior + career; no leakage
5. **Cadence**: Daily / weekly / monthly / quarterly / annual; no leakage
6. **Tool**: Call intelligence / scoring / video / CRM / integration; no leakage
7. **Measurement**: Win-rate + revenue + quota-attainment + retention + speed; no leakage
8. **Not one-shot**: Gradual from audience → content → cadence → tool → measurement; no skipping levels
9. **No report-ism**: Report is just the start; not the end
10. **No empty slogans**: Every principle must mark implementation evidence; no vagueness
11. **Versioned**: Strategy is versioned; evolution is traceable
12. **Link with sales-playbook**: Coaching + playbook co-build
13. **Link with sales-enablement**: Coaching + enablement co-build
14. **Link with leadership**: Coaching + leadership co-build
15. **Link with performance-management**: Coaching + PM co-build
16. **Link with sales-ops**: Coaching + operations co-build
17. **Toolchain**: Gong / Chorus / Second Nature / Mindtickle / Saleshood / Showpad / Lessonly / Outreach-Coaching
18. **Publicly discoverable**: Strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: Why must sales coaching strategy; worst consequence of not doing
21. **Inversion**: Rely on performance assessment how much can be solved; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: Second-order consequence after strategy (cost / Risk / revenue / retention) 
23. **Occam's razor**: Sales coaching simpler is better; cut redundant steps
