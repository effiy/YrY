## Action recommendations

1. **Five dimensions**: audience + content + channel + cadence + Measurement; no missing dimension
2. **Business-value driven**: set priority by SQL + revenue + conversion + speed + retention; no empty slogans
3. **Audience**: ICP + tier + segment + signal + intent; none missing
4. **Content**: email / demo / video / case study / resource / multi-channel sequencing; none missing
5. **Channel**: phone / email / social / video / direct / partner; none missing
6. **Cadence**: T+0 / +1 / +3 / +7 / +14 + escalate; none missing
7. **Measure**: SQL + revenue + conversion + speed + retention; none missing
8. **Not one-shot**: progressive from audience -> content -> channel -> cadence -> Measurement; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with sales-playbook**: sales development + playbook co-build
13. **Link with lead-scoring**: sales development + lead scoring co-build
14. **Link with demand-generation**: sales development + funnel co-build
15. **Link with ABM**: sales development + ABM co-build
16. **Link with sales-ops**: sales development + operations co-build
17. **Toolchain**: Outreach / Salesloft / Apollo / 6sense / Demandbase / Clearbit / ZoomInfo / Cognism / LinkedIn-Sales-Nav
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why must sales development strategy; worst consequence of not doing it
21. **Inversion**: how much can be solved by relying on part-time AE; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / brand)
23. **Occam**: sales development the simpler the better; cut redundant steps
