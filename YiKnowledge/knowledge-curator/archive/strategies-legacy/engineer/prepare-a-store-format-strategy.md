## Action recommendations

1. **Five dimensions**: scale + positioning + format + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Scale**: area / shelf / closed-loop; do not omit
4. **Position**: customer segment / ticket size / closed-loop; do not omit
5. **Format**: hyper / super / convenience / closed-loop; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: efficiency + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from scale → positioning → format → governance → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with store-operations**: StoreFormat + StoreOperations co-built
13. **Link with retail-operations**: StoreFormat + RetailOperations co-built
14. **Link with merchandising**: StoreFormat + Merchandising co-built
15. **Link with assortment**: StoreFormat + Assortment co-built
16. **Link with planogram**: StoreFormat + Planogram co-built
17. **Toolchain**: JDA / Blue Yonder / SAP S/4HANA / Oracle / Spaceman
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must StoreFormat; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by copying a store; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: StoreFormat the simpler the better; cut redundant formats
