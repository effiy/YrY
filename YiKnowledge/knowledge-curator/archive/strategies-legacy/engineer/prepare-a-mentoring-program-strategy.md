2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; no empty slogans
3. **matching Match**: intent / skill / target / capacity; none missing
4. **relationship Relationship**: contract / cadence / feedback / termination; none missing
5. **enablement Enable**: training / resources / templates / incentives; none missing

7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from matching → relationship → enablement → governance → measurement; no skipping levels
