## Action recommendations

1. **Five dimensions**: strategy + structure + operations + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by growth + trust + speed + risk + cost; no empty slogans
3. **Strategy**: market / product / technology / resource / policy; no leakage
4. **Structure**: equity / board / management / decision / exit; no leakage
5. **Operations**: people / finance / assets / sales / IT; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: growth + trust + speed + risk + cost; no leakage
8. **Not one-shot**: gradual from strategy → structure → operations → governance → measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with strategic-alliance**: JV + Alliance co-build
13. **Link with partnership**: JV + Partnership co-build
14. **Link with m-and-a**: JV + M&A co-build
15. **Link with corporate-governance**: JV + Governance co-build
16. **Link with risk**: JV + Risk co-build
17. **Toolchain**: DealRoom / Transcript / PitchBook / Crunchbase / Affinity
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: why must JV; worst consequence of not doing it
21. **Inversion**: how much can a wholly-owned entity solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after the strategy (growth / trust / speed / risk)
23. **Occam's razor**: simpler JV is better; cut redundant clauses
