## Action recommendations

1. **First principles**: first ask "what does the rebrand solve / what happens without rebrand / ROI / user impact"; do not rebrand for rebranding's sake; see [first-principles-summary.md](../../knowledge-curator/templates/thinking/first-principles.md).
2. **Inversion**: first imagine "how the rebrand will fail (users don't accept / trust collapse / legal risk / churn / confused old users / delayed promotion)" then set guardrails; see [inversion-summary.md](../../knowledge-curator/templates/thinking/inversion.md).
3. **Strong opinions loosely held**: must run [strong-opinions-loosely-held-summary.md](../../knowledge-curator/templates/thinking/strong-opinions-loosely-held.md); strong stance + leave room for dialogue.
4. **Second-order effects**: rebrand → traffic drops short-term → rises long-term → another rebrand; follow [second-order-thinking-summary.md](../../knowledge-curator/templates/thinking/second-order-thinking.md).
5. **Occam**: the simplest rebrand that meets strategy wins; do not pile up changes; see [ockhams-razor-summary.md](../../knowledge-curator/templates/thinking/ockhams-razor.md).
6. **Strategy**: must run [product-strategy-summary.md](../../product-manager/frameworks/prepare-a-product-strategy.md) + [second-curve-summary.md](../../executive/strategy/second-curve.md) + [porter-five-forces-summary.md](../../executive/strategy/porter-five-forces.md); rebrand must serve strategy.
7. **JTBD**: must run [jobs-to-be-done-summary.md](../../product-manager/frameworks/jobs-to-be-done.md) to understand real user needs; do not pile up visuals.
8. **Audience**: must run [stakeholder-map.md](../../knowledge-curator/people/stakeholders/stakeholder-map.md); old users / new users / media / investors / employees / partners each get tiered narrative.
9. **Story**: must run [flywheel-effect-summary.md](../../knowledge-curator/templates/thinking/flywheel-effect.md); past → present → future + must have emotion + must have data.
10. **Visual**: must run visual specs (logo / color / typography / icon / photography / layout) + asset inventory + migration checklist.
11. **Comparison**: must run [competitor-analysis-template.md](../../executive/industry/competitors/competitor-analysis.md) + same-industry brand comparison + must differentiate.
12. **Roadmap**: must run [now-next-later-roadmap-summary.md](../../executive/strategy/now-next-later-roadmap.md); warm-up → announce → launch → promote → consolidate.
13. **Landing**: after rebrand passes, must land in ADR + milestones + retrospective; follow [adr-template.md](../../knowledge-curator/templates/adr.md).
14. **RACI**: must run [raci-matrix-summary.md](../../engineer/processes/collaboration/raci-matrix.md); marketing / engineering / product / sponsor / legal owner.
15. **Cross-timezone**: must run [cross-timezone-collaboration-summary.md](../../engineer/processes/collaboration/cross-timezone-collaboration.md); multi-timezone tiered announcement.
16. **Freeze period**: big promotions follow [release-freeze-process.md](../../oncall-sre/release/release-freeze.md); do not rebrand.
17. **Notification**: must run [communication-cadence.md](../../knowledge-curator/people/stakeholders/communication-cadence.md) to notify inside and outside + must all-hands + must Q&A.
18. **Pre-read**: send materials ahead + sponsor pre-review + pull sponsor; follow [i-want-to-prepare-an-all-hands.md](./prepare-an-all-hands.md).
19. **Monitoring**: must run [monitoring-governance-process.md](../../engineer/processes/monitoring-governance.md) to watch traffic / retention / NPS / feedback.
20. **Retrospective**: after rebrand must run [retrospective-template.md](../../knowledge-curator/templates/retrospective.md) retrospective + archive [review-log.md](../../knowledge-curator/governance/review-log.md).
21. **Quarterly audit**: follow [governance.md](../../knowledge-curator/governance/governance.md) + [review-log.md](../../knowledge-curator/governance/review-log.md); scan whether brand assets still aligned + users still accept.
22. **Flywheel**: rebrand done well → trust rises → more investment → bigger business; see [flywheel-effect-summary.md](../../knowledge-curator/templates/thinking/flywheel-effect.md).
