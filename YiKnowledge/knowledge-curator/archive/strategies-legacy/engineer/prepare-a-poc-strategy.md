## Action recommendations

1. **Five dimensions**: goal + scope + success + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by win-rate + cycle-time + POC-to-close + revenue + renewal; not sloganeering
3. **goal Objective**: business / value / technical / validation / decision; do not omit
4. **scope Scope**: use cases / data / integration / time / resources; do not omit
5. **success Success**: measurement / threshold / decision / fallback / measurement; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: win-rate + cycle-time + POC-to-close + revenue + renewal; do not omit
8. **not one-shot**: from goal → scope → success → governance → measurement progressively; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with pov**: POC + POV co-build
13. **link with pilot**: POC + pilot co-build
14. **link with trial**: POC + trial co-build
15. **link with mutual-action-plan**: POC + MAP co-build
16. **link with value-selling**: POC + value selling co-build
17. **toolchain**: Salesforce / Clari / Gong / Jira / Confluence / Slack
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why POC must exist; the worst consequence of not doing it
21. **inversion thinking**: how much can a demo alone solve; if solvable don't introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (cost / risk / revenue / retention)
23. **Occam**: POC the simpler the better; cut redundant use cases
