## Action recommendations

1. **Five dimensions**: role + responsibility + decision + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Role**: owner / steward / custodian; do not omit
4. **Responsibility**: define / maintain / serve; do not omit
5. **Decision**: change / priority / risk; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: coverage + response + cost + risk + satisfaction; do not omit
8. **not one-shot**: progressive from role → responsibility → decision → governance → measurement; no skipping
9. **not report-ized**: owner count only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **Link with data-governance**: ownership + data governance co-built
13. **Link with data-stewardship**: ownership + data stewardship co-built
14. **Link with data-custodian**: ownership + data custodian co-built
15. **Link with data-domain**: ownership + data domain co-built
16. **Link with data-product-management**: ownership + data product co-built
17. **Toolchain**: Collibra / Informatica Axon / Alation / DataHub / Amundsen
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must data ownership; worst consequence of not doing it
21. **inversion thinking**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk) 
23. **Occam**: data ownership the simpler the better; cut redundant layers
