## Action recommendations

1. **Five dimensions**: site + observation + inquiry + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Site / Gemba**: actual place / time / role / process / trace; do not omit
4. **Observe**: original state / waste / exception / dependency / closure; do not omit
5. **Ask**: 5W1H / why / assumption / verification / closure; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: efficiency + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from site -> observation -> inquiry -> governance -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with lean**: Gemba + Lean co-build
13. **Link with continuous-improvement**: Gemba + CI co-build
14. **Link with process-excellence**: Gemba + Process co-build
15. **Link with kaizen**: Gemba + Kaizen co-build
16. **Link with quality-management**: Gemba + QM co-build
17. **Toolchain**: Lean games / Gemba Walk App / KaiNexus / Miro / iObeya
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must Gemba; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by reports; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk) 
23. **Occam**: Gemba the simpler the better; cut redundant steps
