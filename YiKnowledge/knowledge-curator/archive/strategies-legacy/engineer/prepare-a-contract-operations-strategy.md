2. **Business-value driven**: prioritize by risk + trust + speed + cost + compliance; no empty slogans
3. **Drafting**: template + clauses + risk + version; none missing
4. **Negotiation**: red lines + concessions + records; none missing

8. **Not one-shot**: progressive from drafting → negotiation → performance → governance → measurement; no skipping levels
