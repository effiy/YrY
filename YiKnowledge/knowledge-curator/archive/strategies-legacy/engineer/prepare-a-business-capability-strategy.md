## Action recommendations

1. **Five dimensions**: identify + tier + map + governance + measurement; no missing dimension
2. **business-value driven**: by efficiency + trust + speed + risk + cost set priority; no sloganeering
3. **identify Identify**: capability / sub-capability / element / relation; do not omit
4. **tier Tier**: core / differentiating / supporting / strategic; do not omit
5. **map Map**: organisation / process / application / data; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: from identify → tier → map → governance → measurement gradual; no skipping
9. **not report-ism**: list is only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **and business-architecture link**: capability + business architecture co-build
13. **and capability-based-planning link**: capability + capability planning co-build
14. **and operating-model link**: capability + operations model co-build
15. **and strategic-planning link**: capability + strategic planning co-build
16. **and business-strategy link**: capability + business strategy co-build
17. **Toolchain**: Archi / Sparx EA / BiZZdesign / Avolution / Planview LeanIX
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must business-capability strategy; worst consequence of not doing
21. **inversion thinking**: rely on default how much can be solved; if solvable, do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk) 
23. **Occam**: business capability the simpler the better; cut redundant layers
