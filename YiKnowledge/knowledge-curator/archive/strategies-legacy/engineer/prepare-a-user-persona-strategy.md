## Action recommendations

1. **Five dimensions**: data + structure + usage + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by growth + trust + speed + risk + cost; not sloganeering
3. **data Data**: qualitative / quantitative / behavior / mindset; do not omit
4. **structure Structure**: background / goal / pain point / behavior; do not omit
5. **usage Use**: product / marketing / sales / design; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: coverage + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: progress from data → structure → usage → governance → measurement; no skipping
9. **not report-ized**: profile is only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **Link with persona-research**: persona + research co-build
13. **Link with customer-needs**: persona + needs co-build
14. **Link with user-research**: persona + user co-build
15. **Link with ux-research**: persona + UX co-build
16. **Link with market-segmentation-research**: persona + segmentation co-build
17. **Toolchain**: Userforge / Xtensio / HubSpot Make My Persona / Personapp / Delve
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must user persona strategy; worst consequence of not doing it
21. **inversion thinking**: how much can be solved by defaults; if solvable, don't introduce a heavy strategy
22. **second-order thinking**: second-order consequences after strategy (growth / trust / speed / risk)
23. **Occam**: user persona the simpler the better; cut redundant layers
