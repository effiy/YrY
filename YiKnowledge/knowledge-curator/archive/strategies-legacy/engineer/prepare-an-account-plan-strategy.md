## Action recommendations

1. **Five dimensions**: target + stakeholder + path + risk + measurement; none can be missing
2. **Business-value driven**: prioritize by ARR + NRR + win-rate + cycle-time + renewal; no empty slogans
3. **Target**: revenue / renewal / expansion / strategy / relationship; no leakage
4. **Stakeholder**: champion / decision-maker / influencer / blocker / user; no leakage
5. **Path**: milestone / cadence / next-step / retire / upgrade; no leakage
6. **Risk**: competition / budget / time / decision / implementation; no leakage
7. **Measurement**: ARR + NRR + win-rate + cycle-time + renewal; no leakage
8. **Not one-shot**: progressive from target → stakeholder → path → risk → measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with account-mapping**: account plan + account mapping co-build
13. **Link with account-tiering**: account plan + account tiering co-build
14. **Link with account-management**: account plan + account management co-build
15. **Link with win-plan**: account plan + win plan co-build
16. **Link with mutual-action-plan**: account plan + MAP co-build
17. **Toolchain**: Salesforce / Clari / Boost-UP / People-AI / Gong / Outreach
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why an account plan is necessary; worst consequence of not doing it
21. **Inversion**: how much can AE self-direction solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (cost / risk / revenue / retention) 
23. **Occam's razor**: account plan — simpler is better; cut redundant sections
