## Action recommendations

1. **Five dimensions**: design + operate + evolve + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Design**: architecture / boundary / role / responsibility; no leakage
4. **Operate**: process / decision / collaboration / information; no leakage
5. **Evolve**: change / stage / learning / retrospective; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: from design → operate → evolve → governance → measurement gradual; no skipping levels
9. **No report-ism**: architecture is only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with org-design**: organization + organization design co-built
13. **Link with organizational-culture**: organization + culture co-built
14. **Link with people**: organization + people co-built
15. **Link with leadership**: organization + leadership co-built
16. **Link with governance**: organization + governance co-built
17. **Toolchain**: McKinsey Org Solutions / orgvue / Workday / Pi / Korn Ferry
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why an organization strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam's razor**: organization simpler is better; cut redundant layers
