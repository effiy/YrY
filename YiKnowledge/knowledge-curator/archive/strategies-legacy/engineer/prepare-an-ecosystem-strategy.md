## Action recommendations

1. **Five dimensions**: core + boundary + role + value + measurement; none can be missing
2. **Business-value driven**: prioritize by business growth + network effect + LTV + defense; no empty slogans
3. **Core**: core capability + non-replicable + data + user + algorithm; no leakage
4. **Boundary**: open + closed loop + internal/external + governance + exit; no leakage
5. **Roles**: platform + provider + consumer + governance + third-party + developer; no leakage
6. **Value**: bidirectional + multi-sided + network effect + scale + synergy; no leakage
7. **Measurement**: nodes + transactions + retention + network density + single-sided/multi-sided ROI; no leakage
8. **Not one-shot**: progressive from core → boundary → role → value → measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with product-strategy**: ecosystem + strategy co-build
13. **Link with partnership**: ecosystem + partnership co-build
14. **Link with developer-portal**: ecosystem + developer co-build
15. **Link with go-to-market**: ecosystem + GTM co-build
16. **Link with product-roadmap**: ecosystem + roadmap co-build
17. **Link with revenue-ops**: ecosystem + revenue co-build
18. **Toolchain**: Ecosystem-Strategy Framework / Platform Revolution / Matchmakers / Network Effects / API Platform / Stripe Atlas / AWS Partner Network / App Store Connect / Google Play Console
19. **Publicly discoverable**: strategy is publicly discoverable; not hidden
20. **Regular review**: evolve and update; not one-shot
21. **First principles**: why an ecosystem is necessary; worst consequence of not doing it
22. **Inversion**: how much can a single-sided approach solve; if solvable, don't introduce a heavy strategy
23. **Second-order thinking**: second-order consequence after strategy (cost / risk / growth / business) 
24. **Occam's razor**: ecosystem — simpler is better; cut redundant steps
