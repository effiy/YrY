## Action recommendations

1. **Five dimensions**: rules + redemption + experience + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Rules**: earn / burn / expiry / fairness; no leakage
4. **Redeem**: redemption / inventory / fulfillment / anti-fraud; no leakage
5. **Experience**: visibility / immediacy / itemization / surprise; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: gradual from rules -> redemption -> experience -> governance -> measurement; no skipping levels
9. **No report-ism**: points are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with customer-loyalty**: rewards + loyalty co-build
13. **Link with customer-retention**: rewards + retention co-build
14. **Link with customer-program**: rewards + program co-build
15. **Link with customer-lifetime**: rewards + lifetime co-build
16. **Link with customer-engagement**: rewards + engagement co-build
17. **Toolchain**: Klaviyo / Talon.One / SessionM / Smile.io / LoyaltyLion
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must customer rewards strategy; worst consequence of not doing
21. **Inversion**: rely on defaults to solve how much; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (growth / trust / speed / risk)
23. **Occam's razor**: simpler rewards is better; cut redundant layers
