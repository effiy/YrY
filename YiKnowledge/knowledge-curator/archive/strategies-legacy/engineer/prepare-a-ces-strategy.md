## Action recommendations

1. **Five dimensions**: touchpoints + survey + segment + closed loop + measurement; no missing dimension
2. **Business-value driven**: prioritize by retention + repeat purchase + conversion + win-back + support cost; not sloganeering
3. **Touchpoints**: support tickets + billing + configuration + refunds + upgrade; do not omit
4. **Survey**: 1-5 / 1-7 scale + timing + channel + copy + anonymity; do not omit
5. **Segment**: new + existing + high-value + at-risk + churned; do not omit
6. **Closed loop**: high effort → trigger + owner + deadline + retrospective; do not omit
7. **Measurement**: CES + CES trend + ticket reopen + first-contact resolution + churn correlation; do not omit
8. **Not one-shot**: progress gradually from touchpoints → survey → segment → closed loop → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with nps**: CES + NPS co-built
13. **Link with csat**: CES + CSAT co-built
14. **Link with customer-experience**: CES + CX co-built
15. **Link with customer-journey**: CES + journey co-built
16. **Link with customer-support**: CES + support co-built
17. **Toolchain**: Qualtrics / Typeform / SurveyMonkey / Delighted / Hotjar / Zendesk / Intercom / Front
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why a CES strategy is necessary; the worst consequence of not doing it
21. **Inversion thinking**: how much can be solved with CSAT alone; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / retention / business)
23. **Occam**: the simpler CES is, the better; cut redundant steps
