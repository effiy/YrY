## Action recommendations

1. **Five dimensions**: event + time + trigger + intervention + measurement; no missing dimension
2. **business-value driven**: prioritize by activation rate + retention + LTV + conversion; not sloganeering
3. **Event**: activation-event + aha-moment + core + derived + threshold; do not omit
4. **Time**: TTFV + TTA + D1 / D7 / D30 + time window + decay; do not omit
5. **Trigger**: behavior + frequency + threshold + time + signal; do not omit
6. **Intervene**: email + push + in-app + education + offer + tip; do not omit
7. **Measure**: activation rate + TTA + retention + conversion + funnel; do not omit
8. **not one-shot**: progress gradually from event -> time -> trigger -> intervention -> measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **Link with onboarding**: activation + onboarding co-built
13. **Link with retention**: activation + retention co-built
14. **Link with product-analytics**: activation + measurement co-built
15. **Link with north-star**: activation + north star co-built
16. **Link with PLG**: activation + growth co-built
17. **Toolchain**: Activation-Framework / Amplitude / Mixpanel / Heap / PostHog / Appcues / Pendo / Userflow / Whatfix / Customer.io
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must activation strategy; worst consequence of not doing it
21. **inversion thinking**: how much can be solved by natural first login; if solvable, do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (cost / risk / retention / business)
23. **Occam**: activation the simpler the better; cut redundant steps
