## Scenario description

When preparing intern program / new grad program / campus recruiting / summer internship / intern onboarding / day-one orientation / mentor pairing / intern project design / mid-term evaluation / return offer decision / conversion onboarding / quarterly intern retrospective, TL + mentor + sponsor + HR need to look up Process + Thinking + Case study. This entry aggregates intern-program related Process + Thinking + Case study within a 2-hop path, avoiding "scattered recruiting / dragged onboarding / missing mentor / empty project / shallow evaluation / gut-call conversion / missing retrospective / no quarterly improvement".

## Action recommendations

1. **First principles**: first ask "what does the intern program solve / what happens if not done / ROI / business impact"; don't recruit for the sake of recruiting; see [first-principles-summary.md](../../knowledge-curator/templates/thinking/first-principles.md). 
2. **Inversion**: first imagine "how the internship could go wrong (dragged onboarding / missing mentor / empty project / shallow evaluation / misjudged conversion / trust collapse)" then set guardrails; see [inversion-summary.md](../../knowledge-curator/templates/thinking/inversion.md). 
3. **Second-order effects**: recruit one batch -> team culture changes -> mentors expect raises -> another batch; follow [second-order-thinking-summary.md](../../knowledge-curator/templates/thinking/second-order-thinking.md). 
4. **Occam**: the simplest program that meets requirements wins; don't pile up Process; see [ockhams-razor-summary.md](../../knowledge-curator/templates/thinking/ockhams-razor.md). 
5. **Recruitment**: must run clear JD + must interview rubric + must double-blind + must no bias + must early offer. 
6. **onboarding**: must run [onboarding-process.md](../../new-hire/onboarding) + must day-one / week-one / month-one checklist + must assessment. 
7. **mentor**: must run [i-want-to-mentor-and-grow-engineers.md](../processes/mentor-and-grow-engineers.md) + must pair mentor + buddy + must weekly 1:1. 
8. **project**: must run shippable independent project + must have impact + must stretch + must review. 
9. **1:1**: must run [one-on-one-template.md](../../knowledge-curator/templates/one-on-one.md); mentor + intern weekly 1:1 + monthly sponsor 1:1. 
10. **Evaluation**: must run mid-term + end-of-term evaluation + must feedback + must leave a trail; follow [eval-driven](../../engineer/engineering/evaluation-driven-development.md). 
11. **Conversion**: must run return offer rubric + must multi-person assessment + must sponsor approval + must 30-day feedback. 
12. **OKR**: must run [okr-design-summary.md](../../product-manager/frameworks/okr-design.md) + must quarterly alignment. 
13. **Cross-timezone**: must run [cross-timezone-collaboration-summary.md](../../engineer/processes/collaboration/cross-timezone-collaboration.md); remote interns need double documentation. 
14. **Communication**: must run [communication-cadence.md](../../knowledge-curator/people/stakeholders/communication-cadence.md) internal/external communication + must all members introduced. 
15. **RACI**: must run [raci-matrix-summary.md](../../engineer/processes/collaboration/raci-matrix.md); TL / mentor / sponsor / HR owner. 
16. **Retrospective**: after each intern batch must run [retrospective-template.md](../../knowledge-curator/templates/retrospective.md) retrospective + archive to [bugs/](../../engineer/lessons/failures/bugs). 
17. **Quarterly audit**: follow [governance.md](../../knowledge-curator/governance/governance.md) + [review-log.md](../../knowledge-curator/governance/review-log.md) to scan whether mentor matrix is still accurate + project still reasonable. 
18. **ADR**: intern decisions must land in ADR; see [adr-template.md](../../knowledge-curator/templates/adr.md). 
19. **Flywheel**: internship done well -> talent pipeline -> team rises -> business rises; see [flywheel-effect-summary.md](../../knowledge-curator/templates/thinking/flywheel-effect.md).
