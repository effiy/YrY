## Action recommendations

1. **Five dimensions**: recruit + integrate + co-sell + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by co-sell revenue + registration + co-sell + retention + experience; not sloganeering
3. **Recruit**: profile / standard / onboard / review / pilot; do not omit
4. **Integrate**: API / SDK / marketplace / embed / certify; do not omit
5. **Co-sell**: registration / roadshow / joint visit / co-build / performance; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: co-sell revenue + registration + co-sell + retention + experience; do not omit
8. **not one-shot**: progressive from recruit -> integrate -> co-sell -> governance -> measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with partner-program**: ISV + Partner Program co-built
13. **link with partner**: ISV + Partner co-built
14. **link with ecosystem**: ISV + Ecosystem co-built
15. **link with reseller**: ISV + Reseller co-built
16. **link with co-marketing**: ISV + Co-Marketing co-built
17. **Toolchain**: AWS / Azure / GCP marketplaces / Salesforce AppExchange / Crossbeam / Tackle
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must ISV; worst consequence of not doing it
21. **inversion thinking**: how much can direct sales solve; if solvable, do not introduce a heavy strategy
22. **second-order thinking**: second-order consequences after the strategy (cost / channel conflict / revenue / retention) 
23. **Occam**: ISV the simpler the better; cut redundant tiers
