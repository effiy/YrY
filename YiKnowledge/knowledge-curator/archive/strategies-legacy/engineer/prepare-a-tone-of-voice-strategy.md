## Action recommendations

1. **Five dimensions**: personality + tone + rules + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Personality**: 4-7 adjectives; not vague
4. **Tone**: scenario / emotion / relation; no leakage
5. **Rules**: vocabulary / sentence patterns / taboos; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: gradual from personality → tone → rules → governance → measurement; no skipping levels
9. **No report-ism**: style is only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
