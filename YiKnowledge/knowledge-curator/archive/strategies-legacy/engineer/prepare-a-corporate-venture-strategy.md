## Action recommendations

1. **Five dimensions**: Strategy + portfolio + operations + governance + measurement; no missing dimension
2. **Business-value driven**: Set priority by strategy + trust + speed + risk + cost; no empty slogans
3. **Strategy Strategy**: Market / product / tech / talent / ecosystem; none missing
4. **Portfolio Portfolio**: Stage / industry / geography / theme / exit; none missing
5. **Operations Operations**: Sourcing / assess / invest / enable / exit; none missing
6. **Governance**: Owner / cadence / review / docs / drift; none missing
7. **Measure**: Strategy + trust + speed + risk + cost; none missing
8. **Not one-shot**: From strategy -> portfolio -> operations -> governance -> measurement progressive; no skipping levels
9. **Not report-only**: Reports are only the starting point; not the endpoint
10. **No empty slogans**: Every principle must have landed evidence; no ambiguity
11. **Versioned**: Strategy has versions; evolution is traceable
12. **Linked with m-and-a**: CVC + M&A co-build
13. **Linked with strategic-alliance**: CVC + Alliance co-build
14. **Linked with investor-relations**: CVC + IR co-build
15. **Linked with corporate-governance**: CVC + Governance co-build
16. **Linked with risk**: CVC + risk co-build
17. **Toolchain**: PitchBook / Crunchbase / Affinity / DealRoom / Visible.vc
18. **Publicly accessible**: Strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; not one-shot
20. **First principles**: Why must CVC; worst consequence of not doing it
21. **Inversion**: How much can in-house R&D solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: Second-order consequences after the strategy (strategy / trust / speed / risk) 
23. **Occam**: CVC the simpler the better; cut redundant LP layers
