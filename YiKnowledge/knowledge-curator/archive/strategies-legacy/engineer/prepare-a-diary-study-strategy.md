## Action recommendations

1. **Five dimensions**: recruit + task + collection + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Recruit**: persona / filter / quota / incentive; no leakage
4. **Task**: prompt / frequency / channel / duration; no leakage
5. **Collection**: log / photos / location / emotion; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measure**: coverage + adoption + cost + risk + satisfaction; no leakage
8. **Not one-shot**: from recruit → task → collection → governance → measurement gradual; no skipping levels
9. **No report-ism**: diaries are only the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with ethnographic-research**: diary + ethnographic co-build
13. **Link with customer-interview**: diary + interview co-build
14. **Link with contextual-inquiry**: diary + context co-build
15. **Link with user-research**: diary + user co-build
16. **Link with customer-research**: diary + customer co-build
17. **Toolchain**: Dscout / Experience Fellow / Metricwire / Indigov / Paco
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why must a diary research strategy; worst consequence of not doing
21. **Inversion**: rely on defaults to solve how much; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (growth / trust / speed / risk)
23. **Occam's razor**: diary research simpler is better; cut redundant layers
