## Action recommendations

1. **Five dimensions**: values + visual + audio + application + measurement; no missing dimension
2. **Business-value driven**: prioritize by brand equity + retention + NPS + conversion + revenue contribution; not sloganeering
3. **Values**: mission + vision + values + principles + boundaries; do not omit
4. **Visual**: logo + color + font + icon + photography + grid; do not omit
5. **Audio**: voice + tone + naming + slogan + sound; do not omit
6. **Application**: web / mobile / print / video / collateral + retirement; do not omit
7. **Measure**: brand equity + retention + NPS + conversion + revenue; do not omit
8. **Not one-shot**: progressive from values -> visual -> audio -> application -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with brand-voice**: identity + voice co-built
13. **Link with brand-strategy**: identity + brand co-built
14. **Link with design-system**: identity + design system co-built
15. **Link with positioning**: identity + positioning co-built
16. **Link with content**: identity + content co-built
17. **Toolchain**: Figma / Sketch / Adobe CC / Canva / Frontify / Brandfolder / Bynder / Widen / Asset Bank
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must brand identity strategy; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by gut-call design; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (cost / risk / perception / business) 
23. **Occam**: brand identity the simpler the better; cut redundant steps
