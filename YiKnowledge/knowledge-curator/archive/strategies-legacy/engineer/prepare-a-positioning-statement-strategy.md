## Action recommendations

1. **Five dimensions**: audience + category + difference + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by difference + trust + conversion + speed + cost; no empty slogans
3. **Audience (For)**: buyer / user / champion / economic / decision; no leakage
4. **Category**: existing / new / re-segment / super / sub; no leakage
5. **Differentiator**: function / experience / integration / commercial / trust; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: difference + trust + conversion + speed + cost; no leakage
8. **Not one-shot**: progressive from audience → category → difference → governance → measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must have implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with messaging-framework**: Positioning + Framework co-built
13. **Link with value-proposition**: Positioning + ValueProp co-built
14. **Link with product-positioning**: Positioning + Product co-built
15. **Link with competitive-positioning**: Positioning + Competitive co-built
16. **Link with brand**: Positioning + Brand co-built
17. **Toolchain**: Notion / Confluence / Miro / Gong / Highspot
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolution updates; not one-shot
20. **First principles**: why must Positioning; worst consequence of not doing it
21. **Inversion**: how much can be solved by product function alone; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (difference / trust / conversion / cost)
23. **Occam's razor**: Positioning simpler is better; cut redundant adjectives
