## Action recommendations

1. **five dimensions**: listen + diagnose + advise + cadence + measurement; no missing dimension
2. **business-value driven**: prioritize by win-rate + ACV + cycle-time + renewal + NRR; not sloganeering
3. **listen Listen**: pain points / business / role / decision / risk; do not omit
4. **diagnose Diagnose**: current state / root cause / impact / value / risk; do not omit
5. **advise Advise**: solution / value / path / resource / measurement; do not omit
6. **cadence cadence**: listen / diagnose / advise / verify / close; do not omit
7. **measurement Measure**: win-rate + ACV + cycle-time + renewal + NRR; do not omit
8. **not one-shot**: progressive from listen -> diagnose -> advise -> cadence -> measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **links with solution-selling**: consultative + solution co-build
13. **links with challenger-sale**: consultative + challenger co-build
14. **links with spin-selling**: consultative + SPIN co-build
15. **links with discovery-call**: consultative + discovery call co-build
16. **links with value-selling**: consultative + value selling co-build
17. **Toolchain**: Gong / Clari / Salesforce / Outreach / Salesloft / 6sense
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must consultative selling; worst consequence of not doing it
21. **inversion thinking**: how much can a product demo solve; if solvable, don't introduce a heavy strategy
22. **second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / retention)
23. **Occam**: consultative selling the simpler the better; cut redundant steps
