## Action recommendations

1. **Five dimensions**: scope + resource + success + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by pilot-to-close + win-rate + cycle-time + revenue + renewal; no empty slogans
3. **Scope**: use case / department / region / product / limits; no leakage
4. **Resource**: AE / SE / CS / data / integration; no leakage
5. **Success**: measurement / threshold / decision / exit / measurement; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: pilot-to-close + win-rate + cycle-time + revenue + renewal; no leakage
8. **Not one-shot**: progressive from scope → resource → success → Governance → Measurement; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Links with poc**: pilot + POC co-build
13. **Links with pov**: pilot + POV co-build
14. **Links with trial**: pilot + trial co-build
15. **Links with mutual-action-plan**: pilot + MAP co-build
16. **Links with customer-onboarding**: pilot + customer onboarding co-build
17. **Toolchain**: Salesforce / Clari / Jira / Confluence / Slack / Pendo
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why must pilot; worst consequence of not doing
21. **Inversion**: rely on POC to solve how much; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (cost / risk / revenue / retention)
23. **Occam's razor**: pilot simpler is better; cut redundant resources
