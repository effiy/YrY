## Action recommendations

1. **Five dimensions**: stance + relationship + agenda + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by impact + trust + compliance + risk + speed; no empty slogans
3. **Stance Position**: policy / regulations / industry / region / alliance; none missing
4. **Relationship Relationships**: legislative / executive / regulatory / think tank / association; none missing
5. **Agenda**: monitoring / analysis / stance / intervention / closed loop; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: impact + trust + compliance + risk + speed; none missing
8. **Not one-shot**: from stance → relationship → agenda → Governance → Measurement progressive; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Links with regulatory-affairs**: GR + Regulatory co-build
13. **Links with compliance**: GR + Compliance co-build
14. **Links with public-relations**: GR + PR co-build
15. **Links with corporate-governance**: GR + Governance co-build
16. **Links with risk**: GR + risk co-build
17. **Toolchain**: Bloomberg Government / FiscalNote / Quorum / Politico Pro / CQ
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why must GR; worst consequence of not doing it
21. **Inversion**: how much can passive response solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (impact / trust / compliance / risk) 
23. **Occam**: GR the simpler the better; cut redundant agenda items
