## Action recommendations

1. **Five dimensions**: task + scenario + Measurement + moderation + analysis; no missing dimension
2. **Business-value driven**: prioritize by business impact + user value + risk + opportunity; no empty slogans
3. **Task**: core task + success criteria + duration + path + distractors; none missing
4. **Scenario**: real scenario + role + target + context + hypothesis; none missing
5. **Measurement**: completion rate + duration + error rate + satisfaction + SEQ + SUS; none missing
6. **Moderator**: script + neutral stance + follow-up + recording + no leading; none missing
7. **Analysis**: problem + severity + frequency + suggestion + prioritization; none missing
8. **Not one-shot**: progressive from task → scenario → Measurement → moderation → analysis; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Links with user-research**: usability test + UXR co-build
13. **Links with journey-mapping**: usability test + journey graph co-build
14. **Links with product-discovery**: usability test + discovery co-build
15. **Links with product-analytics**: usability test + measurement co-build
16. **Links with heart-aarrr**: usability test + HEART+AARRR co-build
17. **Links with mobile-ux**: usability test + mobile co-build
18. **Toolchain**: Usability-Testing Framework / UserTesting / Maze / Lookback / Hotjar / FullStory / Optimal Workshop / SUS / SEQ
19. **Publicly accessible**: strategy accessible to everyone; not hidden
20. **Regular review**: evolve and update; not one-shot
21. **First principles**: why must usability testing; worst consequence of not doing it
22. **Inversion**: how much can product intuition solve; if solvable, don't introduce a heavy strategy
23. **Second-order thinking**: second-order consequences after the strategy (cost / risk / speed / business)
24. **Occam**: usability testing the simpler the better; cut redundant steps
