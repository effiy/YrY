## Action recommendations

1. **Five dimensions**: user + task + journey + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **User**: research / role / scenario / empathy / closed loop; do not omit
4. **Task**: goal / steps / obstacles / closed loop / traces; do not omit
5. **Journey**: touchpoints / state / emotion / closed loop / traces; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: efficiency + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from user → task → journey → governance → measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with customer-experience**: UX + CX co-build
13. **Link with design-system**: UX + DesignSystem co-build
14. **Link with accessibility**: UX + Accessibility co-build
15. **Link with service-design**: UX + ServiceDesign co-build
16. **Link with product-strategy**: UX + ProductStrategy co-build
17. **Toolchain**: Figma / Sketch / Adobe XD / Framer / InVision
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why UX is a must; worst consequence of not doing
21. **Inversion thinking**: how much can UI solve; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: the simpler UX is the better; cut redundant stages
