## Action recommendations

1. **Five dimensions**: planning + deployment + enablement + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by adoption + trust + speed + risk + cost; not sloganeering
3. **Plan**: site-survey / resources / cadence / risk / closed-loop; do not omit
4. **Deploy**: hardware / software / network / integration / acceptance; do not omit
5. **Enable**: training / documentation / tools / launch / handover; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: adoption + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from planning → deployment → enablement → governance → measurement; no skipping
9. **Not report-only**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with technical-support**: FE + TS co-built
13. **Link with professional-services**: FE + PS co-built
14. **Link with customer-success**: FE + CS co-built
15. **Link with customer-education**: FE + Education co-built
16. **Link with sales-engineering**: FE + SalesEng co-built
17. **Toolchain**: Salesforce Field Service / ServiceNow FSM / SAP Field Service / ClickSoftware / Praxedo
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why FE is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can be solved by TS alone; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (adoption / trust / speed / risk)
23. **Occam**: the simpler FE is, the better; cut redundant layers
