## Action recommendations

1. **Five dimensions**: audience + value + story + channel + measurement; no missing dimension
2. **Business-value driven**: prioritize by conversion + speed + revenue + retention + experience; not sloganeering
3. **Audience Audience**: executives / technical / business / user / partners; do not omit
4. **Value Value**: pain points / solution / differentiation / evidence / ROI; do not omit
5. **Story Story**: core / framework / personalization / cadence / reuse; do not omit
6. **Channel Channel**: website / sales / marketing / PR / channel; do not omit
7. **Governance Governance**: owner / cadence / review / documentation / drift; do not omit
8. **Measurement Measure**: conversion + speed + revenue + retention + experience; do not omit
9. **Not one-shot**: progressive from audience → value → story → channel → measurement; no skipping
10. **Not report-ized**: reports are only the start; not the end
11. **Not sloganeering**: every principle must have landing evidence; not vague
12. **Versioned**: strategy has versions; evolution is traceable
13. **Link with gtm**: Messaging + GTM co-built
14. **Link with messaging-house**: Messaging + Messaging House co-built
15. **Link with positioning**: Messaging + Positioning co-built
16. **Link with value-proposition**: Messaging + Value Proposition co-built
17. **Link with product-launch**: Messaging + Product Launch co-built
18. **Tooling**: Highspot / Seismic / Guru / Notion / Figma
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why GTM Messaging is necessary; worst consequence of not doing it
22. **Inversion thinking**: how much can be solved by sales eloquence; if solvable, do not introduce a heavy strategy
23. **Occam**: Messaging the simpler the better; cut redundant pitch lines
