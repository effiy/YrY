## Action recommendations

1. **Five dimensions**: audience + content + compliance + cadence + measurement; no missing dimension
2. **Business-value driven**: prioritize by sending → conversion + revenue + opt-in + retention + CAC; no empty slogans
3. **Audience**: opt-in / segmentation / stage / channel / time window; no leakage
4. **Content**: copy / short link / template / personalization / A/B; no leakage
5. **Compliance**: TCPA / GDPR / opt-out / frequency / time segment; no leakage
6. **Cadence**: daily / weekly / monthly / quarterly / milestone; no leakage
7. **Measure**: sending → conversion + revenue + opt-in + retention + CAC; no leakage
8. **Not one-shot**: from audience → content → compliance → cadence → measurement gradual; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with email-marketing**: SMS + email co-build
13. **Link with push-notification**: SMS + push co-build
14. **Link with lifecycle-marketing**: SMS + lifecycle co-build
15. **Link with customer-engagement**: SMS + customer engagement co-build
16. **Link with demand-generation**: SMS + funnel co-build
17. **Toolchain**: Twilio / Bandwidth / Sinch / Attentive / Postscript / Klaviyo-SMS / Braze / Iterable
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why SMS is necessary; worst consequence of not doing it
21. **Inversion**: how much can email solve; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (cost / risk / revenue / compliance)
23. **Occam's razor**: SMS simpler is better; cut redundant steps
