## Action recommendations

1. **Five dimensions**: opportunity + match + adapt + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by talent + trust + speed + risk + cost; not sloganeering
3. **Opportunity**: position / project / rotation / gig / task; do not omit
4. **Match**: willingness / ability / cadence / assessment / consent; do not omit
5. **Adapt**: onboarding / feedback / adjust / closed loop / retrospective; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: talent + trust + speed + risk + cost; do not omit
8. **not one-shot**: progressive from opportunity → match → adapt → governance → measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with career-development**: MB + Career co-build
13. **link with workforce-planning**: MB + Workforce co-build
14. **link with talent-review**: MB + Talent co-build
15. **link with skills-matrix**: MB + Skills co-build
16. **link with chro**: MB + CHRO co-build
17. **Toolchain**: Gloat / Workday Talent Marketplace / Fuel50 / Eightfold / Degreed
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must MB; worst consequence of not doing
21. **inversion thinking**: rely on hiring how much can be solved; if solvable, do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (talent / trust / speed / risk) 
23. **Occam**: MB the simpler the better; cut redundant process
