## Action recommendations

1. **Five dimensions**: mind + behavior + visual + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Mind**: mission / vision / values / closed loop; do not omit
4. **Behavior**: style / code / closed loop; do not omit
5. **Visual**: logo / font / color / closed loop; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measurement**: efficiency + trust + speed + risk + cost; do not omit
8. **Not one-shot**: progressive from mind → behavior → visual → governance → measurement; no skipping
9. **Not report-only**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Linked with corporate-branding**: CorporateIdentity + CorporateBranding co-build
13. **Linked with corporate-communications**: CorporateIdentity + CorporateCommunications co-build
14. **Linked with brand-positioning**: CorporateIdentity + BrandPositioning co-build
15. **Linked with corporate-culture**: CorporateIdentity + CorporateCulture co-build
16. **Linked with employer-branding**: CorporateIdentity + EmployerBranding co-build
17. **Toolchain**: Interbrand / Siegel+Gale / Pentagram / Chermayeff / Landor
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why CorporateIdentity is necessary; worst consequence of not doing it
21. **Inversion thinking**: how much can ad-hoc visuals solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (efficiency / trust / speed / risk)
23. **Occam**: the simpler CorporateIdentity is, the better; cut redundant layers
