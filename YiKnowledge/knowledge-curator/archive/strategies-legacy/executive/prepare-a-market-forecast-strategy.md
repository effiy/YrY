## Action recommendations

1. **Five dimensions**: method + assumptions + outputs + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Method**: time-series / causal / judgmental / composite; none missing
4. **Assumptions**: macro / industry / self / competitor; none missing
5. **Output**: baseline / optimistic / pessimistic / range; none missing
6. **Governance**: owner / cadence / review / documentation / drift; none missing
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progress from method → assumptions → outputs → governance → measurement; no skipping levels
9. **Not report-only**: gut call is only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with market-analysis**: forecast + analysis co-build
13. **Link with market-intelligence**: forecast + intelligence co-build
14. **Link with futures-research**: forecast + future co-build
15. **Link with trend-research**: forecast + trend co-build
16. **Link with market-research**: forecast + research co-build
17. **Toolchain**: Forecast Pro / R forecast / Tableau / Anaplan / Gartner Forecast
18. **Publicly accessible**: strategy is accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why a market-forecast strategy is necessary; the worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: the simpler the market forecast, the better; cut redundant layers
