## Action recommendations

1. **Five dimensions**: size + structure + dynamics + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Size**: TAM / SAM / SOM / growth rate; none missing
4. **Structure**: segments / players / share / concentration; none missing
5. **Dynamics**: drivers / resistors / substitutes / entry; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measure**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive: size → structure → dynamics → governance → measurement; no skipping levels
9. **Not report-only**: charts are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **links with market-intelligence**: analysis + intelligence co-build
13. **links with industry-analysis**: market + industry co-build
14. **links with market-forecast**: analysis + forecast co-build
15. **links with market-segmentation-research**: analysis + segmentation co-build
16. **links with market-research**: analysis + research co-build
17. **Toolchain**: Statista / IBISWorld / Euromonitor / Gartner / IDC
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: Evolve and update; Not one-shot
20. **First principles**: why a market-analysis strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: the simpler market analysis is, the better; cut redundant layers
