## Action recommendations

1. **Five dimensions**: signal + trigger + conversion + Governance + Measurement; no missing dimension
2. **Business-value driven**: prioritize by speed + conversion + cost + trust + Risk; no empty slogans
3. **Signal**: registration / activation / adoption / upgrade / invite; no leakage
4. **Trigger**: threshold / queue / upgrade / scoring / Risk; no leakage
5. **Conversion**: MQL / SQL / opportunity / close / expansion; no leakage
6. **Governance**: owner / cadence / review / documentation / drift; no leakage
7. **Measurement**: speed + conversion + cost + trust + Risk; no leakage
8. **Not one-shot**: from signal → trigger → conversion → Governance → Measurement gradual; no skipping levels
9. **No report-ism**: report is just the start; not the end
10. **No empty slogans**: every principle must mark implementation evidence; no vagueness
11. **Versioned**: strategy is versioned; evolution is traceable
12. **Link with plg**: PLS + PLG co-build
13. **Link with self-serve**: PLS + Self-Serve co-build
14. **Link with sales-process**: PLS + Sales co-build
15. **Link with lead-scoring**: PLS + Scoring co-build
16. **Link with pricing**: PLS + Pricing co-build
17. **Toolchain**: Pendo / Madkudu / Clearbit / 6sense / Apollo
18. **Publicly discoverable**: strategy is publicly discoverable; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why PLS is necessary; worst consequence of not doing it
21. **Inversion**: how much can be solved by outbound calls alone; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (speed / conversion / cost / trust)
23. **Occam's razor**: simpler PLS is better; cut redundant signals
