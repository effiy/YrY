## Action recommendations

1. **Five dimensions**: problem + solution + validation + priority + conversion; no missing dimension
2. **Business-value driven**: prioritize by business impact + user value + risk + opportunity; no empty slogans
3. **problem**: user pain + business pain + opportunity + hypothesis + uncertainty; none missing
4. **solvesolution**: multiple + parallel + divergent + convergent + hypothesis-driven; none missing
5. **validation**: user interview + prototype + usability test + A/B + smoke test + MVP; none missing
6. **priority**: RICE / ICE / Kano + business value + risk + confidence; none missing
7. **conversion**: discovery → delivery + landed on roadmap + Measurement + Retrospective; none missing
8. **Not one-shot**: progressive: problem → solution → validation → priority → conversion; no skipping levels
9. **Not report-only**: reports are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **links with product-strategy**: discovery + strategy co-build
13. **links with jobs-to-be-done**: discover + JTBD co-build
14. **links with user-research**: discover + users co-build
15. **links with market-research**: discover + market co-build
16. **links with competitive-analysis**: discover + competitors co-build
17. **links with product-roadmap**: discover + route graph co-build
18. **Toolchain**: opportunity-solution-tree / dual-track-agile / continuous-discovery / Miro / Figma / UserTesting / Maze / Optimal Workshop / Amplitude
19. **Publicly accessible**: strategy accessible to everyone; not hidden
20. **Regular review**: Evolve and update; Not one-shot
21. **First principles**: why product discovery is necessary; worst consequence of not doing it
22. **Inversion**: how much can product intuition solve; if solvable, don't introduce a heavy strategy
23. **Second-order thinking**: second-order consequences after the strategy (cost / risk / speed / business)
24. **Occam**: the simpler discovery is, the better; cut redundant steps
