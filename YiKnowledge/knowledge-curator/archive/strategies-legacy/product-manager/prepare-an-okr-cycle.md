## Action recommendations

1. **First principles**: First ask "what question should OKR answer / what happens if not done / ROI / user impact"; do not do OKR for OKR's sake; see [first-principles-summary.md](../../knowledge-curator/templates/thinking/first-principles.md).
2. **Inversion**: First imagine "how OKR will fail (vague goals / scattered alignment / lagging tracking / missing evaluation / chaotic quarterly rolling)" then set guardrails; see [inversion-summary.md](../../knowledge-curator/templates/thinking/inversion.md).
3. **Second-order effects**: OKR lands → resources in place → expectations raised → risk of missing; see [second-order-thinking-summary.md](../../knowledge-curator/templates/thinking/second-order-thinking.md).
4. **Occam**: The simplest OKR that satisfies strategy wins; do not pile up KRs; see [ockhams-razor-summary.md](../../knowledge-curator/templates/thinking/ockhams-razor.md).
5. **Strategy**: must run [product-strategy-summary.md](../../product-manager/frameworks/prepare-a-product-strategy.md) + [second-curve-summary.md](../../executive/strategy/second-curve.md); OKR must serve strategy.
6. **Deploy**: must run top-down + bottom-up + must cross-team align + must dual-sign.
7. **Alignment**: must run [stakeholder-map.md](../../knowledge-curator/people/stakeholders/stakeholder-map.md) + must align across levels / teams / projects.
8. **JTBD**: must run [jobs-to-be-done-summary.md](../../product-manager/frameworks/jobs-to-be-done.md) to understand real user needs.
9. **North star**: must run [north-star-metric-summary.md](../../product-manager/discovery/metrics/north-star-metric.md) + must reverse-derive KRs.
10. **KR**: must run 3-5 KRs + must be quantifiable + must have baseline + must have target + must stretch.
11. **Tracking**: must run weekly / monthly tracking + must have confidence + must have trend + must have early warning; see [iteration-pm-handbook-process.md](../../engineer/process/iteration-pm-handbook.md).
12. **Evaluation**: must run quarterly evaluation + must score + must retrospective + must stretch-score.
13. **RACI**: must run [raci-matrix-summary.md](../../engineer/processes/collaboration/raci-matrix.md); sponsor / TL / PM / team owner.
14. **Cross-timezone**: must run [cross-timezone-collaboration-summary.md](../../engineer/processes/collaboration/cross-timezone-collaboration.md); tiered alignment across time zones.
15. **Broadcast**: must run [communication-cadence.md](../../knowledge-curator/people/stakeholders/communication-cadence.md) to broadcast internally and externally + must hold all-hands.
16. **Retrospective**: after quarter must run [retrospective-template.md](../../knowledge-curator/templates/retrospective.md) retrospective + archive to [review-log.md](../../knowledge-curator/governance/review-log.md).
17. **Rolling**: must run semi-annual strategy rolling + must run quarterly OKR rolling + must retire / add.
18. **Quarterly audit**: run [governance.md](../../knowledge-curator/governance/governance.md) + [review-log.md](../../knowledge-curator/governance/review-log.md) to scan whether OKR still aligns with strategy + whether still accurate.
19. **ADR**: OKR decisions must be recorded as ADR; see [adr-template.md](../../knowledge-curator/templates/adr.md).
20. **Flywheel**: OKR smooth → alignment up → business up → trust up; see [flywheel-effect-summary.md](../../knowledge-curator/templates/thinking/flywheel-effect.md).
