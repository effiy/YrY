## Action recommendations

1. **Five dimensions**: data + channels + workflow + governance + measurement; no missing dimension
2. **Business-value driven**: set priority by speed + consistency + conversion + trust + cost; not sloganeering
3. **Data**: product / SKU / attribute / relation / price; do not omit
4. **Channels**: web / mobile / marketplace / print / syndication; do not omit
5. **Workflow**: import / enrich / review / publish / archive; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **Measure**: speed + consistency + conversion + trust + cost; do not omit
8. **Not one-shot**: from data -> channels -> workflow -> governance -> measurement gradual; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with master-data**: PIM + MDM co-build
13. **Link with dam**: PIM + DAM co-build
14. **Link with content-operations**: PIM + ContentOps co-build
15. **Link with ecommerce**: PIM + eCommerce co-build
16. **Link with data-governance**: PIM + Governance co-build
17. **Toolchain**: Akeneo / Salsify / Informatica PIM / Riversand / Inriver
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **First principles**: why must PIM; worst consequence of not doing
21. **Inversion thinking**: how much can be solved by relying on ERP; if solvable, do not introduce a heavy strategy
22. **Second-order thinking**: second-order consequence after strategy (speed / consistency / conversion / cost) 
23. **Occam**: PIM, the simpler the better; cut redundant fields
