## Action recommendations

1. **Five dimensions**: collection + analysis + application + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **collection Collect**: instrumentation / schema / validation; do not omit
4. **analysis Analyze**: funnel / path / retention; do not omit
5. **application Apply**: insight / experiment / decision; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: efficiency + trust + speed + risk + cost; do not omit
8. **not one-shot**: progressive from collection → analysis → application → governance → measurement; no skipping
9. **not report-ized**: reports are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with product-analytics**: ProductUsage + ProductAnalytics co-built
13. **link with product-metrics**: ProductUsage + ProductMetrics co-built
14. **link with product-health**: ProductUsage + ProductHealth co-built
15. **link with product-adoption**: ProductUsage + ProductAdoption co-built
16. **link with product-engagement**: ProductUsage + ProductEngagement co-built
17. **Toolchain**: Amplitude / Mixpanel / Pendo / Heap / PostHog
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must ProductUsage; worst consequence of not doing it
21. **inversion thinking**: how much can be solved by surveys alone; if solvable do not introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: ProductUsage the simpler the better; cut redundant layers
