## Action recommendations

1. **Five dimensions**: user + value + differentiation + time window + measurement; no missing dimension
2. **Business-value-driven**: prioritize by scenario + user impact + business loss + strategic alignment; no empty slogans
3. **User**: target user + pain point + JTBD + persona + scenario; nothing missed
4. **Value**: core value + user value + business value + differentiation; nothing missed
5. **Differentiation**: competitors + blue ocean + second curve + moat + flywheel; nothing missed
6. **Time window**: 5-year + 18-month + OKR + quarterly + sprint; nothing missed
7. **Measurement**: north star + north-star metric + health + value metrics + retrospective; nothing missed
8. **Not a one-shot exercise**: progress gradually from slogan → 5-year → 18-month → OKR → sprint; no skipping
9. **Not just reports**: reports are only the starting point; not the end
10. **No empty slogans**: every principle must mark the implementation evidence; no vagueness
11. **Versioning**: the vision has versions; evolution is traceable
12. **Link with product-strategy**: vision + strategy built together
13. **Link with technical-vision**: vision + technology built together
14. **Link with product-roadmap**: vision + roadmap built together
15. **Link with pitch**: vision + pitch built together
16. **Link with rebranding**: vision + brand built together
17. **Link with GTM**: vision + go-to-market built together
18. **Toolchain**: Notion / Coda / Productboard / Aha! / Confluence / Pitch
19. **Publicly accessible**: everyone can look up the vision; not hidden
20. **Regular review**: evolve and update; not a one-shot exercise
21. **First principles**: why a product vision is necessary; the worst outcome of not having one
22. **Inversion**: how much can a roadmap solve; if it can be solved, do not introduce a heavy strategy
23. **Second-order thinking**: second-order consequences after the strategy (cost / complexity / consistency / business)
24. **Occam**: a product vision should be as simple as possible; cut redundant steps
