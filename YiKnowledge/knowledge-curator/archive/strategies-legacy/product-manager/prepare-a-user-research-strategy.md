## Action recommendations

1. **Five dimensions**: recruiting + interview + synthesis + prioritization + landing; no missing dimension
2. **Business-value driven**: prioritize by business impact + user value + risk + opportunity; not sloganeering
3. **Recruiting**: goal + filter + quota + incentive + diversity; do not omit
4. **Interview**: script + opening + main questions + follow-up + closing; do not omit
5. **Synthesis**: affinity map + theme + pattern + reference + opportunity; do not omit
6. **Prioritize**: impact + confidence + frequency + pain point + RICE; do not omit
7. **Landing / Operationalize**: convert to roadmap + measurement + validation + retrospective + iteration; do not omit
8. **Not one-shot**: progress from recruiting → interview → synthesis → prioritize → landing; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Linked with journey-mapping**: UXR + journey map co-built
13. **Linked with jobs-to-be-done**: UXR + JTBD co-built
14. **Linked with customer-segmentation**: UXR + segmentation co-built
15. **Linked with product-discovery**: UXR + discovery co-built
16. **Linked with usability-testing**: UXR + usability testing co-built
17. **Linked with market-research**: UXR + market research co-built
18. **Toolchain**: User Research Framework / UserTesting / UserInterviews / Respondent / Maze / Optimal Workshop / Dovetail / Notion / Miro
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why user research is needed; worst consequence of not doing it
22. **Inversion thinking**: how much can be solved by intuition alone; if solvable, don't introduce a heavy strategy
23. **Second-order thinking**: second-order consequences after the strategy (cost / risk / speed / business)
24. **Occam**: user research, the simpler the better; cut redundant steps
