## Action recommendations

1. **Five dimensions**: audience + value + evidence + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by growth + trust + speed + risk + cost; no empty slogans
3. **Audience**: decision maker / influencer / user / detractor; none missing
4. **Value**: value / scenario / competitive / price; none missing
5. **Evidence**: case study / data / demo / trial; none missing
6. **Governance**: owner / cadence / review / docs / drift; none missing
7. **Measurement**: coverage + adoption + cost + risk + satisfaction; none missing
8. **Not one-shot**: progressive from audience → value → evidence → governance → measurement; no skipping levels
9. **Not report-only**: talking points are only the starting point; not the endpoint
10. **No empty slogans**: every principle must have landed evidence; no ambiguity
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with messaging**: product messaging + messaging co-build
13. **Link with product-positioning**: product messaging + product positioning co-build
14. **Link with product-marketing**: product messaging + product marketing co-build
15. **Link with product**: product messaging + product co-build
16. **Link with positioning-statement**: product messaging + positioning statement co-build
17. **Toolchain**: Pitch / Messaging Studio / Gong / Crystal / Lusha
18. **Publicly accessible**: strategy accessible to everyone; not hidden
19. **Regular review**: evolve and update; not one-shot
20. **First principles**: why a product messaging strategy is necessary; worst consequence of not doing it
21. **Inversion**: how much can defaults solve; if solvable, don't introduce a heavy strategy
22. **Second-order thinking**: second-order consequences after the strategy (growth / trust / speed / risk)
23. **Occam**: simpler product messaging is better; cut redundant layers
