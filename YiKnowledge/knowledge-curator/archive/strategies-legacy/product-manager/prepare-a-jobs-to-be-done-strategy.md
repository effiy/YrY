## Action recommendations

1. **Five dimensions**: functional + emotional + social + context + measurement; no missing dimension
2. **Business-value driven**: prioritize by business impact + user value + risk + opportunity; not sloganeering
3. **Functional jobs**: what task the user wants to complete + functional value + output; do not omit
4. **Emotional jobs**: what the user feels + emotional value + expected feeling; do not omit
5. **Social jobs**: how the user sees themselves + how others see them + social value; do not omit
6. **Context jobs**: what scenario + what time + what conditions + what constraints; do not omit
7. **Measurement**: job completion rate + satisfaction + dissatisfaction points + opportunities + retrospective; do not omit
8. **Not one-shot**: progress from functional -> emotional -> social -> context -> measurement; no skipping
9. **Not report-ized**: reports are only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with product-discovery**: JTBD + discovery co-build
13. **Link with product-strategy**: JTBD + strategy co-build
14. **Link with user-research**: JTBD + user co-build
15. **Link with product-analytics**: JTBD + measurement co-build
16. **Link with market-research**: JTBD + market co-build
17. **Link with customer-segmentation**: JTBD + segmentation co-build
18. **Toolchain**: JTBD Framework / Outcome-Driven-Innovation / Switch-Interview / Jobs-Map / Ulwick JTBD / Amplitude
19. **Publicly queryable**: strategy everyone can look up; not hidden
20. **Periodic review**: evolution updates; not one-shot
21. **First principles**: why must JTBD; worst consequence of not doing it
22. **Inversion thinking**: see how much a user story can solve; if solvable, do not introduce a heavy strategy
23. **Second-order thinking**: second-order consequences after strategy (cost / risk / speed / business)
24. **Occam**: JTBD the simpler the better; cut redundant steps
