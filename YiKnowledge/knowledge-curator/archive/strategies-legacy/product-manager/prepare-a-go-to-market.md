## Scenario

When launching a product / planning GTM / cross-functional kickoff (marketing + sales + customer service + engineering + legal), PM + business owner + GTM Lead need to look up strategy + stakeholders + industry cases + measurement + landing experience. This entry aggregates GTM-related 5 leaves + stakeholders + industry + cases into a 2-hop path, avoiding "launch by gut call / no sales enablement / no customer service readiness / missing measurement / no risk contingency".

## Action recommendations

1. **Strategy alignment**: First articulate the product's position in the strategy map (blue ocean / red ocean / second curve) + value proposition + target users; see [product-strategy-framework-summary.md](../../executive/strategy/product-strategy-framework.md) + [blue-ocean-strategy-summary.md](../../executive/strategy/blue-ocean.md).
2. **RACI**: Cross-functional RACI required (marketing / sales / customer service / engineering / legal / finance); see [raci-matrix-summary.md](../../engineer/processes/collaboration/raci-matrix.md).
3. **Cadence**: T-4 weeks strategy alignment → T-3 weeks cross-functional mobilization → T-2 weeks sales enablement + customer service training → T-1 week gray release → T-day launch → T+1 week retrospective.
4. **Sales enablement**: Sales scripts + customer profiles + competitor comparisons + objection handling + Demo video + pricing strategy + FAQ.
5. **Customer service readiness**: Knowledge base + ticket classification + escalation process + pre-answered high-frequency questions + AI customer service training.
6. **Communication plan**: Internal weekly report + external PR / official account / industry conference + customer conference + moments / email + KOL engagement.
7. **Measurement**: North star + 3 auxiliary metrics + first-week launch expectations + 7/30/90-day milestones; see [north-star-metric-summary.md](../../product-manager/discovery/metrics/north-star-metric.md).
8. **Risk contingency**: Compliance / security / performance / experience / competitor counterattack / PR risks must be registered + mitigation + owner; see [ai-product-launch-lessons-summary.md](../../engineer/lessons/failures/ai-product-launch-lessons.md).
9. **Inversion**: First imagine "how the launch could fail" then set guardrails; see [inversion-summary.md](../../knowledge-curator/templates/thinking/inversion.md).
10. **Gray release**: Internal first → gray customer → full release; see [canary-release-process.md](../../oncall-sre/release/canary-release.md).
11. **Cross-region**: For multi-region launches check [countries.md](./../../brd/README.md) + [regulations.md](./../../brd/README.md) + [cross-cultural-ux-summary.md](../../product-manager/discovery/ux/cross-cultural-ux.md).
12. **Retrospective**: T+7 retrospective, T+30 major retrospective, T+90 quarterly retrospective; see [iteration-pm-handbook-summary.md](../../engineer/process/iteration-pm-handbook.md).
