## Action recommendations

1. **Five dimensions**: assessment + path + investment + governance + measurement; no missing dimension
2. **business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **assessment Assess**: dimension / level / evidence; do not omit
4. **path Path**: capability / milestone / cadence; do not omit
5. **investment Investment**: people / tools / platform; do not omit
6. **governance Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: level improvement + ROI + coverage + risk + cost; do not omit
8. **not one-shot**: from assessment → path → investment → governance → measurement gradual; no skipping
9. **not report-ized**: scores are only the start; not the end
10. **not sloganeering**: every principle must have landing evidence; not vague
11. **versioned**: strategy has versions; evolution is traceable
12. **link with data-culture**: maturity + data culture co-build
13. **link with data-literacy**: maturity + data literacy co-build
14. **link with data-governance**: maturity + data governance co-build
15. **link with data**: maturity + data strategy co-build
16. **link with data-democratization**: maturity + data democratization co-build
17. **toolchain**: DMM / DCAM / IBM Data Maturity / Gartner Maturity / internal maturity-model
18. **publicly queryable**: strategy everyone can look up; not hidden
19. **periodic review**: evolution updates; not one-shot
20. **first principles**: why must data maturity; worst consequence of not doing
21. **inversion thinking**: how much can be solved by build-as-you-go; if solvable don't introduce heavy strategy
22. **second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk) 
23. **Occam**: data maturity the simpler the better; cut redundant layers
