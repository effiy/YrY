## Action recommendations

1. **Five dimensions**: scenario + tip + model + governance + measurement; no missing dimension
2. **Business-value driven**: prioritize by efficiency + trust + speed + risk + cost; not sloganeering
3. **Scenario**: business / use case / ROI; do not omit
4. **Tip Prompt**: template / version / evaluation; do not omit
5. **Model**: selection / fine-tuning / deploy; do not omit
6. **Governance**: owner / cadence / review / documentation / drift; do not omit
7. **measurement Measure**: quality + adoption + cost + risk + satisfaction; do not omit
8. **not one-shot**: progress gradually from scenario -> tip -> model -> governance -> measurement; no skipping
9. **not report-ized**: model count is only the start; not the end
10. **Not sloganeering**: every principle must have landing evidence; not vague
11. **Versioned**: strategy has versions; evolution is traceable
12. **Link with ai-strategy**: LLM + AI strategy co-built
13. **Link with ml-strategy**: LLM + ML strategy co-built
14. **Link with llm-platform**: strategy + LLM platform co-built
15. **Link with llm-ops**: strategy + LLM Ops co-built
16. **Link with llm-engineering**: strategy + LLM engineering co-built
17. **Toolchain**: OpenAI / Anthropic / Llama / Mistral / vLLM
18. **Publicly queryable**: strategy everyone can look up; not hidden
19. **Periodic review**: evolution updates; not one-shot
20. **first principles**: why must LLM strategy; worst consequence of not doing it
21. **inversion thinking**: how much can be solved by rules alone; if solvable, do not introduce heavy strategy
22. **Second-order thinking**: second-order consequences after strategy (efficiency / trust / speed / risk)
23. **Occam**: LLM strategy the simpler the better; cut redundant layers
