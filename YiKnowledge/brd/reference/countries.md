# Country & Region Profiles

> 目标国家/地区业务画像，供 `yry-gen-brd` skill 在生成 BRD 时匹配市场特征和法规要求。

---

## 欧洲市场

### 德国 (de)

| 维度 | 描述 |
|------|------|
| 语言 | 德语 |
| 汽车行业地位 | 欧洲最大汽车市场，OEM 总部（大众、宝马、奔驰） |
| 用户特征 | 高期望、技术敏感、合规意识强 |
| 售后市场特征 | 高度发达的授权经销商网络；独立售后连锁（ATU, Pitstop）占比约 35% |
| 数据保护 | GDPR + BDSG（联邦数据保护法）— 最严格的欧盟成员国之一 |
| 劳工法 | 劳资协同决策（Betriebsrat）、严格工时规定 |
| 关键法规差异 | 强制 TÜV 车检每 2 年；严格的环保排放标准 |

### 法国 (fr)

| 维度 | 描述 |
|------|------|
| 语言 | 法语 |
| 汽车行业地位 | 欧洲第二大汽车市场；Stellantis 和 Renault 总部 |
| 用户特征 | 品牌忠诚度高、售后服务期望高 |
| 售后市场特征 | 授权网络 + 独立维修商（约 40%）；Autodistribution 等大型配件分销商 |
| 数据保护 | GDPR + Loi Informatique et Libertés（法国数据保护法） |
| 劳工法 | 35 小时工作周；强制员工代表 |
| 关键法规差异 | 严格的反不正当竞争法；法语强制使用规定 |

### 英国 (uk)

| 维度 | 描述 |
|------|------|
| 语言 | 英语 |
| 汽车行业地位 | 右舵车市场；独立售后占比 ~45% |
| 用户特征 | 价格敏感、线上化程度高 |
| 售后市场特征 | 独立连锁（Halfords, Kwik Fit）强；MOT 年检驱动 |
| 数据保护 | UK GDPR + Data Protection Act 2018（脱欧后独立于 EU GDPR） |
| 劳工法 | 较灵活的雇佣制度（相对欧盟大陆） |
| 关键法规差异 | MOT 强制年检（3 年以上车龄）；脱欧后独立的法规体系 |

### 意大利 (it)

| 维度 | 描述 |
|------|------|
| 语言 | 意大利语 |
| 汽车行业地位 | 欧洲第三大汽车保有量市场 |
| 用户特征 | 品牌情感连接强、小型车偏好 |
| 售后市场特征 | 独立维修商占比 > 50%；配件分销碎片化 |
| 数据保护 | GDPR + Codice Privacy（意大利数据保护法典） |
| 劳工法 | 严格裁员限制；工会在大型企业中影响力强 |
| 关键法规差异 | 强制 MOT 类车检（Revisione）；发票电子化（Fattura Elettronica） |

### 西班牙 (es)

| 维度 | 描述 |
|------|------|
| 语言 | 西班牙语（部分地区加泰罗尼亚语、巴斯克语） |
| 汽车行业地位 | 欧洲第四大汽车市场；重要制造基地 |
| 用户特征 | 性价比导向、数字化接受度高 |
| 售后市场特征 | 独立维修商 > 50%；配件市场以价格竞争为主 |
| 数据保护 | GDPR + LOPDGDD（西班牙数据保护和数字权利法） |
| 关键法规差异 | ITV 强制车检（与德国 TÜV 类似）；区域自治影响法规统一性 |

### 荷兰 (nl)

| 维度 | 描述 |
|------|------|
| 语言 | 荷兰语（英语普及率 > 90%） |
| 汽车行业地位 | 欧洲重要物流枢纽；电动车普及率最高（> 30% 新车销量） |
| 用户特征 | 高度数字化、环境意识强 |
| 售后市场特征 | 授权经销商网络集中度高；电动车售后改变传统模式 |
| 数据保护 | GDPR + UAVG（荷兰 GDPR 实施法）— AP（荷兰数据保护局）执法严格 |
| 关键法规差异 | BPM 高额车辆注册税（按 CO2 排放）；MOT 类 APK 车检 |

### 波兰 (pl)

| 维度 | 描述 |
|------|------|
| 语言 | 波兰语 |
| 汽车行业地位 | 中东欧最大汽车市场；重要零部件制造和共享服务中心 |
| 用户特征 | 价格非常敏感、二手车偏好高 |
| 售后市场特征 | 独立维修商 > 60%；灰色市场配件占比高 |
| 数据保护 | GDPR + Polish Data Protection Act |
| 劳工法 | 较灵活的雇佣制度（相对西欧） |
| 关键法规差异 | 强制车检（Badanie techniczne）；电子发票 KSeF 2026 年强制 |

## 亚太市场

### 中国 (cn)

| 维度 | 描述 |
|------|------|
| 语言 | 中文 |
| 汽车行业地位 | 全球最大汽车市场（年产 > 2600 万辆） |
| 用户特征 | 移动互联网原生、数字化服务期望极高 |
| 售后市场特征 | 授权经销商 4S 店 + 独立售后连锁（途虎等）+ O2O 平台 |
| 数据保护 | 个人信息保护法 (PIPL) + 数据安全法 (DSL) — 与 GDPR 近似但有境内存储要求 |
| 劳工法 | 劳动合同法强制书面合同 |
| 关键法规差异 | 强制汽车召回条例；新能源汽车三电系统专项三包规定 |

### 日本 (jp)

| 维度 | 描述 |
|------|------|
| 语言 | 日语 |
| 汽车行业地位 | 全球第三大汽车市场；OEM 总部（丰田、本田、日产） |
| 用户特征 | 品质要求极高、售后服务忠诚度强 |
| 售后市场特征 | 授权经销商网络主导；车检制度（車検）驱动售后需求 |

| 劳工法 | 长期雇佣传统；工作方式改革法 |
| 关键法规差异 | 强制车检制度（車検 2–3 年）；右舵车市场 |

## 全球/多区域 (global)

用于需要跨多个区域部署的 BRD。

| 维度 | 描述 |
|------|------|
| 法规策略 | 按最高标准设计（通常 GDPR + 本地法），在本地法规要求更宽松的市场也保持一致 |
| 多语言 | 至少 EN + DE + ZH + FR + ES + JA — 优先覆盖最大用户群 |
| 多币种 | EUR + USD + CNY + JPY — 汇率使用欧洲央行月度汇率 |
| 多时区 | 设计需支持 UTC 基础时间 + 本地化显示 — 避免时区混淆 |
| 本地化 | 日期格式、数字格式、度量单位按市场调整 |
