# BRD-2026-006: YiVad Framework Skills

## Executive Summary

YiVad leverages two curated framework skills — Vue 3 and Vite — that provide best-practice guidance, ecosystem knowledge, and architectural patterns for building the admin dashboard. These skills are integrated into the .claude/ skills directory and are invoked during development to ensure consistency with the Vue 3 Composition API, Vite/Rsbuild build tooling, and the broader Vue ecosystem.

## Architecture Overview

### Skills (2)

| Skill | Domain |
|-------|--------|
| vite | Vite.js ecosystem navigator — starters, plugins, integrations, SSR, showcases |
| vue | Vue 3 best practices — Composition API, TypeScript, Pinia, Vue Router, Element Plus, directives, composables |
