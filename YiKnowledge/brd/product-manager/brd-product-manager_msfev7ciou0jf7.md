# PRD — retention and churn metric system

**PRD ID**: PRD-2026-PM-009 | **Project**: ALL | **Domain**: Metrics — Retention & Churn
**Priority**: p1 | **Status**: adopted | **Country**: ALL | **Owner**: PM Team
**KB Source**: product-manager/product/metrics/retention-and-churn.md

## Business Objective
Prepare a unified retention and churn metric system, cross-project aligned definition + compute methodology + data sources.

## User Segment
PM / data analysts / engineer / CTO

## Target Metric
next-day retention >= 40%; 7-day retention >= 25%; 30-day retention >= 15%; monthly churn <= 8%

## Success Criteria
1. metric definitions 100% aligned 2. data sources unified 3. quarterly review 4. churn early-warning mechanism launched

## Stakeholders
PM Team (Decision); data analysts (compute); engineer (data sources); CTO (approval)
