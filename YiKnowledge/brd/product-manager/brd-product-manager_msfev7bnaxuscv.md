# PRD — Tech review process

**PRD ID**: PRD-2026-PM-008  |  **Project**: ALL  |  **Domain**: Process — Tech Review
**Priority**: p1  |  **Status**: adopted  |  **Country**: ALL  |  **Owner**: Tech Lead Team
**KB Source**: product-manager/processes/tech-review.md

## Business Objective
Standardize the tech review process to ensure proposals go through 5-dimension review before launch (architecture / performance / security / maintainability / cost).

## User Segment
engineer / Tech Lead / architecture team / CTO

## Target Metric
Tech review coverage 100%; review pass rate >= 75%; post-launch architecture rollback <= 1

## Success Criteria
1. All new proposals 100% go through review 2. review pass rate >= 75% 3. post-launch architecture rollback <= 1 4. review records archived + ADR related

## Stakeholders
Tech Lead Team (decision); architecture team (review); CTO (approval); PM (requester)
