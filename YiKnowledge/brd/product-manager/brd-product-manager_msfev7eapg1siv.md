# PRD — AI Product UX Pattern

**PRD ID**: PRD-2026-PM-012  |  **Project**: yiai  |  **Domain**: AI Product UX
**Priority**: p2  |  **Status**: reviewed  |  **Country**: ALL  |  **Owner**: PM + designer

## Business Objective
Accumulate AI product UX patterns: streaming output + interruptible + reference display + feedback closed loop + edit back to stream. 

## User Segment
Designer / PM / engineer / AI user

## Target Metric
NPS >= 40; task completion rate >= 85%; edit-back-to-stream rate >= 50%; feedback collection rate >= 80%

## Success Criteria
1. All 5 major UX patterns implemented 2. NPS >= 40 3. Edit-back-to-stream rate >= 50% 4. Feedback collection rate >= 80%

## Stakeholders
PM + designer (decision); engineer (implementation); AI user (feedback); CTO (approval)
