# PRD — YiAi Project Management and BRD Agent Collaboration

**PRD ID**: PRD-2026-PM-002  |  **Project**: yiai  |  **Domain**: AI Product Management
**Priority**: p0  |  **Status**: adopted  |  **Country**: ALL  |  **Owner**: YiAi PM
**KB Source**: product-manager/projects/yiai/project-management.md

## Business Objective
Manage the iteration cadence of YiAi (FastAPI backend + BRD agent + Chat + RAG), ensuring the BRD agent's 5-stage launch proceeds on schedule + that the evaluation-set gate is not bypassed. 

## User Segment
BRD business stakeholders / engineer / CTO / QA

## Target Metric
BRD writing time 2h → 25min (-79%); structural completeness 90%+; user-edit-to-stream rate 60%+; P0 bugs after launch = 0; evaluation-set baseline recall regression ≤ 5%

## Success Criteria
1. BRD agent 5 stages all launched 2. writing time ≤ 25min 3. structural completeness ≥ 90% 4. user-edit-to-stream rate ≥ 60% 5. P0 bug = 0 6. evaluation-set baseline not regressed

## Stakeholders
YiAi PM (decision); YiAi main owner (execution); BRD business stakeholders (consumption); CTO (approval); QA; architecture team
