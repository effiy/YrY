# PRD — AI product metric system

**PRD ID**: PRD-2026-PM-011  |  **Project**: yiai  |  **Domain**: AI Product Metrics
**Priority**: p1  |  **Status**: adopted  |  **Country**: ALL  |  **Owner**: AI PM
**KB Source**: product-manager/product/metrics/ai-product-metrics.md

## Business Objective
Build an AI product-specific metric system: accuracy + recall + user satisfaction + cost + latency.

## User Segment
AI PM / AI engineer / BRD business stakeholder / CTO

## Target Metric
RAG recall ≥ 80%; ragas faithfulness ≥ 0.85; user satisfaction ≥ 4.0/5; per-call cost ≤ $0.05; P95 latency ≤ 5s

## Success Criteria
1. 4-dimension metric full-volume launch 2. quarterly review 3. dashboard launch 4. exception alert mechanism

## Stakeholders
AI PM (Decision); AI engineer (data); BRD business stakeholder (satisfaction); CTO (approval)
