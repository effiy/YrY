# PRD — YiVad Project Management Iteration Cadence

**PRD ID**: PRD-2026-PM-001  |  **Project**: yivad  |  **Domain**: Project Management
**Priority**: p1  |  **Status**: adopted  |  **Country**: ALL  |  **Owner**: YiVad PM
**KB Source**: product-manager/projects/yivad--project-management.md

## Business Objective
With "page-domain-driven + ProTable paradigm + cross-project contract consumption" as the main axis, each iteration cadence = one view domain landing + supporting api module + store + route registration.

## User Segment
operations / development / newcomers / handover recipients

## Target Metric
Stable iteration cadence (weekly meeting once + async daily report + end-of-iteration retrospective); newcomers run SPA on Day-1; handover trio complete (onboarding + engineering mirror + current iteration view domain list)

## Success Criteria
1. Each iteration lands 1 view domain (knowledge 28 leaf / aicr 9 store + 8 modal) 2. ProTable paradigm covers 100% of new list pages 3. Newcomer Day-1 calls through /login + one ProTable + v-auth test 4. Handover trio 100% complete

## Stakeholders
YiVad PM (decision); YiVad main owner (execution); CTO (approval); frontend lead; QA; newcomer (consumption)
