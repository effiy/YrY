# PRD — Design Review Process

**PRD ID**: PRD-2026-PM-007  |  **Project**: ALL  |  **Domain**: Process — Design Review
**Priority**: p1  |  **Status**: adopted  |  **Country**: ALL  |  **Owner**: PM Team + designers
**KB Source**: product-manager/processes/design-review.md

## Business Objective
Standardize the design review process, ensuring design goes through 4-dimensional review before launch (usability / consistency / accessibility / aesthetics).

## User Segment
designers / PM / engineers / QA

## Target Metric
Design review coverage 100%; Review pass rate ≥ 80%; Post-launch UX feedback ≤ 2

## Success Criteria
1. All new designs 100% go through review 2. Review pass rate ≥ 80% 3. Post-launch UX feedback ≤ 2 4. Review records archived

## Stakeholders
PM Team + designers (Decision); engineers (review); QA (review)
