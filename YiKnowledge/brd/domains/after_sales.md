# After-Sales / Customer Service Domain

> 售后服务与客户服务领域知识 — 涵盖工单管理、保修索赔、配件物流、呼叫中心、客户满意度等核心业务场景。

---

## 1. 领域概述

After-Sales（售后服务）是汽车、制造、消费电子等行业的核心业务域，直接影响客户生命周期价值（CLV）、品牌忠诚度和重复购买率。在汽车行业，售后服务收入通常占总利润的 40–60%，配件销售毛利率可达 25–40%。

### 典型业务子域

| 子域 | 描述 | 典型系统 |
|------|------|---------|
| **工单/票务管理** | 客户问题记录 → 分派 → 处理 → 关闭的全生命周期 | Zendesk, ServiceNow, Jira Service Management |
| **保修与索赔** | 保修资格验证 → 索赔提交 → 审核 → 赔付 | SAP Warranty, Oracle Warranty Management |
| **配件与物流** | 配件目录 → 库存管理 → 订单处理 → 配送追踪 | SAP ECC (MM/SD), PartsLink, TecDoc |
| **呼叫中心/客服** | 全渠道接入 → IVR → 技能路由 → 工单创建 | Genesys, Avaya, Amazon Connect |
| **技术服务公告 (TSB)** | 厂商发布 → 经销商通知 → 维修指引 → 执行追踪 | 自研系统或 Dealer Portal |
| **客户满意度** | NPS/CSAT 调查 → 反馈分析 → 改进闭环 | Medallia, Qualtrics, Salesforce Surveys |
| **经销商管理** | 经销商绩效 → 培训认证 → 索赔审计 → 激励 | Dealer Management System (DMS) |

## 2. 关键指标体系 (KPI)

### 服务质量

| KPI | 行业基准 | 优秀目标 | 测量方法 |
|-----|---------|---------|---------|
| 平均首次响应时间 (FRT) | 4–8 小时 | < 2 小时 | 工单创建 → 首次人工回复的时间差 |
| 平均解决时间 (MTTR) | 24–72 小时 | < 8 小时 | 工单创建 → 关闭的时间差（仅计营业时间） |
| 首次联系解决率 (FCR) | 60–70% | > 85% | 一次交互即解决的工单占比 |
| SLA 达标率 | 85–90% | > 95% | 按优先级分组的 SLA 达标工单占比 |
| 客户满意度 (CSAT) | 75–85% | > 90% | 工单关闭后即时调查 |
| 净推荐值 (NPS) | 30–50 | > 60 | 季度 NPS 调查 |
| 客户努力度评分 (CES) | 3.5–4.5 | < 3.0 | "解决问题需要多少努力"1–7 分 |

### 运营效率

| KPI | 行业基准 | 优秀目标 | 测量方法 |
|-----|---------|---------|---------|
| 单工单处理成本 | €15–35 | < €12 | 总运营成本 / 工单总量 |
| 代理人日均工单量 | 15–25 单 | > 30 单 | 已关闭工单 / (代理人 × 工作日) |
| 升级率 | 15–25% | < 10% | 需 Tier-2/3 处理的工单占比 |
| 重复工单率 | 8–15% | < 5% | 同一客户 7 天内同主题再开工单 |
| 自助解决率 | 20–40% | > 60% | 通过 FAQ/知识库/Chatbot 自行解决的占比 |
| 配件首次满足率 | 75–85% | > 92% | 一次订货即满足的配件需求占比 |

### 财务指标

| KPI | 行业基准 | 优秀目标 | 测量方法 |
|-----|---------|---------|---------|
| 保修成本率 | 1.5–3.0% 营收 | < 1.5% | 保修支出 / 总营收 |
| 配件库存周转率 | 3–6 次/年 | > 8 次/年 | 配件销售额 / 平均库存金额 |
| 客户保留率 | 60–75% | > 85% | 保修到期后继续回厂的比例 |
| 单车售后收入 (RPU) | €800–1,500/年 | > €2,000/年 | 售后总收入 / 活跃车辆数 |

## 3. 常见痛点与改进机会

### 工单管理

| 痛点 | 量化影响 | 改进方向 |
|------|---------|---------|
| 多系统切换 | 每工单 4–6 分钟切换时间；8–15% 数据录入错误 | 统一工单平台（Single Pane of Glass） |
| 手动分派 | 分派延迟 30–60 分钟；15% 错分率 | 基于技能 + 负载的自动路由 |
| 信息不完整 | 20–30% 工单需回访补充信息 | 结构化工单模板 + 客户自助提交 |
| SLA 监控滞后 | 5–10% 工单超时后才被发现 | 实时 SLA 仪表盘 + 预警通知 |
| 知识孤岛 | Tier-1 解决率 < 50% | AI 知识库 + 相似工单推荐 |

### 保修与索赔

| 痛点 | 量化影响 | 改进方向 |
|------|---------|---------|
| 纸质流程 | 每单处理 15–30 分钟；5–8% 数据错误 | 数字化 + OCR 自动采集 |
| 欺诈检测弱 | 年损失估值的 2–5% | 基于规则的自动审核 + 异常检测 |
| 返利结算慢 | 经销商资金压力，满意度下降 | 加快审核周期，实时结算 |
| 政策不一致 | 同故障不同市场不同赔付 | 全局保单管理 + AI 辅助审核 |

### 配件与物流

| 痛点 | 量化影响 | 改进方向 |
|------|---------|---------|
| 库存不透明 | 紧急订单占比 20–30%；加急运费高 | 全局库存可视化 + 智能调拨 |
| 需求预测不准 | 呆滞库存 15–25%；缺货率 5–10% | ML 需求预测 + 动态安全库存 |
| 配件查询慢 | 每工单查询 2–5 分钟 | VIN 自动匹配 + 图形化配件目录 |
| 物流追踪断链 | 经销商频繁电话查询 | 端到端物流追踪 + 主动推送 |

## 4. 典型用户角色/画像

| 角色 | 职责 | 使用频率 | 关键需求 | 影响级别 |
|------|------|---------|---------|---------|
| **Tier-1 客服代理** | 一线客户接待、工单创建、FAQ 解答 | 每日 | 快速工单创建、知识库搜索、客户历史查看 | End User |
| **Tier-2 技术专家** | 复杂问题诊断、技术方案制定、Tier-1 升级处理 | 每日 | 全功能工单处理、配件查询、TSB 检索、远程诊断工具 | End User |
| **技术服务经理** | 团队管理、SLA 监控、质量审核、培训 | 每日/每周 | 仪表盘、团队绩效报告、工单抽样、排班管理 | Decision Maker |
| **保修审核员** | 索赔审核、欺诈检测、政策执行 | 每日 | 批量审核、异常标记、赔付计算、审计追踪 | Key Influencer |
| **配件计划员** | 库存计划、采购订单、供应商管理 | 每周 | 需求预测、库存报告、自动补货建议 | Key Influencer |
| **区域售后总监** | 多市场运营、战略决策、预算管理 | 每周/每月 | 跨市场对比、财务分析、NPS 趋势 | Decision Maker |
| **经销商服务顾问** | 客户接待、维修接待、工单录入 | 每日 | 预约管理、VIN 查询、配件可用性、维修进度 | End User |
| **客户（终端用户）** | 报修、预约、进度查询、满意度反馈 | 按需 | 自助门户、手机预约、实时进度推送 | End User |

## 5. 适用法规框架

| 法规 | 适用范围 | 对 BRD 的影响 |
|------|---------|--------------|
| **GDPR (EU) 2016/679** | EU/EEA 所有个人数据处理 | 客户数据最小化；数据保留期限；数据可携带权；删除权 |
| **EU Data Act 2025** | 互联产品（含车联网）数据共享 | 车辆数据访问权；第三方数据共享义务 |
| **EU Right to Repair Directive** | 消费电子、汽车 | 配件可得性；维修信息透明；独立维修商平等访问 |
| **Block Exemption Regulation (EU) 461/2010** | 汽车售后市场 | 经销商配件来源自由；独立维修商技术信息获取权 |
| **German Supply Chain Due Diligence Act (LkSG)** | 德国企业供应链 | 供应商合规审查；人权与环境尽职调查 |
| **ISO 9001:2015** | 质量管理体系 | 服务流程标准化；客户投诉闭环；持续改进 |
| **Consumer Rights Directive (EU) 2011/83** | B2C 交易 | 14 天退货权；维修服务透明度；价格披露 |

## 6. 常见系统集成

| 源系统 | 集成方向 | 数据/功能 | 协议 |
|--------|---------|----------|------|
| **SAP ECC / S/4HANA** | 双向 | 配件目录、库存量、采购订单、财务过账 | RFC / OData / IDoc |
| **CRM (Salesforce / Dynamics)** | 双向 | 客户主数据、车辆档案、交互历史 | REST API |
| **DMS (Dealer Management System)** | 双向 | 预约、工单、配件订单、索赔状态 | REST / SFTP |
| **TecDoc** | 入站 | 配件目录、OE 编号、替代件映射 | REST API |
| **CTI / 呼叫中心** | 入站 | 来电弹屏、IVR 菜单、通话记录 | CTI Protocol |
| **TMS (Transport Management)** | 出站 | 配件发货、物流追踪、签收确认 | REST / EDI |
| **PowerBI / Tableau** | 出站 | 运营仪表盘、SLA 报告、NPS 分析 | ODBC / REST |
| **SSO (Azure AD / Okta)** | 入站 | 统一认证、角色权限 | SAML / OIDC |

## 7. 领域术语

| 术语 (EN) | 术语 (ZH) | 定义 |
|-----------|-----------|------|
| Ticket / Case | 工单/案例 | 客户服务请求的记录单元 |
| First Response Time (FRT) | 首次响应时间 | 客户提交 → 客服首次回复的时间 |
| Mean Time to Resolve (MTTR) | 平均解决时间 | 工单创建 → 关闭的平均耗时 |
| First Contact Resolution (FCR) | 首次联系解决率 | 一次交互即解决的工单占比 |
| Service Level Agreement (SLA) | 服务水平协议 | 约定的服务响应/解决时间目标 |
| Escalation | 升级 | 工单从低级别到高级别团队的转移 |
| Warranty Claim | 保修索赔 | 经销商/客户提交的保修赔付请求 |
| Technical Service Bulletin (TSB) | 技术服务公告 | 厂商发布的已知问题修复指引 |
| Recall | 召回 | 批量安全/合规缺陷的主动修复 |
| Parts on Demand (POD) | 按需配件 | 无库存配件的紧急订购 |
| Back-order | 缺货订单 | 库存不足无法立即满足的订单 |
| VIN (Vehicle Identification Number) | 车辆识别码 | 17 位全球唯一车辆标识符 |
| Dealer Management System (DMS) | 经销商管理系统 | 经销商日常运营管理软件 |
| Net Promoter Score (NPS) | 净推荐值 | 客户推荐意愿的标准化测量 (0–10) |
| Customer Effort Score (CES) | 客户努力度评分 | 衡量解决问题所需客户投入的指标 |
| Hypercare | 上线后保障期 | Go-Live 后 2–4 周的增强支持窗口 |
| Run Mode / Project Mode | 运营模式/项目模式 | 持续运维 vs 一次性项目交付的区分 |
| After-Sales Retention Rate | 售后保留率 | 保修到期后继续回厂维修的比例 |
| Parts Fill Rate | 配件满足率 | 首次订货即满足的配件需求占比 |
| Core Charge | 旧件押金 | 更换配件时旧件未退的附加费用 |
| Labour Time Guide (LTG) | 工时指南 | 每项标准维修操作的额定工时 |
