# Human Resources Domain

> 人力资源领域知识 — 涵盖员工生命周期、绩效管理、学习发展、招聘、编制规划等核心场景。

---

## 1. 领域概述

HR 域管理企业最重要的资产——人才。在跨国企业环境中，HR 系统需支持多法律实体、多币种薪酬、多语言、多时区等复杂性。核心系统为 HRIS（人力资源信息系统）或 HCM（人力资本管理）平台。

### 典型业务子域

| 子域 | 描述 | 典型系统 |
|------|------|---------|
| 员工主数据 | 员工档案、职位历史、组织架构 | SAP SuccessFactors, Workday, Oracle HCM |
| 招聘管理 (ATS) | 职位发布 → 简历筛选 → 面试排程 → 录用 | Greenhouse, Lever, SmartRecruiters |
| 绩效管理 | 目标设定 → 持续反馈 → 评估 → 校准 | Lattice, 15Five, Betterworks |
| 学习与发展 (LMS) | 课程目录 → 选课 → 学习追踪 → 认证 | Cornerstone, Docebo, SAP Litmos |
| 薪酬与福利 | 工资计算、奖金、股权、福利管理 | ADP, Paylocity, Workday Payroll |
| 时间与考勤 | 打卡、请假、加班、排班 | Kronos, Replicon, SAP Time |
| 编制与预算 | 岗位编制规划、人力成本预算、Headcount 追踪 | Anaplan, Adaptive, 自研 |

## 2. 关键指标体系 (KPI)

| KPI | 行业基准 | 优秀目标 |
|-----|---------|---------|
| 招聘周期 (Time-to-Hire) | 30–60 天 | < 25 天 |
| 主动离职率 | 10–20% | < 8% |
| 入职完成时间 | 2–4 周 | < 1 周 |
| 绩效评估完成率 | 70–90% | > 95% |
| 培训完成率 | 60–80% | > 90% |
| 薪酬市场竞争力 (Compa-Ratio) | 0.9–1.0 | 1.0–1.1 |
| HR 服务台 SLA 达标率 | 80–90% | > 95% |

## 3. 常见痛点

| 痛点 | 量化影响 | 改进方向 |
|------|---------|---------|
| 多系统数据不一致 | 同一员工在不同系统信息不同 | 统一 HRIS + 系统集成 |
| 入职流程碎片化 | IT/HR/Facility 各自独立，耗时 2–4 周 | 自动化入职工作流 |
| 绩效管理走过场 | 评估流于形式，缺乏实质反馈 | 持续反馈 + OKR 对齐 |
| 报表手工做 | HRBP 每月 8–16 小时做人力报表 | 自助 BI + 实时仪表盘 |
| 合规风险 | 劳工法违规（加班、休假、合同） | 规则引擎 + 自动预警 |

## 4. 典型用户角色

| 角色 | 使用频率 | 关键需求 | 影响级别 |
|------|---------|---------|---------|
| HR 专员 | 每日 | 员工服务、数据处理、问题解答 | End User |
| HRBP | 每日/每周 | 组织诊断、人才盘点、报表分析 | Key Influencer |
| 招聘专员 | 每日 | 职位管理、候选人沟通、面试安排 | End User |
| 直线经理 | 每周/每月 | 团队目标、绩效评估、请假审批 | End User |
| 员工（全员） | 按需 | 个人信息、请假、工资单、学习 | End User |
| CHRO / HR VP | 每月/每季 | 人力资本仪表盘、战略规划、合规 | Decision Maker |

## 5. 领域术语

| 术语 (EN) | 术语 (ZH) | 定义 |
|-----------|-----------|------|
| HRIS / HCM | 人力资源信息系统/人力资本管理 | HR 核心管理平台 |
| ATS (Applicant Tracking System) | 招聘管理系统 | 端到端招聘流程管理工具 |
| LMS (Learning Management System) | 学习管理系统 | 培训课程创建、分发和追踪平台 |
| OKR (Objectives & Key Results) | 目标与关键结果 | 目标管理和对齐框架 |
| Compa-Ratio | 薪酬比率 | 员工薪酬 / 市场中位值 |
| Headcount | 编制人数 | 经批准的岗位编制数量 |
| JML (Joiner-Mover-Leaver) | 入职-调动-离职 | 员工生命周期的三个关键事件 |
| FTE (Full-Time Equivalent) | 全职当量 | 折算为全职工作量的标准单位 |
| 9-Box Grid | 九宫格 | 绩效-潜力矩阵人才盘点工具 |
| Employee Value Proposition (EVP) | 员工价值主张 | 雇主提供的全面价值（薪酬+文化+发展） |
