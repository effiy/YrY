# Marketing / Campaign Domain

> 市场营销与活动管理领域知识 — 涵盖活动编排、客户分群、多渠道触达、营销归因、预算管理等核心场景。

---

## 1. 领域概述

Marketing 域驱动客户获取和品牌建设。在汽车行业，市场营销覆盖品牌活动、新车型上市、售后促销、客户忠诚度计划等。现代营销的技术栈高度依赖 Martech 工具链（MAP + CDP + DAM + Analytics）。

### 典型业务子域

| 子域 | 描述 | 典型系统 |
|------|------|---------|
| 活动编排 | 活动策划 → 受众选择 → 内容创建 → 多渠道发布 → 效果追踪 | Salesforce Marketing Cloud, HubSpot, Marketo |
| 客户分群 | 基于行为/属性/价值的动态分群 | CDP (Segment, mParticle, Treasure Data) |
| 营销自动化 | 触发式邮件/短信/推送 → 客户旅程编排 | Braze, Iterable, Customer.io |
| 数字资产管理 | 品牌素材存储、版本管理、分发 | Bynder, Adobe AEM, Contentful |
| 营销归因 | 多点触达归因（first/last/multi-touch） | Google Analytics 4, Adobe Analytics |
| 忠诚度计划 | 积分、等级、权益、兑换 | LoyaltyLion, Comarch, 自研 |

## 2. 关键指标体系 (KPI)

| KPI | 行业基准 | 优秀目标 |
|-----|---------|---------|
| 邮件打开率 | 15–25% | > 30% |
| 邮件点击率 (CTR) | 2–5% | > 8% |
| 落地页转化率 | 2–5% | > 10% |
| 营销获客成本 (M-CAC) | €50–200 | < €100 |
| 营销 ROI (ROMI) | 3–5× | > 5× |
| 客户参与度评分 | — | 环比增长 10%+ |
| 活动触达覆盖率 | 60–80% | > 90% |

---

## 3. 常见痛点

| 痛点 | 量化影响 | 改进方向 |
|------|---------|---------|
| 渠道数据割裂 | 每个渠道独立报告，全局 ROI 不可见 | CDP 统一客户视图 + 跨渠道归因 |
| 分群靠手工 | 营销团队每周 4–8 小时手拉清单 | 实时动态分群 + 预测性分群 |
| 审批流程慢 | 活动上线延迟 2–5 天 | 内容审批工作流 + 模板化 |
| 素材管理混乱 | 20–30% 时间花在找素材 | 统一 DAM + AI 标签 |
| 合规风险 | GDPR/CCPA 违规罚款可达营收 4% | 自动化合规检查 + 同意管理 |

## 4. 典型用户角色

| 角色 | 使用频率 | 关键需求 | 影响级别 |
|------|---------|---------|---------|
| 市场经理 | 每日/每周 | 活动策划、预算管理、效果报告 | Decision Maker |
| 数字营销专员 | 每日 | 多渠道发布、A/B 测试、受众选择 | End User |
| 内容创作者 | 每日 | DAM 存取、模板使用、审批流程 | End User |
| 数据分析师 | 每周 | 归因分析、分群优化、ROI 计算 | Key Influencer |
| 合规官 | 按需 | 同意管理审核、素材合规检查 | Key Influencer |

## 5. 领域术语

| 术语 (EN) | 术语 (ZH) | 定义 |
|-----------|-----------|------|
| MAP (Marketing Automation Platform) | 营销自动化平台 | 自动化营销触达和客户旅程的工具 |
| CDP (Customer Data Platform) | 客户数据平台 | 统一客户画像的跨渠道数据聚合平台 |
| DAM (Digital Asset Management) | 数字资产管理 | 品牌素材的存储、检索、分发系统 |
| Multi-Touch Attribution (MTA) | 多点触达归因 | 分配转化贡献到多个营销触点的模型 |
| Customer Segmentation | 客户分群 | 按属性/行为将客户分组以精准营销 |
| A/B Testing | A/B 测试 | 对比两版内容/设计的随机实验 |
| Consent Management | 同意管理 | 按 GDPR/ePrivacy 管理客户营销同意 |
| Lead Scoring | 线索评分 | 基于行为/属性的潜在客户价值评分 |
| Customer Journey | 客户旅程 | 客户从认知到忠诚的全触点路径 |
| ROMI (Return on Marketing Investment) | 营销投资回报率 | (营销收入 - 营销成本) / 营销成本 |
