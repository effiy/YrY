# 专家 / Experts

收录行业专家、技术权威信息。

## 文件类型

- `{专家姓名}.md`：单人档案

## 推荐结构

```markdown
---
title: 某专家
tags: [专家, 领域]
category: people/experts
created: YYYY-MM-DD
source: <主页 / 社交链接>
type: summary
---

## 背景与履历
## 主要观点与作品
## 关注的领域
## 引用价值（适合用于什么场景背书）
```

## 隐私与合规

- 仅收录公开信息（公开演讲、文章、博客）
- 不收录私人联系方式
- 标注信息最后核实日期
