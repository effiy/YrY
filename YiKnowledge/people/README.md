# 人脉 / People

收录工作相关人员档案：团队成员、利益相关者、行业专家。

## 子目录

| Leaf | 收录内容 |
|---|---|
| [team/](./team/) | 团队成员档案与协作约定 |
| [stakeholders/](./stakeholders/) | 业务利益相关者（合作方、审批角色） |
| [experts/](./experts/) | 行业专家与技术权威 |

## 隐私与合规

- 仅收录公开信息（公开演讲、文章、博客、官方履历）
- 不收录私人联系方式（电话、私人邮箱、住址）
- 团队成员内容变更需本人确认
- 专家档案须标注「最后核实日期」
