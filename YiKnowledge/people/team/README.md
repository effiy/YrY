# 团队成员 / Team

收录团队成员档案与协作约定。

## 文件类型

- `{姓名}.md`：单人档案

## 推荐结构

```markdown
---
title: 某成员
tags: [团队, 角色]
category: people/team
created: YYYY-MM-DD
source: internal
type: summary
---

## 角色与职责
## 专业领域
## 协作偏好（沟通方式、PR 风格、会议节奏）
## 时区 / 工作时间
## 当前主负责项目
```

## 隐私与合规

- 仅收录工作相关信息
- 不收录私人联系方式
- 内容变更需本人确认
