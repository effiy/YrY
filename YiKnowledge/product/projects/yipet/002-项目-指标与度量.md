# YiPet 项目指标与度量

> **作为** PM / Chrome 扩展工程师 / Leader，**我想要**一页看懂 YiPet 全部指标（北极星每日激活会话数、双世界执行、知识底座、跨项目 Hub、隐私仪表盘 139-prd），**以便** Chrome Store 新版本上架前快速过仪表盘就知道「能不能上架」。

## 北极星指标表

| 北极星指标 | 定义 | 公式 | 谁负责 | 当前值（2026-10-07 内测样本） | Q4 目标 | 更新频率 |
|---|---|---|---|---|---|---|
| **每日激活会话数（Daily Active Sessions, DAS）** | 每个自然日内，用户点击 YiPet 图标或按快捷键唤起聊天窗口，并在 10 分钟窗口内完成 ≥ 1 轮有效交互（非空消息 / 非纯错误响应 / 非系统自动心跳）的会话总数；统计独立用户的会话次数求和 | `DAS = Σ count_distinct(session_id where interactions ≥1 AND status=SUCCESS)` 按天聚合；MV3 Service Worker 存活期间 session_id 连续，睡眠重启后分配新 session_id | PM + Chat Controller Owner（前端） | 184（内部 23 人 × 7 天平均，知识底座 + 纯聊天合并） | ≥ 500（Chrome Store 正式上架首月目标） | 每日（chrome.storage.local 日快照 → 用户主动同步或可选遥测） |

## AARRR 五阶段漏斗表

|---|---|---|---|---|
| **获客 Acquisition** | Chrome Web Store 周安装量（YiPet 商店页） | 次 / 周 | 商店后台 Installs 统计，过滤 24h 内卸载的「试玩即走」 | < 50 危险 / 50~200 警告 / ≥ 500 健康 |
| **获客 Acquisition** | 首次扩展加载成功率（含 Service Worker 唤醒 + CDN vendor 80+ 库加载） | % | `count(service_worker.activated AND cdn.all_loaded) / count(extensions_installed_events)`；CDN 加载见 src/content/cdn/catalog.ts | < 75% 危险 / 75~90% 警告 / ≥ 97% 健康 |
| **激活 Activation** | Day1 知识底座会话占比：新用户 Day1 ≥ 1 次勾选「知识底座」的会话 / 新用户总会话 | % | 「知识底座」= RAG 范围选择器选中 YiKnowledge 目录的会话；对应产品愿景核心价值 | < 15% 危险 / 15~30% 警告 / ≥ 40% 健康（与 01-项目-管理 成功指标 北极星对齐） |
| **激活 Activation** | 宠物图标 + 浮动按钮渲染成功率（双世界 MAIN World DOM 注入） | % | `count(page_has_pet_dom) / count(content_script_injected)`；ISOLATED → MAIN 双世界注入链路（01-入职 架构概览 双世界边界） | < 85% 危险 / 85~95% 警告 / ≥ 99% 健康 |
| **留存 Retention** | W4 会话留存率：W0 有激活会话的用户，W4 仍 ≥ 1 DAS 的比例 | % | Cohort W0 install 分组，W4 DAS ≥ 1 / W0 总数 | < 10% 危险 / 10~25% 警告 / ≥ 35% 健康 |

| **收入 Revenue**（效率等价） | 跨项目 Hub 使用率（Bug 上报 / YiVad aiChat 跳转 合计用户占比） | % | 「跨项目 Hub」= lessons/0009-成果-YiPet跨项目Hub.md 定义的桥接能力 | < 2% 危险 / 2~7% 警告 / ≥ 15% 健康 |
| **推荐 Referral** | 会话分享导出率（周内 ≥ 1 次导出 md/html） | % | `count(users where session_export ≥1 in 7d) / weekly_active_users`；会话功能见 01-项目-管理 交付物「会话功能已交付」 | < 1% 危险 / 1~4% 警告 / ≥ 10% 健康 |
| **推荐 Referral** | AiCR（AI Code Review）触发率（周内使用 AiCR 子模式 ≥ 1 次） | % | `count(users where aicr_triggered ≥1 in 7d) / weekly_active_users`；关键产品决策「AiCR 整合到 aiChat 而非独立入口」验证 | < 3% 危险 / 3~10% 警告 / ≥ 20% 健康 |

## 数据质量 SLA（4 条） + 验收 Checklist（3 条）

### 数据质量 SLA 四项

| # | 数据质量维度 | SLA 定义 | 违反后果 | 修复时限 |
|---|---|---|---|---|
| D1 | **准确性** | YT01（DAS）、YT04（知识底座占比）、YT14（隐私红线）三条关键指标抽样对账误差 ≤ ±3%（考虑可选遥测开关样本少） | 关键指标面板灰「?」+ Chrome Store 版本上架前需要人工二次确认 | ≤ 48 工作小时 |
| D2 | **完整性** | MV3 Service Worker 沉睡可能丢事件：「连续 30 分钟无埋点」判定为 SW 睡眠丢失，丢失率标记 10% 容忍；CDN 指标必须覆盖全部 80+ vendor，缺 1 个即完整性告警 | 丢失率 > 10% 时指标旁标注「SW 沉睡丢失 X%」；CDN 缺失 Top3 vendor 立即 P2 告警 | ≤ 24 工作小时（CDN 补全）/ ≤ 72h（SW 埋点改造） |
| D3 | **时效性** | 用户本地快照聚合到可选遥测后端 → 仪表盘可见，延迟 P95 ≤ 90 分钟（浏览器默认不常驻后台）；隐私仪表盘（139-prd）自检「加密合规」实时（启动即显示） | 面板「迟滞 N min」黄牌；隐私自检启动 > 30 秒未完成弹窗提示 | ≤ 6 小时（集中遥测）/ 实时（隐私自检 ≤ 5s） |
| D4 | **新鲜度** | 指标字典 updated_at ≤ 90 天；质量审计报告（110-prd）每月出一份；CDN catalog.ts 新 vendor 加入后 48h 内 YT15 指标覆盖对应条目 | 指标旁「⚠️ stale」；110-prd 当月未出 → Leader 月报 Top 风险项 | ≤ 5 工作天（字典）/ 当月 （110-prd） / ≤ 2 天（CDN 指标覆盖） |

### 验收 Checklist（3 条）

- [ ] **双世界注入端到端验证**：20 个主流站点白名单（百度、掘金、GitHub 等）Selenium 跑一遍 YT05 渲染率 ≥ 99.5%，YT16 失败率 < 0.5%；所有失败站点归类记录到 110-prd 质量审计报告 附录 A
- [ ] **隐私红线冒烟**：故意在开发环境写入未加密会话历史 → YT14 自检 100% 命中 → 隐私仪表盘（139-prd）红色告警条弹出 → 修复（加密重写）后告警自动消除
- [ ] **RPC 契约零错误闭环**：构造一条 SessionService 调用故意传 `query` 而非 `filter` 参数 → YT18 拦截器捕获错误率 = 1 次 → 控制台红色警告 + 自动纠正（开发模式）→ 确保 lessons/06-陷阱 不再重现
