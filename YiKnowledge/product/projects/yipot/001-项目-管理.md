# YiPot 项目管理

> **作为**产品经理/工程师，**我想要**了解 YiPot 项目管理上下文，**以便**协调跨项目工作、对齐品牌替换与安全加固阶段目标，并理解当前交付节奏。

## 项目定位

YiPot 是 YrY 旗下的**跨平台桌面翻译应用**（前身为开源项目 Pot 的品牌衍生版），基于 Tauri 1.6 + Rust + React 18 构建，覆盖 macOS / Windows / Linux 三端，核心能力：

- 全场景取词：全局划词翻译、剪切板监听翻译、手动输入翻译
- OCR 截图识别：系统原生 OCR + 14 款云端 OCR 插件 + 公式/表格/二维码识别
- TTS 朗读 + 生词本收藏：21 种翻译服务、2 款生词本同步（Anki / 欧路词典）
- 可扩展插件系统：翻译 / OCR / TTS / 生词本 四类 30+ 插件，用户可自主配置
- 内嵌 HTTP Server（60828 端口）：对外提供翻译 API，供 PopClip（macOS）和 SnipDo（Windows）扩展调用

YiPot 是面向**个人生产力**的端侧应用，数据和密钥默认本地存储，无强制云端账号。

## 产品愿景

**让任何人在任何屏幕上，一键跨越语言障碍。**

- 任何屏幕：文档、PDF、浏览器、IDE、聊天窗口、视频字幕 → 划词 / 截图都能翻译
- 一键：全局热键 / 剪切板监听 / PopClip 扩展，减少从选中文本到获得结果的操作路径
- 任何语言：20+ 翻译服务 + 本地离线词典兜底 + 21 国 UI 语言

## 关键产品决策

- **数据默认本地，云端可选同步**：所有 API Key、翻译历史、生词本默认存本地 AppConfig 目录；WebDav / 阿里云 OSS 备份需用户主动开启，零强制账号
- **翻译服务插件化而非内建单一**：30+ 服务让用户自选，避免单一服务中断导致全局不可用；失败自动切换 + 熔断器指数退避
- **Tauri 而非 Electron**：安装包 < 10MB（Electron 通常 100MB+）、内存 < 100MB、启动 < 500ms；牺牲少量 Node 生态换取体验
- **60828 HTTP 端口硬编码**：PopClip / SnipDo 扩展硬编码该端口，避免用户配置；冲突时自动提示用户关闭占用进程
- **OCR 本地优先、云端兜底**：system_ocr.rs 优先调平台原生 Vision API（免密钥、零延迟），失败再走云端高精度插件

## 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| **翻译服务密钥泄露风险**（若前端反编译能取到硬编码 Key） | 品牌口碑 + 账单损失 | 插件三件套禁令：禁止 index.jsx 写死 Key，必须 Config.jsx 让用户自填；v2.x 增加 store 密钥简单加密 |
| **Rust `unwrap()` panic 导致崩溃** | 偶发退出 / 翻译丢失；用户信任度下降 | v2.x M2 主干模块 unwrap 替换率 ≥ 95%；CI 中 `cargo clippy -- -D clippy::unwrap_used` |
| **PopClip / SnipDo 依赖的 60828 端口被占用** | 扩展按钮无响应 | 启动时检测端口冲突，弹窗引导关闭占用者；提供 Config → General 修改端口 + 扩展重新打包指引 |
| **Linux Wayland 下全局热键 / 截图 / 剪贴板权限** | 功能部分失效，用户误以为是 bug | Config → General 黄条显式提示；README 平台差异章节；自带 hyprland.patch（已在 patches/） |
| **Tauri 1.x 升级到 2.x 的破坏性改动** | 插件 API / 权限模型变更 | 锁定 tauri = "1.6"，升级前 ADR 评估 + 专项里程碑 |
| **第三方翻译 / OCR 服务 API 变更或封禁** | 单个插件不可用 | 插件数量冗余（同类 2~5 个可选）；自动切换备用；提供插件更新热更新机制 |

### PM 操作指南

**新增翻译服务插件时**：
1. 确认插件类别（translate / recognize / tts / collection）
2. 按开发规范准备三件套：`info.ts`（id 唯一）+ `index.jsx`（方法签名对齐）+ `Config.jsx`（NextUI 表单）
3. 在 `src/utils/service_instance.ts` 注册，冒烟验证：配置 → 调用 → 失败切换备用
4. 更新 [0003-项目-功能模块.md](../../../engineer/learn/projects/yipot/003-项目-功能模块.md) 插件清单
5. 两周小版本中随包发布，记录 CHANGELOG

**报告 bug 时**：
1. 标注平台（macOS / Windows / Linux，含版本与架构 x64/arm64）
2. 复现步骤 + 使用的翻译/OCR 插件 ID（如 `translate/deepl`）
3. 崩溃类：附上 `~/Library/Logs/com.yipot.desktop/*.log` 或等效路径
4. 安全 / 品牌类 → P0 热修复
