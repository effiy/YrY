# YiPot 项目指标与度量

> **作为** PM / Rust 桌面工程师 / Leader，**我想要**一页看懂 YiPot 全部量化指标（北极星「每日划词翻译成功率」、三端 AARRR、60828 HTTP SLO、unwrap 崩溃率），**以便**两周小版本发布前快速判定「是否可以发版」。

## 北极星指标表

| 北极星指标 | 定义 | 公式 | 谁负责 | 当前值（2026-10-07 快照） | Q4 目标 | 更新频率 |
|---|---|---|---|---|---|---|
| **每日划词翻译成功率** | 在用户主动触发的「划词 + 全局热键 + PopClip」三类翻译意图中，YiPot 在 5 秒内返回有效翻译结果（非空、非错误提示、用户未二次重试）的比例 | `success_rate = (翻译成功数 × 去重用户) ÷ (翻译意图总数 × 去重用户)`；按日汇总，跨平台加权（macOS 0.5 / Windows 0.35 / Linux 0.15）；成功判定：window.translate 收到 code=0 且 result.length>0 且 trigger→result 间隔 ≤ 5,000ms | PM + 翻译引擎 Owner（Rust 端 server.rs + 前端 TranslateWin） | 88.2%（内部 beta 组 23 人 × 7 天数据；匿名遥测默认关闭，手动开启样本） | ≥ 96%（正式版 v2.x M2 里程碑） | 每日（样本用户）+ 每两月（全量匿名遥测用户一次性汇总） |

## AARRR 五阶段漏斗表

| 漏斗阶段 | 指标名（#1 / #2） | 单位 | 计算公式 / 口径 | 阈值（危险 / 警告 / 健康） |
|---|---|---|---|---|
| **获客 Acquisition** | 三端累计下载 / 安装量（GitHub Release + 镜像） | 次（累计） | `count(download_asset = .dmg OR .msi OR .AppImage)`；按平台拆解：macOS=AppleSilicon+Intel / Windows=x64 / Linux=x64+arm64 | < 1k 危险 / 1k~20k 警告 / ≥ 50k Q4 目标 健康 |
| **获客 Acquisition** | 首启完成率：下载 → 首次成功拉起托盘且无 crash（三端） | % | `count(first_launch tray_loaded=true) / count(download_total)`；排除 Gatekeeper/SmartScreen 拦截未真正启动 | < 70% 危险 / 70~85% 警告 / ≥ 92% 健康 |
| **激活 Activation** | Day1 完成 ≥ 5 次翻译的新用户占比（三端去重 user_id） | % | `count(new_users where day1_translation_count ≥5) / count(new_users_total)`；new_user=install_date 当日首次启动 | < 25% 危险 / 25~45% 警告 / ≥ 60% 健康 |
| **激活 Activation** | PopClip/SnipDo 扩展首次调用 `/config` 路由返回 ok 率（server.rs 第 52 行） | % | `count(POST /config response = ok) / count(all_popclip_snipdo_first_config_calls)`；路由定义见 YiPot `src-tauri/src/server.rs:52`（/config 路由） | < 80% 危险 / 80~92% 警告 / ≥ 98% 健康 |
| **留存 Retention** | 7 日留存（D1→D7 均有 ≥ 1 次翻译成功的新用户比例） | % | Cohort：D0 install 用户，在 D7 仍然翻译成功 ≥ 1 次 / D0 总数；含平台分拆 | < 15% 危险 / 15~30% 警告 / ≥ 40% 健康 |
| **留存 Retention** | 周使用深度：周翻译 ≥ 50 次的用户占周活跃用户比例 | % | `count(weekly_active_users where translations ≥50) / count(weekly_active_users)` | < 8% 危险 / 8~18% 警告 / ≥ 30% 健康 |
| **收入 Revenue**（效率等价） | 翻译平均响应时间 P95（三端网络正常下，端到端） | 毫秒 | `percentile(trigger_to_result_ms, 95)` 过滤 HTTP 200 / code=0 的成功翻译 | > 2,500ms 危险 / 1,200~2,500ms 警告 / ≤ 1,200ms 健康（目标 P95 ≤ 1.2s） |
| **收入 Revenue**（效率等价） | 插件切换成功率：翻译失败自动切换到备用插件后成功的比例（衡量插件冗余架构价值） | % | `count(fallback→success) / count(total_plugin_failures that had fallback available)` | < 40% 危险 / 40~65% 警告 / ≥ 85% 健康 |
| **推荐 Referral** | 生词本导出 / WebDav 备份功能周使用率 | % | `count(users where 生词本导出 or webdav_backup_success ≥1 in 7d) / count(weekly_active_users)` | < 2% 危险 / 2~6% 警告 / ≥ 10% 健康 |
| **推荐 Referral** | OCR 二次识别率：同一选区 OCR 后 60 秒内用户重按截图键（暗示第一次结果差） | % | `count(ocr_second_trigger within 60s same area) / count(all_ocr_triggers)`；越低越好（反向指标） | > 20% 危险 / 10~20% 警告 / ≤ 5% 健康 |

## 数据质量 SLA（4 条） + 验收 Checklist（3 条）

### 数据质量 SLA 四项

| # | 数据质量维度 | SLA 定义 | 违反后果 | 修复时限 |
|---|---|---|---|---|
| D1 | **准确性** | YP01~YP22 关键 5 项（YP01/YP08/YP10/YP11/YP12）人工抽样对账误差 ≤ ±2%；匿名遥测样本与内测组实测偏差 ≤ ±5% | 仪表盘关键指标灰「?」；两周小版本发布 Gate 需人工确认 | ≤ 48 工作小时 |
| D2 | **完整性** | Rust panic 上报丢失率（因遥测未开启不计）≤ 实际 crash 的 20%（考虑多数用户关遥测）；CI unwrap 计数 100% 覆盖主干四模块 | 缺失面板显示 N/A 且附注「样本不足」；完整性警告 ≤ 1 周不触发 P0/P1 发布冻结 | ≤ 72 工作小时（补埋点）|
| D3 | **时效性** | 仪表盘指标更新端到端延迟 ≤ 60 分钟（本地 SQLite → 用户主动同步 → 集中面板）；CI unwrap/品牌检查实时（5 分钟内到 PR 评论） | 面板显示「迟滞 N min」黄牌；CI 超时自动重新触发 | ≤ 4 小时（集中面板）/ ≤ 30 分钟（CI PR 评论）|
| D4 | **新鲜度** | 指标字典文档 updated_at ≤ 90 天；OCR 评测集每季度更新 ≥ 10% 新样本；APIKey 加密覆盖率每周二刷新 | 指标旁「⚠️ stale」图标；Curator 季度审查 Top1 待修 | ≤ 5 工作天（字典文档）/ ≤ 3 天（加密周刷新）|

### 验收 Checklist（3 条）

- [ ] **北极星闭环**：连续 14 天收集 20+ 内测用户真实划词数据，YP01 成功率日波动与人工 spot-check 误差 ≤ ±2%，D1 准确性达标
- [ ] **崩溃埋点对账**：Sentry（或等价上报）与 Rust panic_handler 本地 double-write 双写日志对比，YP10 crash 数偏差 ≤ ±10%（考虑用户关遥测）
- [ ] **安全合规两条红线联调**：① CI `cargo clippy -D unwrap_used`（YP11）真实失败触发 PR block → 修复后放行；② 人工构造明文 APIKey（YP12 bugs/安全隐私/001-APIKey明文存储.md）插件自动被 secureStore.ts 拒绝保存
