# YiVad 项目指标与度量

> **作为** PM / Vue 前端工程师 / Leader，**我想要**一页看懂 YiVad 全部指标（项目按期交付率北极星、ProTable 效率、/#/project 路由、动态路由权限、MongoDB projects 集合 5 项目数据），**以便**季度 OKR 评审会上 5 分钟就能过仪表盘讲清楚「各项目交付节奏对不对」。

## 北极星指标表

| 北极星指标 | 定义 | 公式 | 谁负责 | 当前值（2026-10-07 基线） | Q4 目标 | 更新频率 |
|---|---|---|---|---|---|---|
| **项目按期交付率（On-time Delivery Rate）** | 对 YiVad /#/project 路由下注册的 5 个项目（YiAi / YiVad / YiPet / YiPot / YiKnowledge），每个项目的 issues / milestones / cycles 中标记为「本期应交付」的条目，在计划结束日期（due_date / cycle_end_date）当天或之前标记为 done / closed / resolved 的条目数占比 | `按期交付率 = Σ count(issues where status ∈ {done,closed,resolved} AND closed_at ≤ due_date) ÷ Σ count(issues where due_date ∈ 本统计窗口 AND 非取消项)`；按季度窗口，5 项目聚合，权重按项目 issue 数量加权（大项目不被小项目稀释）；数据来源：YiAi → MongoDB `projects` 集合 5 项目文档 | 产品 PM + 各项目 Owner 联合（共 5 位） | 71%（Q3 回溯数据，5 项目共 137 条应交付，97 条按期，基线建立于 2026-10-01） | ≥ 85%（Q4 5 项目联合目标） | 每两周（Sprint 结束日）更新 + 每月 QBR 快照 + 季度正式评审 |

## AARRR 五阶段漏斗表

| 漏斗阶段 | 指标名（#1 / #2） | 单位 | 计算公式 / 口径 | 阈值（危险 / 警告 / 健康） |
|---|---|---|---|---|
| **获客 Acquisition** | 每周新增注册项目数（通过 /#/project 路由「新建项目」） | 个 / 周 | `count(projects where created_at in 7d)` from MongoDB `projects` 集合（5 项目以外的新增用户项目） | < 2 危险 / 2~5 警告 / ≥ 8 健康 |
| **获客 Acquisition** | 动态路由首屏渲染完成率（登录 → 菜单加载 → 首路由可交互 ≤ 3 秒） | % | `count(first_render_ready ≤ 3000ms) / count(login_events)`；路由=/#/project 或 /#/aiChat；动态路由注册见 src/routers/modules/dynamicRouter.ts | < 75% 危险 / 75~90% 警告 / ≥ 97% 健康 |
| **激活 Activation** | 新项目 Day7 活跃率：创建后 7 天内至少有 1 次 issue CRUD 的项目 / 新项目总数 | % | `count(projects join issues where issues.updated_at within 7d of project.created_at) / count(new_projects)`；MongoDB 聚合 | < 40% 危险 / 40~60% 警告 / ≥ 75% 健康 |
| **激活 Activation** | ProTable 首次使用成功率：首 7 天内至少完成 1 次「筛选 + 分页 + 排序」组合操作的用户占比 | % | `count(distinct user_id where actions = {filter, paginate, sort}) within 7d of first_login`；ProTable 标准模式 src/components/ProTable/ | < 30% 危险 / 30~50% 警告 / ≥ 65% 健康 |
| **留存 Retention** | W4 周活项目率：创建 W0 的项目在 W4 仍 ≥ 1 次 issue / cycle 更新 | % | Cohort 按 project.created_at 周分组；projects 集合 `updated_at` 字段过滤 | < 35% 危险 / 35~55% 警告 / ≥ 70% 健康 |
| **留存 Retention** | 权限按钮使用广度：周活用户中使用过 ≥ 3 个不同 v-auth 按钮的占比（体现「不是只读观众」） | % | `count(distinct users where weekly_auth_unique ≥ 3) / count(weekly_active_users)`；v-auth 指令 src/directives/modules/auth.ts | < 25% 危险 / 25~45% 警告 / ≥ 60% 健康 |
| **收入 Revenue**（效率等价） | ProTable 单次查询平均耗时（筛选 + 查 YiAi RPC + 渲染返回）P95 | 毫秒 | `percentile(query_start → table_rendered, 95)`；仅 data_service.query_documents；含 YiAi 后端延迟合计 | > 2,500ms 危险 / 1,000~2,500ms 警告 / ≤ 600ms 健康 |
| **收入 Revenue**（效率等价） | Agent 报告生成成功率（触发 → 草稿 → 用户点击「保存」完整链路） | % | `count(agent_reports with final_status=saved) / count(agent_triggers)`；Agent 模式 Q3 规划中 | < 30% 危险 / 30~70% 警告 / ≥ 90% 健康（MVP 稳定版） |
| **推荐 Referral** | Bug 跨项目提交率：YiPet 桥接 + YiVad 内部提交 → bugs 集合周新增 bug 报告中含复现步骤 + 附件的比例 | % | `count(bugs where steps_to_reproduce IS NOT NULL AND attachment_count ≥ 1) / weekly_new_bugs`；跨项目依赖 YiPet → YiVad bugs | < 20% 危险 / 20~50% 警告 / ≥ 75% 健康 |
| **推荐 Referral** | 知识库浏览 → 跳转 RAG 会话的转化率 | % | `count(session where origin=knowledge_browser_click) / count(knowledge_file_views)`；知识库功能前端 | < 3% 危险 / 3~10% 警告 / ≥ 15% 健康 |

## 数据质量 SLA（4 条） + 验收 Checklist（3 条）

### 数据质量 SLA 四项

| # | 数据质量维度 | SLA 定义 | 违反后果 | 修复时限 |
|---|---|---|---|---|
| D1 | **准确性** | YV01 按期交付率：抽查 20 条 issue 的 due_date / closed_at / status 与 MongoDB 原始文档一致性，错误率 ≤ 1 条（≤ 5%）；projects 集合 5 项目 ID 映射正确（无项目张冠李戴） | 北极星指标红「⚠️ 校准中」；QBR 评审必须附人工校正版 | ≤ 48 工作小时 |
| D2 | **完整性** | projects/issues/bugs 三个集合统计周期内条目丢失率 ≤ 0.2%（YiAi MongoDB → YiVad 前端 RPC 桥梁之间丢数）；缺失条目由 YiAi 审计日志可恢复 | 仪表盘指标附「丢失 X 条已排除」注释；连续 3 天丢数触发 P2 | ≤ 24 工作小时恢复 + 根因报告 ≤ 5 工作日 |
| D3 | **时效性** | 双周 Sprint 结束日 18:00 前 YV01 按期交付率必须刷新到仪表盘；ProTable P95 延迟指标到面板端到端 ≤ 15 分钟 | YV01 延迟 → PM 站会必须解释；ProTable 面板黄色「迟滞 N min」 | Sprint 截止日 ≤ 18:00（YV01）/ ≤ 15 分钟实时指标 |
| D4 | **新鲜度** | 指标字典 updated_at ≤ 90 天；RBAC 权限矩阵审计脚本每月至少跑 1 次（YV15）；MongoDB 5 项目映射表每季度检查一次（新增/删除/合并项目） | 指标旁「⚠️ stale」图标；Curator 季度审查 Top 待修 | ≤ 5 工作天（字典）/ 当月（RBAC 审计） / 季度（项目映射表） |

### 验收 Checklist（3 条）

- [ ] **projects 集合对账**：YiVad /#/project 路由列表展示的 5 项目（YiAi/YiVad/YiPet/YiPot/YiKnowledge），逐一手动与 MongoDB `projects` 集合 `find({project_id: {$in: [...]}})` 结果对比，字段名（name / owner / status / updated_at）100% 一致，YV12 写入成功率验证脚本通过 ≥ 100 次模拟写入
- [ ] **按期交付率回算**：手动从 MongoDB 抽取 Q3 5 项目共 137 条应交付 issue，逐条核对 status / due_date / closed_at，回算 YV01 = 71%，与仪表盘值误差 ±1 个百分点（D1 满足）
- [ ] **v-auth 权限冒烟（YV15 SLO P1红线）**：用 5 个角色（admin / pm / engineer / curator / viewer）账号分别登录 → 遍历 20 个关键按钮 → 对照 RBAC 矩阵快照；任一漏权限或越权限，仪表板 YV15 自动触发红色告警并阻断当日 deploy 流水线
