# 第二曲线（The Second Curve）

## 1. 框架定义

Charles Handy（2015）提出。核心命题：**任何业务都有生命周期（第一曲线），到达巅峰前必须开启第二曲线，否则会被时代抛弃**。

```
第一曲线 S 形：起步 → 加速 → 巅峰 → 衰退
                ↑
              第二曲线在此处启动
```

关键时机：第一曲线还在上升但尚未到巅峰时启动第二曲线——此时有资源、有时间、有容错空间。

## 2. 核心概念

| 概念 | 含义 |
|---|---|
| 第一曲线 | 当前主营业务 |
| 第二曲线 | 下一阶段业务 |
| 鸿沟 | 从第一到第二的过渡期，需双线运行 |
| 巅峰 | 第一曲线最高点，过了启动第二已迟 |
| 推动力 | 个人或组织内部的变革驱动力 |
| 时机 | 第二曲线必须在第一曲线巅峰前启动 |

## 3. 经典案例

### Netflix

- 第一曲线：DVD 邮寄
- 第二曲线：流媒体
- 第三曲线：自制内容
- 第四曲线：游戏 / 周边业务

每次都在前曲线巅峰前启下一曲线。在 DVD 业务巅峰时启动流媒体，牺牲短期利润换长期生存。

### Apple

- 第一曲线：Mac
- 第二曲线：iPod / iTunes
- 第三曲线：iPhone
- 第四曲线：Watch / Services

### Kodak（反例）

- 第一曲线：胶卷
- 第二曲线：本应启动数字摄影
- 巅峰过了才意识到，2012 破产

Kodak 实际上发明了数码相机，但被胶卷业务绑架，不愿自我颠覆。

## 4. 实施步骤

1. **诊断第一曲线位置**：在 S 曲线哪一段？是否临近巅峰
2. **找第二曲线候选**：3-5 个方向
3. **资源双线**：保留 70% 在第一曲线，30% 投第二
4. **实验第二曲线**：小规模、低承诺、快速验证
5. **过渡**：第二曲线验证成功，逐步加资源；第一曲线下降时不抵抗
6. **新第一曲线**：第二曲线成新主业

## 5. 启动时机的判断

| 信号 | 含义 |
|---|---|
| 增长率开始下降 | 第一曲线接近巅峰 |
| 新玩家涌入 | 红海化 |
| 客户结构老化 | 新客户获取变难 |
| 利润率压缩 | 价格战开始 |
| 技术趋势变化 | 新技术出现 |

不要等"巅峰已过"才启动——那时已无资源。

## 6. 与其他框架对比

| 框架 | 视角 | 与第二曲线关系 |
|---|---|---|
| 第二曲线 | 跨越式创新 | 自我颠覆 |
| 蓝海战略 | 重定义市场边界 | 第二曲线的具体方法 |
| Porter 五力 | 行业结构 | 第二曲线避开五力强的红海 |
| Disruptive Innovation | 颠覆性创新 | 第二曲线常是颠覆式 |

## 7. 适用场景与边界

**适用**：

- 当前业务接近巅峰
- 行业技术 / 模式在变
- 公司有资源投第二曲线

**不适用**：

- 早期创业（第一曲线还没立住）
- 资源紧张（养活第一曲线都难）
- 内部工具（与公司业务无直接关系）

## 8. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 巅峰才启动第二 | 没资源了 | 必在巅峰前启动 |
| 第二曲线与第一冲突 | 内部利益对立 | 文化上接受自我颠覆 |
| 资源全投第二 | 第一曲线崩塌太快 | 70/30 平衡 |
| 不实验直接 All-in | 风险大 | 小规模验证再扩大 |
| 第二曲线过多 | 同时开 5 条 | 1-2 条为主 |
| 不愿放弃第一 | 文化 / 利益绑架 | 高层推动 + 长期激励 |

## 9. AI 产品的第二曲线思考

- 通用 chatbot 是第一曲线，红海化
- 第二曲线候选：垂类深度、业务流闭环、Agent / 多模态、端侧 AI
- 时机判断：用户增长是否放缓、利润率是否压缩

YiAi BRD 团队：BRD 生成是当前曲线，第二曲线候选 = 海外业务流闭环（BRD + 工单 + 跨系统）

## 10. 落地要点

- 战略评审时画第一 / 第二曲线图
- 高层对第二曲线有明确承诺与激励
- 双线运行不互相挤兑
- 复盘第一曲线衰退与第二曲线成长节奏
