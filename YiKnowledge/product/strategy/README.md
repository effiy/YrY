# 产品战略 / Product Strategy

收录产品战略框架、路线图设计、商业模式、定位方法。

## 收录范围

- 产品愿景与定位
- 商业模式画布（Business Model Canvas）
- 路线图设计（Now / Next / Later）
- 竞争战略（蓝海、差异化）
- 第二曲线与产品组合管理

## 文件类型与命名

- `{战略名}-summary.md`：战略框架摘要
- `{战略名}-strategy.md`：本产品战略实例
- 命名采用英文 kebab-case

## Frontmatter 模板

```yaml
---
title: 某战略框架
tags: [战略, 产品, 主题]
category: product/strategy
created: YYYY-MM-DD
updated: YYYY-MM-DD
source: <链接或 internal>
type: summary
status: stable
---
```

## 写作推荐结构

1. 战略框架定义
2. 适用场景
3. 设计步骤
4. 关键产出物
5. 反模式
6. 本产品落地实例
