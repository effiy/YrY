# Porter 五力分析

## 1. 框架定义

Michael Porter（1979，HBR）提出。把行业竞争拆为五种力量，看行业整体吸引力与利润空间。**不是看竞品对比，而是看行业结构**。

## 2. 五种力量

| 力量 | 含义 |
|---|---|
| 现有竞争者的竞争强度 | 同行竞争激烈程度 |
| 供应商议价能力 | 上游能压你多少价 |
| 客户议价能力 | 下游能压你多少价 |
| 新进入者威胁 | 新玩家进入门槛高低 |
| 替代品威胁 | 完全不同的方案取代 |

## 3. 各力分析要点

### 现有竞争者

- 行业增长率（增长慢竞争激烈）
- 固定成本结构（高固定成本激烈）
- 差异化程度（差异化低激烈）
- 退出壁垒（高退出壁垒激烈）

### 供应商议价

- 供应商集中度（少数供应商强）
- 切换成本（高则强）
- 前向整合威胁（供应商可自己做下游）
- 输入独特性（独特则强）

### 客户议价

- 客户集中度（少数客户强）
- 切换成本（低则强）
- 后向整合威胁（客户可自己做）
- 产品对客户重要性（低重要性则强）

### 新进入者

- 规模经济门槛
- 资本需求
- 渠道与品牌优势
- 政策与许可
- 切换成本

### 替代品

- 性价比替代方案
- 客户切换替代品的成本
- 替代品行业利润率（高利润率可能降价冲击）

## 4. 分析步骤

1. 定义行业边界
2. 五力分别评估：强 / 中 / 弱
3. 找最强势力与最弱势力
4. 推演行业利润空间
5. 制定战略：定位在五力较弱的环节，或改造行业结构

## 5. 战略含义

- **成本领先**：与现有竞争者拼成本，适合规模玩家
- **差异化**：建立独特性降低客户议价、提高进入门槛
- **聚焦**：选择五力较弱的细分市场

## 6. 与其他框架对比

| 框架 | 视角 | 适合 |
|---|---|---|
| Porter 五力 | 行业结构 | 战略定位 |
| SWOT | 内部 + 外部 | 战略评审 |
| Business Model Canvas | 商业模式全貌 | 描述与诊断 |
| 蓝海战略 | 重新定义市场边界 | 创新方向 |

五力看"是什么行业"，蓝海看"换一个市场"。

## 7. AI 行业应用

以"AI BRD 生成工具"为例：

| 力 | 强度 | 评估 |
|---|---|---|
| 现有竞争 | 中 | OpenAI / Anthropic / 通用 chatbot 可替代 |
| 供应商议价 | 强 | 大模型 API 价格由少数厂商控制 |
| 客户议价 | 中 | 企业客户集中度中等 |
| 新进入者 | 高 | 通用 LLM 加 prompt 可入场，门槛低 |
| 替代品 | 高 | 人工 + Excel、咨询公司服务 |

结论：行业利润空间被压缩；战略上需差异化（垂类 BRD + 多语言 + 业务知识库）。

## 8. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 只列竞争者 | 忽略供应商 / 替代品 | 五力必全 |
| 静态分析 | 三年前的力已变 | 年度复审 |
| 不制定行动 | 评估完不行动 | 必出战略选择 |
| 行业边界模糊 | 把所有都当行业 | 明确边界 |

## 9. 落地要点

- 与 Now/Next/Later 路线图配合
- 战略评审时先跑五力
- 新业务评估前必做
