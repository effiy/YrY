# 产品战略框架摘要

## 1. 战略层次

1. **愿景（Vision）**：我们要成为什么？3-5 年的长远目标
2. **战略（Strategy）**：我们如何达成愿景？关键路径选择
3. **路线图（Roadmap）**：阶段性目标和里程碑
4. **战术（Tactics）**：具体执行计划

## 2. 战略分析工具

### 2.1 SWOT 分析
内部分析（优势 / 劣势）+ 外部分析（机会 / 威胁）。

### 2.2 波特五力模型
- 供应商议价能力
- 购买者议价能力
- 新进入者威胁
- 替代品威胁
- 行业内竞争

### 2.3 PEST / PESTEL
宏观环境分析：Political / Economic / Social / Technological（+ Environmental / Legal），适合评估海外市场进入。

### 2.4 蓝海战略
通过「价值创新」跳出红海：剔除、减少、提升、创造四步动作框架。

## 3. 目标管理

### 3.1 OKR
- **Objective**：鼓舞人心的定性目标
- **Key Results**：可衡量的定量结果（3-5 个）
- 趋势：从年度 OKR 转向季度 + 双周对齐

### 3.2 平衡计分卡
从财务、客户、内部流程、学习成长四个维度平衡短期与长期。

## 4. 用户与需求分析

### 4.1 Jobs-to-be-Done（JTBD）
用户不是购买产品，而是「雇佣」产品完成某项任务。
- 公式：当我 [情境]，我想要 [动机]，以便 [期望结果]
- 价值：跳出功能堆砌，关注用户真正想完成的事

### 4.2 Kano 模型
- **基础属性**：没有会不满，有了也无效
- **期望属性**：越多越好，线性
- **兴奋属性**：没有也不满，有了会惊喜
- 应用：评估功能优先级，避免过度投入基础属性

## 5. 增长与指标

### 5.1 North Star Metric（北极星指标）
- 一个能代表产品核心价值的单一指标
- 例：Airbnb = 订单数；Spotify = 总收听时长
- 关键：与长期价值强相关、可分解为输入指标

### 5.2 AARRR 海盗指标
- **Acquisition**：拉新
- **Activation**：首次体验核心价值
- **Retention**：留存（最重要）
- **Revenue**：变现
- **Referral**：传播
- 趋势：补充为 RARRA（留存优先），反映移动时代留存比拉新更难

### 5.3 增长循环
- 拉新循环：内容 SEO → 流量 → 转化
- 病毒循环：邀请奖励 → 用户裂变
- 留存循环：核心价值 → 习惯 → 付费
- 关键：每个循环可量化、可放大

## 6. 优先级与决策

### 6.1 RICE
Reach × Impact × Confidence / Effort，量化优先级排序。

### 6.2 MoSCoW
Must / Should / Could / Won't，适合版本范围控制。

### 6.3 ICE
Impact / Confidence / Ease，轻量级快速评估。

## 7. 战略决策原则

- 聚焦核心用户价值，警惕「可以做的」vs「应该做的」
- 做减法比做加法更难但更重要
- 长期主义与短期收益的平衡：用 70% 资源保住当前业务，30% 投入未来
- 「Second-order thinking」：考虑决策的二阶后果
- 反向思考：先想清楚什么会毁掉产品，然后避免
- 不逆向趋势，但要警惕 FOMO 驱动的伪需求
