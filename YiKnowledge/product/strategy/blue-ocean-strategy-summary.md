# 蓝海战略（Blue Ocean Strategy）

## 1. 框架定义

W. Chan Kim 与 Renée Mauborgne（2005）提出。

- **红海**：现有市场，竞争激烈，价格战
- **蓝海**：无人竞争的新市场，创造而非争夺

核心命题：与其在红海拼刺刀，不如重新定义市场边界，开创新需求。

## 2. 核心工具：价值创新

### Eliminate-Reduce-Raise-Create（ERRC）四步动作框架

| 动作 | 含义 |
|---|---|
| Eliminate 消除 | 行业理所当然但其实无价值的因素 |
| Reduce 减少 | 远超行业标准的因素降低 |
| Raise 提升 | 远低于行业标准的因素提升 |
| Create 创造 | 行业从未提供的因素 |

### 战略画布（Strategy Canvas）

X 轴：行业竞争因素
Y 轴：每因素的高低
画自己与竞品曲线，对比形状差异

蓝海产品曲线通常与红海显著不同形状。

## 3. 六条路径重定义市场

1. **跨行业**：看替代行业（如电影院 = 餐厅 = 剧院）
2. **跨战略集团**：在高价与低价之间找位
3. **跨买方链**：从用户到决策者到影响者
4. **跨互补品**：把互补品合并
5. **跨功能 / 情感**：原本情感转向功能或反向
6. **跨时间**：把握趋势的早期信号

## 4. 实施步骤

1. 画当前战略画布（自己 + 竞品）
2. 看 ERRC 四步能去掉 / 减少 / 提升 / 创造什么
3. 画蓝海战略画布（目标新曲线）
4. 验证：用户访谈、原型测试
5. 执行：从红海过渡到蓝海

## 5. 案例

### Cirque du Soleil（太阳马戏团）

- 消除：动物表演、明星演员
- 减少：成本（无动物成本）
- 提升：艺术性、音乐、故事
- 创造：戏剧化的成人主题

从传统马戏（红海）走到"马戏 + 戏剧"新市场（蓝海）。

### Yellow Tail 葡萄酒

- 消除：年份、复杂术语
- 减少：口感强度、酒类繁多
- 提升：易饮性、乐趣
- 创造：零售体验、简易标签

从专业酒（红海）走到"轻松饮品"市场（蓝海）。

## 6. 与其他框架对比

| 框架 | 视角 | 与蓝海关系 |
|---|---|---|
| Porter 五力 | 红海竞争 | 蓝海是反五力 |
| Business Model Canvas | 商业模式描述 | 蓝海战略可填入 BMC |
| JTBD | 用户要完成什么 | 蓝海先问 Job 不被现有方案框住 |
| 第二曲线 | 跨越式创新 | 蓝海是第二曲线的具象方法 |

## 7. 适用场景与边界

**适用**：

- 现有市场红海化、利润空间压缩
- 有能力重新定义市场
- 创业期找方向

**不适用**：

- 强合同 / 强合规场景（市场边界被锁）
- 内部工具（市场边界无意义）
- 短期生存危机

## 8. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 把差异化当蓝海 | 还在同一市场 | 必须重新定义边界 |
| ERRC 只 Raise / Create | 只增不减成本爆 | 消除减少同等重要 |
| 不验证就上 | 蓝海变成"无人海" | 必须验证需求 |
| 忽略红海过渡 | 旧业务还在养新业务 | 平稳过渡 |
| 一次到位 | 没准备就跳 | 渐进切换 |

## 9. AI 产品的蓝海思考

通用 chatbot 是红海（OpenAI / Anthropic / 国产大厂）。蓝海方向：

- 垂类深度（BRD / 售后 / 法律 / 医学）
- 业务流闭环（不只是问答，是端到端工作流）
- 多语言小语种市场
- 数据闭环（用户偏好数据飞轮）

YiAi BRD 智能体的蓝海：海外售后 BRD 自动化 + 多语言 + 业务术语锁定——通用 chatbot 无法做到这深度。

## 10. 落地要点

- 战略评审时与五力结合
- 新业务探索时跑 ERRC
- 战略画布每年更新
