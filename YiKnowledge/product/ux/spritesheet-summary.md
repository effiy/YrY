# Spritesheet 精灵图资源

## 概述

WebP 格式的精灵图（雪碧图），用于产品 UI 界面中的图标/图片合并展示，减少 HTTP 请求、优化加载性能。

## 文件信息

- **格式**: WebP
- **原始路径**: `/Users/ruiyi/Downloads/YrY/spritesheet.webp`
- **归档路径**: `product/ux/spritesheet.webp`

## 用途

精灵图通常用于将多个小图标或 UI 元素合并到一张图片中，通过 CSS background-position 定位显示不同图标，常见于 Web/移动端产品的图标系统。

## 行动建议

- 如需修改图标，使用对应的源文件重新生成 spritesheet
- 确认该 spritesheet 对应的产品模块和图标清单
