# 产品知识 / Product

收录产品战略、需求文档、UX、指标体系。

## 子目录

| Leaf | 收录内容 |
|---|---|
| [strategy/](./strategy/) | 产品战略、路线图、商业模式 |
| [prd/](./prd/) | 具体产品 PRD 实例（模板见 `resources/templates/prd.md`） |
| [ux/](./ux/) | UX 研究、设计原则、可用性测试 |
| [metrics/](./metrics/) | 指标体系、监控规范、北极星指标 |

## 归档原则

- 战略与 PRD 类内容须标注版本与生效日期
- UX 研究须记录方法、样本量、关键发现
- 指标定义须含公式、采集方式、健康阈值
