## 边界：方法论 vs 记录

| 内容 | 归属 | 位置 |
|---|---|---|
| 如何评估风险（本文档） | leader/risk/ | 方法论 |
| 如何写复盘（本文档） | leader/risk/ | 方法论 |
| 实际的风险登记册 | leader/risk/ | 模板 + 实例 |
| 具体事故的复盘报告 | srer/incident-response/ | 实操记录 |
| 从复盘中提取的通用教训 | engineer/learn/lessons/ | 知识沉淀 |

## 风险管理闭环

```
风险识别 ──→ 风险评估 ──→ 风险登记 ──→ 风险缓解
    ↑                                      │
    │                                      ↓
    └── 事后复盘 ←── 事故响应 ←── 风险实现
```
