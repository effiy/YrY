## 一、YiAi — FastAPI 后端

### 1. RPC 端点认证

```bash
# 检查是否有未认证即可调用的敏感端点
grep -r "X-Token" YiAi/src/server/ --include="*.py" | wc -l
```

- [ ] 敏感操作（数据修改、文件写入）要求认证（如果认证已启用）
- [ ] 未认证的端点仅限只读和低风险操作

### 2. 路径遍历

- [ ] `/read-file` 和 `/write-file` 端点的 `target_file` 参数限制了访问范围
- [ ] 不能通过 `../` 访问 YiKnowledge 目录之外的文件
- [ ] 验证方式：尝试 `target_file=../../../etc/passwd` 应被拒绝

```python
# 应有类似这样的检查
target = Path(YIKNOWLEDGE_ROOT) / target_file
target.resolve().is_relative_to(Path(YIKNOWLEDGE_ROOT).resolve())
```

### 3. 注入防护

- [ ] MongoDB 查询使用参数化（Motor 的 `find({key: value})`），不拼接用户输入到查询字符串
- [ ] 没有使用 `eval()` 或 `exec()` 处理用户输入
- [ ] LLM prompt 中的用户输入经过了基本的注入防护（至少限制长度）

### 4. 密钥管理

```bash
# 检查代码中是否有硬编码密钥
grep -rE "(api_key|password|secret|token)\s*=\s*['\"]" YiAi/ --include="*.py" | grep -v "os.environ" | grep -v "config"
```

- [ ] 所有密钥通过环境变量或 `config.yaml` 管理
- [ ] `.env` 和 `config.yaml`（如果含密钥）在 `.gitignore` 中
- [ ] 日志中不输出密钥、token、密码

### 5. 依赖 CVE

```bash
pip-audit
```

- [ ] 无 high/critical 级别的已知 CVE
- [ ] 如有中等 CVE，已评估影响和缓解措施

### 6. CORS 配置

- [ ] CORS 仅允许已知的前端域名（`localhost:8848`、YiPet 扩展 ID）
- [ ] 不是 `allow_origins=["*"]`

---

## 二、YiVad — Vue 3 SPA

### 7. XSS 防护

- [ ] 用户输入在渲染前经过转义（Vue 默认转义 `{{ }}`，确保没有用 `v-html` 渲染用户内容）
- [ ] 检查所有 `v-html` 使用——它们的数据来源是否可信？

```bash
grep -r "v-html" YiVad/src/ --include="*.vue"
```

### 8. Token 存储

- [ ] Token 存储在安全的存储机制中（localStorage 或 cookie with HttpOnly）
- [ ] 退出登录时清除 Token
- [ ] Token 不在 URL 参数中传递

### 9. 敏感路由

- [ ] 管理后台的敏感页面受 `v-auth` 权限指令保护
- [ ] 未登录状态下访问受保护页面会被重定向到登录页

### 10. 依赖 CVE

```bash
pnpm audit
```

- [ ] 无 high/critical 级别的已知 CVE

---

## 三、YiPet — Chrome MV3 扩展

### 11. 内容安全策略 (CSP)

- [ ] `manifest.json` 中定义了 CSP
- [ ] 不使用 `eval()`、`new Function()`、内联脚本
- [ ] 外部资源加载限制在可信域名

### 12. 权限最小化

- [ ] `manifest.json` 中申请的权限是最小必要集合
- [ ] 不使用 `"permissions": ["<all_urls>"]` 除非绝对必要
- [ ] 可选权限与必需权限分离

### 13. 跨世界通信安全

- [ ] Content Script 与 Service Worker 的消息有类型验证
- [ ] 不信任来自页面的消息（页面可能被 XSS 攻击）
- [ ] session key 不通过不安全的渠道传递

### 14. 存储安全

- [ ] 敏感数据（Token、session key）使用 `chrome.storage.local`，不暴露给页面
- [ ] 不在 `window` 对象上挂载敏感数据

### 15. 依赖 CVE

```bash
npm audit
```

- [ ] 无 high/critical 级别的已知 CVE
