# 决策可回溯率

> **指标定义**：架构决策可回溯到对应需求的比例。即：对于任意一个 ADR，能否通过其 frontmatter 中的 `related` 字段和文档交叉引用，找到驱动该决策的原始需求？
>
> **为什么选择这个指标**：ADR 本身只记录了"做了什么决策和为什么"。可回溯率保证决策不会被孤立——它回答了"这个决策是为了满足什么需求"的问题。对于需求变更场景，可回溯性让团队能够快速定位哪些 ADR 需要重新评估。

## 计算方法

```
决策可回溯率 = 可追溯至需求的 ADR 数 / 全部 ADR 数 × 100%
```

"可追溯"的定义：ADR 的 `related` frontmatter 字段中包含至少一个指向需求文档（PRD、用户故事、CLAUDE.md 相关章节、工程师实现记录）的有效链接。
