# ADR 覆盖率

> **指标定义**：产出 ADR（上下文/决策/后果）的需求占所有重大技术需求的比例。
>
> **为什么选择这个指标**：ADR 覆盖率直接衡量技术决策的可追溯性。无 ADR 覆盖的需求意味着它的技术决策仅存在于实施者的记忆中——一旦实施者离开或遗忘，决策理由将永久丢失。

## 计算方法

```
ADR 覆盖率 = 已产出 ADR 的重大需求数 / 全部重大需求数 × 100%
```

"重大需求"的定义：涉及跨模块影响、技术选型、架构变更或不可逆决策的需求。不包括纯 bug 修复、配置调整或单文件范围内的改动。
