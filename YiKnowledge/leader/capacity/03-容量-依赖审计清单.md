## 三、维护状态检查

对超过 **12 个月无新版本** 的依赖重点审查：

| 依赖 | 最后发布时间 | 无更新月数 | GitHub Stars | 最近提交 | 评估 |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |

**评估指南**：
- 🟢 **健康**：最近 3 个月有提交，issue 有响应
- 🟡 **关注**：3-12 个月无提交或 issue 积压
- 🔴 **风险**：超过 12 个月无活动，或已声明停止维护
