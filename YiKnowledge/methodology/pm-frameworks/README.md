# 产品管理框架 / PM Frameworks

收录产品管理方法论、流程框架、决策模型。

## 收录范围

- 敏捷产品管理（Scrum / Kanban / SAFe）
- 产品发现与交付（Dual-Track Agile、Discovery）
- 路线图与优先级（RICE、ICE、MoSCoW、Kano）
- 用户研究方法（JTBD、persona、旅程图）
- 度量与复盘（OKR、NPS、HEART、AARRR）

## 文件类型与命名

- `{框架名}-summary.md`：框架摘要
- `{框架名}-template.md`：可复用模板
- 命名采用英文 kebab-case

## Frontmatter 模板

```yaml
---
title: 某框架
tags: [PM, 框架, 主题]
category: methodology/pm-frameworks
created: YYYY-MM-DD
updated: YYYY-MM-DD
source: <链接或 internal>
type: summary
status: stable
---
```

## 写作推荐结构

1. 框架来源与作者
2. 核心概念与原则
3. 实施步骤
4. 输入 / 输出工件
5. 适用场景与边界
6. 与其他框架对比
7. 本团队落地案例
