# 二阶思维（Second-Order Thinking）

## 1. 模型定义

二阶思维：考虑行动的**后果之后果**。

- 一阶思维：做 X，得到 Y
- 二阶思维：得到 Y 之后，又会发生什么？
- 三阶思维：再下一层（少用，避免过度推演）

Howard Marks 在《投资最重要的事》中强调二阶思维：一阶思维只看直接结果，二阶思维看连锁反应。一阶"降价能涨销量"，二阶"降价伤品牌、引发价格战、长期 LTV 下降"。

## 2. 适用场景

- 决策有强外部性（影响他人或后续行动）
- 系统性问题（一处改变触发链式反应）
- 长期权衡（短期收益 vs 长期成本）
- 反直觉现象（一阶对二阶错）

## 3. 使用步骤

1. **写下一阶结果**：做 X 直接会发生什么？
2. **逐个追问"然后呢"**：每个一阶结果会引发什么？
3. **二阶与三阶推演**：通常到二阶已足够
4. **加总权衡**：一阶收益 vs 二阶成本
5. **决策**：一阶 + 二阶净值为正才做

## 4. 案例

### 城市堵车加宽道路

- 一阶：加宽 → 通行能力上升 → 不堵
- 二阶：不堵 → 更多人开车 → 通行量上升 → 又堵
- 三阶：又堵 → 加宽… 重复诱导需求
- 结论：单纯加宽无效，需配合限号 / 公共交通

### 软件项目加人

- 一阶：加人 → 产能上升 → 早点上线
- 二阶：加人要培训 → 老人带新人 → 老人产能降 → 实际产能短期下降（Brooks's Law）
- 三阶：短期延期 → 客户投诉 → 加更多压力 → 质量下降
- 结论：加人不如减少 WIP（在制品）

### YiAi 引入新模型降价

- 一阶：换便宜模型 → 单 token 成本下降 50%
- 二阶：质量下降 → 重生成率上升 → 实际 token 总量上升 → 总成本反升
- 三阶：用户满意度下降 → 流失 → LTV 下降
- 结论：不能只看单价，要看单位任务总成本

### 限免券拉新

- 一阶：送券 → 注册涨
- 二阶：薅羊毛用户涌入 → 付费转化率降 → 营销 ROI 看起来好实则差
- 三阶：员工追逐虚假增长 → 战略漂移
- 结论：券要看 LTV 不是注册数

## 5. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 只看一阶 | "这看起来对" | 强制问"然后呢" |
| 推演过远 | 5 阶之后失控 | 通常二阶够，三阶慎用 |
| 没有权重 | 二阶影响都列了但没对比 | 概率 × 影响打分 |
| 不更新假设 | 二阶预测错了不修正 | 季度复盘，对照预测 |

## 6. 工具：决策树与影响图

- **决策树**：分支罗列一阶 / 二阶路径与概率
- **影响图（influence diagram）**：节点间因果关系，可视化反馈环
- **系统思考**（systems thinking）：找反馈环（正反馈强化 / 负反馈平衡）

## 7. 与其他思维模型关系

- 第一性原理：拆基础事实 → 二阶推后果
- 反向思考：反向避免失败 → 反向列二阶风险
- 奥卡姆剃刀：解释同一现象取最简，避免过度二阶

## 8. 落地要点

- 团队决策时强制写"一阶收益 / 二阶成本"两列
- 季度复盘预测对错，校准推演能力
- 重要决策有二阶记录，避免重复讨论
