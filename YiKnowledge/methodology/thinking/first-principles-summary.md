# 第一性原理思考（First Principles Thinking）

## 1. 模型定义

第一性原理思考：把问题拆到不可再分的基础事实（first principle），从这些事实向上推理，而不是依赖类比与既有做法。

源于亚里士多德，被 Elon Musk 在 SpaceX 与 Tesla 决策中带火。"我会从第一性原理而不是类比出发"——Musk 解释火箭成本时，不是问"市面火箭多少钱"，而是问"火箭的原材料构成值多少钱"。

## 2. 适用场景

- 长期决策（资金投入大、转向成本高）
- 现状有强惯性而无法解释为何如此
- 类比法导致趋同，需要差异化判断
- 复杂系统诊断根因

## 3. 使用步骤

1. **找出当前假设**：列出现状所基于的所有"理所当然"
2. **质疑每个假设**：它是事实、是约定、还是惯性？
3. **拆到不可再分**：把真的事实留下，拆出最基础的物理 / 经济 / 数学事实
4. **从基础事实重建**：如果今天从零开始，怎么解决？
5. **对比**：基础推理方案 vs 类比方案，差异在哪里

## 4. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 把"约定俗成"当事实 | 拆不彻底，仍在惯性中 | 多问"为什么" |
| 拆得过细耗时 | 第一性原理不是用于一切决策 | 用在大决策 |
| 不对比现实 | 拆完没落地 | 从基础事实重建方案 |
| 拒绝类比 | 类比有时是最优解 | 类比只是起点不是终点 |

## 5. 案例

### SpaceX 火箭

- 类比法：市面火箭一次发射 6500 万美元 → 重复使用降一些
- 第一性原理：火箭材料 = 铝 / 钛 / 铜 / 碳纤维，按重量算成本 = 一次发射成本的 2% → 可回收
- 决策：自研可回收火箭

### YiAi BRD（假设性案例）

- 类比：照搬 ChatGPT 的对话 UI + 模板填空
- 第一性原理：BRD 核心是结构化业务需求 + 多语言 + 可审批，无对话也能完成 → CLI / API 优先
- 决策：先做 API 与模板库，对话 UI 第二步

## 6. 注意事项

- 适用范围有限，小事不必第一性原理
- 拆得越细，对领域知识要求越高；不熟领域易拆错
- 拆完应验证基础事实是否真"基础"，避免凭空推理

## 7. 关联思维模型

- 反向思考（Inversion）：与第一性原理互补，正向拆基础，反向想"如何失败"
- 二阶思维：拆到基础事实后，推演多步后果
- 奥卡姆剃刀：解释同一现象，取假设最少的版本
