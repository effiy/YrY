# 飞轮效应（Flywheel Effect）

## 1. 模型定义

Jim Collins 在 *Good to Great*（2001）提出：卓越公司不是靠单一戏剧性事件突破，而是持续推动一个**飞轮**——每一圈的转动都让下一圈更容易。

核心特征：

- 多个环节互相加强
- 一环节的产出是另一环节的输入
- 转动需要持续力，但启动后势能累积

## 2. 经典案例

### Amazon 飞轮

```
降低价格 → 吸引更多顾客 → 吸引更多卖家 → 扩大选品 → 降低成本 → 降低价格（循环）
```

每环节都推动其他环节，越转越快。

### YiAi BRD 飞轮（假设）

```
更多用户用 BRD 生成 → 收集更多用户偏好数据 → 微调模型 → 生成质量提升 → 用户更满意 → 更多用户
```

## 3. 适用场景

- 业务战略设计：找业务能否形成自增强循环
- 产品规划：判断功能能否累积势能
- 增长诊断：找飞轮哪一环卡住
- 长期决策：选能形成飞轮的方向

## 4. 使用步骤

1. **列出业务关键环节**：用户、供给、成本、数据、品牌
2. **找互相强化关系**：A 增 → B 增 → C 增 → A 增
3. **画飞轮图**：环状循环
4. **诊断哪一环弱**：飞轮卡在最弱环
5. **设计推动**：把资源投到最弱环节，转动整个飞轮

## 5. 与漏斗 / 增长黑客关系

| 概念 | 视角 | 特征 |
|---|---|---|
| 漏斗 | 线性转化 | 单向、衰减 |
| 飞轮 | 循环 | 互相强化、累积 |
| 增长黑客 | 实验 | 短期实验 |

漏斗看一段，飞轮看整体循环。漏斗改善是单点优化，飞轮改善可能撬动全局。

## 6. 飞轮设计原则

- **环节不要太多**：3-5 环最佳，太多失焦
- **每环要有正向反馈**：A 增必推动 B 增
- **必须有势能累积**：每圈都让下一圈更易，不是无限循环相同状态
- **可量化**：每环有可观察的指标

## 7. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 飞轮环节太多 | 8 环，每环都"可能"推动 | 简化到 3-5 |
| 飞轮无势能累积 | 转一圈和上一圈一样 | 必有累积（数据、品牌、规模） |
| 只推一环 | 推 A 不管 B、C | 找最弱环，但目标在整体 |
| 无可观察指标 | 飞轮在转但看不到 | 每环节必填指标 |
| 戏剧化突破 | 想找"灵丹"一夜翻身 | 飞轮靠持续推 |

## 8. AI 产品的飞轮

数据飞轮是 AI 产品核心战略：

```
更多用户使用 → 更多真实偏好数据 → 模型 / 评估质量提升 → 更好产品 → 更多用户
```

关键：

- 数据采集要在产品体验中（"重生成"按钮既是 UX 又是数据源）
- 偏好数据存储要有结构化设计（不能只存日志）
- 模型迭代节奏快（飞轮推一环才有效）
- 评估自动化（不然数据多了反而处理不过来）

## 9. 本团队落地案例

- YiAi BRD：飞轮设计 = 用户使用 → 偏好数据 → prompt 与模型微调 → 质量提升 → 用户更多
- 关键指标：每环节都有（用户数、偏好数据量、模型评测分、用户满意度）
- 飞轮卡点评估：当前最弱在偏好数据结构化

## 10. 与其他思维模型关系

- 第一性原理：拆基础事实后再看能否形成飞轮
- 二阶思维：飞轮是二阶强化的具象
- 复利：飞轮是商业版的复利
