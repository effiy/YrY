# 会议纪要模板

## 使用场景

评审会、对齐会、决策会、复盘会。本模板遵循"无议程不开会、无纪要不结束"原则。

## 模板正文

```markdown
# {会议主题}

**日期**：YYYY-MM-DD
**时间**：HH:MM - HH:MM（时长 X 分钟）
**主持人**：{name}
**参与者**：{name1, name2, ...}
**缺席者**：{name}（如适用）
**会议类型**：评审 / 对齐 / 决策 / 复盘 / 头脑风暴

## 1. 议程

1. {议程项 1}
2. {议程项 2}
3. ...

## 2. 讨论要点

### 议程 1：{标题}

- {要点}
- {分歧点}
- {数据 / 证据}

### 议程 2：{标题}

- ...

## 3. 决议

| # | 决议 | 决策方式 | 责任人 | 截止日 |
|---|---|---|---|---|
| 1 | {decision} | 共识 / 投票 / 主持人定 | {name} | YYYY-MM-DD |
| 2 | ... | ... | ... | ... |

## 4. 行动项（Action Items）

| # | 行动 | 责任人 | 截止日 | 验证方式 |
|---|---|---|---|---|
| 1 | {action} | {name} | YYYY-MM-DD | {metric / artifact} |
| 2 | ... | ... | ... | ... |

## 5. 未决议题（Parking Lot）

- {议题} → 移至下次会议 / 异步处理
- ...

## 6. 下次会议

- 时间：YYYY-MM-DD HH:MM
- 议程：{要点}

## 附：相关材料

- {链接到 PRD / 设计 / 数据 / 上次会议纪要}
```

## 填写规范

| 字段 | 必填 | 规范 |
|---|---|---|
| 议程 | 是 | 会前发，会中不改 |
| 决议 | 是 | 决策方式必标 |
| 行动项 | 是 | 责任人 + 截止 + 验证 |
| 未决议题 | 推荐 | 不丢失 |
| 相关材料 | 推荐 | 链接 |

## 会议效率原则

- **无议程不开会**：议程在会前 24h 发出
- **无纪要不结束**：24h 内发出纪要
- **15 分钟原则**：单议题超 15 分钟未决议，移至线下
- **行动项可执行**：每条有明确产出物，不是"讨论 X"
- **决策可追溯**：决议要写理由与依据

## 反模式

- 议程模糊（"讨论下 BRD"）→ 写具体议题与期望产出
- 决议含糊（"达成一致"）→ 写具体决定
- 行动项无责任人 → 必填
- 纪要延迟 > 24h → 当天发
- 未决议题丢失 → Parking Lot 永久保留
