# 1on1 模板

## 使用场景

管理者与下属的定期一对一沟通。Ben Horowitz 推广；Camille Fournier 在 *Managers' Path* 中系统化。1on1 是员工成长与反馈的核心场景，不是状态汇报。

## 模板正文

```markdown
# 1on1：{员工姓名} × {经理姓名}

**日期**：YYYY-MM-DD
**节奏**：每周 / 每两周
**本周重点**：{一句话主题}

## 1. 员工主导话题（10-15 分钟）

让员工先讲。常见引导问题：
- 这周有什么让你兴奋 / 困扰？
- 需要我帮忙的阻塞？
- 任何想反馈给我或团队的？

记录要点：
- {要点 1}
- {要点 2}

## 2. 反馈（5-10 分钟）

### 经理给员工的反馈

- **Keep**：本周做得好的（具体事 + 数据 + 原因）
  - {item}
- **Improve**：可以更好的（具体事 + 期望 + 建议）
  - {item}

### 员工给经理的反馈

- {item}

## 3. 成长与发展（5-10 分钟）

- 短期目标（本季度）：{1-2 条}
- 长期方向（6-12 月）：{1-2 条}
- 学习资源 / 导师匹配：{建议}

## 4. 行动项

| # | 行动 | 责任人 | 截止日 |
|---|---|---|---|
| 1 | {action} | {name} | YYYY-MM-DD |
| 2 | ... | ... | ... |

## 5. 下次主题（预约）

- {要点}
```

## 填写规范

| 字段 | 必填 | 规范 |
|---|---|---|
| 员工主导话题 | 是 | 员工先讲，至少 10 分钟 |
| 反馈 | 是 | 双向，含具体事 |
| 行动项 | 是 | 责任人 + 截止 |
| 成长发展 | 推荐 | 至少每两月一次 |

## 1on1 原则

1. **员工主导**：90% 时间员工说话（理想状态）；新人 / 危机期经理多说无妨
2. **不在工位**：换个空间，降低等级压力
3. **准时不取消**：除非紧急，否则按时；取消必当天改期
4. **不状态汇报**：状态走异步文档，1on1 谈成长与感受
5. **保密**：员工分享的个人信息不外传
6. **跟进行动项**：上次行动项必查
7. **记录简短**：不逐字记录，记要点 + 行动

## 周期节奏

| 员工类型 | 频率 |
|---|---|
| 新人（前 3 月） | 每周 |
| 资深稳定 | 每两周 |
| 高自驱独立贡献者 | 每月（但随时可约） |
| 危机期 / 大变动 | 临时加密 |

## 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 经理独白 | 1on1 变成汇报 | 员工先讲，经理后说 |
| 状态汇报 | 复述项目进度 | 走异步文档 |
| 取消频繁 | 1on1 优先级最低 | 与日历强绑，不可随意取消 |
| 反馈空泛 | "做得不错" | 用具体事 + 数据 |
| 不跟进 | 行动项不了了之 | 上次必查 |
| 个人隐私外传 | 信任崩塌 | 严格保密 |

## 与 IDP 关系

- 1on1 谈短期成长与反馈
- IDP（个人发展计划）谈 6-12 个月长期
- 1on1 是 IDP 的执行节奏
