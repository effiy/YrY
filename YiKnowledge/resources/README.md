## 子目录与文件

| Leaf | 收录内容 |
|---|---|
| [prompts/](./prompts/) | 可复用 Prompt 资产 |
| [templates/](./templates/) | 文档模板（PRD / BRD / 复盘等） |

## 归档原则

- 模板与 Prompt 应含使用场景说明与变量列表
- 测试账号、密钥等敏感信息只存元数据指针，凭证存密码管理器
- 阅读清单按月度归档，读书笔记单独成文
