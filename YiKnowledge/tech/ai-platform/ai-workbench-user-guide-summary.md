# AI 桌面工作台使用指南摘要

## 1. 定位

基于开源 Agent 框架构建的桌面客户端 AI 工作台。底层复用框架的 Agent 执行、模型调用、工具调度、技能加载、记忆管理与任务编排能力；上层包装为聊天界面 + 工作空间 + Agent/Skill/协作平台/浏览器/文件等入口。核心特征：本地运行、基于文件系统的身份与记忆、高度透明可编辑。

## 2. 四层架构

| 层级 | 作用 |
|---|---|
| 桌面客户端层 | 聊天、Agent、Skills、工作空间、设置、外部通道入口 |
| 运行时层 | Agent 执行、上下文管理、工具调度、模型调用、技能加载 |
| 工作空间与记忆层 | 文件、产物、引导文件、长期记忆、技能沉淀 |
| 外部能力层 | Excel/PPT/协作平台/浏览器/网页/系统文件对接 |

## 3. 核心组成

- **Agent**：分工明确的 AI 角色（数据分析 / PPT 专家 / 市场情报 / 项目助理等），各自有独立工作区、上下文与长期记忆。
- **Workspace**：Agent 的工作台，存放输入文件、产物、引导文件（SOUL/USER/IDENTITY/AGENTS）。
- **SOUL.md**：长期角色设定——这个 Agent 是谁、遵循什么原则、输出风格、业务边界。
- **USER.md**：用户偏好——输出结构、汇报习惯、常用口径、确认要求。同一 Agent 给不同用户使用时此文件可不同。
- **IDENTITY.md**：身份与业务背景——部门、岗位职责、业务对象、沟通注意事项。
- **AGENTS.md**：工作区规则——目录组织、文件处理流程、必须确认的操作、安全边界。
- **Memory**：分四层——会话记忆 / 短期记忆（每日文件）/ 长期记忆（MEMORY.md）/ 梦境（整理机制）。适合沉淀偏好、口径、项目背景、技能经验；**不得**存密码、密钥、客户隐私。
- **Skill**：可复用操作手册——触发条件、输入、步骤、输出格式、限制。先完成真实任务 → 复盘 → 沉淀 Skill → 边用边迭代。
- **Tools**：让 AI 从"回答"走向"执行"——读取 Excel/Word/PPT/PDF、生成 Markdown/HTML/PPT、操作浏览器、写入协作平台、整理文件。
- **定时任务**：周期性工作触发，与 Agent/Skill/Memory 组合。

## 4. 引导文件分工速查

| 文件 | 解决的问题 | 适合写 | 不适合写 |
|---|---|---|---|
| SOUL.md | Agent 是谁 | 角色、原则、边界、长期风格 | 每日临时任务 |
| USER.md | 怎么配合我 | 用户偏好、汇报习惯、常用格式 | 密码、密钥、敏感隐私 |
| IDENTITY.md | 业务背景 | 岗位、部门、职责、业务对象 | 过细的个人隐私 |
| AGENTS.md | 工作区规则 | 文件规则、操作规范、安全要求 | 与任务无关的大段背景 |
| Memory | 哪些经验以后还要用 | 偏好、口径、长期项目、有效经验 | 未脱敏的敏感原始数据 |
| Skill | 某类任务如何稳定复用 | 步骤、工具、输入输出模板 | 只出现一次的临时想法 |

## 5. 通用业务实操主线

```
业务问题 → 上传数据或给出目标 → AI 分析和执行 → 生成产物 → 人工确认 → 沉淀为模板/Skill/记忆/知识库/定时任务
```

关键原则：
- 越清楚给定角色、数据口径、输出格式、约束，结果越可用。
- 复杂任务让 AI 拆步骤、给依据、列风险、输出待确认项。
- 涉及对外发送、协作平台写入、系统提交、记忆沉淀、文件批量修改，**先预览、再确认、后执行**。

## 6. 八类实操场景

1. **Excel 数据分析总结**：先做字段识别与风险点扫描，不编造未读数据，不确定标注"待确认"。
2. **Skill 使用与创建**：把成功读取经验沉淀成 `local-excel-reader` 类 Skill，结构含触发条件/输入/步骤/注意事项/限制/输出格式。
3. **用 Skill 做第二轮业务分析并迭代 Skill**：边用边优化，区分"可固化字段识别规则"与"必须留给业务确认的判断"。
4. **协作平台文档 + HTML 看板**：先写协作平台文档做协同沉淀，再用 HTML 看板做可视化原型；敏感操作必须人工确认。
5. **多 Agent 使用**：数据分析 / PPT 专家 / 知识库管理员 / 调度者分工；用 `@Agent` 切换；可建"调度者 Agent"维护 `agents-index.md` 索引，按任务类型选派角色。
6. **浏览器自动化 + Subagent**：拆任务给数据抓取 / 清洗 / 主题分析 / 建议生成；必须标注来源链接、采集时间、口径限制；**数据不足时明确说明，不编造**。
7. **档案 + 记忆 + 定时任务**：一次性分析变成长期跟踪——档案做长期沉淀，记忆固化跟踪口径，定时任务按时间触发。
8. **知识库整理**：分类目录 + 双份归档（原文 + 摘要） + YAML Frontmatter + 渐进式读取（先元数据，再全文）。

## 7. 界面功能速览

- **会话区**：附件上传、Agent/模型/思考强度切换、上下文压缩、问题队列与"追加"补上下文、`/btw` 临时问话、`/reset` 重置上下文。
- **顶栏**：修改标题、置顶、分享导出 PNG、刷新。
- **右侧时间轴 / 左侧历史**：节点定位、按时间/Agent 标签筛选、搜索跨会话跳转、梦境会话显示/隐藏、批量操作。
- **功能版**：工作版、Agent 管理与上下文/技能/工具配置、技能市场下载与发布、定时任务、工作空间文件浏览、梦境日记/高级整理。
- **设置**：账号用量、协作平台授权、外观/字体/桌面宠物、网关、储存清理、快捷键、Token 消耗、版本更新。

## 8. 使用技巧

- 做错了就明确告诉 AI，让它写入长期记忆，下次避免。
- 记忆越清晰，输出越稳定；记忆越混乱，越容易跑偏。
- 定期检查并删除错误或过时记忆。
- 生成产物（协作平台文档 / HTML 看板 / PPT 大纲）是中间素材，便于后续产品化与复核。
- 公开仓库内容需注意来源、许可证、网络与企业合规要求；不把内部敏感数据交给未经审核的外部角色模板处理。
