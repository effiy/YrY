# 容量与成本（FinOps）摘要

> 本摘要说明容量规划与成本治理方法；空白可填表单见 [capacity-and-cost-template.md](./capacity-and-cost-template.md)。

## 1. 是什么

把资源利用率、扩容阈值、单次请求成本、季度优化项放到一张表上定期审查。FinOps（Cloud Financial Operations）= 财务 + 工程协作，目标是：

- 不会因为省钱牺牲稳定性
- 不会因为稳定浪费预算
- 让每个团队知道自己的真实成本

## 2. 为什么做

云端成本失控很常见：

- 服务开了不关，月底账单吓人
- 一个服务的浪费拖累整体预算
- 没人知道某团队花了多少
- AI 推理成本随用量线性涨，没规划就失控

FinOps 把"账单"变成"可管理的工程指标"。

## 3. 容量规划

### 3.1 基线

- 当前 QPS / TPS（峰值 / 均值）
- 单请求算力消耗（CPU / GPU）
- 资源利用率（CPU、内存、GPU、网络）
- 瓶颈资源（CPU bound / IO bound / GPU bound）

### 3.2 扩容阈值

| 阈值 | 触发 | 动作 |
|---|---|---|
| CPU > 70% | 5 分钟 | 自动扩容 |
| GPU > 80% | 5 分钟 | 扩容或限流 |
| 队列 > 100 | 持续 | 扩容 |
| 延迟 p99 > SLA | 任何 | 扩容 + 告警 |

### 3.3 容量评估方法

- 历史数据 + 增长趋势
- 大促 / 节假日峰值倍数
- 单压测（关键场景跑极限）
- 容量规划 = 峰值 × 安全系数（1.5-2）

### 3.4 收缩机制

- 自动缩容（连续 30 分钟低负载）
- 夜间降配（业务低峰）
- Spot 实例（无状态服务）

## 4. 成本结构

### 4.1 直接成本

| 类别 | 典型 | 占比 |
|---|---|---|
| GPU 推理 | LLM 服务 | 40-60% |
| CPU / 内存 | 应用服务 | 10-20% |
| 存储 | 数据库 / 对象存储 | 10-15% |
| 网络 | 流量 / NAT | 5-10% |
| 第三方 API | OpenAI / Cohere | 10-30% |
| 许可 | 商业组件 | 视情况 |

### 4.2 单次请求成本

```
单次任务成本 = (GPU 成本 + API 成本 + 存储分摊 + 网络分摊) / 任务数
```

监控此数比"月总成本"更可操作——能看出效率改善。

### 4.3 隐性成本

- 监控 / 日志存储
- 备份与灾备
- 测试环境
- 数据迁移
- 厂商退出 / 迁移

## 5. 季度优化项

每季度找 3-5 个优化点：

### 5.1 资源利用率

- 闲置资源（夜间无负载）
- 过度配置（CPU 利用率 < 10%）
- 共享实例（多服务共用）

### 5.2 推理优化

- 用便宜模型做首轮
- 缓存命中（prefix cache / 全文 cache）
- Speculative decoding
- 模型量化
- 推理服务拆池（长上下文单独池）

### 5.3 第三方 API

- 用量监控（异常增长告警）
- 替换为自部署（成本拐点判断）
- 多供应商比价

### 5.4 存储优化

- 冷热分离（热存 SSD / 冷存对象存储）
- 数据生命周期（保留期、自动归档）
- 去重

## 6. 评估指标

| 指标 | 含义 | 阈值 |
|---|---|---|
| CPU 利用率 | 实际占用 | 50-80% 健康 |
| GPU 利用率 | 实际占用 | 60-90% 健康 |
| 单任务成本 | 成本 / 任务数 | 季度环比下降 |
| 缓存命中率 | prefix cache | > 50% |
| 预算执行率 | 实际 / 预算 | 90-100% |
| 异常增长告警 | 月环比 | > 20% 触发 |

## 7. 落地节奏

| 时点 | 事项 |
|---|---|
| 每日 | 监控仪表盘自动出 |
| 每周 | 团队级成本 review |
| 每月 | 公司级账单分析 |
| 每季 | 容量与成本优化项 |
| 半年 | 容量规划重做 |

## 8. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 省钱牺牲稳定 | SLA 暴跌 | 必须先保 SLO |
| 只看总账单 | 不知哪里浪费 | 按团队 / 服务分账 |
| 不算单任务成本 | 效率改善无感知 | 必算单位经济 |
| 不优化推理 | LLM 成本失控 | 季度推优化项 |
| 没告警 | 月底被账单吓 | 周环比告警 |
| 闲置资源不收 | 夜间跑着不关 | 自动缩容 |

## 9. 与 AI 产品关系

AI 产品成本特征：

- 推理成本随用量线性增长（不是规模经济）
- 单任务成本决定商业可行性
- 模型价格波动大，需多供应商策略
- 缓存与优化决定单位经济
