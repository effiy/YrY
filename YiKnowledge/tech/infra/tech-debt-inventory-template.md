# 技术债务盘点模板

> 使用方法：每季度对各域技术债务做一次盘点。配套 qb-row「Tech debt inventory」一键 prompt：classify core debts by domain, assess interest, and prioritize quarterly repayment。本模板产出一张可排序的债务表 + 季度清偿优先级。复制到 `tech/infra/{季度}-tech-debt-inventory.md`。

| 字段 | 内容 |

| 盘点季度 | （示例：2026 Q3） |
| 盘点人 | （示例：架构组） |
| 参与域 | platform / middleware / business |
| 数据来源 | 代码扫描 + 架构评审 + 团队上报 |

## 3. 利息与紧急度评估口径

| 利息 | 定义 | 紧急度判定 |
|---|---|---|
| 高 | 每月阻塞 ≥ 1 次上线或造成故障 | 影响上线 / 合规 / 安全 → 🔴 高 |
| 中 | 每季度影响 1-2 次效率 | 影响效率但非阻塞 → 🟡 中 |
| 低 | 仅认知负担，可绕过 | 无影响 → 🟢 低 |
