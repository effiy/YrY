## 文件类型与命名

- `{公司英文名}-profile.md`：竞品公司档案
- `{公司英文名}-{产品名}-comparison.md`：对比分析
- `competitor-analysis-template.md`：通用模板
- `*-summary.md`：竞品动态摘要

所有文件名采用 kebab-case 英文。

## Frontmatter 模板

```yaml
---
title: 某竞品档案
tags: [竞品, 行业, 公司名]
category: industry/competitors
created: YYYY-MM-DD
updated: YYYY-MM-DD
source: <官网 / 新闻链接>
type: summary
status: stable
---
```

## 写作推荐结构（竞品公司档案）

1. 公司概况（成立、规模、地域、融资阶段）
2. 核心产品矩阵
3. 商业模式与定价
4. 渠道与生态
5. 技术栈与公开能力
6. 与本产品对标维度（功能覆盖差异、价位差异、用户差异）
7. 近期动态与发布事件
8. 我方应对策略
