# 行业报告 / Reports

收录第三方行业报告摘要与原文存档。

## 收录范围

- 咨询公司 / 投行 / 研究机构发布的行业报告
- 政府与监管机构白皮书
- 行业联盟与媒体年度盘点
- 厂商技术白皮书

## 文件类型与命名

- `{年份}-{主题}-summary.md`：报告摘要
- `{年份}-{主题}-original.md`：原文存档（PDF / MD）
- 命名采用英文 kebab-case，年份用四位数字

## Frontmatter 模板

```yaml
---
title: 2026 AI 行业趋势报告摘要
tags: [行业报告, AI, 2026]
category: industry/reports
created: YYYY-MM-DD
updated: YYYY-MM-DD
source: <原文链接>
type: summary
status: stable
last_verified: YYYY-MM-DD
---
```

## 写作推荐结构（摘要）

1. 报告基本信息（机构、作者、发布日期、页数）
2. 核心观点（3-5 条）
3. 关键数据（市场规模、增长率、渗透率）
4. 行业判断与预测
5. 对本产品 / 业务的启示
6. 引用原文金句
