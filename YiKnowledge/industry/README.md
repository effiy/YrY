## 归档原则

参见 [`../MEMORY.md`](../MEMORY.md) 的「双份归档原则」与「YAML 元数据规范」。

行业知识时效性强，所有摘要必须包含 `updated` 与 `last_verified` 字段，半年以上未核实的条目标注 `status: deprecated`。
