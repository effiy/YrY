<p class="wp-block-paragraph">Opening a new AI tool can feel a little like staring at a blank page. You know you want help with something, but figuring out exactly what to ask can be its own task.</p>



<p class="wp-block-paragraph">The good news is that you don&rsquo;t need to write the perfect prompt to get started. A prompt is simply a description of what you want to accomplish. Start with what you know, give Copilot some context, and refine the request as you go.</p>



<p class="wp-block-paragraph">Let&rsquo;s walk through what it looks like to start your first task in the <a href="https://github.com/features/ai/github-app?utm_source=blog-copilot-app-ep2&amp;utm_medium=blog&amp;utm_campaign=copilot-app-for-beginners-series">GitHub Copilot app</a>.</p>



<h2 class="wp-block-heading" id="h-start-with-the-right-context">Start with the right context</h2>



<p class="wp-block-paragraph">Before you can ask Copilot to make a change, it needs something to work on. Agent sessions can be connected to a GitHub repository or a folder on your local machine, giving Copilot access to the code and files it needs for the task.</p>



<p class="wp-block-paragraph">From the GitHub Copilot app home screen, you can select a project you&rsquo;ve worked with before or add a new one.</p>



<p class="wp-block-paragraph">If you&rsquo;re working on code that&rsquo;s only on your computer, you can add a local folder instead. Either way, connecting a project gives the session the context it needs to work with your codebase.</p>



<p class="wp-block-paragraph">Once your project is selected, you&rsquo;re ready to write your first prompt.</p>



<h2 class="wp-block-heading" id="h-describe-what-you-want-in-plain-english">Describe what you want in plain English</h2>



<p class="wp-block-paragraph">You don&rsquo;t need to learn a special syntax or figure out the perfect way to phrase your request. Start by describing the change you want to make.</p>



<p class="wp-block-paragraph">For example: <code>Add a most-funded sort option to the games list.</code></p>



<p class="wp-block-paragraph">That&rsquo;s enough to get started. Copilot can examine the project, find the relevant parts of the codebase, and work on the requested change.</p>



<p class="wp-block-paragraph">If the first attempt isn&rsquo;t quite what you had in mind, you can provide additional details or ask for changes. Prompting is an iterative process, so you don&rsquo;t have to anticipate every detail before you begin.</p>



<p class="wp-block-paragraph">The best prompt is often the one that gets you moving.</p>



<h2 class="wp-block-heading" id="h-choose-the-right-model-when-you-need-it">Choose the right model when you need it</h2>



<p class="wp-block-paragraph">The GitHub Copilot app also lets you choose which AI model handles your task. Different models have different strengths, and some are better suited to complex reasoning while others can handle simpler tasks more quickly.</p>



<p class="wp-block-paragraph">If you&rsquo;re just getting started, the default model is a good place to begin. You don&rsquo;t need to understand every difference between the available models before you can use the app.</p>



<p class="wp-block-paragraph">As you work, you can switch models when a task requires more complex reasoning or when the first approach isn&rsquo;t giving you the results you need. Think of the model selector as another tool you can reach for when the task calls for it, rather than something you need to configure before every session.</p>



<h2 class="wp-block-heading" id="h-use-whatever-input-feels-natural">Use whatever input feels natural</h2>



<p class="wp-block-paragraph">Typing isn&rsquo;t the only way to write a prompt. The GitHub Copilot app includes built-in voice input, which can be useful when you&rsquo;re thinking through a problem out loud or have a longer request to describe.</p>



<p class="wp-block-paragraph">Your speech is converted into text in the prompt box, where you can review and edit it before sending it. That means you can think out loud without immediately committing to the first version of your request.</p>



<p class="wp-block-paragraph">Sometimes it&rsquo;s easier to explain what you want than to type it out. Voice input gives you another way to get that idea into the session.</p>



<h2 class="wp-block-heading" id="h-customize-how-the-work-runs">Customize how the work runs</h2>



<p class="wp-block-paragraph">You can also change how your session handles the work. From the session title, you can select a different agent or enable remote control for the session.</p>



<p class="wp-block-paragraph">Different agents can be configured for different types of work, so you can choose the one that best fits the task you&rsquo;re working on.</p>



<p class="wp-block-paragraph">Remote sessions give you another kind of flexibility. Instead of running the work only on your local machine, you can access the same session from the web. You can start a task, close your laptop, and return to the session later from another device without losing your place.</p>



<p class="wp-block-paragraph">These options aren&rsquo;t things you need to configure before your first prompt. They&rsquo;re there when you need more control over how a task is handled.</p>



<h2 class="wp-block-heading" id="start-small-and-iterate">Start small and iterate</h2>



<p class="wp-block-paragraph">Your first prompt doesn&rsquo;t need to be perfect. Start with a small change you&rsquo;d like to make in a project you already know, describe what you want in plain language, and see what happens.</p>



<p class="wp-block-paragraph">From there, you can refine the request, try a different model, or adjust how the session runs. The more you use the app, the more natural these choices become.</p>



<p class="wp-block-paragraph">The important part is getting started. Pick a project, give Copilot a task, and see where it takes you.</p>
