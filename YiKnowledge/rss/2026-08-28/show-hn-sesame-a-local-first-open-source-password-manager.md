<p>I have been working on Sesame, an open-source password manager that keeps your vault local by default. You don't need an account to create or use a vault, and the hosted service never receives the vault itself.
It's still early software and the independent security review isn't finished yet, so I am mainly interested in feedback, testing, and people looking through the code.<p>(Linux support is yet to be released on v0.1.2, but currently is in the works.)</p>
