<section class="">从人形、轮式到重载，从家庭、零售到工业，银河星脑正在走进更多身体和真实场景。</section>
<section><strong style="text-indent: 0em; font-size: 16px; color: #375474; font-family: Optima-Regular, PingFangTC-light;"><br />作者｜Li Yuan</strong><strong style="text-indent: 0em; font-size: 16px; color: #375474;"><br /></strong></section>

<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">每年走进世界机器人大会，人们最先看到的都是身体。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">有的机器人长出双腿，有的装上轮子；有的把手指做得越来越像人，有的用钢铁手臂扛起几十公斤重物。我们也因此习惯用外形给机器人分类：会跳舞的是一种，能搬箱子的是另一种，会进厨房和卧室的，又是另一种。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">今年的世界机器人大会上，这套认识开始松动。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">银河通用在分论坛发布了小型双足人形机器人 ET1。它第一次登台便跳起一段高动态舞蹈，也第一次让银河通用拥有了一副可以走路、舞动，并从人类动作中继续学习的双足身体。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">银河通用创始人兼 CTO 王鹤说，ET1 的名字承载着一种期待：成为「有智能、会学习、会思考、会成长的人形机器人」。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">但这副新身体并不是从零开始。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">几十米外的展台上，轮式双臂机器人 G1 正在做早餐、叠衣服，重载机器人 S1 在拆垛和码垛，春晚亮相的「小盖」则在与人交互。它们看起来像四种机器人，银河通用却把它们放进同一套技术叙事：不同的身体，接入同一套银河星脑。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">这并不意味着一套控制程序可以原封不动地塞进所有机器人。双足、轮式和重载本体仍然拥有各自的运动模型与控制系统。真正开始被复用的，是上层的感知、任务理解、世界建模与行动规划能力。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">机器人的身体依然不同，但今后，它认识过的世界，可以不必每次重来。</p>

<p><strong style="letter-spacing: 1px;"><strong style="letter-spacing: 0.578px; color: #000000;">一副能够学习人类动作的身体<br /></strong></strong></p>
</section>
</section>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">&nbsp;</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">一段音乐响起，ET1 在世界机器人大会的舞台上跳起街舞。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">它的身形不大，动作却并不拘谨。转身、摆臂、高抬腿、身体跟着节拍连续移动，在重心快速变化时也能保持稳定。</p>

<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">这是银河通用过去没有的机器人形态。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">此前，银河通用最为外界熟悉的是轮式双臂机器人 G1 和工业重载机器人 S1。前者借助轮式底盘进入家庭与零售，后者伸出重载双臂，在工厂承担拆垛、搬运与码垛。ET1 第一次把银河通用已经积累的具身智能能力带进小型双足人形本体。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">轮式与双足各有取舍。轮式底盘稳定、高效，适合在结构化环境中持续移动；双足更接近人的身体形态，能够适应台阶、复杂地面等为人设计的空间，同时也提供了一块更具挑战性的高动态运控试验场。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">新身体只是表层。更关键的问题是，为什么 ET1 一登台，就能做出如此连续、拟人的动作。</p>

<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">背后发挥作用的，是 AstraBrain WBC，即银河星脑体系中负责全身实时运动控制的小脑基座模型。王鹤在发布现场透露，此前公开介绍的是 AstraBrain-WBC 0.5，银河通用内部的 AstraBrain-WBC 1.0 已经在 ET1 上进行预览。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">比如，街舞演员给出新的动作，ET1 通过视觉识别并提取人的实时运动轨迹，再把动作映射到自己的身体上。这不是从预先编排的动作库里挑出一条轨迹重新播放，而是面对新的运动输入，让机器人自己的身体把它接住。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">这套模型背后，是银河通用积累的约 10 万小时人类动作数据。其中既有高精度动作捕捉，也有从互联网人类视频中重定向而来的动作数据。模型先从大量人类运动中学习身体如何移动，再把新的视觉输入翻译成 ET1 能够执行的全身动作。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">据银河通用介绍，ET1 也在继续学习打网球等复杂运动。打网球的意义不只在于击中来球，它还要求机器人同时处理视觉判断、身体移动、挥拍时机与全身平衡。舞蹈也好，网球也好，ET1 承担的是同一项任务：把银河通用的小脑模型推向更快、更复杂的运动。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">银河通用发布的不只是又一台会跳舞的小人形机器人，而是让已经积累的运动智能进入一副新身体，并让这副身体继续接住新的动作。</p>

<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">我们咨询了银河通用的现场负责人。他表示，展台上的轮式、重载和双足机器人全部基于同一套具身基础大模型，「轮式的、重载的，还有双足的，都可以用」。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">为什么这件事重要？</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">因为具身智能长期面对的一道难题，是机器人每换一副身体，过去积累的数据和能力就很难继续使用。双足、轮式、两指夹爪、多指灵巧手拥有不同的机械结构和动作空间。如果模型学到的始终是「某台机器人的第几个关节应该转多少度」，硬件一换，训练往往就要大面积重来。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">银河通用今年推出的通用大脑 AstraBrain WAM 0.5，试图把动作从具体关节里抽出来，重新放回物理世界。模型要学习的，不只是机械臂怎样转动，而是手怎样靠近一个物体，怎样抓住、推拉、翻转、插入和对齐。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">这样一来，不同机器人虽然仍要用各自的身体完成动作，动作作用于世界的基本规律却可以被复用。抓住杯子的夹爪可以不同，但杯子如何受力、怎样被拿起，不会因为机器人换了一副身体就完全改变。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">为了建立这层通用能力，银河通用在预训练阶段引入视频、图像、仿真、遥操作和机器人自主运行等多种数据。基础模型先从不同来源的数据中学习物理世界与动作之间的关系，再用少量后训练数据适配新的本体和场景。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">「以前做任何一个场景，都要针对场景做非常详细的专项训练。」该负责人表示，「现在稍微收一些数据，做一些兼容就可以了。」</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">展台展示的，正是这套通用能力落进不同身体后的结果。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">家庭展区里，G1 把同一套操作能力放进了不同任务。它既要区分积木、钥匙串、玩偶等物体的物理属性，也要进行高难度的柔性物体操作&mdash;&mdash;处理容易变形的衣物，连续完成叠衣、洗衣、穿衣架和晾晒。早餐工位则加入动态干扰：面包、水壶、杯子或盘子被移动后，机器人需要重新识别目标、调整路径，把任务继续做完。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">展台另一侧，S1 用重载本体完成物料的拆垛、搬运和码垛。按照现场讲解，箱体接触垛面后，机器人还会根据受力情况调整姿态，直至稳定归位。</p>

<p><strong style="letter-spacing: 1px;"><strong style="letter-spacing: 0.578px; color: #000000;">机器人走到这一步，意味着什么<br /></strong></strong></p>
</section>
</section>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">&nbsp;</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">不同身体只是基础，具身大脑最关键的还是要完成任务。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">展区内核心位置，我们看到 G1 正在完成一项极其长程的早餐制作任务&mdash;&mdash;烤面包、倒饮料，双臂协同，全程流畅无断点。这套流程涉及多物品操作、多步骤规划，是对机器人长程任务执行能力的极限施压。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">而真正的考验不止于「长」。整条任务链的每一个环节都可以被随机干扰：面包的摆放位置可以被挪动，倒水的壶可以被移走，杯子可以变换位置，放面包的盘子也可以被随意移动。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">这意味着，机器人不再只是执行一条预设轨迹，而要边感知、边理解、边决策、边执行，在环境变化后自己把任务接下去。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">ET1 的另一段演示把这件事又往前推了一步。人类没有逐步告诉它该去哪里、对谁说什么，只给出一个目标：「帮她多卖点。」随后，ET1 自主调用移动、多模态交互和语言能力，制定方案，再走到顾客面前推销零食。</p>

<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">在银河通用的技术框架里，AstraBrain 由大脑、脑桥和小脑组成：WAM 作为大脑模型，承担感知、理解与行动决策；WBC 作为小脑模型，负责全身实时运动控制；脑桥则连接两者，让上层意图落到身体执行。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">这套框架解决的是认知决策与身体行动如何连成闭环。ET1 的演示则进一步呈现了面向完整目标的任务能力：接到「帮她多卖点」的要求后，系统深度思考并调用多模态交互能力，制定方案并完成推销。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">当机器人已经能够在变化中完成长程任务，并围绕一个目标调动多种能力，下一道门槛就不再是「会不会做」，而是这种能力能否低成本复制到新的现场。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;"><strong style="margin-top: 0px; margin-bottom: 0px; text-align: left; color: #000000; letter-spacing: 0px; font-size: 16px; line-height: 1.6;">王鹤把</strong><strong style="margin-top: 0px; margin-bottom: 0px; text-align: left; color: #000000; letter-spacing: 0px; font-size: 16px; line-height: 1.6;">具身智能</strong><strong style="margin-top: 0px; margin-bottom: 0px; text-align: left; color: #000000; letter-spacing: 0px; font-size: 16px; line-height: 1.6;">的「</strong><strong style="margin-top: 0px; margin-bottom: 0px; text-align: left; color: #000000; letter-spacing: 0px; font-size: 16px; line-height: 1.6;">ChatGPT</strong><strong style="margin-top: 0px; margin-bottom: 0px; text-align: left; color: #000000; letter-spacing: 0px; font-size: 16px; line-height: 1.6;">时刻」放在两项能力上：机器人既要具备面对新任务的泛化能力，也要让普通客户不必成为人工智能专家，就能使用和调整模型。</strong></p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">这也是通用基模的另一层意义。模型在预训练阶段已经从人类视频、仿真和真机数据中学习物理世界的规律，进入新场景时便不必完全从头训练。银河通用正在尝试让用户通过拍摄无标注的第一视角工作视频，帮助机器人适应新的门店、货架或工位。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">机器人不仅要把事情做完，还要把已经学会的能力更低成本地带到下一个现场。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">一些能力已经开始离开展台。银河通用披露，其智慧药房解决方案已在全国数十个城市部署百家即时零售仓，银河太空舱进入 40 余个城市、落地超过 170 个点位；S1 已在宁德时代产线实现全天候常态化作业。银河通用也在开放模型、仿真、数据采集和后训练工具，让产业伙伴围绕自己的场景继续开发。</p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;"><strong style="margin-top: 0px; margin-bottom: 0px; text-align: left; color: #000000; letter-spacing: 0px; font-size: 16px; line-height: 1.6; font-family: Optima-Regular, PingFangTC-light;">因此，世界机器人大会上更值得追踪的，不只是机器人又学会了什么动作，而是一项能力能否从动作延伸成任务，从一副身体进入另一副身体，再从一次展示走进长期运行的真实现场。</strong></p>
<p style="margin: 25px 8px; text-align: justify; color: #000000; letter-spacing: 1px; font-size: 16px; line-height: 1.75;">我们以为机器人就是眼前那副身体。2026 世界机器人大会呈现的另一种可能是：身体仍然不同，但认识过的世界，不必每次重来。</p>
