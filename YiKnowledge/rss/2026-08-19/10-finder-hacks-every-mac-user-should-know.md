<h2 id="add-frequently-used-folders-to-finders-sidebar-for-instant-access">Add frequently used folders to Finder's sidebar for instant access</h2><p>The left pane in the Finder app has quite a few shortcuts. You can think of these as bookmarks that let you access various files and folders. However, you can personalize this list to fit your workflow. To start, drag any item in Finder's sidebar to reorder the list, which includes sections such as "Favorites" or "Locations." You can also drag individual items in a section to prioritize folders you access frequently. The best feature is the ability to remove stuff you don't use. To try it out, click the <strong>Finder</strong> button in the menu bar at the top of your screen, and select <strong>Settings &gt; Sidebar</strong>. Uncheck items you don't need, such as Recent Tags (a feature I never use on my Mac). You can also drag any folder to the Favorites section in the sidebar, which is a faster way to open folders you access frequently.</p><h2 id="change-finders-default-search-location-to-the-current-folder">Change Finder's default search location to the current folder</h2><div class="eloquent-imagery-image">

<p>Whenever I use the search box in Finder, it defaults to showing all the results from my Mac. I prefer to view results from the currently open folder, which takes a lot less time than going through all my files. You can make this happen by going to <strong>Finder Settings &gt; Advanced</strong> and selecting the drop-down menu under "When performing a search." Here, select <strong>Search the Current Folder</strong>. While you're at it, you can also try out the hidden advanced search mode in Finder <a href="https://lifehacker.com/your-macs-finder-has-a-hidden-advanced-search-mode-1850106810" target="_blank">to add multiple search filters</a>. This makes it easier to find a specific file in a massive, unorganized folder. After you type a query, hit the "+" button below Finder's search bar to reveal these filters.</p><h2 id="make-your-macs-trash-clean-itself-up-automatically-to-avoid-running-out-of-space">Make your Mac's Trash clean itself up automatically to avoid running out of space</h2><p>When you delete files, they're sent to the Trash on your Mac. This folder takes up storage space, which can quickly become a problem for those of us with base model MacBooks. You can solve this by automatically deleting those files after 30 days. Go to <strong>Finder Settings &gt; Advanced</strong>, and enable "Remove items from Trash after 30 days."</p><h2 id="automatically-delete-zip-files-after-expanding-an-archive-to-avoid-clutter-on-your-mac">Automatically delete zip files after expanding an archive to avoid clutter on your Mac</h2><p>When you unzip a compressed file, your Mac pastes the contents in a new folder, but it doesn't automatically delete the original archive. You can make it automatically delete these files to clean up the mess. For this, you can press <strong>Command-Space</strong>, search for <strong>Archive Utility</strong>, and open the app. Next, click the <strong>Archive Utility</strong> button in the menu bar, and head over to <strong>Settings</strong>. Click the drop-down menu next to "After expanding," and choose "move archive to Trash."</p><h2 id="use-this-plugin-to-view-folder-contents-on-your-mac-without-opening-them">Use this plugin to view folder contents on your Mac without opening them</h2><div class="eloquent-imagery-image">

<p>Quick Look is one of macOS' best features. It allows you to preview any file without actually opening it. However, this feature doesn't let you preview the <em>contents</em> of folders, which means that when you select a folder and press Spacebar, you'll only see the size of the folder and how many files it has. To fix this, you can use a plugin called <a href="https://apps.apple.com/us/app/folder-preview/id6698876601?mt=12" rel="noopener" target="_blank" title="open in a new window">Folder Preview</a> ($1.99), which does allow you to <a href="https://lifehacker.com/tech/this-free-mac-utility-adds-folder-previews-to-quick-look" target="_blank">preview the contents of folders</a>. There's a better version of the app called <a href="https://anybox.ltd/folder-preview-pro" rel="noopener" target="_blank" title="open in a new window">Folder Preview Pro</a> ($9.99), which lets you copy, paste, and even preview files from within a folder preview.</p><h2 id="use-this-shortcut-to-cut-and-paste-files-in-finder">Use this shortcut to cut and paste files in Finder</h2><p>Those who switch from Windows to Mac will immediately miss the lack of an obvious cut-and-paste workflow for files. Your Mac does ship with this feature, but it's not easy to discover. You can first copy a file by pressing <strong>Command-C</strong>, or going to the <strong>Edit</strong> menu and selecting "Copy." Next, open a different folder, and press <strong>Command-Option-V</strong> to move it, as opposed to pasting it. You may also use the Edit menu and select "Move Item Here." In case this option doesn't show up there, you can right-click an empty space in the destination folder, and hold <strong>Option</strong> to reveal "Move Item Here."</p><h2 id="use-quick-actions-to-remove-an-images-background-without-opening-it">Use Quick Actions to remove an image's background without opening it</h2><div class="eloquent-imagery-image">

<p>Finder supports unique actions for each file type, so you can perform tasks without even opening a file. For instance, you can right-click any image in Finder, and select <strong>Quick Actions &gt; Remove Background</strong>. This will create a new image file without the background present in the original. The Quick Actions menu shows multiple actions for some file types, so you should explore it to find other useful functions.</p><h2 id="show-all-filename-extensions-to-protect-your-security">Show all filename extensions to protect your security</h2><p>By default, Finder doesn't show file extensions, which means that a file name looks something like, "Lifehacker." If this is a harmless image file, there's nothing to worry about. But if it's a malicious app, you could end up with some unwanted computer trouble. To save yourself the hassle, <a href="https://lifehacker.com/the-one-thing-you-should-check-before-opening-any-app-f-1849189644" target="_blank">you can force Finder to show file extensions</a>, which will change the aforementioned file name to something like "Lifehacker.jpg." This way, you can be sure of the type of file you're opening. To set this up, go to <strong>Finder Settings &gt; Advanced</strong>, and enable "Show all filename extensions."</p><h2 id="customize-finders-toolbar-to-instantly-reveal-file-paths-and-more">Customize Finder's toolbar to instantly reveal file paths (and more)</h2><p>Finder's toolbar has a set of buttons that cover the most common functions users need, but there are more that may prove to be useful for some people. Right-click an empty space in the Finder toolbar, and click "Customize Toolbar<strong>"</strong> to reveal these options. For example, you can drag the "Path" button to the toolbar, and select <strong>Done</strong>. You can now click "Path" any time to see the full folder path of any location in Finder. Similarly, the AirDrop button lets you select files and instantly opens the AirDrop sharing menu, which otherwise takes three clicks.</p><h2 id="use-this-hidden-setting-to-change-the-background-of-finder-windows">Use this hidden setting to change the background of Finder windows</h2><p>If you're tired of the standard white or black backgrounds that Finder defaults to, you can change the background color or even replace it with a wallpaper of your choice. This feature only appears when you use the "Icons" view in Finder. To check it out, open any folder in Finder, and press <strong>Command-1</strong> (or click "View" in the menu bar, and pick "as Icons") to switch to the Icons view. Now press <strong>Command-J</strong> (or <strong>View &gt; Show View Options</strong>) to open a pop-up window. Under "Background," you can select "Color" to set a new background color, or "Picture" to add a wallpaper. Note that the wallpaper won't automatically scale to fit the window, so if you resize windows often, you'll be left with a blank white space at times.</p>
