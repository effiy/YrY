<p>IT之家 8 月 29 日消息，微软于当地时间 8 月 27 日正式向 Release Preview 通道的 Windows Insider 用户推送了 Windows 11 年度功能更新版本 26H2（Build 26300.9278），供用户在年底正式发布前进行预览测试。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/ffee7ef3-a51c-4834-a717-01c74ca6f676.png?x-bce-process=image/format,f_auto" /></p><p>IT之家附 Windows 11 改进进展如下：</p><h2>1、更新基本信息：</h2><p>本次面向 Release Preview 通道推出的 Windows 11 26H2 是微软今年的年度功能更新，将在今年晚些时候正式向公众推送。</p><p>26H2 将以启用包（eKB）的形式推送，这意味着 24H2、25H2 和 26H2 三个版本共享同一服务分支，操作系统核心相同。因此，26H2 的新功能实际上已包含在 24H2 和 25H2 中只是处于禁用状态。</p><p>对于 24H2 或 25H2 设备，26H2 升级包大小不足 500KB，安装仅需约 2 分钟和一次重启。对于仍运行 22H2 和 23H2 等较旧服务分支的设备，26H2 将作为完整功能更新推送，大小约为 6.5GB。</p><p>IT之家注：启用包是微软自 25H2 起采用的“轻量化”年度更新方式 —— 新功能通过每月累积更新逐步下发，年度版本更新仅通过一个小型启用包“激活”已存在于系统中的功能，而非替换整个操作系统。</p><h2>2、面向商业客户的更新：</h2><p>对于商业客户，Windows 11 26H2 默认启用了部分此前版本已经推出但未默认开启的功能，包括：</p><ul class=" list-paddingleft-2"><li><p>Windows 设置备份</p></li><li><p>任务栏中的特定应用操作</p></li><li><p>部分文件资源管理器增强功能</p></li></ul><p>已加入 Windows Insider 商业计划的客户，可通过 Windows 更新客户端策略和 Windows Server Update Services（WSUS）在企业内部部署并开始验证 Windows 11 26H2 ，Azure Marketplace 也将于晚些时候开放提供。若部署过程出现问题，IT 管理员可申请微软支持。</p><h2>3、更新获取方式：</h2><ul class=" list-paddingleft-2"><li><p>Release Preview 通道符合 Windows 11 硬件要求的预览体验成员，可通过进入设置 &gt; Windows 更新手动检查并下载安装本次更新；升级到 26H2 后，将继续通过 Windows 更新自动获取常规月度服务更新。</p></li><li><p>ISO 镜像文件也将于近期在 Windows Insider ISO 下载页面开放下载。</p></li></ul><p>微软再次提醒：Windows 11 24H2 家庭版和专业版将于 2026 年 10 月 13 日结束支持。企业版和教育版则享有额外一年支持期，支持至 2027 年 10 月 12 日。</p>
