<p>IT之家 8 月 30 日消息，科技媒体 Windows Latest 昨日（8 月 29 日）发布博文，报道称<strong>谷歌计划为其 AI 编程智能体工具 Antigravity 扩展支持 WSL</strong>，完善对 Windows 10、Windows 11 系统原生支持。</p><p>IT之家注：WSL 全称是 The Windows Subsystem for Linux，不需要安装双系统，可以让用户在 Windows 平台上调用 Linux 命令行、软件包与开发工具。</p><p>在已落地的产品侧，GitHub Copilot 桌面端于 8 月 26 日宣布实验性支持 WSL。用户可在“设置 → 实验性功能”中启用“WSL hosts（预览）”，连接已通过 <span class="link-text-start-with-http">wsl.exe</span> 安装的 WSL 2 发行版，并使用 Linux 绝对路径注册项目。</p><p>谷歌 Antigravity 与 DeepMind 团队的高级开发者关系工程师 Rody Davis 发布推文，表示谷歌正在为智能体开发平台 Antigravity 开发 WSL 支持，并改善其原生 Windows 使用体验。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/8f163b1e-dcf8-43e4-b2a8-a402ed192eb8.png" /></p>
