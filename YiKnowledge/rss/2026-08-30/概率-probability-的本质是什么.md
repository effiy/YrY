<p>概率已经被彻底公理化了，也就是说它的逻辑已经研究透了，但是公理化里面一定会存在一些基本概念，它没有定义，只能依赖你对世界本身的理解。</p>
<p>公理化是一种特殊的数学思维方式。它的做法是：</p>
<p>先选出几个不加定义的「原始概念」，再规定这些概念之间必须满足的几条规则（公理），整套理论的全部内容都从公理纯逻辑推出来。</p>
<p>这种思路的鼻祖是欧几里得。他在《几何原本》里没有真正定义「点」「线」——「点是没有部分的」「线是没有宽度的长度」这种话根本不算严格定义——但他给出了五条公设，规定了这些概念之间的关系。然后整本《原本》几百条几何定理，全是从这五条公设推出来的。</p>
<p>到 20 世纪初，希尔伯特把这种思路推向极致。他重新公理化了欧氏几何，明确说：</p>
<p>公理系统里的原始概念是什么，没关系。把「点、线、面」全部换成「桌子、椅子、啤酒杯」，只要它们之间满足同样的公理，全部几何定理一字不变。</p>
<p>这句话说了公理化的核心精神：公理系统只规定原始概念之间的逻辑结构，不规定它们「是什么」。「是什么」这个问题被赶到系统外面，交给经验、物理直觉、或者别的更基础的理论。</p>
<p>这种安排有两个好处：</p>
<ol><ol>
<li>逻辑彻底透明。 任何结论都能追溯到具体的公理，没有「直觉给的暗箱」。</li>
</ol></ol><ol>
<li>理论的应用范围极宽。 同一套公理可以套到不同对象上——欧氏几何既可以描述平直桌面，也可以描述某些弯曲空间的局部邻域。</li>
</ol>
<p>代价是：理论本身不告诉你原始概念在现实里指什么。 这个问题留给系统外的世界。</p>
<p>20 世纪之前，概率论一直处在「能算但不严格」的状态。古典的拉普拉斯定义（「等可能结果数之比」）在简单情形下好用，但一遇到复杂问题就翻车。</p>
<p>一个出名的反例是贝特朗悖论：「在一个圆内随机选一条弦，长度超过内接等边三角形边长的概率是多少？」用三种看似合理的「随机选法」算出来，得到三个不同答案（1/2、1/3、1/4）。原因是「随机选弦」这句话根本没有数学定义，不同的「随机」方式对应不同的概率模型。</p>
<p>这种困境一直持续到 1933 年。</p>
<p>那年，苏联数学家柯尔莫哥洛夫出版了一本薄薄的小册子《概率论的基本概念》，把整个概率论建立在三条公理上，彻底终结了这种混乱。</p>
<p>他的做法是把概率论嫁接到当时刚成熟的测度论上。一个概率模型被定义成一个三元组 (Ω, F, P)，满足三条公理：</p>
<ol><ol>
<li>非负性：对任意事件 A，P(A) ≥ 0</li>
</ol></ol><ol>
<li>归一性：P(Ω) = 1</li>
</ol><ol>
<li>可数可加性：若 A₁, A₂, … 互不相交，则 P(A₁ ∪ A₂ ∪ ⋯) = P(A₁) + P(A₂) + ⋯</li>
</ol>
<p>就这三条。剩下整个概率论的内容——条件概率、独立性、期望方差、大数定律、中心极限定理、马氏链、布朗运动、伊藤积分、随机过程——全部从这三条公理纯逻辑推出来。</p>
<p>这是一个完整、自洽、严格的公理化系统，跟欧氏几何那种「五条公设撑起整本《原本》」是同一种东西。</p>
<p>但请回想公理化的精神：这套系统只规定了 Ω、F、P 之间的逻辑关系，没规定它们「是什么」。</p>
<p>这就是公理中的基本概念</p>
<p>(Ω, F, P) 里的三个原始对象，是概率论里的「点、线、面」。</p>
<p>样本空间 Ω</p>
<p>Ω 是「所有可能结果的集合」。每个元素 ω ∈ Ω 是一种「可能发生的世界」。</p>
<ul>
<ul>
<li>掷一颗骰子：Ω = {1, 2, 3, 4, 5, 6}</li>
</ul>
</ul>
<ul>
<li>掷两颗骰子：Ω = {(i, j) : 1 ≤ i, j ≤ 6}，36 个有序对</li>
</ul>
<ul>
<ul>
<li>测量身高：Ω = (0, ∞)</li>
</ul>
</ul>
<ul>
<li>股价路径：Ω 是所有连续函数 [0, T] → ℝ 构成的空间</li>
</ul>
<p>Ω 可以是有限的、可数的、连续的，甚至是无穷维函数空间。它就是建模时你愿意考虑的「全体可能」。</p>
<p>σ- 代数 F</p>
<p>F 是 Ω 的一些子集组成的集合，这些子集被称为「事件」。</p>
<p>为什么不直接用「Ω 的所有子集」当事件？因为在连续情形下（比如 Ω = ℝ），「所有子集」太大，里面有些子集没办法一致地分配概率（这是测度论里著名的不可测集问题）。F 是个折衷：把那些「可以问发生没发生」的子集挑出来，要求它对补集和可数并封闭。</p>
<p>直觉上你可以把 F 理解成「你愿意接受提问的事件清单」。对骰子来说，{2}、{2, 4, 6}、{1, 2, 3} 都在 F 里，你可以问「掷出 2 的概率」「掷出偶数的概率」「掷出小于 4 的概率」。</p>
<p>概率测度 P</p>
<p>P 是定义在 F 上的函数，给每个事件赋一个 [0, 1] 之间的数，满足前面那三条公理。</p>
<p>P 怎么具体算？分两种：</p>
<ul>
<ul>
<li>离散情形：给每个 ω 指定一个数 p(ω)，加起来等于 1，则 P(A) = Σ_{ω ∈ A} p(ω)</li>
</ul>
</ul>
<ul>
<li>连续情形：给一个密度函数 f(x)，满足 ∫f = 1，则 P(A) = ∫_A f(x) dx</li>
</ul>
<p>但请注意，数学公理不规定 P 具体长什么样。具体的 P 是从公理系统外面输入的——靠对称性、靠物理定律、靠经验数据、靠主观信念。一颗公平骰子每面 1/6，依据是对称性，而非来自公理推导。</p>
<p>再加一层：随机变量</p>
<p>有了 (Ω, F, P)，随机变量就自然出场。</p>
<p>柯尔莫哥洛夫对它的定义看起来反直觉但极其漂亮：</p>
<p>随机变量 X 是 Ω 上的一个可测函数 X: Ω → ℝ。</p>
<p>注意，X 本身是完全确定的函数——你输入同一个 ω，它一定吐出同一个数。所谓「随机」跑哪去了？跑到「抽中哪个 ω」这一步上了。Ω 上配了概率测度 P，规定每个 ω 被抽中的概率，一旦 ω 抽出来，X(ω) 只是个普通的数。</p>
<p>举例。掷两颗骰子求和：</p>
<ul>
<ul>
<li>Ω = {(i, j)}，36 个有序对</li>
</ul>
</ul>
<ul>
<li>X((i, j)) = i + j 是个普通加法函数</li>
</ul>
<ul>
<li>P({(i, j)}) = 1/36</li>
</ul>
<p>要算「两数之和等于 7 的概率」，就是数那些满足 X(ω) = 7 的 ω 有多少个：(1,6)(2,5)(3,4)(4,3)(5,2)(6,1)，共 6 个，所以 P(X = 7) = 6/36 = 1/6。</p>
<p>这个定义把直觉里那个神秘的「随机」彻底数学化了：世界上没有「随机的数」，只有一个确定的函数 + 一个概率测度。随机性整个打包进了 P，函数那一侧全是确定运算。后面所有东西——期望、方差、独立性、收敛性——都可以用这套语言重写。比如期望就是个普通积分：</p>
<p>E[X] = ∫_Ω X(ω) dP(ω)</p>
<p>那么概率的本质是什么？</p>
<p>数学层面，概率是一个公理化系统：(Ω, F, P) 三元组加上柯尔莫哥洛夫三条公理。所有概率论的结论都从这里推出来，干净、严格、毫无含糊。</p>
<p>但按公理化的精神，Ω、F、P 在现实里「是什么」，被留在了系统外面。这给了不同学派可乘之机，各自给出不同的解释：</p>
<ul>
<ul>
<li>频率派：P(A) 是 A 在无穷次重复试验中的极限频率</li>
</ul>
</ul>
<ul>
<li>贝叶斯派：P(A) 是理性主体对 A 的信念程度</li>
</ul>
<ul>
<ul>
<li>倾向性解释（波普尔）：P(A) 是物理系统产生 A 的客观倾向</li>
</ul>
</ul>
<ul>
<li>古典解释（拉普拉斯）：等可能结果之比</li>
</ul>
<p>到现在这几派都还有人坚持。同一个公式 P(A) = 0.3，物理学家、统计学家、贝叶斯派、赌徒嘴里指的可能是完全不同的东西。但他们用的都是同一套公理，证的都是同样的定理。哲学层面打成一团，数学层面照常运转。</p>
<p>所以概率的本质有两层：</p>
<ul>
<ul>
<li>内层是清晰的公理化数学（柯尔莫哥洛夫公理 + 测度论），规定不确定性必须遵守的逻辑规则</li>
</ul>
</ul>
<ul>
<li>外层是对原始概念的解释和建模，把数学跟现实连接起来</li>
</ul>
<p>内层人类已经搞定了，外层解释有很多，它依赖于你怎么看待这个世界。</p>
