display: block; margin: 0 auto;" width="466" /><p>此后，第72分钟，沃尔特马德头球助攻维萨禁区侧钩破门，将比分改写为2比0，帮助客队锁定比赛胜利。</p><p>赛后，热刺主帅德泽尔比在接受采访时表示，他们在丢球前是表现更好的一方，“我对比赛结果感到失望。我为球迷感到抱歉，也为球员们感到抱歉。在我们丢掉第一个球之前，我认为纽卡斯尔联踢得不错，但我觉得我们的表现更好，我们创造了更多进球机会，也有更多射正。其实在第一个丢球之前，我们本可以踢得更好，但在防守阶段，我们的站位距离出现了问题，我们没能与前锋和后卫之间保持正确的联系。”</p><p>此外，他也表示，这场失利让球员们很沮丧，“非常沮丧，也非常失望。但在那种时刻，我们必须做出反应。我们必须作为个人做出反应，同时也作为团队做出反应。正如我所说，我为今天的结果感到抱歉，因为这样的结果很难接受。但我没有任何怀疑。”</p><p>热刺今夏“烧了”超过3.5亿欧元用于引援，全欧范围内仅次于切尔西，但新赛季两轮全败，得失球0比5，“标王”托纳利迟迟没有进入状态。打完两轮仍没有进球的球队，只有热刺和考文垂。</p><p>值得一提的是，本场比赛打入第一球的埃兰加，在进球后模仿了亨利的庆祝进球动作，他在赛后接受采访时表示：“我一直都说（亨利）是我最喜欢的球员，所以我知道如果我今天进球，这个庆祝动作一定会出现。”</p><img alt="" class="img_default" height="1673" src="https://imgpai.thepaper.cn/newpai/image/1788048842811_QbNQRA_1788048955384.jpg?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="2500" /><p><strong>利物浦2比2森林，新赛季遭遇二连平</strong></p><p>北京时间8月29日晚，2026-2027赛季英超联赛第2轮继续进行，坐镇安菲尔德球场的利物浦在两度落后的情况下，两度追平比分，最终以2比2和诺丁汉森林握手言和。两轮过后，他们暂列第11位。</p><p>回顾本场比赛，第24分钟，施拉格尔回做，怀特分球，恩多耶禁区左肋低射远角破门，诺丁汉森林反客为主取得1比0的领先。易边再战，第60分钟，利物浦扳平比分，加克波禁区右侧传中，伊萨克后点推射空门入网，这也是他本赛季打进的第一个进球。</p><img alt="" class="img_default" height="200" src="https://imgpai.thepaper.cn/newpai/image/1788051808011_b2cYN3_1788051828902.gif?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="400" /><p>利物浦追平比分之后，诺丁汉森林又展开攻势，第70分钟，诺丁汉森林再次超出比分，怀特主罚点球命中，他们再度反超利物浦。第82分钟，维尔茨直传，穆尼奥斯禁区右肋转身爆射破门，利物浦再度将比分追平。值得一提的是，穆尼奥斯斩获了他在利物浦生涯的处子球。最终，双方以2比2战平。</p><p>赛后，利物浦新帅伊劳拉表示，球队在上半场的低迷状态是输球的关键因素，“上半场我们表现得很差。下半场我们的发挥提升了很多，两次从落后追平，但我认为正是上半场的表现让我们最终没能赢下比赛。”</p><p>此外，在这位利物浦新帅看来，球队没有给对手在传球方面施加压力，也是非常令人失望的表现，“两个丢球都来自界外球，我们防得不够好。整体感觉就是防守端太被动。”</p><p>不过，除了批评球队的表现，伊劳拉也表达了对本场裁判团队的不满，特别是那个点球，“关于点球，那次对抗发生时，实际上进攻已经结束了。而且那并不是一次激烈的接触。然后就是我们的换人被推迟，我们不得不等了大约3分钟。换人牌出了问题，我不知道是不是坏了，但我们确实希望在（诺丁汉第二粒）进球前的两三次死球时就完成换人。（只拿到平局）不只是这个原因，但所有因素叠加都会产生影响。”</p><img alt="" class="img_default" height="1667" src="https://imgpai.thepaper.cn/newpai/image/1788048880020_WFtYSr_1788048967194.jpg?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="400" /><p>回顾本场比赛，第5分钟，马竞就完成闪击破门，新加盟球队的李刚仁送出助攻，巴埃纳将球打进，帮助马竞早早取得领先。</p><img alt="" class="img_default" height="223" src="https://imgpai.thepaper.cn/newpai/image/1788051875225_62Z84Z_1788051921058.gif?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="400" /><p>第26分钟，巴里奥斯助攻卢克曼扩大比分，马竞2比0领先对手。</p><img alt="" class="img_default" height="223" src="https://imgpai.thepaper.cn/newpai/image/1788051884417_tdYkTx_1788051931198.gif?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="400" /><p>第33分钟，略伦特助攻巴埃纳，后者远射破门，完成梅开二度，而马竞则是以3比0领先结束上半场。</p><img alt="" class="img_default" height="223" src="https://imgpai.thepaper.cn/newpai/image/1788051950009_j2mHa6_1788051957602.gif?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="400" /><p>易边再战，塞维利亚做出调整，逐渐找回一些状态，第66分钟，谢拉凌空扫射破门得分，帮助塞维利亚扳回一球。而3比1的比分也被保持到了终场哨响。</p><p>“我们知道我们的目标是什么，也知道哪些是需要重点准备的关键比赛。没有中锋不代表我们不进攻，我们前两场比赛进了4球，我很满意我们对这场比赛的理解。”赛后，马竞主帅西蒙尼出席新闻发布会，肯定了球队的表现，“我们看懂了要从哪里给对手制造伤害，我们冷静地做出最佳选择，通过团队配合放大了个人能力。”</p><p>除了表扬团队合作，西蒙尼也提到了梅开二度的巴埃纳，“现在确实很有威胁，上赛季初他的状态也很好，无论把他放在哪个位置，他都能很好地完成任务。世界杯给他的信心和情绪带来了积极作用，我跟他说，希望这能进一步激发他的潜力，因为他是一名能改变比赛的球员，我们认为他具备这种水平。这场比赛他证明了这点，我们会继续以这种标准要求他。”</p><img alt="" class="img_default" height="667" src="https://imgpai.thepaper.cn/newpai/image/1788048891894_RJjp2A_1788048978221.jpg?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="1000" /><p><strong>山东泰山逆转取胜申花，成都蓉城下一轮迎“冠军点”</strong></p><p>北京时间8月29日，2026赛季中超联赛第25轮战罢。山东泰山在客场以3比2逆转战胜上海申花，大连英博在主场与北京国安1比1战平。“领头羊”成都蓉城以2比1力克辽宁铁人，下一轮若能够在客场取胜，将提前锁定本赛季中超联赛冠军。</p><p>据新华社报道，山东泰山队开球后经过两脚传球，克雷桑送出过顶长传，买乌郎机敏插上挑射，开场仅10秒便完成破门。第41分钟，申花队的高天意右路传中，拉唐中路包抄，在无人盯防的情况下破门，将比分扳为1比1平。上半场补时阶段，高天意再次送出助攻，阿苏埃兜射远角破门，申花队2比1领先泰山队。</p><p>易边再战，第79分钟，克雷桑主罚点球命中，帮助泰山队将比分扳平。第83分钟，李源一送出直塞，李小恒拿到球后推射破门，最终山东泰山在客场取胜。</p><p>另一场比赛中，同积36分的大连英博与北京国安相遇。比赛一开始，双方攻防节奏就很快，身体接触和拼抢激烈。第43分钟，茹子楠右路下底传中，张玉宁头球破门，国安队率先打破场上僵局。下半场刚开始不久，德尔加多在大禁区外轰出一记“世界波”，帮助大连队扳平比分。比赛临近结束时，双方爆发较大规模冲突，部分替补球员和教练组成员冲进场内，大连队助理教练李钢和国安队已被换下的外援达万吃到红牌。</p><p>此外，凭借费利佩和席尔瓦的进球，“领头羊”成都蓉城在主场以2比1力克辽宁铁人，拿到关键三分。他们如果在下一轮比赛中客场击败河南队，将提前夺得本赛季中超冠军。但核心费利佩因累积黄牌下轮停赛，球队进攻端面临考验。</p><p>本轮其他比赛中，天津津门虎以1比1战平青岛西海岸，河南队同样以1比1与重庆铜梁龙握手言和；上海海港1比0战胜深圳新鹏城，浙江队6比0大胜云南玉昆，武汉三镇5比1大胜青岛海牛。</p><img alt="" class="img_default" height="1687" src="https://imgpai.thepaper.cn/newpai/image/1788048926268_TjWa6E_1788048989739.jpg?x-oss-process=image/resize,w_1024" style="height: auto; display: block; margin: 0 auto;" width="2500" /><p><strong>周鹏回归广东宏远，一年合约开启生涯第21赛季</strong></p><p>北京时间8月29日，广东宏远篮球俱乐部官方宣布，曾为俱乐部效力十六个赛季的老将周鹏，将回归俱乐部并签约一年。下个赛季，他将重新披上熟悉的11号战袍。</p><p>广东男篮在公告中这样写道：“惜别四载，周鹏即将正式回归母队！经双方友好沟通并达成共识，完成一年球员合同的签订。待注册材料递交CBA公司并完成审核、公示后，他将再度披上熟悉的华南虎11号战袍，回到梦开始的地方征战新赛季CBA联赛。”</p><p>2004年，周鹏加入宏远青训梯队，2006-2007赛季升入一队。在此前为宏远效力的十六个赛季中，他八次夺得CBA总冠军，荣膺2020-2021赛季常规赛最佳防守球员、入选最佳阵容二阵。</p><p>赛场之上，他以强硬的防守、均衡的进攻能力、果敢的出手成为球队的中坚力量；赛场之外，他严于律己、恪守职业精神，更作为队长扛起球队文化与铁血精神传承的责任。国家队层面，他长期入选中国男篮，曾任国家队队长，多次征战奥运会、亚运会、亚锦赛等国际大赛。</p><p>2022年，周鹏加入深圳男篮，关键场次屡屡挺身而出，用丰富的赛场经验贡献力量。2025年，他作为广东男篮的一员帮助球队第三次获得全运会金牌。</p><p>广东男篮在公告的最后也提到，希望周鹏能够做好“传帮带”，像导师一样将经验分享给年轻人，“期待他在职业生涯的第21个赛季，继续在赛场上释放光与热，通过自身经验与实力加持球队锋线，发挥老将传帮带作用，助力年轻球员不断成长，并肩作战、共赴新程！”</p>
