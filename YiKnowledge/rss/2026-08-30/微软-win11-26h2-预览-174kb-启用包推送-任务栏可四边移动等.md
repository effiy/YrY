<p>IT之家 8 月 30 日消息，科技媒体 Windows Latest 昨日（8 月 29 日）发布博文，报道称微软已邀请 Release Preview 通道用户，<strong>测试 Windows 11 26H2 更新，首个版本号为 26300.9278。</strong></p><h2>一、更新方式</h2><p>Windows 11 26H2 通过启用包（enablement package）方式推送，体积约 174KB，与 24H2、25H2 共用同一服务分支，用户若从 23H2 升级，仍需下载接近 6.5GB 的完整系统更新。</p><p>Windows 11 26H2、25H2 和 24H2 功能更新均基于 Germanium 系列分支，微软此前已通过每月累积更新方式，提前向设备推送相关功能，只是默认处于关闭状态。</p><p style="text-align: center;"><img alt="Graphical representation of the source code branches for Windows 11" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/6/17ca251a-f8f8-49f4-8524-5b5618c3609b.png?x-bce-process=image/format,f_auto/auto-orient,o_1" /></p><figcaption>Windows 11 源代码分支的图形化表示</figcaption><p style="text-align: center;"><img alt="How to update from one version of Windows to another depends on their branches" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/6/0a0630ec-3d0a-423f-adac-af34153dc9a1.png?x-bce-process=image/format,f_auto/auto-orient,o_1" /></p><figcaption>Windows 11 版本跃迁情况，图源：微软</figcaption><p>版本变更方面，Windows 11 26H2 将启用 26300 前缀，首个版本为 26300.9278：</p><ul class="medium-size list-paddingleft-2"><li><p>Windows 11 24H2：Build 版本前缀为 26100</p></li><li><p>Windows 11 25H2：Build 版本前缀为 26200</p></li><li><p>Windows 11 26H2：Build 版本前缀为 26300</p></li></ul><p>在服务周期方面，Windows 11 24H2 家庭版、专业版将于 2026 年 10 月 13 日结束更新，企业版和教育版则支持至 2027 年 10 月 12 日。</p><p>而 Windows 11 25H2 家庭版及专业版支持至 2027 年 10 月 12 日，企业版和教育版支持至 2028 年 10 月 10 日。微软的年度功能更新通常为个人版提供 24 个月、企业和教育版提供 36 个月支持。</p><h2>二、更新内容</h2><h3>2.1、任务栏</h3><p>本次更新为了让用户更好地利用屏幕空间，为用户提供了更多自定义任务栏的方法，用户可以选择任务栏显示在屏幕底部、顶部、左侧或右侧。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/ff018e06-a221-4d7a-8a70-abc8caf404b4.jpg?x-bce-process=image/format,f_auto" /></p><p>搜索框和较小的任务栏目前仅支持顶部和底部位置。要更改任务栏的位置，请转到“设置”&gt;“个性化”&gt;“任务栏”&gt;“任务栏行为”&gt;“任务栏位置”。</p><p style="text-align: center;"><img alt="Taskbar position adjustment in Windows 11" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/a019ef5d-95ce-4527-bec8-9a61407adca5.jpg?x-bce-process=image/format,f_auto" /></p><p style="text-align: center;"><img alt="taskbar in top position" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/4394dc7f-bfcb-4d65-ad6f-4aad48d56be6.jpg?x-bce-process=image/format,f_auto" /></p><p style="text-align: center;"><img alt="New option to make Taskbar in Windows 11 smaller" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/1bd17e30-32dd-4419-9b72-89f802eacba4.gif" /></p><h3>2.2、开始菜单</h3><p>Windows 11 KB5120998 新增开始菜单尺寸选项。默认情况下，开始菜单会根据屏幕分辨率自动调整，用户也可以在“设置”&gt;“个性化”&gt;“开始”中选择“小”或“大”。</p><p>更新还允许用户移除“推荐 / 最近”内容，仅保留已固定应用；也可以移除“已固定”区域，只显示“所有应用”列表。</p><p style="text-align: center;"><img alt="New Windows 11 Start menu is almost twice the size of old Windows 11 Start menu" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/a5715c2b-9a70-40d0-b1d3-884c9c7e2daa.jpg?x-bce-process=image/format,f_auto" /></p><p>此前关闭开始菜单中的“推荐”内容时，文件资源管理器的“最近”项目和任务栏右键跳转列表也会受到影响。此次更新将这些设置分离，关闭开始菜单中的“最近 / 推荐”内容后，不会再影响其他区域。</p><p style="text-align: center;"><img alt="Start menu size toggle" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/5193116e-be32-4f8d-b78c-f7e5d39bdf10.png?x-bce-process=image/format,f_auto" /></p><p style="text-align: center;"><img alt="Start menu with just pinned apps" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/783aef9e-9c57-4816-b3be-9d1b689eab95.png?x-bce-process=image/format,f_auto" /></p><h3>2.3、Windows 搜索可关闭 Bing 和 Microsoft Store 结果</h3><p>KB5120998 允许用户关闭 Bing 和 Microsoft Store 搜索结果。关闭后，Windows 搜索将只显示本地内容，包括文件、图片和 Windows 应用，也会优先显示 Windows 设置。</p><p style="text-align: center;"><img alt="Search shows Windows Settings instead of web results" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/48cbe4af-382d-4094-a7fe-7bdd2bba1e7c.png?x-bce-process=image/format,f_auto" /></p><p style="text-align: center;"><img alt="Ability to turn off web searches in Windows 11" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/a96d226d-22e0-4b8a-ae2f-7faa5910d793.jpg?x-bce-process=image/format,f_auto" /></p><p>微软表示，Windows 搜索还会改进结果呈现，帮助用户更快找到目标内容，让结果更易浏览。相关选项位于“设置”&gt;“隐私和安全”&gt;“搜索”。</p><p style="text-align: center;"><img alt="Cleaner Search in Windows 11" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/c95dfee2-10b9-436a-bc26-b7c9c22f9601.jpg?x-bce-process=image/format,f_auto" /></p><h3>2.4、彻底移除 WMIC</h3><p>WMIC（Windows Management Instrumentation Command-line）是 Windows 的命令行管理工具，可让管理员通过脚本查询系统硬件、软件和配置状态。由于它是系统自带且由微软签名的组件，攻击者也可能借它执行侦察、识别安全产品或辅助投放恶意软件。</p><p>微软在 Windows 11 Build 26220.9202 (25H2) 和 28020.2731 (26H1) 预览版中已移除 WMIC，在 9 月累积更新中将会全面推广。</p><p style="text-align: center;"><img alt="Windows 11 WMIC is not recognized" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/57ab25f5-32c6-442f-949b-c31a92e66b3e.jpg?x-bce-process=image/format,f_auto/auto-orient,o_1" /></p><figcaption>返回了“命令无法识别”的错误</figcaption><p style="text-align: center;"><img alt="WMIC.exe in Command Prompt" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/0e3c307f-6494-4bb7-87d4-f4d0ded80bc6.jpg?x-bce-process=image/format,f_auto/auto-orient,o_1" /></p><figcaption>在 Windows 11 25H2 以及此前版本中可以正常运行</figcaption><p>该媒体在 Windows 11 预览版中测试，发现 Windows 搜索结果、系统分区文件以及命令提示符已经没有 WMIC 踪迹，用户在命令提示符运行 wmic 后，系统会返回“命令未识别”错误。用户也无法通过 Windows 11“可选功能”页面或任何终端命令重新启用 WMIC。</p><h3>2.5、时光机</h3><p>符合条件的 PC 升级 Windows 11 26H2 系统后，将会默认启用时间点还原（Point-in-Time Restore）功能。</p><p>IT之家注：该功能可视为“时光机”，在用户的 PC 遇到故障、驱动程序回滚或应用损坏等突发状况后，能够在几分钟内将设备安全地回滚到先前的正常状态。</p><p>在运行机制方面，在默认情况下，该功能会每隔 24 小时自动创建备份点，最多保留 72 小时，可还原系统版本、应用、设置及本地账户数据。</p><p style="text-align: center;"><img alt="Point-in-time restore" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/686eac22-e828-430a-acc7-97454ceec0b7.png?x-bce-process=image/format,f_auto/auto-orient,o_1" /></p><p>磁盘空间占用方面，时间点还原最高可能占用 50GB 存储空间，用户可通过“最大使用限制”滑块控制其占用容量。</p><p style="text-align: center;"><img alt="Point-in-time Restore size options" class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/6/24596f81-5c5a-4a47-83a5-e7889d620f06.gif?x-bce-process=image/format,f_png" /></p><p>Windows 11 26H2 默认启用该功能的前提是系统卷容量达到 200GB；容量低于 200GB 时，系统不会自动启用，但用户仍可手动开启。企业管理员还可通过组策略阻止该功能。</p><h3>2.6、更新 Get Started 应用</h3><p>微软计划在 Windows 11 26H2 系统中，更新“入门”（Get Started）应用程序，加入应用安装、网站固定和个性化主题等页面。</p><p>本次更新后“入门”应用在承担介绍 Windows 11 新功能 / 新特性同时，还会根据设备情况展示相关建议，帮助用户了解系统功能、安装必要应用、探索 Microsoft Store 应用商店等。</p><p>IT之家援引博文介绍，附上本次新增页面如下：</p><p style="text-align: center;"><img class="no-alt-img"
