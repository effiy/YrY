<p>IT之家 8 月 30 日消息，科技媒体 Windows Latest 今天（8 月 30 日）发布博文，报道称微软通过 Windows 安全中心，承认在 Windows 11、Windows 10 等系统中存在“病毒防护已关闭”误报问题。</p><p>微软表示部分 Windows 设备在安装 Microsoft Defender Antivirus 更新后，可能会错误跳出“病毒防护已关闭”或“Microsoft Defender Antivirus 已关闭”等安全通知。</p><p>在影响范围方面，该问题共计影响 14 个 Windows 版本，客户端涉及 8 个 Windows 版本：</p><ul class="medium-size list-paddingleft-2"><li><p>Windows 11 26H1、25H2、24H2、23H2</p></li><li><p>Windows 10 22H2、21H2、Enterprise LTSC 2019 及 Enterprise LTSC 2016</p></li></ul><p>服务器端影响 6 个版本：</p><ul class="medium-size list-paddingleft-2"><li><p>Windows Server 2025、2022、2019 和 2016</p></li><li><p>Windows Server 2012 R2、2012</p></li></ul><p>在影响方面，微软称这类通知可在 Windows 启动后出现，也可能在随后使用中随机弹出，即便用户关闭系统通知设置，提示仍可能保留或重复出现。IT之家附上相关截图如下：</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/8958beaf-d5f2-4895-8b42-e7ebd48bec41.jpg?x-bce-process=image/format,f_auto" /></p><p>修复方面，微软暂未给出临时规避方案或修复发布日期，仅表示正在开发补丁，并将在未来的 Microsoft Defender Antivirus 更新中发布更多信息。</p>
