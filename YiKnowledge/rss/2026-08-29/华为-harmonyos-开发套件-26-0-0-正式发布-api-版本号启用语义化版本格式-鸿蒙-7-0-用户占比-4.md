<p>IT之家 8 月 29 日消息，华为昨晚面向 Mate 80、Pura 80 等机型推送了 HarmonyOS 7.0.0.105 SP6 版本升级，系统包大小超 6GB（机型不同大小也有不同）。</p><p>本次更新优化了桌面显示、图库使用等场景下的使用体验。同时，更新后的 OpenHarmony 版本已经升级到最新的 7.0 Release 版本，API 版本 26.0.0。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/e354e118-5335-424a-8556-f7c7182569e8.jpg?x-bce-process=image/format,f_auto" /></p><p>与此同时，华为也面向开发者发布了 HarmonyOS 开发套件 26.0.0 版本。该版本的首个 Beta 版于 2026 年 HDC（华为开发者大会）期间推出，并于 8 月 29 日正式 Release 发布。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/14e42cf5-3954-47d8-8330-ac001578f415.jpg?x-bce-process=image/format,f_auto" /></p><p>此次版本更新对开发套件的版本号格式进行了调整。从 API 版本 26.0.0 开始，版本号统一采用语义化版本（Semantic Versioning，简称 SemVer）格式（<span class="link-text-start-with-http">X.Y.Z</span>），取代原有的 <span class="link-text-start-with-http">X.Y.Z</span> (N) 格式。</p><p>其中 X 为主版本号，包含大量新功能及重要变更，可能涉及 API 修改，需要开发者适配；Y 为次版本号，包含新功能，原则上向后兼容；Z 为修订版本号，用于问题修复和小改进，保持向后兼容。</p><p>IT之家注：此前的版本号格式中括号内的 N 表示 OpenHarmony 底座 API level。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/1209f77e-9efe-4c22-885b-08d5e70a43f2.jpg?x-bce-process=image/format,f_auto" /></p><p>据华为官方介绍，26.0.0 版本在 6.1.1 (24) 的基础上进行了多项增强。ArkUI 进一步增强了组件的材质效果，实现更好的沉浸光感效果，并新增了多个基于状态管理（V2）实现的组件。</p><p>Ability Kit 新增了基于 <span class="link-text-start-with-http">ModularObjectExtensionAbility</span> 的模块化对象，支持应用将自身功能以模块化对象形式开放给其他应用调用。</p><p>Core File Kit 支持将沙箱目录共享为系统级可见。Device Security Kit 增强了星盾引擎能力和超级隐私管控能力。</p><p>Graphics Accelerate Kit 新增预启动特性，以提升游戏应用的启动体验。Notification Kit 增强了通知管理能力和显示效果，支持以半模态方式拉起应用的通知设置界面。此外，ArkWeb 的 Chromium 内核从 132 版本升级至 144 版本。</p><p>DevEco Studio 26.0.0 Release 版本（26.0.0.821）同步更新，新增多项能力：支持开发 API 26.0.0 工程；支持按需加载模块以提升代码索引效率；新增 Code Scanner 工具，支持检查整个项目的资源泄漏问题；支持同时预览应用在 8 个典型档位断点下的 UI 效果；新增 Car 设备模拟器，支持远程控制模拟器；支持将设备投屏到 DevEco Studio 中使用；支持对应用崩溃生成的 dump 文件进行解析并展示异常堆栈。</p><p>配套信息方面，API 26.0.0、DevEco Studio 26.0.0.821 及 HarmonyOS SDK 26.0.0.105（基于 OpenHarmony SDK Ohos_sdk_public 26.0.0.105）均已发布。SDK 内置在 DevEco Studio 中，开发者安装时将自动安装配套版本。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/f056b227-1f18-4aab-9ec3-66cf4508cbc1.jpg?x-bce-process=image/format,f_auto" /></p><p>此次版本还包含一项针对所有应用的变更：系统引入了默认浏览器权限管控机制。应用需申请 <span class="link-text-start-with-http">ohos.permission.DEFAULT_WEB_BROWSER</span> 权限，方可被展示在默认浏览器备选列表中并设置为默认浏览器。该权限面向浏览器类应用，需满足浏览器品类标准并通过安全、隐私、用户体验三项审核方可申请。此项管控将于 HarmonyOS 下一个正式发布版本生效。</p><p>此外，Agent Framework Kit 的 OnDataCallback 接口存在变更，method 参数类型由枚举 AgentOperation 变更为 string，<span class="link-text-start-with-http">RequestContext.getClientSessionId</span> () 方法已被删除。此变更仅当应用的 targetSdkVersion 设置为大于等于 26.0.0 时生效。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/0ffee15e-3de9-4652-b509-3f05c51088c0.jpg?x-bce-process=image/format,f_auto" /></p><p>华为官方同时公布了目前存量设备的 API 版本使用占比数据，其中 API 版本 6.1.1 (24) 的设备量占比最高，达 84.93%；而最新的 7.0.0 测试版（API 26.0.0）仅 4.65%。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/7686a4f3-685f-4495-b592-d6c8eb00346b.jpg?x-bce-process=image/format,f_auto" /></p>
