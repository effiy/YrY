<p>IT之家 8 月 29 日消息，据科技媒体 Phoronix 今天报道，“开源 Windows”项目 ReactOS 现已发布 0.4.16 更新，<strong>最大的变化是加入了全新 GUI（图形界面）安装程序</strong>。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/748b2ca3-8f25-49dc-9d4e-a0cf084bc13a.jpg" /></p><p>IT之家从原报道了解到，ReactOS 的图形安装程序已被集成到启动 CD 和 Live CD 环境中。用户可使用同一镜像文件，完成体验系统、安装系统流程，具体工作流程与 Linux 的 Live 环境类似。</p><p>同时，本次更新还新增了 ReactOS Server Core 安装类型，设计理念类似于 Windows Server 自 &nbsp;2008 起提供的 Server Core 模式。在该模式下，图形化 Explorer Shell 将被禁用。</p><p>ReactOS 0.4.16 还针对多显示器支持进行了基础改进，并带来了多项图形驱动优化。</p>
