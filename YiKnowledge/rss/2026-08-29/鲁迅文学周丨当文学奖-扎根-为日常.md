<p>在上海，文学是整座城市共同呼吸的节拍。</p><p>鲁迅公园里，年近古稀的上海市民带上自己收藏的早年版本鲁迅作品，成为了“遇见大先生”文创市集的摊主，只因“鲁迅的一生，为我们老百姓说真话”；鲁迅小道上，一群稚气未脱的少年顶着烈日，为往来游客细数“大先生”的故事；街头巷尾，百余支队伍沿着鲁迅生前的生活轨迹穿行，在实景迷宫里“文学闯关”；浦西第一高楼白玉兰广场和中国第一高楼上海中心，“鲁迅文学奖，致敬新时代”“文学盛典，魅力申城”等标语相继亮灯，在城市的夜色中熠熠生辉……</p><p>如果鲁迅先生能看到——他所珍爱的文学事业，在他生活过的城市，被寻常百姓这样热切地拥抱着——大概也会感到欣慰吧。</p><img class="ait_item_box img_default" height="844" src="https://imgpai.thepaper.cn/newpai/image/20260828/0722095e-b5a0-4651-bf62-76326582e9bd.jpeg" style="height: auto; display: block; margin: 0 auto;" width="1268" /><p class="image_desc">“2026鲁迅文学周”于8月25日至30日在鲁迅公园举行。摄影：吴栋</p><p></p><p></p><p>今年，第九届鲁迅文学奖颁奖典礼首次在上海举办。这是中国文学最高奖之一鲁迅文学奖首次走出北京，落地鲁迅先生曾经长期生活并创作的文学之城。也是在这一年，这座城市有了一处为文学而生的“家”——上海文学馆。</p><p>一幅更完整的文学地图从此在上海铺展开来：从鲁迅公园、鲁迅墓，到大陆新村鲁迅故居、内山书店、左联会址纪念馆，再到新开的上海文学馆——它们不是散落的文学孤岛，而是串联起一条可以步行丈量的文脉。鲁迅文学奖，最终落在了这片与鲁迅生命最后十年紧密相连的街巷里。</p><img class="ait_item_box img_default" height="844" src="https://imgpai.thepaper.cn/newpai/image/20260828/fc7bf1f1-0eba-40e2-a661-78d3d37079d5.jpeg" style="height: auto; display: block; margin: 0 auto;" width="1269" /><p class="image_desc">上海文学馆 摄影：吴栋</p><p></p><p></p><p>这几天总有读者在社交媒体上提问，围绕第九届鲁迅文学奖颁奖典礼展开的“鲁迅文学周”几日结束？之后还会不会再有？这些提问本身就是一个耐人寻味的信号：曾经遥不可及的文学奖，已变成普罗大众可感知、可参与的文学现场，也变成人们不想“错过”的一种生活。一场典礼会落幕，一届文学周也会结束，但文学的根系已经扎进这座城市的街巷与日历里——每一天，都可能有人追寻鲁迅先生的足迹，有人走进鲁迅的文字，也有人坐下来，写一行属于自己的句子。</p><img class="ait_item_box img_default" height="1279" src="https://imgpai.thepaper.cn/newpai/image/20260828/df9956d2-13ff-43c8-b04f-b73b383537fc.jpg" style="height: auto; display: block; margin: 0 auto;" width="1923" /><p class="image_desc">一群稚气未脱的少年为往来游客细数“大先生”的故事。摄影：吴栋</p><p></p><p></p><p>今天文学还在吗？我们还需要文学吗？这个时代，节奏飞快，技术狂飙，短视频与算法争夺着人们的每一秒注意力。但我们看到，依然有人愿意亲近文学，愿意尝试写作，愿意讲出自己的故事——这其中的勇气、真诚、鲜活，为文学界珍视，亦是对那两个问题最好的回答。</p><p>有一种声音说，文学是“大家”的事情，但在今天这个时代，“大家”不再指代已有成就的名家，而是指向了包括你我在内的所有人。那位在鲁迅公园摆摊的老人，未必读过鲁迅全集，但他懂得“说真话”三个字的分量；那些在“鲁迅小道”中漫步的少年，未必能完全理解课文的意涵，但他们开始用自己的脚步丈量出“大先生”曾经走过的日常。还比如在鲁迅公园、内山书店、今潮8弄，那座红黄相间的“大家的写作屋”格外引人注目。它欢迎所有人走进去，拿起笔，写下身边的日常小事。</p><p>这才是文学最本真的模样。它往往只需要一支笔、一张纸，和一颗愿意表达的心。</p><img class="ait_item_box img_default" height="952" src="https://imgpai.thepaper.cn/newpai/image/20260828/bd49d3db-362a-4bff-968d-c241452dafaf.jpeg" style="height: auto; display: block; margin: 0 auto;" width="1270" /><p class="image_desc">“大家的写作屋”</p><p></p><p></p><p>鲁迅文学奖“回家”了——回到鲁迅生命最后十年生活的城市。但这场“回家”更深层的意义或许是：文学奖回到了它应该去的地方——不是殿堂，而是人间；不是少数人的盛宴，而是所有人的日常。当一座城市用书写、朗读、奔跑等等方式来回应百年前的文学火种，我们看到的不仅是一场颁奖典礼的迁徙，更是一个时代的文学观正在悄然转身。</p><p>“有一分热，发一分光。”</p><p>你我都是那道光。</p><img class="ait_item_box img_default" height="846" src="https://imgpai.thepaper.cn/newpai/image/20260828/230d4362-080a-4ec7-87b3-ecc7d3495ec2.jpeg" style="height: auto; display: block; margin: 0 auto;" width="1269" /><p class="image_desc">文学标语在城市的夜色中熠熠生辉。摄影：吴栋</p><p></p><p></p>
