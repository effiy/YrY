<p>IT之家 8 月 29 日消息，小红书用户 @金刚 今日发文称，通过对小米智能存储进行 Root 操作后发现，该设备底层运行着一套完整的 ARM64 Linux 环境。</p><p>据该用户分享的信息，设备搭载 Realtek RTD1619B 处理器（4 核 Cortex-A55），内存约 3.7GB，系统基于 Yocto 5.0.3 开发，内核版本 Linux 6.6.35，架构为 ARM64/aarch64。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/0cff6ce3-6568-40b8-9413-a4c463d9e4db.jpg" /></p><p>更值得注意的是，该用户在系统中发现了完整的 Docker 环境，包括 Docker Engine 20.10.17、containerd 和 runc 等组件。</p><p>他表示 Docker 能力已存在于官方系统之中，只是官方尚未向普通用户开放。该用户还成功部署并运行了 OpenClaw 容器。</p><p style="text-align: center;"><a href="https://img.ithome.com/newsuploadfiles/2026/8/cb5af231-7250-4f29-97af-42d7ff574c8e.jpg" target="_blank"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/b0d143ac-d391-4897-af76-227c176de8ae.jpg" /></a></p><p>小米智能存储搭载 Arm 芯片，上市前外界普遍认为该产品不支持 Docker，例如海康威视同类产品 Mage 20 Pro 就在固件层面锁定了 Docker 功能。</p><p>该用户表示，接下来还计划在不影响原有存储功能的前提下，尝试部署 Home Assistant、MiLoCo 等应用，并称如有其他用户在研究这台设备，后续可以继续整理 Root、Docker 部署和实际使用情况。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/1ba06864-30df-46eb-8108-93576a373841.jpg" /></p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/8/73e4390a-6813-435a-be59-93d3fc00e18b.jpg" /></p><p>IT之家此前报道，小米首款 NAS 产品“Xiaomi 智能存储”8 月 27 日式正在电商平台开售，提供 4TB、8TB、16TB 三个规格，售价分别为 2699 元、3499 元和 5499 元。</p><p>该产品采用双盘位设计，最大支持 60TB（30TB×2）容量，配备 4GB 内存 +32GB 存储，接口包括 1 个 2.5GbE 网口、1 个 HDMI 1.4 接口和 1 个 USB-A 3.0 接口。</p><p style="text-align: center;"><img class="no-alt-img" src="https://img.ithome.com/newsuploadfiles/2026/7/73d4e18b-46ff-4e3b-bca6-887e8469d971.jpg?x-bce-process=image/auto-orient,o_1" /></p><p>8 月 28 日，小米智能存储公布开售首日更新内容，固件版本为 1.0.8.425。相册 AI
