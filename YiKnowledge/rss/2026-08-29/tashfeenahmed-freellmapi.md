<h2>Why this exists</h2> 
<p>Every serious AI lab now offers a free tier, a few million tokens a month, a few thousand requests a day. On its own each tier is a toy. Stacked together, they add up to roughly <strong>7.4 billion tokens per month</strong> of working inference capacity, across <strong>474 model families / 635 provider endpoints</strong> from small-and-fast to reasonably capable.</p> 
<p>The problem is that stacking them by hand is painful: thirty-four different SDKs, thirty-four different rate limits, thirty-four places a request can fail. FreeLLMAPI collapses that into one OpenAI-compatible endpoint. Point any OpenAI client library at your local server, and it routes transparently across whichever providers you've added keys for.</p> 
<p>And the free-tier landscape shifts weekly: providers launch models, retire them, and change quotas without notice. FreeLLMAPI tracks all of that for you. The router pulls a signed model catalog from <a href="https://freellmapi.co">freellmapi.co</a> on its own, so your install keeps up without a <code>git pull</code>. See <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/#premium-live-catalog">Premium (live catalog)</a> for how fast it keeps up.</p>

<h2>Features</h2> 
<p><img alt="Feature overview" src="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/repo-assets/features.png" /></p> 
<ul> 
 <li><strong>Every OpenAI-style surface</strong> — <code>/v1/chat/completions</code>, <code>/v1/responses</code> (what Codex CLI needs), <code>/v1/completions</code> (editor ghost-text autocomplete), <code>/v1/images/generations</code>, <code>/v1/videos/generations</code>, <code>/v1/audio/speech</code>, <code>/v1/audio/transcriptions</code>, <code>/v1/embeddings</code>, and <code>/v1/models</code> — streaming and non-streaming, from the official SDKs or any OpenAI-compatible client. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/api.md">API reference →</a></li> 
 <li><strong>Anthropic Messages API</strong> — <code>/v1/messages</code> speaks Anthropic's wire format over the same router, so <strong>Claude Code</strong> and the official Anthropic SDKs run against your free pool. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/api.md#anthropic--claude-clients">Details →</a></li> 
 <li><strong>Native Gemini + Ollama surfaces</strong> — Gemini CLI can use <code>/v1beta</code> (<code>generateContent</code>, streaming, token counting, models), while opt-in Ollama emulation serves NDJSON chat/generate, tags, metadata, and embeddings for Zed, JetBrains, and other local-model clients.</li> 
 <li><strong>Fusion (multi-model synthesis)</strong> — request the virtual <code>fusion</code> model and the router fans your prompt out to a panel of diverse free models in parallel, then a judge model synthesizes one answer from the drafts. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/api.md#fusion-multi-model-synthesis">Details →</a></li> 
 <li><strong>Image, video &amp; speech generation</strong> — <code>/v1/images/generations</code>, <code>/v1/videos/generations</code>, and <code>/v1/audio/speech</code> route across the providers that serve media models; images and speech also accept custom OpenAI-compatible media endpoints. Video jobs are normalized across synchronous and queued providers and return a completed MP4.</li> 
 <li><strong>Tool calling &amp; structured outputs</strong> — OpenAI-style <code>tools</code> round-trip across providers (plain-text tool calls are rescued into real <code>tool_calls</code>), plus <code>response_format</code>, <code>seed</code>, <code>logprobs</code>, penalties, and the rest of the sampling params passed through per provider.</li> 
 <li><strong>Smart routing, six strategies</strong> — live per-model speed/capability/reliability scores rank your chain; automatic fallover retries the next model on 429/5xx with cooldowns and key rotation. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/architecture.md#routing-in-detail">Routing in detail →</a></li> 
 <li><strong>Unified models &amp; profiles</strong> — the same model on several providers collapses into one entry with strict in-group failover; named fallback-chain profiles (a coding chain, a vision chain) switch from the dashboard or per request via <code>auto:&lt;profile&gt;</code>.</li> 
 <li><strong>Per-key rate tracking</strong> — RPM/RPD/TPM/TPD counters per <code>(platform, model, key)</code> that learn providers' reported ceilings, so routing always stays under every cap.</li> 
 <li><strong>Self-updating model catalog</strong> — the router syncs a signed catalog from <a href="http://freellmapi.co">freellmapi.co</a> twice a day: new models, quota changes, and provider quirk fixes land automatically. Free installs track the monthly snapshot, which each model joins 30 days after it lands in the live feed; premium routers get it same-day. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/#premium-live-catalog">Premium →</a></li> 
 <li><strong>Sticky sessions &amp; context handoff</strong> — conversations stay on one model for 30 minutes; an optional compact handoff note keeps the thread coherent when a mid-chat switch does happen. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/clients.md#context-handoff">Details →</a></li> 
 <li><strong>Prompt compression (opt-in)</strong> — a shared, fail-open request pipeline can deduplicate prompts, filter tool output, compact repeated JSON, and trim stale context before cache lookup and routing. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/compression.md">Details →</a></li> 
 <li><strong>Encrypted keys, one token out</strong> — provider keys are AES-256-GCM encrypted in SQLite and decrypted in-memory per request; your apps only ever see a single unified <code>freellmapi-…</code> bearer token.</li> 
 <li><strong>Admin dashboard &amp; analytics</strong> — React UI to manage keys, reorder the chain, run a playground, and read p50/p95/TTFT analytics over 24h–90d windows; login-gated, dark/light themes, <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/#languages">60 languages</a>.</li> 
 <li><strong>MCP server &amp; interactive docs</strong> — agents can introspect usable models, provider health, and routing strategy over <code>/mcp</code>; a dependency-free OpenAPI viewer lives at <code>/v1/docs</code>. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/clients.md">Coding agents →</a></li> 
 <li><strong>Ops niceties</strong> — opt-in response cache, encrypted DB backups, periodic key health checks, bulk key import/export, declarative startup config. <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/install.md">Install &amp; deploy →</a></li> 
 <li><strong>Runs anywhere Node 20+ runs</strong> — Windows, macOS, Linux servers, or a small ARM SBC (Raspberry Pi included). ~40 MB RSS at idle behind PM2 / systemd / whatever supervisor you prefer.</li> 
</ul> 
<p>The scope is deliberately narrow — see <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/architecture.md#not-yet-supported">what's not supported yet</a>.</p> 
<h2>Quick start</h2> 
<p><strong>One-liner</strong> (Docker required — sets up <code>~/freellmapi</code>, generates an encryption key, pulls the image, and starts the container):</p> 
<pre><code class="language-bash">curl -fsSL https://freellmapi.co/install.sh | bash
</code></pre> 
<p>Prefer to read before you pipe to bash? <a href="https://freellmapi.co/install.sh">The script is here</a>. Re-running it is safe: your <code>.env</code> (and encryption key) is preserved and the container updates to <code>:latest</code>.</p> 
<p>Open <a href="http://localhost:3001">http://localhost:3001</a>, add your provider keys on the <strong>Keys</strong> page, reorder the <strong>Fallback Chain</strong> to taste, and grab your unified API key from the <strong>Keys</strong> page header. That unified key is what you point your OpenAI SDK at.</p> 
<p>On Windows, the easiest path is the desktop <strong><a href="https://github.com/tashfeenahmed/freellmapi/releases/latest"><code>.exe</code> installer from Releases</a></strong> (below). On Android, see the experimental <a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/install/android-termux.md">Termux guide</a>.</p>

<h2>Premium (live catalog)</h2> 
<p>The router keeps its model catalog fresh on its own: it pulls a signed catalog from <a href="https://freellmapi.co">freellmapi.co</a> twice a day and applies new models, quota changes, and provider quirk fixes to your local DB. Your own enable/disable choices and custom providers are never touched, and every download is verified against a pinned Ed25519 key before it is applied.</p> 
<p>The catalog currently tracks <strong>34 providers</strong>, <strong>474 model families</strong>, <strong>635 free provider/model endpoints</strong> (584 chat, 41 embeddings, 7 transcription, 3 video), and roughly <strong>7.4 billion tokens per month</strong> of listed free-tier capacity. Browse the full set at <strong><a href="https://freellmapi.co/models.html">freellmapi.co/models</a></strong>.</p> 
<p>Free installs pull the same signed catalog, but from the monthly snapshot: a model joins it 30 days after it lands in the live feed, so the free build currently sits about 303 models behind. Nothing expires and nothing is crippled — it just arrives later.</p> 
<p>Premium keeps that signed catalog live on every router you run. When a provider launches a strong free model, quietly tightens a quota, or breaks a wire format, live-feed routers receive the update the same day we ship it.</p>

<h2>Using the API</h2> 
<pre><code class="language-python">from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3001/v1",
    api_key="freellmapi-your-unified-key",
)

resp = client.chat.completions.create(
    model="auto",  # let the router pick; or "auto:fast", "auto:smart", a profile, or a model id
    messages=[{"role": "user", "content": "Summarise the fall of Rome in one sentence."}],
)
print(resp.choices[0].message.content)
print("Routed via:", resp.headers.get("x-routed-via"))
</code></pre>

<h2>How it works</h2> 
<p><img alt="One request in, the best free model out — the fallback chain with live scores, cooldowns, and quota tracking" src="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/repo-assets/router-flow.png" /></p> 
<p>One request in, the best free model out: the router picks the highest-priority model with a healthy key that's under all its rate limits, decrypts the key in memory, and calls the provider — on a 429/5xx it cools that key down and retries the next model in your chain. The component walkthrough, routing internals, and operational details live in <strong><a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/architecture.md">docs/architecture.md</a></strong>.</p> 
<h2>FAQ</h2> 
<p><strong>Do I need a password?</strong> Not for the desktop app — the dashboard signs itself in with a hidden local account, so there is nothing to set up and nothing to forget. Open it from the tray icon → <strong>Open Dashboard</strong>. Server installs (Docker, one-liner, <code>npm run dev</code>) do have an email + password account.</p> 
<p><strong>I forgot the password on a server install.</strong> Click <strong>Forgot password?</strong> on the login page. There is no email to send a link to, so the one-time code is printed to the server log — read it with <code>docker compose logs -f freellmapi</code> (or in the terminal running the server, or in the desktop log file), then enter it on the reset form. The code lasts 15 minutes.</p> 
<p><strong>Where are the logs?</strong> In the container log for Docker, in the terminal for a source run, and in <code>&lt;data dir&gt;/logs/freeapi.log</code> for the desktop app — reachable from the tray menu's <strong>Open Logs Folder</strong>.</p> 
<p><strong>How do I uninstall?</strong> Remove the app (Trash on macOS, <em>Settings → Apps</em> on Windows, <code>docker compose down -v</code> for Docker), then delete the data directory: <code>%APPDATA%\FreeLLMAPI\</code>, <code>~/Library/Application Support/FreeLLMAPI/</code>, or <code>~/.config/FreeLLMAPI/</code>. Uninstalling never touches that folder on its own.</p> 
<p>Longer answers, per install method: <strong><a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/install.md#faq-passwords-logs-uninstall">docs/install.md#faq-passwords-logs-uninstall</a></strong>.</p> 
<h2>Limitations</h2> 
<p>Stacking free tiers has real trade-offs: no frontier models, variable latency, no SLA — and the effective intelligence of the endpoint dips late in the day as top models hit their daily caps, then resets at UTC midnight. Read the honest list in <strong><a href="https://raw.githubusercontent.com/tashfeenahmed/freellmapi/main/docs/architecture.md#limitations">docs/architecture.md#limitations</a></strong> before building anything real on this.</p>
