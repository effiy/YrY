<p>从浦江之畔到昆仑之麓，文脉跨越山海，艺术双向奔赴。8月27日，2026 年度上海市“文化润疆”重点文旅演艺项目——原创浸入式剧目《织遇》，在新疆喀什古城东区“织遇·古城里巷”专属小剧场迎来首演。</p><p>这部由上海市演出有限公司原创打造的沉浸式剧目，以国家级非遗艾德莱斯绸为文化内核，用全新的空间叙事与互动演艺形式，开启沪疆文化交融的全新篇章。</p><img class="ait_item_box img_default" height="708" src="https://imgpai.thepaper.cn/newpai/image/20260829/6ce8bea0-7a79-410d-92e6-ca73429f5958.png" style="height: auto; display: block; margin: 0 auto;" width="530" /><p class="image_desc">演出海报</p><p></p><p></p><p><strong>挖掘千年丝路文脉，古城即舞台</strong></p><p>作为上海文化润疆重点文旅创新项目，《织遇》从前期筹备、剧本创排、剧场改造到落地上演，全程坚持“沪疆联动、在地共生”的创作理念。</p><p>项目选址喀什古城东区，依托古城街巷肌理与民俗风貌，将传统民居空间改造为专属浸入式小剧场，打破观演边界，让街巷、光影、织艺与人文融为一体，打造“古城即舞台，游客入剧情”的独特体验。</p><img class="ait_item_box img_default" height="575" src="https://imgpai.thepaper.cn/newpai/image/20260829/69bbf88d-96ec-43e4-a968-99d8edc34c10.png" style="height: auto; display: block; margin: 0 auto;" width="863" /><p class="image_desc">沉浸式演出剧场场景</p><p></p><p></p><p>剧目深耕新疆本土文化，以国家级非遗艾德莱斯绸的古老织造技艺、斑斓纹样美学与历史传承故事为核心线索，串联起丝路古道的商贸往来、南疆大地的民俗烟火与沪疆两地的文脉互通。</p><p>主创团队深入喀什街巷采风，挖掘丝绸织造背后的匠人精神、民族审美与时代变迁，通过歌舞演绎、情境独白、沉浸式空间表演等多元艺术手法，将静态非遗文化转化为可看、可感、可共情的动态舞台故事，让古老的艾德莱斯绸在当代文旅场景中焕发新生。</p><img class="ait_item_box img_default" height="510" src="https://imgpai.thepaper.cn/newpai/image/20260829/d26225a9-bc29-46ee-a90d-5813ec4f5dcb.png" style="height: auto; display: block; margin: 0 auto;" width="371" /><p class="image_desc">剧场外观</p><p></p><p></p><p>区别于大型实景演艺，《织遇》主打“小而精、专而美”的街巷沉浸式体验。剧场依托古城原生空间量身设计，采用近距离互动式观演模式，打破舞台与观众的距离。观众既能看见匠人精神的织艺浪漫，也能读懂各民族交融共生的温情故事，沉浸式触摸千年丝路的文化脉络，感受沪疆跨越山海的深厚情谊。</p><p>项目丰富了喀什古城轻量化、精细化的沉浸式演艺形态，为本土非遗传承、文旅消费升级与文化双向交流搭建了新桥梁。</p><p><strong>落地常态阵地，打造“文化润疆”新标杆</strong></p><p>项目负责人介绍，《织遇》自启动创排一年多来，团队集结了沪疆优质文艺力量，历经本土采风、项目研讨、剧本打磨、建组创排、剧场建设与实地试演等多个阶段，始终坚持“尊重本土、深耕文化、创新表达”的创作原则，力求用年轻化、国际化的艺术语言，讲好沪疆故事、传播丝路文化、诠释民族交融之美。前期内部试演受到当地市民和游客的一致好评，观众现场踊跃互动。</p><img class="ait_item_box img_default" height="419" src="https://imgpai.thepaper.cn/newpai/image/20260829/3da3f208-6c8b-408d-bb75-e408d3c7ec76.png" style="height: auto; display: block; margin: 0 auto;" width="629" /><p class="image_desc">观众和演员互动</p><p></p><p></p><p>剧中三位演员均来自新疆，分别就读于上海戏剧学院和浙江传媒学院影视播音相 关专业，通过招募面试和密集排练回到家乡演出，感慨良多。男主演茹斯坦江·库尔班江更是如假包换的喀什本地人，第一次在父老乡亲面前以全新面貌展现自我，令他感到激动又骄傲。</p><img class="ait_item_box img_default" height="482" src="https://imgpai.thepaper.cn/newpai/image/20260829/fb8186cf-4472-4c2e-a530-53508ca5b26d.png" style="height: auto; display: block; margin: 0 auto;" width="724" /><p class="image_desc">演出剧照</p><p></p><p></p><p>与此同时，《织遇》剧目的正式首演和专属小剧场“织遇·古城里巷”的落成，也为上海优质演艺资源在新疆落地扎根与长期艺术交流提供了一个新的阵地。据悉，上海文广演艺集团旗下多家院团也将不定期到访登台，为古城观众送上彩蛋式的惊喜演出。</p><p>此外，项目在运营中也同步吸纳本地人才，目前已有三位喀什本地年轻成员加入团队，承担演出技术、后台抢妆、剧场运维等日常工作，以岗代训，持续孕育当地专业能力，为阵地长效发展厚植人才基础。</p><img class="ait_item_box img_default" height="427" src="https://imgpai.thepaper.cn/newpai/image/20260829/6575ce2e-9256-4639-9882-3c102edf9ac3.png" style="height: auto; display: block; margin: 0 auto;" width="640" /><p class="image_desc">剧组试演合影</p><p></p><p></p><p>依托喀什古城核心景区的客流优势，剧场在非演出时段，向游客市民提供咖啡茶饮服务，试营业一周以来日营业额稳定突破预期。剧场内依照剧情设定打造的百年艾德莱斯老店的特色场景，也吸引了不少旅拍客驻足打卡。</p><p>未来，“织遇·古城里巷”这块专属文化阵地将持续常态化运营，打磨优质原创内容、开展文化交流活动、培育本土文艺力量。</p>
