<p>（本文作者为 字母AI，钛媒体经授权发布）</p><blockquote style="margin-bottom: 25px;"><p>文 | 字母AI</p></blockquote><p><strong>Codex的活跃用户，到2000万了。</strong></p><p><img src="https://images.tmtpost.com/uploads/images/2026/08/d78f83556ff6f2ab7a408defaacbbbda_1787393678.jpg" /></p><p>OpenAI Codex负责人Tibo昨天在X上确认，Codex本周已经突破2000万活跃用户。此前CNBC获得的OpenAI内部数据也显示，公司AI编程与工作类Agent产品已经达到约2000万周活。</p><p>这个数字延续了过去一个多月的高速增长。7月，OpenAI曾连续公布Codex与ChatGPT Work的600万、700万、800万、900万乃至1000万用户里程碑。</p><p>用户增长之外，OpenAI的企业业务也在明显提速。据CNBC披露，从本季度开始至今，按照当前收入水平年化计算，OpenAI企业业务的收入规模已经增长约50%，明显快于公司整体35%的增幅。</p><p>另一边，今年春天几乎定义了AI Coding热潮的Claude Code，开始慢了下来。</p><p>数据追踪平台TickerTrends最新追踪显示，<strong>截至8月10日，Claude Code过去四周的增长率已经降至5.2%；而OpenAI Codex同期增长20.8%，接近前者的4倍。</strong></p><p><img src="https://images.tmtpost.com/uploads/images/2026/08/6e3d18614224a28a2f325b07fab645a7_1787393679.jpg" /></p><p>几个月前，两条曲线还完全不是现在的样子。今年2月到6月，Claude Code一路狂飙，把对手远远甩在身后。但进入7月，它的增长曲线第一次明显走平；而原本落后的Codex加足了马力。</p><p><strong>Claude Code在AI Coding里的统治力，正在受到冲击。</strong></p><h2><strong>Claude Code踩下刹车</strong></h2><p>Claude Code的增长神话，终于撞上了一条再普通不过的商业规律：<strong>用户是有限的。</strong></p><p><img alt="" class="aligncenter" id="edit_8112850" src="https://images.tmtpost.com/uploads/images/2023/tkrss/43t5y6jytfeb3.png" /></p><p>今年2月，Claude Code的年化收入还只有25亿美元左右。随后几个月，这个数字几乎是一路往上蹿：3月底超过60亿美元，4月底突破100亿美元，到6月已经超过140亿美元。</p><p>短短四个月，翻了五倍多。</p><p>那段时间，Anthropic自己也在不断给这场狂飙加戏。5月，公司披露Claude已经能完成Anthropic内部超过80%的代码；6月又开始讨论递归式自我改进、&ldquo;AI构建AI&rdquo;，以及Agent如何从执行一个Bug修复任务，一路走向自己判断该解决什么问题。</p><p>Claude Code几乎成了Anthropic展示&ldquo;AI如何改变软件开发&rdquo;的最佳样板。</p><p>然后，7月来了。</p><p>TickerTrends的追踪数据显示，7月6日，Claude Code的年化收入约为142.6亿美元；一周后143.8亿美元；7月20日144.7亿美元；到了7月27日，甚至短暂回落到143.5亿美元。8月3日回到145亿美元，直到8月10日才重新跳到151.2亿美元。</p><p><img src="https://images.tmtpost.com/uploads/images/2026/08/703d705e28b1a94627408fb549b40923_1787393679.jpg" /></p><p>钱还在赚，收入并没有真的掉下去。</p><p><strong>但那个每隔几周就要刷新一次纪录、动不动几十个百分点增长的Claude Code，突然掉进了现实世界里那个紧巴巴的个位数增长区间。</strong></p><p>截至8月10日，Claude Code过去四周相比此前四周只增长了5.2%。</p><p>这事儿本身并不难理解：Claude Code最早吃到的就是最容易被AI Agent转化的一批人。</p><p>程序员本来就坐在电脑前，有清晰的任务、有代码库、有测试结果，甚至连&ldquo;AI到底有没有把活干完&rdquo;都比其他知识工作更容易验证。产品足够好以后，开发者很快就会涌进来，并形成很强的使用习惯。</p><p>《The Information》今年7月底采访多家企业发现，<strong>即使Claude Code越来越贵，许多工程师依然不愿意换。</strong>在Weave追踪的200多家企业中，今年上半年Claude Code单用户成本翻了两倍多，活跃用户却增加到原来的3倍。Workato的AI编程使用量中，Claude Code占到80%，Codex只有20%。</p><p><img src="https://images.tmtpost.com/uploads/images/2026/08/5472a6f841423ed3ca8f0d3a443cc549_1787393679.jpg" /></p><p>Claude Code不只抢到了第一批用户，也抢到了开发者的默认选项。</p><p>但程序员终究只有这么多，越往后，剩下的人越难转化。早期爱尝鲜的开发者已经装了Claude Code；重度用户一天能用十几个小时。Anthropic今年6月的研究甚至显示，Claude Code用户平均每周已经使用约20小时。</p><p>一个产品渗透到这种程度之后，还想永远按照早期速度扩张，本来就不现实。</p><p>过去一年，coding已经成为Anthropic最重要的商业支点之一：Claude Code直接贡献收入，Cursor、Cognition、GitHub Copilot等客户通过API调用Claude，本质上也在放大Anthropic在编程场景里的优势。</p><p>Claude Code今天的增速放缓，并不意味着它哪里突然出了问题，更可能的情况是：最容易吃的一块市场，已经被它吃得差不多了。</p><p>Anthropic自己当然也知道这一点。</p><p>过去几个月，它一直在试图把Claude Code验证过的工作方式搬出程序员群体。</p><p>Cowork让用户把文件、浏览器和各种工具交给Claude完成多步骤工作；6月推出的Claude Tag甚至被Anthropic直接称为&ldquo;Claude Code的一次演化&rdquo;，希望把这种Agent式工作方式带进产品、客服、数据分析等团队。Anthropic自己的Economic Index也开始把Claude Code和Cowork放在一起研究，观察Agent如何从软件开发扩散到更广泛的知识工作。</p><p>只是截至目前，公开数据里还没有出现第二条像早期Claude Code那么夸张的增长曲线。</p><p><strong>Anthropic最好讲的第一个故事，已经讲到了后半程。</strong></p><p>偏偏就在这个时候，之前一直追在后面的Codex，开始跑快了。</p><h2>Codex追上来了</h2><p>Claude Code慢下来的同时，TickerTrends看到的另一条曲线，正在往上走。</p><p>截至8月10日，其模型估算的Codex年化收入指标过去四周增长20.8%，接近Claude Code同期5.2%的4倍。7月初，Claude Code的估算规模还是Codex的2.4倍；五周以后，这个差距已经缩小到约1.7倍。</p><p><img src="https://images.tmtpost.com/uploads/images/2026/08/32b526f448245ae14d2bfd7f83d71751_1787393679.jpg" /></p><p>但这里需要先打一个很重要的补丁：TickerTrends并没有直接追踪到Codex赚了多少钱。</p><p>Claude Code这条曲线至少还有一个官方锚点：Anthropic今年2月披露，其年化收入已经超过25亿美元，TickerTrends再根据自己的数据往后外推。</p><p>Codex则没有这样的官方收入数字。TickerTrends的做法，是先估算OpenAI的企业年化收入，再假设其中45%归属于Codex，由此得到88.3亿美元以及20.8%的增长率。</p><p>即便如此，趋势是真实存在的。OpenAI自己的管理层也已经把Codex列为近期收入加速的重要驱动因素之一。</p><p>更直接的证据，来自OpenAI自己的用户数据。</p><p>6月2日，OpenAI官方披露，Codex周活用户已经超过500万，相比2月桌面应用上线时增长超过6倍。</p><p>而且它的用户群体不只程序员。当时，知识工作者已经占Codex用户的约20%，包括分析师、营销人员、运营、设计师、研究员、投资人和银行从业者；这部分用户的增长速度，甚至超过开发者的3倍。</p><p>GPT-5.6发布之后，OpenAI曾经连续几天公布Codex与ChatGPT Work的用户里程碑：600万、700万、800万、900万&hellip;&hellip;那几天，<strong><a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzYzMjc5ODU4Mw==&amp;mid=2247507034&amp;idx=1&amp;sn=1d7687c0c4f471d4b415f7a2495549c2&amp;scene=21#wechat_redirect" rel="noopener" target="_blank">这个数字几乎以每天100万的速度往上涨</a>。</strong></p><p>7月21日，OpenAI宣布Codex与ChatGPT Work合计已经达到约1000万周活用户。</p><p>一个月不到，这个数字又翻了一倍。</p><p>CNBC最新获得的OpenAI内部数据显示，公司的&ldquo;AI编程与工作类Agent产品&rdquo;已经达到约2000万周活用户。</p><p>不过，在OpenAI把Codex合并到ChatGPT这个入口之后，产品的口径变得非常模糊，很难再用一个单独的&ldquo;Codex用户数&rdquo;，去衡量它和Claude Code之间的竞争。</p><p>OpenAI和Anthropic本来就在走两条不同的路。</p><p>Anthropic是从Claude Code往外扩，先拿下程序员，再把Claude Code验证过的Agent工作方式搬到Cowork、Claude Tag和更广泛的知识工作里。Anthropic自己对Cowork的定义，就是把Claude Code已经证明过的执行能力带给更多人。</p><p>OpenAI则正好反过来。Codex最早也是从程序员切入，但从今年6月开始，它就在不断吸收分析师、营销、运营、研究等非开发者用户；GPT-5.6发布之后，OpenAI又把Codex和ChatGPT Work一起收进ChatGPT这个更大的入口里。如今ChatGPT桌面端已经明确分成Chat、Work和Codex几个工作入口，其中Work负责长时间、多步骤的知识工作，Codex继续负责软件开发，但两者共享同一套Agent使用额度。</p><p><strong>Anthropic是在把Claude Code向外扩，OpenAI是在把Codex往ChatGPT里收。</strong></p><p>如果严格比较Coding Agent，应该看Codex对Claude Code；但如果讨论OpenAI现在公布的2000万AI编程与工作类Agent用户，那么Anthropic一侧更接近的参照，其实应该是Claude Code + Claude Cowork，甚至再加上Claude Tag这类从Code演化出来的Agent产品。</p><h2>但OpenAI还没追上Anthropic</h2><p>如果把镜头从Codex和Claude Code拉回两家公司，局面突然又反了过来。</p><p>2025年底，OpenAI的年化收入运行率已经超过200亿美元，是Anthropic约90亿美元的两倍以上。</p><p>半年多以后，领先者换了人。</p><p>截至7月底，Anthropic的年化收入运行率已经突破650亿美元，OpenAI最新披露的年化收入水平则超过400亿美元。</p><p>按650亿美元和400亿美元的下限计算，Anthropic目前的年化收入水平至少领先约六成。</p><p>甚至只看Anthropic自己，仅从5月底到7月底，Anthropic就新增了超过180亿美元年化收入，两个月新增的体量，已经接近OpenAI去年年底的整个年化收入规模。</p><p><img src="https://images.tmtpost.com/uploads/images/2026/08/51e39cb7da2c85221af30a65d68bfad5_1787393680.jpg" /></p><p>另外，《华尔街日报》获得的两家公司非公开财务数据显示，今年二季度，OpenAI收入为67亿美元，环比增长18%；Anthropic同期收入则超过一倍，达到116亿美元，第一次在单季度收入上超过OpenAI。</p><p>尽管两家公司的收入确认口径并不完全一致，例如Anthropic会把通过云合作伙伴销售Claude产生的部分收入计入自身收入，而OpenAI的处理方式不同，这些数字并不是完全严格的一对一比较。</p><p>但从公司层面看，Claude Code的增速变化，目前还远不足以撼动Anthropic已经建立起来的收入优势。</p><p>一个很重要的原因在于，Claude Code本来就不是Anthropic收入的全部，甚至不是大头。</p><p>Anthropic真正的收入主力，仍然是向企业和第三方产品出售Claude模型能力。Cursor、Cognition、GitHub Copilot等产品通过API调用Claude，企业客户直接采购模型服务，这些收入加在一起，才构成了Anthropic最主要的商业基本盘。公司此前甚至预计，到2028年，API及相关企业应用收入仍会贡献超过80%的收入。</p><p>Claude Code的意义，更像是把Anthropic在coding场景里的模型优势变成一个直接面向用户的产品，同时又反过来强化企业和第三方对Claude模型的需求。</p><p>换句话说，哪怕Claude Code最陡的增长阶段过去了，但Anthropic靠coding建立起来的收入优势并没有消失。</p><p>而这也是Codex，或者说OpenAI，真正想要追赶的地方。</p><p>Codex从诞生起就是一款软件工程Agent，和Claude Code争夺的是同一批开发者和企业工程团队。只不过Claude Code先跑了出来，也率先证明了一件事：coding不仅是一个高频AI使用场景，还可以长成一门庞大的企业生意。</p><p>现在，OpenAI正在补这段差距，并表现出明显的企业化动作。</p><p>今年4月，OpenAI专门推出Codex Labs，并与大型系统集成商合作，要把Codex推进数千家工程组织；当时Codex周活开发者已经从月初超过300万涨到两周后的400万以上。OpenAI列举的客户场景也几乎全部是企业软件工程：测试、代码审查、功能开发、大型代码库理解、事故响应。</p><p>至少从最新的收入表现来看，这条路已经走出了一些效果。<strong>据CNBC披露，本季度开始至今，OpenAI整体收入的年化运行率增长约35%，企业业务则增长超过50%。</strong></p><p>Codex最近的用户增长很漂亮，但2000万用户到底能转化为多少企业业务&mdash;&mdash;或者说，到底值多少钱&mdash;&mdash;才是接下来真正决定竞争格局的数字。</p><p>因为ChatGPT本来就拥有数亿级用户入口。把Codex塞进ChatGPT、共享额度、降低门槛，当然有可能迅速做大用户规模。可这些新增用户里，有多少是真正高频使用的专业开发者，又有多少最终能够转化成高客单价的企业客户，目前还没有公开数据给出答案。</p><p>如果OpenAI接下来也能把Codex迅速增长的用户和使用量，转化成同样迅速增长的企业收入，两家公司之间的竞争格局完全可能再翻一次。</p><p>至于该如何转化，可能还是要回归到那个最底层的变量：模型。</p><p>OpenAI手里还有尚未发布的Astra，按照目前披露的信息，它在Agent编程和网络安全能力上已经出现明显跃升，甚至因为可能触及最高级别的网络安全风险阈值，OpenAI不得不放慢开发，加强安全测试。Anthropic那边，最近关于Fable 5.1的传闻也越来越多，有报道称公司已经开始内部测试这一版本。</p><p>Claude Code和Codex能够成为今天这样的产品，前提都是Claude和OpenAI的基础模型已经足够好用。</p><p>产品入口、企业销售、用户习惯可以放大这种优势，但一旦下一代模型拉开明显的能力差距，产品层面的领先关系也可能被重新改写。</p><p>产品可以建立壁垒，但对OpenAI和Anthropic来说，最核心的资产始终还是模型。</p><p><p style="text-align:
