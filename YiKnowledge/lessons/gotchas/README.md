# 陷阱 / Gotchas

收录工程、产品、流程中踩过的坑与注意事项。

## 文件类型

- `*-gotcha.md`：单点陷阱记录
- `*-summary.md`：某主题陷阱合集摘要

## 推荐结构

```markdown
---
title: 某陷阱
tags: [陷阱, 主题]
category: lessons/gotchas
created: YYYY-MM-DD
source: internal
type: summary
---

## 现象
## 根因
## 解决方案
## 预防措施
```
