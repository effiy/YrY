# 5 项目统一健康看板设计 — Grafana Dashboard 首页 8 指标 × 下拉变量

> **适用场景**：SRE 每日站会看板、告警后关联上下文、发布后回滚判定、健康度周报数据来源。

| 项目 | 内容 |
|---|---|
| **Dashboard ID** | GRAF-UNIFIED-HEALTH-019 |
| **数据源** | Prometheus (+ MongoDB Exporter / Node Exporter / Blackbox) |
| **变量定义** | `project` / `time` / `env` |
| **适用范围** | YiAi / YiVad / YiPot / YiPet / YiKnowledge 五项目 |
| **最后更新** | 2026-10-07 |

## 一、Dashboard 首页布局与变量

### 1.1 顶部变量区 (Dropdown × 3)

| 变量 Key | Label | 可选值 | 默认值 | Grafana Query/定义 |
|---|---|---|---|---|
| `$project` | 项目 | `All` / `yiai` / `yivad` / `yipot` / `yipet` / `yiknowledge` | `All` | `label_values(up, project)` 或自定义常量列表 |
| `$time` | 时间范围 | `Last 1h` / `Last 6h` / `Today` / `Last 7d` / `Last 30d` | `Last 6h` | 内置 `__time_affine` + 顶部 TimeRange 控制 |
| `$env` | 环境 | `All` / `dev` / `staging` / `prod` | `prod` | `label_values(up, env)` |

> **仪表盘复用**：同一 Dashboard 通过 `$project=All` 展示 5 项目叠加/分列对比；通过 `$project=<单个>` 下钻到项目专属视图。

## 二、8 指标面板定义表 (名称 / 单位 / 阈值颜色 / PromQL 模板)

> 规则：`$project` / `$env` 都通过 label matcher 注入；若某项目暂无该指标（如 YiPot 桌面端 RPM），面板显示 `-` 或 0 但**不报错**。

| # | 指标名称 | 单位 | 阈值颜色 (绿/黄/红) | PromQL / 查询模板 | 说明 |
|---|---|---|---|---|---|
| **1** | **可用性 SLI**<br>`sli_availability_5xx_ratio` | % | ≥99.9% 绿<br>99.0-99.9% 黄<br><99.0% 红 | `1 - (sum(rate(http_requests_total{project=~"$project",env=~"$env",status=~"5.."}[$__rate_interval])) / clamp_min(sum(rate(http_requests_total{project=~"$project",env=~"$env"}[$__rate_interval])), 1))` | 核心 SLI。桌面端 YiPot 用本地 HTTP `:60828/health` 可用性替代：`1 - clamp_max(probe_success{job="yipot_local",project="yipot"},0) on() vector(1)` |
| **2** | **请求延迟 p95**<br>`latency_http_p95` | ms | <200ms 绿<br>200-800ms 黄<br>≥800ms 红 | `histogram_quantile(0.95, sum by (project, le) (rate(http_request_duration_seconds_bucket{project=~"$project",env=~"$env"}[$__rate_interval]))) * 1000` | YiPot 用 `/translate` p95；YiPet 用 content script 注入耗时 (UDM 探针上报)。无 histogram 时 fallback：`avg_over_time(http_request_duration_seconds_sum[$__rate_interval])/clamp_min(avg_over_time(http_request_duration_seconds_count[$__rate_interval]),1)*1000` |
| **3** | **资源 CPU 使用率**<br>`resource_cpu_percent` | % | <60% 绿<br>60-85% 黄<br>≥85% 红 | `100 - (avg by (project) (rate(node_cpu_seconds_total{mode="idle",project=~"$project",env=~"$env"}[$__rate_interval])) * 100)`<br>容器版: `sum(rate(container_cpu_usage_seconds_total{project=~"$project",env=~"$env"}[$__rate_interval])) / sum(kube_pod_container_resource_limits{resource="cpu",project=~"$project"}) * 100` | 5 项目共用；YiPot 桌面端用 `process_cpu_seconds_total{process="YiPot"}` 换算。 |
| **4** | **业务量 RPM**<br>`traffic_requests_per_minute` | rpm | _(自适应刻度)_<br>无红绿黄，用同比环比 | `sum by (project) (increase(http_requests_total{project=~"$project",env=~"$env"}[1m]))` | 5 项目维度：YiAi=RPC/min, YiVad=Page View/min, YiPot=Translate API hits/min, YiPet=Context Menu Action/min, YiKnowledge=Git Push 事件/min。 |
| **5** | **错误率 (按类型)**<br>`error_rate_4xx_5xx` | % | <0.5% 绿<br>0.5-3% 黄<br>≥3% 红 | `sum(rate(http_requests_total{project=~"$project",env=~"$env",status=~"4..|5.."}[$__rate_interval])) / clamp_min(sum(rate(http_requests_total{project=~"$project",env=~"$env"}[$__rate_interval])),1) * 100` | 下钻面板可拆 4xx/5xx；YiPot 桌面端用 `yipot_crash_count_per_minute + sqlite_integrity_error_count` 替代。 |
| **6** | **队列深度 / 积压**<br>`queue_backlog` | items | <100 绿<br>100-1000 黄<br>≥1000 红 | YiAi:`mq_rabbit_queue_messages{project="$project",queue!~".*dlq"}`<br>通用 fallback: `redis_list_length{project="$project",key=~".*:queue:.*"}` 或 `goroutine{label="worker_q"}` | 无队列的项目（YiVad SPA / YiKnowledge）面板显示 0 或 `-`；YiPot 用 `yipot_clipboard_pending_queue`。 |
| **7** | **部署 / 版本存活**<br>`deploy_version_gauge` | (枚举) | 唯一版本 = 绿<br>2 版本 = 黄(发布中)<br>≥3 或 0 = 红 | `count by (project) (group by (project, revision, image_tag) (up{project=~"$project",env=~"$env"} == 1))`<br>面板渲染使用 `Group by: project` + `Tooltip: image_tag/revision` | 用于金丝雀/蓝绿期间一眼看版本分裂。YiPot 桌面端用 `yipot_app_version_info{project="yipot"}` gauge。 |
| **8** | **活跃告警数 P0-P3**<br>`alerts_active_by_severity` | count | 0 绿<br>P1≥1 或 P2≥3 黄<br>P0≥1 红 | `ALERTS{alertstate="firing",project=~"$project",env=~"$env"} * on(alertname,project) group_left(severity) label_replace(ALERTS_FOR_STATE, "severity", "$1", "severity", "(.*)")`<br>简化版: `count(ALERTS{alertstate="firing",project=~"$project"}) by (project, severity)` | 数据来源 Alertmanager；单 Stat 面板用 `Thresholds: P0=1 P1=1 P2=3 P3=10` 叠加判断。 |

## 三、项目专属下钻 Panel (Repeat)

当用户选择 `$project=<单项目>`，面板按项目重复展开：

| 列名 | 面板类型 | 数据源补充 |
|---|---|---|
| **YiAi** | TimeSeries: RPC p95 × route + MongoDB Pool Current + 熔断器打开次数 | `yiai_circuit_breaker_opened_total{module=~".*"}` (见 105-prd-熔断器.md) |
| **YiVad** | TimeSeries: FCP/LCP p75 (Lighthouse exporter) + Assets cache hit % | `lighthouse_audit_performance_score{url=~".*/#/project"}` |
| **YiPot** | TimeSeries: `:60828` up + clipboard events/min + translation latency p95 | `probe_success{target="http://127.0.0.1:60828/health"}` |
| **YiPet** | TimeSeries: content script injection OK count + storage.sync 延迟 + runtime.lastError 率 | `yipet_mv3_runtime_errors_total{project="yipet"}` |
| **YiKnowledge** | TimeSeries: Git Sync latency + indexer backlog + search qps | `wikisync_last_duration_ms{project="yiknowledge"}` |

### 3.1 阈值颜色统一策略

- **颜色语义**：Green = SLO 内；Yellow = 消耗错误预算 30-70%；Red = 错误预算 100% 已消耗
- **颜色实现**：Grafana Stat Panel → `Thresholds (Base=green, ...)` + `Value mappings`；TimeSeries 用 `Series overrides -> Fill below to + thresholds`
- **无数据**：`No data = grey` + `Display value = "-"`，不触发告警

### 3.2 Grafana Provisioning 片段 (YAML 样例)

```yaml
# dashboards/unified-health-019.yaml (Grafana provisioning)
dashboard:
  uid: unified-health-019
  title: "Unified 5-Project Health Overview"
  templating:
    list:
      - name: project
        type: query
        query: "label_values(up, project)"
        current:
          text: "All"
          value: "$__all"
        includeAll: true
      - name: env
        type: custom
        options: [dev, staging, prod]
        current: {text: prod, value: prod}
        includeAll: true
  panels:
    - id: 1
      type: stat
      title: "1. Availability SLI"
      repeat: project
      repeatDirection: h
      gridPos: { h: 4, w: 5 }
      targets:
        - expr: |
            1 - (
              sum(rate(http_requests_total{project="$project",env=~"$env",status=~"5.."}[$__rate_interval]))
              / clamp_min(sum(rate(http_requests_total{project="$project",env=~"$env"}[$__rate_interval])),1)
            )
          legendFormat: "{{project}}"
      thresholds:
        - {color: green, value: null}
        - {color: yellow, value: 0.99}
        - {color: red, value: 0.99}   # 显示为百分数则 <99% = 红
      fieldConfig:
        defaults:
          unit: percentunit
          decimals: 2
```
