<h2 class="wp-block-heading" id="h-find-your-flow">Find your flow</h2>



<p class="wp-block-paragraph">Some of the best moments at Universe happen heads-down: working through a real problem, configuring something on your own machine, and walking out with a project you can actually use. This year&rsquo;s catalog leans into that with learnings you can take straight back to your repositories.</p>



<p class="wp-block-paragraph">A few sessions to start with:</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1775863398105001Nya7?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>Stop prompting, start delegating: Configure Copilot to own the work</strong><br /></a><em>Ken Muse, GitHub; Mickey Gousset, GitHub<br /></em>Learn how the right Copilot configuration turns AI into something you can trust with complex tasks. Layer Copilot&rsquo;s full stack onto a TypeScript app, and you&rsquo;ll leave with a working project and a clear sense of which capability fits which task, so you can delegate more and prompt less.</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1777584211997001vbxd?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>Inside GitHub Copilot&rsquo;s coding harness: Optimizing across every model</strong><br /></a><em>Julia Kasper, Microsoft<br /></em>Shipping a coding agent that works across OpenAI, Claude, Gemini, and whatever drops next week takes a harness. See the evaluation framework the GitHub Copilot team uses to test and optimize its agent across every model: reproducible benchmarks, thousands of autonomous coding tasks, and LLM-graded assertions that catch regressions before users do.</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1777610662772001qS4e?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>Stop waiting on your own pull requests: GitHub stacked pull requests in practice</strong><br /></a><em>Sameen Karim, GitHub<br /></em>Stacked pull requests let you split changes into smaller, dependent pull requests that move through review efficiently while preserving the full picture. This demo builds a stack with the GitHub CLI, reviews it on github.com, and merges each pull request as it&rsquo;s ready&mdash;so you leave with a workflow you can use tomorrow.</p>



<h2 class="wp-block-heading" id="h-find-your-people">Find your people</h2>



<p class="wp-block-paragraph">Hallway conversations, a question that reframes your whole approach, the engineer who already solved the thing you&rsquo;re stuck on. This year&rsquo;s agenda is filled with sessions for exactly that. Plus, hallway tracks, partner booths, and Ship &amp; Tell sessions where teams show what they&rsquo;ve actually built.</p>



<p class="wp-block-paragraph">A few sessions worth your time:</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1782223817329001J5Je?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>Building AI fluency at UPS</strong><br /></a><em>Jared Hatfield, UPS<br /></em>Getting developers to try GitHub Copilot is simple; getting them fluent with it&mdash;using agents to plan, write, and ship real work&mdash;is the harder challenge. See how UPS moves developers from awareness to fluency, why motivation and measurement matter as much as the tooling, and where to focus first at enterprise scale.</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1777670345672001qdye?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>Code is the easy part: Building Home Assistant in the open</strong><br /></a><em>Franck Nijhof, Open Home Foundation<br /></em>&ldquo;Building in the open&rdquo; usually means one thing: code on GitHub. But the hard work starts long before code&mdash;ideas, UX, design, architecture, the roadmap itself. At Home Assistant, every step happens in the open across 20,000 contributors and a dozen GitHub organizations. See how the Open Home Foundation runs its whole roadmap with issues, projects, and discussions, including the harder parts, like being wrong in public, fixing it in public, and proving you don&rsquo;t have to be technical to contribute.</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1777614539199001PlmK?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>I made my Octolamp think with GitHub Copilot CLI hooks</strong><br /></a><em>Beatris Mendez Gandica, Nuevo Foundation<br /></em>What if your desk lamp could show when GitHub Copilot CLI is thinking? Using the native hooks system, Beatris Mendez Gandica made hers breathe green when the agent works, go white when idle, and blink red on errors. No prompting tricks, just system-level lifecycle events driving a physical light via the WLED API. In this session, you&rsquo;ll see how Copilot CLI hooks work under the hood, and leave knowing how to write your own for any use case.</p>



<h2 class="wp-block-heading" id="h-build-what-s-next">Build what&rsquo;s next</h2>



<p class="wp-block-paragraph">Want to know what&rsquo;s on the horizon? These are the talks that pull back the curtain on where AI-assisted development is heading.</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1776470103196001fJPe?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>The view from the labs: What&rsquo;s next for AI-assisted development</strong><br /></a><em>Cara Phillips, Anthropic; Rohan Varma, OpenAI; Kate Catlin, GitHub<br /></em>The people building frontier AI models see where capabilities are heading before anyone else. This interactive panel brings leaders from Anthropic, OpenAI, and other labs that power GitHub Copilot together for a candid look at the next two years of AI-assisted development, and what it means for you.</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1777489102123001ThSM?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>Open pull requests, don&rsquo;t merge them: Fine-grained authorization for hosted MCP servers</strong><br /></a><em>Nick Taylor, Pomerium<br /></em>Hosted MCP servers hand every agent everything its human can do: OAuth in, broad scope out, one global toggle. But what if an agent should open a pull request and leave the merge to a reviewer? See a pattern that works today: an identity-aware proxy that adds per-identity authorization in front of any hosted MCP server with no changes upstream, demonstrated live with Copilot doing exactly that.</p>



<p class="wp-block-paragraph"><a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/sessioncatalog/session/1777439139735001Ke6p?utm_source=GitHub&amp;utm_medium=Blog&amp;utm_campaign=aglaunch_eb_uni_26"><strong>From writing code to managing agents: Scaling 50+ services at GitHub</strong><br /></a><em>Anjuan Simmons, GitHub<br /></em>GitHub&rsquo;s Lifecycle team traded hand-coding fixes across 50+ services for an agentic pipeline where AI agents classify issues, research codebases, write implementation plans, and open draft pull requests automatically. Get the real lessons and numbers from running it at GitHub&rsquo;s own scale: how it was built with GitHub Actions and Copilot, where automation pays off most, and why engineers still deliberately write some code by hand.</p>



<h2 class="wp-block-heading" id="h-cast-your-vote">Cast your vote!</h2>



<p class="wp-block-paragraph">Three breakout sessions are heading to Universe this year, but we need your help deciding which one makes it to the main stage. Read through the descriptions, then <a href="https://reg.githubuniverse.com/flow/github/universe26/attendee-portal/page/shapethelineup?utm_source=Blog&amp;utm_medium=GitHub&amp;utm_campaign=launch_seb_uni_26">cast your vote before August 21</a>. Whichever session wins will also be available on demand, so even if you can&rsquo;t join us in person, your vote shapes what you&rsquo;ll get to watch later.</p>



<p class="wp-block-paragraph"><strong>Session 1: Why sketching in code matters more in the age of AI</strong><br /><em>Qianqian Ye, Processing Foundation / University of Southern California; John Maeda, GitHub<br /></em>AI can generate clean, working code from a short prompt, so the real question now is how to understand what&rsquo;s been made. Qianqian Ye draws on teaching creative coding at USC and leading p5.js to show why sketching and thinking in code builds the intuition to shape systems, not just prompt them.</p>



<p class="wp-block-paragraph"><strong>Session 2: Still open: How AI reshaped open source</strong><br /><em>Angie Jones, Agentic AI Foundation; David A. Wheeler, The Linux Foundation; Priya Pahwa, Django Software Foundation</em><br />Open source is being stress tested. While AI has accelerated contributions, it&rsquo;s also raised hard questions about quality, governance, and the power of community when bots can contribute at machine scale. In this session, you&rsquo;ll learn why AI makes open source more essential than ever.</p>



<p class="wp-block-paragraph"><strong>Session 3: The human side of AI: How building community drove 94% Copilot adoption</strong><br /><em>Brittany Istenes, Independent<br /></em>What if scaling AI isn&rsquo;t about better models, but better human connection? A large U.S.-based financial services firm hit 94% Copilot adoption and 78% agent-written code, and the driving force was community, not tooling. In this session, you&rsquo;ll discover how grassroots engagement, storytelling, and innersource made AI something developers actually wanted to use and build together.</p>
