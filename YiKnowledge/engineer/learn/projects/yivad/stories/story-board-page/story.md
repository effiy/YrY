# Story Board Page

A Kanban-style story management board for tracking feature stories, epics, and tasks across the full development lifecycle (planning → design → develop → testing → operations → archived). Supports card/list dual views, multi-dimensional filtering (project/time/search), scenario management with Gherkin-style Given/When/Then steps, and AI-powered Claude Code prompt generation via Ollama integration.
