# YiVad 开发规范

> 完整规范详见 [engineer/projects/04-项目-YiVad项目.md](../../../projects/04-项目-YiVad项目.md) 和 [YiVad/CLAUDE.md](../../../../YiVad/CLAUDE.md)。以下为快速参考。

## 命名约定

| 范畴 | 规范 | 示例 |
|---|---|---|
| 组件 | PascalCase | `ProTable.vue`, `ChatInput.vue` |
| 组合式函数 (Composables) | camelCase | `useTable.ts`, `useTheme.ts` |
| Store | camelCase | `aiChat.ts`, `globalStore.ts` |
| API 模块 | camelCase | `dataService.ts`, `chatService.ts` |
| CSS 类 | kebab-case | `.pro-table`, `.chat-input` |

## 标准模式（必须遵守）

### ProTable — 标准表格组件

YiVad 的核心数据展示模式。**任何新表格页面必须使用 ProTable，严禁直接使用 `el-table`。**

```vue
<ProTable
  :columns="columns"
  :requestApi="getTableData"
  :pagination="true"
  :searchCol="searchCol"
/>
```

ProTable 内置了搜索、分页、排序、列配置、行选择、导出功能——这些都是裸 `el-table` 需要手动实现的功能。

### v-auth — 按钮级权限

**禁止使用 `v-if` 配合 auth 状态来控制按钮显隐。** 统一使用 `v-auth` 指令。

```vue
<!-- 正确 -->
<el-button v-auth="'user:add'">添加用户</el-button>

<!-- 错误 —— 不要这样用 -->
<el-button v-if="authStore.hasPermission('user:add')">添加用户</el-button>
```

### RequestHttp — 唯一 HTTP 入口

**所有 HTTP 调用必须通过 `RequestHttp` 类。** 禁止在任何地方直接导入 `axios`。

```typescript
// 正确
import http from '@/api';
const res = await http.post('', body);

// 错误 —— 不要在 Store 或组件中直接使用 axios
import axios from 'axios';
```

### RPC 信封

所有跨项目调用使用统一的 RPC 格式：

```typescript
const body = {
  module_name: 'services.database.data_service',
  method_name: 'query_documents',
  parameters: { cname: 'projects', filter: {}, pageNum: 1, pageSize: 20 }
};
```

## RPC 字段契约（关键约束）

| 正确 | 错误 | 上下文 |
|---|---|---|
| `filter` | `query` | `data_service.query_documents` —— 后端 `_build_filter` 读取 `filter` 键 |
| `target_file` | `path` | `fileService.readFile/writeFile` —— 后端 Pydantic 模型字段名为 `target_file` |

## SSE `onDone` 守卫

**每个带有外部副作用的 SSE `onDone` 处理器必须在执行前检查 `!aborted && !error`：**

```typescript
// 正确
onDone: () => {
  if (!lastPet?.aborted && !lastPet?.error) {
    autoForwardToRobots(streamed);  // 仅在自然完成时转发
  }
}

// 错误 —— 中止的流也会触发副作用
onDone: () => {
  autoForwardToRobots(streamed);
}
```

## 编码风格

| 规范 | 说明 |
|---|---|
| 组件风格 | `<script setup lang="ts">` + Composition API —— **禁止 Options API** |
| Props/Emits | `defineProps<{...}>()` / `defineEmits<{...}>()` |
| 状态管理 | Pinia setup-function 语法 |
| 样式 | Scoped SCSS，变量从 `src/styles/var.scss` 全局注入 |
| UI 组件 | Element Plus 2.14，`el-` 前缀 |
| 路径导入 | `@/` 别名跨模块，相对路径同目录 |
| 环境变量 | 前缀 `RSBUILD_ENV_`（禁止使用 `VITE_` 前缀） |

## 构建与检查

| 工具 | 用途 |
|---|---|
| Rsbuild 1 | 构建工具 |
| `vue-tsc --noEmit` | 类型检查（Rsbuild 构建时静默剥离类型，不检查） |
| ESLint 10 + Prettier 3 | Lint + 格式化 |
| Stylelint 17 | 样式检查 |
| Conventional Commits | commitlint + cz-git |
