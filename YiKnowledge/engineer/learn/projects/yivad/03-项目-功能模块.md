## API 模块（18 个）

所有模块位于 `src/api/modules/`，通过 `RequestHttp` 发送 RPC 信封到 YiAi：

| 模块 | 用途 |
|---|---|
| `sessions.ts` | 会话 CRUD |
| `chatService.ts` | AI 聊天（SSE 流式） |
| `dataService.ts` | 通用 MongoDB CRUD |
| `fileService.ts` | 文件读写（`target_file` 参数） |
| `faqService.ts` | FAQ 管理 |
| `weChatService.ts` | 企业微信消息 |
| `knowledgeService.ts` | 知识库扫描/读取/写入 |
| `ragService.ts` | RAG 检索/聊天 |
| `agentService.ts` | Agent 聊天/确认/steer |
| `authService.ts` | 认证 |
| `menuService.ts` | 菜单管理 |
| `storyService.ts` | Story 管理 |
| `bugService.ts` | Bug 管理 |
| `configService.ts` | 配置管理 |
| `rssService.ts` | RSS 管理 |
| `uploadService.ts` | 文件上传 |
| `userService.ts` | 用户管理 |
| `logService.ts` | 日志管理 |
