# YiVad 架构设计

> 完整架构详见 [engineer/projects/04-项目-YiVad项目.md](../../../projects/04-项目-YiVad项目.md)。本文为快速参考摘要。

## 分层架构

```
Views (页面组件，按功能域组织)
  → Components (可复用组件) + Hooks (逻辑复用)
    → Stores (Pinia 状态管理)
      → API Modules (领域服务)
        → RequestHttp (Axios 封装 + RPC 信封)
          → YiAi Backend (FastAPI :10086)
```

## 关键组件

| 层 | 实现 | 职责 |
|---|---|---|
| 布局系统 | 4 种模式（纵向/经典/横向/分栏）通过 `globalStore.layout` 切换 | 应用外壳：Header、Menu、Footer、Tabs |
| 路由系统 | Vue Router 5 hash 模式，动态路由从后端菜单 API 获取 | 页面导航：静态路由（登录/404）+ 动态路由（菜单驱动） |
| ProTable | 声明式表格，由 `ColumnProps[]` 驱动，封装搜索/分页/排序/导出 | **YiVad 标准表格模式**——禁止直接使用 `el-table` |
| 权限指令 | `v-auth` 指令级按钮权限，从 DOM 中移除无权限元素 | 按钮级权限控制，与路由守卫解耦 |
| HTTP 封装 | `RequestHttp` Axios 包装器——拦截器、取消、错误映射 | 所有 HTTP 请求的统一出口 |
| 状态管理 | Pinia 4 setup 函数语法 + `pinia-plugin-persistedstate` 持久化 | 全局状态、用户、权限、AI 聊天、知识库、RAG |

## 关键数据流

### 表格数据获取

```
View 组件
  → ProTable(:columns, :requestApi)
    → api/modules/dataService.ts
      → http.post("", { module_name: "services.database.data_service",
                         method_name: "query_documents",
                         parameters: { cname, filter, pageNum, pageSize } })
        → RequestHttp 拦截器（注入 Token、Loading）
          → Axios POST → YiAi RPC 分发器 → MongoDB
        ← { code: 0, data: { list: [...], total: 100 } }
      ← 返回 { list, total }
    ← ProTable 渲染表格行
```

### AI 聊天 SSE 流式

```
aiChat Store
  → streamChat(messages)
    → fetch POST / { module_name: "services.ai.chat_service", method_name: "chat" }
      → SSE text/event-stream 解析
        → onChunk: 增量更新消息文本
        → onDone: 检查 !aborted && !error → 执行副作用（如 WeCom 转发）
```

### 文件读写

```
fileService.readFile(target_file)
  → POST /read-file { target_file: "/engineer/build/rpc-protocol.md" }
    → YiAi 文件处理器 → 返回 { content, is_base64 }
```

**关键约束**：参数名是 `target_file` 不是 `path`。使用 `path` 会返回 HTTP 422。

| 切面 | 实现 |

## 降级策略

| 故障场景 | 系统行为 |
|---|---|
| 后端菜单 API 不可用 | 回退到静态菜单文件 `src/assets/json/authMenuList.json` |
| Token 过期 | 401 拦截器跳转登录，清除 user/auth Store |
| 类型检查失败 | `vue-tsc --noEmit` 阻断 `pnpm build:*` |
| SSE 流中断 | 消息标记 `aborted=true`，跳过 WeCom 自动转发 |
