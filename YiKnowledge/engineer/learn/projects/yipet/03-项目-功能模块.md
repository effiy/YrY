# YiPet 功能模块清单

> 完整模块清单详见 [engineer/projects/03-项目-YiPet项目.md](../../../projects/03-项目-YiPet项目.md)。以下为快速参考。

## Popup 弹窗 (`src/popup/`)

| 模块 | 文件 | 职责 |
|---|---|---|
| 根组件 | `App.tsx` | 皮肤中心：角色选择、颜色选择、模型设置 |
| 入口 | `index.tsx` | ReactDOM 挂载 |
| 配置适配器 | `data.ts` | 颜色/角色/模型配置数据 |

**组件清单**：`AppHeader`（渐变色头部）、`PetPreview`（宠物预览与皮肤环）、`ColorPicker`（6 色选择器）、`RolePicker`（2 列角色卡片）、`AppFooter`（底部提示）、`AboutCard`（关于信息）

## 聊天窗口 (`src/chat/`)

| 模块 | 文件 | 职责 |
|---|---|---|
| 控制器 | `controller.ts` | 状态机：流式处理、操作、中止——所有聊天逻辑的核心（约 3000 行） |
| 类型 | `types.ts` | `ChatState` 类型定义 |

**组件清单**（19 个）：`ChatWindow`（主窗口：拖拽/缩放/全屏）、`ChatInput`（输入框：@mention/文件预览/发送）、`ChatMessages`（消息列表）、`MessageBubble`（消息气泡：操作按钮/token 芯片）、`ChatSidebar`（侧边栏：会话/知识/Stories/Bugs 四标签）、`ChatToolbar`（工具栏：导出/分支/跨项目导航）、`ChatHeader`（头部）、`SessionStatusBar`（状态栏：token/模型/阶段/sparkline）、`ContextScopeBar`（上下文范围条）、`SearchBar`（搜索栏）、`QuickButtons`（快捷按钮）、`FileMentionDropdown`（@文件下拉）、`KnowledgePreviewDialog`（知识预览）、`RagSourcesPreviewDialog`（RAG 来源预览）、`RagDecomposeDialog`（子问题分解）、`SessionSummaryDialog`（会话摘要）、`SessionEditDialog`（会话编辑）、`BugReportDialog`（Bug 报告）、`SaveToKnowledgeDialog`（保存到知识库）、`PageContextEditor`（页面上下文编辑）

## Content Script (`src/content/`)

| 模块 | 文件 | 职责 |
|---|---|---|
| 双世界入口 | `bootstrap.ts` | 第一阶段（ISOLATED）→ 第二阶段（MAIN）的自注入流程 |
| CDN 目录 | `cdn/catalog.ts` | 80+ 第三方库资源清单（单一事实来源） |
| CDN 注入器 | `cdn/injector.ts` | 按需注入 CDN 资源，全局存在检查短路重复注入 |
| 跨世界通信 | `ipc/messages.ts` | ISOLATED ↔ MAIN 的消息类型定义 |
| 宠物渲染 | `rendering/overlay.ts` | 浮动宠物 DOM（皮肤环、角色图片、工具提示） |

## API 服务层 (`src/api/services/`)

| 服务 | 文件 | RPC 调用 |
|---|---|---|
| AuthService | `auth.ts` | 认证 |
| ChatService | `chat.ts` | `services.ai.chat_service.chat`（SSE 流式） |
| SessionService | `sessions.ts` | `data_service.query_documents("sessions", ...)` |
| ConfigService | `config.ts` | 配置管理 |
| DatabaseService | `database.ts` | `data_service.*`（通用 CRUD） |
| FaqService | `faq.ts` | FAQ CRUD |
| KnowledgeService | `knowledge.ts` | `knowledge_service.*` |
| RagService | `rag.ts` | `rag_service.*` |
| BugService | `bug.ts` | `data_service.*` + `knowledge_service.write` |

## 共享模块 (`src/shared/`)

| 模块 | 职责 |
|---|---|
| `i18n/` | 类型化的 `t('key')` 函数，55+ 键，`en` 回退 |
| `theme/` | 主题变量系统 |
| `roles.ts` | 角色定义与配置 |
| `state.ts` | Chrome Storage API 封装 |
| `env.ts` | 环境检测 |
| `log.ts` | 开发日志 |

## Background Service Worker (`src/background/`)

- 命令分发：`Ctrl+Shift+P`（切换宠物显隐）、`Ctrl+Shift+X`（打开聊天窗口）
- 消息路由：Popup ↔ Content Script 的消息中转
