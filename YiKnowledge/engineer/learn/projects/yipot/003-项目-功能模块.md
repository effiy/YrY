# YiPot 功能模块清单

> 完整模块清单详见 [engineer/projects/0005-项目-YiPot项目.md](../../../projects/005-项目-YiPot项目.md)。以下为快速参考。

## 一、前端窗口模块（8 大窗口）

`src/window/` 下每个子目录对应一个独立的 Tauri WebviewWindow，按需懒加载。

| 窗口 | 路由目录 | 职责说明 | 关键子组件 / 页面 |
|---|---|---|---|
| **Main 翻译窗口**（Translate） | `src/window/Translate/` | 主交互窗口：输入翻译、划词翻译唤起入口、剪切板翻译展示 | `LanguageArea/`（源/目标语言切换）、`SourceArea/`（输入区）、`TargetArea/`（结果展示、发音、收藏） |
| **Config 配置中心** | `src/window/Config/` | 所有设置聚合页：常规 / 翻译 / OCR / TTS / 热键 / 历史 / 备份 / 关于 | 8 个 pages：`General/`, `Translate/`, `Recognize/`, `TTS/`, `Hotkey/`, `History/`, `Backup/`, `About/` + `SideBar/` 导航 |
| **OCR 识别窗口**（Recognize） | `src/window/Recognize/` | 截图识别结果确认页：图片预览 + 文本编辑 + 一键翻译 | `ImageArea/`（原图 + 框选层）、`TextArea/`（可编辑识别文本）、`ControlArea/`（操作按钮栏） |
| **Screenshot 截图窗口** | `src/window/Screenshot/` | 全屏覆盖浮层：鼠标拖拽框选 OCR 区域、快捷键取消/确认 | 全屏 Canvas 绘制矩形选区，ESC 取消 / Enter 确认回调 Recognize |
| **Wordbook 生词本**（Chat / History） | `Config/pages/History/` + `services/collection/` | 历史记录 + 收藏生词：按时间浏览、批量导出、同步到 Anki / 欧路词典 | 列表 + 搜索框 + 导出（JSON/CSV） + Anki 一键推送 |
| **Chat 对话模式** | 预留窗口 | 连续多轮翻译对话：上下文保留、角色扮演翻译、润色改写 | 依赖 YiAi RAG / LLM（v2.x 路线图） |
| **About 关于页** | `Config/pages/About/` | 版本号、许可证、作者信息、检查更新、开源协议、跳转官网 | 展示 Bundle ID `com.yipot.desktop`、GitHub 链接、CHANGELOG 入口 |
| **Backup 备份恢复** | `Config/pages/Backup/` | 设置导出/导入、WebDav 同步、阿里云 OSS 备份 | `WebDavModal/`、`AliyunModal/`、utils：`local.jsx` / `webdav.jsx` / `aliyun.jsx` |
| **Updater 升级窗口**（额外） | `src/window/Updater/` | 检测到新版本时弹出：changelog 展示 + 下载进度 + 重启安装按钮 | 配合 `src-tauri/src/updater.rs` 使用 Tauri 官方 updater |

## 二、Rust 后端模块（11 个）

`src-tauri/src/` 下每个 `.rs` 文件为独立模块，在 `main.rs` 中通过 `mod xxx;` 引入。

| 模块 | 文件 | 职责说明 | 关键 Struct / Command |
|---|---|---|---|
| **main 入口与 setup** | `main.rs` | Tauri Builder 初始化：注册所有 commands、设置托盘、创建主窗口、加载图标、插件初始化 | `fn main()`、`#[tokio::main]`、`tauri::Builder::default()` |
| **托盘菜单** | `tray.rs` | 系统托盘图标 + 右键菜单：显示/隐藏主窗口、截图翻译、剪切板翻译、设置、退出 | `TrayId`, `TrayIcon`, `on_menu_event` 匹配 ID |
| **备份模块** | `backup.rs` | WebDav / 本地文件 导入导出配置和生词本数据 | `export_to_webdav()`, `import_from_webdav()`, `backup_local()` |
| **HTTP Server** | `server.rs` | 内嵌 `axum` / `hyper` HTTP 服务，监听 `127.0.0.1:60828`，供 PopClip / SnipDo 扩展调用 | `start_http_server()`, route `/translate`, `/ocr` |
| **Commands 聚合** | `cmd.rs` | 所有 `#[tauri::command]` 函数统一在此声明（转发到各子模块），保证 main.rs 干净 | `pub fn register_all_commands() -> Vec<InvokeHandler>` |
| **窗口管理** | `window.rs` | 创建/销毁/聚焦各 WebviewWindow；窗口参数配置；跨窗口传值 emit 事件 | `show_translate_window(initial_text)`, `show_screenshot_window()` |
| **本地 OCR** | `system_ocr.rs` | 封装平台原生 OCR：macOS Vision.framework / Windows OCR API / Linux Tesseract CLI | `fn system_ocr(image_bytes: &[u8], lang: &str) -> Result<String>` |
| **剪切板监听** | `clipboard.rs` | 启动后台线程轮询或监听 OS 剪贴板变化，新内容时 emit 事件给前端（剪切板翻译） | `ClipboardMonitor`, `start_monitor()`, `stop_monitor()` |
| **全局热键** | `hotkey.rs` | 注册/注销全局快捷键：划词翻译（默认 Cmd+Shift+T）、截图 OCR（默认 Cmd+Shift+S） | `register_hotkeys()`, `unregister_hotkeys()` |
| **截图捕获** | `screenshot.rs` | 调用 Tauri `window.capture` 或原生 API 获取全屏像素，返回 PNG base64 给 Screenshot 窗口 | `fn capture_display(display_id: u32) -> Result<Vec<u8>>` |
| **自升级** | `updater.rs` | 基于 Tauri updater + GitHub Release API 检查新版本、下载差分包、校验签名、安装重启 | `check_update()`, `download_and_install()` |
| **其他** | `config.rs` / `error.rs` / `lang_detect.rs` | 配置读写（config.rs）、统一错误类型（error.rs，thiserror）、本地语言检测（lingua） | `struct AppConfig`, `enum YiPotError`, `detect_langs(text: &str)` |

## 三、Services 层插件（4 类 30+）

`src/services/{category}/{plugin_id}/`，每类遵循「三件套规范」：info.ts + index.jsx + Config.jsx。

### 3.5 Services 调度入口

| 文件 | 职责 |
|---|---|
| `src/services/translate/index.jsx` | 翻译服务调度：选当前 provider → 调用 → 失败自动切换备用 → 返回结果 |
| `src/services/recognize/index.jsx` | 识别服务调度：同上 |
| `src/services/tts/index.jsx` | TTS 服务调度：同上 |
| `src/services/collection/index.jsx` | 生词本服务调度：可同时调用多个（Anki + 本地同时写） |
| `src/utils/service_instance.ts` | 插件元数据 registry，基于 info.ts 动态加载所有已注册插件 |
| `src/utils/invoke_plugin.js` | 统一插件调用函数：`invokePlugin(category, pluginId, params)`，熔断器 + 超时包一层 |

## 四、共享层与基础设施

| 模块 | 路径 | 职责说明 |
|---|---|---|
| **状态管理（Jotai）** | 分散在 hooks 与 window 内 | atoms：翻译源/目标文本、服务配置、热键、UI 主题 |
| **Hooks 集合** | `src/hooks/` | `useConfig.jsx` 读写配置；`useGetState.jsx` 获取跨窗口共享状态；`useSyncAtom.jsx` 持久化同步；`useToastStyle.jsx` 统一 Toast；`useVoice.jsx` 播放 TTS |
| **i18n 多语言** | `src/i18n/` | 21 种语言：`zh_CN`、`en_US`、`ja_JP`、`ko_KR`、`de_DE`、`fr_FR`、`es_ES`、`ru_RU`、`ar_AE` 等，`index.jsx` 基于当前配置切换 |
| **UI 组件** | `src/components/` + NextUI | `WindowControl/`（红绿灯窗口按钮）+ 所有窗口直接用 NextUI（Button/Input/Select/Switch/Tabs/Modal） |
| **工具函数** | `src/utils/` | `index.js`（通用工具）、`env.js`（区分 dev/prod、平台）、`lang_detect.js`（前端语言检测后备）、`language.ts`（ISO 639-1 ↔ 中文 ↔ 插件支持列表映射） |
| **样式** | Tailwind + `src/style.css` + 各窗口内 `style.css` | CSS 变量前缀 `--yp-*`，Tailwind 主题扩展在 `tailwind.config.cjs` |
