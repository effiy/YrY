# YiPot 开发规范

> 完整规范详见 [engineer/projects/0005-项目-YiPot项目.md](../../../projects/005-项目-YiPot项目.md) 和 [YiPot/CLAUDE.md](../../../../../YiPot/CLAUDE.md)。以下为快速参考。

## 命名约定

| 范畴 | 规范 | 示例 | 禁止 |
|---|---|---|---|
| Rust 文件/函数/变量 | `snake_case` | `backup.rs`, `fn save_config()`, `hotkey_manager` | `camelCase` 文件名 |
| Rust 结构体/枚举 | `PascalCase` | `struct AppState`, `enum BackupError` | — |
| Rust 常量 | `SCREAMING_SNAKE_CASE` | `const HTTP_PORT: u16 = 60828;` | 硬编码魔法数字 |
| React 文件/组件 | `PascalCase`（组件）+ 目录 `PascalCase/` | `Config/index.jsx`, `<LanguageArea />` | `snake_case` 组件名 |
| React 变量/函数 | `camelCase` | `const handleTranslate = () => {}`, `sourceText` | `snake_case` |
| React Hooks | `use` 前缀 `camelCase` | `useConfig.jsx`, `useVoice.jsx` | 无 `use` 前缀的自定义 hook |
| CSS 变量 | `--yp-` 前缀 + `kebab-case` | `--yp-primary-color`, `--yp-window-radius` | 无前缀、`snake_case`、数字结尾如 `--color2` |
| Tailwind 工具类 | 默认 `kebab-case` | `bg-slate-50`, `text-lg` | 自定义类不带 `--yp-` 前缀 |
| Services 插件目录 | 小写 `kebab-case` 或品牌原拼写 | `services/translate/deepl/`, `services/recognize/tesseract/` | 大写开头目录名 |
| i18n locale 文件 | `语言_CODE.json` | `zh_CN.json`, `en_US.json` | 随意命名 |
| Store 键（前端） | `yp:` 前缀 + `camelCase` | `yp:translate.service`, `yp:ocr.defaultProvider` | 无前缀、纯数字键 |

## 分层纪律

```
Window (UI)  →  Hooks  →  Services  →  Tauri Bridge  →  Rust Backend
     ↓             ↓           ↓              ↓                ↓
  禁止越层    仅封装逻辑   插件适配层   统一 invoke   系统能力原语
```

### 核心约束

| 约束 | 说明 | 正确示例 | 错误示例 |
|---|---|---|---|
| **Window 组件不得直接调用 `window.__TAURI__`** | 必须通过 hooks 或 services 层间接调用 | `const { config } = useConfig();` | `invoke('get_config')` 直接写在 JSX |
| **Services 层不得直接依赖 Tauri API 全局对象**（system_ocr 等例外需标注） | 通过 `invoke_plugin.js` 统一封装 | `await invokePlugin('translate', args)` | `window.__TAURI__.clipboard` 直接在插件内使用 |
| **Rust command 返回值必须为 `anyhow::Result<T>`** | 禁止裸返回 `T`，所有错误统一向上转换 | `fn save_config() -> Result<(), Error>` | `fn save_config()` 无返回类型 |
| **`unwrap()` / `expect()` 禁令**（生产代码） | 必须用 `?`、`match`、`unwrap_or_default()`、`if let Some()` | `let port = port.unwrap_or(60828);` | `config.unwrap()` 导致 panic |
| **插件禁止硬编码 API Key** | 所有密钥通过 Config.jsx 让用户填入并存储在本地 store | `apiKey = config.apiKey` | `const KEY = "sk-xxx"` 写死在 index.jsx |

### 正确调用链路示例

```jsx
// src/window/Translate/index.jsx  →  窗口层只渲染，不处理业务
const TranslateWindow = () => {
  const { translate, isLoading } = useTranslateService();
  const onTranslate = async () => { await translate(sourceText); };
  return <TargetArea result={result} />;
};

// src/services/translate/deepl/index.jsx  →  服务层只做协议适配
export const translate = async (text, { sourceLang, targetLang, apiKey }) => {
  const resp = await fetch('https://api-free.deepl.com/v2/translate', { body });
  return resp.json();  // 不直接调用 tauri
};
```

## 插件三件套规范

`src/services/{category}/{name}/` 下必须包含以下三个文件，缺一不可：

| 文件 | 职责 | 输出/导出 | 约束 |
|---|---|---|---|
| **`info.ts`** | 插件元数据清单 | 默认导出一个对象：`{ id, name, description, category, version, author, website, icons[], supportedLangs[], requiredKeys[], features[] }` | `id` 唯一且等于目录名；`supportedLangs` 非空数组；`requiredKeys` 列出 Config.jsx 中必填字段 |
| **`index.jsx`** | 核心业务实现 | 按 category 导出固定方法：<br/>translate → `export async function translate(text, opts)`<br/>recognize → `export async function recognize(imageBase64, opts)`<br/>tts → `export async function speak(text, opts)`<br/>collection → `export async function addWord(word, opts)` | 方法签名与 category 对齐；返回值 schema 遵循 `service_instance.ts` 定义 |
| **`Config.jsx`** | 用户配置表单 UI | 默认导出 React 组件，接收 `{ value, onChange }` props | 必须使用 NextUI 组件（Input / Select / Switch）；表单 state 受控；密码字段用 `type="password"` + 眼睛图标切换 |

### info.ts 最小示例（services/translate/deepl/info.ts）

```ts
export default {
  id: "deepl",
  name: "DeepL",
  category: "translate",
  version: "1.0.0",
  description: "DeepL Pro / Free API 翻译服务",
  author: "YiPot",
  icons: ["/logo/deepl.svg"],
  supportedLangs: ["zh", "en", "ja", "ko", "de", "fr", "es", "ru"],
  requiredKeys: ["apiKey"],
  features: ["formality", "glossary"],
};
```

### index.jsx 方法签名约定

| Category | 方法签名 | 返回值（Promise） |
|---|---|---|
| translate | `translate(text: string, { sourceLang, targetLang, ...config })` | `{ text: string, dict?: DictEntry, alternatives?: string[] }` |
| recognize | `recognize(imageBase64: string, { lang, ...config })` | `{ text: string, lines?: { text, bbox }[] }` |
| tts | `speak(text: string, { lang, voice, rate, ...config })` | `{ audioBase64?: string, directPlay?: boolean }` |
| collection | `addWord(word: WordEntry, { ...config })` | `{ success: boolean, id?: string }` |

## 错误处理规范

### Rust 后端

| 场景 | 做法 |
|---|---|
| 函数返回类型 | 统一 `anyhow::Result<T>`，自定义错误在 `error.rs` 用 `thiserror` 派生 |
| 可恢复错误 | `?` 冒泡到 command 层，Tauri 自动序列化为前端 Promise reject |
| 配置缺失 | 返回 `Err(anyhow::anyhow!("Missing config key: {}", key))`，带用户可读信息 |
| IO / 网络错误 | 保留原始 source：`.with_context(|| "Failed to read config file")` |
| 禁止 | `unwrap()`、`expect("msg")`、`panic!()`（测试和 `main.rs` setup 初始化 `expect("must not fail")` 除外，必须附说明） |

### React 前端

| 场景 | 做法 |
|---|---|
| Promise 错误捕获 | `try/catch` + Toast 提示（`useToastStyle.jsx`），禁止静默吞错 |
| 空值安全 | 可选链 `?.`、`??` 默认值、`useSyncAtom` 带 fallback |
| 插件调用失败 | `services/*/index.jsx` 抛出 `Error`，由 `invoke_plugin.js` 统一处理并切换备用 |
| 禁止 | `JSON.parse()` 无 try、`array[0].field` 无判断、`.catch(() => {})` 空 catch 块 |

## 定时器 / 监听器生命周期纪律

| 资源 | 创建位置 | 清理位置 | 反模式 |
|---|---|---|---|
| `setInterval` / `setTimeout` | React 组件 `useEffect(() => { const t = setInterval(...) })` | `useEffect` 返回函数 `() => clearInterval(t)` | 组件卸载后仍运行，内存泄漏 |
| `window.addEventListener` | 同上 `useEffect` | 返回函数中 `removeEventListener`，**必须保存 handler 引用**（匿名函数无法移除） | 每次 render 重复 addEventListener |
| Tauri `listen()` 事件监听 | `useEffect(async () => { const unlisten = await listen(...) })` | 返回函数 `() => unlisten()` | 忘记调用 unlisten 导致重复回调 |
| 全局热键注册（Rust） | `hotkey.rs` 在 App 销毁时 `GlobalShortcutManager::unregister_all` | `main.rs` 的 `on_window_event` CloseRequested | — |
| 剪贴板轮询（Rust） | `clipboard.rs` 持有 thread JoinHandle | Drop 时发送停止信号并 `.join()` | 线程未 join 导致进程 hang 退出 |

### 正确 React 清理示例

```jsx
useEffect(() => {
  let cancelled = false;
  const timer = setInterval(async () => {
    const data = await fetchClipboard();
    if (!cancelled) setClipboardText(data);
  }, 500);
  const unlisten = window.__TAURI__?.event?.listen('yp://clipboard', handler);
  return () => {
    cancelled = true;
    clearInterval(timer);
    unlisten?.then(f => f());
  };
}, []);
```

## 配置管理规范

### Rust 侧（`src-tauri/src/config.rs`）

| 项目 | 规范 |
|---|---|
| 存储格式 | `serde_json` → `config.json`，位于 AppConfig 目录 |
| 结构体 | `#[derive(Serialize, Deserialize, Clone, Debug)]` + `#[serde(default)]` |
| 默认值 | 实现 `impl Default for AppConfig`，所有字段必须有合理默认（端口 60828，自动更新 true 等） |
| 加载流程 | `fn load() -> Self`：读文件 → 解析失败 → 回退 Default + 记录 warn 日志 |
| 保存流程 | `fn save(&self) -> Result<()>`：原子写入（tmp + rename），防止中断损坏 |

### 前端侧（`src/utils/store.js`）

| 项目 | 规范 |
|---|---|
| 底层 | `localStorage` + Jotai `atomWithStorage` |
| 键前缀 | 所有 store key 以 `yp:` 开头，见命名约定 |
| 默认值 | atom 创建时必须传第二个参数 fallback，即使 `null` 也要显式 |
| 敏感字段 | API Key 存储前可选择加密（v2.x 路线图），至少 `type="password"` 显示掩码 |
| 已知键清单 | 集中在 `store.js` 顶部导出常量，禁止字符串字面量散落在组件里 |
