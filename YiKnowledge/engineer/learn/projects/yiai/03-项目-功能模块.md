# YiAi 功能模块清单

> 完整模块清单详见 [engineer/projects/01-项目-YiAi项目.md](../../../projects/01-项目-YiAi项目.md)。以下为快速参考。

## Domain 模块（10 个）

| 模块 | 路径 | 职责 | 关键文件 |
|---|---|---|---|
| AI 聊天与 Agent | `domain/ai/` | AI 聊天、工具注册、Agent 循环 | `chat.py`, `agent.py`, `tools.py`, `data_tools.py` |
| 认证 | `domain/auth/` | JWT + bcrypt 认证 | `jwt.py`, `password.py` |
| 模块执行 | `domain/execution/` | 通用模块执行器 | `executor.py` |
| 文件管理 | `domain/files/` | 文件 CRUD、OSS 上传、双写持久化 | `local.py`, `storage.py`, `paths.py` |
| 知识库 | `domain/knowledge/` | Markdown 扫描、监听、写入 | `scanner.py`, `watcher.py`, `writer.py` |
| RAG 检索 | `domain/rag/` | RAG 引擎、索引构建、混合检索 | `engine.py`, `indexer.py`, `settings.py` |
| RSS 聚合 | `domain/rss/` | RSS 源解析、定时抓取 | `parser.py`, `scheduler.py` |
| 状态存储 | `domain/state/` | 状态记录 CRUD | `store.py` |
| 企业微信 | `domain/wework/` | 企业微信消息发送 | `sender.py` |

## Service 层（7 个）

| Service | 路径 | 封装内容 | RPC 方法 |
|---|---|---|---|
| 聊天服务 | `services/ai/chat_service.py` | AI 聊天流式输出 | `chat`, `chat_rag` |
| 数据服务 | `services/database/data_service.py` | 通用 CRUD（通过 RPC 信封） | `query_documents`, `create_document`, `update_document`, `delete_document` |
| 模块执行器 | `services/execution/executor.py` | 模块执行 | `execute` |
| 知识库服务 | `services/knowledge/knowledge_service.py` | 知识扫描/读取/写入 | `scan`, `read`, `write` |
| RAG 服务 | `services/rag/rag_service.py` | RAG 查询/聊天 | `query`, `chat` |
| RSS 服务 | `services/rss/` | RSS 源管理 + 定时调度 | `fetch`, `list` |
| OSS 客户端 | `services/storage/oss_client.py` | 阿里云 OSS 对象存储 | `upload`, `download` |

## 路由模块（18 个）

注册在 `src/app.py`，覆盖完整的 API 面：

| 路由前缀 | 文件 | 说明 | 端点数 |
|---|---|---|---|
| `/` | `app.py`（根路由处理器）| RPC 分发器 | 1 |
| `/about` | `about.py` | 服务信息 | 1 |
| `/auth/*` | `auth.py` | 认证（登录/注册/Token）| 3 |
| `/users/*` | `users.py` | 用户管理 | 5 |
| `/system/*` | `system.py` | 系统信息 | 1 |
| `/files/*`, `/read-file`, `/write-file` | `files.py` | 文件操作 | 6 |
| `/execution/*` | `execution.py` | 模块执行 | 2 |
| `/wework/*` | `wework.py` | 企业微信消息 | 2 |
| `/maintenance/*` | `maintenance.py` | 维护操作 | 2 |
| `/state/*` | `state.py` | 状态存储 | 3 |
| `/agent/*` | `agent.py` | Agent 聊天/确认/steer | 4 |
| `/health` | `health.py` | 健康检查 | 1 |
| `/knowledge/*` | `knowledge.py` | 知识库扫描/读取/写入 | 5 |
| `/rag/*` | `rag.py` | RAG 检索/聊天/构建/状态 | 6 |
| `/search/*` | `search.py` | 全局搜索 | 1 |
| `/mcp/*` | `mcp.py` | MCP 协议 | 2 |
| `/dashboard/*` | `dashboard.py` | 仪表盘数据（最大模块）| 8 |
| `/v1/*` | `openai_compat.py` | OpenAI API 兼容接口 | 3 |

**总端点数**：约 55 个

## 数据访问层

| 模块 | 职责 | 关键方法 |
|---|---|---|
| `data/database.py` | MongoDB 单例（Motor async） | `get_db()`, `get_collection()` |
| `data/repository.py` | 通用 CRUD | `query_documents`, `create_document`, `update_document`, `delete_document` |
| `data/sessions.py` | 会话数据操作 | `get_session`, `save_session`, `list_sessions` |
| `data/store.py` | 状态存储 | `get_state`, `set_state` |
| `data/seeds/` | 种子数据（JSON） | 启动时自动导入空集合 |
