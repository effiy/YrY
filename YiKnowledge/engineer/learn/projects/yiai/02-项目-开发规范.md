# YiAi 开发规范

> 完整规范详见 [engineer/projects/01-项目-YiAi项目.md](../../../projects/01-项目-YiAi项目.md) 和 [YiAi/CLAUDE.md](../../../../YiAi/CLAUDE.md)。以下为快速参考。

## 命名约定

| 范畴 | 规范 | 示例 |
|---|---|---|
| 文件 | snake_case | `chat_service.py`, `error_codes.py` |
| Domain 模块 | `domain/<name>/` 含 `__init__.py` 公开 API | `domain/ai/chat.py` |
| Service 层 | `services/<name>/<name>_service.py` | `services/ai/chat_service.py` |
| 路由模块 | `server/routes/<name>.py` | `server/routes/agent.py` |
| 数据模型 | Pydantic BaseModel，snake_case 字段 | `class FileReadRequest(BaseModel)` |

## 分层纪律

```
Routes → Services → Domain → Data（禁止越层）

- Routes 不能直接调用 data/（必须通过 services/）
- Domain 包不能导入 server/（领域逻辑与传输层无关）
- 调用者使用 __init__.py 的 re-export，不导入内部文件
```

### 正确的调用示例

```python
# ✓ 正确：Routes → Services → Domain → Data
from services.ai.chat_service import chat
result = await chat(**parameters)

# ✗ 错误：Routes 直接调用 Data
from data.repository import query_documents  # 不允许
```

## RPC 字段契约（关键约束）

这是 YrY 中最容易出错的环节。参数名不匹配不会产生任何编译错误或 lint 警告——后端只会静默忽略或返回 422。

| 正确 | 错误 | 上下文 | 检查方式 |
|---|---|---|---|
| `filter` | `query` | `data_service.query_documents` | 检查 `data/repository.py` 的 `_build_filter` |
| `target_file` | `path` | `/read-file`、`/write-file` | 检查 `server/routes/files.py` 的 Pydantic 模型 |
| `cname` | `collection_name` | `data_service` 集合参数 | 检查 `data/repository.py` 的 `query_documents` 签名 |

## 配置管理

- 配置文件：`config.yaml`（YAML 格式）
- 配置加载：pydantic-settings + `YamlConfigSettingsSource`
- 配置键：扁平 YAML 键（点分隔），如 `server.host`、`mongodb.uri`

```yaml
# config.yaml 结构示例
server:
  host: "0.0.0.0"
  port: 10086
mongodb:
  uri: "mongodb://localhost:27017"
  db_name: "ruiyi"
ollama:
  host: "http://localhost:11434"
  model: "qwen3.5:4b"
```

## 测试规范

| 属性 | 值 |
|---|---|
| 框架 | pytest 8 + pytest-asyncio + httpx + pytest-cov |
| 目录结构 | `tests/{unit,integration,eval}/` |
| 运行命令 | `python -m pytest tests/ -v` |
| 覆盖率目标 | shared/ 模块 90%+，services/ 70%+ |
| 标记 | `@pytest.mark.slow`（慢测试）、`@pytest.mark.integration`（集成测试）|

## SSE 流式响应规范

```python
from fastapi.responses import StreamingResponse

async def chat_stream():
    async for chunk in ollama_client.stream(prompt):
        yield f"data: {json.dumps({'content': chunk})}\n\n"
    yield "data: [DONE]\n\n"

return StreamingResponse(
    chat_stream(),
    media_type="text/event-stream"
)
```

## 日志规范

- 使用标准 Python `logging` 模块
- 格式：`%(asctime)s - %(name)s - %(levelname)s - %(message)s`
- 在 `tenacity` 的 `before_sleep_log` 中记录重试信息
- Domain 层记录业务日志，Data 层记录数据库操作日志
