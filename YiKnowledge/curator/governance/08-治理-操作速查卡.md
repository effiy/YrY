# 知识管理者操作速查卡

> 日常工作的一张纸。需要详细说明时再翻阅对应的治理文件。

## 每日（5 分钟）

```bash
# 1. 检查收件箱有无新条目
cat curator/governance/03-治理-收件箱.md | grep "| -- |"

# 2. 如有新条目，分类到角色目录
#    参考: 03-治理-收件箱.md 中的"清空流程的常见决策场景"

# 3. 抽查当日新增文件的 frontmatter
find YiKnowledge -name "*.md" -newer <昨天修改的文件> | head -5 | while read f; do
  for field in title tags category created updated source type status; do
    rg -q "^$field:" "$f" || echo "MISSING $field: $f"
  done
done
```

**判定标准：** 收件箱 0 条未处理 = 每日任务完成。

## 每周（20 分钟）

### 1. 清空分类队列
```bash
# 查找所有 lifecycle: triage 的文件
rg -l "^lifecycle: triage" YiKnowledge --type md
```
→ 逐文件执行[就绪检查清单](./04-治理-就绪检查清单.md)，通过后改 `lifecycle: active`

### 2. 新鲜度扫描
```bash
# 查找超过 6 个月未验证的文件
rg -l "^last_verified: 202[0-5]" YiKnowledge --type md
rg -l "^last_verified: 2026-0[1-3]" YiKnowledge --type md
```
→ 标记为待审查，通知对应 Reviewer

### 3. 死链抽查
```bash
# 检查最近修改文件的 related 链接
git diff --name-only HEAD~1 | grep "\.md$" | while read f; do
  grep -A10 "^related:" "$f" | grep "^- " | awk '{print $2}' | while read link; do
    ls "$(dirname "$f")/$link" 2>/dev/null || echo "DEAD: $f -> $link"
  done
done
```

### 4. 更新审查日志
在 [05-治理-审查日志](./05-治理-审查日志.md) 中记录本周操作。

## 每月（30 分钟）

### 1. 刷新健康看板
```bash
# 统计文件数
for role in engineer executiver leader aier producter srer curator; do
  echo "$role: $(find YiKnowledge/$role -name '*.md' | wc -l | tr -d ' ')"
done

# 统计 frontmatter 合规率
total=$(find YiKnowledge -name "*.md" -not -path "*/rss/*" | wc -l | tr -d ' ')
benefit=$(rg -l "^benefit:" YiKnowledge --type md | wc -l | tr -d ' ')
echo "benefit 覆盖率: $benefit / $total"
```
→ 更新 [01-治理-知识健康看板](./01-治理-知识健康看板.md) 的数据

### 2. 隐性知识审查
- 检查 [06-治理-隐性知识待办](./06-治理-隐性知识待办.md) 中各条目进度
- 从本月复盘中提取新的隐性知识项

### 3. 模板审查
- 抽查 2-3 个模板是否仍符合当前工作流
- 收集模板使用反馈

## 每季度（2 小时）

### 1. 全面审计
```bash
# 逐角色目录检查 last_verified
for role in engineer executiver leader aier producter srer curator; do
  echo "=== $role ==="
  find "YiKnowledge/$role" -name "*.md" | while read f; do
    last=$(rg "^last_verified:" "$f" | head -1 | awk '{print $2}')
    [[ -z "$last" ]] && echo "MISSING last_verified: $f"
  done
done
```

### 2. 4 张图验证
逐张检查 [diagrams/](../diagrams/) 中的 4 张图是否过时：
- [ ] 看板索引的数据是否准确
- [ ] 目录蓝图与实际目录结构是否一致
- [ ] 知识地图的文件计数和持有者是否正确
- [ ] 用户旅程的断点是否已修复

### 3. 归档清理
```bash
# 查找 status: deprecated 超过 6 个月的文件
rg -l "^status: deprecated" YiKnowledge --type md
```
→ 确认无交叉引用后移至 `archive/`，在 [归档索引](../archive/01-归档-归档说明.md) 中登记

### 4. 治理指标更新
对照 [02-治理-治理规范](./02-治理-治理规范.md) 中的"治理指标"表，更新 6 项指标数据。

## 常见场景处置

### 场景 1：收到新知识内容
```
判断是否为领域内容？
├── 是 → 放入对应角色目录，执行就绪检查清单
└── 否（关于 KB 本身）→ 放入 curator/，执行就绪检查清单
```
→ 在 [05-审查日志](./05-治理-审查日志.md) 记录 `created`

### 场景 2：发现过时文件
```
内容是否仍然准确？
├── 是 → 更新 last_verified，保持 active
└── 否 → 是否有替代文件？
    ├── 是 → 标记 deprecated + superseded_by，6 个月后归档
    └── 否 → 主题是否仍需要？
        ├── 是 → 修复/重写内容
        └── 否 → 标记 deprecated，6 个月后归档
```

### 场景 3：收件箱积压（> 10 条）
1. 暂停新内容收集
2. 逐条分类：能 1 分钟内判断归属的立即分，无法判断的标记 `[待分类]`
3. 30 分钟内清空至 5 条以下
4. 复盘积压原因，调整收集节奏

### 场景 4：死链修复
```bash
# 全局死链扫描
find YiKnowledge -name "*.md" -not -path "*/rss/*" | while read f; do
  dir=$(dirname "$f")
  grep -A10 "^related:" "$f" 2>/dev/null | grep "^- " | awk '{print $2}' | while read link; do
    # 跳过外部链接
    [[ "$link" =~ ^https?:// ]] && continue
    [[ "$link" =~ ^[a-z]+/ ]] && target="$link" || target="$dir/$link"
    ls "$target" 2>/dev/null || echo "DEAD: $f -> $link"
  done
done
```

### 场景 5：新成员入职引导
1. 指出 [../README.md](../README.md) 了解角色边界
2. 指出 [04-治理-就绪检查清单](./04-治理-就绪检查清单.md) 掌握发布标准
3. 指出 [templates/](../templates/) 选择合适模板
4. 指出 [COLLABORATION.md](../COLLABORATION.md) 查协作资源

| 操作 | 命令 |
|------|------|
| 查找缺少 benefit 字段的文件 | `find YiKnowledge -name "*.md" -not -path "*/rss/*" \| while read f; do rg -q "^benefit:" "$f" \|\| echo "$f"; done` |
| 查找缺少 last_verified 的文件 | `find YiKnowledge -name "*.md" -not -path "*/rss/*" \| while read f; do rg -q "^last_verified:" "$f" \|\| echo "$f"; done` |
| 查找 lifecycle:triage 的文件 | `rg -l "^lifecycle: triage" YiKnowledge --type md` |
| 查找 status:deprecated 的文件 | `rg -l "^status: deprecated" YiKnowledge --type md` |
| 统计角色文件数 | `find YiKnowledge/<role> -name "*.md" \| wc -l` |
| 查找超过 6 个月未验证的文件 | `rg -l "^last_verified: 202[0-5]\|^last_verified: 2026-0[1-3]" YiKnowledge --type md` |
| 全文搜索某个概念 | `rg -l "<关键词>" YiKnowledge --type md` |

## 反模式速查

| 反模式 | 一句话修复 |
|--------|----------|
| 收件箱长期为空 | 每次会议、每篇好文章、每个 bug 都记录一条 |
| 只看体量不看质量 | 体量 + 新鲜度 + 质量 + 覆盖度四个维度同步关注 |
| 看板数据从不更新 | 每月固定日程，纳入日历提醒 |
| 隐性知识只识别不捕获 | 每季度至少完成 1-2 项 |
| 跳过复盘阶段 | 不复盘等于白做——每个闭环必须以复盘收尾 |
