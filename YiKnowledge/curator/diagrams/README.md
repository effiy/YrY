# 图表子目录

> 4 张规范图构成知识库的视觉骨架。每张图回答一个核心问题，组合起来提供知识库的全景视图。

## 4 张图

| 图 | 文件 | 回答的问题 | 审查频率 |
|------|------|-----------|----------|
| 看板索引 | [01-图表-看板索引.md](./01-图表-看板索引.md) | 知识库多健康？体量/新鲜度/质量/覆盖度 | 每月 |
| 目录蓝图 | [02-图表-目录蓝图.md](./02-图表-目录蓝图.md) | 用户如何 2 跳内找到内容？ | 每季度 |
| 知识地图 | [03-图表-知识地图.md](./03-图表-知识地图.md) | 什么知识存在？显性 vs 隐性？谁消费？ | 每季度 |
| 用户旅程 | [04-图表-用户旅程.md](./04-图表-用户旅程.md) | 知识如何在流水线中流转？断点在哪？ | 每季度 |

## 使用方式

- **月度审查** — 刷新看板索引的指标数据
- **季度审查** — 逐张验证 4 张图的内容是否仍然准确
- **新人入职** — 按 地图 → 蓝图 → 旅程 的顺序阅读，建立知识库的思维模型
