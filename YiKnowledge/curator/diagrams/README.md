# Knowledge Curator — 图表

## 4 张图

在扩展知识库之前绘制这 4 张图：

| 图 | 文件 | 回答的问题 |
|---|---|---|
| 知识地图 | [knowledge-map.md](./knowledge-map.md) | 存在哪些知识？显性 vs 隐性？持有者和消费者？ |
| 用户旅程图 | [user-journey.md](./user-journey.md) | 知识在哪里？如何流动？断点在哪里？ |
