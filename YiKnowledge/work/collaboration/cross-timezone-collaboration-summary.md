# 跨时区协作约定

## 1. 是什么

跨多个时区团队协作的工作约定，核心是：**让每个时区都能在合理时间工作，不要求某方持续熬夜**。

## 2. 核心原则

1. **轮流错峰**：会议时间轮流错峰，不要固定让某时区早 / 晚
2. **异步优先**：可异步的不开会
3. **同步窗口**：每天固定 2-4 小时同步窗口（重叠工作时区）
4. **会议录屏留档**：缺席者可回看
5. **决策必有书面**：会议讨论 → 文档化 → 同步全员

## 3. 同步窗口设计

### 找重叠时区

```
时区 A: 09:00 - 18:00
时区 B: 14:00 - 23:00
重叠: A 的 14:00-18:00 = B 的当地工作时间 → 4 小时同步窗口
```

### 窗口内安排

- 跨时区会议
- 决策讨论
- 实时协作

### 窗口外

- 异步沟通
- 独立工作
- 文档反馈

## 4. 会议节奏

| 频率 | 类型 | 时长 |
|---|---|---|
| 每日 | Standup（异步文档版） | 15 分钟读 |
| 每周 | 团队同步 | 30-60 分钟 |
| 每两周 | 跨团队对齐 | 60 分钟 |
| 每月 | All-hands | 60 分钟 |
| 季度 | 战略评审 | 2 小时 |

**重要原则**：跨时区会议必录屏 + 纪要，缺席者可在 24h 内回看。

## 5. 时区表达约定

- 文档中时间统一用 UTC + 当地时区标注（如 2026-07-31 14:00 UTC / 22:00 CN）
- 截止日用绝对日期，不用"周五"
- 倒计时统一用小时数（72h）而非"3 天"

## 6. 跨时区反馈时效

| 紧急度 | 响应时限 |
|---|---|
| P0 紧急 | 30 分钟内（电话 / 短信） |
| P1 高 | 4 小时内 |
| P2 中 | 24 小时内 |
| P3 低 | 72 小时内 |

约定 P0 触发方式：电话 + 短信，不只是 Slack。

## 7. 轮值机制

- 重要岗位（oncall、值班 PM）轮值
- 时区覆盖：每时区都有负责人
- 交接文档：交接时 handover document
- 跨时区 handover：白天结束前给下一时区留下状态

## 8. 文化敏感性

- 节假日：每地区有不同节假日，日历共享
- 工作时间：尊重当地（如欧洲晚 6 点后不打扰）
- 沟通风格：高语境 vs 低语境文化差异
- 反馈表达：间接文化注意委婉

## 9. 工具栈

| 用途 | 工具 |
|---|---|
| 异步文档 | Notion / Confluence |
| 即时消息 | Slack / 飞书 |
| 视频会议 | Zoom / Teams / Google Meet |
| 录屏 | Otter.ai / 生成纪要 |
| 时区协调 | World Time Buddy / Clockify |
| 任务追踪 | Linear / Jira（带时区） |

## 10. 反模式

| 反模式 | 现象 | 修复 |
|---|---|---|
| 固定让某方早 / 晚 | 不公平 | 轮流错峰 |
| 跨时区会议无录屏 | 缺席者错过 | 必录屏 + 纪要 |
| 即时消息期待即时回应 | 干扰睡眠 | 异步语义 |
| 时区表达混乱 | 误算时间 | UTC + 当地双标 |
| 决策只会议口头 | 信息丢 | 必有书面 |
| 不考虑节假日 | 文化冒犯 | 共享节假日日历 |

## 11. 与异步协作关系

- 跨时区协作是异步协作的子集
- 跨时区更需要"文档先行"，因对方睡觉时你在写
- 见 [async-collaboration-principles-summary.md](./async-collaboration-principles-summary.md)

## 12. 落地要点

- 团队约定同步窗口（如 CN 14:00-18:00 / EU 09:00-13:00）
- 所有跨时区会议必录屏
- 重要决策文档化 + 全员同步
- 节假日日历共享
