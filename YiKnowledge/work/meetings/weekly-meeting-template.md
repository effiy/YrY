# 周会模板

## 使用场景

团队每周对齐。核心原则：**只讨论需要全队知道或决定的事，状态走异步文档**。

## 模板正文

```markdown
# {团队} 周会

**日期**：YYYY-MM-DD
**主持**：{name}
**参与者**：{列表}
**时长**：30 分钟（超时即停车库）

## 1. 上周关键事件回顾（5 分钟）

- {3-5 条团队级成果}
- {数据：北极星 / DORA / 留存}

## 2. 本周重点（10 分钟）

每子团队 2 分钟：

- 业务 A：本周交付目标 + 风险
- 业务 B：...
- 平台：本周交付目标 + 风险

## 3. 跨团队对齐（10 分钟）

- 待对齐议题 1：{决策或依赖}
- 待对齐议题 2：...

## 4. 风险与阻塞（5 分钟）

| 风险 | 影响 | 责任人 | 行动 |
|---|---|---|---|
| {risk} | {impact} | {name} | {action} |

## 5. 行动项（前收尾）

| # | 行动 | 责任人 | 截止日 |
|---|---|---|---|
| 1 | ... | ... | YYYY-MM-DD |

## 6. 下周预告

- {下周重要节点}

## 附：状态报告（异步阅读，不在会中讲）

- 业务 A 上周完成：{链接到文档}
- 业务 B 上周完成：{链接到文档}
- 平台上周完成：{链接到文档}
```

## 填写规范

| 字段 | 必填 | 规范 |
|---|---|---|
| 上周关键事件 | 是 | 3-5 条，含数据 |
| 本周重点 | 是 | 每子团队 2 分钟 |
| 跨团队对齐 | 是 | 决策或依赖 |
| 风险与阻塞 | 是 | 含影响与责任 |
| 行动项 | 是 | 责任人 + 截止 |
| 状态报告 | 是 | 异步链接，不在会中讲 |

## 周会原则

1. **状态走异步**：状态报告不在会中讲，会前读完
2. **只讨论需对齐的事**：决策、依赖、风险
3. **30 分钟上限**：超时停车库
4. **每议题有时长**：主持控时
5. **必出行动项**：每条有责任人与截止

## 反模式

- 周一列流水账 → 状态走异步
- 一人讲 30 分钟 → 全员参与
- 无行动项 → 必出行动项
- 同步会议变汇报会 → 只讨论需对齐

## 节奏建议

- 周一上午开：定本周方向
- 周五不开：避免状态汇报
- 30 分钟：超时停车库
- 月度：60 分钟，加季度对齐
