# 技术路线图审查模板

> 使用方法：每季度末对齐会前 48 小时填写本模板。重点输出「本季度投资分布 + 里程碑对齐」一张表，让 platform / middleware / business 三域投资比例一目了然。复制到 `work/processes/{季度}-tech-roadmap-review.md`，如 `2026Q3-tech-roadmap-review.md`。

## 1. 基本信息

| 字段 | 内容 |
|------|------|
| 审查季度 | （示例：2026 Q3） |
| 评审范围 | platform / middleware / business 三域 |
| 主持人 | （示例：CTO / 架构组长） |
| 参与人 | platform、middleware、business 各域负责人；PMO；财务 BP |
| 评审日期 | （示例：2026-09-25） |
| 上次审查 | [链接]({上一季度文件路径}) |
| 输入材料 | 上季度复盘、各域 OKR 草案、预算约束、客户反馈 Top10 |
