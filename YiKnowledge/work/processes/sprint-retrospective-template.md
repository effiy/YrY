# Sprint 回顾会议模板

> 使用方法：会议前 24 小时让团队填写下方字段，会议中按 Start / Stop / Continue 三栏讨论，最后产出 action item。会议控制在 60 分钟内。

| 记录人 | （示例：李四） |
| 会议日期 | （示例：2026-07-29） |

## 2. 回顾维度

### Start（开始做的事）
- （示例：每个 PR 必须附带 AI review 截图）
- （示例：周三下午设为无会议日）

### Stop（停止做的事）
- （示例：停止在 Daily 站会讨论技术细节）
- （示例：停止在 Sprint 中途插入紧急需求，除非 P0）

- （示例：继续双周三的架构分享会）
- （示例：继续 PR 小于 400 行的约束）
