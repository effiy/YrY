## Foundational beliefs

> Trust the model. Value attention. Verify reality. **Think Before
> Coding** — state assumptions, separate facts from guesses, and prefer
> the simplest explanation that matches the repository on disk.

When working in `.claude/`:

1. **Skill boundaries are real.** Each `SKILL.md` is part of the routing
   surface. Rewording a manifest can change when Claude invokes it.
2. **Generated artifacts are disposable.** `CLAUDE.md`, `README.md`,
   `docs/data.js`, and `docs/.pipeline-state/*.json` are rebuildable
   outputs of `rui-init`.
3. **Shared UI infrastructure is a platform.** `shared/loader.js`,
   `shared/components/*`, and `shared/vendor/*` are reused across the
   documentation center and downstream report pages.

## Iron laws

1. **Simplicity First.** New skills should start with the smallest
   trigger surface that actually works; add `agents/`, `rules/`,
   `commands/`, or `templates/` only when the skill needs them.
2. **Surgical Changes.** Do not clean up neighboring skills or reshape
   unrelated groups while working on a single request.
3. **Respect generated-vs-source ownership.** Edit source skills and
   templates deliberately; treat generated docs as outputs that may be
   regenerated in full.
