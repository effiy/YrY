Methodology & thresholds
Health score
0–100 composite from size, coupling, risk, and freshness sub-metrics. A ≥ 90 · B ≥ 75 · C ≥ 60 · D ≥ 40 · F < 40.
P0 — Critical
Must resolve before merge / release: file > 1000 LOC, circular dependency, or fan-in / fan-out ≥ 20.
P1 — Warning
Review within iteration: file 500–1000 LOC, fan-in / fan-out 10–19, or stale ≥ 180 days.
P2 — Info
Optional improvements: file 200–500 LOC, fan-in / fan-out 3–9, or orphan file (no inbound references).
Fan-in
Number of other files that import / reference this file. High fan-in = hub file; changes ripple widely.
Fan-out
Number of other files this file imports / references. High fan-out = god object; candidate for decomposition.
Max depth
Longest dependency chain from this file to a leaf. Deep chains signal layered architecture.
Freshness
Days since last mtime, anchored to the newest file in scope. Stale ≥ 180 days, dead ≥ 365 days.
Data locality
All metrics computed statically from the source tree — no network calls, no telemetry, nothing uploaded.
