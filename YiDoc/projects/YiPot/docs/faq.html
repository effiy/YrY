Usage

常见原因与解决方案：

  • API Key 未配置：在 Config 窗口中添加对应引擎的 API Key
  • 网络问题：检查是否能正常访问翻译引擎的 API 端点
  • 请求频率限制：某些引擎有 QPS 限制，稍后重试或切换引擎
  • 语言不支持：确认源语言与目标语言在引擎的支持列表中
  • API 余额不足：检查引擎的账户余额

提高 OCR 识别精度的方法：

  • 切换 OCR 引擎：不同引擎对不同语言/字体有优势，尝试多个后端
  • 提高图片质量：确保截图清晰，避免模糊或过小文字
  • 指定语言：在 Config 中设置正确的 OCR 语言（如中文、英文、日文）
  • 在线 OCR 服务：百度/腾讯/Google Vision 等在线服务通常精度更高
  • 裁剪图片：对识别区域进行裁剪，减少干扰

YiPot 基于 WebView，内存占用通常在 200-500MB。优化方法：

  • 关闭不使用的窗口（特别是 Screenshot 窗口）
  • 在 Config 中减少同时启用的翻译引擎数量
  • 定期清理翻译历史与缓存
  • macOS 用户可在"活动监视器"中查看各窗口内存占用
Engine Selection

根据场景选择：

场景 推荐引擎 原因
日常通用 Google 免费 · 100+ 语言 · 速度快
欧洲语言 DeepL 质量最佳 · 支持术语表
上下文理解 OpenAI GPT-4o · 理解语境
文学翻译 Claude 文风自然 · 情感细腻
中英互译 百度 国内速度 · 中文优化
专业词典 有道 110+ 语言 · 词典丰富

步骤：

  1. 在 Config → Translate 中勾选要对比的引擎（最多 4 个）
  2. 在 Translate 窗口输入文本
  3. 点击"Compare"按钮
  4. 结果将以并排卡片形式显示

注意：多引擎对比会消耗多次 API 调用，可能产生额外费用。

取决于 TTS 引擎：

  • OpenAI TTS：支持 50+ 语言 · 6 种音色（alloy · echo · fable · onyx · nova · shimmer）
  • Replicate：支持多模型 · 包含 voice cloning
  • CTranslate2：本地推理 · 支持自定义模型
Development

Rust 首次编译需要下载并编译所有依赖（包括 Tauri），通常需要 10-30 分钟。后续增量编译较快（1-5 分钟）。

加速方法：

  • 使用国内镜像源（如清华/中科大 Rust crate 镜像）
  • 确保网络连接稳定
  • 使用 SSD 存储（机械硬盘编译速度显著下降）
  • 启用 sccache 缓存编译产物

添加新翻译引擎需要修改 src/services/translate/：

  1. 在 config.js 中添加引擎定义（id、name、endpoint、supported）
  2. 在 engines/ 目录下创建引擎适配器文件
  3. 实现 translate(text, sourceLang, targetLang) 方法
  4. 在 index.js 中注册引擎

PR 欢迎！请参考现有引擎的实现。详见 Customization · Recipes。

调试方法：

  • 前端侧：右键窗口 → Inspect Element → Console
  • Rust 侧：使用 println! / eprintln! 输出日志
  • 日志查看：开发模式下 Rust 日志输出到终端
  • 事件追踪：在 Rust 侧监听 tauri::Event，打印所有 emit 事件
Platform

macOS 对未签名应用有安全限制，解决方法：

  • 右键点击应用 → 选择"打开" → 在弹窗中点击"打开"
  • 或在"系统偏好设置 → 安全性与隐私"中允许该应用
  • 开发模式可运行 xattr -cr YiPot.app 移除隔离标记

Windows 10 / Server 需要 Edge WebView2 Runtime（Win11 内置）：

  1. 访问 WebView2 下载页
  2. 下载 "Evergreen Standalone Installer"
  3. 运行安装程序，按默认选项完成
  4. 重启 YiPot

Linux 截图依赖 X11 / Wayland 的屏幕访问权限：

  • X11：通常无需配置
  • Wayland：需在 ~/.config/electron-flags.conf 添加 --ozone-platform=wayland
  • Flatpak：需授予 --filesystem=/tmp 权限
