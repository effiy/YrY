Changelog

YiPot（跨平台桌面翻译器）版本演进历史。所有版本均通过 yry-init 流水线的 5 步验证（detect → explore → generate → arch → verify）。本文档记录每次发布的功能、修复与破坏性变更。

Semantic Versioning — 遵循 semver.org 规范。
New 新功能 Improved 优化 Fixed 修复 Breaking 破坏性变更

Version Timeline

v3.0.7 · Latest v3.0.6 v3.0.5 v3.0.0 v2.x
v3.0.7 2026-07-21 Latest
  • New 新增 3 个翻译引擎（OpenAI · Claude · Gemini）
  • New Updater 窗口支持后台静默更新
  • New macOS Universal Binary（同时支持 Intel / Apple Silicon）
  • Improved Tesseract.js 5.1 升级，OCR 速度提升 40%
  • Improved Framer Motion 11.11 升级
  • Fixed Windows 11 截图窗口焦点丢失问题
v3.0.6 2026-06-10
  • New 翻译历史批量导出（Excel / Markdown）
  • New 快捷键自定义功能
  • Improved 配置持久化重构，使用 Tauri appConfig 替代 localStorage
  • Fixed Linux WebKit2GTK 兼容性问题
v3.0.5 2026-05-03
  • New Screenshot 窗口支持多屏截图
  • New 翻译结果对比视图（最多 4 引擎同时显示）
  • Improved Rust 后端 tiny_http 升级至 0.12
  • Improved React Router 6.27 升级
v3.0.0 2026-03-15 Major
  • Breaking 重构为 Tauri + React 架构（v2.x Electron 迁移）
  • New Rust 原生后端，应用体积从 120MB 降至 20MB
  • New 5 窗口架构（Translate · Recognize · Screenshot · Config · Updater）
  • New NextUI 组件库替换为 Ant Design
  • New Jotai 状态管理替换为 Redux
Migration: 从 v2.x 升级到 v3.0.0 是完整架构重构（Electron → Tauri）。用户需卸载旧版本，清除 ~/Library/Application Support/YiPot 缓存后重新安装。配置文件格式已从 JSON 迁移为 TOML。
v2.x 2025-12 ~ 2026-02 Legacy
  • Legacy v2.5.0: 基于 Electron 的旧版本（已停止维护）
  • Legacy v2.0.0: 支持 15 个翻译引擎与 8 个 OCR 后端
