Introduction

YiPot 是一款基于 Tauri + React 的跨平台桌面翻译器，集成 21 种翻译引擎、15 种 OCR 后端与 TTS 语音合成能力。支持 Windows / macOS / Linux 三大平台，通过 Rust 原生后端提供高性能的本地服务。

项目采用 Rust 后端 + JSX 前端的混合架构：Rust 侧通过 Tauri 框架提供窗口管理、系统调用、HTTP 服务与 IPC 通信；React 侧通过 hooks、services、components 构建响应式 UI。前端使用 Tailwind CSS + NextUI 组件库，支持深色模式与多语言国际化。

本文档面向所有希望安装、使用、定制或贡献 YiPot 的用户与开发者。7 个页面覆盖了从快速上手到架构定制的完整旅程。

Architecture Overview

YiPot 采用 5 窗口 + Rust 后端 的桌面架构：React 前端通过 Tauri IPC 与 Rust 后端通信，Rust 侧负责窗口管理、HTTP 服务、系统集成与原生 OCR 调用。每个窗口独立打包 React 应用，共享统一的 Jotai 状态与 i18n 实例。

Key Features

  • Tauri 1.8 — 轻量级桌面框架，Rust 原生后端 + WebView 前端
  • 21 翻译引擎 — Google · DeepL · Bing · 百度 · 有道 · 彩云 · OpenAI …
  • 15 OCR 后端 — Tesseract.js · 系统原生 OCR · 在线 OCR 服务
  • TTS 语音合成 — 多引擎语音朗读与发音
  • React 18.3 — 函数式组件 + Hooks 架构
  • NextUI 2.4 — 企业级 React 组件库，内置无障碍与深色模式
  • Tailwind CSS 3.4 — 原子化 CSS，快速样式迭代
  • Jotai 2.10 — 原子化状态管理，自底向上响应式
  • i18next 23.16 — 多语言国际化框架
  • Framer Motion 11.11 — 声明式动画库
  • Tesseract.js 5.1 — 浏览器端 OCR 引擎
  • crypto-js + jose — HMAC-SHA256 签名 + JWT 令牌
  • 5 个独立窗口 — Config · Recognize · Screenshot · Translate · Updater
  • Rust 后端服务 — tiny_http 嵌入式 HTTP + Reqwest 异步客户端
  • 跨平台支持 — Windows · macOS · Linux 三端原生构建
  • 324 源文件 — 完整的桌面应用生态 · 20MB 资源体量

Use Cases

YiPot 的多引擎架构使其能适配多种翻译与识别场景：

多引擎翻译

21 种翻译引擎自由切换，支持文本翻译、文档翻译、批量翻译，满足不同语言对与专业领域的需求。

截图 OCR 识别

通过 screenshots 模块截取屏幕区域，调用 Tesseract.js 或系统 OCR 识别文字，支持 15 种 OCR 后端。

语音朗读

TTS 引擎支持多语言语音合成，适用于外语学习、文档听读、无障碍辅助等场景。
