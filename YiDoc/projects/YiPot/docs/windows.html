Windows

YiPot 采用 5 窗口架构，通过 Tauri 的窗口管理 API 创建独立窗口。每个窗口对应一个 src/window/ 模块，拥有独立的 React 路由与状态管理。窗口间通过 Tauri 事件系统 + 共享存储 + 全局快捷键进行通信。

Window Catalog

Translate Window（翻译主窗口）Primary

核心翻译界面，支持文本输入、21 引擎切换、语言选择、多引擎结果对比。通过 src/window/Translate/ 实现。

  • 入口：index.html · 路由 /translate
  • 关键 Hooks：useConfig · useGetState · useToastStyle
  • 体积：~85 KB（含 React + NextUI + Jotai）
  • 特性：多引擎结果对比 · 翻译历史 · 实时预览 · Markdown 渲染
Recognize Window（OCR 窗口）

图片 OCR 识别界面，支持拖拽图片、框选区域、识别结果编辑。调用 services/recognize/ 中的 15 个 OCR 后端。

  • 入口：index.html · 路由 /recognize
  • 后端：Tesseract.js · 系统原生 OCR · 在线服务
  • 特性：批量识别 · 多语言混合 · 结果复制
Screenshot Window（截图窗口）

屏幕截图与区域选择工具，通过 Rust 后端的 screenshots crate 捕获屏幕，前端处理区域裁剪与坐标传递。

  • 入口：daemon.html（独立窗口）
  • Rust API：capture_screen · save_clipboard
  • 特性：多屏支持 · 自动识别后翻译
Config Window（配置窗口）

应用设置界面，管理 API Key、翻译引擎优先级、OCR 后端选择、主题切换、快捷键绑定、语言偏好。

  • 入口：index.html · 路由 /config
  • 持久化：Tauri appConfig（v3.0.6 起替代 localStorage）
  • 特性：导入/导出 TOML · 配置校验 · 版本回滚
Updater Window（更新窗口）

版本检查与自动更新界面，通过 Tauri 的 updater API 下载并安装新版本。支持手动检查与后台静默更新。

  • 入口：index.html · 路由 /updater
  • API：Tauri updater 插件 + 自定义签名验证
  • 特性：差量更新 · 回滚保护 · 更新日志展示

Window Lifecycle

每个窗口遵循 Tauri 的标准生命周期：

┌──────────────────────────────────────────────────────────────┐
│  Rust: WindowBuilder::new(label, url)                         │
│    │                                                           │
│    ▼                                                           │
│  WebView loads index.html (or daemon.html)                    │
│    │                                                           │
│    ▼                                                           │
│  React Router → /translate | /recognize | /config | /updater  │
│    │                                                           │
│    ▼                                                           │
│  Mount React App · Load Jotai atoms · Restore appConfig       │
│    │                                                           │
│    ▼                                                           │
│  Ready — User interaction                                      │
│    │                                                           │
│    ├─ invoke('command_name', args) ──► Rust handler            │
│    │                                     │                     │
│    │  ◄───── emit('event_name', payload) ─┘                    │
│    │                                                           │
│    ▼                                                           │
│  Window close → State persisted → Resources released          │
└──────────────────────────────────────────────────────────────┘

Inter-Window Communication

窗口间通过以下方式通信：

Channel API Use Case
Tauri Events emit / listen 跨窗口实时通知（如截图完成 → 翻译窗口）
Shared Storage appConfig (Tauri storage) 持久化全局配置（API Keys · 引擎优先级）
Clipboard arboard crate (Rust) 翻译结果复制到剪贴板，供其他窗口使用
Global Shortcut globalShortcut API 触发跨窗口操作（如 ⌘+Shift+T 唤起翻译窗口）
System Tray SystemTray (Rust) 托盘菜单快速打开任意窗口

IPC Command Reference

Command Window Args Returns
capture_screen Screenshot display_id, rect base64 PNG
translate_text Translate text, from, to, engine translated string
recognize_image Recognize image, lang, backend recognized text
save_config Config key, value Result<()>
check_update Updater — UpdateManifest
install_update Updater — Result<()>
write_clipboard All text Result<()>
open_window All window_label Result<()>
Tip: 所有 IPC 命令在 Rust 侧通过 #[tauri::command] 宏声明，自动生成 TypeScript 类型定义（src/types/ipc.d.ts），前端调用时享有完整的类型推导。
