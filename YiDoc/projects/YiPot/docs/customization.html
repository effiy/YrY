Customization

YiPot 提供多层次的定制能力：翻译引擎配置、UI 主题、OCR 后端选择、快捷键绑定等。所有配置通过 React 状态管理（Jotai）与 Tauri 本地存储持久化。

翻译引擎配置

在 src/services/translate/ 中定义各引擎的 API 密钥与端点：

// src/services/translate/config.js
export const TRANSLATE_ENGINES = [
  {
    id: 'google',
    name: 'Google Translate',
    apiKey: '', // 用户配置
    endpoint: 'https://translate.googleapis.com/',
    supported: ['en', 'zh', 'ja', 'ko', 'fr', 'de', ...]
  },
  {
    id: 'deepl',
    name: 'DeepL',
    apiKey: '',
    endpoint: 'https://api-free.deepl.com/v2/translate',
    supported: ['en', 'zh', 'ja', 'fr', 'de', 'es', ...]
  },
  // ... 21 个引擎
];

用户可在 Config 窗口中添加 API Key，配置通过 useConfig hook 持久化到 Tauri 的 appConfig 存储。

Theme 主题定制

YiPot 使用 Tailwind CSS 的 dark: 前缀与 NextUI 的 theme 配置实现深色/浅色模式切换： 

// tailwind.config.cjs
module.exports = {
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        primary: '#6366f1',
        secondary: '#8b5cf6',
        background: 'var(--background)',
        foreground: 'var(--foreground)',
      }
    }
  }
}

OCR 后端选择

在 src/services/recognize/ 中配置 OCR 引擎优先级：

后端 类型 说明
Tesseract.js 本地 浏览器端 OCR，无需网络，支持 100+ 语言
macOS Vision 系统 macOS 13+ 内置，速度极快，准确率高
Windows OCR 系统 Windows 11 内置，支持 70+ 语言
Linux Tesseract 系统 需安装 tesseract-ocr 包
百度 OCR 在线 中文识别最佳，需 API Key
腾讯 OCR 在线 通用文字识别，免费额度
Google Vision 在线 多语言准确率高，需 GCP 账号
Azure CV 在线 Azure Computer Vision，支持手写

用户可在设置中选择首选 OCR 引擎，配置持久化到本地存储。系统会按优先级回退（如 Vision 失败则尝试 Tesseract.js）。

快捷键绑定

全局快捷键通过 Tauri 的 globalShortcut API 注册，可在 Config 窗口中自定义：

默认快捷键 功能 可自定义

Ctrl+Shift+S 截图 OCR 识别 Yes

Ctrl+Shift+R 朗读剪贴板内容 Yes

Ctrl+Shift+Q 退出应用 No

国际化（i18next）

YiPot 使用 i18next 管理多语言。添加新语言步骤：

// src/i18n/locales/ja.json (新增日语)
{
  "translation": {
    "translate": "翻訳",
    "recognize": "認識",
    "settings": "設定",
    "engine": "エンジン"
  }
}

// src/i18n/index.js
import ja from './locales/ja.json';
i18n.use(initReactI18next).init({
  resources: {
    ja: { translation: ja }
  }
});

Common Recipes

在 src/services/translate/ 创建新引擎文件：

// src/services/translate/MyEngine.js
export class MyEngine {
  constructor(config) { this.config = config; }
  async translate(text, from, to) {
    const res = await fetch(this.config.endpoint, {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${this.config.apiKey}` },
      body: JSON.stringify({ text, from, to })
    });
    return (await res.json()).translated;
  }
}

编辑 src-tauri/tauri.conf.json：

"windows": [
  {
    "label": "translate",
    "title": "YiPot · Translate",
    "width": 800,
    "height": 600,
    "minWidth": 400,
    "minHeight": 300,
    "resizable": true,
    "decorations": true,
    "transparent": false
  }
]
提示：所有配置变更在 Config 窗口保存后立即生效，无需重启应用。Tailwind 主题修改需重新 pnpm tauri dev。
