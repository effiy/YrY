Setup

Note: YiPot 是 Tauri 桌面应用，可从预编译安装包直接使用，或从源码构建。开发模式需要 Rust + Node.js 环境；首次 Rust 编译约 5–10 分钟，后续增量编译 < 30 秒。

Prerequisites

根据你的操作系统，安装以下依赖：

Requirement Version Platform Purpose
Rust toolchain ≥ 1.75 All 编译 Rust 后端（rustup 推荐）
Node.js ≥ 18 LTS All 构建 React 前端 + Vite dev server
pnpm ≥ 8 All 包管理器（推荐）· 也可用 yarn / npm
WebKit2GTK 4.0-dev Linux Tauri WebView 后端
Edge WebView2 ≥ 110 Windows Tauri WebView 后端（Win11 已内置）
Xcode CLT ≥ 15 macOS 原生编译工具链
Rust 安装命令
# macOS / Linux
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Windows: 下载 rustup-init.exe
# https://win.rustup.rs/x86_64

# 验证
rustc --version
cargo --version
Linux 系统依赖（Ubuntu / Debian）
sudo apt update
sudo apt install -y libwebkit2gtk-4.0-dev build-essential libssl-dev \
  libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev

Installation Steps

1
克隆仓库
git clone https://github.com/your-org/YiPot.git
cd YiPot
2
安装前端依赖
pnpm install
# 或 yarn install / npm install
3
开发模式启动

同时编译 Rust 后端 + 启动 Vite dev server： 

pnpm tauri dev
4
生产构建

生成 .msi / .dmg / .AppImage 安装包：

pnpm tauri build
# 产物: src-tauri/target/release/bundle/

Docker Build (Optional)

无需本地 Rust 环境？可使用 Docker 构建产物：

# 使用提供的 Dockerfile
docker build -t yipot-builder .

# 提取构建产物
docker create --name tmp yipot-builder
docker cp tmp:/app/src-tauri/target/release/bundle ./dist
docker rm tmp

Troubleshooting

原因：缺少 C/C++ 编译器（Rust 依赖系统 linker）。

解决：macOS 安装 Xcode CLT（xcode-select --install）；Linux 安装 build-essential；Windows 安装 Visual Studio Build Tools（C++ workload）。

检查项：

  • Linux：确认 libwebkit2gtk-4.0-dev 已安装（dpkg -l | grep webkit2gtk）
  • Windows：确认 Edge WebView2 Runtime 已安装（Win11 内置，Win10 需手动安装）
  • macOS：系统自带 WebKit，无需额外安装
  • 打开 DevTools（右键 → Inspect Element）查看 Console 错误

Tauri 通过 tauri.conf.json 的 build.devUrl 指向 Vite dev server。

检查：① vite.config.js 的 server.port 与 tauri.conf.json 的 build.devUrl 一致；② 未被防火墙拦截；③ 浏览器访问 http://localhost:1420 验证 Vite 是否正常。

开发模式无需签名。生产分发需配置：

// tauri.conf.json
"mac": {
  "signingIdentity": "Developer ID Application: ...",
  "entitlements": "entitlements.plist"
}

公证命令：xcrun notarytool submit <app.zip> --apple-id <email> --team-id <team> --password <app-pwd> --wait
