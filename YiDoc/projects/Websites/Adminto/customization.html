Customization

Adminto 提供了全面的定制化能力，从布局模式、色彩方案到字体和组件样式均可灵活调整。本指南涵盖了从入门到高级的定制方法，帮助你快速适配品牌需求。

Layout Options

Adminto 提供多种布局选择，包括垂直布局（左侧主导航）和水平布局（顶部主导航）。通过修改 <html> 元素上的 data 属性即可切换：

参考 src/ 或 dist/ 目录下的 layouts-horizontal.html 文件了解水平布局的激活方式。

Data Attribute Configuration Reference

通过 <html> 元素上的 data 属性控制布局、色彩和组件行为。完整配置项如下：

Attribute Type Options Description
data-mode String "light" | "dark" 全局色彩模式。默认跟随系统偏好，可强制指定。
dir String "ltr" | "rtl" 布局方向。LTR 为从左到右，RTL 为从右到左。
data-layout-width String "fluid" | "boxed" 内容区域宽度。fluid 为自适应全宽，boxed 为固定宽度居中。
data-sidenav-view String "default" | "condensed" | "compact" 侧边栏显示模式。default 展开完整菜单，condensed 仅显示图标，compact 为紧凑模式。
data-layout-position String "fixed" | "scrollable" 布局定位方式。fixed 固定侧边栏和顶栏，scrollable 随页面滚动。
data-menu-color String "light" | "dark" | "brand" | "gradient" 侧边栏菜单配色。brand 使用主题色，gradient 使用渐变背景。
data-topbar-color String "light" | "dark" 顶部导航栏配色。
配置示例
<!-- 深色侧边栏 + 浅色顶栏 + 固定布局 -->
<html data-menu-color="dark" data-topbar-color="light" data-layout-position="fixed">

<!-- 品牌色侧边栏 + 深色模式 -->
<html data-menu-color="brand" data-mode="dark">

<!-- 紧凑侧边栏 + RTL + 盒装布局 -->
<html data-sidenav-view="compact" dir="rtl" data-layout-width="boxed">

SCSS Variable Override

Adminto 使用 SCSS 变量系统实现全局样式控制。通过覆盖以下核心变量来快速定制主题外观：

Variable Default Description
$primary#727cf5主题色，影响按钮、链接、活跃状态、进度条等
$secondary#6c757d次要色，用于次要按钮和背景
$success#0acf97成功色，用于成功状态、通知
$danger#fa5c7c危险/错误色，用于错误提示和删除操作
$warning#ffbc00警告色，用于警告提示
$info#39afd1信息色，用于信息提示
$font-family-base'Inter', sans-serif全局基础字体栈
$font-size-base0.875rem基准字号
$body-bg#fafbfe页面背景色
$body-color#6c757d正文文字颜色
$border-radius0.25rem全局圆角值
$input-btn-padding-y0.45rem按钮/输入框垂直内边距
$input-btn-padding-x0.9rem按钮/输入框水平内边距
$enable-shadowstrue是否启用全局阴影效果
$enable-gradientsfalse是否启用渐变背景

修改变量后，运行 gulp build 重新编译 SCSS 即可生效。建议在 src/assets/scss/_variables.scss 中集中管理所有变量覆盖。

CSS Custom Properties (Runtime Theming)

除了 SCSS 编译时变量，Adminto 还提供运行时 CSS 变量系统，无需重新构建即可动态调整样式。在 :root 或任意选择器中覆盖即可：

/* 动态切换主题色（无需重新编译） */
:root {
    --color-primary: #0acf97;
    --color-primary-hover: #09b885;
    --color-bg: #f5f6fa;
    --color-surface: #ffffff;
    --color-text: #4a5568;
}

/* 按需覆盖侧边栏变量 */
:root {
    --color-sidebar-bg: #1a1c2e;
    --color-sidebar-text: #a0a7b8;
    --sidebar-width: 260px;
}

/* 启用深色模式 */
.dark {
    --color-bg: #0f1117;
    --color-surface: #1a1d2e;
    --color-text: #a0a7b8;
    --color-heading: #e2e4e9;
}

完整的设计 Token 列表请参阅 Specifications 页面。深色模式通过 .dark 类自动激活，切换按钮位于顶栏右侧的月亮/太阳图标。

CSS Variable Default Size in px Usage

Adding New Pages

使用 pages-starter.html 作为模板创建新页面。请确保以下要点：

  1. 引入核心资源：确保页面包含 css/app.min.css、css/icons.min.css 和 js/app.min.js
  2. 设置页面标识：在 <main> 元素上设置 data-page 属性，以便 layout.js 正确高亮侧边栏菜单
  3. 引入组件资源：如使用图表、数据表格、日历、地图等组件，需额外引入对应的 CSS 和 JS 文件
  4. 构建：运行 gulp build 编译新页面到 dist/ 目录
