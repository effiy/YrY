Coding Standards & Conventions

CSS / SCSS
  • Design Tokens (CSS Custom Properties): 所有颜色、字体、间距等设计变量统一通过 :root 中的 CSS 变量定义，变量名遵循语义化命名规范（如 --color-primary、--font-size-base），禁止在变量名中使用数字。
  • 变量命名规范: 采用两层结构 --{category}-{property}，例如：
    • --color-* — 色彩系统（bg, surface, text, primary, danger 等）
    • --font-* — 字体系统（family, size-*, mono）
    • --sidebar-* — 侧边栏相关
    • --topbar-* — 顶栏相关
    • --radius-* — 圆角系统
    • --shadow-* — 阴影系统
  • 响应式断点: 继承 Tailwind CSS 默认断点 — sm: 640px, md: 768px, lg: 1024px, xl: 1280px, 2xl: 1536px。
  • 类命名: 采用 Bootstrap 风格的功能性前缀命名法，如 .font-*、.bg-*、.text-*。
  • 布局模式: 使用 Flexbox 和 CSS Grid 进行布局，侧边栏采用 position: fixed 实现固定定位。
JavaScript
  • 模块化架构: JS 按职责分离 — layout.js 负责共享布局注入（侧边栏、顶栏、页脚），app.min.js 负责页面交互逻辑（菜单高亮、移动端折叠、滚动条初始化等）。
  • 页面识别: 通过 main#page-content 上的 data-page 属性标识当前页面，layout.js 据此动态高亮对应菜单项。
  • 初始化模式: 采用 DOMContentLoaded 事件驱动的初始化流程，各功能模块封装为独立函数（initLoading, initMenuToggle, initActiveMenu, initSimpleBar）。
  • 严格模式: 所有脚本默认启用 'use strict'。
  • 无全局污染: 使用 IIFE（Immediately Invoked Function Expression）包裹，避免变量泄漏至全局作用域。
  • 防御性编程: 在调用第三方库（如 SimpleBar）时提供 try/catch 包裹及降级方案。
HTML
  • 语义化标签: 使用 <main> 包裹页面主体内容，<footer> 定义页脚区域。
  • 无障碍访问: 图片提供 alt 属性，链接使用 aria-label 或描述性文本。
  • 编码规范: 统一使用 UTF-8 编码，设置 X-UA-Compatible 为 IE=edge。
  • Viewport: 统一设置 width=device-width, initial-scale=1.0 以适配移动端。

Performance & Accessibility Targets

Performance
  • 首次内容绘制 (FCP): < 1.5s
  • 最大内容绘制 (LCP): < 2.5s
  • 累计布局偏移 (CLS): < 0.1
  • 总阻塞时间 (TBT): < 200ms
  • CSS 体积: 核心样式 < 150KB (未压缩)
  • JS 体积: 核心脚本 < 100KB (未压缩)
Accessibility
  • WCAG 级别: 目标 AA 级合规
  • 色彩对比度: 正文 ≥ 4.5:1，大文本 ≥ 3:1
  • 键盘导航: 支持完整的 Tab 键焦点导航
  • 屏幕阅读器: 关键交互元素配备 aria-* 属性
  • 焦点指示器: 保留浏览器默认 :focus-visible 样式

Build Pipeline

Command Description
yarn install 安装所有依赖至 node_modules/
gulp 启动开发服务器（默认 vertical 布局），监听文件变更并实时刷新。访问 http://localhost:3000/
gulp build 编译 SCSS → CSS，合并/压缩 JS，输出至 dist/ 目录用于生产部署
npm rebuild node-sass 重建 node-sass 原生绑定（用于解决安装过程中的二进制兼容问题）
Gulp 构建流程包括：SCSS 编译 → Autoprefixer 添加浏览器前缀 → CSS 压缩 → JS 合并与压缩 → HTML 文件复制。
