Changelog

Adminto 的完整版本变更记录。我们持续改进模板的功能、性能和开发体验。建议在升级前查阅变更内容并备份自定义代码。

v1.2.0 — 15 March 2024 (Latest)

New Features
  • Added Kanban Board page with drag-and-drop task management
  • Introduced File Manager with grid/list views, upload, and folder management
  • Added Timeline component for activity feeds and event logging
  • New Email pages: Inbox, Compose, Read, and Templates
  • Introduced Vector Maps integration (jsvectormap) for geographic data visualization
  • Added Sweetalert2 integration for enhanced alert dialogs
Improvements
  • Enhanced dark mode contrast ratios for better WCAG AA compliance
  • Optimized SCSS compilation pipeline — build time reduced by ~40%
  • Refactored sidebar menu to support multi-level nested navigation
  • Improved mobile touch interaction for DataTables and Select2
  • Updated Remix Icon to v4.1.0 with 300+ new icons
  • Added CSS logical properties throughout for seamless RTL support
Bug Fixes
  • Fixed dropdown menu overflow issue on small viewports
  • Resolved z-index stacking conflict between modals and offcanvas
  • Fixed Chart.js responsive resize on sidebar toggle
  • Corrected Flatpickr date picker alignment in RTL mode

v1.1.0 — 05 December 2023

  • Added CSS Custom Properties design token system (--color-*, --font-*, etc.)
  • Introduced shared layout injector (layout.js) to eliminate HTML duplication across documentation pages — reduced code footprint by ~80%
  • Enhanced RTL support with automatic direction detection via dir attribute
  • Added SimpleBar custom scrollbar integration for sidebar and content areas with graceful fallback
  • Improved responsive behavior on mobile devices — sidebar overlay mode for small screens
  • Updated Bootstrap to v5.2.3 and jQuery to v3.7.1
  • Documentation site restructured with modular shared assets architecture
  • Added search functionality in documentation with keyboard shortcut support
  • Introduced light/dark mode toggle with system preference detection

v1.0.1 — 20 September 2023

  • Fixed sidebar scroll position persistence issue on page reload
  • Resolved dark mode color contrast issues on form elements (input, select, textarea)
  • Optimized SCSS compilation output — reduced CSS bundle by 15%
  • Fixed overlapping tooltip on collapsed sidebar menu items
  • Minor UI refinements: typography scale, card shadows, button hover states
  • Improved NPM post-install script compatibility on Windows environments

v1.0.0 — 17 August 2023 (Initial Release)

Core Architecture
  • Vertical and Horizontal dual layout modes, switchable via data attributes
  • Light and Dark color modes with CSS custom property-driven theming
  • Full RTL (right-to-left) layout support leveraging Bootstrap 5 logical properties
  • Gulp 4.x build pipeline: SCSS compilation, Autoprefixer, CSS/JS minification, live reload
  • Tailwind CSS 3.3.3 integration as design foundation
  • Bootstrap 5.2.3 component library with full grid system and utilities
Pages & Features
  • Dashboard analytics with ApexCharts integration — line, bar, area, pie, and radial charts
  • DataTables integration with sorting, filtering, pagination, and server-side support
  • Built-in authentication pages: Login, Register, Recover Password, Lock Screen, Logout
  • Error pages: 404 Not Found, 500 Internal Server Error, Maintenance Mode
  • Starter page template for rapid new page creation
UI Components
  • Base: Alerts, Badges, Breadcrumbs, Buttons, Cards, Dropdowns, Progress Bars, Spinners
  • Navigation: Tabs, Pills, Accordions, Pagination
  • Form: Inputs, Select2, Flatpickr date/time picker, Dropzone file upload, Quill rich text editor
  • Advanced: Modals, Offcanvas, Tooltips, Popovers, Toasts, Carousel
  • Icon libraries: Remix Icon (2000+ icons), Feather Icons, Material Design Icons

Upgrade Guide

从旧版本升级到最新版本时的注意事项：

v1.1.x → v1.2.0
  • 新增 Kanban、File Manager、Timeline、Email 等页面文件，需手动复制到项目中
  • Remix Icon 升级至 v4.1.0 — 部分图标类名可能变更，请参考 Remix Icon 官方文档
  • SCSS 构建配置优化 — 如自定义了 gulpfile.js，需合并上游变更
v1.0.x → v1.1.0
  • CSS Custom Properties 系统引入 — 旧版硬编码的颜色值需迁移至 var(--color-*) 变量
  • 文档站点重构 — layout.js 统一管理布局注入，自定义文档页面需适配新的数据属性约定
  • Bootstrap 更新至 5.2.3 — 使用已废弃的类（如 .form-group）需更新
提示：升级前务必备份 src/ 目录下的自定义代码。建议使用版本控制（Git）管理项目，以便在升级出现问题时回滚。
