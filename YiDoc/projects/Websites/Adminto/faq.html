Frequently Asked Questions

以下汇总了 Adminto 管理后台模板在使用、定制和部署过程中的常见问题。如未能找到解答，请通过官方支持渠道联系我们。

General Questions

Q: Adminto 适用于哪些类型的项目？

Adminto 是为企业级后台管理系统设计的全能型管理面板模板，适用于 CRM（客户关系管理）、CMS（内容管理系统）、ERP、数据分析仪表盘、SaaS 管理后台、项目管理工具等各类 Web 应用。内置丰富的组件库和布局方案，覆盖绝大多数业务场景。

Q: 购买后可获得哪些交付物？

解压购买后的 ZIP 包，你将获得：

  • Admin/ — 管理后台模板源码，包含 SCSS 源文件、未压缩 JS、HTML 页面源文件、Gulp 构建配置
  • dist/ — 预编译的生产就绪文件，可直接部署
  • Documentation/ — 本文档系统，涵盖使用指南、定制说明和规范
  • README.md — 快速入门说明
Q: 是否支持多语言 (i18n) 和 RTL？

是的。Adminto 原生支持 RTL（从右到左）布局，只需在 <html> 标签上设置 dir="rtl" 即可激活。多语言集成可通过第三方库（如 i18next）实现，模板提供了友好的扩展接口。

Q: 如何获取最新版本更新？

更新会通过购买平台（如 ThemeForest）发布。我们建议关注更新通知，并在升级前备份自定义代码。版本变更详情可参阅 Changelog 页面。

Setup & Environment

Q: 运行 gulp 时报错 Error: ENOENT: no such file or directory, scandir '.../node-sass/vendor'，如何解决？

这是 node-sass 原生二进制未正确构建导致的。依次尝试以下方案：

  1. 运行 npm rebuild node-sass 重建绑定
  2. 删除 node_modules/ 目录，重新执行 yarn install
  3. 如问题持续，考虑升级 node-sass 或切换至 sass (dart-sass)
Q: 能否跳过构建流程直接使用 dist/ 目录？

可以。如果你不需要修改 SCSS 或进行自定义构建，直接使用 dist/ 目录中的预编译文件即可。该目录包含所有已压缩的 CSS、JS 和 HTML 页面，可直接部署到生产环境。

Q: 支持哪些 Node.js 版本？

建议使用 Node.js 16.x 及以上 LTS 版本。较低版本可能存在兼容性问题，尤其是 Gulp 4.x 和 node-sass 原生模块构建方面。

Q: yarn install 安装依赖缓慢怎么办？

建议：

  • 配置国内镜像源 — yarn config set registry https://registry.npmmirror.com
  • 使用代理网络环境
  • 确保 Node.js 版本和 Yarn 版本均为 LTS 最新版

Customization

Q: 如何修改主题的主色调？

有几种方式：

  • SCSS 方式：修改 src/assets/scss/_variables.scss 中的 $primary 变量，重新执行 gulp build
  • CSS 变量方式：覆盖 :root 中的 --color-primary 和 --color-primary-hover
  • Tailwind 方式：修改 tailwind.config.js 中的颜色配置
Q: 如何切换布局模式（垂直 vs 水平）？

布局模式由 data-layout 属性控制。在 <html> 标签上设置对应属性值即可。详见 Customization 页面中的完整配置选项表。

Q: 如何添加新的页面？

使用 pages-starter.html 作为模板创建新页面。确保引入必要的 CSS（app.min.css, icons.min.css）和 JS（app.min.js）。如使用图表、表格等组件，还需额外引入对应的插件资源文件。

Q: 能否禁用深色模式？

可以。通过设置 <html data-mode="light"> 固定为浅色模式，或移除模式切换相关的 JS 逻辑。默认情况下，主题会根据系统偏好或用户选择切换。

Components & Plugins

Q: 模板内置了哪些第三方插件？

Adminto 集成了广泛的第三方优秀插件，包括但不限于：

  • 图表: ApexCharts, Chart.js
  • 表格: DataTables
  • 表单: Select2, Flatpickr, Dropzone, Quill Editor
  • 地图: Google Maps, Vector Maps
  • 图标: Remix Icon, Feather Icons, Material Design Icons
  • 其他: FullCalendar, SweetAlert2, SimpleBar
Q: 如何升级某个第三方插件到最新版本？

通过 yarn upgrade <package-name> 升级后，重新运行 gulp build 即可。注意部分插件的 API 可能在主版本升级中发生 Breaking Change，请在升级前查阅相应插件的 Changelog。

Q: 能否使用其他 UI 组件库替代 Bootstrap？

Adminto 深度基于 Bootstrap 5 构建，核心布局、网格系统和大量组件都依赖 Bootstrap。不建议替换，但可以通过 SCSS 变量覆盖或 CSS 层叠来定制 Bootstrap 的整体视觉风格，以匹配你的品牌。

Deployment & Production

Q: 如何部署到生产环境？

执行 gulp build 后，将 dist/ 目录部署到你的 Web 服务器（Nginx、Apache、CDN 等）。该目录包含所有已压缩优化的文件，可直接提供服务。建议额外配置 HTTP/2、Gzip/Brotli 压缩和 Cache-Control 头以最大化性能。

Q: 能否用于 SPA 框架（React / Vue / Angular）？

Adminto 的原生 HTML/JS/CSS 架构不直接兼容 SPA 框架，但可以将 SCSS 样式体系迁移至你的框架项目中使用。CSS 变量系统和 Tailwind 配置是框架无关的，可直接复用。

Q: 模板是否包含后端代码？

不包含。Adminto 是纯前端模板，不涉及任何服务端逻辑。你可以使用任何后端技术栈（PHP、Node.js、Python、Java、Go 等）与之集成。模板页面的表单、表格等组件可与后端 API 进行对接。
