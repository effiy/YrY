RTL (Right-to-Left) Support

Adminto 原生支持 RTL（从右到左）布局模式，适用于阿拉伯语、希伯来语、波斯语、乌尔都语等 RTL 语言的 Web 应用。RTL 模式自动反转布局方向、文本对齐、间距和图标方向，无需手动调整任何组件。

Activation

激活 RTL 模式只需两步，无需额外的 CSS 或 JS 文件：

方法一：HTML 属性（推荐）

在 <html> 标签上同时设置 dir="rtl" 和 lang 属性：

<html lang="ar" dir="rtl">
  ...
</html>

Bootstrap 5 内置的 RTL 支持会自动响应 dir 属性，无需额外引入 bootstrap.rtl.css。所有工具类（如 me-*/ms-*、pe-*/ps-*）都会自动翻转。

方法二：data 属性配置

通过 data-layout 属性配置 RTL：

<html lang="ar" data-layout='{"dir": "rtl"}'>
  ...
</html>
在 src/partials/main.html 文件中修改 <html> 标签即可全局生效。

What Gets Flipped Automatically

启用 RTL 后，以下元素会自动适配：

Category LTR Default RTL Behavior
Layout Direction Content flows left → right Content flows right → left
Sidebar Position Left side (left: 0) Right side (right: 0)
Content Offset margin-left: 250px margin-right: 250px
Topbar Position left: 250px; right: 0 right: 250px; left: 0
Text Alignment text-align: left text-align: right
Margin/Padding margin-left, padding-right Logical properties auto-flip
Icons Normal orientation Mirrored where appropriate
Tables Columns left → right Columns right → left

RTL CSS Architecture

Adminto 的 RTL 支持基于以下 CSS 特性实现：

1. Bootstrap 5 Logical Properties

Bootstrap 5 广泛使用 CSS Logical Properties，在 dir="rtl" 时自动翻转方向：

/* 使用逻辑属性替代物理属性 */
margin-inline-start: 1rem;   /* 替代 margin-left (LTR) / margin-right (RTL) */
padding-inline-end: 1rem;    /* 替代 padding-right (LTR) / padding-left (RTL) */
border-inline-start: 1px;    /* 替代 border-left (LTR) / border-right (RTL) */
text-align: start;           /* 替代 text-align: left/right */
2. Direction-Aware Utility Classes

使用 Bootstrap 5 的方向感知类，避免硬编码左右方向：

Old (Physical) New (Logical) Description
.ml-*.ms-*Margin start（LTR 时左侧，RTL 时右侧）
.mr-*.me-*Margin end（LTR 时右侧，RTL 时左侧）
.pl-*.ps-*Padding start
.pr-*.pe-*Padding end
.text-left.text-startText align start
.text-right.text-endText align end
.float-left.float-startFloat start
.float-right.float-endFloat end
3. SCSS RTL Mixins

在 SCSS 源文件中，使用 RTL mixin 编写方向感知样式：

// In SCSS source files
.sidebar {
    @include ltr {
        left: 0;
        border-right: 1px solid $border-color;
    }
    @include rtl {
        right: 0;
        border-left: 1px solid $border-color;
    }
}

Supported Languages & Locales

Adminto RTL 模式已在以下语言环境中经过验证：

  • Arabic (ar) — العربية
  • Hebrew (he) — עברית
  • Persian / Farsi (fa) — فارسی
  • Urdu (ur) — اردو
  • Pashto (ps) — پښتو
  • Dari (prs) — دری
  • Sindhi (sd) — سنڌي
  • Kurdish (ku) — کوردی

RTL 布局与所有内置组件（图表、表格、表单、模态框）兼容。第三方插件的 RTL 支持情况请参考各自文档。

RTL Development Best Practices

Do
  • 使用 Bootstrap 5 逻辑工具类（.ms-*, .me-*）
  • 使用 text-start / text-end 而非 text-left / text-right
  • 图标方向相关的用 CSS transform: scaleX(-1) 翻转
  • 在 SCSS 中使用 @include rtl { } mixin
  • 使用 CSS 自定义属性动态调整方向相关值
Don't
  • 避免硬编码 left / right 定位
  • 避免使用 .ml-* / .mr-*（已废弃）
  • 避免在 JS 中直接计算元素方向
  • 避免使用 direction: ltr 内联覆盖
  • 避免对图标使用固定的旋转角度
