Setup

Quick Start — YiH5 是一个 Vanilla JS H5 前端。以下步骤假设你已具备基本的 Node.js 开发经验。预计安装时间 5-10 分钟。

Prerequisites

Requirement Version Purpose Status
Node.js 18 LTS+ JS 运行时 + npm Required
npm 9+ 依赖管理 Required
Git 2.30+ 版本控制 Required
VS Code latest 推荐编辑器 Optional
Tested on
macOS 13+ · Ubuntu 22.04 · Windows 11
Known issues
Node 16 已 EOL，请使用 18+
Tip
推荐使用 nvm 管理 Node 版本

Installation Steps

  1. 1
    Clone the repository 
    git clone <repository-url>
cd YiH5
  2. 2
    Install Node.js (via nvm) 
    nvm install 18
nvm use 18
  3. 3
    Install dependencies 
    npm install
  4. 4
    Configure environment 
    cp .env.example .env
# 编辑 .env 填入 API base URL 等
  5. 5
    Start dev server 
    npm run dev

Development Workflow

步骤 操作 Expected Result
修改代码 编辑 YiH5/ 目录下的源文件 编辑器保存即触发

Docker Setup (Optional)

推荐使用 Docker 进行生产部署，避免环境差异：

# # Dockerfile (Node)
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --production
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]

# docker-compose.yml
version: '3.8'
services:
  yih5:
    build: .
    ports:
      - "3000:3000}
    environment:
      - NODE_ENV=production
    restart: unless-stopped

# 启动
docker-compose up -d

Troubleshooting

尝试删除 node_modules/ 和 package-lock.json 后重新安装。 

rm -rf node_modules package-lock.json
npm cache clean --force
npm install

检查 vite.config.js 中的 server.watch 配置。某些文件变更可能需要手动重启 dev server。

默认端口 5173 被占用时，更改配置或释放端口：

# vite.config.js
export default { server: { port: 3000 } }

# 或释放端口（macOS/Linux）
lsof -i :5173
kill -9 <PID>
Verification — 安装成功后：
  • 访问 http://localhost:5173 应展示应用首页
  • 浏览器 DevTools Console 无错误
  • 所有依赖版本与 package.json 一致
