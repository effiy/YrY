Customization

YiH5 提供多种定制选项，覆盖配置、主题、API 端点与扩展机制。以下是常用定制场景与代码示例。

CSS Variable Reference

YiH5 的文档页面通过 projects/templates/docs/css/docs.css 定义了一套 CSS 变量。在 docs/assets/css/docs.css 中覆盖即可定制品牌色与主题：

Variable Default Description
--yry-doc-accent #f59e0b 品牌主色 — 侧边栏高亮、按钮、链接、进度条
--yry-doc-accent-ink #fff 品牌色上的文字颜色（通常为白或深色）
--yry-doc-bg #f5f5f5 页面整体背景色
--yry-doc-sidebar-bg #ffffff 侧边栏背景色
--yry-doc-topbar-bg #ffffff 顶部栏背景色
--yry-doc-card-bg #ffffff 卡片背景色
--yry-doc-text #212529 主文本颜色
--yry-doc-muted #6c757d 次要文本颜色
--yry-doc-border #dee2e6 边框颜色
--yry-doc-code-bg #f8f9fa 代码块背景色

Common Customization Scenarios

Theme & Branding

修改 docs/assets/css/docs.css 中的 --yry-doc-accent 以适配品牌色。所有交互组件（侧边栏高亮、按钮、链接）自动继承。 

:root {
  --yry-doc-accent: #ff6b6b;
  --yry-doc-accent-ink: #ffffff;
}
API / Service Extension

在 src/services/ 或 src/api/ 添加新模块

i18n / Localization

HTML lang attribute + 文案替换

Security & Auth

按需配置 CORS / CSP headers

Code Sample — Env + Vite Config 

# .env — YiH5 环境变量
VITE_API_BASE_URL=https://api.example.com
VITE_API_TIMEOUT=30000
VITE_FEATURE_FLAG_NEW_UI=true
VITE_FEATURE_FLAG_DARK_MODE=true
VITE_GA_TRACKING_ID=UA-XXXXX-Y

# vite.config.js — 构建配置
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import path from 'path'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: { '@': path.resolve(__dirname, 'src') }
  },
  server: {
    port: 5173,
    proxy: {
      '/api': 'http://localhost:8000'
    }
  }
})

layout.js Configuration Shim

每个项目的 docs/assets/js/layout.js 是一个 30 行的 shim，设置 window.YRY_DOC_CONFIG 后加载共享 layout.js： 

window.YRY_DOC_CONFIG = {
    brand:        'YiH5',
    tagline:      'Vanilla JS H5 前端',
    version:      'v1.2.0',
    brandColor:   '#f59e0b',
    pages: [
        { key: 'index',    href: 'index.html',    icon: 'ri-honour-line',    label: 'Introduction' },
        { key: 'setup',    href: 'setup.html',    icon: 'ri-tools-fill',     label: 'Setup'        },
        { key: 'customization', href: 'customization.html', icon: 'ri-paint-line', label: 'Customization' },
        { key: 'specifications', href: 'specifications.html', icon: 'ri-file-list-3-line', label: 'Specifications' },
        { key: 'pages', href: 'pages.html', icon: 'ri-window-2-line', label: 'Pages' },
        { key: 'faq',      href: 'faq.html',      icon: 'ri-question-answer-line', label: 'FAQ'    },
        { key: 'changelog',href: 'changelog.html',icon: 'ri-book-open-line',  label: 'Changelog'   },
    ]
};
(function () {
    var s = document.createElement('script');
    s.src = '../../../templates/docs/js/layout.js';
    document.head.appendChild(s);
})();

Extension Recipes

Add a New Doc Page
  1. 创建 docs/new-page.html
  2. 在 layout.js shim 的 pages 数组添加条目
  3. 使用 <main id="page-content" data-page="new-page"> 包裹内容
Override Shared Styles
  1. 编辑 docs/assets/css/docs.css
  2. 覆盖 --yry-doc-* 变量
  3. 共享 layout.js 自动应用新主题
Tip: 所有 YiH5 文档页面共享 projects/templates/docs/ 中的 layout.js 与 docs.css。定制交互行为（暗色模式、侧边栏搜索、TOC、代码复制按钮）时编辑共享文件即可全局生效。

Debugging Patterns

YiH5 是零构建项目，所有源码在浏览器 DevTools 中可见。常用调试技巧：

  • Network 过滤：XHR 面板查看 api.effiy.cn 请求耗时与响应
  • Console 断点：在 index.js 顶部 debugger; 语句触发断点
  • Storage 查看：Application → Local Storage 检查缓存数据
  • Performance：录制主线程长任务 · Layout Shift 分析
  • Mobile 调试：chrome://inspect · USB 连接手机

Web Component Development

// 创建新组件 · cdn/components/my-widget/MyWidget.js
class MyWidget extends HTMLElement {
  connectedCallback() {
    this.innerHTML = `
      <div class="my-widget">
        <slot name="header"></slot>
        <slot></slot>
      </div>`;
    this.addEventListener('click', this._onClick);
  }

  static get observedAttributes() {
    return ['variant', 'size'];
  }

  attributeChangedCallback(name, old, val) {
    if (val !== old) this.render();
  }

  _onClick = (e) => {
    this.dispatchEvent(new CustomEvent('action', {
      bubbles: true,
      detail: { source: this }
    }));
  }
}
customElements.define('my-widget', MyWidget);
