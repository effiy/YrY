Architecture Overview

YiH5 是零构建的 Vanilla JS 单页应用：HTML 入口 → ES Module 加载 → 服务层调用 api.effiy.cn。所有 UI 通过 Web Components + 原生 DOM 渲染，无需 React/Vue 等框架。

Key Features

  • 零构建 — 无 Webpack/Vite，ES Module 原生加载，部署即用
  • 会话管理 — 双 token 机制 · 自动续期 · 失效跳登录
  • AI 对话 — 流式 SSE · 多轮上下文 · Markdown 渲染
  • 新闻订阅 — RSS 源聚合 · 离线缓存 · 关键词高亮
  • 组件化 — 9 个 Web Components · 可复用 · 可插拔
  • 极速首屏 — 总 JS 体积 < 80 KB · 3 秒内 TTI
