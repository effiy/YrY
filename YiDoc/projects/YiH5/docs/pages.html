Page Architecture

pages/<name>/
├── index.html          # HTML 入口
├── index.css           # 页面级样式
├── index.js            # 页面逻辑 (IIFE)
└── components/         # 页面私有组件

Loading Order

每个 HTML 页面通过 <script> 标签按顺序加载：

  1. /YiPet/cdn/loader.js — 组件自动加载器
  2. cdn/utils/core/*.js — 核心工具（DOM · event · storage）
  3. cdn/components/*.js — 共享组件（header · sidebar）
  4. pages/<name>/index.js — 页面逻辑

Adding a New Page

  1. 创建 pages/my-page/ 目录
  2. 添加 index.html（引用共享 CDN）
  3. 添加 index.css（页面级样式）
  4. 添加 index.js（IIFE 包裹，DOMContentLoaded 监听）
  5. 在首页导航添加链接
Design Principle: 每个页面是独立入口，不依赖全局路由。页面间通过 localStorage 和 URL 参数传递状态。这种模式适合移动端 H5 场景。

Data Fetching Patterns

// 每个页面 index.js 的典型结构
document.addEventListener('DOMContentLoaded', async () => {
  // 1. 读取缓存（离线体验）
  const cached = await Storage.get('page-data');
  if (cached) render(cached);

  // 2. 后台拉取最新数据
  try {
    const fresh = await fetch('/api/...', {
      headers: { Authorization: `Bearer ${getToken()}` }
    }).then(r => r.json());
    Storage.set('page-data', fresh);  // 更新缓存
    render(fresh);
  } catch (err) {
    Toast.error('网络错误，使用缓存数据');
  }
});

// SSE 流式（用于 chat 页面）
const es = new EventSource('/api/stream');
es.onmessage = (e) => {
  appendMessage(JSON.parse(e.data).chunk);
};

Inter-Page Communication

页面间不直接耦合，通过以下机制共享状态：

  • URL 参数：短数据 · 页面 ID · 分享链接
  • localStorage：会话 ID · 主题偏好 · 未发送草稿
  • StorageEvent：跨 Tab 监听（一个 Tab 修改 → 其他 Tab 响应）
  • CustomEvent：同 Tab 广播（跨组件通信）
