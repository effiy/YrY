Setup

Note: YiviY 需要 Python 3.10+ 与 FFmpeg。GPU 加速需要 NVIDIA GPU + CUDA 12.4。支持本地运行、Docker 部署、Google Colab 三种方式。完整安装约 10–15 分钟（含模型下载）。

Prerequisites

根据你的使用场景，准备以下依赖：

Requirement Version Required Purpose
Python ≥ 3.10 Yes 主运行时（Streamlit + core 流水线）
FFmpeg ≥ 6.0 Yes 视频/音频抽取、合并、转码
NVIDIA GPU ≥ 8GB VRAM Optional WhisperX / CTranslate2 GPU 推理（CPU 也可运行）
CUDA Toolkit 12.4 + cuDNN Optional GPU 加速依赖（仅 GPU 模式）
OpenAI API Key — Optional GPT-4o 翻译 + OpenAI TTS
Replicate Token — Optional 云端 ML 模型（ASR / TTS / 翻译）
FFmpeg 安装命令
# macOS
brew install ffmpeg

# Ubuntu / Debian
sudo apt install ffmpeg

# Windows (Chocolatey)
choco install ffmpeg

# 验证
ffmpeg -version

Installation Steps

1
克隆仓库
git clone https://github.com/your-org/YiviY.git
cd YiviY
2
创建虚拟环境
python -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate   # Windows
3
安装 Python 依赖
pip install -r requirements.txt
# 或使用一键脚本
python install.py
4
配置 config.yaml

编辑 API Key、模型路径、输出目录：

openai:
  api_key: "sk-xxx"
asr:
  backend: "whisperx"
  model: "large-v3"
tts:
  backend: "openai"
5
启动 Streamlit
streamlit run st.py
# 访问 http://localhost:8501
6
验证流水线

在 UI 中粘贴一个短视频 URL，点击"1-Key Full Pipeline"，等待 12 步完成。

Docker Deployment

使用 Docker 快速部署，无需本地 Python 环境：

# 构建镜像
docker build -t yiviy .

# CPU 模式运行
docker run -p 8501:8501 yiviy

# GPU 模式运行（需要 nvidia-docker）
docker run --gpus all -p 8501:8501 yiviy

# 挂载配置与输出目录
docker run --gpus all -p 8501:8501 \
  -v $(pwd)/config.yaml:/app/config.yaml \
  -v $(pwd)/output:/app/output \
  yiviy

Google Colab

无需本地 GPU？使用 Google Colab 云端运行：

  1. 上传 VideoLingo_colab.ipynb 到 Google Drive
  2. 双击在 Colab 中打开，选择 Runtime → Change runtime type → T4 GPU
  3. 按顺序执行所有单元格
  4. 运行后通过 Files 面板下载输出
Windows 用户：可以使用 batch/OneKeyBatch.bat 一键安装与运行，无需手动配置环境。首次运行会自动下载 Python 嵌入版与 FFmpeg。

Troubleshooting

症状：OSError: Could not download model 或 HuggingFace 连接超时。

解决：① 使用代理（export HF_ENDPOINT=https://hf-mirror.com）；② 手动下载模型到 ~/.cache/huggingface/hub/；③ 切换 backend 为 replicate 走云端推理。

症状：RuntimeError: CUDA out of memory

解决：① 在 config.yaml 中将 asr.model 从 large-v3 降为 medium 或 small；② 关闭其他占用显存的进程；③ 使用 --device cpu 强制 CPU 模式（慢 5-10 倍）。

症状：FileNotFoundError: ffmpeg

解决：① 确认 ffmpeg -version 在终端能正常执行；② Windows 用户手动下载 FFmpeg 并将 bin 目录加入 PATH；③ 在 config.yaml 中显式指定 ffmpeg_path: /usr/local/bin/ffmpeg。

症状：Port 8501 is already in use

解决：streamlit run st.py --server.port 8502，或杀掉占用进程：lsof -ti:8501 | xargs kill。
