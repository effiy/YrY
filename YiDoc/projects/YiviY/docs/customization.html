Customization

YiviY 通过 config.yaml 集中管理所有配置，包括 API Key、模型选择、流水线参数、输出格式等。同时支持自定义术语表与 prompt 模板。

Config Entry Points
config.yaml
全局运行时配置
custom_terms.xlsx
术语映射表
core/prompts.py
LLM Prompt 模板
translations/*.json
UI 国际化文案

config.yaml 核心配置

# config.yaml
# ── API 配置 ──
openai:
  api_key: "sk-xxx"
  base_url: "https://api.openai.com/v1"
  model: "gpt-4o"

replicate:
  api_token: "r8_xxx"

# ── ASR 语音识别 ──
asr:
  backend: "whisperx"  # whisperx | huggingface | replicate
  model: "large-v3"
  language: "auto"  # auto | en | zh | ja | ...
  device: "cuda"  # cuda | cpu

# ── 翻译配置 ──
translate:
  engine: "openai"  # openai | replicate | deepl
  target_lang: "zh-CN"
  prompt_template: "prompts/translate.txt"

# ── TTS 语音合成 ──
tts:
  backend: "openai"  # openai | replicate | ctranslate2
  voice: "alloy"
  speed: 1.0

# ── 流水线参数 ──
pipeline:
  output_dir: "output"
  keep_intermediate: true
  batch_size: 10

Config Key Reference

Key Default Effect
openai.model gpt-4o 翻译使用的 LLM 模型
asr.backend whisperx ASR 引擎（whisperx / huggingface / replicate）
asr.device cuda 推理设备（cuda / cpu）
translate.target_lang zh-CN 目标翻译语言
tts.voice alloy OpenAI TTS 音色
tts.speed 1.0 语速（0.5 – 2.0）
pipeline.batch_size 10 批量翻译每批句子数
pipeline.keep_intermediate true 保留中间 JSON（便于重试）

自定义术语表

通过 custom_terms.xlsx 指定专业术语的翻译映射，确保一致性：

原文 译文 说明
artificial intelligence 人工智能 技术术语
machine learning 机器学习 技术术语
neural network 神经网络 技术术语
large language model 大语言模型 技术术语

翻译引擎会优先使用术语表中的映射，确保专业名词的一致性。术语表在 Step 06（翻译）时自动注入到 prompt 中。

Prompt 模板定制

翻译与摘要的 prompt 模板定义在 core/prompts.py 中，可以根据需求调整：

# core/prompts.py
TRANSLATE_PROMPT = """
You are a professional translator. Translate the following text from {source} to {target}.
Maintain the original tone and style. Use the glossary below for consistent terminology:

{glossary}

Text to translate:
{text}

Translation:"""

支持以下模板变量：

  • {source} — 源语言代码（如 en）
  • {target} — 目标语言代码（如 zh-CN）
  • {glossary} — 术语表格式化字符串
  • {text} — 待翻译文本
  • {context} — 前文上下文（可选）

ASR / TTS 后端切换

YiviY 支持多个 ASR 与 TTS 后端，可在 config.yaml 中自由切换：

类型 后端 优势 需要 GPU
ASR WhisperX 本地 GPU · 词级时间戳 · 说话人分离 Recommended
HuggingFace 灵活模型选择 · 支持自定义模型 Optional
Replicate 云端 · 无需 GPU · 按用量付费 No
TTS OpenAI 高质量自然语音 · 多音色 No
Replicate 多模型可选 · 支持 voice cloning No
CTranslate2 本地 GPU · 快速推理 · 无 API 费用 Yes

UI 国际化

UI 文案通过 translations/ 目录管理，支持中英双语：

  • translations/en.json — 英文文案
  • translations/zh-CN.json — 简体中文文案
  • translations/translations.py — 加载与切换逻辑

Common Recipes

在 core/_3_asr.py 中注册新后端：

# core/_3_asr.py
def transcribe(audio_path, config):
    backend = config['asr']['backend']
    if backend == 'my_backend':
        from .backends.my_backend import MyBackend
        return MyBackend().transcribe(audio_path)
    # ... existing backends

在 config.yaml 中添加 subtitle 段：

subtitle:
  font: "Arial"
  font_size: 24
  primary_color: "&H00FFFFFF"  # white
  outline_color: "&H00000000"  # black
  outline_width: 2
  position: "bottom"  # top | center | bottom
  margin_v: 30

在 config.yaml 中配置 pipeline.skip_steps：

pipeline:
  skip_steps: [5]  # 跳过 Step 05 说话人分离

注意：跳过步骤可能导致后续步骤缺少依赖数据，请确认中间产物已存在。

提示：修改 config.yaml 后需要重启 Streamlit 应用（Ctrl+C 后重新运行 streamlit run st.py）。术语表修改无需重启，下次翻译自动生效。
