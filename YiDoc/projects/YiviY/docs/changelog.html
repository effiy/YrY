Changelog

YiviY（视频翻译配音工作台）版本演进历史。所有版本均通过 yry-init 流水线的 5 步验证。本文档记录每次发布的功能、修复与破坏性变更。

Semantic Versioning — 遵循 semver.org 规范。
New 新功能 Improved 优化 Fixed 修复 Breaking 破坏性变更

Version Timeline

v1.0 · Latest v0.9 · RC v0.8 v0.5 · Alpha v0.1 · Init
v1.0 2026-07-21 Latest
  • New 12 步流水线架构正式发布
  • New WhisperX ASR 后端集成（词级时间戳 + 说话人分离）
  • New 多 TTS 引擎支持（OpenAI · Replicate · CTranslate2）
  • New LLM 翻译集成（OpenAI GPT-4o）
  • New Streamlit Web UI 上线
  • New Docker 容器化部署（CUDA 12.4 GPU 加速）
  • New Google Colab 支持（VideoLingo_colab.ipynb）
  • New 自定义术语表（custom_terms.xlsx）
  • New 中英双语 UI 国际化
  • New Windows 一键批处理（OneKeyBatch.bat）
v0.9 2026-06-05 Release Candidate
  • RC 发布候选版本，完成核心流水线集成测试
  • New PyAnnote Audio 说话人分离
  • New spaCy NLP 句切分
  • Improved MoviePy 视频合成稳定性提升
  • Improved Rich 控制台 UTF-8 编码支持（Windows 兼容）
v0.8 2026-05-10
  • New 12 步流水线架构设计完成
  • New yt-dlp 视频下载集成
  • New WhisperX 初步集成
  • New Streamlit UI 原型
v0.5 2026-04-01 Alpha
  • Alpha 内部测试版本
  • New 基础 ASR + 翻译 + TTS 流程验证
  • New config.yaml 配置系统
v0.1 2026-03-01 Initial
  • Init 项目初始化
  • Init 架构设计与技术选型
