Pipeline Step Breakdown

Step Module Backend Input → Output
01 _1_ytdlp yt-dlp URL → mp4
02 _2_asr WhisperX / CTranslate2 mp4 → segments.json
03.1 _3_1_split_nlp spaCy segments → sentences.json
03.2 _3_2_split_meaning GPT-4o sentences → meaning.json
04.1 _4_1_summarize GPT-4o text → summary.json
04.2 _4_2_translate GPT-4o / Replicate sentences → translated.json
05 _5_split_sub spaCy translated → subtitle.json
06 _6_gen_sub local subtitle → .srt / .vtt
07 _7_sub_into_vid MoviePy + FFmpeg mp4 + srt → mp4 (hardsub)
08.1 _8_1_audio_task OpenAI / Replicate segments → tasks.json
08.2 _8_2_dub_chunks TTS backend tasks.json → chunks/
09 _9_refer_audio pydub chunks → references/
10 _10_gen_audio TTS backend references → full_dub.wav
11 _11_merge_audio FFmpeg dub + original → mixed.wav
12 _12_dub_to_vid MoviePy mp4 + mixed → final.mp4
