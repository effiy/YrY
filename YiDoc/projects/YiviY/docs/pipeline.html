12-Step Pipeline

YiviY 的核心是 12 步流水线，从视频下载到配音合成形成完整链路。每个步骤以 _N_xxx.py 命名，可独立调试或全流程运行。

步骤 模块 职责 输入 输出
1 _1_ytdlp.py 视频下载 URL video.mp4
2 _2_asr.py 语音识别（ASR） video.mp4 words.json（词级时间戳）
3.1 _3_1_split_nlp.py NLP 句切分 words.json segments.json
3.2 _3_2_split_meaning.py 语义感知切分 segments.json segments.json（优化）
4.1 _4_1_summarize.py 内容摘要 segments.json summary.txt
4.2 _4_2_translate.py LLM 翻译 segments.json + glossary translated.json
5 _5_split_sub.py 字幕行切分 translated.json subtitle_lines.json
6 _6_gen_sub.py 字幕生成（SRT/VTT） subtitle_lines.json subtitle.srt
7 _7_sub_into_vid.py 字幕嵌入视频 video.mp4 + subtitle.srt video_subbed.mp4
8.1 _8_1_audio_task.py 音频任务准备 translated.json audio_tasks.json
8.2 _8_2_dub_chunks.py 分块配音 audio_tasks.json dub_chunks/
9 _9_refer_audio.py 参考音频生成 原文音频 reference.wav
10 _10_gen_audio.py TTS 音频生成 audio_tasks.json + reference tts_audio.wav
11 _11_merge_audio.py 音频合并（原声+配音） original.wav + tts_audio.wav merged_audio.wav
12 _12_dub_to_vid.py 配音合成到视频 video_subbed.mp4 + merged_audio.wav final_output.mp4

│ 1. yt-dlp│  URL → video.mp4
└────┬─────┘
     │
┌────▼─────┐
│ 2. ASR   │  video → words.json (WhisperX)
└────┬─────┘
     │
┌────▼──────────┐
│ 3. NLP Split  │  words → segments (spaCy)
└────┬──────────┘
     │
┌────▼─────────┐
│ 4. Translate │  segments → translated (LLM)
└────┬─────────┘
     │
┌────▼────────┐
│ 5-6. Subtitle│  translated → .srt
└────┬────────┘
     │
┌────▼──────────┐
│ 7. Sub Embed  │  video + srt → video_subbed
└────┬──────────┘
     │
┌────▼────────┐
│ 8-10. Dub   │  translated → TTS audio
└────┬────────┘
     │
┌────▼────────┐
│ 11-12. Merge│  audio → final video
└────┬────────┘
     │
┌────▼─────┐
│  Output  │  final_output.mp4
└──────────┘
