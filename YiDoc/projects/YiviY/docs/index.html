Introduction

YiviY 是一款基于 Streamlit 的视频翻译配音工作台，提供 12 步流水线完成从视频下载到配音合成的全流程自动化。集成 ASR 语音识别、NLP 句切分、LLM 翻译、TTS 语音合成等能力，支持 WhisperX · Replicate · OpenAI · CTranslate2 等多个后端。

项目采用 Python + Streamlit 技术栈，通过 st.py 提供 Web UI，core/ 目录组织 12 个流水线步骤的独立模块。每个步骤以 _N_xxx.py 命名，按序号顺序执行，支持单步调试与全流程运行。

本文档面向所有希望安装、使用、定制或贡献 YiviY 的用户与开发者。7 个页面覆盖了从快速上手到流水线定制的完整旅程。

Architecture Overview

YiviY 的核心是 12 步流水线，每一步对应一个独立模块（core/_N_xxx.py），按序号顺序执行。Streamlit UI 提供交互入口，用户可以逐步运行或全流程自动化。下图展示了流水线的数据流向与模块依赖： 

┌─────────────────────────────────────────────────────────────────┐
│                       YiviY Video Translation                    │
├─────────────────────────────────────────────────────────────────┤
│  Input            │  Video URL (YouTube / Bilibili / local)       │
├─────────────────────────────────────────────────────────────────┤
│  Step 01          │  _1_video_downloader.py  (yt-dlp)             │
│  Step 02          │  _2_extract_audio.py   (ffmpeg)               │
│  Step 03          │  _3_asr.py             (WhisperX / CTranslate2)
│  Step 04          │  _4_sentence_split.py  (spaCy NLP)            │
│  Step 05          │  _5_speaker_diarize.py (PyAnnote)             │
│  Step 06          │  _6_translate.py       (GPT-4o / Replicate)   │
│  Step 07          │  _7_generate_subtitles.py (SRT / VTT)         │
│  Step 08          │  _8_tts.py             (OpenAI / Replicate /  │
│                   │                                               CTranslate2)
│  Step 09          │  _9_align_audio.py     (pydub + whisperX)     │
│  Step 10          │  _10_merge_audio.py    (ffmpeg)               │
│  Step 11          │  _11_render_video.py   (MoviePy)              │
│  Step 12          │  _12_final_output.py   (post-process)         │
├─────────────────────────────────────────────────────────────────┤
│  Supporting       │  config.yaml · custom_terms.xlsx              │
│                   │  i18n (en.json / zh-CN.json) · Rich logger    │
├─────────────────────────────────────────────────────────────────┤
│  UI Layer         │  st.py (Streamlit Web UI)                     │
│                   │  OneKeyBatch.bat · VideoLingo_colab.ipynb     │
└─────────────────────────────────────────────────────────────────┘
Note: 每一步都支持单步调试。流水线输出以 JSON 中间态存储于 output/ 目录，失败可重试任意步骤，无需从头开始。

Key Features

  • 12 步流水线 — 从 yt-dlp 下载到配音视频合成的完整链路
  • 多 ASR 后端 — WhisperX · HuggingFace Transformers · CTranslate2
  • NLP 句切分 — spaCy 驱动的语义感知分句
  • LLM 翻译 — OpenAI GPT · Replicate · 自定义模型
  • 多 TTS 引擎 — OpenAI TTS · Replicate · CTranslate2
  • 说话人分离 — PyAnnote Audio 多说话人识别
  • 字幕合成 — MoviePy 视频编辑与字幕叠加
  • Streamlit UI — 零前端代码的交互式 Web 界面
  • 批量处理 — OneKeyBatch 一键批量运行
  • 双语支持 — 中英双语字幕与配音
  • 自定义术语 — custom_terms.xlsx 术语表
  • Docker 部署 — GPU 加速的容器化部署
  • Colab 支持 — VideoLingo_colab.ipynb 云端运行
  • Rich 控制台 — UTF-8 编码的彩色日志输出
  • 多语言 UI — en.json / zh-CN.json 国际化
  • 74 源文件 — 精简的 Python 代码库 · 592KB

Use Cases

YiviY 的多步骤流水线使其能适配多种视频翻译与配音场景：

视频翻译配音

下载 YouTube 视频，自动生成双语字幕与配音，适用于跨语言内容创作与本地化。

多说话人配音

PyAnnote 说话人分离 + 多 TTS 引擎，保留原始对话结构与情感。

字幕生成

从视频自动生成 SRT / VTT 字幕文件，支持时间轴对齐与双语显示。
