   abstraction — reuse it instead of inventing a new one.
2. **Surgical Changes.** Don't "improve" adjacent code; match existing style
   (4-space indent, double quotes, PEP 8, type hints on public exports).
   Every changed line traces to the user's request.
3. **No silent writes outside cwd.** The cwd is the docs catalog entry at
   `YiDoc/projects/YiviY/`. Source-tree writes go through the user; this
   file only orchestrates the docs catalog.
4. **Streamlit-first.** YiviY has no `package.json` and no frontend build
   step. The Web UI is `st.py` (Streamlit) and step modules are plain Python
   under `core/`. Do not introduce a JS bundler or a separate frontend.

## Project Constraints

### Non-negotiable baselines

1. **No JS build step.** The Web UI is Streamlit (`st.py`); step modules are
   plain Python. Do not introduce a frontend bundler or a separate Vue/React
   UI — Streamlit widgets own all interactivity.
2. **The 12-step pipeline is the law.** Each step lives in
   `core/_N_xxx.py` (numeric prefix = execution order). New pipeline
   stages append a new `_N+1_xxx.py` module; they do **not** refactor
   existing step boundaries. Steps communicate through JSON intermediate
   state under `output/`.
3. **Backend adapters are isolated.** ASR backends live under
   `core/asr_backend/`; TTS backends under `core/tts_backend/`. Step
   modules (`_2_asr.py`, `_10_gen_audio.py`) dispatch to these adapters
   via config — they do not import backend SDKs directly.
4. **Config-driven, not code-driven.** API keys, model names, language
   pairs, and feature toggles live in `config.yaml` + the Streamlit
   sidebar. Do not hardcode keys or model versions in step modules.

### Degradation countermeasures

- WhisperX GPU unavailable → fall back to CTranslate2-accelerated Whisper
  (see `core/asr_backend/whisperX.py`).
- OpenAI / Replicate unreachable → `requests` surfaces the timeout; the
  Streamlit UI shows the error toast and the step can be retried from
  `output/` intermediate state without re-running earlier steps.
- `ffmpeg` missing → `install.py` aborts with a clear message (it is a
  hard prerequisite for steps 2 / 7 / 11 / 12).
- API key missing → `setup_env.py` raises before the pipeline starts; the
  Streamlit sidebar highlights the missing field.
- Step failure mid-pipeline → JSON intermediate state is preserved under
  `output/`; any step can be re-run individually via the sidebar selector.
