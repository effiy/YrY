Architecture Overview

YiWeb 是 Vue 3 CDN SPA：单一 HTML 入口 → Vue 运行时 → 路由懒加载 → 组件树。采用 Composition API + Hook 模式管理状态，无 Vite/Webpack 构建步骤。 

┌─────────────────────────────────────────────┐
│      Browser · index.html (CDN entry)         │
│  ┌─────────────────────────────────────────┐  │
│  │  Vue 3 Runtime (CDN · ~40 KB)           │  │
│  │  Vue Router 4 · Pinia · customElements  │  │
│  └─────────────────┬───────────────────────┘  │
└────────────────────┼──────────────────────────┘
                     │ createApp()
        ┌────────────▼────────────┐
        │     App.vue (root)      │
        │          │
        └────────────┬────────────┘
                     │ lazy import()
     ┌───────────────┼───────────────┐
     ▼               ▼               ▼
┌─────────┐    ┌──────────┐    ┌──────────┐
│ /aicr   │    │ /claude  │    │ /story   │
│ view    │    │ view     │    │ view     │
└────┬────┘    └────┬─────┘    └────┬─────┘
     │              │               │
     └──────────────┼───────────────┘
                    ▼
        Hooks Store (66 hooks)
        · useState · useChat · useStory
                    │
                    ▼
            fetch / SSE → backend

Key Features

  • CDN 零构建 — Vue 3 + Router + Store 全部 CDN 加载
  • Hook 模式 — 66 个自定义 Hook 统一状态/副作用/计算
  • 三大视图 — aicr / claude / story 各自独立懒加载
  • 组件化 — 20 个 SFC · 单文件组件 · scoped 样式
  • 路由守卫 — beforeEach 鉴权 · 动态标题 · meta 驱动
  • 性能优化 — 异步组件 · keep-alive · 虚拟滚动
