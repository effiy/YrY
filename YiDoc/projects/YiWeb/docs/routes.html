Vue Router Routes

YiWeb Vue 3 SPA 的路由清单。使用 Vue Router 4，支持懒加载与嵌套路由。

Route Catalog

Path Name Component Meta Lazy
/ home views/Home.vue title: 首页 ✓
/about about views/About.vue title: 关于 ✓
/dashboard dashboard views/Dashboard.vue title: 仪表盘 · auth: true ✓
/profile profile views/Profile.vue title: 个人中心 · auth: true ✓
/settings settings views/Settings.vue title: 设置 · auth: true ✓
/login login views/Login.vue title: 登录 · layout: blank ✓
/:pathMatch(.*)* not-found views/NotFound.vue title: 404 ✓

Router Configuration

// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    { path: '/', name: 'home', component: () => import('@/views/Home.vue'), meta: { title: '首页' } },
    { path: '/dashboard', name: 'dashboard', component: () => import('@/views/Dashboard.vue'), meta: { title: '仪表盘', auth: true } },
    // ...
  ]
})

router.beforeEach((to, from, next) => {
  document.title = to.meta.title ? `${to.meta.title} · YiWeb` : 'YiWeb'
  if (to.meta.auth && !isAuthenticated()) next('/login')
  else next()
})

Navigation Guards

beforeEach

全局前置守卫 — 处理 auth 检查与页面 title 设置

beforeResolve

组件加载完成后执行 — 常用于数据预加载

afterEach

导航完成后触发 — 常用于分析埋点、滚动恢复

Meta Fields Reference

Meta Key Type Default Description
title string 'YiWeb' 页面标题 — 显示在浏览器标签页
auth boolean false 是否需要登录 — 未认证重定向到 /login
layout string 'default' 布局类型 — 'blank' 用于登录/错误页
keepAlive boolean false 是否缓存组件状态
icon string — 侧边栏图标 class

Lazy Loading Strategy

所有页面组件使用动态 import() 实现懒加载。Vite 自动进行 code-splitting：

// 懒加载组件 — 按需加载
component: () => import('@/views/Dashboard.vue')

// Vite 构建产物
dist/
├── index.html
├── assets/
│   ├── Dashboard-abc123.js   # 按需加载
│   ├── Home-def456.js        # 按需加载
│   ├── Profile-ghi789.js     # 按需加载
│   └── vendor-jkl012.js      # 第三方库（长期缓存）

// 预加载关键路由
import(/* prefetch */ '@/views/Dashboard.vue')

// 预获取数据
router.beforeRouteEnter((to, from, next) => {
  fetchDashboardData().then(data => {
    next(vm => vm.initData = data)
  })
})

Navigation Guards

YiWeb 使用全局前置守卫进行鉴权与标题同步：

router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('yry-token')

  // 1. 标题同步
  document.title = to.meta.title
    ? `${to.meta.title} · YiWeb`
    : 'YiWeb'

  // 2. 鉴权
  if (to.meta.requiresAuth && !token) {
    next({ name: 'login', query: { redirect: to.fullPath } })
    return
  }

  // 3. 埋点
  trackPageView(to.path)

  next()
})

router.afterEach((to) => {
  // 关闭全局 loading
  store.loading = false
  // 滚动到顶部
  window.scrollTo(0, 0)
})

Route Reload Pattern

强制重新加载当前路由组件（清除 keep-alive 缓存）：

// 方法 1：key 强制重渲染
<router-view :key="$route.fullPath" />

// 方法 2：编程式 reload
function reloadPage() {
  const path = route.fullPath
  router.replace({ path: '/redirect' + path })
}
// redirect 路由定义
{ path: '/redirect/:path(.*)', redirect: to => '/' + to.params.path }
