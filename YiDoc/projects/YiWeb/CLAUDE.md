- **Trust the model.** Default to reading the source before assuming; let the
  code be the authority when docs and code disagree.
- **Value attention.** A small surgical change beats a sprawling refactor;
  scope is a finite resource, spend it on the user's actual request.

## Iron Laws

1. **Simplicity First.** No features beyond what was asked; no abstractions
   for single-use code; no error handling for impossible scenes. The hook
   pattern (store + computed + methods per view) is the established
   abstraction — reuse it instead of inventing a new one.
2. **Surgical Changes.** Don't "improve" adjacent code; match existing style
   (2-space indent, double quotes, ES modules, no semicolons, JSDoc on
   public exports). Every changed line traces to the user's request.
3. **No silent writes outside cwd.** The cwd is the docs catalog entry at
   `YiDoc/projects/YiWeb/`. Source-tree writes go through the user; this
   file only orchestrates the docs catalog.
4. **CDN-first.** YiWeb has no `package.json` and no build step. Vue 3, the
   shared `/cdn/utils/*` helpers, and all UI components are loaded via
   `<script>` tags from `/YiPet/cdn/`. Do not introduce npm-style imports
   into the source.

## Project Constraints

### Non-negotiable baselines

1. **No build step.** Source ships as native ES modules. Vue 3 SFC syntax
   is not used — components are HTML templates loaded dynamically by
   `componentLoader.js`. Do not introduce a bundler.
2. **Hook pattern is the law.** Each view (`aicr`, `claude`, `story`) owns
   its `composables/store.js` (state), `composables/useComputed.js`
   (derived), `composables/useMethods.js` (actions). New state lives in
   the owning view's `composables/`; cross-view state goes through
   `src/services/`.
3. **CDN paths are absolute.** Imports like `/cdn/utils/core/log.js` and
   `/src/utils/resizer.js` resolve from the web root. Do not relativize
   them.
4. **Dark mode + zh-CN.** Default UI language is Simplified Chinese; CSS
   token bridge (`--yry-*`) shared with the YiDoc catalog.

### Degradation countermeasures

- Vue 3 CDN load fails → fall back to `unpkg.com/vue@3.4.27` (see root
  `index.html` of catalog entries).
- Ollama unreachable → `requestHelper.js` surfaces the timeout; the UI
  shows the error state via `YiErrorState`.
- Auth token missing → `authErrorHandler.js` opens the API-settings dialog.
- Streaming response aborts → `AbortController` in `requestHelper.js`
  releases the reader; no leaked socket.

### Self-constraints

- This docs catalog entry (`YiDoc/projects/YiWeb/`) is regenerated by
  `yry-init`. The dashboard `data.js`, `index.html`, `index.css`,
  `index.js` are the docs home 4-file set; `CLAUDE.md` and `README.md`
  sit beside them; `arch/` + `test/` are the two story directories.
- The actual YiWeb source tree lives at
  `/Users/ruiyi/Downloads/YrY/YiWeb/`; this catalog entry reads it but
  writes nothing there.
