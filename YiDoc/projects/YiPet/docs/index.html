Introduction

YiPet（温柔陪伴助手）是一款基于 Chrome Manifest V3 的浏览器扩展，旨在为用户的浏览时光添加一位温柔体贴的 AI 伴侣。它集成了 AI 对话、FAQ 知识库、Markdown / Mermaid 渲染，并通过共享的 YiPet/cdn/ 组件体系提供一致的 UI 与交互体验。

扩展采用 IIFE 模块化架构，通过 manifest.json 声明权限、内容脚本与后台 service worker，核心代码组织在 core/ 与 modules/ 两大目录下。共享原型工具方法与 CDN 资源已统一迁移至 cdn/ 顶层，便于跨项目复用。

本文档面向所有希望了解、安装、定制或贡献 YiPet 的用户与开发者。从安装、定制到模块深度解析，7 个页面覆盖了 YiPet 的完整生命周期。

Architecture Overview

YiPet 采用经典的 三段式扩展架构：UI 层（Popup / SidePanel）↔ 逻辑层（Service Worker + Content Scripts）↔ 资源层（CDN + Storage）。下图展示了各层之间的数据流向： 

┌─────────────────────────────────────────────────────────────────┐
│                       Chrome Extension (MV3)                     │
├─────────────────────────────────────────────────────────────────┤
│  UI Layer         │  Popup Window  │  SidePanel  │  Content UI   │
│                    └────────┬───────┴──────┬──────┴──────┬───────┘
│                             │              │             │
│                             ▼              ▼             ▼
├─────────────────────────────────────────────────────────────────┤
│  Logic Layer      │  Background Service Worker (MV3)              │
│                    │  ┌──────────────────────────────────────┐  │
│                    │  │ SessionService · API · Logger         │  │
│                    │  │ imageResourceManager · token · error  │  │
│                    │  └─────────────────┬────────────────────┘  │
│                    └────────────────────┼────────────────────────┘
│                                         │
│                             chrome.runtime.sendMessage
│                                         ▼
├─────────────────────────────────────────────────────────────────┤
│  Content Layer    │  Content Scripts (chrome.scripting)          │
│                    │  ┌──────────────────────────────────────┐  │
│                    │  │ Mermaid · Markdown · FAQ · Pet        │  │
│                    │  └─────────────────┬────────────────────┘  │
│                    └────────────────────┼────────────────────────┘
│                                         │
├─────────────────────────────────────────────────────────────────┤
│  Resource Layer   │  CDN (49 assets)  │  chrome.storage.local   │
│                    │  52 Web Components │  FAQ cache · Sessions   │
└─────────────────────────────────────────────────────────────────┘
Note: 所有跨层通信都通过 chrome.runtime 消息 API，避免直接访问 DOM 或 window 对象，符合 MV3 安全模型。

Key Features

  • Manifest V3 — 符合 Chrome 最新扩展规范，service worker 后台 + content scripts 注入
  • AI 陪伴对话 — 温柔体贴的 AI 伴侣，支持上下文会话与多轮交互
  • FAQ 知识库 — 内容驱动的 Q&A 模块，Markdown 渲染 + Mermaid 图表
  • Markdown / Mermaid 渲染 — 基于 marked + mermaid 的富文本展示
  • 共享 CDN 组件体系 — 49 CDN 资源库 · 52 Web Components · 统一设计语言
  • 会话管理 — SessionService + sessionManager 管理多会话状态
  • 权限最小化 — 仅声明 storage / tabs / scripting / webRequest
  • 跨域 API — 统一 token / error / logger / request 管道
  • IIFE 模块化 — 无构建步骤，直接以 <script> 顺序加载
  • Background Service Worker — MV3 事件驱动的后台逻辑
  • Content Script 注入 — 精确控制注入顺序与依赖关系
  • Popup UI — 扩展弹窗，用户交互入口
  • Pet 互动组件 — companion 角色与动画反馈
  • 图片资源管理 — imageResourceManager 统一管理扩展图片
  • Loading 动画 — loadingAnimationMixin 提供一致的加载反馈
  • 527 源文件 — 完整的扩展生态 · 25MB 资源体量

Use Cases

YiPet 的架构设计使其能适配多种陪伴与知识辅助场景：

AI 陪伴对话

在浏览任何网页时，通过扩展弹窗或侧边面板与 AI 伴侣进行多轮对话，获取温柔体贴的陪伴与建议。

FAQ 知识查询

内容驱动的 FAQ 模块，支持 Markdown 渲染与 Mermaid 图表，适用于产品帮助、术语解释、流程指引等场景。

浏览陪伴

Pet 互动组件在用户浏览时提供轻量陪伴反馈，增强长时间浏览的趣味性与情感连接。
