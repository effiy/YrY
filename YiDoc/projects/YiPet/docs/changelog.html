Changelog

YiPet（温柔陪伴助手）版本演进历史。所有版本均通过 yry-init 流水线的 5 步验证（detect → explore → generate → arch → verify）。本文档记录每次发布的功能、修复与破坏性变更。

Semantic Versioning — 遵循 semver.org 规范（MAJOR.MINOR.PATCH）。
New 新功能 Improved 优化 Fixed 修复 Breaking 破坏性变更

Version Timeline

v1.1.2 · Latest v1.1.1 v1.1.0 v1.0.x
v1.1.2 2026-07-21 Latest
  • New 共享 CDN 资源体系迁移至 cdn/ 顶层目录
  • New Mermaid 图表渲染支持（5 插件：AIFix · Clipboard · Download · Fullscreen · Toolbar）
  • New Markdown 渲染引擎升级为插件化架构（9 插件）
  • Improved SessionService 会话管理性能优化
  • Improved Pet 互动动画流畅度提升
  • Fixed content script 注入顺序导致的依赖错误
v1.1.1 2026-06-15
  • New FAQ 模块本地缓存策略（支持离线访问）
  • New Popup UI 响应式布局适配
  • Improved API 请求管道增加 tenacity 风格的重试机制
  • Fixed Service Worker 休眠后状态丢失问题
v1.1.0 2026-05-08 Major
  • Breaking 迁移至 Manifest V3 规范
  • New Background Service Worker 替代 persistent background page
  • New 动态 content script 注入（chrome.scripting API）
  • New 共享 Web Components 体系（YrYButton · YrYSceneCard · YrYModal …）
  • Improved 权限模型细化，支持可选权限请求
Migration: 从 v1.0.x 升级到 v1.1.0 需要更新 manifest.json 为 V3 格式。Background page 需迁移为 Service Worker。Content script 注册方式改为 chrome.scripting.executeScript。
v1.0.x 2026-03 ~ 2026-04 Initial
  • New v1.0.3: 初始 AI 对话功能上线
  • New v1.0.2: Pet 互动组件首版发布
  • New v1.0.1: 基础扩展框架搭建（Manifest V2）
  • Init v1.0.0: 项目初始化
Detailed Diff

每个版本的完整代码差异可通过 Git 查看：

# 查看 v1.1.1 → v1.1.2 的所有提交
git log --oneline v1.1.1..v1.1.2

# 查看特定版本的文件变更
git diff v1.1.1..v1.1.2 --stat

# 查看 Manifest V3 迁移的完整 diff
git diff v1.0.3..v1.1.0 -- manifest.json
Contributing
