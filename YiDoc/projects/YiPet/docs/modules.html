Modules

YiPet 采用三层模块化架构：core/ 提供基础设施，modules/ 承载功能业务，cdn/ 汇聚共享资源。各模块通过 IIFE 暴露全局接口，由 manifest.json 控制加载顺序。

core/ — 核心基础设施

Module Role Key API
config.js 全局配置中心 — API 端点、功能开关、UI 主题参数。所有模块通过 window.YIPET_CONFIG 读取。 getConfig() · setConfig()
bootstrap/ 扩展生命周期引导 — 初始化序列、服务注册、依赖检查。确保各模块按正确顺序启动。 init() · registerService()
api/services/ API 服务层 — SessionService（会话管理）与 FaqService（FAQ 查询），共享 token / error / logger / request 管道。 SessionService · FaqService
constants/ 常量与端点定义 — endpoints.js 集中管理所有 API 路径，避免硬编码。 ENDPOINTS · CONFIG_KEYS
logger.js 统一日志接口 — 分级输出（debug · info · warn · error），支持 chrome://extensions/ 调试。 log.debug() · log.error()
token.js API Token 管理 — 读取 chrome.storage.local 中的密钥，自动 refresh 过期 token。 getToken() · refreshToken()
error.js 错误分类与上报 — 将原始错误包装为业务错误码，上报到 Service Worker 的错误追踪。 classifyError() · report()

Module Loading Order

manifest.json 中的 content_scripts 数组决定了脚本加载顺序，错误的顺序会导致运行时 ReferenceError： 

// manifest.json — content_scripts order (critical)
"content_scripts": [
  {
    "matches": ["<all_urls>"],
    "js": [
      "cdn/vendor/marked/marked.min.js",     // 1. 第三方库
      "cdn/vendor/mermaid/mermaid.min.js",
      "cdn/utils/browser.js",                // 2. 工具层
      "cdn/utils/core.js",
      "core/config.js",                      // 3. 核心层
      "core/token.js",
      "core/logger.js",
      "core/api/services/SessionService.js", // 4. 服务层
      "core/api/services/FaqService.js",
      "modules/pet/content/pet.js",          // 5. 业务层
      "modules/faq/content/faq.js"
    ]
  }
]
Dependency Rule: config.js 必须在 token.js 之前（token 依赖配置中的端点）；loader.js 必须在任何 Web Component 之前（注册自定义元素）；第三方库必须在工具层之前。

IIFE Module Pattern

每个模块遵循统一的 IIFE 模式，通过全局命名空间暴露接口：

// modules/pet/content/pet.js
(function (window, config, logger) {
  'use strict';

  const Pet = {
    // 内部状态
    state: { emotion: 'happy', x: 0, y: 0 },

    // 公开方法
    init() {
      logger.debug('[Pet] initialized');
      this.render();
      this.bindEvents();
    },
    render() { /* ... */ },
    bindEvents() { /* ... */ }
  };

  // 暴露到全局命名空间
  window.YrY = window.YrY || {};
  window.YrY.Pet = Pet;

})(window, window.YrY.Config, window.YrY.Logger);
