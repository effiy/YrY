目录结构

Permissions Matrix

Permission Scope Usage
storage Local API Key 加密存储 · 会话状态 · 用户偏好 · FAQ 缓存
tabs Read-only 检测当前标签页 URL · 控制 Popup 内容
scripting Runtime 动态注入 content scripts（FAQ / Pet）
webRequest Filter API 请求拦截 · Token 注入 · 错误重试
最小权限原则：YiPet 仅声明上述 4 项权限，无 activeTab / bookmarks / browsingData 等敏感权限。所有 API Key 在 chrome.storage.local 中以 AES 加密存储。
