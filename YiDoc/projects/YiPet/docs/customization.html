Customization

YiPet 提供了多个配置入口，允许你自定义 API 端点、UI 主题、功能开关等。所有配置集中在 core/config.js 中，运行时可通过 chrome.storage API 持久化用户偏好。

Config Entry Points
core/config.js
全局运行时配置
cdn/styles/*
CSS Variables 主题层
modules/pet/config.js
Pet 角色参数

API Endpoints 配置

在 core/config.js 中定义 API 端点和认证信息：

// core/config.js
window.YIPET_CONFIG = {
  api: {
    baseUrl: 'https://api.effiy.cn/v1',
    endpoints: {
      chat: '/chat/completions',
      session: '/sessions',
      faq: '/faq/query'
    }
  },
  features: {
    enablePetAnimation: true,
    enableMarkdownRender: true,
    enableMermaidRender: true,
    debugMode: false
  },
  ui: {
    theme: 'auto', // 'light' | 'dark' | 'auto'
    animationSpeed: 'normal' // 'slow' | 'normal' | 'fast'
  }
};

Feature Flags

Flag Default Effect
enablePetAnimation true Pet 角色的表情、动作动画
enableMarkdownRender true Markdown 渲染插件系统（9 插件）
enableMermaidRender true Mermaid 图表渲染（5 插件）
debugMode false 启用 verbose 日志输出（debug 级别）
enableOfflineMode true FAQ 离线访问（Service Worker 缓存）
enableMultiSession true 支持同时保持多个会话

Theme 主题定制

YiPet 使用 CSS 自定义属性（CSS Variables）实现主题切换。你可以通过修改 cdn/styles/ 下的样式文件来自定义主题：

变量名 默认值 说明
--yipet-bg #ffffff 主背景色
--yipet-text #333333 主文字颜色
--yipet-accent #6366f1 强调色（按钮、链接）
--yipet-border #e5e7eb 边框颜色
--yipet-shadow 0 2px 8px rgba(0,0,0,.08) 浮层阴影（Popup / 卡片）
--yipet-radius 8px 圆角半径
--yipet-font 'Inter', sans-serif 主字体

自定义主题示例 — 在 assets/css/docs.css 中覆盖：

:root {
  --yipet-bg: #fafafa;
  --yipet-accent: #ec4899; /* pink accent */
  --yipet-border: #f3f4f6;
  --yipet-radius: 12px;
}

Pet 角色定制

YiPet 的陪伴角色外观定义在 modules/pet/components/ 中。你可以：

  • 替换角色图片 — 修改 modules/pet/assets/ 下的图片资源
  • 调整动画参数 — 在 modules/pet/config.js 中配置动画速度、触发条件
  • 扩展交互行为 — 在 modules/pet/content/ 中添加新的事件监听器 
// modules/pet/config.js
window.YIPET_PET = {
  companion: {
    name: 'YiPet',
    idleAnimation: 'breathing',
    emotionCycle: ['happy', 'curious', 'sleepy'],
    emotionInterval: 30000, // ms
  },
  triggers: {
    onPageLoad: { emotion: 'happy', duration: 2000 },
    onScroll:   { emotion: 'curious', duration: 1500 },
    onIdle:     { emotion: 'sleepy', duration: 5000 }
  }
};

FAQ 知识库配置

FAQ 模块的内容通过 API 动态获取，但你可以配置本地缓存策略：

// core/config.js 中的 FAQ 配置
faq: {
  cacheTTL: 3600,       // 缓存有效期（秒）
  maxEntries: 100,      // 本地缓存最大条目数
  enableOfflineMode: true // 启用离线访问已缓存的 FAQ
}

Common Recipes

修改 api.baseUrl 指向自建 OpenAI 兼容服务：

api: {
  baseUrl: 'https://my-llm.example.com/v1',
  endpoints: {
    chat: '/chat/completions',
    // 支持自定义端点
    translate: '/translate'
  }
}

在 cdn/markdown/plugins/ 创建新插件文件，命名规范 XxxPlugin.js，必须实现： 

// cdn/markdown/plugins/MyPlugin.js
window.YrYMarkdownPlugins = window.YrYMarkdownPlugins || [];
window.YrYMarkdownPlugins.push({
  name: 'my-plugin',
  init: function (md) {
    md.use(/* marked extension */);
  }
});

YiPet 通过 cdn/i18n/ 管理多语言。添加新语言：

  1. 复制 en.json 为 ja.json（日语为例）
  2. 翻译所有 key 对应的 value
  3. 在 Popup 设置中选择 "Language: Japanese"
提示：修改配置后需要重新加载扩展（chrome://extensions/ → 🔄）才能生效。所有配置变更可通过 Popup → Settings → Advanced → Export 导出为 JSON 文件备份。
