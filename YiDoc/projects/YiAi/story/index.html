模块化方向

  • 公共 API 显式化：每个领域模块 __init__.py 显式 __all__ 导出。
  • 跨模块依赖方向：引入 services → domain 单向依赖断言。
  • 路由层瘦身：路由只做参数解析与委派。
  • observer 旁路：定义 Event 类型，订阅而非直调。

非目标

  • 不拆分独立服务（模块化优先于微服务化）。
  • 不强制更换 ORM。
