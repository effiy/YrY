API Endpoints

YiAi FastAPI 后端暴露的 HTTP 端点清单。所有端点需通过 X-Token 头部认证（除 /health）。

Authentication

# 所有受保护端点需在请求头携带
X-Token: your-secret-token

Example Request

curl -X POST http://localhost:8000/api/execute \
  -H "Content-Type: application/json" \
  -H "X-Token: your-secret-token" \
  -d '{"module": "ai.chat", "input": {"message": "hello"}}'

Response Format

{
  "code": 0,
  "message": "success",
  "data": { ... },
  "timestamp": "2026-07-21T12:00:00Z"
}

Error Codes

Code HTTP Status Meaning Common Cause
0 200 Success —
400 400 Bad Request 参数缺失或格式错误
401 401 Unauthorized X-Token 缺失或无效
404 404 Not Found 模块或资源不存在
429 429 Too Many Requests 超出速率限制
500 500 Internal Server Error 服务异常 — 检查日志

SSE Streaming Example

/api/execute 支持 Server-Sent Events 流式响应，适用于 AI 对话场景：

curl -X POST http://localhost:8000/api/execute \
  -H "Content-Type: application/json" \
  -H "X-Token: your-secret-token" \
  -H "Accept: text/event-stream" \
  -d '{"module": "ai.chat", "input": {"message": "hello", "stream": true}}'

# 响应（SSE 格式）
data: {"chunk": "Hello"}
data: {"chunk": ", how"}
data: {"chunk": " can I help?"}
data: [DONE]

Module Registry

/api/execute 通过模块名路由到具体业务模块。可用模块清单：

Module Category Input Schema
ai.chat AI 对话 {message: string, stream?: bool}
ai.code_review 代码评审 {code: string, lang: string}
ai.story 故事生成 {prompt: string, n: int}
rss.fetch RSS 拉取 {url: string, limit?: int}
rss.summarize 内容摘要 {url: string}
oss.upload OSS 上传 {file: binary, path: string}
oss.sign 预签名 URL {key: string, expires?: int}

Python SDK Example

import requests

BASE = "http://localhost:8000/api"
HEADERS = {"X-Token": "your-secret-token", "Content-Type": "application/json"}

# 同步调用
resp = requests.post(f"{BASE}/execute", headers=HEADERS,
                     json={"module": "ai.chat", "input": {"message": "hello"}})
print(resp.json()["data"])

# SSE 流式调用
with requests.post(f"{BASE}/execute", headers=HEADERS, stream=True,
                   json={"module": "ai.chat",
                         "input": {"message": "hello", "stream": True}}) as r:
    for line in r.iter_lines():
        if line:
            print(line.decode())

Pagination Convention

列表端点（/api/files / /api/stories 等）使用统一的分页参数：

Param Type Default Description
page int 1 页码（从 1 开始）
page_size int 20 每页条数（max 100）
sort string -created_at 排序字段（- 前缀表示降序）
q string — 全文搜索关键词 
# 响应结构
{
  "code": 0,
  "data": {
    "items": [...],
    "total": 142,
    "page": 1,
    "page_size": 20
  }
}

Webhook Events

企业微信 Webhook（/api/wework/webhook）支持的消息类型：

  • text — 纯文本消息
  • markdown — Markdown 格式（支持加粗、链接、代码块）
  • image — 图片消息（base64 或 URL）
  • news — 图文消息（1-8 条）
  • template_card — 模板卡片（按钮、投票、表单）
