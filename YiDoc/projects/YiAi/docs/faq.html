General 4

YiAi 支持 Docker 容器化、systemd 服务、uvicorn + Gunicorn 生产部署等主流部署方式。推荐生产环境使用 Docker 或 CI/CD 自动化部署。

查看 Changelog 了解版本变更，按迁移指南操作。建议先在开发环境验证后再部署生产。每次升级前请备份数据和配置。

Python 3.10+ · FastAPI · MongoDB · motor · Pydantic · uvicorn。

本项目遵循 MIT 许可证开源。你可以自由使用、修改和分发，但需保留原始版权声明。

Development 5

参考 Specifications 中的模块清单，在对应目录添加新文件并遵循现有架构模式。建议先创建 arch scene 记录设计决策，再编写代码。

推荐 VS Code + Python Extension Pack + Black Formatter + isort。项目根目录已包含 .editorconfig 和 .gitignore。

pytest tests/ -v --cov=src — 生成覆盖率报告到 htmlcov/。

ruff check src/ && black --check src/。建议在 CI 中集成 lint 步骤。

Fork → 创建 feature 分支 → 编写代码 + 测试 → 提交 PR。PR 需通过 CI 检查（lint + test + build）并由维护者 review。

Troubleshooting 4

查阅 Setup 的 Troubleshooting 章节，或查看 logs/ 目录中的日志文件。常见问题已在下方列出。如果问题无法解决，请在 Git 仓库提 issue。

使用 mongodump 定期备份 MongoDB，OSS 中的文件通过 oss2 SDK 下载。推荐每日自动备份 + 每周全量备份。

FastAPI 异步架构支持 1000+ 并发连接。优化建议：MongoDB 索引、连接池调优、Gunicorn worker 数量 = CPU 核心 × 2 + 1。

检查 config.yaml 中的 mongodb.uri。确认 MongoDB 服务运行正常：mongosh 测试连接。调整 mongodb.pool_size 参数。

Security 3

所有受保护端点需通过 X-Token 头部认证。Token 在 config.yaml 的 auth.token 配置。生产环境建议使用环境变量注入。

使用环境变量或 config.yaml（已加入 .gitignore）存储敏感信息。切勿将密钥提交到 Git 仓库。推荐使用 HashiCorp Vault 或 AWS Secrets Manager。

推荐在 Nginx/Caddy 反向代理层配置 TLS 证书，而非直接在 FastAPI 中启用。

Still stuck? 查阅 Setup Troubleshooting 或检查 Changelog 是否已知问题已在最新版本修复。也可以在 Git 仓库提 issue 获取帮助。
