Architecture Overview

YiAi 采用分层异步架构：FastAPI 路由 → Pydantic 模型 → 异步服务层 → MongoDB / OSS。所有 I/O 均为 async/await，支持高并发请求。

Key Features

  • 模块化执行引擎 — 热插拔 Module，通过 registry 注册并按需加载
  • AI 对话 — OpenAI 兼容接口 · 流式响应 · 多轮上下文
  • RSS 订阅 — 定时拉取 · 内容解析 · Markdown 摘要
  • OSS 存储 — S3 兼容 API · 预签名 URL · 图片/音频
  • JWT 鉴权 — 短期 access token + 长期 refresh token
  • 可观测性 — 结构化日志 · /health · /metrics 端点
