Setup

Quick Start — YiAi 是一个 FastAPI + MongoDB 后端。以下步骤假设你已具备基本的 Python 开发经验。预计安装时间 5-10 分钟。

Prerequisites

Requirement Version Purpose Status
Python 3.10+ 运行 FastAPI + 异步任务 Required
MongoDB 6.0+ 数据持久化 Required
pip 23+ 依赖管理 Required
Git 2.30+ 版本控制 Required
Docker 24+ 容器化部署 Optional
mongosh 2.0+ MongoDB CLI 调试 Optional
Tested on
macOS 13+ · Ubuntu 22.04 · Windows 11 (WSL2)
Known issues
MongoDB 4.x 不支持新的聚合管道特性
Tip
推荐使用 pyenv 管理 Python 版本

Installation Steps

  1. 1
    Clone the repository 
    git clone <repository-url>
cd YiAi
  2. 2
    Create virtual environment 
    python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
  3. 3
    Install dependencies 
    pip install -r requirements.txt
  4. 4
    Configure environment 
    cp config.example.yaml config.yaml
# 编辑 config.yaml 填入 MongoDB URI、API 密钥等
  5. 5
    Start the server 
    uvicorn main:app --reload --host 0.0.0.0 --port 8000

Development Workflow

步骤 操作 Expected Result

Docker Setup (Optional)

推荐使用 Docker 进行生产部署，避免环境差异：

# # Dockerfile (Python)
FROM python:3.10-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

# docker-compose.yml
version: '3.8'
services:
  yiai:
    build: .
    ports:
      - "8000:8000}
    environment:
      - NODE_ENV=production
    restart: unless-stopped

# 启动
docker-compose up -d

Troubleshooting

检查 config.yaml 中的 mongodb.uri 是否正确。确认 MongoDB 服务已启动。 

# 验证 MongoDB 连接
mongosh "mongodb://localhost:27017"

# 检查服务状态
systemctl status mongod  # Linux
brew services list       # macOS

确认请求头包含 X-Token: your-secret-token。Token 需与 config.yaml 中的 auth.token 一致。

默认端口 8000 被占用时，更改配置或释放端口：

uvicorn main:app --port 8001

# 或释放端口（macOS/Linux）
lsof -i :8000
kill -9 <PID>
Verification — 安装成功后：
  • 访问 http://localhost:8000/api/health 应返回 {"status": "healthy"}
  • Swagger UI 可访问：http://localhost:8000/docs
  • 所有依赖版本与 requirements.txt 一致
