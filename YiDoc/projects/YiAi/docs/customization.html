Customization

YiAi 提供多种定制选项，覆盖配置、主题、API 端点与扩展机制。以下是常用定制场景与代码示例。

Configuration Files

File Purpose Common Edits
config.yaml 主配置文件 — MongoDB、API、认证 URI · Token · CORS · 日志级别

.env (optional) 环境变量覆盖 生产密钥 · 敏感配置

layout.js Configuration Shim

每个项目的 docs/assets/js/layout.js 是一个 30 行的 shim，设置 window.YRY_DOC_CONFIG 后加载共享 layout.js： 

window.YRY_DOC_CONFIG = {
    brand:        'YiAi',
    tagline:      'FastAPI + MongoDB 后端',
    version:      'v1.0.0',
    brandColor:   '#ef4444',
    pages: [
        { key: 'index',    href: 'index.html',    icon: 'ri-honour-line',    label: 'Introduction' },
        { key: 'setup',    href: 'setup.html',    icon: 'ri-tools-fill',     label: 'Setup'        },

Extension Recipes

Add a New Doc Page
  1. 创建 docs/new-page.html
  2. 在 layout.js shim 的 pages 数组添加条目
  3. 使用 <main id="page-content" data-page="new-page"> 包裹内容
Override Shared Styles
  1. 编辑 docs/assets/css/docs.css
  2. 覆盖 --yry-doc-* 变量
  3. 共享 layout.js 自动应用新主题
Tip: 所有 YiAi 文档页面共享 projects/templates/docs/ 中的 layout.js 与 docs.css。定制交互行为（暗色模式、侧边栏搜索、TOC、代码复制按钮）时编辑共享文件即可全局生效。

Environment Variables

YiAi 支持通过 .env 文件或系统环境变量覆盖 config.yaml 中的值：

Variable Default Description
YIAI_MONGODB_URL — MongoDB 连接字符串（覆盖 mongodb.url）
YIAI_AUTH_TOKEN — X-Token 鉴权密钥
YIAI_LOG_LEVEL INFO 日志级别（DEBUG/INFO/WARN/ERROR）
YIAI_OSS_ENDPOINT — OSS 服务端点（S3 兼容）
YIAI_OPENAI_API_KEY — LLM Provider API Key
YIAI_SENTRY_DSN — Sentry 错误监控 DSN（可选）

Module Development

添加新模块到 /api/execute 的步骤：

# 1. 创建模块文件
# src/modules/my_feature/__init__.py
from typing import Dict, Any

async def execute(input: Dict[str, Any]) -> Dict[str, Any]:
    """模块入口函数"""
    name = input.get("name", "world")
    return {"greeting": f"Hello, {name}!"}

# 2. 注册到 ModuleRegistry
# src/modules/registry.py
from . import my_feature
REGISTRY["my_feature.greet"] = my_feature.execute

# 3. 调用
curl -X POST /api/execute \
  -H "X-Token: ..." \
  -d '{"module": "my_feature.greet", "input": {"name": "YiAi"}}'

Security Hardening Checklist

  • 生产环境：将 auth.token 替换为 JWT 签发机制（避免硬编码）
  • CORS：在 main.py 中限制 allow_origins 为已知域名
  • HTTPS：通过 Nginx/Caddy 终止 TLS · HSTS · HTTP/2
  • 速率限制：启用 slowapi 中间件 · IP 级 + Token 级
  • 日志脱敏：在 logging filter 中过滤 password / token 字段
  • 数据库索引：为 user_id / created_at 建立复合索引
