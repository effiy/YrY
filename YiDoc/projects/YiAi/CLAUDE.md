   (4-space indent, double-quoted strings, ES-modules-style imports via

   `YiDoc/projects/YiAi/`. Source-tree writes go through the user; this

4. **FastAPI + Motor async-first.** YiAi is fully async (FastAPI + Motor +
   AIOHTTP + APScheduler). Do not introduce blocking I/O in request paths;
   route handlers are `async def`, services return awaitables.

## Project Constraints

### Non-negotiable baselines

1. **No bundler, no transpile.** Source ships as plain Python modules under
   `src/`; `sys.path` is augmented at startup in `main.py` and `src/app.py`.
   Do not introduce a build step.
2. **Layered architecture is the law.** Routes (`src/server/routes/`) →
   Services (`src/services/`) → Domain (`src/domain/`) → Data
   (`src/data/`). New endpoints follow this triple; `shared/` is the only
   cross-cutting layer (config / response / error_codes / exceptions /
   logging / utils).
3. **Config lives in `config.yaml`.** All runtime knobs (server host/port,
   MongoDB URL, OSS credentials, Ollama URL, observer toggles, RSS
   scheduler) are loaded via `src/shared/config.py`'s `settings` singleton.
   Do not hardcode values that belong in `config.yaml`.
4. **Async-first I/O.** Every route handler that touches MongoDB, OSS, or
   external HTTP is `async def`. APScheduler runs on `AsyncIOScheduler`.
   Observer middleware (`throttle`, `sampler`, `sandbox`, `guard`) wraps
   the ASGI app without blocking.

### Degradation countermeasures

- MongoDB unreachable → `db.initialize()` logs and re-raises on startup;
  routes that need Mongo surface `BusinessException` via the registered
  exception handlers in `src/server/errors.py`.
- Ollama unreachable → `domain/ai/chat.py` surfaces the timeout; the
  chat route returns the error code via `shared/error_codes.py`.
- Auth token mismatch → `header_verification_middleware` short-circuits
  the request with the configured error code (toggleable via
  `middleware.auth_enabled`).
- Observer guard depth exceeded → `ReentrancyGuard` (max_depth=3) aborts
  the nested call; the outer handler still completes.
- OSS upload failure → `domain/files/storage.py` raises
  `BusinessException(ErrorCode.OSS_UPLOAD_FAILED)`.
